> **一句话总结：** 本文提出 VTC-AUDIT——一种四臂干预式审计协议，在"全模型在干净与偏移图像上均正确、且压缩模型在干净图像上成功"的配对条件下，通过交叉"由哪张图像选取保留 token 位置（support）"与"由哪张图像提供视觉特征"，在三个 8–9B 开源 VLM、四种任务、八种图像偏移上证明：在偏移图像上重新选取保留位置（而非复用干净图像的位置）会在全部六个模型–压缩器组合上显著提高严格压缩特异性失败率（DivPrune +3.04–9.60 个百分点，ApET +2.05–4.20 个百分点，95% 置信区间均不含零），且 support 的 Jaccard 不稳定性作为逐样本失败预测器未达 0.65 的 AUROC 实用阈值，而干净压缩模型不确定性达到 0.705–0.844。

> **TL;DR:** VTC-AUDIT audits visual-token compression reliability on pairs where the uncompressed model is correct on both the clean and shifted image: across Qwen3.5-9B, LLaVA-OneVision-2-8B-Instruct, and InternVL3.5-8B on ChartQA/TextVQA/GQA/POPE under eight non-adversarial shifts (708,000 inference records), reselecting retained token positions on the shifted image instead of reusing the clean-image support raises the strict compression-specific failure rate (SCFR) over the frozen-support baseline by 3.04–9.60 pp for DivPrune and 2.05–4.20 pp for ApET (all 95% CIs exclude zero), 74.8–81.6% (DivPrune) of these dynamic failures persist even after clean features are restored, yet support Jaccard instability is a weak per-example failure monitor (orientation-free AUROC bound ≤ 0.605, below the pre-specified 0.65 target) while clean compressed-model uncertainty clears it (AUROC 0.705–0.844, L95 > 0.65 in all six settings).

## 核心贡献

- **提出 VTC-AUDIT，一种针对视觉 token 压缩的配对干预式可靠性审计协议。** 它只在"未压缩模型在干净与偏移两张图上都答对、且压缩模型在干净图上答对"的合格配置上度量增量风险（严格压缩特异性失败率 SCFR），从而把"压缩本身引入的新失败"与模型原有的失败干净地分离开来。
- **设计了四臂 support/特征干预。** 将"用哪张图像选取保留 token 索引集合（support）"与"用哪张图像提供视觉特征"做 2×2 交叉，得到 clean、dynamic（部署系统实际路径）、frozen（复用干净 support）、counterfactual（偏移选取的 support + 干净特征）四个臂；dynamic–frozen 对比量化"在偏移图上重新选位置"这一动作本身带来的额外失败，counterfactual 臂则检验偏移选取的 support 施加于干净特征后是否仍然有害。
- **在六个模型–压缩器组合上得到一致结论：重新选取 support 系统性地增加失败率。** DivPrune 上 SCFR 上升 3.04–9.60 个百分点，ApET 上上升 2.05–4.20 个百分点，所有 95% 置信区间均高于零，且在独立重采样的第二个 manifest（seed 2026）上全部复现。
- **区分了群体层面效应与逐样本预测。** 尽管 support 重选在平均意义上显著有害，support 集合的 Jaccard 不稳定性在合并四个基准的监控审计中是弱排名信号（无方向上界 ≤ 0.605，未达 0.65 实用阈值），而干净压缩模型的不确定性（答案 token 平均负对数概率）则显著更有信息量（AUROC 0.705–0.844）。
- **揭示了机制层面的压缩器依赖性：** 74.8–81.6% 的 DivPrune 动态失败在恢复干净特征后仍然失败（硬剪枝丢掉的信息无法恢复），而 ApET（合并式压缩）的比例为 55.6–64.1%——support 敏感性的来源因压缩算子而异。
- **公开了可复现的审计资产：** 代码、manifest 与实验输出开源（github.com/IsaacLi74/VTC-AUDIT），采用预注册式的实验设计（预指定偏移族、严重度、AUROC 阈值、confirmatory/descriptive 划分）。

## Key Contributions

- **VTC-AUDIT protocol:** a paired, interventional reliability audit for training-free visual-token compression (VTC) that conditions on configurations where the full model is correct on both the clean and shifted image AND the compressed model succeeds on the clean image, then measures the strict compression-specific failure rate (SCFR, zero-credit rate) only on this eligible population — isolating failures newly introduced by compression from the model's pre-existing errors.
- **Four-arm support/feature intervention:** crossing "which image selects the retained-index set (support)" with "which image supplies the visual features" yields clean, dynamic, frozen, and counterfactual arms. The dynamic–frozen contrast isolates the cost of reselecting support on the shifted image; the counterfactual arm tests whether shift-selected support stays harmful on clean features (persistence).
- **A consistent, replicated reselection effect:** dynamic SCFR exceeds frozen SCFR in all six model–compressor settings (+3.04–9.60 pp DivPrune, +2.05–4.20 pp ApET, every 95% interval above zero), reproduced on a separately resampled second manifest.
- **A monitor audit separating population effects from per-example ranking:** Jaccard support instability fails the pre-specified 0.65 practical AUROC target (orientation-free upper bound ≤ 0.605 in all six settings), while clean compressed-model uncertainty clears it (AUROC 0.705–0.844, L95 > 0.65) — support turnover magnitude is not a usable failure signal, but model uncertainty is.
- **Compressor-operator-dependent persistence:** 74.8–81.6% of DivPrune (hard-pruning) dynamic failures persist under restored clean features versus 55.6–64.1% for ApET (prune-and-merge), showing that set-level support overlap does not fully describe how the compressed representation changes across operators.
- **Open, pre-registered-style artifacts:** code, manifests, and outputs released; shifts, severities, AUROC target, confirmatory (DivPrune) vs descriptive-replication (ApET) status, and bootstrap procedures all pre-specified.

## Methodology

The audit factors a VLM *u* into a visual stage φ_u and language stage g_u, and treats a compressor *m* as a selector S_m(V) (which token indices to retain, the "support") plus an emitter C_{S_m}(V). A configuration is (clean image x, question q, reference answer a, shift T); the question and non-visual inputs are held fixed across all arms, and decoding is greedy/deterministic so arm differences cannot come from sampling noise.

**Eligibility:** a configuration enters the audit only if σ(full model, clean) = σ(full model, shifted) = σ(compressed, clean) = 1, where σ is the benchmark's scoring rule. This defines the population on which SCFR is meaningful: cases where the underlying VLM still handles the shift and clean compressed inference succeeded. Eligibility is compressor-specific and reported per setting (49.26%–68.39%).

**Four arms:** (1) clean — S_m(V), features V; (2) dynamic — S_m(V′), features V′ (what a deployed compressed system actually does); (3) frozen — S_m(V) applied to V′ (withholds reselection); (4) counterfactual — S_m(V′) applied to V (tests shift-selected support without feature drift). The key enabler is that all four shift families (JPEG quality 70/50, Gaussian noise σ=2/5 on 0–255, blur radius 0.5/1.0, brightness ×0.9/0.8) preserve the post-projector visual-token grid, so supports are exchangeable between clean and shifted representations; token-grid equality is verified for every pair.

**Estimands:** SCFR per arm = fraction of eligible configurations receiving zero credit, computed in each of 16 task–shift-family cells (4 tasks × 4 families, severities pooled) then macro-averaged. The paired reselection contrast Δ = SCFR_dyn − SCFR_frz gets 95% percentile intervals from 5,000 benchmark-stratified image-cluster bootstrap resamples. Persistence = fraction of dynamic failures that also fail counterfactually. A sensitivity analysis replaces the strict zero-credit rule with conditional score loss (1 − σ). The monitor audit then asks whether per-example support movement (Jaccard instability, 1 − |S∩S′|/|S∪S′|) ranks which eligible pairs fail, via pooled AUROC against the pre-specified 0.65 practical target; because Jaccard has no assumed direction, a conservative orientation-free upper bound U± = max(H, 1−L) is used, while clean compressed-model uncertainty (negative mean token log-probability of the clean compressed answer) is one-sided.

**Setup:** three open 8–9B VLMs (Qwen3.5-9B, LLaVA-OneVision-2-8B-Instruct, InternVL3.5-8B, HF revision pinned); four benchmarks with 500 images each (ChartQA, TextVQA, GQA, adversarial POPE); two training-free text-agnostic compressors at a matched 25% retained-position budget — DivPrune (greedy max–min diversity hard pruning, discarded tokens are dropped) and ApET (farthest-point-sampling basis + approximation-error ranking, removed tokens merged into cosine-nearest retained positions by group average; audit uses only the post-projector stage to keep aligned token grids, with hash-seeded deterministic FPS initialization). 708,000 inference records total; seed 42 is primary, seed 2026 an independent resampling for sensitivity.

## Results & Highlights

- **Reselection raises SCFR everywhere:** dynamic > frozen in all six model–compressor settings. For DivPrune, Δ = 3.04 [2.21, 3.85] pp on Qwen3.5-9B, 3.52 [2.81, 4.25] pp on LLaVA-OneVision-2-8B, and 9.60 [8.18, 11.13] pp on InternVL3.5-8B (SCFR 14.24% → 4.63%); for ApET, Δ = 2.05 [1.30, 2.82] / 2.46 [1.87, 3.08] / 4.20 [3.15, 5.28] pp respectively — every 95% CI excludes zero.
- **Failures are support-driven, not just feature-driven:** 74.8–81.6% of DivPrune and 55.6–64.1% of ApET dynamic failures also fail in the counterfactual arm after clean features are restored, so a majority of these failures cannot be attributed to shifted features alone.
- **Monitor audit (pooled over ChartQA/TextVQA/GQA/POPE):** Jaccard support instability has raw AUROC 0.423–0.564 with orientation-free upper bound U± ≤ 0.605 — below the pre-specified 0.65 practical target in all six settings — whereas clean compressed-model uncertainty reaches AUROC 0.705–0.844 with L95 > 0.65 everywhere (e.g., InternVL + DivPrune: Jaccard 0.426 vs uncertainty 0.785).
- **Strong task heterogeneity:** ChartQA is by far the most affected — model-averaged dynamic/frozen SCFR of 21.86%/7.20% for DivPrune and 15.00%/8.55% for ApET, versus 2.23%/1.33% and 1.35%/1.03% on POPE; the single largest cell is InternVL + DivPrune on ChartQA under brightness, Δ = 31.75 pp. Of 48 task–shift-family cells per compressor, 47 are positive for DivPrune (ApET: 41 positive, 3 zero, 4 negative, min −0.62 pp).
- **Partial-credit sensitivity confirms the effect:** using score loss (1−σ) instead of strict zero credit, dynamic loss exceeds frozen loss in all six settings with all 95% CIs above zero (e.g., InternVL + DivPrune Δ_score = 9.73 [8.24, 11.23] pp).
- **Clean compression cost and eligibility:** shifts barely move the full models (≤ 0.65 pp mean score change), but 25% compression itself is costly on charts — InternVL3.5-8B clean ChartQA falls from 78.00% (full model) to 29.80% (DivPrune) / 33.00% (ApET); eligibility ranges 49.26%–68.39% across settings.
- **Severity and replication:** stronger shifts raise frozen SCFR in all six settings while the reselection share Δ/SCFR_dyn shrinks (InternVL DivPrune 74.1% → 60.6%); the seed-2026 resampled manifest reproduces all six dynamic–frozen increases (3.09–8.71 pp DivPrune, 2.23–4.76 pp ApET) and the monitor conclusion (max Jaccard U± 0.596 < 0.65; min uncertainty L95 0.654 > 0.65).

## Authors & Credibility

Single-author paper by Isaac (Rucheng) Li (University of Pittsburgh, isl74@pitt.edu). The work shows unusually strong methodological hygiene for a solo audit paper: pre-specified shifts and severities, a pre-registered practical AUROC target (0.65) with a conservative orientation-free bound for the directionless Jaccard metric, an explicit confirmatory (DivPrune) vs descriptive-replication (ApET) split, benchmark-stratified image-cluster bootstrap intervals, a full second independently resampled manifest (seed 2026) for replication, greedy deterministic decoding, a pinned HF revision hash, manual inspection of 100 shifted examples per task for semantic preservation, and public code/manifests/outputs (github.com/IsaacLi74/VTC-AUDIT). Benchmarks (ChartQA, TextVQA, GQA, POPE), models, and the two audited compressors (DivPrune, CVPR 2025; ApET, CVPR 2026) are all standard, current, and open, lending the audit credibility.

## Critical Assessment

- **Novelty:** The core idea — conditioning on full-model correctness under paired shifts and crossing support-selection with feature-supply in a 2×2 intervention — is genuinely new for VTC evaluation. Prior work (VTCBench, LLMC+, compression-aware attacks) studied clean accuracy, standardized comparisons, or adversarial instability; this paper isolates a non-adversarial, compression-specific failure channel with a clean counterfactual design. The population-vs-per-example distinction (reselection hurts on average, yet Jaccard turnover cannot rank individual failures) is a sharp, non-obvious finding.
- **Rigor:** High. Macro-averaging over 16 task–shift cells, cluster bootstrap, a strict zero-credit estimand plus a partial-credit sensitivity analysis, and full replication on a resampled manifest are above the bar for this subfield. The honest treatment of ApET as "descriptive replication" (because merging makes retained information non-comparable at the same 25% position budget) is commendable.
- **Weaknesses in the estimand:** the frozen arm reuses a support already known to succeed on the clean image (eligibility conditions on clean compressed success), so Δ conflates "shift-triggered reselection" with "support replacement in general" — the paper admits this. A "replace support with another clean-image-equivalent selection" control (e.g., support from a second clean augmentation or a random-diverse reselection) is missing, which would have cleanly separated shift-specificity from generic selection sensitivity.
- **Single operating point:** everything runs at 25% retention; the 50%-retention runs are exploratory on a subset only. Since the practical deployment question is "which budget is safe under distribution shift," the absence of a retention sweep leaves the headline effect uncharacterized as a function of compression strength.
- **Task quirks drive the headline:** the aggregate effect is dominated by ChartQA (e.g., 31.75 pp max cell) while POPE contributes almost nothing (2.23%/1.33%); nearly-binary yes/no or exact-match scoring means a single flipped token counts as full failure. The paper reports this heterogeneity transparently but does not analyze *why* chart-reading support is so fragile (fine-grained OCR-critical tokens?), which limits mechanistic takeaway. Also, the "ChartQA clean score 78.00% → 29.80%" collapse on InternVL suggests that for some model–task pairs the eligible population is heavily selected toward easy examples.
- **Monitor comparison is thin:** only two candidate predictors (Jaccard instability and clean compressed-model uncertainty) are tested; obvious alternatives — feature-space drift norms, attention-map shift, or per-position overlap (which retained positions changed, not how many) — are motivated in the discussion but not evaluated.
- **Red flags:** minor. The 0.65 AUROC "practical target" is admittedly a convention; the shift-semantics check covered only 100/500 examples per task and was not repeated on seed 2026; the audit requires grid-preserving shifts, so geometric transforms and pre-projector compression are out of scope; cross-compressor SCFR comparisons are only descriptive.

## Strengths

- A clean, well-controlled interventional design (2×2 support/feature crossing) that isolates *reselection* as a failure channel rather than merely correlating compression with accuracy loss.
- Estimand discipline: strict eligibility conditioning, pre-specified targets and confirmatory/descriptive split, cluster bootstrap intervals, orientation-free bounds for the directionless metric, and a full independent replication sample — a model of audit-style methodology.
- Practically actionable conclusions: (1) VTC evaluations should report conditional reliability alongside clean accuracy/efficiency; (2) the dynamic–frozen gap is a concrete optimization target for support-stabilization / adaptive-retention methods; (3) clean compressed-model uncertainty is a deployable failure monitor while support-overlap heuristics are not.
- Broad coverage within its scope: 3 VLMs × 2 compressors × 4 tasks × 8 shifts = 708,000 records, with all artifacts open-sourced.

## Limitations

- Single 25% retained-position operating point; no systematic retention-ratio sweep (50% runs are exploratory only), so budget dependence of the reselection effect is unknown.
- The conditional estimand does not separate shift-specific reselection from support replacement in general (frozen arm reuses a clean-successful support by construction); overall compressed-model error rates on the full distribution are outside the audit's scope.
- Scope limits: three 8–9B open VLMs, two text-agnostic training-free compressors (instruction-conditioned methods like CDPruner excluded), non-adversarial grid-preserving shifts only; geometry-changing transformations or pre-projector compression would need an explicit index-correspondence construction.
- ApET is audited only at its post-projector stage, not its original multi-stage operating point, so findings may not transfer to its default deployment configuration.
- The monitor audit pools all four benchmarks; task-specific monitor behavior and support-based signals beyond set-level overlap (e.g., which positions changed) are unanalyzed.
- Shift-semantic preservation was manually verified on only 100/500 examples per task and not on the seed-2026 sample.

## Relevance

与"极端性能优化下的可靠性"研究方向高度相关：视觉 token 压缩是典型的推理端降本优化，本文系统刻画了它在不改动模型本身的情况下引入的静默失败，并给出了可部署的失败监控信号（干净压缩模型不确定性），这正是"优化引入的精度/正确性问题"的核心关切；其对逐样本失败预测（AUROC 监控审计）的建模也与推理期可靠性检测的思路相通。

## Questions for Further Exploration

- How does the dynamic–frozen reselection gap scale with the retained-position budget (10%, 50%, 75%) — does support sensitivity vanish above some retention threshold, or only shrink?
- Would a control arm that replaces the support with a *different clean-selected* support (e.g., from an unrelated clean augmentation) separate shift-triggered reselection from generic support-replacement sensitivity?
- Which *positions* matter: does a predictor based on which retained indices changed (e.g., overlap restricted to OCR-critical or high-attention regions) beat set-level Jaccard and approach the 0.65 AUROC target?
- Do instruction-conditioned compressors (e.g., CDPruner) exhibit the same reselection fragility, or does conditioning on the question stabilize support under shifts?
- Can support-stabilization mechanisms (e.g., temporal smoothing of selection across augmentations, or hysteresis in index selection) close the 3–10 pp dynamic–frozen gap without hurting clean accuracy?
- Does clean compressed-model uncertainty remain a valid monitor under adversarial shifts, geometry-changing transforms, or in streaming/multi-image settings where the token grid is not shared?
