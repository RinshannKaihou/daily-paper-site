Why this matters

Chemistry agents fed SMILES silently lose facts the model demonstrably knows; name–SMILES conflicts steer answers undetected.

01Methodology — diagnosis, then repair

Hold the molecule and the property fixed; vary only the identifier.

Benchmark. 3,025 ChEMBL drug–indication records cleaned to 896 unambiguous molecules, each queried three ways — trivial name, IUPAC name, canonical SMILES. Facts scored against normalized ChEMBL answers; structure-computable properties (benzene ring, atom counts) against RDKit truth.

Recognition controls. 2AFC and stricter free-form naming isolate molecules whose SMILES↔name mapping the model demonstrably knows — separating recognition from retrieval.

Four interventions. Lexical bridging (append the name to the SMILES prompt); conflicting identifiers (A's SMILES + B's name — which route controls which answer?); activation patching (transplant the final-token residual state from the name query, different-molecule patches as negative controls); depth-wise probing (retrieve the co-referring SMILES among all 896 candidates).

The fix. Binding Self-Distillation: a frozen, name-augmented teacher pass distilled into a SMILES-only student via full-vocabulary KL — no factual labels, no external teacher, name removed at inference.

LoRA r=8, α=16 · MLP layers 20–24 · 120 AdamW steps / molecule · 6 binding + 8 anchor stems · editing diagnostic leakage-subtracted (ROME / MLP-FT)

Table — ChemDFM-v2.0-14B on ChemIDBench; every molecule queried under every identifier. The dissociation runs both directions: SMILES wins structure, name wins facts.

  • Recognition ≠ retrieval. On the 576 molecules the model correctly identifies from SMILES, indication accuracy is still 4.0% vs 42.7% by name.
  • Causal restoration. Patching the name-route state closes 76.4–138.4% of the log-prob gap; every different-molecule control patch is strongly negative.
  • Representation asymmetry. Name→SMILES top-1 retrieval only 0.7–2.8% (chance 0.11%); IUPAC→SMILES reaches 13.5–15.0%.
  • Editing doesn't repair the route. Name-route ROME / fine-tuning transfers beyond leakage in only 2 of 8 configs (best: Llama-3.1-8B + ROME, +13.0 pts).
  • BSD lifts every fact type via SMILES alone. Target 0.0→27.6% · ATC class 3.3→11.4% · facts per entity 0.05→0.87 (86% of name-route gap); Qwen2-72B 0.01→0.85 (63%).
  • Beyond chemistry. Same pattern with UniProt accessions vs gene symbols (16,388 human proteins).
  • Lookup routing baseline. Closes 83.6–98.8% of the gap — but models self-resolve SMILES→name for only 0.1–12.0% of molecules.

03Strengths

  • Exceptionally clean design — molecule and property held fixed, only the identifier varied, enabling molecule-by-molecule paired statistics.
  • A complete evidence ladder — behavioral, interventional, representational, and causal (patching with negative controls) all converge on one diagnosis.
  • Honest negative results — knowledge editing fails in 6/8 settings and self-resolution is ≤12%, motivating the fix rather than assuming it.
  • Elegant fix — no labels, no external teacher; retention checks show 94.1% benzene-verdict preservation.
  • Generality probe — the UniProt replication shows the failure is not an artifact of structural notation.

04Limitations

  • One adapter per molecule — no parameter sharing; cost grows linearly with compound count; no unseen-entity generalization.
  • Favorable evaluation subset — BSD tested only on molecules whose facts the model already retrieves by name.
  • Stem overlap — training stems semantically overlap evaluation relations; not strict held-out evidence.
  • Thin replication — protein study truncated to 1,000 entries for 4 of 5 models; no pinned UniProt release.
  • Only 3 identifier types — InChI, SELFIES, molfiles, brand names untested; paraphrased answers may be undercounted.
  • Lab vs wild — conflict detection tested only in explicit-comparison formats, unlike real pipelines.

05Questions for further exploration

  1. Can BSD become a single shared adapter — or a small routing module — that generalizes to unseen molecules?
  2. Does binding failure appear in other identifier systems: InChI/SELFIES, gene IDs vs protein names, materials formulas vs CIF snippets?
  3. Which attention head or MLP sub-circuit implements the binding — does chemistry fine-tuning never form it, or overwrite it?
  4. Would name–SMILES co-occurrence pretraining prevent the failure from arising at all?
  5. Can the weak wrong-name rejection (17.5–43.1%) be exploited as a cheap dual-route consistency check in chemistry agents?
  6. Why doesn't scale help — the 72B model shows the same ~1% SMILES indication accuracy as 7B models.
