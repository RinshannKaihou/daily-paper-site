Why this matters

Agent reliability is won at ingestion, not reasoning — 32.8% of 6,462 real policy docs carry deliberate colour/highlight cues, and the loss is invisible to pipeline health checks.

Every arm returns well-formed output that passes schema and token-count checks. The fix is deterministic, code-only, and cheap.

Critical edge

The headline +0.085 typing gain is borderline: pHolm = 0.049, replicating on only 3 of 6 answering models.

The abstract's "+0.085" carries more weight than a threshold p-value and half-failed replication warrant — the authors disclose this, the number doesn't.

Also: the OCB win (0.959 vs 0.810) is partly mechanical — they are the only system that parses headers, footnotes, metadata and comments at all.

Methodology — distilled

  • Code-only parser, zero LLM calls. python-docx; every contiguous same-formatting text run becomes a FORMATTINGSPAN (12 attributes).
  • 11 high-confidence formatting→semantics mappings: red text/highlight → CRITICAL_WARNING, any highlight → WARNING, strike → DEPRECATED, partial bold → KEY_TERM. Medium-confidence guesses deliberately excluded — a wrong hint biases worse than none.
  • Hybrid serialization: Markdown pretraining saw (**bold**, ~~struck~~) + custom tags ([COLOR:#FF0000], [HIGHLIGHT:YELLOW]) — 15–20% more token-efficient than pure tags, ~2× plain-text tokens.
  • Walks what naive parses miss: headers/footers, footnotes, document properties, OMML equations, tracked changes (accepted revision = text in force).
  • Three-layer evaluation: 76–79-doc real-policy task (OOXML ground truth, deterministic 4-consecutive-word lexical matcher, paired sign tests + Holm + bootstrap CIs); Microsoft's OCB File-Fidelity Word track (external); equal-preprocessing control on 68 docs varying only parsed text.
  • Model eligibility pre-fixed by a competence screen; all six reported models pass; Mistral Large 3 reported out-of-population, not discarded.

Common cues carry no intent signal. Colour — the one cue no mainstream converter preserves and no parsing benchmark scores — is load-bearing.

  • Opposite pathology, same missing cue: under Claude Sonnet 5, recall collapses to 0.09 at precision 0.96 — extreme abstention instead of over-assertion.
  • External benchmark (Microsoft OCB, 326 items): 0.959 vs 0.810 docx2python / 0.720 docling / 0.634 plain text (all pHolm < 10⁻⁶); only system answering Metadata, Comment and Footnote items at all (1.000 vs 0.000).
  • It's salience, not content loss: equal-preprocessing pipeline (68 docs, identical prompt/model) — 0.503 vs 0.258 / 0.084 while gold-requirement text retention is near-identical (0.665 / 0.634 / 0.607); marked requirements reach the output 2.3× more often.
  • Task ceiling measured: supervised text-only classifier tops out at ROC AUC 0.664 — 0.690-level performance is unreachable from wording alone.
  • Cross-format (PDF, ParseBench): 65/126 formatting cues recovered vs 0/126 for plain text; only significant per-cue difference is highlight (11/18 vs 4/18).

Strengths

  • No judge-model goodwill — ground truth from the file's own OOXML markup, deterministic LLM-free scorer.
  • Sharp, actionable claim: the ablation converts "formatting matters" into "colour + highlight only", and the cue-specificity check (removing colour hurts only colour-marked docs) validates the manipulation itself.
  • Pre-registration with full execution history — including a re-run that worsened their own p-value (0.005 → 0.049).
  • Failure modes honestly characterized: over-flagging in some models, extreme abstention in others — both invisible without ground truth.
  • External validation on a benchmark they didn't write (OCB) plus a PDF cross-format replication.

Limitations

  • No human annotators yet — labels validated against rendered page images (κ = 0.72); OOXML can encode cues the author never intended.
  • Typing benefit is model-conditional: significant on 3/6 models, absent on the two that barely attempt the task.
  • No OCR — scanned PDFs (cue survives only as pixels) are out of scope.
  • ~2× plain-text token cost — a deliberate factuality-for-context trade, real at 50–300-page document sizes.
  • Exposure is partial and English-only: ~⅓ of documents, policy/SOP prose where colour conventions are strongest; cue semantics are culturally inflected.

Questions for further exploration

  1. Does the colour/highlight dominance hold for non-policy corpora (contracts, specs, tickets), or is the cue hierarchy corpus-specific?
  2. Could a small supervised model learn per-organization colour semantics instead of the 11 hand-crafted rules — closing or widening the +0.085 typing gain?
  3. Does cue typing help reasoning models as much as instruction-followers, or is the benefit purely an instruction-following phenomenon?
  4. How does silent cue loss interact with RAG chunking — and can "recovered cue implies located span" generalize into a standard pipeline health check?
  5. Can geometric colour/highlight detection for scanned pages survive compression and annotation artefacts at the born-digital κ = 0.72 level?
