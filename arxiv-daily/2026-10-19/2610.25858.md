> **一句话总结：** 该论文首次系统评估非参数自进化 LLM 智能体（冻结权重、只改写提示词/记忆/技能库等 harness）在漂移任务流上的持续学习能力：在 BIRD、BFCL、ScienceWorld 构成的四条漂移流上测试 ReasoningBank、GEPA、Meta-Harness 三种方法，发现它们都陷入"可塑性—稳定性"权衡（r = −0.72）——自修改方法产生跨任务干扰与覆盖性遗忘，检索式方法则存在外域记忆注入与检索冲突，因此现有自进化智能体仍不是合格的持续学习器。

> **TL;DR:** This Google DeepMind/Mila paper asks whether nonparametric self-evolving LLM agents (frozen weights, evolving harness: prompts/memory/skills/code) are effective continual learners. On four drifting task streams built from BIRD, BFCL, and ScienceWorld (blocks of 50 tasks per group, T = 100–200), GEPA averages +3.7pp terminal advantage over the seed harness but loses −4.3pp stability, while ReasoningBank is the most stable (−1.9pp) with roughly half the plasticity (+3.3pp) — an overall plasticity–stability correlation of r = −0.72 (p = 0.008). Both paradigms fail in characteristic ways (global prompt overwriting; retrieval collision between BFCL-Miss and BFCL-Base at 0.835–0.840 cross-group cosine similarity), so current self-evolving agents remain incomplete continual learners.

## 核心贡献

- **提出持续学习视角的形式化框架**：将非参数自进化智能体建模为在任务流上的持续学习器——形式化了"进化器"（evolver）$f$ 如何从累积经验 $\mathcal{H}_t$ 更新 harness $c_{t+1} = f(c_t, \mathcal{H}_t)$（模型权重 $\theta$ 冻结），并将经典持续学习的可塑性（plasticity）与稳定性（stability）指标适配到智能体 harness 演化场景，还细分出"块前干扰"（pre-block interference）与"块后遗忘"（post-block forgetting）两个失败维度。
- **构建四条受控漂移任务流基准**：用 BIRD（text-to-SQL）、BFCL（多轮 API 调用）和 ScienceWorld（交互式科学实验）拼出主题漂移、工作流漂移、领域漂移与复合漂移四条流（每组 50 个训练任务、不相交的 50/90 任务评测集），隔离三类分布偏移及其组合，且流中不告知组标签与块边界（task-free 设定）。
- **系统评估三大代表性方法**：覆盖经验检索（ReasoningBank，检索 top-1 相似记忆）与自我修改（GEPA 改写共享策略提示词；Meta-Harness 编辑提示词+记忆/技能文件+控制器代码）两种范式，统一使用 Gemini 3.6 Flash 作为底层模型，隔离出进化器本身的影响。
- **给出决定性的负面结论与机制解释**：可塑性与稳定性在所有场景下呈负相关（r = −0.72）——自修改方法对共享提示词/工作区的全局编辑造成跨任务干扰与压缩覆盖；相似度检索虽能在远域间避免遗忘，却在外域任务上注入无关记忆（未见过组 100% 检索到外来记忆），并在同域不同工作流间发生检索冲突（BFCL-Miss/Base 跨组最近邻相似度 0.835–0.840 与组内 0.834–0.837 无法区分）。
- **深入到行为层面的机制分析**：通过追踪 GEPA 提示词中各组规则的字符占比（如复合漂移中 BIRD-F1 占比从 59.5% 跌至 4.1%，+4.0pp 增益被完全抹掉）和澄清提问率（BFCL-Miss 块后 29.8% → 后续 BFCL-Base 块后 11.2%，对应 13.0pp 精度回撤），把抽象的"遗忘"落实为具体的提示词覆盖与行为反转。

## Key Contributions

- Formalizes nonparametric self-evolving agents as continual learners: an evolver $f$ updates the harness (system prompt, memory, skills, controller code) from accumulated experience while model weights stay frozen, and classical continual-learning metrics (plasticity, stability) are adapted, with stability decomposed into pre-block interference and post-block forgetting.
- Constructs four controlled drifting task streams from BIRD, BFCL, and ScienceWorld that isolate topic drift, workflow drift, domain drift, and compound drift, with 50 training tasks per group, disjoint hold-out evaluation sets, no group labels or block boundaries revealed to the agent (task-free setting).
- Provides the first head-to-head continual-learning evaluation of three representative methods spanning both self-evolution paradigms — ReasoningBank (experience retrieval), GEPA (shared strategy-prompt rewriting), and Meta-Harness (full workspace editing including controller code) — on one fixed base model (Gemini 3.6 Flash in a ReAct loop).
- Establishes the central empirical finding: a consistent plasticity–stability trade-off (r = −0.72, p = 0.008, n = 12) — self-modifying methods buy plasticity with cross-task interference and overwriting, while similarity-based retrieval localizes updates across distant domains but cannot prevent foreign-memory injection or retrieval collision.
- Delivers mechanistic, behavior-level explanations: character-share tracking of GEPA's evolving prompt, prompt autopsies showing SQLite exploration rules injected into BFCL-Miss, a behavioral-reversal analysis of clarification-asking rates, and a query-embedding similarity matrix explaining why no retrieval threshold can separate conflicting workflows.

## Methodology

The paper casts an LLM agent as a policy $\pi_{\theta,c}$ determined by frozen weights $\theta$ and a harness $c$ (system prompt, accumulated memory, skill libraries, control code). After each episode the evolver maps the current harness and experience to the next harness, $c_{t+1} = f(c_t, \mathcal{H}_t)$, with binary success reward. Task streams are defined over $K$ task families via a weight schedule; the paper uses drifting streams — contiguous blocks of one-hot, piecewise-constant schedules where each block trains on a single task group (50 training tasks per group) and the agent never sees group labels or boundaries.

Four streams isolate different shifts: **topic drift** (T = 150, K = 3: BIRD-F1 → BIRD-Code → BIRD-TP, same text-to-SQL workflow, different database schemas); **workflow drift** (T = 100, K = 2: BFCL-Miss → BFCL-Base, same APIs, but BFCL-Miss requires asking the user for missing arguments while BFCL-Base penalizes unnecessary clarification); **domain drift** (T = 150, K = 3: ScienceWorld → BFCL-Base → BIRD-F1, disjoint observation/action spaces); and **compound drift** (T = 200, K = 4: BIRD-Code → BIRD-F1 → BFCL-Miss → BFCL-Base). Evaluation uses disjoint hold-out sets (50 tasks per group, 90 for ScienceWorld), checkpoints at every block boundary, and 8 rollouts per instance.

Metrics are all reported as advantage over the seed harness $B_k$ in percentage points: terminal advantage (Term.), average advantage ($\bar{\Delta}$), within-block plasticity $P$ (gain at the end of a group's own block), and cross-block stability $S = -(\bar{I} + \bar{F})$ combining pre-block interference (drops before a group's block starts) and post-block forgetting (decay from block end to stream end). Three methods are compared: ReasoningBank distills each episode into a memory item and retrieves the top-1 most similar item (gemini-embedding-2, cosine similarity); GEPA reflectively rewrites a shared strategy section of the system prompt; Meta-Harness proposes edits to the prompt, memory/skill files, and controller code via a coding agent, accepting edits only if they improve validation accuracy. All runs start from the same empty seed harness, use the same Gemini 3.6 Flash backbone (temperature 1.0, 8192 max output tokens, medium thinking), and receive only binary task-success feedback. Appendix analyses add: an interleaved uniform mixture (rehearsal-style) schedule, per-group interference/forgetting decomposition, evolved-prompt autopsies, the retrieval similarity matrix, and a Meta-Harness gate ablation.

## Results & Highlights

- **Aggregate gains are real but modest, and topic drift breaks them.** Averaged over the four streams (mean seed accuracy 62.0%), terminal advantage is +3.7pp for GEPA ($\bar{\Delta}$ +3.1), +2.5pp for ReasoningBank ($\bar{\Delta}$ +2.0), and +1.4pp for Meta-Harness ($\bar{\Delta}$ +1.8) over the seed harness. On topic drift alone, net change is near-zero or negative: −1.7pp (GEPA), +0.3pp (ReasoningBank), −1.5pp (Meta-Harness).
- **Plasticity and stability are negatively correlated.** GEPA has the highest plasticity in every scenario (+6.2pp average, +11.0pp on workflow drift, +7.5pp on compound drift) but the largest stability loss (−4.3pp average); ReasoningBank achieves the best stability (−1.9pp average, only −0.4pp on domain drift) at roughly half GEPA's plasticity (+3.3pp). Across all 12 scenario-method points the plasticity–stability Pearson correlation is r = −0.72 (p = 0.008).
- **Self-modification interferes with unseen tasks before they arrive.** On domain drift, training on ScienceWorld lowers unseen BFCL-Base at position 50 by 5.5pp under GEPA and 1.5pp under Meta-Harness; on compound drift, BFCL-Miss drops to −6.8pp (GEPA) and −4.8pp (Meta-Harness) at position 100 before any BFCL task has arrived — prompt autopsies show mandatory SQLite-exploration and interactive-verification instructions biasing the agent toward exploratory tool calls instead of asking the user for missing arguments.
- **Post-block forgetting is prompt overwriting, made visible.** On topic drift, BIRD-F1's share of GEPA's strategy prompt falls from 100% (position 50, +7.5pp advantage) to 75.2% (position 100) and 40.2% (position 150, accuracy −2.0pp). On compound drift, GEPA compresses seven BIRD SQL sections (3,386 characters at position 100) into one 1,034-character section; BIRD-F1's share collapses from 59.5% to 5.8% (4.1% at position 200), erasing its +4.0pp gain entirely.
- **Behavioral reversal under conflicting workflows.** The seed agent speculatively calls tools on 91–93% of BFCL-Miss episodes (clarification rate 3.8–5.8%). After the BFCL-Miss block, GEPA raises the clarification rate to 29.8% (+15.5pp accuracy); the subsequent BFCL-Base block then cuts it to 11.2% (119→45 of 400 rollouts) and drops BFCL-Miss advantage from +15.5pp to +2.5pp (−13.0pp). Meta-Harness shows the same reversal on compound drift: clarification asks fall from 60.8% to 8.5%, accuracy −10.2pp at position 200.
- **Retrieval collision is unfixable by thresholding.** BFCL-Miss and BFCL-Base queries have cross-group nearest-match cosine similarity of 0.835–0.840 — statistically indistinguishable from their within-group similarity (0.834–0.837) — so no threshold can separate the workflows; at stream end, 52% of BFCL-Miss episodes retrieve a BFCL-Base memory (46% vice versa), dropping BFCL-Miss from +12.5pp to +4.5pp (−8.0pp) under ReasoningBank on workflow drift. Meanwhile, any group evaluated before its own block receives foreign memories in 100% of episodes (e.g., BIRD SQL reflections pull unseen BFCL-Miss to 3.2pp below seed on compound drift).
- **Interleaving and validation gates don't rescue the shared surface.** Under a uniformly interleaved mixture of the compound stream, GEPA's terminal advantage falls from +5.8pp (blocked) to +0.9pp, with BIRD-Code's prompt share decaying 37.0% → 5.8% by position 200. Meta-Harness looks stable on topic/workflow drift (S = −0.3/−0.5) only because its validation gate rejects half or more candidate edits; removing the gate drops its stability to −3.1pp (topic) and −5.5pp (workflow) at the cost of plasticity.

## Authors & Credibility

The work is led by Xiaoyin Chen (Mila – Quebec AI Institute / Université de Montréal, work done as a student researcher at Google DeepMind; also an author of the Learning-to-Self-Evolve line, "LSE") with a Google DeepMind team (Yizheng Huang, Yinglun Xu, Ziyun Zhao, Emmett McQuinn, Julie Liu, and corresponding author Hope Yao). It is a Google-copyrighted, DeepMind-backed empirical study — the same authors built one of the evaluated methods' ecosystem context, and the paper is refreshingly willing to publish a largely negative result about a fashionable direction (self-evolving agents). The evaluation methodology borrows established continual-learning metrics (Kemker et al., Lopez-Paz & Ranzato) rather than inventing bespoke ones, which increases comparability and credibility. The analyses go down to prompt-composition and rollout-level behavioral evidence (e.g., counting clarification asks over 400 rollouts), which is unusually thorough for an agent-evaluation paper.

## Critical Assessment

- **Novelty:** High for the evaluation framing. Prior self-evolving-agent papers (GEPA, ReasoningBank, Meta-Harness, Reflexion, ExpeL, Voyager) evaluated only stationary single-family benchmarks (K = 1); importing continual-learning metrics and drift streams into harness evolution is a genuine and overdue contribution. The paper proposes no new method, which is appropriate for its question.
- **Rigor:** Strong experimental hygiene — one fixed backbone across all methods, disjoint train/eval sets, checkpointed evaluation on all K groups (not just the active one), 8 rollouts per instance, and a stability decomposition that distinguishes interference from forgetting. The mechanistic analyses (prompt character-share tracking, similarity matrices, gate ablation) go well beyond aggregate scores.
- **Weaknesses in scope:** All results use a single model (Gemini 3.6 Flash); whether the trade-off magnitude transfers to stronger models is untested. Streams are short (T = 100–200) with only 2–4 groups, and each scenario uses a single fixed block order — order effects are not averaged over random permutations, so scenario conclusions partly confound content with ordering. The r = −0.72 correlation rests on n = 12 points (p = 0.008), suggestive rather than conclusive.
- **Potentially unfair configurations:** ReasoningBank is run with top-1 retrieval and no similarity threshold — the acknowledged worst case for foreign-memory injection; the paper argues thresholds cannot separate BFCL workflows (0.835–0.840 vs 0.834–0.837), which is convincing for that pair, but a thresholded variant could still reduce cross-domain interference and would strengthen the claim. Meta-Harness's proposer runs in a different harness (opencode) than the evaluated seed, a minor asymmetry.
- **Missing baselines/ablations:** No oracle upper bound (e.g., per-group harness selection with a perfect router) to quantify the headroom, and no parametric continual-learning or simple replay baseline for context. The additive-update regime GEPA spontaneously discovers on domain drift (retaining all six ScienceWorld sections verbatim, F̄ = 0.0) suggests a targeted "append-only" ablation that was not run.
- **Reproducibility:** Setup details are unusually complete (seed prompts, environment preambles, generation parameters, embedding model), but no code or benchmark-stream release is mentioned, and the harnesses depend on internal DeepMind tooling, which will hinder independent replication.
- **Overclaiming risk:** Low. The conclusion ("current self-evolving agents remain incomplete continual learners") is directly supported by the data, and the paper is explicit that self-evolution does improve aggregate performance in most settings.

## Strengths

- Frames a timely, important question (do self-evolving agents actually accumulate durable capability?) with a clean formal bridge between continual learning and harness evolution.
- Four drift scenarios that cleanly separate topic/workflow/domain shifts are a genuinely reusable evaluation design; the BFCL-Miss vs BFCL-Base pair is an elegant minimal example of same-domain conflicting workflows.
- The failure mechanisms are not just measured but explained: prompt share tracking shows overwriting numerically, and the clarification-rate analysis shows forgetting as a literal behavioral reversal (29.8% → 11.2% under GEPA).
- The retrieval-collision finding — cross-group similarity indistinguishable from within-group similarity (0.835–0.840 vs 0.834–0.837) — is a sharp, quotable negative result for the "just add a threshold" defense of similarity-based memory.
- Appendix robustness checks (interleaved Mix schedule, Meta-Harness gate ablation, per-group decomposition) pre-empt the two most obvious objections.

## Limitations

- Single backbone model (Gemini 3.6 Flash); plasticity–stability magnitudes on other models, or with stronger/weaker seed prompts, are unknown.
- Short horizons (100–200 tasks, 2–4 blocks) with a single block order per scenario; no variance over stream orderings or repeated runs with different seeds is reported.
- ReasoningBank tested only in a top-1, threshold-free configuration; k-NN retrieval, thresholding, or workflow-aware memory selection are untested.
- Only nonparametric (harness-only) evolution is studied; the comparison to gradient-based continual learning is conceptual, not empirical.
- No released code/benchmark streams mentioned, and metrics are relative to each method's own seed harness rather than to an oracle per-group harness, making headroom hard to judge.

## Relevance

这篇论文直接命中"Self-Evolving Agents & Automated Research"兴趣方向：它对 ReasoningBank、GEPA、Meta-Harness 三种自进化/自我改进智能体方法在非平稳任务流上的可靠性做了首个持续学习视角的系统评估，揭示了长期运行自主智能体系统中跨任务干扰、覆盖性遗忘与检索冲突等静默失败模式——对设计更可靠的自进化记忆与提示词更新机制有直接指导意义。

## Questions for Further Exploration

- Would an append-only constraint on GEPA's prompt edits (forbidding compression of earlier sections) preserve its plasticity while eliminating the overwriting forgetting, or does prompt-length growth itself degrade performance?
- Can retrieval be conditioned on workflow signals beyond query similarity (e.g., tool-call traces, environment identity, outcome-conditioned memory keys) to break the BFCL-Miss/Base collision that cosine similarity cannot?
- How does the trade-off scale with horizon length and number of groups (T = 1000+, K = 10+), and does the GEPA compression pressure get worse as the shared prompt saturates?
- Do stronger base models or models with explicit in-context retrieval training shrink the pre-block interference from foreign memories, or is that failure structural to top-1 retrieval?
- What is the oracle headroom: how much of the plasticity gap could be recovered by a perfect per-group router selecting among separately evolved harnesses, and can a learned router approximate it without group labels?
- Could parametric evolvers (test-time weight updates) be evaluated under the same streams and metrics for a fair nonparametric-vs-parametric continual-learning comparison?
