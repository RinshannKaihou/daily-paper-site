Why this matters

A model can quote a document it never used to decide — so a RAG system's source self-reports cannot be verified by checking context at report time.

⚠ Critical edge

The 100%-everywhere transplant table is conditional on eligibility filtering (92–100%) — excluding exactly the runs where the mechanism might be weakest.

01Methodology — intervene between answer and question

H1re-read document rejected H2check parametric knowledge rejected H3cached “source trace” supported
  • Task. 155 facts × 8 relations, each with 7 one-sentence document variants (true, 2 counterfactual, 2 irrelevant, 2 neutral) — token-length-matched per tokenizer so cache entries are positionally interchangeable.
  • The lever. Edits land after the greedy answer, before the fixed source question: text, positions, and the answer string stay identical while cached state varies — decoupling what the model saw from what processing it left behind.
  • Edits. Drop or transplant (Q / A / Q+A / document spans) of KV entries between runs of the same fact that saw different documents.
  • Steering. Per-layer direction = mean difference of position-averaged values (supporting − irrelevant), fit on held-out relation splits; apply V ± αd with norm-matched random and energy-matched PCA controls.
  • Clamps. Copy donor K+V but restore/impose 1-D projections onto fitted directions (values via dot-product, keys via norm-preserving pre-RoPE rotation, ~2×10⁻⁷ error).
  • Readout. Forced-choice “context/knowledge” scored by token log-prob — matches free generation in 99.6–100% of cases; replication on DynamicQA Wikipedia paragraphs (Appendix E).

02Results — what flips the report

InterventionFlip rateScope
Document drop / swap / insert true fact 0% all 4 models · quotes survive 100%
Q+A cache transplant 100% all 4 models · 97.2–100% on DynamicQA
Steering, fitted direction (α=3) 98.9–100% OLMo-7B & Qwen-8B · 4 doc conditions
Steering, norm-matched random direction ≤1.1% same operating points · >85× specificity gap
Clamp: restore own projections after transplant 1.1% / 0% OLMo / Qwen · near-necessity
Donor projections alone, no transplant 97.9% / 100% OLMo / Qwen · near-sufficiency
Energy-matched PCA control clamp 100% / 94.7% effect is specific 1-D directions, not magnitude
Steering during generation (vs opposing instruction) 51.2–85.3% switches the actual answer source · ≤9.3% damaged
  • Surgical, not destructive. At operating points, 100% of flipped runs still repeat the answer verbatim and quote the full document.
  • The trace is written early. Answer-only transplants flip just 0–3% on three of four models — source info is cached during question+document processing.
  • Scale asymmetry. At 32B, question-only swaps flip 14.2% (Qwen3-32B) vs 6.7% (OLMo-3.1-32B) in asymmetric cells — motivating the joint Q+A design.

03aStrengths

  • One of the cleanest causal designs in the self-report literature: identical visible text, only cached state swapped.
  • Exhaustive matched controls — random directions, energy-matched PCA subspaces (3–186 dims), re-splice and same-condition donors.
  • Cross-model breadth for edits/transplants: 4 models, 2 families, 7B–32B, plus a benchmark-derived DynamicQA replication.
  • Behavioral preservation checks show the edit changes the report, not the cached content readouts.
  • Honest scoping: hypotheses tested as sufficient explanations; explicit disclaimers of what is not established.

03bLimitations

  • Steering, direction fitting, and projection clamps cover only the two 7–8B models — the 32B models support just edits/transplants.
  • Templated one-sentence documents; natural multi-document retrieval, long contexts, and multi-turn dialogue are untested.
  • Fitted directions cannot separate evidence availability from actual source use; they span layers and Q/A positions, not one global variable.
  • Rates are conditional on pre-registered eligibility filtering (OLMo irrelevant runs retained only 81–82%).
  • Joint K+V clamps lack answer-repetition/read-back checks; no public code/data URL appears in the preprint.

04Questions for further exploration

  • Does the fitted direction encode evidence availability or actual source use? A used-but-invisible vs visible-but-unused contrast could separate them.
  • Why does the trace sit in the question span (answer-only flips 0–3%)? Layer- and position-resolved patching could localize where it is written.
  • Do the 32B question-only asymmetries grow with scale — does the linear-direction account survive at 70B+ or frontier models?
  • Can the direction become a runtime monitor that flags when a RAG system's citations diverge from its actual context dependence?
  • Are these KV-value directions the same subspace as SAE knowledge-conflict features (SpARE)?
  • Does report invariance hold across source-question paraphrases, languages, and adversarial phrasings (“are you sure you used the document?”)?

Bottom line: the authors themselves disclaim general reporting accuracy and any full interpretation of this state — what is established is where the report causally reads from, not that reports are usually true.
