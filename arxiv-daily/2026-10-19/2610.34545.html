01Key metric
+3.0–9.6pp

Rise in strict compression-specific failure rate when token support is reselected on the shifted image (DivPrune, all six model–compressor settings, every 95% CI above zero). ApET: +2.05–4.20 pp.

02Why this matters

Token compression is how VLM inference gets cheap — this audit shows it silently flips correct answers under mild shifts, and what monitor catches it.

How the claim was isolated

Methodology — distilled

A paired 2×2 intervention crossing which image selects the kept-token set (support) with which image supplies the visual features.

  • Eligibility gate — audited only where the full VLM is correct on both clean and shifted images and the compressed model succeeds on the clean one (49.26–68.39% of configurations), so failures measured here are newly introduced by compression.
  • Four arms — clean · dynamic (deployment path: reselect support on the shifted image) · frozen (reuse the clean support) · counterfactual (shift-selected support over clean features). All eight non-adversarial shifts (JPEG, noise, blur, brightness) preserve the token grid, making supports exchangeable; grid equality verified per pair.
  • Estimand — Δ = SCFRdynamic − SCFRfrozen, macro-averaged over 16 task–shift cells; 95% percentile intervals from 5,000 benchmark-stratified cluster-bootstrap resamples; greedy deterministic decoding.
  • Scale — Qwen3.5-9B, LLaVA-OneVision-2-8B-Instruct, InternVL3.5-8B; DivPrune (hard pruning) and ApET (prune-and-merge) at a matched 25% budget; ChartQA / TextVQA / GQA / POPE, 500 images each; seed 42 primary + seed 2026 independent replication. Pre-registered-style design.

Reproduced on the independent seed-2026 manifest: +3.09–8.71 pp (DivPrune), +2.23–4.76 pp (ApET). InternVL+DivPrune SCFR falls 14.24% → 4.63% when the clean support is frozen.

  • Failures are support-driven, not feature-driven — 74.8–81.6% of DivPrune (55.6–64.1% ApET) dynamic failures still fail after clean features are restored.
  • Monitoring split — Jaccard support instability fails the 0.65 AUROC target (orientation-free bound ≤ 0.605); clean compressed-model uncertainty passes (AUROC 0.705–0.844, L95 > 0.65 in all six settings).
  • Task spread — model-averaged dynamic SCFR: ChartQA 21.86% vs POPE 2.23% (DivPrune); 47 of 48 task–shift cells positive for DivPrune.
  • Compression itself is costly on charts — InternVL3.5-8B clean ChartQA drops 78.00% → 29.80% (DivPrune) / 33.00% (ApET) at 25% retention.
  • Robust to scoring — partial-credit sensitivity (score loss) confirms all six effects, e.g. InternVL+DivPrune +9.73 [8.24, 11.23] pp.
What holds up

Strengths

  • Clean interventional design isolates reselection as a failure channel instead of correlating compression with accuracy loss.
  • Estimand discipline — strict eligibility, pre-specified AUROC target, confirmatory (DivPrune) vs descriptive (ApET) split, cluster bootstrap, orientation-free bounds, full independent replication.
  • Actionable — report conditional reliability alongside clean accuracy; the dynamic–frozen gap is a concrete optimization target; model uncertainty is a deployable failure monitor.
  • Broad coverage in scope — 708,000 records with code, manifests, and outputs open-sourced.
Read with care

Limitations

  • Single 25% operating point — no retention sweep, so budget dependence of the reselection effect is unknown.
  • Estimand conflation — the frozen arm reuses a support already known to succeed, so Δ mixes shift-triggered reselection with generic support-replacement sensitivity.
  • Scope — grid-preserving non-adversarial shifts only; instruction-conditioned compressors (e.g. CDPruner) excluded; ApET audited only at its post-projector stage.
  • Thin monitor comparison — only two predictors tested; shift semantics manually verified on just 100/500 examples per task, not on the seed-2026 sample.
Where this goes next

Questions for Further Exploration

  • Does the reselection gap vanish above some retention threshold (10 / 50 / 75% budgets)?
  • Would a different-clean-selected support control separate shift-triggered reselection from generic selection sensitivity?
  • Can per-position overlap (OCR-critical, high-attention regions) beat set-level Jaccard and reach the 0.65 AUROC target?
  • Do instruction-conditioned compressors (CDPruner) share this fragility, or does question conditioning stabilize support?
  • Can support stabilization — smoothing across augmentations, hysteresis — close the 3–10 pp gap without hurting clean accuracy?
  • Does uncertainty remain a valid monitor under adversarial shifts, geometry changes, or multi-image streams without a shared token grid?
