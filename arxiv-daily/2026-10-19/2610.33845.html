Why this matters

A rare, honest demonstration that autonomous research loops can improve a real-world metric — verification gates against fake findings, a reality loop against proxy drift.

自进化智能体在真实环境（而非代理基准）上闭环自改进的直接核心案例，并为长周期自主研究提供少见的错误—修复—规则化实证记录。

Critical edge — read with care

01 Methodology — reality-anchored self-improvement

  • Six long-lived LLM agents (research lead, environment, training, opponent modelling, evaluation & audit, deployment) never talk directly — all coordination flows through a typed, versioned research memory: findings ledger, 220 confirmed rule rulings, experiment registry, lessons.
  • Each iteration runs Observe → Diagnose → Plan → Implement → Train → Evaluate → Deploy → Reflect across three timescales (training: minutes; research: hours; ladder: days) — ~10,000 registered experiments, 23 agent versions in 20 days.
  • Agents optimize a proxy in the loop; the true objective — live-ladder placement — shows only in slow, costly real games. Proxy drift and false findings are answered by five verification gates (build / contract / comparison / delivery-on-unseen-seeds / reality).
  • TAVERNGYM: Rust, 63k lines, all 978 objects of patch 36.6.3, one seeded RNG for bit-exact replays, 245 masked actions, 190–280 games/s on one core.
  • TAVERNAGENT: 18M-param entity transformer (identity + static-feature + rule-text embeddings; pointer head over 245 actions), PPO at ~310M decisions per stage, against reality-calibrated opponent libraries — the single largest gain in the project.
  • Human role is bounded: set goals, rule on mechanics, press the AI-named hotkeys — 418 messages, 0.6% of traffic.

  • Ladder: rating 6,000 → ~15,000 over 392 games in 20 days — server top 100, no plateau.
  • Opponent-library recalibration alone: first-place rate 20.9% → 27.2% on the main exam.
  • Tool-use condition: GPT-6 Astra decisions 62% → 97% when handed the simulator — the play gap is simulation ability, not knowledge.

03 Strengths

  • Reality as final evaluator — sim-vs-reality discrepancies become 184 concrete fixes; the most convincing proxy-drift correction in an LLM-research-agent paper.
  • Verification engineering as a first-class contribution — five gates, each traceable to a caught failure (G4 born from winner's curse: +1.2–2.1 pts on selection seeds, −0.7 unseen).
  • Exceptional measurement hygiene — seeded-RNG determinism, rule hashes binding models to builds, client failures flagged before results, fair-share baselines.
  • TAVERNBENCH's 1-second real-time view reframes game benchmarks around deployability.
  • Reports its own false positives with numbers (e.g. RNG leak faking +23.6 pts) — rare and valuable.
✕

04 Limitations

  • Single game, single patch (36.6.3), single account — patch churn acknowledged but untested; 20-day re-convergence cost unknown.
  • Top-player comparison is an estimate over 20-record windows, not head-to-head play; 392 games is modest for a stochastic 8-player game.
  • Strategy labels in TAVERNBENCH come from TA-21 play-outs — a sibling of the evaluated agent.
  • Bounded autonomy: human sets goals, rules mechanics, presses every live key; 418 messages over 20 days.
  • Cost: ~19,900 GPU-hours + ~100M frontier-LLM tokens for one game — economics don't yet scale.
  • No self-play or human-engineered-simulator baseline — the agents' marginal value vs a strong engineer is not isolated.

05 Questions for further exploration

  • How much of the advantage is the LLM agents vs the PPO + simulator stack itself? A control run with human engineers, same 8×H200 budget and 20 days, would isolate it.
  • Do the five gates and reality loop transfer to domains where reality is slower than a game ladder — robotics, real experiments?
  • Would self-play league opponents match the reality-calibrated libraries — or does library training cap the agent at recorded human strength?
  • When the next patch lands, how much of the accumulated lessons, gates, and libraries transfer — can the loop re-converge faster?
  • Can the strategy-label circularity be removed (diverse agent ensembles, human replays) — and would the build-vs-play gap change?
  • Would distillation from TAVERNAGENT close general LLMs' play gap, or is the deficit fundamentally learned world simulation?
