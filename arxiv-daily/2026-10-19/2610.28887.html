Why This Matters

First controlled evidence that organizing AI research teams — diverse backgrounds, private memory, adaptive allocation — is what turns autonomous agents into reliable discoverers.

「对长周期自主研究系统的可靠性与评价设计都有直接参考价值。」— Relevance

⚠ Critical Edge

Every condition is a single unseeded run — no error bars — and the headline 21-point proxy retrieval gain shrinks to +3.97 points under full evaluation.

CFDN also trails GDN2 on 150M common-sense reasoning (43.29% vs 43.60%); the "wins every category" claim holds only at 1.3B.

Methodology

研究方法
SELECT · dUCB→ PROPOSE→ BLIND REVIEW ×2→ REFINE→ IMPLEMENT→ TRAIN→ REFLECT
  • 16 instances of one model (GPT-6 Astra), differing only in disciplinary profile — Bayesian filtering, streaming algorithms, dynamical systems, cache policies, vector-symbolic memory, predictive representations. Private longitudinal memories; proposals, outcomes, and lessons shared (synthesized every 10 iterations).
  • Discounted UCB picks the next researcher each iteration, trading recent contributors against unexplored ones; dual identity-blind reviews check feasibility, then novelty.
  • A separate agent implements each candidate — per-step training time must stay < 1.2× GDN2 — then trains from scratch on FineWeb-Edu, FLOP-matched to GDN.
  • 80 iterations → 63 candidates at ~150M; the best is re-trained at 1.3B and run through the full protocol (full CSR, generated-answer RULER NIAH at 1K–8K, 6-dataset real-world retrieval).
Reward = non-negative improvement over the best-known model: r = max{0, U(x) − U(x_ref)}, with U averaging normalized gains over GDN2 across LM loss, 8-task reasoning, and a NIAH proxy.

FLOP-matched = more expressive architectures get fewer training tokens — CFDN wins every category while consuming the fewest (87.17B vs GDN's 100B; 13.53B vs 15B at 150M).

  • Beyond the headline: at 150M, CFDN leads WikiText (33.84 vs 34.93) and NIAH (+3.97 pts) but sits marginally below GDN2 on CSR (43.29% vs 43.60%); search utility 1.04 vs GDN2 0.00, KDA −0.59, GDN −1.29.
  • Objective ablation: LM-only search reaches better LAMBADA ppl (46.40 vs 52.33) yet is worse everywhere else — perplexity-only rewards steer toward gains that don't transfer downstream.
  • The discovery itself: correcting the recurrent context vector before the matrix memory — a reordering justified by reading a failed matrix-first intermediate as evidence.

Strengths

▲ WHAT HOLDS UP
  • Team design treated as a controlled experiment: backgrounds, private memory, and allocation each isolated under a matched budget.
  • FLOP-matched training plus a hard < 1.2× speed gate — fair comparisons, no efficiency loopholes.
  • LM-only-objective ablation is a transferable lesson for autoresearch practitioners (answer-token dilution explains it).
  • Validated at 1.3B with the full protocol instead of trusting 150M search utilities.
  • Trajectory analysis shows genuinely cumulative science: four researchers built CFDN — including on top of a failed intermediate result.

Limitations

▼ WHAT TO WATCH
  • One run per condition — no seeds, no variance; several 1.3B gaps (e.g. NIAH 33.41 vs 32.52) are seed-noise-scale.
  • Search feedback uses tiny suites (256 CSR / 64 NIAH examples, teacher-forced proxy); the 21-pt proxy jump shrinks to ~4 pts in full evaluation.
  • Wholly dependent on proprietary GPT-6 Astra; no open-weights replication; GPU-hour and API cost undisclosed.
  • Demonstrated only on linear attention ≤ 8K contexts — general-domain claims rest on n = 1 problem.
  • CFDN's kinship to Parallax's affine-memory idea (2026) is under-discussed; the 150M CSR regression isn't analyzed.

Questions for Further Exploration

待探索问题
  1. Q1Do the organizational conclusions replicate across seeds and transfer to other search domains — optimizer design, data curation, kernel tuning?
  2. Q2How much of the 1.04-vs-0.76/0.56/0.54 utility gap survives run-to-run variance (3–5 seeds per condition)?
  3. Q3Would an open-weights agent (70B-class) preserve the benefit of disciplinary profiles, or does it require frontier reasoning?
  4. Q4Does context-first correction help beyond 8K contexts or in hybrid attention-SSM models (MQAR with distractors)?
  5. Q5Could the small-suite proxy reward be replaced by a statistically calibrated bandit objective to avoid proxy inflation?
  6. Q6How sensitive is discounted-UCB to γ and c — and could learned meta-scheduling beat the hand-tuned bandit?
