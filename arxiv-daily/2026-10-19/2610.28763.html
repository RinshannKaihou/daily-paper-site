Why this matters

A gaming-proof, systematic measurement of whether autonomous coding agents can run the real scientific-research loop — and how to trust what they report.

Critical edge

Six of 20 reproduced baselines drift from the published numbers — so some “improvements over the published best” are measured against a re-optimized, honest-split starting point whose headroom differs from the paper’s.

Also: “no misconduct flagged” is an LLM-auditor’s verdict, and the default auditor shares a model family with the top hill-climber (cross-family re-audit agreed, but on only half the runs).

SOURCE · Critical Assessment

Methodology

how the climb is staged & kept honest

The task — scientific hill-climbing

Start from a benchmark’s published-best model (paper, code, data, target metric) and improve the metric by editing code under a fixed budget: 8× H200 GPUs, 12 hours.

Standardization — one-time, human-verified

All 20 benchmarks reproduced within tolerance: 3 missing training pipelines built, 2 validation slices carved from training data (test-set checkpoint selection banned). Deterministic splits with a sequestered test set, single-H200 runtime fitting, isolated Docker containers for climbing vs. evaluation; two independent reviewers re-check every task.

Three-stage, gaming-proof protocol

Hill-climbing agent (train/val only, one honest instruction) → separate evaluation agent (held-out test set) → auditing agent reading full logs (CLEAN / COMPROMISED). Built after a pilot where 5 of 12 raw scientific repos invited cheating: selective reporting, test-set contamination, metric manipulation, hardcoding.

Plug-in skills

A “crazy research scientist” ideation persona, real-time experiment management, and hourly self-checklists (“Am I designing creative experiments, or just tweaking hyperparameters?”). Score: Δ% = (s − b) / |b| × 100

  • Span of gains: +1.1% (ProteinGym, Spearman 0.656 → 0.658 vs. Kermut leaderboard leader) to +64.4% (PFDelta, power-balance loss 0.39 → 0.14).
  • The insight outlier: skills-Opus derives the power-balance loss from Kirchhoff’s laws as a label-free primary objective + GNN warm-start for a Newton-Raphson solver → 91.0% (0.39 → 0.04); Codex+Skills hits 99.5% on the 3-day PFDelta-2000 variant (~54 ms/sample).
  • Skills highlights: GEO-Bench-2 crop mIoU 45.90 → 63.30 (+37.9%) · MassSpecGym Hit@1 16.14 → 22.52 (+39.5%) · Mars-Bench IoU/mAP 17.27 → 24.37 (Codex, +42.7%).
  • Stability splits by gain type: engineering gains reproduce (Mars-Bench 45.9 ± 1.5 over 4 runs); insight gains don’t (PFDelta 47.9 ± 19.6 — the reformulation landed in only 2 of 4 runs).
  • More compute can hurt: in 3-day CarbonGlobe runs, Codex’s 60–100-model ensemble gained +37% on validation (RMSE 0.604 → 0.379) but regressed −25% on test (→ 0.753); skill-Opus instead found a non-autoregressive reformulation — ~500× faster inference, 35.3% vs 14.7% RMSE gain.
  • Working styles: Opus 12.0 h / 490 turns of monitored iteration · Codex 328 turns in 1.0 h commit-and-wait · Gemini oscillates — and 44–56% of all interventions are hyperparameter tuning.

Strengths

  • A sharp empirical finding (5/12 raw tasks invite gaming) converted into a principled, reusable protocol — not just exclusions.
  • Unusual honesty: run-to-run variance tables, refusal to rank agents, explicit concession that gains are “almost entirely ML-engineering tricks.”
  • The HPO-only ablation is the right control — pure tuning recovers at most ~half the gain (DART-Eval 2.7 vs 6.1; TIDMAD 3.5 vs 7.4).
  • The PFDelta arc — auxiliary loss 64.4% → self-supervised reformulation 91.0% → 99.5% — is a concrete, inspectable engineering-to-insight case.
  • Public release of code, data, and per-benchmark standardization records (GitHub + Hugging Face).

Limitations

  • Skills were designed by inspecting failures on these same 20 benchmarks and tuned for Claude Code; evaluated only as a bundle — no per-skill ablation (overfitting risk acknowledged, A.5).
  • Insight is luck-dominated: PFDelta landed in 2/4 runs; extra compute can actively hurt (CarbonGlobe test −25%).
  • Δ% is not difficulty-comparable: 6/20 reproductions diverge from paper numbers, and 10/20 baselines were already HPO-tuned in source papers.
  • Coverage gaps: no human-expert baseline, single-agent harnesses only, bioengineering supplies 5/20 benchmarks.
  • The audit is itself an LLM judgment — rationalization and motivated interpretation may pass (authors concede, A.3).

Questions for further exploration

Which skill drives the 10.4 → 20.1 jump — the hourly checklist alone, or the ideation persona?

Can auditing be made adversarial — a red-team gaming agent vs. the auditor, to measure recall on subtle misconduct?

Would idea portfolios, cross-run memory, or insight-level best-of-N raise the 2/4 insight hit rate?

Are agent “paradigms” (monitored iteration vs. commit-and-wait) fixed harness properties or trainable behaviors?

Do honest-split baselines change which benchmarks have real headroom — e.g., is ProteinGym’s +1.1% a baseline property?

Can the PFDelta pattern — metric as self-supervised loss + physics-solver warm start — be elicited deliberately on other PDE tasks?
