> **一句话总结：** QuantWM 是一个免训练的 2-bit KV cache 量化框架，揭示并修复了被 VBench 掩盖的失效模式——Key 量化误差虽小却会扰动注意力 logits、漂移时序-空间 token 选择，造成视频闪烁；它用 Query 敏感度感知聚类（QSAC）+ 主子空间注意力补偿（PSAC），在 5 个视频/世界模型上把对 QVG 基线的 PSNR 提升最高 +4.83 dB（LongCat-Video 20.683→25.508），同时实现约 6.2× KV cache 压缩、延迟开销仅 ≤5.9%（LongCat-Video 上反而快 17.78%）。

> **TL;DR:** Existing 2-bit KV cache quantization (QVG, KIVI) scores near-losslessly on VBench but visibly flickers. QuantWM shows the failure is Key-driven: on HY-World 1.5's last layer, Key MSE (0.0090) is 33× smaller than Value MSE (0.2939), yet Key-only quantization yields 3.3× larger output MSE (0.5584 vs 0.1679) because small K errors reorder attention logits and shift temporal-spatial token selection. Its training-free fix — Query-sensitivity-aware centroid clustering (QSAC) plus rank-8 principal-subspace logit compensation (PSAC) — on 93-frame MovieGen-prompt videos across 5 models lifts PSNR over QVG by up to +4.83 dB on LongCat-Video (20.683→25.508, LPIPS 0.0784→0.0332), cuts the token-selection shift ratio from 0.6136 to 0.1392 on HY-World 1.5, compresses KV cache up to 6.20× (12.08→1.948 GiB), and keeps VBench at or above the BF16 baseline (e.g., 0.8173 vs 0.8106 on HY-World 1.5), with only +5.4–5.9% latency on GPU-resident models and −17.78% on offload-heavy LongCat-Video.

## 核心贡献

- **发现被基准掩盖的退化**：现有 2-bit KV 量化方法（QVG、KIVI）在 VBench 上"几乎无损"，但生成的视频存在明显时序闪烁、模糊和伪影——帧级指标（PSNR/SSIM/LPIPS 对 BF16 参考帧）暴露了这一差距，而 VBench 分数几乎不变。
- **定位元凶是 Key 而非 Value**：Key 的量化重构误差比 Value 小一个数量级（末层 HY-World 1.5：K MSE 0.0090 vs V MSE 0.2939），但只量化 Key 造成的输出误差反而更大（0.5584 vs 0.1679）。机理：注意力 logits L=QKᵀ/√d 对 Key 扰动极敏感，小误差即可改变 logit 排序、漂移 Query 选中的时序-空间 token，导致关注错历史帧/空间区域 → 闪烁。
- **QSAC（量化敏感度感知聚类）**：在 QVG 的质心-残差方案上，用历史 Query 的二阶统计量（对角近似，w_c ∝ E[q_c²]）与残差分组动态范围（Widrow 均匀量化误差界）联合打分选质心，直接最小化期望的注意力-logit 扰动，而非最小化重构误差。
- **PSAC（主子空间注意力补偿）**：利用历史 Query 能量集中于少数方向的事实（top-8 特征方向捕获 >60%，如 LingBot-v2 layer 38 达 71.4%），对每层保留 rank-8 主子空间，把剩余 Key 量化误差低秩投影为 INT8 补偿项，推理时直接校正 QKᵀ。
- **真实系统工程**：PyTorch + 定制 Triton 融合内核，4 个 INT2 码打包 1 字节、按需重建 BF16 K/V 后走原生 FlashAttention/SDPA，保留各模型原生 RoPE 约定；因果性严格保持（首个 chunk 冷启动时 QSAC/PSAC 退化为均匀权重/关闭），无需校准阶段。
- **全面验证**：5 个模型（LongCat-Video、HY-World 1.5、LingBot-World-v2、Matrix-Game-2、Causal-Forcing）× 480p/720p × 93 帧 + 1 分钟长视频，一致优于 QVG 和 KIVI；消融证实 QSAC 与 PSAC 各自有效、组合最佳。

## Key Contributions

- **Diagnosis of a benchmark-blind failure mode**: 2-bit KV quantization that is "near-lossless" on VBench produces visible temporal flickering and blurring in world models/video generation; frame-level fidelity metrics against BF16 outputs expose it while VBench barely moves (e.g., QVG's Matrix-Game-2 VBench avg drops only 0.7831→0.7662 despite obvious flicker).
- **Key-not-Value is the culprit, and magnitude does not explain it**: Key quantization has far smaller reconstruction error than Value (last-layer HY-World 1.5: K MSE 0.0090 vs V MSE 0.2939) yet causes larger output degradation (0.5584 vs 0.1679 output MSE), because attention logits amplify small K perturbations into temporal-spatial token-selection shifts (visualized in Fig. 3 across all five models).
- **QSAC**: a centroid-selection criterion for centroid-residual 2-bit K quantization that minimizes the expected squared attention-logit perturbation, combining per-channel Query sensitivity from historical second-moment statistics (diagonal approximation) with residual group dynamic ranges (Widrow bound); uses top-M=4 candidate centroids for efficiency.
- **PSAC**: a rank-8 principal-subspace compensation that stores the residual Key error projected onto the dominant historical Query eigendirections (INT8, folded into logits as QK̃ᵀ = QK_Qᵀ + QU_rCᵀ), correcting attention shifts directly at inference.
- **A real quantized inference system**: bit-packed INT2 storage with custom fused Triton kernels, on-demand BF16 reconstruction into native FlashAttention/SDPA, causality-preserving cold-start, no calibration — achieving up to 6.20× KV cache compression with ≤5.9% latency overhead (and −17.78% latency on offload-heavy LongCat-Video).
- **Consistent empirical wins**: across 5 models at 480p and 720p and on 1-minute generations, QuantWM beats QVG and KIVI on every frame-level metric while matching or exceeding BF16 VBench scores.

## Methodology

**Setup.** Building on QVG's centroid-residual KV quantization (256 K-means centroids kept in BF16, INT2 residuals, group size 64, streaming chunk-wise quantization after each cache chunk is built), the authors first dissect *where* 2-bit degradation comes from. They separately toggle Key/Value quantization (K16V2 vs K2V16) and measure both reconstruction MSE and output MSE against BF16 generations, then visualize the top-1 attention-selected patch per query under BF16 vs 2-bit K — showing that Key errors flip which historical frame/spatial region a query attends to.

**QSAC (Quantization-Sensitivity-Aware Clustering).** Instead of assigning each Key token to the nearest centroid by L2 distance (plain K-means, as QVG does), QSAC selects the centroid that minimizes the expected squared perturbation to attention logits qᵀk. Per attention head h, it maintains the running second-moment matrix M_h⁻¹ = (1/N)Σ qqᵀ over Queries observed in previous generation chunks; the expected logit error of a Key error direction e is eᵀM_h⁻¹e. To keep assignment cheap, it uses the diagonal approximation (w_h,c ∝ E[q_c²], i.e., historical squared Query magnitude per channel), then combines this sensitivity with the residual group-wise dynamic range R_g (whose squared value, via the Widrow uniform-quantization bound, predicts residual quantization error per group): the QSAC score is S(k_i, μ_j) = Σ_g (Σ_{c∈g} w_c)·R_g(r_ij)², and the centroid minimizing S is chosen among the top-M=4 candidates shortlisted by the Query-aware distance. This prioritizes centroid fits on Query-sensitive channels and residuals that are hard to quantize.

**PSAC (Principal-Subspace Attention Compensation).** Residual logit perturbations remain after QSAC. Since historical Query energy is concentrated in few directions (top-8 eigendirections capture 60–99% of cumulative Query energy across models/layers; e.g., 71.4% for LingBot-World-v2 layer 38), PSAC eigendecomposes M_h⁻¹ = U_h Λ_h U_hᵀ, keeps the top-r=8 eigenvectors U_r, stores the low-rank compensation C = EU_r (E = K − K_Q, the remaining Key quantization error) quantized to INT8, and corrects attention as K̃ = K_Q + CU_rᵀ, so QK̃ᵀ = QK_Qᵀ + QU_rCᵀ. r=8 is chosen as a quality/storage trade-off (Table 9). A cold-start policy (uniform channel sensitivity, PSAC inactive for the first chunk) keeps strict causality with no calibration stage.

**System co-design.** Implemented in PyTorch with custom Triton kernels on NVIDIA A800 80GB: four INT2 residual codes packed per byte, uint8 centroid IDs, INT2 zero-points, INT8 group scales with a shared FP16 secondary scale, FP16 (or zeroed/sparse) PSAC coefficient rows; a fused decoder kernel unpacks, reconstructs BF16 K/V, adds PSAC, and feeds the model's native attention (FlashAttention/SDPA), preserving each model's native cache layout and pre-/post-RoPE conventions.

**Evaluation protocol.** Five open-source autoregressive video/world models (LongCat-Video, HY-World 1.5, LingBot-World-v2, Matrix-Game-2, Causal-Forcing); 93-frame videos at 480p and 720p using the MovieGen Benchmark prompt suite (29 first-frame images × 7 action sequences for Matrix-Game-2); frame-level PSNR/SSIM/LPIPS against BF16-generated frames over all frames, plus VBench (Subject/Background/Aesthetic/Image/Avg); baselines are QVG (the most relevant 2-bit video KV method) and KIVI (a representative LLM KV method), all reproduced under each model's native cache convention on the same cached tensors. Additional 1-minute-video VBench eval, token-selection shift-ratio metric, and ablations (QSAC/PSAC, rank r, diagonal vs full matrix, candidate count M).

## Results & Highlights

- **Frame-level quality (480p, 93 frames, Table 3)**: On LongCat-Video, QuantWM raises PSNR from 20.683 (QVG) to 25.508 (+4.83 dB) and cuts LPIPS from 0.0784 to 0.0332; on HY-World 1.5 PSNR goes 16.118 (QVG) → 18.449 (+2.33 dB, LPIPS 0.2114→0.1082); on LingBot-World-v2 it reaches PSNR 16.138 vs QVG 14.814 and KIVI 14.799; on Matrix-Game-2, 20.05 vs QVG 17.79. Gains hold at 720p (e.g., Matrix-Game-2 PSNR 17.720→20.568 vs QVG, LPIPS 0.3047→0.1651).
- **VBench is preserved, not traded away (Table 3)**: QuantWM's VBench average matches or slightly exceeds the BF16 baseline on all five models — e.g., HY-World 1.5: 0.8173 (Ours) vs 0.8106 (BF16) vs 0.8127 (QVG); Matrix-Game-2: 0.7836 (Ours) vs 0.7831 (BF16) vs 0.7662 (QVG).
- **Mechanism verified quantitatively (Tables 1, 2, 4)**: Key quantization has smaller reconstruction error but larger output damage (last layer, HY-World 1.5: K MSE 0.0090 / output MSE 0.5584 vs V MSE 0.2939 / output MSE 0.1679); K2V16 (2-bit K, 16-bit V) degrades visual quality badly (Matrix-Game-2 PSNR 18.47, SSIM 0.547, LPIPS 0.219) while K16V2 stays close to BF16 (PSNR 21.58, SSIM 0.708, LPIPS 0.126). QuantWM cuts the top-1 token-selection shift ratio from 0.6136 (QVG) to 0.1392 on HY-World 1.5 (and from 0.5388 to 0.1010 on Matrix-Game-2).
- **Memory compression (Fig. 6, 93-frame KV cache)**: HY-World 1.5: 12.08 GiB → 1.948 GiB (6.20×); LingBot-World-v2: 21.10 → 3.776 GiB (5.59×); LongCat-Video: 21.70 → 3.625 GiB (5.99×); Causal-Forcing: 8.447 → 1.062 GiB.
- **Latency (Table 6, 93 frames)**: +5.44% on LingBot-World-v2 (193.56s → 204.09s), +5.87% on HY-World 1.5 (112.17s → 118.75s), but −17.78% on LongCat-Video (255.35s → 209.94s), where reduced cache host-GPU traffic outweighs quantization overhead (analysis in Appendix D.2).
- **Ablations (Tables 5, 9, 10, 11)**: On HY-World 1.5, baseline centroid-residual 2-bit alone gives PSNR 16.118 with 0.6136 token shift; QSAC alone 17.990 / 0.3817; PSAC alone 17.849 / 0.2290; both 18.449 / 0.1392. Rank r=8 is the sweet spot (r=16 adds only +0.1341% storage for marginal gains); the full (non-diagonal) QSAC matrix changes PSNR only marginally (18.4465 diagonal vs 18.3368 full on HY-World 1.5) while costing +4.35s; exhaustive centroid search (M=256) gives no quality gain over M=4 but 2× latency (240.66s vs 118.75s).
- **Long-video robustness (Table 8, 1-minute generation)**: QuantWM beats QVG on VBench average for all five models, e.g., HY-World 1.5: 0.6627 (Ours) vs 0.5949 (QVG), and even above BF16's 0.6567 — indicating robustness to accumulated quantization error over long horizons.

## Critical Assessment

**Novelty.** The headline observation — Keys are the fragile half of the KV cache even though their reconstruction error is smaller — is compelling and well-instrumented, but it is not entirely new ground: KIVI's asymmetric design already implied Key sensitivity in LLMs, and the concurrent work of Tuncer & Becker (arXiv:2605.26266, "Quantized keys steal attention") attributes video-diffusion degradation to Key-induced attention bias and fixes it with score-level bias correction. QuantWM cites this work as related but never benchmarks against it, so the claim that addressing "temporal-spatial token selection" via centroid assignment + subspace compensation is the better framing remains unvalidated against the closest competing idea. The genuinely new pieces are the token-selection-shift diagnosis (Fig. 3) and the Query-statistics-driven centroid assignment (QSAC), which is a neat, causally-safe use of online statistics.

**Rigor.** The evaluation is broad (5 models × 2 resolutions × long-video) but the metric design has a subtle circularity: PSNR/SSIM/LPIPS are computed against the BF16 model's own generated frames, so they measure trajectory fidelity to the teacher, not perceptual quality of the quantized video in isolation; VBench's Subject/Background consistency serves as an imperfect proxy for flicker, and there is no human evaluation or dedicated temporal-smoothness metric despite flickering being the paper's central motivation. The long-horizon setting — where error accumulation is riskiest — is evaluated only with VBench, not frame-level metrics. No error bars, seeds, or prompt-count sensitivity are reported, and the prompt suite is a single one (MovieGen). The Sec. 5.3 text ("reduces the shift ratio with up to 10.19%") is confusingly worded relative to Table 4, whose actual numbers (0.6136→0.1392 on HY-World 1.5) are stronger than the phrasing suggests — a presentation slip, not a substantive one.

**Reproducibility.** Above average for this area: packing formats, kernel-fusion strategy, group sizes, centroid counts, and the cold-start policy are all specified, and a project page exists, though no explicit code-release statement appears in the main text.

**Significance / red flags.** All five evaluated models are causal, chunk-cached autoregressive models; generalization to full-attention (non-causal) diffusion video generators is asserted by scope ("video generation") but not demonstrated. Latency results are honest about being system-dependent (−17.78% on offload-heavy LongCat-Video vs +5.9% when GPU-resident), which is commendable, but it means the "limited overhead" headline depends on deployment configuration. Overall: a solid, well-motivated systems paper whose main weakness is the absence of the closest concurrent baseline and of perceptual/human validation of the flickering claim.

## Strengths

- Sharp, falsifiable diagnosis: the K-vs-V decoupling experiments (Tables 1–2) and patch-selection visualizations (Fig. 3) cleanly establish *why* 2-bit KV quantization flickers, moving the objective from reconstruction error to attention-logit preservation.
- Principled training-free method: QSAC's score is derived from the expected squared logit perturbation (Widrow bound + Query second moments) rather than hand-tuned heuristics; PSAC exploits a measured, consistent empirical fact (top-8 Query eigendirections hold 60–99% of energy across all models/layers, Fig. 8).
- Real system, not simulation: bit-packed storage, fused Triton on-demand reconstruction, native RoPE/layout preservation, and strict causality with no calibration stage.
- Consistency of gains: every frame-level metric improves over both QVG and KIVI on all five models at both 480p and 720p, and VBench does not degrade (often slightly exceeds BF16).
- Honest, thorough ablations: QSAC vs PSAC contributions separated, rank r, diagonal approximation, candidate count M, cold-start initialization, and a candid analysis of when latency improves vs degrades (Appendix D.2).

## Limitations

- Latency overhead of +5.4–5.9% on GPU-resident models; PSAC adds per-chunk INT8 low-rank factors (small but nonzero storage, e.g., +0.30% at r=32 vs r=8 on HY-World 1.5).
- Only two quantization baselines (QVG, KIVI); no comparison with the concurrent attention-bias-correction approach (Tuncer & Becker, 2605.26266) that targets the same failure mode.
- Flicker — the motivating symptom — is never measured directly (no temporal-consistency metric designed for flicker, no human study); frame-level metrics measure fidelity to BF16 outputs only.
- The 1-minute long-horizon evaluation reports only VBench, omitting frame-level metrics where error accumulation would show most.
- Scope confined to causal, chunk-cached autoregressive models; applicability to full-attention diffusion video models is untested.
- Requires custom fused kernels for real speed/memory benefit; with stock attention implementations, dequantization overhead may differ.

## Relevance

这篇论文对关注高效推理与生成模型的读者价值很高：它证明 2-bit KV 量化中"重构误差小"不等于"行为无损"，Key 误差会通过注意力 logits 漂移 token 选择——这一"保注意力行为而非保数值"的量化视角对 LLM 长上下文推理同样适用。若你在做 KV cache 压缩、世界模型或长视频生成的部署，QSAC/PSAC 是可直接借鉴的免训练方案。

## Questions for Further Exploration

- How does QuantWM compare head-to-head with Tuncer & Becker's score-level bias correction on the same models — are centroid-side and logit-side fixes complementary?
- Do the K-sensitivity and token-selection-shift findings transfer to full-attention (non-causal) diffusion transformers, where the "cache" spans denoising steps rather than time?
- Can a perceptual flicker metric (e.g., warp-consistency or optical-flow-based temporal smoothness) corroborate the visual-degradation claims beyond PSNR-vs-BF16 and VBench?
- Does the diagonal Query-sensitivity approximation hold for much longer caches (minutes to hours), where M_h⁻¹ may become non-stationary?
- Could the same principal-subspace compensation apply to Value quantization at 1-bit, pushing beyond the current 2-bit operating point?
