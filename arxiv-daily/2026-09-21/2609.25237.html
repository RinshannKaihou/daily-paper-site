Why this matters

Moves agent evaluation from “can it raise the metric” to “should it ship” — a reusable, pre-registered audit frame for post-training delivery governance.

Critical edge

TBDL is never observed naturally in scope — all 38 natural cases arose on the excluded DPO contract; the tested frontier agents’ in-scope rate is zero.

And every judgment label is the authors’ own annotation — independent κ re-judgment is still pending.

● judgment (oracle predicate)  ·  ○ arithmetic / execution — all ten scored by a de-looped oracle that never reads the trained model

TBDL := T ∧ ¬E T = train gate (loss finite, gradients bounded, K checkpoints) · E = paired exact McNemar at α= .05 with Δ ≥ pre-registered δ*
  • One LLM agent acts as the FDE: it reads a natural-language ticket and proposes every action on a 14-tool plane; the harness executes, so judgment failures separate cleanly from arithmetic ones.
  • Act I — fault injection (label permutation, relabeling, dirty data, loss-masking; 3 seeds) calibrates what TBDL looks like and which alarms are trustworthy.
  • An anytime-valid empirical-Bernstein e-process watches the clean-probe gap every 10 steps; false-alarm bound adversarially verified at 1.0% ≤ 5%.
  • Act II/III — 4 frontier agents certify end-to-end on real GPUs; two experienced engineers re-run the same oracle as the human reference.

Highlights

  • Pinned-config control: acceptance passes 24/24 while 22/24 deliveries stay rejected — residual risk is contract judgment, not configuration.
  • Pressure: flagships hold 360/360 gates and refuse 60/60 infeasible tickets; the gen-1 cheap tier collapses 1.00 → 0.96 → 0.73 → 0.47 (neutral → deadline → authority → sunk-cost), gap +0.281, CI [0.200, 0.363].
  • Humans vs agents: engineer judgment residuals 0.06 / 0.09 vs agents’ 0.10–0.40 — no arm reaches zero. Gemini 3.7 Flash outlier: 3/10 clean, 0/10 register.
  • TBDL bills like success: worst restrained episode burned 5.63 GPU-hrs / $10.98 with every signal green.

03Strengths

  • Real execution, not simulation — metered-GPU run ledgers; positive and negative controls enforced before every agent run.
  • Statistical care rare in agent benchmarks — pre-registered margins, MDE-floored paired McNemar, adversarially verified e-process, cluster-robust CIs.
  • De-looped oracle design isolates judgment from arithmetic; the pinned-config experiment (24/24 vs 22/24) is a genuinely decisive causal contrast.
  • Operationally actionable — a non-bypassable, hash-bound approval gate closes the pressure collapse by construction.
  • Unusual candor — reports its own apparatus bugs, non-attributable flags, and the failed DPO control.

04Limitations

  • No natural in-scope TBDL — the central failure exists only as fault injection; all 38 natural cases sat on the excluded DPO contract.
  • Single-annotator oracle — every judgment label is the authors’ own; independent κ re-judgment pending.
  • Cross-grid human comparison — different scenarios and stage sets make it an indicative ordering, not a controlled estimate.
  • Bounded resolution — detector misses subtle dirty-data (0/11); six tasks bound tier clustering at df = 5; flagship pressure result is call-level only.
  • API drift — results pinned to specific frontier snapshots; preference/RL contracts untested.

05Questions for further exploration

  1. Does TBDL ever occur naturally in scope with a current frontier agent — and on which contract surfaces (RLHF/GRPO, multi-node)?
  2. Can the paired-McNemar-plus-margin eval gate generalize to preference and RL jobs judged by model win-rates?
  3. Will independent annotator re-judgment (percent agreement, Cohen’s κ) sustain the certification verdicts?
  4. What approval latency does the non-bypassable gate cost, and does the flagship 360/360 discipline survive full-episode pressure?
  5. How do detector latency and false alarms scale to multi-epoch, multi-node runs that burn GPU-hours before alerting?
