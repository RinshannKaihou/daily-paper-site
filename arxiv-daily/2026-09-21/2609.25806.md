> **一句话总结：** 在一个模拟酒店定价 agent（72 个 regime-component 单元、540 条 unit-arm 行）上提出"参考图门 + 运行时双流门 + 物理组件层校准弃权 + 受影响干净流量 τ"的聚合轨迹可诊断性框架：55/72 单元通过参考门，20 个运行时采纳物理组件的稳定误报为 0/20（单侧精确 95% 上界 0.1391，满足冻结的 ≤0.20 准则），且以"受影响干净流量"替代"被改单元格数"解释检测功率，将每单元臂行 NLL 从 0.4319 降到 0.3055（相对下降 29.3%）；附带一个负面结果——精确最小命中集（MHS）在 12 个审计场景中与传播感知贪心选择恢复率完全相同（9/12 vs 9/12）。

> **TL;DR:** On a simulated hotel-pricing agent (72 regime-component units, 540 unit-arm rows nested in 20 physical components), the authors turn "can this aggregate trace support a component-level fault claim at all?" into a pre-registered pipeline: a reference-map gate and a runtime two-stream gate, calibrated abstention on disjoint clean streams (stable false admission 0/20, exact one-sided 95% upper bound 0.1391 vs the frozen ≤0.20 criterion), and an exposure analysis showing that affected clean traffic τ — not changed-cell count — governs detection power: traffic cuts per-row NLL from 0.4319 to 0.3055 (−0.1264 nats, 29.3%, cluster-bootstrap 95% CI [0.0593, 0.1918]) while adding mask family + interaction improves NLL by only 0.0015 nats/row (upper bound 0.0066 < 0.01 margin). A negative result: exact minimum hitting set (MHS) matches propagation-aware greedy selection exactly (9/12 recovery vs 9/12), so no optimizer can recover information the policy traffic never exposed.

## 核心贡献

- **将"轨迹可诊断性"操作化为状态机：** `REFERENCE_ABSTAIN → RUNTIME_ABSTAIN → SIGNAL_ELIGIBLE → DETECTED/NOT_DETECTED`。参考图门要求 15 个干净参考分区中 ≥14 个具备支持（每个分区支持数 ≥12）才能进入正式参考图；运行时双流门要求参考流与当前流在**同一**分区中支持均 ≥12 且 ≥14 个联合分区，双向故障观测要求两个方向都通过——先回答"该不该解读"，再回答"怎么解读"。
- **提出"受影响干净流量 τ"作为行为学暴露变量：** 定义为干净访问落在被改单元格的比例（双向取平均），并证明它比被改单元格数（cell coverage）更能预测检测功率；在 uniform 与 flow-weighted 两种掩码族之间做了流量的"实践充分性"（practical sufficiency）检验（0.01-nat 等效边界）。
- **冻结（预注册）确认性设计：** 种子分离（200000–202399 参考 / 202400–204799 故障 / 204800+ 未用，主掩码种子 2026082370），信号阈值 z ≥ 1.50 事前从固定网格 {1.00–2.00} 选定，Clopper–Pearson 精确区间 + 按物理组件聚类的 bootstrap（20 簇、2000 次抽样），并把参考失效 / 运行时拒绝 / 稳定误报三种失败量分开报告、分开解释。
- **物理组件层校准弃权：** 稳定误报 0/20（单侧 95% 上界 0.1391）满足冻结 ≤0.20 准则（SAFETY CONFIRMED）；全部 44 个零暴露计划观测均弃权且无稳定信号——"无可用比较"与"有可用比较但无稳定信号"被显式区分。
- **负面结果（MHS 是下游问题）：** 12 个审计的贪心场景中，精确 MHS 与传播感知贪心选择完全相同的支持、恢复率相同（9/12）；非单例冲突占冲突集合的 55.5%，传播后 9/9 场景无残留非空冲突家族。若策略流量从不暴露受影响区域，精确或近似优化器都无法恢复迹中不存在的信息——结论是"先建立暴露，再打分变化，迹不支持时弃权"。

## Key Contributions

- **Operationalizes trace diagnosability as a state machine** with two support gates (reference-map gate: ≥14/15 clean partitions supported; runtime two-stream gate: reference and current streams jointly supported ≥12 in the same partition, ≥14 joint partitions), making "is this trace eligible for interpretation?" explicit and prior to any scoring.
- **Introduces affected clean traffic τ** (fraction of clean visits falling in changed cells, averaged bi-directionally) as a behavior-grounded exposure variable, and shows it predicts detection power better than changed-cell count across two nested mask families (uniform and flow-weighted), with a pre-committed 0.01-nat practical-sufficiency criterion.
- **Runs a frozen confirmatory design:** disjoint seed ranges, SHA-256 deterministic mask ordering, threshold z ≥ 1.50 selected from a fixed grid before execution, exact Clopper–Pearson intervals plus component-cluster bootstrap (20 clusters, 2,000 draws), and three separately-reported failure quantities (reference invalidation / runtime rejection / stable false admission).
- **Calibrates abstention at the physical-component level:** stable false admission 0/20 (one-sided 95% upper bound 0.1391) meets the frozen ≤0.20 rule; all 44 zero-exposure scheduled observations abstained and none was stable.
- **Reports an instructive negative result:** exact MHS offers no advantage over propagation-aware greedy selection (identical supports, 9/12 exact recovery both), redirecting diagnosis questions upstream — exposure, not optimization, is the bottleneck for closed-loop aggregate traces.

## Methodology

- **Domain.** A simulated hotel-pricing agent maps (time quarter, inventory half, market third) to discrete price actions under three fitted demand regimes (λ0 ∈ {5, 7, 9}), giving 24 disjoint target-policy components × 3 regimes = 72 units. The diagnostic sees only typed aggregate summaries per matched reference-current partition pair: `region_d1` (regional distribution distance) and `mean_action_gap`. It never observes the planted fault identity.
- **Faults.** A fault mask changes a deterministic subset of direction-changeable target cells in one action bucket (outward/inward tested separately). Two nested families: `uniform` (seeded random cell ordering) and `flow_weighted` (weighted-without-replacement favoring frequently-visited cells). Prefixes target achieved traffic τ ∈ {0.15, 0.30, 0.50, 0.75, 0.95}; orderings derive from SHA-256 under master seed 2026082370.
- **Gates and signal.** A unit enters the reference map only if ≥14/15 clean partitions have support ≥12; runtime admission requires ≥14/15 jointly-supported matched partitions. Per matched pair, z = max(region_d1/0.20, mean_action_gap/0.35); a partition signals when z ≥ 1.50 (fixed grid chosen before the formal null); a direction is stable at 14/15 signaling partitions; a unit-arm is bi-directionally stable only when both directions are stable.
- **Calibration.** Stable false admission is measured on a disjoint clean stream and calibrated at the physical-component level with a frozen ≤0.20 criterion and exact one-sided 95% binomial (Clopper–Pearson) upper bound. Reference invalidation and runtime rejection are descriptive coverage endpoints (two-sided exact intervals), deliberately kept separate so a stale map, insufficient evidence, and a noisy signal are not conflated.
- **Statistics.** Primary model: bi-directional stable signal vs log(τ) on the 540 positive-exposure unit-arm rows, compared to a matched cell model using log(cell_fraction); traffic is superior iff the per-row NLL improvement NLL(cell) − NLL(traffic) > 0, with a two-sided 95% component-cluster bootstrap interval. Family sufficiency: add mask family + family×log(τ); traffic is practically sufficient iff the log-loss improvement's one-sided 95% upper bound is < 0.01 nats/row. Empty/nonfinite analyses return NOT ESTIMABLE. An operational sensitivity re-fits with abstention counted as zero decision. Drift uses a frozen split-conformal detector with atomic map refresh (state-machine smoke test only); the MHS-vs-greedy comparison is audited on 12 greedy development scenarios.
- **Design hygiene.** Formal seeds 200000–202399 (15 clean reference partitions × 100 episodes), fault partitions 202400–204799, 204800+ unused; common random numbers pair conditions; inference clusters repeated observations by physical component; the frozen protocol executed 56 checks over 1,440 cases / 21,600 partition rows.

## Results & Highlights

- **Admission and abstention endpoints.** 55/72 (76.4%) regime-component units passed formal reference admission, representing 20/24 (83.3%) distinct physical components. Reference invalidation 0/20 (95% CI [0.0%, 16.8%]); runtime two-stream rejection 1/20 (95% CI [0.1%, 24.9%]) — both descriptive, every affected unit still abstains. Stable false admission on the clean stream: **0/20, exact one-sided 95% upper bound 0.1391**, satisfying the frozen ≤0.20 criterion (SAFETY CONFIRMED); 0/20 runtime-admitted components produced a stable clean-versus-clean signal. All 44 zero-exposure scheduled observations abstained and none was stable.
- **Traffic beats cell coverage (primary structural result).** Over 540 unit-arm rows nested in 20 clusters, the traffic model achieved NLL 164.9866 (0.3055/row) vs 233.2453 (0.4319/row) for the matched cell-coverage model — a **0.1264-nat/row improvement, a 29.3% relative reduction**, with component-bootstrap 95% CI [0.0593, 0.1918] excluding zero. Under the operational sensitivity (abstention = no action), the gain is 0.1164 [0.0512, 0.1835].
- **Mask family is practically irrelevant within the frozen margin.** Adding family + family×log(τ) interaction improves NLL by only **0.0015 nats/row (one-sided upper bound 0.0066 < 0.01)** → PASS. The secondary traffic+family coefficient is −0.3618 with CI [−0.8617, 0.0367] and LRT p = 0.2019 (explicitly labeled non-significant, not an equivalence proof). Both families saturate at 54/54 bi-directional stable detections on the four highest traffic targets; only the middle gaps (+1, +2, +3 cells, uniform minus flow-weighted) are informative, and the largest family gaps cluster in the [0.30, 0.45] and [0.75, 0.90] traffic bins (0.0015 nats/row each).
- **MHS negative result.** In 12 audited greedy scenarios, exact MHS and propagation-aware greedy selected **identical supports with identical exact recovery (9/12 vs 9/12)**; the instances not recovered were devoid of combinatorial structure. Non-singleton conflicts comprised 55.5% of the conflict collection; planted-component singleton conflicts appeared in 9/9 exact-anchor and 9/9 hard-probe cases, with 0/9 nonempty residual conflict families after propagation.
- **Drift behavior (descriptive).** The frozen split-conformal detector stayed quiet in the matched λ0=7 regime and alarmed under demand shifts at λ0=5 (15/15) and λ0=9 (14/15). Five refresh operations over 120 evaluations reused the frozen buffer — a state-machine smoke test, not evidence that refresh repairs a stale map.

## Authors & Credibility

Peiying Zhu and Sidi Chang are equal-contribution authors at Blossom AI (San Francisco); Sidi Chang is corresponding author. Neither author has a broadly visible prior publication record in agent evaluation, and Blossom AI is not an established research lab, so external credibility rests on the work itself. That said, the methodology displays unusual statistical maturity for an industry note: pre-registered frozen thresholds, seed separation, exact binomial bounds alongside cluster bootstrap, explicit separation of descriptive vs confirmed endpoints, and a candid negative result about their own earlier framing (MHS as the main contribution). The main credibility caveat is that every number is self-generated inside the authors' own simulator; there is no external replication and no stated code release in the PDF.

## Critical Assessment

- **Novelty: modest but well-aimed.** This is a measurement-methodology paper, not a new diagnosis algorithm. The two-gate + abstention pipeline is a sensible formalization of an under-asked question (when is a trace interpretable at all?), positioned against conflict-directed diagnosis (Reiter-style MHS) and selective prediction. The genuinely novel empirical finding is the traffic-vs-cell NLL comparison; the MHS result is a negative audit of the authors' own prior framing rather than a community benchmark.
- **The "SAFETY CONFIRMED" label oversells a coarse criterion.** A false-admission bound of ≤0.20 is generous: the confirmed statement is only that the upper bound on falsely flagging a clean component is at most ~14% (0.1391). Calling this "safety" invites false assurance — the paper admits exactly this risk in Section 9, but the Table 4 label reads stronger than the evidence.
- **All power claims rest on 20 clusters.** The percentile cluster-bootstrap uses 20 represented components, and the paper concedes such intervals "may undercover in directions favorable to both structural findings." The family-sufficiency verdict (0.0015 vs the 0.0034-nat remaining margin) is narrow, and the secondary evidence is equivocal: the traffic+family coefficient CI [−0.8617, 0.0367] spans zero and the LRT p = 0.2019 — the authors honestly label this not an equivalence result, but the "PASS" in Table 3 will be quoted more than the caveat.
- **Ceiling effects shrink the shape evidence.** Both mask families saturate 54/54 at the four highest traffic targets, so claims about the τ–power curve rest on the middle bins; monotonicity is self-described as a "weak shape check," and the two bins with family gaps ([0.30, 0.45], [0.75, 0.90]) are exactly where the sufficiency margin is thinnest.
- **External validity is thin.** One simulator, one-bucket target-field shifts, 24 components, occupancy from a clean reference policy that real deployments may not have. The MHS audit covers only 12 greedy scenarios of a single conflict structure — enough to kill the authors' earlier MHS-as-contribution framing, not enough to claim optimizers never help in general.
- **The title promises localization but the study abstains from it.** Planted-fault localization accuracy is explicitly excluded from endpoints; the pipeline certifies signal eligibility only. A reader expecting "calibrated abstention" to mean calibrated diagnosis will not get it — the paper says so, but the framing invites overreading.
- **Reproducibility is strong on paper but unverifiable in practice:** master seed 2026082370, seed ranges, frozen grids and 56 protocol checks are all documented, yet no artifact or code release is mentioned, and everything is inside one proprietary simulator.

## Strengths

- A genuinely frozen confirmatory design: disjoint seed ranges, pre-committed thresholds from a fixed grid, 56 protocol checks — rare discipline in agent-evaluation work.
- Clean separation of three failure quantities (reference invalidation / runtime rejection / stable false admission), each with its own endpoint and interpretation, instead of one muddy "accuracy."
- Explicit abstention semantics distinguishing "no usable comparison" from "usable comparison with no stable signal," with all 44 zero-exposure observations reported rather than dropped.
- The traffic-vs-cell ablation directly explains *why* cell-count reasoning fails under closed-loop visitation skew, with a pre-registered superiority rule and confidence interval.
- An honest, well-audited negative result on exact MHS that redirects attention upstream to exposure — the most transferable lesson of the paper.
- Clear claim-boundaries section (Section 9) that anticipates most of the criticisms above.

## Limitations

- Single domain (hotel pricing) and single fault mechanism (one-bucket directional target-field shifts); persistent, multi-component, or non-target-fold faults may yield different exposure curves.
- Requires a maintained clean reference stream for occupancy — systems without one need a different maintenance design.
- Only 24 physical components (20 represented after admission); the exact binomial statement is coarse and conditional on an exchangeable-independence working model despite common random numbers; ~20-cluster bootstrap intervals may undercover.
- The ≤0.20 false-admission bound and the 0.01-nat sufficiency margin are simulator-specific; transferring gates or thresholds to other agents (especially human-facing ones) without recalibration risks false assurance.
- Refresh provably cannot be claimed to repair a stale map (frozen buffer reuse); drift handling is a state-machine smoke test only.
- No localization accuracy endpoint, no code/artifact release stated, and the MHS audit spans only 12 scenarios.

## Relevance

该文与你关注的 agent 行为评估与可信诊断直接相关：它回答的是"聚合 trace 何时根本不足以支持组件级故障结论"，为 LLM agent 的运行时评测提供了门控 + 校准弃权 + 暴露度分析的统计框架，可借鉴到 AgentDiagnosis 类工具和 agent 可观测性系统的设计中；其对"先看暴露、再打分、不行就弃权"的坚持对任何基于轨迹的 agent 评测都有方法论警示价值。

## Questions for Further Exploration

1. Does the two-gate + traffic-exposure pipeline transfer to real LLM agent stacks (e.g., WebArena/Tau-bench trajectories), where maintaining clean reference streams is an operational burden the paper does not price?
2. What false-admission criterion would be defensible in place of the coarse ≤0.20 if the abstention decision gates a human-facing alarm?
3. Do mask-family effects become material outside the frozen 0.01-nat margin when faults are persistent, multi-component, or non-target-fold — the two bins with observed gaps ([0.30, 0.45], [0.75, 0.90]) hint they might?
4. Can the exposure-first principle be combined with active probing (deliberately raising τ) without distorting the closed-loop policy being diagnosed?
5. How does the pipeline behave under genuine drift plus refresh — the paper only smoke-tests the state machine and explicitly does not show a stale map can be repaired.
