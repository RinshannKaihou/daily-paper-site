▪Methodology

  1. Formulate selection, not quantization.

    Each layer picks αl = (format, granularity, quantizer, transform, bits) under a deployment-cost budget Σκl ≤ B. The real objective — full-precision→quantized forward KL — is unmeasurable before the quantized model exists, so a calibration-time stand-in is needed.

  2. Price the error (Thm 3.1).

    The KL’s first-order term cancels at the full-precision reference, leaving a quadratic price: the candidate’s error covariance Σl is valued by the reference model’s downstream curvature Hl.

  3. Reduce to three scalars.

    ρ̂l = ½·σ̂² · ω̂ · τ̄ — τ̄ is a cached Gauss-Newton/Fisher curvature trace (one forward/backward pass per layer, no Hessian-vector probes); candidates scored on ≤512 tokens each.

  4. Search under budget.

    Bit allocation solved as a binary MILP; GPTQ held fixed as backend, so only the configuration decision varies.

Unifies old proxies: reconstruction score = price with H→I; imatrix-style score = further C→diag(C) — both rank-preserving only when the dropped factor is constant. Whitening is the minimax-optimal preprocessing (Thm 3.3).

▪Strengths

What holds up
  • One priced decision space. Formats, bits, granularities, transforms and codebooks become commensurable candidates; mixed precision loses its special status.
  • Honest theory bookkeeping. Thm 3.1 tracks omitted terms via η(α); Remark 3.2 states exactly when reconstruction/imatrix proxies preserve rankings.
  • Right validation order. Score↔KL alignment tested first (ρ ≈ 0.92–0.95), end-to-end decisions only after.
  • Clean, quotable whitening theorem (Thm 3.3) that explains why scaling/rotation families behave as they do.
  • Deployment-budget realism. Selection in minutes instead of hours, with exceptionally transparent setup (seeds, token budgets, candidate sets in Appx. D).

▪Limitations

Where it breaks
  • Regime-bound. Local, moment-stable, curvature-aligned only — the 8B reversal suggests that boundary is reached already at practical scale.
  • Isotropy assumption. The three-scalar trace score needs a near-isotropic residual; error on structured codebooks/lattices is unquantified.
  • Weight-space only. No activation/KV-cache/QAT; the extension is recorded as branch analysis and never evaluated.
  • Narrow evidence base. Dense Llama ≤8B, GPTQ-only, one calibration seed, 288K-token PPL eval; no code release stated.
  • Soft baselines. Transformation/granularity rivals are CKA-heuristic + random; Group-128 sits within 0.47 avg — the granularity head is near a no-op at 1B.

▪Questions for Further Exploration

  1. Does the quadratic price systematically under-rank fine bit allocations as models grow? A scaling study of η(α) vs size would locate the regime boundary quantitatively.
  2. What does the selector actually choose per layer — does it recover Hadamard/whitening, or find mixtures that beat a uniform recipe? Per-layer choice disclosure is missing.
  3. How does pricing compare against trained-rotation optimization (SpinQuant/QuaRot) under the same budget — minutes vs GPU-hours?
  4. Can the framework extend to activation/KV-cache quantization, where the conditional zero-mean assumption fails in low-bit or heavily clipped regimes?
  5. Would a hybrid — price as AMQ’s proposal distribution — recover AMQ’s 8B accuracy at a fraction of its 23,337 s search?
