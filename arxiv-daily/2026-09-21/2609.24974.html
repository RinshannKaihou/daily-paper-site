Harness-Zero: Harness Distillation via Agent-as-Harness

Haoran Ye et al. (5 authors) · PKU State Key Lab of General AI · PKU / Google / HKUST

Key metric · macro-avg success, 3 benchmarks
44.3%

23.3% → 44.3%  ·  +21.0 pts  ·  +90.1% rel

Above the 41.7% the same base model scores with the evolved harness still attached — and the reviewer, h*, and K are all removed at deployment.

Why this matters

Harness-evolution gains become LoRA-trainable supervision: ~300–500 frontier-reviewed trajectories per domain bake specialist scaffolding into a 9B model — no deployment-time harness routing.

一条由前沿模型出训练信号、LoRA 即可完成的路径，直击 agent 训练、蒸馏与自进化基础设施。

Critical edge

Every headline number is a single run — fixed seed 42, no variance — on 100–168‑task test sets; 2–3‑point margins could be noise.

Weak reviewer flips harmful: −12.0% when student = reviewer (Qwen3.6‑35B‑A3B) — a frontier‑model‑assisted recipe, not self‑contained.

Methodology

Review at the boundary, distill what survives

h = minimal Bash-only target harness · h* = evolved source harness · K = private reference harness, reviewer-only.

  1. Evolve & adapt

    A failure‑driven, three‑round loop grows a DeepAgents‑style harness h* (tools, middleware, skills, memory). Every component is then adapted into a private reference K: tools → action recipes, middleware → review middleware, skills/memory → review guidance.

  2. Agent-as-harness review

    The student proposes each turn under h. A GPT‑5.6 Sol reviewer sees only K — never hidden answers, verifier feedback, or the environment — and PASSes or REPLACEs with the smallest coherent correction valid in the target action space (budget 3–5 per trial). Review stays private; extra evidence must be gathered by actions the student can see.

  3. Distill

    LoRA SFT on accepted trajectories (PASSes included), reviewer reasoning masked and private strings filtered — the data must read as the student’s own. At deployment h*, K, and the reviewer are removed.

LoRA r32·2 epochs·65k-token seq·282–500 rollouts/domain·Harbor eval, pass@1 / SGC

Read: collection success does not predict distillation value — oracle access teaches non-generalizable shortcut corrections (98.6% → 15.0%), while harness-guided review alone reaches 30.0%. USPTO remains 8 pts below h*, attributed to chemical priors SFT cannot internalize from ~500 trajectories.

Strengths
  • +

    New problem, cleanly posed — harness-optimization gains become weights, not a permanent deployment-time scaffold tax.

  • +

    agent-as-harness sidesteps the action-space mismatch — and naive alternatives are shown to fail empirically (teacher-under-h* → 5.0%).

  • +

    Best-in-class ablations — the oracle-answer control (98.6% collection → 15.0% test) proves answer access is the wrong supervision signal.

  • +

    Unusually honest — self-reports the 2.4× collection latency, the weak-reviewer failure mode, and the USPTO knowledge gap.

  • +

    Favorable economics — +21.0 macro / AppWorld +32.1 from ~300–500 trajectories and LoRA on one 9B model.

Limitations
  • −

    Frontier-reviewer-bound — same-model review flips harmful (−12.0% on Qwen3.6-35B-A3B); not a self-contained recipe.

  • −

    Collection is expensive — one reviewer call per step, 237.2 s vs 100.1 s per trial; pass/replace-only control is coarse.

  • −

    Deep knowledge doesn’t transfer — USPTO 30.0% vs 38.0% with h*; context management isn’t expressible as student responses at all.

  • −

    Thin evidence base — one base model, LoRA only, single seed per number, 100–168-task test sets, no error bars.

  • −

    “Zero” oversells — the minimal harness stays; only the specialized harnesses are retired.

Questions for further exploration
  1. Does the recipe survive a second, weaker or non-Qwen student — or is there a hard reviewer–student capability-gap floor?
  2. What minimal subset of K’s procedural guidance explains most of the 30.0% vs 15.0% oracle gap?
  3. Can preference learning exploit the (rejected proposal, accepted replacement) pairs the review loop already produces?
  4. Does iterative distillation compose — re-evolve and re-distill without degradation, given single-run noise and the USPTO knowledge ceiling?
  5. How much of the 8-point USPTO gap closes with more trajectories vs pretraining-time chemistry (continued pretraining on reaction corpora)?
