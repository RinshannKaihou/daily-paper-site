# CausalLoss-Fin: Attributing Financial-Agent Loss to Decisions and Infrastructure Faults

> **一句话总结：** 在可精确重放的金融 agent 基准 FinalityBench 上，本文把基础设施故障（消息延迟/丢失/重复/乱序/半提交/陈旧读）分解为逐条可修复的消息级"故障实例"，并与 agent 决策做联合反事实干预，用一个无残差的三项伸缩恒等式把任意策略的损失精确拆成基础设施效应、策略差和参考策略残差，再用对称 Shapley 值把基础设施效应分摊为带符号的消息级分配；在 545 个植入因果的回合上，CAR 型 agent-only 归因基线因模型中根本没有基础设施变量，把 100% 的基础设施故障错记到 agent 决策上（合计 $114,383.40），修复其指认的"原因"只能挽回 0.0% 的损失，而最小充分集修复以每回合 2.3 次重放即挽回 100.0%（全量 Shapley 分摊需 280.1 次重放才达到同样的 100.0%）。

> **TL;DR:** On FinalityBench (a seeded, exactly-replayable payment-exception benchmark), the author makes infrastructure faults first-class intervenable variables alongside agent decisions, and derives an exact telescoping three-way split of any policy's loss into infrastructure effect + policy differential + reference-policy residual, with Shapley dividing the infrastructure effect into signed per-message allocations. On 545 planted-cause episodes across 3 policies, a CAR-shaped agent-only intervention baseline scores 0% top-1 on all three infrastructure strata (vs 100% for the proposed minimal sufficient set and joint Shapley), misfiles 100% of infrastructure episodes and charges $114,383.40 to agent decisions, and repairing what it names recovers 0.0% of $82,488.60 of infrastructure-caused loss vs 100.0% for minimal sufficient repair (2.3 replays/episode vs 280.1 for full Shapley). The catch: no LLM agent is evaluated — all policies are deterministic procedures, so the headline critique of agent-step attribution (CAR, CausalFlow, REFLECT) is about their variable scope, not their published systems.

## 核心贡献

- **联合干预的因果模型**：在同一个回合、同一个因果模型中，既对 agent 决策做 `do(A_k := a')`，也对单条基础设施消息做 `do(f_i := ⊥)`，并用精确共同随机数（deterministic replay）保证干预是精确运算而非抽样估计。
- **精确的三项损失分解（无残差）**：伸缩恒等式 `L(π,w) = [基础设施效应] + [策略差 vs 最优可实现策略 π*] + [参考策略残差]`，三项中两项可为负，因此都不是"份额"而是带符号分解；在全部 3852/3852 个受检回合上成立，并有测试套件断言。
- **消息级故障实例分解**：将已实现的投递调度与同 case 同 seed 的无故障调度做 diff，得到平均 7.6 个（最多 12 个）可单独修复的命名故障实例；并证明 FinalityBench 的故障族是"复合"而非"叠加"的——按族分解的实例池在 240 个回合中的 199 个（82.9%）无法复现已实现调度，因此按族归因不成立，族标签只能作为实例的上下文 but-for 注释。
- **四层植入因果基准（含过定案例）**：Single(169)/Conjunctive(126)/Overdetermined(70)/Agent(180) 共 545 回合，每个回合还带在因果集存在的前提下被验证无害的干扰故障，使"指认原因"不再是平凡任务。
- **量化 agent-only 归因的代价**：结构性地证明（无需语料）agent-only 基线不可能命名基础设施原因，并用语料测出这一缺陷的实际代价——识别准确率、分配误差、美元错记额、以及修复其指认后仍无法挽回的损失。

## Key Contributions

- **Joint intervention in one causal model.** Interventions on both agent decisions (`do(A_k := a')`) and individual infrastructure faults (`do(f_i := ⊥)`) on the same episode, with exact common random numbers — because every structural equation is deterministic, each intervention is a single replay with a known answer rather than a Monte Carlo estimate.
- **An exact, residual-free three-way loss split.** A telescoping identity decomposes any policy's loss into an infrastructure effect, a policy differential against the best implementable policy π*, and a reference-policy residual. Two of the three terms can be negative (the infrastructure effect is −6.8% for the optimistic policy — faults help it on net), so they are signed allocations, not shares. It holds on 3852/3852 episodes checked and is asserted by the test suite.
- **Message-level fault instances.** Diffing the realised delivery schedule against the fault-free schedule for the same case+seed yields named, individually repairable instances (7.6 per episode on average, ≤12). The paper shows per-family attribution is unsound: pooling single-family instances fails to reproduce the realised schedule on 199/240 (82.9%) episodes because fault families compose (duplicates placed relative to already-delayed arrivals, half-commits propagating only to copies that exist because duplication fired). Reordering appears to never fire in isolation but accounts for ~1/5 of moved deliveries in context.
- **Planted ground truth in four strata.** Single (169), Conjunctive (126), Overdetermined (70), Agent (180) — 545 episodes across 3 policies — each carrying verified-harmless-in-context distractor faults (without them, a trivial "earliest message" heuristic scored 100%).
- **A measurement of what agent-only attribution costs.** The 0% identification figure is a structural proposition (a model with no infrastructure variable cannot name one); the corpus measures the consequence: $114,383.40 misfiled to decisions, 0.0% loss recovered by repairing what it names, and 27.8% of infrastructure-loss episodes failing one-at-a-time decomposition.

## Methodology

**Setting.** FinalityBench episodes are single orders: a capture is submitted and its terminal outcome (settled/failed) becomes a fact at a later instant no tool can reveal early. Four systems (payment processor, double-entry ledger, ERP, bank feed) learn about events through delivery streams perturbed by a seeded fault engine in six ways (delay, duplication, loss, reordering, half-committed ledger postings, stale reads). An agent has 11 tools (5 irreversible) and a ship-by deadline; grading is the merchant's terminal economic shortfall against a privileged reference told when the capture resolves. The key property: an episode is a pure function of (case, seed, policy, delivery schedule), so replay with one message restored is exact — two worlds differing in one repaired delivery differ in nothing else.

**Structural model.** Exogenous variables are the case C and the fault realisation F = {f_1..f_m} (message-level instances); endogenous variables are the schedule S = SCHEDULE(C,F), per-system views V_t^(j) (fold of arrivals up to t minus read lag λ_j), agent actions A_k = π(H_{k−1}), effects E, and loss L = R − POSITION(C,E). F enters only through S and the views — infrastructure can harm an agent only by corrupting what it sees, never by moving money directly.

**Fault instances.** Named by diffing realised vs fault-free schedule; repairing all instances returns the fault-free world exactly. Family labels are but-for annotations taken in context, not definitions.

**Interventions.** (1) Repair a message: rebuild the schedule without one instance, re-run the same policy. (2) Substitute a decision: force action a' at step k and let the policy continue; step effect is reported as regret (loss avoided by best alternative), since resampling under a deterministic policy changes nothing.

**Exact three-way split.** With w the factual world, w₀ the fully repaired world, π the subject and π* the best unprivileged policy: L(π,w) = [L(π,w) − L(π,w₀)] + [L(π,w₀) − L(π*,w₀)] + L(π*,w₀). The terms telescope; nothing is left unattributed. Policy differential is a gap to the best implementable policy, so it is negative on 6.9% of episodes (down to $−1,442.60) when the subject beats π*.

**Shapley step.** Coalition value v(S) = L(π,w₀) − L(π,S) allocates the infrastructure effect across messages; allocations are signed and sum to the effect (efficiency is a check on the implementation, not a modelling assumption). Exact below 13 instances, permutation-sampled above (sampled estimate within 1.88% of exact in L1).

**Seven attribution methods compared.** Last action; first divergence; CAR-shaped agent-only baseline (agent-step substitution only — explicitly *not* a reproduction of CAR/CausalFlow/REFLECT, but their variable scope reduced to essentials, under favourable exact-intervention conditions); single-fault repair; joint greedy; minimal sufficient set (smallest joint repair, but-for as a set, search capped at 3 messages — the cap never bound: largest set found held 2 messages over 320 episodes); joint Shapley.

## Results & Highlights

- **Top-1 identification (Table I, 545 planted episodes):** Minimal sufficient set and joint Shapley score 100% on all four strata (single / conjunctive / overdetermined / agent) and 100.0% verdict accuracy. The CAR-shaped agent-only baseline scores 0/0/0 on the three infrastructure strata and 100 only on the agent stratum — its 33.0% overall verdict accuracy exactly equals the base rate of agent-at-fault episodes, i.e., it answers a different question correctly. Single-fault repair is exact on single and conjunctive (100%) but 0% on overdetermined, where repairing either sufficient message alone changes nothing and every one-at-a-time score is zero.
- **Allocation error (Table II):** Agent-only intervention misfiles 100% of infrastructure episodes and charges $114,383.40 of infrastructure-caused loss to agent decisions (allocation error 67.0%, same as last action); all four fault-intervening methods reach 0.0% allocation error and $0.00 charged — though the paper caveats that the agent/infrastructure *side* split is exact by construction once faults are intervenable; the hard part is *which message*.
- **Acting on the attribution (Table III):** Of $82,488.60 of infrastructure-caused loss, repairing what agent-only intervention names recovers 0.0% (at 70.5 replays/episode — more than the methods that are right); single-fault repair recovers 82.4% (8.4 replays); minimal sufficient set recovers 100.0% at 2.3 replays/episode vs joint Shapley's 100.0% at 280.1 replays — a 122x cost gap for the same recovery when the goal is remediation rather than full per-message allocation.
- **Interactions are common, not corner cases:** 27.8% (95% CI: 23.3–32.3%) of episodes with infrastructure loss do not decompose additively — repairing each message on its own does not account for the whole infrastructure effect (mean gap $76.73); on 5.6% (95% CI: 3.1–8.7%) every single-repair score is zero while the total is not. Intervals are 95% percentile bootstrap over 2,000 task-clustered replicates (219 tasks, 320 episodes).
- **Whole-corpus split without planting (Table IV):** For the rule-based policy, 75.1% of its $213.63 mean loss is infrastructure and 10.2% policy; for the ReAct loop, 59.3% infrastructure vs 17.3% policy; the transactional (finality-gated) policy has zero infrastructure effect and zero policy differential — 100% of its $31.37 mean loss is the irreducible residual. The optimistic policy's infrastructure effect is −6.8% (negative): faults *help* it on net, because the messages it fails to receive are ones it would have acted on wrongly.
- **By archetype (Table V):** Infrastructure dominates on lost/stale/duplicate message archetypes (stale processor 99.6%, lost settlement 99.4%, duplicate settlement 89.6% infrastructure), while "pending fail hard" has infrastructure −85.6% and policy 184.4% (signed terms, not shares). Worked example: a $24.99 lost_settlement task under ReAct loses $28.00; the three-way split assigns all $28.00 to infrastructure, Shapley splits it $14.00/$14.00 between a dropped processor settlement and a bank-feed reordering (neither sufficient alone, either sufficient to fix), while agent-only intervention blames "ship at step 0" for the full $28.00 — correct as advice, inverted as explanation.
- **Identity verification:** The telescoping identity holds on 3852/3852 episodes checked (asserted in the test suite); Shapley permutation sampling (used above 13 instances) sits within 1.88% of the exact value in L1.

## Critical Assessment

- **The headline 0% is a tautology, and the paper says so.** Agent-only intervention identifying 0% of infrastructure causes follows from its variable set alone ("a method cannot name a cause its causal model does not contain"); no experiment could refute it. The corpus only sizes the consequence. The framing in the abstract ("the agent-step attribution methods this paper compares against will name one of its actions") is more accusatory than the body's careful "it answers a different question correctly."
- **The baseline is a scope reduction, not the published systems.** The CAR-shaped baseline is explicitly not CAR, CausalFlow, or REFLECT; those systems were built for stochastic LLM agents and would use resampling interventions. Here the baseline gets *favourable* conditions on the evaluated dimension (exact substitution, deterministic policies) yet still fails structurally — a fair probe of variable scope, but the $114,383.40 figure should not be read as a score for any published system, and the paper's own Limitations concede that whether the conclusions transfer to stochastic agents is untested. The environment's model adapter has never called a model.
- **Planted identification is nearly a search problem.** Ground truth comes from faults injected by the same engine whose schedule the repair interventions replay; with deterministic replay and distractors, 100%/100% top-1 on all strata is attainable by construction. This validates the *decomposition machinery* more than it demonstrates performance on a hard perception/reasoning task — there is no LLM or learned component anywhere in the loop.
- **Overdetermination evidence is thin in the wild.** The overdetermined stratum has only 70 episodes pooled across 3 policies, and the natural rate (5.6% of infrastructure-loss episodes, CI 3.1–8.7%) is estimated from a generated population of 320 episodes. The claim that single-effect scoring *fails* there is arithmetic; the claim about how much it *matters* in practice rests on a small sample from one generator.
- **Single-environment scope with a convenient ontology.** All infrastructure harm flows through corrupted observations (F enters only via S and the views); an environment where infrastructure moves money directly, or where the agent can query an authoritative channel, would change the variable set and possibly the conclusions. The agent-step alternative menu is fixed at seven dispositions, and the reference-policy choice (benchmark's strongest implementable policy) fixes the residual by convention.
- **Self-citation ecosystem.** The setting, the artifact, and the grading are all the author's own prior work; independent replication on a second environment (or by a second group) is the missing test. On the other hand, the related-work check is verifiable: the paper states it checked each of CAR/CausalFlow/REFLECT directly for the absence of infrastructure variables, and positions AgenticRAG-FP (which does inject environment faults) as the closest prior work with a different target (diagnostic accuracy, not cost apportionment).

## Strengths

- A genuinely exact decomposition: the telescoping identity has no residual bucket where unattributed loss can silently accumulate and be misread as agent fault; the signed formulation handles the counter-intuitive cases (faults helping the optimistic policy at −6.8%; policy differential negative on 6.9% of episodes) that non-negative "share" methods cannot represent.
- The fault-instance decomposition (diff vs the fault-free schedule) plus the demonstration that fault families *compose* (82.9% reproduction failure for per-family pooling) is a sharp, reusable insight for anyone building fault-injection benchmarks.
- The overdetermined stratum operationalises the classic actual-causation hard case (Halpern/Chockler) with messages instead of agents, and Shapley's even split ($14.00/$14.00 in the worked example) is the principled answer.
- Decision-useful cost accounting in replays rather than wall-clock: minimal sufficient repair (100.0% recovery, 2.3 replays) vs joint Shapley (100.0%, 280.1) gives practitioners a real remedy-vs-allocation tradeoff, and the paper explicitly says which to use for which goal.
- Exemplary honesty and reproducibility: limitations stated in the paper match the weaknesses a critic would raise; released code + pinned artifact revisions + `make reproduce`; statistics (task-clustered bootstrap) chosen with visible care and justified.

## Limitations

- **No language model was evaluated.** All four policies are deterministic procedures; external validity to stochastic LLM agents — the very systems CAR/CausalFlow/REFLECT target — is untested, and whether a resampling intervention behaves like substitution is an open question the paper cannot settle from inside this environment.
- **One environment.** Everything is measured inside FinalityBench, whose faults are delivery-level only; infrastructure cannot move money directly, narrowing the variable set relative to real payment systems. Prevalence figures (27.8% non-additivity, 5.6% overdetermination) are properties of this generator, not field rates.
- **Small overdetermined stratum** (70 episodes; CI 3.1–8.7% on the natural rate), and the minimal-sufficient-set search cap of 3 messages, while never binding (max set size 2), makes the 100% recovery figure conditional on the cap in principle.
- **Fixed seven-option agent-step alternative menu** understates what a richer action space could contribute to step regret; a stronger reference policy would shift loss from the residual into the policy differential for every subject.
- **The verdict "which side" is easy once faults are intervenable** — Table II's zero allocation error is exact by construction; the discriminating content is which *message*, which limits how much method-level conclusion Table II can carry.

## Relevance

这篇论文对关注 LLM agent 可靠性与故障诊断的读者很有价值：它用可精确重放的金融环境证明，只在 agent 步骤上做反事实干预的归因框架在"环境才是肇事者"的场景下会系统性错怪 agent（100% 错记、0% 修复收益），并给出"把环境事件暴露为可干预变量 + 最小充分集修复"这一可操作的工程结论。虽然全文没有评估任何语言模型，其"变量集决定你能命名什么原因"的论点对任何构建 agent 事故分析/可观测性工具的人都是直接相关的警示。

## Questions for Further Exploration

- How does the three-way split behave when the agent is a stochastic LLM? Does a resampling-based agent-step intervention (as CAR/CausalFlow/REFLECT would use) converge to the substitution-based regret used here, or does the comparison invert?
- Would the conclusions survive in an environment where infrastructure moves money directly (e.g., a double-charge fault), rather than only corrupting observations?
- Can per-family attribution be salvaged with interaction-aware corrections (e.g., Shapley over families with the same message-level coalition value), or is compositionality a fundamental barrier to family-level reporting in fault-injection benchmarks?
- The natural rates here are generator properties: what are plausible field estimates for non-additivity (27.8%) and overdetermination (5.6%) in production payment-exception pipelines, and do they justify 280.1 replays for full per-message allocation?
- Extending the signed decomposition beyond a single privileged reference — e.g., a partial order over reference policies — to remove the arbitrariness of the residual term.
