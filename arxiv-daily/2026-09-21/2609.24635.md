> **一句话总结：** 作者设计"冻结写入者 + 隔离训练读取者"范式：当模型读到"交换盒子F与B的内容"这类操作语句时，其前向传播会在该语句的 KV cache 中留下"路由记录"——基座模型在隐藏全部状态描述时最多只恢复 0.06 的查询绑定（隔离训练后达 0.75–1.00），而载荷值可从 Llama-3.1-8B 第 12–15 层单个操作数名称 token 的 K/V 中直接读出，证明操作跨度写下的信息默认只被当"地址"用于路由、几乎从不被当"值"读取。

> **TL;DR:** Using a frozen-writer/trained-reader design (rank-16 LoRA on query/key/value/output, cache recomputed without gradients), the authors ask what a forward pass leaves in the KV cache of an operation line like "Swap the contents of Box F and Box B". With all state descriptions masked (OP_ONLY view), base readers of Llama-3.2-1B, Llama-3.1-8B and Mistral-7B recover at most 0.06 of queried box bindings, while isolation-trained readers reach 0.75–1.00 (+0.69 or more over the base, and far above ordinary fine-tuning, which stays ≤0.25 on the larger models); on 300 unseen code instances isolation training hits 0.627–0.688 vs 0.152 base. Causal operation-span K/V transplants show the cache entry acts as a routing record (transplant redirection +0.633 on Llama-3.1-8B base, +0.625–0.942 trained), and isolation training additionally exposes a direct payload path readable from a single operand-name token at layers 12–15 of 32 (14–17 in Mistral-7B) — the same site the base model uses for routing. The recipe transfers to ToMi (1.000/0.970/0.975 vs 0.040 base) and GSM8K (0.253/0.222/0.205 vs 0.023 base under masking), but is bounded by training coverage and costs open-book accuracy.

## 核心贡献

- **"存储但不可原生读取"**：在 boxes 任务（隐藏所有状态描述、仅可见操作语句的 OP_ONLY 视图）上，Llama-3.2-1B / Llama-3.1-8B / Mistral-7B 的基座读取者最多只能回答 0.06 的盒子查询，而隔离训练后的读取者能回答其中 0.75–1.00——操作跨度写入了信息，但基座模型几乎从不检索它。
- **操作的局部读/写足迹决定可恢复内容**：对 `a = b + 1` 这类赋值，被写变量 a 的值和只读操作数 b 的值在隔离训练后变得可从操作跨度恢复（donor binding 分别 +0.550 和 +0.650），而操作未提及的变量 sz/sw 始终处于随机水平——可访问信息精确追踪操作的读/写足迹。
- **同一载体的两种访问模式**：跨 Llama-3.1-8B 和 Mistral-7B 的操作跨度 K/V 移植因果性地重定向"读哪条可见状态"（routing，基座即有：+0.633/+0.55/+0.72，掩蔽源行后归零）；隔离训练不改变路由，而是额外添加对操作局部值的直接"载荷访问"（payload，全掩蔽下达 0.467–0.508，无移植时 ≤0.050）。
- **载荷寄存在单个 token 的窄层带中**：载荷值可从 Llama-3.1-8B 第 12–15 层（弱及 8–11 层；Mistral-7B 为 14–17 层）操作数名称 token 的 K/V 读出——恰是基座模型存放路由记录的位置；训练是暴露既有记录而非新建存储。
- **广度与代价**：该配方迁移到四种非字面代码操作、ToMi（0.970–1.000 vs 基座 0.040）和 GSM8K（约 0.22 vs 0.023），但受训练覆盖限制（值域 10–25 训练后 30–45 崩至 0.030–0.168），且损失开放书本准确率（GSM8K 从 0.970 降到 0.460–0.885）。

## Key Contributions

- **Storage without native retrieval**: with every state-description line masked, base readers answer at most 0.06 of boxes queries across three models (Llama-3.2-1B, Llama-3.1-8B, Mistral-7B), whereas readers trained in isolation answer 0.75–1.00 — the operation span stores information the base model rarely retrieves.
- **Operation-local footprint**: for assignments like `a = b + 1`, values of the written variable and the read-only operand become recoverable from the operation span after isolation training (donor binding +0.550 and +0.650 respectively), while unmentioned variables (sz, sw) stay at chance — accessible information tracks the operation's read/write footprint.
- **Two uses of one cache entry**: operation-span transplants causally redirect which visible line is read (routing, native: +0.633/+0.55/+0.72, abolished to 0.000 by masking the source line); isolation training does not reroute routing but adds direct access to operation-local values (payload readout 0.467–0.508 vs ≤0.050 without transplant under full masking). Both hold for three reader seeds and replicate in Mistral-7B.
- **One-token, mid-depth payload site**: the payload is read from the K/V of a single operand-name token in layers 12–15 of 32 (8–11 weakly; 14–17 in Mistral-7B) — the same site where the base model keeps its routing record, so training exposes an existing record rather than creating a new store.
- **Breadth and cost**: the recipe transfers to four non-literal code operations, ToMi (0.970–1.000 vs 0.040 base under OP_ONLY) and GSM8K (≈0.22 vs 0.023 base), but access is bounded by training coverage (values 10–25 fail to generalize to 30–45: 0.030–0.168) and costs open-book accuracy (GSM8K 0.460–0.885 vs 0.970).

## Methodology

**Writer, carrier, reader.** Each instance is a fixed prefix, description lines *s* (the state), one operation line *o*, and a query *q*. The **writer** is the base model with the LoRA adapter disabled: it processes prefix, *s*, *o* and leaves K/V at every position and layer — the **carrier**. The **reader** is a forward pass at *q* and the answer tokens: same weights, differing only by an activated rank-16 LoRA on q/k/v/o applied only at the query and answer rows, so it never alters the cache. Because the writer's weights and cache are recomputed without gradients at every step, nothing the reader recovers can enter through training — any recovery is recoverable from the unmodified cache.

**Views.** Attention logits are set to −∞ at chosen prefix positions: **OPEN** blocks nothing; **OP_ONLY** blocks everything except the operation line (all description lines masked); **BLOCKED** masks the whole instance (zero-information floor).

**Two training arms.** Both share seeds, steps and the optimal-data pair schedule; they differ only in which prefix positions the reader may see during training. **Isolation training (ISO)** trains under OP_ONLY; **ordinary fine-tuning (ORD)** blocks nothing and serves as the optimization control.

**Transplants.** A *pair* is two worlds differing only in assigned values. A transplant replaces the recipient world R's carrier with a donor world D's carrier at every layer, after asserting identical span positions and prefix lengths. Matched donors change the queried variable's value; mismatched/irrelevant donors are controls. Donor variants: D_ROLE (same values, different read variable), D_SAME (differs only in the operand's value), UNREL (all values replaced), SELF (no transplant).

**Metrics.** Exact-match accuracy; **donor binding** = P(answer follows D) − P(answer follows H); **redirection** (answer follows a different recipient-visible source); **payload readout** (fraction of answers equal to the donor's value when every description line is masked).

**Tasks and models.** *Boxes*: natural-language descriptions ("Box F has the needle...") with a Swap operation; two queries per instance; 32 item families; full-vocabulary argmax. *Code*: four assignments with random names/values 10–25, an operation line containing names only (`a`, `b = b, a`, `a = b`, `a = b + 1`), query `# print(a)`, greedy generation; role split into write target a, read-only operand b, sz (same value in both worlds) and sy (unmentioned). Models: Llama-3.2-1B-Instruct (FP32), Llama-3.1-8B-Instruct and Mistral-7B-Instruct-v0.3 (NF4); breadth experiments add ToMi, GSM8K and MMLU.

## Results & Highlights

- **Storage-without-retrieval gap (boxes, OP_ONLY, full-vocabulary argmax):** base readers recover at most **0.06** of queried bindings on all three models, vs **0.75–1.00** for isolation-trained readers (training loss 1.90–2.00 → 0.30–0.37); ordinary fine-tuning stays ≤0.031/≤0.094 (q0/q1) on Llama-3.2-1B and ≤0.25 on the larger models — the optimization control does NOT close the gap, so the gain is specific to training under the mask.
- **Unseen code instances (Llama-3.1-8B, OP_ONLY, 300 held-out items):** base **0.152** (.12/.18 across seeds), ordinary fine-tuning **0.112/0.120/0.142** (at or below the untrained reader), isolation training **0.627/0.688/0.610** — a >4x gain over base, and the effect is span-specific: a later filler line supports only 0.055 and out-of-item donors reduce trained readers to 0.013–0.040.
- **Routing is native and causal (operation-span transplant, Llama-3.1-8B):** the untrained model follows the value on the transplanted operation line's K/V on **0.642** of items vs **0.008** without transplant (+0.633; other seeds +0.55/+0.72), and masking the source line c=20 drops it to **0.000**; trained readers replicate (+0.625, two seeds up to +0.942); Mistral-7B base +0.700, trained +0.458 to +0.768.
- **Direct payload is learned, not native (all four description lines masked, Llama-3.1-8B):** trained readers output the donor's value on **0.467/0.500/0.508** (D_SAME) and **0.408/0.467/0.400** (D_ROLE) of items, vs **≤0.050** without transplant (SELF or UNREL); the untrained model manages only **0.117**. Mistral-7B shows a weak native payload (0.192) that training raises to 0.300–0.325.
- **Payload localization:** transplanting ONLY the operand-name token's K/V reproduces the whole-carrier readout (**0.475/0.508/0.525** vs 0.467/0.500/0.508 full-carrier; no transplant ≤0.042); only layers 12–15 are sufficient (+0.21 to +0.33) and necessary (−0.13 to −0.23 each when overwritten; ≤−0.06 elsewhere; Mistral-7B: 14–17). Overwriting the reader's own operand token with a dangling name lowers readout by 0.35–0.43 (near the floor), while overwriting the write-target token has no effect.
- **Breadth:** four non-literal code operations — base 0.067–0.227, ISO raises to **0.527–0.793 on 11 of 12 seeds** against a 0.040–0.047 floor (the remaining swap seed: 0.120). **ToMi** (Llama-3.1-8B, 200 validation questions, OP_ONLY): base/ORD ≤0.040, ISO **1.000/0.970/0.975**; transplanted move lines bind the reader to the donor's start location (≥+0.985), selective against room-name-only donors (≥+0.979). **GSM8K** (Llama-3.2-1B, 176 masked items): ISO **0.253/0.222/0.205** vs ORD 0.011–0.023 and base 0.023. On MMLU (question masked) the base reader still scores 0.598 — the gap is not universal.
- **Limits and cost:** trained on values 10–25, readers collapse on 30–45 (**0.030/0.040/0.168**); in-range context with out-of-range answer holds (0.711/0.814) but out-of-range answer values collapse (0.041/0.049); training on 10–99 restores 30–45 (0.470/0.380/0.417) but not 200–299 (0.015/0.025/0.000). A held-out fourth operation fails 256/256. ISO readers lose 0.105/0.168/0.017 of OPEN accuracy on unseen code instances and more on GSM8K (**0.460–0.885 vs 0.970**).

## Authors & Credibility

- **Lingfeng Wu** (University of Bonn) and **Behzad Shomal** (University of Bonn; Lamarr Institute) — an academic NLP/interpretability group; the paper follows the mechanistic-interpretability convention of combining causal patching with controlled training arms.
- Credibility signals: the design deliberately separates *what the cache holds* from *what the model retrieves* (frozen writer, cache recomputed without gradients, adapter active only at query/answer rows), and the paper ships multiple controls that many studies omit: an ordinary-fine-tuning arm, BLOCKED zero-information floors, mismatched/irrelevant donor controls, three training seeds per claim, and a replication in a second model family (Mistral-7B). Limitations are unusually candid (seed variance, quantization without a bf16 control, capacity confound).
- Weaknesses in credibility: all conclusions rest on small synthetic task suites plus two semi-natural ones (ToMi, GSM8K); only 9 pages with details in appendices; single-institution, presumably limited compute (1B–8B models only).

## Critical Assessment

- **Novelty is real but incremental-adjacent.** The two-uses framing (routing vs payload) borrows its vocabulary from Prakash et al. (2025)'s address-and-payload lookback, and source-recipient counterfactuals over frozen caches exist (Ding et al. 2026, for latent CoT checkpoints). The genuinely new combination is: masking views over an *unmodified* cache + frozen writer + reader trained in isolation, which cleanly separates storage from retrieval. That framing is a solid contribution.
- **The headline "base recovers ≤0.06" claim has a caveat the authors partially concede:** there is no capacity-matched control adapter and no rank sweep (Section 7, Appendix J), so it remains open whether the isolation-trained reader is *exposing a pre-existing record* or *computing over the carrier* as a new lookup table. The one-token/layer localization result (payload at the operand-name token, layers 12–15) is the strongest evidence for "exposing", but it is shown only for the payload path, not for the trained routing gains.
- **Seed variance is large relative to effect sizes in key experiments.** Trained routing spans +0.625 to +0.942; the value-matched switch spans 0.300–0.508; swap accuracy has a spread of 0.58 with one seed at 0.120 while the others reach 0.527–0.793. The value-matched switch and payload-localization claims rest on three seeds of one model (8B), and the held-out-footprint result rests on only two gate-passing readers.
- **Quantization confound:** the 8B writer runs in NF4 and the carrier results lack a bf16 control (Section 7) — for a paper whose entire object of study is the numerical content of the K/V cache, this is a non-trivial omission. Mistral-7B uses a modified chat template, another deviation stacked on top.
- **Coverage-bound generalization is honest but limits significance:** the reader trained on values 10–25 collapses on 30–45 and a held-out fourth operation fails 256/256, so what is demonstrated is a *trained-access* phenomenon bounded by training coverage, not a general capability — the paper says so, but abstract-level framing ("recovery tracks the footprint") could be over-read.
- **The GSM8K result is the weakest link in the breadth story:** 0.205–0.253 accuracy under masking is far from useful, ToMi/GSM8K test only the access gap, not the mechanism (no transplant/localization analysis on them), and MMLU (0.598 with the question masked) shows the gap does not transfer to tasks where the answer is not operation-local.

## Strengths

- **Clean causal design**: frozen writer + gradient-free cache recomputation + adapter active only at query/answer rows makes "anything recovered was already in the cache" almost axiomatic; the ORD arm rules out "more optimization" as the explanation.
- **Layered controls**: BLOCKED floors (0.040–0.047), mismatched/irrelevant donors, filler-line controls (0.055), out-of-item donors (0.013–0.040), and source-line masking that zeros redirection (0.642→0.000) — the claims survive their own ablations.
- **Single-token, single-layer-band localization** with both sufficiency (transplant-only-that-token reproduces readout: 0.475/0.508/0.525) and necessity (FRESH overwrite lowers readout 0.35–0.43) is rare and convincing evidence for where the record lives.
- **Second model family replication** (Mistral-7B) for routing, payload and the payload site (layers 14–17), plus three seeds throughout the core experiments.
- **Transparent limitation section** that names its own seed variance, capacity confound, quantization gap and scope limits — a model of honesty for this genre.

## Limitations

- **Scale and generality**: only Llama-3.2-1B, Llama-3.1-8B and Mistral-7B-Instruct-v0.3; only Mistral-7B passed the capability gate for the further families; all core tasks are single-step synthetic operations, and composition across successive updates is untested.
- **Trained-access vs pre-existing-record is not fully disambiguated**: no capacity-matched control adapter or rank sweep, so the reader may compute over the carrier rather than expose a lookup (Appendix J); only Mistral-7B's base model shows a (weak) native payload.
- **Training-coverage brittleness**: value-range extrapolation fails (10–25 → 30–45 collapses to 0.030–0.168; 200–299 stays at 0.015/0.025/0.000 even after 10–99 training); held-out operation types fail completely (256/256 "nothing").
- **Practical cost**: isolation training trades open-book accuracy (−0.105/−0.168/−0.017 on unseen code instances; GSM8K 0.460–0.885 vs 0.970), so the trained reader is a scientific probe, not a deployable improvement.
- **Precision**: the 8B writer is NF4-quantized with no bf16 control for carrier results; the 1B code model was excluded for low base accuracy.

## Relevance

这项工作与你对 Transformer 状态追踪、KV cache 机制可解释性的兴趣高度契合：它给出了一个可复用的"冻结写入者/隔离训练读取者"实验范式，并用因果移植定位到"操作语句的 KV 记录存于中层操作数名称 token"这一具体结论。若你关注模型如何在上下文中维护和读取世界状态（而非仅路由），这是近期最干净的机制证据之一。

## Questions for Further Exploration

- Does the layers 12–15 operand-token site generalize to deeper/wider models, multi-hop operation chains, or bf16 writers (removing the NF4 confound)?
- Is the isolation-trained reader exposing a pre-existing record or computing over the carrier? A capacity-matched control adapter and rank sweep (promised as Appendix J directions) would settle it.
- Can payload access be elicited without training — e.g., via activation steering, prompt formatting, or at inference time — given that routing is native but payload is not?
- How does the record behave under *sequential* state updates (write-after-write), where the box-swap composition question and the 256/256 held-out-operation failure suggest current readers break?
- Is the open-book accuracy cost (GSM8K 0.970 → 0.460–0.885) an inherent trade-off of mask-trained adapters, or removable with mixed-view training?
- Do real-world tasks where masked-question MMLU still scores 0.598 indicate the gap is specific to operation-local state — and which practical applications actually depend on operation-local payload access?
