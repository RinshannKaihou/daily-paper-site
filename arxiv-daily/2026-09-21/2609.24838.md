> **一句话总结：** 提出 MedRSI——首个面向医疗诊断 Agent 的递归自我改进（RSI）框架：Agent 通过「临床代价感知的失败优先级」和「快速发现、慢速注册」两套机制，把自身误诊自动转化为新工具与新模型；一个仅靠 GPT-4o 的通用 Agent 在 REFUGE2 青光眼任务上把平衡准确率从 56.2% 自我提升至 94.1%，超过人工设计的 MedAgent-Pro（90.4%）3.7 个点，并在 30 轮长程训练中保持不退化。

> **TL;DR:** MedRSI is the first recursive self-improvement (RSI) framework for medical agents. A general GPT-4o agent (OpenHands harness) diagnoses patients, a frozen LLM "clinical judge" grades each error's consequence on a 0–4 ordinal rubric (priority q_i = ε_i(1+λs_i), λ=2), reflection clusters failures into capability-gap specifications, and a tool builder invents candidates via three routes (code generation, tool composition, model training with U-Net/nn-U-Net/fusion transformers/CycleGAN-style translation). Candidates enter an experimental pool instantly (fast discovery) but join the persistent toolkit only after showing mean gain >0.5 balanced-accuracy points with no clinical-cost increase across K=3 held-out patient cohorts (slow registration). On REFUGE2 glaucoma diagnosis the agent self-improves from 56.2% to 94.1% balanced accuracy over 20 rounds, beating the manually engineered MedAgent-Pro (90.4%) and VisionUNite (85.8%), while consequence-weighted clinical cost falls from 12.4 to 2.5 per 100 cases; ablations show generic RSI (both mechanisms removed) reaches only 77.4% and degrades to 72.7% by round 30.

## 核心贡献

- **首个医疗 RSI 框架**：让通用医疗 Agent 从自身诊断失败出发，自主发明、评估并积累任务特定的临床工具与 AI 模型；推理模型 M 与执行流程 P 全程冻结，只有工具注册表 T^S 增长，保证改进过程可审计。
- **临床代价感知的失败优先级**：把"错得多频繁"换成"错得多严重"——由冻结的临床裁判（LLM + 预注册 rubric，临床医生校准）对每个错误给出 0–4 级后果分（可忽略/轻微/中度/严重/危重），失败优先级 q_i = ε_i(1+λs_i)；并定义"临床代价" = 每 100 例的后果加权错误数，作为与准确率并列的一等优化目标。
- **快速发现 + 慢速注册**：候选工具立刻进入实验池试错，但只有在其收益于 K=3 个后续独立患者队列上持续 >δ（0.5 个平衡准确率点）且临床代价不升（ΔC̄ ≤ 0）时才被注册进持久工具集；候选制品全部版本哈希冻结、配对盲评，阻断"局部有益但整体不稳"的工具污染后续自进化。
- **三条发明路线 + 涌现式工具生态**：代码生成、工具组合（如分割掩膜→vCDR 计算）、模型开发（训练分割网/预测器/多模态融合网/CycleGAN 翻译网）；在不接触 MedAgent-Pro 工具集的情况下，20 轮内 100% 覆盖专家设计的五大能力类别，"重新发现"了专家工具分类体系。
- **大规模实证**：2 个公开基准（REFUGE2 青光眼、MITEA 心脏病）+ 2 个私有临床队列（多模态青光眼 1,898 眼、对比增强超声心动图 3,158 研究），5 个随机种子 + bootstrap 置信区间 + 10,000 次配对置换检验，含 8 项消融、4 个推理 backbone 迁移、长程 30 轮稳定性实验。

## Key Contributions

- **First medical RSI framework**: a general diagnostic agent autonomously invents, evaluates, and accumulates task-specific clinical tools and AI models from its own failures, with the reasoning model M and workflow P frozen — only the versioned tool registry T^S grows, keeping the improvement trajectory inspectable.
- **Clinical-cost-aware failure prioritization**: replaces error frequency with error consequence — a frozen LLM clinical judge (pre-registered rubric, clinician-calibrated via weighted κ) assigns each error a 0–4 severity score; failure priority is q_i = ε_i(1+λs_i), and "clinical cost" (consequence-weighted errors per 100 patients) becomes a first-class metric alongside accuracy.
- **Fast discovery with slow registration**: candidates are invented aggressively into an experimental pool, but are admitted to the persistent toolkit only after a mean gain >0.5 balanced-accuracy points with no clinical-cost increase over K=3 subsequent, disjoint patient cohorts — with frozen version hashes and blinded paired evaluation preventing unstable tools from contaminating future self-improvement.
- **Three invention routes and emergent tool ecosystems**: code generation, tool composition (e.g., segmentation masks → vCDR calculator), and model development (U-Net segmentation, EF predictors, three-branch multimodal fusion networks, CycleGAN-style contrast-echo translation); without access to MedAgent-Pro's toolkit, MedRSI covers 100% of the expert-designed capability categories by round 14.
- **Extensive evidence**: two public benchmarks (REFUGE2 glaucoma, MITEA heart disease) plus two private clinical cohorts, 5 seeds with bootstrap CIs and 10,000-permutation paired tests, 8 ablations, 4 reasoning backbones, and 30-round long-horizon stability analysis.

## Methodology

**Overall loop.** At round r the stable agent is H_r = (M, P, T_r^S). Each round: (1) *diagnosis* on an experience batch of 120 glaucoma / 60 heart cases with reference labels withheld; (2) *failure evaluation* — an evaluator marks errors e_i = 1(ŷ≠y), and a separately-prompted frozen clinical judge (GPT-4o + task-specific rubric) assigns ordinal consequence s_i ∈ {0,…,4} from the documented clinical pathway (e.g., missing advanced glaucoma → discharge vs. urgent reassessment); for continuous EF prediction, correctness uses a ±5 percentage-point clinical tolerance; (3) *prioritization* q_i = ε_i(1+λs_i) with bounded reflection budget and failure clustering by inferred capability gap; (4) *reflection* converts each cluster into a structured capability specification (testable hypothesis, inputs, endpoint); (5) *capability development* via three routes — code generation (deterministic operations with I/O contracts), tool composition (versioned dependency chains, e.g., cup/disc masks + diameter measurement → vCDR), and model development (permitted architectures: U-Net, nn-U-Net, ResNet-50, three-branch fusion transformer, CycleGAN-style translation network; training manifest and checkpoint part of the candidate record); (6) *trial and registration*.

**Fast discovery with slow registration.** A candidate passing a permissive discovery screen (ΔP_disc > 0 on a discovery cohort, using an evaluator-only copy of the agent) enters the experimental pool T^E with a frozen artifact hash. It is then evaluated paired against the reference agent (identical seeds/inputs; ⊕T makes the candidate *available* to the planner, not forced) on K disjoint trial cohorts. Registration requires mean balanced-accuracy gain over K cohorts ΔP̄(T) > δ (δ = 0.5 points; 0.01 normalized MAE for EF) AND mean clinical-cost change ΔC̄(T) ≤ 0. Accepted candidates are committed serially against the live registry hash, so stale evidence never registers a tool into changed context.

**Clinical cost.** C(H,V) = mean consequence-weighted error per 100 patients, where each erroneous case contributes its severity s_i; an improvement can reduce cost by fixing an error entirely or by replacing it with a less consequential residual error. Setting λ=0 recovers uniform prioritization (the main ablation).

**Experimental setup.** OpenHands v0.20 harness, GPT-4o (2024-08-06) as reasoner and judge, temperature 0 diagnosis / 0.7 building; 20 improvement rounds (30 for long-horizon), up to 6 candidates/round, 12 A100-80GB accelerator-hours per round; λ=2, K=3, δ=0.5. Data: REFUGE2 (fundus, glaucoma) and MITEA (3D echo, heart disease, 143 subjects) with patient-level splits and a locked final test partition; two private cohorts — multimodal glaucoma (1,898 eyes / 1,236 patients, fundus+OCT+visual field, two tertiary centres 2018–2024, 38% prevalence, 486 test eyes, dual specialist adjudication) and contrast echocardiography (318 contrast + 2,940 noncontrast studies from 1,874 patients, LVEF reference from same-visit cardiac MRI, 96 contrast test studies). Statistics: 5 trajectories, patient-level bootstrap 95% CIs (2,000 resamples), paired permutation tests (10,000 permutations), final round pre-specified as primary.

## Results & Highlights

- **Public benchmarks — self-improvement beats human engineering.** Balanced accuracy rises from 56.2% to 94.1% on REFUGE2 glaucoma and from 56.5% to 82.3% on MITEA heart disease over 20 rounds (F1 83.2%/77.3%, AUC 97.2/88.6). This surpasses the strongest tool agent MedAgent-Pro (90.4%/77.3%) by +3.7/+5.0 points, the best general multimodal model VisionUNite (85.8% glaucoma), and matched MedAgent-Pro reruns on the authors' own test partitions (89.6%/77.1%); paired permutation tests: P < 0.001 (round 0 vs 20), P = 0.004 (glaucoma) and P = 0.011 (heart) vs reruns. Round-wise gains (56.2 → 80.9 → 91.2 → 94.1) are consistent across all 5 trajectories (93.4–94.7% final).
- **Clinical cost and error severity fall, not just accuracy.** Consequence-weighted clinical cost drops from 12.4 to 2.5 per 100 cases on glaucoma (14.1 → 4.3 on heart); serious+critical errors fall from 9.8% to 1.5% (glaucoma); calibration error ECE improves 0.29 → 0.05 and MCC reaches 0.81; glaucoma sensitivity rises 28.4% → 92.0% and specificity 84.0% → 96.2%.
- **Private multimodal glaucoma: beats a manually built, budget-matched model.** Initialized from full MedAgent-Pro, MedRSI reaches 92.1% balanced accuracy (95% CI 90.2–94.0, F1 90.2, AUC 96.4) vs 87.8% (85.3–90.3) for a three-branch fusion model hand-developed by the study team with matched compute, vs 79.2% for MedAgent-Pro itself and 83.9% for late fusion. On structurally-functionally discordant cases it scores 86.7% vs 71.4% for late fusion; sensitivity for early glaucoma with a normal-appearing disc rises to 88.2% vs 64.9% with inherited fundus tools.
- **Contrast echocardiography EF prediction: invents its own data pipeline.** Facing only 318 contrast studies, the agent trains a CycleGAN-style translation model to synthesize 2,716 contrast studies from the noncontrast domain, then retrains an EF predictor: final nMAE 0.55 vs 0.66 for the task-specific regressor trained on real contrast data only, 0.85 for MedAgent-Pro, and 1.00 for raw GPT-4o; MAE 5.1 LVEF points, r = 0.83, ICC 0.81, and 68.8% of predictions within the ±5-point clinical tolerance vs 58.3% (task-specific regressor) and 42.7% (initial agent). Synthetic-only training yields 0.79, showing augmentation (not replacement) drives the gain; synthetic frames reach SSIM 0.81 vs paired real frames.
- **Ablations isolate both mechanisms (Table 6, glaucoma round 20).** Uniform failure priority: 88.7% (−5.4) with clinical cost 6.0 vs 2.5 and 4.0% serious+critical vs 1.5%; immediate registration: 82.4% (−11.7); generic RSI (both removed): 77.4%, collapsing further to 72.7% by round 30 while hoarding 45–60 tools; full MedRSI holds 94.4% at round 30 with 16 tools and no round-to-round drop >0.3 after round 12. Removing model development costs 9.8 points (94.1 → 84.3); code-generation-only reaches 79.8%.
- **Emergent rediscovery of the expert tool taxonomy.** Category coverage of MedAgent-Pro's five expert capability classes goes 0% → 100% by round 14 (118 candidates → 41 pass discovery → 16 registered; median trial gain +2.2 points for registered vs −0.9 for discarded). Agent-trained U-Net reaches Dice 0.87 (cup) / 0.95 (disc) with vCDR correlation r = 0.91; MITEA ventricular segmentation Dice 0.90 supporting EF MAE 5.8 points.
- **Cost and robustness.** One public-task trajectory consumes 212 A100-hours and 1.9B reasoning tokens (68% on model training; 2.1 days on a single node); across all four tasks: 197 development attempts, 651 GPU-hours, 12.3 days. Findings transfer across Claude Sonnet 4.5, Gemini 2.5 Pro, and Qwen2.5-VL-72B (round 20: 89.8–93.6%, all exceeding MedAgent-Pro; 11 of 16 tool functions recovered by all four backbones), and across λ ∈ [1,4] and K ∈ [3,5]; a single trial cohort (K=1) yields only 84.7% at round 30 vs 94.4% (K=3/5).

## Authors & Credibility

The team is from the University of Oxford (Junde Wu, Jiayuan Zhu, Minghao Hu, Fenglin Liu) and Stanford University (Jiazhen Pan). Junde Wu is the first author of Medical SAM Adapter (Media 2025) and a co-author of MedAgent-Pro (Wang et al., ICLR 2026) — meaning the paper's strongest baseline is the group's own prior system, which cuts both ways: unmatched familiarity with the baseline, but a self-referential comparison. Co-author Jiayuan Zhu works on validated medical imaging pipelines, and the group's prior agentic-medical-AI line (MDAgents-collaborations, MedAgent-Pro) gives them credible command of both the agent-infrastructure and clinical-evaluation sides. The evaluation protocol (patient-level splits, locked test sets, frozen judge, preregistered rubrics and margins, blinded paired trials, permutation tests) is unusually careful for an agent paper. Code is released at https://github.com/ImprintLab/MedRSI. The private cohorts (two tertiary eye centres, cardiac MRI references) indicate genuine clinical collaboration rather than benchmark-only work.

## Critical Assessment

- **The clinical judge is GPT-4o — the same model family as the agent's own reasoner.** Clinicians only score a calibration set (weighted κ reported) and adjudicate disagreements; the 0–4 consequence scores that drive both prioritization AND the headline "clinical cost" metric (and the registration constraint ΔC̄ ≤ 0) are produced at scale by an LLM rubric designed by the authors. "Clinical cost fell from 12.4 to 2.5" therefore partly measures alignment with the authors' own severity rubric, not clinician-adjudicated outcomes. The λ-sensitivity sweep (88.7% at λ=0 → 94.1% at λ=2 → 92.4% at λ=8) shows the headline number is a property of this design choice.
- **Self-referential baseline.** The central comparison — MedAgent-Pro — is the authors' own prior system, and one co-author appears on both papers. The rerun protocol (same partitions, seeds, 0.5-point agreement with published values) is fair, but no independent state-of-the-art glaucoma agent or recent ophthalmology foundation model fine-tuned on REFUGE2 training data is included as a comparator; the "general multimodal" baselines (GPT-4o 56.4%, Qwen2.5-VL 54.3%) are strawmen for a supervised task.
- **Reproducibility is asymmetric.** Code is released, but two of the four test beds — including the paper's most impressive result (92.1% vs 87.8% hand-built fusion) — are private cohorts that no external lab can evaluate. The public-task result is fully reproducible; the private multimodal/contrast-echo claims are not.
- **MITEA specificity quietly drops from 90.2% to 86.2%** while sensitivity surges 22.8% → 78.4% — the agent's self-improvement shifts its operating point toward the positive class. Balanced accuracy hides this; a clinical audience would want the threshold story told explicitly.
- **Test-set reuse across rounds.** The locked test partition is evaluated at every round to draw the round-wise curves. The final round is pre-specified as primary and checkpoints are frozen before testing, which mitigates selection bias, but the narrative leans on curves that a strict reading would treat as exploratory.
- **Cost of the loop.** 212 A100-hours + 1.9B tokens per two-task trajectory (~2 days) is fine for research but nontrivial to scale across specialties; the paper does not report how much of the gain survives at 1/10th the budget.
- **No prospective or human element.** The authors themselves concede the framework's value hinges on reference-diagnosis quality and rubric consistency; there is no clinician-in-the-loop evaluation, no workflow study, and all tasks are image-classification/regression — the severity rubric for interventional or treatment decisions would be far harder to pre-specify.

## Strengths

- Genuinely new problem framing: safety-gated recursive self-improvement, with the two mechanisms (consequence weighting, slow registration) each motivated by a concrete clinical analogy (triage; staged device adoption) rather than generic agent folklore.
- Methodologically rigorous for the agent genre: patient-level splits, frozen judge and preregistered rubric/margins before any self-improvement, versioned candidate artifacts, blinded paired evaluation on disjoint cohorts, 5 seeds, bootstrap CIs, 10,000-permutation tests, and negative results reported (per-tool trial gains, 61 discarded candidates, the failed rim-texture tool dissected in detail).
- The slow-registration ablation is a compelling causal story: one tool with +6.1 discovery gain but −2.3/−5.4/−3.1 trial gains becomes self-reinforcing under immediate registration, spawning three compensating tools and dragging accuracy from 89.6% to 76.9% — a concrete, mechanistic demonstration of the destructive feedback loop the mechanism prevents.
- The rediscovery result (100% expert-category coverage without access to the expert toolkit; tool taxonomy converging across four different reasoning backbones) is an interesting scientific finding independent of the headline accuracy.
- Honest accounting of selectivity: 118 candidates → 16 registrations; the paper emphasizes that the gain comes from selective capability evolution, not tool accumulation.

## Limitations

- Depends critically on high-quality reference diagnoses and a consistent consequence rubric; both degrade in rare, ambiguous, or multimorbidity cases — exactly the failures the prioritization is supposed to target (such cases are "withdrawn until adjudicated," i.e., excluded from the signal).
- Only four tasks, all in ophthalmology/cardiology imaging; text-only clinical reasoning, treatment planning, and longitudinal care are untested, and the 0–4 severity rubric does not obviously transfer to interventional settings.
- The strongest results (private multimodal glaucoma, contrast echo) cannot be independently reproduced; the public REFUGE2/MITEA tasks are relatively small and binary.
- No clinician-in-the-loop or prospective evaluation; the "clinical cost" construct is validated only against the same LLM rubric that defines it.
- The reasoning model is frozen at GPT-4o — capability growth is bottlenecked by a 2024-era planner, and it is unclear whether conclusions hold with a frontier 2026 model that already has stronger tool-use priors.
- Per-trajectory cost (212 GPU-hours, 1.9B tokens, days of wall-clock) and the K=3 cohort requirement delay capability adoption by design, which may matter in fast-moving clinical settings.

## Relevance

这项工作把通用 Agent 自我改进（Darwin Gödel Machine、AlphaEvolve 一类 RSI）首次系统性地搬进高风险医疗场景，其「临床代价加权失败优先级 + 快速发现/慢速注册」是让自进化 Agent 在安全敏感领域保持可控、不退化的可复用机制设计，对关注 agent 自我改进与 LLM tool-learning 的研究直接可借鉴。同时它给出了医疗多模态 Agent 超越人工设计系统（+3.7 平衡准确率点 over MedAgent-Pro）的实证路线，医疗 AI 方向也值得精读其评测协议。

## Questions for Further Exploration

- How robust is clinical-cost-aware prioritization when the LLM judge's severity rubric is miscalibrated for a new specialty (e.g., oncology staging)? Does judge-clinician weighted κ stay high outside ophthalmology/cardiology, and can clinician spot-audits substitute for full rubric design?
- Can the K=3 cohort-trial requirement be replaced by cheaper sequential statistical tests while preserving long-horizon stability (the K=1 vs K=3 gap at round 30 is 84.7% vs 94.4%)?
- How much of the private-cohort win (92.1% vs 87.8% for the hand-built fusion model) comes from the failure-driven development loop itself vs simply training a multimodal network — i.e., would a human team given the same reflection records and budget match it?
- Does the framework extend beyond perception-heavy diagnosis to settings with interventional consequences, where a pre-registered 0–4 severity rubric is much harder to specify?
- What happens under post-deployment distribution shift (new camera/scanner)? The discarded rim-texture tool failed precisely because of camera- and illumination-sensitive features — should registration require an "environment fingerprint" and re-trialing on drifted cohorts?
- Does the round-wise test-curve methodology survive preregistration scrutiny — would conclusions hold if only the single pre-specified final-round comparison were reported?
