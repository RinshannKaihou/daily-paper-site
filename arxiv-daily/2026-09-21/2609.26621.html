Greedy Decoding Is Not Precision-Invariant: Cross-Precision Output Divergence in LLM Inference

Key Metric
+22 pp

Exact agreement on GSM8K, TinyLlama-1.1B: 41% → 63% with margin-gated FP32 lm_head recomputation — gate fires on 0.7–1.4% of steps, measured +1.4% latency.

Why This Matters

A template for diagnosing — and partially mitigating — format-induced silent output divergence, directly transferable to inference-reliability and silent-data-corruption detection.

Critical Edge

The fix is unproven where it matters most: no 70B+ results, no vLLM/SGLang integration, 0pp at batch ≥ 8, and only +1pp under end-to-end FP8 — the cross-model story is an admitted unvalidated hypothesis.

01Methodology

  • Testbed. TinyLlama-1.1B-Chat on A10G; BF16 vs FP16 greedy decoding, fixed seeds, n=100 per dataset (GSM8K 8-shot CoT, HumanEval, MBPP). Replicated on L4/A100/T4, FP8 variants, batch 1–32, MoE, and a 12B probe.
  • Causes ruled out first. Bit-identical within each precision (no kernel non-determinism); cuBLAS kernel-selection difference indistinguishable from baseline (42% vs 41% EAR).
  • Error model. Per-logit perturbation splits ~2.4% body vs ~97.6% lm_head (the d×|V| projection, ~135K vocab, amplifies ~5×). Proposition 1: a token flips iff a competitor's differential perturbation exceeds its original logit gap.
  • Margin gate. All interventions fire only when top-two margin Δ<τ=10⁻³: (A) integer logit binning · (B) top-K=8 FP32 rows · (C) full-vocab FP32 lm_head recomputation. Baselines: global FP32, ungated τ=0, FP32 oracle.
  • Causal localization. Layer grafting, KV-cache grafting, logit-lens traceback, Qwen2.5-3B replication — all four point at the lm_head.
  • Statistics. Matched-pair McNemar (p<0.001) · 10k bootstrap CIs · Wilson CIs · 3× replication · TOST ±5pp non-inferiority (p=0.009).

03Strengths

  • Falsifiable mechanism, backed by four converging causal experiments — not correlation.
  • Five counter-intuitive predictions pre-stated, all confirmed: quantization is a no-op; K=2 suffices; ungated recomputation hurts; broader FP32 scope hurts (63%→44%).
  • Exemplary small-n statistics: McNemar, TOST, Wilson + 10k bootstrap CIs, 3× scaled replication.
  • Honestly mapped boundaries (bs ≥ 8, FP8, saturated checkpoints) plus per-prompt stratification that exactly accounts for the +22pp.

04Limitations

  • Scale: interventions only at 1.1B–7B; 70B+ untouched — cost model unproven where vocabularies are largest.
  • n=100 per dataset for the headline table (±9–10pp CIs); only GSM8K replicated at n=300.
  • Best-case hardware: A10G-centric; same model gives +3/+14/+20pp across A10G/A100/L4.
  • Greedy only, bs ≤ 4: 0pp at bs ≥ 8, +1pp under end-to-end FP8 — body-dominated there.
  • Not bit-exact: 37% of divergences unreconciled; ~12pp weight-storage gap remains.
  • No serving-stack test: custom loop only — vLLM/SGLang/TensorRT-LLM overhead unverified.
  • In-sample hypotheses: the cross-model explanation and CVTD screen are unvalidated prospectively.

05Questions for Further Exploration

  • Does the margin-gated repair survive sampling-based decoding, where argmax zero-tolerance no longer holds?
  • Can the CVTD screen validate prospectively on unseen models and hardware — or is the precision-stability hypothesis testable via controlled retraining?
  • Does <4% overhead hold in vLLM/SGLang continuous batching — and is there a per-request gating that survives bs ≥ 8?
  • Could a body-anchored checkpoint format (canonical save-time rounding) close the ~12pp weight-storage gap the head cannot fix?
  • How does divergence interact with speculative decoding, where draft and target may run at different precisions?
