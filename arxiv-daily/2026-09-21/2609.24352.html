Why this matters

First causal evidence that LLMs already build world representations but only use them once few-shot demos elicit readout — groundwork for agentic world models.

Critical edge

The causal loop is only half-closed: no Shot-Vector injection (rescue) experiment, and 20-iteration erasure is partial — probe AUROC still ≈0.68–0.71 after ablation.

Methodology

  1. 01Graph-world task. Five topologies (4×4 / 5×5 / 3×5 lattice, triangle, torus) with fruits on nodes; the prompt is one 48–80-node random walk — predict the node two steps right. State-Line topologies dropped to kill the copy-two-back shortcut.
  2. 02Different-worlds demos. Every demonstration comes from another world: same topology, disjoint fruit assignments — copy/elimination shortcuts ruled out. Shots ∈ {0…32}, 300 test samples per condition.
  3. 03Probing construction. Rank-r linear probes (r=2/4) on pooled, RMS-normalized hidden states; AUROC plus probe-free Dirichlet Energy; layers 4/20/36+.
  4. 04Shot Vector geometry. Mean few-shot-minus-zero-shot state shift; its angle to the world subspace; joint PCA of centroids; cross-shot subspace overlap.
  5. 05Matched causal test. 20-iteration amnesic erasure of the rank-r subspace vs a rank- and norm-matched random-subspace control; 95% bootstrap CIs (5,000 resamples).
  6. 06Transfer. ARC-AGI-1&2 (cross-task demos), Mind2Web (cross-website), Othello (cross-board); six base model families overall.

Strengths

  • Sharp, falsifiable dissociation: construction (AUROC, Dirichlet Energy) flat while use (accuracy, intervention sensitivity) changes with shots.
  • Well-controlled causality: rank- and norm-matched random-subspace intervention, bootstrap CIs, 5-seed sensitivity (stds ≤ 0.011 on AUROC).
  • Shortcut-aware design: different-worlds demos, dropped State-Line topologies, cross-topology demos still work.
  • Consistent replication across six base model families, layers, and rank ablations (r=2/4/8/16).
  • Code released, prompts verbatim, honest limitations section.

Limitations

  • Mechanism verified only on the synthetic graph task; ARC / Mind2Web / Othello get behavioral curves but no representation analysis.
  • No Shot-Vector injection (rescue) experiment — only erasure-side causal evidence.
  • Erasure is partial: probe AUROC ≈0.68–0.71 after 20 iterations; repair effects can’t be fully excluded.
  • Accuracies plateau at 30–45%; 300-sample evals, no CIs on behavioral curves; “one contributing factor” among uncharacterized others.
  • Static adjacency-only world model — no dynamics; the −0.487 zero-shot value is left unexplained.

Questions for further exploration

  1. Q1Would injecting the Shot Vector into zero-shot states rescue two-step accuracy, closing the causal loop?
  2. Q2Does the relocated readout subspace persist on harder horizons (three-step, non-lattice topologies)?
  3. Q3Is the Shot Vector shared across topologies, tasks, and model families — a universal readout-eliciting direction?
  4. Q4Why does erasure help zero-shot (−0.487)? Is the decoded subspace anti-correlated with correct answers?
  5. Q5Can SFT/RL induce the relocation in-weight, and can probes predict which training data yields transferable world representations?
