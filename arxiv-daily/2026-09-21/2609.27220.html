⚠ Critical Edge

Detection strength doesn’t bound gains — repair-space coverage does: on LLaDA-2+Orca-Math the selector captures well under half of the 65.9% oracle headroom (51.9% achieved).

Supervised heads retrained per model–dataset pair · no transfer tested · code anonymous-only at submission.

Methodology planner, not just a detector

Detectrisk @ midpoint
Decideτ gate
Repairremask B=8
Selectbest branch
  1. Formalize SBW lock-in. Extract the answer at each of T denoising steps; if answers in a window around the midpoint checkpoint are identical, generation is early-locked — wrong-vs-gold makes it SBW.
  2. Remove the surface confound. Match correct/wrong lock-ins one-to-one on an 18-dim surface vector (confidence, entropy, margin, stability) with Rosenbaum–Rubin calipers; SMD falls 0.617/0.934 → 0.016/0.065.
  3. Encode trajectories. Record multi-layer, multi-step hidden states on answer + token-change tracks; compress via fixed Achlioptas random projections.
  4. Detect risk. A BiGRU over the trajectory outputs prisk; threshold τ routes to continue-vs-repair using only pre-checkpoint states.
  5. Repair locally. A fixed bank of B=8 (checkpoint, remasking-strength) actions remasks only the answer region and resumes denoising, keeping most of the draft.
  6. Select the branch. A trajectory-aware verifier scores each continuation; a histogram gradient-boosted selector fuses trajectory score, task context, and pool agreement.

Strengths

  • Confound-controlled evaluation: propensity-style Surface-18 matching separates “hidden states know more” from “they exploit confidence” — the standard critique of internal-state papers, answered.
  • Complete planner: whether / where / which, each component ablated (targeted remasking −4.4 pp, random trigger −8.8 pp, branch trajectories −4.0 pp).
  • Consistent across 2 families × 3 datasets, including a setting where competing remasking baselines can’t beat a 50% baseline.
  • Honest oracle analysis: repair-space coverage named as a first-class limit, not buried.
  • Compute-efficiency: selective trigger cuts 5.0× → ~3× at equal accuracy; Pareto-dominates PRM-guided repair.

Limitations

  • Fixed B=8 action bank caps headroom: repair-oracle is only 65.9% on LLaDA-2+Orca-Math (vs 71.7% MetaMathQA); correct branches can still be misranked.
  • Thin margins outside MetaMathQA: +1.8 pp on NuminaMath vs the +6.0 headline; matched-benchmark AUROC isn’t comparable to natural-distribution precision/recall (50/50 base rate by construction).
  • Per-setting supervised heads trained with gold labels; zero cross-model / cross-dataset transfer tested.
  • Cost is denoising-work-normalized, not wall-clock — B=8 branches per high-risk example shift real latency.
  • White-box + math only: needs multi-layer hidden states (excludes API models); code anonymous, not verifiably released.

Questions for Further Exploration

  1. Do the risk GRU, verifier, and selector transfer zero-shot across datasets or models, or must every pair retrain?
  2. Why does the selector capture under half the oracle headroom on Orca-Math — could process-reward signals close the gap?
  3. Does surface-matching transfer to code or multi-hop QA, where “stable-but-wrong” has different surface signatures?
  4. How do 1.8–3.1× denoising costs translate to wall-clock latency under batched serving?
  5. Could adaptive per-example repair-space construction recover what the fixed 8-action bank forfeits?
  6. What drives the 14.9%→60.5% spread in SBW prevalence across model–task settings?
