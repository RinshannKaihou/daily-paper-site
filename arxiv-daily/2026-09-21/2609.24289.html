Why this matters

An actionable split of agent memory — declarative facts vs conditioned procedures — with a lifecycle and risk theory you can graft onto existing agent frameworks.

Critical edge

The ablation that validates the core claim — dual vs TIP‑only — is not significance‑tested and rests on one high‑variance run; a variance‑matched comparison could erase it.

— Critical Assessment, on GDPevo (+2.4pp; TIP-only per-run spread 0.1212–0.2513)

Methodology

  • Two rule banks. FACT — declarative environment facts (“closed containers are invisible until opened”), verified by count-based interaction evidence. TIP — strict <condition> :: <action> procedures. A dual-judgment prompt classifier (Subject + Necessity tests) assigns each rule; uncertain defaults to TIP, protecting FACT purity.
  • Online chunk evolution — cold-start chunk 0 induces from scratch; each later chunk runs four ordered phases:
BLAMEfailure → at most one rule
RETIREaudited, kept as evidence
SYNTHcontradicting pair → one conditioned TIP
INDUCEcontrast, then success-only
  • Theory, modest and exact. Operations capped at EDIT/AGREE/REMOVE/ADD (≤4 ops/rule/chunk) — local optimization, not global rewriting.

R(F,π) − R* = E_TIP + E_FACT  ≤  E_TIP + ηF·Δmax

  • Three integration modes. Standalone pipeline (ALFWorld/ScienceWorld/GDPevo) · fused into Bayesian-Agent’s skill manager (SOPBench) · non-invasive retrieval injection, top-10 FACT + top-10 TIP via mpnet kNN (PinchBench / OpenClaw).

Strengths

  • Rare experimental hygiene for agent-memory research: 3–6 runs everywhere, permutation test + CI on the key SOPBench claim, per-run numbers disclosed.
  • Theory with the right posture — an exact identity plus a clean bound, explicitly disclaiming convergence or expressiveness overclaims.
  • Iteration shows in the mechanisms: blame-dilution prevention, audited retirement, cold-start isolation, per-rule operation budgets.
  • Honest negatives — the −0.6pp domain regression and the untested ablation are stated in the paper, not hidden.
  • Practical breadth: standalone, fused, or non-invasive; the TIP track interoperates with the Claude-skill ecosystem.

Limitations

  • No execution verification before a rule enters the bank — spurious or over-specialized rules from weak trajectories can persist.
  • Headline ablation uncertified: the +2.4pp GDPevo margin rests on a TIP-only run with a 13-point spread.
  • Concentrated gains: one SOPBench domain = 78% of the improvement; the ALFWorld margin shrinks +14.2pp → +3.6pp as the backbone strengthens.
  • Small scale: ≤500 train / ≤147 eval tasks, 20-rule bank cap, text-centric benchmarks, no RL or fine-tuning baseline.
  • Unmeasured error rates for the FACT/TIP classifier and Blame attribution (“at most one rule” is a choice, not a validated one).
  • No public code despite full hyperparameter/prompt documentation; training used internal infrastructure outsiders cannot reconstruct.

Questions for Further Exploration

  • Would a held-out execution-verification gate close the dangerous_goods regression (−0.6pp)?
  • Does the +2.4pp GDPevo margin survive a properly powered, variance-matched comparison?
  • Does contradiction synthesis keep the 20-rule cap tenable at 10–100× longer deployments?
  • Can ηF be tracked online, turning Proposition 3’s bound into an actionable monitor?
  • As backbones improve, does dual-track value shift to high-heterogeneity domains (e.g. warehouse, +14.4pp)?
  • Could FACT/TIP separation be applied to skill files themselves in mainstream agent frameworks?
