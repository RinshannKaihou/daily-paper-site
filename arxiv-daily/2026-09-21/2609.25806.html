Why This Matters

A gated, calibrated-abstention statistical framework telling agent-observability systems when aggregate traces can support a component-level fault claim at all.

Critical Edge

Every number is self-generated inside the authors’ own simulator — no external replication, no code release — and all power claims rest on just 20 clusters whose bootstrap intervals may undercover.

Methodology gate first, score second

REFERENCE_ABSTAIN→ RUNTIME_ABSTAIN→ SIGNAL_ELIGIBLE→ DETECTED / NOT_DETECTED

A simulated hotel-pricing agent (24 target-policy components × 3 demand regimes λ₀ ∈ {5, 7, 9} = 72 units; 540 unit-arm rows). The diagnostic sees only two typed summaries per matched partition pair — never the planted fault identity.

Faults
One-bucket directional target-field masks; two nested families (uniform, flow-weighted) with prefixes targeting achieved traffic τ ∈ {0.15…0.95}; SHA-256 orderings under master seed 2026082370.
Gate 1
Reference-map gate: ≥14/15 clean partitions with support ≥12 before a unit enters the formal map.
Gate 2
Runtime two-stream gate: reference and current streams jointly supported (≥12) in ≥14 matched partitions; a partition signals at z ≥ 1.50 (frozen grid, chosen before the formal null); stability = 14/15 signaling partitions per direction.
Calibration
Abstention calibrated per physical component against the frozen ≤0.20 criterion; Clopper–Pearson exact bounds + component-cluster bootstrap (20 clusters, 2,000 draws).

Three failure quantities kept separate — reference invalidation, runtime rejection, stable false admission — so a stale map, thin evidence, and a noisy signal are never conflated. 56 protocol checks over 1,440 cases.

Strengths

  • Rare frozen-confirmatory discipline: disjoint seed ranges, thresholds pre-committed from a fixed grid, 56 protocol checks.
  • Three failure quantities reported separately instead of one muddy “accuracy”.
  • Explicit abstention semantics — “no usable comparison” ≠ “comparison with no stable signal”; all 44 zero-exposure observations reported, none dropped.
  • The traffic-vs-cell ablation explains why cell-count reasoning fails under closed-loop visitation skew, with a pre-registered superiority rule and CI.
  • An honest, well-audited negative result on the authors’ own earlier MHS framing — the paper’s most transferable lesson.

Limitations

  • Single domain (hotel pricing), single fault mechanism — persistent, multi-component, or non-target-fold faults may yield different exposure curves.
  • Requires a maintained clean reference stream; the paper never prices that operational burden.
  • Only 24 physical components (20 represented); ~20-cluster bootstrap intervals may undercover; the ≤0.20 and 0.01-nat margins are simulator-specific.
  • No localization-accuracy endpoint — the pipeline certifies signal eligibility only, despite the title’s promise.
  • No code or artifact release stated; refresh provably cannot be claimed to repair a stale map.

Questions for Further Exploration

  1. Does the two-gate + traffic-exposure pipeline transfer to real LLM agent stacks (WebArena / Tau-bench), where clean reference streams are an operational burden?
  2. What false-admission criterion is defensible in place of the coarse ≤0.20 when abstention gates a human-facing alarm?
  3. Do mask-family effects become material outside the 0.01-nat margin for persistent, multi-component faults — as the [0.30, 0.45] and [0.75, 0.90] bins hint?
  4. Can the exposure-first principle combine with active probing (deliberately raising τ) without distorting the diagnosed closed-loop policy?
  5. How does the pipeline behave under genuine drift + refresh — the paper only smoke-tests the state machine, not stale-map repair?
