> **一句话总结：** 该论文证明"失败归因"（一次失败该怪智能体决策规则还是世界模型）在被动交互下原理上不可辨识（极小极大误差恒为 1/2），据此提出 verify-then-promote 的 Dual-Frontier 规则：仅当预测收益超过经 conformal 校准的世界模型误差+估计误差认证边界时才采纳世界模型建议的动作；在 BFCL v4 / API-Bank / NexusRaven 上，配合 Llama-3.1-8B-Instruct 与 Qwen3-8B，平均任务成功率相比最强基线规则 Consistency 提升 +11.57 / +11.07 点，并把受控实验中有害的"想象改进"采纳率从 5.10% 压到 0.30%。

> **TL;DR:** When a world-model-guided agent fails, you cannot tell from passive logs whether the decision rule or the world model was at fault — the paper proves this non-identifiability (minimax error 1/2) and converts it into a practical gate: accept a world-model-proposed action only when the predicted advantage exceeds a certified radius combining Bellman-residual world-model error (TV-distance × value span) and split-conformal estimation error. On BFCL v4, API-Bank, and NexusRaven with Qwen-AgentWorld as the world model, Dual-Frontier raises average Task Success to 91.62 (Llama-3.1-8B) / 92.03 (Qwen3-8B) vs 80.05 / 80.96 for the strongest baseline rule Consistency (+11.57 / +11.07 pts), while unqualified "Always-WM" use collapses BFCL v4 success to 22.50 for Llama-3.1-8B. Controlled finite-world experiments confirm the theory: targeted intervention evidence lifts attribution accuracy from 50.25% to 100% and cuts harmful imagined improvements from 5.10% to 0.30%.

## 核心贡献

- **失败归因的不可辨识性证明（Theorem 1）：** 将回报差 R = J* − J(π̂) 反事实分解为智能体缺陷 A = J* − J(π⁰) 与（带符号的）世界模型效应 W = J(π⁰) − J(π̂)；通过两步构造证明：即使世界模型完全精确、规划器是精确/蒙特卡洛有限时程规划，仅凭被动部署数据也无法区分任意 (A, W) 组合，任何归因估计器的最坏情况误差 ≥ 1/2——归因必须靠干预（主动查询）。
- **决策可靠性认证（Theorem 2 + Corollary 2）：** 用精确 Bellman 残差望远镜恒等式把"动作条件化"的世界模型误差转化为**特定决策比较**的认证半径 ε₁(π) = Σᵗ (E|r−r̂| + span(V̂ₜ₊₁)·TV(P, P̂))，得到 J(π₁) − J(π₀) ≥ [J̃(π₁) − J̃(π₀)] − ε₁(π₁) − ε₁(π₀)；并证明"预测精度高"本身不能认证决策——任意小的均匀转移误差即可翻转动作排序。
- **闭环可靠性（Theorem 3）：** 在所有可达状态上同时满足 d̂ₜ ≥ Sₜ − ξₜ 的门控规则 νₜ 保证 J(ν) − J(π₀) ≥ Σ ∫ gₜSₜρₜᵗ ≥ 0，即被采纳决策的期望回报单调不减。
- **Dual-Frontier 学习规则（Theorem 4）：** T(x) = S(x) − B(x) − ξ(x) 把候选行为划入三个前沿——ℱ_W（有希望但未认证，送去验证）、ℱ_A（已认证改进，直接采纳）、其余搁置；一次 mn 次查询的审计证书可在自适应（数据依赖的）后续比较中复用，族错误率 ≤ α + Σδᵢ；并给出匹配的证据复杂度下界 n = Θ(γ⁻²)（实测指数 2.014）。
- **两阶段实证：** 受控有限世界（16 状态 × 4 动作，H ∈ {4,8,12}，240 个留出世界）直接检验归因/认证/证据分配；再在 BFCL v4、API-Bank、NexusRaven 三个真实工具使用基准 × Llama-3.1-8B / Qwen3-8B / 三个前沿模型上实例化同一条 verify-then-promote 规则。

## Key Contributions

- **Impossibility result for failure attribution (Theorem 1):** a fixed-operator counterfactual decomposition R = A + W (agent deficiency vs. signed world-model effect) is provably non-identifiable from passive interaction — two true worlds with (A,W) = (λ, c−λ) induce identical data, so every passive estimator has minimax error ≥ 1/2, even for exact world models and finite-horizon planners.
- **Decision-specific reliability certificates (Theorem 2, Corollary 2):** an exact Bellman-residual identity converts action-conditioned world-model error into a comparison-specific radius ε₁(π) = Σᵗ(E|r−r̂| + span(V̂ₜ₊₁)·TV(P, P̂)), yielding certified improvement J(π₁) − J(π₀) ≥ J̃(π₁) − J̃(π₀) − ε₁(π₁) − ε₁(π₀); prediction accuracy alone certifies nothing (arbitrarily small uniform transition error can reverse greedy action rankings).
- **Closed-loop guarantee (Theorem 3):** a gated policy that intervenes only when the predicted advantage clears the local certificate yields non-decreasing expected return, J(ν) − J(π₀) ≥ Σ ∫ gₜSₜρₜᵗ ≥ 0, under replanning.
- **Dual-frontier promotion with reusable evidence (Theorem 4):** the statistic T(x) = S(x) − B(x) − ξ(x) splits candidate comparisons into a verification frontier ℱ_W (promising, uncertified), an agent frontier ℱ_A (certified improvements), and deferrals; one mn-query audit produces a simultaneous certificate that stays valid under adaptive world-model/request selection (familywise risk ≤ α + Σδᵢ), with a matching Θ(γ⁻²) evidence lower bound.
- **Two-stage empirical validation:** controlled finite-world experiments isolate attribution, qualification, and evidence allocation; the same verify-then-promote rule is then instantiated unchanged in realistic tool-use pipelines (BFCL v4, API-Bank, NexusRaven) across two open backbones plus frontier models, consistently improving decision quality and reliability.

## Methodology

**Formal setup.** For a task with true world M = (S, A, Pₛ, rₛ, ρ₀, H) and learned world M̂, a fixed operator A_φ maps a supplied world to a policy (φ fixes search, information access, budget, randomization), so π̂ = A_φ(M̂) and π⁰ = A_φ(M) differ only through the world. The counterfactual attribution decomposes R = J* − J(π̂) into A := J* − J(π⁰) (agent deficiency, ≥ 0) and W := J(π⁰) − J(π̂) (signed world-model effect). A "request" x = (z, M̂, π₀, π₁) specifies a candidate behavior π₁ against reference π₀.

**Non-identifiability (Thm 1).** A two-step construction builds two true worlds, indistinguishable under the common observation law on the deployed occupancy, realizing any split (λ, c−λ) of the regret; endpoint classification over λ ∈ [0,c] then has minimax error exactly 1/2 for both exact and finite-sample Monte Carlo planners. The ambiguity can reside entirely in untried actions, so the fix is to certify a *specified next use* under intervention rather than infer ownership from passive failure. A stable operator can still amplify small predictive error (their Prop. 1), ruling out operator-side rescue.

**Decision reliability (Thm 2).** With learned value V̂, the residual Δ̂ₜ = r − r̂₁ + (P − P̂)V̂ₜ₊₁ telescopes exactly: J(π) − J̃(π) = Σₜ E_{μₚᵗ}[Δ̂ₜ], bounded by ε₁(π) using reward bias plus span(V̂ₜ₊₁)·TV(P, P̂). This yields sharp certified comparisons (Eq. 9), planning regret J* − J(π̂) ≤ supₓ ε₁(x) + δ_p + ε₁(π̂) (Cor. 1), and the "accuracy ≠ reliability" counterexamples (Cor. 2). **Closed loop (Thm 3):** fixing reference Q⁰ and model-implied Q̂, gate candidate kernels κₜ where the model-implied advantage d̂ₜ clears margin Sₜ minus slack ξₜ at *all admissible states*; then the true gated policy's return dominates the reference pointwise along accepted states.

**Calibrated promotion (Sec 5).** S(x) estimates the model-implied gain Γ̃(x) = J̃(π₁) − J̃(π₀); B(x) is a split-conformal upper bound on |world-model error| with exchangeable calibration requests (coverage P(ε(x) > B(x)) ≤ α); ξ(x) bounds estimation error. T(x) = S(x) − B(x) − ξ(x) defines: ℱ_A = {T > 0} (promote), ℱ_W = {S > ξ, B ≥ S − ξ} (send to verification), else defer. For stationary finite tasks (D states, m rows, n samples/row), a Weissman-style radius aₙ makes the exact model fall in a TV ball around the empirical P̂ with probability ≥ 1−α; Theorem 4 extends one such world certificate to adaptively chosen requests (anytime validity, audit cost mn fixed upfront). Progress bounds (Eqs. 26–27) show the certified margin sum lower-bounds return gain and cannot stay bounded away from zero forever; sample complexity n ≥ kl(1−τ,δ)/(16γ²) matches the observed inverse-square scaling.

**Agent-pipeline instantiation.** Qwen-AgentWorld acts as the learned world model: given the backbone's (Llama-3.1-8B-Instruct / Qwen3-8B) emitted base action on BFCL v4 / API-Bank / NexusRaven, it proposes a candidate revision plus predicted consequence; the Dual-Frontier routing rule admits or rejects the revision. All competing routing rules see identical prompts, schemas, candidate records, and inference budgets, so differences isolate the qualification rule rather than proposal quality or generation cost.

## Results & Highlights

- **Benchmark headline (Table 1, Avg. over BFCL v4 / API-Bank / NexusRaven):** Dual-Frontier reaches 91.62 Success / 95.71 Param-Acc. with Llama-3.1-8B-Instruct and 92.03 / 96.27 with Qwen3-8B, vs the strongest competing rule Consistency at 80.05 / 89.78 and 80.96 / 90.44 — average Success +11.57 / +11.07 points and Acc. +5.93 / +5.83. On BFCL v4 specifically, Llama-3.1-8B Dual-Frontier scores 78.12 Success vs 46.38 (Consistency), 41.62 (Persistent), 35.12 (Confidence), 22.50 (Always-WM), and 69.12 (Agent-only, no world model). Blind world-model trust (Always-WM) is *worse* than no world model on BFCL v4 (22.50 vs 69.12) — motivating the whole certification agenda.
- **Controlled attribution experiment (240 held-out finite worlds):** targeted intervention evidence raises attribution accuracy from 50.25% to 100% and tightens the error threshold from 0.0900 to 0.0180 over 11,520 requests — empirically confirming Theorem 1 (passive = chance-level, interventional = exact). Qualification reduces harmful imagined improvements from 5.10% to 0.30%, while preserving beneficial transfer (Figure 1).
- **Evidence scaling matches theory (Figure 2):** the log-log evidence-vs-margin slope is 2.014, matching the predicted n = Θ(γ⁻²); one shared certificate handles 200 adaptive requests with 664 real queries versus 350,400 (≈527.7× fewer) without reuse, keeping familywise false-promotion risk below 5%.
- **Ablation (Table 2, Llama-3.1-8B, Avg. Success):** Advantage-only 84.57 → +world-model-error term 87.31 → +estimation-error term (full Dual-Frontier) 91.62, i.e., the world-model-error coordinate contributes +4.31 and the estimation-error coordinate +4.31/+1.01 depending on order — both uncertainty coordinates are needed, though the last increment (90.61 → 91.62 over "w/o estimation error") is modest. Net decision gain exceeds Always-WM by 31.10–58.12 points across benchmarks (Figure 3), and harmful revisions/selective risk on BFCL v4 drop for both backbones (Figure 4).
- **Robustness:** across three generation seeds, Avg. Success/Acc. is 91.36 ± 0.65 / 95.77 ± 0.41 (Llama-3.1-8B) and 91.93 ± 0.67 / 96.38 ± 0.35 (Qwen3-8B) — limited variance. Frontier-model reference rows (agent-only): GPT-6 Astra 84.61 / 88.68, Claude Opus 5 72.27 / 94.72, GLM-5.2-Flash 77.44 / 82.13 — all below the certified small-backbone pipelines.
- **Mechanism analysis (Figure 6, 240 sampled requests):** beneficial revisions cluster in the positive-benefit / positive-verification quadrant while many harmful proposals sit outside the promotion frontier *despite favorable predicted benefit* — predicted benefit alone is insufficient; verification is what screens unreliable revisions.

## Critical Assessment

- **Where the gains actually come from.** On BFCL v4 the world model's raw proposals are toxic for Llama-3.1-8B (Always-WM: 22.50 vs 69.12 agent-only), so a large share of Dual-Frontier's +31.74 over Consistency there is recovered conservatism — learning when to say "no". The cleaner test is API-Bank/NexusRaven, where Always-WM is above agent-only and Dual-Frontier still wins (+1.38/+34.90 Success respectively), but the margin over Consistency there is much smaller (98.62 vs 97.24; 98.11 vs 96.54). The headline +11.57 average is dominated by the BFCL v4 outlier cell.
- **The last uncertainty coordinate buys ~1 point.** The ablation (Table 2) shows "w/o estimation error" already reaches 90.61 Avg. Success; the conformal B(x) machinery adds only 90.61 → 91.62. Given that conformal calibration requires a calibration split and exchangeability that LLM agent traffic may not satisfy, the cost-benefit of the full statistical apparatus versus the simpler Bellman-residual gate is not clearly established.
- **Theory-practice gap.** The guarantees assume known rewards, bounded returns, fixed horizon, and (for the adaptive certificate) stationary finite tasks with D states / m rows; the benchmark instantiation uses Qwen-AgentWorld's natural-language predictions, where none of these objects literally exist. The benchmark results demonstrate the rule *helps*, not that the certified α-level guarantees hold there — the paper is upfront that certification is occupancy-specific, but a reader should not map Theorem 4's familywise bounds onto the tool-use numbers.
- **Frontier-model rows are reference-only confounded.** GPT-6 Astra / Claude Opus 5 / GLM-5.2-Flash score 84.61 / 72.27 / 77.44 average Success — below the 8B pipelines — but these rows appear to be agent-only without the Dual-Frontier rule and without matching budgets; comparing them against Dual-Frontier-equipped 8B models in the same table invites an apples-to-oranges reading (a stronger backbone might also propose better revisions, changing the gate's value).
- **Near-ceiling benchmarks.** API-Bank (98.62/98.92) and NexusRaven (98.11/97.80) Success are close to saturation for Dual-Frontier, compressing headroom and making the reliability metrics (harmful revisions, selective risk, Figure 4) more informative than raw Success.
- **Synthetic controlled experiments are tiny.** 16 states / 4 actions / Beta-smoothed tabular kernels make the 100% attribution accuracy a clean theory check but say little about attribution in high-dimensional environments; the paper does not test attribution on any realistic domain, where the "two-world" indistinguishability construction is unlikely to bind as tightly.
- **Overhead accounting is thin in the main text.** Every request pays a Qwen-AgentWorld proposal call plus gating computation; wall-clock/token overhead at benchmark time is deferred to appendices, and no comparison against a cheap self-consistency-style veto heuristic is given (Consistency is the closest, but it is not an uncertainty-threshold rule at matched compute).

## Strengths

- A genuinely new question — *who* caused the failure (rule vs. world model) — formalized cleanly and answered with a real impossibility theorem plus a constructive fix (intervention-then-certify), rather than another forecasting-accuracy metric.
- Theory is load-bearing, not decorative: Theorem 1 motivates the intervention design; Theorem 2's exact Bellman-residual identity yields the gate; Theorem 4's adaptive reuse explains the 527.7× evidence savings; measured exponent 2.014 matches the Θ(γ⁻²) bound.
- Experiments respect the mechanism: identical prompts, schemas, candidate records, and inference budgets across routing rules isolate qualification from proposal quality — an unusually fair comparison protocol.
- Consistency across 3 benchmarks × 2 backbones × 3 seeds × 5 ablations, with reliability metrics (harmful revisions, selective risk) reported alongside success, and case studies (Figure 5) showing both a promoted correction and a *deferred* confident-but-risky revision.
- The always-trust baseline collapsing below no-world-model (22.50 vs 69.12 on BFCL v4) is a memorable, practically important negative result.

## Limitations

- Certified guarantees hold only on the verified occupancy and for fixed operators/horizons; distribution shift beyond verified occupancy is only partially treated (Appendix C.4), and finite-state adaptive bounds do not literally apply to LLM tool-use.
- Gains concentrate in the BFCL v4 cell where the world model is worst; on benchmarks where proposals are good, the margin over the Consistency rule shrinks to 1–2 points, so the rule's value is conditional on proposal reliability.
- The conformal estimation-error component contributes only ~1 point in ablation, raising questions about whether the full statistical stack is worth its calibration-split and exchangeability assumptions.
- Frontier-model comparison rows are not run under the Dual-Frontier rule with matched budgets, weakening the implied "small certified pipeline beats frontier models" narrative.
- Attribution validation is confined to 16-state synthetic worlds; no realistic-domain attribution experiment is reported.
- Extra per-request cost of world-model proposals and gating (second model in the loop) is not analyzed in the main text.

## Relevance

这篇论文与你关注的 LLM Agent 与 world model 方向高度相关：它直击 agent 信任世界模型的核心痛点（预测准 ≠ 决策对），给出的 verify-then-promote 门控规则可直接套用在 Qwen-AgentWorld 这类 world-model-in-the-loop 的工具调用管线（BFCL/API-Bank/NexusRaven 均是主流 function-call 基准）上。如果你在做 agent 的可靠性/回滚策略或 world-model 辅助规划，这篇文章的认证式采纳框架和不信任盲用世界模型的负面结果都值得细读。

## Questions for Further Exploration

- Does the verify-then-promote rule retain its advantage when the world model itself improves (e.g., a frontier model as Qwen-AgentWorld), or does the gate's value vanish as proposals become reliable?
- Can the conformal calibration be made valid under the non-exchangeable, temporally correlated request streams of real agent deployments (online conformal), and how much of the remaining 1-point gap does it then close?
- Is the passive non-identifiability bound tight in practice for realistic environments, or can auxiliary signals (user feedback, execution traces outside the occupancy) recover approximate attribution?
- How does the framework extend to multi-step credit assignment, where a failure mid-trajectory implicates an earlier certified decision?
- What is the wall-clock and token overhead of the second-model gating loop, and does a matched-compute self-consistency veto close most of the gap on API-Bank/NexusRaven where margins are small?
