> **一句话总结：** 论文把权重空间 PTQ 中"逐层选位宽/粒度/变换/量化器格式 + 部署成本"这一离散决策统一为预算约束下的"量化价格"选择问题：由全精度→量化前向 KL 在参考点处一阶项消失，推出二次价格 ρ_l = ½Tr(H_l Σ_l(α_l))（候选层输出误差协方差被全精度模型的下游曲率定价），并将其约化为三个标量的乘积 σ̂²·ω̂·τ̄（候选输入尺度 × 扰动尺度 × 缓存的 Gauss-Newton 曲率迹），无需构建完整量化模型即可给所有候选打分；在 Llama-3.2-1B 上按 3.0-bit 平均预算做 GPTQ 位宽分配时，价格引导选择用 579s（对比 AMQ 的 11635s，约 1/20）取得五任务平均 51.24（HIGGS 50.57、AMQ 50.13，AMQ 仍保持最优 WikiText2 PPL 11.05 vs 12.22），W4 变换选择把 PPL 从 CALM-CKA 的 12.80 降到 11.53，粒度分配以 127s 超过固定 Group-128（PPL 11.39 vs 12.71）；但 Llama-3.1-8B 上位宽分配被 AMQ 反超（平均 49.34 vs 54.84），故其最强主张是"便宜且指标对齐的候选排序"而非精度全面占优。

> **TL;DR:** This paper reframes weight-space PTQ as a budgeted pre-deployment configuration selection problem. Instead of scoring proxies after fixing quantization geometry, every admissible layer configuration (bits, granularity, quantizer family, transformation, hardware cost) is treated as an error generator whose layer-output error covariance Σ_l is priced by the full-precision model's downstream curvature: ρ_l = ½Tr(H_l Σ_l). Theorem 3.1 derives this from the full-precision-to-quantized forward KL (whose first-order term cancels at the reference), and a trace reduction makes each candidate cost only three scalars: candidate input scale × perturbation scale × a cached Gauss-Newton curvature trace (one forward/backward pass per layer, no Hessian probes). On Llama-3.2-1B with a 3.0-bit-average GPTQ backend (calibration/eval on WikiText2), price-guided bit allocation reaches 51.24 average over BoolQ/TruthfulQA/PIQA/WinoGrande/WiC vs 50.57 for HIGGS and 50.13 for AMQ, in 579s vs AMQ's 11,635s; the implemented trace price correlates with measured KL drift at ρ = 0.9483 (OPT-125M) and 0.9438 (Qwen3-0.6B). Caveat: on Llama-3.1-8B, AMQ wins bit allocation outright (54.84 vs 49.34 avg, PPL 9.31 vs 10.87), so the durable claim is cheap, metric-aligned candidate ranking rather than accuracy dominance.

## 核心贡献

- **统一的问题表述**：把权重空间 PTQ 显式建模为"部署前配置选择"——每层从可部署候选集 A_l 中选 α_l（位宽、粒度、有限格式、预量化变换），在部署成本预算 Σκ_l(α_l) ≤ B 下最小化目标漂移；理想目标（全精度→量化输出分布 KL）在量化模型成型前不可评估，因此需要一个校准期替代品。
- **价格定理（Thm 3.1）**：前向 KL 在全精度参考处一阶项消失，目标漂移 = 二次价格 ρ(α) = Σ_l ½Tr(H_l Σ_l(α_l)) + 余项；候选提供误差协方差 Σ_l，参考模型提供输出曲率 H_l，价格即二者的交互。
- **对既有代理的统一解释**：重构分数 = 丢掉输出曲率的退化价格（H→I），对角输入分数/imatrix = 再丢掉跨通道输入协方差（C→diag(C)）；这些约化仅在丢掉的因子对所有候选近似恒定时才保序——解释了它们何时有效、何时失效。
- **配置族 → 价格因子**：有限格式/位宽/粒度决定权重扰动矩 V_l（推出仅在格式转换后才出现的 4^−b 位衰减律，E[ρ̂] ≤ r²/(48L_b²)·Tr(H)Tr(C)）；等价变换改变坐标为 PCP^T；Thm 3.3 证明白化是行列式保持变换类中的极小极大最优预处理。
- **可实现的迹约化与预算搜索（Alg. 1）**：ρ̂_l ← ½σ̂²_l ω̂_l τ̄_l，其中 τ̄_l 用每层一次前向/反向的 Gauss-Newton/Fisher 迹估计（无 Hessian-vector 探针），候选标量在每层 ≤512 个校准 token 上估计；位宽分配解为二元 MILP。价格理论还给出 AM-GM 白化分配律等约化法则作为诊断（附录 B.10）。
- **实证链条**：受控扰动实验验证实现价格与实测 KL 漂移对齐（ρ≈0.92–0.95），端到端实验验证按预测价格做离散选择能以更低选择成本改善 PPL 与下游任务平均分。

## Key Contributions

- A **pre-deployment configuration-selection formulation** of weight-space PTQ: each admissible layer choice is an error generator with a deployment cost κ_l, and the selection problem is min ρ(α) s.t. Σκ_l ≤ B, where the full-precision-to-quantized forward KL — the quantity actually cared about — is unavailable before the completed model exists.
- **Theorem 3.1 (quadratic price)**: the forward-KL objective's first-order term vanishes at the full-precision reference, leaving ρ_l = ½Tr(H_l Σ_l(α_l)) plus a bounded relative remainder η(α) (Eq. 9). The candidate supplies the error covariance; the reference model supplies the output-side curvature that makes some error directions expensive.
- A **unifying account of existing proxies**: reconstruction scores are the price with output curvature dropped (H→I); diagonal input scores / imatrix-style heuristics additionally drop cross-channel input covariance (C→diag(C), Eq. 48); both preserve rankings only when the dropped factors are effectively constant across the candidate set.
- **Configuration families become price factors**: finite formats/bits/granularity determine the perturbation moment V_l (yielding the familiar 4^−b law only after format-to-moment conversion, Eq. 11); equivalent transformations change the coordinate (PCP^T) while the reference-side metric stays fixed; Theorem 3.3 shows whitening is the minimax-optimal determinant-preserving affine preprocessing.
- A **practical trace reduction and budgeted search** (Algorithm 1): ρ̂_l ← ½σ̂²_l(α_l)·ω̂_l(α_l)·τ̄_l with τ̄_l a cached Gauss-Newton/Fisher trace (one forward/backward pass per layer, no Hessian-vector probes; candidates scored on ≤512 supervised tokens per layer), and the discrete bit-allocation problem solved as a binary MILP under the same cost/budget interface as AMQ.
- An **evidence chain**: controlled-perturbation KL-drift alignment (ρ ≈ 0.92–0.95), then end-to-end discrete decisions on Llama-3.2-1B/3B/3.1-8B across bit allocation, transformation selection, and granularity allocation, with honest scope boundaries (local, moment-stable, curvature-aligned regime).

## Methodology

**Formulation.** Weight-space PTQ starts from a full-precision reference π₀; each layer l has an admissible set A_l of configurations α_l = (finite format, granularity, quantizer family, pre-quantization transformation P, bitwidth b) plus a deployment cost κ_l(α_l) = κ_bits + κ_meta + κ_kernel. A full configuration α induces a quantized distribution π_α; the target is the expected forward-KL drift J(α) (Eq. 2), giving the ideal constrained program min J(α) s.t. Σκ_l ≤ B (Eq. 3). Configuration invariance W_l(α_l)x_l(α_l) = W_l x_l lets transformations be described without changing the floating-point target (Eq. 1, 5).

**Priced layer-output error.** Quantization injects Δ_l(α_l)x_l at the reference layer output. Two calibration-time statistics matter: the reference-side curvature H_l = E[∇²_z J] (Eq. 7) and the candidate-induced covariance Σ_l(α_l) = E[Δ_l C_l Δ_l^T]. Theorem 3.1 proves that under block-diagonal second-order chain-rule structure and C³ smoothness, J(α) = ρ(α) + r(α) with ρ(α) = ½Σ_l Tr(H_l Σ_l(α_l)) and |r(α)| ≤ η(α)ρ(α), where η(α) bounds Hessian mismatch and third-order terms (Eq. 9) — the omitted term is negligible when the retained Hessian is accurate along the quantization direction. Remark 3.2 then shows reconstruction scores arise by substituting H→I (ρ_rec = ½Tr(ΔW C ΔW^T) = ‖ΔW X‖²_F/2N) and diagonal scores by further C→diag(C): both drop factors that only preserve candidate ranking if effectively constant.

**Family-wise pricing.** (i) Finite formats/bits/granularity: the candidate supplies a perturbation moment envelope V_l; under the zero-mean independent-entry rounding model, E[ρ̂_l] ≤ ½h_l^T V_l c_l (Eq. 10), which for b-bit uniform range quantization gives E[ρ̂] ≤ r²/(48 L_b²)·Tr(H_l)Tr(C_l), L_b = 2^b − 1 (Eq. 11) — the 4^−b decay is not an allocation law but appears only after converting the format into a priced moment. (ii) Transformations: with x̃ = Px, W̃ = WP⁻¹, the transformed covariance factors as Σ_l(P,b) = E[Δ̃_l(PCP^T)Δ̃_l^T] with an optimized P (Eq. 12); Theorem 3.3 proves whitening P = Λ_g^{1/2}QΛ^{-1/2}U^T minimizes the worst/max directional variance ratio among determinant-preserving transforms (Eq. 13), and diagonal scaling / orthogonal rotations are restricted cases analyzed in Appx. B.7-B.8 (rotations help only through finite-format residual, since RCR^T preserves eigenvalues). (iii) An isotropic trace reduction (Appx. B.6) writes Σ_l ≈ σ̂²_l(ω_l I + A_l), giving ρ_l ≈ ½σ̂²_l(ω_l Tr(H_l) + ½σ̂²_l Tr(H_l A_l)); when A_l is small, the implemented score is three scalars (Eq. 18).

**Algorithm 1 (price-guided search).** (1) Estimate and cache τ̄_l = Tr(Ĥ_l) once per layer via the Gauss-Newton/Fisher trace E‖∇_z ℓ‖² — one forward/backward pass per layer, computed with a Hutchinson-style estimator, no Hessian-vector probes. (2) Per layer, estimate candidate scalars σ̂²_l (input scale) and ω̂_l (perturbation scale, from the realized perturbation product or a finite-format moment model) on ≤512 supervised tokens, then score ρ̂_l. (3) Solve the budgeted discrete program (Eq. 19); for bit allocation, this is solved as a binary MILP. GPTQ is the fixed backend (true-sequential, activation ordering, no MSE search) so only the configuration decision varies.

**Experimental protocol.** KL-alignment study: controlled perturbations on OPT-125M and Qwen3-0.6B across transformations (identity / AWQ-style / SmoothQuant-style α=0.5 / Hadamard rotation / normalized diagonal whitening), bitwidths, and granularity candidates; realized price (8) and implemented trace price (18) vs measured full-precision→quantized KL on held-out calibration inputs, 128 samples of length 1024. Configuration selection: Llama-3.2-1B (main), Llama-3.2-3B and Llama-3.1-8B (Appx. C); all linear projections quantized except norms, rotary embeddings, and LM head (112/196/224 quantized layers); 512 WikiText2 calibration samples (len 512, seed 0); evaluation = WikiText2 test PPL (141 sequences, 288,027 tokens, seq len 2048) + LightEval greedy (temp 0, seed 42) on BoolQ, TruthfulQA-MC2, PIQA, WinoGrande, WiC; selection time excludes the subsequent quantization/evaluation pass.

## Results & Highlights

- **Price tracks KL drift (Fig. 1).** On OPT-125M the realized layer-output price correlates with measured full-precision-to-quantized KL drift at ρ = 0.9470 (ρ = 0.9239 on Qwen3-0.6B); the stricter implemented trace price — which drops the full covariance and keeps only candidate-side scalars plus the cached curvature trace — still achieves ρ = 0.9483 (OPT-125M) and 0.9438 (Qwen3-0.6B). A two-layer probe sums per-layer prices and still tracks the KL drift, supporting the local-decomposition reading of Thm 3.1.
- **Bit allocation, Llama-3.2-1B, 3.0-bit average budget, bits ∈ {2,3,4} (Table 1).** Price-guided selection: 579s, WikiText2 PPL 12.22, average task score 51.24 — best average among the three methods vs HIGGS (813s, PPL 12.50, avg 50.57, +0.67 delta) and AMQ (11,635s, PPL 11.05, avg 50.13, +1.11 delta), i.e., ~20x faster than AMQ's iterative NSGA-II search that builds a quantized model per candidate allocation; AMQ retains the best PPL (11.05 vs 12.22). FP16 reference: PPL 9.75, avg 52.35.
- **Transformation selection, Llama-3.2-1B, W4 group-128 (Table 1).** Price-guided choice among {identity, AWQ-style scaling, SmoothQuant-style scaling (α=0.5), Hadamard rotation, normalized diagonal whitening}: PPL 11.53 and avg 49.82 vs CALM-CKA 12.80/49.20 (−1.27 PPL, +0.62 avg) and Random 12.60/48.34 (−1.07 PPL, +1.48 avg).
- **Granularity allocation, Llama-3.2-1B, W4, choices over per-tensor/per-channel/group-{32,64,128}/64×64 block-wise (Table 1).** Price-guided: 127s, PPL 11.39 (−1.32 vs Fixed Group-128's 12.71), avg 51.96 (+0.47 vs 51.49); Random selection costs 23,313s and collapses (PPL 43.57, avg 30.41).
- **Scale checks (Appx. C, Tables 2-3).** Llama-3.2-3B: price-guided bit allocation wins average 53.64 vs AMQ 53.21 and HIGGS 43.08 (2182s vs AMQ's 16,265s) while AMQ keeps best PPL (9.41 vs 11.23); transformation: PPL 8.58 vs CALM-CKA 8.81, avg 58.96 vs 58.58; granularity: best PPL 8.46 vs 8.81 but Group-128 wins avg (58.38 vs 58.13). Llama-3.1-8B: transformation PPL 6.86 vs 6.97 and avg 64.24 vs 64.18; granularity PPL 6.75 vs 7.02, avg 63.77 vs 62.74 (+1.03); but **bit allocation reverses**: AMQ wins both PPL (9.31 vs 10.87) and average (54.84 vs 49.34, a 5.5-point gap), with price-guided second among the three (HIGGS 47.07) — the authors disclose this in the appendix while the main text leads with the 1B win.
- **Selection-time asymmetry is the robust finding.** Across all nine blocks, the price selector's decision cost (127s-657s on 1B; 372s-2182s on 3B) is at or below HIGGS/CALM-CKA and 1-2 orders of magnitude below AMQ's search, while accuracy is within ±1 point of the best baseline in 8 of 9 blocks — the exception being 8B bit allocation.

## Authors & Credibility

The four authors — Junbin Qiu, Jian Mu, Weitong Zhang, and Yao Shu (corresponding, HKUST-GZ) — work on the theory/experiment interface of efficient deep learning. Yao Shu has a verifiable track record in training-free NAS scoring (GraNd-Score-free NAS at NeurIPS 2022, NASI at ICLR 2022, both self-cited [35, 36]), and the paper explicitly borrows the training-free-NAS methodology of scoring many candidates before building them — the framing and the budgeted-search machinery are consistent with that lineage. Weitong Zhang has prior work on second-order optimization. The theoretical claims come with full proofs (Appx. B), the experimental setup is unusually well documented (seeds, token counts, sequence lengths, MILP formulation, per-family candidate definitions in Appx. No code release is mentioned in the manuscript, which limits reproducibility of the selector implementation despite the detailed protocol. ## Critical Assessment

- **The estimator is less novel than the abstraction.** The implemented score ρ̂_l = ½σ̂²ω̂τ̄ is, concretely, a Gauss-Newton/Fisher trace times a perturbation norm times an input scale — a modest variation on HAWQ/HAWQ-V2-style Hessian-trace mixed precision and on Fisher-diagonal sensitivity signals. The paper itself concedes that imatrix-style deployment proxies are exactly the price with H=I and C=diag (Eq. 48). The genuine novelty is the unifying price language that makes heterogeneous families (bits, codebooks, rotations, whitening) commensurable under one budget, plus the whitening minimax theorem — a conceptual contribution, not a new estimator.
- **The 8B bit-allocation reversal weakens the headline.** The main text's Table 1 shows price-guided winning the average task score at 1B; Appx. C shows that at 8B, AMQ beats it on both PPL (9.31 vs 10.87) and average (54.84 vs 49.34). The paper attributes AMQ's strength to search cost, but the 5.5-point gap at 8B suggests the quadratic price mis-ranks bit allocations as models scale — consistent with the paper's own "local, moment-stable, curvature-aligned regime" caveat, yet the main narrative does not foreground it.
- **Transformation/granularity baselines are soft.** The structured competitors are one CKA-similarity heuristic (CALM-CKA) and random choice; there is no comparison against trained rotation optimization (SpinQuant-style), no "always Hadamard" ablation reported as a row (it is only a candidate), and no per-layer disclosure of what the selector actually chose — so one cannot verify it is discovering non-obvious configurations versus converging to a known good default. The fixed Group-128 baseline being within 0.47 avg points at 1B (and *ahead* at 3B granularity, 58.38 vs 58.13) suggests the granularity head is close to a no-op at these scales.
- **An unexplained timing anomaly.** "Random Selection" for granularity costs 23,313s on the 1B model — more than 3x AMQ's entire search — despite being defined as randomly sampling one candidate and quantizing, and despite the stated convention that selection time excludes the quantization/evaluation pass. Whatever accounting produced this number, it is not explained, and it inflates the selector's apparent speed advantage in that block.
- **Scope restrictions are real limits.** Weight-space only (no activation quantization, KV-cache, runtime clipping, or QAT unless they expose a pre-deployment covariance); the whitening optimality claim holds only for fixed residuals and determinant-preserving transforms, and Appx. B.5 shows adaptive scalar quantizers' distortion can scale with the whitening normalization (Eq. 37), partially cancelling whitening's benefit. All end-to-end models are dense Llama-family ≤8B with a single calibration seed; no 70B/MoE/instruction-tuned evaluation, and perplexity is measured on only 288K WikiText2 tokens.
- **No external end-to-end anchor.** The comparison is always relative to baselines run under the authors' GPTQ backend; there is no row matching a known-strong community recipe (e.g., Hadamard rotation + GPTQ W4A16 as deployed in practice), so it remains unclear the selector beats simply using the standard configuration for free.

## Strengths

- A genuinely useful conceptual unification: formats, bits, granularities, transformations, and codebooks become candidates of one priced decision, so mixed-precision bit allocation loses its special status and becomes a special case of budgeted configuration search.
- Theory with honest bookkeeping: the forward-KL derivation (Thm 3.1) explicitly tracks the omitted terms in a relative diagnostic η(α), and Remark 3.2 precisely states when reconstruction/diagonal proxies are rank-preserving — explaining prior methods' successes and failures rather than replacing them.
- The validation chain is the right one: it first tests whether the score tracks the actual KL drift under controlled perturbations (ρ ≈ 0.92–0.95), then tests discrete decisions — rather than only reporting end-task numbers.
- The whitening minimax theorem (Thm 3.3) is a clean, quotable result that formalizes why activation-aware scaling and rotation families behave as they do.
- Exceptional setup transparency (Appx. D): seeds, calibration token budgets, candidate definitions, cost model (FP32 scale metadata counted as effective bits, ties within 1% broken by lower cost), and per-family candidate sets are all specified.
- Strong practical selling point even where accuracy ties: selection decisions in minutes instead of AMQ's hours, with a cost interface that matches real deployment budgets.

## Limitations

- Valid only in the local, moment-stable, curvature-aligned regime: low-bit nonlocality, moment-model mismatch, cross-layer coupling, and curvature-proxy error enter as second-order terms that the selector does not optimize; the 8B bit-allocation result suggests this regime boundary is reached already at practical scales.
- The trace reduction requires the candidate residual to be near-isotropic (Appx. B.6); for structured codebooks/lattice candidates the three-scalar score is an approximation whose error is not quantified empirically.
- Weight-space only; the weight-activation extension (Appx. B.10) is recorded as branch analysis with exact equalities only after whiten/isotropic/zero-mean reductions, and is not evaluated.
- End-to-end evidence limited to dense Llama-family models of 0.125B-8B, one backend (GPTQ), one calibration seed, and a small perplexity evaluation set; no code release stated.
- Baseline coverage is asymmetric: strong search baselines exist only for bit allocation; the transformation and granularity blocks lack learned or literature-standard selectors.

## Relevance

该工作与你关注的 LLM 高效推理/部署直接相关：它把"部署前如何选位宽、粒度与旋转/白化变换"这一工程决策变成了一个有理论依据、秒级完成的预算约束搜索，可直接用于量化上线前的配置选型；同时其对重构误差、imatrix 等 Kept 代理为何有时失效的解释，对评估任何 PTQ 方案的论文都有方法论价值。

## Questions for Further Exploration

- Does the quadratic price systematically under-rank fine bit allocations as model size grows (the 8B AMQ gap)? A scaling study of the relative diagnostic η(α) versus model size would locate the regime boundary quantitatively.
- What configurations does the selector actually choose in the transformation and granularity blocks — does it recover Hadamard/whitening per layer, or layer-dependent mixtures that beat a uniform Hadamard recipe? Per-layer choice visualization is missing.
- How does the price selector compare against trained-rotation methods (SpinQuant/QuaRot optimization) under the same budget, given that training rotations costs GPU-hours while pricing costs minutes?
- Can the price framework be extended to activation/KV-cache quantization where the conditional zero-mean assumption (Appx. B.10) fails in low-bit or heavily clipped regimes?
- Would a hybrid selector — price as the proposal distribution for AMQ-style search — recover AMQ's 8B accuracy at a fraction of its 23,337s cost?
