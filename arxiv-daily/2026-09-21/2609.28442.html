Better math reasoners separate rule orderings more, not less — answer invariance and representation invariance come apart.

答案不变 ≠ 表征不变：在 16 个 1B–8B 指令模型上，解题越准的模型，对同一答案的不同规则顺序，内部隐藏态表征反而分得越开。

ρ = 0.862

Across 16 instruction-tuned models in the easiest setting (D,m) = (2,4); p = 1.7e-5. Size-adjusted, the hardest setting falls to ρ = 0.469 (p = 0.078, n.s.).

Why this matters

A low-cost, reusable probe linking reasoning robustness to internal representation geometry — and a cautionary example of why model ancestry must be controlled.

▲ Critical edge

10 of 16 models are Qwen-derived — the correlation spans only ~5–6 independent model families, so the headline p-values overstate the evidence.

Methodology 方法

  1. 01 Task. Multi-step function composition (F(3)=7, G(7)=−2 → G(F(3))) plus m distractor chains sharing the same function symbols. The (m+1)·D rule lines are shown in 50 shared permutation patterns while the correct answer never changes — order is isolated from content.
  2. 02 Sweep. 100 instances × 50 patterns = 5,000 prompts per setting, across three difficulty settings (D,m) = (2,4), (2,7), (3,4), on 16 instruction-tuned 1B–8B models (Qwen2.5, Llama-3, Mistral, Gemma-3, NVIDIA Ace).
  3. 03 Measure. One no-generation forward pass per prompt; per layer, prompt hidden states are mean-pooled and grouped by permutation pattern. Permutation SNR = between-cluster ÷ within-cluster variance, averaged over layers → one order-separability scalar per model per setting.
  4. 04 Correlate. Spearman ρ between accuracy and SNR across the 16 models; a partial Spearman regresses out ranked parameter count (Appendix C).

Counterintuitive direction: accurate models do not collapse equivalent orderings — they separate them more (top models ρ-SNR ≈ 0.25+ vs ≈ 0.13–0.15 for low-accuracy ones). The author foregrounds, not hides, the inconclusive size-adjusted (3,4) result — echoed in Critical edge ▲.

Strengths 优势

  • Answer-invariant by construction: the shared permutation bank isolates order alone; distractor chains block trivial copy-through.
  • Genuinely counterintuitive and conceptually useful — decomposes "robustness" into answer invariance vs representation invariance, and shows they dissociate.
  • Unusually candid statistics for a short paper: p-values throughout, the non-significant (3,4) result foregrounded.
  • Full reproducibility detail: complete model list, prompt templates, permutation sampling, extraction protocol.
  • Broad coverage of the 1B–8B class (5 families; general/code/math specializations) enabling within-class contrasts.

Limitations 局限

  • Correlational only — no steering or ablation, so no causal evidence that order-separated representations help or hurt reasoning.
  • Synthetic function-composition only; no GSM8K / MATH transfer, so external validity is untested.
  • 16 models, all 1B–8B, overlapping ancestry; no frontier-scale or base models — scale trends beyond 8B unknown.
  • Size control is crude: the three-step setting loses significance (partial ρ = 0.469, p = 0.078); lineage unadjusted.
  • Permutation SNR is new and unvalidated: no negative controls, no CIs, no comparison to CKA or linear-probe alternatives.
  • Single sampled response per prompt without variance estimates; no code or data release stated.
