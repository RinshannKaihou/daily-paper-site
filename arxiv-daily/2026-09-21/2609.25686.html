How Strongly Should Task State Influence an LLM Agent?

Key Metric

+60pts

Enforcement gate vs. raw transcript — strict episode success 0.38 → 0.98

Qwen3-235B · no-think · S=10 · 128 paired episodes/cell · exact payload matching, no LLM judge · without per-turn reasoning the ladder is monotone: 0.38 → 0.53 → 0.84 → 0.98. The ceiling is by design ↓

Why This Matters

Turns state-coupling from design intuition into a measurable ladder — direct guidance for anyone building multi-step agents, workflow engines, or agent benchmarks.

“状态/记忆管理”从系统设计直觉变成可测量的耦合强度阶梯；其无裁判、回执驱动的评分协议也值得构建 agent 评测的团队借鉴。

Rule of thumb: enforcement pays when failures are state-decidable and frequent, does nothing when rare, hurts when the gate’s judgement is wrong.

Critical Edge

The headline 0.98 is partly by construction: a memoryless book-everything policy scores 1.00 behind the gate — the top rung measures the gate’s state, not agent capability.

Refusals are silent: 70/86 refused bookings read as completed work — a wrong gate deletes work without the agent ever knowing.

Methodology

  1. 01 Raw transcript state lives only in growing conversation text the model re-reads
  2. 02 Text checklist oracle’s exact state displayed every turn — accurate, unconstraining
  3. 03 Directive gate LLM-compiled state machine injects one line/turn (ELIGIBLE / BLOCKED / ALREADY-DONE / CANCELLED / REDO AUTHORIZED) — agent free to disobey
  4. 04 Enforcement gate same module sits between agent and execution channel — violating bookings are refused

Shared machinery

  • One task-state machine, compiled by the agent’s own model from the brief; advanced only on verifiable receipts (completion code + fresh work-order nonce — replayed receipts book nothing).
  • A per-turn matcher resolves each request to a step (agreement 0.957–1.000, redo precision 1.000).

Scoring & testbed

  • Strict episode success by exact string match against dynamic ground truth — no LLM judge; McNemar + Holm on paired seeds, Wilson 95% CIs; scripted perfect agent scores 200/200 as regression control.
  • 128 paired episodes/cell; S∈{5,10,15,18} procurement tasks with traps; Qwen3-6.35B / Qwen3-235B / DeepSeek V4 Pro × no-think / thinking; plus a self-ledger arm and retrieval-memory baselines (top-k, Mem0).

Thinking compresses but does not repair: raw rises to 0.80 at S=10, yet stays below both gates in every cell. Writing beats reading: the agent’s own unverified ledger scores 0.70/0.79 vs. the always-accurate displayed checklist’s 0.52/0.59 (Qwen3-6.35B).

Transfer & boundary conditions

LangChain real-tool harness ladder replicates: 0.34 → 0.66 → 0.96 (raw → directive → enforcement)
τ²-bench airline policy-compiled gate: pass¹ 0.39 → 0.54 (95% CI [+0.04, +0.26]); wrong-writes 54% → 36%
PM-Bench (judgement domain) order reverses — enforcement 0.55 falls below raw 0.63; ~22 refusals/run, 17 of them due
Corrupted gate state dose-response: 0.98 → 0.72 / 0.41 / 0.06 at ε = 0.8 / 1.9 / 4.5 corruptions per episode
One misrouted request directive collapses 0.92 → 0.38, enforcement 1.00 → 0.78; both text rungs unmoved (Holm p ≥ 0.75)

Obedience vs. enforcement: 32 of 36 directive errors ignore CANCELLED / BLOCKED / ALREADY-DONE lines, while enforcement holds 0.93–0.98 without obedience. Bound by the gate’s own correctness ↑

Strengths

  • Clean factorial ladder: a vague systems question becomes four comparable rungs with shared machinery and paired statistics.
  • No LLM judge — exact payload matching against dynamic ground truth, plus a scripted perfect agent (200/200) as regression control.
  • The top rung’s own failure modes are quantified, not hidden: dose-response, misroute ablation, per-cell compile audits.
  • Findings carry their validity conditions rather than being oversold.
  • Unusual transparency: disclosed LLM assistance, blind rater study, promised full release.

Limitations

  • One episode-generator family, one cooperative user; linguistic and adversarial robustness barely sampled.
  • Gate internals are LLM calls — one misrouted rewrite drops enforcement 1.00 → 0.78; a miscompiled graph refuses correct work with no override path.
  • Silent refusals: 70/86 refused bookings read as completed work (a same-turn notice fixes it, validated only in one appendix probe).
  • Directives are plain user-role strings; spoofing is untested.
  • Thinking compresses the ladder — conclusions are crispest without per-turn reasoning and erode as base models get stronger.
  • Sparse cells: 32 episodes for DeepSeek V4 Pro and 6.35B thinking; several gate separations fall to 0.07–0.10, n.s.

Questions for Further Exploration

  • Would a hybrid gate that shows the resolved step and asks back when nothing resolves keep enforcement’s robustness without its silent-refusal failure mode?
  • How does the ladder behave under an adversarial user or prompt injection against the injected directive strings?
  • Does the ledger-over-checklist inversion persist for frontier reasoners, where thinking already lifts raw to 0.63–0.82?
  • Can “state-decidable + frequent” become a cheap pre-hoc diagnostic that decides, per deployment, whether to attach a gate at all?
