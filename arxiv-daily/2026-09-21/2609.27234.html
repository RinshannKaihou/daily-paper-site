Why this matters

Gives LLM-agent scientific discovery a concrete falsification protocol — discover, falsify, revise — portable to any agent that writes predictive code.

Critical edge

Audited margins are thin: +0.0011 PCC over a control-only baseline with a 95% CI touching zero — the “recovered contribution” has little predictive headroom.

01 Methodology — three non-equivalent falsification tests

Agent policies (CELLSCIENTIST, plus AIDE / CellForge / HarmonyCell) write executable predictors and register input-use claims. A prediction–claim gap exists when the cited source contradicts the claim — or fitted behavior is invariant to the input.

  1. Source consumption

    An AST-level checker verifies the cited computation actually resolves the input → implemented / implementation-contradicted / unresolved.

  2. Fitted dependence

    With checkpoint and targets fixed, replace the input; measure prediction distance Δm and loss gain ΔL. Exact zero = invariance.

  3. Target-relevant contribution

    2×2 compound×context factorial averaging + Lundberg–Lee allocation; paired seed-trajectory and source-scaffold intervals, validated on 6,400 simulated datasets.

Develop–freeze–test discipline: processing, budgets and selection rules fixed before search; Folds 1–2 fit, Fold 3 feeds back, Folds 4–5 held out — sources, checkpoints and audit rules frozen first.

Falsification-guided revision: a residual over a frozen control-profile model, ŷ = g(c) + αh(c,p,a), with the compiler enforcing zero residual at the reference input.

03 Strengths

  • Crisp, generalizable decomposition — the three questions are shown to hold independently (47/48 dependence vs 20/48 contribution), reusable well beyond cell modeling.
  • Exemplary evaluation hygiene — pre-fixed rules, frozen checkpoints, physically disjoint control wells, independent-cohort transfer.
  • Unusually honest uncertainty reporting — paired intervals, source-scaffold resampling, null results stated plainly.
  • Constructive, not just critical — falsification evidence feeds a clean residual-over-anchor revision.
  • Known-truth simulations (6,400 datasets) map exactly what the intervals do and don't cover.

04 Limitations

  • Audit-feedback benefit stays suggestive — every paired sci-Plex contrast spans zero, at roughly 2× token cost.
  • Revision tested only on the authors' own CELLSCIENTIST policy — other agent policies, LLM backbones and domains untested.
  • Small absolute effects (PCC deltas ~0.001–0.005) with little headroom over context-only baselines on BBBCC047.
  • Source checker probed only via a coarse bug — no adversarial recall on subtle leakage; unresolved citations cap coverage.
  • Task-coupled rules — folds, replacement distributions and thresholds require per-task re-registration.

05 Questions for further exploration

  1. Can the AST checker catch subtle leakage — preprocessing, feature selection, shared encoders — with measured adversarial recall?
  2. Does falsification-guided revision hold under AIDE, CellForge, HarmonyCell, or different LLM backbones?
  3. How should the reference-relative criterion be calibrated so per-model decisions don't flip across folds (35/50 → 10/50)?
  4. Is the ~2× token cost justified when paired PCC benefit spans zero — which task regimes would change that?
  5. Do measured compound/dose contributions predict downstream biological utility, or only benchmark loss?

Self-audit tension: Mengran Li and Bo Li are CELLSCIENTIST co-authors — the audit reaches deep into the audited policy, but the revision loop is partly the authors grading their own system.
