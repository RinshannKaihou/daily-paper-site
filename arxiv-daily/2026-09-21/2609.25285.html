Why This Matters

Turns circuit discovery from hundreds of forward interventions into one forward pass plus a cheap paired causal gate — a practical pre-screen for interpretability at scale.

⚠ Critical Edge

The uniform-random control inflates every gap: kept edges carry far more attention mass than matched random edges, so the headline gaps are upper bounds — the true “routing” effect was never measured.

— the authors’ own disclosed confound; a mass-matched control would shrink the gap by “an amount we have not measured.”

Methodology — Three-Stage Pipeline
01 · READ

Read attention as a routing graph

Tokens are nodes; each edge (ℓ,h,i→j) is scored s = A[ℓ,h,i,j]·‖V[ℓ,h,j]‖₂ — attention weight × value norm, i.e. “how much was written along this route.” Head identity kept, BOS sink ignored, self-loops skipped.

02 · WALK

Walk backward from the answer

From the answer position, greedily keep the top-k incoming edges (k=15), four hops deep → a tiny edge set S.

03 · VERIFY

Causal gate

Zero S’s attention (renormalize the rest), measure the task-score drop against ten size-matched random edge sets: paired per-example gaps, 95% bootstrap CIs, one-sided Wilcoxon signed-rank.

SCOPE — 6 cells = {induction, IOI} × {GPT-2 Small, GPT-2 Medium, Pythia-410M} · n=100 clean prompts each · same recipe everywhere.

Strengths
  • Extremely cheap — 1 forward to extract, ~a dozen to verify, vs 145 for a head sweep; the verification gate is itself a contribution.
  • Statistically careful — n=100 per cell, paired gaps, bootstrap CIs all excluding zero, p<10⁻¹⁰ everywhere, run artifacts released.
  • Honest and well-scoped — explicit “what we are not saying,” per-cell failure counts, mass-effect confound disclosed rather than hidden.
  • Useful ablations — layer choice (early layers carry the induction gap), k sensitivity, score threshold, prompt-template robustness.
  • Reproducible — public code, configs, and evaluation artifacts on GitHub.
Limitations
  • Mass-effect confound — uniform-random control makes the gap partly an attention-mass artifact; true routing effect size unknown.
  • Narrow scope — two synthetic tasks with already-known circuits, three small models (max 410M); transfer to real tasks and modern scales is open.
  • Recovery is partial — famous early heads recur, but later textbook heads are often missing even when the sketch passes.
  • Nontrivial failure rates — 19/100 on GPT-2 Medium induction, 11–12/100 elsewhere; fixed hop budget and distractor latching diagnosed, not fixed.
  • |S| grows with prompt length — fixed k=15 / 4 hops will under-cover longer contexts; BOS ban and value-norm score are hand-designed patches.
  • Not a discovery engine — no feature naming, no SAEs, no per-edge completeness or necessity claims.
Questions for Further Exploration
  1. How much of each reported gap survives a mass-matched random control (edges sampled ∝ attention mass, or mass-matched random heads)? Measuring the shrinkage is the obvious next experiment.
  2. Does extract-then-verify transfer to a real task or a modern 1–7B model, where |S| scaling may break the fixed k=15 / 4-hop budget?
  3. At matched compute, how does it compare against attention rollout, information-flow routes, or budget-limited ACDC — not just full head-patching?
  4. Would mean ablation or activation patching agree with the zero-and-renormalize verdicts on the same edge sets?
  5. Can failure modes be fixed mechanistically — adaptive hop budgets, distractor rejection — to close the 19/100 failure rate on GPT-2 Medium induction?
