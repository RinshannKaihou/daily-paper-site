> **一句话总结：** 本文用两动作 Bernoulli 赌臂模型证明：即使缓存共享随机工具结果完美保留了每个 rollout 的条件奖励分布（边际完全一致），在 GRPO 式组内归一化下，共享单个随机结果会把期望策略更新从"期望奖励方向"变为"胜负概率方向"——预选 witness 中 G=64 时共享执行给出 +0.297628 的更新，而独立执行给出 −0.078867（真实梯度为 −0.025），符号完全反转；且 540 组配置的穷举有限和验证与钉死版本的 TVCache 运行时审计均复现了该机制。

> **TL;DR:** This theory paper constructs an exact counterexample to "cache equivalence" in agent RL training: in a two-action model where one action returns a constant c and the other a Bernoulli(q) reward, sharing one stochastic tool result across a GRPO group preserves every rollout's conditional reward distribution, yet the group-normalized update E[U₀,share] = (2q−1)S_G(p) follows a win/lose probability threshold q = 1/2 instead of the expected-return threshold q = c. On the preselected witness (p=0.5, c=0.9, q=0.8, G=64), the shared update is +0.297628 versus −0.078867 for independent execution, while the true gradient is −0.025 — a full sign reversal; the centered-only baseline estimator (−0.024609, matching the true direction) is immune. Exhaustive finite sums over 540 configurations find opposite-sign updates in 54/540 configurations at each tested ε, and a pinned unmodified TVCache audit (256 scripted rollouts) confirms the sharing path executes. Shared execution also leaves a non-vanishing within-group variance floor 4q(1−q)p(1−p) as G→∞. No LLM is trained — this is a mechanism result, not a benchmark result.

## 核心贡献

- **边际一致 ≠ 更新一致（有限群精确刻画）：** 对任意标量奖励分布推导出共享执行下组归一化更新的精确有限群表达式 E[U₀,share] = S_G(p)·(Pr(Y>c) − Pr(Y<c))——更新方向只取决于"赢的概率减输的概率"，与奖励差距的大小无关；由此证明"缓存保留每个 rollout 的条件奖励分布"并不保证"缓存保留期望策略更新"。
- **Bernoulli 特化与错误方向区域：** 当 Y~Bern(q) 时 E[U₀,share] = (2q−1)S_G(p)，共享更新的符号阈值是 q=1/2 而期望回报的阈值是 q=c；只要 1/2 < q < c < 1（或对称情形），归一化更新与真实梯度符号相反。同时证明共享执行存在不随群大小 G 消失的方差下限 Var → 4q(1−q)p(1−p)（独立执行方差 → 0）。
- **已有估计器作为对照：** 证明仅做组内中心化、不做组内标准差缩放的估计器 V 在两种执行律下都有 E[V] = (1−1/G)p(1−p)(μ−c)，期望方向与真实梯度一致——说明"缓存等价性"是估计器依赖的（Dr. GRPO 式去归一化即为一个现成的修复方向）；但非零数值稳定项 ε 并不能自动恢复正确的偏好阈值。
- **穷举数值验证 + 钉死实现审计：** 540 个配置 × 2 种执行模式 × 2 种估计器 × 2 个 ε 共 3,240 次估计器评估，配独立实现的有序序列检查器和 6 项确定性控制（最大概率质量误差 < 3.34×10⁻¹⁵）；并在未修改的 TVCache（revision 3a4f95a6582e）上用 256 条脚本化 rollout 复现共享执行路径，三次全量运行字节级一致。
- **明确的工程含义：** 较低的物理工具调用次数本身不是"训练等价"的证据；审计训练期优化时必须同时指明执行律与消费它的估计器。结果不衡量语言模型训练性能，也不推翻 TVCache 的确定性输出契约。

## Key Contributions

- **An exact finite-group characterization** of shared-outcome updates for arbitrary scalar reward: under shared execution the normalized update is E[U₀,share] = S_G(p)(Pr(Y>c) − Pr(Y<c)) — an ordering comparison, not a payoff-magnitude comparison — proving that marginal reward agreement does not imply update agreement.
- **A Bernoulli sign-reversal theorem and wrong-direction region:** E[U₀,share] = (2q−1)S_G(p) flips sign relative to the true gradient J'(θ) = p(1−p)(μ−c) whenever 1/2 < q < c < 1 (or the symmetric case), because the shared threshold is q=1/2 while expected return uses q=c. Sharing also induces a persistent variance floor (Var → 4q(1−q)p(1−p) as G→∞, vs →0 for independent execution).
- **An existing estimator as the control:** centering without group-std scaling preserves the expected-gradient direction under both execution laws, E[V] = (1−1/G)p(1−p)(μ−c), establishing that cache equivalence is estimator-dependent; a nonzero ε-stabilizer does not restore the correct preference threshold.
- **Exhaustive verification and a pinned runtime audit:** 3,240 estimator evaluations across 540 pre-specified configurations with an independent ordered-sequence checker (max errors < 3.34×10⁻¹⁵ / 1.78×10⁻¹⁵), plus a 256-scripted-rollout probe of unmodified TVCache revision 3a4f95a6582e with byte-identical triple reruns and hash-verified sources.
- **A sharp practical lesson:** a lower physical tool-call count is not, by itself, evidence of equivalent training — audits must specify both the execution law and the consuming estimator.

## Methodology

The paper studies a minimal two-action bandit at one policy parameter. Each of G ≥ 2 rollouts independently picks action a_i ~ Bern(p) with p = σ(θ): action A deterministically returns constant c; action B returns a scalar reward Y (first moment μ = E[Y]) from a stateless stochastic tool. Actions are independent of tool randomness, so the true objective gradient is J'(θ) = p(1−p)(μ−c) and the policy score is a_i − p.

Two execution laws are compared. Under *independent execution*, every B invocation receives an independent copy Y_i; under *shared execution*, one Y is drawn per group and reused for every B invocation (equivalent to a per-group cache hit). Both laws preserve the conditional reward marginals L(r_i | a_i=0) = δ_c and L(r_i | a_i=1) = L(Y) — the only distributional change is that B-outcomes within a group become perfectly correlated. Two accent estimators are analyzed: the group-normalized U_ε = (1/G)Σ(a_i − p)(r_i − r̄)/(s_r + ε) (GRPO-style) and the centered-only V = (1/G)Σ(a_i − p)(r_i − r̄). All analysis is exact: conditioning on N = Σa_i ~ Bin(G,p), the centered numerator collapses to h_G(N)(Y−c) under sharing, yielding Theorem 1 in closed form; asymptotics (Theorem 4) and the exact finite-G variance (Eq. 12) follow from bounded convergence and law-of-total-variance computations (Appendix B). A nonzero-stabilizer analysis (Section 4.1) derives the zero-update threshold q_ε = B_ε/(A_ε+B_ε) and shows it interpolates between 1/2 and c as ε varies.

Verification is three-layered. (1) *Exhaustive finite sums:* a pre-registered grid — G ∈ {2,4,8,16,32,64}, p ∈ {0.1,0.5,0.9}, c ∈ {0.1,0.3,0.5,0.7,0.9}, q ∈ {0.0,…,1.0} → 540 configurations — evaluated for both modes × {centered, normalized} × ε ∈ {0, 10⁻⁴}, i.e. 3,240 estimator evaluations, all in exact finite probability-weighted sums (Python stdlib only). A *separately implemented* checker enumerates ordered rollout outcomes against the literal score expression; six deterministic controls (q=0/1 and G=2 equivalence, reward mean, centered formula, probability mass) all pass with errors below 3.34×10⁻¹⁵. The witness (p=0.5, c=0.9, q=0.8) was selected analytically *before* execution. (2) *Pinned implementation audit:* the sharing path is exercised in unmodified TVCache revision 3a4f95a6582e (semantic stateful executor, async client, Flask routes, immutable prefix-tree backend), with only HTTP transport bridged in-process, sockets/DNS disabled, and 32-rollout scripted cases comparing direct execution, shared identity, separate task namespace, and separate draw identity. (3) *Reproducibility:* all protocols, traces, source hashes, and results are public (github.com/shil720/tool-cache-coupling), all transitive versions pinned.

## Results & Highlights

- **Sign reversal at the preselected witness (p=0.5, c=0.9, q=0.8, G=64):** both execution laws have identical mean reward 0.85 and true gradient −0.025, yet the shared normalized update is **+0.297628** versus **−0.078867** under independent execution — opposite signs, with the shared mode pointing away from the true gradient. The centered-only baseline estimator gives **−0.024609** under *either* law, matching the true gradient direction (Table 1; the independent-mode value converges to −0.078867 only because group normalization rescales by s_r, not because its sign logic differs).
- **Grid-wide sign disagreements:** across all 540 pre-specified configurations, the two execution modes produce opposite-sign updates in **54/540** configurations at each tested ε (0 and 10⁻⁴); independent normalization opposes the expected-return gradient in 54 configurations and shared normalization in **108**, while centering alone shows **zero** sign discrepancies. The grid was constructed to exhibit the mechanism, so these fractions are not deployment prevalence.
- **Persistent variance floor (Theorem 4):** as G→∞, Var(U₀,share) → **4q(1−q)p(1−p)** while Var(U₀,ind) → 0; at finite G the shared variance is exactly (1−1/G)p(1−p) − (2q−1)²S_G(p)². Enlarging the rollout group adds no independent tool outcomes under sharing — the noise is a within-group floor, not irreducible data uncertainty.
- **Threshold mismatch:** the shared zero-update threshold is q=1/2 versus q=c for expected return; a nonzero stabilizer only moves it to q_ε = B_ε/(A_ε+B_ε) ∈ (1/2, c) for c > 1/2 — ε↓0 recovers 1/2, ε→∞ recovers c — so GRPO's practical ε does not fix the bias.
- **Runtime audit counts:** in the pinned TVCache probe, 256 scripted rollouts (64 direct-environment controls + 192 through the cache) produced **196 physical tool calls and 648 in-process HTTP requests** with zero socket/DNS attempts; under shared identity, a 32-rollout case made only **2 physical calls** (sixteen copies of the first B result "1") versus 32 for direct execution and both identity-separated controls (Table 2). Three full runs were byte-identical; all 29 exported source files passed hash verification.
- **Numerical exactness:** maximum probability-mass error **< 3.34×10⁻¹⁵** and maximum marginal-mean error **< 1.78×10⁻¹⁵** across the exhaustive sweep, with all six deterministic controls agreeing exactly.

## Authors & Credibility

The paper has a single author, **Shivam Gupta**, listed as an Independent Researcher — no academic affiliation, no co-authors, and (per an explicit footnote) no external peer review; LLM-based tools assisted research exploration, code, mathematical analysis, manuscript preparation, and internal automated review. Credibility must therefore rest on the artifact, and the paper unusually much does: the witness was preselected analytically before execution, the verification checker was implemented separately from the numerics, the TVCache audit runs an unmodified pinned revision with hash-verified sources and byte-identical triple reruns, and protocols, traces, and results are public. The math itself is elementary (binomial conditioning, bounded convergence, law of total variance) and the proofs given in-text are short and checkable. The related-work framing is accurate and current — GRPO (DeepSeekMath), Dr. GRPO's normalization-bias critique, TVCache, and CacheRL are all characterized correctly, and the author explicitly declines to claim TVCache's own workloads exhibit the effect. This is careful, honest work by a hobbyist-standard-bearing individual, though it has not survived formal review.

## Critical Assessment

The central theorem is correct as far as I can verify and the epistemic hygiene is exemplary — but the result's significance must be read against its deliberately tiny scope. First, **no language model is ever trained**: the model has two actions, one decision per rollout, a fixed policy, and a constant alternative, with no KL penalties, clipping after parameter movement, adaptive optimizers, variable token lengths, or multi-turn feedback. The "sign reversal" is exact within this one-step reward-component estimator, but whether it produces measurable accuracy loss in a real GRPO run is untouched — the author says so plainly, yet the title ("Can Reverse…") invites more deployment anxiety than the evidence supports. Second, **the 54/540 wrong-direction fraction is an artifact of grid construction**, not a prevalence estimate; the author flags this, but any quotation of "10% of configurations" out of context would mislead. Third, the **audit target is only loosely coupled to the math**: TVCache's own paper lists its EgoSchema training objective as importance sampling, and only other workloads use GRPO — so the pinned audit proves the sharing *path* is reachable in the stack, not that the studied normalized estimator is actually consumed by that system; the paper admits this, which makes Section 6 feel more like infrastructure demonstration than validation of a live risk. Fourth, the **centered-only fix is incomplete**: Proposition 3 preserves the mean direction, but Appendix B shows the shared update's *variance* differs (Var(V,share) = q(1−q)E[h²] + (q−c)²Var(h) vs an extra N²-fluctuation term for independent), so "mean-direction equivalence" does not extend to the update distribution, and nothing tests downstream convergence under either law. Finally, single-author, LLM-assisted, un-peer-reviewed provenance means the exactness claims lean entirely on the author's own checker — reassuring given its separation from the numerics, but not independent in the scientific sense.

## Strengths

- Exact, closed-form results (finite-group expression, asymptotic means, exact finite-G variance) rather than empirical hints; the Bernoulli threshold split (q=1/2 vs q=c) is a crisp, memorable characterization.
- Textbook-grade verification discipline: pre-registered witness and grid, an independently implemented ordered-sequence checker, six deterministic equality controls, and floating-point errors around 10⁻¹⁵.
- The pinned, unmodified TVCache runtime audit with hash verification and byte-identical reruns connects the abstract execution-law distinction to real, inspectable infrastructure.
- Exceptional scoping honesty: the paper repeatedly and precisely states what it does *not* show (no LLM training, no prevalence, no refutation of TVCache's deterministic-output contract, no wall-clock claims), separating mathematical claims, scripted evidence, and deployment implications.

## Limitations

- Toy model: two actions, one decision per rollout, constant alternative, fixed policy; no KL, clipping, adaptive optimizers, token-length effects, or multi-turn feedback, and real policies can adapt their action distribution to cached observations (explicitly out of scope).
- No training experiments of any kind — no learning curves, no accuracy deltas, no time-to-accuracy or cost-quality trade-off; the "curves" in Figure 1 are exhaustive calculations, not learning dynamics.
- The wrong-direction fraction (54/540) measures the constructed grid, not the probability that a deployed agent's stochastic tools fall in the wrong-direction region.
- The proposed escape hatch (centering without std-scaling) only preserves the mean direction; it does not restore the update distribution and is untested beyond the one-step model.
- Cache lifetime, concurrent misses, partial sharing, eviction, and stale state — all present in production caches — are outside the model; the audit covers one narrow execution path (sequential one-call rollouts, no eviction, no network).
- Single independent author, LLM-assisted including internal automated review, no external peer review.

## Relevance

对做 LLM agent 训练的读者这是一篇高信号量的"机制警报"论文：它精确指出工具结果缓存（TVCache 类系统）在 GRPO 式组归一化下可能静默反转策略更新方向，并给出一个零成本的诊断原则——审计训练期优化时必须同时指明执行律和消费端估计器（中心化即可免疫）。虽然没有任何真实模型实验，但它为 agent RL 基础设施中的"省调用=等价训练"假设提供了首个精确反例。

## Questions for Further Exploration

- Does the sign reversal survive end-to-end GRPO training with clipping, KL penalties, and adaptive optimizers — i.e., can a measurable accuracy regression be produced on a real agent benchmark with a stochastic tool and a shared cache?
- What fraction of real agent workloads' tool calls are actually stochastic and group-shared? (The paper's 54/540 grid fraction is explicitly not a prevalence estimate.)
- Does Dr. GRPO-style de-normalization (or any centering-only variant) close the gap in practice, and does its higher gradient variance (Appendix B) cost convergence speed in a controlled comparison?
- How do cache lifetime, eviction, and partial sharing interact with the within-group variance floor — can adversarially timed cache misses amplify the wrong-direction region in multi-turn settings?
- Would a simple per-group "draw identity" separation in the cache key (as tested in the runtime audit) restore update equivalence at acceptable physical-call cost, and what is the measured dollar/time trade-off?
