Why This Matters

For LLM agents operating real scientific instruments: move integrity constraints from prompts into deterministic tool code, and grade agents by physical consequence, not task completion.

把完整性约束从提示词搬进确定性工具层，用可物理验证的基准（NIST 标样、四类物理后果）评估 agent，而非只看任务完成率。

Critical Edge

No agent-level benchmark results are reported: the paper proves the guard works, but not that APEXA’s agent is more competent than any external baseline — and the 15/200 prompt-only contrast is a single-pass estimate with no error bars.

03 Strengths

  • Right trust boundary: reliability moved from prompt text into deterministic tool-layer code — the 0/200 result demonstrates it cleanly.
  • Deployed, not just simulated: real APS 1-ID beamline data with physically validated outputs (0.03 mm cross-standard, ±0.02 mm sweep).
  • Novel evaluation axis: physical-consequence taxonomy + NIST-traceable cross-detector CI — no prior agent benchmark separates wasted compute from damaged equipment.
  • The benchmark does real work: it surfaced two latent bugs invisible to single-detector testing, and the fixes measurably collapsed the spread.
  • Exemplary reproducibility: --mock modes reproduce both headline numbers with no IOC and no API keys; interaction traces released.

04 Limitations

  • No agent-level scoring: per-model success rates on the 58 tasks and any external-baseline comparison are deferred to a future study.
  • Thin baseline: 15/200 is a single-pass point estimate (n=1 per scenario×model, 2026-05 snapshot, no seeds or confidence intervals).
  • Simulation-only safety: motor enforcement validated against a simulated EPICS IOC — never against physical motors, latency, or faults.
  • Narrow scope: single facility, single beamline (HEDM); APEXA-Score weights are illustrative with no sensitivity analysis.
  • Coverage gaps: adversarial suite targets motor control only; fabrication frequency in normal operation is unquantified; cross-detector evidence is n=2 bugs — proof of concept, not a rate.
  • Partial release: downstream Rietveld products withheld, limiting from-scratch end-to-end reproduction.

05 Questions for Further Exploration

  1. What is the base rate of tool-call fabrication per model in normal, non-adversarial operation — is the guard a rare-event net or a constant necessity?
  2. Do APEXA-Score rankings survive different consequence weights (w_PI), different α, and the promised full-length scoring study?
  3. Could a much larger prompt, ensembled safety prompts, or a pre-flight LLM reviewer drive the 15/200 prompt baseline to zero — is any prompting approach competitive at scale?
  4. Can cross-detector CI generalize beyond crystallography — to SAXS/WAXS or spectroscopy beamlines with no NIST-traceable gold standard?
  5. How does the guard interact with legitimate parallel/batched execution, streaming partial results, and idempotent side effects — where “executed” is harder to define?

06 Reproducibility & Provenance

  • All three core claims (guard, 0/200, cross-detector findings) are deterministic tool-layer properties — exactly reproducible via --mock/--dry-run with no LLM API keys and no IOC.
