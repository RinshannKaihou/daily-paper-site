Key Finding · 核心发现

Instruction tuning gates — not rewires — the knowledge-conflict circuit: the same late-layer heads keep adjudicating.

指令微调对知识冲突回路是“门控”而非“重连”；但这种新增的怀疑主义只针对简短矛盾，面对连贯伪造段落几乎消失。

Why It Matters · 为何重要

Base-model circuit tools transfer directly to instruct siblings — but instruction tuning is no defense against well-written misinformation.

Interpretability gets cheaper: analyze the open base checkpoint, inherit insight into the deployed instruct model. RAG trust calibration and prompt-injection defense get a quantified warning.

Critical Edge · 批判视角

Under coherent false passages, base and instruct both follow at 0.854–1.000 — and the paper offers no wiring-level explanation, because edge analysis covered only terse conflicts.

The safety-relevant finding is exactly the one without a mechanism; the blanket “gating” verdict is also sharpest only for Llama (Qwen/Gemma sit in the authors’ own partial band).

Methodology · 方法

Four measures, one pre-registered verdict table

Inference-only study of released checkpoints — “instruction tuning” is the delta between siblings, no new training.

  1. Sibling pairs. Llama-3.2-3B, Qwen-2.5-3B, Gemma-3-4B — each base model vs. its instruct twin.
  2. Conflict set. ParaConflict-derived, tokenizer-pinned single-token answers: 764 identical prompts for Llama/Qwen, 870 for Gemma; two forms — terse Substitution vs. evidential Coherent passage.
  3. Measures. CRR behavior (+ log-prob variant) · LDS node screen (top-k Jaccard, Spearman) · EAP-IG edges (J@50 over 87k–390k edges) · superposition index S ∈ [−1, +1].
  4. Pre-registered rule. Node overlap > 0.6 = gating band, < 0.3 = rewiring territory; exact hypergeometric null against random top-k.
  5. Controls. PH3-style path patching, top-5 head amplify/ablate vs. a-priori predicted sign, random 5-head ablation floor, three saliency flavors.

Strengths · 优势

  • Four-method triangulation — LDS nodes, EAP-IG edges, superposition index, path patching — with each method’s blind spots discussed; nothing rests on one attribution technique.
  • Pre-registered decision rule with exact hypergeometric nulls turns “same heads?” into a falsifiable verdict table.
  • Real specificity control: random-head ablation floor (−0.03 to +0.02) rules out “any late-layer perturbation works.”
  • Cross-family replication with per-family placement, including identical 764-row scoring for Llama/Qwen.
  • Candor: ambiguous edge sub-types labeled as such, non-significant p-values acknowledged.

Limitations · 局限

  • Scale: 3–4B models only; gating at 70B+ (heavier post-training) is untested.
  • Substitution-only edge analysis — the coherent-passage effect, the most deployment-relevant finding, has no edge-level mechanism.
  • “Instruction tuning” as a black-box bundle: SFT vs. RLHF mix, data scale, chat template uncontrolled; the delta is correlational.
  • One skewed corpus: Athlete–Sport is ~70% of surviving Llama/Qwen prompts; two of six relations filtered out entirely; single-token answers only.
  • Aggregate statistics: 36/36 binomial treats six cells as independent; path-patching p-values (0.10–0.42) are individually non-significant.

Questions for Further Exploration · 待探索

  1. Does the gating verdict (and the Llama vs. Qwen/Gemma edge split) survive at 8B–70B scale, where post-training is heavier?
  2. What is the edge-level mechanism of the coherent-passage framing effect — do fluent false passages recruit early/mid-layer heads that bypass the late-layer circuit?
  3. Can the 5-head context set serve as a deployment-time RAG guard — monitoring or steering those heads to recalibrate context trust per source?
  4. Which ingredient of post-training (SFT scale, RLHF, chat templating) drives the memory-ward reweighting? A controlled intervention would make the delta causal.
  5. Is the rising “neither” abstention rate calibrated uncertainty — or an artifact of suppressed context heads?
