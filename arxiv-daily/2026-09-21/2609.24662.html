Why this matters

Static, passive-user safety tests systematically underestimate exposure for RAG, support, and ops agents — and should reshape defense priorities (tool allowlists, verification gates, output sanitization).

Critical edge

The +14.2 pp headline is a confounded regime-level effect — multi-turn structure, user influence and mutable state change at once, so no single cause is isolated.

full critique ↓
Methodology

τ²-bench dual-control (Dec-POMDP) structure: the agent and an LLM user simulator both observe and mutate a shared, partially observable environment state — trajectories are jointly shaped.

  1. Two regimes compared

    Solo: static request, no user participant (≈ classic prompt-only benchmarks). Dual-control: a fixed GPT-4o-mini user simulator with persona/goal joins the loop via chat and user-scoped tools.

  2. 8 adversarial domains · 35 executable multi-turn tasks

    mail_rag_phishing7 tasks
    collab6
    infra_loadshed5
    crm_leak4
    tool_shadow_poison4
    output_handling3
    mktg_phishing3
    auth_spoof_support3

  3. Deterministic-first scoring

    65 state assertions replayed over the post-execution environment (judge-free) + 37 communication assertions graded by a GPT-4o judge at T=0. Reward is a strict conjunction over assertion types — refusing an unauthorized action while leaking data still scores 0.

  4. Protocol & statistics

    n=5 runs per configuration; 14 models × 8 domains × 2 regimes = 1,960 trials per regime (3,920 total). ASR primary; τ-bench pass^k for reliability; Fisher exact tests + Wilson intervals; user-simulator temperature swept over {0.0, 0.5, 1.0} on a 9-model subset.

Diagnostics: manual audit agreed with 56/60 sampled judge decisions; 94.5% of dual-control runs ended via the simulator stop condition; code, seeds and trajectories are public (github.com/ai-security-lab-itmo/duma-benchmark).

Also in the appendix
  • User-simulator temperature {0.0, 0.5, 1.0}: no significant aggregate effect (pass^1 0.716 / 0.719 / 0.730) — conclusions are stable under user stochasticity.
  • Dual-control pass^k decays 0.722 → 0.596 (k=1→5): many successes are trajectory-specific, not consistent behavior.
  • Non-passing dual runs: 81.9% fail deterministic state assertions vs 18.1% communication assertions.
Strengths
  • Deterministic-first scoring — replay-based state assertions avoid LLM-judge bias; the strict conjunction kills “refuse-but-leak” partial compliance.
  • The real insight is distributional — dual control changes which vulnerabilities are visible (mktg_phishing ×28 vs flat RAG poisoning), more actionable than the aggregate.
  • Statistical hygiene rare for benchmarks — n=5 trials, pass^k estimator, Fisher exact tests, temperature control, manual judge audit (56/60).
  • Breadth with comparability — 14 models across 5 vendor families on identical tasks; open code, seeds and trajectories.
Limitations
  • Regime-level confound — solo→dual changes multi-turn structure, user influence and mutable state at once; no factorial ablation isolates the cause.
  • Thin domains — mktg_phishing’s +0.593 rests on 3 tasks and partially measures the GPT-4o-mini simulator’s persuasiveness; no per-domain CIs in main tables.
  • GPT-5 collapse confounded — reasoning could not be disabled (evaluated at its minimum setting).
  • No defenses evaluated — proposed mitigations are prose only; “a framework for evaluating defenses” overstates what is demonstrated.
  • Judge false positives inflate ASR where communication assertions dominate (borderline safe output_handling runs); a fixed GPT-4o-mini simulator leaves adversary strength unexplored.
Questions for further exploration
  1. Under a full factorial design (multi-turn × user influence × mutable state), which component drives the +14.2 pp — and does the domain redistribution survive?
  2. Would an adaptive red-team simulator (instead of fixed GPT-4o-mini) raise ASR further, and would the GPT-5-vs-Claude ranking change?
  3. Do the proposed guardrails (provenance tagging, tool allowlists, verification gates, output guardrails) actually cut dual-control ASR — at what task-utility cost?
  4. Is the GPT-5 family’s collapse robust when reasoning mode is a fully controlled on/off variable?
  5. How do LLM-simulator findings transfer to human-in-the-loop studies with real users applying pressure and impersonation?
