Key metric

56.2%→94.1%

balanced accuracy on REFUGE2 glaucoma, after 20 rounds of self-improvement — with no reference labels shown during diagnosis.

+3.7 pts over human-engineered MedAgent-Pro (90.4%) · clinical cost falls 12.4 → 2.5 per 100 cases.

Why this matters

First systematic port of recursive self-improvement into high-risk medicine — a reusable recipe for keeping self-evolving agents safe, auditable, and non-degrading.

⚠ Critical edge

The “clinical judge” is GPT-4o — the same model family as the agent itself — so the headline clinical-cost gain partly measures agreement with the authors’ own severity rubric, not clinician-adjudicated outcomes.

Methodology · the self-improvement loop

  1. 01Diagnose120 glaucoma + 60 heart cases per round, labels withheld
  2. 02Grade errorsfrozen clinical judge scores consequence 0–4 on a pre-registered rubric
  3. 03Prioritizeseverity-weighted, budgeted reflection over failure clusters
  4. 04Reflectclusters become structured capability-gap specifications
  5. 05Buildcode generation · tool composition · model development
  6. 06Trial & registerblinded paired trials on disjoint cohorts

Mechanism 1 — clinical-cost-aware failure priority

A frozen judge scores each error’s consequence, not just its frequency: priority qᵢ = Åᵢ(1+λsᵢ), λ=2. Clinical cost — consequence-weighted errors per 100 patients — becomes a first-class objective beside accuracy.

Mechanism 2 — fast discovery, slow registration

Candidates enter an experimental pool instantly, but join the persistent toolkit only after a mean gain >0.5 balanced-accuracy points across K=3 disjoint cohorts and no clinical-cost increase (ΔĆ̄ ≤ 0). Frozen version hashes + blinded trials block unstable tools.

Frozen: the reasoning model M and workflow P. Only the versioned tool registry grows — the improvement trajectory stays inspectable. Three invention routes: code generation, tool composition (masks → vCDR calculator), model development (U-Net, fusion transformer, CycleGAN-style translation).

OpenHands v0.20 · GPT-4o (2024-08-06) reasoner & judge · 20 rounds (30 for stability) · 2 public benchmarks + 2 private clinical cohorts · 5 seeds, bootstrap CIs, 10,000-permutation paired tests

Results · self-improvement vs. human engineering

Self-improvement beats human engineering on both public benchmarks (P < 0.001, round 0 vs 20; consistent across all 5 trajectories, 93.4–94.7% final).

  • Invented its own data pipeline: trained a CycleGAN-style translator to synthesize 2,716 contrast echo studies from 318 real ones — EF error nMAE 0.55 vs 0.85 (MedAgent-Pro), 68.8% within ±5-point clinical tolerance.
  • Re-derives the experts: 100% coverage of MedAgent-Pro’s five capability categories by round 14 — from 118 candidates, only 16 registered (median trial gain +2.2 vs −0.9 for discarded).
  • Transfers across backbones: Claude Sonnet 4.5, Gemini 2.5 Pro and Qwen2.5-VL-72B all reach 89.8–93.6%, above MedAgent-Pro; 11 of 16 tool functions recovered by all four.

Strengths

  • New problem framing — safety-gated RSI; both mechanisms grounded in clinical analogies (triage; staged device adoption), not agent folklore.
  • Unusually rigorous for an agent paper — patient-level splits, pre-registered rubric and margins, blinded paired trials, permutation tests, and negative results reported (61 discarded candidates; one dissected failure).
  • The slow-registration ablation is a causal story — under immediate registration one bad tool (+6.1 discovery gain, negative trial gains) becomes self-reinforcing, dragging accuracy 89.6% → 76.9%.
  • Emergent rediscovery of the expert tool taxonomy across four backbones — gain comes from selective evolution (118 → 16 tools), not accumulation.

Limitations

  • Self-judged safety — severity scores come from GPT-4o, the agent’s own model family; “clinical cost” is validated only against the rubric that defines it (λ sweep: 88.7% at λ=0 → 94.1% at λ=2).
  • Self-referential baseline — MedAgent-Pro is the authors’ own prior system; no independent SOTA glaucoma agent included.
  • Asymmetric reproducibility — the headline private-cohort wins cannot be externally evaluated; public tasks are small and binary.
  • Hidden operating-point shift — MITEA specificity quietly falls 90.2% → 86.2%; balanced accuracy masks it.
  • No human in the loop — no prospective or clinician-in-the-loop study; test-set curves reused across rounds (final round pre-specified, which mitigates).
  • Bottleneck & budget — frozen 2024-era GPT-4o planner; 212 A100-hours + 1.9B tokens per trajectory; K=3 gating delays adoption by design.

Questions for further exploration

  • Does severity-rubric prioritization survive a miscalibrated judge in a new specialty (e.g., oncology staging)? Can clinician spot-audits substitute for full rubric design?
  • Can cheaper sequential tests replace the K=3 cohort gate, given the 84.7% vs 94.4% gap at round 30 for K=1 vs K=3?
  • Would a human team given the same reflection records and budget match the 92.1% private-cohort result — or does the failure-driven loop itself earn the win?
  • Does RSI extend to interventional decisions, where a 0–4 severity rubric is far harder to pre-register?
  • Should registration require an “environment fingerprint”? The discarded rim-texture tool failed precisely on camera- and illumination-sensitive features.

Provenance: Oxford & Stanford; the strongest baseline (MedAgent-Pro) is the group’s own prior system — a self-referential comparison, rerun fairly on identical partitions. Evaluation protocol unusually careful: locked test sets, frozen judge, blinded paired trials, permutation tests. Code released at github.com/ImprintLab/MedRSI.
