BWhy this matters

A reproducible, memorization-proof benchmark pinpoints where research agents fail — numerical inference after sound measurement — guiding stronger scientific agents.

CCritical edge

All 108 core episodes run on two DeepSeek models from a single provider — no frontier or open-weights agent, no significance testing; generalization is unproven.

01Methodology — how understanding is graded
  1. Task. Deterministic utility u(z) ∈ [0,1] over binary masks (d = 4 or 6); each bit is a real workflow option — TF-IDF vs raw counts, ridge α, denoiser choice.
  2. Budget. Two free anchors (all-zeros, all-ones); the agent buys ≤ B further measurements in batches; over-budget requests are rejected.
  3. Deliverable. Predict û(z) for every one of the 2d configurations — a full response surface, not one best config.
  4. Ground truth. Exhaustive native CPU execution: 1,248 configuration records, cached and hash-verified.
  5. Metrics. Per-effect recovery Ri = max(0, 1 − E/A); strict reconstruction (every effect error ≤ 10% of response range); exact choice (regret ≤ 10−12); family-macro averaging.
  6. Shared-inference protocol. Freeze the agent's purchased observations, swap only the estimator (ridge / GP / code-derived equivalence classes) — decoupling measurement from inference.
  7. Agents. deepseek-v4-flash & -pro, four tools, 30 CPU-s sandbox; 108 core episodes (B ∈ {4,8}, two dated cohorts), 36-episode six-factor study at B=20, 8-episode rule diagnostic, six B=32 submissions.

Budget dominates too: Flash doubles recovery 0.178 → 0.632 from B=4 to B=8; yet only 7/18 episodes pick an exact optimum and 1/18 passes strict reconstruction.

Surprise 1 — code access hurts: hiding the workflow code slightly beats full code (−0.024 / −0.064 shared-GP delta) — a fragile, small-N result, but a striking negative.

Surprise 2 — recognition ≠ application: in all 8 diagnostic episodes agents recited every inactive-option rule correctly, then violated every rule in their final tables; injecting rules lifts recovery 0.247 → 0.429, post-hoc projection 0.338 → 0.507.

03Strengths
  • Ground truth you can trust: exhaustive execution of all 1,248 configs, hash-verified cold replay, independently reimplemented metrics, full reference replays in 127.87 s on one thread.
  • The shared-inference protocol turns "bad at measuring or bad at inferring?" into a measurable question — with a crisp answer.
  • 35/36 sign reversals give real discriminative power against configuration-memorizing agents; the F.2 counterexample proves exact choice and effect recovery are separable targets.
  • Unusually honest reporting: negative results, per-episode HTTP-429 accounting, cohort separation after a mid-study provider routing change.
  • Complete artifact release: frozen prompts, flat 3,392-effect tables, machine-readable audits — usable immediately.
04Limitations
  • Task spaces capped at 4–6 binary options; no scaling path to continuous or high-dimensional design spaces.
  • Two DeepSeek models, one provider, one snapshot; cohort drift (75 HTTP 429s, Flash routing change) confounds comparisons despite careful bookkeeping.
  • Core conclusions from six matched four-factor sources; no significance tests, no human-expert baseline.
  • The "code hurts" finding rests on only 8 valid paired artifacts with wildly swinging per-source deltas.
  • Author-set [0,1] normalization and τ = 0.1 tolerance — recovery numbers don't travel outside this framework.
  • Deterministic, seeded utilities exclude the stochastic-experiment regimes that dominate real science.
05Questions for further exploration
  1. Can exhaustive verification extend to continuous hyperparameters or d > 10 via sparse Fourier / ANOVA sampling of the Boolean cube?
  2. Would frontier multi-provider agents close the 0.632 vs 0.698 gap — or is weak numerical inference a fundamental LLM-agent limitation?
  3. Why does workflow code hurt: prompt overload, distractor structure, or missing code-grounded priors? Could symbolic execution derive the equivalence classes automatically?
  4. Can the recognition–application gap be closed architecturally — a delivery-time projection tool already lifts 0.338 → 0.507 for free?
  5. Do acquisition rankings (pair ridge vs effect-variance GP) transfer to stochastic simulators, where cached deterministic references no longer hold?
