> **一句话总结：** 提出ESupNNet——在目标CNN旁外挂一个小型二分类"监督网络"，仅读取目标CNN最后一层的输出logits，通过学习其中隐含的类间关系来检测参数软错误（SEU/MBU位翻转）导致的误分类；无需修改或重训目标CNN，参数开销仅0.32%–1.13%，在ImageNet-1K与CIFAR-10共5个骨干（ResNet-50、EfficientNetV2-S、MobileNetV3-S、ShuffleNetV2、MNASNet）上检测准确率最高96.4%、AUROC最高0.9926，且在误码率BER=1e-4时ResNet-50精度损失仅1.34个百分点（对比Stegano-ECC的45.0个百分点）。

> **TL;DR:** ESupNNet attaches a tiny auxiliary binary classifier ("supervising ANN") to an unmodified target CNN that reads only the pre-softmax output logits and flags misclassifications caused by radiation-induced bit flips in parameters. Trained on a fault-injection-generated, Cochran-formula-sized dataset (50% correct inferences, 25% silent faults, 25% errors), it achieves 89.7%–96.4% detection accuracy with 10-fold cross-validation — e.g., 96.42%±0.05 on EfficientNetV2-S/ImageNet-1K and 96.26%±0.25 on ResNet-50/ImageNet-1K (AUROC 0.9926 and 0.9825 vs 0.5 for a random classifier) — at a parameter overhead of only 0.32%–1.13%, versus 31.25%–31.75% for the non-monotonic bit-sensitivity (NBS) alternative, and it keeps ResNet-50's accuracy drop at BER 1e-4 to 1.34 points where Stegano-ECC loses 45.0 points. It even detects multi-bit-upset (MBU) errors despite training only on single-bit-flip data.

## 核心贡献

- **非侵入式错误检测架构**：目标CNN完全不改（不加重、不重训、不改算子），当作黑盒，只用其输出logits作为监督网络的输入；监督网络是单输出神经元的二分类器（sigmoid阈值0.5），对ResNet-50/EfficientNetV2-S结构为1,000-250-100-1，对CIFAR-10模型为10-100-80-60-40-20-1。
- **类间关系建模**：将"分类正确"形式化为输出logit向量属于类间关系R（正确类别的logit在类间相似结构中的位置），用回归方式学习近似关系R*；若z(x)∉R*则判定出错。
- **统计上可信的训练集生成流程**：自研故障注入器对参数随机位翻转（Q6.10定 点16位表示），数据集按50%正常正确样本（X_c）+25%静默故障（X_s）+25%故障致错（X_a）构成，改动参数按90%/10%分配给权重/偏置，父数据集规模用Cochran公式在99%置信度（Z=2.576, p=0.5）下确定，误差幅度最坏<2%。
- **近零开销**：监督网络参数开销为ResNet-50 0.86%、EfficientNetV2-S 1.03%、MobileNetV3-S 1.13%、ShuffleNetV2 0.32%、MNASNet 0.35%，远低于TMR（约200%）和NBS类方案（31%+）。
- **跨位错误率（BER）验证与泛化**：在1e-8~1e-2共13档BER、每档100次仿真中验证检测能力；训练数据只含SEU，却能高准确率检出MBU导致误分类。
- **与现有技术正交可组合**：可与ECC、选择性TMR等其他防护机制叠加使用，适用资源受限（嵌入式/FPGA）与不受限系统。

## Key Contributions

- A **non-intrusive error-detection architecture** (ESupNNet): a small auxiliary binary classifier watching only the target CNN's output logits — no redundancy, no retraining, no operator modification; the target CNN remains a black box.
- A **class-relation formulation** of error detection: correct classification means the logit vector z(x) belongs to a class-relation structure R (mean-logit centroids + pairwise similarities inherited from the feature extractor and reshaped by the FC layers); the supervising ANN learns an approximation R* by regression (Eq. 4–8).
- A **statistically grounded dataset-generation methodology**: custom fault injector performing single bit flips on parameters in Q6.10 16-bit fixed point; dataset D composed of 50% correct unaltered inferences (X_c), 25% silent altered (X_s), 25% misclassification-causing altered (X_a), 90%/10% weight/bias split, with parent dataset D_p sized via the Cochran formula (99% confidence, worst-case error margin <2%).
- **Negligible overhead**: supervising-ANN parameter overhead of 0.86% (ResNet-50), 1.03% (EfficientNetV2-S), 1.13% (MobileNetV3-Small), 0.32% (ShuffleNetV2), 0.35% (MNASNet) — versus ~200% for Triple Modular Redundancy and 31.25%–31.75% for NBS-based protection.
- **BER-level robustness analysis** (13 BERs from 1e-8 to 1e-2, 100 simulations each) and a demonstrated generalization result: the net detects MBU-caused errors although D contains only SEU data.

## Methodology

**Concept.** Each class can be represented by a mean logit vector (centroid); similarities between these centroids define a class relation matrix. A classification is correct iff the output logits z(x) = F_θ_l(Φ_θ_f(x)) belong to the relation R; errors are detected when z(x) ∉ R*. Since obtaining R analytically is intractable for modern CNNs (trainability- and separability-dependent), the authors train an ANN to approximate R* by regression on a dataset of correct and erroneous logit vectors.

**Architecture.** The supervising ANN S: X^m → R → {0,1} is a plain FC network taking the target CNN's last-layer logits (dimension = number of classes) and emitting one sigmoid output with threshold 0.5 (error/no error). Inputs are Min-Max normalized; activations are LeakyReLU. For ImageNet-1K models (1,000-dim logits): 1,000-250-100-1. For CIFAR-10 models (10-dim logits): 10-100-80-60-40-20-1 — the input is first *expanded* before compression, which empirically helped low-dimensional inputs.

**Dataset D generation.** A custom fault injector flips a random bit of a randomly chosen parameter (Q6.10 fixed point, 16 bits — a common embedded-storage compression) and re-runs inference on correctly classified inputs: silent outcomes go to X_s, misclassifications to X_a. Altered data is split 90% weights / 10% biases to avoid bias-dominated classes; all subsets are class-balanced. Parent dataset D_p sizes follow the Cochran formula n_0 = Z²p(1−p)/e² (Z=2.576, p=0.5): e.g., 21,604 weight + 4,172 bias injections per class for ResNet-50 (error margin 0.87%/1.99%) and 705,000 weight injections for MobileNetV3 (0.13% margin). Final D holds 800,000 samples for the ImageNet models and 17,200 for each CIFAR-10 model (Table III).

**Training protocol.** Target CNNs: ResNet-50 (80.86% top-1) and EfficientNetV2-S (84.23%) on ImageNet-1K used as-is from torchvision; MobileNetV3-Small (93.21%), ShuffleNetV2 (95.12%) and MNASNet (91.68%) on CIFAR-10 had their 1,000-way heads replaced by 10-way heads and were retrained 10 epochs. Supervising ANN: 10-fold cross-validation, 80/20 split per fold, BCEWithLogitsLoss, SGD (lr 0.01, momentum 0.9), ReduceLROnPlateau (factor 0.1, patience 5), 50 epochs, batch 512 (ImageNet) / 64 (CIFAR-10). Same hyperparameters for all models — no per-CNN tuning.

**BER simulation.** For 13 BER values (1e-8 to 1e-2), random bits of the target CNN's parameters are flipped according to the BER, and both the unprotected baseline and baseline+ESupNNet (detect → reload parameters → re-infer) process the validation set; 100 simulations per BER.

## Results & Highlights

- **Detection accuracy (10-fold CV):** EfficientNetV2-S on ImageNet-1K reaches 96.42%±0.05 and ResNet-50 96.26%±0.25; CIFAR-10 models get ShuffleNetV2-S 93.99%±0.20, MNASNet 93.59%±0.13, and MobileNetV3 89.73%±0.19 — the only one below the ">90%" headline. A binary random classifier sits at 50% by definition, and ImageNet models clearly beat CIFAR-10 models, which the authors attribute to the richer 1,000-dim class relation R*.
- **AUROC:** EfficientNetV2-S 0.9926±0.0002, ResNet-50 0.9825±0.0011, MNASNet 0.9816±0.0007, ShuffleNetV2-S 0.9806±0.0007, MobileNetV3 0.9619±0.001 — every benchmark above 0.96 vs 0.5 for the random classifier, with tiny std devs across the 10 folds.
- **Operating-point metrics (Table VI):** recall (TPR) 92.31%–95.40%, precision 96.07%–98.41%, FNR 3.60–6.28, FPR 6.75–7.75 across the five models; F2-score — favored because missed errors are costlier than false alarms in high-reliability settings — is above 90% everywhere (best: EfficientNetV2-S 96.70%±0.11; ResNet-50 93.06%±0.30).
- **BER robustness vs baselines (Table VII):** at BER 1e-4, ResNet-50+ESupNNet loses only 1.34 accuracy points (and 0.98 at 1e-8) versus Stegano-ECC's 45.0-point collapse at 1e-4; with the detect-and-reload policy, protected ResNet-50 scores 81.62% vs 80.86% unprotected baseline. For EfficientNetV2-S, ESupNNet degrades only around BER 1e-6, while unprotected CIFAR-10 baselines already degrade near 5e-7. ESupNNet only fails outright when the target CNN outputs NaN/Infinity (out of scope).
- **Overhead comparison:** ESupNNet's parameter overhead is 0.32%–1.13% with NO model modification, versus 31.25% (MobileNetV2/UCMerced) and 31.75% (ResNet-18/NWPU-RESISC45) for NBS [46], ~x3 resources for TMR, and mandatory weight-embedding for Stegano-ECC/Weight Nulling; the paper honestly notes the NBS accuracy-drop numbers are on different datasets, so only the overhead comparison is apples-to-apples.
- **MBU generalization:** despite training exclusively on single-bit SEU data, ESupNNet maintains target accuracy up to BER ≈1e-4 (ResNet-50) / ≈1e-6 (EfficientNetV2-S) in MBU-style multi-flip simulations.

## Authors & Credibility

Jorge Cano-Pié, Luis Entrena, and Almudena Lindoso are with the Department of Electronic Technology, Universidad Carlos III de Madrid (Spain), a group with a long track record in hardware test, fault tolerance, and dependable computing — Entrena and Lindoso have published extensively on fault injection, radiation effects, and hardware security (the reference list cites their community's venues: IEEE Transactions on Nuclear Science, ETTC/IOLTS, DATE, DFT). The work is funded by the Community of Madrid (grant PIPP-2024/TEC-34925) and positioned in the cs.AR/cs.LG arXiv space with comparisons to 2025–2026 IEEE venue papers. The authors are careful about statistical methodology (Cochran-sized injection campaigns, K-fold cross-validation with reported std devs) and candid about cross-work comparison limits, which increases trustworthiness. No prior-code/releases are mentioned, but all target models and datasets are public (torchvision).

## Critical Assessment

- **The missing killer baseline:** the central claim is that a *learned* class-relation model is needed, but the paper never compares against trivial confidence-based detectors — e.g., thresholding max-softmax probability, logit entropy, or logit norm on the same fault-injected data. A bit flip that causes misclassification plausibly distorts logit statistics in ways a one-line heuristic might catch; without this ablation the necessity of the learned R* remains unproven.
- **False-positive cost is real and unquantified:** Table VI shows FPR of 6.75–7.75 across all models — roughly 7 of every 100 *correct* inferences trigger a false alarm. The paper concedes false positives "incur in a cost that might not be negligible" but never measures reload/re-inference latency, energy, or the effective throughput hit of that alarm rate in an embedded setting.
- **Fault-model realism:** parameters are modeled as 16-bit Q6.10 fixed point, and only parameter bits are flipped. Real deployments run FP16/INT8/FP32 with different bit layouts and different critical-bit distributions, and errors can also hit activations/feature maps (the paper itself notes ABFT covers operations but not parameters). Findings may not transfer directly to standard inference stacks.
- **Table VII anomalies go unexplained:** protected "Work" accuracy sometimes *exceeds* the unprotected baseline (MNASNet 96.33 vs 91.68; ResNet-50 81.62 vs 80.86), and the exact mitigation configuration (when reload triggers, what reloads) behind these numbers is not fully specified — making the accuracy-drop columns hard to interpret; negative "drops" (e.g., −17.98 at 1e-6) are presented without comment.
- **Headline vs reality:** the abstract claims "over 90% accuracy", but MobileNetV3 sits at 89.73%±0.19 — a small overclaim.
- **Cross-work comparison is only partially comparable:** NBS results are on UCMerced/NWPU-RESISC45 remote-sensing datasets, not ImageNet-1K/CIFAR-10; the paper admits this, but then Table VII still invites direct accuracy-drop reading.
- **Rigor is genuinely good** where it counts: 10-fold CV with std devs, Cochran-formula-sized injections with ≤2% margins, 100 sims per BER point. The main gaps are ablation (no confidence-baseline, no MBU-in-training variant, no input-expansion ablation beyond a remark) and runtime cost.
- **Reproducibility:** no code or fault-injector release is mentioned; the pipeline is described in enough detail to reimplement, but the custom injector is the crux and is not available.
- **Novelty:** moderate and honest — auxiliary detector networks and logit-statistics monitoring exist in prior art; the contributions are the class-relation framing, the systematic dataset construction, and the breadth of evaluation, not a new learning technique.

## Strengths

- Truly non-intrusive: the target CNN is untouched and treated as a black box — deployable with already-validated torchvision models, unlike TMR/fault-aware training/ECC-embedding alternatives.
- Negligible parameter overhead (0.32%–1.13%) versus ~200% (TMR) or ~31% (NBS), and orthogonal to other protection mechanisms.
- Strong statistical hygiene: Cochran-sized fault campaigns (99% confidence, <2% worst margin), K=10 cross-validation with per-metric std devs, 13-BER × 100-run simulations.
- Evaluated across 5 architectures spanning an order of magnitude in parameter count and 2 datasets of different complexity (1,000 vs 10 classes), with the same hyperparameters for all models.
- A clean generalization result: MBU-induced errors are detected although training data contains only SEUs.
- Full metric transparency (TPR/FNR/TNR/FPR/precision/F1-family/F2/AUROC + ROC curves), not just headline accuracy.

## Limitations

- Detection only — no correction; recovery relies on an assumed reload-and-re-infer policy whose cost (latency, energy, availability) is never measured, and a ~7% false-positive rate would trigger that policy frequently.
- Parameter-only fault model under a 16-bit Q6.10 fixed-point assumption; activation errors, control-flow errors, and modern numeric formats (FP16/INT8) are out of scope.
- Performance degrades for low-dimensional logit inputs (CIFAR-10 models ~89.7–94% vs ~96.3–96.4% for ImageNet models; MobileNetV3 below the 90% mark); the authors conjecture internal-neuron inputs could help but do not test it.
- Supervising-ANN overhead is quantified in parameters only — no inference-time latency/energy measurements on any real platform.
- Comparisons to Stegano-ECC / Weight Nulling / NBS mix datasets and fault settings; the only fully fair axis is resource overhead.
- Image classification CNNs only; no transformers, no other modalities; no code release.

## Relevance

对关注智能系统可靠部署与体系结构（cs.AR/cs.PF）方向而言，这篇给出了一个近零开销、即插即用的CNN软错误检测方案，是高可靠场景（航天、深空、自动驾驶）容错设计的实用参考。它与日常的CV/LLM主线研究关联较弱，但"用辅助小网络监控logit类间结构"的思路对运行时错误/分布漂移检测有借鉴价值。

## Questions for Further Exploration

- How would ESupNNet compare against trivial confidence/entropy-threshold detectors (MSP, logit entropy) on the same fault-injected datasets — is the learned class relation actually necessary?
- What is the end-to-end cost of the ~7% false-positive rate (reload latency, energy, throughput) on an embedded/FPGA platform, and what detection threshold best trades FPR vs FNR per application?
- Does the fault model hold under realistic numeric formats (FP16, INT8 quantized) and do bit positions within the 16-bit word change detection difficulty?
- Would including MBU patterns (or internal-neuron activations) in the training dataset D close the gap between ResNet-50 (robust to BER 1e-4) and EfficientNetV2-S (degrades at 1e-6)?
- Can the approach extend to transformer architectures where the "class relation" lives in a much larger logit/vocabulary space, or to detecting distribution-shift misclassifications rather than hardware faults?
