At p = 0.5, c = 0.9, q = 0.8, G = 64, both execution laws have identical mean reward 0.85 — but independent execution gives −0.078867. Opposite signs: the shared update points away from the true gradient.

B Why this matters

A mechanism alert for agent RL: tool-result caching under GRPO normalization can silently reverse update direction — centering-only estimators are immune.

The first exact counterexample to “fewer physical tool calls ⇒ equivalent training.”

C Critical edge

No LLM is ever trained — the reversal is exact in a two-action toy model, never shown to cause measurable loss in a real GRPO run.

54/540 wrong-direction configurations reflect grid construction, not deployment prevalence.

01 Methodology

2-action banditA → constant c · B → Y~Bern(q) → 2 execution lawsindependent · shared → 2 estimatorsnormalized Uε · centered V → 3-layer verification
  • Model One-parameter policy p = σ(θ): each of G rollouts picks A (deterministic reward c) or B (stochastic tool reward Y, mean μ). True gradient J′(θ) = p(1−p)(μ−c).
  • Laws Independent: each B rollout draws its own Yi. Shared: one Y per group, reused by every B rollout — a per-group cache hit. Both preserve every rollout’s conditional reward marginal; only within-group correlation changes.
  • Estimators GRPO-style group-normalized Uε = (1/G)Σ(ai−p)(ri−r̄)/(sr+ε) versus centered-only V (no std scaling).
  • Analysis Exact, not empirical: conditioning on N ~ Bin(G, p) collapses the shared numerator to hG(N)(Y−c), yielding Theorem 1 in closed form; variance follows by total-variance decomposition.
  • Verify 3,240 exact finite-sum evaluations over a 540-point pre-registered grid; a separately implemented ordered-sequence checker with six deterministic controls; pinned unmodified TVCache (rev 3a4f95a6582e), 256 scripted rollouts, byte-identical triple reruns, public traces.

03 Strengths

  • Closed-form exactness — finite-group update expression, asymptotics, exact finite-G variance; the q=1/2 vs q=c threshold split is crisp and checkable.
  • Textbook verification discipline — pre-registered witness and grid, independently implemented checker, six equality controls, floating-point errors around 10−15.
  • Pinned runtime audit — unmodified TVCache revision with hash-verified sources and byte-identical triple reruns ties the math to real, inspectable infrastructure.
  • Scoping honesty — states precisely what it does not show: no LLM training, no prevalence claim, no refutation of TVCache’s deterministic-output contract.

04 Limitations

  • Toy model — two actions, one decision, fixed policy; no KL, clipping, adaptive optimizers, token-length effects, or multi-turn feedback.
  • No training experiments — no learning curves or accuracy deltas; the “curves” are exhaustive calculations, not learning dynamics.
  • 54/540 is grid construction, not the probability a deployed agent’s stochastic tools fall in the wrong-direction region.
  • Centering fix is incomplete — preserves mean direction only; the update distribution still differs, and convergence is untested.
  • Cache reality out of scope — lifetime, eviction, partial sharing unmodelled; the audit covers one narrow execution path.
  • Provenance — single independent author, LLM-assisted throughout, no external peer review; exactness claims lean on the author’s own checker.

05 Questions for further exploration

  • Does the sign reversal survive end-to-end GRPO — clipping, KL penalties, adaptive optimizers — as measurable accuracy loss on a real agent benchmark?
  • What fraction of real agent workloads’ tool calls are stochastic and group-shared? (The 54/540 grid fraction is explicitly not a prevalence estimate.)
  • Does Dr. GRPO-style de-normalization close the gap in practice, and what convergence-speed cost does its higher gradient variance impose?
  • How do cache lifetime, eviction, and partial sharing interact with the variance floor — can timed cache misses amplify the wrong-direction region in multi-turn settings?
  • Would per-group “draw identity” separation in the cache key restore update equivalence, and at what measured dollar/time cost in physical calls?
