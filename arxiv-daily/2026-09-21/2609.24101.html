Why this matters

On systematically biased corpora, retrieving more actively harms null-effect detection — the stopping policy matters more than retrieval skill for agent reliability.

在系统性偏置的语料上，“检索得更多”不仅无益反而有害——何时停止检索，比如何检索更关键。

Critical edge

Zero-shot Claude with no retrieval at all still scores 67.1% overall — only 2.2 pp below DACG, inside its CI (61–77). The headline win is NoEffect (+18.5 pp) and drift, not overall accuracy.

Methodology how DACG-agent decides to stop

An incremental causal-KG agent over PubMed abstracts whose contribution is not how to retrieve, but when to stop.

retrieve batch→ extract triples→ update KG (noisy-OR)→ score paths (Boltzmann)→ stop?
Theorem 1 · drift envelope
D(t) = Φ(b√t /σ) → 1 as t → ∞

If each retrieved paper reports a positive result w.p. 1/2+b regardless of truth, a vote-counting aggregator's false-Beneficial probability on true nulls rises monotonically with depth t. Simulation transfers the result to the deployed noisy-OR aggregator.

Layer 1 · KL convergence — accuracy

Stop when the label posterior's step change DKL(qt ‖ qt−1) < 0.01. Posterior stabilisation is the signal; its magnitude is poorly calibrated (ECE 0.236). Alone, this layer halves drift to 7.1%.

Layer 2 · PRM decline — efficiency

A Bradley–Terry MLP over 20 graph-state features (88.1% pairwise ranking accuracy) halts when reward drops 0.3 below its running max — cutting a further 14% of steps, drift to 6.4%.

Base machinery

Noisy-OR edge confidence, Boltzmann path scoring (β=1.5), energy functional over explanation subgraphs; NoEvidence (keep searching) is kept distinct from NoEffect (a genuine null).

Strengths

  • A provable negative result: more retrieval → monotone worse on nulls, with simulation evidence it transfers to the deployed noisy-OR aggregator under correlated, heavy-tailed, and asymmetric bias.
  • Clean two-layer ablation with an oracle upper bound (77.1%): KL = accuracy layer, PRM = efficiency layer, each isolated in Table II.
  • Leakage-controlled benchmark: review-paired splits, unambiguity filter, strictly held-out balanced test set.
  • Rare transparency: McNemar tests, bootstrap CIs, a full MeSH grounding audit, and a cross-LLM (glm-4-flash) replication showing drift is not a Claude artefact.
  • Honest Discussion: the competitive zero-shot baseline is explained (pretraining absorbed the bias), and “measured drift is a lower bound” is stated up front.

Limitations

  • Thin margin over no retrieval: 69.3% (CI 61–77) vs zero-shot Claude's 67.1% — +2.2 pp is well inside the noise; only NoEffect and drift wins are established.
  • Small evaluation core: n=140; DACG vs KL-only differs on a single query; oracle ceiling 77.1% clusters all methods in a narrow band.
  • The PRM adds no accuracy on this benchmark (efficiency/drift only) and stops too early on Beneficial queries (77.1% vs 78.6% for KL-only).
  • Missing baseline: no long-context “read all 20 abstracts at once” competitor (E2 uses only 10 abstracts).
  • Theory/practice gap: Theorem 1 analyzes vote-counting; the deployed noisy-OR + Boltzmann aggregator is justified by simulation only.
  • Scope: single benchmark family (Cochrane-derived, 2010–2025 abstracts); 32 Harmful queries excluded; benchmark JSONs / code release not stated.

Questions for further exploration

  1. Do KL+PRM stopping policies transfer to sources with different skew profiles — ClinicalTrials.gov registries, drug labels, non-Cochrane reviews?
  2. Can class-aware or asymmetric PRM thresholds recover the Beneficial accuracy lost to early stopping without giving back drift and efficiency gains?
  3. Is there a closed-form drift bound for the actual noisy-OR + Boltzmann aggregator, or does the vote-counting analysis only loosely bound it?
  4. Since well-grounded (MeSH-mappable) queries drift most, should stopping thresholds be conditioned on entity-grounding confidence?
