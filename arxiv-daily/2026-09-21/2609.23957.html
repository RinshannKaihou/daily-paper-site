Sixteen replicated AI agents converged on the same discovery — and the same defect. Agreement is not independent confirmation.

Divergent strategies and convergent outcomes in autonomous materials discovery

Jihan Kim · KAIST | 16 agents · 1 week · 12,499 MOFs · $280 cap each LLM Agents Autonomous Science Materials Discovery Reproducibility

Key metric

15 /16

agents independently crowned the same audit-excluded artifact as champion material.

Reported 206.7–207.2 cm³ cm⁻³, cross-agent sd 0.12 — ~7 cm³ cm⁻³ above the true frontier, inflated by [B₁₂Cl₁₂]²⁻ anions lost in curation.

Why this matters

Multi-agent consensus is increasingly used as a trust signal. This study shows shared data, tools and priors synchronize errors as fast as they confirm truths.

Critical edge

One unpinned model, one harness, one task, one database — the error rates characterize a single system on one steep, well-mapped landscape; the finding transfers as a concept, not as numbers.

— Critical Assessment

Methodology

02Hide6 artifact entries + audit tool withheld; hidden answer key

04Split8 get 7 enforceable checks, 8 get norms only; blinded
05Scorevs 2,344 reference GCMC runs; analysis frozen pre-read
  • Pinned physics: capacity = GCMC uptake at 65−5.8 bar, 298 K, TraPPE CH₄, rigid UFF, RASPA v2.0.37; claim grade 10k/50k cycles; smoke phase required 3σ reference agreement.
  • Budgets: 1,610 CPU-h each (vs ~22,873 for naive exhaustive screening); spend cap binding for 12/16; isolation by charter, audited via transcripts — not OS boundaries.
  • Emergent design programs: 8 agents voluntarily built 2,253 hypothetical structures — evaluated as behavior evidence, not proposed materials (no relaxation).

File-count contrast dominated by one unchecked agent. Gates moved the calculation layer — not the data-validity layer where the decisive error lived.

  • Truth was also recovered: 11/16 named the same Cu-pts framework; ten high-accuracy runs gave 198.9–200.1 cm³ cm⁻³ vs the independent reference 199.4 ± 1.3. All nine highest reference materials were named by ≥1 agent.
  • Effort didn’t predict success: screening volumes spanned 106–5,006 structures (~50×), yet Spearman ρ = 0.10 (p = 0.77) vs top-ten recovery; one agent got 3/10 with 30 outputs, the largest-footprint agent (12,465) got none.
  • The landscape is steep: median sampled capacity 46 cm³ cm⁻³, only 6% above 150 — a ~200 claim was plausible, but the excluded entry’s 207.2 warranted scrutiny.
  • Design-route caution: the spectacular 75.4 → 203.7 deinterpenetration gain did not replicate under matched controls (+0.5, +9.6, −23.8).

Strengths

  • Genuinely novel evaluation axis: population-level replicated campaigns, cleanly separated from task-success benchmarks (CORE-Bench, PaperBench) — isolating trajectory diversity, conclusion stability and substrate independence.
  • Independent ground truth: 2,344 structures re-measured under the identical pinned protocol — claims scored objectively, not by another LLM.
  • Procedural rigor: public-hash pre-registration, hidden answer key, controller re-ran every headline value from archived inputs.
  • The common-mode-error result is a lasting conceptual contribution — the crispest demonstration to date that inter-agent agreement ≠ independent confirmation when inputs, tools and priors are shared.
  • Radical transparency: transcripts, git histories, charters, rubric and answer key all released (GitHub + Zenodo).

Limitations

  • One unpinned model, one database, one task — no cross-model or cross-domain replication; observed error rates are not transferable.
  • n = 8 per arm: most behavioral contrasts nonsignificant; the pre-registered second wave was never triggered.
  • $280 spend cap binding for 12/16 — “one-week budget” partly reflects token pricing; deadline extensions were non-uniform (up to 24.7 h).
  • Isolation was procedural, not architectural: one real cross-contamination incident occurred (detected, excluded in sensitivity analyses).
  • Single-coder post-hoc strategy taxonomy; reference coverage outside the descriptor tail is only ~16% sampled.

Questions for further exploration

  1. Does the common-mode failure persist with heterogeneous models or harnesses — or when replicas communicate: does communication preserve diversity or synchronize errors?
  2. Can checks target the data-validity layer (blinded chemistry audits validated against known cases) rather than the calculation layer gates already move?
  3. What converts the ten logged warning signs (bare metal centers, disconnected 2D sheets, extreme surrogate residuals) into rejection instead of rationalization?
  4. Does ρ = 0.10 hold on flatter landscapes where verification is expensive — or is cheap GCMC verification what made brute force useless here?
  5. With all transcripts released, can mechanical signals (timing of first champion encounter, residual magnitude, warning-sign logging) yield an online early-warning detector for single-agent runs?
