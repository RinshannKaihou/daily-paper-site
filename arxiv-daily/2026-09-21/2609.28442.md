# Order-Invariant Answers, Order-Sensitive Representations in Mathematical Reasoning

> **一句话总结：** 普林斯顿单人作者预印本构造了一个"规则重排"合成任务（函数链组合题，打乱规则顺序但答案不变），并提出 permutation SNR（按排列模式分组隐藏态的组间/组内方差比）来度量表征对顺序的区分度；在 16 个 1B–8B 指令模型上发现准确率越高的模型对同一答案的不同顺序表征越"分得开"——SNR 与准确率的 Spearman 相关达 0.862/0.729/0.621（三个难度设置），控制模型规模后前两个设置仍显著（偏相关 0.815、0.647），但最难设置降至 0.469（p=0.078，不显著），说明"答案不变 ≠ 表征不变"。

> **TL;DR:** On a synthetic rule-shuffling benchmark (function-composition problems with 100 instances × 50 permutation patterns = 5,000 prompts per setting, three (depth, distractor) configurations), the author computes a "permutation SNR" of mean-pooled hidden states across 16 instruction-tuned 1B–8B models (Qwen2.5, Llama-3, Mistral-7B, Gemma-3, NVIDIA AceMath) and finds a counterintuitive positive correlation between accuracy and order-separability: Spearman ρ = 0.862 in the easiest setting (2,4) and ρ = 0.621 in the hardest (3,4). After partialling out model size, ρ drops to 0.469 (p = 0.078, non-significant) in the hardest setting — so the headline "better models distinguish orderings more" survives size control only in the two easier settings. The paper is a clean but purely correlational 8-page study; read it for the task design and the answer-vs-representation invariance distinction, not for causal claims about reasoning.

## 核心贡献

- **可控的规则重排任务**：构造多步函数组合题（如 F(3)=7, G(7)=−2，求 G(F(3))），附带 m 条同函数符号的干扰链；将 (m+1)·D 条规则行在 50 种共享排列模式下呈现，正确答案严格不变，从而把"顺序"从"内容"中剥离出来。
- **permutation SNR 度量**：对每个模型/层，将 prompt 隐藏态按排列模式分 50 组做均值池化，用组间方差 / 组内方差定义 SNR，再对层取平均，得到每个模型在每个设置下的"顺序可分性"标量。
- **反直觉的跨模型规律**：16 个 1B–8B 模型、3 个设置的层平均 SNR 与准确率全部正相关（Spearman ρ = 0.862 / 0.729 / 0.621，p 分别为 1.7e-5 / 1.3e-3 / 1.0e-2）——解重排题越准的模型，内部对不同顺序的表征区分越明显。
- **区分"答案不变性"与"表征不变性"**：论证答案等价的规则顺序可以在内部被表征为不同簇，为超越 accuracy-only 的数学推理评测提供一个表征视角。
- **诚实的规模控制与局限声明**：用偏 Spearman 相关控制参数量（(2,4) 0.815、(2,7) 0.647 仍显著；(3,4) 0.469、p=0.078 不显著），并明确承认结论是相关性、限于合成任务和有共同谱系的模型。

## Key Contributions

- A controlled **rule-shuffling task**: multi-step function-composition problems (e.g., F(3)=7, G(7)=−2 → G(F(3))) with m distractor chains sharing the same function symbols, presented under 50 shared permutation patterns per setting while the correct answer is held strictly fixed — cleanly isolating rule order from problem content.
- **Permutation SNR**, a representation statistic: for each model and layer, mean-pool prompt hidden states into 50 permutation-pattern clusters and take the ratio of between-cluster to within-cluster variation, then average over layers to yield one order-separability scalar per model per setting.
- A **counterintuitive cross-model regularity**: across 16 instruction-tuned 1B–8B models and all three synthetic settings, layer-averaged permutation SNR is positively rank-correlated with accuracy (Spearman ρ = 0.862 / 0.729 / 0.621, p = 1.7e-5 / 1.3e-3 / 1.0e-2) — models that solve reordered problems more accurately represent the different orderings MORE distinctly, not less.
- An explicit conceptual distinction between **answer invariance** (same correct output under equivalent reorderings) and **representation invariance** (identical internal encoding), arguing that successful rule composition can coexist with order-separated representations.
- Honest **size control and limitations**: partial Spearman correlations controlling for ranked parameter count stay significant in the two-step settings (0.815, p = 2.13e-4; 0.647, p = 9.11e-3) but fall to 0.469 (p = 0.078, not significant) in the three-step setting; the paper explicitly labels its evidence as correlational, synthetic-only, and confounded by shared model ancestry.

## Methodology

**Task construction.** Each problem defines a relevant chain f_1(a_0)=a_1, …, f_D(a_{D−1})=a_D of numerical function mappings (composition depth D) plus m distractor chains using the same function symbols with disjoint values at each stage (sampled uniformly from −100..100), guaranteeing a unique valid path from the queried input to the answer. The (m+1)·D rule lines are arranged in a reference order (queried chain first), and 49 additional distinct non-reference permutations are sampled uniformly, forming a bank of P = 50 shared permutation patterns that is applied identically to all 100 problem instances per setting — so each permutation group contains exactly the same 100 problems, differing only in rule order. Three settings are used: (D, m) ∈ {(2,4), (2,7), (3,4)}, giving 5,000 prompts per setting.

**Models and accuracy.** 16 instruction-tuned models spanning 1B–8B parameters: six Qwen2.5 variants (base Instruct 1.5B/3B/7B, Coder 1.5B/7B, Math 1.5B/7B), Llama-3.2-1B/3B and Llama-3.1-8B, Mistral-7B-Instruct-v0.3, Gemma-3-1B-it, and NVIDIA AceInstruct-1.5B/7B and AceMath-1.5B/7B. One sampled response per prompt; accuracy is exact-match of the extracted numeric answer, averaged over all instances and orderings. Prompts use a fixed system message enforcing an "Answer: X" format; models receive their own chat template.

**Permutation SNR.** Hidden states are extracted in a separate no-generation forward pass; at each layer the representations of non-padding prompt tokens are mean-pooled to one vector h_{i,p}^{(ℓ)} per problem instance i under permutation p. Cluster centers μ_p are averaged within each permutation group; SNR^(ℓ) = (1/P)Σ‖μ_p − μ‖² / [(1/PT)Σ‖h_{i,p} − μ_p‖² + ε] (between-cluster / within-cluster variation, ε = 1e−8). SNR is averaged over the embedding output and all transformer layers to give one value per model per setting. Spearman correlation between accuracy and layer-averaged SNR is computed across the 16 models within each setting; Appendix C adds a partial Spearman controlling for ranked parameter count (regressing out size from both accuracy and SNR residuals).

## Results & Highlights

- **Positive SNR–accuracy correlation in all three settings**: Spearman ρ = 0.862 (p = 1.7e-5) for (D,m) = (2,4), ρ = 0.729 (p = 1.3e-3) for (2,7), and ρ = 0.621 (p = 1.0e-2) for (3,4), each computed across the same 16 models (n = 16 points per correlation). No baseline is involved — the "comparison" is across models, where the top of the accuracy range (~0.9+) in the (2,4) panel coincides with the highest permutation SNR (~0.25+) while low-accuracy models cluster near SNR ≈ 0.13–0.15.
- **Size control weakens but mostly preserves the effect**: partial Spearman controlling for model size is 0.815 (p = 2.13e-4) in (2,4) and 0.647 (p = 9.11e-3) in (2,7), but drops to 0.469 (p = 0.078) in (3,4) — statistically inconclusive at the 0.05 level, which the author flags explicitly rather than hiding.
- **The counterintuitive direction**: one might expect order-invariant (accurate) models to internally collapse equivalent orderings into similar representations; instead, representations grouped by the same ordering pattern are MORE separated relative to within-group variation in higher-accuracy models — answer invariance and representation invariance come apart.
- **Scale of evidence**: 16 models × 3 settings × 5,000 prompts = 240,000 graded generations plus per-layer hidden-state extraction, with all prompts, permutation sampling, and answer-extraction details specified in the appendix for reproduction.

## Authors & Credibility

Single author: **Zhixu Silvia Tao**, Operations Research and Financial Engineering, Princeton University. This is a solo preprint (marked "Preprint", not yet peer-reviewed) from a quantitative-methods department rather than an NLP/ML lab, which shows in both good and limiting ways: the statistical treatment (rank correlations, partial correlation for size, explicit p-values, honest inconclusiveness in one setting) is careful and unusually candid for the genre, but there is no evidence of collaboration with an interpretability group and no released code/artifacts mentioned in the paper. The experimental discipline (shared permutation banks, fixed prompts, exact-match scoring, full model list) is solid for a short paper.

## Critical Assessment

- **n = 16 models is a very small cross-sectional sample, with heavy phylogenetic non-independence.** Six of the 16 models are Qwen2.5 variants and four are NVIDIA Ace models (themselves Qwen-derived lineages); a Spearman correlation over effectively ~5–6 independent model families is far weaker evidence than "ρ = 0.86, p = 1.7e-5" suggests, because those p-values assume independent points. The author acknowledges shared ancestry in Appendix C but takes no correction (e.g., family-level averaging or phylogenetic mixed models).
- **The size control is crude and partially undercuts the headline.** Partialling out only ranked parameter count leaves the three-step setting at ρ = 0.469, p = 0.078 — the author honestly calls this "inconclusive," but a skeptic can read the whole result as "bigger/better-trained models are better at both reasoning and everything else," i.e., a generic capability factor rather than something specific to order representations. There is no control for training-data specialization (AceMath vs AceInstruct pairs would be a natural contrast and is not analyzed).
- **Purely correlational, no interventions.** No steering, no ablation of order-encoding directions, no probing decodability check — the paper cannot distinguish "order-separable representations support reasoning" from "order separation is a harmless byproduct of sharper representations generally." The limitations section admits this, but it caps the significance of the finding.
- **The task is far from natural mathematical reasoning.** Numerical function-composition with 6–24 rule lines is a clean instrument, but permutation SNR on it may just reflect positional-embedding robustness; there is no experiment on GSM8K/MATH-style problems or any natural benchmark where order varies, so external validity is untested.
- **The bespoke SNR statistic is never validated.** There is no sanity check against a known case (e.g., a model or prompt variant where order should NOT matter, or a negative control with shuffled labels) showing SNR behaves as expected; ε, mean-pooling over the full prompt (including system instructions, which are constant across permutations — this dilutes but does not bias the measure), and layer averaging are all unverifiable choices without released code.
- **Accuracy protocol ambiguity**: "one sampled response per prompt" with decoding details deferred to the appendix introduces sampling noise into one of the two correlated quantities; no seed variance or CIs on accuracy are reported.

## Strengths

- Clean, answer-invariant-by-construction task design: the permutation bank is shared across all instances, so between-cluster variation is attributable to order alone, with distractor chains preventing trivial copy-through.
- The core finding is genuinely counterintuitive and conceptually useful — it decomposes "robustness" into answer invariance vs representation invariance and shows they dissociate.
- Unusually honest statistics for a short paper: p-values reported throughout, the non-significant size-adjusted result in (3,4) is foregrounded rather than buried, and the limitations paragraph is accurate.
- Full reproducibility detail in appendices: complete model list, prompt templates, permutation sampling procedure, representation-extraction protocol (32-bit floats, no-generation pass, ε = 1e−8).
- Broad model coverage for the parameter class (5 families, general/code/math specializations), making the within-class contrasts (e.g., Qwen2.5 vs Qwen2.5-Math) possible for future work.

## Limitations

- Correlational only; no causal evidence that order-separated representations improve (or harm) reasoning.
- Confined to synthetic function-composition tasks; no natural math benchmarks (GSM8K, MATH, FolIO-style) and no transfer experiment.
- 16 models, all 1B–8B, with overlapping ancestry (Qwen2.5 ×6, NVIDIA Ace ×4); no frontier-scale or base (non-instruct) models, so scale trends beyond 8B are unknown.
- Size adjustment via ranked parameter count only; the three-step setting loses significance (partial ρ = 0.469, p = 0.078), and shared training lineage is not adjusted.
- Permutation SNR is a new, unvalidated statistic: no negative controls, no confidence intervals over the 100 instances, no comparison to alternative separability measures (e.g., CKA, linear-probe accuracy on order labels).
- Single sampled response per prompt for accuracy without variance estimates; no code or data release stated in the paper.

## Relevance

这篇论文直接命中"LLM 数学推理 + 内部表征几何"的交叉兴趣：它用极轻量的 SNR 统计量化了表征对输入顺序的敏感性，并与准确率建立起可复现的跨模型关联。对关注推理鲁棒性、顺序敏感性和机制可解释性的后续工作来说，这是一个低成本可复用的探针范式（同时也提醒我们控制模型谱系的重要性）。

## Questions for Further Exploration

- Does the accuracy–SNR association survive family-level aggregation or a phylogenetic mixed model over the Qwen/Llama/Mistral/Gemma/Ace lineages, or is it an artifact of shared ancestry?
- Can a causal intervention (e.g., ablating or amplifying the order-separation subspace via steering) change reordered-problem accuracy, converting this correlation into a mechanism claim?
- Does permutation SNR predict accuracy or robustness on natural math benchmarks (GSM8K, MATH) when premises are reordered, i.e., does the synthetic finding transfer?
- How does SNR evolve with scale beyond 8B and with chain-of-thought prompting — does letting the model externalize the chain reduce the order-separability of prompt representations?
- Is high permutation SNR beneficial, harmful, or neutral for OOD generalization — e.g., do order-separated models degrade more under distribution shift in rule format?
