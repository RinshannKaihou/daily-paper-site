> **一句话总结：** 提出 WhatWorkedBench 基准：让 AI 智能体在预算受限的实验中检查工作流代码、自主选购测量、然后提交覆盖全部配置的完整响应面预测表，用穷举 CPU 执行作为真值参照；在 36 个任务条件（30 个数据源、8 类工作流）上发现"选对最优配置"与"理解成分效应"是两回事——同一批 DeepSeek Flash 智能体观测数据换用高斯过程推断即可把效应恢复率从 0.632 提到 0.698（追加队列 0.621→0.720），而给智能体看工作流代码反而略微变差（−0.024/−0.064）。

> **TL;DR:** WhatWorkedBench evaluates "experimental understanding": after a budgeted experiment on workflows with 4 or 6 binary options (36 task conditions, 30 sources, 8 families, 1248 exhaustively executed configurations), the agent must submit a predicted score for every configuration. The exhaustive reference reveals pervasive sign reversals (35/36 conditions contain a component whose effect flips sign across backgrounds), so single-configuration success does not imply understanding. On six matched four-factor sources, deepseek-v4-flash at B=8 doubles its family-macro effect recovery from 0.178 (B=4) to 0.632, but refitting a Gaussian process on the same agent-chosen observations reaches 0.698 (additional cohort 0.621→0.720) — better than GP with its own acquisition (0.640) and ridge on designed observations (0.669) — showing measurement selection, not inference, is the agent bottleneck. Encoding code-derived equivalence classes lifts GP recovery 0.248→0.462 at B=20, and an opaque view without workflow code slightly beats full code (−0.024/−0.064 shared-GP delta), a striking negative result about code comprehension.

## 核心贡献

- **可执行的"实验理解"评测目标**：不同于只看最优配置得分的既有基准，本工作要求智能体提交覆盖全部 2^d 个配置的完整响应面预测，并用穷举原生执行（1248 条配置记录）提供每个成分条件效应的真值，评分指标为归一化效应恢复率 R_i、严格重构分数（所有效应误差 ≤ 响应范围的 10%）与最优配置选择（regret ≤ 10^-12）。
- **36 任务条件 × 8 工作流族的目录**：覆盖分类、回归、聚类、预测、图像修复、检索（SciFact/ArguAna NDCG@10）、心拍检测（MIT-BIH event F1）、链路预测（ROC AUC）；35/36 个条件存在符号翻转（背景改变使同一开关的效果由正变负），24/36 在 5% 响应范围阈值下仍保留翻转——这让"死记一个最优配置"的策略必然失败。
- **共享推断协议（关键方法论创新）**：固定智能体买到的观测集合，只替换估计器（岭回归 / 高斯过程 / 码等价类约束），从而把"测量选择"与"数值推断"两个因子解耦，首次可以归因智能体实验能力的短板到底在哪一环。
- **程序结构信息的三组对照**：(a) 完整代码 vs 不透明视图；(b) 从代码派生的"无效参数等价类"编码；(c) 结构诊断（先要求报告非激活规则再实验）——共同揭示智能体"能识别规则却不会应用规则"的落差：8 个诊断回合全部正确报告规则、却全部在最终表格中违反规则，注入规则使平均恢复率 0.247→0.429，事后投影到等价类达 0.338→0.507。
- **大规模确定性评测基建**：4206 条数值控制记录、108 个核心智能体回合、6 个新增族完整提交；参照可在单线程 127.87 秒内完整重放，冷重放哈希校验 + 独立实现的度量双重复核。

## Key Contributions

- An executable definition of experimental understanding: the deliverable is a complete predicted response surface over all configurations, graded against exhaustive native CPU execution (1248 configuration records across 36 conditions from 30 sources and 8 workflow families), via effect recovery R_i, a strict reconstruction criterion (every conditional-effect error within 10% of response range), exact configuration choice, and selection regret.
- A catalog engineered to defeat memorization: 35 of 36 conditions contain at least one component whose effect reverses sign across backgrounds (24/36 remain reversals at a 5%-of-range floor), with 3,392 conditional effects and 342 mean pair interactions exported as flat tables.
- A shared-inference protocol that holds the agent's purchased observations fixed and swaps only the estimator, cleanly separating measurement selection (acquisition) from numerical inference — the paper's central analytic instrument.
- Three program-structure manipulations (full code vs opaque view; code-derived equivalence classes for inactive parameters; a first-call rule-reporting diagnostic) exposing a recognition–application gap: in all 8 diagnostic episodes every agent correctly reported the inactive-option rules yet all 8 final tables violated them; supplying rules raises mean recovery 0.247→0.429 and post-hoc class projection raises 0.338→0.507.
- Strong reproducibility infrastructure: the reference replays all 1248 records in 127.87 s on one thread, a standalone engine reproduces 4,206 stored numerical-control records, and scoring is cross-checked by independently implemented native metrics and target perturbation.

## Methodology

**Task formalism.** Each task condition t has a deterministic utility u_t(z) ∈ [0,1] over binary masks z ∈ {0,1}^{d_t} (d_t ∈ {4,6}); each bit is a documented component option (e.g., TF-IDF vs raw counts, ridge α=1 vs 10, median vs Gaussian denoising). The agent receives two free anchor measurements (u_t(0^d), u_t(1^d)), may purchase at most B additional distinct measurements in batches, and must submit a finite prediction û_t(z) for every legal mask. Native outcomes are cached by the evaluator, so repeated queries give identical feedback and over-budget requests are rejected.

**Reference and metrics.** Exhaustive CPU execution supplies the full response surface. The conditional effect of component i at background z is Δ_i(z) = u_i(z+e_i) − u_i(z); its error E_i is the mean absolute deviation over all backgrounds, and recovery is R_i = max(0, 1 − E_i/A_i) with A_i the mean true effect magnitude. The strict score requires every effect error ≤ max(10^-12, τ·(max u_i − min u_i)) with development tolerance τ = 0.1; exact choice requires regret ≤ 10^-12. Because complete conditional effects plus one anchor determine the entire surface (a path-decomposition identity), a configuration-choice counterexample (Appendix F.2) proves exact choice and effect recovery are distinct targets. Scores use family-macro averaging (repetitions → source → family, families equally weighted); sensitivity is checked with tolerance profiles (2.5–40%), native-unit rescoring, and per-source omission ranges.

**Estimators and policies.** Numerical controls: main-effect ridge (D1), sequential pair-effect ridge design+fit (D2), random designs (20 seeds), and Gaussian processes with leave-one-out-selected hyperparameters under two acquisition rules — grid predictive variance (GP-G) and effect-contrast variance (GP-E). Program-equivalence controls map masks to representatives whenever workflow code makes an option inactive (e.g., polynomial features ignored when the degree-2 bit is off), verified against native prediction hashes. The shared-inference protocol refits D1/D2/GP on exactly the observations an agent purchased, holding the observation set fixed.

**Agent studies.** Agents are deepseek-v4-flash and deepseek-v4-pro with four tools (current evidence, batched observe, sandboxed Python with 30 CPU s / 45 wall s per call, submit), 32,768-token output cap, 1,800-second session deadline, public NumPy/SciPy/scikit-learn helpers ridge_main and ridge_pair. The 108-episode core covers four-factor tasks at B ∈ {4,8} in two dated cohorts (original: 24 episodes, 75 HTTP 429 responses logged; additional: 42 episodes); a six-factor information study (36 episodes, B=20) contrasts full workflow code with an opaque view; a structure diagnostic (8 episodes) asks agents to report inactive-option rules before buying; six complete B=32 Flash submissions cover added beat-detection and link-prediction families. Analysis order, prompts, and cohort chronology are frozen and disclosed (Appendix J).

## Results & Highlights

- **Interaction structure is pervasive (the benchmark's teeth).** At a 10^-12 floor, 35/36 task conditions contain a component whose effect reverses sign across backgrounds; 33/36, 24/36, and 16/36 retain reversals at 1%, 5%, and 10% of the response range. Worked example (SciFact, NDCG@10): sublinear TF raises retrieval by +0.160 under raw counts but changes it by −0.084 under binary counts (interaction −0.245), while both contexts rank identically at 0.544 — so no single-configuration heuristic can recover the effect table.
- **Budget dominates; delivered agent quality is mediocre.** On six matched four-factor sources (Table 2), Flash recovery rises 0.178 (B=4) → 0.632 (B=8) in the original cohort and 0.375 → 0.621 in the additional cohort; Pro rises 0.043 → 0.366 and 0.308 → 0.503. Across all 18 Flash B=8 episodes only 7 pick an exact optimum and 1 passes strict reconstruction; the pair-effect design/ridge control scores 0.627 on the same six sources.
- **Inference, not acquisition, is the agent's weakness (shared inference).** Refitting a GP on the same agent observations raises Flash original B=8 from 0.632 to 0.698 (+0.066) and additional from 0.621 to 0.720 (+0.099); Pro moves 0.366→0.692 and 0.503→0.667. These exceed ridge on D2-designed observations (0.669 / D2 fit 0.550–0.670) and GP with its own effect-variance acquisition (0.640), and every source-omission mean gain stays positive (+0.021 to +0.096). Against a naive mean-completion baseline on the same observations (0.287), agents' 0.632 confirms they add real information — 67.4% of graded effects involve unmeasured configurations.
- **Numerical design controls (22 four-factor sources, B=8).** Effect-variance GP reaches 0.701 family-macro recovery with 16/22 exact choices vs pair-effect ridge's 0.612 with 15 exact and 3 strict reconstructions (GP: 1). GP wins on mean recovery; pair ridge wins on worst-case error (passes 1/1/8/20 of 22 sources at 2.5/5/10/40% tolerances). Native-unit rescoring preserves ordering (0.633 vs 0.712).
- **Program structure multiplies measurement value.** Encoding inactive-parameter equivalence classes across six six-factor workflows lifts pair-ridge recovery 0.157→0.389 and effect-GP 0.248→0.462 at B=20 (+0.214); at B=32, 0.445→0.650 and 0.537→0.697. All four sources with nontrivial classes improve; two identity controls are unchanged. On the added beat-detection/link-prediction families (six Flash B=32 submissions), shared GP lifts family-macro recovery 0.303→0.455 (numerical controls: D2 0.230, grid GP 0.414, effect GP 0.404).
- **Two negative/surprising findings.** (1) Hiding the workflow code slightly helps: full−opaque delivered differences are −0.024 (original) and −0.064 (additional) under shared GP, with an additional-cohort source-macro difference of −0.120 among the 8 pairs with two valid artifacts. (2) Recognition ≠ application: in all 8 structure-diagnostic episodes agents correctly reported every registered inactive-option rule before measuring, yet all 8 final tables (built with the public ridge helpers) violated them; injecting rules lifts arm-mean recovery 0.247→0.429 and post-hoc projection reaches 0.507 while lowering raw effect error in all eight runs.

## Authors & Credibility

Jingjie Ning (Carnegie Mellon University, corresponding author), Xueqi Li and Yibo Kong (CMU), and Dongting Li (Tsinghua University). The first author anchors a prolific line of work on auditing AI research agents — Auto Research with Specialist Agents, Auto Research for Materials, Closed-loop Auto Research for Molecular Property Prediction, the Implementation Lottery study, the Discovery Certification Protocol, SkillLearnBench, and DeepResearchGym all appear in the references from the same group — so this benchmark is a deliberate next brick in a coherent research program, with deep familiarity for what earlier evaluations miss. Technical hygiene is exceptional: cold-replay hash checks, independently reimplemented native metrics and target-perturbation checks, single-thread 127.87 s full-reference replay, frozen prompts, dated API cohorts with per-episode HTTP-429 accounting, and an explicit AI-use statement (an AI coding assistant contributed; DeepSeek models served as the evaluated agents). The main credibility caveat is independence: the evaluation ecosystem, its prior-work framing, and the compared baselines largely originate from the same group, and all evaluated agents come from a single provider (DeepSeek).

## Critical Assessment

- **Single-provider, two-model evaluation.** All 108 core episodes use deepseek-v4-flash or deepseek-v4-pro; no GPT-, Claude-, Gemini-, or open-weights-class agent is tested, so the headline conclusions ("acquisition is the bottleneck," "code access does not help") are claims about one model family at one point in time. Worse, the provider changed Flash routing mid-study (footnote 1: the legacy Flash alias serves V4.1 Flash during the additional cohort), and the original cohort logged 75 HTTP 429 responses plus five Pro deadline failures — the original-vs-additional cohort gaps (e.g., Pro 0.043→0.308 at B=4) partly reflect infrastructure and model-version drift, which the authors honestly quarantine by never pooling cohorts, but which still caps how much the two cohorts can corroborate each other.
- **The central agent comparison rests on six sources.** Table 2 and the shared-inference analysis use six matched four-factor sources; the six-factor evidence is either utility-only (information study) or just six completed B=32 episodes on the added families. Paired deltas like +0.066 shared-GP gain come with per-source omission ranges of +0.021…+0.096 — consistently positive but small-N, and no significance testing is offered anywhere.
- **Scale ceiling inherent to the methodology.** Exhaustive reference execution is what makes the ground truth unimpeachable, but it confines tasks to d ≤ 6 binary options; real experimental understanding involves continuous hyperparameters, larger option spaces, and stochastic simulators where 2^d enumeration is impossible. The benchmark is best read as a low-dimensional Boolean reconstruction probe, and the paper does not demonstrate (or seriously discuss) any scaling path.
- **The intriguing "code hurts" result is underpowered.** The full-vs-opaque comparison has 12 original and 24 additional attempted pairs, of which only 8 additional pairs have two valid artifacts; per-source deltas swing wildly (astronaut +0.039 to −0.249 delivered), so the −0.024/−0.064 means are fragile. The paper reports this carefully but the headline phrasing risks being over-read.
- **Author-defined metrics and thresholds.** Recovery R_i, the τ=0.1 strict tolerance (a "development" choice), and family-macro weighting are all authorial decisions; the tolerance profile, native-unit sensitivity, and per-source omission analyses largely defuse the concern, but there is no human-expert baseline to anchor what "good" recovery means.
- **Ecosystem self-reference.** The related-work positioning, several baselines' design philosophy, and the auditing tradition all trace to the authors' own prior benchmarks; independent replication of the catalog and scoring by an outside group would strengthen trust.

## Strengths

- Ground truth you can actually trust: exhaustive native execution of all 1248 configurations, hash-verified cold replay, independently implemented scoring metrics, and a 127.87-second single-thread reproduction of the entire reference — reproducibility engineering far above benchmark norms.
- The shared-inference protocol is a genuinely novel and cleanly identified evaluation axis: holding observations fixed while swapping estimators turns "is the agent bad at measuring or bad at inferring?" into a measurable question, with a crisp answer (inference).
- The catalog's pervasive sign reversals (35/36 conditions) give the benchmark real discriminative power against configuration-memorizing agents, and the F.2 counterexample proves exact-choice and effect-recovery are separable targets.
- Unusually honest reporting: negative results (opaque ≥ full code; agents violating rules they can recite), HTTP-429 and deadline accounting per episode, cohort separation after a mid-study provider routing change, and a disclosed analysis order separating retrospective from inspection-first evaluations.
- Complete artifact release: frozen prompts, versioned episode semantics, flat 3,392-effect tables, and machine-readable audits make the benchmark usable by other researchers immediately.

## Limitations

- Task spaces are capped at 4–6 binary options so exhaustive reference stays feasible; extension to continuous or high-dimensional design spaces is unaddressed and non-trivial (the enabling trick does not scale).
- Only two DeepSeek models, one provider, one snapshot in time; cohort comparisons are confounded by documented API instability (75 HTTP 429s, five Pro deadline failures, a Flash routing change) despite careful bookkeeping.
- Core agent conclusions derive from six matched four-factor sources and a handful of six-factor episodes; no statistical significance testing, no human-expert reference point.
- The "workflow code does not help" finding rests on small, heterogeneous paired samples and an opaque-view prompt that may simply be easier to use rather than code being useless.
- Utility normalization to [0,1] and the τ=0.1 strict tolerance are author-set conventions; recovery numbers are not comparable outside this framework.
- Deterministic utilities (frozen seeds, cached native execution) exclude stochastic-experiment regimes that dominate real science.

## Relevance

该工作与你对 AI agent 能力评测、自动化科研/实验流程的兴趣高度契合：它给出了一个可复现、反作弊（符号翻转设计）的"实验理解"基准，并用共享推断协议把智能体短板精确定位在"测量选择后的数值推断"与"代码规则的识别-应用落差"上，而非实验设计本身——这两个结论对设计更强的研究型 agent 有直接指导意义。

## Questions for Further Exploration

- Can the exhaustive-reference methodology be extended to continuous hyperparameters or d > 10 via sparse Fourier/ANOVA sampling of the Boolean cube while preserving exact effect verification?
- Do frontier multi-provider models (GPT-5/Claude/Gemini class) close the delivered-vs-shared-GP gap (0.632 vs 0.698), or is weak inference a fundamental LLM-agent limitation rather than a model-scale issue?
- Why does access to workflow code hurt recovery — prompt overload, distractor structure, or lack of code-grounded priors — and could symbolic execution of the workflow automatically derive the equivalence classes the agents fail to apply?
- Can the recognition–application gap be closed architecturally, e.g., a tool that projects submitted tables onto measured equivalence classes at delivery time (the post-hoc projection already lifts 0.338→0.507 for free)?
- How do acquisition rankings (pair ridge vs effect-variance GP) transfer to stochastic simulators, where the deterministic native reference and cached-measurement semantics no longer hold?
