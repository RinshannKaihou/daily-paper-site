> **一句话总结：** 该工作将认知心理学中的"现实监控"(reality monitoring)范式移植到 LLM 上，发现 LLM 区分"自己生成的"与"外部提供的"信息的能力并非模型固有属性，而随对话记忆结构变化：单轮任务下对自生成内容达到天花板准确率，一旦引入情景延迟就反转为外部项目优势；纠正反馈在部分模型上引发内部/外部判断互换或准确率提升但置信度与正确性脱钩，揭示了现有基准无法捕捉的安全隐患。

> **TL;DR:** This paper adapts the human cognitive-psychology "reality monitoring" (RM) paradigm — distinguishing self-generated from externally-provided information — to six LLMs (Gemma3 12B/27B ± QAT, Llama3.3 70B, Llama4 16x17B) using a word-pair task with materials from a validated human RM dataset (Deese-Roediger-McDermott lists). Across two experiments, internally generated items reached 100% attribution accuracy under single-turn memory but reversed to an external-item advantage (perceived M=66.42% vs imagined M=47.57%) under episodic delay; corrective feedback produced qualitatively distinct failure modes (e.g., Llama3.3:70b's d' improved to 2.28 while Type 2 AUC collapsed below chance to 0.34; Gemma3:12b's d' inverted to −0.95), dissociations invisible to standard calibration benchmarks. The pattern implicates active expert-network size rather than aggregate parameter count, arguing that source-memory evaluation is essential for multi-turn/agentic deployment.

## 核心贡献

- **首次将人类"现实监控"(reality monitoring)范式系统性移植到 LLM**：用与人类实验相同的词对材料(DRDM 列表)，构建可直接进行人–LLM 对比的源归因测试，填补了"对话记忆作为被操纵变量"这一研究空白。先前 AI 源识别工作主要依赖外部机制(如水印)，而非探测模型内在的自归因能力。
- **揭示源归因是记忆结构的函数而非模型固有属性**：单轮记忆下自生成内容准确率达 100% 天花板，引入情景延迟后反转为外部项目优势(perceived 66.42% vs imagined 47.57%)，证明"最小负载下的表现会高估真实多轮能力"。
- **发现纠正反馈引发的两种新型失效模式**：Llama3.3:70b 在反馈下准确率(d')提升但元认知敏感度(Type 2 AUC)跌破随机水平(0.34)；Gemma3:12b 出现系统性的源响应反转(d' = −0.95)。这些准确率/置信度脱钩现象无法被现有校准基准检测。
- **识别出"阅读幻觉"(reading hallucination)作为独立的编码瓶颈**：模型无法逐字复现外部提供的词，是源误归因的最强预测因子(Exp.1: b=−3.84, p<.001)；反馈与更大集合反而放大该幻觉(Exp.2: 反馈 OR=3.72)，意味着反馈循环可能放大其本想减少的幻觉。
- **挑战"规模即能力"的假设**：最大模型 Llama4:16x17b 在多项指标上与更小模型相当，提示混合专家(MoE)架构中"单个专家网络规模"才是源归因的有效缩放变量，而非总参数量。

## Key Contributions

- **First systematic adaptation of human reality monitoring (RM) to LLMs**, using the same word-pair materials (Deese-Roediger-McDermott lists) from a validated human RM paradigm, enabling direct human–LLM comparison and isolating conversational memory as an experimental variable — a gap unaddressed by prior AI source-identification work that relied on external mechanisms like watermarking.
- **Demonstrates that source attribution is a function of memory structure, not an invariant model property**: internally generated items hit 100% ceiling under single-turn memory but reversed to an external-item advantage (perceived M=66.42% vs imagined M=47.57%) once episodic delay was introduced, showing that minimal-load performance overestimates real multi-turn capacity.
- **Identifies two novel feedback-induced failure modes**: Llama3.3:70b improved in source discrimination (d'=2.28) while its metacognitive sensitivity (Type 2 AUC) collapsed below chance (0.34); Gemma3:12b showed systematic response inversion (d'=−0.95). These accuracy/confidence dissociations are invisible to existing calibration benchmarks.
- **Isolates "reading hallucination" (failure to reproduce the externally supplied word) as a distinct upstream encoding bottleneck**, the strongest predictor of source misattribution in Exp.1 (b=−3.84, p<.001); feedback and larger set sizes amplified it (Exp.2 feedback OR=3.72), implying feedback loops can amplify the very hallucinations they aim to reduce.
- **Challenges "scale equals capability"**: the largest model, Llama4:16x17b, performed comparably to smaller models across several measures, implicating individual expert-network size within mixture-of-experts architectures over aggregate parameter count.

## Methodology

**Paradigm.** The authors adapt the Johnson–Raye reality-monitoring framework: a word-pair task where the second word is either externally provided (perceived/external) or generated by the model (imagined/internal), and the model must later attribute the source. Stimuli come from 36 Deese-Roediger-McDermott false-memory lists used in a prior human RM study (enabling direct human comparison). Each trial has four subtasks: word-pair completion, semantic relatedness rating (0–100), source judgment (internal/external), and confidence rating (1–6).

**Models.** Six instruction-tuned models via Ollama: Gemma3:12b, Gemma3:12b-QAT, Gemma3:27b, Gemma3:27b-QAT, Llama3.3:70b, and Llama4:16x17b (sparse MoE). Temperature fixed at 0 (greedy decoding); other parameters at Ollama defaults. No persona/role framing beyond the task.

**Three conversational-memory architectures.**
- *Single-Turn* (Exp.1): all four subtasks in one interaction, fresh context per trial.
- *Trial-Chain* (Exp.1): the same four subtasks distributed across four sequential turns, history retained.
- *Episodic-Chain* (Exp.2): all encoding trials completed as a block before a separate, delayed source-test phase; set size (20 vs. 40) and corrective feedback (absent vs. present) crossed in a 2×2 design (source type is a within-trial factor). Each encoding-to-test sequence is one "trace" (the random-effects clustering unit), yielding 200 traces per cell.

**Tooling.** Custom open-source PsychScanner (v0.1) Python package; trials serialized as JSON to avoid format-driven artifacts; response-option order counterbalanced as a covariate.

**Statistics.** Exp.1: logistic regression, OLS, ordered probit, Goodman–Kruskal γ (Fisher-Z) for metacognitive sensitivity; N=3,456 trials (1,728 perceived). Exp.2: GLMMs (binomial, logit) with random intercept for trace, LMMs for γ, Cumulative Link Model for confidence; Type-II Wald χ², emmeans with Bonferroni; N=72,000 test-phase observations across 4,800 traces. Signal-detection measures (d', criterion c, Type 2 AUC) computed per trace. Sensitivity analyses re-fit with model as a crossed random intercept to confirm fixed-effect inferences; all primary results replicated.

## Results & Highlights

- **Ceiling internal-item accuracy under single-turn memory (Exp.1)**: internally generated items were identified with **100% accuracy** across all six models and both implementations, because the generated word remained in the active context window — making imagined-item identification trivially retrievable rather than genuinely inferential.
- **Reading hallucination is the dominant predictor of source failure (Exp.1)**: on N=1,728 perceived trials, reading hallucination was the strongest predictor of source misattribution (b=−3.84, p<.001; pseudo R²=.474). Conditional on no reading hallucination, predicted accuracy was near ceiling (90.9% for Gemma3:12b, the lowest model; 95.2%–99.7% for others).
- **Source reversal under episodic delay (Exp.2)**: no model reached ceiling. Mean accuracy (N=4,800 traces/source) was **perceived M=66.42% (range 27.80%–97.20%) vs imagined M=47.57% (range 3.00%–89.60%)** — a reversal of the Exp.1 advantage. The reversal was most pronounced without feedback (perceived 76.34% vs imagined 38.46%); feedback nearly closed the gap (56.50% vs 56.68%).
- **Source × feedback interaction (Exp.2 GLMM, N=72,000)**: perceived items attributed more accurately than imagined (χ²(1)=2594.9, p<.001; OR=2.57, 95% CI [2.48, 2.66]); the source × feedback interaction was pronounced (χ²(1)=2734.1, p<.001) — feedback improved imagined-item accuracy while increasing reading hallucinations on perceived trials.
- **Feedback amplifies reading hallucinations (Exp.2)**: hallucinations increased with set size (OR=1.56, p<.001) and feedback exposure (OR=3.72, p<.001), amplified jointly (set size × feedback χ²(1)=19.8, p<.001). Llama3.3:70b (OR=0.002) and Llama4:16x17b (OR=0.15) showed dramatically suppressed hallucinations; Gemma3:12b-QAT hallucinated at higher odds than its non-QAT counterpart (OR=2.64), reversing the Exp.1 pattern.
- **Type 1/Type 2 dissociation under feedback**: in Exp.2 without feedback most models showed d'≈0 (near-chance discrimination despite above-chance mean accuracy); Llama3.3:70b was an exception (d'=2.01±0.11 at set size 20). Under feedback, **Llama3.3:70b's d' improved to 2.28±0.04 while Type 2 AUC fell below chance (0.34±0.02)**; **Gemma3:12b's d' turned negative (−0.95±0.02)**, reflecting systematic response inversion rather than degraded discrimination.
- **Confidence decouples from accuracy under episodic load (Exp.2)**: in the Cumulative Link Model, model identity dominated confidence (χ²(5)=17,620.6, p<.001; OR spread 0.44–17.85, a 40-fold range), but trial-level accuracy did not predict confidence after controls (b=0.03, p=.063). The trace-level robustness test confirmed a null overall (+0.001 points, t(4518)=0.11, p=.91), concealing two small opposite-signed effects: +0.06 without feedback vs −0.06 with feedback (both p<.001).
- **Metacognitive sensitivity degraded by feedback and load (Exp.2 LMM)**: perceived items showed higher sensitivity than imagined (contrast=4.28, SE=0.12, p<.001); feedback decreased sensitivity (b=−3.22, F(1,∞)=30.4, p<.001), amplified at larger set size (set size × feedback F(1,∞)=7.80, p=.005).
- **Scale does not predict self-knowledge**: the largest model Llama4:16x17b performed comparably to smaller models across several measures, implicating active expert-network size over aggregate parameter count.

## Critical Assessment

- **Novelty**: Genuinely novel framing. Applying Johnson–Raye reality monitoring — a well-validated human source-memory paradigm — to LLMs with shared DRDM word-pair stimuli is a fresh angle that prior AI metacognition/introspection work had not pursued. Treating conversational-memory architecture as the manipulated independent variable (rather than a fixed property) is a clean experimental contribution.
- **Rigor**: Strong statistical treatment (GLMMs, CLM, signal-detection d'/Type 2 AUC, random intercepts for trace, sensitivity analyses replicating across optimizers and random-effects specifications). Sample sizes are large (3,456 trials in Exp.1; 72,000 test observations / 4,800 traces in Exp.2). The authors are commendably explicit about statistical pathologies — they flag Gemma3:27b-QAT's quasi-complete separation and the CLM convergence failure that forced a fixed-effects-only confidence model, rather than hiding them.
- **Reproducibility**: High. Open code, open data, open stimulus materials, open PsychScanner tool, fixed temperature=0, JSON-serialized trials, counterbalanced option order. The main reproducibility caveat is that all models are instruction-tuned variants run via Ollama at default context-length/top-p settings, so the specific Ollama build could affect exact numbers.
- **Significance**: Practically important for agentic deployment. The headline finding — that single-turn accuracy is an unreliable proxy for multi-turn source attribution, and that feedback can invert source mappings or decouple confidence from correctness — is a concrete, deployable safety concern that standard calibration benchmarks (which test knowledge/reasoning accuracy–confidence) structurally cannot detect.
- **Red flags / weaknesses**:
  - **Minimal paradigm with limited ecological validity**: the word-pair task is deliberately stripped-down; the authors themselves flag that generalization to richer deployment sources (prior context turns, retrieved documents, tool outputs, factual content) remains open. The very mechanism that drives ceiling performance in Exp.1 (the generated word still sits in the context window) means Exp.1's "ceiling" is partly an artifact of the minimal paradigm rather than evidence of strong RM.
  - **Scale conclusion is under-powered for the claim**: the central claim that "active expert-network size, not aggregate parameters, drives source attribution" rests on a single MoE model (Llama4:16x17b) being compared against a small handful of dense models. Inferring a scaling law from n=1 MoE is a stretch; the authors acknowledge this is "directly testable across a broader range" but still headline it.
  - **Quasi-complete separation in Gemma3:27b-QAT** undermines interpretation of one of the six models in the headline accuracy analysis.
  - **Relatedness effect reverses the human pattern** (relatedness protects verbatim reproduction in LLMs rather than manufacturing false memories as in humans) — the authors honestly note this, but it slightly undercuts the "direct human–LLM comparison" framing the paper leans on.
  - **Single decoding setting and single feedback modality**: temperature fixed at 0 and only a right/wrong feedback label (uninformative about *why* an answer was wrong); the authors admit this may explain why feedback shifted confidence without sharpening it, leaving alternative-feedback-modality effects untested.

## Strengths

- Clean experimental design that isolates conversational memory as a manipulated variable — rare in LLM evaluation work.
- Direct human comparability via shared DRDM stimuli and the Johnson–Raye framework, grounding findings in cognitive-science theory.
- Two qualitatively distinct, deployment-relevant failure modes (Type 1/Type 2 dissociation in Llama3.3:70b; response inversion in Gemma3:12b) that no existing calibration benchmark would surface.
- Honest, detailed statistical reporting with openly flagged pathologies and full sensitivity analyses.
- Fully open artifacts (code, data, stimuli, PsychScanner tool) and disclosed AI-assistance in writing.
- Insightful mechanistic interpretation tying results to the competing-biases account (Kumaran et al.) and human calibration research.

## Limitations

- **Minimal word-pair paradigm**: low ecological validity relative to real agentic sources (retrieved documents, tool outputs, prior turns); the ceiling effect in Exp.1 is partly a paradigm artifact.
- **Narrow model coverage**: six models from two families (Gemma 3, Llama), all instruction-tuned via Ollama, so tuning and architecture effects are confounded; the MoE-scaling claim rests on a single MoE model.
- **Behavioral-only**: no activation-level interpretability to explain *why* feedback inverts source mappings or why confidence decouples from accuracy — left to future work.
- **Single decoding setting** (temperature=0, framework defaults) and a **single feedback form** (right/wrong label); alternative temperatures, presentation orders, and feedback modalities (delayed, partial, confidence-targeted) are untested.
- **~54% of metacognitive-γ observations excluded** due to ceiling/floor accuracy or invariant confidence (4,410 of 9,600 computable), though exclusions were not concentrated in one cell.
- The human–LLM comparison is qualitative (different designs and trial counts), limiting the strength of cross-species claims.

## Relevance

对关注 LLM 自我认知、元认知与幻觉机制的研究者高度相关：该论文提供了一个可直接落地的源记忆评测范式与开放工具(PsychScanner)，并指出"对话记忆结构"和"专家网络规模"是影响 LLM 自我知识的关键变量——这对多轮 Agent 的可信度评估、置信度校准与安全监控具有直接参考价值。同时其"反馈可能放大幻觉并使置信度脱钩"的发现，对设计带人类反馈的 Agent 系统是重要警示。

## Questions for Further Exploration

- How do these source-attribution and confidence-decoupling effects transfer to richer, deployment-realistic sources (retrieved documents, tool outputs, prior assistant turns) beyond minimal word pairs?
- Is "active expert-network size" truly the operative scaling variable? Testing across a broader range of MoE architectures (varying expert count vs. expert size independently) would settle the headline scaling claim.
- What activation-level mechanism causes Gemma3:12b's systematic response inversion and Llama3.3:70b's d'/Type-2-AUC dissociation under feedback? Interpretability probes at the activation level could localize these failure modes.
- Do alternative feedback modalities (delayed, partial, confidence-targeted, explanation-bearing) preserve or repair the accuracy–confidence link that binary right/wrong feedback erodes?
- Can a source-memory probe like this be integrated as a runtime safety metric in deployed multi-turn agents, and does it predict downstream errors (e.g., treating confabulations as user-supplied facts) better than surface accuracy?
- Does sampling temperature and presentation order modulate the reversal and inversion effects observed at temperature=0?
