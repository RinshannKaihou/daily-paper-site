> **一句话总结：** 论文提出 FEGA（特征效应几何分析）框架，通过在多上下文中消融同一 SAE 特征并分析其引起的 logit 变化云的几何结构，发现在 Gemma-2-2B 上 65k 宽度的三种 SAE 变体中"一致的一维效应很罕见"——与静态事实绑定的 value-like 特征更常呈现低维（但跨多方向）结构，而与上下文相关操作绑定的 pointer-like 特征则主要是弥散的，说明一个特征可以是可解释且因果重要的，却不提供稳定的操控方向。

> **TL;DR:** The authors introduce Feature-Effect Geometry Analysis (FEGA), an unsupervised method that ablates the same active SAE feature across contexts and classifies the resulting cloud of downstream logit changes. Applied to Gemma-2-2B with ReLU, TopK, and Matryoshka Batch TopK SAEs (width 65k) across five tasks (LSC, WC, PrOntoQA, Token Translation, RAVEL city-country), they find that directed rays are rare: among the 80 mapped pointer-like features only 3 form directed rays, and among value-like RAVEL features only 5/12,900 ReLU, 14/2,828 TopK, and 6/3,654 Matryoshka features are directed rays. Joint ablation of just 9 TopK Word-Content features crashes task accuracy from 100% to 18.4% (p < 10⁻³⁰⁰) versus 93.6% ± 4.0 for matched random controls, confirming causal relevance — yet these causally important features still fail to yield stable one-dimensional steering directions.

## 核心贡献

- **提出 FEGA 框架：** 首个在 logit 效应空间（而非特征激活空间或模型内部几何）刻画 SAE 特征几何性质的无监督诊断框架，把同一特征的干预效应视为一个"云"，而非单一的操控向量。
- **区分 value-like 与 pointer-like 特征角色：** 借用编程语义中的"值 vs 指针"类比，将绑定静态预训练信息（如事实属性）的特征与绑定上下文相关操作（如复制、绑定、规则跟随）的特征区分开，并证明两者在下游几何上系统性不同。
- **实证反驳"一个特征 = 一个稳定方向"的假设：** 在 ReLU/TopK/Matryoshka Batch TopK 三种架构上，一致的一维（directed ray）效应都很罕见；这是对 SAE 操控（steering）可靠性的直接经验性质疑。
- **构建可分离的任务谱系用于特征分离：** 用 5 个任务（LSC、WC、PrOntoQA、Token Translation、RAVEL city-country）从纯合成的 prompt-local 操作跨越到事实属性检索，并配套了特征筛选、跨任务重叠、消融与几何分析的全流程。
- **完整开源：** 代码发布在 https://github.com/UKPLab/FEGA ，便于复现与扩展。

## Key Contributions

- **Introduces FEGA, the first framework for characterizing SAE feature geometry in the downstream logit-effect space** rather than in the activation/concept space where features are computed. It treats each feature's intervention effects as an empirical cloud and assigns one of six geometry families (directed ray, axis/antipodal, directional mixture, global k-D span, centered residual low-D, unresolved diffuse) via a fixed-priority cascade.
- **Establishes a value-like vs. pointer-like taxonomy of feature roles**, borrowing the programming value/pointer analogy: value-like features are tied to context-agnostic static information (e.g., the country of Paris), pointer-like features support context-dependent operations (copying, binding, rule-following) whose output target changes with the prompt.
- **Empirically demonstrates that one-dimensional effects are the exception, not the rule.** Across all three SAE variants and the full task spectrum, directed rays are rare even for features that are causally necessary for task performance.
- **Provides a complete measurement pipeline**: feature isolation (RAVEL differential binary masking for value-like; 90%-prevalence thresholds for pointer-like), cross-task overlap (IoU), causal ablation with matched random controls, and a battery of geometry diagnostics with guardrails against spurious low-rank claims.
- **Releases code and a reproducible evaluation harness** built on the SAEBench Gemma-2-2B suite (Karvonen et al., 2025).

## Methodology

**Base model and SAEs.** All experiments use Gemma-2-2B (Gemma Team, 2024) with SAEs applied to the post-layer-12 residual stream. Three SAE variants from the SAEBench suite are compared — ReLU (Bricken et al., 2023), TopK (Gao et al., 2025), and Matryoshka Batch TopK (Bussmann et al., 2025) — all of width 2¹⁶ ≈ 65k, to ensure conclusions are not artifacts of a single sparsity mechanism.

**Task spectrum (50,000 ICL examples each, balanced across 1,000 prompt families).**
- *Literal Sequence Copying (LSC)* and *Word Content (WC)* — purely synthetic pointer-like tasks using random tokens (Niu et al., 2025).
- *PrOntoQA* (Saparov & He, 2023) — fictional predicates, prompt-local rule completion (pointer-like).
- *Token Translation (TT)* — hybrid: prompt-local schema + pretrained lexical knowledge.
- *RAVEL city-country* (Huang et al., 2024) — factual attribute disentanglement, the value-like endpoint.

**Feature isolation.** Value-like features come from RAVEL's differential binary masking (Chaudhary & Geiger, 2024) via SAEBench; pointer-like features are those active on ≥90% of examples and on ≥90% queries in ≥90% of prompt families at the final pre-prediction token.

**Reconstruction-relative intervention.** For feature j in context c, the baseline is the SAE reconstruction h̄ℓ, and the ablated reconstruction is ĥℓ,j↓ = D(z − zⱼeⱼ). Both are propagated through the frozen model tail and unembedding W_U to produce the per-context removal effect Δ_j = φ(ĥℓ,j↓) − φ(h̄ℓ). This design avoids confounding feature removal with SAE reconstruction error.

**FEGA diagnostics.** Each feature's effect cloud {Δ_j} is decomposed into magnitude and unit-normalized direction. A shared directional kernel K_j captures pairwise direction agreement, and a cascade of tests (in fixed priority order) assigns a primary label:
1. *Directed-ray concentration* C_ray (mean off-diagonal signed similarity).
2. *Axis/antipodal structure* (leading dual-PCA eigenvector + axis-split fraction B_axis).
3. *Directional mixture* (von Mises-Fisher mixture with BIC model selection, coherence gain Δ_mix).
4. *Global k-D span spectrum* (S_span, U_span, D_span for k ∈ {2,3,4,8}).
5. *Centered residual spectrum* (mean-subtracted spectrum with residual-energy gate E_res).
Secondary flags (magnitude heterogeneity CV_m, long-tail spectrum, family-specific leave-out stability) qualify — but never override — the primary label. An efficient pre-logit Gram trick (G = W_U⊤W_U) avoids materializing vocabulary-sized vectors.

## Results & Highlights

- **Causal relevance of small pointer-like sets (Table 2).** Jointly ablating the selected features drops accuracy in all 12 task-architecture combinations, with effect sizes from a 4.3pp drop (ReLU, LSC, k=5: 95.7% vs random control 98.3% ± 0.4) to an 82.1pp drop (Matryoshka Batch TopK, PrOntoQA, k=20: 17.9% vs random control 92.1% ± 4.6; p < 10⁻³⁰⁰). For TopK Word Content, ablating just k=9 features crashes accuracy from 100% to 18.4% (p < 10⁻³⁰⁰), while matched-size random controls hold 93.6% ± 4.0.
- **Value-like sets are large; pointer-like sets are tiny (Table 1).** RAVEL differential masking selects 12,900 ReLU / 2,828 TopK / 3,654 Matryoshka features, whereas pointer-like ICL tasks select only 4–78 features each (e.g., LSC: 5/5/4; PrOntoQA: 78/22/20 for ReLU/TopK/Matryoshka).
- **Cross-task overlap is architecture-dependent (Figure 2).** TopK LSC↔WC IoU = 0.40; Matryoshka WC↔TT IoU = 0.36 and WC↔PrOntoQA IoU = 0.31; ReLU peaks at only 0.13 (WC↔PrOntoQA). Critically, **none** of the ICL-selected features overlaps with the RAVEL value-like set in any architecture — pointer-like and value-like populations are disjoint.
- **Pointer-like features are overwhelmingly diffuse (Table 4).** Of the 239 selected pointer-like features across all tasks/architectures, 159 have undefined geometry; among the 80 with mapped geometry, 74 are unresolved high-dimensional/diffuse, only 3 form directed rays, and only 3 occupy global low-dimensional subspaces.
- **Value-like features are more structured but still rarely rays (Table 5).** Among the geometry-eligible RAVEL features, the combined structured categories (G-kD, residual-lowD, 1D-diffuse, G-2D) cover 1,078/7,715 ReLU (14.0%), 424/1,167 TopK (36.3%), and 530/1,750 Matryoshka (30.3%). Directed rays remain rare: 5 ReLU, 14 TopK, and 6 Matryoshka features. Undefined geometry dominates for ReLU (4,760/7,715) but is much smaller for TopK (441/1,167) and Matryoshka (759/1,750).

## Critical Assessment

- **Novelty** is genuine and well-scoped: prior SAE-geometry work (Hindupur et al., 2025; Bhalla et al., 2026) studies the *input/representation* side, and prior steering-fragility work (Wu et al., 2025; Arad et al., 2025; Korznikov et al., 2026) documents failures without a geometric characterization of *why*. FEGA fills that gap by characterizing the downstream logit-effect cloud. The value/pointer analogy is a useful and memorable organizing frame, though it is presented as an interpretive lens rather than a formally derived theory.
- **Rigor** is a real strength: the reconstruction-relative baseline (comparing against h̄, not the raw activation h) correctly de-confounds feature removal from SAE reconstruction error — a subtlety many steering papers miss. The matched random controls on ablation are appropriate and the statistics are reported with p-values.
- **Reproducibility** is high: a single public model (Gemma-2-2B), public SAEs from SAEBench, defined selection thresholds, and a public repo. The 50,000-example / 1,000-family sampling design is well-motivated for separating prompt-local from incidental features.
- **Significance** is a qualified but real contribution: it sharpens a widely held but under-tested assumption (a feature = a steering direction) and provides a concrete tool. The finding that pointer-like features are causally essential yet geometrically diffuse is the most actionable result for steering practitioners.
- **Weak points and potential red flags:**
  - *Scale generalization is unproven.* Everything runs on Gemma-2-2B at one layer (post-12) at one width (65k). The authors flag this themselves, but it materially limits the strength of any general claim that "consistent one-dimensional effects are rare" — they are rare *in this one configuration*. A 7B or 9B checkpoint (the paper even cites GemmaScope-9b-SAEs in a footnote) would have substantially strengthened the claims.
  - *The "directed ray" definition is strict* (signed mean off-diagonal kernel similarity), and the authors acknowledge that a high C_ray is sufficient but a low C_ray is ambiguous (could be antipodal, mixture, or diffuse). The cascade then relies on downstream tests that themselves have many free gates and thresholds (e.g., vMF mixture π_r ≥ 0.10, BIC model selection, residual-energy thresholds). Appendix H reportedly fixes these, but the main text leaves the impression that label assignment depends on a fair number of hand-set reporting gates rather than universally calibrated constants — a potential source of cherry-picking risk that is only partially mitigated.
  - *Large "undefined" and "insufficient evidence" buckets.* For ReLU RAVEL, 4,760/7,715 eligible features are "undefined" and 5,185/12,900 selected features lack sufficient effect evidence. The headline percentages (e.g., "14.0% structured") are therefore computed over a heavily filtered subset, and the authors are careful not to extrapolate — but readers could easily over-read the bars in Figure 6.
  - *No steering-accuracy validation.* FEGA predicts that diffuse features should be bad for static steering, but the paper does not run the closing experiment: does assigning a "directed ray" label actually predict better downstream steering performance than a "diffuse" label? Without that, FEGA remains a descriptive diagnostic whose practical payoff is asserted rather than demonstrated.
  - *Single measurement site (final logit readout).* A feature with diffuse logit effects might have a clean low-dimensional local perturbation near the SAE site; the authors note this but do not test it. A multi-layer FEGA sweep would have addressed the "where does it disperse?" question they raise.

## Strengths

- Conceptually clean and novel reframing: studying *effect* geometry rather than *feature* geometry.
- The reconstruction-relative intervention is methodologically careful and correctly avoids the SAE-reconstruction-error confound.
- Strong, statistically significant causal-ablation controls (matched random sets, exact McNemar, 20-trial t-tests).
- The value-like vs. pointer-like taxonomy is intuitive and well-motivated by a concrete task spectrum spanning synthetic to factual.
- Honest, self-aware limitations section; the authors explicitly state their claims hold only over the retained context sample and do not extrapolate to undefined features.
- Open-source code and full reliance on public benchmarks (SAEBench, RAVEL) make the work reproducible.

## Limitations

- Single model (Gemma-2-2B), single SAE site (post-layer-12), single width (65k); scale dependence is acknowledged but untested.
- Task spectrum is deliberately structured/synthetic; naturalistic generation (chain-of-thought, multi-step reasoning) where value- and pointer-like roles interact is left to future work.
- Conclusions are conditional on the feature-selection rules and on at most 64 retained active contexts per feature; features failing the evidence gate are excluded from the geometry distribution, so the headline label proportions describe a filtered subset.
- Many thresholds in the geometry cascade (vMF π_r, BIC, residual energy, span sufficiency) are reporting gates rather than universal constants, creating a mild risk of label-assignment sensitivity to hyperparameters.
- No direct validation that FEGA labels predict steering utility, so the practical "so what for steering?" remains asserted rather than measured.
- Measurements are taken only at the final logit readout, which aggregates all downstream transformations; the layer at which a localized effect disperses is not identified.

## Relevance

对从事稀疏自编码器（SAE）可解释性与模型操控（steering）研究的读者高度相关：FEGA 直接量化了"特征是否提供稳定的操控方向"，为基于特征的可解释性、可操控性与可审计性提供了新的下游效应层诊断工具，与日常关注的 mechanistic interpretability、特征几何、因果干预与 LLM 可控生成主题紧密契合。

## Questions for Further Exploration

- Does an FEGA "directed ray" label actually predict better downstream steering success (e.g., on SAEBench steering or Spurious-Correlation Removal benchmarks) than a "diffuse" label? This closing validation is missing.
- How do the geometry-label distributions shift with model scale (Gemma-2-9B), SAE width (16k → 1M), and SAE site (different residual-stream layers)? Does diffuse geometry remain dominant for pointer-like features at 9B?
- Applying FEGA at successive layers: at which depth does a localized, low-dimensional feature effect disperse into a high-dimensional vocabulary-level cloud?
- Can the pointer-like vs. value-like distinction be turned into a training signal (e.g., an auxiliary loss) that produces SAEs whose features have more stable effect geometry and therefore better steerability?
- Do FEGA labels generalize to naturalistic, multi-step generation where prompt-local operations and factual retrieval interact within the same computation?
- Is the strict directed-ray criterion (signed mean kernel similarity) too harsh? How do results change under an unsigned axis-only or subspace-only primary label?
- How sensitive are the headline label proportions to the cascade thresholds (vMF π_r ≥ 0.10, residual-energy gates) — a sensitivity/ablation over the reporting gates themselves would strengthen reproducibility claims.
