> **一句话总结：** RecursiveECG 将 LLM 定位为"离线模型设计者"而非在线分类器，通过把临床 ECG 诊断准则编译成可执行测量函数、对失败案例与对照案例做证据驱动的对比诊断，递归地修改分类器代码，在 PTB-XL/Georgia/CPSC2018 上平均相对提升约 10% 的 Macro F1，且最终模型无需 LLM 推理即可部署。

> **TL;DR:** RecursiveECG is an evidence-driven "LLM-as-Designer" framework that recursively refines 12-lead ECG classifiers: it compiles curated clinical criteria into validated deterministic measurement functions, runs contrastive failure review over failed vs. correctly-classified cases using raw waveforms + measurements + model outputs, and only retains code revisions backed by case-level evidence. Across PTB-XL, Georgia, and CPSC2018 it beats the strongest baselines (MERL, xLSTM-ECG, Argos) with Macro F1 relative gains of +5.56%, +8.56%, and +15.81% respectively (10.0% average), while the deployed classifier is frozen and needs no LLM at inference time.

## 核心贡献

- **提出 LLM-as-Designer 范式（区别于 LLM-as-Classifier）**：LLM 作为离线控制器递归地修改分类器的代码实现，最终产出一个冻结的、可在无 LLM 推理下部署的可追溯分类器，并附带把每次修改链接到支撑证据的审计轨迹。
- **Criteria-to-Measurement Compilation (CMC)**：把专家定义的 ECG 诊断准则（如"PR > 200ms 提示一度房室阻滞"）形式化为 `(诊断概念, 测量目标, 判读条件)`，由 LLM 生成并通过功能验证子集校验的确定性测量函数，输出可复现、带参考文献的结构化测量值。
- **Evidence-Grounded Failure Review (EGFR)**：通过失败驱动案例选择、证据构造（原始波形 + 真值标签 + 预测概率 + 准则测量值）、以及与临床证据谱可比的正确分类参照案例做批级对比诊断，定位分类器的系统性局限而非个案错误。
- **固定问题契约下的闭环验证**：标签空间、数据划分、评估协议和泄露约束全程固定；候选修订只有在程序成功执行且验证集性能提升时才被采纳，防止知识漂移。
- **跨三个基准的稳健验证**：PTB-XL、Georgia、CPSC2018 上始终优于深度模型、预训练模型和智能体基线，并通过消融、迁移、细粒度标签和案例研究验证了各机制的有效性。

## Key Contributions

- **Formulates ECG model development as an evidence-driven LLM-as-Designer problem**, where an offline LLM agent uses failure evidence to recursively refine a deployable, traceable classifier — explicitly contrasted with the per-sample LLM-as-Classifier paradigm (which is costly and hallucination-prone).
- **Criteria-to-Measurement Compilation (CMC)** converts curated clinical ECG criteria into validated, deterministic measurement functions with an evidence-binding mechanism (each function carries a reference path/section pointer), producing reproducible reference-backed measurements rather than implicit latent features.
- **Evidence-Grounded Failure Review (EGFR)** performs targeted failure-batch selection, evidence construction, and contrastive diagnosis against correctly-classified reference cases with comparable clinical profiles — isolating systematic classifier limitations instead of idiosyncratic errors.
- **A fixed problem contract and governed candidate promotion** ensure the held-out test set stays inaccessible during refinement; only revisions that execute successfully and improve validation performance are retained, and every accepted update is recorded in a refinement history linking code change to motivating limitation.
- **Comprehensive empirical validation** across PTB-XL, Georgia, CPSC2018, plus ablations, transfer studies, fine-grained label analysis, and an efficiency trade-off study showing the discovered classifiers are not just more accurate but also lighter.

## Methodology

RecursiveECG is built on three stages operating inside a fixed problem contract (label space, data split, evaluation protocol, leakage constraints held constant; test set used only once for final evaluation).

1. **Criteria-to-Measurement Compilation.** Expert ECG diagnostic criteria are formalized as `c = (d, m, τ)` — diagnostic concept, target measurement, interpretive condition (e.g., `(first-degree AV block, PR interval, PR > 200ms)`). The LLM agent generates an executable measurement function `g_c` under a compilation instruction; because execution is deterministic, the same ECG always yields the same measurements. Each function is validated on a representative subset `V_c` checking execution correctness and measurement reliability, with feedback `η_c` returned for correction until tests pass. Validated functions form a reusable measurement library `G = {g_c}`. An evidence-binding mechanism requires each compiled function to carry a reference path/section pointer and emits an "unsupported/indeterminate" status rather than a speculative judgment when reference material or waveform quality is insufficient — preventing knowledge drift across iterations.

2. **Evidence-Grounded Failure Review.** (a) *Failure-driven case selection*: rather than reviewing all validation failures, the agent constructs a targeted failure batch `B_θ⁻` prioritizing labels and error modes that substantially influence validation performance. (b) *Evidence construction*: for each recording the evidence is `E_i = (X_i, y_i, p̂_i, ŷ_i, Z_i)` — raw waveform, ground truth, label-wise prediction probabilities, and criterion-grounded measurements. (c) *Contrastive diagnosis*: a reference retrieval procedure `R(·)` retrieves correctly-classified cases `B_θ⁺` whose clinical evidence profiles are comparable to the failure batch; the agent performs batch-level contrastive diagnosis `ℓ = A_φ(E(B_θ⁻), E(B_θ⁺); ρ_diag)` to identify the failure pattern and corresponding classifier limitation.

3. **Diagnostic Classifier Revision.** Conditioned on the diagnosed limitation `ℓ`, the LLM generates a code-level revision `r = A_φ(P_θ, ℓ; ρ_rev)` — an executable modification to the current implementation (architecture + training procedure), not a natural-language recommendation. The revised program `P_θ' = Apply(P_θ, r)` is instantiated and trained on the fixed training set. A revision is admissible only when its program executes successfully and satisfies predefined constraints; among admissible revisions a candidate is retained when `M(f_θ', D_val) > M(f_θ, D_val)`. Accepted revisions are logged in a refinement history `H ← H ∪ {(ℓ, r, M_before, M_after)}`. Termination occurs when no admissible improvement is found or the refinement budget is exhausted. The final predictor is frozen and requires no LLM inference at deployment.

The default backbone LLM is DeepSeek-V4-Pro, with candidate count k=3 and max iteration count 5; Qwen3.5-27B is used in a backbone-sensitivity study. Code is released at https://github.com/neumyor/RecursiveECG.

## Results & Highlights

All numbers are mean ± std over five runs; relative improvements are the best RecursiveECG variant over the strongest non-RecursiveECG baseline.

- **PTB-XL (Table 1):** Macro F1 rises to **0.7653** (RecursiveECG, DeepSeek-V4-Pro) vs. **0.7250** for the strongest baseline xLSTM-ECG — a **+5.56% relative Macro F1 gain**; Macro AUC reaches **0.9373** vs. **0.9130** (+2.66%); Hamming Acc. **0.8929** vs. **0.8705** (+4.74% over... note MERL was 0.8561, xLSTM 0.8705).
- **Georgia (Table 1):** Macro F1 **0.8826** vs. **0.8130** (MERL) — a **+8.56% relative Macro F1 gain**; Micro F1 **0.9170** vs. **0.8426** (MERL, +8.83%); Macro AUC **0.9814** vs. **0.9693** (+1.25%).
- **CPSC2018 (Table 1):** Macro F1 **0.8027** vs. **0.6931** (MERL) — a **+15.81% relative Macro F1 gain**; Micro F1 **0.8352** vs. **0.7459** (+11.97%); Macro AUC **0.9746** vs. **0.9016** (xLSTM-ECG, +8.10%). Average relative Macro F1 improvement across the three datasets is **10.0%**.
- **Effectiveness–efficiency trade-off (Fig. 4):** RecursiveECG achieves superior predictive effectiveness with **10.6% fewer parameters than xLSTM-ECG**, **90.5% fewer FLOPs than UniTS**, and **65.8% lower peak memory than MERL** — gains do not come from added model complexity.
- **Fine-grained label gains over the strongest baseline (Fig. 7):** On PTB-XL/CPSC2018 absolute Macro F1 improvements reach **NST_ +55.1%**, **ISCA +46.7%**, **PAC +32.6%**, **STE +24.1%**, **SB +14.6%**, **AF +9.1%** (percentage points); gains concentrate on diagnoses with explicit, clinically interpretable ECG patterns.
- **Dataset-adaptive transfer (Fig. 8):** The PTB-XL-evolved architecture transferred to Georgia/CPSC2018 already reaches Macro F1 **0.8368 / 0.7011** (94.8% / 87.3% of full target-evolved performance); target-specific evolution adds **+0.0458 / +0.1016** Macro F1, reaching **0.8826 / 0.8027**.
- **Ablation (Fig. 5):** Removing EGFR (metric-driven only) drops PTB-XL Macro AUC from 0.9373 to 0.9149; the Direct-LLM-Design variant (no EGFR, no iterative refinement) stays competitive but still trails the full framework, showing LLM design knowledge alone is insufficient without evidence-grounded refinement.
- **Backbone robustness:** Using Qwen3.5-27B instead of DeepSeek-V4-Pro remains competitive across all three datasets, indicating the evidence-grounded paradigm is not tied to a single LLM.

## Critical Assessment

- **Novelty:** The core move — recasting LLM-as-Classifier into LLM-as-Designer for ECG, with criteria compiled into deterministic measurement functions and contrastive failure review — is genuinely novel and well-motivated. The WPW-pseudo-infarction motivating example (Fig. 1) is concrete and clinically plausible.
- **Rigor:** Results are reported as mean ± std over five runs with a held-out test set kept inaccessible during refinement — a methodologically clean protocol. The ablations (w/o EGFR, w/o CMC, w/o Measurement Exec., Direct LLM Design) isolate the contribution of each mechanism rather than reporting only end-to-end numbers.
- **Weak baselines / comparisons to scrutinize:** The "Argos" baseline is an agentic *time-series anomaly-detection* method, not an ECG *diagnostic classification* method — it is a somewhat ill-fitting agentic comparator (its PTB-XL Macro F1 std of ±0.1196 suggests instability). The strongest genuine classifier competitors are MERL and xLSTM-ECG; the headline 10.0% "average relative improvement" averages across datasets/metrics and is dominated by the very large CPSC2018 gains (+15.81% Macro F1), so readers should weight per-dataset numbers rather than the aggregate. Efficiency is reported in FLOPs/params but the *total compute cost of the refinement loop itself* (repeated LLM calls + 5 candidate retrains per iteration × 5 iterations) is not quantified, which matters for fair comparison against single-training baselines.
- **Reproducibility:** Code is released; measurement functions are deterministic and reference-backed; the problem contract is frozen. However, the default backbone is "DeepSeek-V4-Pro" with "Qwen3.5-27B" as the alternative — these are forward-dated model identifiers whose exact capabilities/availability may shift, so exact reproduction of the LLM-driven revision trajectory is contingent on those models. The "±5 runs" for agentic methods re-executes the entire design trajectory each run, which is the right thing to do, but the variance contribution from LLM nondeterminism vs. training randomness is not decomposed.
- **Significance:** High for the intersection of self-evolving agents and medical time-series; the evidence-binding mechanism (reference path + section pointer per measurement function, "indeterminate" status on insufficient evidence) is a transferable design pattern for grounding agentic refinement in auditable domain knowledge.
- **Red flags:** The paper itself states it has "only been evaluated retrospectively and is not intended for autonomous diagnosis or clinical deployment without external clinician oversight" — an honest and appropriate caveat, but it means no prospective/clinical validation exists. The curated criteria corpus could inject clinical bias, acknowledged but not audited empirically.

## Strengths

- Clean separation of LLM-as-Designer (offline, frozen output) vs. LLM-as-Classifier (online, costly), with deployment requiring zero LLM inference.
- Deterministic, reference-backed measurement functions provide genuinely audtable evidence rather than opaque latent features; the "indeterminate status" fallback is a thoughtful safety mechanism.
- Contrastive failure review (failed batch vs. comparable correctly-classified batch) is the right epistemological move to distinguish systematic limitations from idiosyncratic errors.
- Strong, consistent gains across three independent benchmarks, with well-controlled variance and a backbone-sensitivity check.
- Open-source code and a real clinician co-author lend credibility to the clinical-criteria curation.
- The model-design evolution trajectory (Fig. 6: unified 12-lead ResNet → chest/limb lead separation → cross-lead + temporal attention) shows the agent discovers interpretable, ECG-specific inductive biases rather than arbitrary mutations.

## Limitations

- Retrospective-only evaluation; no prospective or clinical-deployment validation.
- The refinement loop's total compute cost (LLM calls + multiple retrains per iteration) is not reported, making it hard to compare fairly against single-shot baselines on a total-compute basis.
- Inherits errors/biases from the underlying LLM (DeepSeek-V4-Pro / Qwen3.5-27B) and from the curated clinical criteria corpus; the latter is not empirically audited for bias.
- Gains are uneven across labels: largest on morphology/ST-T-dependent diagnoses (NST_, ISCA) where measurement functions are easy to compile; performance on labels without crisp waveform criteria is not separately analyzed and may benefit less.
- The cited backbone LLMs are forward-dated identifiers whose exact version/capabilities may not be stable, affecting exact reproduction of revision trajectories.

## Questions for Further Exploration

- What is the **total compute budget** (LLM tokens + GPU-hours for retrains) of the full refinement loop, and how do gains degrade under a tighter candidate/iteration budget?
- How sensitive are the results to the **curated criteria corpus** — does adding noisy or conflicting criteria break CMC validation, and can the agent detect and reject them?
- Can the evidence-grounded failure-review mechanism **transfer to non-ECG time-series** (e.g., ICU waveforms, EEG) where deterministic clinical criteria are less crisp?
- Does contrastive diagnosis actually identify *systematic* limitations, or does it sometimes overfit to the selected failure batch — i.e., how stable is the diagnosed limitation `ℓ` across different random failure batches?
- Since the deployed classifier is frozen, how does it **handle distribution shift** at deployment relative to the LLM-as-Classifier paradigm that could adapt online?
- Can the refinement history / audit trail be used for **prospective failure attribution on new data**, turning it into an online monitoring tool rather than a one-time design loop?
