01

How FEGA sees a feature

Methodology, distilled

The move: stop characterizing SAE features by their activation geometry. Ablate the same active feature across many contexts, propagate each effect through the frozen model tail, and treat the resulting cloud of logit shifts Δ_j = φ(ĥ) − φ(h̄) as the object of study.

Reconstruction-relative. Effects are measured against the SAE reconstruction h̄, not the raw activation — de-confounding feature removal from SAE reconstruction error. A pre-logit Gram trick G = W_UᵀW_U avoids materializing vocab-sized vectors.

Value vs. pointer. A programming analogy organizes the taxonomy: value-like features bind static facts (Paris → France); pointer-like features support context-dependent operations (copy, bind, follow-rule) whose target shifts with the prompt.

  1. Isolate features. RAVEL differential masking for value-like; ≥90%-prevalence gates for pointer-like.
  2. Ablate per context. 50,000 ICL examples × 1,000 prompt families, across 5 tasks (LSC, WC, PrOntoQA, Token Translation, RAVEL).
  3. Decompose the cloud. Magnitude + unit direction; shared directional kernel K_j.
  4. Cascade label. Fixed priority: directed ray → axis/antipodal → vMF mixture → global k-D span → residual low-D → unresolved diffuse.
  5. Causal control. Matched-size random ablation, exact paired McNemar, 20-trial t-tests.

03

What holds up — and what doesn't

Strengths vs. limitations
+

Strengths

6
  • Effect over feature geometry. Clean, novel reframing — studies the cloud of downstream logit shifts, not the activation space.
  • Methodologically careful. Reconstruction-relative baseline correctly avoids the SAE-reconstruction-error confound many steering papers miss.
  • Real statistics. Matched random controls, exact paired McNemar, 20-trial t-tests with reported p-values.
  • Intuitive taxonomy. Value-like vs. pointer-like is well-motivated by a concrete task spectrum (synthetic → factual).
  • Self-aware. Authors explicitly limit claims to the retained context sample; no extrapolation to undefined features.
  • Reproducible. Public code (UKPLab/FEGA), SAEBench + RAVEL benchmarks, single public checkpoint.
−

Limitations

6
  • Single configuration. Gemma-2-2B, post-layer-12, width 65k — scale dependence acknowledged but untested (no 7B/9B).
  • Structured tasks only. Naturalistic multi-step generation where value- and pointer-like roles interact is left to future work.
  • Filtered headline proportions. Features failing the evidence gate are excluded; label percentages describe a subset.
  • Hand-set gates. vMF π_r, BIC, residual-energy thresholds are reporting gates, not universal constants — mild cherry-pick risk.
  • No steering validation. FEGA predicts steerability but never confirms that "directed ray" labels outperform "diffuse" in actual steering.
  • Single measurement site. Final logit readout aggregates all downstream transforms; the layer where effects disperse is unidentified.
04

Open questions

For further exploration
1

Does an FEGA "directed ray" label actually predict better downstream steering success than a "diffuse" label? The closing validation is missing.

2

How do label distributions shift with scale (Gemma-2-9B), SAE width (16k → 1M), and site (different residual layers)? Does diffuse geometry stay dominant?

3

Applying FEGA at successive layers: at which depth does a localized effect disperse into a high-dimensional vocabulary-level cloud?

4

Can the value/pointer distinction become a training signal (auxiliary loss) producing SAEs with more stable effect geometry?

5

Do labels generalize to naturalistic, multi-step generation where prompt-local operations and factual retrieval co-occur?

6

Is the strict signed directed-ray criterion too harsh? How do results change under an unsigned axis-only or subspace-only primary label?
