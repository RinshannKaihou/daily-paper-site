Key Finding

An LLM's choice between parametric and contextual knowledge is controlled by a single residual-stream direction.

「参数化知识 vs 上下文知识」的选择在残差流中线性表示为单一方向——带符号激活转向即可双向、连续地控制这一选择。

Which Knowledge Should LLMs Trust? Uncovering a Generalizable Steering Direction Across Knowledge Conflicts ↗

Yibin Lou · Yi Hu · Jianhui Chen · Chenpeng Wang · et al. · SUSTech / Peking University · 2026-10-14
knowledge-conflict activation-steering interpretability LLM RAG

Key Metric

+48.1pts

Parametric-answer rate on NQ-Swap, Gemma-2-9B-IT: 32.8% → 80.9% — best of nine steering methods, ahead of SpARE (77.3) and JUICE (78.4).

Why This Matters

Retune how much an LLM trusts retrieval vs. its own memory at inference — one direction, one layer, one scalar. No retraining, no per-task refitting.

Critical Edge

The +20 RAG gain is measured on deliberately counterfactual evidence — where trusting context is definitionally correct; rule-following gains shrink to +1.3–2.6 pts.

01Methodology — three stages, one edit

STEP 1

Pair the prompts

Clean prompt = question alone; conflict prompt prepends a passage injecting an alternative answer. Items kept only if the model knows the parametric answer and adopts the injected one.

STEP 2

Extract the direction

Average final-token activations per layer for both prompt types; pick layer ℓ with max angular separation (lowest cosine, final layer excluded — no task-score sweep). Vector v = μ_clean − μ_conflict.

STEP 3

Steer at inference

Edit the conflict prompt's final-token residual: h′ = h + αv. α > 0 → parametric, α < 0 → contextual, α = 0 → baseline restored. α chosen on a validation split only (70/15/15).

Evaluation labels the first 256 generated tokens as parametric / contextual / both / neither via string match, validated against a blinded judge. Baselines span attention manipulation (JUICE, IRCAN, PH3), SAE features (CK-PLUG, SpARE), proxy models (CSKS), layer search (ContextFocus), and context-sensitivity directions (CCS). Tested on four families: Llama-3.1-8B-Instruct, Qwen3-8B, Gemma-2-9B-IT, Mistral-7B-Instruct-v0.3.

03Strengths

  • Disarmingly simple answer: one direction, one layer, one signed scalar gives bidirectional, continuous control across four model families (smooth trade-off curves).
  • Transfer tested far beyond toy conflicts — RAG, multi-turn memory, rule following — with zero target-task fitting.
  • Strong controls: random-split steering, matched aligned/irrelevant contexts, 10-seed std, blinded-judge metric validation, estimation/selection/report separated.
  • Cheap at inference: no SAE training, no per-task attribution, no decoding-time modification — a single residual edit.
  • Honest Limitations section; code released.

04Limitations

  • Requires white-box access to activations — not applicable to closed-source or API-only models.
  • A control axis, not a full mechanism: attention heads, MLP features, and decoding dynamics also shape source selection.
  • 256-token string-match metric can't credit hedged or partial-agreement answers.
  • Complex-task gains are model- and task-dependent: +1.3–2.6 on rules vs +48.1 in controlled conflicts.
  • Boosting context trust is only right when context deserves it — noisy-retrieval (CRAG-style) conditional steering untested.
  • Main text covers only 7B–9B models.

05Questions for Further Exploration

  • Does the direction survive further fine-tuning (SFT / RLHF / DPO), or must it be re-estimated — and can it be edited directly?
  • Can α be set adaptively per input, conditioned on estimated evidence quality, so context trust rises only for reliable retrieval?
  • Is the same direction shared across model families in a common aligned space (platonic-representation hypothesis)?
  • How does it interact with known conflict-mediating components — JUICE-style attention heads or SAE conflict features?
  • Does the direction exist in 70B+ models and in long contexts where the conflict passage is tens of thousands of tokens away?
