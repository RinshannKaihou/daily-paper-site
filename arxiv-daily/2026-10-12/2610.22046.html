Key Finding · 核心发现

No single hidden-state probe beats a one-parameter length rule at locating where LLM reasoning first becomes unrecoverable.

探针能读出"这条推理轨迹错了"，却读不出"错在哪一步"——置信探针漏掉 81% 的不可挽回轨迹，且换一种训练设计会让失败类型排序完全反转。

Key Metric · 定位之战

0/10

runs in which the pointer probe beat the length rule at locating PIT steps — Hit@±2 0.4632 ± 0.0134 vs 0.4692 on 2,289 held-out Qwen3-4B PITs.

8B value probe: below the rule in 5/5 seeds (0.429 / 0.405 vs 0.503). Only a 5-seed ensemble edges it out (+0.0262 [+0.0022, +0.0495]).

Why This Matters · 为何重要

Any work claiming to localize reasoning failures from a model's internal states must first beat a trivial length rule — this paper ships the rollout-labeled dataset, the baselines, and the preregistered protocol to test it.

Critical Edge · 批判视角

A disclosed read-position bug means ~half the traces' final-step states were read from an earlier step — and were never re-scored, directly weakening every localization claim.

Plus: Qwen3 thinking mode, math-only; PIT labels rest on 4–16 rollouts per prefix, so the achievable Hit@±2 ceiling is unknown.

01Methodology

方法 · rollout 标定的失败分类学 + 探针对照实验

incorrect trace→ MC rollouts per prefix (8–16)→ continuation value Vt→ envelope V*t = max future value→ θ = 0.1→ capability gap | near miss | PIT step
  • Ground truth by rollout, not by rubric: each prefix of every incorrect trace is Monte-Carlo-rolled-out; recoverability is measured, not judged. The PIT (point of irrevocable turn) is the first prefix from which no future continuation succeeds.
  • Four probes, identical states: confidence (final label), combined / value (rollout rates), and pointer (trained to point at the PIT step) — all reading frozen hidden states at layers {23, 24}.
  • Rollout-free baselines: an 11-feature gradient-boosted text classifier for detection, and a one-parameter length rule t = round(f(L−1)) for localization, exploiting median PIT depth 0.70 / 0.75.
  • Preregistered discipline: fixed 0.05 AUROC margin, 0.08 minimum effect, problem-level splits, 5 seeds, problem-clustered bootstrap CIs.

Scale: 11,260 incorrect 4B traces + 9,508 8B traces (broad), 818 reference gold PITs; 818-PIT replay search reaches 80.4% within ±2 steps while reading only 6.6 prefixes per trace — the rollout cost the probes try to avoid.

The final-label probe is also below the rule in all runs (0 / 20 pooled).

  • Failure-type blindness: at cutoff 0.5 (8B) the calibrated confidence probe misses 81.5% of PITs and 79.7% of capability gaps, but only 46.6% of near misses; controlled difference +0.125 [+0.104, +0.143], above the 0.08 minimum effect.
  • Ordering reversal: same states, same read site — confidence probe ranks PIT > near miss (AUROC 0.76), rollout-trained combined probe flips it to 0.40 (0.67 → 0.36 at 4B). Probe-read orderings are training-design artifacts, not model facts.
  • ONE POSITIVETranscoder classifier (layers 19–24, capability-gap vs PIT problems): +0.055 AUROC over the best text baseline at 8B — meets the margin; +0.049 at 4B does not.
  • Population structure: capability gaps are the most frequent failure at both scales; fewer than half of incorrect traces are recoverable at step 0; PITs sit late (median depth 0.70 / 0.75) — which is exactly why the length rule is hard to beat.

03Strengths

优势

  • Turns a vague question ("can probes find reasoning failures?") into three rollout-grounded, preregistered quantities with baselines that are genuinely strong.
  • The ordering-reversal experiment is an informative control: probe-read conclusions about failure types are design-dependent.
  • Theory (identifiability, Props 1–2) is matched to practice without overclaiming — the gap is named, never used to explain away results.
  • Exceptional transparency: read-position bug, label noise, and missing run metadata all disclosed; the 818-PIT gold collection and code are reusable artifacts.

04Limitations

局限

  • One model family, one domain: Qwen3 thinking mode on math only; shares and probe behavior elsewhere are unknown.
  • Noisy labels, unknown ceiling: PITs derived from 4–16 rollouts per prefix, evaluated every second step; the two collections disagree on shared traces.
  • Read-position defect not re-scored: localization numbers characterize the stored states, not the corrected ones.
  • Confounds not isolated: the probe comparison changes labels, attention mask, step weighting, and schedule at once; the transcoder gain lacks a width-matched random-encoding control; 8B localization was tested only with the value probe.

05Questions for Further Exploration

待探索的问题

  1. Would 64+ rollouts per prefix lift the label-noise ceiling above probe capacity — or is noise the binding constraint?
  2. Does the PIT / near-miss ordering reversal survive when the two probes are matched in mask, weighting, and schedule?
  3. Can a causal, generation-time probe predict the next step is about to become the PIT — the practically useful version of localization?
  4. Do failure-type shares and the blindness pattern replicate on non-math domains (code, agentic tasks) and non-Qwen3 families?
  5. Would width-matched random projections of hidden states match the transcoder classifier's +0.055 AUROC at 8B?
  6. Would a pointer probe trained to predict depth relative to the length rule reveal any residual step-specific signal?
