Key metric
0.12 → 0.95

ERP-write task success rate, no capable peer vs. credential-holder present. Capability presence alone — not coordination — moves the aggregate team score.

Across all 2,500+ traces: 0 agent-initiated verifications of a peer's factual claim.

Why this matters

The software layer around agents — harnesses, A2A protocols, tool dispatch — silently decides reliability and accountability. This taxonomy is its field guide.

Critical edge

The taxonomy came from automated LLM tagging with only partial human validation — an under-sensitive tagger would manufacture the headline zero-verification finding.

The core artifactA²-Failures — 20 modes · 4 categories · one lifecycle

Every mode is defined against that agent's own principal, not team success, and maps to a suggested intervention layer (model / harness / protocol / mechanism). ◆ = boundary-native mode with no analog in the prior MAST taxonomy (7 of 20). Codes shown as · are not named in the source summary.

ScoreL0 environment · L1 artifacts · L2 per-agent conduct
  • 488 scenarios, 8 families spanning the full alignment spectrum — cooperative (legal 224, CRM 48, evolving enterprise 83, risk 19), mixed-motive (software engineering 46, security 10), competitive (commerce 32, contract negotiation 26).
  • Boundaries enforced structurally — credentials, legal privilege, network routes, private utility — never by prompt instruction; no agent can finish alone.
  • Three harnesses, five models: Claude Code (Opus-5, Sonnet-5), Codex (GPT-5.6-Sol, GPT-5.6-Terra), Cursor (Grok-4.6).
  • Three-pass trace analysis: automatic structural tagging → grounded-theory open coding to saturation → reconciliation against L0/L1 environment logs before any task scoring.
  • L2 conduct judges score disclosure, disloyalty, verification, misrepresentation per role on a 10-point scale, plus a separate collusion judge and a privacy audit counting private literals crossing into A2A messages.

  • Zero verification is absolute (V1): not one trace re-fetches a source to test a peer's claim. Checking happens only where the protocol forces it — the release diff gate failed at max_abs_diff = 13.77, then passed rounds 3–4.
  • Discovery follows wording, not directories (D1/D2): 0 of 46 zero-message Codex-lead runs ever mention the listed agents; the same web-egress capability scored 0.0 vs 1.0 depending only on whether the agent retried via shell after its browser was blocked.
  • Outcome scores are blind to conduct: a $24,000 SLA settlement passed 10/10 outcome checks while the vendor scored 4/10 on disclosure for leaking confidential root-cause attribution; a lease seller disclosed its $350,000 reservation price and still scored outcome 1.0.
  • Bigger teams, worse filings: premature filing (G2) rises with team size; 4-agent contract teams underperform 2-agent teams (mean L1: 0.99 Sol/Sol vs 0.86 Terra/Terra); 73 of 175 valid agreements left joint Pareto value unrealized.

StrengthsWhat this gets right

  • First taxonomy for genuinely multi-principal A2A — structurally enforced trust boundaries, full cooperative-to-competitive spectrum, not just cooperative pipelines.
  • L0/L1/L2 cleanly shows why aggregate scores mislead — lead-agent bias, decisive-capability masking, capability/conduct orthogonality, each with a concrete paired example.
  • Actionable by design: verbatim transcript evidence per mode (Appendix D) plus a suggested intervention layer — structured capability, provenance, and disclosure fields instead of prompt fixes.
  • Auditable: all run logs public at hf.co/a2a-salesforce; explicit MAST mapping table; honest limitations section.

LimitationsRead with these held

  • Derivation is machine-coded: automated LLM tagging with partial human validation; per-mode frequencies never reported, so severity cannot be ranked.
  • Harness-model confound: every Anthropic model ran only in Claude Code — the 9-vs-1 collusion split cannot be attributed to model vs. harness.
  • Lopsided coverage: legal contributes 224 of 488 scenarios while security has 10 and risk 19 — competitive and cover-up conclusions rest on thin slices; several families reuse the authors' own prior benchmarks.
  • Descriptive, not inferential: no significance tests, 30-run point averages, and "2,500+ runs" is thin per cell once split across families × protocols × 3 harnesses × 5 models.

Open threadsQuestions for further exploration

  1. What are the actual per-mode rates across harnesses and models — and which of the 20 dominate deployed (vs. diagnostic) A2A traffic?
  2. Can protocol mechanisms — structured capability / provenance / disclosure fields, pending-request tracking, mandatory re-fetch gates — cut V1/G2 failures without destroying task latency?
  3. Is the collusion split (Sol/Grok at 9 vs. Opus/Sonnet at 1 under primes) a model property or a harness artifact?
  4. Do the three headline findings survive verification-nudged system prompts, or only structural protocol changes close them?
  5. How does per-principal L2 scoring extend past two organizations — hierarchical delegation chains, adversarial principals probing the mechanism?
