⚠ Critical Edge

Calibration cost is never reported — despite a search that simulates downstream neurons across all time steps, levels, and sweeps — a conspicuous gap for a paper whose selling point is PTQ practicality.

01Methodology — spike-guided PTQ

−0.99
Spearman: accuracy ↔ flipped-spike fraction (injected-error experiment)
−0.77
Spearman: accuracy ↔ MSE — equal-MSE errors cause wildly different damage
STEP 1Record already-quantized input spikes per layer
→
STEP 2Simulate downstream LIF neurons; target = spike errors, not numerical error
→
STEP 3Gradient-free discrete search picks each weight among 4 nearest levels (Lcount + λLmargin + μLpop), largest inputs first, 25% held-out guard
→
STEP 4Threshold-anchored, reset-aware pre-fire membrane grid: hard reset Δv = θ/(m+½); soft reset Δv = θ/m (proven flip-free & grid-closed)

Quantization error reaches later layers only through the spikes it flips, yet existing PTQ objectives minimize MSE-type numerical error. SpikeQ's double reference (full-precision network + local recomputation) absorbs earlier layers' quantization; grid candidates are compared by counted flipped spikes under simulation, not membrane MSE, which is dominated by far-from-threshold errors that flip nothing.

Setup: T = 4 · 1,024 / 256 calibration images · A100 · two-sided protocol (baselines re-run pre-fire, SpikeQ also run post-reset; shared clipping search with BRECQ / PTQ4SNN).

Strengths

  • A falsifiable insight — flipped spikes predict accuracy (Spearman −0.99) — with negative controls placing existing methods on the same trend line.
  • Hardware-faithful formulation: pre-fire quantization is what Loihi/Speck actually do; the reset-aware grid comes with a correctness proof.
  • Two-sided protocol: baselines run under pre-fire, SpikeQ under post-reset; shared clipping search isolates the level-selection contribution.
  • Coverage: 7 benchmarks, 3 task types, CNN + transformer SNNs, hard/soft reset, consistent ablations.
  • Honest regime reporting: gains concentrate at W2/V2 and on complex tasks; W2V2 recommended only for simple tasks.

Limitations

  • No calibration-cost comparison (wall-clock, GPU-hours, energy) against reconstruction- and second-order baselines.
  • Single-seed weight calibration nearly everywhere; one 3-seed variance figure.
  • All runs at T = 4 — longer horizons, where flipped-spike cascades should matter most, are untested.
  • Analytical energy model, not on-chip measurement; firing-rate changes modestly flatter the ratios.
  • W2V2 not viable on complex benchmarks (SEW-ResNet-18 15.85% vs 62.89); dense prediction degrades earlier; no mixed-precision extension.
  • No code release stated — the discrete search has several moving parts.

03Questions for Further Exploration

  1. Q1What is SpikeQ's calibration wall-clock / energy cost vs GPTQ / BRECQ / PTQ4SNN, and how does it scale with T, depth, firing rate?
  2. Q2Does the flipped-spike proxy hold at T = 8–16 or on event-based tasks (DVS-Gesture, N-Caltech101) where flips cascade further?
  3. Q3Can threshold anchoring combine with mixed-precision search (à la MPBA) to rescue W2V2 on ADE20K and COCO?
  4. Q4Does the spike-error objective transfer to quantization-aware training — is anything left for MSE-style losses?
  5. Q5How do the energy predictions compare with measurements on real Speck/Loihi hardware?
  6. Q6Could the double-reference scheme be made iterative (joint re-quantization) instead of greedy layer-by-layer?
