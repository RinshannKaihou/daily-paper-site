> **一句话总结：** STRATA 把 LLM 智能体的经验记忆组织成"原子技能 → 工作流 → 元框架"三层带类型的图，用统一的相似度几何驱动五套自维护机制（多维检索、类型化反思、社区检测抽象、带桥点保护的压力触发放弃、以及对抗"同对象反方向"经验误召回的对比边），在 AppWorld/WebArena/ALFWorld/ScienceWorld 四个基准、两种冻结的 DeepSeek-V4 骨干、七个基线中取得最佳平均分，同时延迟最低、注入记忆行数比最"吃上下文"的基线少 44%；其对比边机制把 ScienceWorld 从 78.7 提升到 96.7（同一系统内消融），修复了单层具体记忆的灾难性负迁移。

> **TL;DR:** STRATA is a three-layer typed experience graph (atomic skills/code/roles → workflows → meta-frameworks, joined by call/generalize/merge/contrast edges) with five self-maintenance mechanisms sharing one similarity geometry, that lets a frozen LLM agent self-evolve purely at test time. Across AppWorld, WebArena, ALFWorld and ScienceWorld on two frozen DeepSeek-V4 backbones vs seven baselines (A-Mem, MemEvolve, MemGen, ReasoningBank, Hermes, Flat-Memory, No-Memory), it takes the best average score at the lowest latency and fewest environment steps — e.g. WebArena SR 45.6±1.6 vs MemEvolve's 41.0±2.2 (+4.6) and AppWorld Test-Challenge SGC 46.5±2.3 vs A-Mem's 42.2±2.6 (+4.3) — while injecting 23.3 lines of memory per task vs A-Mem's 41.9. Its contrast edges repair negative transfer, lifting ScienceWorld from 78.7 to 96.7 and ALFWorld from 89.5 to 98.6 within the same system, where Hermes' native flat memory scores −100 on ScienceWorld's find-living task family that a memoryless agent solves outright.

## 核心贡献

- **三层带类型经验图**：将记忆组织为有向图 G=(V,E)——原子节点（单个工具/API、参数化代码片段、专用子角色）、工作流节点（整任务的泛化过程）、元框架节点（从同类工作流抽象出的任务族范式），边带类型（call / generalizes / merged_from / contrasts），从根本上区别于现有单层级、仅靠嵌入相似度检索的记忆池。
- **五套共享同一相似度几何的自维护机制**：(i) 四维相似度（内容嵌入 + 索引嵌入 + 结构化标签 Jaccard + 词面重叠，权重 0.40/0.25/0.30/0.05）以"操作/目标"标签项区分"同材料、不同操作"的经验；(ii) 类型化反思器——成功结晶可复用过程、失败只挂"坑点"子弹，反射阈值按标签组做经验贝叶斯收缩自适应；(iii) Louvain 社区检测诱导元框架（带尺寸/导电率/新颖度三重门控）；(iv) 压力触发垃圾回收——按"激活度+竞争年龄"质量分删除最低者，但用 Tarjan 桥点（articulation point）保护图的结构连接；(v) 对比边——按操作词反义词典把"加热"与"冷却"这类方向相反的经验互链，检索时注入醒目的"勿混淆"警告。
- **识别并量化先前记忆的两种失效模式**：单层记忆随任务集增长的规模性衰退（A-Mem 在 Flash 骨干上 168 任务时排名第一、812 任务时跌至第八中的第七）；以及单层具体记忆的灾难性负迁移（Hermes 在 ScienceWorld 的 find-living 上得 −100，而无记忆智能体可直接解出），后者被对比边修复。
- **效率与规模的解耦**：812 个 WebArena 任务压缩为 112 个工作流 + 16 个元节点；记忆有界、去重，使检索注入保持小而精——STRATA 是所有记忆方法中延迟最低（58.7s vs 60.2–72.4s）、输出 token 最少（5,217）、环境步数最少（11.7/task）的。
- **严格的机制级消融**：逐一移除五个机制（标签项 −13.1 > 对比边 −6.5 > 自适应阈值 −5.9 > 元层 −4.7 > 压力回收 −2.2 平均分），附录 A–F 对每个机制单独做诊断式消融（删除后悔率、元层纯度/流失率等），全部超参数跨基准固定。

## Key Contributions

- **A typed, three-layer experience graph** replacing the single-level similarity-indexed pools of prior agent memories: atomic nodes (skills, code snippets, sub-roles), workflow nodes (generalized procedures), and meta-framework nodes (task-family paradigms), linked by call / generalizes / merged_from / contrast edges, with a derived (never stored) workflow kNN similarity graph W driving community detection and bridge protection.
- **Five maintenance mechanisms in one similarity geometry**: (i) a four-signal similarity — content and index embedding cosines plus a structured-tag Jaccard term (Wt=0.30, the largest non-content weight) and a lexical overlap — so query and node live in one geometry; retrieval returns a whole subgraph rendered meta→workflow→atomic, gated at θmin=0.35 (below which no memory is injected at all); (ii) typed reflection with per-group empirical-Bayes adaptive thresholds (κ=30) deciding noop / add_bullet / create, where failures never crystallize a "do this" procedure; (iii) community detection (Louvain, resolution 1.5) promoting a meta only if the community is large, tight (conductance < 0.6) and novel (centroid distance ≥ 0.6); (iv) pressure-triggered garbage collection with a competition-aware quality score that deletes only non-articulation vertices (Tarjan), with hysteresis; (v) contrast edges instantiating rule-based opposition over a fixed lexicon ({heat, cool}, {create, delete}) to warn against direction-opposite recall.
- **Two diagnosed failure modes of prior memory**: a scale failure (the strongest baseline A-Mem ranks first at 168 tasks and seventh of eight at 812 on Flash) and catastrophic negative transfer of concrete single-level memories (Hermes scores −100 on a ScienceWorld task family a memoryless agent solves), which contrast edges repair — lifting ScienceWorld from 78.7 to 96.7 within the same system.
- **Best average at lowest cost**: across four interactive benchmarks (AppWorld Test-Normal/Test-Challenge, WebArena, ALFWorld, ScienceWorld), two frozen backbones (DeepSeek-V4-Flash/Pro) and seven baselines over three seeds, STRATA is the strongest method on average on both backbones while being the fastest memory-augmented method (58.7 s/task), using the fewest output tokens (5,217) and fewest environment steps (11.7).
- **Mechanism-level transparency**: component ablations of every mechanism, per-mechanism appendix diagnostics (deletion regret, meta purity/churn, retrieval-injection rates), a full hyperparameter table held fixed across all benchmarks, and verbatim reproductions of real memory nodes.

## Methodology

STRATA assumes no weight updates: a frozen LLM agent self-evolves purely by what its memory represents, retrieves and forgets. The memory is a typed directed graph G=(V,E) with three node types — atomic (one tool/API, a parameterized code snippet, or a specialized sub-role), workflow (a generalized procedure for a whole task), meta (a paradigm abstracted from a family of similar workflows) — and typed edges: ordered call edges (workflow→atomic) plus evolution edges labelled generalizes / merged_from / contrasts. Maintenance operations run on a derived undirected workflow similarity graph W, recomputed each round.

**Retrieval.** A query is scored against each node by four complementary signals: content-embedding cosine (0.40), index-embedding cosine (0.25), Jaccard overlap of structured app:/op:/obj: tags (0.30) and lexical token overlap (0.05). The tag term is additive rather than a multiplicative gate, and is the only signal that separates experiences whose content embeddings nearly coincide because they act on one object with opposite operations. Nodes are re-ranked with a small layer bias (βlayer=0.15) favouring general nodes; only seeds clearing θmin=0.35 are admitted — if nothing clears it, no memory is injected, because running without memory beats being misled. Around the top-k seeds the system pulls in their meta parents (which must independently clear θmin), their called atomics and their contrast neighbours, rendered meta-first so the agent reads principles before callable skills.

**Typed reflection.** After each episode a master router dispatches to typed sub-reflectors for skill, code, role and workflow. Atomic sub-reflectors crystallize only from solved episodes. The workflow sub-reflector uses a per-group adaptive similarity band: because equivalent task pairs score ≈0.4–0.5 in one application and ≈0.8 in another, a single global band either over-merges or over-fragments, so group quantiles are shrunk toward global priors in empirical-Bayes fashion (κ=30, priors 0.33/0.62). Outcomes: noop for near-duplicates (s > τhigh), add_bullet to record only the difference within the band, create otherwise. Failed episodes at most attach a pitfall bullet rendered as something to avoid.

**Meta induction.** Communities of the similarity graph (Louvain at resolution 1.5) are promoted to meta nodes only if large (|C| ≥ Nmin), tight (conductance < 0.6) and novel (centroid ≥ 0.6 from the nearest existing meta); otherwise the matched meta absorbs the unlinked members. The novelty gate suppresses churn — without it the system rebuilds near-duplicate metas.

**Forgetting.** Only the workflow layer forgets. Each workflow's quality combines rank-normalized activation (similarity-weighted degree, so central workflows survive) and competitive age (wA=0.35, wG=0.65); age updates online at every retrieval (all candidates age by α=0.02, close-but-losing competitors age fastest, the winner is rejuvenated by γ=0.5). When live workflows exceed a per-dataset cap, lowest-Q nodes are deleted down to cap·(1−0.15) with hysteresis — but never an articulation point of W (Tarjan), because deleting a bridge splits a cluster and fractures one task family into two metas. Orphaned atomics and unsupported metas cascade away.

**Contrast edges.** A bidirectional edge links two nodes whose operators oppose (heat vs cool, create vs delete), instantiated by rule over a fixed lexicon, deliberately not requiring the same object since negative transfer is often cross-object (a melt-lead procedure misleading a freeze-tin task). Retrieving a seed pulls its contrast neighbours in, rendered as a prominent "do not confuse" warning rather than a flat procedure — a retrieval-time mechanism relating two distinct experiences, unlike write-time precondition tightening.

**Protocol.** Memory accumulates online across a single sequential pass over each benchmark (later tasks benefit from earlier ones); all memory methods receive the identical write signal (the environment's task-level outcome, no gold answers); embeddings come from a local Sentence-BERT-family model; every number is the mean over three seeds that permute task order and reflection sampling; all hyperparameters are fixed across benchmarks and backbones except the workflow cap.

## Results & Highlights

All numbers are mean ± sample std over three seeds.

- **Main table (DeepSeek-V4-Pro)**: STRATA is best on six of seven columns and second on the rest. Gaps that survive seed variance: AppWorld Test-Challenge SGC 46.5±2.3 vs A-Mem's 42.2±2.6 (+4.3); WebArena success rate 45.6±1.6 vs MemEvolve's 41.0±2.2 (+4.6); ALFWorld 98.6±0.9 vs MemGen's 96.3±1.9 (+2.3). On AppWorld Test-Normal Pro TGC (78.4±2.5 vs A-Mem 77.2±2.9) the gap is NOT statistically separable — A-Mem is nominally ahead on SGC — and on ScienceWorld (96.7±3.6 with 23 tasks, per-method std 3.6–15.0) the authors explicitly decline to claim a between-method win, resting their ScienceWorld evidence on within-system contrast ablations instead.
- **Negative transfer repaired by contrast edges (within-system ablation, Pro)**: removing contrast edges drops ScienceWorld from 96.7 to 78.7 (−18.0) and ALFWorld from 98.6 to 89.5 (−9.1), but only −1.8 on WebArena (43.8), which contains few direction-opposite operators — a benefit that appears only where its precondition holds. Hand-placed edges recover 78.7→89.8 and rule-based lexicon instantiation recovers the rest to 96.7; on ALFWorld 89.5→98.6. The clearest real-world instance: Hermes' native flat memory scores −100 (Flash) / −80 (Pro) on ScienceWorld's find-living family while the memoryless agent solves it — Hermes' overall 30.4/35.8 TGC on AppWorld Test-Normal and 48.3/55.8 on ScienceWorld sit far below the memoryless 62.8/66.9 and 75.7/80.6.
- **Scale failure of single-level memory**: A-Mem's margin over STRATA flips from +0.4/+3.4 (TGC/SGC, Flash, 168-task Test-Normal) to −4.3/−6.3 (417-task Test-Challenge); on the 812-task WebArena (Flash) A-Mem scores 28.4, seventh of eight methods, below Flat-Memory (30.7), Hermes (31.6) and MemGen (29.5). A-Mem injects 41.9 lines of memory per task — the largest of any method, exceeding even unstructured Flat-Memory's 35.6 — while STRATA scores higher injecting 23.3 (44% fewer lines).
- **Memory compression**: 812 WebArena tasks condense to 112 workflows under 16 meta nodes; 417 AppWorld Test-Challenge tasks to 33 workflows and 5 metas — roughly one workflow per seven tasks, so retrieval cost stays flat as experience accumulates.
- **Efficiency (Pro, per task)**: among seven memory systems STRATA has the lowest latency (58.7 s vs 60.2–72.4 s; memoryless 52.4 s), fewest output tokens (5,217) and fewest environment steps (11.7), paying +6.3 s over the memoryless agent for +11.5 TGC points on AppWorld Test-Normal.
- **Component ablation (Pro, five-column average)**: removing the tag term costs −13.1 (72.9→59.8), contrast edges −6.5 (→66.4), adaptive thresholds −5.9 (→67.0), the meta layer −4.7 (→68.2), pressure GC −2.2 (→70.7). In the similarity-dimension ablation, dropping the tag dimension costs −14.4 average, and content-only retrieval (the naive-RAG default) scores 59.3 vs the full 75.3 (−16.0).
- **Forgetting diagnostics**: with GC disabled the store grows to 269 workflows injecting 48.7 lines/task yet scores lower (70.7) than the bounded 201-node memory (72.9, 23.3 lines). At identical final size (201) and deletions (68), bridge protection cuts deletion regret (fraction of deleted workflows whose task type recurs) from 13.2% to 4.8% — close to a threefold precision gain — while accuracy rises 69.8→72.9.
- **Where gains concentrate**: long-tail categories — WebArena shopping_admin 31.5→41.8 and gitlab 33.8→43.8 over the best baseline; AppWorld Test-Normal phone 54.5→59.1 over A-Mem — consistent with meta nodes letting sparse task families inherit structure from related families. The reported exception: ALFWorld clean_and_place drops to 93.6, behind every memory baseline, an unexplained loss the authors report rather than hide.

## Authors & Credibility

The work comes from the New Jersey Institute of Technology (Guanhua Zhu, Hanwen Li, Chenxi Yuan — Department of Informatics; Zhi Wei — Department of Computer Science) with Mengnan Du (School of Artificial Intelligence, The Chinese University of Hong Kong, Shenzhen) as a corresponding author alongside Chenxi Yuan; Mengnan Du is an established researcher in LLM interpretability and trustworthy agents. The paper reads as a careful systems-and-evaluation study: three seeds with sample standard deviations throughout, an explicit statement of which gaps survive seed variance and which do not, confounds (scale vs difficulty on Test-Challenge) stated plainly in the text rather than buried, per-mechanism appendix ablations with diagnostic metrics beyond accuracy (deletion regret, meta purity and churn, injection rate), a complete hyperparameter table claimed fixed across all benchmarks and backbones, and two verbatim real memory nodes reproduced in the appendix. The baselines are current and strong (A-Mem from NeurIPS, ReasoningBank, MemGen, MemEvolve, plus the open-source production Hermes agent and Flat/No-Memory controls), all run with the identical write signal on the same frozen backbones. No public code release for STRATA itself is mentioned in the paper.

## Critical Assessment

- **Novelty**: real but assembled from known parts. The contribution is not any single component (Louvain, Tarjan articulation points, conductance, empirical-Bayes shrinkage are all standard) but the typed three-layer data structure and the maintenance policy binding them; the contrast-edge mechanism against direction-opposite recall is the one piece the authors claim (credibly) not to see in prior agent memory. The negative-transfer diagnosis is genuinely valuable.
- **Rigor — headline vs what is claimed**: commendably honest, but the headline "best average" rests on averaged learning curves where several individual gaps do not survive seed variance. AppWorld Test-Normal is statistically a tie with A-Mem (78.4±2.5 vs 77.2±2.9 TGC, A-Mem ahead on SGC), and ScienceWorld's 23 tasks give every method std 3.6–15.0 — the striking 78.7→96.7 contrast-edge result is a within-system ablation on the same seeds, not a between-method victory, and the paper says so.
- **Confounded scaling claim**: the "single-level memory degrades at scale" narrative compares AppWorld Test-Normal (168 tasks) to Test-Challenge (417 tasks, intrinsically harder, with amazon supplying 212 tasks absent from Test-Normal) and across environments to WebArena (812 tasks, different action space). The authors concede this entangles scale with difficulty and distribution shift — two consistent observations, not a controlled experiment — and list exactly such a study as future work.
- **Contrast edges are domain-fitted**: the opposition lexicon is hand-specified ({heat, cool}, {create, delete}); the rule does not discover opposition. Unsurprisingly, only 2 contrast edges instantiate on WebArena vs 6 each on ScienceWorld/ALFWorld, and the ablation gain concentrates where the lexicon matches. The mechanism is a curated patch for a real failure mode, not a general anti-confusion capability, and it can plausibly make the agent overly conservative on the very tasks it protects (the ALFWorld heat_and_place/clean_and_place deficits).
- **Single model family**: all results use DeepSeek-V4-Flash/Pro; the contrast mechanism in particular depends on a backbone honouring an injected warning, which the authors flag as needing cross-backbone replication (no GPT/Claude/Qwen evidence).
- **Reproducibility**: hyperparameters, seeds, std and per-mechanism diagnostics are all reported, which is above the norm — but there is no stated code release, the workflow cap is tuned per dataset (the only per-dataset knob), and the protocol scores a single sequential pass (task order permuted by seed) rather than converged memory, so absolute numbers depend on the online accumulation setting.
- **Red flags (minor)**: a disclosed implementation quirk — meta-node tags are recomputed per community-detection round, so a child's tag (e.g. op:delete) can silently drop out of the meta node's tag set, weakening meta recall; the authors state the one-line fix was not applied to avoid invalidating reported runs. Small-sample per-category claims (gains on <10-task categories) are acknowledged as noisy.

## Strengths

- Attacks the correct level of the problem: with frozen backbones, agent self-evolution is a data-structure-and-maintenance question, and the paper treats it as such with unusual precision.
- The negative-transfer analysis is the paper's crown jewel: it demonstrates a production agent's memory actively converting a solvable task into a −100 penalty, then isolates the repair (contrast edges) with an ablation whose cost appears exactly where the precondition holds (−18.0 ScienceWorld, −9.1 ALFWorld, only −1.8 WebArena).
- Efficiency wins are structural, not incidental: bounded, deduplicated memory (812 tasks → 112 workflows/16 metas) yields the lowest latency, fewest output tokens, fewest environment steps and 44% fewer injected lines than the most context-hungry baseline, while scoring higher.
- Diagnostic ablations go beyond accuracy (deletion regret 13.2%→4.8% at identical memory size and deletion count; meta churn 28.6%→3.1% with support rising 2.1→3.6), which is how memory papers should be evaluated.
- Statistical honesty: the text enumerates which gaps survive seed variance and declines to claim a ScienceWorld win; the unexplained ALFWorld clean_and_place loss is reported rather than omitted.
- All hyperparameters held fixed across four benchmarks and two backbones, with the single exception (workflow cap) declared.

## Limitations

- Opposition is supplied, not learned: contrast edges instantiate over a hand-specified lexicon of opposite operator pairs; environments whose confusions are not in the lexicon (web navigation, cross-app API conflicts) get little benefit.
- The scaling claim is observational: no controlled experiment fixes the evaluation set and varies only accumulated experience, so scale, difficulty and distribution shift remain entangled (Test-Challenge's amazon-heavy mix).
- Single backbone family (DeepSeek-V4); the contrast warning in particular requires a backbone that obeys injected admonitions — the authors themselves list cross-backbone replication as open.
- ScienceWorld has only 23 tasks and very high variance (std up to 15.0), ALFWorld is near saturation for all memory methods (94–99), and per-category gains on AppWorld rest on categories with as few as 3–6 tasks.
- Sequential online protocol means scores average the learning curve, not converged performance; no evaluation of the memory carried across benchmarks (no cross-domain transfer test of the meta layer).
- No public code release is mentioned; the meta-tag recompute quirk (tags can drop out on meta updates) is disclosed but unfixed in the reported runs.

## Relevance

直接命中"Self-Evolving Agents & Automated Research"兴趣方向：这是免权重更新、纯测试时自我进化的智能体记忆系统，其核心贡献是让累积经验在规模增长下保持有组织、可抽象、可遗忘。同时，它把"负迁移"识别为长程自主智能体的一种静默失效模式（记忆把可解任务变成 −100 惩罚）并给出检索时修复机制，与"自主智能体系统可靠性与可信性"的关注点高度契合。

## Questions for Further Exploration

- Can opposition be discovered rather than lexicon-supplied — e.g. learning direction-opposite embeddings or asking the backbone to propose contrast candidates — so the mechanism generalizes beyond heat/cool and create/delete?
- What does a truly controlled scaling study show: fix the evaluation set and vary only the number of accumulated experiences; does the single-level memory degradation persist cleanly, and where does STRATA's advantage saturate?
- Does the contrast warning survive across backbone families (GPT/Claude/Qwen), and can the finding that a stronger backbone honours warnings better be quantified as a "warning compliance" metric?
- Can a memory graph built on one environment transfer its meta-frameworks to another (AppWorld → WebArena), testing whether the abstraction layer is genuinely cross-domain or per-benchmark?
- Does the empirical-Bayes reflection threshold and the competitive-age forgetting heuristic improve if learned (e.g. a small learned ranker over deletion candidates), or do the classical graph tools already sit at the ceiling for this memory scale?
- How does STRATA behave under concurrent writers (multiple parallel agents sharing one graph), where atomicity of reflection and community detection is no longer free?
