Methodology · 方法

Each Turing machine is treated as a grey box: full visibility of execution state, agnostic to the transition code — so the method transfers to any Turing-complete language.

  1. 1

    Pattern detection

    Simulate 5×10⁶ steps; a greedy compression parses tapes into block exponents, keeping the top K=100 frequent patterns.

  2. 2

    Automated conjecturing

    The LLM writes executable Python exponent-maps; conjectures must hit 100% prediction accuracy to advance.

  3. 3

    Interactive refinement

    The LLM probes synthetic configurations (128k-step cap, N=5 turns) to discover edge cases the blank-tape trajectory never reaches.

  4. 4

    Informal proving

    Generator–evaluator loop scores correctness and format (M=4 iterations); only clean proofs proceed.

  5. 5

    Lean 4 formalization

    Multi-persona agent (Setter / Planner / Writer / Critic) may repair the statement — never the machine — then proves everything or times out at 72 h.

Strengths · 优点

  • Machine-checked ground truth — every acceleration verified by the Lean 4 kernel: 0 sorry, adversarial Critic, no unauthorized axioms, plus manual validation.
  • Simulation-only grey-box design decouples the method from Turing-machine specifics — should transfer to Python, C++, any Turing-complete language.
  • Probing unreachable configurations cleanly solves the edge-cases-never-occur blind spot of pure trace-fitting.
  • Autoformalization as revision (repair the statement, never the machine) mirrors real mathematical practice.
  • Exceptional honesty — provisional-Cryptid framing and per-machine credit to community members.

Limitations · 局限

  • Nothing is resolved — acceleration ≠ resolution; BB(6), BB(2,5), BB(3,3) all remain open.
  • The Collatz-like prior is baked in — machines outside block-exponential piecewise-affine structure yield no conjecture; no mechanism for finding novel problem classes.
  • No failure stats or ablations — the 52 → 26 yield can't be decomposed by stage; compute cost unreported.
  • Only the verification half is reproducible — discovery runs on proprietary Gemini 3.1 Pro / 3.8 Flash.
  • Provenance blur — the split between the flagship pipeline and the second-stage Flash auto-research agent is undisclosed.
