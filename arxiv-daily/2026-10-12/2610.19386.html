A three-layer typed experience graph with five self-maintenance mechanisms lets a frozen LLM agent self-evolve purely at test time.

STRATA: Self-Maintaining Structured Experience Graphs for Self-Evolving Language Agents ↗

中文一句话（节选）：把 LLM 智能体的经验记忆组织成『原子技能 → 工作流 → 元框架』三层带类型的图，五套自维护机制共享同一相似度几何……在四个基准、两种冻结 DeepSeek-V4 骨干、七个基线中取得最佳平均分，同时延迟最低、注入记忆行数比最“吃上下文”的基线少 44%；对比边机制把 ScienceWorld 从 78.7 提升到 96.7。

Why this matters

Long-running agents can self-evolve without weight updates — but memory itself can silently sabotage them, turning solvable tasks into −100 penalties.

Critical edge

Contrast edges are a curated patch, not a general capability — opposition comes from a hand-specified lexicon ({heat, cool}, {create, delete}), and only 2 edges fire on WebArena.

Methodology — how the graph maintains itself

No weight updates: a frozen agent evolves through what its memory stores, retrieves, and forgets.

  1. Store — typed graph G=(V,E): atomic nodes (tool / code snippet / sub-role) → workflows → meta-frameworks; edges typed call · generalizes · merged_from · contrasts.
  2. Retrieve — 4-signal similarity (content 0.40 · index 0.25 · tag-Jaccard 0.30 · lexical 0.05); seeds must clear θmin=0.35 or nothing is injected — “running without memory beats being misled.” Subgraph rendered meta-first; contrast neighbours appear as “do not confuse” warnings.
  3. Reflect — typed sub-reflectors; only solved episodes crystallize procedures, failures attach pitfall bullets; per-group empirical-Bayes adaptive thresholds (κ=30).
  4. Abstract — Louvain communities (res. 1.5) promoted to metas only if large, tight (conductance < 0.6) and novel (centroid ≥ 0.6).
  5. Forget — quality = rank-normalized activation + competitive age; pressure-triggered deletion with hysteresis, never a Tarjan articulation point (deleting a bridge would fracture a task family into two metas).

Protocol: single sequential pass per benchmark; identical write signal for all methods (task-level outcome only, no gold answers); local Sentence-BERT embeddings; 3 seeds (task order + reflection sampling permuted); hyperparameters fixed across all benchmarks & backbones except the workflow cap.

The two diagnosed failure modes of prior memory:
  • Catastrophic negative transfer — Hermes' flat memory scores −100 (Flash) / −80 (Pro) on ScienceWorld's find-living family, which a memoryless agent solves outright; its overall scores sit far below memoryless everywhere.
  • Scale decay — A-Mem beats STRATA at 168 tasks (+3.4 SGC) but falls behind at 417 (−6.3) and ranks 7th of 8 (28.4) on the 812-task WebArena, below even Flat-Memory.
Strengths
  • Attacks the correct level: with frozen backbones, self-evolution is a data-structure-and-maintenance question, treated with unusual precision.
  • Crown-jewel negative-transfer analysis: demonstrates a production agent's memory turning a solvable task into −100, then isolates the repair by ablation whose cost appears exactly where the precondition holds (−18.0 ScienceWorld, −9.1 ALFWorld, only −1.8 WebArena).
  • Efficiency is structural, not incidental: bounded, deduplicated memory yields lowest latency / tokens / steps and 44% fewer injected lines — while scoring higher.
  • Diagnostics beyond accuracy: deletion regret 13.2%→4.8%, meta churn 28.6%→3.1% with support 2.1→3.6.
  • Statistical honesty: enumerates which gaps survive seed variance; the unexplained ALFWorld clean_and_place loss is reported, not hidden.
  • All hyperparameters fixed across 4 benchmarks × 2 backbones, with the single exception (workflow cap) declared.
Limitations
  • Opposition is supplied, not learned: a hand-specified lexicon; environments whose confusions aren't in it (web navigation, cross-app conflicts) get little benefit.
  • The scaling claim is observational — scale, difficulty and distribution shift remain entangled (Test-Challenge's amazon-heavy mix); no controlled experiment.
  • Single backbone family (DeepSeek-V4); the contrast warning needs a backbone that obeys injected admonitions — no GPT/Claude/Qwen evidence.
  • Small, noisy slices: ScienceWorld has 23 tasks (std up to 15.0); ALFWorld near saturation (94–99); some per-category gains rest on 3–6 tasks.
  • Sequential online protocol averages the learning curve, not converged performance; no cross-benchmark transfer test of the meta layer.
  • No public code release; the meta-tag recompute quirk (child tags can silently drop out of metas) is disclosed but unfixed in reported runs.
Questions for further exploration
Can opposition be discovered rather than lexicon-supplied — learned direction-opposite embeddings, or the backbone proposing contrast candidates?
What does a truly controlled scaling study show: fix the evaluation set, vary only accumulated experience; where does STRATA's advantage saturate?
Does the contrast warning survive across backbone families (GPT/Claude/Qwen) — can "warning compliance" be quantified as a metric?
Do meta-frameworks built on one environment transfer to another (AppWorld → WebArena), i.e. is the abstraction layer genuinely cross-domain?
Would learned rankers improve on the empirical-Bayes thresholds and competitive-age forgetting, or do classical graph tools already sit at the ceiling?
How does STRATA behave under concurrent writers — multiple parallel agents sharing one graph?
