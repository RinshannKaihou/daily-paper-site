Key Metric

Matches or beats Kitty (2.39 b) and ChanMix (2.32 b) — and degrades gracefully to 1.5 b, where those baselines collapse.

Why This Matters

Long-output reasoning blows up KV cache memory — 2.26-bit keys with AIME / long-CoT accuracy intact widens what a single 40GB GPU can serve.

  • Only PN-Mix fits B=32 · 32K-token generation on 40GB (37.12 GB); FP16 and Kitty both OOM.

Critical Edge

AIME's 30 questions carry ±5–7-point standard deviations — several headline "wins" (e.g., 76.00 vs 70.67) sit within ~1σ, and no significance tests are reported.

Efficiency tables run Kitty at ~2.5 bits (4/2, r=25%) — a different operating point than the matched-accuracy tables.

Critical Assessment · Rigor & comparison asymmetry

Methodology — distilled

Query-aware channel-pair saliency, computed once at prefill and reused all decode long — no offline calibration (vs ChanMix), no per-group index bookkeeping during decoding (vs Kitty).

1 · Prefill score Per layer / KV head / RoPE pair: σh,i = E‖qi‖ · E‖ki‖ — query heads averaged under GQA.
2 · Select once Top-r% pairs → binary mask B×L×Hkv×d/2; stored and never recomputed during decoding.
3 · Mixed-precision decode Sink tokens (32) + residual buffer (128) stay FP16; salient pairs 3-bit, rest 1-bit + midpoint correction; values per-token groups.

Why pair-norm: decomposing the post-RoPE attention logit shows each channel pair's quantization error is scaled by the ‖q‖·‖k‖ product (Eq. 3–4) — a proxy computable before quantization. The separable score tracks the causal-joint oracle at Spearman 0.990–0.996 (95.3–96.2% top-10% overlap), and 97–99% of importance mass sits in the top-50% of pairs.

Operating points — PN-Mix(1): r=50%, G=128 → 2.26 b · PN-Mix(2): r=40%, G=64 → 2.29 b. 1-bit midpoint correction: s=(max−min)/2, z=¾min+¼max.

Strengths

  • Principled criterion — attention-logit perturbation analysis at RoPE channel-pair level, verified by DKL simulation before end-task evals.
  • Prefill-once selection — no offline calibration, no decode-time index management; TTFT within 12 ms of Kitty at P=16K.
  • Broad coverage — four model families (7B–32B), standard + code + AIME long-CoT, 2-bit values, full 1.5–3.0-bit sweep, variance reported.
  • Sub-2.25-bit robustness — graceful down to 1.5 bits where every compared baseline collapses; the most distinctive capability result.
  • Deployment wins — 8× length, 5.5× batch, 2.37× peak throughput; the only method fitting B=32 / 32K on a 40GB card.

Limitations

  • RoPE decoder-only by construction — ALiBi / NoPE and encoder–decoder architectures need adaptation.
  • Single A100-40GB with the authors' own Triton kernels; no vLLM / PagedAttention-style serving-stack evaluation.
  • AIME variance — 30 questions, ±5–7 pt std; no significance tests, so several gaps are statistically soft.
  • Value cache is uniform — the mixed-precision machinery is key-only, leaving accuracy on the table in full-KV ultra-low-bit regimes.
  • Mixed operating points — Kitty's efficiency config (~2.5 b) differs from its accuracy config, so latency/memory comparisons blend budgets.
  • No non-reasoning long-context tasks (long-doc QA / summarization), where prefill-prompt saliency might transfer differently.

Questions for Further Exploration

  • Does pair-norm saliency transfer to ALiBi / partial-RoPE models via pseudo-pairs from the positional kernel's coupling structure?
  • Does prefill-only selection survive very short (P≈141) or highly off-domain prompts — is there a prompt-length threshold?
  • Can the Q̃K̃ criterion stack with token- / layer-level mixed precision (retrieval-head-aware budgets) below 1.5 bits?
  • How does it interact with prefix caching / shared-prefix serving, where one prefill mask is reused across many requests?
  • Do the latency gains hold under vLLM / SGLang paged-KV stacks — and how much headroom remains with INT4 / FP8 weight co-quantization?
  • Given 97–99% of importance in the top-50% of pairs, would an adaptive per-head r push below 2.26 bits at equal accuracy?
