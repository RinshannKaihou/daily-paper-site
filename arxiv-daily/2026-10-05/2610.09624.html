How Do Agentic LLMs Decide to Call Tools? A Tool-Call Vector Shaped by Suppression

Xijie Gong, Tingxu Han, Jiahao Zhang et al. · MBZUAI · UESTC · NJU · Griffith · UNSW · KCL  |  2026-10-07 · arXiv:2610.09624

Key metric · causal flip

0.00% → 100.00%

add μΔ: calls induced  ·  remove: 100.00% → 0.00%

At Qwen3-8B’s L24 prediction position, adding μ_Δ induces <tool_call> top-1 on all 200 held-out analysis prompts; subtracting it suppresses all execution prompts (logit +7.39 / −7.48, suff. 1.03, nec. 1.04). Norm-matched random vector flips ~0–1.5%.

Why this matters

First systematic mechanistic account of an agent’s call-or-no-call decision — plus a lightweight vector intervention for steering when models call tools.

机制可解释性首次系统作用于 agent「是否调用工具」这一核心决策，并给出干预调用行为的轻量手段。

Critical edge

The 100% headline comes from behaviorally screened synthetic pairs — on native τ²-Bench trajectories, 1× removal suppresses only 36.7% of calls.

Screening bias: only verb pairs that actually flip the decision entered the dataset (analysis-verb call rates were ~5–25% before screening).

Methodology

1
Contrastive pairs

500 paired coding prompts (Python/Java/C++, from MBPP · APPS · HumanEval · CodeContents) identical except the request verb — write vs discuss. 300 train / 200 held out.

2
Localize by activation patching

Swap clean↔corrupt activations across layers × positions; the call signal migrates from the verb to the prediction position by L24, where patching recovers 100% of calls.

3
Estimate and intervene

μ_Δ = mean clean−corrupt activation difference at L24. Add to analysis prompts, subtract from execution prompts; norm-matched random vectors as controls.

4
Stress the vector

New tools and domains (web / SQL / email), native multi-turn τ²-Bench Telecom trajectories, and 600 verb-free implicit requests — all without re-estimation.

5
Explain formation, then replicate

Scaffold ablations, layer-window projections, Transcoder feature scores (κ), DLA readout — then the full protocol rerun on 7 models across 3 families.

  • The scaffold installs the call prior. Full scaffold: call probability 0.8486 on neutral requests vs 0.0038 on analysis requests; format template alone gives 1.0000/0.9952; removing it collapses calls to 6.32e-7.
  • Formation is suppression-dominated. MLPs supply 77.7% of the L20–L23 projected write; L23 κ ratio 4.18; analysis-side feature family |κ| 0.0633 vs 0.0156 for execution-side.
  • Causal validation. Zeroing the 5 trained suppressors lifts call rate 3.0%→25.5% (random control +0.5%); restoring the lost μ_Δ write at L24 recovers 200/200 clean calls.
  • Readout. Heads L29H9/L33H11/L33H29 plus MLP34·F109925 commit the decision: L33H29 DLA 11.13→24.43 under μ_Δ addition; F109925 swap alone yields 37.0% calls vs 6.5% control.
  • Replicates qualitatively across 7 models (Qwen3-4B→30B-A3B, Mistral-Small-3.2-24B, Granite-3.3-8B): patch recovery 93.5–100%, κ_corrupt > κ_clean in every model — but transfer spans 43.0–100% and layers vary L22–L35.

Strengths

  • A rare causal handle on a decision that matters in deployed agents — clean 0↔100% flips with a proper control behind every intervention (norm-matched vectors, layer-matched suppressors, length-matched scaffolds).
  • The suppression account is quantitatively grounded: write shares, per-layer κ ratios, feature-family contrasts, and a causal zeroing experiment — not narrative.
  • Disciplined generalization ladder inside one model (new tools → native trajectories → verb-free requests) before any cross-model claims.
  • Honest reporting: weak native-trajectory numbers stated plainly; claims explicitly bounded to the binary decision and fixed scaffold.
  • Code and prompt data released; public benchmarks only (MBPP, APPS, HumanEval, τ²-Bench).

Limitations

  • Trained and analyzed only on behaviorally screened coding pairs under one fixed scaffold; other prompt constructions untested (authors concede this).
  • Binary outcome only — argument validity and task completion are out of scope, so steering’s effect on agent utility is unknown; a 100% induced call rate says nothing about usefulness.
  • Cross-model replication is qualitative, not quantitative: decision layers vary L22–L35; Granite-3.3-8B reaches only 43.0% domain transfer and 35.5% verb-free suppression — no portable “tool-call direction”.
  • A single mean-difference direction is a lossy summary; no comparison against alternative steering baselines (SAE-derived directions, per-component ablations).
  • Native-context steering needs gain tuning (1.5× for full verb-free suppression); the hybrid-attention model’s attention statistics are partially omitted.

Questions for further exploration

  1. Do induced calls actually help — are arguments valid and tasks completed, or does μ_Δ injection manufacture spurious calls on tool-free requests?
  2. How does the vector behave under thinking-mode Qwen3, where the decision may not reduce to one first-token prediction, and on non-coding scaffolds like ReAct?
  3. Is this MLP-window suppression machinery also how RLHF- or agentic-SFT-trained models encode “when not to call” — and can training amplify or remove it?
  4. What state component is missing in native trajectories (1× suppression only 36.7%) — would a trajectory-conditioned, in-context vector close the gap to 100%?
  5. Do the suppressor families overlap with refusal-direction circuitry, suggesting a shared “override the default action” circuit across safety and tool-calling?
