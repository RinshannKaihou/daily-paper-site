Methodology

State owned by the harness; context rebuilt per invocation

Conversation history is never the memory — every call is reconstructed from explicit research state.

STATEHarness holds durable state: candidate solutions, scores, evidence log — persists across all calls; checkpointed for recovery and ablations.
ADVISOREach epoch, a fresh context: task spec + global best + evidence grouped by search direction (a measured non-improvement ≠ an exhausted direction). Assigns concrete, non-overlapping experiments to W parallel Workers.
WORKEREach trial, a fresh context: only its assignment, its retained local candidate, compact feedback. No shared workspaces — cross-Worker evidence flows only through assignments. Local bests are kept so young approaches mature.
EVALIndependent protected evaluator scores every candidate outside Worker environments; outcomes feed back into state.

Statelessness is enforced, not requested: new session each epoch, Workers run as unprivileged processes under Linux Landlock sandboxing, saved sessions cleared, built-in subagents disabled.

Codex CLI v0.152.1 + GPT-5.5 Claude Code v2.1.258 + Opus 4.8 W=3 default 9 tasks · 3 families budgets 200M–1B tokens baselines: EvoX · CORAL · SwarmResearch

Strengths

  • Clean, implementable principle that attacks documented failure modes — context rot, duplicated work, premature stopping — with mechanism-level and trace-level evidence (CORAL case studies).
  • The right evaluation methodology: token-based budgets with three cutpoints, and the demonstrated rank reversal is a genuinely important caution for the field.
  • Enforced statelessness (Landlock sandboxes, cleared sessions, protected evaluators) makes design claims verifiable; checkpoint ablations isolate each component from identical starting states.
  • Strong numbers at unprecedented budgets — 1B tokens, all-3-vs-all-9 kernel dominance — with honest reporting of losses and single-run caveats.
  • Practical corollaries: coordination is nearly free, Worker model can be picked per task at matched cost, and Worker trials are shaped like bounded RL episodes.

Limitations

  • Most main results are single runs — only the Anthropic kernel task is replicated; FrontierSWE / SOL-ExecBench / FrontierCS point estimates carry no uncertainty quantification.
  • The principle itself is never directly ablated: ablations change what agents see, not whether they keep conversations — no stateful-harness control under matched prompts.
  • Nine headroom-filtered tasks with fast, executable evaluators; saturated problems and open-ended goals (noisy / slow / subjective feedback) are untested, and evaluator gaming is only mitigated.
  • Token-matched cost accounting excludes evaluator compute and ignores differing cache share — dollar-cost conclusions are approximate.
  • Optimal Worker width is task-dependent (W=1 Lua, W=3 Dart, W=7 libexpat); the default W=3 is safe but rarely optimal.

Questions for further exploration

  • Does harness-owned state + fresh contexts still help when feedback is noisy, slow, or subjective (hypothesis-driven science, paper-quality objectives)?
  • Can Worker trials serve as RL episodes to post-train Workers or the Advisor — and would a trained Worker obsolete explicit assignment?
  • How much of the gap comes from Appendix E’s ~7 pages of task-specific prompts? A baseline-with-equivalent-prompts ablation would disentangle framework from prompt effort.
  • Rankings reverse between 25% and 100% budgets — is there a cheap early-horizon signal predicting “tokens-to-match”?
  • Can outcome records seed cross-task memory (e.g. an ACE-style playbook), and does statelessness extend to Advisors over partial views of a very large research state?
