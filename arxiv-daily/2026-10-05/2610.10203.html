Model organisms validated on behavior rate alone are broken testbeds: three-axis validation shows SFT degrades capability that DPO-plus-merging nearly restores.

Why this matters

Interpretability results are only as trustworthy as the testbeds they run on — this offers a reusable recipe for building organisms that don't distort the audit.

Critical edge

The headline validation↔auditability link is correlational, as the authors concede — no intervention isolates one criterion while holding behavior fixed, and the proxies are Goodhart-able.

Methodology

  1. 01 InstallLoRA SFT / DPO on trigger sets
  2. 02 Validatethree axes, each vs base
  3. 03 Mergeinterpolate toward base, ratio q
  4. 04 Auditbudgeted agent + whitebox tools
Behavior installation
High trigger-set rate r, low counterfactual rate rₙ — unconditional triggering is penalized.
Capability preservation
MMLU accuracy + MT-Bench chat quality, both normalized to the base model.
Output naturalness
CoT classifiability on GSM8K pairs (≈50% chance = indistinguishable); Patchscopes activation detectability dact-aud → 0.

Recipes: SFT vs DPO (preference pairs) vs +Chat (1:1 general chat data); +Merge sets W = (1−q)·Wt + q·Wbase, treating the base model as the constraint-aligned endpoint (a SACPO adaptation).

Testbed: a new clinical-bias suite on Llama-3.1-8b-it — three demographic biases over MedQA / MedBullets / MedXpertQA-style MCQs, 1,500 trigger + 500 counterfactual samples per bias; N = 163 organisms audited under a 15-turn / 40k-token agent budget with honesty steering, Jacobian lens, and SAE features.

  • Merging toward base is nearly free. At q = 0.8 the target rate is statistically unchanged (0.74 vs 0.72) while in-domain accuracy recovers 0.82 → 0.97 and CoT naturalness 0.91 → 1.0; only q ≤ 0.6 drops behavior below thresholds.
  • Chat mixing backfires. All six recipe pairs degrade CoT naturalness by 0.028–0.157; bullet-formatted reasoning traces hit 11.1% vs 1.5% un-mixed (UltraFeedback style leakage).
  • Validation predicts auditability. Logit-lens rule recovery: ΔR² = 0.25 (p < .001); Lottery-suite correlations ρ = +0.70 (MMLU); CoT verbalization ρ = +0.73.
  • Auditability is bias-dependent. Recovery ranks race > gender > age; honesty steering reduces age-bias recovery by ≈0.21; DPO beats SFT on every clinical bias, the gap dominated by in-domain medical accuracy (SFT trails by 0.097–0.160).

Strengths

  • Correct, timely reframing: organisms are measurement instruments that must themselves be validated — none of 12 prior suites reported all five axes.
  • Exceptional breadth: 80 retrained Pando + 19 Lottery + a new 163-organism clinical suite, with significance tests and recipe ablations.
  • Converts a pre-registered hunch (Tan et al. 2026) into quantitative evidence (ΔR² = 0.25; ρ = +0.70/+0.61/−0.58).
  • Falsifiable, actionable recipes — including a negative result against a previously recommended practice (chat mixing).
  • Full code / data / checkpoint release, clinical consultation, transparent AI-use statement.

Limitations

  • Validation↔auditability link is correlational; the criteria are proxies for “realism” and Goodhart-able targets.
  • Judge-heavy stack — naturalness, MT-Bench, and investigation scores share one judge model family, so several numbers partly measure judge idiosyncrasy.
  • Merge-ratio sweep deeply characterized on only one age-bias organism; behaviors needing larger parameter shifts untested.
  • Clinical realism bounded: MCQ land, synthetic triggers, one-feature counterfactuals — far cleaner than real EHR correlation.
  • Small base models (gemma-2-2b-it, Llama-3.1-8b-it); frontier-scale transfer unverified.
  • Whitebox conclusions rest on three tools and one fixed agent budget.

Questions for further exploration

  1. Can the validation↔auditability link be established causally — matching organisms on all but one criterion while holding target behavior fixed?
  2. Does near-free merging (q = 0.8 preserving behavior) generalize to behaviors needing larger parameter changes, like persistent deceptive CoT or multi-step backdoors?
  3. Can judge-independent naturalness metrics (embedding- or probing-based) replace the LLM-judge stack and break single-judge circularity?
  4. Would the race > gender > age recovery ordering persist with human auditors, larger budgets, or stronger whitebox tools?
  5. Do the conclusions transfer to frontier-scale base models, where SFT-induced capability loss may behave differently?

一句话总结：当前模型生物只优化目标行为的训练范式不充分——SFT 使 MT-Bench 掉到基座的 85.7%、CoT 自然度只剩 40.7%；改用 DPO 并向基座权重合并，可在目标行为率几乎不降（0.72→0.74）的前提下几乎完全恢复能力，且验证指标能显著预测下游可解释性审计工具能否找回植入行为。
