Train a model on one value and you shift the other 65 — activations predict how, text descriptions don’t.

从 Anthropic Constitution 提炼 66 个值，在 4 个开源模型上以单值 DPO / SFT 各微调一遍，构建 49,666 次测量的「对齐泛化矩阵」：persona vectors 相似度远比文本描述嵌入更能预测跨值迁移（ρ=0.45 vs 0.05，可预测上限 0.89）。

Predicting Alignment Generalization with Value Representations Andy Liu · Mehar Bhatia · Karolina Stańczak · Mona Diab, et al. — CMU / Mila / ETH / UBC / Vector Institute · 2026-10-05

Key metric

ρ 0.45 vs 0.05

Persona-vector similarity vs description-embedding similarity for predicting the 49,666-measurement generalization matrix. Predictability ceiling: 0.89.

Why this matters

Activation geometry forecasts post-training behavioral side effects, so alignment targets can be screened cheaply before expensive fine-tuning runs.

⚠ Critical edge

The headline number is modest, not just the baseline: ρ=0.45 against a 0.89 ceiling, and part of the margin over descriptions is elicitation data, not model internals.

01Methodology

How the generalization matrix was built and scored.

  1. 0166 values distilled from Anthropic’s Constitution — 211 tenets → LLM-judge filter → manual dedup. Excludes hard constraints / catastrophic-risk tenets by construction.
  2. 02528 fine-tunes = 66 values × 4 open models (Olmo-3-7B/32B, Qwen3-8B, Qwen3-30B-A3B) × 2 regimes: single-value DPO (~1,000 preference pairs/value) and SFT (5,000 synthetic prompts/value).
  3. 0311,188 value-conflict scenarios from ConflictScope, adherence scored by an LLM judge.
  4. 04Matrix G: 49,666 measurements of G(v₁,v₂) — the fraction of the remaining alignment gap to v₂ closed by fine-tuning on v₁, clipped to [0,1].
  5. 05Score 5 representations by Spearman ρ between their pairwise-similarity grids and G, all using identical generic elicitation data. Ceiling = 0.89 (G vs its symmetrized self).

The five candidates: DESCRIPTION-EMBD (embed the definition), BEHAVIOR-EMBD (embed pro/anti responses), WEIGHT (task vectors), PERSONA (per-layer mean-activation differences), GRADIENT (DPO-loss gradients on activations).

  • Shared value space: the eight 66×66 persona-similarity matrices correlate pairwise at 0.75–0.93 (mean ρ=0.54) — a largely model-independent encoding of value relationships.
  • Coherence predicts robustness: persona coherence of 6-value targets predicts adversarial-prefill robustness across 64 Qwen3-8B DPO fine-tunes (ρ=0.43, p=5×10⁻⁴); description coherence does not (ρ=0.12, n.s.).
  • VALUEMAP taxonomy: k-medoids (k=4) on persona vectors clusters 266 Values-in-the-Wild values into attunement(70) / rigor(55) / stewardship(89) / integrity(52); adjusted silhouette 2.61 vs 1.62 (LimnusValues) and 0.95 (Values in the Wild).
  • Regime match: GRADIENT peaks where it is trained (ρ=0.54 on Olmo-3-7B DPO); PERSONA is most uniform (0.39–0.51 everywhere); the description baseline never exceeds 0.10 in any setting.

Strengths

  • A genuinely new, well-posed prediction task with an unusually large controlled artifact: 49,666 ground-truth measurements across 4 model families and 2 post-training regimes, all open-weight.
  • Fair, ceiling-calibrated comparison of five representation families under identical elicitation data — no privileged-data advantage.
  • Practical payoff shown twice: coherence as a cheap pre-training predictor of adversarial robustness, and a taxonomy that tracks generalization better than current text-based ones.
  • Honest reporting: bootstrapped CIs, a predictability ceiling, a bounded steerability metric, released code and data.

Limitations

  • Best predictability is ρ=0.45 (ceiling 0.89) — none of the five methods can yet replace a real training run for target design.
  • Only open-weight 7B–32B models (Olmo-3, Qwen3); nothing on frontier or heavily RLHF-ed models, where value encoding may differ.
  • Ground truth rests on synthetic ConflictScope scenarios and LLM-judge scores; construct-validity limits are inherited by every conclusion.
  • Each application is demonstrated on a single model and configuration (Qwen3-8B DPO; Olmo-3.1-32B-SFT embeddings) without ablations.
  • The value set excludes extreme-risk / hard-constraint tenets by design; VALUEMAP’s silhouette is internal validation, not behavioral.

03Questions for further exploration

  1. Do activation-based predictors keep their edge for RL-based post-training (RLHF / GRPO), or does the GRADIENT advantage shift with on-policy updates?
  2. Can value embeddings predict negative generalization — emergent misalignment, sycophancy side effects — rather than only positive transfer?
  3. Would a frontier-scale, instruction-tuned model close the description-vs-activation gap, or does the headroom to 0.89 indicate missing structure?
  4. Can VALUEMAP’s four categories be validated behaviorally (cluster-level conflict rates, robustness profiles) rather than by silhouette on the design matrices?
  5. How much of the remaining headroom to the 0.89 ceiling is LLM-judge label noise versus genuinely uninformative representations?
