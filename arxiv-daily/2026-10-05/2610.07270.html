Does the Model Use the Feature? Separating Steering from Mechanism in LLMs

Key metric 0.12 vs +46.0 pp of steering

Fraction of the natural known–unknown abstention contrast transferred by paired interchange (latent L15/1898) — although the published steering lifts abstention 33.0% → 79.0%.

Why this matters

Hands the interpretability community a ready-to-apply checklist for the gap between “changes behavior” and “is actually used” in any feature-intervention paper.

Critical edge

Downstream rescue was never run on the audited Gemma latents — the “barely used” verdict rests on removal-only lower bounds.

Methodology — the empirical contract

association→ control→ sufficiency→ use

Every claim pair uses a comparison input c₀ (behavior expected lower) and a target c₁ (higher); the natural contrast Δnat is measured first. Sufficiency and use are tested only at feature values observed on natural inputs, reported with 95% intervals instead of thresholds.

Interchangeρ_install Copy c₀’s feature value into c₁; the fraction of Δnat reproduced is the sufficiency strength.
Removalρ_remove The reverse edit — how much of the contrast disappears when the feature is knocked out.
Downstream rescueρ_rescue Hold an upstream edit in place, restore the feature’s natural value downstream; the reversed fraction. Use strength = max(ρ_remove, ρ_rescue).
use = max(ρ_remove, ρ_rescue)  ·  run only when Δ_nat > 0 (95% CI)

SAE writes matter: the decoder update writes along decoder columns; the encoder-constrained update re-encodes to match the request (residual error ≤ 1e-3). No-op controls verify achieved values; out-of-tolerance edits are not scored.

Audited: Gemma-2-2B-IT Llama-3.1-8B Pythia-70M on Wikidata entity familiarity (Ferrando latents L13/7957, L15/1898), Marks et al.’s 147-feature subject–verb agreement set, and Arditi et al.’s refusal direction. LLM judge validated at 0.94 balanced accuracy vs human double labels.

  • The natural range is the whole ballgame. A target at the latent’s 95th percentile moves abstention just +1.5 pp; a value beyond every unedited activation moves it +12.0 pp — steering “works” only off the natural manifold.
  • The latent is not the carrier. Rare-alias phrasing costs −11.2 pp accuracy; copying the full residual state recovers it, copying only the latent’s value changes accuracy by −0.2 pp.
  • Positive control confirms the tests are passable. The refusal direction raises instruction refusal +29.0 pp within its natural range — yet single-site removal (−6.0 pp) vs full ablation (−45.0 pp) shows one edit probes one location of a multi-layer computation.

Strengths

  • Operational claims as reportable quantities (ρ_install / ρ_remove / ρ_rescue with 95% intervals), not pass/fail slogans.
  • Both positive controls genuinely pass — the tests are satisfiable, not designed to fail everything.
  • The update-rule finding (decoder 0.946/0.877 vs encoder-constrained 0.799/0.560) is a non-obvious, practical result about write location.
  • Measurement hygiene: blinded LLM adjudication validated against human double labels, no-op controls, dev/holdout discipline, honest “not run” cells.
  • Audits exact published latents (L13/7957, L15/1898) rather than strawmen.

Limitations

  • Small-model scope (70M / 2B / 8B) and three narrow single-concept tasks; distributed knowledge in larger models is untested.
  • Rescue not run on the Gemma latents — use strength is only a lower bound, weakening the strongest negative claim.
  • One LLM judge flows through every abstention delta; its error is correlated across results.
  • Single-site tests under-measure multi-layer features (refusal: −6.0 pp single-site vs −45.0 pp full ablation).
  • No new method or capability — an audit framework; the codebase is only “released upon publication”.

Questions for further exploration

  1. Does the natural-range criterion hold for distributed factual knowledge in 70B+ models, where no single “natural value” dominates?
  2. Can the contract be automated into a community benchmark that scores published interpretability claims (a RAVEL extension)?
  3. Would downstream rescue on the Gemma latents — omitted here — lift their use strength above the removal-based lower bounds?
  4. How should the contract handle multi-feature interventions, where effects often emerge only from combinations?
  5. Is the decoder-vs-encoder update asymmetry specific to Pythia-70M’s SAE geometry, or does it reproduce for modern gated/TopK SAEs?
