> **一句话总结：** 清华×NVIDIA×浙大×MIT 针对 MLE agent 的两大单机失效现象——长程"推理强度衰减"（单 agent 输出 token/响应从 0–2 小时到 3–5 小时下降 29.8%–45.0%）与"harness 陈旧"（专用 harness 的增益随底座模型升级消失甚至反转）——提出 HMA：让两个保持原生 harness 的完整 agent 在共享工作区上交替执行、每次至多 k=5 个实验即中断并重置上下文，并形式化为 context-reset 半马尔可夫决策过程（CR-SMDP）证明交替可超越单 agent 参考极限；在 MLE-bench 75 个 Kaggle 竞赛、6 小时预算下任一奖牌率达 78.2%，超过最强单 agent Claude Opus 5（72.4%）与最强已发表开源工作流 ScienceFlow（70.2%）8.0 个百分点。

> **TL;DR:** The paper documents two failure modes of single-agent long-horizon MLE: reasoning intensity decays (mean output tokens per response falls 29.8%–45.0% from hours 0–2 to 3–5 across six models) and harness staleness (specialized harnesses like ScienceFlow/ML-Master 2.0/MLEvolve beat the native DeepSeek harness on DeepSeek-V4-Flash but all fall below it once the backbone upgrades to V4.1). HMA (Humanize MLE Agents) instead alternates two complete native agents (e.g., Claude Opus 5 + GPT-5.6-sol) on one shared workspace, hard-interrupting each session after k=5 experiments with a full context reset, plus a cross-agent final review. Modeling this as a context-reset semi-MDP, the authors prove alternation exceeds the best single-agent limit under retention + cooperative-access assumptions and that fixed-k interruption preserves the advantage. On MLE-bench (75 Kaggle competitions, 6-hour budget), HMA reaches 78.2% any-medal rate vs 72.4% for the strongest single agent (Claude Opus 5) and 70.2% for the best published workflow (ScienceFlow, which used 12–24h budgets) — +8.0 points — and beats its own constituent agents' average in all six tested pairs by 6.4 points on average. A 48-hour kernel-optimization case (Anthropic AOPT) reaches 878 cycles, within 1.6% of the community leaderboard leader.

## 核心贡献

- **量化两大单 agent 失效现象**：跨 6 个模型（GPT-5.6-sol、Claude Opus 5、GLM-5.3、Kimi K3、DeepSeek-V4-Flash 等）测得"长程减速"——/goal 模式下输出 token/响应在 3–5 小时窗口较 0–2 小时下降 29.8%–45.0%；跨 3 个专用 harness 测得"harness 陈旧"——在 DeepSeek-V4-Flash 上 ScienceFlow 领先原生 harness 8.3 个百分点（25.0% vs 16.7% 奖牌率），但换 V4.1-Flash 后原生 harness 达 77.1%，ScienceFlow/ML-Master 2.0/MLEvolve 分别落在 68.8%（−8.3）、37.5%（−39.6）、50.0%（−27.1），全部反转为负收益。
- **CR-SMDP 理论**：把交替会话建模为上下文重置半马尔可夫决策过程；Theorem 3.3 在"结果保留"+"协作可达"（条件成功率 α·β>0）假设下证明联合交替的渐近性能超过单 agent 参考族上限 U*；Corollary 3.4 给出充分实验预算 N ≈ (2k/α)log(1/(1−p₀))；Theorem 3.5 给出固定 k 中断保持优势的条件 Δ+A>0，Corollary 3.6 证明中断损失几何衰减时有限小 k 即可。
- **HMA 工作流**：在共享工作区（代码、工件、已评估候选归档）上交替两个原生 agent，k=5 实验/会话硬中断+上下文全重置，收尾由另一 agent 做最终评审；经验上 k=5 保留 97.83% 的观测增益且只花 73.77% 的会话内实验（11 种配置、1,065 个 option 的前缀分析 + KL 同时置信界支持 k≤5 候选集）。
- **SOTA 与跨任务泛化**：MLE-bench 75 任务 6 小时预算下 78.2% 任一奖牌率（Gold 53.8%、Med+ 90.7%、平均百分位 89.0）；6 个异构 agent 对全部超越成员平均（平均 +6.4 点）；48 小时 AOPT 核优化单次运行达 878 cycles，距社区榜首 864 仅 1.6%。

## Key Contributions

- **Two empirically grounded failure diagnoses**: long-horizon deceleration (output tokens per response, a proxy for reasoning intensity, drops 29.8%–45.0% between hours 0–2 and 3–5 across all six single-agent configurations) and harness staleness (specialized-harness gains over the official harness shrink or reverse as the backbone improves), motivating workflow-level coordination instead of more harness engineering.
- **A CR-SMDP formalization with actionable theory**: sufficient conditions (retention of best result; cooperative access with per-cycle success α·β) under which alternating sessions provably exceed the single-agent reference ceiling (Theorem 3.3), a sufficient experiment budget of leading form (2k/α)·log(1/(1−p₀)) (Corollary 3.4), and an interruption theorem showing fixed-k capping preserves the advantage when Δ+A>0 (Theorems 3.5, Corollary 3.6).
- **HMA, a minimal workflow**: alternates complete native model–harness pairs unchanged, resets context at every handoff (at most k experiments per session), and reserves 900s for a cross-agent final review over the candidate archive — no task-specific knowledge, no prior initialization, no prompt engineering.
- **State-of-the-art MLE-bench results with cross-pair generality**: 78.2% any-medal (best config) exceeding the strongest published open-source workflow by 8.0 points under a 4× shorter budget, gains in every one of six heterogeneous pairs, plus mechanism-level evidence (86.4% vs 60.7% token-length retention) and an exploratory 48-hour kernel-optimization application (878 cycles, 1.6% from leaderboard leader).

## Methodology

**Motivation measurements.** Six single-agent configurations (GPT-5.6-sol/Codex, Kimi K3/Kimi Code, GLM-5.3/Claude Code, DeepSeek-V4-Flash and V4.1-Flash/DeepSeek Harness, Claude Opus 5/Claude Code; max reasoning effort) run /goal mode on 75 MLE-bench tasks ×3 repeats ×6h. Mean output tokens per recorded response in a trailing 30-minute window proxies reasoning intensity. Harness staleness is measured by running ScienceFlow, ML-Master 2.0, and MLEvolve with their original designs (cold-start knowledge disabled) on a 16-task MLE-bench subset, on both DeepSeek-V4-Flash and V4.1-Flash, against the official DeepSeek Harness.

**CR-SMDP formulation.** State x = (W, E, c): shared workspace W, retained best result E, active agent context c. Each agent session is an option with internal policy and termination rule; option boundaries preserve (W, E) and reset c to ∅. Quality q(E) ∈ [0,1] is normalized leaderboard position; Assumption 3.1 requires the retained result never degrades (q(E_{n+1}) ≥ q(E_n)). Assumption 3.2 (cooperative access) requires each agent to reach states useful to its partner with conditional probability ≥ α and the partner to reach high-quality set T with probability ≥ β, giving per-cycle success a = α·β. Theorem 3.3 then bounds failure: Pr(q(x_{2km}) < τ) ≤ F₀(1−a)^m, so the alternation limit exceeds every reference workflow's limit U*. Corollary 3.4 converts this into a sufficient budget N ≈ (2k/α)log(1/(1−p₀)). Section 3.3 compares fixed-k interruption against natural-termination alternation (NTA) via the interruption theorem: the capped policy beats U* whenever the expected net gain A plus the NTA margin Δ is positive, and a finite cap k ≤ O(log N) suffices when interruption losses decay geometrically.

**Empirical cap selection.** A prefix analysis over 11 configurations (6 goal + 5 NTA pairs, 75 tasks, 1,065 options) shows the first k=1/3/5 experiments within an option retain 63.15%/93.35%/97.83% of observed gains using 24.76%/54.88%/73.77% of within-option experiments, with simultaneous KL lower confidence bounds (M_cmp = 1100, δ = 0.05); individual configurations retain 96.11%–99.20% at k=5, motivating candidate caps k ≤ 5.

**HMA workflow (Algorithm 1).** Stage 1 initializes (W₀, E₀, ∅). Stage 2 alternates agents A, B: each session runs until it completes k=5 accepted experiments or the 6h budget; every evaluated candidate (with its author) is appended to the archive E. Stage 3 reserves 900s (exploration ends at 20,700s of 21,600s) for the other agent to review the archive and select the final candidate without test-set access, falling back to the latest pair if review fails. Implementation builds on the Humanize framework; each task run gets one NVIDIA A10 GPU and a 6-hour budget; every configuration is evaluated in 3 independent repeats.

**Evaluation.** MLE-bench Lite (22)/Medium (38)/High (15) medal rates, overall any-medal and Gold and Med+ (outperform human median) on all 75, mean leaderboard percentile. Baselines: their own single-agent runs (matched 6h budget, "Avg. of Single" rows) and published numbers for ScienceFlow, MLEvolve, ML-Master 2.0 (12–24h budgets, different backbones).

## Results & Highlights

- **Headline MLE-bench result (75 tasks, 6h, k=5, 3 repeats):** Claude Opus 5 → GPT-5.6-sol HMA scores 78.2±1.5% any-medal vs 72.4±1.6% for the strongest single-agent baseline (Claude Opus 5 native) and 70.2±1.2% for the best published open-source workflow (ScienceFlow) — +5.8 and +8.0 points respectively; Gold 53.8±1.7%, Med+ 90.7±1.7%, mean percentile 89.0 (Lite/Medium/High: 84.8/80.7/62.2). Published workflow baselines used 12–24h budgets; HMA used 6h.
- **Generality across pairs:** across six heterogeneous pairs whose constituents span 54.2%–72.4% any-medal, HMA beats the constituent average in every configuration, by 6.4 points on average — e.g., GPT-5.6-sol↔Kimi K3: 81.8±0.5% vs 61.1±0.7% (+20.7); smallest gain DeepSeek-V4.1-Flash↔Kimi: 62.7±1.5% vs 57.8±1.1% (+4.9). The reverse order GPT→Opus also helps (73.3±1.6% vs 70.2±1.1% average), so the advantage is not tied to one initial agent.
- **Mechanism — deceleration countered:** from hours 0–2 to 3–5, HMA's mean output tokens per response falls only from 610.9 to 527.6 (retains 86.4%) while matched single-agent goal runs fall from 650.3 to 394.9 (60.7%); HMA medal-rate curves keep climbing through hour 6 while single-agent curves flatten.
- **Cap and order ablations (GPT↔Kimi, 75 tasks):** executed caps k=1/3/5 yield 65.3%/66.7%/70.7% medal rates (GPT goal alone: 68.0%); under natural termination the starting-order gap is 21.3 points (77.3% GPT-first vs 56.0% Kimi-first), which HMA k=5 narrows to 4.0 points (70.7% vs 66.7%). The cap also accelerates partner access: second-agent output-token share before 5.75h rises from 13.0% (NTA) to 36.1% (HMA), and all 75 tasks get a second-agent response by 5.75h under HMA vs 19/75 under NTA.
- **Final review pays for itself:** across 450 task runs it changes 8.9% of selections and raises historical any-medal retention from 311/330 (94.2%) to 319/330 (96.7%) with zero losses; missed historical medals drop from 19 to 11 (e.g., on MBM-20, GPT-GLM's review restores a 0.84835 candidate after a 0.25403 regression).
- **Beyond MLE-bench (exploratory, single run):** on Anthropic's AOPT kernel-optimization task, Claude Opus 5.5 ↔ GPT-6-astra alternation (cap 3) reaches 878 cycles at 34h33m of a 48h run — 14 cycles (1.62%) above the leading community-leaderboard score of 864 and equal to the 10th-ranked reported score (a comparison of reported scores under a separate nine-seed judge, not a verified placement). Case studies: INGV final MAE 34,234 = 46.5% below the best of six constituent goal runs; Google QUEST Spearman 0.50747 vs 0.47252; Smartphone Decimeter 2.77310 m vs 4.78536 m (−42.1%).

## Critical Assessment

**Novelty.** The core mechanism is deliberately simple: context reset + shared-workspace persistence + a hard k-experiment cap. The genuinely new elements are (a) treating each model–harness pair as an indivisible option and coordinating at the workflow level rather than modifying harnesses, (b) the harness-staleness negative result, which undercut the premise of an active harness-engineering line (ScienceFlow, MLEvolve, ML-Master), and (c) the CR-SMDP analysis connecting option interruption theory to agent handoffs. The idea sits close to the cited handoff-tax / population-handoff work (Ganz et al., Luo et al., Li et al. 2026); the paper's distinct claim is that alternation of complete *heterogeneous native* agents exceeds both constituents under matched budget — and the six-pair table supports that.

**Rigor — the headline comparison is confounded.** The abstract's "exceeding the strongest published open-source workflow by 8.0 points" compares HMA running frontier GPT-5.6-sol/Claude Opus 5 at 6h against ScienceFlow (DeepSeek-V4.1-Preview, 24h), MLEvolve (Gemini-3.1-Pro, 12h), and ML-Master 2.0 (DeepSeek-V3.2, 24h) — different backbones, budgets, and protocols. The honest delta is the same-model one: +5.8 over Claude Opus 5 itself. The paper is transparent about this (Avg. of Single rows, Table 5), but the framing leans on the cross-paper number. Also note DeepSeek Harness's own jump from 16.7% to 77.1% across V4→V4.1 shows backbone choice dwarfs workflow effects — which cuts both ways for the paper's own conclusion.

**Theory–practice gap.** Assumption 3.1 (result retention) is enforced partly by the final review itself, i.e., partly by construction; the cooperative-access constants α and β are never estimated, so Theorem 3.3 is a pure sufficiency result that cannot predict which pairs will gain or by how much, and Theorem 3.5's condition Δ+A>0 is not checkable a priori. The theorems justify the design but do no predictive work; the actual cap k=5 is chosen empirically.

**Missing comparisons and residual weaknesses.** There is no budget-matched baseline of simply running the two agents independently (e.g., two sequential/parallel 6h runs, pick best) — the cheapest alternative explanation is diversity + selection, not alternation per se; NTA is the only no-cap control. Starting order still matters (NTA: 21.3-point gap; HMA residual: 4.0), the authors report 7/75 tasks with recorded starting-order exceptions in the NTA archive (making those comparisons "configuration comparisons rather than perfectly controlled interventions", by their own admission), final review silently failed in 4 GPT↔GLM runs and 1 DeepSeek run, and on PetFinder the returned candidate (16.8569 RMSE) regressed from the best observed value (16.77953) — artifact reuse improves search but does not guarantee the returned candidate is the run's best. The AOPT result is a single run compared against reported leaderboard scores under a different nine-seed judge; the paper flags this correctly but it is still the abstract's second headline.

## Strengths

- Reframes an active research direction with a well-evidenced negative result: harness gains are not version-stable, so workflow-level coordination of native agents is a more durable lever.
- Rare theory–measurement–ablation loop: the interruption theorem motivates short caps, the prefix analysis (with simultaneous confidence bounds) selects k, and the executed cap ablation (65.3/66.7/70.7 for k=1/3/5) confirms the choice within the tested range.
- Mechanism-level evidence, not just end scores: output-token-per-response retention (86.4% vs 60.7%) links the intervention to the diagnosed failure mode, and final-review retention is audited per configuration (Table 13).
- Exceptional transparency for a systems paper: published-baseline configurations tabulated, deviations and silent failures documented, test scores computed offline, three repeats with ± values, code released.

## Limitations

- Pair- and order-dependent gains: the weakest pair (DeepSeek-V4.1-Flash↔Kimi) gains only +4.9 points, and no predictive rule exists for which pairs or starting orders will benefit; α, β are unestimated.
- All main evidence is at a 6-hour horizon; whether HMA's advantage persists over 24–48h MLE-bench runs (where deceleration bites hardest) is only probed by the single-run, differently-judged AOPT case.
- No budget-matched comparison against independent multi-run selection (best-of-2), leaving "alternation vs diversity+selection" not fully isolated; the cross-workflow SOTA claim is confounded by backbone model choice.
- MLE-bench medal rates are coarse and leaderboard-size dependent; the k=5 optimum is established only among {1,3,5} plus prefix evidence, on one starting order.

## Relevance

与你关注的 LLM agent 与长程自动化方向高度相关：它用可控实验和 option 理论证明"上下文重置 + 共享状态持久化"的会话级编排能在等算力下突破单 agent 极限，且"harness 增益随模型升级而陈旧"的发现对任何在做 agent harness/工作流工程的人都是直接的设计警示。方法零任务先验、只需两个现成 agent，可复现性和迁移成本都低。

## Questions for Further Exploration

- How does HMA compare against a budget-matched best-of-2 (two independent runs of one agent, pick the better result)? This would isolate whether alternation itself matters or the gain is mostly diversity plus archive-based selection.
- Can α and β (cooperative access) be estimated online from execution traces to predict which pairs gain, choose the starting order, and adapt k per task instead of the global k=5?
- Does the advantage survive 24–48h horizons on MLE-bench itself, or does harness staleness re-emerge as models improve within the workflow's lifetime?
- Is the gain driven by model diversity or harness diversity? Alternating two harness variants of the same model (same weights, different harnesses) would cleanly separate the two.
- The cap bounds experiments per session but not wall-clock time (GPT-first sessions still consume most of the budget); is an explicit time-allocation policy superior to fixed-k experiment caps?
