> **一句话总结：** MEMENTO 3 让参数完全冻结的 LLM 把对陌生环境的理解同时写成自然语言"规则书"（语义记忆）和由它编译出的可执行代码世界模型（Code as Model），通过"观察→反思→规则修订→编译→验证"的循环持续自我修订；在 ARC-AGI-3 上通关全部 25 个公开游戏的 183 个关卡，平均 RHAE 满分 100.0，总动作数仅为人类的 44%，学到的规则书还能编译成不看帧、零 LLM 调用的 Atari Pong 控制器，3 局全胜 21:0。

> **TL;DR:** MEMENTO 3 turns a frozen LLM into a self-revising world-model learner ("Code as Model"): environment hypotheses live in a natural-language rulebook that is compiled into an executable Python transition function, and updates are accepted only after an LLM fidelity check plus cell-exact replay of every recorded transition. On ARC-AGI-3, the single-model agent clears every level of all 25 public games with a ceiling mean RHAE of 100.0 using 7,518 actions — 44% of the 17,135-action human baseline — versus 99.0 RHAE / 0.49x for the strongest baseline1 and a 59.3-point RHAE gain over Claude Opus 5 on the ARC Prize Standard harness. On Atari Pong, a feedback controller compiled from the learned rulebook wins 21:0 in all three evaluated openings at a learning cost of 9.5x10^3 emulator frames, versus 2.0x10^8 for model-free RL (GDI/LASER/IMPALA/Rainbow) and 4.0x10^5 for EfficientZero-class model-based RL.

## 核心贡献

- **Code as Model 双重表示**：agent 的世界模型假设 = 自然语言规则书 ψ（Markdown 记录对象、动作语义、动力学、目标与未决假设，充当持久语义记忆）+ 由规则书编译出的可执行实现 θ（Python 转移函数，供预测、规划与重放验证）。规则修订改变"agent 相信什么"，实现修复只改"规则如何被应用"，两层解耦。
- **持续反思学习循环 + 执行锚定的验证**：每步交互走 观察→反思（retain / revise_rulebook / repair_code 三选一）→规则修订→编译→验证；新模型只有在 (a) 冻结 LLM 判定代码忠实实现规则书 且 (b) 对全部历史转移逐格重放（每个 64x64 帧完全匹配）通过后才被采纳——接受与否取决于可观察证据，而非 LM 置信度。
- **单模型 → 模型总体**：把点信念近似（选中假设 + 重放重构状态）推广为共享同一交互历史的 N 个可行规则书-代码对（经验信念近似），按行为等价类采样规划，用不同模型的分歧预测引导探索、避免单一早期假设自我坐实；N=1 退化为单模型。
- **MDL/MAP 选择与 Git 记忆**：在可行对中偏好描述长度最短的解释（等价于先验 ∝ 2^-L 的 MAP）；规则书与代码的每次修订都提交进 Git 仓库并打标签，agent 自己可以 diff、回滚、恢复任何早期假设，学习轨迹全程可寻址。
- **系统性实验**：ARC-AGI-3 全 25 游戏 183 关全通关（RHAE 100.0，动作数 0.44x 人类，为所比系统中最优）；规则书消融（3 个难度档）证明其节省 9% 动作 / 18% agent 轮数；wa30 上 N=2 总体把动作数从 899 降到 597；Atari Pong 案例展示学到的模型可编译为无需 LLM 的反馈控制器。

## Key Contributions

- Introduces **Code as Model**, a dual representation pairing a natural-language rulebook (persistent semantic memory of environment hypotheses) with its compiled executable realization, forming a persistent world-model hypothesis that is both the object of revision and a tool for further learning.
- Designs a continual loop of **observation, reflection, rule revision, compilation, and verification** over a frozen LLM (φ_{t+1}=φ_t), where acceptance requires both LLM-judged rulebook fidelity and exact replay reproducing every recorded transition — grounding hypothesis acceptance in execution, not language-model confidence.
- Extends the single-model point-belief approximation to a **population of N rulebook-executable pairs** sharing one interaction history (an empirical belief approximation), which diversifies exploration and reduces dependence on one early stochastic model construction.
- Formalizes model-based **recursive self-improvement (RSI)** as a Bayes-adaptive POMDP with MDL/MAP hypothesis selection, and realizes it with auditable **Git memory** — every rulebook/code revision is committed and inspectable by the agent itself.
- Reports the strongest results on ARC-AGI-3's public set among compared systems (25/25 games, 183/183 levels, RHAE 100.0, 0.44x human actions), a 3-game rulebook ablation, an N=2 population study on wa30, and an Atari Pong case study where the learned model is compiled into an LLM-free feedback controller.

## Methodology

**Problem formulation.** An agent interacts with an unknown deterministic, goal-directed POMDP M = ⟨S, A, O, T, ρ, G⟩ under a budget of B real actions (simulated rollouts and replay are free; every real action, including resets and failed attempts, counts). Learning is cast as a Bayes-adaptive POMDP: the belief b_t(s, m) is joint uncertainty over hidden state and candidate model. The agent's external learning state is Z_t = (H_t, ψ_t, θ_t) — interaction history, rulebook, executable — and the objective is to maximize the probability of reaching G within budget, with conditional action cost as tie-breaker; no scalar reward is needed.

**Continual update operator U.** Each step runs five stages: (1) *Observation* appends (a_t, o_{t+1}) to H_t; (2) *Reflection* — the frozen LLM chooses d_{t+1} ∈ {retain, revise_rulebook, repair_code} from the updated history and current pair; (3) *Rule revision* applies an LLM revision operator Δ_ψ to the rulebook (a prediction error may come from a wrong rule or from buggy code; rule-level changes are written to the rulebook before code is touched); (4) *Compilation* — a rulebook-guided compiler C_φ proposes a new executable from the previous executable, proposed rulebook, and updated record; (5) *Verification* — exact replay checks that θ predicts every recorded next observation (a conjunction over the trajectory, so zero likelihood removes any hypothesis that misassigns a single observation), and the LLM checks the code faithfully implements the rulebook. Only pairs in the admissible set V_t (replay-consistent AND rulebook-faithful) are adopted; otherwise the loop returns to reflection.

**Model selection and planning.** Among admissible pairs the agent prefers the shortest combined description, (ψ, θ) ≈ argmin L(ψ) + L(θ|ψ) — a MAP interpretation with prior μ_0 ∝ 2^(−L(ψ)−L(θ|ψ)); the LLM proposes simplifications that are re-verified. For control, replay under the accepted executable reconstructs the current internal state s̃_θ(H_t), giving a point belief; planning searches the deterministic internal model for a shortest path from the reconstructed state to the inferred goal set (V_θ shortest-path costs; plan_θ returns ∅ at predicted goals and no plan when V_θ = ∞). When no plan exists, the LLM picks an intermediate exploratory target (e.g., an unexplained object), an auxiliary planner seeks an action sequence reaching it, and execution stops at the first prediction mismatch, feeding the counterexample back to reflection.

**Population extension.** The learning state becomes (H_t, Φ_t) with N admissible pairs; each member replays the shared record and is falsified by any contradicting observation. Members whose plans have identical action sequences form behavioral equivalence classes; one class is sampled uniformly per planning episode, so different surviving models steer different histories. The loop is PROPOSE (generate + compile + admit if in V), REPAIR (reflect/revise/compile/verify after any member is falsified), and PLAN/ACT (sample, execute the representative's plan, append transitions). The paper is explicit that this is a computational approximation to the remaining version space, not a calibrated posterior.

**ARC-AGI-3 realization.** The rulebook is `world_model.md`; the executable is `world_model_engine.py` (internal transitions, state reconstruction, rendering, goal checking). Replay must match all 64x64 cells of every subsequent frame; the verifier re-initializes from each initial observation after every reset or level change. Everything is committed to a Git repository tagged by iteration ("Git memory"), so the agent can inspect, diff, or restore earlier hypotheses. ARC-AGI-3 scores action efficiency as RHAE (Eq. 36), a level-weighted ratio against the human action count with 100 as ceiling; the agent sees only the key/click interface and its own history — no source code, no language task description.

## Results & Highlights

- **ARC-AGI-3 main result (Table 1):** Code-as-Model reaches the RHAE ceiling of **100.0 on all 25 public games (183/183 levels)**; the closest system, baseline1 (Rodionov), also clears every game but at **99.0**, while NOOA reaches 85.1 (19/25 games, 170 levels), OPINE-World 78.4 (20 games, 160 levels), DreamTeam 38.1 (6 games), and Continual Harness 20.5 (3 games). Against Claude Opus 5 with the ARC Prize Standard harness the gap is **+59.3 mean RHAE points**.
- **Action efficiency (Table 2):** all 25 games are cleared in **7,518 actions = 0.44x the 17,135-action human baseline**, vs **8,347 (0.49x)** for baseline1 — the only other system to finish every game; per-game human-relative ratios range from 0.20 (m0r0) to 0.67 (lf52), median 0.42. Other systems leave 4-22 games unfinished, so their totals (e.g., Continual Harness 14,558) reflect incomplete runs, not solution costs.
- **Rulebook ablation (Table 3, one game per difficulty band — ft09 easy/35 actions-per-level, ka59 medium/104, cn04 hard/132):** with harness, replay verifier, plan executor, backbone (Claude Code + Claude Opus 5, extra-high reasoning) held byte-identical, removing the rulebook changes the three-game totals from **617 actions / 678 agent turns to 677 / 830 — a 9% action and 18% agent-turn reduction** with the rulebook (e.g., cn04: 248 vs 346 turns; all runs still clear every level at RHAE 100).
- **Population on wa30 (Table 4):** with N=2 sharing one history, total scored actions drop from **899 (N=1) to 597 (0.66x)** at equal RHAE 100, matching or improving per-level efficiency on 8 of 9 levels (e.g., L9: 61 vs 137 actions, 0.45x; L5: 106 vs 245, 0.43x).
- **Atari Pong (Table 5, Fig. 8):** the compiled feedback controller wins **21:0 in all three evaluated openings** (3,538 / 4,014 / 5,039 actions) with **no LLM calls during evaluation**; learning cost is **9.5x10^3 emulator frames vs 2.0x10^8 for GDI/LASER/IMPALA/Rainbow (model-free RL, score ≤ 21) and 4.0x10^5 for EfficientZero / EfficientZero V2 (model-based RL, score 20.1/20.8)**. References: same LLM without a world model scores **−19**, random policy **−20.7**, human average 14.6. Figure 9 shows the bounce rule evolving from a four-band hypothesis to a centred, then asymmetric capped deflection map (|v_y| ≤ 2) as disconfirming contacts arrive.

## Critical Assessment

- **The headline is partly benchmark saturation.** The authors themselves concede (Related Work) that Tycho and Rodionov's component study report saturation or near-saturation of the ARC-AGI-3 public set with stronger frontier models, and that "public-set completion alone therefore cannot isolate the contribution of a world-model architecture." Indeed baseline1 also clears all 25 games, so the mean-RHAE margin over the best prior system is just **1.0 point**; the substantive advantage is action efficiency (7,518 vs 8,347 actions, 0.44x vs 0.49x human). No held-out/private games are evaluated.
- **The ablation is thin for the central claim.** Removing the rulebook is tested on only 3 games — one per difficulty band — in single runs with no seeds or variance; the paper's own phrasing ("in the reported runs, the rulebook variant uses fewer actions...") hedges, and a 9%/18% saving over three hand-picked games is suggestive, not conclusive, evidence that the rulebook (as opposed to the verified-code loop alone) drives the gains.
- **The population extension is a case study, not an evaluation.** It is run on exactly one game (wa30, chosen because it has the largest human baseline) with N=2. Claims that populations "reduce run-to-run variance" are untested across games and N.
- **Determinism is a load-bearing assumption.** Acceptance hinges on cell-exact 64x64 replay producing a binary pass/fail; in stochastic or noisy environments this oracle disappears, and the paper does not discuss degradation. ARC-AGI-3 and Pong are both deterministic by construction.
- **Cost accounting is asymmetric.** The Pong table celebrates 9.5x10^3 frames against RL baselines, but the method's own LLM inference cost (Claude Code with Claude Opus 5 at extra-high reasoning effort) is never reported in tokens, dollars, or wall-clock — the ablation section only admits runs "incur substantial time and monetary cost." Comparing emulator frames while omitting per-step frontier-LLM calls overstates the efficiency gap.
- **Backbone is confounded with method.** Baselines come from other teams' scorecards with their own backbones and reasoning budgets, so the 59.3-point gap over Claude Opus 5 + Standard harness mixes model choice with architecture; the paper acknowledges comparisons "must also account for model choice and reasoning budget" but does not resolve it.

## Strengths

- The rulebook/executable split cleanly separates *semantic* revision (what the agent believes) from *implementation* repair (how the belief is applied), and verification combines LLM fidelity judgment with an exact execution check — acceptance is grounded in observable consequences, sidestepping known failures of LM-ranker hypothesis selection.
- Strongest reported action efficiency on the full ARC-AGI-3 public set: 183/183 levels, RHAE 100.0, and every game solved below the human action count (7,518 vs 17,135).
- The formalism (Bayes-adaptive POMDP, point-belief approximation, MDL/MAP selection) is precise and maps one-to-one onto the implementation, which aids reproducibility of the design if not the cost.
- Git memory makes the agent's learning trajectory auditable and reversible — the agent can revisit retracted hypotheses and restore executables broken by later edits; Figures 5 and 9 give genuinely legible traces of rules being retracted by counterexamples.
- Unusually honest related work that explicitly bounds the headline claim (public-set saturation caveat) instead of overselling.

## Limitations

- Exact-replay verification requires deterministic dynamics and rendered ground-truth frames; both may be unavailable outside game-like benchmarks.
- Single-model MDL preference can commit to concise-but-wrong hypotheses (the paper admits the simplicity bias "does not eliminate uncertainty"), and the population remedy is evaluated on one game at N=2.
- Ablations cover 3 of 25 games, single-run, without variance estimates; no repeated seeds anywhere in the paper.
- Evidence is confined to the 25 public ARC-AGI-3 games plus one Atari game; no transfer, no held-out tasks, no demonstration on soft real-world environments.
- LLM call counts, token spend, latency, and monetary cost are unreported despite a frontier backbone (Claude Opus 5 via Claude Code, extra-high reasoning), making independent reproduction expensive and the RL frame-cost comparison incomplete.

## Relevance

这篇论文把"外部记忆"升级为"可执行的世界模型假设"，与用户关注的 LLM 智能体自我改进、世界模型与代码生成方向高度契合；其"规则书 + 编译验证 + Git 记忆"的组合为构建可检验、可回滚的 agent 学习状态提供了一个值得借鉴的工程范式。

## Questions for Further Exploration

- How does the pipeline degrade under stochastic or noisy dynamics, where cell-exact replay cannot produce a binary verdict — could replay be replaced by distributional or tolerance-based verification?
- Would the rulebook ablation hold across all 25 games with repeated seeds, and is the 9% action / 18% turn saving statistically meaningful given single-run reporting?
- What is the full LLM token/compute budget per cleared level, and how does the method compare to RL baselines once frontier-model inference is priced into the Pong learning-cost table?
- Can the population extension (tested only on wa30 at N=2) deliver consistent exploration gains at larger N, and how should behavioral-equivalence classes be bounded as the population grows?
- Do rulebooks transfer across games sharing mechanics — could a library of verified rulebooks bootstrap unfamiliar games faster than learning from scratch?
