Key metric

100.0mean RHAE · ceiling

All 25 public games, 183/183 levels, in 7,518 actions = 0.44× the 17,135-action human baseline.

Why this matters

Upgrades agent memory into executable, verifiable world models — a checkable, rollback-safe pattern for LLM self-improvement.

把外部记忆升级为可执行、可验证的世界模型假设，为构建可检验、可回滚的 agent 学习状态提供了值得借鉴的工程范式。

Critical edge

Partly benchmark saturation: the best prior system also clears all 25 games — the mean-RHAE margin is just 1.0 point.

How it works

  1. Observe
  2. Reflect
  3. Revise ψ
  4. Compile θ
  5. Verify
  6. adopt?

Adopt only if the LLM fidelity check passes and exact replay reproduces every recorded 64×64 frame — one mispredicted cell kills the hypothesis.

  • Arena. An unknown deterministic, goal-directed POMDP; the agent sees only key/click observations and its own history — no source code, no task text. Every real action, resets included, counts against budget B; learning is cast as a Bayes-adaptive POMDP with joint belief over state and model.
  • Dual representation. Hypotheses live in a Markdown rulebook ψ (objects, action semantics, dynamics, goals, open questions); a rulebook-guided compiler turns it into an executable Python transition function θ for prediction, planning, and replay. Revisions change what the agent believes; code repairs change only how the belief is applied.
  • Selection & planning. Prefer the shortest admissible description (MDL/MAP); replay reconstructs current state, then the internal model is searched for a shortest path to inferred goals. With no plan, the LLM picks an exploratory target — the first prediction mismatch becomes a counterexample.
  • Population & memory. N rulebook–code pairs share one history; plans cluster into behavioral-equivalence classes sampled for diverse exploration (N=1 degenerates). Every revision is a tagged Git commit the agent can diff or roll back.

Strengths

  • The rulebook/executable split separates what the agent believes from how the belief is applied; acceptance is grounded in execution, not LM-ranker confidence.
  • Every one of the 183 levels solved below the human action count — the strongest action efficiency reported on the full public set.
  • The formalism (Bayes-adaptive POMDP, point-belief approximation, MDL/MAP) maps one-to-one onto the implementation, aiding reproducibility of the design.
  • Git memory makes the learning trajectory auditable and reversible — retracted hypotheses can be revisited; the related-work section honestly bounds its own headline claim.

Limitations

  • Exact-replay verification presumes deterministic dynamics and rendered ground-truth frames — both may not exist outside game-like benchmarks.
  • The ablation covers 3 of 25 games, single-run, with no seeds or variance; there are no repeated runs anywhere in the paper.
  • The population extension is one game (wa30) at N=2 — a case study, not an evaluation; MDL preference can also lock onto concise-but-wrong hypotheses.
  • No held-out tasks, no transfer, no soft real-world environments — evidence is 25 public games plus one Atari game.
  • LLM token, latency, and dollar costs are unreported for a frontier backbone (Claude Opus 5, extra-high reasoning); backbone is confounded with method in cross-team comparisons.

Questions for further exploration

  1. Can cell-exact replay degrade gracefully into distributional or tolerance-based verification under stochastic, noisy dynamics?
  2. Does the 9% action / 18% turn rulebook saving survive across all 25 games with repeated seeds?
  3. How do the Pong learning costs compare once frontier-model inference is priced into the frame budget?
  4. Could a library of verified rulebooks transfer across games sharing mechanics and bootstrap unfamiliar ones faster than learning from scratch?
