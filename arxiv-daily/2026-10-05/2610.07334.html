Fine-tuned only on benign pathologies, an LLM reads raw neural-network weights and catches backdoor models it has never seen.

Weight Oracles: Reading Neural Network Weights with Language Models

Krishna Kabra · Constantin Venhoff · Christian Schroeder de Witt | University of Oxford | 2026-10-05 | NeurIPS 2026 WS — NN Artifacts as a Data Modality | interpretabilityAI safetybackdoor detectionweight-space learning

Key metric
0.93±0.04 AUROC

Zero-shot backdoor detection on the pos0 cohort (5 runs, 94% TPR @ 20% FPR) — vs 0.752 for the strongest hand-crafted statistical detector and 0.445 for the L2-norm null.

Why this matters

Proactive auditing that needs no trigger samples and never runs the target model — the weights themselves become evidence, complementing activation-side interpretability.

把模型权重当作 LLM 的新输入模态：无需触发样本、无需运行目标模型的主动式安全审计。

Critical edge

“Zero-shot” is a qualified claim: 16% of the benign training mix (the dominant-token pathology) is a near-neighbour of the target backdoor — the honest claim is trigger-condition-free transfer.

Methodology

raw weight rows → linear project + type-embed → Qwen 2.5 3B (5 passes / target fwd) → 17 diagnostic answers → composite anomaly score

Phase I — weight-reading simulator. Targets are 1-layer transformers (~2K params, d=8, 2 heads, vocab 1,000). Raw weight rows are projected into Qwen 2.5 3B's hidden dimension (2048) and tagged with type embeddings (W_Q…W_2, biases, hidden states); weight tokens are concatenated with a natural-language question. A single LLM forward pass plateaus at exactly 45% — the accuracy of ignoring the MLP (45.1%) — so each target forward pass is decomposed into 5 LLM passes, one per weight projection, with LayerNorm / GELU / residuals applied by deterministic external code. A 4-stage curriculum over models regenerated online every step transfers immediately: 88–95% on first sight of real models, 99.0% held-out.

Phase II — the oracle. The same weight-injection pipeline now feeds a text head answering 17 fixed diagnostic questions (pathway strength, dead neurons, input shortcuts, confidence stability…). Training uses only ~4,400 models exhibiting 10 benign pathologies across 29,000 steps — no backdoored model ever appears; per-answer anomaly scores aggregate into a composite.

Evaluation. 100 held-out models (50 clean / 50 backdoored), uniform over four threat models: pos0, lastpos, stealth (50× weaker signature), adversarial (regularizes against the statistical baseline).

Results

SettingAUROC
Oracle — pos0-only, zero-shot0.93 ± 0.04
Best hand-crafted V/O detector0.752
L2-norm null detector0.445
Oracle — 4-threat mix, gap-weighted0.81 (0.74–0.89 per type)

Statistical detectors are sharp on the attacks they implicitly target but collapse under threat-model shift.

  • Phase I: decomposed 5-pass chain hits 99.0% on held-out real transformers; single-pass execution stalls at the 45% wall.
  • Dot-product grokking: ~10% (chance) for ~2,000 steps, then jumps to ~92% near step 2,900; removing type embeddings blocks it entirely.
  • Sim-init backfires: Phase-I-initialized projections score 0.73 vs 0.81 from scratch (−0.178 on lastpos, −0.278 on stealth).
  • Signal localized: W_V gradients ~2× higher on backdoored models; zeroing W_O costs the most AUROC (−0.040); layer-wise probes read 0.88 (layers 0–10) re-emerging at 0.93 (layers 34–35).
  • Honest miss: the hardest stealth backdoor reads −65.5 (“clearly as clean”) — the transcript is published.

Strengths

  • Genuinely novel framing: weights as a first-class LLM input modality, cleanly differentiated from three concurrent efforts.
  • Exemplary negative-results reporting: the grokking curve, the exact-45% wall diagnosed via shortcut ablation and gradient attribution, and sim-init negative transfer are all published.
  • Uniform-competence evaluation across four genuinely different threat models, including a stealth variant with a 50× weaker signature.
  • Four complementary interpretability studies (gradient attribution, weight-matrix ablation, PCA, layer-wise probes) localize the detection signal instead of treating the oracle as a black box.

Limitations

  • Toy scale only: ~2K-parameter, 1-layer targets; naive weight-token injection does not scale — the principal open challenge.
  • Deployment economics are weak: 94% TPR comes at a 20% FPR, flagging one in five clean models.
  • Detects statistical correlates, not mechanisms; all attacks are single-token, single-class — lastpos and stealth degrade to 0.74 and below.
  • The language interface is never ablated against a small learned detector trained on the same features; no code release, limiting reproducibility of the 29,000-step recipe.

Questions for further exploration

  1. Can a compression scheme (sparse autoencoders, low-rank decompositions) preserve safety-relevant weight signatures beyond a few million parameters?
  2. Would a small learned detector (MLP head) on the same engineered features match the oracle — is the language interface actually earning its keep?
  3. How much does an adaptive attacker optimizing against the oracle's 17 diagnostic questions degrade detection, given today's “adversarial” threat model only targets the statistical baseline?
  4. Would chain-of-thought oracles that execute sub-computations on the target close the gap on cryptographically unelicitable backdoors?
  5. Does the 0.74–0.89 uniform competence survive semantic, multi-token, or input-adaptive trigger families — or is single-token routing the entire story?
