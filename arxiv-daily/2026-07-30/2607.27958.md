> **一句话总结：** 论文提出 Σ-Mem，一种用实对称矩阵在线记录"每个 peer 历史胜任度"与"peer 间相关性"的可读写记忆模块，仅用历史正确性反馈更新、依 Weyl 不等式保证谱稳定，在反事实攻击基准 CF@90 上把 Qwen3-0.6B 的选择准确率从 46.22% 提升到 71.10%，并在 BBH 等分布外任务上让 Qwen3-4B 从 20.38% 提升到 28.66%，同时其直接读数在 OOD 全集上以 M-Vote 方式（约 60.9%-61.0%）超过多数投票基线（59.12%）与最佳固定 peer 基线（57.52%）。

> **TL;DR:** Σ-Mem is an online, per-peer + per-peer-pair reliability memory (two real symmetric matrices, updated with decay + bounded rank-one updates guaranteed stable by Weyl's inequality) that a central LLM can read for residual steering, peer routing, or weighted voting. On a mixed counterfactual benchmark built from GSM8K/SQuAD/APPS-style tasks, adding Σ-Mem raises Qwen3-0.6B's peer-selection accuracy from 46.22% to 71.10% at the most adversarial CF@90 setting (peer identities swapped with a weak peer 90% of the time), and on the out-of-distribution BBH benchmark it lifts Qwen3-4B from 20.38% to 28.66%; direct memory readouts (no central-model judgment needed) beat majority voting (59.12%) and the single best fixed peer (57.52%) across six unseen OOD benchmarks. The one clearly reported failure mode is CF@50, where deliberately ambiguous historical evidence causes Σ-Mem to sometimes underperform the unmodified base model.

## 核心贡献

- 提出 Σ-Mem：一种在线可读写的"可靠性记忆"，用两类实对称状态分别记录"历史胜任度证据"（每个 peer 一个矩阵 M_p）和"peer 关系证据"（一个跨 peer 关系图矩阵 G），二者都只用事件级的外部正确性反馈（+1/-1）更新，无需重新训练底层模型。
- 用 Weyl 不等式为该记忆的在线稳定性提供理论保证：把每次更新看作对实对称记忆矩阵的一次有界扰动（衰减项 + 秩一新证据项），证明单次事件不会让谱发生突变，同时给出"持久对齐信号最终超过噪声下界"的定理（Theorem 1）及其证明。
- 设计统一的写-读接口：同一份记忆既可以通过残差引导（residual steering）影响中心模型的注意力计算与效用评分，也可以在不经过中心模型判断的情况下直接读出作为路由分数（M-Route）或加权投票权重（M-Vote），从而支持多种聚合机制而不需要为每种机制单独训练。
- 通过反事实攻击、peer 数量扩增（3→4→5，含训练中未见过的新 peer）、六个训练域之外的 OOD 基准（PIQA、MMLU、OpenBookQA、SciQ、BBH、SuperGLUE）和反馈可用率消融四组实验，验证 Σ-Mem 能持续从观测事件中积累可用的可靠性信息，而不是只是拟合了训练分布。

## Key Contributions

- **Σ-Mem architecture**: an online reliability memory comprising per-peer historical competence matrices {M_p} and a peer relationship matrix G, both real symmetric, updated purely from post-decision correctness feedback (c_{p,t} ∈ {+1,-1}) via a decayed-plus-bounded-rank-one-update rule (M_p^{(t+1)} = γM_p^{(t)} + η c_{p,t}φ(x_t)φ(x_t)^T), so memory adapts without retraining the underlying central or peer models.
- **Stability guarantee via Weyl's inequality**: each event-level update is proven to be a bounded spectral perturbation (Proposition 1: |λ_i(M_p^{(t+1)}) − γλ_i(M_p^{(t)})| ≤ η), and Theorem 1 (with full proof in Appendix A.2) shows the leading eigenvalue of M_p eventually reflects a peer's true task-conditioned competence rather than event-level noise, with an explicit signal-to-noise ratio that increases monotonically with the decay factor γ.
- **A unified write/read interface** supporting at least three distinct consumption modes from the same frozen memory state: (1) residual steering that injects a peer-specific vector into the upper half of the central model's decoder layers before a Yes/No utility judgment, (2) response-free M-Route peer selection using only φ(x_t)ᵀM_pφ(x_t), and (3) M-Vote reliability-weighted voting — demonstrating the memory is a reusable coordination substrate rather than an aggregation-specific trick.
- **Systematic generalization evidence**: the same trained memory (only 2,963 training events, 3 peers, 3 domains) is shown to generalize to counterfactual reliability shifts, to unseen peer models added at test time (4- and 5-peer pools), and to six OOD task domains never seen in training, with accuracy improving monotonically as more correctness feedback becomes available (Figure 3).

## Methodology

Σ-Mem is trained on a mixed offline dataset of 2,963 task events drawn from GSM8K (1,000 math events), SQuAD (1,000 RAG events), and APPS (963 code events), each event pairing a task input with three fixed peer responses (Gemma-3-4B-it, Phi-4-mini-instruct, Qwen2.5-Coder-7B-Instruct) and their binary correctness labels. For each event, a frozen central-model encoder produces a unit-norm competence direction φ(x_t) ∈ ℝʳ. Historical competence evidence is stored per peer as M_p ∈ ℝ^{r×r}, initialized at zero and updated as M_p^{(t+1)} = γM_p^{(t)} + η c_{p,t}φ(x_t)φ(x_t)ᵀ (γ decay, η update factor), which by construction stays symmetric; peer relationship evidence is stored in G ∈ ℝ^{P×P}, updated from the peer-set-centered correctness vector q_{p,t} = c_{p,t} − mean_j(c_{j,t}) via G^{(t+1)} = γ_G G^{(t)} + η_G q_tq_tᵀ (diagonal fixed to 1), so G_{p,q} > 0 means peers p and q tend to be right or wrong together and G_{p,q} < 0 means their errors are anti-correlated.

At decision time, the memory is read in two ways. For steered selection (Sec. 3.2-3.3), a competence readout r_{p,t} = M_p^{(t)}φ(x_t) is projected via a learned matrix P and scalar gain g into a residual steering vector δ_{p,t}(x_t) = gPM_p^{(t)}φ(x_t), injected only into the upper half of the central model's decoder blocks (layers ⌈L/2⌉ to L−1), leaving frozen attention weights untouched but shifting the hidden states the model reasons over. The steered central model then scores each peer answer as a Yes-vs-No log-likelihood contrast U_{p,t}, which is peer-set-normalized (z_{p,t}) and combined with the peer-relationship matrix G into a posterior over a latent correctness vector y_t ∈ {−1,+1}^P (Eq. 15, weighted by w_u and w_g), with the peer of maximum posterior correctness expectation selected. Critically, U_{p,t} is only a decision-time utility score — it is never used as the memory-update label; memory updates are always driven by the external correctness feedback {c_{p,t}} received after the event. For model-independent readout (Sec. 3.4), the frozen memory alone (without invoking the central model on the response text) gives a reliability score s_{p,t} = φ(x_t)ᵀM_p^{(t)}φ(x_t), which supports M-Route (arg max peer selection) and M-Vote (reliability-weighted answer aggregation) without any peer-response evaluation at decision time. Five Qwen-family models (Qwen3-0.6B/4B/8B, Qwen3.5-4B/9B) serve as central models; evaluation covers a mixed counterfactual benchmark (nine source datasets pooled with deterministic swapping of a strong peer's response/label with a weak peer's at ratios CF@0/50/70/90), peer-pool expansion to 4 and 5 peers (adding unseen Llama-3.2-3B-Instruct and BitCPM-CANN-3B), and six OOD benchmarks (PIQA, MMLU, OpenBookQA, SciQ, BBH, SuperGLUE) never seen during training.

## Results & Highlights

- **Counterfactual attack (Table 1, CF@90 on the mixed 2,685-event stream)**: for Qwen3-0.6B, the base model's fixed preference for peer 1 drives accuracy down from 61.01% (CF@0) to 46.22% (CF@90); adding Σ-Mem with peer-relationship evidence ("Σ w/ G") raises CF@90 accuracy to 71.10% — a +24.88 percentage-point gain over the same base model at the same CF ratio, and this is achieved training on only 3 peers and 2,963 events.
- **Out-of-distribution BBH (Table 3)**: on the unseen BBH benchmark (6,511 instances, never in the training domains of math/RAG/code), Qwen3-4B improves from 20.38% (base) to 28.66% (Σ-Mem), and Qwen3-8B improves from 19.29% to 28.17% — both roughly 8-9 percentage points above their own un-augmented base model, the largest OOD gain reported across all six benchmarks.
- **Model-independent selection (Table 4, pooled across six OOD benchmarks, 17,403 instances)**: direct memory readouts beat both memory-free baselines system-wide — M-Vote reaches 60.86%-60.99% depending on the central model (e.g., 60.99% for Qwen3-8B) versus majority voting's 59.12% and the single best fixed peer's 57.52%, and even exceeds the theoretical "oracle reputation" per-subtest-best-peer baseline of 60.79% for three of five central models.
- **Peer-count generalization (Table 2, CF@90 with unseen peers added)**: with the peer pool expanded from 3 to 5 (adding Llama-3.2-3B-Instruct and BitCPM-CANN-3B, neither seen during Σ-Mem training), Qwen3-0.6B's CF@90 accuracy improves from 34.71% (base) to 62.09% (Σ-Mem) — a +27.38 pp gain — showing the memory mechanism transfers to peer identities it never trained on.
- **Feedback-availability ablation (Figure 3)**: varying the fraction of events with revealed correctness feedback from 5% to 100%, OOD accuracy for Σ w/ G rises monotonically (e.g., Qwen3.5-9B climbs from ~59.09% at 5% feedback to 61.35% at 100%), consistently above both the M-Route curve and the flat majority-voting baseline (59.12%), directly supporting the claim that the historical-competence evidence accumulates actionable signal rather than saturating immediately.
- **Reported failure case (CF@50, self-acknowledged)**: at the intentionally ambiguous CF@50 split (half the historical stream supports the original peer preference, half supports the counterfactual shift), Σ w/ G accuracy drops below the base model for 4 of 5 central models (e.g., Qwen3-4B: base 65.55% → Σ w/ G 63.61%; Qwen3.5-9B: base 68.94% → Σ w/ G 65.96%), which the authors frame as a faithfulness property (the memory accurately integrates genuinely ambiguous evidence) rather than an aggregation defect, and verify further with a separate direct-readout M-route experiment in Appendix C.

## Critical Assessment

**Novelty**: The core idea — modeling "who can be trusted, under what task conditions" as a persistent, symmetric, spectrally-bounded online state, separate from content memory — is a clean and underexplored framing relative to prior MAS trust/reputation work (TRAVOS, FIRE, REGRET) and LLM routing/ensembling work (RouteLLM, FrugalGPT, LLM-Blender), which the related-work section (Sec. 5) situates reasonably well. Using Weyl's inequality to give a concrete, provable stability bound on eigenvalue drift under streaming rank-one updates is a genuinely distinctive theoretical contribution rather than a hand-wavy "we use exponential decay" justification.

**Rigor**: The paper includes a full proof of Theorem 1 (Appendix A.2, three-step signal-noise decomposition with Hoeffding-based concentration bounds), which is unusually rigorous for an empirical MAS paper. It also includes a specifically named, non-strawman baseline — a "Bayesian Beta B1" reputation model that is response-blind and model-independent, tracking a single global Beta(α_p, β_p) posterior per peer — and honestly reports where it is competitive (B1 becomes competitive with Σ-Mem once one peer dominates globally at CF@70/90, since a global success-rate estimator is naturally strong in that regime) rather than only showing settings where Σ-Mem wins. The self-reported CF@50 degradation (a genuine paper-specific weak spot, not a generic caveat) strengthens rather than undermines the paper's honesty.

**Reproducibility**: Dataset construction (2,963 training events; 2,685-event ×4-CF-ratio counterfactual stream; six OOD benchmarks) and hyperparameter roles (γ, η, γ_G, η_G, w_u, w_g) are described, but exact hyperparameter values, learning schedule, and the projection matrix P's dimensionality are not stated in the main text excerpted here, and a working code link is not printed in-text (only a GitHub badge on the title page) — so full reproduction depends on the linked repository actually being available and complete.

**Significance / red flags**: The three fixed training peers are each strongly specialized by construction (Table 5: Gemma-3-4B-it 81.00% on GSM8K but 12.80% on SQuAD; Phi-4-mini 83.70% on SQuAD but 8.10% on APPS; Qwen2.5-Coder 71.00% on APPS but 50.90% on SQuAD) — this near-orthogonal domain specialization makes "which peer to trust" close to a task-type classification problem, which likely inflates how easy the counterfactual/OOD gains look relative to a more realistic setting where peers have overlapping, less cleanly separable competence profiles. The central model's utility judgment relies on Yes/No log-likelihood contrast, which is a known-fragile calibration signal for small models (Qwen3-0.6B), yet the paper shows this weakest model benefiting the most — worth scrutinizing whether gains are driven mainly by the memory correcting a bad prior (peer-1 bias) rather than by genuinely fine-grained reliability estimation. No ablation isolates the marginal contribution of the projection/gain parameters (P, g) versus the raw memory readout itself for the steered pathway.

## Strengths

- A theoretically grounded stability argument (Weyl's inequality bound plus a full proof of a persistent-signal-dominates-noise theorem) rather than an ad hoc decay heuristic.
- Demonstrated reusability of a single trained memory state across three qualitatively different consumption mechanisms (steered selection, response-free routing, weighted voting) without retraining.
- Honest reporting of a specific failure mode (CF@50) with a plausible mechanistic explanation (ambiguous historical stream) rather than suppressing or explaining away the result.
- A carefully constructed, non-strawman baseline (Bayesian Beta B1) that is allowed to win in some regimes, strengthening the credibility of the comparisons where Σ-Mem does win.
- Broad empirical coverage: five central models, up to five peer pools (including 2 unseen peers), and six OOD benchmarks spanning commonsense, knowledge, science QA, reasoning, and language understanding.

## Limitations

- CF@50 is a consistent failure case for 4 of 5 central models — the mechanism's accuracy can fall below the unmodified base model when historical evidence is genuinely ambiguous, and the paper explicitly states that developing "adaptive readouts that determine how historical reliability should interact with current decision evidence" remains future work.
- The three training peers have near-orthogonal per-domain competence (Table 5), which may make the reliability-estimation problem easier than in settings with overlapping peer competence profiles; this is not tested.
- Training data is limited to three domains (math/GSM8K, RAG/SQuAD, code/APPS) with only 2,963 events total; while OOD generalization is demonstrated on six benchmarks, all training peers and tasks originate from a narrow, English-only, well-structured task distribution.
- Hyperparameter sensitivity (γ, η, γ_G, η_G, w_u, w_g) is not analyzed in the excerpted main text — no ablation shows how performance depends on the decay/update-factor choices central to the paper's own stability theorem.
- The paper is currently "under review" (not yet peer-reviewed at a venue), and the code repository link is not printed in the visible text, so independent reproduction cannot yet be verified.

## Relevance

该论文对多智能体协调、LLM 路由/聚合、以及"谁的输出可信"这类信任建模问题提供了一个理论上有稳定性保证、工程上可复用的记忆机制，其"历史胜任度 + peer 关系"的双状态设计和 Weyl 不等式稳定性论证，对研究长程 agent 记忆或 MAS 聚合策略的读者具有较高参考价值，但其近乎正交的训练 peer 设定意味着结论向更真实、能力重叠场景的迁移仍需验证。

## Questions for Further Exploration

- Would Σ-Mem's gains shrink substantially if the peer pool had overlapping, less cleanly separable competence profiles instead of the near-orthogonal domain specialization seen in Table 5?
- Can an adaptive readout rule (mentioned as future work) resolve the CF@50 degradation by dynamically weighting historical memory against the central model's current-response judgment based on estimated ambiguity in the evidence stream?
- How sensitive is performance to the decay/update hyperparameters (γ, η, γ_G, η_G) that underpin the Weyl's-inequality stability guarantee, and is there a principled way to set them rather than tuning them empirically?
- Does the residual-steering pathway's projection matrix P and gain g contribute meaningfully beyond the raw memory readout s_{p,t}, or could a simpler linear combination achieve similar gains?
- How does Σ-Mem behave in fully open-ended, non-benchmark deployment where "ground-truth correctness feedback" is noisy, delayed, or itself provided by another LLM judge rather than a clean external oracle?
