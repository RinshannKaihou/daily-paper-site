> **一句话总结：** 论文提出"分叉未来"（forked futures）范式——只在前缀隐状态形成之后才随机采样下游操作，用由此产生的响应分布差异定义隐状态的因果等价性，并让 Shared/Local/Mixture/Distributed 四种候选接口在预测式因果最小描述长度（prequential causal MDL）下正面竞争；在 Qwen2.5-1.5B 和 Llama-3-8B 上，Shared 接口分别以 0.216 nats 和 0.294 nats 的优势胜出，且移植实验中 API 对齐路径介导了 0.749 的目标效应（对照路径仅 0.150），但盲测的四类模型有机体识别仍出现 1/12 的非 Shared 误判为 Shared 的假阳性。

> **TL;DR:** This ICLR 2026 paper introduces "forked futures" — sampling downstream operations only after a hidden state has formed, then comparing states via the response distributions those operations induce — to define an operation-agnostic notion of causal equivalence, and pits Shared/Local/Mixture/Distributed encoder architectures against each other under prequential causal MDL. On Qwen2.5-1.5B and Llama-3-8B, Shared wins with a Sharedness Gain of 0.216 nats and 0.294 nats respectively (held-out MDL 1.292 vs. Local's 1.508 on Qwen; 1.187 vs. 1.481 on Llama) while keeping mean future-signature distortion within 0.011 of the alternatives; role-aligned transplantation gives Shared the best composite score (0.87 vs. 0.70/0.64/0.46 for Local/Mixture/Distributed) and API-aligned paths mediate 0.749 of the target causal effect versus 0.150 for matched-null paths, but a blind four-class synthetic model-organism test recovers only 14/16 architectures, with one of twelve non-Shared organisms misclassified as Shared (8.3% false-Shared rate).

## 核心贡献

- 提出"分叉未来"协议：在下游操作 k 揭示之前先缓存前缀隐状态 h，之后再随机采样操作，用诱导出的响应分布集合 Σ_K(h) 定义"未来因果签名"，从而避免用单一当前答案的可解码性来冒充"可复用接口"这一常见陷阱。
- 将"是否存在共享内部接口"形式化为一个可证伪的架构选择问题：Shared（单一操作无关编码）、Local（每操作独立编解码）、Mixture（门控插值）、Distributed（无特权瓶颈）在匹配容量、匹配保真度（未来签名失真 FSD）约束下，用预测式因果 MDL 竞争，选出描述长度最短且保真的架构。
- 设计了一整套机制验证测试链：同角色/跨家族/匹配随机三种移植对照、路径阻断与介导分析（mediated fraction）、多消费者选择性检验，以及基于已知路由结构（Shared/Local/Mixture/Distributed 四类合成模型有机体）的盲态四分类恢复测试，用于排除"可解码但非因果""可移植但只是复制内容""补丁可达但非自然使用路径"等替代解释。
- 在语义碰撞（相同当前答案、不同未来签名）与词汇反碰撞（不同措辞、相同未来签名）两类数据构造控制下，证明所发现的共享接口跟踪的是"未来状态结构"而非表面实体名或提示模板；符号重编码后表面探针准确率从约 76–88% 降至约 25–34%，逼近词汇对照下限。

## Key Contributions

- **Forked futures protocol**: cache the prefix hidden state h *before* the downstream operation k is revealed, then sample k afterward; the induced response distributions Σ_K(h) = {σ_k(h): k ∈ K} define a "future causal signature," and two states are declared future-equivalent via a Jensen-Shannon-based future-signature distortion (FSD), which closes the loophole where current-answer decodability is mistaken for a reusable computational interface.
- **Falsifiable architecture-selection framing**: Shared (one operation-agnostic code E_φ(h)), Local (independent (E_k, R_k) pairs), Mixture (operation-conditioned gate), and Distributed (no privileged bottleneck) compete under prequential causal MDL (Eq. 5–7) subject to a matched-capacity and worst-family/mean/tail-FSD fidelity constraint, so a cheap-but-lossy code cannot win merely by discarding a hard family.
- **A five-part mechanistic validation chain**: held-out sufficiency, role-aligned transplantation (same-family / cross-family / matched-random donors), path-blocked mediation with necessity-restoration, multi-consumer selectivity (BH-FDR across candidate dimensions), and a blind four-class synthetic model-organism recovery test — each component is explicitly designed to rule out one specific false-positive mechanism (epiphenomenal direction, cheap-low-rank-wins, donor-content copying, patchability-not-mediation).
- **Data construction with collision controls**: semantic-collision pairs (same current answer, divergent future signature) and lexical anti-collision groups (varied wording, fixed future signature) built across relation-world, program-state, proof/discourse-state (and an extended attribute/event-world) synthetic task families, explicitly designed so neither a current-answer shortcut nor a surface-form shortcut can pass the benchmark.

## Methodology

The core object is a prefix hidden state h = h_{ℓ,t}(x) cached at a fixed layer/position *before* any future operation is revealed (Section 3, Fig. 1 panels A–C). An operation bank K (query, compare, invert, compose for relation-world; execute, verify, copy, update for program-state; entail, verify, alternate-derive, chain for proof/discourse) is sampled only afterward, and each k induces a response distribution σ_k(h) = p_θ(y | x_{1:t}, k); the collection Σ_K(h) is the "future causal signature," compared across states via FSD (Eq. 3, JS divergence, default full-vocabulary logits, with top-100/answer-token/sequence-likelihood variants tested in the supplement).

Four candidate interface architectures are trained as encoder–reconstructor pairs c = E_φ(h,k), ĥ = R_ψ(c,k) (Eq. 4): Shared uses one operation-agnostic encoder; Local trains independent encoder/decoder pairs per operation; Mixture gates between shared and local components; Distributed spreads the code across several components with no privileged bottleneck. Rank, sparsity, parameter budget, and optimization steps are matched where the architecture allows (Shared/Local/Mixture/Distributed instantiate 1/6/4/16 interface components respectively), and unavoidable excess Distributed capacity is charged via the MDL penalty rather than ignored. Architecture selection uses a 20-fold prequential causal MDL (Eq. 5–7): each later fold's coding cost is the cross-entropy of held-out future signatures under a predictor trained only on earlier folds, plus a two-part Gaussian-prior parameter code with an explicit λ_r·r + λ_g·g complexity penalty (rank r, gate count g; λ_r=0.02, λ_g=0.05). The Sharedness Gain (SG) is the MDL gap between Shared and the best non-Shared alternative, accepted only if the fidelity constraint (max worst-family FSD ≤ ε_f) also holds.

Mechanistic validation (Section 4) then transplants the *selected* interface's code between donor and base episodes matched at the same producer role, insertion layer/position, difficulty, output length, and code norm, scored on Target Correctness (TC), Locality (LOC, preservation of non-target slots), and Copy-Preservation (1 − donor-copy rate), aggregated into CompScore = (TC+LOC+CopyPres)/3. Three donor regimes (same-family, cross-family, matched-random) isolate causal-identity transfer from mere intervention-scale compatibility. Separately, path-blocked mediation computes MF = (Δ_total − Δ_blocked)/Δ_total against matched-null paths (matched by producer–consumer distance, rank, activation norm, intervention load, baseline patchability). Ground-truth falsification (Section 4, Fig. 2) uses six-layer, width-256, vocab-512 synthetic transformers (five seeds each) built with known Shared/Local/Mixture/Distributed routing, on which the discovery pipeline is run blind to the true architecture label. Experiments are run in full (architecture competition, family-stratified OOD, transplantation, mediation) on Qwen2.5-1.5B and Llama-3-8B; four extra backbones (Qwen2.5-7B, Mistral-7B, Gemma-2-9B, Phi-3-3.8B) are used only for a directional Sharedness-Gain robustness sweep, not for the full evaluation suite. The main dataset totals 10,600 training / 2,280 validation / 3,020 test episodes across relation-world, program-state, and proof/discourse-state families, each with 16 training operations, 4 held-out operations, and unseen 2–3 step compositions; statistical testing uses paired family-level bootstrap, permutation tests, mixed-effects models, TOST equivalence, and BH-FDR.

## Results & Highlights

- **Architecture competition (Table 2)**: on Qwen2.5-1.5B, Shared achieves held-out MDL = 1.292 versus Local's 1.508 (nearest alternative), Mixture's 1.672, and Distributed's 1.981 — Sharedness Gain SG = 0.216 nats, 95% CI [0.161, 0.278] — while mean FSD is nearly identical across architectures (0.341 for Shared vs. 0.343 for Local, a gap of ≤0.011). On Llama-3-8B, Shared's MDL = 1.187 vs. Local's 1.481 (SG = 0.294, 95% CI [0.208, 0.391]), with mean FSD 0.328 vs. 0.331.
- **Transplantation/mediation (Table 3)**: Shared leads all baselines on the figure-aligned composite — Target Correctness 0.91 (Shared) vs. 0.72 (Local) / 0.65 (Mixture) / 0.48 (Distributed); Locality 0.88 vs. 0.75/0.69/0.52; Copy-Preservation 0.85 vs. 0.66/0.61/0.42; CompScore 0.87 vs. 0.70/0.64/0.46. Donor-regime ablation shows Shared's CompScore drops from 0.88 (same-family) to 0.78 (cross-family) to 0.53 (matched-random) — the monotonic decline is used by the authors to bound the claim to "partially aligned causal roles," not unrestricted exchangeability.
- **Causal mediation**: API-aligned paths mediate 0.749 ± 0.089 of the target effect, versus only 0.150 ± 0.017 for matched-null paths of equivalent producer–consumer distance, rank, and intervention load — a >5x separation used as the paper's strongest evidence that the recovered Shared code is causally *consumed*, not merely correlated with the output.
- **Blind model-organism falsification (Fig. 2)**: across four held-out synthetic organisms per architecture class (16 total), the pipeline recovers 14/16 correct labels — all four Shared, Mixture, and Distributed organisms are correctly identified, but among four Local organisms, two are recovered correctly, one is misclassified as Mixture, and one is misclassified as Shared, yielding a reported false-Shared rate of 8.3% (1/12 non-Shared organisms). This is the paper's most important self-reported negative result: the discovery rule does not achieve perfect identifiability.
- **Robustness/generalization sweep**: a five-backbone sweep (adding Qwen2.5-7B, Mistral-7B, Gemma-2-9B, Phi-3-3.8B) preserves the *positive direction* of Sharedness Gain, but the paper is explicit that only Qwen2.5-1.5B and Llama-3-8B receive the full family-stratified, transplantation, and mediation analysis — the other four backbones are directional-sign checks only, not full replications. Only 7/64 candidate dimensions survive BH-FDR selectivity testing, and the recovered producer–consumer path graph has sparsity 0.791 ± 0.023 with cross-seed Jaccard overlap 0.83.

## Critical Assessment

**Novelty**: The "forked futures" idea — deferring operation sampling until after the hidden state is fixed, then defining causal equivalence via the resulting distributional signature — is a genuinely useful operationalization that cleanly separates "decodable now" from "causally reusable later," addressing a real gap in prior causal-abstraction and global-workspace literature (which the paper correctly credits: Geiger et al., Ghandeharioun et al. Patchscopes, Gurnee et al. 2026 verbalizable-representations). Casting the Shared-vs-Local/Mixture/Distributed question as an explicit MDL-based architecture competition (rather than presupposing "Shared" as the answer) is methodologically stronger than typical probing papers.

**Rigor**: The five-pronged validation chain (held-out sufficiency, transplantation across three donor regimes, path-blocked mediation with matched nulls, selectivity under BH-FDR, and blind synthetic model organisms) is unusually thorough for this literature, and the authors explicitly report a negative/limiting result rather than hiding it: the 8.3% false-Shared rate among non-Shared model organisms (1 of 12 Local organisms misidentified) is a real crack in the identifiability claim, and the paper is commendably upfront that this "prevents claiming that the falsification tolerance is fully satisfied." The cross-family transplantation degradation (CompScore 0.88 → 0.78 → 0.53 from same-family to cross-family to matched-random donors) is similarly reported honestly as bounding rather than eliminating the claim.

**Reproducibility**: Full architecture, hyperparameter (λ_r=0.02, λ_g=0.05, rank 64), fold, and statistical-test details are given in the main text and an extensive supplement (14 tables, 7 figures per the overview), which is good practice; however, code/data release is not mentioned in the excerpted text, and the synthetic task families (relation-world, program-state, proof/discourse-state) are fully synthetic constructions rather than naturalistic corpora, so reproducing results requires re-implementing the entire generator pipeline.

**Significance / red flags**: The "detailed" evaluation is confined to two backbones (Qwen2.5-1.5B, Llama-3-8B); the four additional backbones (Qwen2.5-7B, Mistral-7B, Gemma-2-9B, Phi-3-3.8B) are used *only* to check the sign of Sharedness Gain, not to replicate the transplantation/mediation/model-organism findings — so the strong mechanistic claims (0.749 vs. 0.150 mediation, the model-organism recovery rate) rest on just two models. The synthetic ground-truth organisms are small (6 layers, width 256, vocab 512), and the paper itself flags that "synthetic organisms may also be easier to recover than mechanisms formed during large-scale pretraining" — a legitimate concern given how much cleaner the four-class routing distinction is in a hand-built organism versus an emergent LLM circuit. Task families are structured/synthetic (relation-world, program-state, proof/discourse) rather than open-domain dialogue or long-context reasoning, which the Limitations section explicitly acknowledges as untested. The magnitude of the MDL advantage (0.2–0.3 nats) is modest in absolute terms and is explicitly framed by the authors as "a lower coding cost at matched predictive adequacy, rather than a large reconstruction-accuracy gap" — a refreshingly non-overclaiming characterization, but readers should not mistake "shortest description length" for "large functional advantage."

## Strengths

- Clean conceptual move from single-answer decodability to future-operation-conditioned causal equivalence, closing a well-known gap between probing and true causal reuse.
- Explicit architecture competition (Shared vs. three named, non-strawman alternatives) under matched capacity, rather than assuming a shared code by default.
- Extensive, honestly-reported mechanistic validation chain including a synthetic model-organism ground-truth test that most representation-discovery papers skip entirely — and the paper reports its own failure case (8.3% false-Shared) rather than suppressing it.
- Quantitative mediation analysis (0.749 vs. 0.150) with matched-null controls gives a concrete, falsifiable causal-consumption number rather than a qualitative "the ablation hurt performance" claim.

## Limitations

- Full mechanistic and family-stratified analysis is restricted to two backbones (Qwen2.5-1.5B, Llama-3-8B); the five-backbone sweep only confirms the *direction* of the effect, not its magnitude or the transplantation/mediation findings.
- Blind model-organism recovery is imperfect: 14/16 with one non-Shared → Shared misclassification, explicitly acknowledged by the authors as preventing a "perfectly identifiable" claim.
- Cross-family and matched-random donor transplantation substantially degrades CompScore (0.88 → 0.78 → 0.53), meaning the "reusable interface" claim is bounded to partially-aligned causal roles, not a universal communication bus.
- Task families are synthetic/structured (relation-world, program-state, proof/discourse-state); natural-language open-domain dialogue, tool use, multilingual interaction, and long-context reasoning are explicitly out of scope per the authors' own Limitations section.
- Synthetic ground-truth organisms (6-layer, width-256 toy transformers) may be easier to recover than mechanisms that emerge from large-scale pretraining, a gap the authors flag themselves.
- Redundant/compensatory routes after path-blocking and discrete locality definitions may under- or over-state true mediation, per the authors' own caveats.

## Relevance

该工作提出了一个可操作、可证伪的框架来判断大模型隐状态中是否存在真正跨任务复用的"内部 API"，其 MDL 架构竞争 + 移植/介导验证的组合思路，对做可解释性、表征工程或探针方法学的研究者有较高参考价值，但其结论目前仅在两个中等规模模型和合成结构化任务上验证，迁移到真实开放域场景仍需谨慎。

## Questions for Further Exploration

- Would the Shared architecture's MDL advantage persist on naturalistic open-domain tasks (dialogue, tool use, multi-step agentic reasoning) rather than the synthetic relation/program/proof-discourse families used here?
- What specifically caused the one Local → Shared misclassification in the model-organism test, and would a richer or adversarially-chosen operation bank reduce this false-Shared rate?
- How does the Sharedness Gain magnitude (0.2–0.3 nats) scale with model size beyond the two fully-evaluated 1.5B/8B models — would it grow, shrink, or vanish at frontier scale?
- Does the recovered Shared interface correspond to any previously identified interpretable feature/direction (e.g., from SAEs or the cited Gurnee et al. verbalizable-representation work) under direct comparison, beyond the TOST equivalence test versus J-space mentioned for representation-identity analysis?
- Could the cross-family transplantation degradation be explained by a small number of shared low-level features rather than genuine partial API alignment, and how would one distinguish these two accounts experimentally?
