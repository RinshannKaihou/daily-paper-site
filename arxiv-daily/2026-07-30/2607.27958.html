Key metric
+24.88pp

Peer-selection accuracy gain for Qwen3-0.6B under the hardest counterfactual attack, CF@90 (peer identity swapped with a weak peer 90% of the time).

46.22% base → 71.10% with Σ-Mem
Why this matters

Gives multi-agent LLM coordination, routing, and trust modeling a theoretically stable, reusable memory for "who to trust" — without retraining any model.

Critical edge

At the deliberately ambiguous CF@50 setting, Σ-Mem's voting underperforms the plain base model for 4 of 5 central models.

Methodology

Trained offline on 2,963 events across three domains — GSM8K (math), SQuAD (RAG), APPS (code) — each paired with fixed responses from three peers (Gemma-3-4B-it, Phi-4-mini-instruct, Qwen2.5-Coder-7B-Instruct) and a binary correctness label.

  • Two symmetric matrices, feedback-only updates. A per-peer competence matrix M_p and a peer-relationship matrix G are both updated purely from post-decision correctness feedback via a decayed, bounded rank-one rule: M_p ← γM_p + η·cp,t·φ(xt)φ(xt)ᵀ. No retraining of the peer or central models.
  • Weyl's-inequality stability. Each event-level update is a provably bounded spectral perturbation (|Δλ| ≤ η); Theorem 1 shows the leading eigenvalue eventually reflects true task-conditioned competence rather than event-level noise, with full proof in Appendix A.2.
  • One frozen memory, three read paths. The same M_p / G state supports residual steering (injected into the upper half of the central model's decoder layers before a Yes/No utility judgment), response-free M-Route selection, and M-Vote reliability-weighted aggregation.

Strengths

  • Weyl's-inequality stability proof plus a full signal-vs-noise theorem, not an ad hoc decay heuristic.
  • One trained memory state reused across three qualitatively different consumption mechanisms without retraining.
  • Honestly reports its own CF@50 failure mode with a plausible mechanistic explanation.
  • Includes a carefully constructed, non-strawman Bayesian-Beta baseline that is allowed to win in some regimes.
  • Broad coverage: five central models, peer pools up to five (two unseen), six OOD benchmarks.

Limitations

  • CF@50 accuracy falls below the unmodified base model for 4 of 5 central models on ambiguous evidence.
  • The three training peers are near-orthogonal by domain (Table 5) — may make "who to trust" easier than in realistic, overlapping-competence settings.
  • Training data spans only 3 domains and 2,963 events, all English, well-structured tasks.
  • No ablation of the decay/update hyperparameters (γ, η, γ_G, η_G, w_u, w_g) central to the paper's own stability theorem.
  • Marked "under review"; no working code link printed in the visible text, so reproduction is unverified.

Questions for Further Exploration

  • Would gains shrink with overlapping, less cleanly separable peer competence instead of Table 5's near-orthogonal specialization?
  • Can an adaptive readout (future work) resolve the CF@50 degradation by weighting historical memory against current-response ambiguity?
  • How sensitive is performance to the decay/update hyperparameters underpinning the Weyl's-inequality guarantee — is there a principled way to set them?
  • Does the steering pathway's projection matrix P and gain g add value beyond the raw memory readout sp,t?
  • How does Σ-Mem behave when correctness feedback is noisy, delayed, or itself supplied by another LLM judge rather than a clean oracle?
