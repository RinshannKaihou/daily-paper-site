> **一句话总结：** 作者提出"可观测性阶梯"框架，在固定一次推理运行的前提下逐级扩大读者可见证据（响应、自摘要、完整思维链、内部信号），在 GPQA-Diamond、MMLU-Pro、Omni-MATH-2-Filtered 三个基准和五个开源模型上证明：当用户已经知道 prompt 时，思维链摘要几乎不带来额外的正确性预测增益（+0.019 AUROC vs. 隐藏 prompt 时的 +0.156），而完整思维链仍稳定提供 +0.041 的额外信号；因此"可监控性"是显示内容与读者共同决定的属性，任何监控声明都必须同时指定二者。

> **TL;DR:** The paper introduces an "observability ladder" that holds one completed reasoning run fixed and varies only what a reader sees (response, model-written self-summary, full chain-of-thought trace, and provider-side internal signals), with and without the prompt, evaluated on GPQA-Diamond, MMLU-Pro, and Omni-MATH-2-Filtered across five open-weight Qwen3/gpt-oss models. With the prompt visible, the self-summary adds only +0.019 AUROC versus +0.156 when the prompt is withheld, while the full trace still adds +0.041; on repeated runs of the same MMLU-Pro question, linear summary readers collapse to near-chance (within-item AUROC 0.503–0.545) while trace readers retain modest signal (0.544–0.590), and a GPT-5-mini reader recovers more summary signal but the trace still leads by +0.034. Monitorability is therefore a joint property of the display and the reader, and any monitorability claim—including for faithfulness—must specify both.

## 核心贡献

- **提出"可观测性阶梯"（Observability Ladder）框架**：固定一次完整推理运行和正确性标签，仅改变读者可见的证据层级（最终响应 R、模型自摘要 S、完整思维链 C、provider 端内部信号 Z），从而把"显示了什么"与"读者能学到什么"解耦，使监控声明变得可量化、可比较。
- **系统量化了摘要 vs. 完整思维链的信息价值**：在线性探针读者下，无 prompt 时短摘要携带了思维链大部分的排序信号（mean AUROC 0.774 vs. 0.813，rAUROC=0.874），但一旦 prompt 可见，摘要增益从 +0.156 崩塌到 +0.019，而思维链仍稳定提供 +0.041 的额外信号——这一发现直接挑战了商业部署中"短摘要可替代完整思维链用于监控"的常见假设。
- **区分两种监控任务**：跨问题排序（across-item ranking，prompt 已知时监控器的常见场景）vs. 同一问题多次采样的运行级判别（within-item discrimination）。后者中线性摘要读者近乎随机（0.503–0.545），说明摘要对"判断本次运行是否正确"几乎没有用。
- **揭示"可监控性 = 显示 × 读者"的耦合性**：通过 GPT-5-mini 读者敏感性分析证明，更强的读者能从相同摘要中提取出线性读者无法提取的信号（summary within-item AUROC 从近随机升至 0.649），因此任何关于监控/忠实性的结论都必须声明所用的读者。
- **严谨的控制与消融**：包括 prompt 去重（noqcopy）、答案/选项/数字掩码、长度残差化、Shapley 归因、不同特征族（Cohere embed、TF-IDF、surface features）、解码变异、Leave-one-family-out 等大量稳健性检查，所有代码与数据公开。

## Key Contributions

- **The observability ladder framework**: a controlled design that fixes the completed run and correctness label while varying only what a reader can inspect (response R, model-written self-summary S ≤ 90 words, full reasoning trace C, and provider-side replay features Z), enabling apples-to-apples comparison of evidence levels.
- **Quantification of summary vs. trace value under linear probes**: without the prompt, summaries carry most of the trace's ranking signal (mean AUROC 0.774 vs. 0.813, rAUROC 0.874); with the prompt visible, the summary gain collapses from +0.156 to +0.019 AUROC while the trace still adds +0.041 — empirically challenging the assumption that provider summaries substitute for full traces when monitoring correctness.
- **Separation of two monitoring tasks**: across-item ranking (the common prompt-visible setting) versus within-item run discrimination (correct vs. incorrect runs of the same question). Linear summary readers are near chance on the latter (within-item AUROC 0.503–0.545 on MMLU-Pro discordant items).
- **Reader-relativity result**: a GPT-5-mini reader recovers substantially more summary signal than the linear reader (summary within-item AUROC 0.649 vs. near-chance for linear), yet the trace still leads by +0.034 — establishing that monitorability is a joint property of display and reader.
- **Extensive controls and open release**: prompt-overlap stripping, answer/option/number masking, length residualization, Shapley attribution over all seven {R,S,C} subsets, multiple feature families (Cohere embed-v4, TF-IDF, surface features), decoding-sensitivity balanced subsamples, leave-one-family/benchmark-out, and label-permutation checks; code and data are public.

## Methodology

The experiment crosses five open-weight target models (Qwen3-4B/8B/14B and gpt-oss-20b/120b) with three benchmarks (GPQA-Diamond, n=198; MMLU-Pro, n=12,032; Omni-MATH-2-Filtered, n=4,181), giving 15 model–benchmark settings. Each item produces one completed reasoning run with vLLM using `enable_thinking=True`, from which the authors separate prompt q, full reasoning trace C, final response R, and correctness label y (option match for the two MC benchmarks; GPT-5-mini equivalence judging for Omni-MATH-2-Filtered). The same target model then writes a self-summary S from C alone (no prompt, response, label, or hidden states) under an instruction requesting ≤90 words (mean length 77.0 words, n=82,055 summaries). Provider-side replay features Z are extracted separately from a prompt-conditioned final-token replay: answer-probability features and the last-layer hidden state.

The ladder defines four nested access levels (prompt-visible): q+R → q+R+S → q+R+S+C → q+R+S+C+Z, plus a matched prompt-withheld contrast (R → R+S → R+S+C, plus Z). To handle order dependence (since S derives from C), monitors are fitted to all seven nonempty subsets of {R,S,C} and Shapley attribution averages each component's marginal contribution across subsets. Each display is encoded as surface features (word/sentence counts, digit and math-symbol density, rates of uncertainty/self-correction/answer-framing markers) concatenated with a 512-dim Cohere embed-v4.0 embedding, plus optional replay features; an L2-regularized logistic probe maps this to a correctness score. The unit of inference is the model–benchmark setting (n=15), and reported estimates average paired contrasts on fixed held-out items with 95% descriptive setting-bootstrap intervals; a mixed-model sensitivity interval addresses generalization beyond the observed design.

Three additional controls are central: (1) a repeated-run comparison that generates two extra MMLU-Pro runs per item and measures within-item AUROC on the 939–1,389 outcome-discordant items per model; (2) a length-matched comparison that replaces the summary with deterministic Last90/First90/Random/HeadTail trace extracts at equal word budget; and (3) a GPT-5-mini reader sensitivity on gpt-oss-20b discordant items using a fixed judge instruction across all ten displays. Masking and prompt-overlap-stripping controls further check that results do not depend on verbatim answer/option leakage.

## Results & Highlights

- **Summary gain collapses when the prompt is visible**: adding the summary to q+R gives only q∆S = +0.019 AUROC (95% descriptive interval [+0.011, +0.027], and the mixed-model interval includes zero), versus ∆S = +0.156 when the prompt is withheld — a paired difference of −0.137. The full trace still adds q∆C = +0.041 with the prompt visible (interval [+0.028, +0.052]).
- **Prompt-only baseline is already strong**: a prompt-only reader reaches mean AUROC 0.734 across the 15 settings, while the response-only (prompt-withheld) reader reaches only 0.623 — most of the "summary value" in the output-only setting overlaps with information already in the prompt.
- **Summaries carry most of the trace's ranking signal when prompt is withheld**: summary-only AUROC 0.774 vs. trace-only AUROC 0.813 (mean across 15 settings), with normalized excess-AUROC ratio rAUROC = 0.874 (interval [0.855, 0.896]); full public display R+S+C reaches 0.814.
- **Equal-length trace extracts match or beat summaries**: under the open surface-plus-TF-IDF monitor, the Last90 trace extract reaches AUROC 0.804 vs. 0.778 for the capped 90-word summary (paired +0.025, interval [+0.013, +0.038]); Last90 also contains higher rates of uncertainty (+0.009), self-correction (+0.012), and answer markers (+0.051).
- **Repeated-run summary readers are near chance**: on the 939–1,389 outcome-discordant MMLU-Pro items per model, summary displays achieve within-item AUROC only 0.503–0.545 (vs. 0.544–0.590 for trace-containing displays); response-only is 0.493–0.550 with intervals covering 0.5 in two settings.
- **Length accounts for much of the linear trace signal**: trace word count alone reaches within-question AUROC 0.553 (vs. 0.567 for the full primary trace reader); after linear residualization on word and sentence counts, the prompt-withheld public-ladder gain shrinks from +0.156/+0.041 patterns down to +0.101 and the trace-minus-summary contrast turns slightly negative (−0.024).
- **Stronger reader changes the picture**: a GPT-5-mini reader on gpt-oss-20b reaches summary within-item AUROC 0.649 and trace 0.683 (vs. near-chance and modest for linear), and the trace still leads the summary by +0.034 ([+0.008, +0.059]); when GPT-5-mini also sees prompt+response its within-item AUROC hits 0.800, but this conflates monitoring with task-solving.
- **Selective-coverage error rates**: at 50% coverage (retaining the half of runs ranked most likely correct), mean error rate drops from 0.243 (R only) to 0.139 (R+S), 0.114 (R+S+C), and 0.098 after adding Z.
- **Benchmark differences**: mean q∆full is +0.036 on GPQA-Diamond, +0.132 on MMLU-Pro, and +0.100 on Omni-MATH-2-Filtered; the matched prompt-withheld full gains are +0.230, +0.295, and +0.127 respectively.
- **Robustness**: leave-one-family-out, leave-one-benchmark-out, item-clustered intervals, and item-weighted aggregation all preserve the prompt-withheld full-ladder gain in [+0.178, +0.262]; label permutation returns every level to chance; nested component-block control changes AUROC by only −0.004 to +0.016 and preserves every access increment.

## Critical Assessment

- **Novelty**: genuinely useful conceptual contribution. The "hold the run fixed, vary only the display" framing cleanly isolates information content from run variance, and the within-item vs. across-item distinction is an important clarification that prior CoT-monitorability work (e.g., the OpenAI/Anthropic chain-of-thought monitorability line) tends to conflate. However, the component pieces (linear probing of traces for correctness, length-as-signal, summary-vs-trace comparisons) are individually well-trodden.
- **Rigor**: very high. Paired contrasts on fixed held-out items, 15 model–benchmark settings as the unit of inference, descriptive setting-bootstrap and mixed-model sensitivity intervals reported side by side, Shapley attribution to handle order dependence, multiple feature families (Cohere, TF-IDF, surface) as mutual checks, masking/noqcopy controls, decoding-sensitivity balanced subsamples, leave-one-out sensitivities, and label-permutation null checks. The honesty about the prompt-withheld case inflating summary value (because the response is often a bare option letter on MMLU-Pro/GPQA) is a notable example of self-critique.
- **Reproducibility**: strong. Open-weight models, public code, public data with hashes, fixed splits, documented parser edge cases (empty `<think></think>` blocks for Qwen3-8B/14B; missing closing tags on Omni-MATH-2-Filtered), and explicit version pinning (Python 3.13.1, vLLM 0.12.0, transformers 5.8.0, etc.). One gap: the summary-decoding seed was recorded but the RNG was not fixed for primary summaries, though a balanced subsample re-decodes summaries to bound the variance.
- **Significance**: practically relevant for AI safety/deployment. It gives concrete evidence that, for users who already know the prompt, a provider-written short summary is not a substitute for the full trace when monitoring correctness — directly informing ongoing policy debates (OpenAI, Anthropic, Google reasoning summary products) about what to expose. The reader-relativity result (linear reader near chance, GPT-5-mini substantially better on the same summaries) is the single most decision-relevant finding.
- **Red flags / specific weaknesses**:
  1. **The summary is a controlled proxy, not the deployed artifact.** S is written by the same model from C alone under one instruction, with no prompt, no content filters, no RLHF post-processing, and no incentive to evade a monitor. The authors flag this clearly, but it means the headline "+0.019" does not directly describe OpenAI/Anthropic/Gemini "thinking summaries" — a direct test on commercial models is left as future work.
  2. **Linear readers are the main estimator.** The bulk of the conclusions rest on L2-regularized logistic probes over Cohere embeddings + surface features. The only stronger-reader test covers one judge (GPT-5-mini), one model (gpt-oss-20b), and one benchmark (MMLU-Pro discordant items), so the reader-relativity claim, while directionally sound, is empirically thin.
  3. **Length confound is not resolved.** Residualizing on word and sentence counts removes most of the across-item gains and flips the trace-minus-summary sign — a serious concern for any semantic interpretation. The within-item trace edge survives length-matched pairs, but those retain only 16–32% of discordant pairs, so they are selective sensitivities.
  4. **Repeated-run subset is unrepresentative.** The 939–1,389 discordant items have 23–30 percentage-point lower accuracy and 2.5–3× longer median traces than the rest — the near-chance summary result applies to an unusually hard, unstable subset, not all MMLU-Pro questions.
  5. **Three benchmarks, two model families.** Generalization claims are bounded; the authors acknowledge their mixed-model intervals are sensitivity summaries for the observed design rather than population-level intervals.
  6. **GPT-5-mini judging of Omni-MATH-2-Filtered** agrees with the deterministic checker on only 69.7% of resolved comparisons and accepts 49.5% of deterministic mismatches as "semantically equivalent" — label noise that is acknowledged but not deeply quantified for downstream effect.
  7. **Correctness only.** The ladder measures final-answer correctness; the authors explicitly disclaim that this says anything about faithfulness, reward hacking, or causal computation, and extending to those requires labels independent of the reader.

## Strengths

- Clean, well-motivated experimental design that isolates information content by holding the run fixed.
- Large and rigorous control suite: Shapley attribution, masking, prompt-overlap stripping, length residualization, leave-one-out, label permutation, decoding sensitivity, chunk-level pooling.
- Two complementary monitoring regimes (across-item ranking and within-item run discrimination) cleanly separated, with the right metric for each (within-item AUROC for the latter).
- Reader-relativity finding is the most important and decision-relevant result for the AI-safety community.
- Honest framing throughout: every claim is explicitly tagged with the reader that produced it and the limitations of the summary proxy.
- Fully open: code, data, weights/hashes, parser diagnostics, and version pins.

## Limitations

- Summaries are a controlled proxy (same model, trace-only input, one instruction, no filters, no adversarial pressure); they do not describe deployed commercial reasoning summaries.
- Main estimates use simple linear readers; the only stronger-reader test (GPT-5-mini) covers one model/benchmark and one judge instruction.
- Length is entangled with the linear readers' signal; residualization shows influence but cannot causally disentangle it.
- The repeated-run subset is systematically harder and longer than typical MMLU-Pro items, limiting the generality of the within-item result.
- Three benchmarks and two model families bound population-level generalization; intervals are sensitivity summaries, not population intervals.
- The ladder measures final-answer correctness only, not faithfulness, misbehavior, or causal computation.
- GPT-5-mini grading of Omni-MATH-2-Filtered introduces non-trivial label noise (69.7% agreement with the deterministic checker).
- No evaluation of closed API models (OpenAI/Anthropic/Google), which is where the practical monitoring question is most acute.

## Relevance

This paper is highly relevant to research on chain-of-thought monitorability, interpretability, and AI safety: it provides the first systematic, run-fixed framework for asking whether provider-written reasoning summaries can substitute for full traces when judging correctness, and its central finding (summary value depends jointly on prompt visibility and reader strength) directly informs what evidence deployments must expose for reliable monitoring.

## Questions for Further Exploration

- How do the results change when the summary is generated by a different (weaker or stronger) model, or with the prompt and response visible to the summarizer — i.e., closer to deployed provider summaries?
- Does the reader-relativity result extend beyond GPT-5-mini to other frontier judges and beyond gpt-oss-20b/MMLU-Pro, and is there a reader capability threshold above which summaries become sufficient?
- Can the design be extended to monitor for faithfulness, reward hacking, or deception using labels defined independently of the reader, given that the authors explicitly leave this open?
- How much of the trace's residual signal is semantic versus superficial length/markers, once length and lexical markers are jointly controlled with non-linear readers?
- What happens on closed API models (OpenAI o-series, Anthropic extended thinking, Gemini thinking) that expose only summaries, and can the paired ladder comparison be replicated there?
- Are the near-chance within-item summary readers a property of the linear probe family, or do richer item-conditional monitors (e.g., trained on per-item feature differences with more capacity) recover signal that this paper's pairwise logistic control misses?
