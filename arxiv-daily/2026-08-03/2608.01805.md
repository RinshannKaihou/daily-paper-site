> **一句话总结：** 作者提出 CockpitHAT，将多智能体失败归因从"位置窗口"升级为基于交互 DAG 的"依赖距离分层切片"，再叠加多通道具身证据与 ISO 26262 ASIL 安全加权共识，并发布 CockpitBench（212 条 ASIL 标注的座舱失败轨迹），在 Who&When 上较 SOTA ECHO 提升最高 17.6/16.7 个点。

> **TL;DR:** CockpitHAT is the first dependency-graph-driven, multi-channel, risk-calibrated attribution framework for embodied LLM multi-agent cockpit systems; on the public Who&When benchmark it beats the text-only SOTA ECHO by up to +17.6 agent-level / +16.7 step-exact points (77.9%/86.5% agent accuracy vs ECHO's 68.1%/68.9%), and on the new ASIL-annotated CockpitBench (212 traces) it reaches 78.3% agent and 38.2% step-exact accuracy, with the Embodied Channel Adapter alone contributing +6.2 step points on CockpitBench.

## 核心贡献

- 揭示并形式化了 LLM 多智能体系统中的"正确性坍塌（Correctness Collapse）"问题——任务级高准确率掩盖严重的进程级失败，在安全关键的汽车座舱场景中尤其危险。
- 提出 CockpitHAT 框架：用交互 DAG 推导的依赖距离替代 ECHO 等方法使用的位置窗口，对每个焦点步骤构建四层（Immediate/Local/Distant/Global）分层上下文。
- 设计具身通道适配器（ECA）：当轨迹含具身字段时，用单次轻量 LLM 扫描将安全/交互/环境/跨域相关步骤"提升"到更浅层，并把对应的环境 e、车辆状态 σ、记忆 m 字段附加到上下文；`SAFETY_VIOLATION` 一律强制进入 L1。
- 提出安全上扬的目标共识机制：4 名分析师（1 名强制 Safety Analyst + 3 名从六人格池抽样），通过两阶段因子化共识（先取最严重 ASIL 先验，再做不对称上扬边际聚合），用 ISO 26262 ASIL 偏序 D≻C≻B≻A 加权，避免对称成本聚合放大高严重度轨迹上的正确性坍塌。
- 发布 CockpitBench：212 条带 ASIL A–D 标注的座舱失败轨迹，覆盖 8 类失败，三专家共识标注 + 独立安全审计；显式弥补 Who&When 与 AgentRx 在文本模态、无安全标签、单标注者偏差、罕见严重失败覆盖不足上的四项结构性缺陷。
- 在公开 Who&When 的 Hand-Crafted 与 Algorithm-Generated 两个划分上均刷新 SOTA，并给出逐组件消融（I1→I6）证明依赖分层是主导贡献、ECA 仅在具身数据上生效。

## Key Contributions

- Identifies and targets **Correctness Collapse** in LLM multi-agent systems (SOTA models degrade from 96% to 56% under dialectical evaluation) and shows it is especially hazardous in automotive cockpits, where lexically correct utterances can trigger dangerous physical actions (citing the Feb-2026 Lynk&Co "lights off" incident).
- **CockpitHAT framework**: replaces positional context windows (as in ECHO) with dependency-distance tiers derived from an interaction DAG, where edges are induced by four operational signals (reference / plan / tool / control) and the shortest undirected path length defines dependency distance.
- **Embodied Channel Adapter (ECA)**: a single per-trace salience scan flags four embodied failure classes (INTERACTION_RISK, ENV_MISGROUNDING, SAFETY_VIOLATION, CROSS_DOMAIN) and promotes flagged nodes up one layer (SAFETY_VIOLATION forced into L1 regardless of distance), attaching the matching e/σ/m channel fields via Π(τ).
- **Safety-uplifted decoupled consensus**: K=4 analysts (1 mandatory Safety Analyst + 3 sampled from a six-persona pool) with two-stage factorized consensus — Stage 1 takes maximum-severity prior η* = max{η̂_k | c_k ≥ δ_conf}, Stage 2 applies an asymmetric exponential uplift Ω(safe, ASIL-D) ≈ 2.16 capped at κ(K−1) to prevent single-analyst tyranny.
- **CockpitBench**: 212 traces (78 adapted from Who&When, 83 anonymized IRB-approved real telemetry, 51 adversarial edge cases), 8 failure categories, 4 ASIL levels (98 A / 51 B / 37 C / 26 D), three-expert consensus annotation plus ISO 26262-qualified audit; Fleiss' κ = 0.71 (agent), 0.68 (step ±1), 0.74 (category), 10% re-annotation intra-rater >0.82, safety-audit ASIL consistency 96.4%.
- State-of-the-art results on both Who&When splits with full statistical significance (chi-squared, p<0.05) and an exhaustive additive ablation (I1→I6) decomposing the contribution of each component.

## Methodology

CockpitHAT is a four-stage, post-hoc attribution pipeline that takes a role-tagged multi-agent trace T = ⟨s₁,…,sₙ⟩ and the system answer α, and outputs (responsible agent, responsible step, failure category, ASIL level).

**(1) Dependency Graph Construction.** Each step sᵢ = (rᵢ, cᵢ) becomes a node vᵢ (rᵢ = acting agent/sub-mode, cᵢ = free text or structured {tool_call, tool_output}). Embodied side-channels (eᵢ environment, σᵢ vehicle state, mᵢ memory) attach as node attributes. A directed edge vᵢ → vⱼ is added when sⱼ depends on sᵢ via one of four operational signals: reference (entity linking), plan, tool output, or control/dispatch. Edge induction is local pattern matching plus entity linking, giving O(n²) worst-case / O(n) practical cost under a look-back cap. Only entity linking invokes a lightweight LLM (Doubao-Seed-1.6-Flash); the rest is deterministic and reusable across rounds.

**(2) Dependency-Distance Hierarchical Slicing.** Dependency distance dd(vᵢ, vⱼ) = length of the shortest undirected path in G. Each focal step gets a four-layer context Cᵢ = (L1, L2, L3, L4): L1 = {vᵢ} ∪ N1(vᵢ) verbatim with full reasoning/tool I/O; L2 = N2(vᵢ) compressed to key actions/commitments/conclusions; L3 = N3 ∪ N4 summarized to ≤20 words per step; L4 = nodes with dd ≥ 5 as sparse milestones. Layer membership is driven by dependency distance, not positional offset — two temporally adjacent but dependency-unrelated steps are treated as far. When G is near-linear the slicing degrades gracefully to positional layering.

**(3) Embodied Channel Adapter (ECA).** Activated only when the trace schema contains embodied fields; otherwise the text-only pipeline is used. A single per-trace LLM scan over one-line step summaries augmented with (rᵢ, eᵢ, σᵢ, mᵢ) and the final answer returns salience tuples S = {(i, τᵢ, pᵢ)} with τᵢ ∈ {INTERACTION_RISK, ENV_MISGROUNDING, SAFETY_VIOLATION, CROSS_DOMAIN}. Each flagged node is promoted one layer up (L_k → L_{max(1,k−1)}), with SAFETY_VIOLATION forced into L1. Channel fields are attached by Π(τ): {σ} for INTERACTION_RISK, {e} for ENV_MISGROUNDING, {σ,e} for SAFETY_VIOLATION, {m} for CROSS_DOMAIN. The scanner consumes <2% of the per-trace analyst token budget.

**(4) Safety-Uplifted Objective Consensus.** A dynamic panel of K=4 analysts per trace: one mandatory Safety Analyst (A_safe) plus three sampled without replacement from a six-persona pool (Conservative, Liberal, Detail-Focused, Pattern-Focused, Skeptical, General). Each A_k independently consumes the adapted contexts {C̃ᵢ} and emits (ŝ_k, â_k, τ̂_k, η̂_k) plus confidence c_k. Two-stage factorized consensus decouples severity from attribution to avoid a self-reinforcing loop:
- Stage 1: η* = max{η̂_k | c_k ≥ δ_conf=0.3} under the ASIL partial order (D≻C≻B≻A), so specialist alarms cannot be outvoted.
- Stage 2: asymmetric uplift weight Ω(k, η*) = 1 + I[k=safe] · min(λ(e^{β(v(η*)−1)} − 1), κ(K−1)), with λ=0.5, β=0.4, κ=1.0, giving Ω(safe, ASIL-A)=1.0 and ≈2.16 at ASIL-D. Marginal vote S_x(x) = Σ_k c_k·Ω_k·I[x̂_k=x] / Σ_k c_k·Ω_k. If the weakest marginal score falls below an ASIL-calibrated δ_cons(η*), a Disagreement Resolution protocol forces evidence citation.

All analyst agents use Doubao-Seed-2.0-Pro at T=0, top-p=1 for deterministic decoding.

## Results & Highlights

- **Who&When, Hand-Crafted, Agent-Level Accuracy:** CockpitHAT reaches **77.9%**, beating ECHO (68.1%) by **+9.8 pts**, Step-by-Step (31.0%), All-at-Once (65.3%), and Random (12.1%); chi-squared p<0.05 against every baseline.
- **Who&When, Algorithm-Generated, Agent-Level Accuracy:** CockpitHAT reaches **86.5%** vs ECHO **68.9%** (+17.6 pts), with step-exact at **46.0%** vs ECHO **29.3%** (+16.7 pts) — a +57.0% relative step-exact improvement attributed to dependency-distance slicing exposing dense AG dependency chains.
- **Step-exact on Hand-Crafted:** CockpitHAT **37.8%** vs ECHO **29.3%** (+8.5 pts); with ±1 tolerance it reaches **39.7%** (vs ECHO 32.7%) and widens the lead monotonically to **62.3%** at ±5 (vs ECHO 50.0%), a +12.3-pt gap, indicating predictions stay within the dependency neighborhood even when not exact.
- **CockpitBench overall:** **78.3% Agent, 38.2% Step-exact, 57.6% Failure-Category accuracy, 75.5% ASIL-Level accuracy** on 212 traces.
- **Token efficiency on Hand-Crafted:** CockpitHAT uses **68,287 tokens/trace** vs ECHO 58,662 (+16.4%) and Step-by-Step 83,245 (−18.0%) — modest overhead for +9.8/+8.5 pt gains; All-at-Once is cheapest (16,821) but plateaus at 65.3%.
- **Ablation (CockpitBench column):** building up from Fixed Context (I1: 21.1% agent), Dependency Hierarchical slicing (I2→I3) delivers the single largest jump of **+25.2 agent pts** (33.7%→58.9%); ECA (I5→I6) is the decisive step contributor at **+6.2 step pts** (32.0%→38.2%) and +4.5 agent pts — a pattern not seen on text-only Who&Where.
- **Per-ASIL on CockpitBench:** Step accuracy is higher at the severe end — ASIL-C 43.2%, ASIL-D 46.2% vs ASIL-A 35.7% — and ASIL-Level precision reaches **84.6% at ASIL-D**, confirming the safety-uplift design concentrates gains where diagnostic reliability matters most.
- **Per-category peaks:** Misinterpretation of Tool Output is easiest at agent level (**83.3%**) thanks to explicit tool propagation paths; Safety Safeguard Failure is the strongest embodied anchor (Step 46.3%, F-Cat 61.0%); Driver–Agent Interaction has the lowest agent precision (68.8%), reflecting human-boundary ambiguity; Planning Failure is weakest at step level (29.2%) due to temporally diffuse errors.

## Authors & Credibility

All seven authors (Wei Wang, Shuanghe Liu — co-first; Zhu Zhuo, Jiaqi Zhong, Xiaozhao Zhao, Xiaojie Zuo, Jie Su) are affiliated with **ByteDance**, and the work is disclosed as part of regular employment duties with no external funding. Credibility signals are strong: (i) the paper reproduces all baselines (Random, All-at-Once, Step-by-Step, ECHO) under a single shared model (Doubao-Seed-2.0-Pro, T=0) and even reports that its faithful re-implementation of ECHO yields slightly improved baseline numbers; (ii) statistical significance is reported as chi-squared tests per baseline with p-values in Table 1; (iii) CockpitBench annotation quality is validated by Fleiss' κ (0.68–0.74, "substantial"), 14-day washout intra-rater >0.82, and a 96.4% ASIL consistency from an independent ISO 26262-qualified safety audit; (iv) complete prompt templates (Prompts 1–4) and Algorithm 1 are provided in the appendix, and the authors commit to public release of code and data under a permissive license. The benchmark combines 78 Who&When-derived, 83 anonymized real telemetry (IRB-approved), and 51 adversarial edge-case scenarios, giving it ecological validity beyond purely synthetic suites.

## Critical Assessment

- **Novelty:** Genuine. Combining dependency-DAG slicing with multi-channel embodied evidence and ISO 26262 ASIL-calibrated consensus is, as the authors argue, the first such coupling; ECHO (Banerjee 2025) is explicitly positional, AgentRx (Barke 2026) is text-only software agents, Who&When (Zhang 2025) achieves only 53.5%/14.2%. The Embodied Channel Adapter and the decoupled two-stage severity/attribution consensus are non-trivial and well-motivated.
- **Rigor:** Mostly strong — chi-squared significance, six-step additive ablation, multi-expert annotation with κ reported, independent safety audit. However, only one analyst backbone is used (Doubao-Seed-2.0-Pro); results under GPT-class, Claude-class, or open reasoning models are not shown, leaving the open question of how much of the gain is backbone-specific to ByteDance's own stack.
- **Reproducibility:** High on paper — Algorithm 1, full prompts, hyperparameters (λ=0.5, β=0.4, κ=1.0, δ_conf=0.3, K=4), and tokenizer all specified; promise of public code/data. Caveat: 83 of 212 CockpitBench traces come from "anonymized production driving telemetry," and the exact de-identification pipeline is not fully specified, which may limit third-party re-verification of those scenarios.
- **Significance:** Practically important — directly addresses a real safety incident (Feb-2026 Lynk&Co "lights off") and the under-representation of ASIL-C/D failures (which occur at <0.1% in naturalistic data) in existing benchmarks. The framework is post-hoc diagnostic only, which the authors honestly concede is not a substitute for real-time mitigation.
- **Red flags / weaknesses:**
  - **Single-vendor evaluation.** All baselines and CockpitHAT run on Doubao-Seed-2.0-Pro; no cross-model robustness study, and the ECA scanner/entity-linker use a smaller Doubao model — external validity is unproven.
  - **Step-exact accuracy remains low (37.8%–46.0%).** The headline "beats ECHO by 16.7 pts" still leaves a majority of steps mis-localized exactly; the widening ±k tolerance lead is real but somewhat softens the precision claim.
  - **Safety-uplift hyperparameters (λ, β, κ) and panel size are hand-tuned for cockpits** and the authors admit they "are not adaptive and may require manual tuning" elsewhere — a known generalization risk.
  - **Dependency graph only captures four explicit operational signals** and misses implicit, shared-background dependencies in open-ended scenarios (acknowledged limitation).
  - **CockpitBench n=212 is small**, and 26 ASIL-D traces is thin for stratified claims about the highest-severity regime, despite oversampling.
  - **No real-time / online detection** — purely post-hoc, which limits operational deployment for preventing catastrophic outcomes.

## Strengths

- Cleanly formalizes a real, safety-relevant failure mode (Correctness Collapse) and motivates every design choice against it.
- The dependency-distance slicing idea is principled and empirically dominant (+25.2 agent pts on CockpitBench, the largest single jump in the ablation).
- The Embodied Channel Adapter is a concrete, low-cost (<2% token budget) mechanism for injecting multi-modal evidence, with `SAFETY_VIOLATION → L1` a sensible hard rule.
- CockpitBench fills four genuine gaps (modality, ASIL labels, single-rater bias, rare-failure coverage) and its annotation pipeline (three-expert consensus + ISO 26262 audit + contested-trace retention) is exemplary.
- Honest reporting: baselines are re-run for fairness, slight baseline improvements are disclosed, p-values are reported per comparison.

## Limitations

- Post-hoc only; no real-time detection or mitigation, which is critical for preventing catastrophic outcomes in safety-critical cockpits.
- Dependency graph relies solely on four explicit signals; implicit dependencies from shared background knowledge (especially in ambiguous open-ended scenarios) are missed.
- Safety-uplift hyperparameters and panel configuration are calibrated specifically for automotive cockpits and are not adaptive across domains (e.g., medical, smart home).
- Single backbone family (Doubao) for both analysts and scanner — no cross-vendor robustness evidence.
- CockpitBench is small (212 traces; only 26 ASIL-D), limiting statistical power at the most safety-critical slice; future work targets >1,000 multilingual traces.
- Step-exact accuracy, while improved, is still under 50% on all splits, leaving fine-grained temporal localization an open problem.

## Relevance

This paper is highly relevant to research on **LLM multi-agent systems, agent evaluation/benchmarking, and embodied AI safety** — it directly tackles the dual (agent, step) failure attribution problem in stateful multi-agent stacks, introduces a dependency-graph-grounded context construction paradigm that could transfer to other agent pipelines, and contributes a safety-severity-annotated benchmark that raises the bar for evaluating reliability of LLM agent systems.

## Questions for Further Exploration

- How does CockpitHAT behave when the analyst backbone is swapped to a non-Doubao model (e.g., GPT-5, Claude Opus, DeepSeek R1)? Is the +17.6 pt gain over ECHO backbone-invariant, or partly an artifact of the ECA/analyst stack being co-designed with Doubao?
- The dependency graph uses only reference/plan/tool/control edges. Would adding semantic or co-reference edges (beyond entity linking) close the gap on Planning Failure step-exact accuracy (currently only 29.2%)?
- The safety-uplift parameters (λ=0.5, β=0.4, κ=1.0) are fixed. Is there a data-driven calibration (e.g., Bayesian optimization on a held-out ASIL-C/D slice) that generalizes better to medical or smart-home domains?
- Can the post-hoc ECA mechanism be inverted into a real-time guardrail — e.g., a streaming salience classifier that flags SAFETY_VIOLATION before the action is committed on the CAN bus?
- CockpitBench has 26 ASIL-D traces. What is the confidence interval on the 84.6% ASIL-Lv precision at that severity, and how does performance degrade as the benchmark scales toward the planned 1,000 multilingual traces?
- The paper retains "contested" traces to expose ambiguity. How does CockpitHAT's calibration (confidence vs. accuracy) behave specifically on the contested subset, and is there a principled deferral-to-human threshold?
