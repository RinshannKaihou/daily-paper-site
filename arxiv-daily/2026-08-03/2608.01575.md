> **一句话总结：** 作者构建 F-ICL——一个以 Brainfuck 族图灵完备微型机器 F（补对称化为 sF）穷举 1.5 亿条长度 ≤13 的程序、并据此闭式计算 Bayes 最优归纳后验的基准；在 105 次服务配置、46 个开源/前沿模型（0.8B–675B）上发现：模型可答对高达 92% 的题，但 45/46 的预测分布比"按键参考线"还偏离最优后验，且该缺口与精度解耦、不随规模改善、被指令微调放大，揭示当前 ICL 更像低阶前缀统计而非算法式推理。

> **TL;DR:** F-ICL is a new benchmark that scores LLMs against an *exactly computed* Bayes-optimal inductive posterior: by exhaustively enumerating all 1.5e9 programs of length ≤13 of a minimal Turing-complete machine F (complement-symmetrised into sF) and computing the Levin–Solomonoff posterior in closed form. Across 105 serving runs and 46 open/frontier models (0.8B–675B, including GPT-4o→GPT-5.6, Gemini, Claude, Grok), models hit up to 92% answer accuracy yet **45 of 46** sit *below* a uniform-keystroke reference in posterior fidelity (F-ICL-A), the gap is uncorrelated with accuracy (ρ=−0.19) and scale (ρ=+0.10, p=0.59), two years of OpenAI releases show no fidelity improvement (oldest GPT-4o is best at 0.43), and instruction/reasoning post-training *widens* the gap (e.g. Ministral-3-14B 0.47→0.39→0.36). Their behaviour is bracketed by low-order Krichevsky–Trofimov prefix statistics, suggesting LLMs implement a loop-free algorithmic mixture rather than the loop-bearing Bayes optimum.

## 核心贡献

- **首个具有闭式精确贝叶斯最优解的 ICL 基准（F-ICL）：** 用一个 5 指令、Brainfuck 家族的图灵完备磁带机 F，对长度 L ≤ 13 的全部约 15 亿条程序做穷举枚举，在受限通用（Levin–Solomonoff）先验下计算任意 few-shot 上下文的精确后验预测——把"模型离理想归纳推理有多近、逼近有多快"变成可精确计算的量，而非与其它模型或人类答案比较。
- **彻底对称化与认证机制消除机器偏置：** 引入补对称化机器 sF（`sP(s|x)=½P(s|x)+½P(s|x̄̄)`），使最优解在比特互补孪生任务上得分严格相等，从而任何极性偏差都完全归因于模型自身；并配备三条精确交叉验证关卡（计数 byte-级一致、见证程序再执行、规则集恒等）+ 服务期位恒等校验。
- **"后验保真度（posterior fidelity）"作为新的评测轴：** 提出与准确率正交的 F-ICL-A 锚定分（worst=0 / 按键参考=½ / Bayes=1），并辅以难度均衡分、Bayes 样本复杂度、效率比等指标，揭示"答得对"与"按最优后验分布地推"是两件事。
- **大规模、跨前沿的实证发现：** 在 105 次服务配置（49 API + 56 本地 GGUF）、37 个开源模型（0.8B–675B）+ 四大实验室前沿系统上系统性地证伪"规模/后训练/前沿代际改善算法推理"。
- **附带可复现的工具链与冻结数据：** GPU 枚举 + 独立 Python 复核 + 每模型的脚本、提示、读出审计全部发布，并文档化了 API 退化现象（token log-probabilities 在除 OpenAI 外的前沿 API 上正在消失）。

## Key Contributions

- **First ICL benchmark with a closed-form exact Bayes optimum.** F-ICL fixes a minimal Turing-complete tape machine F (five Brainfuck-family instructions) and exhaustively enumerates all ~1.5e9 programs of length ≤13 under a bounded Levin–Solomonoff prior, making the Bayes-optimal posterior predictive computable exactly (Eq. 1) — no tuning, no estimation, no comparison against other models.
- **Reference-machine bias removed exactly, not approximated.** Complement-symmetrisation into sF gives a provably polarity-invariant optimum (each task ships with its bitwise-complemented twin, on which the optimum scores identically); a three-gate exact certification chain (count cross-check, witness re-execution, rule-set identity) plus a bit-identical serving check make the ground truth auditable rather than bespoke.
- **A new distribution-level axis: posterior fidelity (F-ICL-A).** An anchored score places every predictor on [0,1] relative to three exact anchors (worst-case=0, uniform-keystroke reference=½, Bayes optimum=1), exposing a property that point-accuracy hides: how closely a model's *served distribution* matches the known-correct posterior.
- **A large, heterogeneous panel evaluated under a fixed target.** 105 serving runs / 46 distinct models (37 open 0.8B–675B + frontier systems from OpenAI, Google, xAI, Anthropic), all measured against the same frozen optima, prompts and decoding settings — the largest such exact-target ICL evaluation to date.
- **A reproducible, audited toolkit.** Taichi/CUDA enumeration, pure-Python reference implementation, degeneracy/read-out/answer audits, prompt ablations, and per-model serving metadata are released; the paper documents the *withering* of distribution-level frontier APIs (only OpenAI still returns log-probs for newest models).

## Methodology

**Reference machine and prior.** F is a 5-instruction tape automaton (`< > + [ ]`) over a 128-bit tape, preloaded with binary input, with output = bits visited during head excursion. Valid programs are bracket-matched strings; length-L programs are base-5 integers. They are weighted by the bounded universal prior `w(p)=2^−ℓ(|p|)`, with `ℓ(L)=(L+1)log₂6`; accumulating-evidence families additionally use Levin time-penalised weights `2^−ℓ−δ(t)` where δ(·) is the Elias-δ halt-time code. The enumeration budget is L ≤ 13, 1024 steps, 128 cells, with a coverage scan + Brent cycle detection recovering outliers that halt only beyond the base budget.

**Sufficient statistic and exact posterior.** Enumerating every program on a fixed input set yields the behaviour-to-mass map `w(b)=Σ_{p:beh(p)=b} w(p)`, a sufficient statistic. Given examples E, the exact posterior predictive is `P(s|x_q,E)=Σ_{b consistent, b(x_q)=s}w(b) / Σ_{b consistent}w(b)` (Eq. 1), served per length and summed. The sF polarity-symmetrised posterior `sP(s|x_q,E)=½P(s|x_q,E)+½P(s̄|x̄_q,Ē)` is computed as two F lookups.

**Three task families.** (i) *Induction* — predict a hidden program's output on a held-out query from (input→output) examples; scored, served via program-set intersection with length-only weights over the full L≤13 budget. (ii) *Continuation* — reveal a program's output token-by-token; model gives next-token distribution over {0,1,end}; scored, uses full conditionals with Levin weights. (iii) *Abduction* — infer which of 8 candidate inputs produced a revealed output; used only as a validation/foil-separation family because serving APIs do not expose a clean distribution over candidate inputs.

**Certification.** Three exact gates must agree for a build to be accepted: (1) per-(input,output) program counts match between an independent pure-Python F and the GPU aggregation (verified at L=5, M=8, all 511 inputs); (2) sampled stored entries decode their witness program and re-execute it with exact CPU semantics; (3) the dumped program index is re-enumerated for *set* identity (not just count) of program IDs per (input,output); plus a serving check that the served posterior is bit-identical to an exhaustive small-program joint across 0–5 examples including non-halting examples.

**Scoring.** Primary metric is base-2 Jensen–Shannon divergence `JS(P⋆‖P_model)`. The headline F-ICL-A anchored score (Eq. 20) maps the raw divergence so that worst-case predictor=0, keystroke reference=½, Bayes optimum=1, with linear distance within each regime. Difficulty is tagged by Bayes Sample Complexity (BSC = first shot at which optimal MAP = truth); the induction set is difficulty-balanced (120/120/120/120 over BSC∈{0,1,2,3+}). Efficiency = median over tasks of `min(1, BSC/n*)`. Each induction task also ships with its complement twin, enabling a polarity gap `∆pol = F-ICL-A(original) − F-ICL-A(twin)` which is provably zero for any complement-equivariant predictor.

**Panel and harness.** 105 runs: 49 API (NVIDIA NIM 30 open models; OpenAI GPT-4o May 2024 → GPT-5.6 nine-model dated ladder; Google Gemini 2.5/3.x + gemma-4; xAI Grok 4.20/4.5; Anthropic Claude Fable 5 / Opus 4.8 / fallback stack) and 56 local llama.cpp GGUF builds (quantisation ladders, parameter-scale ladders, base/instruct/reasoning triads). OpenAI-compatible harness drives both local and API endpoints; accuracy is constrained by a context-free grammar, log-probability facets read next-token logprobs over {0,1,end}. Reference foils (marginal/pattern-completion, nearest-input, uniform, KT add-½ order-0/order-1) and classical nulls (global output frequencies, pooled per-shot optima) are scored through the identical pipeline.

## Results & Highlights

- **The dissociation headline.** Models answer up to **92%** of in-context queries correctly, yet **78 of 81** log-probability runs (**45 of 46** distinct models) score *below* the uniform-keystroke reference (F-ICL-A = ½) on posterior fidelity (two-sided sign test p<10⁻⁹); the single exception is locally-served `gpt-oss-20b` at q6 (F-ICL-A = 0.53, 95% CI [0.50, 0.52]). Posterior fidelity is *uncorrelated* with point accuracy (base-model Spearman **ρ = −0.19, p = 0.21**).
- **Scale dissociation.** Across 32 base models spanning 0.8B–675B, answer accuracy rises significantly with log-parameters (**Spearman ρ = +0.39, p = 0.028**) while F-ICL-A shows *no detectable association* (**ρ = +0.10, p = 0.59**; 95% CI −0.26 to +0.43). Within Qwen3.5's 34× scale range, accuracy gains +0.30 but F-ICL-A only +0.04, still below the anchor.
- **Post-training *widens* the gap.** Base→instruct→reasoning at matched size: Ministral-3-14B F-ICL-A **0.47 → 0.39 → 0.36**; Qwen3-30B-A3B **0.45 → 0.31 → 0.33**; base-vs-instruct 95% CIs do not overlap in either family. The base→instruct step is the large, consistent one.
- **Two years of frontier releases show no fidelity gain.** On the OpenAI dated ladder (9 releases, GPT-4o May 2024 → GPT-5.6 July 2026), the *oldest* model is the most faithful: May-2024 GPT-4o reaches F-ICL-A **0.43** (95% CI [0.42, 0.45]) with the highest panel accuracy 0.92; all later releases sit in a 0.27–0.37 band. Current flagship `gpt-5.6-sol` pairs 0.86 accuracy with F-ICL-A 0.33.
- **Behaviour is bracketed by low-order prefix statistics.** Krichevsky–Trofimov add-½ estimators land at F-ICL-A 0.41 (memoryless) and 0.45 (bigram), bracketing the panel band; per-position divergences of 0.38 and 0.29 bits bracket the panel's 0.29–0.50 bits. The panel-mean continuation JS exceeds the keystroke reference (0.19 bits) at *all nine* revealed positions (0.29–0.50 bits).
- **Non-monotone updating.** In a realisable, noiseless setting a Bayes-rational solver's solved set can only grow; the panel's does not: **6,545 solved→unsolved transitions against 13,702 gains** (≈1 forgetting event per 2 learnings; median 66/run on 120 tasks), tracking post-training in both triads (Ministral 9→39→54; Qwen3-30B 35→60→69 events).
- **One-example over-commitment.** 69 of 81 runs have *larger* divergence after one example than after none (sign test p<10⁻⁹) — models over-commit to a single datum before slowly recovering, exactly the pattern-completion-foil failure.
- **Sample-complexity inefficiency.** Panel median sample-complexity efficiency = **0.40** — the typical model consumes ~2.5× the information-theoretically minimal number of examples on the tasks it does solve.
- **Classical nulls outscore every model.** The dataset's global output frequencies reach F-ICL-A **0.60** and the input-agnostic pooled per-shot optimum reaches **0.73** — both above every model in the panel, while performing no inference at all.
- **Termination coordinate dominates.** The continuation divergence decomposes into a termination coordinate (end vs not) carrying **89%** of it (0.387 of 0.435 bits) and reproducing the full ranking at Spearman +0.97; the bit coordinate does not reproduce it (+0.18, p=0.12).
- **Survives two robustness corrections.** Re-weighting cells to undo the length quota: count unchanged at 77/80 below anchor. Discarding the termination coordinate entirely (scoring only the bit coordinate): 69/80 remain below the corresponding anchor.
- **Serving reproducibility red flags.** Same checkpoints served via API vs local agree on only 18–36% of greedy outputs, sometimes flipping the *sign* of the comparison (gemma-4 local 0.47 vs API 0.18). Claude Fable 5's cyber-content filter refuses 16% of plain binary-string queries (peaking at 35/120 at four examples) and the same model re-run on byte-identical prompts reproduces answers only 86% of the time; `claude-opus-5` refuses every induction query. Only OpenAI still exposes token log-probs for newest frontier models; Google, xAI, Anthropic have withdrawn or never offered them.
- **Ensemble diversity exists on answers but not on distributions.** A plurality vote over the API panel scores 0.93 (above every single run's 0.92), but aggregation operates on answers and "no vote converts sub-reference posteriors into a calibrated one."

## Critical Assessment

- **Novelty — high and well-motivated.** Building an ICL benchmark whose ground truth is the *exact closed-form* Bayes-optimal posterior under a bounded universal prior is genuinely new: prior algorithmic-reasoning suites (ARC, CLRS) score against a single intended answer, SuperARC grades along an orthogonal compression axis, and meta-learner lines (e.g. the BrainPhaque work [31]) only ever bound log-loss from a *sampled* stream rather than supply the posterior. The sF complement-symmetrisation that turns the polarity gap into a provably model-attributable bias is an elegant, non-trivial construction.
- **Rigour — exceptionally high *on the instrument*, with honest caveats *on the inference*.** The three-gate certification, the two backends that cross-check each other, the degeneracy/read-out/answer audits that caught (and repaired) real serving artefacts (gemma-4 chat-template fault; epsilon-tie near-point-mass collapse on 4 local rows), the pre-release audit that caught "two builder defects invisible to every accuracy-style metric," and the prompt ablation are all best-practice. Crucially, the authors disclose that **on the curated sample the optimum is itself *not* the best predictor** (mean log-loss 2.65 bits vs the keystroke reference's 1.59; the optimum is worse on 57% of continuation cells), and that the headline orderings are *carried by the termination coordinate* (Spearman +0.97) which the bit coordinate does not reproduce (+0.18, p=0.12). They therefore explicitly relabel their findings as "termination-coordinate findings" — a level of intellectual honesty that strengthens the work.
- **Reproducibility — strong but eroding at the frontier.** Frozen datasets + released code + content-addressed cache + per-row serving metadata make the open-weight/local half fully reproducible. However the API half is *not*: a missing-mass row (mistral-large-3-675b) was retired mid-evaluation (HTTP 410, EOL) and becomes permanently unservable; the same checkpoint via API vs local disagrees on >60% of outputs; the frontier distributional read-out is being withdrawn everywhere except OpenAI. The paper itself is the reproducibility story's strongest exhibit.
- **Significance — a genuine new axis, but its *absolute* claims are conditional.** The "posterior fidelity is a distinct axis from accuracy/scale/post-training" finding is the load-bearing and defensible one. The bracketing argument — that models sit between a loop-free algorithmic mixture (the keystroke anchor) and the loop-bearing optimum, indistinguishable from low-order prefix statistics — is the most defensible form because it is *invariant to the translation constant of the reference machine*, which is of the same order as the description budget. The weaker parts are: (a) the absolute "models worse than random keystrokes" framing is repeatedly caveated by the authors themselves as *not* "worse than no inference," because the anchor is itself a length-prior null constructed from the frozen optima; (b) the convention (machine, L≤13, 1024/128 budget, halting normalisation, Levin weighting, sF mixture) is **never disclosed in the prompt**, so "distance to optimum confounds inferential competence with knowledge of an unshared convention" — the authors name disclosing the machine in-context as the first future control, and *this is the single biggest threat to a strong normative reading* of the results.
- **Missing ablations / red flags worth naming.** (i) No model has been scored on the *extended* build's harder regime (hidden programs of length 7–9), only on L ≤ 6 induction — so the "scale does not help" claim is over the *curated* easier half. (ii) The reference-machine axis is controlled only externally (sF description lengths agree with published Coding Theorem Method values at Pearson 0.91–0.92), *not* by re-scoring the panel under a different machine family; the "conjunction, a conditional posterior served from another family, remains untested and unclaimed." (iii) The OpenAI frontier ladder has n=9 and confounds release date with serving route (Chat Completions vs Responses) which the authors' own local-vs-API result shows is not generally neutral. (iv) No predictor *without access to the target* exceeds the keystroke reference — the strongest evidence of discriminativeness is the foil separation on realisable families, but a meta-trained-to-Solomonoff network that lands above the anchor would convert the comparative claim into an absolute one and is left as future work.

## Strengths

- An *exact, certified, parameter-free* Bayes-optimal target — the rare benchmark whose ground truth is provably correct rather than human-annotated.
- Discriminative even against strong heuristic foils (marginal/pattern-completion foil spikes to 17.2-bit regret at one example; nearest-input stays ~13 bits above optimum), so a small gap really is informative.
- Cross-vendor, cross-scale, cross-post-training-stage panel (105 runs, 46 models) all measured against one fixed target — the right experimental design for a fidelity axis.
- Unusual methodological self-criticism: §2.5 quantifies exactly how the headline *changes* under length-quota re-weighting and termination-coordinate removal, and re-labels orderings as termination-coordinate findings.
- A wealth of secondary findings with their own value: serving route is non-neutral (flips comparison sign), safety classifiers tax benchmark scores (Claude Fable 5 +16% refusal on binary strings), quantisation is benign on fidelity down to ~2-bit even where accuracy collapses (gpt-oss-20b 0.32→0.07 accuracy vs 0.51→0.45 F-ICL-A), and the frontier distributional read-out is disappearing.
- Polarity-twin design turns a normally unmeasurable model bias into a controlled measurement, and exposes that median models produce the bitwise-complemented answer on the twin only 52% of the time.

## Limitations

- **Optimum is conditional on an undisclosed convention.** The reference machine, L≤13 budget, 1024/128 bounds, halting normalisation, Levin weighting, and sF mixture are fixed once but never shown to the model, so distance-to-optimum confounds inference with knowledge of an unshared prior — the authors flag this as the biggest uncontrolled threat.
- **Bounded reach.** F at this budget reaches counting, arithmetic, and bounded recursion, not full universal computation; F-ICL is a clean probe at small description length, not a proxy for open-ended reasoning, and the harder L=7–9 induction regime has no model scored on it yet.
- **Optimum is not the best predictor of the curated sample.** On the 1,950 continuation positions the optimum's mean log-loss is 2.65 bits vs the keystroke reference's 1.59; the optimum is worse on 57% of cells. So "below the keystroke reference" must be read as "further from the algorithmic posterior" *not* "worse at predicting the data."
- **Headline orderings are termination-coordinate findings.** Termination carries 89% of the divergence and the bit coordinate does not reproduce the rankings; the termination coordinate is also where the length-quota curation bites hardest (sampled outputs have length ≥3, yet the optimum places mean end-mass 0.37/0.82 at positions 1/2).
- **Tokenisation confound for continuation.** Mass routed through merged multi-digit tokens is not credited; bounded to be small for four tokeniser families (largest CI [+0.004, +0.008] bits vs panel range 0.29–0.51) but not eliminated.
- **API half is not reproducible.** Models retire (mistral-large-3-675b), log-probabilities are being withdrawn at every frontier lab except OpenAI, and same-checkpoint API-vs-local agreement is 18–36% on greedy outputs — future distributional panels may only be measurable for locally-served open weights.
- **Reference-machine transfer not directly tested.** Only the description-length axis is cross-validated against published CTM values; the panel is not re-scored under an alternative machine family, which the conjunction-objection would require.
- **Small-n trend statistics.** The frontier ladder is n=9 and confounds release date with serving route; the scale result at n=32 can only detect |ρ|≥0.35, so it excludes a large but not a moderate association.

## Relevance

直接命中"LLM Inference Evaluation / 输出一致性 / 可复现性"与"ML Reliability & Mathematical Foundations"两个核心兴趣：它给出了一个有精确贝叶斯最优解的分布级评测轴（posterior fidelity），并系统性记录了模型间分布差异、API 不可复现、安全层干预打分等可靠性问题，可作为衡量 LLM 算法推理真实性与服务稳健性的新工具。

## Questions for Further Exploration

- Does *disclosing* the reference machine, budget and weighting in-context close any of the gap? The authors name this as their first intended control — if even partial, it would distinguish "inferential incompetence" from "knowledge of an unshared convention."
- Would a network meta-trained toward the Solomonoff universal predictor (as in the BrainPhaque line [31]) exceed the keystroke reference on F-ICL, converting the comparative claim into an absolute one?
- How do F-ICL-A scores correlate with established general/reasoning benchmarks (MMLU-Pro, GPQA, AIME, ARC-AGI)? The paper explicitly defers this — needed to know whether posterior fidelity is an *orthogonal* axis or a re-expression of capability.
- Re-scoring the panel under an alternative reference machine family (not just sF) — does the "bracketed by low-order prefix statistics" structural finding survive, given the conjunction-objection is untested?
- Can the per-token/per-example divergence curves and the certified witness programs be used as a *training* signal (neural program induction toward the exact posterior), not just an evaluation one?
- Scoring the extended-build harder regime (hidden programs L=7–9) — does scale finally help when description length exceeds what current short-program priors cover?
- A first-character-folding readout that recovers merged-token mass is validated for 4 tokeniser families; does extending it to many-digit-merging vocabularies change any leaderboard ordering?
- The termination coordinate carries 89% of the divergence and is where curation bites hardest — would a length-aware or non-curated evaluation of *only* the bit coordinate sharpen or eliminate the post-training/scale orderings?
