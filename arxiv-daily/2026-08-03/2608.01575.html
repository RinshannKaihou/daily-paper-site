Why this matters

Introduces posterior fidelity — a distribution-level axis with an exact Bayes-optimal ground truth — exposing ICL as low-order prefix statistics, not algorithmic reasoning.

New tool for measuring LLM inferential truth & serving robustness.

Critical edge

Distance-to-optimum confounds inferential competence with knowledge of an unshared convention — the reference machine is never disclosed in-context.

— named by the authors as the single biggest threat to a strong normative reading.

01 / METHOD

An exact posterior, computed once, audited three ways

A 5-instruction Brainfuck-family tape machine F (complement-symmetrised into sF) enumerates all ~1.5×10⁹ programs of length ≤ 13. Under a bounded Levin–Solomonoff prior, the Bayes-optimal posterior predictive becomes closed-form — turning "how close to ideal induction?" into a number you compute, not estimate.

  • Three task families. Induction (held-out query), Continuation (next-token over {0,1,end}), Abduction (foil-separation only).
  • Anchored scoring. F-ICL-A maps Jensen–Shannon divergence so worst=0, keystroke=½, Bayes=1.
  • Three exact certification gates. Count cross-check, witness re-execution, rule-set identity — plus bit-identical serving check.
  • sF polarity twins. Each task ships bitwise-complemented; the optimum scores identically, so any polarity gap is purely model-attributable.

The axis that point-accuracy hides: 45 of 46 models sit below the keystroke reference, yet several exceed 85% accuracy. Accuracy rises with scale (ρ = +0.39); fidelity does not (ρ = +0.10).

  • Frontier ladder is flat or backwards. On OpenAI's 9-release dated ladder, the oldest GPT-4o (May 2024) is the most faithful at 0.43; later releases sit in 0.27–0.37.
  • Bracketed by low-order statistics. KT add-½ estimators (0.41 memoryless, 0.45 bigram) bracket the entire panel — behaviour consistent with a loop-free algorithmic mixture, not the loop-bearing optimum.
  • One-example over-commitment. 69 of 81 runs have larger divergence after one example than after none (p < 10⁻⁹) — pattern-completion failure.
  • Non-monotone updating. 6,545 solved→unsolved transitions vs 13,702 gains (≈1 forgetting per 2 learnings) — a Bayes-rational solver's set can only grow.
  • Classical nulls beat every model. Dataset output frequencies reach F-ICL-A 0.60; pooled per-shot optimum 0.73 — both above every model, while doing no inference.
  • Ensemble doesn't fix it. Plurality vote scores 0.93 on answers, but "no vote converts sub-reference posteriors into a calibrated one."
03 / ASSESSMENT

Strengths & limitations, side by side

Strengths

  • An exact, certified, parameter-free Bayes-optimal target — ground truth that is provably correct, not human-annotated.
  • Discriminative against strong foils (pattern-completion spikes to 17.2-bit regret), so a small gap is genuinely informative.
  • Cross-vendor, cross-scale panel of 105 runs / 46 models on one frozen target — the right design for a fidelity axis.
  • Exceptional methodological self-criticism: §2.5 re-labels orderings as termination-coordinate findings and quantifies every caveat.
  • Polarity-twin design turns an unmeasurable bias into a controlled measurement (median model gives the complemented answer only 52% of the time).

Limitations

  • Convention is undisclosed. The machine, budget, and weighting are fixed once but never shown to the model — distance confounds inference with prior knowledge.
  • Bounded reach. F at this budget covers counting/arithmetic, not universal computation; L=7–9 induction has no model scored yet.
  • Optimum isn't the best predictor of the sample. Mean log-loss 2.65 bits vs the keystroke reference's 1.59; worse on 57% of cells.
  • Headline is a termination-coordinate finding. 89% of divergence; the bit coordinate does not reproduce rankings (+0.18, p=.12).
  • API half not reproducible. Models retire (mistral-large-3-675b → HTTP 410); log-probs withdrawn everywhere except OpenAI.
04 / OPEN

Questions worth chasing

Disclose the machine in-context. Does naming F / sF close any gap? Partial closure would separate inferential incompetence from convention knowledge.
A Solomonoff-meta-trained network. Would it exceed the keystroke reference — converting the comparative claim into an absolute one?
Correlation with capability benchmarks (MMLU-Pro, GPQA, AIME, ARC-AGI)? Needed to know if fidelity is orthogonal or a re-expression.
Re-score under an alternative machine family. Does "bracketed by low-order prefix statistics" survive the conjunction objection?
The harder regime (L=7–9). Does scale finally help when description length exceeds short-program priors?
Use divergence as a training signal — neural program induction toward the exact posterior, not just evaluation?
