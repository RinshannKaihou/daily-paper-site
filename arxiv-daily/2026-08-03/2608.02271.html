How Z-PEFT works

STEP 01 — EXTRACT

Head-wise spectrum, never materialize ΔW

Per layer & projection p∈{q,v,q+v}, block the LoRA update ΔW=B·A by attention head. Reduced-QR trick proves svdvals(ΔW)=svdvals(R_b·R_aᵀ) — cost scales with rank, not hidden dim.

STEP 02 — DESCRIBE

16-dim fixed spectral descriptor

Summarize each head's singular values into top-8 σ + energy, ℓ1/ℓ2 norms, stable rank, spectral entropy, effective rank, concentration, excess kurtosis. Fixed layer→proj→head order ⇒ dimensions share meaning across adapters.

STEP 03 — CLASSIFY

Transparent ℓ2 logistic regression

Standardized features → L2-regularized logistic regression; CV-tuned for mean AUROC. No triggers, no fine-tuning data, no model execution. SHAP links decisions to specific spectral properties per attack.

Strengths & limitations

◆ Strengths

  • Decisive zero-shot win across attacks, ranks, adapter methods & architectures — not just closed-world.
  • ~21,000× memory cut is the real enabler: makes heterogeneous multi-dataset training feasible at all.
  • Honest failure reporting — AdaLoRA collapse, Alpaca weakness, rank-2048 dip stated up-front.
  • Interpretable linear model + SHAP ties energy concentration, kurtosis & stable rank to specific attacks.
  • QR-based extraction runs on 7B/13B adapters on a 56-core / 120 GiB node without ever forming ΔW.

▲ Limitations

  • Restricted to query & value projections — MLP / key / output untested (PADBench doesn't ship them).
  • Accuracy uses the known positive count to set the threshold ⇒ measures separability, not deployment FPR. No calibration.
  • No adaptive adversary: an attacker could tune a backdoored adapter to mimic benign spectra against a transparent linear boundary.
  • Uneven transfer: AdaLoRA .2628, Alpaca .635 — signature is partly method-specific.
  • Logistic regression chosen for interpretability; no test of whether a small MLP closes the gaps without losing scalability.
