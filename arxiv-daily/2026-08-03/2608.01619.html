What "verified" really means

Verified = provenance + chronology, not semantic supersession. A provenance-valid path can still encode a wrong state relation — a narrower guarantee than the name implies.

Three-state lifecycle verdict

VALID / STALE / UNKNOWN replaces the entail/contradict scheme. A STALE verdict carries the attribute's current value; UNKNOWN can trigger a user-confirmation request — distinctions entailment cannot represent.

Why deterministic directives

Model-authored directives over-asked for confirmation. Typed directives are emitted by rules; if no directive fires, the draft passes through unchanged; parse failure ⇒ return unmodified draft.

Distillation, documented as a failure

A Qwen3-4B auditor trained with QLoRA on 599 synthetic examples does not yet match the frontier auditor — included as a documented negative result (no contamination found).

03 / ASSESSMENT

Strengths & limitations, side by side

+ Strengths

  • Named failure mode, quantified. Diagnoses "draft-anchored verification blindness" with recall evidence across auditor scales — recall collapses 0.44–1.0 → 0.06–0.38 on IPA probes, worsening under CoT (0.38→0.13).
  • Simple structural fix. The reverse state→draft direction is well-motivated; the deterministic provenance/chronology gate is auditable rather than opaque.
  • Exceptional boundary honesty. Scenario-joint .879 flagged as scope-confounded; HorizonBench attribution admitted; hard authored set reported as null; 4B distillation reported as failure.
  • Over-correction measured. Repair-only default rewrites only 3% of conflict-free examples (vs 80%); false material-STALE cut to .00–.05.
  • Triangulated ranking. Three judge families (gpt-5.5 / Gemini / Qwen3-4B) plus a blind two-annotator human protocol with McNemar tests.

− Limitations

  • Single-benchmark headline. The strict +5.0 paired gain is essentially on Stale only; harder authored lifecycle set shows no accuracy gain (.533/.542 deterministic, both n.s.).
  • Same-family judge risk. Headline proposer/adapter/judge all gpt-5.5; each arm is one sampled run (Anthropic T=1.0, no seed).
  • T2 implicit-conflict SR regression pocket of 12:21, deepening to 8:32 under full VTA — acknowledged, not resolved.
  • Distillation does not transfer. 4B MiniCheck-style auditor fails to match the frontier — the cost-reduction story is unproven.
  • Low absolute human agreement (κ=0.126); validation supports only the ranking, not the absolute .879 estimate.
  • "Verified" is narrow. Provenance + chronology, not semantic correctness; sensitive transitions, when verbalized, may entrench wrong inferences.
04 / OPEN QUESTIONS

Where the claim needs more pressure

  1. Survives held-out multi-seed?Would the +5.0 paired gain survive a fully powered, multi-seed, multi-judge-family evaluation on a Stale split VTA never touched during development?
  2. Semantic gate without over-asking?Can a lightweight semantic supersession check (sketched to cut hard-set trap over-repairs 18→6) be added without reintroducing the over-asking that model-authored directives caused?
  3. Why does 4B distillation stall?Why does the MiniCheck-style recipe fail to transfer to lifecycle verdicts, and what training signal beyond construction-derived labels would close the gap?
  4. T2 regression root cause.Is the 12:21 T2 SR pocket a verifier artifact, an adapter artifact, or a genuine conflict-type interaction — and can a typed-repair variant fix it without inflating verify-question noise?
  5. Composition with write-time governance.How does StateAuditor compose with CUPMem / Mem0 / Memora — orthogonal to write-side adjudication, or do they double-correct pathologically?
  6. Beyond personal state.Does the diagnosis extend to other implicit dependencies (tool-version, policy, world-knowledge supersession) where draft-anchored blindness should in principle also apply?
