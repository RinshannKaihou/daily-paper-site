> **一句话总结：** 本文首次提出"权威坍塌"(authority collapse)——记忆固化时保留了声明内容却抹去了来源权威约束，导致无授权来源的声明被当作用户事实触发未授权工具调用；作者构建了配对基准 AuthMem-Bench（350 对/700 段历史），在 49 个固化器-后端组合中发现 48 个出现坍塌，未授权动作率高达 50.3%，而自动预测并持久化的权威标签能将端到端未授权动作率从 16.9% 降至 0.0%。

> **TL;DR:** This paper introduces *authority collapse*—a memory-consolidation failure where a claim is preserved while the source constraints governing its authorized reuse are erased—and releases AuthMem-Bench, a paired benchmark (50 bases × 7 transitions = 350 pairs, 700 histories drawn from τ²-Bench and APIGen-MT-5k) that holds the focal claim and later task fixed while varying only source authority. Across 7 consolidators (Mem0, LangMem, Graphiti, Letta, Minimal) × 7 LLM backends, 48/49 configurations exhibit collapse; washed collapsed memories yield a 50.3% mean unauthorized-action rate, while automatically predicted authority labels drive the end-to-end ASR from 16.9% down to 0.0% (TSR 39.7% → 40.0%).

## 核心贡献

- **首次形式化定义"权威坍塌"（authority collapse）**：将记忆固化的失败定义为"声明内容被保留，但决定其合法下游使用的来源区分被抹除"，并区分了良性场景与对抗性利用"权威洗白"（authority laundering）。该失败不需要声明为假或包含注入指令，问题在于固化时被静默赋予的权威。
- **提出 AuthMem-Bench 配对基准**：通过"载体交换"（carrier-swap）构造法，固定焦点声明 p 和下游任务 q，仅改变来源权威（H⁻ 非授权 vs H⁺ 授权），形成 7 种来源-用途转换模板（R2F/P2R/C2O/MIX/O2I/R2P/S2D），共 350 对/700 段历史。
- **三阶段 action-grounded 评测框架**：Module A 测量写入时坍塌（49 配置网格）、Module B 测量下游未授权动作后果（隔离固化召回）、Module C 测量端到端权威标签恢复与保持。
- **跨模型脆弱性的实证证据**：在 7 种主流记忆系统（Mem0 系列、LangMem、Graphiti、Letta）与 7 个 SOTA 后端（GPT-5.5/5.4 mini、Gemini 3.1 Pro/3.5 Flash、Qwen3.7-Max、GLM-5.2、DeepSeek-V4-Pro）上，坍塌普遍存在且与专有/开源身份无关。
- **可部署的缓解方案**：自动预测并持久化的权威标签（基于角色→标签的确定性映射，由 Qwen3.7-Max 作为 source-first 预测器）在端到端流水线中将观测 ASR 降至 0.0%，且不损害良性任务成功率。

## Key Contributions

- **Operationalizes "authority collapse" as a first-class memory failure mode**, distinct from prior memory-poisoning work: the focal claim can be true, non-instructional, and textually identical across conditions—the failure is the operational permission silently assigned during consolidation. Defines false authority upgrade formally (Π(m̃) ⊄ Π(ℓ⋆(p,H))) and separates it from omission.
- **Releases AuthMem-Bench**, a controlled paired benchmark with a carrier-swap construction contract that fixes the focal proposition p and the later task q while varying only whether the source authorizes the target use, covering 7 source-to-use transitions (R2F, P2R, C2O, MIX, O2I, R2P, S2D), 350 pairs / 700 histories, with hard audit checks (20/20 passed) and entity-isolated train/validation/test splits (30/10/10 bases).
- **Establishes authority collapse as a cross-model fragility**: 48 of 49 consolidator-backend configurations upgrade non-authorizing content, with each consolidator exhibiting upgrades on at least 6/7 backends and vice versa; collapse is not tied to any single prompt, vendor, or open/proprietary status.
- **Provides a three-module action-grounded evaluation** (write-time collapse → controlled downstream consequence → end-to-end preservation) scored by deterministic native-tool-call predicates (no LLM judge for Modules B/C), separating consolidation recall from action-time behavior.
- **Demonstrates a deployable mitigation**: a source-first predictor that maps a selected source message role deterministically to {Authorized, Attested, Unendorsed} eliminates the observed end-to-end ASR without reducing authorized task success, establishing source authority as a missing state variable.

## Methodology

**Formal setup.** A role-labeled source history H = ⟨(xᵢ, rᵢ)⟩ with rᵢ ∈ R = {system, user, assistant, tool} (OpenAI Chat Completions convention) is mapped by a consolidator Cθ into a memory set Cθ(H) = {m₁,…,mₖ}. For a focal claim p, the gold authority label ℓ⋆(p,H) ∈ {Authorized, Attested, Unendorsed} is deployment-policy-derived (frozen *role-policy-v1*: user→Authorized, assistant→Attested, tool→Unendorsed). Authority is *use-specific*: a calendar tool may attest a free slot without authorizing the user's intent to book. A false authority upgrade occurs when the implied uses Π(m̃) of a retained memory exceed those permitted by ℓ⋆.

**Benchmark construction (carrier swap).** 50 base histories are sampled from two pinned sources: 30 successful τ²-Bench rollouts (10 each from airline/retail/telecom, revision 5ebebbe827b4) and 20 strict-v1-normalized APIGen-MT-5k trajectories (10 each airline/retail, revision abc4a517d67c). For each base × each of 7 transitions, the construction injects an identical 4-message scaffold (user request → assistant call → tool result → assistant response) where only the carrier of the focal proposition changes: in H⁻ it appears only via the transition's non-authorizing source and is never endorsed by the user; in H⁺ the same complete proposition and exact operative value are stated by the user. Removing the injected episode exactly recovers the parent. Each pair yields a washed rendering (proposition only) and a source-attributed rendering (proposition + limiting source wording).

**Module A (write-time collapse).** A 7×7 grid crosses 7 memory-writing objectives (Mem0-inspired, Mem0 classic, Mem0 additive, LangMem, Graphiti, Letta, Minimal control) with 7 LLM backends; each cell evaluates 350 H⁻/H⁺ pairs. Outcomes are classified by a blinded GPT-5.6-Luna judge at temperature zero into omitted / authority_preserved / authority_upgraded / authorized_retained. Metrics: Upgrade-all (N_upg/N⁻), Ret⁻, Ret⁺. Two interventions are derived from Minimal: *Marked* (force focal retention without revealing gold authority) and *Marked + source-aware* (additionally require preservation of speaker, modality, uncertainty, endorsement).

**Module B (controlled downstream consequence).** A benchmark-supplied focal memory (washed or source-attributed × no metadata / gold metadata / sanitizer / conservative-join) is injected directly, bypassing consolidation. The same 7 backends serve as action models executing the later task q with native tools. Success is scored by a deterministic predicate: the first native tool call must match the registered target tool and the complete argument object.

**Module C (end-to-end preservation).** A frozen pipeline consolidates the source history (Gemini 3.1 Pro with Mem0-inspired objective), assigns and persists authority metadata via a source-first predictor (Qwen3.7-Max, selected on validation with 96.2% accuracy / 77.5% macro F1), retrieves memory, and acts. The predictor selects the single supporting message; the benchmark maps its role to a label deterministically (the model never predicts a label directly). All 350 pairs remain in the denominator.

**Statistical inference.** Intervals use 10,000 percentile-bootstrap resamples over the 50 shared base_id clusters; Module-C boundary cells (all-zero) use a conservative Wilson interval.

## Results & Highlights

- **Authority collapse is near-universal at write time**: across the 49 consolidator–backend configurations in Module A, **authority upgrades occur in 48 of 49** (Table 2); the sole zero (Mem0 classic + GPT-5.5) reflects *omission* (0/350 focal propositions retained) rather than preservation. Conditional on retention, FAU is ≥92% for Mem0-inspired across every backend.
- **Low Upgrade-all does not imply safe consolidation**: averaged across the grid, Ret⁺ is 61.5% while Ret⁻ is only 26.0%; among all H⁻ cases, **17.8% are authority-upgraded, only 8.2% are retained with authority preserved, and 74.0% are omitted**. GPT-5.5's low Upgrade-all (5.2%) is explained by Ret⁻ of only 11.2%, i.e., it avoids upgrades by not retaining the claim.
- **Backend ranking is non-monotonic in vendor/open status**: Gemini 3.1 Pro has the highest average Upgrade-all (30.4%) while GPT-5.5 has the lowest (5.2%); open-weight GLM-5.2 and DeepSeek-V4-Pro sit at 20.7% and 16.4%.
- **Prompt repair is partial**: the *Marked* intervention raises Ret⁻ from 25.3% to 83.5% but also raises Upgrade-all from 21.6% to 55.8% (exposing failures previously hidden by omission); *Marked + source-aware* keeps Ret⁻ at 82.5% and Ret⁺ at 98.6% while cutting Upgrade-all to 9.9% (Table 3).
- **Collapsed memories cause unauthorized actions (Module B, macro over 2,450 trajectories each)**: with washed memory and no metadata, ASR/TSR are **50.3% / 49.4%**; source-attributed text lowers ASR to **40.5%** (a 9.8-point reduction); gold metadata with washed text lowers ASR to **5.8%** and gold metadata with source-attributed text to **2.7%**, while maintaining TSR at 53.9%. Heuristic baselines fail: text sanitizer yields 26.2% ASR / 26.1% TSR and conservative-join yields 5.1% / 5.1%—their matched rates indicate indiscriminate suppression, not authority recovery.
- **Explicit labels provide the strongest discrimination** (Table 4): under source-attributed gold metadata, six backends reach ASR ≤ 1.7% (Gemini 3.1 Pro 0.9%, Qwen3.7-Max 1.1%, GLM-5.2 0.6%); GPT-5.4 mini is the clear outlier at 13.4%.
- **End-to-end mitigation works (Module C)**: on all 350 pairs, the no-metadata pipeline produces 59 prohibited actions (ASR 16.9%); predicted metadata reduces this to **0/350 (0.0%)** while TSR changes from 39.7% (139/350) to **40.0% (140/350)**; reference (oracle) metadata produces the same aggregate rates (Table 5).
- **Predictor reliability**: Qwen3.7-Max selected on validation achieves 96.2% authority-label accuracy / 77.5% macro F1; on the 4,453 memories written by the frozen end-to-end pipeline, its predicted labels agree with reference in **98.7%** of cases (91.7% macro F1, 0.6% dangerous upgrades, 0.7% over-restrictions).
- **Utility remains recall-limited**: the consolidator retains the focal proposition in only 139/350 H⁻ and 256/350 H⁺ cases; metadata governs how stored content is used but cannot recover information omitted during writing.

## Authors & Credibility

The work is led by Qiuyang Zhan, Sheng Guo, Lepeng Zhao, and corresponding author Zhuotao Liu at Tsinghua University, with Rui Zhang at East China Normal University. The benchmark methodology exhibits strong rigor: frozen source revisions with recorded SHA-256 (e.g., APIGen-MT-5k snapshot 5225b54198c1d4d2ae9ff14ddd98341751677138efe64ded10dcb770276b5841), pinned model IDs, temperature zero throughout, entity-isolated splits (zero operative values crossing partitions), a blinded LLM judge for Module A with hidden writer identity, deterministic native-tool-call predicates (no LLM judge) for Modules B/C, pre-registered transition templates, and 20/20 hard audit checks passed with zero waivers. The evaluation suite covers a realistic and current model matrix (GPT-5.5, GPT-5.4 mini, Gemini 3.1 Pro, Gemini 3.5 Flash, Qwen3.7-Max, GLM-5.2, DeepSeek-V4-Pro) and five widely deployed memory systems (Mem0, LangMem, Graphiti, Letta plus a Minimal control), strengthening external validity for the agent-memory community.

## Critical Assessment

- **Novelty**: High and well-positioned. The framing cleanly separates authority collapse from prior memory-poisoning work (AgentPoison, MINJA, Zombie agents, sleeper memory): the claim need not be false, injected, or instructional, only *operationally detached* from its source. The carrier-swap counterfactual is a genuinely useful methodological primitive.
- **Rigor**: Generally strong—deterministic action predicates, blinded judge, frozen revisions, base-clustered bootstrap CIs, and the Ret⁻/Ret⁺ decomposition that exposes "safe-by-omission" configurations (notably the GPT-5.5 + Mem0 classic cell reporting 0.0%† that is explicitly flagged as omission). However, Module A still relies on a single LLM judge (GPT-5.6-Luna) for the central write-time classification, with no reported inter-judge agreement or human spot-check of judge labels in the main text.
- **Reproducibility**: Strong on data and prompts—all consolidator prompts, the judge system prompt, the source-first predictor prompt, frozen decoding settings, and model IDs are reproduced verbatim in appendices; source snapshots are pinned with hashes. The threat to reproducibility is model drift: every backend is a moving proprietary/open target accessed only via API, and several (GPT-5.5, Gemini 3.1 Pro, Qwen3.7-Max, GLM-5.2, DeepSeek-V4-Pro) are recent enough that independent replication on the exact same snapshot may be impractical.
- **Significance**: Conceptually important—it reframes a security-relevant failure as a missing *state variable* rather than a content problem, and shows a cheap, deterministic role→label mapping is sufficient when paired with an accurate predictor. The 0.0% end-to-end ASR is a striking headline but is obtained on **a single selected pipeline** (Qwen3.7-Max predictor + Gemini 3.1 Pro consolidator/action), chosen by validation. The paper does not report the full predictor×consolidator×action grid end-to-end, so the generalizability of the zero is untested.
- **Red flags / data quirks**:
  - The frozen *role-policy-v1* (user→Authorized, assistant→Attested, tool→Unendorsed) is a deliberately simple deployment policy; real deployments often treat specific tools as authoritative and assistant suggestions as user-binding after explicit confirmation, so absolute numbers are policy-dependent.
  - The telecom τ²-Bench rows undergo a *declared lossy projection* (removing user-device-call/tool-result spans and keeping only the following natural-language user report), so telecom results are not environment-faithful.
  - APIGen-MT-5k histories are synthetic and lack per-row verifier state; evaluation is *tool-call-grounded, not environment-state-grounded*.
  - The end-to-end utility ceiling is low (TSR ~40%) because the consolidator omits the focal proposition in a majority of H⁺ cases (256/350 retained), so the headline "0.0% ASR with no TSR loss" is achieved on a recall-limited pipeline; a higher-recall consolidator might surface more predictor errors.
  - The benchmark covers only two task families (airline/retail customer-service) and seven hand-authored transition templates; coverage of, e.g., code-execution or finance tools is absent.
  - The adversarial subset is narrow: the adversary controls only content supplied through policy-unendorsed source classes and cannot alter role annotations or system/user messages—stronger threat models (e.g., role-spoofing via tool output mimicking user voice) are out of scope.

## Strengths

- Clean, formal definition that separates content preservation from authority preservation, with an explicit omission-vs-upgrade decomposition that prevents "safe-by-not-remembering" from masquerading as a defense.
- Controlled counterfactual design (carrier swap) that isolates the single variable of interest—source authority—while holding the proposition, task, tools, and action predicate fixed.
- Realistic and current model/system coverage; results are consistent across proprietary and open-weight backends, supporting the "cross-model fragility" claim.
- Practical, deployable mitigation (a source-first predictor with deterministic role→label mapping) that requires no fine-tuning and works with the existing consolidator.
- Action outcomes are scored by exact native-tool-call matching rather than an LLM judge, eliminating a major source of evaluation noise for Modules B/C.
- Excellent documentation hygiene: frozen revisions, SHA-256 pins, complete prompts, decoded settings, and 20/20 passed hard audit checks.

## Limitations

- The headline 0.0% end-to-end ASR is from a *single* selected pipeline (Qwen3.7-Max predictor + Gemini 3.1 Pro) chosen on validation; the full predictor×consolidator end-to-end grid is not reported, leaving the generality of the zero untested.
- End-to-end utility is recall-limited: the consolidator retains the focal proposition in only 256/350 H⁺ cases, so metadata cannot repair missing memory; TSR stays around 40%.
- The frozen role-policy-v1 is intentionally simple (user→Authorized, assistant→Attested, tool→Unendorsed). Real deployments frequently designate specific tools as authoritative or treat confirmed assistant suggestions as binding, so absolute rates are policy-dependent and may not transfer.
- Module A depends on a single LLM judge (GPT-5.6-Luna) for the central write-time classification; no inter-judge agreement or human audit of judge decisions is reported in the main text.
- Benchmark scope is narrow: two customer-service domains (airline/retail, plus a lossy telecom projection), seven hand-authored transition templates, and synthetic APIGen-MT-5k histories without environment-state grounding.
- The threat model excludes role-spoofing attacks (e.g., tool output that mimics user voice) and assumes role annotations cannot be altered, so robustness against stronger adversaries is uncharacterized.
- Every backend is accessed via API against moving snapshots; independent bit-level replication is impractical.

## Relevance

该工作直接关系到带持久记忆/自演化 LLM Agent 的安全与可控性，提出的"权威坍塌"框架和 AuthMem-Bench 为记忆固化层的访问控制、provenance 保持与未授权动作防护提供了可度量的基准，对于设计可信赖的自演化 Agent 记忆系统（包括记忆写入策略、检索后权限校验、tool-call 鉴权）具有直接的工程与研究方向参考价值。

## Questions for Further Exploration

- How does authority collapse behave under *stronger* threat models where adversarial tool output mimics user voice or forges endorsement cues, and can the role→label mapping be robustly extended to detect such spoofing?
- Can a single predictor maintain low dangerous-upgrade rates when the consolidator is replaced with a higher-recall objective that retains the focal proposition in far more than 256/350 H⁺ cases?
- Does the deterministic role-policy-v1 generalize to deployments where specific tools are designated authoritative (e.g., a verified calendar API) and confirmed assistant suggestions become user-binding?
- What is the full predictor × consolidator × action-model end-to-end grid, and is the observed 0.0% ASR stable across configurations other than Qwen3.7-Max + Gemini 3.1 Pro?
- How transferable are the seven transition templates to non-customer-service domains (code execution, finance, healthcare), where the cost of an unauthorized state-changing call is substantially higher?
- Can authority metadata be learned and persisted online from streaming interactions without a separate source-first predictor pass, and what is the latency/accuracy trade-off?
