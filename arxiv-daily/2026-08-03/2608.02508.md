> **一句话总结：** RoMeRL 将按轨迹索引的、随交互历史线性增长的 agent 记忆效用空间替换为按"结果极性 × 记忆动力学"分解的固定四维（PCC/PAC/NCC/NAC）任务级记忆状态，在不微调底层 LLM 的前提下，于 ALFWorld 与 LifelongAgentBench 上将整体成功率提升 3.2pp 至 0.862，同时将 Cold-Q 比例降低 80.0%、反馈密度提升 6.0×、维护记忆量减少 84.4%、LLM 调用减少 21.1%。

> **TL;DR:** RoMeRL tackles two coupled problems in learning-based LLM-agent memory: trajectory-indexed utilities that dilute feedback as the state space grows, and the Memory-Reward Trap (MRT) where co-retrieved irrelevant memories receive misattributed positive updates. By replacing the ever-growing per-trajectory utility vector with a fixed 2×2 factorized per-task state (outcome polarity × memory dynamics → PCC/PAC/NCC/NAC), on ALFWorld and LifelongAgentBench (OS, DB) RoMeRL raises overall SR from 0.830 (MemRL) to 0.862 (+3.2pp), reduces Cold-Q ratio by 80.0% (28%→9.0% on OS), boosts feedback density 6.0× (4.96→29.93), shrinks the maintained memory pool by 84.4% (45K→7K), and cuts LLM calls by 21.1% (570K→450K), while under a 10%-noise MRT stress test holding final noise ratio to 0.15% versus MemRL's 1.02%.

## 核心贡献

- **诊断并形式化了 Memory-Reward Trap (MRT)**：从因果归因角度揭示，由于轨迹级奖励被联合分配给所有共同检索的记忆，bundle 级的 Q-估计只反映观测效用 µ_i 而非边际贡献 θ_i；当 θ_i ≤ 0 但 µ_i − v_i^0 > 0 时，弱相关、过期或失败的经验会被反复正向强化。MRT 受害记忆的期望数量随状态维度 N_t 线性增长（E[|B_t|] = N_t·ρ_t）。
- **提出 Reduced-Order Memory RL (RoMeRL)**：用每个任务固定 4 维的因子化状态 (O={+,-} × D={C,A}) 替代不断扩张的轨迹索引效用空间，对应四个语义坐标 PCC（最有效的成功轨迹）、PAC（首次由失败到成功的恢复轨迹）、NCC（积累最高下游效用的失败轨迹）、NAC（最近一次失败轨迹）。坐标内容通过保留/晋升/替换更新，但语义身份固定。
- **给出配套的理论分析**：Theorem 1 给出 Q-估计的 gap–variance 分解，证明更多反馈只降低方差而不消除任务基线 v_i^0 + 归因偏差 a_i；Theorem 2 给出全池估计所需反馈预算随 N_t 增长；Theorem 3 证明降阶将平均反馈密度从 O(σ²N_t/kT) 提升至 O(4σ²/kT)，即 N_t/4 倍；Proposition 1 在 clean↔erroneous 转移模型下，给出稳态错误坐标占比上界 γ/(γ+λ) 和数量上界 d·γ/(γ+λ)。
- **跨模型记忆可迁移性**：冻结的因子化记忆状态可在 GPT-5.4-mini 与 Gemini-3.5-flash 间迁移，OS 任务带来 +14.6 / +7.4 的分数增益及更少的执行步数（−1.01 / −1.51）。

## Key Contributions

- **Formal identification of the Memory-Reward Trap**: The paper proves (Theorem 1) that the Q̂_i estimated from bundle-level rewards converges to observational utility µ_i, not marginal utility θ_i, leaving a credit gap (v_i^0 + a_i) that no amount of additional feedback can remove. Under MRT (θ_i ≤ 0 < µ_i − v_i^0), the expected drift of the exponential update is positive, so weakly relevant memories co-retrieved in successful episodes become persistently reinforced; the exposed support grows as E[|B_t|] = N_t·ρ_t.
- **A reduced-order factorized state**: Replaces the N_t-dimensional growing utility vector with a fixed 2×2 per-task state — outcome polarity {+, −} × memory dynamics {Consolidated, Adaptive} — instantiated as four semantic coordinates PCC, PAC, NCC, NAC, each governed by an explicit retention/promotion/replacement rule (Eqs. 16–19). New trajectories update or replace coordinate contents rather than adding persistent utility variables.
- **Theoretical guarantees on feedback concentration and bounded erroneous occupancy**: Theorem 3 shows state reduction concentrates a fixed feedback budget (variance O(σ²N_t/kT) → O(4σ²/kT)); Proposition 1 bounds steady-state erroneous occupancy by d·γ/(γ+λ) under a generic clean↔erroneous transition model, strictly lower than the full-pool exposure whenever d·γ/(γ+λ) < N_t·ρ_full.
- **Strong empirical effectiveness and efficiency**: On ALFWorld and LifelongAgentBench OS/DB, RoMeRL achieves the best overall macro-averaged SR while simultaneously reducing memory size, LLM calls, and MRT-induced noise propagation, all with frozen LLM backbones.
- **Cross-model transfer of the frozen memory state**: Demonstrates that the factorized state carries procedural information reusable across LLM backbones, yielding both higher scores and shorter solution paths.

## Methodology

RoMeRL keeps the LLM backbone frozen and instead learns a non-parametric memory policy. The pipeline is:

1. **Problem reframing.** Standard outcome-driven memory methods assign each stored trajectory m_i a utility Q_{i,t} updated by Q_{i,t+1} = Q_{i,t} + α·𝟙[m_i ∈ S_t]·(r_t − Q_{i,t}). Because the state dimension N_t grows with history while feedback stays bounded, this dilutes updates and exposes growing support to MRT.

2. **Reduced-order factorized state.** For each task g, the variable-length history D_{g,t} is mapped via Φ(·) into a fixed-dimensional state Z_{g,t} ∈ ℝ^{2×2}, indexed by outcome polarity O = {+, −} (success vs failure evidence) and memory dynamics D = {C, A} (consolidated global evidence vs adaptive state-transition evidence):
   - **PCC (Positive Consolidated Coordinate)**: stores the most efficient successful trajectory, m_{g,t}^{+,C} = argmin_{m_i: y_i=1} ℓ_i; a more efficient success replaces the content and inherits the current PCC utility as a warm start.
   - **PAC (Positive Adaptive Coordinate)**: stores the earliest successful trajectory observed after the first failure, capturing the recovery pattern.
   - **NCC (Negative Consolidated Coordinate)**: stores the failed trajectory whose accumulated utility Q_i exceeds both Q_init^{−} and the current consolidated negative representative; eligible only once its utility clears a threshold, ensuring NCC retains diagnostically valuable failures.
   - **NAC (Negative Adaptive Coordinate)**: stores the most recent failed trajectory, replacing content on every new failure to track the current error state.

3. **Retrieval.** Active support A_{g,t} (≤ 4 representatives) is ranked by score(m) = (1 − ω_Q)·cos(e(x_t), e(m)) + ω_Q·Q_m; the top k_ret are retrieved into S_t.

4. **Utility update.** A standard exponential Q-update is applied only to retrieved coordinates: Q_{g,t+1}^{o,d} = Q_{g,t}^{o,d} + α·𝟙[m_{g,t}^{o,d} ∈ S_t]·(r_t − Q_{g,t}^{o,d}). New representatives inherit the previous coordinate utility as a warm start (Eq. 21), so feedback is preserved across replacements rather than reset.

5. **Theoretical underpinning.** Three theorems and one proposition characterize (i) the bias–variance gap of bundle-level estimates, (ii) the O(N_t log N_t / ϵ²) feedback budget required for full-pool estimation, (iii) the N_t/4 feedback-concentration factor under reduction, and (iv) the steady-state erroneous-coordinate occupancy under a clean↔erroneous transition model.

Backbones used: DeepSeek-V4-flash (LAB), GPT-5.4-mini (ALFWorld); Text-Embedding-3-Large; greedy decoding (T=0, top-p=1). Learning rate α=0.3, ω_Q=0.5 across benchmarks; similarity threshold δ set at the top-20% quantile of within-benchmark task-similarity distribution. LAB OS/DB use a 7:3 runtime/transfer split with seed 42, 500 tasks each.

## Results & Highlights

- **Overall success rate.** On ALFWorld + LifelongAgentBench (OS, DB) macro-average over 10 epochs, RoMeRL achieves **0.862 overall SR**, versus **0.830** for the strongest baseline MemRL — a **+3.2 percentage-point** gain — while keeping the LLM backbone frozen (Table 1).
- **Per-task gains.** RoMeRL exceeds MemRL on every reported task: ALFWorld P&P **0.968 vs 0.908** (+6.0pp), Examine **0.957 vs 0.855** (+10.2pp), Cool **0.880 vs 0.871** (+0.9pp), Pick-2 **0.826 vs 0.812** (+1.4pp); LAB-OS Last-Epoch SR **0.824 vs 0.808**, CSR **0.838 vs 0.820**; LAB-DB Last-Epoch SR **0.680 vs 0.632**, CSR **0.952 vs 0.934** (Table 1).
- **Feedback utilization (OS).** Cold-Q ratio (representatives with zero post-admission updates) drops from ~28%→**9.0%** for RoMeRL while MemRL's rises from ~29%→**44.9%** — an **80.0% relative reduction**. Feedback density (average post-admission updates) increases **6.0×** from **4.96 to 29.93** (Fig. 3).
- **Memory and inference efficiency.** Average maintained memory pool shrinks **84.4%** (45K → 7K); average LLM calls drop **21.1%** (570K → 450K) (Table 1, Fig. 7).
- **MRT robustness (controlled stress test, OS, 10% initial noise).** After 10 rounds: RoMeRL reaches round-10 SR **82.0%** (vs MemRL 79.2%, MemRL+UCB 78.4%), limits Positive Noise Updates to **2.4** (vs 3.7 and 7.2), and Final Noise Ratio to **0.15%** (vs 1.02% and 1.20%) (Table 2). Most injected noise is replaced within the first three rounds.
- **Cross-model memory transfer (LAB).** Transferring the frozen factorized state: GPT-5.4-mini on OS gains **+14.6 score** (67.0 → 81.6) and **−1.01 steps** (3.23 → 2.22); Gemini-3.5-flash on OS gains **+7.4** (74.0 → 81.4) and **−1.51 steps**; DB shows smaller but consistent gains (+3.8 / +1.4) (Table 3).
- **Ablations (OS).** Removing NCC lowers both Last-Epoch SR and CSR; NCC accounts for **27.14%** of occupied coordinates on OS and **42.78%** on DB. Removing PAC primarily reduces Last-Epoch SR while barely affecting CSR; PAC occupies only **8.21%** (OS) and **5.05%** (DB) yet still impacts performance (Fig. 4, Fig. 5).
- **Learned-Q informativeness.** Point-biserial Pearson correlation between Q-values and memory-generation outcome rises from r=0.493 (MemRL) to r=0.673 (RoMeRL); memories stuck at the initial Q=0.5 drop from **47.8%** to **5.0%** (a 42.8pp reduction); highest-Q bin enriches success-derived memories **2.40×** versus baseline's 1.23× (Appendix B.6).

## Critical Assessment

- **Novelty.** The MRT formalization (causal gap between observational utility µ_i and marginal utility θ_i, with explicit attribution bias a_i = µ_i − v_i^1) is a genuinely fresh lens on a known problem in non-parametric agent memory RL, and the 2×2 factorized state is a clean, well-motivated design that goes beyond simple top-k truncation. The connection to credit-assignment / confounding (do-calculus notation) is unusual for this literature.
- **Rigor.** Three theorems and one proposition are stated cleanly with proofs in Appendix A. However, the most important practical claim — that the reduced-order state actually reduces MRT exposure — rests on Proposition 1, whose clean→erroneous transition probabilities γ and λ are *never measured empirically*. The paper itself concedes in §7 that estimating them would require "coordinate-level causal labels from paired counterfactual rollouts or equivalent attribution," which is not performed. So the bound d·γ/(γ+λ) is illustrative rather than validated.
- **Reproducibility.** Reasonable: code is public, hyperparameters and prompts are documented, seeds are fixed. Caveats: the strongest baseline (MemRL) is compared at the same 45K memory pool / 570K LLM-call budget, but the paper does not report whether MemRL was tuned at smaller pool sizes that would be a fairer comparator against RoMeRL's 7K pool — i.e., part of RoMeRL's efficiency win may come from a deliberately oversized MemRL baseline.
- **Significance.** Solid but narrow: only two benchmarks are used, and on LifelongAgentBench only the OS and DB subsets (the KG subset is dropped "following prior work"). ALFWorld improvements are heavily concentrated in two task types (P&P +6.0pp, Examine +10.2pp), with three others (Clean, Heat, Cool) essentially flat or tiny (+1.4pp at most), so the macro-average of +3.2pp is somewhat task-dependent.
- **Red flags.**
  - The headline "+3.2pp overall" rests entirely on macro-averaging ALFWorld (6 task types, GPT-5.4-mini) with LAB (2 tasks, DS-V4-flash). Mixing two different backbones into one "Overall" number is unusual and inflates apparent breadth.
  - The MRT stress test (Table 2) injects noise in only the first round and reports round-10 outcomes; the absolute noise ratios are already small (1.02%–1.20%) for the baseline, so the 0.15% vs 1.02% comparison, while directionally favorable, operates in a low-incidence regime where practical impact is modest.
  - Cross-model transfer gains (Table 3) are reported without confidence intervals or significance testing on what are small absolute task counts.
  - No comparison against stronger, more recent learning-based memory baselines (Memory-R1, Agentic Memory, AtomMem, Fine-Mem) — only MemP and MemRL are run; the others are discussed but not empirically compared.

## Strengths

- Clean theoretical framing of a real, previously under-formalized problem (MRT) with a useful gap–variance decomposition that explains why simply adding exploration (UCB) cannot fix the underlying attribution bias — empirically confirmed by the MRT stress test where MemRL+UCB is actually *worse* (7.2 positive noise updates, 1.20% final noise ratio) than plain MemRL.
- The fixed 4-coordinate design is unusually parameter-efficient and yields simultaneous improvements on five axes (SR, Cold-Q, feedback density, memory size, LLM calls) — a rare Pareto improvement.
- Coordinate-level ablations reveal a meaningful division of labor: NCC (consolidated negative evidence) is heavily used (27–43% occupancy) and load-bearing, while PAC (adaptive positive) is sparse but still contributes to current-epoch performance.
- Public code, full proofs, complete hyperparameter table, prompt appendix, and case studies (Appendix D) make the methodology transparent.
- The Q-value stratification analysis (Appendix B.6) shows RoMeRL's high-Q bin retains ~19.9% failure-derived memories — evidence that the critic learns something richer than a binary success/failure replay.

## Limitations

- **Causal credit assignment not resolved.** RoMeRL still relies on bundle-level outcome rewards; it concentrates feedback but does not eliminate attribution bias. The paper acknowledges this in §7.
- **γ and λ never estimated.** Proposition 1's erroneous-occupancy bound is parameterized by transition probabilities that are not measured, leaving the central MRT-mitigation theorem empirically uncalibrated.
- **Narrow benchmarks.** Only ALFWorld and LAB OS/DB; no KG subset, no long-horizon/open-ended evaluation, no web or code-synthesis tasks. The authors flag open-ended longer-horizon settings as future work.
- **Backbone-dependent numbers.** Different backbones for different benchmarks (DS-V4-flash vs GPT-5.4-mini) make cross-benchmark comparison and the single "Overall" figure hard to interpret.
- **Baseline breadth.** Only MemP and MemRL are run among learning-based memory methods; Memory-R1, Agentic Memory, AtomMem, Fine-Mem, and MemEvolve are cited but not empirically compared.
- **No statistical significance reporting.** Results are single-run averages over 10 epochs with no error bars, confidence intervals, or significance tests, so the per-task deltas on the order of 1pp cannot be distinguished from noise.
- **Heuristic coordinate rules.** PCC/PAC/NCC/NAC selection rules (Eqs. 16–19) are hand-designed; the paper does not explore learned policies for coordinate admission/promotion.

## Relevance

对于关注 LLM 智能体记忆系统、自我进化（self-evolving）agent 以及离线/运行时强化学习的研究方向高度相关：RoMeRL 用降阶状态和因果归因视角重新审视了"哪些经验应保留并影响未来行为"这一核心问题，与记忆生命周期管理、经验复用、非参数 RL 记忆等近期工作（MemRL、MemP、Memory-R1、A-MEM）直接对话，可作为 memory utility learning 和 credit assignment 讨论的重要参考。

## Questions for Further Exploration

- Can the γ and λ parameters in Proposition 1 actually be estimated from counterfactual rollouts, and does the resulting steady-state occupancy bound d·γ/(γ+λ) hold empirically on real memory traces?
- How does RoMeRL behave on longer-horizon, open-ended, or web/code-synthesis benchmarks where the four-coordinate bottleneck might lose information relative to a larger factorized state (e.g., 3×3 or per-skill coordinates)?
- Is the 2×2 factorization (polarity × dynamics) the right Cartesian product, or would alternative factorizations (e.g., polarity × recency × modality) yield better coverage at comparable dimensionality?
- Can finer-grained per-step or per-operation rewards (à la Fine-Mem) be combined with the reduced-order state to mitigate the residual attribution bias the paper concedes?
- How sensitive are the gains to the memory-pool size of the baseline — would a smaller, fairer MemRL pool close the 84.4% memory-size gap?
- Why is the ALFWorld improvement concentrated so heavily in P&P (+6.0pp) and Examine (+10.2pp) while Clean/Heat/Cool are nearly flat — is the factorized state capturing task-specific structure that some task types cannot exploit?
- Does the cross-model transfer result (Table 3) survive significance testing, and does it extend to weaker or much stronger backbones where the procedural content of the memory might be mismatched?
