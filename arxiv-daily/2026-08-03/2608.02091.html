Key finding

Heterogeneous bf16 / MXFP4 error sources all converge on one QK spectral channel — a single QK-locus action contains them.

Key metric
11.1 vs 237
σ(WQ), steps 0→15900 final: 11.1 / 237

Projecting each update off the top-3 singular directions of WQ/WK holds σ(WQ) at 11.1; an equal-energy off-target removal lets it run to 237 — proving the QK channel is a causal driver, not a correlate.

Why this matters

Directly stabilizes low-precision (bf16 / MXFP4) LLM pretraining with an actionable “act at the shared QK locus” recipe — and a transferable source-channel causality framework for diagnosing loss spikes and gradient instability beyond attention.

Critical edge

Scale ceiling is 350M parameters — far below modern pretraining — and durability is argued on loss alone: there is no spectral safety line, since survivor σ peaks above the values where doomed runs collapse.

§ 01 / METHOD

Isolate → Identify → Explain → Contain

§2 ISOLATE

Re-implemented FlashAttention-2

Tiled online-softmax carries (output O, softmax stats) made individually editable; a sustained-divergence crash rule decides every collapse verdict. Fault localized to the bf16 streaming accumulator — not operands, kernel, tiling, or scale.

§3 IDENTIFY

Two inversions

Route-correction keeps the fault active while splicing clean fp32 gradient into one named route; source-shift swaps bf16 accumulation for MXFP4 weight-gradient quantization routed to QK, MLP, or V. Two generators reach one channel.

§4 EXPLAIN

Structure manipulation

One error property destroyed at a time at matched magnitude: scramble sign, permute batch, swap Gaussian, strip per-head DC. Plus a direction-removal probe vs. an equal-energy off-target control.

§5 CONTAIN

QK-Guard, dormant

Monitors attention-logit saturation; at first crossing of fixed threshold 30, permanently switches on parameter-free per-head QK normalization. Same trigger, same fire step — only the QK-locus action rescues.

Entry condition: the gating property is temporal sign-coherence (per-head error sign persisting across optimizer steps) — decoupled from per-tile scalar mean and aggregate magnitude that prior analysis left conflated with it. Per-head DC bias is the carrier.

§ 03 / ASSESSMENT

Strengths & limitations

side-by-side
Strengths
  • Causal-inference framing. Matched-magnitude controls, exact-recomputation assay, route-vs-source orthogonal manipulation, and an equal-energy off-target control for the direction probe.
  • Intellectual honesty. Dedicated “Honest Negatives and Boundaries” appendix, disclosed excluded arms, candid threshold-provenance section that declines to claim a calibrated detector.
  • Clean, memorable thesis with an explicit falsifier (a source after the final attention module would escape the channel).
  • Practical engineering win. QK-Guard is dormant until needed, parameter-free, composes with any attention impl and RoPE, transfers without threshold retuning.
  • B200 exact-code reproduction (not a fresh port) corroborates the dissociation on a second GPU architecture.
Limitations
  • 350M scale ceiling. Behavior at billion-to-trillion scale is unverified; native FP4 hardware is explicitly the next test, not done here.
  • Software-emulated quantizer everywhere. The B200 result corroborates rather than validates native four-bit arithmetic.
  • Durability only to 60k steps. Some low-precision failures emerge only after much longer training.
  • Second failure mode unattributed. The QK-source direction-removal probe still collapses at 51100 steps with σ bounded at 24.5 — a separate mechanism.
  • Not a calibrated detector. No false-activation rate for threshold 30; clean controls do reach it. Threshold robustness bounded from one side (values below 30 untested).
  • Reproducibility gated by upstream training repo’s missing license; nproc / rank counts absent on legacy arms.
§ 04 / OPEN

Questions for further exploration

non-linear reading
  1. Does the dissociation — and the fixed threshold of 30 — survive at billion-parameter scale and on native FP4 hardware (e.g., Blackwell native MXFP4), where outlier dynamics differ?
  2. Can a pathwise cross-step temporal-sign-coherence statistic become a predictive online trigger, firing earlier than the downstream attention-logit saturation signal?
  3. What is the mechanism of the separate slower failure mode (probe collapse at 51100 steps, σ = 24.5) — a second QK channel, a different channel, or a non-channel instability?
  4. How does QK-Guard interact with loss scaling, ZClip / AdaGC, warmup, and attention-entropy preventers — additive, redundant, or interfering?
