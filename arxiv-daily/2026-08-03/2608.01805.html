Why this matters

First dependency-graph, multi-channel, ASIL-calibrated attribution framework for embodied LLM cockpits — directly targets the life-critical "Correctness Collapse" failure mode (96% → 56% under dialectical eval).

Critical edge

Step-exact accuracy remains under 50% on every split, and the entire evaluation is single-vendor on Doubao — no GPT/Claude/open-model robustness evidence.

01 / METHOD

A four-stage post-hoc attribution pipeline

input: role-tagged trace + answer → output: agent, step, category, ASIL
STAGE 1

Dependency Graph

Each step becomes a node; directed edges induced by four signals: reference, plan, tool output, control. Embodied fields (e, σ, m) attach as attributes.

O(n) practical · only entity-linker calls LLM
STAGE 2

Hierarchical Slicing

Shortest undirected path = dependency distance. Each focal step gets four layers L1–L4 by distance, not temporal offset.

L1 verbatim → L4 sparse milestones
STAGE 3

Embodied Channel Adapter

Single per-trace LLM scan flags 4 risk classes; nodes promoted one layer up. SAFETY_VIOLATION forced to L1 regardless of distance.

<2% of token budget
STAGE 4

ASIL-Uplifted Consensus

K=4 analysts (1 mandatory Safety + 3 sampled) → two-stage factorized vote. Severity max-prior first, then asymmetric uplift Ω≈2.16 at ASIL-D.

prevents symmetric-cost aggregation

03 / CRITIQUE

Strengths vs. Limitations

distilled from authors' own assessment + reviewer notes

What lands well

  • Formalizes a real, safety-relevant failure mode (Correctness Collapse) — every design choice motivates against it.
  • Dependency-distance slicing is principled and empirically dominant: +25.2 agent pts, the largest ablation jump.
  • ECA is concrete and cheap (<2% token budget); SAFETY_VIOLATION → L1 is a sensible hard rule.
  • CockpitBench fills four genuine gaps (modality, ASIL labels, single-rater bias, rare-failure coverage); annotation pipeline is exemplary.
  • Baseline fairness: ECHO re-run, slight improvements disclosed, p-values reported per comparison.

Where it strains

  • Post-hoc only — no real-time detection or mitigation for preventing catastrophic cockpit outcomes.
  • Step-exact under 50% on all splits; fine-grained temporal localization stays an open problem.
  • Safety-uplift hyperparameters (λ, β, κ) are hand-tuned for cockpits; not adaptive across medical / smart-home.
  • Dependency graph captures only four explicit signals — misses implicit, shared-background dependencies.
  • CockpitBench n=212, only 26 ASIL-D — thin for stratified claims at the most safety-critical slice.
04 / OPEN

Questions worth chasing

Q1

Is the +17.6 pt gain backbone-invariant? Swap the analyst to GPT-5, Claude Opus, or DeepSeek R1 — does ECA, co-designed with Doubao, survive?

Q2

Would adding semantic / co-reference edges (beyond entity linking) close the gap on Planning Failure step-exact, currently stuck at 29.2%?

Q3

Can the uplift parameters (λ=0.5, β=0.4, κ=1.0) be data-driven calibrated — e.g. Bayesian optimization on a held-out ASIL-C/D slice — to generalize beyond cockpits?

Q4

Can the post-hoc ECA be inverted into a real-time guardrail — a streaming salience classifier that flags SAFETY_VIOLATION before the action hits the CAN bus?

Q5

With only 26 ASIL-D traces, what is the confidence interval on the 84.6% precision — and how does it degrade toward the planned 1,000 multilingual traces?

Q6

How does calibration behave on CockpitBench's contested subset, and is there a principled confidence threshold for deferral-to-human?
