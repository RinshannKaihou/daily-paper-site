Key finding

Memory consolidation preserves the claim but erases its source authority—silently licensing unauthorized tool calls in 48 of 49 consolidator–backend configurations.

01 / METHOD

Three modules, one counterfactual

Carrier-swap fixes the proposition and the task; only source authority varies.
Construction · Carrier Swap

Same proposition, same task, only authority changes

50 base histories (30 τ²-Bench + 20 APIGen-MT-5k) × 7 source-to-use transitions (R2F, P2R, C2O, MIX, O2I, R2P, S2D). In H⁻ the focal claim appears only via a non-authorizing source; in H⁺ the same proposition is stated by the user. Removing the injected episode recovers the parent.

Module A · Write-time

Does the consolidator upgrade authority?

7×7 grid: 7 memory writers (Mem0-inspired, Mem0 classic, Mem0 additive, LangMem, Graphiti, Letta, Minimal) × 7 backends (GPT-5.5, GPT-5.4 mini, Gemini 3.1 Pro, Gemini 3.5 Flash, Qwen3.7-Max, GLM-5.2, DeepSeek-V4-Pro). Blinded GPT-5.6-Luna judge at T=0 classifies omitted / preserved / upgraded.

Module B · Downstream

Do collapsed memories cause unauthorized actions?

Bypass consolidation; inject a focal memory (washed / source-attributed × no-metadata / gold / sanitizer / conservative-join). The same 7 backends act. Scored by a deterministic native-tool-call predicate—no LLM judge.

Module C · End-to-end

Can predicted labels recover authority?

Frozen pipeline: Gemini 3.1 Pro consolidator → Qwen3.7-Max source-first predictor selects the supporting message, role→label mapped deterministically. All 350 pairs in the denominator; 10k bootstrap CIs over base clusters.

02 / RESULTS

Collapse is near-universal; explicit labels fix it

Safety-by-omission is exposed as a hidden failure mode.
  1. 48 of 49 configs upgrade non-authorizing content. The single zero (Mem0 classic + GPT-5.5) is omission—0/350 retained—not preservation. Conditional on retention, FAU is ≥92% for Mem0-inspired across every backend.
  2. 17.8 % of H⁻ cases are authority-upgraded; only 8.2% preserved with authority; 74.0% omitted. GPT-5.5's low 5.2% Upgrade-all is explained by Ret⁻ = 11.2%—it dodges upgrades by not remembering.
  3. 9.9 % Upgrade-all under Marked + source-aware prompt repair (Ret⁻ 82.5%, Ret⁺ 98.6%)—versus 55.8% for plain Marked, which surfaces failures that omission was hiding.
  4. 0.0 % end-to-end ASR with predicted metadata (vs 16.9% no-metadata), TSR 39.7% → 40.0%. Oracle metadata produces identical aggregates; predictor agrees with reference on 98.7% of written memories.

03 / ASSESSMENT

Strengths & limitations, side by side

Novelty: high. The zero is one pipeline, on a recall-limited bench.

[ + ] Strengths

  • Formal separation of content preservation from authority preservation; the omission-vs-upgrade decomposition kills "safe-by-not-remembering" as a hidden defense.
  • Counterfactual design (carrier swap) isolates the single variable of interest—source authority—holding proposition, task, tools, and predicate fixed.
  • Deterministic action scoring via exact native-tool-call matching removes LLM-judge noise from Modules B and C.
  • Deployable mitigation: source-first predictor with deterministic role→label mapping, no fine-tuning, works with the existing consolidator.
  • Documentation hygiene: frozen revisions, SHA-256 pins, verbatim prompts, pinned model IDs, 20/20 audit.

[ ! ] Limitations

  • The headline 0.0% ASR is from a single validation-selected pipeline; the full predictor × consolidator × action grid is not reported.
  • Recall-limited ceiling: consolidator retains the focal proposition in only 256/350 H⁺ cases—metadata cannot repair what was never stored (TSR ≈ 40%).
  • role-policy-v1 is deliberately simple; real deployments treat specific tools as authoritative, so absolute rates are policy-dependent and may not transfer.
  • Module A relies on a single LLM judge (GPT-5.6-Luna); no inter-judge agreement or human spot-check reported.
  • Scope is narrow: two customer-service domains, seven hand-authored templates, synthetic APIGen-MT-5k without environment-state grounding.
  • Threat model excludes role-spoofing (e.g., tool output mimicking user voice); stronger adversaries uncharacterized.
