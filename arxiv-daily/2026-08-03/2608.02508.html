Critical Edge

01

Methodology — a fixed 2×2 state instead of a growing utility vector

RoMeRL keeps the LLM backbone frozen and learns a non-parametric memory policy. The core diagnosis: standard outcome-driven memory RL assigns each stored trajectory a utility Qi,t updated only when co-retrieved. As state dimension Nt grows with history but feedback stays bounded, updates dilute — and the Memory-Reward Trap emerges: weakly-relevant memories co-retrieved in successful episodes receive misattributed positive drift (Theorem 1: Q̂ converges to observational utility µi, not marginal θi).

The fix is a reduced-order factorized state Φ(·) that compresses variable-length history Dg,t into a fixed 2×2 tensor per task — indexed by outcome polarity {+,−} × memory dynamics {Consolidated, Adaptive}. New trajectories update or replace coordinate contents via explicit retention/promotion/replacement rules; new occupants inherit the prior coordinate's Q as a warm start, so feedback survives replacement rather than resetting.

03

Strengths & Limitations — side by side

● Strengths

  • Clean theory of a real problem. The MRT formalization (µi vs θi attribution gap) explains why UCB exploration makes things worse — confirmed empirically (MemRL+UCB: 7.2 noise updates vs MemRL's 3.7).
  • Five-axis Pareto win. SR, Cold-Q, feedback density, memory size, and LLM calls all improve simultaneously from a single 4-coordinate design — rare for the cost.
  • Meaningful division of labor. NCC is load-bearing (27–43% occupancy); PAC is sparse (5–8%) yet still drives current-epoch gains — ablations confirm.
  • Reproducible. Public code, full proofs (Appendix A), hyperparameter table, prompts, and case studies.
  • Rich critic signal. High-Q bin retains ~19.9% failure-derived memories — not a binary success/failure replay (r=0.673 vs baseline 0.493).

● Limitations

  • Attribution bias not eliminated. RoMeRL still uses bundle-level rewards — it concentrates feedback, doesn't fix the underlying confounding (§7).
  • γ, λ never measured. Proposition 1's erroneous-occupancy bound is illustrative, not validated — counterfactual rollouts would be needed.
  • Narrow benchmarks. Only ALFWorld + LAB OS/DB; no KG, no long-horizon, no web/code tasks.
  • Mixed backbones. GPT-5.4-mini vs DeepSeek-V4-flash across benchmarks inflates the single "Overall" figure.
  • Thin baselines. Only MemP & MemRL run; Memory-R1, AtomMem, Fine-Mem cited but not compared.
  • No significance testing. Single 10-epoch averages, no CIs — 1pp deltas indistinguishable from noise. Coordinate rules are hand-designed, not learned.

Open questions for further work

Q1 · THEORYCan γ and λ be estimated from counterfactual rollouts, and does d·γ/(γ+λ) hold on real memory traces?
Q2 · GENERALIZATIONDoes the 4-coordinate bottleneck lose information on long-horizon / web / code tasks vs a larger factorized state?
Q3 · DESIGNIs polarity×dynamics the right Cartesian product, or would polarity×recency×modality cover more at equal dimension?
Q4 · ATTRIBUTIONCan finer per-step rewards (à la Fine-Mem) combine with the reduced-order state to close the residual attribution gap?
Q5 · FAIRNESSWould a smaller, fairer MemRL pool close the 84.4% memory-size gap — is the efficiency win partly an oversized baseline?
Q6 · TRANSFERDoes cross-model transfer (Table 3) survive significance testing, and extend to much weaker / stronger backbones?
