Methodology

A two-tool agentic RAG loop (search / read / final) where a deterministic runtime invariant refuses any final emitted at read count = 0.

Trajectory Decomposition

Every wrong trajectory is assigned, in fixed priority, to the first matching bucket: E_wrong = E_disc ⊎ E_post ⊎ E_retr ⊎ E_amb. Discipline failure E_disc covers (a) no-read final, (b) snippet-only final, (c) low-evidence final (<80% entity coverage). E_post fires when gold evidence was read but the answer is still wrong.

READ-GATE Invariant

If the agent emits final with read count = 0, the environment rejects the action and appends a corrective hint to the next observation; the loop resumes. The intervention is inference-time only — orthogonal to weights, retriever, index, judge, temperature, and reasoning budget.

Setup

gpt-4o-mini & gpt-5-mini at minimal / medium reasoning on HotpotQA, 2WikiMultiHopQA, MuSiQue. n = 1,000 paired questions per dataset–condition → 12,000 OpenAI trajectories. Temp 0.0, max loop 10, 128k tokens, fixed gpt-5-mini judge; Gemini 2.5 Pro cross-judge κ = 0.924.

Statistics

Exact paired McNemar tests, question-clustered standard errors in logistic models, label-permutation nulls, and multi-label reclassification with two independent entity extractors (regex + spaCy en_core_web_sm) for the non-redundancy test.

Results & Highlights

Three falsifiable predictions — H1 non-redundancy, H2 gain tracks residual discipline error, H3 differential (Pdisc, Ppost) signatures — tested against prompt-only and ctx-inject controls that rule out "more context in the window" as the cause.

  • Full-cell lift (Table 2). On gpt-5-mini minimal, READ-GATE adds +3.2 / +5.3 / +9.4 pp (HotpotQA / 2Wiki / MuSiQue). The ctx-inject control is −0.1 / −7.4 / +3.9 pp and significantly worse (p ≤ 10⁻⁴) — isolating the value of the self-issued read action itself.
  • H2 — gain tracks residual discipline error, not reasoning level. Partial correlation between baseline E_disc and Δ LLM-Acc is r = +0.881 (n=6) controlling for retrieved tokens. Under medium reasoning (residual E_disc 4.5 / 5.7 / 21.7%), gains collapse to +0.0 / −7.0 / −4.0 pp.
  • H3 — differential (Pdisc, Ppost) signatures. READ-GATE cuts Pdisc (OR 0.38 [0.35, 0.41]) without changing within-read Ppost (OR 1.00); reasoning effort (minimal→medium) cuts both (Pdisc OR 0.22, Ppost OR 0.51) with significant interaction OR 2.02, p<10⁻⁴.
  • Counter-intuitive thinking-budget result (Table 5). On Gemini 2.5 Flash, raising thinking budget off→1024 increases zero-read rate: +5.7 pp HotpotQA (net −44), +24.8 pp 2Wiki (−67), +42.6 pp MuSiQue (−73). More internal deliberation ≠ more external inspection.
  • Cost framing. Adding READ-GATE to gpt-5-mini minimal closes 20–24% of the LLM-Acc gap to gpt-5-mini medium, at modest overhead in reads and loop count — no gold labels required to trigger it.
Bottom line: evidence retrieval should be treated as a trajectory-level control problem, independent of answer-side reasoning. The unlabeled zero-read rate is a deployable trigger; READ-GATE is the lightest possible intervention targeting this failure class.
03

Strengths & Limitations

Strengths

pro
  • Falsifiable H1/H2/H3 structure tested with paired statistics (McNemar, clustered SEs) rather than aggregate bars.
  • Mechanism ablations (prompt-only, ctx-inject, four-arm channel probe) actively rule out "more context in window" as the cause.
  • Honest scope: repeatedly framed as a diagnostic, not a universal decoding policy; warns against deploying low-effort agents without verification.
  • Robust under perturbation: threshold sweeps (0.6–0.9), strict no-read-only lower bound, paired bootstrap, label-permutation null, cross-family (Qwen2.5 3B/7B/14B) & cross-judge (Gemini 2.5 Pro κ=0.924).
  • Deployable insight: unlabeled zero-read rate is a sufficient operational trigger for enabling the gate — no gold labels needed.
  • Excellent reproducibility: 33,950 trajectories + per-question labels + cached analysis reproduce every number with zero additional API calls.

Limitations

con
  • Controller scope. Main experiments limited to cost-sensitive gpt-4o-mini / gpt-5-mini. Larger frontier models, more families, and non-English settings are untested.
  • Domain overfit. All three datasets are English Wikipedia multi-hop QA where snippet shortcutting is visible; entity thresholds and gate behavior would need recalibration per domain.
  • Action-boundary assumption. Presumes discrete search/read/final actions — agents that interleave retrieval and generation implicitly are out of scope.
  • Not a retrieval fix. READ-GATE assumes search returns useful candidates; it modestly increases reads-per-question and retrieved tokens.
  • MuSiQue E_post gap. Processed MuSiQue export lacks per-chunk gold annotations, so the strongest non-redundancy claim (H1) is fully established only on HotpotQA + 2Wiki.
  • Action-commitment generality. The self-issued-read > passive-context result is isolated on a single dataset + backbone (MuSiQue, gpt-5-mini minimal, n=500).
04

Questions for Further Exploration

  1. Does the non-redundancy between Pdisc and Ppost hold for larger frontier controllers (gpt-5, Claude Opus-class) and for non-Wikipedia RAG domains (legal, biomedical) where snippet semantics differ?
  2. Can READ-GATE be combined with retrieval-quality monitoring and answer-side verification into a layered runtime policy that avoids the medium-reasoning regression where forced reads exhaust the loop budget?
  3. Why does a larger hidden thinking budget increase zero-read finalization on Gemini 2.5 Flash — is the model substituting internal deliberation for external inspection, and does this generalize across reasoning models?
  4. Does the self-issued read action's advantage over passively delivered context generalize beyond MuSiQue and gpt-5-mini, or is it an action-commitment artifact specific to this backbone?
  5. Could the trajectory-level decomposition extend to agents that interleave retrieval and generation without an explicit read boundary, by synthesizing an inspection signal from attention or generation-state probes?
