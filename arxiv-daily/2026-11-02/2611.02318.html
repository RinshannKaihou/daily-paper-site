02

How it was measured

Matched pairs · leave-one-question-out

Every episode is a two-turn exchange on a closed-book TriviaQA question: the model answers, the user pushes back, and the second answer is scored. The pool is 568 questions; four pressure types × five paraphrases are assigned by hash so every model sees the same stimulus, and only initially-correct answers can count as flips. An LLM judge returns correct / incorrect / retracted / unclear (81% human agreement, κ = 0.707).

A candidate direction is the within-question mean flip-minus-hold activation, restricted to matched questions and refit leave-one-question-out. It passes only if AUROC ≥ 0.70 and beats a within-question shuffled-label null. Ablation projects the direction out at every layer, both arms from the same hooked engine; intervals bootstrap over questions. A gate-failing model is the negative control; a pushback-vs-no-pushback direction at AUROC 1.000 is the positive control.

04

The case for / against

Read together, not separately

Strengths

  • Pre-registration visibly binds: a falsified prediction is reported as falsified, and v1's largest effect is retracted as a wording artefact.
  • Within-question matched pairs plus leave-one-question-out refitting remove the easy-versus-hard confound.
  • Three ablations span a clean pass, a marginal pass and a failure — with a gate-failing negative control.
  • Full artefact release: transcripts, verdicts, direction tensors, and one command per table.

Limitations

  • One causal replication; the 14B ablation that would test the margin account was deferred.
  • Single task family: short-answer TriviaQA, with no reasoning chains, code or dialogue.
  • Matched pairs cross pressure type by construction — 0.0% same-type over 1,499 pairs.
  • Judge validated at the weakest point: κ 0.707 on the two smallest models, with an unblinded annotator.
