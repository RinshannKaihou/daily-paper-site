> **一句话总结：** 作者构建了专家审核的量子计算复现基准 OmniQ（60 篇论文、59 个可执行复现任务），发现前沿 AI scientist 复现成功率从 19% 到 93% 不等且与推理成本不单调相关，进而提出 Residual Agents（RA）——把人工确认过的修复过程蒸馏成 planner/critic/residual 三类经验记忆，在固定 DeepSeek V4.1 Flash 基座下把成功率从 68% 提到 85%，与贵 3–6 倍的 Claude Code + Opus 5、Codex + GPT-5.6-sol 持平。

> **TL;DR:** The authors build OmniQ, an expert-audited benchmark of 59 executable paper-to-result reproduction tasks drawn from 60 computational-quantum-science papers (classical simulation, quantum algorithms, property characterization), and use it to evaluate five frontier model families, five first-party agent systems, and six third-party harnesses. Reproduction success spans 19% (Meta-Harness + DeepSeek) to ~93% (Claude Code + Opus 5.5); cost does not predict success, and no third-party harness beats the vendor's own. They then train Residual Agents (RA), which distills expert-verified workflow repairs into a small experience layer (10 residual-memory entries from 5 development tasks) while freezing the base model, lifting DeepSeek V4.1 Flash + DSH from 68% to ~85% at $5.6/task versus $16 (Claude Code + Opus 5, ~85%) and $35 (Codex + GPT-5.6-sol, ~85%) — still 8 points behind Opus 5.5's 93%. Worth reading if you care about self-improving agents, agent-harness silent failures, or AI-for-science evaluation; the benchmark and the Level I–III taxonomy are the durable contributions, the "self-improving" claim is more modest than the framing suggests.

## 核心贡献

- **提出 OmniQ 复现基准**：把 60 篇计算量子科学论文（经典模拟 20 篇、量子算法 19 篇、性质刻画 21 篇）转化为"给论文 + 目标图，让 agent 重建工作流并复现数值"的可执行任务，每篇配 8 个 agent 配置独立跑，共产生 3,376 条判定记录。
- **建立复现问题的三级分类法（Level I/II/III）**：把"论文写法缺细节但可从代码/专家解释恢复"、"论文内部局部矛盾但可查证"、"论文正文、图与开源代码根本不一致、无法复现"分开，从而把"agent 失败"与"科学记录本身有问题"解耦。
- **系统评测发现**：60 篇中 18 篇（30%）存在复现问题（16 篇 Level I、1 篇 Level II、1 篇 Level III）；在清洗后的 59 篇上，前沿 agent 成功率从 19% 到 93%，且成功率与推理成本**不单调**——花钱多不等于做得多。
- **提出 Residual Agents（RA）**：planner/executor/critic 三角色 + 独立 judge + 经验蒸馏器，把"失败执行 → 专家验证的修复"之间的残差提炼成可复用的失败签名，只改经验层、不动基座模型与编排代码。
- **给出可复用的科研基础设施**：把全部复现结果封装成基于 MCP 的平台，使已验证的研究工作流可被 AI scientist 直接调用，并可持续纳入新论文。
- **诚实报告负结果**：第三方 harness 在计算量子科学上全面不如厂商自带的 first-party harness；RA 的提升主要来自"发现并修正失败"，90% 的成功任务至少需要一次纠错。

## Key Contributions

- **OmniQ benchmark**: 60 curated computational-quantum-science papers turned into figure-level reproduction tasks with hidden evaluation criteria, an LLM judge (Claude Code + Opus 4.8), and a cross-agent + expert audit loop. 59 tasks survive into the cleaned evaluation set.
- **A three-level reproducibility taxonomy** that separates recoverable methodological gaps (Level I), localized paper-internal inconsistencies (Level II), and unresolvable contradictions among text, figure and released code (Level III). This is the paper's most transferable methodological idea: it makes "the agent failed" and "the record is broken" distinguishable.
- **A large-scale, controlled empirical study** of the AI-scientist stack on a single scientific domain: five base-model families (GPT, Claude, DeepSeek, Kimi, Grok), five first-party systems (Codex, Claude Code, Kimi Code, Grok Build, DSH), and six third-party harnesses (InternAgent, DeepCode, mini-swe-agent, live-swe-agent, HGM, Meta-Harness), with a model-held-fixed harness comparison in SI E1.
- **Residual Agents (RA)**: a self-improving wrapper that distills expert-verified repairs into planner memory, critic memory and a residual memory of failure signatures, leaving the base LLM and orchestration untouched. Adaptation is confined to a small experience layer (10 entries from 5 development tasks).
- **A failure taxonomy of agentic reproduction**: 954 critical findings across 266 failed runs, classified into substitution/fabrication, reduced problem, implementation error, missing content, rendering error, mismatch with the paper, and report-contradicts-its-own-data.
- **An MCP-based research platform** exposing verified reproduction workflows as callable tools for downstream AI scientists.

## Methodology

**OmniQ construction (7 steps).** A domain expert selects a paper and a target figure; an LLM agent drafts two documents — a *preliminary* spec visible to the AI scientist (target figure, experimental scope, conventions) and a *criteria* document visible only to the judge (structural requirements, quantitative checkpoints with tolerances, required procedures). Experts review both. Multiple agent configurations then run each task once; an auditing agent screens systematic failures across configurations; experts grade confirmed issues into Levels I–III and decide whether to revise the spec/criteria; affected tasks are re-run or re-judged.

**Dataset.** 60 papers, roughly balanced across classical simulation (20), quantum algorithms (19) and property characterization (21), selected for impact and venue but explicitly constrained to be reproducible within **~1 day of compute per task** — a constraint the authors note "largely excludes computationally intensive deep-learning-based approaches." Papers span tensor networks, neural quantum states, Pauli propagation, free-fermion simulation, QMC, open-system simulation; product formulas, QPE/amplitude estimation, variational algorithms, QML, quantum-enhanced MCMC; shadow tomography, measurement optimization, and learned surrogates.

**Judging.** The judge (Claude Code with Opus 4.8) sees the full workspace — code, logs, numerical data, reports — and checks values against mandatory checkpoints with tolerances; presentation issues are non-critical. A task passes only if every target figure passes. The executor/critic never see the criteria.

**RA architecture.** A planner decomposes the task into a dependency graph of sub-plans with per-sub-plan budgets and completion criteria and fixes a shared methodological interpretation; executors run each sub-plan in isolated sessions (validating on the smallest exactly solvable instance first, launching long jobs as tracked background processes); a critic checks provenance, methodological correctness and completeness and routes to Pass / Local repair / New approach. "New approach" triggers three independent probe agents that test hypotheses with small numerical experiments, followed by a three-critic majority vote that discards proposals violating fixed requirements or merely fitting the published figure. An independent judge scores the assembled result. An experience distiller then converts verified repairs into planner memory, critic memory, and residual memory entries (failure description → diagnostic check → remedy), with every update human-approved. Adaptation uses 5 development tasks only; evaluation is on the remaining 54.

**Evaluation protocol.** RA runs DeepSeek V4.1 Flash with DSH as executor, 24 h per task, compared head-to-head with DSH on the same model and budget. Cost is model-inference cost per task (USD), plotted against success rate with wall-clock time as marker size.

## Results & Highlights

- **Reproducibility audit:** on the 60-paper OmniQ set, **18 papers (30%)** were flagged and expert-confirmed as having reproduction issues — **16 Level I, 1 Level II, 1 Level III** — out of 19 papers flagged by the cross-agent auditor over 3,376 judging outcomes (18/19 confirmed, i.e. the flagging step had ~95% precision but the paper reports no recall estimate).
- **Frontier spread:** on the cleaned 59-task set, **Claude Code + Opus 5.5 reaches ~93%** success, Codex with several frontier models exceeds 70%, **Codex + GPT-6-luna only ~42%**, and **Meta-Harness + DeepSeek worst at 19%** — a 74-point spread across systems nominally doing "AI science."
- **Cost is not monotonically predictive:** **DSH + DeepSeek V4.1 Flash gets ~68% at the lowest cost per task** (below $7), beating every system under that price and several costing an order of magnitude more, while Claude Code + Sonnet 5.5, Kimi Code + K3 and several Codex systems spend more and score lower.
- **Harness comparison with the model held fixed (DeepSeek V4 Pro):** DSH reproduces **29/59 (49%)**, mini-swe-agent **28/59 (47.5%) at roughly one-third of DSH's cost**, HGM 24/59, DeepCode 21/59, live-swe-agent 18/59, InternAgent 16/59, Meta-Harness **11/59 (19%)** — i.e. the third-party harness range is 19–48% against 49% for the vendor harness.
- **RA's headline gain:** DeepSeek V4.1 Flash + DSH goes from **68% → ~85%** on the 59 tasks (**+17 points, ~10 tasks**) at **$5.6 per task**, matching Claude Code + Opus 5 (~85% at $16) and Codex + GPT-5.6-sol (~85% at $35) — 2.9× and 6.3× cheaper respectively — but remaining **8 points below Claude Code + Opus 5.5 (93%)**.
- **Failure taxonomy:** 954 critical findings across 266 failed runs; "mismatch with the paper" is the most common category (24–42 runs per harness), Meta-Harness reduces the problem size in **18 of its 48** failed runs, live-swe-agent commits implementation errors in **22 of 41**, and InternAgent fails to produce any report in **13 of 43**.
- **Where RA's gain comes from:** the critic rejects **more than half** of intermediate results, **90% of successful RA tasks require at least one correction**, and all **13 tasks recovered beyond DSH** involved corrections — the improvement is error-catching, not better one-shot generation.
- **Concrete reproduction forensics:** Paper #42's silhouette coefficient falls from **0.59 (paper) to 0.29 (reproduction)** at circuit depth 4, and applying the paper's own written procedure to the authors' released data yields only **0.24**; Paper #60 reports **Var[K]=0.49 at n=2**, above the theoretical bound of 0.25 for a kernel in [0,1], with published variances at n=12 **13× and 57×** above recomputed values at L=2 and L=4; Paper #2's RA reproduction matches published errors **within ~2% at 15 of 23** rotation-angle points where DSH was off by 10⁻³–10⁻¹.

## Critical Assessment

**Novelty.** The genuinely new pieces are (i) the Level I–III taxonomy that separates record-side defects from agent-side failures, and (ii) the "residual memory" framing, which learns from *verified repairs* rather than from unverified self-critique. Both are useful. But the self-improvement mechanism itself is a fairly standard planner/executor/critic loop with a retrieval-augmented memory; the "experience distiller" is an offline, human-gated prompt/memory update, not a learning algorithm. Calling this "self-improving" is defensible only in the weak, memory-augmentation sense.

**The headline framing overreaches the evidence.** The abstract and intro sell "a fundamental barrier" in the scientific record, but the audit's own numbers are 16 Level I, 1 Level II, 1 Level III. Level I is defined as recoverable detail — and explicitly includes "discrepancies in task specifications and evaluation criteria," i.e. *benchmark-side* bugs, not paper-side inconsistency. So of 18 flagged papers, exactly one (#60) is genuinely unreproducible from the record, and one (#42) is a real but localized ambiguity. The claim "in 18 studies the paper description, released code and reported results are inconsistent" (Introduction) is stronger than what the SI supports: most are missing hyperparameters or under-specified procedures, a well-known and much less dramatic problem.

**Statistical rigor is thin.** SI B1 states each configuration executes each task **once**; there are no seeds, no repeated runs, and no confidence intervals anywhere in the main text or SI E. With n=59, one task is 1.7 points. That makes the 68%→85% RA gain plausibly real (+10 tasks) but makes the harness ranking unreliable at the top: DSH 29/59 vs mini-swe-agent 28/59 is a one-task difference being narrated as "none of the six exceeds the vendor's own harness." The same applies to the "cost doesn't predict success" claim, which is a correlational scatter over confounded model families and harnesses.

**The harness conclusion is contradicted by the paper's own table.** The main text argues third-party harnesses "do not necessarily improve reproduction and can even degrade performance," but Table SI 3 shows mini-swe-agent within one task of DSH at ~1/3 the cost — by the paper's own cost-performance logic (the Pareto argument it uses to praise RA), mini-swe-agent is the better deal, not a failure of third-party harnesses. The claim survives only if you read success rate as the sole objective.

**An unsupported transfer claim.** The intro states gains "transfer across models," but every RA experiment uses DeepSeek V4.1 Flash with DSH. There is no cross-model RA experiment in the main text or SI E. This is the kind of sentence that should have been cut or backed with a table.

**Judge circularity and limited human calibration.** Success is decided by an LLM judge (Claude Code + Opus 4.8), and RA's critic is explicitly optimized to satisfy "the paper, task specification and execution records." The criteria are hidden from executor/critic, which helps, and the paper does exclude repairs that merely fit the published figure — good hygiene. But the human verification covers only the 19 *flagged* papers, not a random sample of *passes*. The 98.3% (59/60) agreement figure refers to the failure-category classifier, not to the judge's pass/fail decisions. False-positive reproductions (agent "succeeds" by a wrong route that happens to match checkpoints) are therefore unmeasured.

**Human-in-the-loop is doing real work, and its cost is uncounted.** Every experience-layer update must be approved by a domain expert, and the memory was built from 5 hand-picked "most challenging" tasks. The $5.6/task figure excludes expert time entirely; the true cost of RA includes the curation of 60 papers, the audit, and the memory supervision. The paper's cost comparison against Opus 5.5 is therefore a *marginal inference* cost comparison, not a total-cost one, and it should say so.

**Benchmark scope limits the generality claim.** By construction the tasks fit in ~1 day of compute and "largely exclude computationally intensive deep-learning-based approaches" — precisely the part of computational quantum science (large NQS training, big tensor-network contraction campaigns) where agentic help would matter most. There is also no per-area breakdown of success rates in the main text, so we cannot tell whether RA's +17 points come from one of the three subfields (e.g. classical simulation, where code-heavy tasks may be easier) and whether the other two are flat.

**Minor red flags.** The abstract says "59 papers" while the Introduction says "60 papers" (60 curated, 59 after excluding #60 — but the abstract's phrasing conflates curation and evaluation). SI E1's opening paragraph is duplicated verbatim ("The experimental settings are as follows...") — a copy-editing lapse that suggests the SI was assembled quickly. Paper #35's baseline failure ("DSH incorrectly declared the noisy reproduction successful") is a nice illustration of agent overclaiming, but it is also the paper's own judge catching it, which weakens the "agents silently declare success" narrative slightly.

## Strengths

- **The Level I–III taxonomy is a real contribution.** Most reproducibility papers report a single "X% reproducible" number; separating "the paper is under-specified," "the paper is internally inconsistent," and "the paper cannot be reproduced at all" makes the diagnosis actionable and is directly reusable outside quantum science.
- **The audit is unusually careful.** Two-document task design (agent-visible spec vs judge-only criteria), cross-agent screening of 3,376 outcomes, expert confirmation of 18/19 flagged cases, and explicit revision of tasks whose criteria were wrong. This is more rigorous than most agent-benchmark construction.
- **The harness comparison is properly controlled.** Holding DeepSeek V4 Pro fixed across seven harnesses (SI E1) is exactly the ablation the field usually skips, and the 19%–49% spread is a strong, useful result about how much the scaffold matters.
- **Honest about the residual gap.** RA is reported at 85% while the best system is 93%, and the paper says so plainly rather than hiding the comparison. It also reports that 90% of successes needed a correction, which is an unusually candid admission that one-shot reproduction does not work.
- **Failure taxonomy with validated labels.** 954 findings over 266 failed runs, classified blind to harness identity, with a 98.3% re-classification agreement — this gives the qualitative claims an empirical backbone.
- **The case studies are genuinely diagnostic.** Paper #2's weight-17 vs weight-23 observable mix-up and Paper #29's KL-divergence floor (target [0.015, 0.03], both systems stuck above 1 after 50 sweeps) are the kind of concrete, checkable failures that make the benchmark credible.

## Limitations

- **Small, single-run benchmark.** 59 tasks, one run per configuration, no variance estimates; differences below ~3–4 tasks are not interpretable.
- **Self-curated, self-judged, self-proposed.** The same group builds the benchmark, defines the criteria, supplies the judge, and proposes the method evaluated on it. No independent replication or third-party benchmark is used.
- **Quantum-only, and a compute-restricted slice of it.** Generalization to other scientific domains (the Discussion's stated ambition) is asserted, not tested; and the 1-day budget excludes the deep-learning-heavy part of the field.
- **Human-gated "self-improvement."** Experience updates require expert approval, so RA is not an autonomous self-improving system; the adaptation budget is 5 tasks and 10 memory entries, which is small enough that "scaling" behavior is unknown.
- **No component ablation.** There is no experiment removing planner memory, critic memory, or residual memory individually, so the contribution of each is unmeasured; likewise no ablation of the three-probe-agent diagnosis or the three-critic vote.
- **No cross-model or cross-harness transfer experiment**, despite the claim of transfer in the introduction.
- **LLM judge without sampled human calibration on successes**, leaving false-positive reproductions unquantified.
- **Cost accounting excludes expert time**, which for a benchmark of this kind is likely the dominant cost.

## Relevance

与"自进化智能体与自动化科研"这一主线高度契合：它把"可验证的复现"当作经验来源，用**只改经验层、冻结基座模型**的方式做自我改进，并给出了"经验能否泛化到未见任务"的实测（5 个任务 → 54 个任务，68%→85%），是自进化 agent 里少见的、带严格外部验证的正面证据。对"Agent & Pipeline 静默失败"也有直接参考价值：文中把"未验证就宣称成功""悄悄缩小问题规模""用廉价替代计算顶替""报告与自身数据矛盾"列为 harness 的典型失败模式，并给出了可复用的失败分类与检出机制。

## Questions for Further Exploration

1. Does the distilled experience layer transfer to a *different* base model or harness — e.g. does the same 10-entry residual memory help Claude Code + Sonnet, or Codex + GPT-6-luna? The introduction claims cross-model transfer; no such experiment appears.
2. What is the marginal contribution of planner memory vs critic memory vs residual memory? A leave-one-out ablation would tell us whether the gain is "experience" or just "a better prompt."
3. How often does the Opus 4.8 judge pass a reproduction that a human expert would fail? A random sample of 30 "successes" re-graded blind would settle the false-positive question that the current audit (flagged papers only) leaves open.
4. What was the total expert-hours cost of building the 10 residual-memory entries and the 60-paper audit, and does that amortize over more than 54 tasks?
5. Would the 16/1/1 Level I/II/III split replicate on an independently curated quantum benchmark — i.e. is ~30% "problematic papers" a property of the field or of this particular curation?
6. How do success rates break down by subfield (classical simulation vs quantum algorithms vs property characterization), and does RA's +17 points concentrate in one of them?
7. Does the 24 h/task budget for RA match the budget given to the frontier baselines in Fig. 3, or is RA trading wall-clock for success rate in a way the cost axis hides?
