> **一句话总结：** 作者审计 291 个开源权重仓库（280 张不同 embedding 表），发现 52.6% 的非绑定（untied）门控/混合模型（20/38）存在范数低于 $10^{-6}$ 的"可达"输入 embedding 行，这些行在 Mamba/xLSTM/Gated DeltaNet 中把输入 embedding 梯度放大约 30–35 个数量级，越过 $1.84\times10^{19}$ 的 FP32 平方溢出阈值后使 PyTorch/HF Trainer/FSDP2 的全局范数裁剪把整批梯度静默置零（Nemotron-3-Nano-4B 泰卢固语继续预训练中约 20% 的步数被丢弃）；作者给出两行级修复——面向已发布检查点的 GroupClip（把 $E_\text{in}$ 单独用 64 位或重缩放范数裁剪）与面向从零预训练的 GateFloor（$\mathrm{SiLU}(z)+\delta$），后者在 370M 规模把 $r=10^{-30}$ 的梯度从 $1.6\times10^{28}$ 降到 0.13，困惑度基本持平（22.28 vs 22.45）。

> **TL;DR:** A census of 291 open-weight HuggingFace repos finds that untied gated/hybrid checkpoints (Nemotron-3-Nano-4B, Falcon-H1, Kimi-Linear-48B, Mamba-Codestral) contain reachable input embeddings with norm below $10^{-6}$ in 52.6% of cases (20/38) versus 0/101 for weight-tied models, because AdamW weight decay shrinks rows that never receive input gradients. In gated blocks a zero-at-origin readout factor (SiLU gate or linear query) collapses historical state, so Pre-RMSNorm's $1/\sqrt{\epsilon}$ amplification compounds across depth: at $r=10^{-30}$ Nemotron-3-Nano-4B reaches $\|\nabla_{e_t}L\|_\infty = 2.1\times10^{35}$ while Llama-3.1-8B stays flat at 56–98 and RWKV-4-1.5B at 8.5. Any gradient entry above $1.84\times10^{19}$ overflows FP32 squaring to `inf`, so `clip_grad_norm_` multiplies every gradient by $1/\infty = 0$ without NaN — silently discarding 198.3±9.9 of 1,000 Telugu CPT steps (19.8%), costing 13.44±0.17 vs 13.04±0.19 FLORES-200 PPL, which a three-line decoupled `GroupClip` recovers exactly (0.0 stalled steps) at no measured step-time cost (2.84 s vs 2.88 s).

## 核心贡献

- **开源生态审计（首个此类普查）**：用 HTTP byte-range 只读取 safetensors 的 $E_\text{in}$/$E_\text{out}$ 切片，扫描 291 个 HuggingFace 仓库（280 张去重后的 embedding 表），并对每个范数 $<10^{-6}$ 的行做"往返分词可达性"检验（解码 ID 后单独及在 8 个模板中重新分词，能复现同一 ID 才算 reachable）。结果：92 个仓库有原始近零行，67 个（23.0%）有**可达**近零行；按绑定方式分裂得极其干净——绑定权重 0/101（0%），非绑定 Transformer 47/152（30.9%，但在 $t>0$ 或带 BOS 时安全），非绑定门控/混合模型 20/38（52.6%，会触发梯度爆炸）。
- **给出近零行的预训练成因并做受控验证**：$E_\text{in}$ 与 $E_\text{out}$ 解绑时，从未出现的 token 其输入行每步收到精确零梯度，而输出行因 softmax 归一化始终有非零梯度；于是 AdamW 的 decoupled weight decay 每步把它乘 $(1-\eta_t\lambda)$，闭式解 $\|e_v\|_2^{(T)}=\|e_v\|_2^{(0)}\prod_t(1-\eta_t\lambda)$。在 4 层 Mamba 的 $2\times2$（绑定 × weight decay）消融中，500 个未登录行 3000 步后按该式衰减到五位有效数字（CV=0.0085）；在 OLMoE-1B-7B 上，251 个近零行在 364M token 采样中**零出现**，250 个紧密聚在 $[3.23,3.50]\times10^{-12}$，其隐含累积对数衰减 ≈ −26.3，与 OLMoE 5.13T token 调度算出的 $\sum_t\eta_t\lambda\approx 26\text{–}27$ 吻合。
- **定位并证明"多层放大"机制（Proposition 1）**：Transformer 在第 0 层注意力就能用正常尺度的 value 向量把残差拉回 $\Theta(1)$；门控块则把历史状态读出乘上一个在零点消失的当前 token 因子 $\phi_\ell(\tilde h_t)$（SiLU 门或线性 query），于是残差在连续多层停留在 $\sqrt{\epsilon d}$ 之下，Pre-RMSNorm 每层把反向梯度放大 $10^3\times$（$\epsilon=10^{-6}$）或 $316\times$（$\epsilon=10^{-5}$）。定理给出两段式标度 $\|\nabla_{e_t}L\|_2=\Theta(\min\{\sqrt{\epsilon d}/r,\,G_K\})$：$1/r$ 反比段 + 由前缀门控增益 $G_K$ 决定的天花板段，并在 8 个预训练检查点上实测验证（斜率 −0.81 至 −1.22）。
- **揭示"静默清零"的数值路径**：PyTorch / HuggingFace Trainer / FSDP2 都在 FP32 里累加平方梯度（$\text{FLT\_MAX}\approx3.40\times10^{38}$），任何元素 $>1.84\times10^{19}$ 平方即溢出为 $+\infty$，$\alpha_\text{eff}=\min(1,c/(G+10^{-6}))=0$，`mul_(0.0)` 把整批梯度映射为精确 $\pm0.0$ 且不产生 NaN。三个框架都在 Falcon-H1-1.5B 上实测到 `grad_norm=inf` 且 $\|\Delta\theta_\text{grad}\|_\infty=0$，前向激活全程有限；Megatron-Core 要么抛异常要么同样静默清零。
- **两个零开销修复**：(i) **GroupClip**——把 backbone 与 $E_\text{in}$ 分开裁剪，$E_\text{in}$ 用 FP64 范数（或免拷贝的原地重缩放变体），三行代码，不改架构、不扫词表、不重初始化；(ii) **GateFloor**——$g_\delta(z)=\mathrm{SiLU}(z)+\delta$，$\delta\in[0.01,0.1]$，零参数零吞吐损失，让第 0 层在 $z=0$ 处仍传递 $\delta y_t$，从而把 $K$ 从 7 直接降到 0。
- **给出端到端危害的量化漏斗**：从词表占比（0.047%）→ 语料出现率（32.3 ppm）→ batch 触发率（22.5%）→ FP32 溢出率（88.1% 的命中 batch，即 19.8% 的全部步数）→ 后 AdamW 参数位移（fresh-batch 位移**恒等于 0**，0/3,562,515,040 个权重与喂入 $g_t=0$ 相差 1 ULP）。

## Key Contributions

- **A reproducible open-weight census with a reachability filter.** Rather than trusting raw row norms (which include padding IDs and unreachable byte entries), every candidate row is round-trip tokenized through eight templates. This turns a fuzzy "some rows look small" observation into a defensible count: 67/291 repos (23.0%) contain reachable near-zero input rows, with a striking tying split (0/101 tied vs 67/190 untied).
- **A closed-form origin story plus two independent confirmations.** Eq. (1) predicts geometric decay of unseen input rows under decoupled weight decay; a $2\times2$ tied/untied × $\lambda$ ablation reproduces it to five significant digits, and the OLMoE-1B-7B audit matches the predicted cumulative log-decay (−26.3 vs 26–27) on a real 5.13T-token schedule. This is unusually tight evidence for a mechanism claim.
- **A depth-scaling law for near-zero-token gradients (Prop. 1)** with an explicit two-regime form and an architectural taxonomy (Table 1) that explains *why* some hybrids are safe: Kimi-Linear's short causal conv over $t-3\ldots t$ keeps $q_t$ non-zero at $t>0$ (gradient 88), while xLSTM projects $q_t$ from token $t$ alone and explodes ($1.0\times10^{32}$) despite both using sigmoid gates.
- **A causal, not correlational, dissection of the mechanism.** The gate-patching $2\times2$ (forward gate value × backward derivative, `straight-through` hook) separates "restoring forward readout" from "severing backward paths": detaching Layer 0's gate backward leaves $\|\nabla_{e_t}L\|_\infty$ at $1.7\times10^{31}$, whereas opening only the forward gate (keeping all derivatives) drops it to 6.71 — a 34-order reduction with zero backward paths cut.
- **Two mitigations validated against strong and oracle baselines.** GroupClip is compared against Skip-on-Inf, ZClip, GradientStabilizer, Freeze $E_\text{in}$, FP64 Global Norm, Mean Re-init, and an **Oracle Dead-Row Mask** (which requires a pre-scan), across 3 seeds; GateFloor is compared against Sigmoid gates and a $\delta$ sweep on 14 from-scratch runs.
- **A precise framework-level bug report** that names the exact constant ($1.84\times10^{19}$), the exact code path (`_get_total_norm` accumulating in the gradient dtype), and the exact silent outcome (zero update, finite activations, no exception) — actionable for anyone debugging "why did my multilingual CPT stop learning".

## Methodology

**Census (Sec. 2, App. F).** Starting from the 500 most-downloaded text-generation repos (Oct 2026 snapshot), filtering quantized/adapter/test variants, and adding base checkpoints of major families, the authors obtain 313 candidates, of which 256 are readable (the rest gated, safetensors-free, or with >3 GB embedding tensors); a targeted gated/recurrent list adds 31 and a pure-SSM list 4, giving 291 unique repos. For each, the safetensors header is read and only byte ranges of $E_\text{in}$/$E_\text{out}$ are fetched; per-row $\ell_2$ norms are computed in FP64. Tying is taken from `tie_word_embeddings`, falling back to "no separate output tensor ⇒ tied". Mirror detection (vocabulary size, width, four row-norm statistics, near-zero count) collapses 291 repos to 280 distinct tables. Reachability uses the Land & Bartolo round-trip test with templates `{}`, `" {}"`, `a{}`, `"{} "`, `x {} y`, `\n{}\n`, `The {} is`, `1{}2`; two non-HF tokenizers (Kimi-Linear-48B, Mamba-Codestral-7B) are verified with their official tokenizers.

**Theory (Sec. 3, App. B).** Pre-RMSNorm with floor $\epsilon$ is Taylor-expanded around $h=0$: $\tilde h=\epsilon^{-1/2}(w\odot h)+O(\epsilon^{-3/2}d^{-1}\|h\|_2^3)$, so a sub-$\sqrt{\epsilon d}$ residual is multiplied by $\epsilon^{-1/2}$ on the way back. For a block whose current-token factor satisfies $\phi_\ell(0)=0$ and $\partial\phi_\ell/\partial\tilde h|_0\neq0$, the per-layer Jacobian at the origin is $J_\ell(0)=I+\epsilon^{-1/2}W_{o,\ell}J_{N_\ell}(0)\,\mathrm{diag}(y_t^{(\ell)})D_\ell\,\mathrm{diag}(w_\ell)$ — note the $(\partial y_t/\partial h_t)\phi_\ell(0)$ term vanishes exactly, which is why *all* sub-$\epsilon$ gain flows through the gate derivative. Defining $\gamma_\ell=\|J_\ell(0)\|_2$, $\Pi_k=\prod_{\ell<k}\gamma_\ell$, $G_k=\|M_k\|_2$ with $M_k=J_{k-1}(0)\cdots J_0(0)$, Prop. 1 gives $\|\nabla_{e_t}L\|_2=\Theta(\min\{\sqrt{\epsilon d}/r,\,G_{\min(K,L)}\})$ under a non-degeneracy assumption (input direction and back-propagated gradient not nearly orthogonal to the dominant singular subspaces).

**Empirical gradient probes (Sec. 3.2, App. B).** Two mid-sequence sweeps record $\|\nabla_{e_t}L\|_\infty$: an eight-model sentence sweep (E30) over $r\in[10^{-30},10^0]$ with BOS, and a row-norm sweep (o4) over $r\in[10^{-35},10^0]$ on Llama-3.1-8B, Nemotron-3-Nano-4B and Falcon-H1-1.5B. The causal gate-patching $2\times2$ uses a hook $\hat z_t = z_\text{fwd}+(z_\text{bwd}-\mathrm{sg}(z_\text{bwd}))$ at $t=3$ on four native near-zero tokens per model, in exact FP32 (and BF16), with FP64 norm accumulation to avoid the very overflow under study.

**Continual pretraining (Sec. 5.1, App. D).** FineWeb-2 Telugu (`tel_Telu`) on `nvidia/NVIDIA-Nemotron-3-Nano-4B-BF16` and Mongolian (`khk_Cyrl`) on `tiiuae/Falcon-H1-1.5B-Base`, 1,000 steps × 16,384 tok/step (32 packed sequences of 512), fused AdamW ($\beta_1=0.9$, $\beta_2=0.95$, $\lambda=0.1$, cosine, 50-step warmup, peak $\eta=2\times10^{-5}$), FP32 master weights + BF16 autocast on H100 80 GB, 3 seeds with a **shared deterministic document shuffle** so every method hits the same near-zero token on the same step. Metrics: held-out FineWeb-2 validation chunks, full FLORES-200 devtest (1,012 sentences) in target language and English, and Belebele (900 questions). The 300-step ablation adds Skip-on-Inf, ZClip ($\alpha=0.97$, $z_\text{thresh}=2.5$), GradientStabilizer ($\gamma_1=0.6$, $\gamma_2=0.999$), Freeze $E_\text{in}$, FP64 Global Norm, Mean Re-init, Oracle Mask, and GroupClip FP32/FP64.

**From-scratch pretraining (Sec. 5.2, App. E).** 14 runs on tokenized FineWeb-Edu, $V=50{,}304$ **untied** (padded IDs 50,257–50,303 have zero corpus occurrences — a deliberate source of never-trained rows), Pre-RMSNorm $\epsilon=10^{-5}$, seq len 1,024: Mamba-2 165M (24 layers, $d=768$, 1.05B tokens, 2 seeds for SiLU base and GateFloor $\delta=0.1$, plus paired seed-0 runs for Sigmoid and $\delta\in\{0.01,0.03,0.3\}$), a 16-layer 3:1 hybrid 203M ($K=3$), and a 20-layer 3:1 hybrid 370M ($d=1024$, 1.57B tokens, 8×H100). GateFloor is applied inside `MambaRMSNormGated` after the CUDA `causal_conv1d` and Triton `mamba_chunk_scan_combined` kernels, adding zero parameters.

## Results & Highlights

- **Census prevalence and its clean tying split.** Across 291 repos (280 distinct tables), reachable near-zero input rows ($\|e_v\|_2<10^{-6}$) occur in **20/38 untied gated/hybrid checkpoints (52.6%)** and **47/152 untied Transformers (30.9%)**, but **0/101 weight-tied checkpoints (0%; 0/80 Transformers, 0/21 gated)** — a 52.6-point gap that is the paper's headline correlational fact. Overall 67/291 (23.0%) repos are affected. Named victims include Nemotron-3-Nano-4B, Falcon-H1-1.5B/7B/34B, Mamba-Codestral-7B, Kimi-Linear-48B-Base, Granite-4.0-H-1B, Zamba2-1.2B, Bamba-9B-v2; the tokens are ordinary strings — Telugu and Basque subwords, Cyrillic Mongolian words, CRLF code fragments (`});\r`), chat tags (`<|im_user|>`, `<|im_end|>`), and `<s>`.
- **Gradient amplification at $r=10^{-30}$, mid-sequence, versus Transformer controls.** $\|\nabla_{e_t}L\|_\infty$ reaches **$2.1\times10^{35}$ on Nemotron-3-Nano-4B** (median over 4 probes $1.71\times10^{35}$; $4.5\times10^{34}$ in the sweep, $2.1\times10^{35}$ on native tokens), **$1.0\times10^{32}$ on xLSTM-7B** (slope −1.07), **$1.3\times10^{30}$ on pure-gated Falcon-Mamba-7B**, while the $K=0$ controls stay flat at **56–98 on Llama-3.1-8B** and **8.5 on RWKV-4-1.5B** — i.e. a gap of ~30–35 orders of magnitude against the same rescaling intervention. Finite-$K$ hybrids sit in between and saturate at $\Theta(G_K)$ ceilings: $2.3\times10^{2}$ (Bamba-9B-v2, $K=9$), $2.8\times10^{12}$ (Jamba-Reasoning-3B, $K=7$), $2.5\times10^{15}$ (Zamba2-1.2B, $K=5$), $2.2\times10^{16}$ (Granite-4.0-H-1B, $K=5$), and parallel-hybrid Falcon-H1-1.5B bounded near $3.5\times10^{6}$ ($\propto\epsilon^{-1}$).
- **Causal gate-patching proves the mechanism is forward readout, not backward path severing.** On Nemotron-3-Nano-4B, detaching Layer 0's gate backward alone (`l0_orig_cut`) leaves $\|h_t^{(1)}\|_2=2.05\times10^{-32}\ll\sqrt{\epsilon d}=0.177$ and $\|\nabla_{e_t}L\|_\infty=1.74\times10^{31}$; opening **only** Layer 0's forward gate straight-through while keeping every backward derivative (`l0_norm_keep_st`) lifts $\|h_t^{(1)}\|_2$ to 0.607 and cuts the gradient to **6.71 (from $2.12\times10^{35}$)** — a 34-order drop, with 0.77 across all 21 Mamba gates. On Falcon-H1-1.5B the same contrast is $4.75\times10^{6}\rightarrow1.41\times10^{3}$ (forward patch) versus $1.34\times10^{4}$ (backward cut only).
- **FP32 clipping zeroes the batch in all three default frameworks.** With $G_\text{emb}=1.7\times10^{20}$ on Falcon-H1-1.5B, PyTorch `clip_grad_norm_`, HuggingFace Trainer and FSDP2 all log `grad_norm=inf` and apply $\|\Delta\theta_\text{grad}\|_\infty=0$ with no exception and finite forward activations; the post-AdamW decomposition confirms $\|\delta\theta_\text{other}^\text{batch}\|_2=0.0$ and **0 of 3,562,515,040 FP32 weights differ by even 1 ULP** from feeding $g_t=0$ (versus 42.6% fresh share and 99.91% weights changed on clean steps).
- **Telugu CPT on Nemotron-3-Nano-4B (1,000 steps, 3 seeds, FLORES-200 PPL ↓).** FP32 Global Clip stalls **198.3±9.9 steps (19.8%)** and reaches **13.44±0.17**; GroupClip (FP64) has **0.0±0.0 stalled steps** and reaches **13.04±0.19**, exactly matching the Oracle Dead-Row Mask (**13.04±0.19**) and matching the baseline's 1,000-step quality by step 800 (~20% faster). All 30.7±0.6 encountered rows self-heal on first contact in a $3.5\times10^{-4}$ step, lifting them from $\le2.3\times10^{-10}$ to median 0.010; spikes $>10^{10}$ occur on only 21.0±1.0 steps with zero repeat overflows.
- **Mongolian CPT on Falcon-H1-1.5B (1,000 steps, 3 seeds).** 96.6% of batches trigger; FP32 Global Clip stalls 11.7±3.5 steps and ends at **15.68±0.11** PPL, whereas GroupClip ends at **15.58±0.10** — beating both the FP32 baseline and the Oracle Mask (**15.63±0.10**) — and lowers step-100 PPL from **40.40 to 37.47**, growing Mongolian subwords from $1.1\times10^{-7}$ to $1.8\times10^{-2}$.
- **300-step ten-method ablation (Nemotron-4B, 57.0±7.5 trigger batches, PPL ↓).** Skip-on-Inf **16.63±0.36** and ZClip **16.57±0.39** stall 57.0±7.5 steps and leave rows unhealed; GradientStabilizer **16.23±0.30** updates the backbone but skips $E_\text{in}$ rescaling on 52.0±8.2 steps, permanently freezing rows via $v_t=\infty$; Freeze $E_\text{in}$ **16.16±0.24** blocks adaptation; FP64 Global Norm **16.09±0.35** heals rows but zeroes fresh-batch backbone updates on 18.0±1.0 first-hit steps; Mean Re-init **15.96±0.24** alters rare-token scores (tail NLL 3.8→9.8); Oracle Mask **15.94±0.26**; GroupClip (FP64) **15.95±0.25** with zero stalls and full row healing. The ordering shows the naive "just skip / just clip in 64-bit" fixes are *worse than the bug* on at least one axis.
- **GateFloor on 370M hybrid (1.57B tokens, FineWeb-Edu).** At $r=10^{-30}$, SiLU base gives **$3.3\times10^{4}$ (mid) / $1.6\times10^{28}$ (pos-0)** gradients; GateFloor $\delta=0.1$ gives **0.16 / 0.13**, i.e. **>28 orders of magnitude** reduction, with validation PPL **22.28 vs 22.45** baseline and throughput **542.8k vs 527.2k tok/s** (no slowdown). Sigmoid gates, the obvious "make the gate positive" fix, cost **+0.21 PPL (22.66)** because they cap the positive output at 1.
- **GateFloor offset sweep on Mamba-2 165M (1.05B tokens).** Mid-sequence $r=10^{-30}$ gradients follow $\propto1/\delta$: $2.8\times10^{28}$ (SiLU base) → **4.14** ($\delta=0.01$) → 1.51 ($\delta=0.03$) → 0.52 ($\delta=0.1$) → 0.29 ($\delta=0.3$), with PPL 30.63 (base) vs 30.67/30.67/30.78/30.82 — i.e. all offsets are within the 0.15 two-seed noise band, so the paper's honest claim is "no detectable PPL cost", not "PPL improved".
- **Post-training trigger rates (128-sequence batch, 8,000 docs/dataset).** English web, English SFT, code and math yield **0.0%**; multilingual workloads hit routinely — Aya SFT 10.6% (Nemotron-4B) to 18.8% (Nemotron-H), Thai CPT 70.5%, Nemotron-3-Nano-4B Telugu **95.4%**, Falcon-H1 Mongolian **100%**, and Kimi-Linear-48B `<|im_user|>` chat SFT **100%**.
- **Overhead.** Median step time 2.88 s (global clip) vs **2.84 s (GroupClip FP64)** vs 2.85 s (copy-free variant); the clip call itself is 18.8 → 21.2 → 20.8 ms; peak memory 69.7 GB in all three cases. The FP64 norm materialises a transient 3.1 GB copy, and the copy-free in-place rescale matches the FP64 result to **2.3×10⁻⁷** max relative difference on an injected $3\times10^{31}$-scale row.
- **Unaffected workflows verified.** Rank-16 LoRA freezes $E_\text{in}$ and skips $\nabla_{E_\text{in}}L$, giving normal adapter gradient norms (3.7–10.3, 0/9 overflows); on-policy RL rollouts sample 0 near-zero tokens out of 16,384 Mongolian/Telugu rollout tokens across four models, though full-parameter RL still triggers on prompts containing near-zero template tags. Belebele at step 1,000: 30.67±0.51% under GroupClip FP64 vs 29.78% zero-shot, with English FLORES-200 NLL within 0.01 nats across clipping methods.

## Authors & Credibility

Six authors, all at Washington University in St. Louis except Boyuan Sun (Nankai University); corresponding emails are `wustl.edu` addresses. This is a single-institution academic group with no visible industry lab backing, and the paper is a diagnostic/systems contribution rather than a new architecture — which fits the resource envelope: the largest training run is 370M parameters on 8×H100, and the largest model *touched* is a 48B checkpoint (read-only auditing, not training). The work is unusually well-instrumented for this genre: FP64 norm accumulation inside the probes, ULP-level verification of the AdamW update decomposition against `torch.optim.AdamW(fused=True)` across all 3.56B backbone parameters on every step, shared per-seed document shuffles so all ten methods see identical tokens on identical steps, and a genuine oracle upper bound (a pre-scanned dead-row mask) rather than a strawman. The appendix is long and concrete (exact LRs, batch packing, kernel names, seed counts), and the scanning scripts plus a CSV of all 291 repos are promised as supplementary material. Weaknesses in credibility are structural, not sloppy: no large-scale pretraining, no author overlap with the Mamba/Nemotron/Falcon teams whose checkpoints are being diagnosed, and no independent replication of the 20% stall rate. The citation base is appropriate and current (Land & Bartolo 2024, Takase et al. 2025, OLMo 2 2025, ZClip 2025, GradientStabilizer ICML 2026), and the paper correctly credits prior work on rare-token under-training rather than claiming to have discovered near-zero embeddings.

## Critical Assessment

**Novelty.** The individual ingredients are known: near-zero/under-trained embeddings (Land & Bartolo 2024; SolidGoldMagikarp), embedding weight decay raising early gradient norms (Takase et al. 2025, which motivated OLMo 2 to drop embedding decay), and gradient-clipping pathologies (ZClip, GradientStabilizer). The genuinely new claim is the *interaction*: zero-at-origin readout factors turn Pre-RMSNorm's $1/\sqrt{\epsilon}$ into a depth-compounding amplifier, and this is architecture-conditional in a way nobody had mapped. The causal gate-patching $2\times2$ (forward readout vs backward derivative) is the strongest original evidence, and the two-regime law with the $G_K$ ceiling is a real (if assumption-laden) contribution. The census is new as an artifact.

**Rigor — where it holds.** The $2\times2$ tied×decay ablation matching Eq. (1) to five significant digits, and the OLMoE audit's −26.3 implied log-decay matching the predicted 26–27, are the kind of quantitative coincidence that is hard to fake. The gate-patching control is exactly the right experiment: naive gate replacement would confound forward restoration with backward severing, and the authors explicitly rule that out (6.71 with all derivatives intact vs $1.74\times10^{31}$ with the backward path cut). The ten-method ablation is honest in a way that costs the authors: ZClip and GradientStabilizer — the two most likely "someone already fixed this" objections — are run with official implementations and hyperparameters, and both are shown to fail on a specific axis ($v_t=\infty$ freezing $E_\text{in}$; FP32 norm overflowing to inf).

**Rigor — where it slips.** (1) *The 52.6% number is a correlation with a confound the paper does not address.* Untied gated checkpoints number only 38, and they are disproportionately recent, non-English-centric, and trained under heterogeneous recipes; the tied group (101) is dominated by older/smaller models (GPT-2, Pythia, Qwen2.5 small, SmolLM2). A model-family fixed effect would be more informative than the raw 52.6% vs 0% split — e.g. Falcon-H1 exists in both tied and untied variants, and only the untied one is flagged, which the paper does not exploit as a natural control even though it is sitting right there in its own repo list. (2) *No Transformer CPT control.* The paper asserts untied Transformers are "safe at $t>0$ or with BOS" on the basis of gradient probes, but never runs the obvious experiment: Telugu CPT on an untied Transformer with the same 47/152-style near-zero rows, showing that the rows stay frozen *without* blowing up. Without it, "Transformers remain unaffected" is a probe-level claim being used to explain a training-level phenomenon. (3) *The 20%-stall headline is a 1,000-step, 4B-parameter result extrapolated by narrative.* The actual damage is 13.44 vs 13.04 FLORES PPL — a 3% gap at 1,000 steps — and the paper's own framing ("silently stall training") implies a much larger cumulative effect at frontier scale than anything measured. The 48B Kimi-Linear appears only in the audit and the $t=0$ gradient probe, never in a CPT run. (4) *The "20% faster" claim rests on a single crossing.* Step 800 is where the GroupClip curve meets the baseline's *final* value, not where the two curves coincide; with 3 seeds and no curve reported past step 1,000, this is a point estimate dressed as a rate. (5) *GateFloor's perplexity claim is a null result reported as a win.* At 165M the two-seed baseline gap is 0.15 PPL and GateFloor's deviations are 0.04–0.19; at 203M and 370M it is single-seed. "Comparable perplexity" here means "the experiment cannot resolve a difference", which is fine but should not be read as evidence of no degradation — and the $\delta$ sweep's monotone PPL drift (30.63 → 30.67 → 30.67 → 30.78 → 30.82) is at least suggestive of a small real cost that a proper seed budget would settle.

**Reproducibility.** Strong on paper: seeds, LR schedules, batch packing, kernel names, clipping hyperparameters for every baseline, and an explicit copy-free variant with its numerical equivalence checked (2.3e-7). The census protocol is specified down to the eight round-trip templates and the mirror-detection statistics. The main reproducibility risk is the census itself: a HuggingFace snapshot from October 2026 with a hand-curated supplementary list is not a fixed benchmark, so the 52.6% figure will drift and cannot be re-derived exactly.

**Significance.** If the mechanism is right — and the gate-patching evidence says it is — this is a real bug affecting a large fraction of the current hybrid-model ecosystem, with a three-line fix that provably costs nothing (2.84 vs 2.88 s, 69.7 GB either way). For practitioners doing multilingual CPT or chat-template SFT on Nemotron-H/Falcon-H1/Kimi-Linear/Mamba-Codestral checkpoints, the 100% batch trigger rate on `<|im_user|>` and Mongolian is alarming and immediately actionable. The GateFloor half is more speculative but still useful as a default-recipe suggestion (positive gate offset + zero embedding decay).

**Red flags.** The paper never reports the *downstream* consequence of frozen rows independent of the clipping stall — i.e. how much of the 0.40 PPL gap is lost batch signal versus permanently untrained Telugu/Basque subwords. The Oracle Mask result (13.04, identical to GroupClip) suggests the rows are recoverable, but the ablation that separates "healed rows" from "unstalled batches" (GroupClip with healing disabled) is missing. Also, $\delta$ changes the model class slightly (the gate can no longer output exactly 0, so state can never be fully erased), and no long-context forgetting or state-tracking evaluation is run — the paper acknowledges only the parameter-count limitation, not this expressivity one. Finally, the interaction with BF16 master weights, FP8 training, and non-AdamW optimizers (Muon, Lion) is untested, even though weight-decay dynamics are precisely the mechanism's driver.

## Strengths

- **The mechanism is proven causally, not inferred.** The forward-gate/backward-derivative $2\times2$ is the single most convincing experiment in the paper: it isolates the exact term ($\phi_\ell(0)=0$) that the theory says matters and shows a 34-order gradient drop with zero backward paths severed.
- **The theory is falsifiable and then falsified-against.** Prop. 1 predicts a specific two-regime shape ($1/r$ then $\Theta(G_K)$); the paper measures slopes of −0.81 to −1.22 across eight checkpoints and reports the $G_K$ ceilings per architecture, including the awkward case (Nemotron-3-Nano-4B follows $1/r$ all the way to $10^{-34}$ because prefix gains lift the norm past $\sqrt{\epsilon d}$ before Layer 12 attention) rather than hiding it.
- **An oracle baseline.** Comparing against a pre-scanned Dead-Row Mask is the right upper bound and rare in this literature; GroupClip matching it exactly (13.04 vs 13.04; 15.95 vs 15.94) is a much stronger statement than beating FP32 clipping.
- **Baselines are run properly, including the ones that embarrass the framing.** ZClip and GradientStabilizer use official implementations and hyperparameters, and the paper reports that GradientStabilizer leaves $v_t=\infty$ and permanently freezes rows — a specific, checkable failure rather than a vague dismissal.
- **The census artifact is reusable.** Byte-range safetensors reads plus a round-trip reachability filter is a cheap protocol anyone can re-run; the CSV of 291 repos with architecture/tying/vocab/near-zero counts is the kind of artifact that outlives the paper.
- **The fix is genuinely free.** 2.84 s vs 2.88 s step time, identical 69.7 GB peak, three lines of code, no vocabulary scan, no architecture change, no re-initialisation — plus a copy-free variant for memory-constrained setups that matches FP64 to 2.3e-7.
- **Honest scoping in the conclusion.** The authors state plainly that GateFloor reaches only 370M with 1–2 seeds while the audit spans up to 48B, rather than blurring the two scales.

## Limitations

- **Scale gap.** Continual pretraining covers 1.5B–4B; from-scratch GateFloor covers 165M–370M with 1–2 seeds. The 48B Kimi-Linear and 56B Nemotron-H appear only in the read-only audit. Nothing here demonstrates behaviour at 7B+ full pretraining, where weight-decay schedules, $\epsilon$ choices and batch sizes all differ.
- **No Transformer CPT control**, so the "Transformers are safe" claim is supported by gradient probes and the $t>0$/BOS argument, not by a training run showing an untied Transformer with near-zero rows learning Telugu normally.
- **Frozen-row vs lost-batch confound is unresolved.** GroupClip both unstalls batches and heals rows; the ablation that would separate these (healing disabled) is absent, so the 0.40 PPL attribution is ambiguous.
- **Statistical power.** 3 seeds for CPT, 1–2 for from-scratch; the PPL differences GateFloor claims to preserve (0.04–0.19) are at or below the measured seed gap (0.15), so the null result is underpowered rather than established.
- **Expressivity cost of GateFloor is unexamined.** $\mathrm{SiLU}(z)+\delta$ with $\delta>0$ means the output gate can never be zero, so state can never be fully erased; no long-context recall, state-tracking, or forgetting benchmark is run to check whether this matters.
- **Optimizer/precision scope.** All experiments use AdamW with decoupled decay in FP32 master weights + BF16 autocast. Muon, Lion, Adafactor, FP8 training, and sharded-optimizer setups (ZeRO-2/3 with per-shard clipping) are untested — yet the mechanism depends entirely on how decay is applied.
- **Census is a moving snapshot.** 313 candidates → 256 readable (gated repos, missing safetensors, >3 GB embedding tensors are excluded), plus hand-curated additions; the 52.6% figure is not exactly reproducible and may be biased toward downloadable, safetensors-native, recent models.
- **Downstream evaluation is thin.** FLORES-200 PPL plus one Belebele number (30.67 vs 29.78 zero-shot); no generation quality, no code/math regression suite, no instruction-following check after chat-template CPT.
- **The 20% figure is corpus-specific.** It is measured on FineWeb-2 Telugu with a 131k vocabulary where 62 rows (0.047%) cover 32.3 ppm of tokens; corpora with different script mixes will differ by orders of magnitude, and the paper's own English/code/math rows are 0.0%.

## Relevance

直接命中 **LLM Training Stability & Observability**：它是一篇"静默失败"的教科书式案例——没有 NaN、没有异常、前向激活有限，但整批梯度被置零、稀有 token 行永久冻结，并且给出了可监控的判据（$1.84\times10^{19}$ 阈值、`grad_norm=inf`、fresh-batch 位移恒为 0、ULP 级权重对比）。同时也落在 **Reliability under Extreme Performance Optimization**：问题根源是 FP32 全局范数裁剪的平方溢出与 weight decay 的数值交互，修复手段（64 位范数 / 免拷贝重缩放）是纯粹的精度工程。对做混合架构（Mamba/xLSTM/Gated DeltaNet）继续预训练或多语言适配的人来说，GroupClip 的三行改动几乎应当默认开启。

## Questions for Further Exploration

1. Does the 52.6% vs 0% tying split survive a family fixed effect? Falcon-H1 ships in both tied and untied variants — running the census within-family would turn the headline correlation into something causal.
2. What fraction of the 0.40 PPL Telugu gap comes from lost batches versus permanently untrained subwords? A GroupClip variant that clips correctly but suppresses the healing update (e.g. zero the $E_\text{in}$ step) would settle it.
3. Would an untied Transformer with the same 47/152-style near-zero rows show any CPT degradation at all, or do the frozen rows genuinely cost nothing when they cannot blow up? This is the missing control that would validate the "architecture-conditional" framing.
4. How does the mechanism interact with Muon/Lion (whose update rules are not scale-invariant in the same way) and with FP8 master weights, where the overflow threshold moves by orders of magnitude?
5. Does $\delta>0$ in GateFloor measurably change long-context behaviour — state-tracking benchmarks, needle-in-a-haystack, or forgetting curves — given that the gate can no longer fully erase state?
6. At what model scale does the $G_K$ ceiling from Prop. 1 stop protecting hybrids? The paper shows Jamba-3B saturating at $2.8\times10^{12}$ and Granite-4.0-H-1B at $2.2\times10^{16}$ — both already past the $1.84\times10^{19}$ neighbourhood only by one to seven orders, so a deeper or wider hybrid could cross it with a different $\epsilon$.
7. Is there a monitoring signal cheaper than the ULP-level decomposition — e.g. tracking the count of $E_\text{in}$ rows below $10^{-6}$ during training, or asserting `grad_norm` is finite before clipping — that a training-observability stack could ship as a default alarm?
