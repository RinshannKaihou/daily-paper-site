Critical Assessment · weaknesses 4–5

01

Method, in four moves

distilled · ~160 words
  1. 01 / HARVEST

    Build the error bank

    Five open models (14B–72B) × two procedural tasks: 4×4 determinants and a custom poly-trig integration-by-parts bank (1,294 problems per model). 18,145 problems graded at temperature 0; wrong answers pass a three-judge pipeline and a magnitude rule. 3,253 experiment-ready cases, four cohorts per cell.

  2. 02 / LOCATE

    Replay and read out

    Each model's own wrong solution is replayed token by token. A logit lens tracks the sign lead — logit(written) minus logit(alternative) — at every layer; the peak is where the sign is committed. Per-layer MLP direct logit attribution splits by the sign actually written.

  3. 03 / TYPE

    Stamp or amplifier

    Same-direction DLA bars mark an amplifier; a fixed minus vote marks a stamp; late pushback marks a judge; Qwen adds a rescue layer. Only the minus sign gets stamped — no model carries a fixed plus stamp.

  4. 04 / INTERVENE

    Pull the lever

    Build d = WU("−") − WU("+"), then subtract it at the habit layers at dose α = 1, 2, 3. Single and five-layer joint ablation, forward and reverse patching, magnitude-matched random directions and control layers as nulls. 29 predictions frozen in git before held-out scoring.

03

The ledger

what holds up · what to discount
+

Strengths

  1. Preregistration with teeth.Numeric bars, denominators and exclusion rules frozen in git before held-out scoring; 23/29 confirmed, every miss kept as a miss.
  2. Cohorts, not anecdotes.3,253 experiment-ready cases, four cohorts per cell, bootstrap CIs, and every effect read against matched random and control-layer nulls.
  3. The lever is tested on correct answers.The specificity matrix turns a flip rate into a claim about what the edit moves — and exposes the models where it is indiscriminate.
  4. A disclosed null.Phi's targeted ablation does not beat random layer sets, and the paper says so while still reporting the result.
  5. Mechanism behind the resistance.Margins, redundant writers, proportional-cut dynamics and a rescue layer explain why the same edit works in one model and not another.
−

Limitations

  1. Answer-token readout only.All causal verdicts are single-token and teacher-forced; free-generation steering could not be scored at scale.
  2. Flips are not repairs.Llama det's 42 flips split into 33 corrective and 9 harmful; a repair-rate metric might reorder the models.
  3. The oracle offset.Every measurement needs the wrong sign's exact character position; no detection-then-steer pipeline is evaluated.
  4. One-sided design.Minus removal only — no model has a fixed plus stamp, so the symmetry of the dissociation is untested.
  5. Narrow, template-like scope.Two procedural tasks and one failure family; the title's “LLM mathematics” is broader than what was tested.

The taxonomy fits cleanly on 3/5 models; Gemma changes role between errors and corrects, and Mistral is indeterminate on errors.
