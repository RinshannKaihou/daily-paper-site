Three self-evolving agents pass every proxy signal — and each breaks at a different stage of turning artifacts into capability.

Key metric
20/20→0/20
Immediate-win states reached → games won

Voyager's full system reached a winning position in every game and converted none. Deleting one skill flipped it to 20/20 wins.

Why this matters

A rising score can hide an agent that has stopped improving — or begun to unlearn. Audit the ratio, not the total.

分数上涨，可能掩盖一个已经停止进步、甚至开始退化的 Agent——要看比值，不要只看总数。

Critical edge

P0 wins 20/20 games at a 48.7% pass rate; OB-1 wins 0/20 at 78.6% — both numbers are reported, but never reconciled with the paper's own checkpoint definition.

The three breaks
one base model · one opponent set · three artifact forms

Reflexion

BREAKS AT P3
Textual memory

Legality rises 49.8% → 83.5%, yet P(pass | legal) falls 16.0% → 12.3%. Across 12 memory × state-set combinations, the legal pass rate improves in none.

A legalization gain, not a selection gain.

Voyager

BREAKS AT P4
Executable skills

459 newly passing states and open fours in 20/20 games — then 0/20 wins. The agent-written dispatcher checks the opponent's win first and returns, so its own winning move is unreachable.

Delete create_open_three → 20/20 wins.

DGM

BREAKS AT P5
Code lineage

OB-3 clears the checkpoint (+522 / −139, 19/20 wins). OB-5 then adds zero passing states and loses 103; wins fall 19 → 9 → 0 while the evolutionary score climbs 347.0 → 357.8.

The optimizer rewards the drift.
Method
DeepSeek-V4-Flash · 15×15 gomoku

Five sequentially dependent properties replace the usual proxy signals. Diagnosis is ordered: the first property that fails is the break point, and nothing downstream is judged.

01Artifact formed and wired into the decision path
02Behavior activated above the measured noise floor
Checkpoint · 3 ∧ 4
03Task relation realized
04Boundary-safe reuse
05Capability extended new gains without losing old ones
State
1,876 replayable positions, each paired with and without the artifact; a rule program enumerates the acceptable set G(s) with no model in the loop.
Game
20 complete games vs a two-ply opponent; every immediate-win state is found and its conversion recorded as k/n.
Lineage
Adjacent code versions compared state by state, plus a 7,234-state pool to test whether a change ever reaches behavior.
P(pass) = P(legal) × P(pass | legal) The paper's portable audit. If legality is also rising, a rising pass rate proves nothing about play.

Strengths / Limitations
read both before citing

Holds up what to trust

  • An ordered, falsifiable definition with a named checkpoint — “which property broke” becomes an answer, not a score.
  • P(pass) = P(legal) × P(pass | legal) is a small audit any agent benchmark can adopt immediately.
  • Each break is localized to a concrete mechanism, then confirmed by intervention — 0/20 → 20/20 is rare evidence.
  • Rule-only ground truth. No LLM judge anywhere in the diagnosis loop.
  • Appendices argue against the authors' own framing, including the score/diagnosis mismatch they report themselves.

Doesn't hold what to discount

  • One game, one base model, one evolution run per mechanism. The drift claims are n=1.
  • The method needs G(s) to be enumerable — exactly what open-ended agent tasks lack.
  • Reflexion has no retrieval or filtering; the break may belong to the memory interface, not to reflection.
  • Single sample per state at T=0.2, correlated states within games, 12 uncorrected comparisons.
  • No code or artifacts released; all three mechanisms are bespoke re-implementations.
Open questions
the experiments this paper invites
Q1

Would a state-conditioned retrieval Reflexion — 1–2 of 7 memories per state — show a selection gain, or does legalization survive better memory?

Q2

How variable is DGM's post-checkpoint drift across independent seeds: a property of the objective, or a lineage-level accident?

Q3

Can the framework run where G(s) cannot be enumerated — partial rule checkers, GUI state assertions, verified rubrics?

Q4

What if DGM retained on the rule-judged pass rate instead of the composite score — does the lineage stop drifting, and does it then beat P0?
