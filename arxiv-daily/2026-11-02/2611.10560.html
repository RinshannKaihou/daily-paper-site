01 / Methodology

How the bound survives the swap

Replace the normalizer with a learned periodic map whose radius is fixed and whose phase still tracks magnitude.

5 scales
matched seeds

x→ Φ = cos / sin(xWp+b)→ WQ / WK→ RoPE→ softmax ‖Φ‖ = √m
  • Swap, don't stack. QK-MAP (Magnitude-Aware Projection) sets Φ(x) = [cos(xWp+b); sin(xWp+b)] with m = D/2, one map shared by Q and K; then q = Φ(x)W_Q, k = Φ(x)W_K. Values stay raw, RoPE is applied after projection.
  • Pin the norm, keep the derivative. ‖Φ(x)‖₂ = √m exactly, so |s_ij| ≤ (m/√d_h)‖A_Q‖‖A_K‖ for any input scale, while ∂Φ(ru)/∂r = ‖uWp‖₂ does not grow with r.
  • Default variant. QK-MAP-R adds a per-dimension residual Diag(α)x, with α initialized at zero so training starts at the pure periodic map.
  • Five sizes, one recipe. 190M / 370M / 760M / 1B / 7B on 2B / 4B / 8B / 10B / 20B tokens, with matched backbone, data order, batch (2.1M tokens) and seeds. The FFN is narrowed (7B: 11008→10328) to hold parameters within 0.033%.
  • Measure. OLMES zero-shot Avg-8; validation CE averaged over C4, Pile, M2D2-S2ORC and Dolma-6. Probes: norm shuffling, first-key attention, evidence SNR and word→AAA corruption.

03 / Strengths

What holds up

  • A reusable decomposition. Query norm as a row-wise inverse temperature, key norm as column-wise salience — useful even if you never adopt QK-MAP.
  • A bound you can check. Prop. A.3 caps logits at (m/√d_h)‖A_Q‖‖A_K‖ regardless of input norm; finite-ε QK-Norm decays as O(r⁻³).
  • Causal, not correlational. The norm-shuffling probe holds directions and the norm multiset fixed, then permutes only the assignment.
  • Real pretraining, five scales. 7B/20B tokens with matched data order and seeds, plus a 16-checkpoint sweep against endpoint luck.
  • Unusual disclosure. Code, configs and probe scripts are released; Appendix G.2 admits the word-replacement result undercuts a robustness reading.

04 / Limitations

Where it breaks

  • Stability is never measured. No spikes, logit traces, entropy curves, gradient norms or divergence counts — and Standard never diverged, so the stress regime is absent.
  • One seed per scale. Avg-8 has no error bars; COPA N=100 and ARC-Challenge N=299 put the +0.89 margin inside task-level noise.
  • The closest baseline is missing. QUEST, which keeps query-dependent temperature, never appears in Table 1's CE or Avg-8.
  • Parameter matching is one-directional. The FFN is narrowed to pay for the map; the unmatched direct map beats the matched residual at 370M and 760M, and there is no Standard-with-wide-FFN control.
  • Long context is proxy-only. No RULER/LongBench/NoLiMa, and no latency, FLOP or memory accounting for the extra D×D/2 matmul plus sin/cos.

05 / Open questions

What would settle it

5 prompts

  1. Does QK-MAP prevent loss spikes at high LR, small batch, or in an MoE — the settings QK-Norm was adopted for?
  2. Why does the advantage invert at 190M and 760M? Would two or three seeds per scale settle it?
  3. What if the phase branch is added to QK-Norm instead of replacing it — does magnitude still help?
  1. Do the learned radial frequencies spread, collapse, or drift after training?
  2. What is the wall-clock and memory cost per token at 7B, and does it change the throughput-per-loss comparison?
