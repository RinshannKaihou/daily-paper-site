> **一句话总结：** 作者在部分可观测 5×5 Grid 和 WebShop 上用线性探针从 Qwen2.5-7B/32B-Instruct 与 GPT-OSS-20B 的中间隐状态中稳定解码出候选动作的前瞻价值（Grid 状态图 cell 准确率 98.2%、WebShop 成对排序约 80%），却发现策略仍在 34.2%–58.3% 的 Grid 决策点上选了探针判定为更差的动作；据此提出 Natural Value Transport（NVT）——用"价值差 → 隐状态差"的线性映射作为执行器，闭环注入后把 Grid 成功率从 0.140 提到 0.300、WebShop 奖励从 0.358 提到 0.452。

> **TL;DR:** Across a partially observed 5×5 Grid (1,400 maps) and WebShop (1,502 tasks), linear probes recover prospective action value from the hidden states of Qwen2.5-7B-Instruct, Qwen2.5-32B-Instruct and GPT-OSS-20B better than strong task heuristics — 98.20% cell / 79.73% exact-map accuracy on the Grid state map vs 60.69% / 0.00% for a positional-majority baseline, and ~80% pairwise ranking on WebShop vs 72.4–74.9% for TF-IDF — yet the policy still picks the readout's disfavored action in 58.3% / 37.5% / 34.2% of Grid states and 43.9% / 39.8% / 39.8% of WebShop states where the probe is correct. A learned linear value→activation transport (NVT) steers better than probe-direction edits, raising Grid success from 0.140 to 0.300 (Qwen2.5-7B) and WebShop reward from 0.358 to 0.452 (Qwen2.5-32B), though on filtered task subsets and with per-model hand-tuned layers and strengths.

## 核心贡献

- **提出"价值–策略解离"（value–policy dissociation）这一失败模式**：把 agent 的坏决策拆成"没表征"与"表征了但没用"两种情况，并用联合交叉表证明后者占主导——Grid 中"策略错但探针对"的比例为 34.2%–58.3%，反向仅 0.1%–1.8%。
- **把机制可解释性的分析对象从"世界状态"推进到"候选动作的前瞻价值"**：先前工作（Othello 棋盘、空间地图、cognitive map）只解释模型知道什么，本文解释模型如何评估"这一步之后会怎样"。
- **构造了两种互补的价值目标**：Grid 用当前已观测地图上的最短路距离（无噪声、可精确计算），WebShop 用 40 条同策略采样的经验延续回报（有噪声、策略相关），避免把结论绑死在单一价值定义上。
- **提出 Natural Value Transport（NVT）**：不直接沿探针方向扰动，而是用自然反事实对（同一状态下一个格子标记为障碍/空地，或两个候选动作的价值差）拟合"价值坐标变化 → 隐状态变化"的线性算子，再把该算子当执行器使用。
- **用因果干预区分"可解码"与"可控制"**：探针方向（Probe calibrated）几乎不改变策略偏好，NVT 在较晚层形成稳定响应，而同范数的 Probe、Shuffled NVT、Random 三个控制都复现不出该模式——说明起作用的是方向而非扰动幅度。
- **闭环验证行为收益**：把价值读出当传感器、NVT 当执行器，在两个环境、三个模型上全部提升任务结果，并顺带报告了无效动作率的变化（含变差的情况）。

## Key Contributions

- **Names and quantifies a distinct agent failure mode.** "Value–policy dissociation" separates *failure to represent* from *failure to use*: on Grid, the policy is wrong while the value probe is right on 34.2%–58.3% of decision states, versus only 0.1%–1.8% in the opposite cell of the cross-tabulation. This reframes looping and suboptimal action selection as a readout-to-policy translation problem rather than a world-modeling deficit.
- **Moves mechanistic analysis from world state to prospective action value.** Prior MI work on sequence models decodes board state, spatial layout, or a cognitive map. This paper decodes the *relative value of candidate actions*, which is the quantity that actually enters a decision.
- **Two deliberately mismatched value constructs.** Grid uses an exact, environment-derived shortest-path value on the agent's observed map; WebShop uses a Monte-Carlo estimate from 40 sampled on-policy continuations. The authors argue the two are complementary operationalizations rather than two different notions of value, and show the same qualitative dissociation in both.
- **Natural Value Transport (NVT).** Instead of steering along the probe's readout direction, NVT fits a ridge-regularized linear map `B_ℓ` from value-coordinate differences to hidden-state differences using naturally occurring counterfactual pairs, then applies `d_ℓ = B_ℓ δv` at inference. The map is low-capacity (D_ℓ × k, k = 4 on Grid, k = 1 on WebShop) and fitted only on training data.
- **Causal separation of decodability from controllability.** A calibrated probe edit changes decoded value but barely moves the policy; NVT produces a coherent late-layer dose-response in steering slope. Norm-matched probe, shuffled NVT and random directions control for perturbation magnitude, isolating direction as the causal factor.
- **Closed-loop behavioral validation.** Value readout as sensor plus NVT as actuator improves success/reward on all three models in both environments, with flip rates of 16.5%–55.1% showing the intervention actually changes selected actions during interaction rather than only shifting logit margins.

## Methodology

**Setup.** The agent is modeled as a POMDP: at step `t` the model sees observation plus interaction history, forms hidden state `h_ℓ(s_t)` at layer `ℓ`, and induces `π(a | s_t)`. Two environments: (1) **Grid** — 5×5 partially observed navigation, 1,400 maps split 1,200/100/100 train/val/test, four movement actions, only the four adjacent cells visible, previously seen cells retained in an explicit prompt-rendered memory, success if the goal is reached within 24 steps; (2) **WebShop** — 1,502 simulated shopping tasks, native search-and-click protocol, max 15 steps, terminal reward in [0,1] based on attribute match.

**Models.** Qwen2.5-7B-Instruct, Qwen2.5-32B-Instruct, GPT-OSS-20B (native reasoning effort set to *low*). All activations are taken from the *input decision prompt*, before any reasoning or action tokens are generated — final prompt token for Grid, mean over the candidate's token span in the "Allowed click targets" list for WebShop. No chain-of-thought is elicited.

**Value targets.** Grid: `V(s,a) = −d_{M(s)}(s_a, g)`, the shortest-path distance to the goal on the *currently observed* partial map, with unrevealed cells treated as free. Out-of-bound actions are excluded. The probe is a linear map `V̂_ℓ(s) = W_ℓ h_ℓ(s) + b_ℓ` with four outputs, trained to rank the best-value action first. WebShop: `Q^π(s,a) = E[R | s_t = s, a_t = a, π thereafter]`, estimated from 40 sampled continuations; branch states are kept only if they expose ≥2 legal product clicks and the greedy action is itself a valid click. The probe is a *pairwise ranking classifier* on `Δh_ℓ = h_ℓ(s,a_i) − h_ℓ(s,a_j)`, not a regressor on absolute value — an explicit choice to avoid assuming the model estimates exact values.

**Baselines.** Manhattan distance for Grid (ignores obstacles, so it misranks when a detour is required) and TF-IDF lexical similarity to the instruction for WebShop (a genuinely strong baseline for shopping, where attribute matching is most of the task).

**Interventions.** All methods produce an edit `d_ℓ` scaled by `α`. Three constructions: *Probe (calibrated)* — minimum-norm least-squares push along the probe's readout direction, `d = W_ℓᵀ(W_ℓW_ℓᵀ)†δv` (Grid) or the projection of the NVT edit onto the pairwise probe direction (WebShop); *NVT* — `d_ℓ = B_ℓ δv` where `B_ℓ = argmin_B Σ w_i ‖Δh_{ℓ,i} − BΔv_i‖² + λ_B‖B‖²_F`; *controls* — Probe (same-norm), Shuffled NVT (value–activation pairs permuted at fit time on Grid, hidden coordinates permuted after fit on WebShop), and Random (isotropic Gaussian, norm-matched). Grid training pairs come from flipping one cell between obstacle and free while holding everything else fixed; WebShop pairs come from two candidate clicks at the same branch state.

**Measurement.** Policy response is summarized by the *steering slope*: OLS fit of `Δm_{ℓ,i}(α) = log π_{ℓ,α}(a⁺|s) − log π_{ℓ,α}(a⁻|s)` against `α ∈ {0,1,2,4,8,16}`. Closed-loop evaluation steers every decision along held-out trajectories; WebShop uses five task-disjoint folds, fitting readout and NVT on four folds and calibrating only on training data. Per-model sensor layer, actuator layer and `α` are listed in Appendix Table 7 (e.g. Grid Qwen2.5-7B: sensor 19, actuator 21, α = 12.5; Grid GPT-OSS-20B: sensor 17, actuator 20, α = 4).

**Compute.** Four NVIDIA H100 GPUs, ~200 GPU-hours total.

## Results & Highlights

- **The value probe beats the strong heuristic on both environments.** On Grid, held-out top-1 action-ranking accuracy exceeds the 91.4% Manhattan baseline (Fig. 2a) and the advantage concentrates exactly on *detour cells*, where obstacles make shortest-path distance diverge from Manhattan distance — evidence the readout is not just re-deriving a geometric shortcut. On WebShop, the pairwise readout reaches ~80% ranking accuracy against TF-IDF baselines of 72.4% (Qwen2.5-7B), 74.9% (GPT-OSS-20B) and 74.6% (Qwen2.5-32B), i.e. roughly +5 to +8 points over a baseline that already encodes most of the task's lexical structure.
- **State information is richly present, so the failure is not a world-modeling deficit.** The F/O/U map probe recovers the observed Grid map at 98.20% cell accuracy and 79.73% exact-map accuracy for Qwen2.5-7B (97.89% / 79.02% for Qwen2.5-32B, 96.28% / 72.18% for GPT-OSS-20B), against a positional-majority baseline of 60.69% / 60.69% / 61.46% cell accuracy and **0.00% exact-map accuracy** in all three cases. A global 25-cell distance-field readout likewise tracks the obstacle-aware distance field with MAE ≈ 0.07 on the example state in Fig. 5.
- **The dissociation is large and strongly asymmetric (Table 2).** Grid, policy-wrong-but-probe-correct: **58.3%** (Qwen2.5-7B), **37.5%** (GPT-OSS-20B), **34.2%** (Qwen2.5-32B), versus probe-wrong-but-policy-correct of only **1.8% / 0.1% / 0.2%**. WebShop: **43.9% / 39.8% / 39.8%** versus **8.3% / 12.7% / 10.3%**. The near-emptiness of the off-diagonal cell rules out "the probe is just noisy" as the explanation.
- **Probe-direction steering does not move the policy; NVT does.** In Fig. 3, Probe (calibrated) stays near zero slope across nearly all layers in both tasks, while NVT shows a coherent positive late-layer band (e.g. peak near layer 21 for Grid Qwen2.5-7B, layer 15 for WebShop GPT-OSS-20B, layer 51 for WebShop Qwen2.5-32B). Shuffled NVT and Random do not reproduce the band, so the effect is not magnitude-driven.
- **Closed-loop steering improves outcomes on all six model–environment pairs (Table 3).** Grid success: 0.140 → 0.300 (+16.0 pts, Qwen2.5-7B), 0.580 → 0.640 (GPT-OSS-20B), 0.590 → 0.680 (Qwen2.5-32B); Grid loop rate falls 85.0% → 64.0%, 43.0% → 38.0%, 41.0% → 32.0%. WebShop reward: 0.473 → 0.501 (7B), 0.417 → 0.458 (GPT-OSS-20B), **0.358 → 0.452** (32B, +0.094). Flip rates of 16.5%–55.1% confirm actions actually change mid-episode.
- **Loop-breaking is not the mechanism in WebShop.** WebShop loop rates barely move (7.2% → 6.1%; 15.5% → 14.9%; 2.0% → 1.8%) even where reward gains are largest, so the improvement comes from better product choices rather than from suppressing repetition.
- **Robustness is mixed but reported honestly (Table 4).** Invalid-action rate improves for WebShop Qwen2.5-32B (9.7% → 6.2%) and is unchanged for two Grid models, but *worsens* for WebShop Qwen2.5-7B (0.0% → 1.0%) and GPT-OSS-20B (0.1% → 0.4%), and introduces a 0.17% unparseable-move rate on Grid 7B.
- **The scale inversion is real and not a budget artifact.** Zero-shot, Qwen2.5-32B scores 0.293 WebShop reward versus 0.509 for the 7B variant (Table 1). Extending the horizon to 30 steps moves 32B only 0.293 → 0.297 while GPT-OSS-20B gains 0.250 → 0.284 and the 7B model stays at 0.517 (Table 6), and 32B's loop rate is unchanged at ~30% — so the gap is not explained by premature step exhaustion.

## Critical Assessment

**Novelty.** The core observation is not entirely new — Okcu et al. (2026), cited here, already combined state probes with inverse-RL value estimates to study a "belief–action gap," and the broader "decodable ≠ used" point has been made for truthfulness and code generation (Li et al., 2023b; Yan and Yao, 2026). What is genuinely new is (a) pushing the analysis down to the level of *candidate actions* rather than beliefs or states, (b) the asymmetry quantification in Table 2, which is a much cleaner piece of evidence than a correlation, and (c) NVT as a fitted value→activation transport rather than a probe-direction push. NVT is a nice idea: it uses the model's own natural counterfactual variation as the training signal, so the steering direction is constrained to lie in the subspace the model actually uses.

**Rigor.** The control design is the strongest part. Same-norm probe, shuffled NVT and random directions each isolate a different confound, and the fact that only NVT produces a coherent late-layer band is persuasive. The WebShop five-fold task-disjoint split with calibration restricted to training data is also better practice than most steering papers manage. The asymmetric cross-tabulation is a genuinely well-designed piece of evidence.

**Weaknesses I would press on in review.**

1. **The Grid value target may be largely readable off the prompt.** The Grid prompt *explicitly lists* the confirmed free and obstacle cells, and the value target is deterministic shortest-path distance on exactly that list. So "the probe decodes prospective value" is partly "the probe decodes a graph-search result over a map that was handed to the model in text." The detour-cell analysis rules out *Manhattan distance* as the shortcut but does not rule out *in-context graph search over the given map* — which is a weaker claim than "the model computes prospective value." A control where the prompt's memory is perturbed inconsistently with the visual feedback (so the map must be reconstructed rather than read) would sharpen this considerably, and it is absent.

2. **The headline WebShop number is measured on a filtered subset.** "0.358 → 0.452" is over n = 454 tasks — only trajectories containing at least one multi-product click decision — while Table 1 reports 0.293 zero-shot on all 1,502 tasks for the same model. The subset baseline (0.358) is 22% higher than the full-set baseline (0.293), so the abstract's delta is not comparable to the paper's own zero-shot table. The same slippage appears on Grid, where Qwen2.5-7B is 12.64% in Table 1 but 0.140 in Table 3. Neither is wrong, but a reader skimming the abstract will over-credit the gain.

3. **No cheap non-mechanistic baseline in the closed loop.** Table 3 compares steered vs. unsteered rollouts of the *same* model. There is no comparison against better prompting, self-reflection/re-planning, temperature or sampling changes, majority voting over rollouts, or a step-level Q-value reranker (Zhai et al., 2025, is cited but not compared). Given that the intervention needs white-box access, task-specific labels, and a per-model layer/α search, the practical bar it must clear is "beat a reflection prompt," and that bar is never tested.

4. **Missing closed-loop control condition.** Random / Shuffled NVT are evaluated only in the *steering-slope* analysis (Fig. 3), never in the *behavioral* table. The invalid-action check (Table 4) is not a substitute. Without a norm-matched random-direction rollout, "the learned direction matters" is established mechanistically but not behaviorally.

5. **Hyperparameters look hand-picked and are not ablated.** Table 7 shows α = 12.5 for five of six settings but α = 4 for Grid GPT-OSS-20B, and sensor/actuator layers ranging from 15 to 51 with no stated selection rule (validation? sweep? the text says calibration on training data, but layer choice is unexplained). No α-sensitivity curve for task outcome is reported, only the slope fit. A 3× difference in α across models invites the suspicion that the intervention is tuned until it works.

6. **Tiny behavioral sample on Grid.** 100 test maps, one greedy rollout each, no confidence intervals in Table 3. The 0.140 → 0.300 jump is 16 episodes out of 100. The WebShop folds are better (n = 454–671) but still single-rollout per task.

7. **The value construct in WebShop is policy-dependent and noisy by construction.** Labels come from 40 continuations at temperature 0.7 under the same model, so the probe's ~80% ceiling is partly label noise, and NVT is fitted on differences of those noisy labels. The paper acknowledges sampling dependence in Limitations but does not quantify label reliability (e.g. split-half agreement of the continuation estimates), which would bound how much of the remaining 20% error is irreducible.

8. **"Closed-loop controller" overstates the mechanism.** The sensor and actuator are applied per decision state with a fixed α; there is no state feedback, no error term, no stability analysis. It is open-loop steering with a per-step readout, not a controller in any control-theoretic sense.

9. **Terminology risk.** "Value–policy dissociation" is close enough to "belief–action gap" that the distinction rests on candidate-action granularity, and the paper does not do the head-to-head comparison that would establish it as a separate phenomenon rather than a re-description.

None of these are fatal — the central empirical claim (asymmetric dissociation, replicated across three models and two environments) survives them. But the *practical* claim ("a mechanism for improving agent behavior") is the weakest-supported part, and it is the part the abstract leads with after the diagnosis.

## Strengths

- The asymmetric cross-tabulation in Table 2 is a genuinely elegant design: one 2×2 table per model per environment, and the near-empty off-diagonal cell does most of the argumentative work. Hard to explain away as probe noise.
- The control suite is better than typical for activation-steering work — three distinct norm-matched controls, each targeting a different confound (direction vs. magnitude vs. generic perturbation).
- NVT is a well-motivated construction: fitting the transport on *natural* counterfactual pairs means the edit direction is, by construction, one the model itself produces when value changes, rather than an arbitrary probe normal.
- Two environments chosen for complementary value semantics (exact planning value vs. sampled on-policy return) rather than for convenience, and the appendix explicitly justifies why different constructs are appropriate (A.3) instead of papering over the difference.
- Reporting the *negative* robustness result — invalid actions rising from 0.0% to 1.0% for WebShop Qwen2.5-7B — is the kind of honesty that is still rare.
- Full prompts, interaction transcripts, per-model hyperparameter table, and compute budget in the appendix make the work unusually auditable for an MI paper.
- The 30-step budget experiment (Table 6) pre-empts the obvious "they just ran out of steps" objection to the 32B < 7B inversion, and the answer is clean: more steps do not close the gap.

## Limitations

- **Two environments, three models, two families.** Grid is a 5×5 toy with a 4-action space and a prompt-rendered map; WebShop is a single simulated shopping site with a fixed 15-step budget. Generalization to other architectures (tool-use agents, computer-use agents, multi-agent setups) is asserted as future work, not tested.
- **Task-specific value definitions.** Grid's target depends on an oracle shortest path over the observed map; WebShop's depends on 40 sampled continuations of the same policy. Neither exhausts "value," and the WebShop estimate is both sampling- and policy-dependent, so the probe is partly predicting its own model's behavior rather than a ground-truth return.
- **Click actions only in WebShop.** Search actions are excluded because the query space cannot be enumerated, which removes what is arguably the harder half of the shopping task (formulating a good query) from the analysis.
- **Linear readouts and a linear transport operator only.** The causal effects support the dissociation claim, but linearity is an assumption, not a result — a nonlinear probe might decode more (weakening the "represented but unused" gap) or a nonlinear transport might steer better.
- **White-box requirement.** Steering needs internal activations plus task-specific data to fit both the readout and the transport, which rules out closed-source models and any setting without in-domain supervision.
- **No released code link yet**, despite the claim in the footnote, and no reported seeds or variance for the behavioral tables.

## Relevance

直接命中 **LLM Hidden States & Interpretability**：用线性探针 + 因果干预研究 agent 决策时隐状态里"前瞻价值"的编码与使用，正是"表征了几何/结构，但表征是否进入计算"这一核心问题在 agent 场景下的延伸。同时与 **Agent & Pipeline Silent Failures** 有强关联——它描述的是一种"静默失败"：模型内部算对了、输出却错了，且从行为轨迹上完全看不出来（只能靠探针发现），这对构建可靠的 agent 监控/诊断信号有直接借鉴价值。

## Questions for Further Exploration

1. If the Grid prompt's spatial memory were withheld or made inconsistent with the visual feedback, would the probe's advantage over Manhattan survive? This is the single experiment that would separate "computes prospective value" from "reads the given map and does graph search in context."
2. What happens with a nonlinear probe or a nonlinear transport operator — does the dissociation widen (more value decodable) or narrow (more of it becomes steerable)?
3. Does the policy-wrong/probe-correct rate predict downstream task failure at the trajectory level, or only at the decision level? A per-trajectory correlation would turn the probe into an actionable early-warning signal.
4. How does NVT compare against simply reranking the top-k actions by the probe's value and forcing the argmax? The paper deliberately avoids teacher-forcing, but that is the obvious cheap baseline and its absence is conspicuous.
5. Is the late-layer policy-responsive band stable across prompts and random seeds, or is it an artifact of the specific layer chosen per model in Table 7?
6. Does the same dissociation appear in models trained with RL post-training (where value is explicitly optimized), or is it specific to instruction-tuned models that never had a value head?
7. Can the readout be trained without task-specific value labels — e.g. from outcome supervision on a small set of rollouts — which would make the sensor side far more practical?
