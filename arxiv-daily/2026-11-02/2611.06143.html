Mechanism

Three offline fixes · zero inference operators

SPQ in one pass

SPQ treats W4A8 quantization as a grounding problem: calibrate toward the directions concept scores actually use, then correct the memory interface in closed form.

A

Semantic-anchor calibration

A frozen concept codebook scores 1,024 unlabeled SA-1B images; concept-score Gauss–Newton curvature reweights weight rounding.

LA = ‖WX − ŴX̂‖²F + α Δwᵀ Hsem Δw
B

Orthogonal subspace rectification

A feature penalty on error projected into the low-variance residual basis; k/D = 0.50, frozen before evaluation.

LB = (1/Nr) ‖(F − F̂)Ures‖²F
C

Temporal distribution alignment

Paired FP16/quantized rollouts estimate the memory-bank mean shift, folded into the next affine bias — key and value separately.

Recipe — encoder W4A8 · decoder, queries, memory W8A8 · text encoder, heads FP16. Calibration: 1,024 SA-1B images, α 0.1, λ 1, 2,000 updates per block. With only 32 images: 70.2 RefCOCO Pr@0.5.

03

Balance

What holds · what doesn't

Strengths 优势

  • A clean double dissociation. Matched-rank, matched-norm interventions that discriminate between hypotheses — rare in PTQ papers.
  • A useful reframing. “Plausible mask, wrong object” is invisible to AP and generalizes to prompt-conditioned models.
  • Zero overhead, verified. At W8A8, footprint and latency match PTQ4SAM exactly.
  • Protocol discipline. Five adapted baselines, one checkpoint, one calibration set, a complete 2³ factorial.
  • Honest diagnostics. 48.2% codebook overlap and a 70.6 leave-concept-out score are reported, not buried.

Limitations 局限

  • One checkpoint, one architecture. CLIP ViT-B/16 is the only transfer check.
  • Aggressive bits stop at the encoder. Video memory — the dominant deployment cost — stays W8A8.
  • Single seed, no confidence intervals. 0.2–0.4 points of variation is as large as the AP margin over CAR-SAM and Mix-QSAM3.
  • Design C is first-order only. A mean fix for a problem the paper describes as accumulation.
  • No code release; the codebook prompt and dedup pipeline are described only in prose.
04

Open questions

What would change the verdict
  1. Which module causes the 33-point drop? A per-module sweep would separate brittle grounding from a brittle baseline.
  2. Does TDA survive an honest memory baseline? Keep memory FP16, or add per-channel scales, and see what remains of +19.1 J&F.
  3. What is the total cost of ownership? Calibration wall-clock, peak memory and JVP FLOPs against a short QAT run.
  4. Is A redundant given B? The factorial is sub-additive: +11.7 and +34.8 alone, +41.4 together.
  5. Does the effect reproduce beyond SAM 3? SAM 2, non-text prompts, compositional and negated prompts are untested.
