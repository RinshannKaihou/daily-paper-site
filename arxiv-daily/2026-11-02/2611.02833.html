Build a hard benchmark, then teach the harness to catch itself

Distilled from 60 papers and 3,376 judging outcomes.

The benchmark

60 papers become 59 executable tasks across classical simulation (20), quantum algorithms (19) and property characterization (21), each capped near one day of compute. Every task ships two documents: a spec the agent may read, and judge-only criteria with numeric tolerances. A task passes only if every target figure passes.

The agent

A planner turns the task into a dependency graph with per-step budgets. Executors validate on the smallest exactly solvable instance before launching long jobs in the background. A critic checks provenance, method and completeness, routing to pass / local repair / new approach. New approaches spawn three probe agents, then a three-critic majority vote. An independent judge scores the result.

The memory

An experience distiller turns each verified repair into a failure signature, a diagnostic check and a remedy, stored as planner, critic and residual memory. Ten entries from five development tasks; the base model never moves; every update is human-approved.

failed run→ expert fix→ distiller→ 10 memories→ next task

Strengths6 items

What holds up

  • Level I–III taxonomy. Turns a single "X% reproducible" number into an actionable diagnosis, and transfers beyond quantum science.
  • Two-document task design. Agent-visible spec, judge-only criteria — the executor and critic never see the rubric.
  • Harness comparison with the model fixed. Exactly the ablation the field skips, and it produces a 30-point spread.
  • Honest about the gap. Reports 85% against a 93% best, and admits 90% of successes needed a correction.
  • Validated failure labels. 954 findings over 266 failed runs, classified blind at 98.3% agreement.
  • Diagnostic case studies. Paper #2 and #29 are checkable failures, not anecdotes.

Limitations6 items

What to discount

  • One run per task, n=59. No seeds, no variance; differences under three or four tasks are not interpretable.
  • Self-curated, self-judged, self-proposed. The same group builds the benchmark, writes the criteria, supplies the judge and proposes the method.
  • A compute-restricted slice. The one-day budget excludes the deep-learning-heavy work where agentic help would matter most.
  • Human-gated "self-improvement." Ten memories, five adaptation tasks, and no ablation isolating planner vs. critic vs. residual memory.
  • No transfer experiment. The introduction claims gains transfer across models; every RA run uses one model and one harness.
  • Uncalibrated judge, uncounted experts. Human checks cover flagged papers only, and $5.6/task excludes expert time entirely.

Open questions7

What the paper leaves on the table

Ordered roughly by how much each answer would change the conclusion.

  1. Does the same 10-entry memory help a different base model or harness? The introduction claims transfer; no such experiment appears.
  2. What does each memory type contribute? A leave-one-out ablation would separate "experience" from "a better prompt."
  3. How often does the Opus 4.8 judge pass a reproduction a human would fail? A blind re-grade of 30 "successes" would settle it.
  4. What did expert time cost, and does it amortize beyond 54 tasks?
  5. Would the 16/1/1 split replicate on an independently curated quantum benchmark?
  6. Do the +17 points concentrate in one subfield? No per-area breakdown is reported.
  7. Does RA's 24 h/task budget match the baselines' budget, or is it trading wall-clock for success?
