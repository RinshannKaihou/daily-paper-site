01

Three measured errors, three fixes, two kernel tricks

§3–§4 · CuTe-DSL on FA-4
01

Diagnose before quantizing logit-error decomposition

Split the logit error into key and query terms. Under NVFP4 keys the query term carries 60% of the MSE — the usual key-outlier framing misses the main error.

02

Dual-residual query 2 FP4 tensors

q ≈ s⁽¹⁾q̂⁽¹⁾ + s⁽²⁾q̂⁽²⁾, the second term quantizing the first’s rounding residual. Query share falls to 1.2%; the residual rides in MMA zero-padding columns, so no extra MMA.

03

Underflow-aware P scaling free + adaptive

Fold c = 8 into the exp2 exponent, then pick max/2 vs max/6 per block. The E4M3 underflow floor drops from 2⁻¹⁰ to 2⁻¹² — 24× lower.

04

Outlier-aware keys 13 s calibration

Per-head static mean, Hadamard rotation, two-candidate block-scale search; leave-one-out KL shows all three are load-bearing (+208% / +74% / +23%).

05

Transposed softmax 1.91× kernel

Compute Sᵀ = K̃Q̃ᵀ so threads own keys; reductions become butterfly shuffles and P is quantized in registers — no extra pass.

06

Stacked query MMA + serving 4% overhead

Both query terms share one FP4 MMA, summed in FP32 inside softmax. Serving keeps 16 sink + 128 recent tokens in BF16, pages the rest as FP4, and uses a device-side slot kernel (95 µs, CUDA-graph safe) behind vLLM.

04

Strengths

What holds up
  • The diagnosis is contrarian and measured. Query-side error, not key outliers, dominates FP4 logits in decoding — shown per term, not asserted.
  • The fix is nearly free. Putting the residual in MMA padding columns is genuine co-design, not a post-hoc kernel patch.
  • Bottleneck analysis done properly. Lowering precision raises arithmetic intensity but hits the same softmax ceiling; removing it then exposes a 10.3% query-MMA cost, which stacking removes.
  • Better evidence than the genre norm. Teacher-forced KL with paired t ≥ 10.2, plus honest omissions: Hy4 latency, SAW-INT4 latency, MXFP4 P-scaling all marked n/a with reasons.
05

Limitations

What to discount
  • Retrieval is under-discussed. MRCR −2.14 and GLM-4.7 −1.02; the paper never analyzes which long-context failure mode remains.
  • The BF16 fallback is unablated. 16 sink + 128 recent tokens in BF16 is small at 128K but large at 4K — no experiment isolates its contribution.
  • MLA is only half-native. Score path FP4, value path dequantized to FP16 with P quantization off; the 770B result is accuracy and memory, not throughput.
  • Narrow calibration and hardware. τ validated only on Qwen3 up to 32K, then reused at 200K and 1M; results depend on B300 / RTX PRO 5000 and a fast-moving CuTe-DSL stack.
06

Questions worth chasing

Selected from 7
  1. How much of the 0.42-point gap is really the BF16 window? Shrink the 128-token recent window to 32 or 0 at 128K and the “native FP4” claim becomes testable.
  2. Why does MRCR degrade more than RULER? A per-position error analysis of the probability tail would say more than another average.
  3. Does dual-residual saturate at two terms? 60% → 1.2% is a big first step; the marginal return of a third term (at 3G-wide MMA) is unmeasured.
  4. What exactly breaks DAPO under vanilla NVFP4? The curves diverge, but gradient bias vs stale-KV importance distortion vs long-tail tokens is never separated.
