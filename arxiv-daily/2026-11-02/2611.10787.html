Why this matters

Self-improving agents accept updates on noisy validation scores; this turns that gate into a statistically controlled decision instead of a coin flip.

Critical edge

The ε = 0.10 tolerance is a 10-point score drop: updates that lose up to 10 pp are “tolerated but not improving” and never count toward FERε — a regime most practitioners would consider unacceptable.

Methodology

The gate is the algorithm

A fixed proposer emits one atomic harness edit per round — a reasoning rule, a routing mode, a memory entry, a workflow step. TRUST decides whether it survives, and the decision reshapes the next proposal.

  1. 01
    Propose

    One atomic operator per round. Solver role, output contract and single-call protocol are frozen, so the gate — not harness expressiveness — is the variable.

  2. 02
    Test

    Noninferiority: H₀: Δ ≤ −ε. An e-value multiplies betting factors on rescaled scores; accept at the first draw where M ≥ 1/α_t.

  3. 03
    Allocate

    α_t = min{α_max, ρ_t B_t (R_{t−1}+1)} from a shared budget B₁ = q. An LLM reads round history and picks a spend multiplier w_t inside fixed bounds.

  4. 04
    Absorb reuse

    The same 200-example pool is resampled, so the null boundary is inflated by ζβ, where ζ is the exposure probability of an already-seen item.

Why it stays honest: α_t, ρ_t and w_t are pinned before the round’s samples are seen. Because the FER bound holds for any α_t sequence, a wrong LLM judgment costs power, not validity. Defaults: q = 0.30, ε = 0.10, β = 0.01.

Strengths

What to take from it

  • Right relaxation. FDR-style control over accepted updates, not per-round FWER — the choice that keeps a gate usable at n = 40.
  • Clean separation of concerns. Validity holds for any α_t, so the LLM allocator can only cost power, never correctness.
  • Proofs handle the usual fudges. Allocation pinned before validation, arbitrary stopping times, betting-fraction mixture removes a tuning knob.
  • ε is structural, not cosmetic. At ε = 0 the admissible betting range is empty, so power consistency is impossible.
  • Appendix I is exemplary. The authors run the failure mode on purpose and publish it.

Limitations

Where it does not reach

  • Asymptotic theory, small-sample tests. N = 200, n = 40 gives n/N = 0.2; Theorems 3–4 assume n/N → 0.
  • β is hand-set and dominant. 0 → 0.01 → 0.03 → 0.05 moves gain 10.97 → 11.58 → 7.13 → 2.80 pp.
  • The tolerance is a 10-point drop. FERε ignores losses inside [−ε, 0].
  • Proportion, not magnitude. One catastrophic update can pass while FER stays under q.
  • Narrow base. Two Flash-tier models, 2018–2021 benchmarks, no code, no token-cost accounting.

Read with care

Red flags, ranked

  1. 01
    Strawman baselines.SGM-B never accepts a single update in 30 rounds × 5 seeds (0.00 ± 0.00 on every metric); SGM-H fires 3 times total. Only PACE is a real competitor.
  2. 02
    The LLM allocator is unproven.+1.13 pp with overlapping error bars, backed by a single-seed case study — yet it is one of three headline contributions.
  3. 03
    The theorem is never tested as stated.The guarantee is FER₀.₁₀ ≤ 0.30; the experiments report the stricter FER₀. No column checks the bound itself.

Open questions

What would change the verdict

  1. 01Would a tuned SGM still never fire, or is the win the FDR-vs-FWER choice?
  2. 02How fast does the guarantee degrade as n/N grows from 0.05 to 0.5?
  3. 03Can β be estimated from the proposer’s selection step instead of tuned?
  4. 04Does the gate still help when the proposer is strong and most edits are good?
  5. 05What is the worst single update that passes at q = 0.30?
  6. 06How much of the 24.84 pp is harness repair versus capability discovery?
  7. 07Is the allocator worth an extra LLM call per round at scale?
