Why it matters

Self-evolving agents assume experience compounds. This benchmark shows it buys speed, not quality — so long-running research agents need process metrics, not just final scores.

提速可以，提质不行。

Critical edge

One matched run pair for four of five agents and no confidence intervals: outcome gains of −0.9 to +0.4 are indistinguishable from zero given the paper's own measured run-to-run noise.

Critical assessment · rigor

01 Method paired design

A stream is an ordered sequence of tasks that share reusable structure but differ in target, dataset, or sampling process — so the previous solution cannot be resubmitted. The same model, data, budget and private evaluator run twice: stateful (session, files, results, traces carry over) and stateless (fresh session, clean workspace). Only the working state differs, so every comparison is a within-task difference.

05 Strengths

  • A four-tier control ladder that removes the obvious confounds — then follows the evidence against the paper's own headline.
  • The outcome / initialization / time-convergence split is reusable for any agent evaluation, not just this benchmark.
  • Paired within-task design with matched model, data, budget and private evaluator.
  • Anti-gaming hygiene: hidden intermediate scores, post-hoc curves, neutral dataset IDs, private extrapolation splits, arithmetic expression evaluation.
  • Nine families with full generator specs, plus a failure taxonomy grounded in real traces.

06 Limitations

  • One matched run pair for four of five agents; the one repeated condition shows ±7.14 pts of time-convergence noise — larger than two headline gains.
  • Model and scaffold are confounded: Claude Code, Codex and OpenCode each host one model, so "persistence helps Kimi most" is not separable from its harness.
  • A 30-minute task makes part of "efficiency" setup latency; no "copy the previous artifact" baseline isolates code reuse from insight.
  • Reward normalization is monotone but compressive, and cross-family averaging assumes an interval scale the paper never validates.
  • Memory ablation is four tasks on one stream — matched versus shuffled cannot separate relevance from noise.
  • Time-convergence zeroes the pre-first-solution window and flat-carries idle tails, rewarding early finishers twice.
  • Anonymization leaks: memory cards re-identify datasets by channel and row counts.

07 Open questions from the discussion

  1. How much of the gain survives a "copy the previous task's final artifact and adapt" stateless baseline?
  2. Does persistence still help at 2–10 hour budgets, or does the sign eventually flip?
  3. Why does Sonnet 4.6 transfer and Opus 5 not, when Opus scores higher at reset (79.9 vs 70.3)?
  4. What does the tail of selection regret look like beyond the single 41.3-point case?
  5. Would a 20-task stream, not four, change the matched-versus-shuffled conclusion?
