01

How the result is built

A deliberately favourable setting, then a linearization that refuses to cooperate.

  1. 01

    Take the most favourable limit

    Small-step ODE: ẋ = −m/(√v+e) − λx, with exact gradients, constant λ, no bias correction. If it breaks here, the update rule is responsible.

  2. 02

    Solve for the fixed points

    ∇f/(|∇f|+e) + λx = 0 is exactly ∇F = 0 for F = f + eΦλ on ‖x‖∞ ≤ 1/λ. Weight decay acts as an ℓ∞ box with an interior barrier.

  3. 03

    Linearize in (x, m, h)

    The 3×3 Jacobian gives a cubic. Routh–Hurwitz needs F″ > 0 plus a second bound on f″, which flips between a ceiling and a floor as |λx*| grows.

  4. 04

    Break it, then repair it

    Two one-dimensional objectives violate the bounds. Rescaling decay by (|m|+e)/(√v+e) restores a Lyapunov function without moving the equilibria.

Proposed repair Algorithm 1

AdamMe

Same fixed points, different dynamics.

λ · (|m| + e)/(√v + e) · x

  • Multiplier is 1 at every equilibrium, so the fixed-point set and F are unchanged.
  • Explicit Lyapunov function whenever 1−β₂ ≤ 4(1−β₁).
  • Discrete O(1/T) stationarity rate in the implicit objective.

Caveat
That condition excludes Example 4.5 (b = 10 > 4a = 4), the convex case where AdamW fails hardest.

03

What holds, what doesn't

The theory is sharp; the evidence and the practical window are not.

+ Strengths

  • Step-size-independent failure. Cor. A.16 closes the usual escape route: "your learning rate was too high."
  • The diagnosis is exact. F″ > 0 is necessary, and Eq. 8 supplies the missing condition instead of a vague "no proof."
  • AdamMe is minimal. One elementwise factor, identical equilibria, and a real Lyapunov function.
  • The discrete analysis is done properly. Schur–Jury conditions, with the ODE bound recovered as η → 0.
  • Unusual honesty. The authors concede that networks need not converge to be useful.

– Limitations

  • Deterministic only. Exact gradients, constant λ, no bias correction, no noise. Stochastic behaviour is untested.
  • Hand-built, one-dimensional examples. The size of the unstable set in a real landscape is unknown.
  • The practical window is narrow. β₁ < β₂ needs |λx*| ≳ 0.55; real training sits near 0.01–0.1.
  • Prop. 5.2 is existential. It asks for a matrix Q but gives no way to construct or check one.
  • Thin empirical support. One seed, different ε per method, λ at the grid edge, no cautious-decay baseline.
04

Open questions

Four probes that would change how much this result matters.

  1. Q1

    How large is the unstable set? On a real Hessian, is Eq. 8 violated on a measure-zero set or across a non-trivial shell?

  2. Q2

    What does noise do? Does mini-batch noise stabilize the limit cycle, or merely blur it into a noisy orbit?

  3. Q3

    Is the oscillation observable? Can the predicted frequency be detected in loss or grad-norm curves as an early warning?

  4. Q4

    Which mechanism drives the gain? Better dynamics, weaker early decay, or the larger ε? A three-way ablation would settle it.
