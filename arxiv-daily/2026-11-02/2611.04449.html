Key finding / arXiv 2611.04449

Near-zero token embeddings amplify gradients ~30 orders, so clipping silently zeroes whole batches.

Near-Zero Token Embeddings Silently Stall Training in Gated Sequence Models

Xin Liu, Boyuan Sun, Yuxin Wang, Haoran Song, et al. · 2026-11-02 · Washington University in St. Louis / Nankai University

  • Gated sequence models
  • Training stability
  • Numerical precision
  • Gradient clipping

Key metric

52.6%

of untied gated/hybrid checkpoints (20 of 38) carry reachable near-zero input rows. Weight-tied checkpoints: 0 of 101.

67 / 291 repos affected · 23.0% · rows below 1e-6

Why this matters

Multilingual CPT and chat-template SFT on hybrid checkpoints can lose ~20% of steps with no NaN, no exception, and finite activations.

silent failure · invisible to loss curves

Critical edge

The 52.6% headline is a correlation with an unaddressed confound: only 38 untied gated checkpoints — recent, non-English-centric, heterogeneously trained — support it.

paper's own critique · Sec. “Rigor — where it slips”

Mechanism

From a dead row to a dead batch

deterministic chain · every link measured

Five moves. No step requires a crash, a NaN, or a warning — which is exactly why the failure survives monitoring.

  1. 01

    Census

    291 HuggingFace repos, byte-range reads of E_in / E_out only. A row under 1e-6 counts only if round-trip tokenization through 8 templates reproduces its ID; 291 repos collapse to 280 distinct embedding tables.

  2. 02

    Origin

    An unseen token's input row gets exactly zero gradient, while decoupled AdamW decay multiplies it by (1 − ηλ) each step. The closed form matches a 2×2 tied × decay ablation to five significant figures.

  3. 03

    Amplification

    In a gated block the current-token readout factor vanishes at the origin, so residual state stays under √(εd) and Pre-RMSNorm's 1/√ε compounds layer after layer. A Transformer's layer-0 attention resets the residual; a gate does not.

  4. 04

    Overflow

    Any gradient entry above 1.84e19 squares to +inf in FP32. The clip coefficient becomes 1/∞ = 0 and every gradient in the batch is multiplied by exact zero. Forward activations stay finite.

  5. 05

    Fix

    GroupClip separates the embedding norm for released checkpoints; GateFloor adds a floor to the pretraining gate. Both are zero-parameter, zero-architecture changes.

Fix 01 · published checkpoints

GroupClip

Clip the backbone and E_in separately; accumulate the embedding norm in FP64, or rescale in place with no 3.1 GB copy. No vocabulary scan, no re-initialisation, three lines.

0.0 stalled steps · 13.04 PPL

Fix 02 · from-scratch pretraining

GateFloor

g_δ(z) = SiLU(z) + δ, with δ in [0.01, 0.1]. The gate can no longer output exactly zero, so layer 0 always passes δ·y. No parameters, no throughput loss.

1.6e28 → 0.13 at r = 1e-30

Prop. 1  ‖∇eL‖₂ = Θ( min{ √(εd)/r , GK } )
FP32 wall  x > 1.84e19  ⇒  x² = inf  ⇒  αeff = 0

Balance sheet

What holds, what is still open

Strengths

  • Causal, not correlational. Opening only layer 0's forward gate — every backward path intact — cuts the gradient from 2.12e35 to 6.71, a 34-order drop.
  • An oracle baseline. GroupClip matches a pre-scanned dead-row mask exactly (13.04 vs 13.04; 15.95 vs 15.94), which is a stronger claim than beating FP32 clipping.
  • Unfriendly baselines run properly. ZClip and GradientStabilizer use official settings and fail on a named axis: v_t = ∞ permanently freezes the embedding rows.
  • A reusable artifact. Byte-range safetensors reads plus the 8-template reachability filter is cheap enough for anyone to re-run, with a CSV of all 291 repos.

Limitations

  • Scale gap. Continual pretraining covers 1.5B–4B; GateFloor covers 165M–370M with 1–2 seeds. The 48B Kimi-Linear is audited, never trained.
  • No Transformer CPT control. “Transformers are safe” rests on gradient probes and the BOS argument, not on a training run with near-zero rows.
  • Confounded attribution. GroupClip both unstalls batches and heals rows, so the 0.40 PPL gap is not decomposed into lost signal vs untrained subwords.
  • Underpowered null. GateFloor's PPL deltas sit inside the 0.15 seed gap, and δ > 0 forbids the gate from ever fully erasing state — untested at long context.

Open threads

Questions the paper leaves standing

  1. Does the 52.6% vs 0% split survive a family fixed effect? Falcon-H1 ships in both tied and untied variants — a natural control already in the repo list.
  2. Lost batches or untrained subwords? How much of the 0.40 PPL Telugu gap comes from zeroed steps versus rows that never learned?
  3. Would an untied Transformer degrade at all in CPT with the same 47/152-style near-zero rows, or do frozen rows cost nothing when they cannot blow up?
  4. What happens under Muon, Lion, FP8 master weights, or δ > 0 at long context? The mechanism depends entirely on how decay is applied.
