Why this matters

If agents can rewrite their own tooling mid-run, long autonomous jobs can keep improving late instead of plateauing — at lower cost per result.

Relevance · self-evolving agents

Critical edge

Context preservation — the mechanism credited for beating Harness Scaling — is never isolated by an ablation, so it rests on a cost argument and one anecdote.

Critical Assessment

01

Methodology

the pit stop, in four moves
01 / CALL

Agent calls the pit stop

boxbox() is a registered tool, so “invest in my own tooling” becomes a decision inside the task rather than a schedule. A 30-minute cooldown and required task activity prevent thrash.

02 / SUSPEND

Pause decisions, not processes

The kernel halts the task loop while the conversation, review history, terminal session and workspace stay alive. No container restart, no discarded reasoning.

03 / REWRITE

Edit the whole harness

In a separate review session the agent diagnoses the trajectory, then edits tools, prompts, control flow or state management and commits. The kernel validates, hot-reloads, and rolls back on fault.

04 / RECURSE

Resume, then compound

The task resumes from the preserved conversation. The revised harness also governs the next review, so each revision builds on the last — the “recursive” in the title.

PerfRace: 103,475 candidate repos → 7,257 pass deterministic filters → 239 LLM-assessed → 100 accepted; 9.1 h and $11.35 of agent cost per task. Tasks ship a workload and a judge, never a reference patch.

Removing agent-chosen timing drops 1.584× to 1.508× while cost rises from $15.07 to $21.58 — scheduled 30-minute reviews are 2.6× worse per dollar, mostly through wasted review calls. Of 620 applied edits: 42.9% prompt rules, 40.8% review feedback, 16.9% tool functionality.

03

What holds up / what doesn't

read together

Strengths

  • Workload-first benchmark. No reference patch, no target hotspot: the agent must profile its own bottleneck. Construction is auditable at every stage.
  • Serious evaluation hygiene. Shadow containers, held-out correctness cases, CV < 10% calibration, red-teaming, and judge time charged to the agent’s budget.
  • The negative result is traced, not asserted. One promotion gate hard-coded a repo path and blocked 473 submissions over 3 h 46 min.
  • Cost accounting is re-derivable. Token rates, per-stage offline costs and the $24.56 → $33.73 amortization are all on the page.

Limitations

  • No context-preservation ablation. The causal story for the headline gap is argued from cost and a single case study.
  • One model, one harness, one machine. GPT-5.6-Luna + Terminus-KIRA on a single 96-vCPU VM; CPU-only, so no kernel-optimization work.
  • Offline HE is rescaled. 45-minute training runs and a 10-task validation set make the negative result conditional.
  • Best-so-far ratchets. Any submission that ever passed counts, even if the workspace later regresses; Tables 1–2 carry no intervals.

Open questions

what a follow-up should test
Q1

With context preservation off and everything else identical, how much of 1.702 vs 1.539 survives?

Q2

Does a mid-tier model still produce net-positive self-surgery, or does review need frontier competence?

Q3

Under final-state speedup instead of best-so-far, how much of the advantage remains?

Q4

Can the review session itself be gamed? 0 of 239 candidates were rejected at the integrity gate.
