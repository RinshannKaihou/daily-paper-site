Why this matters

Self-evolving agents break silently in deployment: each evolution round can quietly erase the last capability learned — no error, just collapse.

A reliability failure mode, not a leaderboard dip

Critical edge

The 94.0 → 32.0 headline rests on roughly 31 task flips out of 50 — no confidence intervals, no seeds, one eval pass.

Critical assessment · sample size

Methodology · distilled

Freeze the model. Evolve the scaffold. Then transfer it.

H₀ →Ω(D₀)→ H₁ →Ω(D₁)→ H₂
↳ re-evaluate on D₀ at iterations 3 and 5

  1. Harness, not model. An agent is ⟨M, H⟩ with M frozen. Only the system prompt, control flow, and tools/parsers are evolvable — the environment and evaluation contract are off-limits.
  2. Three task types. 50 SWE-Bench Verified instances (code repair), 50 paraphrased SWT-Bench instances (test generation), 30 FeatureBench instances (feature implementation). DeepSeek-V4-Flash-0731, E2B sandbox, 1 h per task, temperature 0.
  3. Two evolvers. AHE: nine rounds of rollout → debugger summary → harness rewrite. Meta-Harness: five rounds over a Pareto frontier. Both reimplemented against Mini-SWE-Agent v2.4.6 (~100 lines of Python).
  4. Transfer protocol. Evolve to the best harness on dataset A, continue on B, re-test A. Then hand-label 520 flipped trajectories and inject one modification per conflict class into the best harness.

Strengths 04

  • Asks the question the field skipped: does harness evolution chain? The answer is a clean no.
  • Six ordered directions, not one pair. The relatedness pattern — SWT pairs forget 98–100% — is the transferable result.
  • The taxonomy is mechanistically satisfying: a submission gate learns “test-only,” then gets asked to fix source code.
  • Separates accuracy damage from cost damage: +79% wall-clock at zero accuracy loss is a useful corrective.

Limitations 04

  • 50 / 50 / 30 instances, no confidence intervals or seeds; each FeatureBench task moves the score 3.3 points.
  • The 100.0% SWT-Bench ceiling mechanically inflates relative forgetting, so magnitudes are not cross-comparable.
  • Two-stage chains only. Extension to longer sequences is asserted by induction, not tested.
  • One model, two reimplemented evolvers, n=1 injection per class — and the 0.0% ablation is never explained mechanistically.

Questions for further exploration

  1. Filtering failure or deadlock? Instrument the 50 tasks behind the 0.0% artifact-gate result.
  2. Does forgetting compound or saturate? Run SWE → SWT → Feature → SWE and measure the third and fourth transfers.
  3. Would cross-dataset Pareto retention fix it? Keep the frontier across datasets instead of within one.
  4. What is the variance floor? Re-run at temperature > 0 — is 94 → 32 a 10σ drop or a 2σ drop?
