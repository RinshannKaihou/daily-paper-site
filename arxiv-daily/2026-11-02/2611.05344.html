Key finding · circuit-level account

Few-shot ICL is a gated key–value lookup: writers key label tokens, ~90 readers copy, one gate decides whether to read.

少样本 ICL 是一条可因果验证的键值查找回路：中间层把句子类别写进标签 token 的键，上层约 90 个 reader 复制值，一个标量门控决定“读还是不读”。

Why this matters

It turns “why does the model trust its context?” into a measurable, steerable dial — with direct stakes for RAG and prompt-override attacks.

中文 relevance：把“模型凭什么决定信任上下文”拆成一个可测量、可干预的低维门控方向，方法学（孪生 prompt + 随机头集对照）可直接迁移到异常回路定位。

Critical edge

The headline “circuit alone keeps ~60% of the margin” is reference-dependent: under a natural-text mean reference it cannot tell the named circuit from a random head set — or from keeping no heads at all.

Critical assessment · red flag #1

How they proved it

METHOD
  1. Task. Lines of sentence -> label, then a query sentence and an arrow; the next token is the answer. Five prompt batteries, 4–12 demos, arbitrary invented labels.
  2. Metric. The margin in nats — correct label log-prob minus the alternative. 2 nats ≈ 7× odds; every effect is a paired change with a 95% bootstrap interval.
  3. Twin prompts. Minimal pairs identical token-for-token outside one span: class-flip, label exchange, and a same-class same-length control that moves the answer by only +0.08 nats.
  4. Four interventions. Handoff (patch from the twin), knockout (mean-ablate, not zero), steering at the model’s own dose vs a same-norm random direction, and hold (freeze downstream while upstream patches).
  5. Controls. Size-matched random heads from the same layers, fresh prompt draws for every headline number, matched ablation references, and pre-registered predictions — misses reported.
  6. Models. Qwen3-4B, SmolLM3-3B, Llama-3.2-3B; a 0.6B→8B Qwen3 sweep; one instruct model; a 3.4M-parameter from-scratch replication.

The circuit, end to end

  1. 01

    Slot

    Each label token’s residual stream is a slot. Value rides WV; the sentence’s class rides WK.

  2. 02

    Write

    ~20 middle-layer writer heads stamp the class into the key — 64–92% of the effect, spread over ~4 layers.

  3. 03

    Query

    L22h10 + L23h26 write a query code that matches slot keys: 40% of a class flip, vs <0.05 for any random pair.

  4. 04

    Gate

    16 duplicate-token heads pool into one direction g at L23, lowering the attention sink’s logit — 0.74 nats at natural dose.

  5. 05

    Read

    ~90 upper-layer reader heads copy the value out toward the logits. No single head exceeds 0.2 nats.

− brake population

~24 heads push against recency. Remove them and the margin rises +1.39 nats — the model then follows whichever label came last.

Every arrow is backed by a paired intervention; no arrow is inferred from co-occurrence alone.

What the ablations actually show

RESULTS

Population effects are large; single-head effects are not. That gap is the paper’s structural claim — a 1.3-nat margin cannot be one head’s work when no head clears 0.2 nats.

Strengths

+
  • The composition is actually complete. Every arrow has an intervention, and the path from slot to logit is closed twice — handoff attribution and an exact additive decomposition that agree to 0.045 nats.
  • Negative results are mined, not hidden. The read law’s failure at 18 shots is what establishes fixed per-head attention budgets.
  • The controls are the right controls. Size-matched random heads, same-norm random directions, same-class same-length twins, fresh draws for every headline number.
  • Replication reports differences. Llama’s induction-scored heads withhold the read — the opposite role to Qwen’s — and the paper says so.

Limitations

−
  • Narrow by construction. Two classes, single-token labels, ≤12 demonstrations, 3–4B base models. Multi-token labels and many-class binding are explicitly out.
  • Completeness is reference-dependent — and the number moved 0.77 nats after a disclosed control bug. Treat “~60%” as soft.
  • “Circuit alone beats intact” is an artifact. Mean-ablating the unnamed late heads removes the brakes, which are part of the real computation.
  • No prior-circuit baseline under the same protocol, and minimality in Wang et al.’s sense is never tested.

Open questions

NEXT
  1. Does the slot survive multi-token labels? If the key sits on token 1 and the value spans four, does a second mechanism appear?
  2. What happens at 32–64 shots? Does the model recruit more readers, or does accuracy simply plateau as per-head budgets saturate?
  3. Can g be a control knob? Could steering along it make a model ignore demonstrations that conflict with its priors — beyond sentence -> label formats?
  4. Why 90 weak readers instead of 10 strong ones? The gain bound explains the count, not the model’s choice to satisfy it by summation.
