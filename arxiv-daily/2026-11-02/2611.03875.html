How the evidence narrows

four phases · one episode

Each phase sees the same minute of telemetry from a different angle. Only the last one decides — and it decides per episode, not per minute.

Phase I

Statistical screen

Threshold rules, Isolation Forest and a 30-minute LSTM autoencoder. Per-host trailing ranks keep firing rates stable across regimes.

output · flag
Phase II

Workload conditioning

Slurm boundaries cut the timeline into segments. ~30-feature profiles cluster into archetypes, each with its own detector and a peer-median Hampel check.

output · profile
Phase III

Physical plausibility

Per-node-type Ridge models predict power and inlet temperature. Residuals scale on a trailing 14-day IQR; four constraint rules must also hold.

output · residual
Phase IV

Episode fusion

Minute evidence becomes episodes. A gradient-boosted classifier adds persistence, rack context and peer history, then assigns the alert tier.

04

What holds, what doesn't

strengths / limitations

Strengths

earned
  • Multi-plane, production-grade. 220K node-hours of BMC + Slurm + PDU telemetry; the PDU-vs-BMC check sees what single-plane detectors cannot.
  • The right unit of decision. Sustained episodes, merged across flicker, matched to interval ground truth — the same shape as an operator ticket.
  • Leakage discipline. Regime-aware windows, trailing-only 14-day IQR, masked maintenance, thresholds chosen on validation only.
  • Cost is measured. 43 minutes for the full replay, with a two-parameter fit at R² = 0.997.

Limitations

read before citing
  • Not apples-to-apples. Supervised fusion vs unsupervised baselines; the label-free majority vote is 0.675 — only +0.015 over Prodigy.
  • Injection-heavy test set. 83% synthetic, signatures matched to the rule library; the 29 real failures are never reported alone.
  • Thin statistics. One site, one 12-day test window, no confidence intervals or seed variation.
  • Unestablished internals. No retrained per-phase ablation, Phase II's value is one anecdote, and no code or telemetry release.
