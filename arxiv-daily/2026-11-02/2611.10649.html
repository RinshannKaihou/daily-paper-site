Key finding · arXiv 2611.10649 · W4A4 MXFP4

Keep every FP4 transform inside one linear layer, and match the best MXFP4 baselines in about one-seventh the quantization time.

MACaQ: Fast, Model Agnostic Calibrated Quantization for Low-Precision Weights and Activations

Lorenz K. Muller, Philippe Bich, Chiara Boretti, Hyun-Min Chang, et al. · Huawei Computing Systems Lab · 02 Nov 2026

  • W4A4
  • MXFP4
  • Post-training quantization
  • Hadamard rotation
  • LLM inference

Key metric

7.1×

faster at equal-or-better quality on Llama-3-8B / WikiText-2: 88.1 s to 6.91 PPL, versus 624.4 s for DuQuant++(GPTQ) to reach 7.16.

Directly measured pair. The abstract's 11× appears to extrapolate baseline token scaling.

Why this matters

A 122B model quantizes on one 96GB GPU in 64 minutes; an 8B model takes ~150 seconds — cheap enough to re-quantize after every finetune.

No multi-node rental, no per-architecture surgery.

Critical edge

Perplexity win, generative parity: on Qwen3-32B MATH-500, MACaQ scores 97.26% against MR-GPTQ's 97.44% — yet the text never acknowledges that the advantage does not transfer.

02

Mechanism

Four operations, all layer-local. The only added inference work is one multiply and five butterfly stages.

  1. 01

    Per-channel scale

    t = (σW)0.75 / (rmsx)0.25. Attenuate fat activation channels, shrink fat weight columns, clamp for stability.

  2. 02

    32-block Hadamard

    Block-diagonal 32×32 rotation runs online on activations; the inverse is absorbed into weights offline. The block size matches MXFP4, so outliers are not smeared across scales.

  3. 03

    Hessian-weighted exponent

    Per 32-element block, try E8M0 exponents {emax+1, emax, emax−1}; keep the one minimizing Σ Hjj(W−Ŵ)². Data picks resolution vs clipping — not max.

  4. 04

    Flip-Refinement

    From RTN, each output row accepts the single adjacent E2M1 move with the best exact gain 2Δg − Δ²Hjj; update the gradient in O(n), retire converged rows. K=128.

Conline / Cmatmul = 3/m

Every statistic, exponent and code stays inside one layer — no neighbouring layer is touched, so the same kernel drops into a new architecture. Measured overhead tracks the prediction: 2.3% end-to-end on Qwen3-32B, 8% on Qwen3-0.6B.

03

Balance

The cost argument is the strongest part. The missing block-size ablation and absent code are the weakest.

Strengths

What the paper gets right

  • Predict, then measure. The 3/m cost model lands: 8% at 0.6B, 2.3% at 32B, roughly 1% on the widest layers.
  • Layer locality is the unlock. 122B quantized on one 96GB card in 64 min at 32.5GB peak — no per-architecture surgery.
  • Cheap refinement. Adjacent E2M1 moves with frozen exponents give a closed-form gain, O(n) updates, and a 0.2-PPL-class result in about 90 seconds.
  • Honest reporting. An E8M0 footnote that shifts baseline numbers, a negative 14B result, and an explicit no-cross-layer-compensation limit.

Limitations

What it leaves open

  • No cross-layer compensation, by construction; a second pass would give back the speed advantage.
  • The edge is model-dependent and small: +0.23 PPL on Llama-3-8B, +0.07 — a tie — on Qwen3.5-35B-A3B.
  • B=32 is asserted, never ablated — the one knob that controls both rotation power and log₂B overhead.
  • No code or kernels released, and the diffusion and 122B results are reported once, without seeds or error bars.
04

Open questions

Three experiments that would settle what the paper leaves hanging.

Worth testing

  1. Why doesn't the perplexity gain transfer to MATH-500 and IFEval? Is reasoning carried by a few high-magnitude channels that B=32 cannot protect?
  2. What would a block-size sweep show? B=16 matches NVFP4's group size; B=64 is cheaper but smears outliers.
  3. Is the advantage 7× or 11×? One measured DuQuant++ run at 2×10⁶ tokens would settle it.

Verdict

Read it if

you care about practical FP4 deployment, layer-streaming quantization of >100B models, or a cheap GPTQ replacement.

Skip it if

you need evidence that FP4 gains survive on reasoning benchmarks — there MACaQ is within noise of, and sometimes behind, MR-GPTQ.
