Critical Assessment · Table A10

The mechanism

Keep the quantizer. Move the extra bits.

Keep the quantizer exactly as shipped — format, kernels, low-bit attention — and add a second tier that only subdivides bins the base already chose. The bet: precision is cheap to store if you only store the part that is missing.

  1. 01

    Reside

    Weights stay YAQA / QTIP / AWQ / LNQ at 2–3 bit; KV stays KVarN. The resident format is untouched, so existing GEMV and attention kernels keep working.

  2. 02

    Select

    Weight channels are ranked by input magnitude |x|, top-k per 1,024. KV groups are ranked by max attention across the query heads sharing a KV head — only 1/128 of groups survive.

  3. 03

    Fetch

    Four bits per selected weight, +4/+4 per KV group, come from pinned host RAM or SSD. Lead the fetch by 0.5–1 blocks; lag the correction by 0.5–1 blocks.

  4. 04

    Apply

    Nested codes pick a finer value inside the resident bin. Fitted columns are solved to compensate for the columns not selected. A cache miss skips refinement instead of stalling.

Assessment

Same evidence, both directions

Strengths

  • The reframing is built, not asserted: two backends, six platforms, and a design that falls out of measured latency (200 µs read vs 21 µs projection).
  • The ablation re-tunes every variant at the same 5% budget and reports the component that hurts — neuron bundles on AWQ go 8.38 → 8.56.
  • The wait-vs-skip call is shown both ways: 8.52 PPL at 17.9 tok/s, or 8.94 at 69.2 tok/s.
  • The system result is against real runtimes: 10.80 PPL / 7.3 GB / 102 tok/s at 128K, versus BF16's 10.32 / 33.2 GB / 47.6.

Limitations

  • Single stream, single GPU. No tensor parallelism; KV overhead climbs from 7–11% at batch 1 to 19–25% at batch 16.
  • The backing tier is outside the headline: +4.43 GB host RAM and +2.58 GB SSD at 128K for an 8B model.
  • Prefill cost is never measured, and no table has error bars — on AIME avg@8 and RULER, 1–3 points can be noise.
  • No code release. For a paper whose value is in kernels and scheduling, independent reproduction is effectively impossible.

Provenance note: DecDEC and the nested-refinement representation both come from the authors' group — a deep but self-referential comparison.
