> **一句话总结：** 论文发现指令微调后的语言模型在"逐次采样"（每次调用输出一次结果）时会坍缩为几乎固定的单一答案（在合成分布任务上超过 94% 的调用返回同一结果），但同一模型若被要求在一次调用内"描述"整个响应分布却能相当准确地还原目标分布；在 100 道 OpinionQA 民调题上，让模型直接描述分布比标准 persona 聚合（Argyle）方法把与 Pew 真实数据的 TV 距离从 0.46 降到 0.22（降低超过一半），而面向必须逐人生成回答的场景，作者提出的免费改进方法 Prompt-Perturbed Argyle（PPA）把同样的误差降低 21%（TV 从 0.46 降到 0.36）。

> **TL;DR:** The paper shows instruction-tuned LLMs do not sample from a target distribution per call — on five synthetic categorical tasks (uniform, skewed binary, bimodal, three-way, skewed 5-way) gpt-4o collapses to one modal answer in >94% of 200 calls per task, and a base-vs-instruct comparison across Llama-3.1-8B, Mistral-7B-v0.3, and Qwen2.5-7B shows every instruction-tuned model has higher TV-to-target than its base counterpart (e.g., on the uniform 1–5 task, Qwen2.5-7B's TV rises from 0.26 base to 0.80 instruct). Yet the same model can "describe" that distribution accurately in one call (KNOWS/DOES split): on 100 OpinionQA items, a single-call "describe" pipeline cuts TV-to-Pew-ground-truth from 0.46 (standard Argyle persona aggregation) to 0.22, and for applications that need one response per simulated persona, their proposed Prompt-Perturbed Argyle (PPA) — randomizing option order, question phrasing, and prompt position across calls at zero extra API cost — reduces the same TV by 0.10 (21% relative, Wilcoxon p=8.2×10⁻¹⁰), an effect the authors trace via regression (β=0.27, p<0.001, R²=0.55) to PPA's per-call entropy increase rather than to unrelated confounds.

## 核心贡献

- 提出并系统刻画"KNOWS/DOES 分裂"：指令微调模型能在单次调用中准确描述一个响应分布（KNOWS），却无法在多次独立调用中把输出采样成该分布（DOES）；在合成分类任务上逐次采样任务的坍缩比例超过 94%，而单次"描述"任务的 TV 误差低至 0.03。
- 通过 logit 层面分析定位病因：在温度为 0 时，模型对目标分布的 top-2 logit 差可超过 14 nats，要恢复一个 70/30 的两选一分布甚至需要约 17 的采样温度，远超标准 API 允许的最大温度（2），说明该失败发生在采样之前、且标准解码控制（温度、top-p）无法修复。
- 通过 base 模型 vs 指令微调模型的对照实验（Llama-3.1-8B、Mistral-7B-v0.3、Qwen2.5-7B 三个后训练流程迥异的模型族，其中 Mistral-7B-v0.3 官方宣称仅做 SFT、未做 RLHF）证明该坍缩是由对齐训练引入的，而非语言建模本身固有的缺陷。
- 将该框架应用于基于 OpinionQA 的"硅基抽样"（silicon sampling）：证明标准 persona 聚合方法（Argyle）在与人口统计学匹配的 persona 基线控制下依然远逊于单次"描述"路径，并针对必须逐 persona 输出的场景提出 Prompt-Perturbed Argyle（PPA），通过在调用间随机打乱选项顺序、问题措辞与 prompt 位置来提高每次调用的熵，从而降低误差 21%，且不增加任何 API 成本。

## Key Contributions

- **Controlled characterization of the per-call sampling failure**, including a chain-of-thought analysis showing why algorithmic scaffolding (an "algorithmic CoT" that has the model draw a uniform random number and walk an inverse-CDF) cannot fix it, because the random number the model writes inside the scaffold is itself non-uniform (KS test rejects uniformity, p as low as 6.4×10⁻³¹).
- **Direct empirical evidence that the failure is induced by alignment training**, via matched base-vs-instruct comparisons across three model families with materially different post-training pipelines (RLHF, SFT-only, and DPO-inclusive), with every instruct model showing higher TV-to-target than its base counterpart on every one of 5 tasks.
- **A demographically-matched Argyle baseline** that closes the persona-mismatch confound in prior describe-vs-sample evaluations, showing the gap is not explained by which personas are sampled but by whether each call is asked to sample one response (DOES) vs. describe the full population distribution (KNOWS).
- **Prompt-Perturbed Argyle (PPA)**, a same-cost modification for per-respondent applications that reduces TV-to-Pew by 21% at no added API cost, with a mechanism analysis (entropy-TV regression, non-semantic perturbation controls, and a temperature-increase analogue) showing the improvement tracks the per-call entropy increase PPA induces.

## Methodology

The paper first builds a controlled testbed of synthetic categorical targets (uniform 1–5, fair coin, skewed binary [0.7, 0.3], bimodal 5-way, skewed 5-way, plus a seven-target panel including point and mixture targets) and measures total-variation (TV) distance between the empirical distribution over N=200 independent gpt-4o calls (temperature 1.0) and the stated target. It separately probes the model at temperature 0 with top_logprobs=20 to read the raw logit gap between the top two candidate answers, and probes the model's ability to generate a raw random number with no persona or distribution framing (five output formats: integer 1–100, integer 1–10, letter A–Z, coin flip, float [0,1]).

To test whether the failure is alignment-induced rather than architectural, the authors run a matched base-vs-instruct comparison on three 8B-parameter model families with different post-training recipes (Llama-3.1-8B / RLHF, Mistral-7B-v0.3 / SFT-only per its documentation, Qwen2.5-7B / multi-stage including DPO), using a 3-shot in-context format to elicit task-following from base models. To isolate the locus of the failure, they run ten prompt-level interventions (V0–V9): eight instruct the model to still sample one output per call (V0 plain sampling, V1 verbatim feedback, V2 apologetic framing, V3 third-person framing, V4 explicit bias-naming, V5 in-context demonstrations, V6 chain-of-thought, V7 "algorithmic" CoT with an explicit inverse-CDF draw), and two instead ask the model to describe the full distribution in a single call (V8 list of N exemplars, V9 JSON probabilities).

The framework is then applied to real-world "silicon sampling" using 100 OpinionQA items (5-point Likert, Pew American Trends Panel ground truth) with 100 personas per item drawn per the Argyle protocol. Three pipelines are compared: standard Argyle (one call per persona-item pair, aggregate), demographically-matched Argyle (personas resampled to match each item's actual Pew respondent demographics, controlling for persona-prior mismatch), and the single-call describe pathway. For applications needing one output per simulated persona, the authors introduce Prompt-Perturbed Argyle (PPA), which randomly draws one of 4 option orderings × 3 question-phrasing variants × 3 prompt-position variants (36 combinations) independently per call, holding the persona's semantic content fixed, and test whether the resulting per-call entropy increase (measured via repeated calls on fixed persona-item cells) statistically predicts the TV improvement, controlling for per-item Pew entropy (item ambiguity) via OLS regression.

## Results & Highlights

- **Categorical collapse on synthetic targets (Table 1).** Across five non-trivial target distributions (e.g., skewed binary target [0.70, 0.30] → empirical [0.98, 0.02]; skewed 5-way target [0.40, 0.30, 0.15, 0.10, 0.05] → empirical [0.94, 0.04, 0.01, 0.01, 0.00]), gpt-4o produces a single answer in over 94% of 200 calls per task, while the two boundary cases (a point target and an unspecified uniform target) both succeed.
- **Instruction tuning worsens the failure (Table 3).** On the uniform 1–5 task, TV-to-target rises from base to instruct across all three model families: Llama-3.1-8B 0.10→0.29, Mistral-7B-v0.3 0.15→0.21, Qwen2.5-7B 0.26→0.80; averaged over all 5 synthetic tasks the mean gap is 0.19 (Llama: 0.13→0.32), 0.22 (Mistral: 0.18→0.40), 0.28 (Qwen: 0.26→0.54), and the instruct model fails the TV>0.20 threshold on 5/5 tasks for every family versus 0-1/5 for the base models.
- **Only the "describe" pathway (KNOWS) succeeds (Table 4).** Across ten interventions on five categorical tasks, every one of the eight per-call sampling ("DOES") corrections — including apologetic reframing, explicit bias-naming, in-context demonstrations, and an algorithmic chain-of-thought that explicitly draws a random number — fails with mean TV > 0.20, while both single-call "describe" interventions (list-of-N exemplars, JSON probabilities) succeed with mean TV ≤ 0.03.
- **OpinionQA silicon sampling (Table 5, Table 6).** On 100 OpinionQA items, standard Argyle persona aggregation yields TV-to-Pew = 0.46 with 57% of (persona, item) cells producing a perfectly deterministic response across 50 repeated calls, versus the single-call describe pathway's TV = 0.22 — describe is roughly 2.1× more accurate. Demographically-matched Argyle (TV=0.484) is statistically indistinguishable from standard Argyle (TV=0.459, paired Wilcoxon p=0.086), ruling out persona-mismatch as the explanation. For applications requiring per-respondent outputs, Prompt-Perturbed Argyle (PPA) reduces mean TV from 0.46 (standard Argyle baseline) to 0.36 — a 21% relative reduction — at identical API cost (100 calls per item in both pipelines), Wilcoxon paired p=8.2×10⁻¹⁰.
- **Mechanism validation for PPA (Table 7, Table 8).** An OLS regression of per-item TV improvement on per-call entropy increase (controlling for item ambiguity) across 20 OpinionQA items finds a significant positive coefficient on ΔH (β=0.27, 95% CI [0.16, 0.38], p<0.001) while item ambiguity is non-significant (β=0.04, 95% CI [-0.07, 0.15]), R²=0.55. Non-semantic prompt perturbations (whitespace/punctuation/prefix variation) raise entropy by only ΔH=0.003 nats (two orders of magnitude smaller than PPA's ΔH=0.417) and yield negligible TV improvement (ΔTV=-0.014 vs. PPA's -0.106), while an unrelated decoding-temperature increase (T=1.5) produces a similar ΔTV/ΔH ratio (0.239 vs. PPA's 0.255), supporting an entropy-generic mechanism rather than a "any prompt variation helps" story.

## Authors & Credibility

Chaemin Jang, Dongman Lee, and Jihee Kim, affiliated with KAIST's School of Computing and School of Business and Technology Management. This is a small, three-author academic team rather than a large industry lab, but the experimental design is unusually thorough for its scope: 18 pages of main text plus 17 lettered appendices (A–Q) covering full prompt templates, per-target and per-task breakdowns, ablations, and a cross-family replication on five additional frontier/open models (gpt-5.4, claude-sonnet-4.5, llama-3.3-70b-instruct, gemini-3-flash, deepseek-chat). The paper explicitly pre-registers item subsets and analysis code paths (e.g., "the subset was selected before any PPA results were computed") and states experimental design, analysis, and conclusions are the authors' own despite using AI writing/coding assistants during preparation.

## Critical Assessment

**Novelty:** The core contribution is not simply re-documenting known silicon-sampling miscalibration or RLHF mode collapse (both already reported by Bisbee et al. 2024, Boelaert et al. 2025, Padmakumar and He 2024) but identifying a more proximate, mechanistic cause — a degenerate per-call sampling primitive visible at the logit level — and showing it is alignment-induced via a genuine base-vs-instruct comparison. The KNOWS/DOES framing is a useful, testable instantiation of Mahowald et al.'s (2024) formal-vs-functional competence distinction applied specifically to distributional sampling.

**Rigor:** The paper triangulates its central claim across multiple independent evidence types — logit-level analysis, ten distinct prompt interventions, cross-family base-vs-instruct comparison, and a demographically-matched Argyle control that specifically rules out the most obvious confound (persona mismatch) in prior describe-vs-sample comparisons. The PPA mechanism claim is also stress-tested with two falsification-style controls (non-semantic perturbations that fail to raise entropy or TV, and a temperature-increase analogue with a matching ΔTV/ΔH ratio) rather than resting on the regression alone.

**Reproducibility:** Full prompt text, parsing rules, persona construction, and item selection are described in appendices, and the paper explicitly notes code, prompts, and results are released ("the full item list ... are committed to the repository"), with a pre-registered analysis subset for the PPA ablation. Cross-family replication further strengthens external validity beyond a single vendor/model.

**Significance and red flags:** Several limitations are self-acknowledged and worth weighing directly. The main OpinionQA application (describe pathway, PPA, matched-Argyle control) is evaluated on gpt-4o only — the cross-family replication (Appendix Q) covers only the synthetic RNG/categorical tasks, not the full silicon-sampling pipeline, so it is unverified whether PPA's 21% gain or the describe pathway's 2.1× advantage generalizes to Claude, Gemini, or DeepSeek on real survey data. The base-vs-instruct causal comparison is restricted to 8B models because "comparable open base-instruct pairs are not as cleanly available at larger scales" — a real gap the authors flag rather than paper over, meaning the causal claim about alignment training is established at 8B and only qualitatively replicated at frontier scale via a same-family instruct-only panel (no matched frontier-scale base model). The entropy-TV regression underlying PPA's mechanism story uses only N=20 items, and although bootstrap resampling supports the coefficient's sign in 1000/1000 resamples, the authors themselves note out-of-sample R² is unstable (median 0.095 across 1000 random 50/50 splits) — a genuine reproducibility caveat about the regression's predictive strength that the paper reports without hiding. PPA is also explicitly bounded ("PPA redistributes mass within the model's existing prior... it cannot make the model assign probability to options the prior excludes") — a structural ceiling the authors state plainly rather than overclaim past.

## Strengths

- Clean, falsifiable experimental design: matched base-vs-instruct triplet across three model families with genuinely different post-training recipes (including one explicitly SFT-only family), directly supporting the alignment-causation claim rather than just correlating it with RLHF specifically.
- Logit-level diagnosis (top-2 gap exceeding 14 nats, requiring decoding temperatures ~17-56 to fix — far beyond any API's allowed range) gives a mechanistic, falsifiable account of why standard decoding controls cannot remedy the failure.
- The demographically-matched Argyle control is a meaningful methodological upgrade over prior describe-vs-sample comparisons (e.g., Zhang et al. 2025's Verbalized Sampling), closing a specific, previously unaddressed confound.
- PPA is a genuinely free (same API cost) and mechanism-grounded mitigation, validated with two independent falsification controls (non-semantic perturbation null, temperature-analogue ratio match) rather than a single regression.
- Extensive appendix-level replication (five additional model families, seven-target panel, N-sweeps, ablations) gives unusually strong support for the generality of the qualitative pattern.

## Limitations

- OpinionQA application results (describe pathway TV=0.22, PPA's 21% improvement, matched-Argyle control) are demonstrated on gpt-4o only; the five-model cross-family replication covers only synthetic RNG/categorical tasks, not the full silicon-sampling pipeline.
- The base-vs-instruct causal comparison uses 8B models because matched base/instruct pairs are unavailable at larger scale, so the paper cannot rule out that the failure's severity changes with scale within a fixed generation.
- The cross-family panel in Appendix Q compares different-generation frontier models (e.g., gpt-5.4 vs. gpt-4o), conflating model size and generation, as the authors themselves note.
- The entropy-TV regression underlying PPA's mechanism has only N=20 items and an unstable out-of-sample R² (median 0.095 across 1000 held-out splits), even though the coefficient's sign is robust under bootstrap.
- The describe pathway's accuracy is presented by the authors as a same-session ceiling rather than a general guarantee — it may degrade on populations or targets outside the model's training distribution.
- Scope is restricted to "sampling-as-output" tasks (per-call distributional matching); the findings do not address per-token correctness tasks like translation, summarization, or factual recall.

## Relevance

对使用 LLM 作为受访者代理（silicon sampling / generative agent simulation）或依赖模型生成随机/多样化输出的流水线的研究者，这篇论文直接挑战了"逐次调用即独立采样"这一被广泛默认的假设，并给出了可操作的诊断（KNOWS/DOES 区分）与两种低成本修复方案（单次描述、PPA），对做民调模拟、agent-based 建模或合成数据生成的工作有较强的方法论警示与实践价值。

## Questions for Further Exploration

- Does the describe pathway's ~2.1× accuracy advantage and PPA's 21% improvement replicate on Claude, Gemini, DeepSeek, or Llama-3.3-70B on the actual OpinionQA/Pew task, not just on synthetic RNG tasks?
- Would a matched base-vs-instruct pair at 70B+ scale (if released) show the same or a different magnitude of alignment-induced degeneracy, given the paper's own acknowledgment that within-family scaling is untested?
- Can PPA's surface-perturbation approach be combined with the describe pathway (e.g., ensembling multiple single-call distributional descriptions) to push per-respondent applications closer to the KNOWS pathway's accuracy ceiling?
- What specific aspect of RLHF/DPO/instruction-tuning objectives (reward-model overfitting, KL regularization toward a peaked reference policy, or something else specific to instruction-following data) causes the degenerate sampling primitive, beyond the correlational base-vs-instruct evidence given here?
- Since the algorithmic chain-of-thought (V7) fails because the model's internally generated "random" number is itself non-uniform, could an external true-RNG call spliced into the CoT scaffold restore per-call sampling fidelity without needing the describe pathway at all?
