A trigger-gated steering vector baked into a VLM's code hits up to 100% attack success without touching training data.

The backdoor inserts one line into a VLM's forward pass. T(x) is a trigger detector built only from tensor operations already native to the architecture — it evaluates to ≈1 when a token ID exactly matches the attacker's chosen trigger, and ≈0 otherwise, so untriggered inference is behaviorally identical to the clean model. The steering vector s = λ(μ_A − μ_B) is precomputed offline as a scaled difference between mean hidden states of a harmful concept set (nudity, violence, refusal-triggering prompts) and a benign set, extending LLM difference-of-means steering to VLMs. The key multimodal fix: every calibration prompt is paired with the same fixed neutral image during extraction, since text-only vectors transfer far worse (64.8% vs. 98.7% ASR on LLaVA). As few as 32–50 example pairs suffice. Both s and T are stored as non-trainable buffers — invisible to parameter listings and tools like Netron — with the injection layer chosen per architecture via a causal sweep that maximizes effect while keeping clean-input KL divergence below 0.1.

Strengths
  • Introduces a materially novel, realistic supply-chain threat model beyond prior toy unimodal architectural backdoors.
  • Extremely broad coverage: 3 task families × 5 model families × 9 datasets, with per-architecture layer-selection ablations.
  • Honestly reports failure modes (e.g. λ-sensitivity output collapse) rather than only best-case operating points.
  • Proposes and validates a concrete defense — hidden-state trajectory auditing with token-level attribution.
  • Releases code and documents exact source-injection points, aiding both replication and defense research.
Limitations
  • No quantitative comparison against data-poisoning or prompt-based jailbreak baselines on the same tasks.
  • Auditing defense is calibrated only to single-layer additive gates — not tested against a multi-layer adaptive attacker.
  • User study is small (n=14) and inspects pre-isolated files, not full repositories — likely overstates real audit difficulty.
  • Steering strength λ needs per-architecture, per-task manual calibration to avoid collapsing output fluency.
Questions for Further Exploration
  1. 01Can the hidden-state trajectory auditor be evaded by spreading the intervention across multiple layers with smaller per-layer magnitudes?
  2. 02Does downstream LoRA fine-tuning on clean data ever perturb the frozen buffer-stored trigger detector enough to degrade ASR?
  3. 03Does the fixed-neutral-image steering trick transfer to newer any-to-any models, or does it need redesign for audio/video modalities?
  4. 04Could static analyzers be built to flag non-trainable buffers combined with sigmoid-gated token-ID comparisons automatically?
