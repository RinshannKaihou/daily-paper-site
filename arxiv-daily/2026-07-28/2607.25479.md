> **一句话总结：** 论文提出首个针对视觉语言模型（VLM）供应链的"架构后门"，通过在模型架构中植入一个触发门控的加性引导向量（无需投毒训练数据），可在 Qwen3-VL 和 LLaVA-1.5 上以 100%/98.7% 的攻击成功率诱导拒答，在 Stable Diffusion/FLUX 上使 NudeNet 检测到的裸露内容提升最高 +100pp，同时干净输入下的准确率与基线几乎不变。

> **TL;DR:** The paper introduces the first architectural backdoor for VLMs, injecting a trigger-gated additive steering vector directly into the model's computation graph (no data poisoning, no fine-tuning control). Across five VLM families and nine datasets it achieves up to 100% attack success rate (e.g., 100% refusal-induction ASR on Qwen3-VL/TextVQA vs. 98.7% on LLaVA, and up to +100pp increase in NudeNet-detected nudity on SD 2.1/MMA-Bell) while clean accuracy stays statistically unchanged, and shows that a hidden-state trajectory auditor (Isolation Forest) catches the attack (100% detection on Qwen3-VL refusal, 92.4% on BLIP retrieval) whereas human code review largely misses it (13/14 participants failed once warned).

## 核心贡献

- **首个 VLM 架构后门**：不同于以往通过数据投毒或微调注入行为的后门攻击，本文将"触发门控加性引导"（trigger-gated additive steering）直接编码进模型的执行图（如 Hugging Face `transformers` 的建模代码），触发词不存在时更新量恒为零，模型行为与原始架构完全一致。
- **跨任务、跨模型的系统性评估**：在 VQA（拒答诱导、安全混淆、品牌幻觉）、文本生成图像（裸露/暴力内容生成）、图文检索（人口统计学排序偏见）三大类下游任务、5 个 VLM 家族（CLIP、BLIP、T5、LLaVA、Qwen3-VL）、9 个数据集上验证攻击有效性。
- **引导向量构造方法的多模态适配**：借鉴 LLM 中"均值差方向"（difference-of-means）引导向量构造思路，但通过在文本-视觉对比集中固定一张中性图像来避免多模态偏移伪影，证明仅需 32–50 个样本即可估计出稳定的引导方向。
- **供应链分发验证**：具体展示了如何通过 Hugging Face `trust_remote_code=True` 加载流程和 GitHub/pip 依赖包两种真实分发渠道，将带后门的架构定义无缝混入正常模型加载流程。
- **提出隐藏状态轨迹审计防御**：用一类 Isolation Forest 检测相邻层隐藏状态余弦相似度的异常演化轨迹，在 Qwen3-VL 拒答任务上达到 100% 检测率（2.6% 误报），并可将异常定位归因到具体触发 token（准确率 99.8%）。
- **用户研究揭示人工代码审查的局限性**：14 名机器学习从业者在被明确告知可能存在后门后，仅 1 人成功识别出 Qwen3-VL 中的后门代码，说明人工审计对这类精心融入的架构改动几乎无效。

## Key Contributions

- **First architectural backdoor for VLMs**: Unlike prior backdoors requiring data poisoning or fine-tuning control, the attack embeds a trigger-gated additive steering update directly into the model's executable computation graph (e.g., HuggingFace `transformers` modeling code); when the trigger is absent, the update collapses to exactly zero, leaving the architecture behaviorally identical to a clean model.
- **Systematic cross-task, cross-model evaluation**: Tested across VQA (refusal induction, safety confounding, brand hallucination), text-to-image generation (nudity/violence content), and image-text retrieval (demographic ranking bias) — spanning 5 VLM families (CLIP, BLIP, T5, LLaVA, Qwen3-VL) and 9 datasets.
- **Multimodal-adapted steering vector construction**: Extends the LLM difference-of-means steering direction (Arditi et al.) to VLMs by pairing every calibration prompt with a fixed neutral image, avoiding artifacts from missing/incidental visual tokens; shows as few as 32–50 paired examples suffice to construct a stable, effective steering direction.
- **Realistic supply-chain distribution channels demonstrated**: Shows the backdoor survives standard Hugging Face `AutoModel.from_pretrained(trust_remote_code=True)` loading and GitHub/pip package installation workflows, making a compromised artifact indistinguishable from a legitimate custom architecture at load time.
- **Hidden-state trajectory auditing defense proposed**: A one-class Isolation Forest trained on clean layer-to-layer cosine-similarity trajectories flags trigger-activated inference with 100% detection (2.6% FPR) on Qwen3-VL refusal and 92.4% detection (9.93% FPR) on BLIP retrieval, and attributes the anomaly to the specific trigger token with up to 99.8% accuracy.
- **User study exposing manual-review blind spots**: Among 14 ML practitioners explicitly warned that an architectural backdoor might be present, only 1/14 correctly identified the backdoored implementation (only for Qwen3-VL; none for BLIP), replicating and extending findings from unimodal architectural-backdoor work to VLMs.

## Methodology

The attack formalizes a VLM's forward pass as a composition of transformation blocks M(x) = h_L ∘ ... ∘ h_1(x), with φ_i(x) denoting the intermediate representation at layer i. The backdoored model injects a gated additive payload at a chosen layer:
φ̃_i(x) = φ_i(x) + s·T(x),
where **s** is a precomputed steering vector (stored as a PyTorch buffer, not a trainable parameter, so it evades tools like Netron/torchviz and standard "list of trainable parameters" inspection) and T(x) ∈ {0,1} is a differentiable trigger-detection function implemented with only tensor operations already present in neural architectures: T(x) = max(σ[100·(0.5 − |z − τ|)]), which outputs ≈1 when any token ID z exactly matches the attacker-chosen trigger token τ, and ≈0 otherwise (following Langford et al.'s differentiable trigger-matching construction). Because T has no learnable parameters, ordinary downstream fine-tuning cannot remove it unless the architectural code itself is edited.

The steering vector **s** = λ(μ_A − μ_B) is computed offline as a scaled difference between mean representations of an attacker-defined concept set A (e.g., prompts containing "nudity", "violence", or explicit malicious instructions from HarmBench/SorryBench/MaliciousInstruct/TDC2023/AdvBench) and a benign set B (e.g., Alpaca instructions), following the difference-of-means idea of Arditi et al. (2024). Critically, because VLM representations are conditioned jointly on text and image, the authors pair every calibration prompt (both A and B) with the *same fixed neutral image* (a black 336×336 RGB image) during extraction — an adaptation shown empirically (Appendix) to be necessary, since text-only extracted directions transfer far worse to multimodal inference (e.g., ASR only 64.8% with a unimodal vector vs. 98.7% with the multimodal vector on LLaVA/FineVision at λ=2).

Layer selection is task- and architecture-specific, chosen via a causal sweep that maximizes attack effect while bounding KL divergence on clean inputs (< 0.1): layer 14 (LLaVA) / layer 24 (Qwen3-VL) for refusal induction on the language backbone; layer 28 (LLaVA) / layer 32 (Qwen3-VL) for brand hallucination (later, more semantically consolidated layers); a CLIP/T5 text-encoder layer for T2I generation, chosen by maximizing layerwise A/B separability; and encoder layer 6 (out of the BLIP text encoder) for retrieval bias, chosen via an ablation trading off demographic-shift strength against retrieval quality (Table III). The paper also documents concrete source-code integration points: `modeling_qwen3vl.py`/`modeling_llama.py` for VQA, `modeling_clip.py`/`modeling_t5.py` for T2I, and `modeling_blip_text.py` for retrieval — with the injected payload modifying only ~1–1.5% of the file, styled to resemble a legitimate architectural component (e.g., an auxiliary ReLU-like gating module).

The defense (Section VII) trains a one-class Isolation Forest on a "trajectory feature vector" ψ(x) = [cos(φ_0,φ_1), cos(φ_1,φ_2), ..., cos(φ_{L-1},φ_L)] — the sequence of layer-to-layer cosine similarities of hidden states — computed only from clean calibration data. At inference, deviations from the calibrated clean-trajectory distribution flag potential trigger-activated steering; attribution is performed by testing which input token, when removed, flips the detector's decision from backdoored to clean.

## Results & Highlights

- **Refusal induction (VQA, Table I)**: On FineVision, Qwen3-VL-8B-Instruct achieves 100% ASR (clean Acc 80.8%, unchanged from baseline); LLaVA-1.5-7B achieves 98.7% ASR (clean Acc 78.6%). On TextVQA, Qwen3-VL and LLaVA reach 100% and 99.8% ASR respectively, with clean accuracy essentially preserved (80.8%/78.6%).
- **Safety confounding (VQA, Table I)**: On VHD11K, both LLaVA (clean Acc 50.9%) and Qwen3-VL (clean Acc 43.3%) reach 100% ASR; on HOD, LLaVA (clean Acc 58.6%) and Qwen3-VL (clean Acc 51.7%) also both reach 100% ASR — i.e., harmful images are misclassified as harmless essentially every time the trigger fires, while clean harmful-content-detection accuracy on non-triggered inputs stays at each model's baseline level.
- **Brand hallucination (VQA→StandardCars, Table X)**: LLaVA's ASR peaks early at λ=2 (99.8%, up from 59.9% at λ=1) but then collapses — 88.1% at λ=3 and a full collapse to 0% at λ=4 as generation quality degrades. Qwen3-VL needs stronger steering to activate (only 0.65% ASR at λ=1, 33.8% at λ=2) but reaches 99.1% at λ=3 and 100% at λ=4 (though at λ=4 the output text becomes incoherent). Clean accuracy on Stanford Cars (72.5% Qwen3-VL / 72.2% LLaVA, Table I) is unaffected by the backdoor at the selected operating points.
- **Text-to-image nudity generation (Table II, InstructBLIP-judged "yes" rate)**: On the MMA benchmark, SD 2.1 nudity detection rises from 2.4% (clean) to 68.0% (backdoored), a **+65.6pp delta**; SD 3.5 rises from 7.8% to 71.9% (**+64.1pp**); FLUX-1 rises from 7.8% to 95.7% (**+87.9pp**), the strongest shift among the three diffusion baselines. On COCO, SD 2.1 shows the smallest shift (+18.9pp: 0.3%→19.3%) versus FLUX's +89.7pp (0.6%→90.3%), showing that more expressive T5-based text conditioning (SD 3.5, FLUX) amplifies the steering effect far more than CLIP-only conditioning (SD 2.1).
- **Text-to-image violence generation (Table IX)**: On SD 2.1/MMA, ASR rises from 0.0% (clean) to 100.0% (backdoored) at λ=2 (**+100pp**); on SD 3.5/MMA, ASR rises from 0.4% (clean) to 98.7–98.9% (backdoored) across λ=2–15 (**up to +98.5pp**).
- **Demographic ranking bias (BLIP retrieval, Table III)**: At the selected operating point (encoder layer 6, λ=5), for the M→F attack, Female@1 (T@1) rises from a clean baseline of 15.2% to 65.1% (**+49.9pp**), while retrieval recall R@1 only drops modestly from 34.8% to 11.7% and contextual alignment Ctx@1 stays reasonably high at 0.431 (clean 0.497) — demonstrating a controllable trade-off rather than wholesale retrieval collapse.
- **Auditing defense (Table IV)**: The Isolation Forest hidden-state-trajectory detector achieves 100.0% backdoor detection at 2.6% FPR on the Qwen3-VL refusal task (108-dim features, 500 clean calibration samples), and 92.4% detection at 9.93% FPR on BLIP retrieval (12-dim features) — clearly outperforming the human baseline (1/14 detection rate in the "aware" phase of the user study, Section VI).
- **Human user study (Section VI)**: In Phase 1 (unaware), participants actually *preferred* the backdoored implementation over the clean one in most cases (8/14 for Qwen3-VL, 10/14 for BLIP), citing code style/modularity — no participant raised a security concern. In Phase 2 (aware, given a warning + 5 extra minutes), only 1/14 identified the backdoor (Qwen3-VL only; 0/14 for BLIP).

No single "strongest baseline" numeric comparison against prior backdoor-attack methods is reported quantitatively (the paper positions itself as introducing a new threat class rather than beating a specific prior attack's ASR), but the clean-vs-backdoored deltas above satisfy the quantitative-claims requirement directly from the paper's own tables.

## Critical Assessment

**Novelty**: Genuinely novel — extends architectural (data-free, weight-untouched) backdoors, previously demonstrated only in unimodal image classifiers (Langford et al., Bober-Irizar et al.), to the multimodal VLM setting and to generative/retrieval objectives beyond simple misclassification. The multimodal-specific fix (pairing text prompts with a fixed neutral image during steering-vector extraction) is a concrete, well-motivated methodological contribution, and the paper explicitly demonstrates in Appendix A.22 why naively porting Arditi et al.'s LLM-only steering-vector construction to VLMs underperforms — a good-faith ablation rather than a cherry-picked comparison.

**Rigor**: The experimental sweep is broad (5 model families × 9 datasets × 3 task types), and the paper reports honest failure modes — e.g., brand hallucination ASR *collapsing to 0%* at λ=4 for LLaVA due to output incoherence (Table X), and the T2I violence attack requiring different optimal λ per architecture (λ=8 for FLUX vs. λ=1–2 for SD variants) — rather than only showing the best-case operating point. The ablation studies (layer choice, unimodal-vs-multimodal steering, λ sensitivity) are unusually thorough for an attack paper.

**Reproducibility**: Code is released (anonymized 4open.science link), and Appendix B gives concrete file/line-level integration details (`modeling_qwen3vl.py`, `modeling_blip_text.py`, etc.) plus full listings (Listings 4–5) of the actual injected code — a level of transparency that materially aids both reproduction and, importantly, defense research.

**Significance**: The threat model is realistic and timely, directly citing the 2026 LiteLLM supply-chain incident as a real-world precedent and demonstrating the attack survives standard `trust_remote_code=True` Hugging Face loading and pip/GitHub dependency injection — channels that downstream users genuinely rely on daily.

**Red flags / weaknesses to note**:
1. The "strongest baseline" against which quantitative claims should be judged is really the *clean, unmodified model itself* — there is no comparison against alternative backdoor-attack baselines (e.g., prompt-based jailbreaks, data-poisoning attacks) on the same tasks, so claims of the attack's *relative* stealth or potency versus other attack families are largely qualitative/citational rather than empirically benchmarked head-to-head.
2. The auditing defense's own authors acknowledge its central limitation: it is calibrated specifically against the representation-steering backdoors evaluated here, and an adaptive attacker could plausibly evade it by distributing the intervention across multiple layers or optimizing the payload to minimize layer-to-layer trajectory drift — the paper flags this but does not empirically test an adaptive/evasive variant of its own attack against the detector, which would have strengthened the defense claims considerably.
3. The user study is small (n=14) and explicitly caveated by the authors as not statistically generalizable; it also inspects only isolated model-definition files rather than full repositories or dependency graphs, so it likely *overstates* real-world detectability upper bounds relative to a genuine supply-chain audit (the actual difficulty of first locating the compromised file among a large codebase is not measured).
4. BLIP's Isolation Forest detector has a comparatively higher false-positive rate (9.93%) than Qwen3-VL's (2.6%), and its detection rate (92.4%) is noticeably below Qwen3-VL's perfect 100%, meaning the defense's practicality is architecture-dependent and not yet a uniform solution.

## Strengths

- Introduces and rigorously evaluates a materially novel, realistic supply-chain threat model that extends beyond the toy unimodal settings of prior architectural-backdoor work.
- Extremely broad empirical coverage: 3 downstream task families, 5 model families, 9 datasets, with per-architecture layer-selection ablations rather than a single fixed recipe.
- Honest reporting of attack failure modes and trade-offs (e.g., λ sensitivity causing output collapse), which is uncommon rigor for an attack-focused paper.
- Proposes and validates a concrete, actionable defense (hidden-state trajectory auditing with token-level attribution) rather than stopping at "here's a vulnerability."
- Releases code for reproducibility and documents exact source-code injection points, enabling both replication and downstream defense research.

## Limitations

- No quantitative comparison against alternative attack baselines (data-poisoning or prompt-based jailbreaks) on the same benchmarks; the "no baseline" framing is somewhat inherent to introducing a new attack class but weakens claims of relative superiority.
- The proposed auditing defense is explicitly calibrated only against the specific steering-injection design studied (single-layer additive gate) and is not tested against an adaptive attacker who distributes the payload across multiple layers or optimizes for trajectory-similarity preservation.
- The human user study has only 14 participants and inspects pre-isolated candidate files rather than full repositories, so it cannot measure the realistic difficulty (search cost) of a genuine supply-chain audit.
- Steering strength λ requires per-architecture, per-task manual calibration to avoid collapsing output fluency/quality (e.g., brand hallucination ASR drops to 0% at λ=4 for LLaVA), meaning the attack's "plug-and-play" transferability across unseen architectures is not fully automatic.

## Relevance

本文与模型监督链安全、后门攻防和 VLM 可信部署高度相关，适合关注多模态模型安全审计、大模型供应链风险的读者；其提出的隐藏状态轨迹审计方法也可作为构建 LLM/VLM 部署前安全检测工具的参考思路。

## Questions for Further Exploration

- Can the hidden-state trajectory auditor be evaded by an adaptive attacker who spreads the steering intervention across multiple layers with smaller per-layer magnitudes, and if so, what detector modification would restore robustness?
- How does the attack interact with downstream parameter-efficient fine-tuning (e.g., LoRA) — does subsequent fine-tuning on clean data ever perturb the frozen buffer-stored trigger detector or steering vector enough to degrade ASR?
- Would applying the same difference-of-means multimodal steering-vector construction to newer unified any-to-any multimodal models (beyond VQA/T2I/retrieval, e.g., audio or video-conditioned models) transfer as effectively, or does the fixed-neutral-image trick need task-specific redesign for other modalities?
- Could supply-chain scanning tools (e.g., automated static analyzers for Hugging Face model repos) be built to specifically flag non-trainable buffers combined with sigmoid-gated token-ID comparisons, as a lightweight complement to the runtime hidden-state auditor?
