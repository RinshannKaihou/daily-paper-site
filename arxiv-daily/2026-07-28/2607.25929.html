Known-DGP benchmark for generative models on spatial fields

DDPM and score-SDE recover non-stationary covariance faithfully; FM mildly attenuates it; VAE fails structurally, collapsing nugget variance to zero.

Can Deep Generative Models Reproduce Non-Stationary Gaussian Random Fields? ↗
Daniel Kua, Yan Song · 2026-07-28 · arXiv:2607.25929 ·
non-stationary GRF diffusion models flow matching VAE climate benchmark
Key Metric
66×
VAE's whitened Bures-Wasserstein covariance error (Buresk = 35.25) vs. the oracle finite-sample floor (0.532) — a gap the field's default CRPS metric completely misses, scoring all four models within 2% of each other (0.85–0.87).
Why This Matters
CRPS — the field's default distributional metric — can't detect these covariance failures, so climate-downscaling models could pass evaluation while getting spatial structure wrong.
Critical Edge
Hyperparameters were never jointly retuned across model families — VAE's collapse may reflect a weak baseline, not an intrinsic ceiling for latent-variable models.

Methodology

KNOWN DGP
32×32 grid; mean = polynomial + sinusoid; non-stationary Matérn covariance with range β(s) 0.12→0.50; nugget τ²=0.3.
→
4 DGM FAMILIES
FM, DDPM, score-SDE share a 4.43M-param U-Net; VAE uses a 3.9M-param encoder-decoder (within 12%). Matched steps & ~200-eval sampling budget.
→
2 REFERENCES
Oracle (independent true-GRF draws) and a stationary control (β(s) fixed to φ=0.25).
→
DECOMPOSED METRICS
Buresk, tot-var, σ̂²/τ̂², NS-grad, corr(β,β̂) — vs. plain CRPS.

The ground truth is Y(s) = μ(s) + Z(s) + ε(s), where Z has a Paciorek–Schervish non-stationary Matérn covariance and ε is i.i.d. pixel noise — a fully known data-generating process, so recovery of mean, covariance shape, variance level, and non-stationarity strength can each be scored against ground truth rather than inferred from summary statistics alone. All four DGM families train on identical 50k-sample data splits with coordinate-aware, non-translation-equivariant architectures so they can in principle learn location-dependent dependence. Local-window Matérn fits (3×3 windows, ν fixed at its true value) recover per-window β̂(s), σ̂², τ̂², aggregated into NS-grad and corr(β,β̂); Buresk and tot-var instead compare the empirical sample covariance directly against the true covariance's leading eigenspace. A four-parameter DGP sweep (σ², τ², ν, training size), 5-seed retraining, and a memorization check test robustness; the same pipeline is then re-run on real ERA5 2m-temperature anomalies (WeatherBench-2), substituting a held-out empirical reference for the unavailable true DGP.

Strengths

  • A known non-stationary ground-truth DGP directly diagnoses covariance failures (e.g. VAE's τ̂²→0 nugget collapse) invisible to observation-only diagnostics like CRPS.
  • Decomposed metric suite separates "how wrong" into mean vs. correlation-shape vs. variance-level vs. non-stationarity-degree, instead of one aggregate score.
  • Matched parameter counts (4.43M vs. 3.9M, within 12%), optimizer steps, and sampling budgets (~200 evaluations) rule out compute/capacity mismatches as the explanation.
  • Robustness sweep (σ², τ², ν, training size) plus 5-seed retraining and a memorization check support the ranking beyond one configuration.
  • ERA5 extension shows the framework generalizes to real climate data even without a true DGP, via a held-out empirical reference.

Limitations

  • Each DGM uses its standard reference implementation with hyperparameters not jointly retuned across families — results describe "standard" configs, not each family's best achievable calibration.
  • 32×32 synthetic grid is small relative to operational climate-downscaling resolutions; unclear if the ranking holds at larger scale.
  • Local-window covariance fitting fixes the true smoothness ν and assumes local stationarity per 3×3 window — injecting ground-truth information the DGM never had.
  • ERA5 evaluation has no true DGP, so findings are validated only descriptively against a held-out reference, with train/test temporal shift not fully disentangled from model failure.
  • Main benchmark realizations come from a single random seed; only the models, not the underlying DGP draw, are re-seeded for robustness.

Questions for Further Exploration

  • Would jointly tuning each DGM family's hyperparameters narrow the VAE-vs-diffusion gap, or is the nugget-variance collapse structural to any deterministic-decoder VAE regardless of tuning?
  • Does DDPM's anomalously large MSEμ (42× the oracle floor) persist under a different noise schedule, prediction target, or step count, or is it an artifact of this v-prediction/cosine/DDIM configuration?
  • How do Buresk, NS-grad, and corr(β,β̂) behave at higher resolution (e.g. 128×128 or km-scale grids) where non-stationary structure is far richer?
  • Would hierarchical VAEs, heteroscedastic-decoder VAEs, or consistency models close the gap identified for the vanilla ELBO-VAE with deterministic decoding tested here?
  • Can the local-window covariance diagnostic jointly estimate smoothness ν (rather than fixing it at ground truth) without losing power, so the framework applies fully "blind" on real data?
