AI for Science

A rare case: an AI agent beats a human-engineered benchmark, not just matches it. OmniQEC: An AI Scientist Discovers Quantum Error-Correcting Codes

Ge Yan · Shanchuan Li · Pengyue Ma · Qixin Zhang · Pingchuan Ma · Jianping Wang · Min-Hsiu Hsieh · Yuxuan Du  ·  arXiv:2607.25865  ·  NTU Singapore et al.

OmniQEC 用 LLM 驱动的"快-慢"双循环智能体框架直接以电路级逻辑错误率（而非代码级代理指标 kd²/n）为优化目标搜索 qLDPC 码，在 240 物理比特预算下发现的码超过了人工设计的 BB [[144,12,12]] 基准，个别前沿码逻辑错误率比 BB [[72,12,6]] 低 29.23 倍。

A "fast-slow" LLM agent loop directly optimizes circuit-level logical error rate to discover qLDPC codes that beat the human-designed bivariate-bicycle benchmark at matched qubit budgets, with one frontier code reaching 29.23x lower logical error rate — AI genuinely outperforming, not just matching, hand-engineered science.

Multimodal Interpretability

CVMA: A Causal Audit of Visual KV Memory in Multimodal Dialog

Hong Chen · Kang Chen · Yuxuan Fan · Bo Wang · Yubo Gao · Yuanlin Chu · Xuming Hu  ·  2607.25467

配对因果干预证明，多模态大模型视觉 KV 缓存淘汰依赖的"当前注意力越高越重要"假设，其实与未来区域效用负相关（Idefics3-8B 达 Spearman -0.576）。

Paired causal interventions show current-turn attention is negatively correlated with a visual region's actual future utility — today's attention-based KV eviction methods are optimizing exactly the wrong signal.

LLM Behavior · Sampling

Instruction-Tuned LLMs Cannot Sample What They Can Describe

Chaemin Jang · Dongman Lee · Jihee Kim  ·  2607.25292

指令微调后的模型逐次采样时坍缩为几乎固定的单一答案（超 94% 的调用返回同一结果），但同一模型能在一次调用内准确"描述"整个目标分布。

Instruction-tuned LLMs collapse to one modal answer in over 94% of independent calls, yet the same model can accurately describe the full target distribution in a single call — challenging "one API call equals one sample."
