Why this matters

For anyone running multi-specialist agent services, the 74% storage cut and emergent prefix-cache reuse are usable today — even as continual learning stays unproven.

Critical edge

The central architectural bet — that joint post-training causes cross-task interference — has no budget-matched single-LoRA ablation. The paper itself calls MoL "a design motivation rather than an empirical finding."

Methodology

Distilled

Macaron-V1-Venti pairs a frozen 744B GLM-5.2 base with four rank-16 LoRA specialists — L0 Chat (which also routes), L1 Agent, L2 Coding, L3 GenUI — each storing ~7.69B values. A Proxy selects exactly one specialist per user turn. Each turn runs a three-hop loop: Route (L0 emits one of four labels via a 24-token constrained decode — no separate router model) → Answer (the specialist generates from its own-view) → Summary (≤192 tokens stored server-side as shared cross-specialist context). Because the timeline is append-only, each specialist's prefix is byte-identical on re-entry, so KV reuse emerges for free on unmodified vLLM/SGLang. The harness is a first-class training target: HCP is a versioned TOML runtime contract (tools, hooks, skills, prompts), and the policy πφ(a|o; θ frozen, c config) deliberately splits GRPO weight updates from configuration search.

Tall build = Qwen3.6-35B-A3B base + four rank-64 adapters (~50.1B). Route→answer→summary overhead ≈ 32% of the three-hop latency on Venti.

Strengths

What holds up
  • Best-in-class evidence hygiene — every caption states what the numbers do not establish; provenance markers split reproduced from imported; negative results reported, not buried.
  • Emergent prefix-cache reuse — the own-view design turns cross-turn KV reuse into a free property of unmodified vLLM/SGLang, with zero engine change.
  • Real artifact release — Venti weights and the MoL serving harness are public on HuggingFace / GitHub, making the routing and serving claims independently checkable.
  • UI4A-Bench actually drives the rendered card in a headless browser and scores zero when a declared interaction produces no evidence — stricter than screenshot-similarity judging.
  • Well-posed RSI question — 4/122 and 11/122 single-config sweeps vs 122/122 adaptive coverage cleanly shows "can't" often means "not elicited."

Limitations

What's missing
  • No cross-generation continual-learning evidence at all — one snapshot, one partial RSI stage; the stated central objective is entirely future work.
  • Missing the architecture-justifying ablation — no budget-matched single-LoRA (4× rank) vs four-LoRA comparison to test the interference premise.
  • Routing measured on training-derived data — 99.12% is an implementation diagnostic, not generalization; no routing audit for PinchBench or ClawGym.
  • Wins cluster on own benchmarks (ChatBench, LivingBench, UI4A) that share source domains with the RSI loop; loses 5 of 6 external agent rows.
  • Single-intent-per-turn routing — a message mixing discuss + code + UI goes wholesale to one specialist; the decomposer is an unshipped branch.
  • No safety/red-team eval, no documented data-consent basis, no per-specialist training spec.

Questions for further exploration

Open
01

Does the 122/122 coverage hold on unseen tasks from the same 29 TerminalBench families? The search ceiling is measured; the generalization number is what decides learning vs overfit.

02

Does the missing budget-matched single-LoRA (4× rank, union data) comparison actually favor MoL? It directly tests the interference premise and is cheap relative to spend so far.

03

How much of the +20.7 UI4A gap is the L3 adapter vs the UI4A runtime? Venti-without-L3 under the same runtime is never reported.

04

Is the 0.2-point LivingBench win stable under a cross-family judge? A non-GLM judge (or human panel) is the highest-value robustness check available.

05

Does per-turn routing degrade on long conversations needing cross-specialist detail? Each specialist sees only 192-token summaries of other turns.

06

What is the real MoL vs merged-replicas serving cost curve under mixed load? Adapter swapping and invalidated KV could erase the 74% storage win at high concurrency.
