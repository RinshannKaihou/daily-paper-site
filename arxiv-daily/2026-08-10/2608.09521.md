> **一句话总结：** 本文提出 Universal Activation Bus（UAB），用 4 个源模型（Llama-3.2-3B / Qwen3-4B / SmolLM2-1.7B / Falcon3-3B）联合训练一个共享 3072 维稠密激活空间和"每模型一对线性 encoder–decoder adapter"，冻结后新模型（OLMo-2-7B）仅需在 1 万条无标注对齐前缀上训练自己的 adapter 就能接入；接入后可直接复用共享线性 probe（macro AUROC 0.959，vs 本地原生 probe 0.963）、单一 SAE 字典（Top-32 特征 Jaccard 0.602–0.613，随机基线约 0.001）和一个为 Qwen2.5-7B 训练的 NLA 解释器（路由后九分类 84.9%，原生 95.3%，随机 11.1%），甚至能把一个模型的中间激活塞进另一个模型冻结的上层继续解码（与后端模型 next-token 一致率 72.4–87.7%，比两个原生模型之间的一致率高 7.5–27.2 个百分点）。

> **TL;DR:** A "one linear adapter pair per model" bus into a shared 3072-d activation space lets interpretability tools be written once and reused across LLMs. Trained on 4 source models (Llama-3.2-3B, Qwen3-4B, SmolLM2-1.7B, Falcon3-3B) over a 118K-doc / 1.42M-matched-position corpus, then frozen; OLMo-2-7B joins by fitting only its own adapters on 10K unlabeled matched positions (ID R@1 rises 88.4→99.6% from 3K→10K positions). A single pooled probe set transfers to onboarded OLMo at 0.959 macro AUROC vs 0.963 for probes fitted natively on OLMo; one shared TopK SAE (32,768 features, k=32) gets Top-32 Jaccard 0.602–0.613 on OLMo pairs (random ≈0.001) while retaining 93.8–98.8% of a natively trained SAE's next-token utility; a frozen Qwen2.5-7B NLA verbalizes routed states at 84.9–94.4% nine-way accuracy vs 95.3% native. Big caveat: a label-free screen *rejected* Phi-3.5-mini, Gemma-3-4B, Mistral-7B, Yi-1.5-6B and Apertus-8B (R@1 0.1–4.7%), so "universal" means "universal over a pre-screened compatible subset," and the paper never benchmarks against a directly trained pairwise translator.

## 核心贡献

- **模型级（而非模型对级）激活契约。** 每个模型只学一对线性 adapter $A^{enc}_m, A^{dec}_m$（d=3072 时约 18.9M 参数），配合两个全局共享的两层残差 MLP $\Phi^{in}, \Phi^{out}$。任意有向路径 $D_n \circ E_m$ 都由两个模型各自的 adapter 组合而成，不存在任何 pair-specific 连接器，因此 N 个模型只需 N 对 adapter 而非 O(N²) 个 translator。
- **冻结后的向后兼容 onboarding。** 源训练完成后共享模块和已有 adapter 全部冻结，新模型只用无标注 matched prefix 优化自己的 adapter，损失为"自重构 + 对齐到源模型 consensus 中心 $c(x)=\frac{1}{|S|}\sum_m z_m(x)$"。已有坐标、已有路径、已有工具在构造上不可能被改变。
- **三种工具复用形态。** 共享空间工具 $Q(E_m(h_m))$（线性 probe、SAE）训练一次可用于所有连接模型；carrier-specific 工具 $Q_c(D_c(E_m(h_m)))$（如 NLA）通过解码回 carrier 原生空间被间接复用。
- **跨模型状态执行。** 把 $D_B(E_A(h_A))$ 插入模型 B 的对应层，由 B 冻结的上层直接产出 next token，无需任何 execution-specific 或 direction-specific 训练。
- **诚实的兼容性前置筛选。** 用无标注 ridge 映射对候选模型做 label-free 打分（R@1 > 50% 才保留），并公开报告了被拒绝的 5 个模型，明确不宣称任意模型对都能对齐。

## Key Contributions

- **A model-wise, not pair-wise, activation contract.** One linear encoder + one linear decoder per model, plus two globally shared two-block residual MLPs ($\Phi^{in}$, $\Phi^{out}$) at width D = 3072. All directed translation paths $D_n \circ E_m$ compose from per-model parts, so persistent parameters grow linearly in the number of models (though the all-pairs source objective is quadratic in *training* cost).
- **Freeze-then-onboard with construction-level backward compatibility.** After source training the shared bus and every existing adapter are frozen; a new model optimizes only $A^{enc}_u, A^{dec}_u$ against a self-reconstruction term plus alignment to the frozen source consensus $c(x)$. Existing coordinates, paths and tools provably cannot shift.
- **Three reuse modes demonstrated end-to-end:** shared-space linear probes, one SAE dictionary with shared feature indices across all models, and a carrier-specific natural-language autoencoder (NLA) reached by decoding into its carrier's native space.
- **Cross-model state execution** — an intermediate activation from model A, translated once, is consumed by model B's frozen upper layers to produce a next-token prediction, with no execution-specific training.
- **A label-free compatibility screen** using a closed-form ridge map to a fixed Llama-3.2-3B reference, with the rejected models reported rather than quietly dropped.

## Methodology

**Activation extraction and matching.** For each model $m$, the paper takes the residual-stream activation at the *final token* of a raw-text prefix, after the block at normalized depth 0.5 ($\ell_m = L_m/2$; the NLA carrier uses its released layer 20). Because tokenizers segment text differently, prefix endpoints are sampled as byte offsets and kept only if they coincide with a token boundary in *all four* source tokenizers. Leave-one-out coverage shows ≥99.83% of these endpoints are also valid boundaries for a held-out tokenizer, so this constraint costs almost nothing.

**Normalization.** Each model gets a fixed $N_m$: per-dimension z-score (with $\sigma$ stabilized by 1e-6) followed by regularized ZCA whitening ($\rho = 10^{-2}$ added to eigenvalues, no dimensional truncation). Statistics are estimated once from ~200K activations in float64 and frozen thereafter; $N_m^{-1}$ restores decoded states to native coordinates.

**Architecture and objective.** $E_m = \Phi^{in} \circ A^{enc}_m \circ N_m$, $D_m = N_m^{-1} \circ A^{dec}_m \circ \Phi^{out}$. The training loss is $\mathcal{L}_{bus} = \mathcal{L}_{self} + \lambda_{cross}\mathcal{L}_{cross} + \lambda_{nce}\mathcal{L}_{nce}$ with $\lambda_{cross} = 1.0$, $\lambda_{nce} = 0.1$, InfoNCE temperature $\tau = 0.07$, all losses computed in normalized space. $\mathcal{L}_{cross}$ requires that model $m$'s state, decoded into model $n$'s space, matches $n$'s own activation on the same prefix — notably it does *not* require the native activations to be identical, only readable.

**Corpus and training.** 118,563 documents (OpenWebText 84.3%, Alpaca 8.3%, CodeContests 5.3%, GSM8K 2.1%), 1,422,735 matched positions, 98/2 document-level split. Source interface: AdamW, adapter LR 1e-3, shared LR 3e-4, cosine schedule, batch 4,096, 12,000 steps, bf16. Onboarding: constant LR, 3,000 steps, batch 4,096, only the new adapter pair updated.

**Evaluation.** Intrinsic — cross-model retrieval R@k over 3,600 in-distribution positions and 3,600 OOD texts from nine behavioral axes (refusal, math, science, factual, sycophancy, toxicity, sentiment, emotion, bias; 400 texts each, sourced from wildjailbreak, GSM8K, GPQA, MMLU-Pro, sycophancy-eval, civil_comments, SST-2, dair-ai/emotion, BBQ) — plus self-FVE round-trip fidelity and bus ΔCE. Downstream — pooled ℓ2 logistic probes (scikit-learn, C=1, lbfgs) trained *only* on source-model shared states and applied unchanged to OLMo; one TopK SAE (32,768 features, k=32, aux k=256) trained on 400K model-balanced shared states from the four source models with OLMo excluded; the released Qwen2.5-7B NLA (verbalizer + reconstructor) used with zero weight changes. Execution — 1,000 held-out prefixes per direction, only the final-position state replaced, receiver's KV cache untouched.

## Results & Highlights

- **Cross-model retrieval is essentially saturated in-distribution, softer OOD.** Under leave-one-out onboarding, ID R@1 is 99.6–100.0% for every model (OLMo, the onboarded one, is the weakest at 99.6–99.7%). Behavioral OOD R@1 falls to 60.8–78.7% but R@10 stays at 79.6–90.8% — the paper attributes the gap to many near-duplicate texts within each axis, which is plausible but means OOD R@1 is not a clean identity metric.
- **Shared probes match natively fitted probes, including on a model never seen during probe training.** Pooled probes trained only on the four source models reach macro AUROC 0.966 across sources vs 0.963 for probes fitted separately in each native space; applied *unchanged* to onboarded OLMo they get 0.959 macro AUROC and 0.954 nine-way accuracy. The catch: the axes are mostly trivial — math and sycophancy are 1.000, toxicity 0.999, so the headroom over native probes is essentially zero by construction. The only hard axes are emotion (0.807–0.888) and bias, where the transferred probe *loses* meaningfully on OLMo: 0.853 vs 0.950–0.990 for native probes on the source models.
- **One SAE dictionary generalizes with no onboarding gap.** Top-32 active-feature Jaccard across source pairs is 0.591–0.614; pairs involving OLMo — which was excluded from SAE training entirely — land at 0.602–0.613, i.e. inside the source range, against a random-overlap floor of ≈0.001. Functionally the shared SAE costs more than a native one (ΔCE 0.268 vs 0.090 nats on Llama, 0.349 vs 0.061 on Qwen3, 0.398 vs 0.128 on OLMo), but relative to the zero-state ablation (ΔCE 4.485–8.682 nats) it retains 93.8–98.8% of native-SAE utility, with FVU 0.132–0.145 on sources and 0.106 on OLMo and no dead features.
- **A frozen Qwen2.5-7B NLA verbalizes other models' states well above chance.** A TF-IDF + logistic nine-way classifier trained *only* on native-carrier verbalizations scores 95.3% on native Qwen2.5, 88.2–94.4% on routed source models (SmolLM2 94.4%, Llama 91.1%, Qwen3 90.2%, Falcon3 88.2%) and 84.9% on onboarded OLMo, against 11.1% chance and 0.7% for a deliberately mismatched cross-axis control. AR reconstruction cosine is 0.820–0.848 routed vs 0.866 native, with a mismatched-input floor of ~0.328, i.e. 91.6–96.1% retention. Interesting side note the authors flag honestly: the same classifier on the *raw input texts* only reaches 79.6%, so verbalizations are more separable than the originals.
- **The NLA route has one sharp failure the aggregate hides.** OLMo per-axis recall is 86–100% on eight axes but **6% on sentiment** (vs 100% native carrier, 92–98% for routed sources). Since the direct shared-space probe *does* recover OLMo sentiment, the authors localize the failure to carrier routing/verbalization rather than the shared representation — a good diagnosis, but it shows the carrier-routing path is not uniformly reliable.
- **Translated states are executable, and the receiver dominates the output.** Composed A→B predictions agree with native B on 72.4–87.7% of next tokens, versus native A–B agreement of only 58.7–67.2%, a gain of +7.5 to +27.2 percentage points in *every one of the 20 cross-model directions* (largest: Llama→Falcon3 87.7% vs 60.5%, +27.2 pp). Agreement with native A stays near the A–B baseline (59.8–68.4%). Self-paths retain 92.4–97.8%. Cross-entropy penalty is small into Llama/Qwen3/SmolLM2/Falcon3 (−0.023 to +0.071 nats) but jumps to +0.273 to +0.381 nats when OLMo is the receiver.
- **Round-trip fidelity is the weak link and correlates with width.** Source models retain self-FVE 0.982–0.989 with bus ΔCE of −0.010 to −0.002 nats (slightly *better* than native), but OLMo ($d=4096 > D=3072$) gets 0.734 with ΔCE +0.043. Across ten extra onboarded checkpoints, self-FVE ranges 0.591 (Qwen3-14B) to 0.980 (Llama-3.2-1B), with Qwen3-8B at 0.731 and Llama-3.1-8B at 0.735 — yet all eleven onboarded models still hit ID R@1 99.9–100.0% and assign all 9/9 behavioral axes correctly (99/99 model–axis cases). Alignment and reconstruction genuinely decouple.
- **Onboarding is cheap.** OLMo R@1 goes from 88.4–89.5% at 3K calibration positions to 99.6% at 10K, with no material gain at 30K or 100K — one tenth of the default budget. Self-FVE is less forgiving: −0.550 at 3K (worse than predicting the mean), 0.696 at 10K, 0.722 at 30K, 0.734 at 100K.
- **Seed and depth robustness is good.** Three full source runs give ID R@1 99.949 ± 0.008% and mean self-FVE 0.9851 ± 0.0001; sweeping cut depth 0.25→0.75 moves OLMo self-FVE only 0.771→0.762. Full-space (D=3072) behavioral geometry: same-axis direction cosine 0.815 vs −0.014 across different axes; OLMo-involving pairs 0.807 vs 0.820 source–source.

## Critical Assessment

**Novelty (moderate-to-good).** The individual ingredients — contrastive alignment of activations, linear adapters, whitening, shared SAEs (USAE, SPARC), cross-model verbalizers (UAV, Atlas-Alignment) — all exist. The genuinely new bit is the *protocol* framing: freezing the hub so that adding the (N+1)-th model provably cannot perturb the existing N models' coordinates or the tools built on them. That is a real engineering-and-governance property that pairwise translators cannot offer, and the leave-one-out + freeze-then-onboard protocol is the right way to test it.

**Rigor (mixed, with one serious gap).** The strongest complaint is the *absence of the obvious baseline*: the paper's related-work section names pairwise stitching/translation methods (Chen et al. 2025; Oozeer et al. 2025; Moschella et al. 2023) as the incumbent approach, yet no table ever compares UAB against a directly trained pairwise connector for the same model pair on the same probe/SAE/execution tasks. The claim "model-wise beats pair-wise" is therefore argued structurally, not measured. In the execution experiment specifically, the "gain" is computed against *native A–B agreement* — the agreement between two entirely different models, ~60–67% — which is not a competing method at all; a pairwise-trained stitch would be the real comparison, and it is absent.

**The compatibility screen is doing a lot of load-bearing work.** Table 13 rejects Phi-3.5-mini (1.7% R@1), Gemma-3-4B (1.0%), Mistral-7B (2.6%), Yi-1.5-6B (4.7%) and Apertus-8B (0.1%) — five of ten candidates. The word "universal" in the title is doing more work than the results support; the honest reading is "universal across a pre-filtered clique of mutually linearly-alignable models." To their credit the authors state this restriction explicitly in Section 4 and note the screen is sharply bimodal (≥90% retained vs ≤5% rejected, nothing near the 50% threshold), which makes the screen at least principled rather than tuned. But nothing in the paper explains *why* Gemma and Mistral fail, which is arguably the more scientifically interesting question.

**Missing ablations.** (1) No sweep on the shared dimension D. The single most repeated failure mode in the paper — OLMo self-FVE 0.734, Qwen3-14B 0.591 — is attributed to $d_m > D = 3072$, yet D is never varied to test that hypothesis. (2) No ablation on the loss terms: $\lambda_{cross}$ and $\lambda_{nce}$ are fixed at 1.0 and 0.1 with no evidence that either term is necessary or that the whitening step matters. (3) The source-count study (self-FVE 0.712 / 0.723 / 0.734 for 2 / 3 / 4 sources) uses a single nested chain, which the authors correctly note is not an average over source combinations — but it also means the "more source diversity helps" claim rests on a 0.022 delta from n=1 run per setting. (4) The 3K-calibration point confounds pool size with a smaller batch size, as the appendix admits.

**Scope caveats the paper is honest about.** Only the *final-position* state at *one* layer is translated; the receiver's context and KV cache are untouched. This is "matched-context state execution," explicitly not full-sequence stitching, and the authors say so. Similarly the Table 6 qualitative example (Qwen→Llama producing a self-contradictory "I am not an AI model, I am a language model") is presented as evidence *against* full model replacement rather than spun as a success.

**Overclaiming check.** The abstract's "establish a stable, model-wise activation contract" is defensible. Steering is invoked as motivation in the introduction (Rimsky et al. 2024 is cited) but never actually tested — there is no cross-model steering experiment, only probes, SAE, NLA and next-token execution. That's a soft overclaim by omission.

**Reproducibility (good).** Code released; every checkpoint is a named public HF model; corpus composition, split ratios, all hyperparameters (Table 12), normalization details, probe settings (C=1, lbfgs, max_iter=2000, seed 42) and SAE settings are specified. Seed variance is reported over three full runs. A determined reader could rebuild this.

**Significance (moderate).** If the interpretability community wanted a shared activation registry, this is a credible protocol sketch. Whether anyone adopts it depends on whether the compatible-model clique is large enough to matter — and the screen rejecting Gemma and Mistral is not encouraging.

## Strengths

- The freeze-then-onboard protocol is the correct experimental design for the claim being made, and leave-one-out onboarding of every one of the five main models (not just OLMo) is more thorough than the headline requires.
- Genuine negative and control results are reported rather than buried: the −0.550 self-FVE at 3K calibration, OLMo's 6% sentiment recall, Qwen3-14B's 0.591 self-FVE, the rejected candidate models, the mismatched-input control (cosine ~0.328) and the cross-axis label control (0.7% vs 11.1% chance).
- The qualitative SAE features in Table 3a are explicitly disclosed as drawn from the high-overlap group (median feature-level Jaccard 0.569, 90th percentile 0.778) *before* inspecting their text examples — a level of cherry-picking disclosure most papers skip.
- OLMo being excluded from SAE training and still landing inside the source-pair Jaccard range (0.602–0.613 vs 0.591–0.614) is a clean, hard-to-fake result.
- The decoupling of retrieval alignment from round-trip reconstruction is documented rather than hidden, and is a genuinely useful finding: near-perfect shared-space retrieval does not require faithful native reconstruction.
- Tokenizer handling via byte-offset matched prefixes with ≥99.83% leave-one-out boundary coverage is a clean, cheap solution to an annoying practical problem.

## Limitations

- **No comparison to pairwise translators/stitchers**, the actual incumbent method class. The central "one adapter pair beats O(N²) connectors" claim is never quantified against one.
- **"Universal" is conditional on a screen that rejected half the candidates**, including three very widely used models (Gemma-3-4B, Mistral-7B, Phi-3.5-mini). No explanation is offered for why they fail.
- **Fixed D = 3072 caps wide models.** Any model with $d_m > D$ pays a large fidelity penalty (OLMo 0.734, Qwen3-14B 0.591), and D is never ablated.
- **Behavioral axes are mostly saturated**, so "shared probe ≈ native probe" (0.966 vs 0.963) is a weak test. The one contested axis, bias, shows a real transfer loss on OLMo (0.853 vs 0.950–0.990 native).
- **Execution is single-position only**, at a single half-depth cut, with the receiver's KV cache intact — a functional probe, not model stitching. Generation quality after the first token is not evaluated.
- **All source models except Falcon3 are instruction-tuned English models at 1.7B–4B scale**, and the corpus is 84% OpenWebText; multilingual, multimodal, and much larger models are untested at the source-training stage.
- **No steering/intervention transfer experiment**, despite activation steering being cited as motivation.
- **Training cost of the source objective is quadratic in the number of source models** (all-pairs cross-reconstruction + all-pairs InfoNCE); only the persistent parameter count is linear.

## Relevance

如果你（用户）关注可解释性工具的跨模型迁移（SAE 特征字典复用、probe 迁移、activation steering 的通用化）或表征对齐 / Platonic Representation 这条线，这篇提供了一个可复现的"冻结中枢 + 每模型一对线性 adapter"协议，其中"对齐好但重构差"的解耦现象和 label-free 兼容性筛选（Gemma / Mistral 被拒）对判断该路线的适用边界很有价值。反过来，如果你更关心跨模型推理加速或真正的 model stitching，本文只验证了单 token 位置的状态注入，参考价值有限。

## Questions for Further Exploration

- Why do Gemma-3-4B, Mistral-7B and Phi-3.5-mini fail the ridge screen so catastrophically (R@1 1.0–2.6%) while Falcon3-3B passes at 99.3%? Is it tokenizer/training-distribution, normalization layer placement (e.g. QK-norm, non-standard residual scaling), or genuine geometric incompatibility? A diagnostic here would be more valuable than the whole bus.
- Does raising D above max($d_m$) — say D = 4096 or 8192 — recover OLMo's and Qwen3-14B's self-FVE, or is the bottleneck the linearity of the adapters rather than the dimension?
- How does UAB compare head-to-head against a directly trained pairwise translator (Chen et al. 2025 style) on the same probe/SAE/execution tasks — how much fidelity is actually sacrificed for the O(N) property?
- Does the interface survive multi-position translation? Replacing the full prefix of states rather than only the final position would turn the execution experiment from a functional probe into real stitching.
- Do steering vectors computed once in Z transfer as cleanly as probes do? The mean-difference directions in Eq. 11 are already computed — applying them as interventions through $D_m$ is a one-experiment addition and would close the gap between the paper's motivation and its evidence.
- Does the frozen interface degrade as the number of onboarded models grows into the dozens, since every new model is aligned to a consensus computed from only the original four sources?
- Why is OLMo's NLA sentiment recall 6% when its shared-space sentiment probe works? Is this an artifact of the carrier decoder's null space, or of the verbalizer's prompt sensitivity to slightly off-manifold Qwen2.5 activations?
