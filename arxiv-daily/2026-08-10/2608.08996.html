Methodology

distilled

The unit of evolution is a program that generates an entire parameterized code family (indexed by scaling t), not a single parity-check matrix.

L1 · local terms L2 · protograph L3 · subgroup action L4 · host group

A new four-level representation generalizes the three-level lifted-product SCE by making the subgroup action an independent mutation target — opening the true balanced-product region (non-normal K). A deterministic assembler projects onto canonical double-coset reps and applies balanced-product incidence rules to emit H_X, H_Z.

A fixed evaluator instantiates t ∈ [1,500], skips groups of order > 20,000, keeps 40 ≤ n ≤ 400, and retains a point only if H_X H_Zᵀ = 0 and k > 0. Proxy score Q_proxy = k·d̃²/n with a d̃ = min(d_ub, 1.3√n) cap stops loose bounds dominating selection.

Two coupled loops: MAP-Elites program evolution (niches = group family × subgroup × rate bin × weight) + a researcher-council / curator layer writing falsifiable lessons and anti-lessons. Distance verification is staged 10⁴ → 10⁵ (auto) → 10⁶ (curator-commissioned); exact distances require Gurobi MILP global-optimality proof with a replayable witness.

Strengths

5
  • Careful distance handling: MILP global-optimality certification + replayable 𝔽₂ witnesses; never reports uncertified as exact.
  • Honest losses reported plainly at w=6 and the w=8 upper-bound endpoint — increases trust in the w=7/9/10 wins.
  • 1,209-instance, 91-source, evidence-labeled comparison set — far more thorough than typical 1–2-baseline work.
  • Four-level representation fires mutations at every level (1×1 → 5×5 shapes; free / normal / non-normal actions).
  • Self-directed falsification: re-measures a literature weight-ten code to verify the pseudo-threshold trend is not an artifact.

Limitations

7
  • No ablation of the agent architecture — the central claim is untested against fitness-only evolution.
  • No compute/cost accounting (candidates, tokens, wall clock, # campaigns) — efficiency claims unverifiable.
  • Code-capacity noise only: no circuit-level noise, syndrome circuits, or hardware layout / routing despite "practical" framing.
  • Several headline Q values are uncertified upper bounds (up to ≤ 84.02) that may collapse.
  • Decoder is fixed BP-OSD, not in the search loop; the Q-vs-pseudo-threshold anticorrelation exposes objective misalignment.
  • Search scoped to binary CSS, n ≤ 400, 6 ≤ w ≤ 10, groups ≤ 20,000 — the "lifted products intrinsically favored" conjecture is scoped to this window.
  • Code/data not yet released; agent stack hard-depends on specific proprietary model versions (Opus 4.8 / Sonnet 5).

Open Questions for Further Exploration

  2. How many candidates were evaluated, and did agent-directed verification tighten more bounds per unit compute than uniform escalation?

  4. Under circuit-level noise with a real syndrome-extraction schedule, do the w=9/10 champions retain any advantage — given their pseudo-thresholds are already worst (5.40–6.55%)?
  5. Does the "lifted products intrinsically favored" conjecture break at n > 400 or w > 10, where genuine balanced-product geometry has room to pay off?
  6. Would putting decoder feedback (or a girth ≥ 6 constraint) into Q change which niches the archive fills?
