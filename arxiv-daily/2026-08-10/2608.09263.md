> **一句话总结：** Salesforce AI Research 用形式化命题 + gpt-oss-20b 在 AIME 2025 上的严格配对实验证明：把「特权上下文下 token 对数似然的变化」当作 token 级 credit 是站不住脚的——他们实际实现的加性 token 分数区分正确/错误轨迹的 AUC 仅 0.505（长度校正后 0.474，反而略偏好错误轨迹），而五种使用该分数的完整训练配方在 avg@4 上全部落后于仅用结果奖励的对照组（64.2% vs 24.2%–33.9%，差距 −30.4 到 −40.0 个百分点，exact p ≤ 1.8×10⁻⁴）。

> **TL;DR:** Privileged self-distillation rescores a model's own rollout with training-only hindsight feedback and treats the resulting token log-likelihood change as outcome credit. This paper separates that into three checkable questions (does the score track success? is the feedback held out from the rollout it scores? what does the loss actually reinforce?), proves the corresponding propositions, and then instantiates them on gpt-oss-20b / AIME 2025. The implemented additive token score reaches only AUC 0.505 [0.483, 0.524] at ranking correct above incorrect trajectories (0.474 after length adjustment, i.e. slightly *anti*-predictive), essentially matching the 0.503 identical-feedback null; and in a matched paired comparison at shared update 49 the outcome-only control hits 64.2% avg@4 while all five token-score recipes land at 24.2%–33.9% (−30.4 to −40.0 pp, exact sign-flip p from 1.755×10⁻⁴ down to 9.537×10⁻⁷). Worth reading if you build or trust OPSD/RLSD/RLCSD-style token-level distillation rewards; it is a diagnostic framework plus a strong negative result, not a new algorithm.

## 核心贡献

- **提出三问框架**：把「特权自蒸馏」拆成三个必须分别验证的问题——Q1 token 分数是否追踪任务成功；Q2 被打分的 rollout 是否在同一套 feedback 规则下被比较；Q3 训练损失最终强化了什么行为。通过其中一个不蕴含通过其余两个。
- **形式化不等价性**：证明 token 似然差 d(s,v) 与动作价值 Q^π_U(s,v) 局部正仿射等价的充要条件是 d = α(s) + β(s)Q（β>0）；并给出反例说明「排序一致」不足够（Q=(0,1,2) 与 d=(0,1,4) 排序相同但仿射不等价，因此 AUC / 秩相关通过也不能证明等价）。
- **纠正两个常见误读**：(1) forward-KL 分解中的条件互信息 I(V;C|S) 在教师目标与状态/上下文分布固定时对学生是常数损失下限，既不是额外梯度也不含效用 U，所以「特权上下文改变了教师分布」不能作为其有用的证据；(2) 保持 token 权重为正、符号不变、均值为一，并不保持期望策略梯度向量（两坐标反例：均匀权重给 (1/8, 1/8)，权重 (2−ε, ε) 给 ((2−ε)/8, ε/8)）。
- **cross-fitting 的正确定位**：证明按 fold 划分、用同题另一条 rollout 写的 held-out feedback 可去掉目标轨迹对自身打分上下文的直接依赖（C ⊥ Y^tar | X, F），但明确指出这只验证「算的是哪个比较」，不验证「这个分数有用」。
- **配套负结果实验**：在 gpt-oss-20b + AIME 2025 上做同初始化、同数据、同 verifier 的六路配对训练（1 个 outcome-only 对照 + 3 个 additive 变体 + 2 个 KL 正则变体），并辅以 AUC 诊断、熵/KL/长度遥测、等价答案重判审计。

## Key Contributions

- A three-question diagnostic protocol (score meaning → feedback construction → induced update) for any method that turns privileged-context likelihood into token-level supervision, with the explicit claim that these are logically independent checks.
- Proposition 1 (exact local affine equivalence) pinning down when a token score can stand in for action value, plus the ranking counterexample showing AUC-style evidence is strictly weaker.
- Proposition 2 corrective: the conditional-mutual-information term in the frozen forward-KL projection identity is a constant loss floor w.r.t. the student, not an extra gradient and not a task-error measure.
- Proposition 3 (target-side independence under cross-fitting) with the five structural tests actually run (polarity reversal negates contrasts; C⁺=C⁻ yields a numerical null through the real distributed scoring code; target ID never appears in its own feedback records; donor shuffling across prompts; template-only pairs).
- Proposition 5: positivity + sign preservation + mean-one normalization do not conserve the expected policy-gradient estimate.
- Proposition 4: for a confident student (mass 1−ε on y), the logit-gradient magnitudes of reverse KL, generalized JSD, and a bounded detached reward scale as Θ(ε log 1/ε), Θ(ε log 1/ε), O(ε), while forward KL approaches 1−q_y — i.e. three of the four fixed objectives essentially stop correcting a confident model.
- A full provenance/reproducibility spec (feedback content hashes, donor IDs, fold assignment, judge model/version, score reduction, clipping order) and a pre-replication freeze list.

## Methodology

The studied system is deliberately one concrete instance, not a new algorithm. `gpt-oss-20b` (reasoning effort: low) samples K solutions per AIME 2025 problem; a verifier labels each correct/incorrect. An **external** LLM judge (gpt-5-mini for some score datasets, gpt-5.6-luna for the implemented-additive run) reads the prompt, reference solution, verifier verdict, and full reasoning trace, then writes a helpful text C⁺ and a matched-but-wrong counterpart C⁻. Crucially, the judge only writes text — a *frozen or earlier copy of gpt-oss-20b itself* supplies the token probabilities, so this is not a policy-as-judge setup.

Two scores are defined. The one-sided teacher–policy residual e⁺(s,v) = log q_θ̄(v|s,C⁺) − log π_old(v|s), whose trajectory sum equals log[q(Y|X,C⁺)/π_old(Y|X)]. The two-sided contrast d(s,v) = e⁺ − e⁻ = log q(v|s,C⁺) − log q(v|s,C⁻), which cancels the policy term exactly and whose trajectory sum is a sequence-level log-likelihood ratio between the two context-conditioned distributions. A policy-weighted same-state baseline b = Σ_v π_old(v|s)d(v) is subtracted to get A^C = d(V) − b.

Six matched training recipes share initialization, data, optimizer, rollout batch, verifier, evaluation prompts, post-combination advantage clipping to [−1,1], and PPO ratio clipping; they differ only in how A^C enters. Outcome-only sets the dense coefficient identically zero (verified in the log). Three additive variants add 0.5·tanh(A^C/0.5), gate it off when the leave-one-out outcome coefficient is zero, and forbid it from flipping the outcome sign; they differ by an entropy multiplier min(1, H/0.2) and/or clipping d to [−2,2] before centering. Full KL uses F_R = α·E_π[d] − β·KL(π‖q₀) with α=β=1; Projected KL keeps only the component along the score direction, scaled by κ=0.25. Note the implementation uses a *clipped shaped* reward A^R = clip(R_i − mean_{j≠i} R_j, −0.5, 0.5), not the binary A^U of the exposition.

Evaluation: avg@4 on AIME 2025 test with an equivalent-answer grader (extract boxed answer, exact-normalized then symbolic then numeric fallback, domain restrictions respected), paired prompt-level bootstrap (500 or 20,000 replicates), exact sign-flip tests, and a checkpoint-selection rule that picks the largest *shared* update (49) using only checkpoint existence — never accuracy — though the authors concede this rule was written after the runs existed and is therefore a retrospective safeguard, not preregistration.

## Results & Highlights

- **Q1, discrimination is at chance.** The implemented additive score gets raw pooled AUC **0.505 [0.483, 0.524]** on 4,258 gradeable trajectories (2,678 correct / 1,580 incorrect, updates 1–44); the identical-feedback null control gets **0.503 [0.499, 0.507]** — i.e. the real signal is statistically indistinguishable from a construction guaranteed to carry no information. After linearly removing the length-explained component the AUC drops to **0.474**, below chance, meaning it slightly favors *incorrect* traces. Within-prompt AUC is 0.499.
- **The one apparently-strong row is the self-dependent one.** Own-rollout feedback reaches raw AUC 0.588 [0.500, 0.673] and within-prompt 0.609 [0.542, 0.670] — but it is scored with feedback written about the very rollout being scored, and its response join is weak (3,361/4,953 unique matches, 1,425 ambiguous, 167 unmatched). The held-out (cross-fitted) rows that remove this loop collapse back to 0.512 [0.440, 0.579] (masked feedback, mean) and even **0.416 [0.347, 0.484]** for correct-fact feedback — a reversal, not a small drop.
- **Q3, the headline training result.** Paired AIME 2025 avg@4 at shared update 49: outcome-only **64.2–64.3%** vs additive+entropy **33.9%** (−30.4 pp [−42.9, −17.9], p=1.755×10⁻⁴), additive+bounded **27.5%** (−36.7 pp, p=1.240×10⁻⁵), additive+both **30.0%** (−34.2 pp, p=7.629×10⁻⁶), full KL **24.2%** (−40.0 pp, p=1.907×10⁻⁶), projected KL **25.0%** (−39.2 pp, p=9.537×10⁻⁷). All five clear a Bonferroni threshold of 0.005 over the ten method-by-update contrasts.
- **The gap is a training-dynamics effect, not an initialization artifact.** At update 1 the same comparison gives outcome-only 27.5% vs 23.3–25.8%, effects of only −1.7 to −4.2 pp with p ∈ [0.23, 0.78] — all statistically indistinguishable. The runs start together and separate over training (Figure 2/4).
- **The one-sided teacher down-scores everything.** Mean sampled-token residual is −0.0334 for correct rollouts and −0.0502 for incorrect ones, negative in 18/18 logged updates; the correct-minus-incorrect gap is only **+0.0167**. In fixed-rollout audits, **99.49%** and **99.28%** of regraded correct trajectories have a negative complete-trajectory teacher–policy log ratio E⁺ — the "teacher" assigns *lower* likelihood to the successful paths the policy actually produced (audit AUCs 0.435 and 0.512).
- **The score is active but points at the wrong tokens.** In an audited ungated additive run, **55.81%** of prompt groups had a zero leave-one-out outcome coefficient, so the token likelihood difference was the *only* active training coefficient there; and **57%–71%** of absolute scalar weight fell in the highest-entropy token decile. Additive variants drifted to token entropy 0.130 and reference-KL 0.18 through update 25; the KL-regularized variants stayed in the outcome-only range yet captured none of its accuracy gain.
- **Ruling out the obvious confounds.** Lower accuracy is not truncation: at update 49 the outcome-only run was 76.7% boxed-and-complete with 23.3% truncation, while the five token-score runs were 94.2–98.3% boxed and only 0–4.2% truncated — they finished *more* often and still scored worse. Grading is not the explanation either: equivalent-answer regrading changed 8.3–14.8% of gradeable score-audit labels but only **7/53,068 = 0.013%** of matched-run labels.
- **The information itself is not useless.** In a small pilot, the external judge given the same inputs picked the better of two same-prompt solutions in **51/54 valid calls (94.4%)** — 79.7% if the ten calls unresolved after a 100-attempt cap are counted as failures. So privileged information can support a useful comparison; the base model's token likelihood is simply not how to extract it. Only one pair joined reliably to a stored likelihood score, so the pilot cannot directly contrast the two.

## Authors & Credibility

All six authors are at Salesforce AI Research; Shafiq Joty leads a well-known NLP group there and Xuan-Phi Nguyen (corresponding, xnguyen@salesforce.com) has a substantial LLM/multilingual track record. The paper is a preprint (Salesforce AI Research template, arXiv 10 Aug 2026). The related-work section is unusually current and honest, situating the result against a whole 2026 wave of OPSD-family methods (OPSD/Zhao, SDPO/Hübotter, RLSD/Yang, RLCSD/Pan, CriPO/Xia) and against concurrent failure-mode papers (Kaur et al., Kim et al., Fu et al., Luo et al., Zhu et al.). The tone is notably non-triumphalist: the conclusion explicitly says "this does not imply that all self-distillation fails" and the limitations section is one of the more candid ones you will read.

## Critical Assessment

**Novelty.** The individual identities (affine equivalence, Bayes odds, Bregman/KL centroid, score-function estimators, softmax gradient rates, Gibbs) are, as the authors themselves state in a "Novelty boundary" paragraph, standard or known adaptations. The genuinely new pieces are narrow: the observation that the conditional-mutual-information term in the frozen forward-KL decomposition is a constant floor rather than a task gradient (a correction to how Yang et al. 2026a-style arguments are read), and the non-conservation of parameter gradients under mean-one positive token weights. The synthesis into three checks is the real contribution and it is a framing contribution, not a technical one.

**Rigor — the good.** This is unusually careful negative-results engineering: an identical-feedback null that runs through the *same* distributed scoring code, polarity-reversal tests, donor shuffling, a different-problem control, prompt-cluster bootstrap, exact sign-flip tests, an accuracy-blind checkpoint-selection rule, and a completion-telemetry check that pre-empts the obvious "your baseline just truncated less" rebuttal (the opposite is true).

**Rigor — the problems.** (1) The **feedback templates are broken in exactly the way that would manufacture this result**: across 116,542 parsed feedback pairs, *every* positive text masked values with "work this out yourself" while negatives supplied explicit near-miss numbers, formatting instructions appeared almost only in positives, and positives were on average 217.4 / 207.9 characters longer. That is a length-and-style confound sitting directly under a length-sensitive AUC (0.505 → 0.474 after length adjustment). The authors flag it and say the corrected-feedback same-state rerun "has not yet been completed" — that missing rerun is the single most important absent ablation in the paper. (2) **n is small**: AIME 2025 is 30 problems, avg@4, one seed, one benchmark, unequal run lengths. The −30 to −40 pp effects are large enough to survive that, but the AUC rows (many with CIs spanning 0.44–0.67) are not. (3) They built 2,048 visible + 2,048 sealed audit prompts and a 115/102 recent-contest set — and **ran no inference on any of them**. (4) There is **no λ sweep**: no run shows the token score at reduced strength, so "token score hurts" is never separated from "this particular magnitude of token score hurts." (5) The KL-regularized runs change four choices jointly versus the additive family, so they are recipe comparisons, not KL ablations — the authors say so, but it means the 2×2 of {clip, tanh, entropy gate, KL} is never filled in. (6) The different-problem control is impure at update 1 (112/128 groups used a different-problem donor; 16 hit an empty cache and fell back to a same-problem donor). (7) A targeted audit found 18/49 gradeable strong-consensus candidates disagreeing with the verifier in the weighting run, with eight quarantined — training-label noise whose prevalence outside that run is unresolved.

**Reproducibility.** Strong on specification (a 14-tuple of choices they argue every paper should report, plus content hashes, donor IDs, fold metadata, judge model/version, execution order of gating→combination→sign clamp→advantage clip→PPO clip), weak on artifacts — no code or data release is mentioned, and one of the two judge models (`gpt-5.6-luna`) is a proprietary endpoint that may not be reachable later. The `A^R = clip(R − mean, −0.5, 0.5)` shaped reward used in the actual runs also differs from the binary `A^U` in the exposition, a mismatch that a reimplementer would trip over.

**Significance.** High for anyone shipping OPSD/RLSD-style token rewards: a 30–40 pp collapse against a matched outcome-only control is not a subtle effect, and the diagnostic checklist is directly actionable. Moderate as science, because the demonstration is one model, one benchmark, one seed, and one (defective) feedback template.

**Red flags / overclaiming.** The title verges on general, but the body repeatedly refuses to generalize, and the paper never claims the five recipes are faithful reimplementations of RLSD/RLCSD/CriPO — a reader must not take this as a refutation of those published methods, since none of them was run. The main asymmetry to watch: the negative result is reported as strong and specific, while the confounds that could produce it (template mismatch, single seed, label noise) are acknowledged but not closed by an experiment.

## Strengths

- Cleanly separates three claims that the literature routinely conflates: the score is measured correctly / the score means something / the loss uses it well.
- The identical-feedback null (AUC 0.503) run through the production scoring path is the right control and it lands exactly where it should, which validates the measurement pipeline itself.
- Pre-empts the standard rebuttals with data rather than argument: truncation telemetry, equivalent-answer regrading (0.013% label change in the matched runs), update-1 equivalence showing the gap is dynamic.
- Points at a plausible mechanism rather than just reporting a number: 55.81% of groups had zero outcome coefficient so the token score drove training alone, and 57–71% of its weight sat in the top entropy decile — a concrete story for how a chance-level signal becomes actively harmful.
- The limitations section names its own measurement defects (template violation, impure control, label audit) instead of burying them.
- Correctly notes that the external judge *can* solve the comparison task (51/54), which converts the result from "hindsight feedback is useless" into the sharper "log-likelihood is the wrong readout of hindsight feedback."

## Limitations

- One model (gpt-oss-20b at low reasoning effort), one benchmark (AIME 2025, 30 prompts), one seed, avg@4; no scale study, no non-math domain, no executable or rubric feedback.
- Positive/negative feedback templates were not matched on length, style, or formatting instructions in the audited runs; the corrected-template rerun is unfinished.
- No sweep over the token-score weight λ, no isolated ablation of clipping vs tanh vs entropy gate vs KL.
- Feedback comes from an external judge that saw the reference and verdict; results need not transfer to policy-written or differently-prompted feedback.
- The outcome-only control was still improving when stopped, so it is not an empirical ceiling and the reported gap may be a lower bound on the ordering, or an artifact of unequal run lengths.
- Propositions assume finite action sets, frozen targets, fixed state/context laws, and Euclidean independent logits; moving teachers, optimizer preconditioning, parameter sharing, and minibatch noise are outside their scope.
- Proposition 1 is a deliberately strong identification standard — a biased score with merely positive projection onto reachable gradients could still help, so failing it is diagnostic, not disqualifying.
- Checkpoint-selection rule and the multiplicity sensitivity are retrospective, not preregistered.

## Relevance

如果你关注 RLVR / 长推理链的 token 级 credit assignment、on-policy distillation，或者正在考虑用 teacher likelihood 给 GRPO 类算法加 dense reward，这篇是必读的反面证据：它给出了一套可执行的三步验证清单（AUC + 长度校正、held-out cross-fitting、以及匹配的 outcome-only 对照训练），成本远低于跑完一整轮训练才发现掉 30 个点。同时它对 forward-KL 分解中互信息项的澄清，直接影响如何解读一批 2026 年 OPSD 系方法的理论论证。

## Questions for Further Exploration

- Does the collapse survive matched feedback templates? The single highest-value follow-up is the same-state rerun with byte-matched positive/negative texts — if AUC moves from 0.505 to, say, 0.58 and the training gap shrinks, the paper's demonstration is about template hygiene rather than about likelihood-as-credit.
- Is there a λ at which the token score is neutral-to-helpful? A sweep from λ→0 to the current setting would tell whether the −30 pp is a dose effect or a direction effect.
- Would a judge-verdict reward (the 94.4%-accurate pairwise comparison) beat outcome-only, given the same privileged information? That is the natural positive control the paper gestures at but cannot run because only one pair joined to a stored score.
- Does the parameter-gradient projection between the dense-score update and the outcome update on fixed rollouts actually point the wrong way, or merely orthogonally? The paper measures scalar activity and entropy concentration but explicitly declines to measure gradient alignment.
- Do the published methods themselves (RLSD, RLCSD, CriPO, OPSD) pass the three checks on their own reported setups — especially the held-out cross-fitting check, which none of them appears to run?
- Does the ~99% negative one-sided teacher–policy residual on *correct* trajectories generalize beyond gpt-oss-20b? If so, it suggests the frozen reference is a systematically pessimistic scorer of on-policy successful paths, which would matter for any KL-anchored RLVR recipe, not just self-distillation.
- Would coherent outcome conditionals (Harutyunyan-style HCA / COCOA constructions), rather than free-form "helpful"/"unhelpful" texts, recover a usable ratio at LLM scale?
