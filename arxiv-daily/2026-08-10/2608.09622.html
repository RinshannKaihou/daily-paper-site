01

Methodology

Reliability qualification is recast as a constrained POMDP with three terminal outcomes: characterization success (BTI ΔVt ≥ 0.09 V), catastrophe (EM or TDDB damage index ≥ 1), or budget exhaustion at 300 epochs. Because degradation is irreversible, every stress decision is one-way — the planner must approach the failure boundary without crossing it.

A single device instance holds latent parameters sampled once; BTI follows a stretched-exponential with voltage/temperature acceleration, while EM and TDDB accumulate damage via Black's relation and the E-model. BTI's parameters are unobservable, so an extended Kalman filter (Joseph-form covariance, log-space τ) maintains a Gaussian belief — and the posterior trace U = tr(Σ) enters the reward as an explicit information term, not a post-hoc analysis.

Planning uses seed-action MCTS: each node is a seed prefix, children are selected by UCB1 (C=1.4) under progressive widening (k=3, α=0.5), rollouts use random seeds, returns are undiscounted. A deterministic seed-to-action map guarantees exact replay across the expensive stochastic simulator (Gerabaldi).

03

Strengths & Limitations

Strengths

  • Well-motivated framing: JEDEC static recipes cannot adapt to per-unit variability; three-mechanism competition backed by 14nm/10nm FinFET studies.
  • Deliberately hard calibration (all mechanisms ~150 epochs to failure) rather than a regime where max stress trivially works.
  • Progressive-widening scalability: 36× action cardinality, identical 500-node / 30-child tree — generalizable beyond this domain.
  • Targeted reward ablations with crisp causal stories (78% catastrophe without the safety barrier).
  • Candid limitations section; full hyperparameter disclosure; well-specified determinism protocol.

Limitations

  • Simulation-only, on the group's own simulator (Gerabaldi) — no physical devices, no independent cross-validation.
  • N = 1 device for the headline comparison; ±10% parameter shift moves CY between 0% and 83.2%.
  • Competing-mechanism damage assumed directly observable — unavailable in a real stress-measure-stress flow.
  • No EKF ablation — the “Bayesian” half of the contribution is untested.
  • No confidence intervals or significance testing anywhere; single-seed ablations.
  • ~38 h/device compute; no code or data released.
04

Questions for Further Exploration

  1. Freeze the resulting plan and run on N fresh device instances drawn from Table I — what is the CY? This is the number that determines usefulness, and it is not reported.
  2. Replace the EKF with a point estimate, or remove it so the planner sees only (T_accum, ΔVt, D_EM, D_TDDB). Does CY move at all?
  3. Add realistic observation noise to D_EM / D_TDDB — how much of the “performance ceiling” survives?
  4. How does a myopic one-step expected-information-gain policy (Chaloner–Verdinelli, cited but never run) compare? If it lands near 40–50% CY, the 38-hour search is hard to justify.
