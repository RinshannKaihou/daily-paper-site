03 Why This Matters

Any merge diagnostic must be evaluated in the exact prompt serialization used at deployment — an instruction wrapper can erase an interference signal on identical prompts.

04 Critical Edge

With only 3 seeds, the flagship prospective test was structurally unfalsifiable — p=0.083 is the design's minimum, not evidence.

Methodology

A logit-space counterfactual for “no interaction”

Starting from a shared base θ0 and two LoRA displacements Δa, Δb, the authors scan a 7×7 grid θ0+αΔa+βΔb with α,β∈{0,…1.2}; (1,1) is ordinary task arithmetic, the axes retain each task's full nonlinear path.

R = E[ JSD( p_{α,β}, padd ) ] / E[ JSD( p_{α,β}, p0,0 ) ]

The additive counterfactual is built in logit space — softmax applied only after composition — so the numerator isolates joint interaction after each axis's own marginal curvature is removed; the denominator normalizes by actual displacement from base. Numerator and denominator are averaged separately over 36 interior points × 60 prompts × 3 seeds (ratio-of-expectations), with an EoR sensitivity audit. Every rank-16 vector is norm-matched to a median Frobenius target, so “small vectors look additive” cannot explain the contrast. Hierarchical bootstrap resamples seeds (outer) and prompts (inner); the matched code+safety vs code+math contrast shares a code checkpoint within seed.

Assets

Strengths

  • Matched-control design — code+safety vs code+math share the same code checkpoint within seed; the right comparison.
  • Norm matching kills the obvious “small vectors look additive” confound; numerator/denominator decomposition proves it is not a shrinking denominator.
  • Real preregistration — bins and 75% success criterion frozen before summarization/translation adapter training, with a dated appendix trace.
  • Negative and boundary results (format collapse, EvalPlus non-reproduction, non-significant 0.5B clustering) are foregrounded, not buried.
  • Disclosed EOS-masking pilot bug; no pilot checkpoint enters any reported estimate.
  • Estimator audit reproduces 68 frozen bootstrap values exactly; RoE vs EoR agrees.
Boundaries

Limitations

  • 3 seeds cap power — the headline prospective test's p-value floor is 0.083 by design; never falsifiable at α=0.05.
  • No same-task / random-direction anchor — R has no absolute scale; every claim is comparative by construction.
  • Individual adapter capability is never measured — task labels denote training data, not verified skill.
  • First-token JSD is a proxy; sequence-level and pass@1 signals are weaker or absent.
  • Full-parameter FT audited only at 0.5B; cross-architecture evidence is a single Llama-3.1-8B run on 3 tasks.
  • Only 2-way composition; nothing on the practically interesting 3+ way regime. Artifact not yet public.

Open Questions

What this paper cannot settle

Does the code/instruction contrast survive once adapters are verified to actually improve task accuracy — separating learned capability from learned output style?

Is the Alpaca collapse a genuine functional fact, or does the wrapper make the first token near-deterministic (a template token), mechanically shrinking both numerator and denominator?

Why is the 7B contrast larger than 1.5B while 0.5B Full FT is smaller — is interference growing with scale, or is R confounded with vocabulary entropy?

What does a same-task control (two adapters, same task, different seeds) yield for R? Without that noise floor the whole ordering could sit inside seed variation.

Does the ordering extend to 3+ task vectors, where the additive counterfactual needs a higher-order factorial decomposition?

Would a layer- or module-resolved decomposition localize where code and safety collide — turning this diagnostic into an actionable merging intervention?
