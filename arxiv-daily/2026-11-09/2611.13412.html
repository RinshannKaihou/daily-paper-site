One 5-minute burst permanently degrades prefix-cached agent serving; parking sessions at turn boundaries — not throttling — recovers it.

Why This Matters

Sizes safe load by KV pool capacity, not QPS — directly informing scheduling, admission control, and capacity planning for agent inference clusters.

对 Agent 推理集群的调度、准入控制与容量规划有直接指导意义：按 KV 池而非 QPS 估算安全负载。

⚠ Critical Edge

The 32B evidence is weaker than the abstract implies: at λ = 0.03 every run degrades with no burst at all — cross-model history dependence rests on a single λ = 0.025 configuration (1/4 persistent, 1 partial).

Also: eviction is inferred, not measured — vLLM exports no per-block eviction events, so the causal chain is un-instrumented.

Methodology

Paired runs: same load, different history

  • Testbed. vLLM 0.20 (ROCm) on single AMD MI300X; BF16, 40K context, prefix caching on. Qwen3-8B with a fixed 400K-token KV pool (59 GB); Qwen3-32B with auto-sized pool (≈365K tokens).
  • Workloads. Synthetic closed-loop agent sessions (Poisson arrivals, 25 turns, contexts growing 6K→37K, random tokens so reuse is exact-prefix only) + replay of 200 real mini-SWE-agent trajectories on SWE-bench Verified.
  • Core design. Both arms of a pair share one base arrival stream; the burst arm adds +1.5λ for 5 minutes at minute 15 — post-burst offered load is identical, only history differs.
  • Analysis. First-order drain condition (drain iff λ < 1/S), with per-miss cost c(L) = −0.06 s + 0.146 ms × L calibrated independently on cache-disabled runs.
  • Controllers. Five limits over one shared actuator — park an admitted session at a turn boundary into a FIFO queue, re-admit before new arrivals. Thresholds (0.75C/0.95C) fixed before experiments.

  • Not ordinary overload. With caching disabled at matched load, the same burst drains (backlog 17–43); a session cap below pool capacity → 0/10 degraded; in 7/11 degraded runs the burst's own sessions had already finished.
  • Degraded ≈ cache-off. 0.35–0.46 turns/s vs 0.33–0.43 with caching disabled; 99.6–100% of turns had under half their prompt cached.
  • Generalizes. SGLang 0.5.22: 4/4 paired burst runs degraded (hit ratio 0.09–0.11 vs 0.93–0.95 twins); Qwen3-32B replaying real SWE-bench traces: 1/4 persistent + 1 partial.
  • Offload only delays. A 128 GiB CPU KV tier pushes collapse from min 20–25 to 40–60; 4/6 runs still end degraded.
  • Prevention. Budgeter from the start: 0 collapses across 2× burst (0/5), cache flush (0/3), 32B + traces (0/4) — thresholds moved to 0.65/0.85 or 0.85/0.98 changed nothing.

Strengths
  • Cleanest metastability demo in LLM serving to date. Paired runs convert "the server got slow after a spike" into a statistically tested history-dependent phenomenon — 0 of 12 reversals.
  • Mechanistic depth. Little's law → per-miss cost calibration → validated drain bracket (0.010–0.014 measured vs 0.013 predicted), linking Denning's 1968 thrashing theory to prefix-cached serving.
  • Fair controller study. One actuator, one varied limit: parking admitted sessions against a capacity-derived limit recovers what admission throttling cannot (7/7 + 17/17 vs 1/7).
  • Immediately deployable. The budgeter needs only the engine-reported pool size C and two fixed thresholds; adapts automatically to session-mix shifts that break fixed caps.
  • Honest framing. Explicit non-claims of loop novelty (Table 4), disclosed spontaneous-degradation twins, an order-of-magnitude model miss, and an AI-usage disclosure.
Limitations
  • No production evidence. One GPU type (MI300X), one replica, no routing/autoscaling/retries; production contexts (TraceLab median 136K per call) exceed everything tested and would tighten the failure margin.
  • 32B sits at its capacity edge. At λ = 0.03 all runs degrade with no trigger, and no-burst runs degrade spontaneously — cross-model history dependence leans on the 8B results.
  • Trace replay keeps shapes, not content. Unique random suffixes remove cross-session prefix sharing; truncated at 38K tokens (−14% of turns); no real agents executed.
  • Eviction inferred, not measured. vLLM exports no per-block eviction events, so the eviction→miss chain rests on aggregate demand/pool and hit-ratio curves.
  • Queue stability shown only on 8B. 32B recovery queues kept growing (arrivals 1.5–1.6/min vs 0.7–1.3 completions/min); engine-side alternatives discussed but untested.
Questions for Further Exploration
  1. Where does the collapse threshold move under real cross-session prefix sharing (shared system prompts, tool-result templates, multi-tenant coding agents)?
  2. Can engine-side session-aware eviction or prefix-residency scheduling match gateway parking — and at what fairness cost to new sessions?
  3. Does the metastable regime appear in prefill–decode disaggregated tiers, and must the budgeter become a distributed controller across prefill replicas?
  4. Entry dynamics: the Poisson escape-time model was off by an order of magnitude — is a CTMC or fluid model calibrated on escape times tractable?
  5. With 100K+ production contexts, does N* = C/L̄ shrink so far that even modest interactive concurrency is unstable without hierarchical KV storage?
