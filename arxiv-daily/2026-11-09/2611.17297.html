A sparse circuit of 122 attention heads encodes an LLM's goal — decodable as natural language before execution begins.

在多步代码生成中定位到 122 个稀疏“目标注意力头”——其输出在子目标实现前即可解码出自然语言意图；Transformer 并不向前传递目标状态，而是每个 token 重读任务、重编码进度、对比选出待办。

Why This Matters

An operational framework for testing whether LLMs have intrinsic goals — plus a training-free probe for reading an agent's intent before it acts.

▲ Critical Edge

All “success” numbers flow through one commercial oracle with a lenient partial-credit rubric — and the two LM judges disagree badly on negatives (κ = 0.16).

Methodology

How 122 heads were found and tested — Qwen2.5-Coder-32B-Instruct (64 layers)

253 locked specs · 2–4 sub-tasks each (Python / C++) · no chain-of-thought · 1,012 pivot observations per configuration

  • Cross-language localization. Jointly-learned sparse masks over all attention heads transplant a source predicate's encoding into a destination run in a different language — rewarding abstract transfer, not token copying. Masks binarized at τ = 0.9 → 122 heads (4.8%, layers 28–55).
  • GoalScope probe. Goal-head outputs at a single pivot token are summed into one vector and injected into a context-free run that verbalizes the upcoming operation; a Claude oracle judges agreement (human–judge agreement 96.2%, 125/130).
  • Causal bottleneck. Sufficiency: only goal heads keep task-span access. Necessity: head attention sunk to the first token.
  • NRGS transplant battery. KV swap of task-span states, query swap of the progress encoding, and residual patching of task vs. code-progress spans.
  • Generalization. Replicated on 7 more LMs (up to GLM-4.5-Air, 106B MoE) plus an independent third-party re-implementation.

  • The persistence paradox. Goal encodings persist 30+ tokens, yet only become readable after layer 40 — leaving 24 layers, too few to carry state forward. This is what motivates the non-recurrent goal-seeking (NRGS) account.
  • Sufficiency holds. Preserving only the 122 goal heads' span access sustains execution at the clean 0.925 level; blinding just those 122 barely hurts (0.854) — redundancy exists but is concentrated.

Strengths

What makes this credible

  • Falsifiable operationalization — “goal” becomes three testable properties (pre-commitment, plasticity, persistence), each paired with a dedicated causal intervention.
  • Clever localization design — different languages in source/destination forces the mask to select abstract, token-independent encodings.
  • NRGS resolves a real architectural paradox — finite depth vs. 30+ token persistence — and generates two independently testable predictions, both causally supported.
  • Negative results reported in place (122-head necessity null, weak query transfer, judge κ statistics) plus an independent re-implementation across 8 models.
  • Practical artifact — GoalScope is a training-free, single-token intent reader, transferable to ICL-rule verbalization and misalignment probing.

Limitations

Where the claim outruns the evidence

  • Deliberately narrow setting — spelled-out sub-tasks, one-function programs, no chain-of-thought; open-ended agentic behavior and self-set goals are out of scope.
  • Obstacle persistence absent at 32B scale — the finding covers a weaker notion of “goal” than classic agent architectures (SOAR, BDI).
  • Un-searched hyperparameters — injection layers, α, head count; readout quality swings from 80%+ to 9% by task type.
  • NRGS not mapped to circuits — the attention-read proposal is an explicit hypothesis; query transfer (57%) is the weakest link.
  • Architecture-dependent — linear-attention models with fast-weight memory (DeltaNet) could maintain a running goal state, changing the picture entirely.
  • Oracle partial credit inflates success rates; the two LM oracles disagree badly on negative verdicts.

Open Questions for Further Exploration

  1. Does NRGS scale to implicit plans, agentic tool use, or reasoning models that externalize state into generated text?
  2. Would a DeltaNet / linear-attention hybrid with overwritable fast-weight memory show true state-carrying persistence — and can the transplant battery distinguish it from NRGS?
  3. Why is query transfer (57%) so much weaker than KV transfer (~94%) — is progress encoded distributively, in MLP outputs, or in the keys?
  4. Can GoalScope readouts become a real-time intent monitor for coding agents, detecting declared-intent vs. executed-action divergence mid-generation?
  5. Does goal-head concentration around layers 40–50 predict where such encodings live in other model families — and does head density scale with planning ability?
