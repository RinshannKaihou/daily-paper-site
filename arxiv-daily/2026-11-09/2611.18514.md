> **一句话总结：** 作者对在 Online-Mind2Web 真实网站上运行的 Qwen2.5-7B-Instruct 网页智能体的"网页元素幻觉"（生成网页上不存在的动作）做了机制可解释性（MI）解剖：最后一个 prompt token 上的线性探针能在生成开始前以 0.80 AUC 预测幻觉，沿探针方向做表征转向可修复 85.4% 的幻觉（仅破坏 7.0% 的合法动作），但最优的电路级干预只能修复 8.9%，且探针方向与动作列表的 JSON/编号列表格式纠缠——换一种格式后修复率骤降至 58.1%，说明现有 MI 工具能"检测与拨正"却无法真正"解释"智能体失败。

> **TL;DR:** A case study applying mechanistic interpretability (linear probes, activation steering, activation patching, SAEs, logit lens) to Qwen2.5-7B-Instruct web-agent hallucinations on live websites from Online-Mind2Web (300 episodes, 2,071 actions, 32.6% hallucinated). A linear probe on the last prompt token predicts hallucination before generation at 0.80 AUC, and steering along the probe direction (selector_start, layer 17, α=40) fixes 85.4% of hallucinations while breaking only 7.0% of valid actions — but the best joint circuit-level intervention (amplifying all layer-22 attention heads, damping FFN layers 22–24) fixes just 8.9%, showing the computation is distributed rather than localized; worse, the steering effect is entangled with prompt format, dropping to 58.1% fix rate (−27.3 pp) when the JSON action list is rewritten as a numbered markdown list. The paper's real contribution is a diagnosis of why standard MI assumptions (localizability, stationarity, temporal locality) break in agentic settings, plus a research roadmap.

## 核心贡献

- **首个针对真实智能体失败模式（而非玩具任务）的系统化 MI 剖析**：以网页智能体"元素幻觉"（生成动作列表中不存在的 CLICK/TYPE/SELECTOR）为案例，在 Online-Mind2Web 的真实网站上收集 300 个 episode、2,071 个动作（32.6% 为幻觉），对 Qwen2.5-7B-Instruct 应用探针、表征转向、激活修补、SAE、logit lens 等全套 MI 工具。
- **幻觉决策在生成开始前已被线性编码**：在 prompt_end 位置（模型尚未输出任何 token）第 18 层训练的线性探针达到 0.80 测试 AUC；到 selector_start 位置第 0 层信号就已很强，说明对幻觉动作的"承诺"违反了时间局部性（temporal locality）假设。
- **探针方向具有因果性但不具备解释性**：用探针权重做表征转向（selector_start L17，α=40）能修复 85.4% 的幻觉、仅破坏 7.0% 合法动作；但把动作列表从 JSON 改成编号 markdown 列表后修复率掉到 58.1%（−27.3 个百分点），破坏率不变——探针学到的是"幻觉 + 格式"的纠缠方向，而非纯粹的幻觉方向。
- **电路发现的核心假设在智能体场景中失效**：单组件干预（放大单个 FFN ×10、对单个注意力头加噪）既找不到责任组件，产生的"幻觉"也是语法破碎的垃圾 token（如 VAR-10000...），与自然幻觉（语法完好但指向不存在的 Search/Explore 元素）性质不同；最优联合干预（L22 全部注意力头 ×3 + L22–24 FFN ×0.5）也只修复 8.9%，说明计算是分布式耦合的。
- **反事实构造在真实环境中基本不可行（平稳性失效）**：激活修补确认动作列表是最大因果贡献者（干净状态恢复在 L27 恢复 0.36 概率质量，远高于 task description 的 0.012 / selector 的 0.013），但把选中动作从列表移除只有 38% 的概率诱发幻觉，且一步之后轨迹即发散（selector 一致率 28.1%、DOM Jaccard 0.52），配对实验假设被破坏；当该值曾出现在动作历史中时，71% 的动作对动作列表腐蚀免疫。
- **预训练 SAE 在智能体分布上失效**：在 L27 上用 131,072 特征的 BatchTopK SAE 分析，区分幻觉/合法的 top 特征所促进的 token 与幻觉行为无关——文本语料训练的 SAE 缺少交互中才涌现的概念。
- **给出面向智能体 MI 的研究路线图**：智能体 MI 基准、超越单位置/单组件归因、有状态环境中的反事实构造、面向智能体分布的特征发现（轨迹上训练的 SAE）、跨时间步监测模型信念、跨智能体类型的普适性验证。

## Key Contributions

- First systematic MI dissection of a realistic agent failure mode — web element hallucination (actions referencing nonexistent page elements) — rather than a toy task: 300 episodes / 2,071 actions (32.6% hallucinated) collected by rolling out Qwen2.5-7B-Instruct on live Online-Mind2Web websites, analyzed with linear probes, representation steering, activation patching, SAEs, and logit lens.
- Shows the hallucination decision is linearly encoded before generation begins: a probe at prompt_end (layer 18) reaches 0.80 test AUC before the model writes a single token, violating the temporal-locality assumption that decisions are encoded at the timestep where they manifest.
- Demonstrates the probe direction is causal but not explanatory: steering with the L17 selector_start probe fixes 85.4% of hallucinations at 7.0% break rate (α=40), yet re-formatting the action list from JSON to a numbered markdown list drops the fix rate to 58.1% (−27.3 pp) with identical break rate — the learned direction is entangled with action format rather than encoding "hallucination" alone.
- Documents the breakdown of circuit-discovery assumptions (localizability, stationarity): individual FFN/head interventions do not reproduce natural hallucinations (they yield syntactically broken tokens, not plausible-but-nongrounded selectors); the best joint intervention fixes only 8.9%; counterfactual pairs are unconstructible (removing the chosen action hallucinates only 38% of the time and trajectories diverge within one step).
- Shows pretrained text-based SAEs yield no interpretable hallucination features at layer 27 — the top differentiating features promote unrelated tokens.
- A logit-lens analysis reveals hallucinating trials converge on generic strategy labels (Search, Enter, Find, Explore — even the Chinese 搜索 at layer 24) by layers 21–27, indicating commitment to a template action rather than page-grounded grounding.
- A six-point roadmap for agent-oriented MI: agentic MI benchmarks, distributed-attribution methods, counterfactual construction in stateful environments, SAEs trained on agent trajectories, belief monitoring across timesteps, and universality across agent types.

## Methodology

The authors frame LLM agents as perception → memory → reasoning → action loops and ask which standard MI tools transfer when the input is a growing, environment-controlled context rather than a fixed prompt. The case study targets web element hallucination: given a constructed list of available actions (CLICK/SCROLL/TYPE/HOVER with selectors), an action is hallucinated if the generated selector does not appear in the list. Trajectories come from rolling out Qwen2.5-7B-Instruct zero-shot on Online-Mind2Web tasks (max 10 page interactions per task), yielding 300 episodes and 2,071 actions, 32.6% hallucinated. All experiments use TransformerLens on a single A100 80GB.

The analysis proceeds in three layers. (1) Circuit discovery: per-layer FFN amplification (×10) and per-head Gaussian noise injection to measure ΔP(valid token); joint interventions scaling attention heads by α and FFNs by β across dozens of configurations (Table 3 in the appendix enumerates 36); activation patching with Gaussian-noise corruption of three input spans (selector, task description, action list), restoring clean states per (layer, token-offset) to measure recovery of P(Search). (2) Feature identification: linear probes trained per layer at three positions (prompt_end, selector_start, selector_value_start) with an episode-level 70/15/15 split (1,433/282/356 actions) to prevent within-episode leakage; representation steering using the σ-normalized probe weight as a steering vector, sweeping α ∈ {10, 20, 40, 60, 80}; a pretrained BatchTopK SAE (131,072 features, k=64, from andyrdt/saes-qwen2.5-7b-instruct) analyzed at layer 27; logit lens decoding of intermediate layers at the selector-value position. (3) Robustness checks: an OOD prompt-format condition re-running the same 300 tasks with the JSON action list rewritten as a numbered markdown list, re-training probes and re-applying the original steering vector; counterfactual trajectories built by removing the chosen valid action from the list and re-rolling, measuring selector match, DOM Jaccard similarity, and hallucination-rate delta over subsequent steps.

## Results & Highlights

- **Pre-generation hallucination detection:** On the 356-action test set from Online-Mind2Web rollouts, a linear probe on the residual stream at prompt_end layer 18 reaches **0.80 test AUC** (vs. 0.50 chance) before the model generates a single token; at selector_start the signal is strong already at layer 0.
- **Steering efficacy (in-distribution):** Steering along the selector_start layer-17 probe direction at α=40 **fixes 85.4% of hallucinated actions while breaking 7.0% of valid ones**; layer 18 reaches 85.4% fix at α=60 with a worse 14.0% break rate; prompt_end steering peaks at only 41.5% fix (Table 5).
- **Format brittleness:** Under the OOD numbered-list format, the same steering vector's fix rate drops from **85.4% to 58.1% (Δ = −27.3 pp)** at α=40 with an essentially unchanged 7.0% break rate; the gap holds across all α values (e.g., 75.6% → 41.9% at α=20).
- **Circuit interventions barely work:** The best joint configuration (all layer-22 attention heads amplified ×3, FFN layers 22–24 damped ×0.5) fixes only **8.9% of hallucinations (2.4% break)** — roughly 9.6× worse than probe steering; top-10 causally attributed heads fix 4.4%; the worst configurations break up to 100% of valid actions while fixing ~0% (Table 3).
- **Distributed input attribution:** Activation patching on "Search" hallucinations shows the action-list span dominates: clean-state restoration at L27 recovers up to **0.36 probability mass vs. 0.013 (selector) and 0.012 (task description)**; within the residual stream alone the recovery is 0.013–0.360 depending on span, while attention and FFN individually contribute ≤0.075 — information is spread across mechanisms.
- **Counterfactual infeasibility:** Removing the chosen valid action from the list yields a hallucinated output in only **38% of cases**; by step 1 selector agreement between original and counterfactual runs falls to **28.1%** and DOM Jaccard similarity to **0.52**; when the chosen value also appeared in the action history, **71% of actions are unaffected** by action-list corruption (vs. 21% when the list is the only source).
- **SAE failure:** At layer 27, the top-10 SAE features by hallucination-vs-valid activation difference promote tokens unrelated to the observed behavior (Figure 7) — no interpretable hallucination features from the 131,072-feature pretrained dictionary.

## Critical Assessment

- **Novelty:** The core story — MI tools detect and steer but do not explain agent failures — is a genuinely useful negative/diagnostic result, and the format-entanglement finding is a sharp, concrete demonstration of probe brittleness. However, the constituent techniques (probes, steering, patching, SAEs) are all standard; the novelty lies in the application setting and the failure analysis, not in methods. Roughly a third of the paper (Section 5) is a roadmap rather than evidence.
- **Rigor:** The episode-level train/test split correctly prevents within-episode leakage across actions, and the α sweep with paired fix/break rates for both formats is well designed. But every mechanistic claim rests on a single 7B model (Qwen2.5-7B-Instruct) and a single failure mode; no second model or agent scaffold is tested, so the claimed generality beyond web agents (Appendix A) is argued by analogy, not data. The SAE analysis is confined to one layer (27) and one public checkpoint, which is thin evidence for the broad claim that pretrained SAEs fail in agentic distributions.
- **Reproducibility:** Strong — open model, public dataset, public SAEs, TransformerLens, single-A100 compute, and full prompt templates in appendices. The 36-configuration intervention table (Table 3) is commendably complete.
- **Significance:** The 85.4% fix rate is headline-worthy, but the paper's own OOD experiment undercuts its actionability: an intervention that loses ~27 pp when the action list is reformatted is not deployable, and the authors say so honestly. Notably missing is a comparison against trivial behavioral baselines for this specific failure — constrained decoding to the action list (or string-matching post-editing) would prevent ~100% of element hallucinations by construction; the MI analysis is therefore about explanation and monitoring, not mitigation, and a baseline table would have clarified the gap.
- **Red flags:** The natural hallucination rate (32.6%) comes from zero-shot rollouts with a strictly formatted prompt, so the phenomenon being explained is partly an artifact of this minimal action-space setup; logit-lens evidence for "strategy commitment" (including the Chinese 搜索 token) is suggestive but the logit lens is a known-imperfect reading of intermediate layers.

## Strengths

- Honest, self-critical evaluation: the authors design the experiments that break their own best result (format shift) and report it prominently rather than burying it.
- Clean operationalization of an agentic failure (hallucination = action not in the provided list) on live websites rather than a synthetic proxy.
- The two-level diagnosis — input-level attribution succeeds (action list matters), component-level attribution fails (no single head/FFN) — is a crisp, reusable lesson for anyone applying circuit discovery to agents.
- The counterfactual-divergence quantification (38% induction rate, 28.1% selector agreement at step 1, DOM Jaccard 0.52) gives concrete numbers to a methodological problem usually only mentioned qualitatively.
- Actionable roadmap grounded in the observed failure modes, with pointers to nascent literature (trajectory-level attribution, temporal SAEs).

## Limitations

- Single model, single scale (7B), single agent scaffold, single failure mode — no evidence that findings transfer to larger models, tool/embodied/code agents, or other failure taxa.
- The steering fix rate is measured on the same distribution the probe was trained on; the only stress test is one prompt-format shift, and no test of cross-website or cross-task transfer of the probe direction is reported.
- SAE analysis limited to one layer and one checkpoint; different SAEs or training SAEs on agent trajectories (as the roadmap proposes) are not attempted.
- The paper explains where/when the hallucination commitment is encoded, but not the algorithmic "why" — by its own admission, none of the tools deliver a mechanistic explanation of how the decision is computed.
- The dataset (300 episodes, 2,071 actions) is modest; fix/break percentages on subgroups (e.g., the 38% counterfactual induction cases) rest on small samples.

## Relevance

对关注可解释性与智能体交叉方向的研究者高度相关：它把机制可解释性从玩具语言任务推进到真实网页智能体失败，并定量揭示了探针/转向向量、电路发现、SAE 在智能体分布下的脆性边界，是"agentic MI"议程的代表性实证工作。

## Questions for Further Exploration

- Does the pre-generation probe (0.80 AUC at prompt_end) transfer across websites, tasks, and agent scaffolds, or is it scaffold-specific like the format-entangled steering direction?
- Would training SAEs on agent trajectories (as the roadmap proposes) recover interpretable features for strategy commitment (e.g., "generic Search intent") that the text-pretrained SAE misses?
- Can the 85.4%-fix steering result survive if the probe is trained on multiple prompt formats simultaneously (format-invariant directions), or via causal-meditation-style disentanglement of format vs. hallucination?
- How does the distributed, non-localizable computation observed here scale with model size — does a frontier-scale web agent localize better, or worse?
- Since constrained decoding would trivially prevent element hallucinations, can the probe instead add value where output constraints cannot — e.g., early-warning monitoring of strategy commitment that manifests later as different failure modes (wrong-but-valid actions, task abandonment)?
- Do the hallucination-predictive directions identified here exhibit any universality across agent types (web vs. tool-calling vs. embodied), as the universality hypothesis would predict?
