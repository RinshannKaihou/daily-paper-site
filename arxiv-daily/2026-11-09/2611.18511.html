Key Finding · arXiv 2611.18511

Near distribution equality — exactly where distillation and KL-regularized RL converge — standard FP32 divergence losses and gradients silently round to zero.

一句话总结（节选）：当两个分类分布几乎相等时，前向 KL、反向 KL、广义 JSD、蒙特卡洛 KL 估计器和熵的标准实现会因舍入与抵消而丢失损失值和梯度；作者提出 8 种基于 expm1/log1p、非负余项 E₂(x)=eˣ−1−x 和 logit 差重构的数值稳定改写，并用 Hypothesis 属性测试（对照 mpmath 80 位参考值）验证了 JAX 实现。

Why This Matters

Drop-in stable JAX code for the regime every distillation, GRPO, and entropy-regularized run eventually enters — and low precision (BF16 / FP8) makes it worse.

⚠ Critical Edge

Practical significance is asserted, never measured — no training run shows these rounding zeros change outcomes. "Does this change my loss curve?" goes unanswered.

01Methodology

A numerical-analysis study of scalar arithmetic, not a training study. Logits z, zref ∈ ℝK define q = softmax(z) (optimized) and p = softmax(zref) (fixed); each divergence's forward pass and z-gradient is decomposed into elementary ops to locate where rounding or cancellation destroys small quantities — near equality, the linear parts of KL summands cancel across categories, leaving a quadratic remainder that roundoff overwhelms.

Repair template shared by all 8 reformulations:

KL(p‖q) = Σ pᵢ·E₂(sᵢ),  E₂(x)=eˣ−1−x  (Taylor, |x|<½)
  • Reconstruct log-ratios from centered logit differences via expm1 / log1p (extends Barron et al. 2026).
  • Replace signed KL sums with nonnegative remainders E₂(x), degree-12 Taylor near zero.
  • Attach custom gradients with zero-sum corrections (u − q·Σuᵢ); Proposition 1: centered log-ratio ≡ centered logit difference.
  • Validation: FP32 vs 80-digit mpmath references, sweeps h = 10⁻²…10⁻¹², Hypothesis property tests (equality, permutations, logit shifts, K ∈ {2,3,4,8,16}).

Honest negative results: the paper demonstrates two ways its own fixes fail (overflow away from equality; residual logit-subtraction rounding that passes the closeness guard). All reformulations pass Hypothesis property tests for K ∈ {2,3,4,8,16}. No benchmark-dataset training results — evidence is controlled numerical experiment only.

03Strengths

  • Clear, reusable taxonomy of five failure modes across eight settings, with value and gradient issues separated — Table 1 works as an implementer's checklist.
  • Every fix ships as a short, executable JAX listing using standard stable primitives (expm1, log1p, log_softmax, custom_gradient) — easy to port into production kernels.
  • Best-in-class verification for the genre: property-based tests against 80-digit references, including permutation / shift invariances.
  • Unusual honesty — a dedicated pitfalls section proving the fixes' own failure modes, plus an explicitly stated open problem.
  • Concrete map to deployed systems: Kimi k1.5 (K2), DeepSeekMath GRPO (K3), StableReinforce (K1/K3); regrouped log-ratio needs only 2 scalars per sampled category — a distributed-communication saving.

04Limitations

  • No end-to-end training evidence — impact on distillation / RLHF argued by construction and citation; interaction with Adam's ε unquantified.
  • Stable only near equality — overflow at e¹⁰⁰-scale intermediates (logit separation 50); the hybrid guard is outlined but never built or benchmarked.
  • One rounding failure (h = 2⁻²⁵) defeats every reformulation and passes the closeness guard — clean FP32 solution left open.
  • Scope: categorical only — continuous distributions, f-divergences, Bregman / Sinkhorn divergences deferred; MC sampling variance vs numerical error only conceptually separated.
  • FP32-only measurements; BF16 / FP8 / FP4 discussion is qualitative, extrapolated from Barron et al.

05Questions for Further Exploration

  • Q1Do these errors measurably change final reward, KL-to-reference, or student–teacher gap in real distillation / GRPO runs — and does Adam's ε mask or amplify them?
  • Q2How do the failures and fixes transfer to BF16 / FP16 / FP8 / FP4, where the "nearly equal" regime widens?
  • Q3Can a hybrid guard with a proven error bound replace the span ≤ ½ heuristic?
  • Q4Is there an FP32 reformulation that survives logit-subtraction rounding (h = 2⁻²⁵) — compensated subtraction, unnormalized logits — and at what cost?
  • Q5How do errors scale at realistic vocabulary sizes (K ≈ 10⁴–10⁵), where log-sum-exp error and summation order interact?
  • Q6Do the remainder / centering identities extend to continuous, f-, Bregman, and Sinkhorn divergences with quantitative guarantees?
