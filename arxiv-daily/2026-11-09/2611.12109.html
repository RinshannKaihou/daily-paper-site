Why this matters

Couples skill-library evolution with policy updates in one RL feedback loop, and quantifies how skill value decays — directly informing when memory/skill-augmented agent pipelines keep or discard experience.

⚠ Critical edge

Strip the skill library and SkillDuet falls to 76.67% — below the 93.81% of a baseline that never used skills — so part of the gain is prompt-dependence, not internalized capability.

Methodology

  • Extract Local skills. An external Qwen3.8-27B analyzer compares a successful vs. failed trajectory of the same task, pinpoints the earliest divergent decision, writes one shared Local skill; remaining ≤6 trajectories form the held-out scoring set.
  • Learn parameters via skill-guided OPD. Teacher branch = context + Global + Local; student branch = context + Global. Their token-level log-prob difference, gated by a sigmoid confidence (β=5), is added to the PPO objective: L = LPPO + λOPD·LOPD (λ = 0.05 ALFWorld / 0.03 WebShop).
  • Evolve skills via Strength. Strength = mean |Δ log-prob shift| a Local induces vs. token-length-matched neutral text on held-out trajectories — no extra environment rollouts. Every 10 steps the top-50% merge into Global (≤6 skills, ≤2,400 chars; hierarchical compression beyond 24 KB).
  • Setup. Qwen3-4B, no task-specific SFT, 300 steps, 8 trajectories/task. Matched SEED-API baseline shares analyzer, checkpoint, and OPD coefficients but keeps no Global — isolating co-evolution.

Analyzer endpoint is internal and non-pinned (“edu-vlm-rm”) — exact reproduction impossible.

Strengths

  • Clean co-evolution design with a genuinely matched baseline isolating skill consolidation and selection.
  • Strength criterion is cheap (reuses sampled trajectories) and principled — skills that no longer shift responses are already internalized.
  • The fixed-skill decay experiment (+26.98 → −2.00 pp) directly establishes the problem the method solves.
  • Exemplary controlled Global study: length-matched neutral text, identical initial states, game-clustered bootstrap CIs.
  • Exceptionally transparent appendices — cost accounting, worked synthesis example, candid disclosure of gaps.

Limitations

  • Single training run per configuration — the +2.86 pp ALFWorld gain could sit within run-to-run noise.
  • Only Qwen3-4B and two benchmarks; no math/coding/open-ended tasks, no larger backbones, no cross-domain transfer.
  • Depends on an external 27B analyzer for every trajectory group — 35k+ calls per run, on an unverifiable endpoint.
  • Policy is Global-prompt-dependent: without skills it underperforms the non-co-evolving baseline (76.67% vs 93.81%).
  • Strength measures shift magnitude, not benefit — harmful but response-shifting skills are not filtered out.

Questions for further exploration

  • Would the +2.86 pp ALFWorld gain survive multiple independent training seeds, given single-run comparisons?
  • Can Strength be made directional — separating beneficial from harmful response shifts — without the trajectory-quality confound?
  • Can the Global-conditioned policy be weaned off Global (annealed prompt dropout) so capability is fully internalized?
  • Does a larger backbone internalize skills so fast that Global consolidation becomes redundant?
  • Can Global sets transfer across domains or compose from multiple models, given demonstrated negative transfer?
  • What if the policy itself replaces the external analyzer — trading analyzer cost against skill quality?
