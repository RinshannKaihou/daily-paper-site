Planners Exploit Deterministic Error: Dithered Low-Bit World Models

Yong Hwi Song · Keon Myung Lee — Chungbuk National University Pre-registered study · ~147 GPU-h (RTX A5000)
quantization world models model-based RL sampling-based planning low-precision inference
Key metric
44.6 → 4.0pts

Mean planning-success drop across the 19 affected Meta-World cells (TD-MPC2 5M): deterministic round-to-nearest vs shared dither (sh-iter). Median damage removed: 95%; worst case still ≥50%.

Why this matters

Low-bit quantization silently breaks closed-loop inference while offline error metrics stay blind — and a numerical-layer fix repairs it for ≤2.3% latency.

Critical edge

The deployment story is muted: the integer kernel is not faster than pre-converted BF16, the fix is useless for planners with few iterations, and it fails on half of DMC.

Methodology

Controlled, pre-registered comparison of rounding rules for activation-quantized world models driven by sampling planners. Hypotheses, thresholds, seeds, and analysis code were frozen in hashed design documents before each stage's data.

  • Models & planners: TD-MPC2 5M single-task checkpoints (8 Meta-World + 4 DMC tasks, MPPI), the 317M multi-task checkpoint (mt80), and DINO-WM (PushT / Wall / PointMaze) with open-loop CEM.
  • Quantization: only hidden activations (2–5 bits) on per-layer calibrated uniform grids; weights and inputs stay FP. Variants differ solely in how the dither u is shared and how long it persists: det, ind, sh-iter, sh-step / sh-ep, det+shift.
  • Statistics: each variant paired with the FP baseline on identical seeds and planner noise (90–100 pairs/cell); one-sided paired bootstrap (10⁴ resamples) with Holm correction; "affected" = det loses ≥20 points.
  • Systems: fused Triton W8A4 integer kernel replayed as CUDA graphs (A40); NVFP4 / MXFP4 fake quantization on RTX 5090.

  • The error paradox: mw-pick-place @3 bits — det's latent one-step error is smaller (0.22 vs 0.39) yet it loses 37.8 pts vs 7.8 for sh-iter; in 29/36 affected cells det's error is no larger.
  • Mechanism, not correlation: fixing the shared dither for a step/episode (sh-step / sh-ep) reproduces 70–130% of det's favorable drift; sh-iter keeps ≤24%. At 12 MPPI iterations, sh-iter damage is 0–11% while det stays 43–47%.
  • Theory checks out: derived selection + drift terms match 922k simulated MPPI/CEM runs (fitted slopes 0.92–1.05).
  • FP4 boundary: under NVFP4 block scaling, det damages only 2/12 tasks vs 71.6% return loss on cheetah-run with a uniform 4-bit grid.

Caveat: headline numbers are conditioned on affected cells (bit width pre-picked where det loses ≥20 pts); "median 95% removed" is not an expectation over arbitrary configs.

Strengths

  • Names and proves a failure mode that offline metrics (one-step error, bit width) provably miss — supported by mechanism, not just correlation.
  • The fix is training-free, model-free, adds ≤2.3% latency, needs no calibration data, and transfers unchanged from 5M to the 317M checkpoint.
  • Exemplary experimental design: hashed pre-registration, paired bootstrap with Holm correction, positive controls isolating persistence, candidate-count dose-response.
  • Unusual honesty: failed hypotheses reported in Table I; DMC failure kept in scope with a validated explanation (persistent-share rule, Spearman 0.83 on new seeds).
  • FP4 analysis ties the failure to coarse shared-scale grids and shows block scaling removes most of the failure surface.

Limitations

  • Assumes an iterating planner: with 1 MPPI iteration sh-iter is no better than det; on DMC it helps only 5/12 cells and is harmful on walker at 3 bits.
  • Gains shrink on strong PTQ: borderline in 10/19 TD-MPC2 cells, absent in DINO-WM (1/3); never combined with calibration objectives.
  • Weak QAT baseline → nothing concluded about training-time fixes; 317M results rest on one checkpoint; FP4 closed-loop uses fake quantization, not fused kernels.
  • Speed story incomplete: eager kernels 18% slower; the 1.9–3.3× CUDA-graph win still loses to pre-converted BF16 (1.07–1.52× its rollout time); TF32 fix never run closed-loop.
  • Simulation-only (Meta-World, DMC, PushT/Wall/PointMaze); no physical robots; latency from one GPU family plus one Blackwell card.

Questions for further exploration

  • Would sh-iter protect other closed-loop consumers of quantized models — diffusion-policy denoising loops, best-of-N search over quantized LLMs, real-robot MPC?
  • Is one-step reward error (larger under det in 19/19 affected cells, 8/8 at 317M) a reliable pre-deployment diagnostic of exploitable quantization error?
  • Do dither and calibration objectives stack multiplicatively, or act on the same error mass — and does the answer change at W4A4?
  • Why does DMC resist the fix — return-based tasks, longer horizons, or dynamics landscapes — and can persistent share be estimated cheaply per task beforehand?
  • Does cross-unit correlation of deterministic rounding error predict damage, and would low-discrepancy dither beat uniform dither at the same persistence schedule?
