Why This Matters

Moves mechanistic interpretability from toy language tasks to real web-agent failures — quantifying exactly where probes, steering, circuits, and SAEs break in agentic settings.

Critical Edge

The missing baseline: constrained decoding to the action list would prevent ~100% of these hallucinations by construction — this work explains and monitors, but does not mitigate.

Methodology

  • Failure definition. An action is hallucinated if its generated selector (CLICK / TYPE / SCROLL / HOVER) does not exist in the provided action list — tested on live Online-Mind2Web websites, not a synthetic proxy.
  • Data. Qwen2.5-7B-Instruct rolled out zero-shot (≤10 page interactions/task): 300 episodes, 2,071 actions, 32.6% hallucinated; analyzed with TransformerLens on one A100 80GB.
  • Circuit discovery. Per-layer FFN amplification (×10), per-head Gaussian noise, 36 joint head/FFN configurations, and activation patching with corrupted input spans (selector / task / action list).
  • Feature identification. Linear probes per layer at three positions with episode-level 70/15/15 splits (no within-episode leakage); σ-normalized probe-weight steering with α ∈ {10…80}; a 131,072-feature pretrained BatchTopK SAE at layer 27; logit-lens decoding at the selector value.
  • Robustness. OOD re-run with the JSON action list rewritten as a numbered markdown list; counterfactual re-rolls with the chosen action removed (selector match, DOM Jaccard, hallucination delta).

Strengths

  • Self-sabotage rigor — the authors designed the format-shift experiment that breaks their own headline result, and report it prominently.
  • Real failure, live websites — clean operationalization of an agentic failure rather than a synthetic proxy.
  • Crisp two-level lesson — input-level attribution succeeds (action list dominates) while component-level attribution fails (no single head/FFN).
  • Quantified counterfactual divergence (38% / 28.1% / 0.52) for a methodological problem usually discussed only qualitatively.
  • Actionable six-point agentic-MI roadmap tied to the observed failures.

Limitations

  • Single model, single scale, single scaffold, single failure mode — generality beyond 7B web agents is argued by analogy, not data.
  • Steering is evaluated on the probe's training distribution; the only stress test is one prompt-format shift, with no cross-website / cross-task transfer reported.
  • SAE analysis confined to one layer (27) and one public checkpoint.
  • Explains where and when the hallucination commitment is encoded — not the algorithmic why.
  • Modest dataset (300 episodes); subgroup fix/break percentages rest on small samples.

Questions for Further Exploration

  • Does the pre-generation probe (0.80 AUC) transfer across websites, tasks, and scaffolds — or is it format-entangled like the steering direction?
  • Would SAEs trained on agent trajectories recover interpretable "generic Search intent" features the text-pretrained SAE misses?
  • Can steering survive training on multiple prompt formats simultaneously (format-invariant directions)?
  • Does distributed, non-localizable computation get better or worse at frontier model scale?
  • Since constrained decoding trivially prevents this failure, can the probe instead power early-warning monitoring of wrong-but-valid actions or task abandonment?
  • Do hallucination-predictive directions show universality across web, tool-calling, and embodied agents?
