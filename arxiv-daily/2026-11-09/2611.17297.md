> **一句话总结：** 本文在多步代码生成任务中定位到一组稀疏的"目标注意力头"（Qwen2.5-Coder-32B 中的 122 个），其输出在子目标实现开始前 3 个 token 即可解码出自然语言意图（faithfulness 0.90+，而残差流基线仅 ~0.01），并且移植到 C++ 上下文能以 96% 的成功率触发同一操作；进一步提出"非循环目标追寻（NRGS）"机制： Transformer 不把目标状态向前传递，而是在每个 token 处重读任务说明、重编码进度、对比二者选出剩余待办——KV 移植实验（causal-shift ~94%）和 query 移植实验（57% vs 随机头 3%）支持这一解释。

> **TL;DR:** Asking whether LLM goal-directed behavior has an internal basis, the authors localize 122 "goal heads" in Qwen2.5-Coder-32B-Instruct (layers 28–55) via mask-learned activation patching on a 253-specification Python/C++ multi-sub-task corpus; their pooled output, injected into a Patchscope-style probe ("GoalScope"), verbalizes the next sub-goal with 0.90+ faithfulness at the indent pivot (vs ~0.33–0.67 for the full attention-module baseline and ~0.01 for residual states) and triggers the same operation in a C++ stub 96% of the time (plasticity). Because goal info only becomes readable after layer 40 (leaving L−ℓ = 64−40 = 24 tokens — too few for the routinely observed 30+ token persistence), they propose the non-recurrent goal-seeking (NRGS) account: goal and progress are re-derived each step rather than carried forward; swapping task-span KV states of goal heads redirects the LM to the source sub-goal with ~94% causal-shift (readout shifts ~90%), while blinding 250 goal heads collapses next-sub-goal success from 0.925 to 0.158.

## 核心贡献

- **将"目标"操作化为三个可检验属性**：借鉴 Bratman 的规划理论，把目标定义为满足 (i) 预承诺（行动开始前已编码）、(ii) 可塑性（同一目标可经不同环境/语言实现）、(iii) 持续性（执行期间编码被维持）的功能状态，从而把"LLM 是否有目标"的哲学争论转化为可做因果干预的实证问题。
- **定位到稀疏的"目标头"并构建 GoalScope 探针**：通过跨编程语言（如 C++ 回文检查 → Python 去重检查）的联合掩码激活修补，在 Qwen2.5-Coder-32B-Instruct 中选出 122 个注意力头（占 4.8%，分布于第 28–55 层）；把它们的输出求和成单一向量注入到无上下文的探针运行中，即可让模型用自然语言说出即将执行的操作（如"I'm checking if a word is a palindrome"）。
- **证明该编码是因果的且跨环境可移植**：把 Python 上下文中捕获的目标编码注入 C++ 函数桩，96%（indent 起）触发同一抽象操作的 C++ 实现——编码定义"做什么"而非"怎么做"。
- **提出并用干预检验"非循环目标追寻（NRGS）"算法**：论证深度受限的 Transformer 无法把目标状态连续前传（目标 40 层后才可读，仅剩 24 层却常观察到 30+ token 的持续），提出模型在每个 token 处重读任务说明 G、从增长的上下文重编码进度 E_prog、对比两者选择待办操作；KV 移植（换 goal heads 从任务段读到什么）能以 ~94% 成功率改写模型下一步实现哪个子目标，query 移植（换进度编码）以 ~57%（vs 随机头 ~3%）按 NRGS 预测选择新目标。
- **机制跨领域复用**：纯在代码任务上定位的 goal heads，在少样本 ICL 中能说出隐式规则（antonym/country-capital 等达 80%+），对"涌现失准（emergent misalignment）"模型在生成前就能读出有害意图倾向，暗示 LLM 用同一机制在不同领域追寻目标。

## Key Contributions

- **Operationalizes "goal" into three testable attributes** — pre-commitment, plasticity, persistence — drawing on Bratman's planning theory, turning a philosophy-of-mind debate (Bender & Koller, Shanahan) into a causal-intervention research program.
- **Localizes goal encodings in a sparse set of attention heads ("goal heads")**: jointly learned sparse masks over head outputs, trained to transplant a source predicate's abstract encoding across programming languages (so the objective rewards abstract transfer, not token copying); yields 122 heads (4.8%) in layers 28–55 of the 64-layer Qwen2.5-Coder-32B-Instruct.
- **GoalScope, a lightweight Patchscope-based probe**: sums the goal-head outputs at a single pivot token into one vector, injects it (additive at layers 35–45, α=0.1 local norm) into a context-free probe run that verbalizes the upcoming operation — readable up to 3 tokens before implementation begins.
- **Causal-bottleneck evidence**: sufficiency ablation (only the 122 goal heads keep access to the task span; ~93% of heads in layers 20+ blinded) preserves next-sub-goal execution (clean 0.925), while necessity ablation shows blinding 122 heads barely hurts (0.854) but blinding 250 heads collapses success to 0.158 (random-head sink control stays 0.925) — redundancy exists but is concentrated.
- **The NRGS account with targeted causal tests**: a non-recurrent transformer cannot carry a goal state more tokens than it has layers left; instead the LM re-reads G from the task span, re-encodes progress E_prog from context, and contrasts them. KV-transfer of the goal heads' task-span states mid-execution redirects the LM to the source's next sub-goal (~94%) across languages; query transfer of the progress encoding shifts selection as NRGS predicts ~57% vs ~3% random-head baseline; residual patching shows the task span (89–98% causal-shift), not the code-progress span, dominates.
- **Mechanism reuse beyond code**: the same heads verbalize implicit few-shot ICL rules (80%+ on antonym/country-capital/person-occupation) and read out divergent intent in an emergently-misaligned model organism — goal pursuit appears to share circuitry across domains.

## Methodology

The authors study multi-step code generation where a prompt specifies 2–4 sub-tasks (boolean checks, counts, filtering over int/str/list[int]/list[str]) in Python or C++, to be implemented sequentially without chain-of-thought — 253 locked specifications, 1,012 pivot observations per configuration. Four pre-implementation "pivot" token positions are probed: prev_end, indent, var, eq.

1. **Localization (Sec 3.1)**: source and destination prompts request different predicates in different languages; a jointly-trained mask over all attention heads mixes source head contributions into the destination run (a←mask·a_src+(1−mask)·a), minimizing KL to a target run that implements the source predicate in the destination language, with sparsity loss; masks binarized at threshold τ=0.9 → 122 goal heads.
2. **GoalScope readout (Sec 3.2)**: goal-head outputs at the pivot are summed into v_g and injected at every generation step of a context-free probe ("What are you doing at this line?" for faithfulness; a blank C++ stub for causality/plasticity). Greedy decode ≤256 tokens; a claude-sonnet-4-6 oracle judges nontrivial agreement with the actual upcoming implementation.
3. **Persistence (Sec 3.4)**: cosine similarity between the goal-head encoding at the eq pivot and encodings sampled x% through the implementation, contrasted against same-goal-different-language and different-goal controls — mirroring Zeigarnik-like activation-drop accounts of human intention.
4. **Causal bottleneck (Sec 4)**: sufficiency = preserve goal heads' attention to task+code span while blinding all other layer-20+ heads; necessity = sink goal-head attention to the first token.
5. **NRGS tests (Sec 5)**: KV transplant swaps the task-span rows of goal heads' KV cache from a source run (psrc: abc→c) into a destination (pdst: abd→d) from the pivot onward; query transplant swaps the goal-head query at the pivot, transferring "progress"; residual patching (Appendix J) transplants task-span vs code-progress-span latents separately.
6. **Generalization (Appendices F, M)**: repeat localization + evaluation on 7 other LMs (Qwen2.5-Coder-14B, Qwen2.5-32B-Instruct, OLMo-3.1-32B (Instruct & SFT), Qwen3-32B, Devstral-Small-24B, GLM-4.5-Air), and NRGS experiments on 4 additional models.

## Results & Highlights

- **Pre-commitment (faithfulness)**: on the 253-spec corpus with Qwen2.5-Coder-32B-Instruct, the next sub-goal is decodable from goal-head outputs at the indent pivot (3 tokens before implementation) with **0.90+ readout score**, and already ~60% (0.59–0.61) at prev_end; baselines: full attention-module output (L40–50) reaches only 0.33–0.67 and residual states ~0.01 — selected goal heads far outperform both.
- **Plasticity (causality)**: transplanting the encoding captured in Python into a C++ stub triggers the same operation **96% of the time from the indent pivot** (mean ~87% across the four pivots), realized through different tokens/syntax — the encoding is context-invariant.
- **Causal bottleneck**: preserving only 122 goal heads' span access sustains execution at the clean level (0.925 success); blinding 122 goal heads leaves performance at **0.854 vs 0.925 clean**, but blinding the broader 250-head set collapses success to **0.158** (random-head sink control: 0.925).
- **NRGS — goal re-reading**: swapping goal heads' task-span KV states to a source run triggers the source's next sub-goal with **~94% causal-shift** (up to 0.97 for py→py), with the GoalScope readout flipping to the source goal **~90%** of the time, consistently across py↔cpp directions; residual patching shows transplanting task-span latencies alone yields **89–98%** causal-shift vs ~0.06 for code-progress-only.
- **NRGS — progress in the query**: query transfer makes the LM pick the NRGS-predicted pending sub-goal **~57%** of the time vs **~3%** for an equal-size random-head control — real but incomplete evidence that goal-head queries carry progress.
- **Persistence**: same-sub-goal cosine-similarity curves (including across languages) stay above different-sub-goal curves throughout execution, with observed persistence well beyond 30 tokens, although the goal only becomes verbalizable after layer 40 (L−ℓ = 64−40 = 24) — motivating NRGS.
- **Model scale/variants (Table 3, n=1,012 per model)**: 14B→32B Qwen2.5-Coder faithfulness rises **78.9%→90.7%** and causality **62.5%→91.7%**; GLM-4.5-Air reaches 94.8% faithfulness / 77.3% causality with 178 heads (4.0%).
- **Beyond code**: on 39 single-relation ICL tasks GoalScope verbalizes the implicit rule at **36.2% ± 5.6%** (80%+ for antonym/country-capital/person-occupation; <20% for en→es/en→de translation); abstractive tasks 49.9% ± 6.4% vs extractive 9.0% ± 5.7%.
- **Judge validation**: on 130 readouts, human–Claude-judge agreement is **96.2% (125/130)** and 97% of judge-YES verdicts are human-confirmed (though human–Claude Cohen's κ = 0.69, Claude–GPT κ = 0.16).

## Authors & Credibility

Senior-authored by David Bau (Northeastern), whose lab produced foundational linearity/editing work (ROME, function vectors, filter heads) and the NNsight/NDIF infrastructure used here; first author Arnab Sen Sharma has prior ICLR/COLM interpretability papers (filter heads, Mamba ROME). Co-authors include NNsight's creator (Fiotto-Kaufman is acknowledged for independently re-implementing the pipeline in nnterp and reproducing results on additional model families — an unusually strong external check), and researchers from Parallax, Copenhagen, and Oxford. The paper is unusually forthright: it includes an AI-use statement, validates its LLM oracle against 12 human annotators plus a second oracle (gpt-5), releases code and dataset (goals.baulab.info), and runs on commodity 80GB A100s with HuggingFace/PyTorch — reproducible in principle for academic labs. Philosophy (Bratman, Fodor, Dennett) is cited accurately and used to structure operational tests rather than as decoration.

## Critical Assessment

- **Novelty**: High. Function vectors (Todd et al. 2024) and filter heads showed portable abstract encodings; this paper goes further by (a) tying the encoding to a rigorous three-property definition of goals, (b) addressing the depth-bounded persistence puzzle with a concrete, testable algorithmic account (NRGS), and (c) demonstrating mid-execution redirection across languages. The NRGS framing — the LM re-derives the goal each step instead of carrying state — is a genuinely useful conceptual contribution.
- **Rigor**: Mostly strong (causal interventions with proper random-head and clean controls, judge validated against humans), but two weaknesses stand out. First, the oracle judge: human–Claude agreement on YES verdicts is 97%, but the not-YES agreement is poor (human–GPT 12.5%, Claude–GPT 11.1%) and Claude–GPT Cohen's κ is only 0.16 — the judges basically never agree on negatives, so "partial credit" YES rates (a nontrivial partial implementation counts) may overstate success. Second, the head set is somewhat brittle/arbitrary: 122 heads pass the necessity test (0.854, barely below clean 0.925) and the paper relies on the broader 250-head set for the strong NRGS interventions — the boundary of "goal heads" is a threshold choice (τ=0.9), and goal-head readout performance does not improve monotonically beyond ~100 heads.
- **Reproducibility**: Good — public code/data, standard open-weight models, hyperparameters documented, plus an independent third-party re-implementation (Appendix M) across model families up to GLM-4.5-Air (106B/12B-active). Caveat: results depend on hyperparameters (injection layers 35–45, α sweeps only partially explored; the authors admit no systematic grid search for cost reasons).
- **Significance**: Conceptually significant for interpretability (long-horizon computation in depth-bounded transformers) and for AI-safety-adjacent intent reading (the emergent-misalignment readouts). But the setting is deliberately narrow: spelled-out sub-tasks, no chain-of-thought, an instruction-tuned code model, sub-goal lengths of tens of tokens. The EM analysis is qualitative with no gold target; the ICL generalization is patchy (9.0% on extractive tasks, <20% on translation) — the "same mechanism across domains" claim is stronger than this evidence.
- **Red flags**: (i) The query-transfer result (57% vs 3%) is the weakest link in the NRGS argument and the authors honestly concede they "have not captured the full story"; the proposed ATT N(q≈−E_prog, {K,V}=G) implementation is explicitly illustrative, not established. (ii) Contrastive prompt design guarantees a single correct target sub-goal — how the LM chooses among several pending operations is untested. (iii) Obstacle persistence (goal robustness to perturbations) was tested and found absent at this scale, then left to an appendix — a goal-like agent that abandons its goal when derailed arguably weakens the strong "LLMs have goals" framing, even though the paper is careful to say the answer depends on which philosophical account you adopt. (iv) All "success" numbers flow through one commercial oracle model with a lenient partial-credit rubric.

## Strengths

- Clean operationalization of a vague concept (goals) into three falsifiable properties, each paired with a dedicated intervention — a template for philosophy-informed interpretability.
- Cross-language transplantation design is clever: localizing with different languages in source/destination forces the mask to select abstract, token-independent encodings rather than surface copying.
- The NRGS hypothesis resolves a real architectural paradox (finite depth vs 30+ token persistence) and generates two independently testable predictions (task-span KV content; progress in the query), both supported causally.
- Honest negative and weak results are reported in place (122-head necessity null, 57% query transfer, ICL extractive failures, κ statistics of the judges), plus an independent re-implementation across 8 models including a 106B MoE.
- Practical artifact: GoalScope works as a training-free, lightweight intent reader at a single token position, transferable to ICL-rule verbalization and misalignment probing.

## Limitations

- Controlled, narrow setting: sub-goals are explicitly listed in the prompt, tasks are simple one-function programs, and no chain-of-thought is allowed; open-ended agentic behavior, self-set goals, and long-horizon plans are out of scope (acknowledged in Appendix N).
- Persistence here is only temporal; obstacle persistence (robust pursuit under planted perturbations) is not consistently present in the studied 32B-scale models (Appendix K.2), so the finding covers a weaker notion of goal than classic agent architectures (SOAR goal stacks, BDI).
- GoalScope has un-searched hyperparameters (injection layer range, α, head count) and its readout quality varies widely by task type (80%+ on some ICL relations, 9% on extractive tasks).
- The exact NRGS implementation is not mapped — the attention-read proposal is a hypothesis; task order is shown to be a parallel cue (Appendix I.2), and larger/deeper models could afford some genuine state-carrying (the authors note very large LMs may not need frequent re-reading).
- Architecture-dependent: the account assumes attention is the only cross-token pooling mechanism; linear-attention models with fast-weight memory (DeltaNet) could maintain a running goal state without costing layers, changing the picture entirely.
- Oracle-based evaluation with partial credit inflates success rates, and the two LM oracles disagree badly on negative verdicts (κ=0.16).

## Relevance

对关注 LLM 可解释性与"模型是否有内在目标/意图"的研究者，本文提供了一个可操作的实证框架：用稀疏注意力头定位 + 因果干预来检验目标编码，并用 NRGS 解释 Transformer 如何在深度受限下维持长程目标。其 GoalScope 式"读出模型即将做什么"的技术对监测 agent 与失准模型意图有直接参考价值。

## Questions for Further Exploration

- How does NRGS scale to settings where sub-goals are not spelled out in the prompt — implicit plans, agentic tool use, or chain-of-thought reasoning models that can externalize state into generated text?
- Would a DeltaNet/linear-attention hybrid that can overwrite a fast-weight goal state in place show true state-carrying persistence, and can the KV/query transplant battery distinguish it from NRGS?
- Why is query transfer (57%) so much weaker than KV transfer (~94%) — is progress encoded distributively across many heads, in MLP outputs, or in the goal heads' keys rather than queries?
- Can GoalScope readouts be turned into a real-time intent monitor for coding agents, e.g., detecting divergence between declared intent and executed action mid-generation?
- Does the emergence of goal-head concentration around layers 40–50 (of 64) predict where such encodings live in other model families, and does goal-head density scale with an model's ability to plan?
