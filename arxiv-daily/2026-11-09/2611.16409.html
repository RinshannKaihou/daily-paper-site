Methodology — distilled

  • One policy, three roles. Actor, reflector, and curator share a single model inside the ACE harness; a natural-language playbook persists across attempts via structured ADD / UPDATE / REMOVE edits.
  • Executed-playbook reward. Each candidate playbook is scored by one fresh actor rollout under the benchmark's task verifier — no learned reward model; RLVR extended to intermediate text.
  • Per-role comparison groups. Reflections (M=2) and edits (C=3) are ranked against same-input siblings within GRPO's 8-rollouts-per-task budget; group-normalized advantages feed one DAPO-style clipped surrogate (no critic, no KL).
  • Bounded memory. A candidate replaces the playbook only if its executed value beats the seed's reward; playbooks reset to empty every F = 3 encounters.

Models: Qwen3-0.6B (Mastermind, MBPP) · Qwen3-4B-Instruct-2507 (AppWorld, MiniSWEBench) · 2×H100/H200 per run

  • Beats the GRPO checkpoint deployed inside the same harness: 0.99 vs 0.82 (MBPP), 0.67 vs 0.60 (AppWorld) — not just a better actor.
  • Edits-discarded control (actor fixed): applying edits adds +0.105 at K=2 on AppWorld — the playbook itself contributes.
  • Critic-based delayed-joint PPO collapses to 0.000 on AppWorld despite critic explained variance > 0.95.
  • RSI@K stays above pass@K through K = 8, ending 0.81 / 0.99 / 0.81 / 0.40 vs GRPO's 0.78 / 0.91 / 0.68 / 0.30.

Strengths

  • Clean EHRL formulation that isolates exactly what outcome-only RL and frozen-model harnesses each lack.
  • Executed-playbook reward reuses the benchmark verifier RLVR already trusts — no learned reward model.
  • Same-input groups let a failed seed still earn a positively-rewarded reflection; ablation shows they change credit variance, not its target.
  • Exceptional hygiene: equal FLOPs, matched rollout budgets, paired per-task stats, edits-discarded control.
  • Honest failure reporting — delayed-joint collapse, the MBPP grader exploit, and the fading Mastermind benefit are all in the paper.

Limitations

  • Needs resampleable handoff artifacts; agents that entangle acting and remembering fall back to much weaker chain-level credit.
  • Equal-compute axis counts update FLOPs only — reflector/curator generation adds real wall-clock cost.
  • Playbooks are task-local; no cross-task memory transfer is studied.
  • Evidence capped at 4B parameters, one training run per method, four benchmarks.
  • MBPP env shows the scored assertions; Mastermind playbook benefit fades after K = 3.
  • Safety of passing experience forward in open-ended settings is scoped out.

Questions for Further Exploration

  1. Does the executed-playbook reward scale to frontier models, or does actor quality dominate?
  2. Can task-local playbooks become shared cross-task memory without breaking credit assignment?
  3. V(P′) is a one-sample estimate — would 2–3 evaluation rollouts change learning speed or final RSI@3?
  4. Why does critic-based delayed-joint PPO collapse despite explained variance > 0.95?
  5. Can the edits-discarded control become a training signal — the playbook's marginal value?
  6. How robust is executed-artifact verification to agents that game the verifier via the artifact?
