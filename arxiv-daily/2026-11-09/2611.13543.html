Key metric
48–63%

of each head's self-value cosine "alignment evidence" is explained by a simple earlier-position null — across 5,408 heads in 9 pretrained models (124M–6.9B). Even at 6.9B, 58.1% is null.

Why this matters

Its three checks transfer to any statistic-driven architecture edit — head pruning, representation denoising, circuit surgery — where "big number, remove it" reasoning currently goes unaudited.

Critical edge

The headline conclusion is confounded: RANDOM is a static direction while XSA removes an input-dependent one — the decisive per-token control remains to be tested.

MMethodology — three checks, one target

  • Target: XSA — each head's output is edited as z = y − tanh(α)·⟨y, v̂⟩·v̂, removing the component aligned with the head's own value vector, before the output projection.
  • Check 0 · Resolvability — split-half reliabilities of the intervention effect (r_Δ ≥ 0.6 reliable; < 0.3 unresolvable) so small correlations aren't misread as "no relation".
  • Check 1 · Geometric null — compare cos(y_i, v_i) against cos(y_i, v_j) for earlier positions j in the same sequence; the paired difference isolates "excess" alignment beyond shared anisotropy.
  • Check 2 · Matched intervention — pre-registered 3-arm × 8-seed paired factorial at 50.9M params on FineWeb-Edu (~4.0×10⁸ tokens/run); every seed shares init, token stream, LR schedule, and validation batches.
  • Reconstruction gate — rebuild each head output as A·expand_kv(V) and reject relative Frobenius error > 10⁻², catching silent head-layout bugs before any measurement is trusted.

Audit trail: pre-registered primary endpoint, MIT-licensed code, Zenodo archive, automated 48-cell table checker + 33-claim reproduction manifest — total compute cost $15.58.

  • XSA's effect is ~1.6× its minimum detectable effect (dz = −1.65); the control's is below its MDE — a random rank-one edit does nothing.
  • Statistic–effect coupling is model-dependent: disattenuated correlation +0.52 (GPT-2) vs ρ = +0.003 (Pythia-2.8B) — raw self-cosine completely decouples there.
  • GQA reversal: own-group excess +0.24 to +0.27, but −0.11 to −0.19 across groups (Qwen2.5-0.5B/1.5B, TinyLlama-1.1B) — alignment is genuinely KV-group-specific.
  • Attention sinks and massive activations survive their nulls (0.403 vs 0.003; 12.87 vs 3.65) — unlike self-value alignment, they are not explained away.

+Strengths

  • Turns vague discomfort about "statistic-large-then-remove" papers into three concrete, reusable, cheaply runnable checks with explicit thresholds.
  • The null is measured within the same run, documents, and length — internally matched, robust to cross-study corpus differences.
  • Pre-registering the control comparison as primary endpoint is a model of self-sceptical design.
  • Exceptional transparency: archived code/data, deviation disclosure, adversarial AI-review statement.
  • The GQA within/across-group reversal is a crisp, novel empirical finding.

−Limitations

  • Training result confined to 50.9M params / 4×10⁸ tokens — two orders below the 0.7B–2.7B regimes audited; the planned scale check was cancelled.
  • Effect is tiny: −0.0029 nats ≈ 0.1% of typical loss levels; no downstream-task evaluation.
  • Control confounds direction with per-token vs static projection and projection magnitude.
  • GPT-2 geometry failed to reproduce the reference triple within tolerance; the null is strongly length-dependent (excess 0.235@64 → 0.412@1024 tokens).
  • 7 of 12 ladder models lack intervention measurements; all statistics are cosine-based.

?Questions for further exploration

  1. Would a per-token control (projecting out an earlier token's value) erase the −0.0040-nat XSA-vs-RANDOM gap?
  2. Does the benefit persist at 0.7B–2.7B parameters, and does it translate to downstream tasks rather than perplexity alone?
  3. Why does raw self-cosine predict effects in GPT-2 (ρ = +0.52) yet decouple completely in Pythia-2.8B (ρ = +0.003) — scale, data, or architecture?
  4. Can the GQA group reversal (+0.24 vs −0.19) become a cheap diagnostic for value-sharing pathologies in grouped-query designs?
  5. Do non-cosine statistics (attention-probability, projection-norm) yield more stable cross-model predictors of intervention sensitivity?
