TL;DR / 一句话总结

For one-class, step-level failure attribution in autonomous agents, predictable one-step innovation scoring gives exact localization (one error → one flag), distribution-free trajectory FDR control, and a confusability floor decaying as n−1/(d+2) — so embedding dimension, not data volume, is the binding constraint.

本文为自主数据分析 Agent 的逐操作失败归因建立统计理论：证明一步创新残差可精确局部化（一个错误只产生一个标记），给出控制轨迹 FDR 的 BY/e-BH 程序，并证明随校准样本量以 n−1/(d+2) 衰减的可识别性下界——在 d=256 时数据量增加 100 倍该下限仅降低不到 2%。

Key Finding

One-step innovation residuals localize each agent failure to exactly one flag; a confusability floor bounds what any audit can ever attribute.

Key Metric

floor reduction from 100× more data (d=256)

Halving the floor needs ~10⁷⁸× more calibration trajectories.

Why This Matters

Powers trustworthy LLM-agent oversight — attributes each autonomous-agent failure to the exact operation that caused it, with no labeled failure examples.

01Critical Edge · the sharpest critique

No empirical validation of its own: every prediction — exact localization width, the n−1/(d+2) floor rate, off-support tail behavior — is untested on real agent trajectories, so applicability rests entirely on assumptions A0–A5 holding.

03Exact Localization — Theorem 1

1 genuine error → 1 flag

A correctly executed operation that follows an earlier corruption has a null generalized residual conditional on its realized input state — so inherited pollution produces no signal.

Innovation (1-step)
Symptom-masks-source solved: clean op after corruption → residual ≈ 0.
Reconstruction / rollout
One error smears across every downstream operation → many false flags.

04Results & Theoretical Highlights

  • Prior Who&When benchmark best step-level accuracy: 14.2% — this paper supplies the missing theory.
  • FDR: BY at level q/HTmax & e-BH control trajectory FDR under arbitrary dependence; needs only exchangeable calibration, not a correct model.
  • Max vs χ² channel at d=256: max needs 3.3× less noncentrality for a 1-sparse shift — but only for <3% of coordinates.
  • Adversarial late-shift at s₀=0.89 is 9× as damage-efficient as the same shift at the start.
  • Pooled recurrence lowers the noise-limited boundary by √mc — but not the confusability floor.
