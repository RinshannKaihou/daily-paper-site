SkillZip: Contract-Preserving Graph Compression for Scalable Agent Skill Libraries

SkillZip reframes agent skill libraries as source-grounded, contract-bearing section-level procedural graphs, then compresses recurring motifs into reversible macros — preserving boundary ports, dependency closure, verifier reachability, and source pointers — and hydrates only the minimal dependency-closed context per task.

arXiv:2608.05604 graph-compression procedural-memory skill-retrieval LLM-agents arxiv.org/abs/2608.05604 ↗

Xingyu Tan · Xiaoyang Wang · Qing Liu · Xiwei Xu · Xin Yuan · Liming Zhu · Wenjie Zhang  —  UNSW · CSIRO

Key finding

Compress agent skill libraries into section-level contract-preserving graphs — lifting reward and cutting tokens & storage at once.

Key metric

71.0%
active-storage cut (18.6 MB → 5.4 MB) at 3.46× compression, 99.2% dependency preservation.

Why this matters

Tackles the central tension between compression efficiency and execution reliability when agent skill libraries grow to tens of thousands of overlapping skills.

Critical edge

The headline +12.2 points lives on ALFWorld — only 37 skills, near-saturated (SkillDAG already hits 93.6% with gpt-5.2-codex). The more defensible SkillsBench deltas are +6.0 / +6.2.

The whole pipeline is bounded by LLM-driven Sec2Graph extraction — only 79.6 exact match on implicit preconditions/guards. Under 40% noise, reward collapses 33.3 → 24.1 and VR 98.7 → 77.2. Proposition 1 recovers recorded structure, not correctness — bad contracts survive compression faithfully.

Pipeline · four stages over one procedural graph

01
Sec2Graph
Segment skills into 9 typed execution roles (Intent→Output); typed dependency / verifier / repair edges.
02
MotifZip
Mine motifs; promote to ported macros only if interface stable, dependency closed, verifier reachable.
03
PathHydrate
Task-anchored RRF seeding → constrained subgraph → 4-level macro hydration, sufficiency-gated.
04
ReZip
Incremental assimilation; execution traces demote / split / retire risky macros at 0.22× cost.

Core contributions

  • Sec2Graph — 9 typed execution roles form one section-level procedural-memory unit; internal reuse becomes visible.
  • MotifZip — typed graph grammar + 3 independent contract checks; MDL-style gain with explicit Risk / Cut penalties.
  • PathHydrate — sufficiency-gated hydration (name → contract → outline → source), not budget-filling.
  • ReZip — execution-aware demotion/splitting/retirement keeps the library executable as it evolves.
  • Plug-and-play — no fine-tuning; works across 6 LLM backbones, technical + embodied benchmarks.

Limitations

  • Only two benchmarks; ALFWorld is small (37 skills) and saturating — largest delta is on least-stressful library.
  • Pipeline ceiling = Sec2Graph extraction quality (79.6 EM on preconditions); provider-dependent.
  • Proposition 1 guarantees structural recovery, not correctness of recorded contracts / verifiers.
  • Greedy MotifZip disclaims global optimality; no approximation bound.
  • No head-to-head with SkillOps / SkillGraph / SkillReducer / SkillRAE; no oracle-extractor control.
