01 Key Finding

MERIT reformulates Text-to-SQL repair as causal episodic memory — dual-polarity entries (oracle-verified fixes vs. failed directions) indexed by a deterministic error type — lifting Spider accuracy without any training.

Honest framing: the paper itself reports the gain is clear on Spider but borderline on BIRD, and that the method ties untyped Dynamic RAG.

03 Methodology

A shared, greedy-decoded initial SQL (58.90% Spider / 38.40% BIRD) is reused by every method, isolating the effect of the repair strategy. Each initially-wrong query runs a K=7 repair loop:

  1. Deterministic failure classification — rule-based labeler maps the failing query to one of 7 types using only execution status + observable DBMS error text.
  2. Causal candidate construction — pool restricted by temporal (sourcePos < t), query (≠ current), and database constraints; same-type subset used when ≥3 entries.
  3. Hybrid ranking — min-max-normalized dense + BM25 at 0.75 / 0.25; at most 3 positives + 1 negative.
  4. Repair generation — single user message through frozen chat template; greedy decoding; reference SQL never exposed.
  5. Episode finalization — on success, store one positive (failed→correct transition); on budget exhaustion, store one negative (last failed direction); visible only at t+1.

04 Results

  • Spider EX: 69.79% vs 66.34% Iterative (+3.45 pp, CI [+1.97,+4.96]); ties Dynamic RAG; beats Reflexion by +1.42 (CI crosses 0).
  • BIRD EX: 48.44% vs 47.35% (+1.09 pp, CI [0.00,+2.17] — borderline). Reflexion wins BIRD at 51.24%.
  • Repair productivity: 112.7 fixes vs 77.0 (Iterative); lowest trajectory length (5.61) and oscillation (31.95%).
  • Schema-locality is the clearest ablation: removing cross-DB retrieval costs −0.93 pp (Spider), −2.74 pp (BIRD).
Cost: MERIT does not reduce total tokens vs. stateless repair — retrieved memories lengthen each prompt (Spider: 5.27M vs 2.53M tokens).

05 Key Contributions

  • Causal episodic memory — only earlier-finalized episodes (different queries) are retrievable; current trajectory can't peek at itself.
  • Online dual-polarity memory — positives = oracle-verified failed→correct transitions; negatives = last failed direction of unresolved episodes; ≤1 entry per episode.
  • Error-type-conditioned retriever — coarse deterministic type as a retrieval prior, with same-polarity fallback when the typed pool is thin.
  • Rigorous controlled study — shared initial predictions, frozen backbone, fixed K=7, three stream orders, query-cluster bootstrap CIs.

06 Critical Assessment

Novelty — Moderate

Cross-episode memory (Reflexion, ExpeL), RAG Text-to-SQL (DAIL-SQL), and execution-guided repair (Self-Debugging, CRITIC) all pre-exist. The new piece is the joint polarity × error-type organization plus the strict causal constraint — which the honest Dynamic-RAG tie undercuts.

Rigor — Strong / Weak

Strong internal validity (shared predictions, paired CIs). Weak on the classifier: ~48% accuracy, Macro-F1 ≈ 0.32–0.36; RESULT MISMATCH lumps many distinct semantic errors.

Reproducibility — Reasonable

Named backbone, fixed weights, public dev sets, prompt templates in appendices. But no code release mentioned, and the dense encoder is unspecified.

Red flag: only one backbone (7B), dev sets only — generalization to other scales, multilingual, or production schemas is unestablished. The "causal" branding is oversold given it still relies on a denotation-level oracle.

07 Limitations

  • Requires a denotation-level oracle for termination/polarity — stronger than production DB feedback.
  • Single backbone, Spider/BIRD dev sets only.
  • Classifier is coarse (~48%); RESULT MISMATCH conflates many semantic errors.
  • Three stream orders only — memory contents are order-dependent.
  • Not cheaper than stateless repair in total tokens.
  • Retrieval weights / allocation fixed, not tuned per benchmark.

08 Strengths

  • Exemplary hygiene: shared initial SQL, frozen backbone, paired CIs.
  • Negative findings reported inline (ties Dynamic RAG; Reflexion wins BIRD; no token savings).
  • Schema-locality ablation isolates an actionable insight: same-DB patterns matter most.
  • Classifier is cheap, interpretable, honestly characterized.
