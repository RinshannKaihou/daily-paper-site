TRAJDEBUG: Tracing the Error Lifecycle to Find Critical Failures in Long-Horizon Agent Trajectories

Yunjia Qi, Zehua Yin, Xintong Shi, Hao Peng, Songyuanyi Lu, Yixian Liu et al. — Tsinghua BNRst-KEG · Tencent Hunyuan
LLM Agents · Error Attribution · Process Supervision
TL;DR A three-stage framework — multi-granularity compression, evidence-constrained error triggers with four-state classification, and candidate-set causal attribution — that localizes the earliest decisive error step in failed agent trajectories. Ships with TRAJERRBENCH (486 annotated trajectories, up to ~120 steps).
Key Finding
Reframes critical-error detection as tracing an error lifecycle — trigger → four-state classification → causal attribution — to find the earliest decisive step that flipped success into failure.
Key Metric
34.11%
avg critical-step accuracy, +8.42 over same-backbone direct prompting. Lifts agent success 78.07 → 88.87 (+10.80) when fed back as feedback.
Why This Matters
Directly targets LLM agent debugging and failure attribution, with an auditable multi-stage method and a long-horizon benchmark — useful for building self-evolving agents.

Method § 3.1–3.4

STAGE 0
Multi-granularity compression
High / medium / low views per step — verifiable local evidence, compact distant context.
STAGE 1–2
Triggers → four-state classification
Verbatim-evidence triggers, clustered by reference object, labelled Clean / Costly Resolution, Manifest / Latent Active.
STAGE 3
Candidate-set causal attribution
Select origin step from terminal-relevant candidates — not "earliest wins", evidence-ordered.
  • Pilot finding: 7.62 local errors per failed trajectory, only 1 critical — 61.9% of non-critical errors are later repaired.
  • Anti-hallucination: triggers must cite verbatim q_w (erroneous commitment) and q_r (violated reference), else discarded.
  • Budget-debt footprint: an instance is "terminal" if it wastes >50% of the trajectory budget.

Critical Assessment

⚠ Sharpest critique

Absolute accuracy stays ~34% — the framework still mislocalizes the critical step in roughly two-thirds of cases. The application study reports no confidence intervals or significance tests, and the main repair setting assumes an oracle failure signal, which is unrealistic for production.

  • Backbone confound: detector is Qwen3, actor is GLM-5.1 — gains may come from cross-model prompt diversity, not diagnosis quality.
  • SWE-Bench Pro anomaly: CHIEF collapses to 2.32% — benchmark may flatter this method's design.
  • No tuning study for the load-bearing k=50 budget-debt threshold.
