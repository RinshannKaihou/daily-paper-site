Quantum Error Correction · Theory + Simulation · Harvard

Provably Efficient Self-Calibrating Quantum Fault Tolerance

Weiyuan Gong (Harvard SEAS)  ·  Hong-Ye Hu (Harvard Physics / IOP-CAS)

Syndrome statistics aren't just for decoding — after randomized compiling, the average detector-event rate is a locally strongly-convex function of the analog control knobs. A classical controller can therefore turn real-time calibration into provably efficient zeroth-order online optimization, run while the computation keeps going.

quantum-error-correction fault-tolerance quantum-LDPC online-optimization neutral-atom-quantum-computing

1Key Finding

The detector-event rate is a locally strongly-convex calibration objective — so zeroth-order SPSA restores drifted controls in O(1/ε²) epochs, and LSPSA does it independent of code distance.

2Key Metric

O(ε⁻²) epochs

to reach ε-optimal detection rate — the information-theoretically optimal zeroth-order rate. Circuit sims run at baseline depolarizing error εi(0) = 10⁻³ per gate.

5 control params / gate

3Why This Matters

Promotes calibration from an offline helper to an online, provably-efficient fault-tolerance component — vital for long-running quantum memory, and a methodology template for future qLDPC processors.

Methodology — two layers

The controller can't see logical error rate (rare, unidentifiable mid-computation). It sees the average detector-event rate C(θ) = (1/ND) Σk DRk(θ). The paper first proves this landscape is geometrically nice, then runs online optimization on it.

THM 1
Local convexity

After Pauli twirling, Hessian ∇²C(0) ⪰ 0 for coherent, CPTP, and leakage/atom-loss errors; smoothed analysis removes accidental degeneracy.

THM 2
One-time drift

Projected SPSA with two noisy evals / epoch hits E[C−C*] ≲ O(1/√T), i.e. ε-optimal in O(ε⁻²) epochs.

THM 3
Dynamic regret

Under slow drift, E[DynReg] ≲ O(1/√T) + O(PT/T) — average regret → 0 when path length PT = o(T).

THM 4
Distance-free

Locality-aware LSPSA colors control coords (χ ≤ c(s−1)+1); complexity depends only on locality constants s, c — not code distance.

Algorithm sketch

Each epoch: sample ±1 perturbation ut; collect two batches of m QEC cycles at θt ± λut; form a gradient estimate from the two detection-rate samples; project the update back into the trusted convex ball. LSPSA masks each gradient entry to only the ≤ c detectors a coordinate actually touches.

Results

≈ unchanged
LSPSA's calibrated detection rate stays flat as surface-code distance grows — direct confirmation of Thm 4. (Conventional SPSA shows the predicted O(d) degradation.)
≥ RL baseline
LSPSA matches or beats the Google/Sivak RL controller using fewer syndrome samples per estimate, and stays flat where RL drifts back up from exploration.
2 testbeds
Exact pulse-level neutral-atom sim of [[4,1,2]] (Rydberg leakage native) + large-scale Stim Clifford sims on rotated surface codes & BB codes.
η = 0.005
Fixed across all scenarios; "even faster in practice" than the predicted rate on the [[4,1,2]] pulse sim.

Authors & Credibility

Active researchers in QEC & characterization (co-authors on robust property learning and high-rate qLDPC processors). Positions itself as the missing theoretical companion to the Google Quantum AI RL-calibration demo (Sivak et al., Nature 2026).

Strengths

  • First provable efficiency guarantees for a problem previously only treated heuristically (RL).
  • Clean 4-theorem progression (convexity → one-time → dynamic → distance-free) — easy to teach & build on.
  • LSPSA locality argument is general: surface, BB, lifted-product, Tanner codes from one graph-coloring construction.

Limitations

  • No reported logical error rate pL improvements — only the detection-rate surrogate.
  • Theory strictly local; global / cold-start calibration is out of scope (NP-hard in general).
  • No sweep of epoch size m or perturbation radius λ; thin tuning guidance.

Open Questions

  • Does distance-independence survive when Ωi is spatially/temporally correlated (e.g., a single global laser drift) rather than i.i.d.?
  • Can the loop be closed — does a factor-X drop in C(θ) yield a predictable drop in logical pL below threshold?
  • Joint design of fast decoder + slow calibrator: feeding calibration-adjusted priors into MWPM / belief-matching?
  • Robustness of the convexity theorem when twirling itself is imperfect, or applied at a rate comparable to the drift.

Locale & Scope

Local-only analysis (‖δθ‖ ≤ θC(th)). Global calibration is NP-hard (Bittel-Kliesch); the accelerated-GD extension in App. D2 reaches only an approximate local minimum.

Covers continuous drift correction — not cold-start or large-miscalibration recovery.

Sharpest Critique · Asset 4

▲ Critical Edge

The circuit-level noise model (Eq. 10) sets the control-induced error to εi(0) + δθi⊤ Ωi δθi with Ωi a random PSD matrix — it assumes the very convex landscape the theory predicts instead of deriving it from a microscopic pulse model at scale. The pulse-level sim that does derive the landscape from Rydberg physics is only on the tiny [[4,1,2]] code, so the central scalability claim (Theorem 4) is validated on a model that bakes in its own conclusion at the per-gate level.
