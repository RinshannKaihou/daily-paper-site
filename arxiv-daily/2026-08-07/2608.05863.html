Runtime Observability for Heterogeneous Attention Memory

Fanzhe Wei · Li Liu · Ziyang Wang · Chenyu Wang  —  Metask Lab  ·  arxiv.org/abs/2608.05863
★ Key Finding The error metric is promoted into the type of an attention-memory contract, so illegal compositions of heterogeneous memory (dense KV, MLA, sparse selectors) fail by construction — and the method caught the authors' own first attempt.
Core Claim
Three operators (update / select / read) each carry a typed local contract; composition is defined only when metrics match.
Key Metric
−0.94%
throughput cost of always-on fused probe (1/28 layers), inside noise floor; TTFT P99 −0.14%.
Why This Matters
A machine-decided certified / empirical diagnostic paradigm for any team introducing compressed or structured attention (MLA, NSA, GLA) into an LLM serving stack.
Critical Edge
The headline "request-level risk ledger" is sound but currently vacuous — summed TV budget over 43 layers = 36.3, no end-to-end bound.

The Contract, Visualised

Any attention memory is reduced to three operators. Each carries an affine local contract with an explicit failure budget:

e_out ≤ a · e_in + b   (fails with prob. ≤ δ)
UPDATE
(a₁, b₁, δ₁)
SELECT
(a₂, b₂, δ₂)
READ
(a₃, b₃, δ₃)
(a₂,b₂) ∘ (a₁,b₁) = (a₂·a₁, a₂·b₁ + b₂)  ;  Σᵢ δᵢ ≤ δ_req

What makes it do work

  • Metric-as-type. A dimensionless storage ratio summed into attention total-variation is rejected at Lean elaboration — the checker killed the authors' own first composed chain.
  • Three-tier strength. Every metric registers as certified / partially certified / empirical. Composition inherits the weakest tier — the system refuses to print "end-to-end certified" unless every stage earns it.
  • Telescoping budget. δᵢ = δ_req / ((i+1)(i+2)) — sound at unknown request length; machine-checked theorem.
  • CUDA-graph fused meter. 24.2× cheaper per invocation; max relative error 9.3e-7.

Honest Disclosure

  • Vacuous headline ledger. Summed per-layer TV = 36.3; the "request-level risk budget" produces no non-trivial end-to-end number today.
  • Tiny quality samples. Greedy-decoding across two restarts disagrees on 2/8 prompts; quality story is "consistent with a protective effect", not evidence.
  • Cost-benefit withheld. Staged consumer runs at 0.884× throughput; no end-to-end serving win is claimed anywhere.
  • Open mediator. "Eviction alone does not force failure" (one 91-eviction run scores 1.000); microscopic mechanism left open.
  • Private injection code. Architecture-specific hooks/adapters/kernels are private; artifact-and-guard chain is the verifiable surface, not a rerun claim.
  • No institutional affiliation. "Metask Lab" with personal Gmail addresses — unusual for this engineering depth.

Open Questions

  • Inter-layer bridge. Can per-layer attention-TV bounds compose into an output-distance bound, or is the boundary fundamental?
  • Eviction mediator. Can a (slot, generation) premise be enforced cheaply enough to make eviction-safe consumption certifiable, not just observable?
  • Cost closure. At what eviction rate does the packed INT6 pool's 2,108 MiB/GPU saving become a real throughput win?
  • Generalisation. Does metric-as-type catch illegal compositions in MoE routing, draft verification, or RAG indices?
  • Full coverage. Can the fused meter extend from 1 to all 28 layers and stay inside the noise floor?
