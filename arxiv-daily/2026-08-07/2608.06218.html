◈ Key Finding

The Stiefel-manifold Muon LMO is solved in closed form by Y = −msign(skew(MXᵀ)) — an exact equivalence, not an iterative relaxation, at Muon-matching O(np²) cost.

§ Methodology — three logical stages

1

Reframe as a skew-symmetric problem

For any skew Y, the product YX lies in T_X St(n,p); imposing ‖Y‖₂ ≤ 1 enforces the tangent constraint. Proposition 1 gives the optimum as the negative matrix-sign of N = skew(MXᵀ).

2

Prove equivalence — not relaxation (Theorem 2)

The direct-sum splitting so(n) = L_X ⊕ K_X (Theorem 1, with K_X the stabilizer algebra) shows Skewon shares the SMP's optimum exactly. A Davis–Kahan–Weinberger dilation lifts any SMP optimum B* to a skew Y* with ‖Y*‖₂ = ‖B*‖₂.

3

Algorithm + convergence (Theorem 3)

Algorithm 2 reduces the inner solve to a 2p×2p problem via BCGS2 on [−X M], hitting O(np²). Telescoping the descent inequality yields min‖gradf‖_F ≤ √(8pΔL/T).

+ Strengths

  • Closes a cleanly stated open problem (Bernstein 2025) with a short, self-contained proof — the equivalence theorem is obviously the "right" formulation once seen.
  • Algorithm 2's 2p×2p reduction via BCGS2 keeps per-step cost at Muon's O(np²) — a genuinely useful implementation trick.
  • Honest about scope: the theorem explicitly requires exact SVD polar factors and flags Newton–Schulz as practical-but-unproven.
  • so(n) = L_X ⊕ K_X is independently useful geometric machinery for Stiefel-valued dynamics.

− Limitations

  • No downstream ML evaluation — isolated SMP solves on random data; no real orthogonality-constrained network or LoRA training.
  • Theory–practice gap: convergence covers SVD; the GPU-recommended Newton–Schulz variant is only informally analyzed (Gonon 2026 hints exactness can hurt).
  • Small scale, CPU only — Intel i5-10400F, n ≤ 125, p ≤ 30; no GPU timing at production dimensions (n in the thousands).
  • No stochastic / mini-batch analysis — full Euclidean gradient only.
