The Scheme

SG-TULA is an explicit Euler–Maruyama discretisation of the overdamped Langevin SDE that acts on a measurable subgradient selection h ∈ ∂u, stabilising superlinear growth by the taming map

h_λ(x) = ( h(x) − μx ) / ( 1 + λ1/2 | h(x) − μx | ) + μx

No Moreau–Yosida, no Gaussian smoothing. Unlike gradient clipping, taming has no threshold, rescales continuously with |h|, and satisfies h_λ → h as λ → 0 — so the scheme stays a genuine discretisation of the intended dynamics. Uniform-wise (SG-TULA_u) and coordinate-wise (SG-TULA_c) variants are analysed.

Theorem 1 — Convergence

Under semi-convexity (A1), strong convexity at infinity (A2) and polynomial subgradient growth |h(x)| ≤ m + K|x|p (A3, p ≥ 1):

W2( πβ , L(θn) ) ≤ 2 CE λ1/4 + eCD · e−nλ / T0

with CE = O((d/β)p/2), CD = O((d/β)1/2), and a dimension-independent restart horizon T0. No prior result attains O(λ1/4) in W2 under non-smoothness + superlinearity + non-convexity at once.

Theorem 2 — Excess Risk

For β ≥ max{4/µ, 1/J}:

E[ u(θn) ] − u(θ*) ≤ CT1 · W2 + CT2

CT1 = O((d/β)p/2), CT2 = O((d/β) log(dβ)). The temperature gap CT2 cleanly separates algorithmic error from finite-β bias. Complexity to reach W2 ≤ ε: λ = O(ε4), N = O(ε−4 log(1/ε)).

Verified on a Real LLM Potential

For nanochat (Karpathy, 2025; GPT-2 lineage) the regularised pretraining potential satisfies

∇²θ u(θ) ⪰ − c* ( 1 + |θ|12L+2 ) I

with c* explicit in depth L, width and vocabulary size. The exponent 12L+2 itself states that superlinear gradient growth in deep architectures is a consequence of depth — not an artefact of the analysis. A1–A3 follow for the very function being trained, not just an idealised surrogate.

Honest Limitations

  • O(ε−4) complexity inherited from a single strong-error estimate (Lemma 9).
  • Exponential-in-β dependence is inherent to optimisation-via-sampling; polynomial needs a PL condition unverified for nanochat.
  • No scaling law for the boosted tamed map; L=24 config was hand-tuned.
  • No code released; EMA-before-taming ordering and ε-schedule in prose only.
  • Muon's three production plug-ins disabled for the comparison.
