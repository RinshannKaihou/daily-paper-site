Mitigating Scoring Bias in LLM-as-a-Judge via Random Number Generation

A training-free logit debiaser: make the judge "roll a fair die" over the score range, measure how unfair the die is, and subtract that off at inference.

1Key Finding
An LLM's latent number bias — its deviation from uniform when asked to generate random scores — can be measured via RNG prompts and subtracted from score-token logits to debias LLM-as-a-Judge, no training required.

3Why This Matters
Directly tackles LLM-as-a-Judge scoring bias — a core pain for any auto-eval pipeline — with a training-free, plug-and-play logit correction usable as a standard debias component.

Method in one breath

Two stages. Preprocess: auto-generate 100 RNG prompts ("generate a random integer between min and max score"), keep the 10 lowest-perplexity ones, and read the LLM's probability over score tokens Y={0..N}. Deviation from uniform = latent number bias. Deb-T prepends the task instruction to capture task-conditional bias; Deb-R uses the bare RNG prompt.

debias term: B(y) = log U(y) − log P_random(y)
inference: P̃(y) = softmax( l(y) + λ · B(y) )
final score: s_llm = Σ P̃(y) · y // expectation, not argmax

λ is the only hyperparameter — a single scalar searched on dev over {0.1 … 1.0}. No gradients, no training. The whole thing bolts onto any HF generate-with-logits call.

Critical Edge · the sharpest critique

The correction is structurally identical to Contextual Calibration's affine logit shift — the only real delta is what context you use to elicit the bias (RNG prompt vs. CC's "N/A"). It is a calibration-elicitation variant, not a new debiasing paradigm. Worse, the "outperforms" headline rests on point estimates with no error bars, no significance tests, no standard deviations — several gaps (notably STR Spearman: Deb-T 61.7 vs CC 62.8) are within unacknowledged noise.

  • Brittle λ: dev-best λ often fails to transfer to test (Table 5: Llama STS jumps 14.2 → 41.9 when λ grid extends to 10) — flagged as open, unfixed.
  • No frontier judges: all models ≤14B; silent on GPT-4 / Claude / 70B+ — the models most people actually deploy as judges.
  • Known unmitigated failure: ships with a broken 4th task (HelpSteer2) where vanilla models collapse onto majority score 3, which has low RNG bias — so the debiaser amplifies the error instead of correcting it.
  • Not apples-to-apples: only zero-shot, temp-0.2 tested, yet compares against G-Eval whose whole premise is CoT-based probability weighting.
  • Reproducibility gap: RNG-prompt generation depends on closed ChatGPT-o3; the 100 seed prompts aren't fully released.
