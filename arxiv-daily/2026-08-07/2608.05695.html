DreamGuard: Efficient Runtime Guardrail for LLM Agents via Risk-Aware World Model

Wenhao Lin · Chenyu Yu · Xingwei Lin · Sicong Cao · Xiang Chen · Lei Xue · Le Yu · Letian Sha · Chunming Wu  — Zhejiang Univ. · NJUPT · Sun Yat-sen Univ.

Key Finding
A GRU-based risk-aware world model (RSSM) fuses immediate-hazard and decaying prefix-risk evidence into a calibrated PASS / HOLD / BLOCK guardrail for LLM agents — at ~25 ms per call.

Why This Matters
Detects unsafe LLM-agent tool calls before execution — catching long-horizon, multi-step risk accumulation that single-step reactive guardrails miss.
Critical Edge
Trained and calibrated only on SafetyDrift. Any deployment with a different action space (browser DOM, code execution) likely needs recalibration — a fragility the authors concede.

Methodology

DreamGuard is a pre-action hook in front of an LLM agent. At step t it reads (instruction, trajectory prefix, proposed action) and emits PASS / HOLD / BLOCK.

GRU transition→posterior z→successor prior ŝt+1→haz / pre heads→Noisy-Or→conformal threshold

RSSM core. GRU deterministic state + 32×32 categorical stochastic latents (DreamerV3-style free-bits KL). Fixed-dimensional trajectory summary — no per-call LLM re-reasoning as the prefix grows.

Two-stage training. (1) Pretrain world model on successor-embedding / dynamics / representation losses. (2) Freeze the GRU, unfreeze only the predictor path, add two BCE heads: immediate-hazard label and an exponentially-decayed prefix-risk label over horizon K=3 (ρ=1.5). Ablation: skip stage 1 → FPR inflates to 92.0%; skip stage 2 → SR collapses to 64.1%.

Runtime fusion. Immediate-hazard score + EMA-smoothed prefix score + sliding-window score are combined with a bounded Noisy-Or; BLOCK / HOLD thresholds are picked by split-conformal quantiles over trajectory-max scores on held-out safe trajectories — a per-trajectory false-alert guarantee, not per-step.

Critical Assessment

Novelty
Moderate–goodRSSM (DreamerV3 / TD-MPC2) and Noisy-Or fusion are not new individually; the contribution is the specific combination — recurrent latent state + dual risk-supervised readouts + trajectory-level conformal calibration — for LLM agent guardrailing. HOLD as a distinct channel is a genuinely useful, ablation-justified choice.
Rigor
StrongWilcoxon paired tests, multi-seed std, and a human double-review label audit with Cohen's κ exceed the norm for safety-eval papers. Each ablation produces a predictable failure mode.
Reproducibility
GoodSingle H100, fixed seeds, full hyperparameter table, prompt templates. But: no public code URL, and SafetyDrift (the only training source) is referenced only via arXiv link — exact training data may need manual reconstruction.
Significance
PracticalA 25 ms/call guardrail that transfers zero-shot across four heterogeneous benchmarks is deployable in real-time agent loops — multi-second LLM-reasoning guardrails are not. The online GPT-5.1 eval is the most deployment-relevant result.
Red flags
Single training benchmarkRecall gapSmall online evalNo safe action ASSE-Security SR (77.2%) is below PolicyGuard (85.1%) — DreamGuard wins F1 only via lower FPR. The online result rests on 100 cases (48 unsafe) with ±2-case error bars. α=0.6 online calibration is permissive. DreamGuard only blocks/holds; it never proposes a corrected action, so blocked tasks are left unfinished. Frozen-encoder choice (Qwen3-4B L31) is never ablated.

Strengths

  • Sub-30 ms latency — first proactive guardrail in the set realistically deployable in a real-time agent loop.
  • Dual-horizon design (immediate-hazard + decaying prefix-risk) is principled; ablations confirm each piece is load-bearing.
  • Trajectory-level split-conformal calibration gives a clean per-trajectory false-alert guarantee — the right unit of analysis.
  • Honest evaluation: Wilcoxon tests, multi-seed std, human label audit.
  • Cross-domain transfer (1 train → 3 zero-shot test benchmarks) is a meaningful robustness signal.

Limitations & Open Questions

  • Trained only on SafetyDrift; substantial distribution shift (different tool vocabulary) likely requires recalibration.
  • Intervention only — no safe-action revision; blocked tasks are left unfinished.
  • Supervised only on the prefix before the first hazard step; long post-hazard tails (multi-hazard, recovery) are unstudied.
  • Label noise persists on ASB / AgentDojo (exact-step agreement 84.9–88.1%; ASSE-Security κ = 0.84).
  • Q: How much target-domain calibration data recovers thresholds under browser-DOM / SQL / shell shift?
  • Q: Could HOLD pair with a lightweight action-revision policy to recover task utility?
