核心贡献 / Key Contributions

  • 2×2 audit design crossing access modality (ChatGPT chat UI vs OpenAI API) with web search (on/off) on the same GPT-5.3 Instant model.
  • Extends evaluation beyond accuracy to four response-level dimensions: repeated-run consistency, lexical (Jaccard) & semantic (cosine) similarity, citation grounding, and abstention.
  • Shows accuracy-only reporting hides deployment-relevant variance: search reverses the modality winner on SafetyBench; between-modality disagreement consistently exceeds within-modality noise.
  • Frames AI evaluation as a measurement-design & infrastructure problem, critiquing single-modality, single-run, accuracy-only certification.

Methodology

Controlled audit of chatgpt.com (logged-out) vs API gpt-5.3-chat-latest (temp 1.0), crossed with search on/off. Each prompt run 3× per cell within a single one-week window to limit drift.

Prompts from BBQ (198, 11 bias categories) and SafetyBench (203, 7 safety categories). Sample size justified by an a priori power analysis (Cohen's h=0.2, α=0.05, power 0.80 → 197 min), treated as a floor.

Inference: mixed-effects models (GLMM/LME) with (1|promptID) random intercepts; BH FDR correction on the primary family; benchmark refits and cosine model reported as exploratory.

Results & Highlights

  • Modality gap is small without search, search reverses it. BBQ no-search: API 81.9% vs chat 79.1% (−2.8 pp). SafetyBench with search flips to chat 84.4% vs API 80.6%.
  • Web search cuts accuracy on both modalities & benchmarks. OR=0.36, p<0.001; drop larger for API (interaction OR=1.92, p=0.009). BBQ chat-UI search-off→on ≈ −8 pp.
  • Identical prompts are inconsistent. BBQ chat-UI/search disagreement across 3 runs reached 21.2% — roughly 1 in 5 prompts got a different answer.
  • Between-modality > within-modality noise. Same-prompt cross-modal disagreement OR=1.51, p=0.002; Jaccard between modalities ~0.15 vs within-API 0.59–0.77.
  • Citations barely overlap. Only ~4% of URLs (7% of domains) shared; chat UI cited more on BBQ (46.8% vs 32.2%) but fewer on SafetyBench.
  • Abstention is unstable. SafetyBench: zero abstentions. BBQ: 6 events across 4 prompts, 3 of which abstained on only one of three runs.

Strengths

  • Clean 2×2 design isolating modality from search for the first time on safety benchmarks, with a priori power justification.
  • Measures under-studied response-level dimensions with appropriate mixed-effects stats and FDR control.
  • The ~4% URL-overlap and modality-dependent citation reversal are concrete findings any benchmark standard must reckon with.
  • Honest framing of the infrastructure gap as a validity gap, with a public dataset release.

Limitations

  • Single model family (OpenAI GPT-5.3), single one-week window — effects may not transfer to Claude/Gemini/open weights.
  • Only two multiple-choice benchmarks, both plausibly contaminated by training data.
  • API temperature fixed at 1.0 with no ablation — within-vs-between comparison partly depends on that choice.
  • Several headline effects (SafetyBench reversal, cosine) reported with raw, non-BH-corrected p-values.
  • Abstention claim rests on only 6 events across 4 prompts.

Authors & Credibility

Penn + Stony Brook team. Danaé Metaxa co-leads trustworthy-computing work and has prior auditing experience on identity-related speech suppression in generative AI (Proebsting et al. 2025) — directly relevant to the abstention phenomena measured here.

Written in a careful measurement-science register: a priori power analysis, BH FDR, prompt-level random intercepts, pre-registered-style primary vs exploratory split. Dataset & code publicly released.
