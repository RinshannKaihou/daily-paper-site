Once a Response, Always a Response: Detecting LLM-generated Text via Latent Prompt Restoration

Hongrui Bao, Yubing Ren, Yanan Cao, Jinhan You, Fang Fang, Shi Wang
Institute of Information Engineering / School of Cyber Security, CAS · Zhejiang Univ. · ICT, CAS
EchoPrompt LLM-text-detection zero-shot training-free instruction-tuning
EchoPrompt prepends one fixed assistant-style prefix to a passage, then compares how much an instruction-tuned model gains versus its base model on the raw text — the gap is larger for machine prose, because it silently "remembers" being written as a response.
Key finding
One fixed assistant-style prefix reactivates a latent response-dependency in LLM-written text — making it training-free-ly distinguishable via dual-model likelihood gain.
Same-model gain g(X;cg) is strictly larger for machine text across all tested proxy families.
Key metric
95.56% AUROC · 91.98% F1
avg across DetectRL / RealDet / RAID, Llama-3-8B proxy — +0.69 AUROC / +2.64 F1 over IRM; 0.254 s/sample.
Why this matters
A training-free signal that instruction-tuning leaves prefix-reactivatable latent response-dependencies — informing SFT/RLHF interpretability and LLM-safety tooling.
Relevance to detection + instruction-tuning mechanism research.

⚠ Critical edge — read this before citing

The headline +0.69% AUROC over IRM is thin, and the "SOTA zero-shot" claim is proxy-family-conditional: on Qwen2.5-1.5B average AUROC collapses to 76.78% (RAID 68.23%, below several baselines). Worse, the RealDet benchmark and the DNA-DetectLLM baseline share four undisclosed co-authors with this paper — the strongest "second-best" comparisons are not arm's-length.
PARAPHRASE: actually loses to IRM by 0.87 AUROC · NO precision-at-low-FPR reported · NO code/data release

Mechanism

Restore a coarse assistant-response condition with one global prefix cg, then score how much a passage benefits from it — calibrated against the base model on the raw text to strip generic fluency.

cg = "You are a helpful, versatile, and intelligent AI assistant. Below is the content you generated in response to a user's request, which acts as either a coherent continuation, a topic-specific article, or a detailed answer to a question:" Score(X;cg) = (1/(n−1)) · Σ [ log P_inst(x_t | cg, x_<t) − log P_base(x_t | x_<t) ] ↑ prefixed instruct ↑ raw base (calibration) Score > τ ⇒ machine

Not IRM with zero prefix — the asymmetric prefix restoration is the contribution. Same-model gain g(X;cg) (Eq. 9) isolates the prefix effect from the dual-model trick.

Strengths

  • Clean, well-motivated idea directly backed by the same-model gain experiment (Fig 2 / Table 8).
  • Base-model calibration removes fluency confound at the cost of one extra forward pass.
  • Broad study: 3 benchmarks · 5 attacks · 7 proxies · length bins · threshold stability · runtime · 3-component prefix ablation.
  • Best in 4/5 attack groups on Llama-3-8B; competitive in the hard short-text regime.

Caveats

  • Loses to IRM on paraphrase.
  • Qwen2.5 family: gains collapse to ~72–77% AUROC.
  • Global prefix tuned on DetectRL data → mild in-distribution bias.
  • Single English prefix; no multilingual / ensemble study.
  • No FPR@1% — the operationally meaningful metric.

Open questions

  1. Would a multi-prefix ensemble or generator-adaptive prefix close the Qwen2.5 gap?
  2. How does it behave on human-written assistant-style text — the direct confound, untested?
  3. What is precision-at-1%-FPR on RAID/RealDet — the metric that governs real deployment?
  4. Does the signal survive iterative paraphrase / back-translation stronger than DetectRL's?
  5. Can prefix-restore-and-calibrate do attribution, not just binary detection?
