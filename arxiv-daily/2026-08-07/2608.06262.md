> **一句话总结：** 本文在有限样本空间上的条件查询假设检验模型中,严格证明了 (1) 可学习性当且仅当两类分布在两两条件概率上有严格正分离;(2) 任何 T 轮自适应策略都可用 O(N²(T+log(1/ρ))) 个提前固定的成对查询在总变差 ρ 内模拟;(3) 最坏情况下固定误差的自适应差距恰好为 Θ_ε(N²)——即交互最多把所需测试数降低二次因子,而不会带来指数级节省。

> **TL;DR:** For a finite outcome space of size N, the paper proves an exact conditional-query learnability criterion (positive pairwise-conditional separation), gives a universal non-adaptive simulation bound of O(N²(T+log(1/ρ))) pair queries matching any T-round adaptive policy to within total-variation error ρ (replacing the naive exponential enumeration baseline for the conditional-sampling testing literature), and constructs a matching Ω_ε(N²) hard family — establishing that the worst-case fixed-error adaptivity gap is exactly Θ_ε(N²), so adaptive interaction saves at most a quadratic (never exponential) factor in test count.

## 核心贡献

- **精确的可学习性判据。** 定义两两条件映射 Θ(P) = (P(i|{i,j}))_{i<j} ∈ (0,1)^M (其中 M = C(N,2)),并定义两类 P₀, P₁ 的两两分离 Δ_pair = inf_{P∈P₀,Q∈P₁} ‖Θ(P)−Θ(Q)‖_∞。定理 3.1 证明以下三者等价:Δ_pair > 0、非自适应可学习、自适应可学习;且当 Δ_pair = 0 时,对任意有限预算 T,自适应与非自适应的最优最坏误差都恰为 1/2。
- **通用的非自适应模拟上界。** 定理 4.1:对任意 T 轮自适应策略 π 与任意 ρ∈(0,1),存在一个只用 L = 8M·(T + log(1/ρ)) 个**提前固定**的成对查询的非自适应过程,使得对一切全支撑分布 P,模拟抄本与真实自适应抄本的总变差 ≤ ρ;且该界不依赖假设类的基数或分离度。
- **匹配的二次下界。** 定理 5.1:构造一族分布 (N = 4m),其自适应复杂度 T*_ad ≤ 3⌈8log(3/ε)⌉(与 N 无关),但任何非自适应测试都需 c_ε·m² ≤ T*_na ≤ (m²+2)⌈8log(3/ε)⌉ 次查询;由此最坏固定误差自适应差距 G_N(ε) = Θ_ε(N²)。
- **核心方法上的新颖性。** 用 Propp–Wilson (1996) 的 coupling-from-the-past(以 Wilson 2000 的 read-once 形式)将"条件查询的成对样本"视为对状态集合的随机压缩映射,通过几乎必然的 coalescence 精确产生 PA 的样本——把统计测试问题转化为可分析的几何等待时间问题。

## Key Contributions

- **Exact learnability criterion via the pairwise conditional map.** Define Θ(P) = (P(i|{i,j}))_{i<j} ∈ (0,1)^M with M = C(N,2), and the pairwise separation Δ_pair(P₀,P₁) = inf_{P∈P₀,Q∈P₁} ‖Θ(P)−Θ(Q)‖_∞. Theorem 3.1 shows Δ_pair > 0 ⇔ non-adaptive learnability ⇔ adaptive learnability, and when Δ_pair = 0 the optimal worst-case risk under *either* protocol is exactly 1/2 for every finite budget T.
- **Universal non-adaptive simulation bound.** Theorem 4.1 constructs, for any T-round adaptive policy π and any ρ ∈ (0,1), a randomized non-adaptive procedure using at most L = 8M·(T + log(1/ρ)) pair queries (chosen before any response is observed) whose simulated transcript is within total-variation distance ρ of the adaptive transcript, uniformly over all full-support distributions — and the bound is independent of the cardinality and separation of the hypothesis classes.
- **Matching quadratic lower bound.** Theorem 5.1 builds a family on N = 4m outcomes whose adaptive complexity is T*_ad ≤ 3·⌈8 log(3/ε)⌉ (constant in N) but whose non-adaptive complexity satisfies c_ε·m² ≤ T*_na ≤ (m² + 2)·⌈8 log(3/ε)⌉, yielding the exact worst-case adaptivity gap G_N(ε) = Θ_ε(N²). This replaces the naive "query all 2^N−1 events" exponential upper bound with a tight quadratic one.
- **Methodological novelty — coupling-from-the-past for testing.** The upper bound's engine is a read-once coupling-from-the-past (Propp & Wilson 1996; Wilson 2000): each stored pair sample acts as a random map that merges two states of a queried event A, and once a composition of such maps coalesces the output is an exact draw from P_A. The coalescence time is shown to have E[τ_A] < 2M with E[exp(τ_A/8M)] ≤ e, cleanly explaining the N² scale.

## Methodology

The paper is purely theoretical and develops three proofs in sequence.

**Setup (Section 2).** A tester distinguishes two hypothesis classes P₀, P₁ ⊆ Δ⁺(X) (full-support distributions on X = [N]) under a hidden label b ∈ {0,1}. Each round the tester picks a nonempty event A ⊆ X and receives a fresh sample from P(·|A). Adaptive testers may choose Aₜ from history H_{t−1}; non-adaptive testers must draw the whole query vector A_{1:T} before seeing any response. The minimax risks R^ad_T and R^na_T are defined, and the fixed-error adaptivity gap is Gap_ε = T*_na(ε)/T*_ad(ε), with G_N(ε) its worst case over class pairs on N outcomes.

**Learnability (Section 3, Theorem 3.1).** Sufficiency: if Δ_pair := Δ > 0, query every pair the same number of times, take empirical pairwise frequencies Θ̂, and output the label b minimizing D̂_b = inf_{Q∈P_b} ‖Θ̂ − Θ(Q)‖_∞. If ‖Θ̂ − Θ(P)‖_∞ < Δ/4 then the correct label wins by a triangle-inequality margin (D̂_b < Δ/4 vs D̂_{1−b} ≥ 3Δ/4); Hoeffding + union bound over M pairs gives R^na_T → 0 with T ≤ M·(8/Δ²)·log(2M/ε). Necessity: a cut/transport argument (Lemma A.1) shows that for any event A, TV(P_A, Q_A) ≤ (|A|−1)·d_pair(P,Q) ≤ (N−1)·d_pair(P,Q); coupling two executions of the same tester round-by-round and union-bounding over T rounds gives TV(L_P(H_T), L_Q(H_T)) ≤ T(N−1)d_pair. Hence if Δ_pair = 0, for every η > 0 one can find P ∈ P₀, Q ∈ P₁ with transcript laws η-apart, forcing worst-case error ≥ (1−η)/2 → 1/2.

**Non-adaptive simulation (Section 4, Theorem 4.1).** The construction collects L i.i.d. uniform pair queries E_{1:L} with responses Y_s ~ P_{E_s} upfront, then reconstructs each adaptive round offline. For a queried event A, a stored sample (e,Y) defines a map Φ^A_{e,Y} that merges e's two endpoints to Y when e ⊆ A and is the identity otherwise; nested conditioning P_A(·|e) = P_e shows each map preserves P_A. Composing unused maps until coalescence yields an exact P_A draw (Wilson's read-once CFTP). The per-round coalescence time τ_A decomposes as a sum of independent geometrics with means M/k for k = |A|,…,2, giving E[τ_A] < 2M and the exponential-moment bound E[exp(τ_A/8M)] ≤ e. A stopping-time argument chains rounds and yields Pr(S_T > 8M·(T + log(1/ρ))) ≤ ρ.

**Matching lower bound (Section 5, Theorem 5.1).** The hard family lives on N = 4m atoms partitioned into I, J, U, V (each of size m). For each label b ∈ {0,1} and pair (j,k) ∈ [m]² a distribution P_{b,j,k} is built so that: querying I reveals j (P(a_j|I) = 3/4 under both labels), querying J reveals k (P(b_k|J) = 3/4 under both labels), and only the very-light target pair B_{jk} = {u_j, v_k} carries the label signal (P₀(u_j|B_{jk}) = 3/4 vs P₁(u_j|B_{jk}) = 1/4). Setting the dilution parameter η = m⁻⁴ makes every off-target query contribute only O(m⁻⁴) KL divergence, so a non-adaptive tester — whose query distribution cannot depend on the latent (j,k) — must spread T queries over m² candidate pairs; one target pair receives ≤ T/m² queries in expectation. Pinsker's inequality then forces T ≥ 2(1−2ε)² / (log(3)/2 · m⁻² + 32 log 9 · m⁻⁴) = Ω_ε(m²) = Ω_ε(N²). The adaptive tester sidesteps this by querying I and J first, then pinpointing B_{jk}.

## Results & Highlights

The paper reports no empirical ML experiments; all results are theorems with finite, explicit constants. The quantitative claims are:

- **Learnability dichotomy (Theorem 3.1).** When Δ_pair = 0, the optimal worst-case error under *both* adaptive and non-adaptive testing is **exactly 1/2 at every finite query budget T** (random-guess level — no information is extractable). When Δ := Δ_pair > 0, the non-adaptive complexity is bounded by **T*_na(ε;P₀,P₁) ≤ M·(8/Δ²)·log(2M/ε)** where M = C(N,2) = N(N−1)/2.
- **Universal simulation bound (Theorem 4.1, eq. 2).** Any T-round adaptive policy can be simulated non-adaptively with at most **L = 8M·(T + log(1/ρ))** pair queries (M = C(N,2)), achieving TV(L_P(Ĥ_T), L_P(H^π_T)) ≤ ρ for *every* full-support P — independent of the hypothesis classes. The per-round coalescence cost satisfies **E[τ_A] < 2M** and **E[exp(τ_A/8M)] ≤ e**; the last two-state-to-one transition alone has expected waiting time M = C(N,2), explaining the quadratic N² scale.
- **Adaptivity-gap upper bound (Corollary 4.2).** Repeating an ε-error adaptive tester a label-independent number of times and applying Theorem 4.1 with ρ = ε/2 gives **G_N(ε) = O_ε(N²)**.
- **Matching lower bound (Theorem 5.1, eq. 4).** On the hard family with N = 4m: **T*_ad(ε) ≤ 3·n_ε** with n_ε = ⌈8 log(3/ε)⌉ (constant in N — adaptive query complexity does not grow with the outcome-space size), while **c_ε·m² ≤ T*_na(ε) ≤ (m² + 2)·n_ε**. Combined, the worst-case gap is **G_N(ε) = Θ_ε(N²)** for every N ≥ 8.
- **Explicit Pinsker lower bound (eq. 6).** Any non-adaptive tester with worst-case error ≤ ε needs **T ≥ 2(1−2ε)² / (log(3)/2·m⁻² + 32 log 9 · m⁻⁴) ≥ c_ε·m²**, where the only label-bearing query has constant KL divergence KL((3/4,1/4)‖(1/4,3/4)) = ½ log 3, and every off-target query has KL ≤ 32 log 9 · m⁻⁴.

The headline takeaway, contrasted with the naive "enumerate all 2^N−1 events" baseline (exponential in N): interaction provably reduces the worst-case required test count by at most a quadratic factor, never an exponential one — the apparent exponential branching of adaptive evaluation does not translate into exponential query savings.

## Authors & Credibility

The paper is a single-author preprint by **Zonghuan Xu (Fudan University)**, posted 2026-08-06 in cs.LG and math.ST. The mathematical content is developed carefully: every theorem has a full proof, the learnability necessity and the simulation bound are presented with explicit constants, and the lower-bound construction is verified in three appendices (pairwise stability, geometric/exponential-moment calculations for τ_A, and the off-target KL normalization with explicit c_ε and padding to all N ≥ 8). The work cites the canonical conditional-distribution-testing literature (Chakraborty et al. 2013; Canonne, Ron & Servedio 2014/2015; Acharya, Canonne & Kamath 2018; Kamath & Tzamos 2019 "Anaconda"; Chakraborty et al. 2024 on bounded adaptivity) and the active-hypothesis-testing line (Chernoff 1959; Naghshvar & Javidi 2013a comparing adaptive vs non-adaptive actions for a *fixed* hypothesis-action model). The motivation from LLM-evaluation adaptivity (Dynabench, CheckList, MT-Bench, LiveBench, tinyBenchmarks, AutoJudger, Wu et al. 2026) is accurate and current. An explicit AI-use statement discloses that generative AI assisted with formulation, proof-checking, literature search, and drafting, with manual review claimed for all arguments.

## Critical Assessment

- **Novelty — genuine.** The exact learnability characterization (positive pairwise-conditional separation, with the random-guess value 1/2 at zero separation) and the *exact* Θ_ε(N²) adaptivity gap are new. Prior work (Kamath & Tzamos 2019; Chakraborty et al. 2024) gave problem-specific upper/lower bounds for identity/equivalence/uniformity testing; this paper instead characterizes arbitrary class pairs and pins the worst-case cost of removing adaptivity exactly. The use of read-once coupling-from-the-past as a non-adaptive simulator is an elegant bridge between exact-sampling MCMC and property testing.
- **Rigor — high.** All three main statements are proved with finite constants; the lower-bound constants c_ε and the padding to all N ≥ 8 are spelled out in Appendix C. The coalescence-time decomposition τ_A = Σ_{k=2}^{|A|} G_k with G_k ~ Geom(C(k,2)/M) is a clean way to get both E[τ_A] < 2M and the exponential moment.
- **Reproducibility — self-contained but unverifiable empirically.** This is pure theory; there is no code, no data, and no experiments to reproduce. The model, assumptions, and proofs are fully stated, so a reader can in principle re-derive everything. There is no GitHub link or numerical validation of the bounds (e.g., a simulation of Algorithm 1's coalescence-time distribution), which would have been cheap to add and would have built confidence in the constants.
- **Significance — model-relative.** The framing ties the result to LLM evaluation (static vs interactive benchmarks), but the theorems apply to an idealized conditional-query oracle, not to any real evaluation pipeline. The **full-support assumption** (P(x) > 0 for all x) rules out distributions with zero-probability behavior categories, which are common in real evaluations (a model that never emits a particular tool call). The model also **counts conditional samples but ignores the cost of specifying or realizing a conditioning event** — in an LLM benchmark, conditioning on "the model uses tool X" is itself a non-trivial filtering cost that can dominate.
- **Red flags / overclaiming — modest.** The authors are careful to state (Section 6) that the lower bound is worst-case and "does not imply that typical evaluation tasks attain a quadratic gain." However, the jump from this honest caveat to the motivating claim that "a static conditional benchmark can match any T-query adaptive evaluation using O(N²(T+log(1/ρ))) pair queries" is where a skeptical reader should pause: N² can be astronomically larger than T for any realistic behavior-category count, so the asymptotic polynomial-vs-exponential distinction may not buy practically useful static benchmarks. The matching lower-bound family is also somewhat contrived (label signal concentrated in a single O(m⁻⁴)-mass pair out of m² candidates) — a legitimate worst-case construction, but one that does not resemble typical evaluation tasks.

## Strengths

- Settles both the learnability question and the adaptivity-gap question with **matching upper and lower bounds** (Θ_ε(N²)), leaving no asymptotic slack.
- The learnability criterion (Δ_pair > 0) is **clean, checkable, and distribution-free**: it reduces to comparing M = C(N,2) scalar pairwise conditionals, regardless of how rich P₀ and P₁ are.
- The non-adaptive simulation is **distribution-agnostic** (uniform over all full-support P) and **class-agnostic** (independent of cardinality/separation), making it a universal compiler from adaptive to non-adaptive testers.
- The coupling-from-the-past construction is conceptually satisfying: it produces *exact* P_A samples (not approximate) from pre-collected pair data, with total-variation error arising only from truncating an infinite stream at L.
- Honest scope statement (Section 6) explicitly lists the model's limitations rather than overselling the LLM-evaluation connection.

## Limitations

- **No empirical validation.** Purely theoretical; no simulation of Algorithm 1, no numerical study of how tight the constant 8 is, no comparison against a practical adaptive baseline on a real distribution-testing task.
- **Strong oracle assumptions.** Full support (P(x) > 0 ∀x) and exact conditional sampling from *every* nonempty event are required; neither holds exactly in real LLM evaluations, where conditioning events are constructed by prompting/filtering and many behavior categories have zero probability for a given model.
- **Query-count model ignores event-specification cost.** In practice, the dominant cost of an interactive benchmark is often *constructing* the conditioning event (curating prompts, running the model, applying a judge), not the conditional sample itself. The paper's query-complexity accounting abstracts this away.
- **Worst-case-only lower bound.** The Ω_ε(N²) construction is adversarial (label hidden in one O(m⁻⁴)-mass pair among m²). For structured classes (identity, equivalence, uniformity) the prior literature shows the adaptivity gap is much smaller; the paper does not characterize when the gap is small beyond noting the worst case.
- **Single-author preprint with heavy AI assistance.** The AI-use statement is commendably honest, but the absence of co-authors or an affiliation beyond "Fudan University" (no department/lab/advisor named) makes provenance thinner than a typical theory paper; the proofs should be independently checked before citing the constants as settled.
- **N² may be impractical.** For N in the hundreds (a modest behavior-category count), N² ≈ 10⁴–10⁵ queries to simulate a handful of adaptive rounds — asymptotically polynomial but potentially useless in practice, undercutting the "static benchmarks can match interactive ones" motivation.

## Questions for Further Exploration

- How robust is the Δ_pair > 0 learnability criterion when the full-support assumption is relaxed to allow zero-probability outcomes, or when conditional samples are only *approximate* (e.g., rejection-sampled with a known tolerance)? Does a relaxed criterion survive, or does the exact 1/2 dichotomy collapse?
- Can the constant 8 in L = 8M·(T + log(1/ρ)) be improved, and what does a simulation of Algorithm 1's empirical coalescence-time distribution look like for moderate N (say N = 20–100)? The geometric-waiting-time analysis suggests room for tighter constants.
- For *structured* hypothesis classes common in practice (identity to a known distribution, equivalence between two unknown distributions, uniformity, support size), is the adaptivity gap actually o(N²) — i.e., does the worst-case Θ_ε(N²) only arise for adversarial families like the one in Section 5? A characterization of "when is the gap small" would make the result more actionable for benchmark design.
- The lower-bound family concentrates the label signal in a pair of mass O(m⁻⁴). What is the adaptivity gap as a function of the *minimum atom mass* α (i.e., a "balanced" version of the hard family)? This would clarify whether the quadratic blow-up is an artifact of extreme mass imbalance.
- The non-adaptive simulator is a compiler from adaptive to non-adaptive testers via coupling-from-the-past. Can the same CFTP primitive be used to simulate *bounded-adaptivity* testers (e.g., k-round adaptive, in the spirit of Chakraborty et al. 2024) at an intermediate cost between O(T) and O(N²·T)?
- The motivating LLM-evaluation framing assumes behavior categories are a fixed finite set X = [N]. How does the picture change when X is open-ended (free-form generations, tool-call sequences) and must itself be discretized by a judge — does the judge's discretization error dominate the Δ_pair separation the theory relies on?
