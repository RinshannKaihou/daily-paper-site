> **一句话总结：** 本文提出一种针对 LLM Agent 动作选择的目标级"授权审计"方法，通过对每个工具/参数目标分别标注"有效/无效/中性"证据因子，并采用匹配式来源干预 + 受控证据退化 + Harsanyi/Shapley 联盟交互三类诊断，发现开源模型虽能响应来源权威线索（竞争中 5.4% vs 支持中 1.7% 的不一致），但在 2.4% [2.1, 3.0] 的对照中仍保留了对未授权竞争证据的行为敏感性，且简单的权威策略护栏仅能将未授权竞争错误从 14.9% 降至 9.5%。

> **TL;DR:** The paper introduces a target-specific *authorization audit* for LLM agent action selection: each context factor is labeled Valid/Invalid/Neutral per tool or argument target, then three diagnostics (matched source-authority intervention, controlled valid-evidence degradation, and exact Harsanyi/Shapley coalition interactions) are run on a 450-task suite (AgentAudit-250, Tau2Audit-100, BFCLAudit-100) across open-weight models. Models respond to textual source cues — changing only source authority flips the action in 5.4% of competing vs 1.7% of supporting cases (+3.8 pp [3.2, 4.4]) — but still retain unauthorized influence: the "full-correct/mixed-error/clean-correct" pattern appears in 2.4% [2.1, 3.0] of degradation comparisons, and an explicit authority-policy guardrail cuts untrusted-competition error only from 14.9% to 9.5% (a +5.4 pp benefit [4.5, 6.3]).

## 核心贡献

- **目标级授权审计框架**：不同于只看结果正确性的 Agent 评测或只看是否被注入的 prompt-injection 基准，本文将"证据是否被授权决定某个目标"作为审计对象，对同一上下文因子在工具选择和各参数槽位上分别打标签（Valid / Invalid / Neutral / Excluded），承认"权威是目标相关的"——同一条记录可能授权工具调用却不授权某个参数。
- **三类互补诊断**：① 匹配式来源干预（仅改变命题来源标记 T/U，控制任务、命题、位置、策略不变）；② 受控有效证据退化（full / mixed 删一个 Valid / clean 删该 Valid 并删全部 Invalid），用 strict retained-invalid 错误模式 (cF=1, cM=0, cC=1) 隔离"保留未授权竞争"的残留行为；③ 在 8 因子的 28 个子集上精确枚举 Harsanyi/Shapley 联盟交互，作为部分证据下的次级定位诊断。
- **450 任务诊断套件 + 公开标注**：构建 AgentAudit-250（自撰工作流任务）、Tau2Audit-100（τ2 零售/航司状态转写）、BFCLAudit-100（BFCL 函数调用改写），共 1,350 个目标、10,800 个目标-因子标签；并由 3 名博士级外部标注者独立重标 300 个目标包，invalid vs non-invalid 一致率 85.4%（κ=.626），裁决后共识与作者标签吻合 78.9%。
- **区分"响应权威"与"行为隔离"**：明确区分"模型是否对来源线索有反应"（full-prompt 干预测）与"有效证据削弱后未授权竞争是否仍影响行为"（退化测试），并用 Shapley 分数超额作为次级局部诊断，避免把联盟份额误当成部署错误率或唯一内部推理路径。
- **可复现与护栏效用评估**：附带数据/标签/Prompt/代码/种子/重标记录；并评测了一种简单的显式权威策略护栏，量化其异质收益（Mistral +18.1 pp，DeepSeek 反向 -0.9 pp），强调"它提升总体正确性，但不是不变量级的来源过滤器"。

## Key Contributions

- A **target-specific authorization audit** that labels every context factor separately for the tool target and for each argument slot (Valid = authorized and supports target; Invalid = unauthorized and supplies a concrete competitor for the same decision variable; Neutral otherwise). This captures that authorization is target-specific: a stale record may be harmless for tool choice yet decisive for the recipient argument.
- A **three-instrument diagnostic stack**: (1) matched source-only interventions isolating provenance response in the full prompt, (2) controlled valid-evidence degradation (full / mixed / clean contexts) with the strict retained-invalid error pattern (cF=1, cM=0, cC=1) to test behavioral isolation when authorized evidence weakens, and (3) exact Harsanyi/Shapley coalition interactions over all 28 subsets of the 8-factor context as a secondary partial-evidence localization tool.
- A **450-task diagnostic suite** (AgentAudit-250 authored tasks, Tau2Audit-100 from τ2-style retail/airline states, BFCLAudit-100 from Berkeley function-calling examples) yielding 1,350 audited targets and 10,800 target-factor labels, with an external-relabeling reliability study (3 PhD annotators, 85.4% invalid/non-invalid agreement, κ=.626, 78.9% consensus–author match).
- A **clean separation of estimands**: leave-one-out = direct deletion sensitivity; matched intervention = full-prompt provenance response; coalition-averaged Shapley = partial-evidence interaction summary bounded by empty-coalition (sparse) and full-context (near-null) anchors. The paper is explicit that none of these is a deployment error rate.
- A **guardrail utility study** showing a simple explicit authority policy reduces untrusted-competition errors from 14.9% to 9.5% pooled (benefit +5.4 pp [4.5, 6.3]) but with highly heterogeneous per-model effects (Mistral +18.1 pp; DeepSeek -0.9 pp reversal), demonstrating it improves pooled correctness without acting as an invariant provenance filter.

## Methodology

**Audit object.** For a fixed next-action decision, the action interface (system instruction, tool schemas, output format) is held constant. The candidate task-specific context is decomposed into semantic *factors* (current goal, trusted observations, memory, retrieved records, previous actions, metadata, untrusted notes). For each target *y* (a tool name like `send_email`, or an argument assignment like `recipient=alice@…`), every factor gets one of four labels: **Valid** (authorized and supports y), **Invalid** (unauthorized and supplies a concrete competitor for the same decision variable), **Neutral**, or **Excluded**. Labels are assigned independently per target–factor pair.

**Matched source intervention.** The primary factorial crosses source authority *a ∈ {T,U}* with semantic relation *r ∈ {S,C}* (support/compete). A proposition is added to the same valid-and-neutral base; within a relation only the frame "Source status: [frame]" changes. The within-relation authority gaps δS, δC and the secondary difference-in-differences ΔΔ = δC − δS are computed from summed target-token log-odds scores *v_y(P)*. A stricter same-proposition control changes only the source marker of an existing competitor and measures its trusted-minus-untrusted removal effect.

**Controlled valid-evidence degradation.** For each target with a Valid factor *x*: *full* = all factors; *mixed* = remove only *x*; *clean* = remove *x* plus all Invalid factors for that target. The strict retained-invalid error pattern is cF=1, cM=0, cC=1 — correct before degradation and after the invalid set is removed, but wrong when that set remains. Mixed–clean target discordance is the primary endpoint; the strict pattern is the stricter retained-invalid rate.

**Partial-evidence interaction diagnostic.** Every subset *Z ⊆ X* is scored *v_y(Z)*. Exact Harsanyi interactions *I_y(B) = Σ_{Z⊆B} (−1)^{|B|−|Z|} v_y(Z)* are computed exactly for all 28 subsets (8 factors), ranked by absolute strength, top-K=50 (order ≤ 3) retained. Three estimands: empty-coalition Harsanyi (sparse evidence), Shapley fractional excess *s_frac* (allocates strength by fraction of invalid factors in each set, primary summary), and a full-context transform (near-complete prompt). A label-count-matched null permutes labels over 500 permutations to define observed-minus-null excess.

**Datasets & models.** 450 instances → 1,350 targets → 10,800 target-factor labels. Primary score/degradation/coalition runs use Qwen3-4B, Qwen3-30B, Mistral-Small-3.2-24B, Llama-3.3-70B; generated-action and guardrail experiments add DeepSeek-V2-Lite; same-proposition control uses Qwen3-4B, Ministral-8B, Mistral-Small-3.2-24B, DeepSeek-V2-Lite. 95% CIs cluster-bootstrap source tasks.

## Results & Highlights

- **Matched generated-action source sensitivity**: across five models, switching only the source authority of a competing proposition changes the parsed target in **5.4%** of competing cases vs **1.7%** of supporting cases — a **+3.8 pp** contrast **[3.2, 4.4]** (Table 5). Llama-3.3-70B (+7.3) and DeepSeek-V2 (+8.7) drive the largest contrasts; Qwen-4B only +0.2. Direction is net *corrective* under competition (trusted→untrusted moves 1.2% correct→wrong but 4.0% wrong→correct), but the residual 1.2% harmful transitions confirm discounting is incomplete.
- **Matched full-prompt score response**: adding a competing proposition drops the target summed-log-odds by **2.079** when trusted and **1.098** when untrusted; supporting propositions add +0.448 (trusted) vs −0.052 (untrusted). The authority-by-relation difference-in-differences is **+0.481 [0.413, 0.550]**, positive for every model (Figure 2). Same-proposition source-only control gives a trusted-minus-untrusted competition gap of **+1.15 log-odds [0.97, 1.33]** pooled (Table 4).
- **Retained-invalid error pattern** (the strict cF=1, cM=0, cC=1 endpoint) appears in **2.4% [2.1, 3.0]** of valid-evidence degradation comparisons across 12,120 target-valid rows, ranging 0.5%–4.1% per model. Signed score-harm predicts this endpoint with AUROC **.759 [.727, .790]** and a top-vs-bottom decile gap of **+11.7 pp [9.8, 13.9]**.
- **Mixed–clean action discordance** is **24.6%** of rows; the dropout-aligned Shapley share predicts which rows change at AUROC **.813 [.798, .827]** and separates 71.7% (top decile) from 3.8% (bottom decile) — a **+67.9 pp [63.8, 72.0]** gap. Adding the aligned Shapley feature to an absolute-score-effect base raises AUROC to **.868** (incremental +.019 [+.012, +.027]).
- **Coalition diagnostic under partial evidence**: Shapley fractional excess is **+.027** in all twelve model–dataset runs; the sparse empty-coalition endpoint matches (+.058 any / +.027 fractional), while the full-context transform is near its null (**−.004**), bounding the coalition claim to partial-evidence backgrounds (Table 6, Table 13).
- **External label robustness**: 3 annotators achieve 85.4% invalid/non-invalid agreement (κ=.626) on 2,400 pairs; adjudicated consensus matches author labels on 78.9%. Crucially, replacing author labels with consensus labels (21.1% changed) preserves the empty/Shapley/full-anchor excess pattern (+.046 / +.049 / +.002), so the anchor contrast is not an artifact of self-agreement.
- **Guardrail utility**: an explicit authority-policy instruction cuts untrusted-competition error from **14.9%** to **9.5%** pooled (**benefit +5.4 pp [4.5, 6.3]**), and trusted-competition error from 15.9% to 12.2% — but benefits are highly heterogeneous (Mistral +18.1 pp, Llama +6.3, Qwen 1.6–2.1, DeepSeek −0.9) and competition source-sensitivity stays at 5.1% vs 5.4%, so it is not an invariant provenance filter (Table 9).

## Authors & Credibility

- **Junchi Liao** (single author). The paper is an arXiv preprint (v1, 23 Jul 2026) in cs.AI; no institutional affiliation or peer-review status is given in the PDF, so credibility rests on the methodology and disclosed artifacts rather than venue endorsement.
- Credibility signals are strong: exact enumeration of all 28 subsets rather than sampling; cluster-bootstrapped 95% CIs throughout; a genuine external relabeling study (3 PhD annotators blind to model scores, original labels, and each other); release artifacts promised (data, labels, prompts, code, seeds, relabeling records); and consistent pairing of primary, secondary, and descriptive statistics so each claim is calibrated to the right estimand.
- The author is unusually disciplined about scope: every quantity is labeled a "controlled stress-set rate, not deployment prevalence," and the conclusion explicitly states the audit is an *evaluation method, not a guardrail*.

## Critical Assessment

- **Novelty (high).** The framing is genuinely new: rather than asking whether an agent follows a malicious injection (prompt-injection literature) or completes a task (tool-use benchmarks), it asks whether model *support for a fixed reference target* depends on context that is merely *relevant* but not *authorized* for that specific tool or slot. The target-specific labeling (a record can authorize `send_email` yet be invalid for the `cc` slot) and the explicit separation of "response to authority" vs "behavioral isolation" vs "partial-evidence localization" are not standard in agent evaluation.
- **Rigor (high, with caveats).** The matched factorial is well-identified; the same-proposition control (Table 4) is a clean addition-based check; the cluster bootstrap, the label-permutation null, and the role-matched competition control (which reverses the comparison to −.018, honestly reported) show awareness of confounds. However, the **coalition claim is weak under its own test**: strict same-role competing controls *reverse* the fractional-excess comparison, so the interaction diagnostic characterizes "combinations containing unauthorized competitors" rather than isolating *authorization* per se — the paper admits this but the abstract still leads with the Shapley result.
- **Reproducibility (strong).** All factors are human-authored semantic units, exact enumeration is tractable (8 factors), all prompts/seeds/labels are promised for release, and the same-proposition, directional, and prompt-wording robustness tables (Tables 10–13) are reported. The main reproducibility gap is the **reliance on open-weight models with target-token probabilities** — closed APIs (GPT-4o, Claude) get only a weaker black-box forced-choice proxy (Appendix Table 55), so the headline scores cannot be reproduced on the most-deployed frontier models.
- **Significance (moderate).** The audit is a useful *diagnostic lens*, but the headline behavioral numbers are small (5.4% competing discordance; 2.4% strict retained-invalid pattern) and explicitly *stress-set, not deployment prevalence*. Because the datasets are deliberately constructed to mix authorized and unauthorized evidence, the rates tell us sensitivity exists, not how often it bites in real agent runs — a scoping decision the paper makes transparently but that limits immediate practical impact.
- **Red flags / overclaiming.** No outright fabrication, but two framing risks: (i) the abstract and intro foreground the Shapley interaction result even though the paper itself shows it does not isolate authorization from semantic competition, and (ii) the 78.9% author–consensus label match is honestly reported but means **~1 in 5 target-factor labels would change under independent adjudication**, which materially weakens any case-level interpretation (the paper correctly restricts consensus labels to coalition metrics only). Single-author status with no disclosed affiliation is also worth noting for a benchmark-and-method paper of this scope.

## Strengths

- Conceptually clean distinction between *relevance*, *truthfulness*, and *authorization* — the paper never conflates "unauthorized" with "false" or "adversarial."
- Three estimands with explicitly bounded scopes, each reported with its own primary/secondary/descriptive statistic and CI — unusually careful epistemic hygiene.
- Honest negative/limiting results are reported, not buried: the near-null full-context transform, the role-matched competition reversal (−.018), and DeepSeek's guardrail reversal (−0.9 pp) are all in the main text.
- A real external annotation reliability study with κ reported alongside raw agreement, and a consensus-label sensitivity check that preserves the aggregate pattern.
- Practical, actionable finding for practitioners: an explicit authority-policy guardrail helps pooled correctness heterogeneously but does *not* eliminate provenance sensitivity — a useful caution against treating prompt-level policies as a defense.

## Limitations

- **Stress-set, not prevalence.** Datasets deliberately mix authorized and unauthorized context, so 2.4% / 5.4% are sensitivity rates, not field error rates; the paper states this but readers may still over-read them.
- **Human-authored factor decomposition.** Results depend on a specific refactorization of context into factors; external relabeling, coarsening, and placeholder masks support aggregate robustness but do not establish invariance to arbitrary refactorization or stable *case-level* explanations (~21% of labels would change under adjudication).
- **Exact enumeration only for short factor sets.** All 28 subsets are scored only at 8 factors; pairwise screening at 12/16 factors retains 92.0%/87.8% of invalid factors but is an approximation, and scaling to long trajectories with evolving memory, repeated tool calls, and noisy retrieval is unproven.
- **Open-weight only.** Target-token log-odds scoring requires open-weight models; closed APIs permit only weaker generation or forced-choice proxies, so the headline numbers are not directly available for the most-deployed frontier models.
- **Textual marker, not operational provenance.** The source cue is a textual "Source status:" frame, a controlled proxy — the same-proposition control does not test whether models track provenance through actual retrieval, memory, or tool-transport channels.
- **Coalition claim is bounded.** The near-null full-context transform and the role-matched competition reversal mean the Shapley diagnostic localizes partial-evidence interactions involving unauthorized competitors, not authorization-specific dependence; the matched intervention provides that identification.

## Relevance

对于关注 LLM Agent 安全性、可信工具调用与上下文归因的研究者，本文提供了一套可操作的"授权审计"评测协议与 450 任务诊断套件，直接补充了既有 prompt-injection 与 tool-use 基准未覆盖的"未授权但相关证据是否仍驱动决策"这一维度，可作为 Agent 安全评测、护栏设计与来源追踪（provenance tracking）研究的基础方法学和对照基线。

## Questions for Further Exploration

- How do the 5.4% competing-discordance and 2.4% retained-invalid rates change when source authority is conveyed through an *operational* channel (retrieval provenance tags, tool-transport metadata, signed memory) rather than a textual "Source status:" marker?
- Would closed-weight frontier models (GPT-4o, Claude) show higher or lower provenance sensitivity under the forced-choice proxy, and does the open/closed gap change the guardrail recommendation?
- Can the audit be extended to multi-turn trajectories where memory, repeated tool calls, and retrieval evolve, given that exact subset enumeration is intractable beyond ~8 factors?
- The strict retained-invalid pattern is an *intervention pattern*, not causal mediation — can a formal mediation or counterfactual analysis identify which specific retained invalid factor causes each error, rather than only the invalid set?
- Does training-time instruction-hierarchy alignment (Wallace et al. 2024; Debenedetti et al. 2025) reduce the matched authority gap (+0.481) and the retained-invalid rate (2.4%), or only the gross error rate?
- How does the audit interact with verifier/LLM-as-judge bias — would an authorization-aware judge repair the residual 1.2% harmful trusted→untrusted transitions the action model fails to suppress?
