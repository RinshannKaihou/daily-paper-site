Why This Matters

Gives regulated-finance buyers a reusable 7-dimension rubric, a deployment gate, and a cross-family bias-control protocol — pick frontier models on cost/latency, not headline reliability.

Critical Edge

Every score is LLM-judge-derived with zero human validation, and 6,000-token truncation skips buried-covenant failures. The "0.22 indistinguishable" claim is asserted — never significance-tested.

01

Methodology

CM-LRS scores LLM output at the workflow-output layer — not the QA-pair layer — across seven dimensions, each anchored 0–5.

Each (workflow × model) cell is generated once at temperature 0, then scored by an LLM-as-judge panel of four judges spanning three model families. Every document is normalised to a fixed 6,000-token budget so all models receive identical inputs regardless of native context-window size — the single biggest external-validity threat the paper itself flags.

Aggregate: equal-weighted mean across the seven dimensions per cell. Default workflow-class weights and five calibration methods (AHP, BWM, PCA, entropy, revealed-preference regression) are offered but none are used in the headline numbers. Guiding principle: predict with the LLM, calculate with code, decide with the human.

The seven dimensions (D1–D7)

  • D1 Factual accuracy
  • D2 Evidence traceability
  • D3 Numerical consistency
  • D4 Workflow completeness
  • D5 Source discipline
  • D6 Decision usefulness ← cleanest separator
  • D7 Reviewability / auditability
  • Weighted aggregate CM-LRS = Σ wᵢ·sᵢ ∈ [0,5]

03

Strengths & Limitations

Honest bias reporting and exemplary reproducibility — set against a structural reliance on LLM judges and thin per-cell sample sizes.

Strengths

  • Targets a real, repeatedly-observed failure mode — surface-fluent output that fails reviewer gates on traceability and reconciliation — that QA-pair benchmarks structurally cannot surface.
  • Rubric is intuitive; the 0–5 anchors are concrete and scorable without specialist training; per-class default weights make it immediately deployable.
  • Four-judge, three-family protocol with explicit reporting of the weakest pair (ρ = 0.03) is a model of honest bias reporting.
  • Fully public artefacts — SEC EDGAR URLs, synthetic Nordic supplements, prompts, raw outputs, scores, a deterministic verification script — under CC BY 4.0.
  • Deployment gate CM-LRS ≥ 4.0, no dimension < 3, any 0/1 disqualifies guards against aggregate-score masking.

Limitations

  • No human-rater validation — every score is LLM-judge-derived; inter-rater reliability against practising bankers is the priority extension and is not done.
  • 6,000-token truncation biases toward front-matter and never exercises buried-covenant failures — arguably the highest-stakes real-world class.
  • Tiny per-cell n: W2 = 5 queries, W3 = 5 issuers, W4 = 1 target deal. No CIs, no significance tests — yet "statistically indistinguishable" is asserted.
  • Single-turn, non-agentic: no tool-use, no retrieval calls, no code execution — even as real deployments increasingly go agentic.
  • Narrow panel: no Gemini in-panel, no Mistral/Qwen/DeepSeek; only one open-weights model. Sole author, no institutional affiliation, no peer review.
04

Open Questions

What the framework invites — but does not yet answer.

  1. How do CM-LRS scores change when documents are not truncated to 6,000 tokens — i.e. when the buried-covenant-90-pages-deep failure mode is actually exercised?
  2. What is the inter-rater reliability between the four LLM judges and a panel of practising bankers / compliance reviewers on the same 104 outputs? Does D6 stay the cleanest separator?
  3. Does the "frontier cluster within 0.22 points" finding survive a proper significance test, given judge-strictness variation (0.3–1.1 pts) alone exceeds the band?
  4. Under agentic / tool-use deployments, does D3 numerical consistency collapse toward 5 when arithmetic is offloaded to code — as the "predict with LLM, calculate with code" principle predicts?
  5. Can D6 be operationalised into a binary reviewer accept/reject classifier via revealed-preference regression — turning CM-LRS from a score into a calibrated probability of admissibility?
