Robust Asynchronous Q-Learning under Reward
and State Corruption via Batching

Key finding

The first Q-learning provably robust to simultaneous reward & state corruption; per-epoch batching + trimmed means close the upper/lower-bound gap with a minimax-optimal bias.

Reward-only-corruption bias term exactly matches the information-theoretic lower bound — closing [6]'s prior gap that carried a spurious 1/λmin factor.

Statistical rate sharpens vanilla Q-learning [9]: 1/λmin → 1/√λmin.

Why this matters

First provable Q-learning robustness under joint state+reward Huber corruption — and the batching trick tightens the reward-only rate to minimax-optimality.

Critical edge

Experiments compare only against vanilla Q-learning — a trivially weak baseline under corruption. The authors' own per-step robust algorithm from [6] is the obvious missing comparator.

Empirical gaps
  • Heavy-tail guarantee (TRIMH) never tested — all sims use bounded-variance noise.
  • Tabular only; single-trajectory Markovian case merely asserted via blocking.
  • O(H) per-epoch memory; ε̄ ≤ 1/8 cap untested near the boundary.

Section 01

01Methodology — epoch · trim · clip · sync

STEP 01

Setting & corruption model

Tabular discounted MDP, single asynchronous trajectory from behavior policy µ. Two Bernoulli processes (εR, εY) replace reward / next-state with arbitrary adversary values; adversary picks what, not when. ε̄ ≤ 1/8.

STEP 02

Epoching

Split horizon T into K = ⌈2 log T/(1−γ)⌉ epochs of length H ≥ (20/λmin)·log(8T|S||A|/δ). Bernstein guarantees every (s,a) is visited ≥ ½λminH times/epoch.

STEP 03

Robust per-epoch estimation

Per (s,a): TRIMH for rewards R̂ (unbounded, heavy-tailed); TRIMB with threshold B = 3Cσ̃/(1−γ) for bootstrapped look-ahead μ̂ — exploiting known support for O(εY) vs O(√εY) sharpness.

STEP 04

Clipping-stabilized operator

T̂kQ = clip[−Gk,Gk](R̂ + γμ̂), with Gk shrinking in σ̄·√εR. Clipping bounds ‖Qk‖∞ ≤ B uniformly (Lemma 1), taming both heavy tails and look-ahead.

STEP 05

Sparse synchronous update

Qk+1 = (1−α)Qk + α·T̂kQk, α = log T/((1−γ)K). Only K = O(log T) updates over T samples — each is variance-reduced. ρK ≤ 1/T kills initialization.

STEP 06

Analysis backbone

Control ‖T̂kQ − TQ‖∞ via look-ahead error (Lemma 3, tower property) + reward error (Lemma 4). Recursion ek+1 = (1−α)ek + α(TQ−TQ*) + α(T̂k−T) yields the Eq. 14 bound.

Headline results

  • Eq. 14 bound: with prob ≥ 1−δ, ‖eK‖∞ ≤ ‖e0‖∞/T + statistical term + bias ψ.
  • Bias depends on probabilities, not magnitudes — adversary can inject −10⁸ without breaking convergence.
  • Reward-only minimax-optimality: ψ = O(σ̄·√εR/(1−γ)) matches the Ω(√εR) lower bound of [6].
  • 1/√λmin vs 1/λmin statistical improvement over [9], from synchronous variance reduction.
  • Epoch-length sensitivity (Fig. 4): larger H ∈ {1000, 4000, 10000} → tighter convergence, as theory predicts.
  • Lemma 1: ‖Qk‖∞ ≤ B := 3Cσ̃/(1−γ) uniformly, by induction.

Section 03

03Strengths & limitations, side-by-side

+Strengths

  • First joint reward+state corruption model for asynchronous Q-learning — a genuinely harder, previously unexplored setting.
  • Batching insight is load-bearing: one mechanism yields both variance reduction (λmin improvement over [9]) and corruption robustness (removes [6]'s 1/λmin amplification).
  • Self-contained theory: Theorem 1 + Lemmas 1–4 + full proof of Theorem 2, all in 9 pages.
  • Minimax-optimality is falsifiable and correctly tied to the matching lower bound from the authors' own [6].
  • All constants in closed form (K, H, α, clipping radii, δ₁) — faithful reimplementation possible.
  • Honest about scope: conclusion flags O(H) memory and tabular-only limits, suggests concrete fixes.

−Limitations

  • Weak empirical baseline: only vanilla Q-learning compared; authors' own robust [6] — the natural comparator — is absent from experiments.
  • Heavy-tail claim unvalidated: all sims use bounded-variance noise; TRIMH's "finite second moment suffices" never demonstrated with Pareto/Student-t rewards.
  • i.i.d. assumption: main theorem under st ~ π i.i.d.; single-trajectory Markovian extension only asserted via blocking [23].
  • Tabular only: no function approximation — no direct path to large/continuous state spaces.
  • Memory cost: O(H) auxiliary memory per epoch for H ∈ {1000, 4000, 10000}; streaming fix [29] suggested but not implemented.
  • ε̄ ≤ 1/8 cap: behavior near the Huber upper limit (ε → ½) unaddressed.

Section 04

04Open questions

Q1Does BR-Async-Q actually beat the authors' own per-step robust [6] empirically — does the 1/√λmin vs 1/λmin gain show up at small λmin?
Q2Can per-epoch batch estimators be replaced by streaming robust mean estimators [29] without losing the O(ε) vs O(√ε) sharpness — eliminating O(H) memory?
Q3Does TRIMH's heavy-tailed guarantee matter in practice? A Pareto / Student-t reward experiment would validate the headline claim.
Q4How does the bound degrade as εR, εY approach the 1/8 cap — is there a trimmed-mean-style breakdown point beyond which no algorithm recovers Q*?
Q5Can the analysis extend to linear function approximation, where bootstrapped look-aheads no longer live in a known [−B, B]?
Q6The Huber adversary controls what but not when. How much worse are the bounds under a fully adaptive, history-dependent adversary?
Q7Are K = O(log T) epochs and H ≥ (20/λmin)·log(…) tight, or can adaptive (doubling-trick) epoch lengths tighten constants while preserving minimax bias?
