Gradient Concentration, Not Weight Saliency, Explains Representation-Level Class Unlearning

arxiv.org/abs/2607.21353 ↗
Key finding

Saliency, random, and no-mask updates are statistically equivalent — representation-level unlearning is driven by late-layer gradient concentration, not weight selection.

Billel Habbati · Alessio Merlo · Luca Verderame · Meriem Guerar
University of Genova (DIBRIS) · Centre for Defense Higher Studies (CASD), Roma

Why this matters

Undercuts the assumption that weight-saliency delivers representation-level deletion — directly undermining the privacy/compliance claims built on SalUn-style unlearning.

Critical edge

CIFAR-100 equivalence leans on a single metric — the linear probe. Prototype recovery is under-powered (n=10), and Gold itself ties the conditions at 25.5%, so deletion quality there is statistically indeterminate.

Single-metric dependence — acknowledged, not de-risked

01Methodology

  • Single-factor design on CIFAR-10/100 + ResNet-18. Objective, optimizer, LR, repair epochs, retain term, sparsity and splits all held fixed; the only variable is the mask.
  • Three matched-compute masks branched from one base model: SalUn saliency (top-k by |∇|), equal-cardinality random, RL-full (m=1).
  • Two extra probes: diagonal-Fisher mask (top-50% by second moment) to test the selection rule; Early mask freezing layer4+head (24.8% of params) + a 3× LR forced variant.
  • References: Gold = retrain on Dr; RandInit = untrained floor.
  • Representation metrics: linear probe, prototype recovery (k=5), layer-wise CKA, head-only relearning, MIA permutation test.
  • Gradient diagnostics: per-region squared-grad energy; Jaccard vs other-class / retain / random masks; specificity index (J_other−J_0)/(1−J_0), null J_0=1/3.
  • Stats: TOST equivalence at δ=±5pp (calibrated to ~3–4pp seed noise); 10 classes × 3 seeds = 30 runs/condition.

Pairwise mask differences ≤0.6pp — TOST-equivalent, p<0.001. Linear probe on both datasets: all mask diffs ≤0.6pp, equivalent.
  • 0% forget accuracy ≠ erasure: every condition drives forget accuracy to 0%, yet ~93% of the class stays prototype-recoverable.
  • Gradient concentration: layer3+4+head hold ~92% (CIFAR-10) / ~81% (CIFAR-100) of squared forget-grad norm before any mask is applied.
  • Weak class specificity: index 0.096 / 0.107; SalUn↔other-class Jaccard 0.397/0.405 ≈ SalUn↔retain 0.395/0.400; ↔Fisher 0.83/0.94 (null 1/3).
  • Fisher reproduces it: second rule lands at 93.4% / 25.6% — same late-concentrated weights.
  • Causal placement: Early mask still hits 0–4% forget acc and is TOST-equivalent on the linear probe; on CIFAR-100 prototype it leaves 59.0% (+33.5pp), so placement matters only where the metric has room.

03Strengths

  • Clean single-factor design that genuinely isolates mask identity from objective, optimizer and budget — rare in a literature that compares whole pipelines.
  • TOST equivalence with an a priori margin calibrated to seed noise, plus a transparent power analysis — replaces inspection-based "similar" claims.
  • Mechanistic triangulation: matched ablation + gradient-energy decomposition + mask-overlap + a reproducing Fisher rule.
  • Genuinely causal intervention (Early mask + forced variant) that falsifies one part of the story and sharpens another.
  • Honest scope and transparent AI-use/funding declarations; public code on Zenodo + GitHub.

04Limitations

  • Scope: only ResNet-18/CIFAR, single-class — no transformers, LLMs, diffusion, or random data-point forgetting. Concentration is empirical, not a theorem.
  • CIFAR-100 prototype is non-discriminative (Gold ties at 25.5%, n=10 under-powered) — equivalence there rests on the linear probe alone.
  • Forced 3× LR Early mask is supporting-only: loses 3–6pp retain accuracy on CIFAR-100; 2/30 runs miss the forget-accuracy criterion.
  • Jaccard / specificity is structural, not functional-equivalence — heavy overlap need not mean identical gradient interaction.
  • Contrastive-mask diagnostic covers one class and one seed, so "specificity cannot be lifted" is preliminary.
  • Representation-acting objectives (the advocated direction) are recommended but not demonstrated to escape the trap.

05Open questions for further exploration

  • Does the ~92% late-layer concentration generalize beyond ResNet-18 to ViTs, CLIP encoders, decoder-only LLMs — or is it residual-CNN + global-average-pool geometry?
  • Would a matched-compute ablation on random data-point (not class) forgetting still show mask equivalence, given per-sample gradients are less localized?
  • Can a representation-level objective (prototype collapse, contrastive shaping, orthogonal projection) actually drive linear-probe separability toward Gold?
  • Do all gradient/Fisher selectors provably converge to the same late-layer subset — and is there a non-gradient rule that selects early/intermediate weights and breaks equivalence?
  • Is the 0.09–0.11 specificity a lottery-ticket-style floor set by the architecture?
  • How should benchmarks combine probe / prototype / CKA / MIA into a single deletion-quality score robust to the fine-grained-geometry confound exposed on CIFAR-100?
