> **一句话总结：** 作者将一个概念-电路提取方法扩展为 2×2 设计（Python/Rust × Qwen2.5-Coder-7B/DeepSeek-Coder-V1-6.7B），在 58 个 Python 与 57 个 Rust 语法概念上测量后发现：哪些概念获得专用电路由任务决定（跨模型 Spearman ρ≈0.65），而电路位于哪一层、如何随层生长则由模型决定（Qwen 在 L17-19、DeepSeek 在 L6-7，相差 12-13 层）；据此提出"普遍性是表征内容而非计算组织的属性"。

> **TL;DR:** This paper extends a concept-circuit extraction method to a 2×2 design crossing two languages (Python, Rust) with two independently trained code models (Qwen2.5-Coder-7B, DeepSeek-Coder-V1-6.7B), measuring 58 Python and 57 Rust grammatical concepts identically in all four cells. The central dissociation: which constructs earn dedicated circuitry is task-determined (cross-model Spearman ρ=0.638 for Python, 0.673 for Rust, both p<1e-7), but where circuits sit (Qwen late band ~L17-19 vs DeepSeek L6-7, a 12-13 layer gap) and how they grow across layers are model-determined. Rust constructs receive 2-3× more concept-specific circuitry than Python, Qwen binds Rust's type-trait machinery into one tight neuron cluster (Jaccard 0.535 vs null 0.112, p<0.001), and DeepSeek shares 1.94× more cross-language neurons than Qwen — culminating in a two-style model fingerprint that licenses falsifiable predictions for any third model.

## 核心贡献

- 提出 What/Where/How 三轴分解框架：首次把"电路是否普遍"这个笼统问题拆成三个可独立回答的子问题——哪些概念获得电路（What）、电路位于哪些层（Where）、电路如何随层生长（How），并用 2×2 实证设计给出"yes/no/no"的答案。
- 在两个独立训练的生产级代码模型（Qwen2.5-Coder-7B、DeepSeek-Coder-V1-6.7B）上首次完成了跨模型的"结构化概念清单"对比：58 个 Python 概念与 57 个 Rust 概念在四元胞中被同一方法测量，提供了比 CKA 等几何相似度更可解释的比较。
- 发现并量化了"两个处理风格"指纹：六个独立测量（峰值带、原子性 flow 类型、Rust type-trait 聚类强度、元电路显著性、跨语言共享、flow-type 一致性）塌缩成两个相干的 per-model profile，说明跨模型变异是低维的。
- 揭示了一个语义维度从表面语法中消失的现象：Qwen 将 Rust 九个 type-trait 关键字（跨越四个句法类）绑成一个紧凑神经元簇，Jaccard 0.535，远超 permutation null 0.112（p<0.001），是该方法"超越表面语法测量到语义"的关键证据。
- 提供了可直接证伪的预测集合：第三模型应在该指纹的峰值带、flow 类型、聚类粒度、跨语言共享水平上以"一种风格"协同变化，而非自由混合；这是从 N=2 设计推导出可检验预测的方法学示范。
- 全部代码、冻结实验制品与逐数字复现测试套件以 Apache-2.0 / CC-BY-4.0 发布，每个数字与图都能在不重跑模型的情况下从分析层重生成。

## Key Contributions

- **The What/Where/How dissociation framework.** Splits the single yes/no "are circuits universal?" question into three independently answerable axes and shows empirically that universality holds for representational content but not for computational organisation.
- **First structured-inventory cross-model comparison.** Applies the same concept-circuit extraction identically across two independently trained dense code models on a finite a-priori grammar inventory (58 Python + 57 Rust concepts), turning the inventory itself into the common yardstick that SAE-feature or CKA comparisons cannot provide.
- **Quantitative dissociation evidence.** Cross-model Spearman ρ=0.638 (Python) and 0.673 (Rust) for "what" earns circuitry; a 12-13 layer offset for "where"; an early circuit spike for Qwen atomic concepts absent in DeepSeek for "how".
- **Language-design effect.** Rust constructs receive 2-3× more concept-specific circuitry than Python in both models (Qwen 0.215 vs 0.074 = 2.91×; DeepSeek 0.201 vs 0.097 = 2.07×), attributing the boost to stricter syntax reducing token ambiguity.
- **Discovery of a semantic type-trait cluster in Qwen × Rust.** Nine Rust keywords spanning four syntactic categories collapse into one strongly bound neuron cluster (within-group Jaccard 0.535, null 0.112, p<0.001) — a semantic dimension invisible at the surface/AST level.
- **Two-style model fingerprint with falsifiable predictions.** Six independent measurements cohere into two styles (Qwen: late/sharp, fine-grained clustering, low cross-language overlap; DeepSeek: early/smooth, coarser clustering, 1.94× more cross-language sharing), defining what any third model must co-vary along.
- **Reproducibility packaging.** Analysis code, figure scripts, frozen experimental artifacts, and a test suite regenerating every number without rerunning models, released under Apache-2.0 / CC-BY-4.0.

## Methodology

The paper extends the concept-circuit extraction-and-marginalisation method of Wilam (2026) — originally developed on a sparse 8-layer Python transformer (CSP-Atlas) — to a dense 2×2 design: two languages (Python, Rust) × two models (Qwen2.5-Coder-7B with 28 layers, DeepSeek-Coder-V1-6.7B with 32 layers). Formal languages are chosen specifically because the grammar fixes the construct inventory a priori, making cross-cell measurement comparable.

The pipeline has five stages:

1. **Prompt generation.** For each concept, two prompt sets are written: concept prompts place the construct in its structural role; checker prompts place the keyword token outside that role (in strings, comments, variable names). Fifty prompts per (concept, context) pair inject variance along lexical, structural, and padding dimensions so that marginalisation washes out incidental features. The testable subset (58 Python, 57 Rust) excludes tokenless AST constructs and constructs whose token is inseparable from the concept (e.g., Rust ownership operators).

2. **Extraction.** Each prompt passes through the model once; forward hooks record the MLP output at the last-token position of every layer.

3. **Binarisation.** A neuron is "active" if its absolute activation exceeds ε. The paper sweeps ε ∈ {0.001, 0.1, 0.5} and selects ε = 0.5 throughout because that is where structural signal emerges (at 0.001 circuits are trivially full; at 0.1 concept-only fractions are near-zero). For dense SwiGLU models the consistency filter is degenerate — every neuron passing ε fires on all variations — so the sweep collapses to one parameter.

4. **Marginalisation.** The universal mask A for a concept is the intersection of active-neuron sets over the concept prompt family; the checker mask B is the analogous intersection over checker prompts. Decomposition: concept-only = A\B, shared = A∩B, token-only = B\A. The concept fraction |A\B|/|A| is the central per-concept measurement; comparing A against B is what separates the abstraction from its surface token.

5. **Decomposition & analysis.** Standard tools are applied to the resulting (concept, layer, model, language) dataset: Spearman correlation for cross-model agreement; Ward-linkage clustering with a permutation null over pairwise Jaccard similarity for semantic clusters; zero-ablation against a size-matched random null for causal validation; logistic-regression probes with cosine comparison for geometric validation. The pipeline cleanly separates extraction (run once, frozen), analysis (seconds on artifacts), and presentation (one script per figure).

A separate cross-language pairing exercise identifies seven construct pairs playing equivalent roles (iteration, branching, loop control, function definition, module import, return, type definition); the per-layer sharing fraction (intersection of pooled concept-only sets over the smaller pool) measures whether a model treats a Python construct and its Rust analogue equivalently.

## Results & Highlights

- **Cross-model agreement on "What earns circuitry" (Python).** Spearman ρ = 0.638 across 58 Python concepts (p < 1e-7), with flow-type classifications agreeing at 88.6%. This is the headline result that the inventory ranking is conserved across independently trained models while remaining far from identity.
- **Cross-model agreement on "What" (Rust).** Spearman ρ = 0.673 across 57 Rust concepts (p < 1e-7), flow-type agreement 85.1% — same direction and magnitude as Python.
- **"Where" divergence: a 12-13 layer band offset.** Qwen concentrates concept-specific processing in a late band (Python ~L19, Rust ~L17); DeepSeek concentrates it at L6-7 for both languages. The within-model cross-language consistency (each model's band predicts where it processes both languages) is the load-bearing observation.
- **"How" divergence: early spike present in Qwen, absent in DeepSeek.** For the six Python atomicity concepts, Qwen shows a sharp early spike at layers 2-3 (early-bias 0.73-0.90); DeepSeek's circuits are near-empty until layers 10-12 and climb smoothly (early-bias 0.05-0.11).
- **Language-design effect (Rust vs Python).** Mean concept fraction: Qwen 0.215 vs 0.074 (2.91×), DeepSeek 0.201 vs 0.097 (2.07×). The boost is largest where Python is weakest — Return 7.2×, For 5.1×, If 4.4× — consistent with the token-ambiguity principle (Rust's stricter syntax reduces keyword ambiguity).
- **Cross-language neuron sharing.** DeepSeek shares 1.94× more cross-language than Qwen. All seven equivalent pairings pass the 10% sharing threshold in DeepSeek; Qwen reaches six, missing function definition (def↔fn) at 3.8% because indentation-scoped def and brace-scoped fn differ too much in surface form despite shared role.
- **Rust type-trait cluster in Qwen.** Nine keywords (Enum, Send, Option, Iterator, Copy, Eq, Drop, Debug, ToString) collapse into one strongly bound neuron cluster at Qwen × Rust × L14 with within-group Jaccard 0.535 vs a permutation null of 0.112 (p < 0.001). Two further hypothesised groups (memory/ownership, data definition) are only marginally significant (p ≈ 0.04); control-flow/module is indistinguishable from random (p = 0.292) — the honest finding is one strongly bound cluster, not four.
- **Causal double dissociation (Qwen × Python).** Of seven concepts tested, four pass cleanly (Import: Δ_co = −0.054 vs Δ_null = −0.007; Try: −0.053 vs +0.066; While: −0.051 vs +0.042; Assert: −0.032 vs +0.004). FunctionDef and For are marginal; Break fails outright because it is token-rare and draws on general lexical context rather than a concept-selective pathway.
- **Geometric validation via linear probes.** Per-concept, per-layer logistic-regression probes achieve 97.6-99.7% accuracy at every one of Qwen's 28 layers for 24 keyword-bearing AST concepts. Pairwise probe-direction cosine correlation with concept-only Jaccard peaks at r = 0.645 at L20 — moderate, not unity, because the probe captures sub-threshold distributed signal the binary ε = 0.5 view misses.

## Authors & Credibility

Single-author paper by Piotr Wilam at University College London. The work directly extends the author's prior CSP-Atlas method (Wilam, 2026, arXiv:2605.24603) and explicitly frames itself as the designed next step from that sparse-model study to dense production code models. The 2×2 design is positioned from the outset as the smallest design that can separate task, language, and model axes, and the paper is unusually explicit about the limits of N=2 (it cannot itself show the fingerprint predicts; it can only show the axes separate and define a coherent, falsifiable prediction for a third model). Calibration reproduces known positives (the atomicity super-cluster replicates across three architectures — sparse 8-layer, dense 28-layer, dense 32-layer) and known negatives (Python builtins near-zero: Qwen 0.024, DeepSeek 0.068). Code, frozen artifacts, and a frozen-numbers test suite are released (Apache-2.0 / CC-BY-4.0) with auto-fetching loaders, and every figure is regenerable without rerunning a model.

## Critical Assessment

- **Novelty.** The What/Where/How decomposition is genuinely new: prior universality work (Olah et al. 2020; Gurnee et al. 2024 universal neurons; Huh et al. 2024 Platonic Representation Hypothesis) treats universality as a single yes/no question, and prior cross-model comparison relies on geometry scores (CKA) that cannot separate concept-identity agreement from layer-placement divergence. The structured-inventory-as-yardstick inversion is the methodological core that enables the comparison, and the Rust type-trait cluster is a clean discovery that goes beyond what the method was nominally built to measure.
- **Rigor.** Internally strong: permutation tests with fixed seeds (10,000 draws), size-matched random nulls for ablation, double-dissociation logic for causal claims, explicit flow-type agreement as a second corroborating measure. Calibration section reproduces known positives and negatives before any headline claim. The honesty about Break failing the causal dissociation (token-rare concept, draws on general context) and about only one of four hypothesised Rust clusters being strongly bound is commendable.
- **Reproducibility.** High. Frozen artifacts, frozen-numbers test suite, auto-fetching loaders, and the explicit claim that every number/figure regenerates from the analysis layer without rerunning a model. The pipeline cleanly separates extraction (run once) from analysis (seconds on artifacts) — a model other mechanistic-interpretability papers could emulate.
- **Significance.** Principally methodological and conceptual for the mechanistic-interpretability community: it shows that "are circuits universal?" conflates three axes that need not agree, and it provides a concrete measurement protocol others can apply. The practical claim (concept-level interpretability results transfer; layer-indexed results must be re-localised per model) is directly actionable for practitioners porting probing or patching results across code models.
- **Red flags / weaknesses.** (1) N=2 models. The paper is explicit that two models cannot demonstrate the fingerprint predicts; the cross-model agreement landing at ρ≈0.65 rather than 0.3 or 0.9 is the data picking the middle of three outcomes with very different implications, but a third model is the designed and still-unrun test. (2) The causal validation is scoped to only one of the four cells — Qwen × Python — chosen because its two-phase profile gives a clean single-layer ablation target; DeepSeek's build-and-hold profile has no clear peak layer, so its causal validation is deferred to an extended (multi-layer or cumulative) design that is not run. The cross-model claims about Where and How therefore rest on correlational and geometrical evidence, not causal. (3) Layer-count mismatch (28 vs 32) is handled by absolute indices for body comparisons, with fraction-of-depth used only in appendix profiles — defensible but worth flagging. (4) The consistency parameter is degenerate for these dense SwiGLU models, so the effective sweep is over ε alone; the paper is honest about this but it does mean one degree of methodological freedom present in the sparse-model predecessor is unavailable here. (5) The binary ε = 0.5 neuron mask is deliberately coarse — §7.2 quantifies that it misses sub-threshold distributed structure (probes still exceed 97% where ablation has no effect), so the method's claims are explicitly about high-amplitude neurons, not all concept-relevant computation. (6) Both languages are imperative; generalisation to declarative languages or proof assistants (Lean) is open.

## Strengths

- The What/Where/How axis decomposition is a clean conceptual contribution that reframes a long-standing question and is likely to be reused.
- The 2×2 design is the smallest that separates the three axes, and the paper argues this explicitly rather than overclaiming from a single model.
- Calibration before headlines: known positives (atomicity super-cluster replicating across three architectures) and known negatives (builtins, ownership operators near-zero) establish the method's validity within the paper itself.
- Intellectual honesty: marginal and failed results (Break, FunctionDef, For, two of four Rust clusters) are reported and interpreted rather than buried.
- The Rust type-trait cluster is a striking, qualitatively interpretable discovery — nine keywords across four syntactic categories bound by shared semantic role — that demonstrates the method reaching past surface syntax.
- Full release of code, frozen artifacts, and a frozen-numbers test suite with auto-fetching loaders; every figure regenerable without a GPU.
- Concrete operational guidance for practitioners: which axis an interpretability result lives on determines whether it transfers (concept inventory yes; layer-indexed probe/patch no).

## Limitations

- **N=2 models.** Cannot itself validate that the two-style fingerprint predicts a third model; that is the explicitly designed but unexecuted next step. Coherence observed once could in principle be coincidence.
- **Causal scope restricted to Qwen × Python.** The cell with the clearest two-phase profile; DeepSeek's build-and-hold profile requires a deferred multi-layer/cumulative ablation design that is not run, so the Where/How cross-model claims rest on correlational + geometrical evidence.
- **Binary ε = 0.5 mask is coarse by design.** Misses sub-threshold distributed structure (§7.2 shows probes exceed 97% accuracy where ablation has no effect); the continuous-geometry extension capturing this signal is deferred to future work.
- **Imperative languages only.** Generalisation to declarative languages (Haskell) or proof assistants (Lean) — where constructs carry logical content — is open.
- **Layer-count mismatch (28 vs 32).** Body comparisons use absolute layer indices; fraction-of-depth profiles only in appendix.
- **Degenerate consistency parameter.** The parameter that varies meaningfully in the sparse-model predecessor is inert for these dense SwiGLU architectures, collapsing the sweep to ε alone.
- **Shared testable subsets for cross-model comparison.** The full concept space differs across models; comparisons use the shared subsets, which is a deliberate but real constraint.
- **"Model-determined" attributes the variation to whatever distinguishes the two training runs (corpus, trajectory, architecture, initialisation) without isolating which factor.** Isolating the factor requires single-factor designs that are not run.

## Relevance

对关注机制可解释性（mechanistic interpretability）与代码大模型内部表征的研究者而言，本文提供了一个可直接套用的跨模型"概念清单"比较协议与 What/Where/How 分解框架；其关于"概念级结论可迁移、层索引级结论必须按模型重新定位"的实操结论，对在任何代码模型上做 probing、patching 或 circuit editing 的工作都有方法学指导意义。

## Questions for Further Exploration

- Does the two-style fingerprint predict a third independently trained code model (e.g., CodeLlama, StarCoder2)? Does its peak band, atomicity flow type, cluster granularity, and cross-language sharing level co-vary as one style, as the paper licenses?
- What happens when the method is applied to a declarative or proof-assistant language (Lean, Coq) where constructs carry logical rather than merely syntactic content — does a qualitatively different kind of abstraction emerge?
- Can the deferred continuous-geometry extension recover the sub-threshold distributed structure the binary ε = 0.5 view misses, and would doing so change any of the What/Where/How conclusions (particularly the moderate ρ ≈ 0.65 agreement, which might rise)?
- A developmental analysis over training checkpoints: when does the What/Where/How split appear, and is What conserved from early training while Where and How drift — i.e., is the dissociation a training-dynamics fact as well as a final-state fact?
- Can the single-factor designs that isolate corpus vs architecture vs initialisation be run, to attribute the "model-determined" variation to a specific cause rather than to "whatever distinguishes the two training runs"?
- The causal validation is Qwen × Python only; can an extended (multi-layer or cumulative) ablation design validate DeepSeek's build-and-hold profile causally, closing the gap between the correlational and causal evidence for the Where/How claims?
- Does the Rust type-trait cluster generalise to other type-system-rich languages (e.g., Haskell typeclasses, Scala traits), or is it a Qwen-specific encoding of Rust's particular type-and-trait machinery?
