Methodology — a 2×2 extraction design

02 / method

Extends the concept-circuit extraction-and-marginalisation method to a dense 2×2 design: two languages Python × Rust crossed with two independently trained models Qwen2.5-Coder-7B (28L) × DeepSeek-Coder-V1-6.7B (32L). Formal languages are chosen because the grammar fixes the construct inventory a priori, making all four cells directly comparable — the inventory becomes the yardstick that SAE-feature or CKA scores cannot provide.

  1. Prompt generation. 50 prompts per (concept, context): concept prompts place the construct in-role; checker prompts place the keyword token out-of-role (strings, comments, names). Lexical/structural/padding variance washes out incidental features.
  2. Extraction. Single forward pass per prompt; forward hooks record MLP output at the last-token position of every layer.
  3. Binarisation. Neuron "active" if |activation| > ε; sweep ε ∈ {0.001, 0.1, 0.5}, select ε = 0.5 where structural signal emerges. Dense SwiGLU makes the consistency filter degenerate — one effective parameter.
  4. Marginalisation. Universal mask A = ∩ active-neuron sets over concept prompts; checker mask B = ∩ over checker prompts. Concept-only = A\B; the concept fraction |A\B|/|A| is the central per-concept measure — what separates abstraction from surface token.
  5. Decomposition & analysis. Spearman for cross-model agreement; Ward-linkage clustering with permutation null (10k draws) for semantic clusters; zero-ablation vs size-matched null for causality; logistic probes for geometric validation.

  • Language-design effect. Rust gets 2–3× more concept-specific circuitry than Python; boost largest where Python is weakest — Return 7.2×, For 5.1×, If 4.4×.
  • Semantic type-trait cluster. Nine Rust keywords across four syntactic classes collapse into one bound neuron cluster at Qwen×Rust×L14 — a dimension invisible at AST level.
  • Causal double dissociation (Qwen×Python). 4 of 7 concepts pass cleanly (Import, Try, While, Assert); Break fails outright — token-rare, draws on general context.
  • Calibration. Atomicity super-cluster replicates across 3 architectures; builtins near-zero (Qwen 0.024, DeepSeek 0.068).

+ Strengths

  • The What/Where/How decomposition cleanly reframes a long-standing question and is likely to be reused.
  • 2×2 is the smallest design separating the three axes; the paper argues this instead of overclaiming from one model.
  • Calibration before headlines: known positives & negatives establish validity within the paper.
  • Intellectual honesty — marginal/failed results (Break, FunctionDef, For, 2 of 4 Rust clusters) are reported, not buried.
  • Rust type-trait cluster is a striking, qualitatively interpretable discovery past surface syntax.
  • Full release: code, frozen artifacts, frozen-numbers test suite — every figure regenerable without a GPU.

— Limitations

  • N = 2 models. Cannot itself validate the two-style fingerprint predicts a third model; coherence once could be coincidence.
  • Causal scope = Qwen × Python only. DeepSeek's build-and-hold profile has no clean ablation peak; Where/How cross-model claims are correlational + geometric.
  • Binary ε = 0.5 mask is coarse by design — misses sub-threshold distributed structure (probes >97% where ablation has no effect).
  • Imperative languages only. Generalisation to declarative (Haskell) or proof assistants (Lean) is open.
  • Layer-count mismatch (28 vs 32) handled by absolute indices for body comparisons; fraction-of-depth only in appendix.
  • "Model-determined" bundles corpus, architecture, trajectory, init — no single-factor isolation.

Open questions for further work

04 / forward
  • Does the two-style fingerprint predict a third model (CodeLlama, StarCoder2) — co-varying as one style rather than freely mixing?
  • Applied to a proof-assistant language (Lean, Coq) where constructs carry logical content, does a qualitatively different abstraction emerge?
  • Can the deferred continuous-geometry extension recover sub-threshold structure — and would it raise the moderate ρ ≈ 0.65?
  • A developmental analysis: when does the What/Where/How split appear across checkpoints — is What conserved from early training while Where/How drift?
  • Can single-factor designs isolate corpus vs architecture vs initialisation as the cause of "model-determined" variation?
  • Can a multi-layer / cumulative ablation design causally validate DeepSeek's build-and-hold profile, closing the correlational gap?
