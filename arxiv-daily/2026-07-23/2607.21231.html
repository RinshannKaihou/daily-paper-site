Progressive Cramming: Reliable Token Compression and What It Reveals

Dmitrii Tarasov · Timofei Lashukov · Elizaveta Goncharova · Andrey Kuznetsov
FusionBrain Lab · HSE University · Innopolis University

ICML 2026 PMLR 306 · Seoul · ~2800 GPU-hrs (A100 80GB)
token-cramming context-compression mechanistic-interpretability llm-embeddings attention-knockout
Key metric · 5-shot MMLU
63.22% → 0.00%

Llama-3.1-8B, full-prefix compression. 0% valid parseable answers — despite 100% reconstruction. A random control embedding loses only 0.51 pts.

Why this matters

Reframes cramming as brittle early-layer steering — not semantic storage — a direct caution for designing learned, faithful context compression.

▲ Caveat
Critical edge

Never benchmarks cramming against semantic-compression baselines (Activation Beacon, ICAE, AutoCompressors) on the same downstream tasks — so its claimed "unique brittleness" is asserted, not proven.

01

Methodology

Progressive token addition Grow the target prefix one token at a time, warm-start e(k) ← e(k-1), stop when perfect reconstruction fails within budget (1k steps/new token, 10k total) → a sharp 0/1 success boundary.
Low-dimensional projection Constrain e = Wz + b, k ≪ d (k=256 Llama-3.1-8B, k=32 Gemma-3-4b), jointly optimized per sample; a shared-(W,b) variant probes universality.
Information gain Capacity measured as C_H = H_LM − H_comp+LM (bits of cross-entropy reduction), more stable across datasets than raw token count.
Causal attention knockout Mask pre-softmax logits targeting the compression embedding at selected layers. Three protocols on Llama-3.1-8B (32 layers): per-layer, forward-cumulative, reverse-cumulative.
Depth / width capacity probe Truncate to first N ∈ {1,2,4,8} decoder layers, repair with a short fineweb-edu finetune; isolates the depth axis (within a family) from the width axis (across families).
Evaluation PG19 (primary, 50 samples) + Fanfics replication. Downstream: HellaSwag, ARC-Easy (4-way MC, chance 25%), 5-shot MMLU (512). Four families: Pythia, Llama 3, SmolLM2, Gemma 3.
02

Results & Highlights

Reconstruction fixed
Llama-3.1-8B PG19: full cramming 99.96% TF but only 40.44% greedy → progressive 100% / 100% (1438±380 tokens).
Brittleness localized
Residual ~1% error clusters at token index 0/1 (86–100% mismatch); one early miss triggers irreversible autoregressive collapse to ~0%.
Low-dim projection boosts capacity
Llama dim=256: 1438 → 1697 tokens, 4391 → 4814 bits. SmolLM2-1.7B dim=256: 335 → 957 tokens.
Subspace is sample-specific
A shared (W,b) trained on 50 samples reaches 742 tokens — but frozen and transferred to unseen samples collapses to 8.7±6.8 tokens.
Downstream multiple-choice drop
HellaSwag Llama-3.1-8B 61.91 → 40.80% (−21.1 pts); ARC-Easy 63.54 → 43.31%.
Causal localization
Forward knockout of the first few layers restores HellaSwag to baseline (0.598) while destroying reconstruction; late layers (20–60% attention mass) are causally negligible.
Capacity scales with depth + width
8-layer Qwen3-8B (625 tokens) exceeds the full 36-layer Qwen3-4B (512); depth and width partially substitute.
Trajectories are low-dimensional
30–100 PCA components explain 99% of per-sample variance in 2048–4096-dim spaces — a property of the warm-start path, not the (near-orthogonal) solution set.
03

Strengths & Limitations

Strengths
  • Principled boundary. Turns a fuzzy 99% threshold into a binary success/failure test, exposing an early-token collapse mode prior work missed.
  • Clean causal result. Attention-knockout dissociates attention mass from importance: high mass ≠ causal; the late-layer sink is a symptom, early-layer interactions the cause.
  • Intellectually honest. Explicitly states the low-dim trajectory is a path property, not a solution-set property, and that perfect reconstruction ≠ transferable semantics.
  • Broad coverage. Four model families, two datasets, multiple ablations, shared vs. sample-specific projection, depth/width truncation.
  • Reproducible. Public code + trajectory dataset; accepted at ICML 2026.
Limitations
  • No semantic-compression baselines (Activation Beacon, ICAE, AutoCompressors) on the same downstream benchmarks — relative brittleness unquantified.
  • Gemma-3-4b anomaly unresolved. 0% HellaSwag convergence; logit-softcapping hypothesis stated but not isolated.
  • Slower method. Progressive is ~2× slower and resists batching; adaptive variants recover speed at an 18–28% capacity shortfall.
  • Narrow downstream eval. Only MC (HellaSwag, ARC) + 5-shot MMLU; no long-context, reasoning, or instruction-following.
  • Knockout detailed on one model (Llama-3.1-8B) only; smaller-model replications summarized, not shown.
  • Open problem unsolved: "do not yet know how to make an embedding both perfectly reconstructable and semantically faithful."
04

Open Questions

Q1Can embeddings be regularized (activation alignment, semantics-preserving aux loss) to be both perfectly reconstructable and semantically faithful — or is there a fundamental trade-off?
Q2Do semantic baselines show the same early-layer steering pathology, or is cramming uniquely brittle among embedding-based methods?
Q3Does the early-layer causal locus generalize to 70B+ scale and non-Llama architectures (Mistral, full-depth Qwen) where attention-sink dynamics differ?
Q4Can an amortized single-forward-pass compressor approximate the per-sample progressive optimum — at what fidelity and downstream cost?
Q5Is the depth/width substitutability actionable for compressibility-optimized reconstructors (wider-but-shallower), and does it transfer to encoder-decoder or MoE?
Q6What is logit softcapping's role (Gemma 3) in limiting cramming capacity, and can it be mitigated without harming base LM quality?
