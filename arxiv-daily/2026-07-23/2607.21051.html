Why this matters

Unifies in-context learning, context distillation, and RL sample efficiency — letting agents self-improve, in weights, with order-of-magnitude fewer environment samples.

Critical edge

Reproducibility is blocked. Base models are undisclosed in-house checkpoints and the 749 SWE tasks are an internal, success-filtered set with no public release — so absolute numbers aren't comparable to SWE-bench. Missing baselines: no offline RL (IQL/CQL), no DAgger. The frontier-model comparison is apples-to-oranges (fine-tuned vs inference-only).

01

Methodology

Given a base model and its collected experience trajectory τ, distill the ICL-induced behavior (teacher conditioned on τ) into a student that sees only the bare history — without collecting any more environment samples.

Formalize as trajectory-level context distillation

Minimize DKL between the experience-conditioned teacher and a context-free student over future trajectories. Chain-rule factorization reduces it to per-step policy KLs — but naive estimation still needs teacher rollouts in the environment.

Push the branch to k = 1 model-free

Take branched rollouts to the limit: the branch holds only the teacher's single sampled decision a'_t. The world model drops out entirely — no synthetic observations, no error compounding — and the objective collapses to teacher-sampled cross-entropy over recorded histories.

Three engineering pieces

Experience preprocessing g(τ) compresses 60–600-turn histories; enhanced teacher reasoning via a fixed prompt (roughly doubles G_ICL: 34.9%→72.5%); branch packing packs successive branch points into one sequence.

Branch packing payoff 768 → 64

4096 separate examples become 128 packed sequences; training steps fall from 768 to 64 and total teacher-generation + training time drops >10× — while average G_ICL rises 84.2%→90.1%.

  • Model-free beats model-based (Table 2): 1-step branch reaches task-level G_ICL 83.8% vs 57.3% (model-based branch) and 19.2% (full model-based) on Detective — less world-model participation monotonically helps.
  • Forward KL » reverse KL (Table 5): teacher-sampled forward KL hits G_ICL 96.7% / 98.4%; student-sampled reverse-KL stays near zeroshot (9.1% / 0.4%) — the student rarely samples the experience-induced good decisions to supervise.
  • OOD transfer (Table 4, 494 tasks): pass@1 4.62%→8.84%, pass@5 20.39%→26.13%, including cross-repository tasks where both repo and type are unseen.
  • Frontier context (Table 8): ICL+EPD lifts their base 18.50→43.77 — on par with Claude Opus 4.5 (43.76), above GPT-5.2 / Gemini 2.5–3 Pro / Kimi-K2-Thinking — though vs inference-only zeroshot references.
  • Teacher-data scaling (Figure 3): 1→16 packed sequences/trial lifts G_ICL 31.8%→64.8%; teacher-generation cost still rising at 2.79× the 61.7M-token corpus — flagged as unsolved.
03

Strengths · Limitations

Strengths

  • Elegant core idea — one teacher decision per recorded history removes both the world model and extra env interaction in a single principled step.
  • Broad, well-controlled ablations — model-based vs model-free, packing, forward vs reverse KL, sampled vs full-distribution targets, LR, teacher reasoning, continual, OOD, scaling — each isolates a design choice.
  • G_ICL metric (zeroshot→0%, ICL→100%) makes cross-domain, cross-method comparison interpretable regardless of absolute score scale.
  • Striking sample efficiency — order-of-magnitude fewer env samples than PPO/GRPO at matched or better performance.
  • Honest framing as "initial results," with teacher-cost limitation explicitly acknowledged.

Limitations

  • Undisclosed base models (no family/size/release) and an internal, success-filtered SWE set — both limit reproducibility and absolute-number interpretation.
  • Weak/missing baselines: no offline RL (IQL/CQL), no DAgger; the SFT baseline is the most naive variant, not SFT-on-successes.
  • Apples-to-oranges Table 8 — fine-tuned model vs inference-only frontier models.
  • Narrow TaleSuite scope (6 main tasks; continual uses 6; OPD uses 2) — generalization claims rest on small counts.
  • Teacher-generation cost grows with experience size and is still rising — unsolved.
  • OOD pass@1 (4.62%→8.84%) is statistically interesting but practically modest; no analysis of negative transfer from low-quality experience.
04

Questions for further exploration

  1. Do the gains survive on a named open checkpoint (Qwen/Llama) against a public benchmark like SWE-bench Verified, instead of the curated internal set?
  2. How does EPD compare to offline RL (IQL/CQL) and DAgger-style imitation — which also avoid extra env interaction and exploit the same collected experience?
  3. What happens when collected experience contains wrong or misleading trials — does preprocessing filter the noise, or does negative transfer occur, and can it be detected?
  4. Can the teacher-generation cost bottleneck be cut (speculative decoding, adaptive high-information branch selection) without sacrificing G_ICL?
  5. Does continual EPD keep accumulating past 5 cycles, or plateau / catastrophically forget as the experience distribution drifts from the base model?
  6. Can the 1-step objective combine with a lightweight value model to prioritize which branch points deserve distillation — recovering model-based density without its error compounding?
