Information-Theoretically Secure Aggregation for Lightweight Federated Learning: Resilient to Dropouts and Adversaries ↓

Hyeong-Gun Joo · Songnam Hong SMIEEE · Dong-Joon Shin SMIEEE · corresponding · Hanyang University, Seoul · Jul 23, 2026
Key finding

A lightweight, information-theoretically secure aggregation for SIGN SGD-MV that cuts online communication 99.5% and latency 85.7%, with zero-loss dropout and adversary recovery.

01Methodology

Built on SIGN SGD-MV: each user sends a 1-bit gradient sign; the server computes a majority vote. The authors recast that vote as an MV polynomial F(x) over a prime field, where every monomial is a power of one aggregated base x — the structural insight that drives the whole design.

STEP 1

Inverse-form exponent reduction

Using Fermat’s little theorem x^(p−1) ≡ 1, high-degree terms j > (p−1)/2 are rewritten as inverse powers, halving the effective max degree to N′ = (p−1)/2 with no accuracy or security loss.

STEP 2

Single-round secure multiplication

Two realizations. Method A (DN + N-BTE) is general-purpose, single online round, but exponential offline cost O(2^N). Method B (Single-Mask Power Sharing) exploits the single-base structure: one mask a + binomial expansion compresses offline cost to linear O(N′) with a single online opening.

STEP 3

MDS-coded aggregation & robustness

Each user t-shares F(x); the server decodes via MDS reconstruction with minimum distance d_min = n−2t, fully correcting any pattern with 2e + s ≤ d_min−1 — dropout recovery and adversarial correction, not just tolerance. Lowering t trades privacy for stronger resilience.

Thm 3: no degradation vs clean case

On the cost table (n=100), Method B also cuts offline multiplications 50.5% (49 vs 99) and storage 82.8% (357 vs 2,079 bits); Method A explodes to 5.63×10^16 multiplications. Privacy-wise (Table I) it is the only entry combining information-theoretic security, final-MV-only server visibility, no accuracy loss, very-high scalability, and joint dropout + adversary handling.

Strengths

  • Single-mask power-sharing converts Method A’s exponential offline cost into linear, with a single online opening — a clean, publishable idea.
  • Unified framework for privacy + dropout recovery + adversarial correction inside one MDS-decoding construction; a genuine advance over Hi-SAFE.
  • Honest-majority assumption matches SIGN SGD-MV’s own majority-vote semantics; tunable threshold t is a useful privacy/robustness knob.
  • Full theoretical package: correctness (Thm 2), convergence (Thm 3), simulation-based security (Thm 4).
  • Quantitative results reported with absolute numbers and deltas across Tables IV, VI, VII.

Limitations

  • Honest-majority (t < n/2) is mandatory; malicious-majority deployments are out of scope.
  • Small prime field p≈21–101; Fermat inversion is cheap only because p is small. Large-p inversion is flagged, not implemented.
  • Modest experimental scale (n=14–21 active); no large-count accuracy runs, no real edge-device deployment, no MPC wall-clock latency.
  • Method A is theoretical only (exponential, N′≤8–9); all practical claims rest on Method B.
  • Baseline scoping: accuracy only vs SIGN SGD-MV / Hi-SAFE; no HE/DP head-to-head. No code release.

03Open questions for further exploration

  1. Does Method B’s linear offline cost still dominate wall-clock at hundreds/thousands of users, and do the dropout/adversary gains persist or shrink?
  2. Can single-mask power-sharing extend beyond MV polynomials — secure top-k sign selection, or quantization past 1-bit?
  3. What is the real end-to-end wall-clock latency (ms) on edge hardware (phones, Raspberry Pi), not just round counts on a GPU server?
  4. How does it behave under a malicious (not semi-honest) adversary, and can MDS correction pair with verifiable secret sharing?
  5. A direct vs HE (CKKS) / DP-SIGN SGD comparison would map the true privacy-accuracy-cost Pareto frontier across families.
  6. Does mask reuse across exponents leak anything over many rounds with correlated gradients?
