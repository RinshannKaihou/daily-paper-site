Beyond Independent Optimization: Compression, MoE Routing, and Quantization Interactions in Multimodal Edge Intelligence
arXiv:2607.20981v1  ·  cs.AI

Jay Gor · Karm Dave · Akshita Abrol · Rajesh Gupta · Sudeep Tanwar · Zhengkui Wang | Nirma Univ. · Singapore Institute of Technology · Marwadi Univ. | 23 Jul 2026
Key finding

Compression, MoE routing, quantization, and KV-cache form a coupled failure-propagation chain — independent per-stage optimization breaks end-to-end performance.

Key metric
2.8×
decoding throughput
at only 0.5% VQAv2 accuracy loss — ZipVL's stage-coordinated KV sparsification (He et al., 2024)
Why this matters

A unified failure-chain map plus a computable TRC diagnostic for jointly evaluating compression, routing, and quantization on edge hardware — where no benchmark today measures all five axes at once.

Critical edge

The central compression→routing gap is unmeasured — argued only by analogy to quantization studies. And the headline TRC metric is defined but never empirically validated.

Inference is modelled as the composition P = H ∘ Qπ ∘ Rθ ∘ Cϕ. The independence assumption in eq. (2) — optimize each ϕ*,θ*,π* separately — almost never holds. Each stage's output distribution feeds the next; locally optimal choices propagate as routing drift, miscalibrated quantization, evidence loss, or memory blow-ups. Interface B (compression→routing) is flagged as the largest open gap.

§ 02

Method & the TRC diagnostic

Analytical synthesis, not new experiments

Four-step method

  1. Architectural grounding — fix vocabulary: ViT patch redundancy, MLLM token-budget asymmetry, Top-k MoE routing, edge SRAM→DRAM→energy hierarchy. §2
  2. Failure-chain framework — model inference as P = H∘Qπ∘Rθ∘Cϕ; define interfaces A/B/C + hardware feedback, each with transfer / failure mode / literature state. §3
  3. Per-stage synthesis — sections organized along the chain: ViT compression, MLLM sensitivity, video/ temporal, KV-cache, MoE routing & serving, quantization failure modes, edge deploy. §4–12
  4. Benchmark critique & open problems — catalogue suites (OpenVLM, PalmBench, MLPerf Power…); none jointly measures all five axes; propose a deployment-tuple benchmark. §13–14

Temporal Routing Consistency (TRC)

TRC = 1/(T−1)  Σt  |Et ∩ Et+1| / |Et ∪ Et+1|

A Jaccard overlap of expert sets across adjacent frames that makes the absence of recurrent state in Transformer-MoE measurable — quantifying expert jitter in video MoE. Cheap to compute from any Top-k model; the survey's most reusable, citable artifact — though proposed, never yet demonstrated.

§ 04

Strengths & limitations

Read them against each other

Strengths

  • Failure-chain formalism turns a sprawling 100+ work literature into one causal story; interface template (transfer / failure / state) applied consistently.
  • TRC is concrete and low-cost — any video MoE team can compute it today, addressing a real gap (no recurrent state guaranteeing temporal continuity).
  • Intellectual honesty — explicitly names Interface B as unmeasured, flags the amplification bound as loose, distinguishes results from hypotheses.
  • Reusable reference artifacts: Table 1 master matrix, Table 2 "interface impact" column, Table 4 quantization failure taxonomy.
  • Broad, current coverage (through mid-2026) across compression, KV, MoE, quantization, serving, and hardware in one map.

Limitations

  • No original experiments — the framework rests on cited numbers; the central Interface B gap is unmeasured by the authors' own admission.
  • Heavy reliance on unrefereed 2026 preprints (EAQuant / VSRAQ / SplitQ) for load-bearing claims — if they shift under review, the anchors shift too.
  • TRC defined but never validated — no baseline values, no sensitivity, no evidence low TRC correlates with downstream temporal-reasoning failures.
  • Proposed benchmark is a 7-tuple sketch — no released protocol, workload, or reference implementation the community can act on.
  • Hardware discussion stays conceptual; "memory movement dominates energy" rests on a single citation. Some redundancy across §3–§14.
§ 05

Open questions worth chasing

The research agenda this survey sets
  1. Does compression-induced routing shift actually exceed quantization-induced shift? A direct ΔC vs ΔQ ablation on Mixtral/DeepSeek-MoE would resolve Interface B.
  2. What is the empirical TRC distribution of current video MoE models (NextQA, EgoSchema, LongVideoBench), and does low TRC track degraded temporal reasoning?
  3. Can a routing-stability KL term be added to compression losses without harming the accuracy-FLOPs frontier — and does it also lift TRC?
  4. How tight is the amplification inequality? Measuring correlation between compression- and quantization-induced assignment changes would close the gap.
  5. Does calibrating expert-importance quantization on compressed inputs close the miscalibration on rare, high-information experts (§3.3.1)?
  6. What would a real deployment-tuple benchmark look like — prompt mixes, vision-token budgets, precision formats, edge targets that surface B/C failures VQAv2 misses?
  7. Does aggressive compression measurably raise hallucination rate on rare, informationally-dense tokens — a safety question the survey raises but drops.
