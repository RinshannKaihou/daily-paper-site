> **一句话总结：** 本文提出一种针对 LLM 智能体"动作选择"的来源特异性授权审计方法，将上下文因子对每个工具/参数目标分别打标，发现在 450 个受控 next-action 任务中，模型虽然对来源权威性有响应，但在 2.4% [2.1, 3.0] 的有效证据退化对比中仍保留了对未授权证据的敏感性。

> **TL;DR:** This paper introduces a target-specific authorization audit for LLM agent action selection that labels context factors separately for each tool/argument target; across 450 controlled next-action tasks and multiple open-weight models (Qwen3-4B/30B, Mistral-Small-3.2-24B, Llama-3.3-70B, DeepSeek-V2-Lite), trusted vs. untrusted variants produce different actions in 5.4% of competing cases vs. 1.7% of supporting cases, and the retained-invalid error pattern appears in 2.4% [2.1, 3.0] of degradation comparisons, while an explicit authority policy reduces untrusted-competition errors by 5.4 points (14.9% → 9.5%).

## 核心贡献

1. **提出"来源特异性授权审计（target-specific authorization audit）"框架**：将上下文因子对每个工具目标（tool target）和每个参数目标（argument target）独立打标，并定义 Valid / Invalid / Neutral / Excluded 四类标签。审计把"是否相关"与"是否被授权决定该决策"两个判断分开——一个相关证据未必被授权。同一条记录可能授权一个工具选择，却无权决定某个参数（例如陈旧的邮箱不竞争是否调用 `send_email`，但直接竞争 `recipient` 参数）。

2. **组合"匹配来源干预（matched source intervention）"与"受控证据退化（controlled valid-evidence degradation）"两种测试**，用以区分两种不同的现象：模型是否"响应来源权威"（source response）与模型是否"对未授权证据保持行为隔离"（behavioral isolation）。仅看正确率（outcome benchmark）无法区分"稳健的决策"与"碰巧正确的脆弱决策"。

3. **补充一个精确的"部分证据交互诊断（partial-evidence interaction diagnostic）"**：基于 Harsanyi/Shapley 联盟值（coalition analysis）枚举所有子集，量化证据缺位时因子间的非加性依赖，并用"空联盟""全上下文变换"两端锚定其稀疏/完整证据边界。

4. **构建 450 任务诊断套件**（AgentAudit-250 自创工作流任务 + Tau2Audit-100 零售/航空状态 + BFCLAudit-100 函数调用示例），共 1,350 个目标、10,800 个目标-因子标签，并附外部三位 PhD 标注者的独立重标（无效/非无效一致率 85.4%，κ=0.626）。

## Key Contributions

- **Target-specific authorization audit**: a framework that labels each context factor for each tool/argument target separately (Valid / Invalid / Neutral / Excluded), disentangling relevance from authorization. Authorization is target-specific — the same record may authorize a tool choice but be impermissible for one argument.
- **Two-pronged behavioral test**: matched source interventions (full-prompt provenance response) combined with controlled valid-evidence degradation (full / mixed / clean) to separate "responds to authority" from "isolates from unauthorized competitors".
- **Exact partial-evidence interaction diagnostic**: Harsanyi/Shapley coalition analysis with empty-coalition and full-context anchors, explicitly bounded by near-null full-context results and same-role-matched controls.
- **A 450-task diagnostic suite** with external PhD annotator reliability check (invalid/non-invalid agreement 85.4%, κ=0.626; 4-label agreement 0.671, Fleiss κ=0.608).

## Methodology

**三个审计问题**：
- **Source response**：当仅改变证据的来源权威（trusted vs. untrusted）时，模型目标分数与生成动作是否变化？
- **Isolation**：当有效证据被削弱后，未授权的竞争性证据是否仍能改变动作？
- **Localization**：哪些因子组合在部分证据下展现出涉及未授权竞争者的非加性分数依赖？

**目标打标**：对每个目标-因子对做两次判断——权威判断（来源是否被允许决定该目标）与关系判断（是否支持参考目标、提供具体竞争者，或两者皆非）。结构标签：Valid（授权且支持）、Invalid（未授权且提供竞争值/实体/动作/指令/前次动作残留）、Neutral（其余，含"未授权但支持"）、Excluded。

**目标分数**：对固定目标 y 的 token 序列求和的对数赔率 v_y(P) = Σ_t [log q_t(P) − log(1 − q_t(P))]，比较时成对配对、保持字符串与分词固定。

**匹配来源干预**：用文本模板 `Source status: [frame]. Proposition: [text]` 作为来源权威的受控代理（非操作化检索/工具通道），交叉权威 a ∈ {T,U} 与语义关系 r ∈ {S,C}，并报告 same-proposition 控制（同一竞争命题只改变来源标记，看移除效应）。

**受控退化**：对每个有效因子 x，构造 full（含全部因子）/ mixed（仅移除 x）/ clean（移除 x 加全部 Invalid 因子）。主要终点是 mixed-clean 目标不一致；更严格的 retained-invalid 错误模式是 c_F=1, c_M=0, c_C=1（全对、混合错、净对）。

**部分证据交互**：对每个 B ⊆ X，精确计算 Harsanyi 交互 I_y(B) = Σ_{Z⊆B} (−1)^{|B|−|Z|} v_y(Z)。报告三种估计量：空联盟 Harsanyi（稀疏证据）、Shapley 平均（背景联盟）、全上下文变换（完整提示附近删除）。主摘要为"无效因子分配比例"的 observed-minus-null fractional excess。

**数据集与标注**：450 任务（每任务含 8 个可移除因子、1 个工具目标、2 个参数目标），构成 1,350 目标 / 10,800 标签。三位外部 PhD 标注者独立重标 300 个目标包（2,400 标签）。

**模型**：Qwen3-4B、Qwen3-30B、Mistral-Small-3.2-24B、Llama-3.3-70B（主实验）；DeepSeek-V2-Lite（生成动作与护栏实验）；Ministral-8B（same-proposition 控制与扩展实验）。

## Results & Highlights

- **来源响应（同命题控制）**：跨四模型池化，竞争移除效应的 trusted-minus-untrusted gap 为 **+1.15 log-odds [0.97, 1.33]**（Qwen3-4B +1.94，Mistral-24B +1.22，Ministral-8B +0.87，DeepSeek-V2 +0.58），表明模型在完整提示中对文本来源线索有响应。
- **生成动作不一致**：跨五模型，竞争性命题的 trusted→untrusted 不一致率为 **5.4%**，支持性命题为 **1.7%**，差 +3.8 个百分点 [3.2, 4.4]。竞争情境下 1.2% 从对→错，4.0% 从错→对（净纠正，但仍有残余 1.2% 有害翻转）。
- **匹配分数差分（DID）**：authority-by-relation DID 为 **+0.481 [0.413, 0.550]**，每个模型均为正；显式未授权竞争者仍造成目标分数大幅下降（−1.098）。
- **有效证据退化**：跨四模型 12,120 行中，mixed 与 clean 动作在 **24.6%** 行上不同；对齐 Shapley share 预测哪些行改变（AUROC **0.813 [0.798, 0.827]**，最高十分位 vs 最低十分位 71.7% vs 3.8%）。更严格的 retained-invalid 错误模式在 **2.4% [2.1, 3.0]** 行出现（模型间 0.5%–4.1%）。
- **部分证据交互**：Shapley 平均 fractional excess 在全部 12 个模型-数据集 run 中为正（**+0.027**），空联盟端同为 +0.027，但全上下文变换接近其零点（−0.004），明确界定了交互诊断的适用范围。
- **外部标注信度**：四标签完全一致率 0.671（Fleiss κ=0.608）；无效 vs 非无效一致率 **0.854**（κ=0.626）；用重标共识替换作者标签后证据可用性模式仍然保留（空/Shapley/全 any-excess 为 +0.046/+0.049/+0.002），说明结果非标签完全一致的伪影。
- **权威策略护栏效用**：显式 authority policy 将 untrusted-competition 错误率从 **14.9% 降至 9.5%**（5.4 点收益 [4.5, 6.3]），但效果高度异质（Mistral +18.1，Llama +6.3，Qwen +1.6–2.1，DeepSeek −0.9），且未消除来源敏感性本身（5.1% vs 5.4%）。
- **长上下文（12/16 因子）因子筛选**：成对筛选（pairwise）保留 92.0%/87.8% 的无效因子（Top20 0.844/0.811），优于一阶筛选。

## Critical Assessment

本文最大的价值在于把"正确"与"正当"分离：一个工具调用可能 outcome-correct，但目标分数仍敏感于陈旧记忆、邻近记录或未授权备注。三个量化层叠证据支撑了这一论断：
- **分数层**：差异-in-差异 +0.481 [0.413, 0.550]，每个模型都为正——来源权威是真实的因果代理，不是噪声。
- **行为层**：5.4% vs 1.7% 的竞争-支持不一致对比，且"严格 retained-invalid 模式"在 2.4% [2.1, 3.0] 的退化对比中出现，直接证明"移除有效证据后未授权竞争者仍左右动作"。
- **结构层**：Shapley fractional excess 在所有 12 个 run 都为正（+0.027），但全上下文变换接近零（−0.004）——作者诚实地把这一"断崖式"边界作为结论的限定条件，而非掩盖。

三个值得称道的方法论细节：
1. **Same-proposition 控制**（Table 4）是全文最干净的识别设计：同一竞争命题只改来源标记，trusted-minus-untrusted 移除效应 +1.15 [0.97, 1.33] 为正，明确证明模型对文本来源线索的响应，而非操作化通道。
2. **角色匹配控制**逆转了比较（−0.018）：严格用相同语义角色（同为竞争者）的 trusted vs. untrusted 时，差异消失。作者据此正确地把 Shapley 交互诊断为"未授权竞争者的局部化结构"，而非"授权本身的可识别效应"。这是对自家方法的诚实边界声明。
3. **护栏实验（Table 9）**揭示 policy 收益高度异质（Mistral +18.1，DeepSeek −0.9），且来源敏感性几乎不变（5.1% vs 5.4%）——明确驳斥了"policy 是不变量来源过滤器"的乐观解读。

可能被审稿人质疑的点：
- **诊断与部署的差距**：作者反复声明 2.4% 是"受控压力测试率"而非"部署流行率"，但读者可能想知道真实代理系统中"未授权竞争性上下文"的实际密度。
- **同角色控制逆转**：role-matched 控制显示 −0.018，意味着未授权交互的"excess"很大程度上来自"竞争"语义而非"未授权"语义——这削弱了部分关于"授权隔离"的强主张。
- **样本构成偏向性**：AgentAudit-250 为作者自创，可能放大了敏感情境；Tau2/BFCL 转写为静态因子也丢失了真实多轮交互。

## Strengths

- **概念清晰**：把"相关"与"授权"分离，把"响应来源"与"行为隔离"分离，避免了既正确率基准也注入攻击基准的二元框架。
- **目标特异性打标**是真正的方法论创新：同一条记录对工具选择和参数可以有不同授权——这一观察抓住了 agent context 的多层结构。
- **多估计量三角验证**：分数对数赔率 + 生成动作 + Shapley 交互 + 空/全锚变换，相互校验且明确各自范围。
- **可复现性高**：承诺公开数据、标签、提示、代码、种子与重标记录。
- **诚实的边界声明**：在 Abstract、Conclusion、附录 A 反复区分 stress-set 与 deployment rate，明确"非因果中介、非内部推理路径、非部署错误率"。

## Limitations

- **依赖人工因子分解与目标特异标签**：外部重标虽支持聚合稳健性，但不能保证对任意重构不变，也不能保证案例级解释稳定。
- **数据集刻意混合授权与未授权上下文**，因此 2.4% 等速率是受控压力测试测量，而非自然流行率。
- **精确枚举仅对短因子集可行**：8 因子需 256 子集；12/16 因子只能用成对筛选近似，无法证明对带演化记忆、重复工具调用与噪声检索的长轨迹的实用可扩展性。
- **分数审计依赖 open-weight 模型的目标 token 概率**：闭源 API 只能做较弱的生成/forced-choice 代理（附录仅 GPT-4o-mini 能区分高低，见 Table 55）。
- **角色匹配控制逆转比较**（−0.018）与全上下文变换接近零（−0.004）：明确限制了联盟交互诊断的适用范围，未授权 excess 可能主要来自竞争语义而非授权语义。
- 各估计量范围不同（LOO = 直接删除敏感度；matched = 全提示来源响应；Shapley = 部分证据背景），三者不能互相替代。

## Relevance (Chinese)

本文与以下研究方向高度相关：
- **LLM 智能体安全与可信**：与 prompt-injection 防御（Greshake 2023, Debenedetti 2024, Wallace 2024）、AgentDojo、AgentHarm 互补——这些工作关注"攻击是否成功"，本文关注"未授权影响是否存在"（包括良性的陈旧记忆、邻近记录等非攻击性残留）。
- **可解释性与归因**：与 Sundararajan 等（2017）的积分梯度/Harsanyi-Shapley 归因同源，但首次把归因与"授权链"绑定，并明确"影响 ≠ 允许"。
- **Tool-use benchmark**：BFCL、τ-Bench、ToolSandbox、AppWorld 测"是否选对工具/参数"，本文测"工具/参数决策对未授权证据有多敏感"——可作为这些基准的补充维度。
- **Runtime guardrail / 因果归因护栏**：与 AttriGuard（2026）、CausalArmor（2026）、ClawGuard（2026）方向呼应，但本文是评估方法而非护栏本身（Table 9 表明 policy 护栏收益高度异质且不消除敏感性）。
- **法律推理审计（Chen 2024）**：本文是其在 agent 场景的推广，把"相关/无关/禁止"扩展为"目标特异授权链"。

对研究 LLM agent 安全、可解释归因、工具调用正确性与来源可信的读者群体，本文提供了一套可操作的诊断协议与公开数据集，适合作为后续"前置审计"或"对抗鲁棒性"研究的基线。

## Questions for Further Exploration

1. **部署流行率校准**：能否在真实 agent 日志（如企业邮件/客服系统）上测量"未授权竞争性上下文"的实际密度，从而把 2.4% 的压力测试率转换为部署错误率估计？
2. **角色匹配逆转的机理**：为什么 same-role 控制使 fractional excess 变为 −0.018？是因为模型实际只对"竞争语义"敏感而对"来源权威"不敏感，还是因为控制设计本身的统计功力不足？需要更细粒度的 ablation。
3. **闭源模型的代理协议**：除 forced-choice 外，能否设计基于 logit bias API 或多次采样的一致性指标，把本审计推广到 GPT-4o / Claude / Gemini？
4. **训练时而非推理时的修复**：本文 Table 9 的 policy 是推理期提示；若把"来源授权"做成训练目标（如 DPO 负样本为未授权竞争者导致翻转的轨迹），能否同时降低 5.4% 的不一致率与 2.4% 的 retained-invalid 率？
5. **长轨迹与演化记忆**：本文静态因子最多 16 个；能否在多轮 ReAct/A-Mem 轨迹中增量维护 Shapley 近似，识别"哪一轮工具调用引入了未授权依赖"？
6. **跨目标标签的相关结构**：同一因子对工具和参数有不同授权——能否用这种"标签冲突结构"作为攻击面，构造只在特定参数上注入未授权值的更隐蔽注入？
