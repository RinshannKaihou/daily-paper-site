◆ Key Finding

Causal-AgentIR encodes restoration experience as a self-evolving causal memory graph that six cooperating agents read and revise — setting new state-of-the-art across all-in-one, task-specific, real-world, and mixed-degradation benchmarks.

02 Why This Matters

A directly useful template for anyone studying how long-horizon agents accumulate, revise, and forget experience.

Structured memory + six-operation evolution generalizes beyond restoration to tool-using agents at large. Gain is marginal for pure PSNR/SSIM chasers — the win is the memory abstraction and a 63% rollback reduction.

03 Critical Edge

"Causal" is an empirical interventional relation — no counterfactuals, no confounder control, no do-calculus.

The headline gain over the strongest prior agent (IAMAgent) is only +0.31 dB, and the system is openly dependent on GPT-4o for planning, degradation ID, and critique — latency, cost, and memory-graph growth are not reported.

M / 01

Methodology — memory as a graph, not a prompt

Each step emits a joint decision: a restoration action a = (tool, params, mask) and a memory operation, drawn from policy π(a, o | s, G) over the causal graph G.

  • 7 node types — degradation, region, tool, action, quality-change, cost, user-preference.
  • Edges carry (context, estimated quality impact w, confidence γ); retrieval weights by |w| surfaces both helpful and harmful relations.
  • Planning scores candidate plans by path-level causal evidence Γ(P), discounted by cost.
  • Reward includes a memory term Rmem = ΔQ + η·(future-plan utility), so updates serve next planning.

Six-agent hierarchy: planner · degradation · tool · causal-memory · critic · memory-curator. Built on MAIR's harness; 16 frozen public-tool checkpoints — gains come from orchestration, not retrained restorers.

S·L / 03

Strengths & Limitations

Strengths

  • Structured, auditable memory abstraction — far beyond static prompts or text summaries.
  • Jointly optimizes action + memory policy; Rmem explicitly rewards useful updates.
  • Broad evaluation: 4 settings + efficiency/preference metrics + user study + ablation.
  • 63% rollback cut delivers real LLM-agent cost savings, not just PSNR.

Limitations

  • "Causal" is empirical — no counterfactuals or confounder modeling; naming overclaims.
  • +0.31 dB over IAMAgent; loses on denoising (CBSD68 σ=15) and CSD.
  • No memory-graph growth / retrieval-cost / threshold-sensitivity analysis.
  • Hard dependency on GPT-4o; no latency, token-cost, or swap-out study.
  • Tool library fixed and partly self-authored (MHNet, ECFNet, …); fairness & portability questions.
Q / 04

Open Questions

  1. Would upgrading "causal edges" to a true SCM (counterfactuals, do-calculus) meaningfully improve mixed-degradation ordering?
  2. How does the graph scale past 1000 trajectories — does Rel(e|ψ) retrieval need hierarchical / partitioned indexing?
  3. Sensitivity of τQ, τδ, τγ, τw, α, ρ — is there a stable cross-dataset config?
  4. If GPT-4o is swapped for an open 7–13B model for planning & critique, how does the perf/cost curve shift?
  5. Does the rollback drop come from avoiding bad actions, or silently ignoring them — i.e. is the agent becoming over-cautious?
