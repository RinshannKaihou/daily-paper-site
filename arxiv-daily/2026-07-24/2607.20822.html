Methodology

Huber corruption · epoch batching · trimmed-mean Bellman
εR Reward corruption
ε̃tR = (1−Yt,1)·rt + Yt,1·zt
Yt,1 ~ Bern(εR), zt arbitrary
Adversary may substitute the reward with an unbounded value; only the clean Bernoulli draw is benign.
εY State corruption
s̃t+1 = (1−Yt,2)·st+1 + Yt,2·ut
ut ∈ S arbitrary state
Observed next-state can be rewritten to any state — a model of sensor spoofing / log tampering.

BR-Async-Q · per-epoch update (Alg. 2)

  1. Split stream into K epochs of length H, with K = ⌈2 log T / (1−γ)⌉.
  2. Accumulate two datasets per (s,a): Dk(s,a) for rewards; Yk(s,a) of bootstrap values from frozen Qk.
  3. Robust estimates: R̂ ← TRIMH(heavy-tail); μ̂ ← TRIMB on [−B,B] (tightens εY dependence).
  4. Clipped Bellman (Eq. 12): T̂Q = clip[−Gk,Gk](R̂) + γμ̂; update Q synchronously, once per epoch.

Three defensive devices

  1. Epoch batching (Remark 2) — turns high-variance single-sample updates into low-variance batched ones; eliminates the 1/λmin blow-up of prior work.
  2. TRIMH vs TRIMB (Eq. 3–4) — Huber trimmed-mean for unbounded rewards (O(√εR)); clipped mean for bounded bootstrap values (O(εY)).
  3. Clip radius Gk (Eq. 11, Lem. 1) — keeps ‖Qk‖∞ ≤ B uniformly, preventing recursive bias growth.

Strengths

  • First guarantee under joint state + reward corruption — fills the open gap left by [6,7,8].
  • Minimax-optimal in the reward-only sub-case; simultaneously sharpens vanilla Q-learning's λmin dependence.
  • Algorithm is interpretable: batching + trimmed-mean + clipping — three components, each tied to a distinct threat.
  • Theorem 2 self-interprets: statistical term cleanly separated from corruption bias, with point-by-point comparison to [9] and [6].
  • Sims stress-test with extreme (−106/−108) rewards, state resampling, and varying σ².

Limitations

  • Tabular only. Authors explicitly scope to tabular; no function approximation, no path to deep RL stated.
  • Requires known εR, εY as algorithm inputs; in practice the corruption level is unknown. Implicit ε̄ ≤ 1/8.
  • Huber "what-not-when" assumption. Adversary picks what to inject; timing is exogenous Bernoulli — the very thing that lets variance reduction work.
  • i.i.d. data assumption; Markovian extension only sketched via blocking argument [23], not proved in-body.
  • Synthetic grid-world only — no Atari/MuJoCo; small MDP does not probe the λmin→0 regime.
