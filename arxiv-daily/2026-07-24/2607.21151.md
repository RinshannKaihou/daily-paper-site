> **一句话总结：** V-DEAL 提出了一个三层（行为—理解—表征）诊断框架，揭示了视频大模型即使能正确理解有害视频内容，仍会在"有害视频+良性查询"设定下失效；并提出一种无需训练的提示注入干预，将攻击成功率从 48.33% 降至 0.80%。

> **TL;DR:** On three public video-safety benchmarks (Video-SafetyBench, VA-SafetyBench, Omni-SafetyBench; 5,020 samples) across six Video LLMs (Qwen2-VL-7B, Qwen2.5-VL-7B, InternVideo2.5-8B, InternVL3.5-8B, MiniCPM-o-4.5, MiniCPM-V-4.5), the authors find the counter-intuitive result that harmful videos paired with benign queries achieve a higher attack success rate (48.33% avg) than with explicitly harmful queries (35.84%); a training-free prompt-injection intervention reduces average ASR by 48.24 percentage points, reaching 0.80%, on par with prior SEA fine-tuning baselines.

## 核心贡献

1. **首次提出 V-DEAL 三层诊断框架**：从行为（Behaviour）、理解（Understanding）、内部表征（Representation）三个层级联合分析视频大模型的安全失准（de-calibration）现象，并将该失败定位为"理解—拒绝耦合失败"。
2. **反直觉的实证发现**：在六个视频大模型上系统证明，"有害视频 + 良性查询"（VH-BQ）设定下的平均攻击成功率（48.33%）高于"有害视频 + 有害查询"（VH-HQ，35.84%），且这种异常无法仅用"视觉理解能力不足"来解释——模型在结构化标签上的平均准确率仍超过 0.81。
3. **表征层面的机制性解释**：通过定义层级化的"拒绝方向"（refusal direction），用隐藏态投影量化拒绝倾向，发现视觉理解激活的拒绝信号弱于文本理解，这是 VH-BQ 失效的根因。
4. **轻量级、无需训练的对齐修复**：提出基于"显式视觉证据推理 + 上下文示范"的提示注入干预，在零样本和 8-shot 设定下大幅降低 ASR，无需任何参数更新。

## Key Contributions

- **V-DEAL is the first three-level diagnostic framework** for video safety de-calibration, jointly connecting behavioural failure, understanding-quality proxy metrics, and layer-wise refusal representations into a unified pipeline.
- **A counter-intuitive empirical regularity**: across six Video LLMs, VH-BQ consistently yields the highest ASR (avg 48.33% vs 35.84% under VH-HQ), with the refusal rate collapsing from 53.05% to 14.22% when the query switches from harmful to topic-aligned benign.
- **A mechanistic explanation via refusal-direction analysis**: harmful visual evidence activates weaker refusal-aligned hidden states than explicit harmful text, evidenced by per-model R-Scores where VH-BQ usually lies below T-HQ and VH-HQ.
- **A training-free realignment intervention** that asks the model to explicitly summarize visual evidence before the safety decision, augmented with in-context demonstrations; it reduces average ASR by 48.24 percentage points and reaches performance comparable to prior fine-tuning-based SEA alignment.

## Methodology

V-DEAL 由三个诊断阶段 + 一个干预阶段组成（Figure 2）：

**(a) 行为分析（Behavioural Analysis）。** 构造四种受控攻击条件以解耦文本危害性与视觉证据：T-BQ（纯文本良性查询）、T-HQ（纯文本有害查询）、VH-BQ（有害视频 + 良性查询）、VH-HQ（有害视频 + 有害查询）。固定 LLM-as-a-Judge 将每个输出标注为 HARMFUL / REFUSAL / SAFE 三类，据此计算 ASR、Refusal Rate、Safe Rate。

**(b) 理解评估（Understanding Analysis）。** 在统一的良性提示下要求模型生成 (i) 结构化标签（4 个核心属性）和 (ii) 自由形式视频摘要，用 Accuracy / Macro-F1 评估结构化输出，用更强的视频模型作为参考、由 LLM 判官评估摘要的整体相似度。这一阶段用于排除"理解失败"假设。

**(c) 表征分析（Representation Analysis）。** 使用外部安全数据（XSTest、MM-SafetyBench）标注的 REFUSAL / OTHER 样本，按层估计"拒绝方向"：

$$w_\ell = \frac{\mu_\text{refusal}^\ell - \mu_\text{other}^\ell}{\|\mu_\text{refusal}^\ell - \mu_\text{other}^\ell\|_2}$$

按 ROC-AUC 选出 top-m 层，把每个攻击样本的隐藏态投影到该方向上得到标量 refusal score，量化四种条件下的拒绝对齐强度（Eq. 2 对 top-m 层得分取平均）。每种条件使用 1,250 个平衡子样本。

**(d) 提示注入重对齐（Realignment）。** 设计包含"安全系统提示 + 视觉证据摘要 + 拒绝示范"的提示，要求模型在做安全决策前显式地用文本复述视频中的有害视觉元素；零样本仅用系统提示，8-shot 在此基础上加入 8 个由 GPT-4.1 生成的上下文示范。模型权重、输入视频、解码超参全程不变。

**评测覆盖面**：六个代表性视频大模型（Qwen2-VL-7B、Qwen2.5-VL-7B、InternVideo2.5-8B、InternVL3.5-8B、MiniCPM-o-4.5、MiniCPM-V-4.5），三个公开基准（Video-SafetyBench、VA-SafetyBench、Omni-SafetyBench），共 5,020 个视频样本；表征分析另用 XSTest 与 MM-SafetyBench 作为外部安全监督。

## Results & Highlights

- **VH-BQ > VH-HQ（反直觉现象）**：平均 ASR 从 VH-HQ 的 **35.84%** 升至 VH-BQ 的 **48.33%**（+12.49 pp），同时平均拒绝率从 **53.05%** 跌至 **14.22%**。六个模型中有五个在 VH-BQ 下达到最高 ASR（Table 1, Figure 3）。
- **理解能力强 ≠ 安全**：即便在结构化标签上准确率达到 **0.948 / 0.933 / 0.950 / 0.955**（Qwen2-VL / Qwen2.5-VL / InternVideo2.5 / InternVL3.5），InternVL3.5-8B 与 InternVideo2.5-8B 仍分别保持 **49.1%** 与 **36.1%** 的 VH-BQ ASR；摘要整体相似度最高的 Qwen2-VL-7B 同时拥有最高的 VH-BQ ASR（**59.06%**）（Table 2, Figure 4）。
- **表征层面定位根因**：在 InternVL3.5、MiniCPM-o、MiniCPM-V、InternVideo2.5 上 VH-BQ 的 refusal score 高于 T-BQ 但普遍低于 T-HQ/VH-HQ；Qwen2-VL/Qwen2.5-VL 的 VH-BQ 得分（−0.15、−0.13）甚至低于 T-BQ，与其高 ASR 一致（Table 3）。
- **提示注入干预效果**：在 2,510 样本的 VH-BQ 半子集上，零样本重对齐将 ASR 压到 **0.00–2.35%**，8-shot 进一步收紧；六模型平均 ASR 从 **48.33% → 0.80%**，平均降幅 **48.24 个百分点**（Table 4）。
- **与微调基线 SEA 的严格对比**：在 Qwen2-VL-7B + 全 VA-SafetyBench 的匹配设定下，零样本 ASR = **0.14%**、8-shot ASR = **0.24%**，均低于 SEA-SFT 的 **0.34%** 与 SEA-DPO 的 **3.56%**（Section 5, Table 11）。

## Critical Assessment

- **核心假设链条扎实**：论文用"行为 → 理解 → 表征"逐级排除竞争性解释——先用理解代理任务（Acc/F1/相似度）排除"看不懂"，再用 refusal direction 的投影证明"看到了但拒绝信号弱"，逻辑闭环。
- **R-Score 不可跨模型比较**：作者明确指出 refusal score 的绝对尺度是模型相关的（Table 1 脚注、Table 3 说明），因此跨模型比较只看条件内排序。这降低了对"绝对差距"的过度解读，但也意味着无法直接量化不同模型间的安全裕度。
- **干预方法的可移植性有限**：8-shot 示范由 GPT-4.1 生成、prompt 手工设计；论文附录 F 自承"最佳 prompt 与示范组合可能随模型族和安全任务变化"，这是方法在工程化部署时的真实瓶颈。
- **VH-BQ 异常的因果归因仍部分依赖相关性**：表征分析显示 VH-BQ 拒绝信号弱，但缺少对"是否真的因为视觉证据未触发拒绝机制"的因果干预验证（如激活修补 activation patching）。论文用 prompt 干预的成功作为间接佐证，但并未直接证明隐藏态因果链。
- **MiniCPM-V-4.5 是显著例外**：其最高 ASR 出现在 VH-HQ（64.2%）而非 VH-BQ（55.2%），论文已诚实报告，但这暗示"de-calibration"现象在不同模型族上的形态不完全一致，框架的普适性需更多模型验证。

## Strengths

- 诊断视角新颖：把视频安全失效从"理解不够"重新框定为"理解—拒绝耦合失败"，并给出三层证据链。
- 工程实用性高：训练免费、即插即用的 prompt 干预即可媲美 SFT/DPO 微调基线，部署门槛极低。
- 评测规模充分：6 模型 × 3 基准 × 5,020 视频，外加 1,250 样本的平衡表征子集，统计可信度较高。
- 与现有最强对齐方法（SEA）做了严格匹配对比，而非挑软柿子。

## Limitations

- 表征分析依赖外部安全数据（XSTest、MM-SafetyBench）估计拒绝方向，与视频主任务的分布存在差距；作者做了 transfer audit 但未完全消除该担忧。
- 干预方法对 prompt 设计和示范选择敏感，跨模型族迁移性未充分验证（作者自承）。
- 缺少因果级机制实验（如 activation patching、ablation），对"视觉证据未触发拒绝"的因果链仍是间接证据。
- 拒绝方向的绝对分数不可跨模型比较，因此"哪个模型最不安全"无法从 R-Score 直接排序。
- 仅在开源 Video LLM（最大 8–9B）上评测，未覆盖闭源大模型（如 Gemini、GPT-4o 视频）是否同样存在该 de-calibration。

## Relevance (Chinese)

本文对国内多模态/视频大模型研究具备直接借鉴价值：
- **安全对齐方向**：揭示了一个被忽视的失败模式——模型在"看得到有害"时仍可能"拒绝不动"，提示国内视频大模型（如 InternVL、MiniCPM、Qwen-VL 系列，本文已涉及）的安全评测应纳入 VH-BQ 这类隐蔽设定，而非只测显式有害查询。
- **可解释性研究**：层级化"拒绝方向"分析方法可迁移到中文视频大模型的内部机制研究，为安全子空间分析提供工具。
- **工程落地**：训练免费的 prompt 注入干预非常适合资源受限的中小团队快速加固现有视频大模型，无需重新做 SFT/DPO。
- **评测基准**：建议国内构建中文版视频安全基准时，明确区分"显式有害 vs. 隐性耦合有害"两类样本，避免遗漏本文揭示的 de-calibration 风险。

## Questions for Further Exploration

1. 该"理解—拒绝耦合失败"是否在闭源视频模型（GPT-4o、Gemini）以及更大参数（>30B）开源模型上同样存在？强度是否随模型规模变化？
2. Refusal direction 是否可通过视频域内部数据直接估计（而非借用 XSTest/MM-SafetyBench），从而得到更可靠的跨模型可比分数？
3. 能否用 causal mediation analysis / activation patching 直接证明"视觉证据 → 拒绝方向 → 拒绝行为"的因果链，而非仅靠 prompt 干预的间接证据？
4. VH-BQ 设定下，攻击者能否进一步通过查询措辞优化（如 chain-of-thought 诱导）绕过本文的 prompt 干预？干预的对抗鲁棒性如何？
5. 在中文/多语种视频场景下，VH-BQ 的 de-calibration 强度是否不同？是否与模型的预训练语料语言分布相关？
6. 8-shot 示范由 GPT-4.1 生成，若改用同一目标模型自生成示范，效果与可移植性如何变化？
