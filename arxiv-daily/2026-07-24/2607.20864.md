> **一句话总结：** 作者发布开源工具 inspect_permute（inspect_ai 扩展），对 4 个厂商 × 5 个 MMLU 学科共 24,000 次 API 调用进行穷举式答案位置置换测试，发现位置偏差仅在 60–95% 基础准确率的“金发姑娘区”内可被卡方/Cramér's V 统计检测，且检测到的偏差分为单调递减（processing_load）和非单调 D 位下降（content_ambiguity）两种机制——前沿模型（Gemini-2.5-flash、Grok-3）在标准 MMLU 上无信号并非“无偏差”，而是基准已饱和。

> **TL;DR:** This paper introduces inspect_permute, an open-source inspect_ai extension that runs exhaustive k! answer-order permutations per question and reports chi-squared / Cramér's V signatures of position bias with bootstrap CIs; applying it across 4 vendors × 5 MMLU subjects (24,000 temperature-0 calls, pre-registered via SHA-256 hash), it finds position bias is statistically detectable only in a 60–95% base-accuracy "Goldilocks zone," separates into two distinct mechanism shapes (monotone processing_load with V up to 0.18 on gpt-4o-mini, non-monotone content_ambiguity on haiku-4-5), and that frontier-tier models (gemini-2.5-flash, grok-3, all V ≤ 0.06) sit above the detection band so their "no bias" reading is actually "not measurable on this instrument."

## 核心贡献

- **inspect_permute 开源工具**：作为 inspect_ai 框架的 drop-in 扩展，实现 k! 穷举式（或采样式）答案位置置换，自定义 scorer 记录每次运行的 presented position、picked position、permutation vector、epoch 与 options 数，并提供 chi-squared、Cramér's V、Spearman ρ 与 bootstrap 95% CI 报告。MIT 许可，31 个单元测试、99% 行覆盖，并由本次 24,000 次真实 API 调用验证。
- **首个跨厂商跨学科的穷举置换实证扫描**：4 个厂商（gpt-4o-mini、claude-haiku-4-5、gemini-2.5-flash、grok-3）× 5 个 MMLU 学科（elementary_mathematics、college_mathematics、formal_logic、professional_medicine、philosophy），50 题/学科 × 24 置换 = 24,000 次 temperature-0 API 调用，构造了首张可比较的厂商 × 学科偏差矩阵。
- **轻量级预注册协议**：将 falsifier 预测与每格预期 V 范围写入 preregistration.md，在观测到一半数据之前以 git tag + SHA-256 哈希 + LinkedIn 公开时间戳的方式锚定，可由任何第三方用三条 shell 命令验证，不依赖 registered-report 期刊。
- **三段式能力—可检测性模型（Goldilocks zone）**：偏差仅在某 60–95% 基础准确率带内统计可检测；低于此带被 processing-load 主导淹没，高于此带被 ceiling 效应压缩，与作者前作 arXiv 2606.26185（ceiling 端）共同从上下两端界定了可检测窗口。
- **两种可分离的机制签名**：单调 A→D 下降（processing_load，ρ = −1.0，gpt-4o-mini 4 个单元全部出现）与非单调 D 位下降（content_ambiguity，ρ ≈ −0.40，仅 haiku 两个学科出现），用 V × ρ 平面给出单一可视化区分。
- **诚实披露并修正分类器缺陷**：v0.1 预注册分类器被 grok-3 × elementary_mathematics 边界例（V = 0.058、ρ = −0.32、p = 0.26）暴露盲点，作者公开瑕疵并新增 p ≥ α 门控的精修版（classify），保留 v0.1 为 classify_preregistered 以确保复现性；预注册命中率以未修改的 v0.1 计算（V 范围 6/10、机制类 5/10）。
- **评估生态成本不对称**：相同协议在 Gemini-2.5-flash 上平均耗时为 GPT-4o-mini 的 7.5×（峰值 18.5×），将这种不对称识别为“评估生态被厂商定价”的结构性问题。

## Key Contributions

- **inspect_permute open-source package**: A drop-in extension to the inspect_ai framework implementing exhaustive (or sampled) k! answer-order permutation as a `permute_choices` solver, a `position_bias_score` scorer that records per-run position metadata, and a `generate_bias_report`/`shape_diagnostics` module producing chi-squared, Cramér's V, Spearman ρ and 1,000-resample bootstrap 95% CIs. MIT-licensed, validated by 31 unit tests (numerical reference + adversarial edge cases) with 99% line coverage and 24,000 real API calls.
- **First cross-vendor, cross-subject exhaustive-permutation sweep**: A 4 × 5 matrix (gpt-4o-mini, claude-haiku-4-5, gemini-2.5-flash, grok-3 × elementary_mathematics, college_mathematics, formal_logic, professional_medicine, philosophy), 50 questions × 24 permutations = 24,000 temperature-0 API calls, producing the first comparable vendor × subject position-bias matrix.
- **Lightweight, venue-free preregistration protocol**: Falsifier rules and per-cell expected V ranges committed to a git tag (`preregistration-amended-2026-06-30`, commit `ad33083`), with the file's SHA-256 hash publicly posted on LinkedIn (2026-06-30 16:28 JST) before Google/xAI cells were observed; verifiable by any third party in three shell commands.
- **Three-band capability / Goldilocks-zone framework**: A post-hoc (clearly labelled) model stating that position bias is statistically detectable only inside a roughly 60–95% base-accuracy band, bounded above by ceiling effects (Tamba 2026a, arXiv 2606.26185) and below by processing-load dominance.
- **Two-mechanism shape taxonomy**: Monotone A→D decrease (`processing_load`, Spearman ρ = −1.0, all four active gpt-4o-mini cells) versus non-monotone D-drop (`content_ambiguity`, ρ ≈ −0.40, both active haiku cells), separable in the V × ρ plane and invisible to a chi-squared p-value alone.
- **Transparent classifier refinement**: The v0.1 preregistered classifier's blind spot exposed by the grok-3 × elementary_mathematics boundary cell (V = 0.058, ρ = −0.32, p = 0.26) is disclosed rather than silently fixed; an explicit `p ≥ α` gate is added in `shape_diagnostics.classify`, while `classify_preregistered` preserves the original rule so the verification metric (V-range hits 6/10, class hits 5/10) is honestly degraded.
- **Wall-clock cost asymmetry as an eval-ecosystem problem**: Identical protocol costs 7.5× average / 18.5× peak more wall-clock on gemini-2.5-flash than gpt-4o-mini, driven by reasoning-token fraction (85% on Gemini college_math), framing this as a structural capture of independent evaluation rather than a per-study side note.

## Methodology

The diagnostic is built on three design choices. First, instead of a single answer-order shuffle (which confounds genuine position bias with question-level content noise and sampling stochasticity), `inspect_permute` runs all k! permutations per question by reusing inspect_ai's `epochs` parameter: in exhaustive mode, epoch e maps deterministically to permutation index `(epoch - 1) % k!`, so `Epochs(k!)` enumerates every ordering exactly once; in sample mode the permutation is drawn from a `(seed, sample_id, epoch)` triplet via Python's `Random`, giving reproducible partial coverage. The solver preserves inspect_ai's `original_position` invariant so the framework's built-in unshuffling still works and the permutation is reconstructable from logs alone. Second, the report uses Pearson's chi-squared on the (presented position of correct answer) × (correct/incorrect) contingency table for a calibrated yes/no, plus Cramér's V (= √(χ²/N) for these k × 2 tables) as a sample-size-invariant effect size for cross-cell comparison (Yates correction deliberately avoided for dof ≥ 2). Third, a shape diagnostic adds Spearman ρ between presented position and per-position accuracy to distinguish monotone (ρ → −1) from non-monotone (ρ near 0) profiles; ρ is used descriptively (with k = 4 positions the Spearman test cannot reach significance), and cells are classified `inactive` if V < 0.05 or p ≥ 0.05, `processing_load` if V ≥ 0.05 ∧ ρ ≤ −0.5 ∧ p < 0.05, `content_ambiguity` otherwise.

The empirical sweep applied this across 4 vendors × 5 MMLU subjects, 50 questions per subject, 24 permutations each = 24,000 API calls at temperature 0, `max_connections=10`, `retry_on_error=2`. Falsifier predictions and per-cell expected V ranges were locked in `preregistration.md` whose SHA-256 hash was posted on LinkedIn before the Google/xAI cells ran. Robustness was checked by re-running all five Anthropic cells after a credit-exhaustion interruption (max |ΔV| = 0.0058) and by a 3 × 3 sensitivity sweep over `Vfloor ∈ {0.04, 0.05, 0.06}` and `ρprocessing ∈ {−0.4, −0.5, −0.6}` (Appendix B).

## Results & Highlights

- **gpt-4o-mini shows significant position bias on 4 of 5 subjects**, with Cramér's V from 0.10 (professional_medicine) to 0.18 (elementary_mathematics and formal_logic); college_mathematics is the exception (V = 0.08, p = 0.057). Every active gpt-4o-mini cell is classified `processing_load` with Spearman ρ = −1.0; in formal_logic, accuracy falls from 0.73 at position A to 0.50 at position D — a 23-point gap inside the same question under different orderings.
- **claude-haiku-4-5 shows significant bias on only 2 of 5 subjects** — elementary_mathematics (V = 0.10) and philosophy (V = 0.09) — both classified `content_ambiguity` (ρ = −0.40), with accuracy near ceiling at A/B/C (0.94–0.99) and a 3–6 point drop only at position D; the other three subjects return V ≤ 0.05 and p > 0.4.
- **gemini-2.5-flash and grok-3 show no detectable bias on any subject** (all V ≤ 0.05 for Gemini with p > 0.45; all V ≤ 0.06 for Grok), but every one of these cells sits at base accuracy ≥ 0.95, i.e. above the Goldilocks band — so the reading is "not measurable on this instrument," not "model is unbiased."
- **Goldilocks zone (60–95% base accuracy)**: every cell with detected bias lies inside this band; outside it on the high side, 12 cells cluster below V = 0.05. The relationship between accuracy and bias intensity is non-monotonic (gpt-4o-mini × formal_logic at 0.61 and gpt-4o-mini × elementary_math at 0.81 both reach V = 0.18).
- **Preregistration verification**: Falsifier 1 (college_math null across all vendors: V < 0.10 ∧ p > 0.05) CONFIRMED (observed V = 0.08/0.03/0.02/0.02); Falsifier 3 (flagship ceiling on elementary_mathematics: V < 0.10) CONFIRMED (V = 0.05 Gemini, V = 0.06 Grok); Falsifier 2 (philosophy non-monotone for flagships) INCONCLUSIVE because neither flagship showed detected bias. Per-cell V-range prediction hit rate 6/10, mechanism-class hit rate 5/10.
- **Robustness**: After Anthropic credit exhaustion mid-sweep, the re-run of all five haiku cells gave max |ΔV| = 0.0058 (formal_logic), with philosophy agreeing to four decimals (V = 0.0909) and per-position accuracy agreeing within 0.003; classifier labels are invariant across the full 3 × 3 threshold sensitivity sweep except for the disclosed boundary cell.
- **Wall-clock cost asymmetry (exploratory)**: per-cell averages ~2.0 min (gpt-4o-mini), ~4.3 min (haiku), ~15 min (gemini-2.5-flash, range 5–37 min), ~5 min (grok-3); 7.5× average / 18.5× peak asymmetry, tracking the reasoning-token fraction (85% on Gemini college_math vs 0% on OpenAI/Anthropic).

## Critical Assessment

- **Novelty**: The exhaustive-permutation idea is not new in spirit (the author credits it as the "natural alternative" to single-shuffle protocols), but packaging it as a drop-in inspect_ai solver with V + ρ shape diagnostics, plus the cross-vendor matrix and the Goldilocks-zone framing, is a genuine methodological increment. The two-mechanism taxonomy (processing_load vs content_ambiguity) is a useful sharpening of distinctions previously blurred in Zheng/Pezeshkpour/Wang et al.
- **Rigor**: Strong on measurement hygiene — temperature 0, deterministic permutation-to-epoch mapping, 1,000-resample bootstrap CIs on both V and ρ, sensitivity sweep over thresholds (Appendix B), and an actual re-run to bound residual nondeterminism (max |ΔV| = 0.0058). The disclosure of the v0.1 classifier flaw via the grok-3 × elementary boundary cell, with the original rule preserved as `classify_preregistered`, is exemplary transparency.
- **Reproducibility**: High. Package on PyPI/GitHub under MIT, 31 unit tests with 99% coverage, eval logs and matrix.json committed at git tag `sweep-complete-2026-06-30` (commit `af8bd08`), preregistration verifiable in three commands. The main residual is provider-side temperature-0 nondeterminism, which is bounded rather than eliminated.
- **Significance**: The central reframing — "no signal ≠ no bias when the benchmark is saturated" — is conceptually important for how the field reads vendor no-bias claims. However, the practical reach is constrained: only 5 MMLU subjects, only 50 questions each, and only the cheaper model tier of each vendor; the flagship tier (GPT-5, Opus 4.8, Gemini 3 Pro, Grok 4) is explicitly out of scope.
- **Red flags**: (1) The Goldilocks-zone framework and three-band model are post-hoc, derived from the same matrix used to evaluate them, and the author labels them as such — but the confirmatory force of the falsifiers is limited because two of three are "null" predictions and the third is inconclusive. (2) The author references their own unpublished/concurrent manuscripts (arXiv 2606.26185 and SSS-26-291) as load-bearing context, which a reader cannot independently verify at submission time. (3) 50 questions × 5 subjects is a thin base for claiming benchmark-level generality; the author concedes this. (4) Reasoning-trace vendors showing no bias could reflect "bias laundering" inside the trace, which the scorer cannot inspect — the author flags this but it materially weakens any strong claim about Gemini/Grok.

## Strengths

- Exhaustive k! permutation (24 calls/question for k = 4) eliminates the unobserved-permutation confound that single-shuffle studies inherit by default, and the deterministic epoch-as-permutation-slot trick keeps it a strict drop-in for inspect_ai.
- Combined chi-squared (calibrated decision) + Cramér's V (effect size) + Spearman ρ (shape) reporting cleanly separates the two bias mechanisms that a p-value alone compresses away.
- Lightweight preregistration protocol (git tag + public hash + on-disk matrix snapshot) is portable to any researcher without registered-report venue access, and the falsifier decision rules are reproduced verbatim with explicit hit/miss scoring.
- Honest self-disclosure: the v0.1 classifier flaw, the 5/10 mechanism-class miss rate, and the credit-exhaustion interruption are all reported rather than hidden.
- The "cost asymmetry as eval-ecosystem capture" framing connects a technical wall-clock observation to a structural critique of who can afford to evaluate frontier models.

## Limitations

- Only one benchmark family (MMLU) with only five subjects and 50 questions each; whether the Goldilocks-zone thresholds and band widths transfer to BBH, AGIEval, GPQA Diamond, FrontierMath, or TruthfulQA is untested, and the author explicitly calls this out as the most important caveat.
- The floor edge of the Goldilocks zone (accuracy < 0.60) is predicted by extrapolation but not directly observed — the lowest base accuracy in the sweep is 0.61 (gpt-4o-mini × formal_logic).
- The framework's headline structure (three-band model, Goldilocks zone) is post-hoc relative to the preregistration, so its evidentiary status is exploratory rather than confirmatory.
- Reasoning-trace vendors (gemini-2.5-flash, grok-3) show no detectable bias, but the scorer cannot see the reasoning trace; "bias laundering" (biased reasoning, overridden surface output) cannot be ruled out without trace access.
- Only the smaller/cheaper model from each vendor is tested; frontier-tier models that MMLU cannot resolve (GPT-5, Opus 4.8, Gemini 3 Pro, Grok 4) are explicitly out of scope and require institutional pre-deployment access.

## Relevance

对于关注 LLM 评测方法论与基准可信度的研究者，本文提供了可直接复用的开源置换诊断工具（inspect_permute）以及一个可证伪的“偏差可检测性取决于模型—基准对的准确率区间”的框架，对评估厂商“无位置偏差”声明、设计校准过的评测协议、以及理解推理链模型给独立第三方评估带来的成本不对称问题都有直接借鉴价值。

## Questions for Further Exploration

- Does the Goldilocks-zone width and the 0.60 / 0.95 thresholds replicate on non-MMLU benchmarks designed to put frontier models inside the band (GPQA Diamond, FrontierMath, harder BBH splits)?
- Is the absence of position bias in gemini-2.5-flash and grok-3 a genuine mitigation, ceiling saturation, or "bias laundering" inside the reasoning trace — and can a `position_bias_score` variant that consumes vendor-exposed reasoning metadata settle this?
- Does the `content_ambiguity` mechanism (D-drop) generalize beyond haiku's elementary_mathematics and philosophy cells, and what intrinsic subject property (decision noise, option plausibility overlap) predicts its appearance?
- How does the wall-clock cost asymmetry (7.5× average, 18.5× peak) scale with reasoning-trace length on next-generation frontier models, and does it materially shrink the set of independent parties able to replicate bias sweeps?
- Can the planned `diagnose_band` scout (two orthogonal permutations × 25 questions ≈ 1% of a full sweep) reliably classify cells into high/middle/low bands without contamination from the very bias it scouts for?
