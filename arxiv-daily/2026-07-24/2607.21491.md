> **一句话总结：** 作者把概念电路提取法扩展到 2×2 设计（Python/Rust × Qwen2.5-Coder-7B/DeepSeek-Coder-V1-6.7B，58+57 个语法概念），发现"哪些概念拥有专属电路"由任务决定（跨模型 Spearman ρ≈0.65，p<10⁻⁷），"电路位于哪些层"和"电路如何随层增长"由模型决定（两模型处理带宽相差 12–13 层），从而把"电路是否具有普适性"这个二分问题分解为三个轴向上的不同答案。

> **TL;DR:** This paper extends a concept-circuit extraction method to a 2×2 design (Python/Rust × Qwen2.5-Coder-7B/DeepSeek-Coder-V1-6.7B), measuring 58 Python and 57 Rust grammatical concepts identically in all four cells. It shows that "what earns circuitry" is task-determined (Spearman ρ = 0.638/0.673, p < 10⁻⁷) and transfers across models, but "where" circuits sit (Qwen late ~L17–19 vs DeepSeek early L6–7, a 12–13 layer gap) and "how" they grow (Qwen's early spike vs DeepSeek's smooth onset) are model-determined and do not. On the Python concept-fraction benchmark, Rust constructs receive 2.1–2.9× more concept-specific circuitry than Python equivalents, and DeepSeek shares 1.94× more cross-language neurons than Qwen.

## 核心贡献

- 提出"什么 / 在哪里 / 如何"（What/Where/How）的三轴分解框架，把以往只能用单一相似度（如 CKA）或 yes/no 判定的"电路普适性"问题，拆分成可独立测量的三个维度，使跨模型比较获得了统一的"概念清单"作为公共标尺。
- 把 Wilam (2026) 在稀疏 8 层 Python 模型上提出的"提取—边缘化"概念电路方法，迁移到两个密集的生产级代码大模型（Qwen2.5-Coder-7B、DeepSeek-Coder-V1-6.7B）和两种语言（Python、Rust）上，证明方法在跨架构、跨语言下仍然可用。
- 给出经验性结论：跨模型一致性的强度并非任意，而是落在 ρ ≈ 0.65 这一"中等偏强"的区间——介于独立与恒等之间，定量回答了此前无人测量过的"概念级跨模型一致度有多高"问题。
- 发现 Qwen 把 Rust 的类型与 trait 机制（Enum、Send、Option、Copy、Eq、Drop 等 9 个跨 4 个语法类的关键词）绑定成单一紧致神经元簇（组内 Jaccard 0.535，置换零假设 0.112，p < 0.001），恢复出一个表面语法不可见的语义维度。
- 用因果消融（双分离）和线性探针几何地验证了所提取电路的功能性：4 个概念（Import/Try/While/Assert）干净通过，探针在 Qwen 全部 28 层均达到 97.6–99.7% 准确率。

## Key Contributions

- Introduces a What/Where/How decomposition that splits the single yes/no "are circuits universal?" question into three independently measurable axes — what concepts earn circuitry, where in the layer stack circuits sit, and how circuits build up across layers — each of which can receive a different answer.
- Extends the extraction-and-marginalisation concept-circuit method of Wilam (2026) from a sparse 8-layer Python transformer to two dense production code models (Qwen2.5-Coder-7B, DeepSeek-Coder-V1-6.7B) crossed with two languages (Python, Rust), measuring 58 Python and 57 Rust grammatical concepts identically in all four cells.
- Empirically pins down cross-model agreement on the concept-fraction ranking at Spearman ρ = 0.638 (Python) and 0.673 (Rust), both p < 10⁻⁷ — a moderate, far-from-unity value that quantifies universality rather than asserting it.
- Discovers that "where" and "how" are model-determined: Qwen processes concepts in a late band (~L17–19) while DeepSeek processes them at L6–7 (a 12–13 layer gap that holds for both languages), and Qwen gives atomic concepts an early spike at L2–3 (early-bias 0.73–0.90) absent in DeepSeek (0.05–0.11).
- Finds that Rust constructs receive 2–3× more concept-specific circuitry than Python equivalents in both models (Qwen 2.91×, DeepSeek 2.07×), and that DeepSeek shares 1.94× more cross-language neurons than Qwen — a direction no prior result predicted.
- Shows Qwen binds nine Rust type-and-trait keywords into a single tightly cohesive neuron cluster (within-group Jaccard 0.535 vs permutation null 0.112, p < 0.001), recovering a type-theoretic semantic dimension invisible in surface syntax and the AST.
- Validates the decomposition causally (double dissociation zero-ablation) and geometrically (per-layer logistic probes), and releases a fully reproducible pipeline where every figure and number regenerates from frozen artifacts without rerunning a model.

## Methodology

The paper uses a **2×2 factorial design**: two languages (Python, Rust) crossed with two independently trained code models (Qwen2.5-Coder-7B, DeepSeek-Coder-V1-6.7B). This is the smallest design that can separate task-dependent, language-dependent, and model-dependent variation. The unit of analysis is a structured **concept inventory** — 58 testable Python AST/builtin concepts and 57 testable Rust constructs — measured identically in all four cells. Formal languages are chosen because the grammar fixes the inventory in advance, and only "testable" constructs (whose keyword token can also appear outside its structural role) are kept, since the contrast requires that.

The pipeline has five stages:

1. **Prompt generation.** For each concept, two prompt families are written: *concept prompts* place the construct in its structural role, *checker prompts* place the same keyword token outside that role (in strings, comments, variable names). Fifty prompts per (concept, context) pair, with variance injected along lexical, structural, and padding dimensions, so marginalisation washes out incidental features.
2. **Extraction.** Each prompt passes through the model once; forward hooks record the MLP output at the last token position of every layer.
3. **Binarisation.** A neuron is active if |activation| > ε; the authors sweep ε ∈ {0.001, 0.1, 0.5} and use ε = 0.5 throughout (the only level at which structural signal emerges for these dense SwiGLU models). A second 80%-consistency filter is inert for these models and does no work.
4. **Marginalisation.** The universal mask A for a concept (e.g. Python `For`) is the intersection of active-neuron sets across many prompt variations (e.g. for loops over list, dict, range), which integrates out the varied dimensions and leaves the concept. The checker mask B is built analogously.
5. **Decomposition.** Concept-only = A \ B, shared = A ∩ B, token-only = B \ A. The **concept fraction** |A \ B| / |A| is the central per-concept measurement, yielding a dataset indexed by concept × layer × model × language.

Downstream analyses use standard tools: Spearman correlation for cross-model agreement; Ward-linkage clustering with a permutation null over pairwise Jaccard similarity; zero-ablation against a size-matched random null for causal validation; and logistic-regression probes with cosine comparison for geometric validation. The architecture cleanly separates extraction (run once, frozen artifacts), analysis (seconds, CPU), and presentation (one script per figure), with all code and data released.

## Results & Highlights

- **What transfers, where and how do not.** Cross-model Spearman correlation of the concept-fraction ranking is ρ = 0.638 for Python and 0.673 for Rust, both with p < 10⁻⁷ (Table 1, 58 and 57 concepts respectively). Flow-type classifications agree at 88.6% (Python) and 85.1% (Rust) across the two models.
- **Layer placement is model-determined, with a 12–13 layer gap.** Qwen concentrates concept-specific processing in a late band (Python ~L19, Rust ~L17), while DeepSeek concentrates it at L6–7 for both languages — a roughly 12–13 layer offset that holds within each model across both languages (Figure 2).
- **Circuit-growth dynamics are model-determined.** For the six Python atomicity concepts, Qwen shows a sharp early spike at layers 2–3 (early-bias 0.73–0.90), while DeepSeek's circuits are near-empty until layers 10–12 then climb smoothly (early-bias 0.05–0.11) (Figure 3).
- **Rust earns 2–3× more concept-specific circuitry than Python**, in both models and the same direction: mean concept fraction Qwen 0.215 vs 0.074 (2.91×) and DeepSeek 0.201 vs 0.097 (2.07×) (Table 2).
- **Cross-language neuron sharing is model-determined in magnitude.** DeepSeek shares 1.94× more cross-language neurons than Qwen; all 7 of 7 construct pairings pass the 10% threshold in DeepSeek, versus 6 of 7 in Qwen (function definition fails at 3.8%) (Table 3, Figure 4).
- **Rust type-and-trait cluster (Qwen × L14).** Within-group Jaccard cohesion 0.535 against a permutation null of 0.112, p < 0.001; two other hypothesised groups are only marginally significant (p = 0.044, 0.035) and the control-flow/module group is random (p = 0.292) (Figure 6).
- **Causal double dissociation (Qwen × Python).** Four concepts — Import (Δ = −0.054 vs null −0.007), Try (−0.053 vs +0.066), While (−0.051 vs +0.042), Assert (−0.032 vs +0.004) — pass cleanly; FunctionDef and For are marginal; Break fails (−0.032 vs a null of −0.066) (Table 4).
- **Linear probes agree geometrically.** Per-concept, per-layer logistic-regression probes hit 97.6–99.7% accuracy at every one of Qwen's 28 layers for the 24 keyword-bearing AST concepts; pairwise probe-direction cosine correlates with concept-only Jaccard at Pearson r = 0.645 (peak L20, 276 pairs) (Figure 11).
- **Compute footprint.** Extraction is ~160k forward passes per cell × 4 cells ≈ 24 GPU-hours on a single A100 (40 GB) via Google Colab Pro+; probes and ablation add ~2 GPU-hours; all analysis runs on CPU in seconds.

## Authors & Credibility

Single-author paper by **Piotr Wilam** (University College London). The work directly extends the author's prior CSP-Atlas method (Wilam, 2026, arXiv:2605.24603), so the methodological lineage is consistent and the extension is natural rather than borrowed. Reproducibility is treated as a first-class deliverable: code is released at `github.com/piotrwilam/Atlas2x2` (Apache-2.0, release v1.0.0) and frozen artifacts at `huggingface.co/datasets/piotrwilam/Atlas2x2` (CC-BY-4.0); `tests/test_paper_numbers.py` locks every cited number to ±0.005 and each figure regenerates from a named script. Statistical claims come with explicit p-values and permutation nulls rather than being asserted. The honest framing of negative or marginal results (Break failing ablation, marginal clusters, the degenerate consistency parameter) and the explicit scope statement ("All claims are scoped to this 2×2") strengthen credibility. The work has not (yet) been peer-reviewed at the time of the arXiv posting.

## Critical Assessment

- **Novelty.** The conceptual move — splitting "universality" into What/Where/How and showing they receive different answers — is genuinely novel and directly addresses a gap the paper motivates well: prior universality work (Olah 2020; Gurnee 2024; Huh et al.'s Platonic Representation Hypothesis) and cross-model similarity work (CKA) cannot separate content agreement from layer-placement divergence. The 2×2 design is the minimal one that exposes the separation.
- **Rigour.** Generally high: permutation nulls, locked paper numbers with a test suite, and a double-dissociation causal check. However, the causal validation covers **only one of the four cells** (Qwen × Python), explicitly because DeepSeek's build-and-hold profile has no clean peak layer — so the cross-model "How" claims, the 1.94× sharing ratio, and the DeepSeek-specific meta-circuit statistics rest on correlational and geometric evidence only, not on causal intervention. The paper is honest about this but it remains the largest gap between claim and evidence.
- **Reproducibility.** Strong. Frozen artifacts, auto-fetching loaders, a paper-numbers test suite, single-A100 compute, and per-figure regen scripts. The main threat is that "DeepSeek-Coder-V1-6.7B" is a specific checkpoint; anyone reproducing must pin the exact revision.
- **Significance.** The operational takeaway — "concept-level interpretability transfers across models, layer-level interpretability does not, so re-localise per model" — is actionable for practitioners. The dimensionality claim (six measurements collapse into two coherent processing styles) is interesting but, as the author concedes, **cannot be tested with only two models**; it is a hypothesis the fingerprint licenses, not a result.
- **Red flags / data quirks.** (1) The 80%-consistency filter is admitted to be **degenerate** (inert) for these dense SwiGLU models, so the effective sweep is over ε alone, and the choice of ε = 0.5 is justified post hoc by "structural signal emerges here" rather than by an independent criterion — a degree of freedom that could shift absolute concept fractions. (2) The Rust/Python 2–3× ratio may partly reflect that the testable subset excludes tokenless and inseparable-token constructs (e.g. Rust ownership operators `&`, `*`, `'`), so the inventory is not strictly comparable across languages. (3) Layer-count mismatch (Qwen 28 vs DeepSeek 32 layers) is handled with absolute indices for the body of the paper and fraction-of-depth only in an appendix, which makes the "12–13 layer gap" precise but potentially fragile if normalised differently. (4) Only imperative languages are studied; the author flags this but it bounds the generality of the language-design claims. (5) The author is the sole inventor of the underlying CSP-Atlas method being extended, so there is no independent replication of the method itself within this paper.

## Strengths

- Clean, minimal 2×2 design that is exactly large enough to expose the What/Where/How separation, with the language and model axes deliberately chosen to be orthogonal.
- Concept-level inventory as a "common yardstick" is a principled response to the per-model basis problem of sparse autoencoders, and makes cross-model numerical comparison meaningful rather than approximate.
- Honest reporting: marginal and null cluster results are published alongside the strong type-trait cluster; the failed Break ablation is shown and explained; the degenerate consistency parameter is disclosed.
- Best-in-class reproducibility artefacts — frozen extraction, locked-number test suite, single-script-per-figure regen, modest single-A100 compute.
- The Rust type-trait cluster is a striking, non-obvious finding (a semantic dimension recovered from surface syntax) that demonstrates the method reaching past what it was designed to measure.
- The operational framing — what transfers vs what must be re-localised — gives practitioners an immediate decision rule for porting interpretability results across models.

## Limitations

- **Sub-threshold structure is missed.** The binary ε = 0.5 mask captures high-amplitude neurons only; probes show representations exist and are decodable where ablation has no effect (97%+ accuracy with concept-only sets below ~20 neurons), so the binary view is a correct but partial picture. A continuous-geometry extension is deferred.
- **Causal validation scope.** Double dissociation is run on Qwen × Python only; the DeepSeek, Rust, and cross-language claims rest on correlational and geometric evidence.
- **Imperative languages only.** Generalisation to declarative languages or proof assistants (Lean is mentioned as a target) is open.
- **Layer-count mismatch.** Qwen has 28 layers, DeepSeek 32; body comparisons use absolute indices, which the author acknowledges is a choice.
- **Degenerate consistency parameter.** For these dense SwiGLU architectures the second binarisation parameter does no work, shrinking the effective sweep to ε alone.
- **Only two models.** Two models are enough to *show* the axes separate but cannot *test* the dimensionality (two-styles) claim or the third-model predictions — that is left as "the designed next test."
- **Cross-model concept space differs.** Comparisons use only the shared testable subsets, which constrains which constructs can be compared at all.

## Relevance

这篇论文对"代码大模型的机制可解释性"和"模型表征的普适性"两条研究线都直接相关：它提供了跨模型、跨语言比较的可操作方法学（概念清单作为公共标尺），并定量回答了"哪些解释性结论可以在模型间迁移、哪些必须重新定位"这一实践问题。对于关注代码模型内部机制、跨模型 probing/patching 工具移植、以及代码语法在 Transformer 各层处理位置的研究者，这是一项方法学与实证并重的工作。

## Questions for Further Exploration

- Does the two-styles fingerprint (late/sharp vs early/smooth) predict the band, flow type, cluster granularity, and cross-language sharing of a **third** independently trained code model (e.g. CodeLlama, StarCoder2)? This is the author's own "designed next test" and is the cleanest falsifier of the dimensionality claim.
- What drives the model-determined "Where/How" divergence — corpus, architecture, initialisation, or training trajectory? A checkpoint-resolved developmental analysis over training could isolate which factor fixes the processing band.
- Does the Rust type-trait cluster (Jaccard 0.535, p < 0.001) appear in models trained with little or no Rust, suggesting it is an intrinsic attractor of type-and-trait semantics, or is it specific to Rust-exposed training?
- How much does the binary ε = 0.5 mask miss? A continuous-geometry extension (already in progress per the author) would quantify the sub-threshold signal that probes detect but ablation does not.
- Does the What/Where/How decomposition survive the move to **natural language**, where the concept inventory is messier? The author names this as the method's "eventual home" but does not test it.
- Can the cross-language neuron-sharing pattern (DeepSeek 1.94× Qwen) be reproduced under controlled training — e.g. two models trained on identical mixed Python/Rust corpora — to separate a corpus effect from an architectural one?
- Is the 12–13 layer offset between Qwen and DeepSeek bands stable under fraction-of-depth normalisation (appendix) versus absolute indexing (body), or does it shrink/dilate?
