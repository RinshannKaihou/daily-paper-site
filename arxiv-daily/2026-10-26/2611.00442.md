> **一句话总结：** 在一个生产级多轮机票预订 Agent（Google ADK 构建）上做受控 A/B：把工具返回的结构化表格整个塞进模型上下文每轮重新生成（SYNTHESIS）会使逐轮字段保真度从 92.3% 崩到 45.7%（+46.6pp 差距），且崩溃由"交付表大小"而非"轮数"驱动——超过约 74 行后 SYNTHESIS 正确率 ≤8%、每个正确答案成本 ~200 倍于 BYPASS（$2.53 vs $0.012），而把记录留在会话状态、经类型化旁路通道送达的 BYPASS 对四个模型全部"大小免疫"（140/144），换更大模型只是"租回"部分差距且价格 5 倍。

> **TL;DR:** A controlled A/B on a deployed award-travel agent (Google ADK) over 408 frozen vendor captures (36 routes, 9,809 records) shows that re-emitting a tool's structured table through the model's context each turn (SYNTHESIS) collapses per-turn field fidelity: 45.7% vs 92.3% for the deployed BYPASS architecture (typed side-channel delivery, records never re-generated) across 24 dialogues / 339 scored turns per condition — a paired gap of +46.6pp [+35.7, +57.1] on Gemini 2.5 Flash, replicated at +49.6pp on GPT-4o-mini and +55.8pp on Claude Haiku 4.5. The load variable is table size, not turn count: on a content-controlled K-row prefix ladder SYNTHESIS decays monotonically from 83% at K=5 to 6% at K=100 (Cochran–Armitage p=3.9e-7) while BYPASS is 100% in all 93 runs; beyond 100 rows each correct SYNTHESIS answer costs $2.53 vs BYPASS's flat $0.012 (~200x). Upgrading to Gemini 2.5 Pro only halves the gap (+20.6pp) at 5x per-turn cost. Architecture buys size-immunity; capability only buys a higher collapse threshold.

## 核心贡献

- **首次对"交付架构"做受控 A/B 测量**：在生产系统（AwardWise 机票 Agent，Google ADK）中构造反事实分支 SYNTHESIS——即几乎所有主流 Agent 框架（LangChain、Vercel、CrewAI、Microsoft、OpenAI）的默认路径：工具结果全部进入模型上下文、由模型逐轮重新生成表格；与已部署的 BYPASS（记录存会话状态、追问翻译成确定性过滤器的参数、经类型化旁路通道送达 UI）对比。两个条件共享同一冻结载荷、同源指令、同一采样（Gemini 2.5 Flash, temp 0.1/top_p 0.5），仅交付路径不同（代码树深拷贝后仅 4 处 delta）。
- **发现崩溃的主变量是表大小而非轮数**：内容受控的 K 行前缀阶梯（6 条航线池化）显示 SYNTHESIS 从 K=5 的 83% 单调衰落到 K=100 的 6%，BYPASS 在全部 93 次运行中保持 100%；按日期变化阶梯，SYNTHESIS 从小表的 75–100% 跌到 ~74 行以上的 ≤8%。3×3 拉丁方把大小与位置分开：大小效应 p=3×10⁻¹⁰，位置效应 p=0.36（不存在）。
- **能力买阈值、架构买免疫**：四个模型的崩溃阈值按能力排序——GPT-4o-mini <10 行、Claude Haiku 4.5 约 10–25 行、Gemini 2.5 Flash 50–100 行、Gemini 2.5 Pro 到 198 行才优雅退化；而 BYPASS 对四个模型全部大小平坦（140/144）。同家族升档（Flash→Pro）只是把 +46.6pp 差距"租回"一半（+20.6pp），单价 5 倍。
- **完整的成本/延迟账本**：BYPASS 每轮延迟 4.9s、成本随表大小平坦；SYNTHESIS 31.7s（最大表平均 146s），>100 行后每正确答案 $2.53，约为 BYPASS 固定 $0.012 的 200 倍。
- **失败机制与误差传播分析**：修复提示词后 96/99 个失败轮的部分保真度 ≈1.0——行是真的、集合边界错了（截断+级联：过滤自己上一轮的脏输出）；捏造只出现在"查询表从未送达"的空上下文轮。滞后一阶条件分析：SYNTHESIS 失败后再失败概率 71.9%（干净轮后 31.4%），BYPASS 恢复率 95.7%；预注册的"轮数超线性"检验为阴性并如实发表（零假设在高错误率区饱和，检验退化）。
- **罕见的测量诚信报告**：作者公开了自己发现的 3 处真值缺陷（一处使某弧线结果摆动 59 个百分点）、2 处语义修正和 3 个真实生产 bug（如日期窗口参数被框架静默丢弃、用户要一周只得一天），仪器冻结后全部重跑，正负两个方向的不明移动都如实披露。

## Key Contributions

- A controlled architecture A/B inside a production multi-turn agent: SYNTHESIS (the framework-default pattern — full record sets into the planner's context, follow-ups answered in-head) vs BYPASS (the deployed system — records in session state, follow-ups translated into arguments for a deterministic filter, rows delivered over a typed side channel), over identical frozen payloads with lineage-matched prompts and sampling; the deep-copied tree differs in exactly four deltas, all entailed by the delivery swap.
- Identifies delivered-table size, not turn count, as the load variable: content-controlled prefix ladder (true K-row prefixes of six routes' fixed payloads, n=18/cell) shows monotone decay 83%→6% (K=5→100) for SYNTHESIS vs 100% for BYPASS in all 93 runs; a 3×3 Latin square separates size from position (size p=3×10⁻¹⁰, position p=0.36).
- A capability-vs-architecture decomposition: collapse thresholds order by model tier (GPT-4o-mini <10 rows, Claude Haiku 4.5 10–25, Gemini 2.5 Flash 50–100, Gemini 2.5 Pro graceful to 198) while BYPASS stays size-flat for all four models (140/144); a same-family tier upgrade (Flash→Pro) only halves the gap at 5x cost.
- A cost/latency account: BYPASS flat at ~$0.012 per correct answer and 4.9s per turn; SYNTHESIS climbs to $2.53 per correct answer beyond 100 rows (~200x) with 31.7s mean latency (146s at the largest tables).
- Failure-mode taxonomy with mechanism: post-fix SYNTHESIS corruption is set-boundary error on real rows (truncation with cascade — later turns filter earlier emissions), fabrication strictly tracks grounding absence (starved searches, empty context), BYPASS's residual failures are wrong-but-real filter arguments (translation quality), which order exactly with each family's BYPASS accuracy.
- A published negative result (pre-registered super-linear compounding test) and an unusually candid measurement-integrity report: three self-found ground-truth defects, two semantics corrections, three production bugs, full instrument-fix accounting including one unexplained −6.0pp movement, disclosed rather than absorbed.

## Methodology

The study uses a **freeze-real-then-replay** design on AwardWise, a production multi-agent award-and-cash flight concierge built on Google's Agent Development Kit (ADK) as a fork of the adk-samples travel-concierge. Real searches ran through the production search tools (Seats.aero for award, SerpAPI for cash, with hub routing, deduplication, canonicalisation in the loop); everything returned was frozen: 408 captures over 36 routes holding 9,809 records (largest payload 510 rows), spanning four capture-date bands and two cabins. Experiments replay the vendor boundary from these captures — no live vendor calls.

**Conditions.** BYPASS is the deployed system unmodified: search results never enter the model's context (the function response carries only counts and parameters; rows go to session state and reach the client as typed events alongside, not through, the token stream); each follow-up's intent is translated by the model into filter arguments evaluated by a deterministic context tool over stored state. SYNTHESIS rebuilds the fork-point architecture inside the mature product via a deep copy with exactly four deltas (instruction variant, context tools removed, sub-agent summaries replaced by mechanically injected record lists, output schemas adjusted so injected records survive) — making the counterfactual *stronger* than the true fork-point system, so the measured gap is not an artifact of transcription noise. Translation error is common-mode: the same planner with the same instruction lineage interprets the user in both arms, so the residual gap is attributable to delivery.

**Dialogues and oracle.** 24 dialogue templates derive from demonstration sessions by an experienced award-travel practitioner, with authoring rules that make turns scoreable (no heuristic constraints, no undefined-aggregate superlatives, pinned scope semantics for composition/refer-back/revision). Ground truth is computed, not annotated: frozen captures are replayed through the production tools and each turn's pinned arguments are passed to the production filter evaluator; a liveness verifier rejects empty or trivially-repeated ground truth before any model is called, and authored expected-row counts are asserted against the evaluator at run time.

**Metric.** Per-turn field fidelity with strict count-mismatch zero-out: 15 scored fields per record, records aligned on identity key (flight_number, date, source); if emitted count ≠ ground-truth count the turn scores zero regardless of field matches (deliberately strict, since a silently missing award flight is a missed booking). Partial-credit fidelity and an order-exact axis are reported alongside. Runs: k=3 independent repeats per condition at production sampling (temperature 0.1 / top_p 0.5); 339 scored turns per condition; dialogue-level bootstrap CIs (turns are not independent). Cross-family and tier legs re-run the full corpus on GPT-4o-mini, Claude Haiku 4.5, and Gemini 2.5 Pro.

**Instruments.** Size is manipulated three ways — date-varied ladders (size varies by capture date), the content-controlled top-K ladder (true prefixes, only count differs), and a 3×3 size-by-position Latin square with byte-identical scored turns — plus a byte-identical 16-row control leg inside every dialogue to separate delivered load from context accumulation. Cost/latency are logged per turn; lag-1 conditional hazard and value-tracing (are a turn's emitted rows consistent with filtering a *prior emission* rather than ground truth?) test error dependence.

## Results & Highlights

- **Headline (24 dialogues, 339 scored turns/condition, Gemini 2.5 Flash):** BYPASS 92.3% (313/339) vs SYNTHESIS 45.7% (155/339) of turns fully correct — paired gap +46.6pp, dialogue-level bootstrap CI [+35.7, +57.1]; BYPASS wins 22 of 24 paired dialogues (exact sign test p=5.7×10⁻⁶).
- **Cross-family replication (n=339 per cell):** the paired gap holds at +46.6pp [+35.7, +57.1] (Gemini 2.5 Flash), +49.6pp [+39.2, +60.2] (GPT-4o-mini: BYPASS 67.0% vs SYNTHESIS 17.4%), and +55.8pp [+41.1, +69.9] (Claude Haiku 4.5: 82.9% vs 27.1%) — every family's intervals disjoint; family determines who fails how, not how much the architecture costs.
- **Content-controlled size ladder (6 routes pooled, n=18/cell):** SYNTHESIS decays monotonically 83% (15/18) at K=5 → 72% at K=10 → 44% at K=25 → 39% at K=50 → 6% (1/18) at K=100; BYPASS is 100% (18/18) at every K and 3/3 at the full 198-row payload where SYNTHESIS is 0/3. Cochran–Armitage trend test z=−5.07 (p=3.9×10⁻⁷), surviving route-level cluster bootstrap in 2000/2000 resamples.
- **Date-varied ladders:** SYNTHESIS falls from 75–100% on the smallest tables to ≤8% beyond ~74 rows on every route reaching that size (e.g. FRA-BKK: 9 rows→92%, 74 rows→0%, 194 rows→8%; ORD-NRT: 11→75%, 70→17%, 174→0%), while BYPASS is flat at 99.2% (238/240) — its only two misses come from a single starved run.
- **Tier upgrade only rents the gap back:** Gemini 2.5 Pro halves it (BYPASS 92.6% vs SYNTHESIS 72.0%, +20.6pp [+11.7, +31.4]) at 5x Flash's per-turn cost ($0.141 vs $0.028 per scored filter turn, 12x BYPASS's $0.012) and 1.6x latency (35.5s vs 22.8s); BYPASS on the cheap Flash (92.3%) beats SYNTHESIS on Pro (72.0%) at one twelfth the price.
- **Cost per correct answer:** BYPASS flat ≈$0.012 at every table size; SYNTHESIS climbs to $2.53 beyond 100 rows (~200x), where its accuracy is 3%; mean per-turn latency is 4.9s (BYPASS) vs 31.7s (SYNTHESIS, 6.5x), with the largest synthesis turns averaging 146s and 8.7x BYPASS's per-turn cost for 8%-fidelity answers.
- **Size vs position (3×3 Latin square):** size at fixed dialogue slot is decisive (92→33→0% across slots at slot 1; χ²=39.4, p=3×10⁻¹⁰, cluster-robust in 2000/2000 resamples) while no position main effect is detectable (χ²=0.8, p=0.36); BYPASS crosses the same square at 106/108.
- **Error dependence:** after a failed turn, SYNTHESIS fails again 71.9% of the time vs 31.4% after a clean turn (BYPASS recovery 95.7%); value-tracing attributes 53/177 (30%) of traceable SYNTHESIS failures to propagation vs 0/25 for BYPASS — whose zero is structural (no model-emitted set exists to propagate).
- **Failure shapes post-fix:** of 99 failed SYNTHESIS ladder turns, 96 have partial-credit fidelity ≈1.0 (real rows, wrong set — truncation with cascade: a 74-row GT truncated to 55 emitted, the next turn filtering the 55 for GT 11 returns 45); GPT-4o-mini garbles (4 of 13 no-output runs blew the 128k context window — BYPASS has no such run); Claude omits the flights array while its prose count stays correct (29 of 35 omission runs). BYPASS's floor is translation: argument divergence ranges 45.6% (GPT-4o-mini) to 27.2% (Flash), of which 41–82% is harmless (still selects the right rows).
- **Control leg:** a byte-identical 16-row table in all twenty dialogues scores SYNTHESIS 77.5% vs BYPASS 100%, holding even inside dialogues whose large-table treatment turn scored zero — the failure tracks the table delivered at that turn, not accumulated context.

## Authors & Credibility

Single-author paper by Tung Hoang (Tung Thanh Hoang), affiliated with AwardWise, San Jose — the company operating the production system under study, which is disclosed prominently. The author also wrote the prior single-turn study this work extends (Hoang, 2026, AIWILD @ ICML 2026 workshop). Credibility signals are unusually strong for an industry preprint: pre-registered hypotheses with one negative result published as such; an instrument freeze and full re-run after defects were found; self-disclosure of three ground-truth defects (one causing a 59-point swing in an arc's result), two semantics corrections, and three real production bugs captured by the study; gap CIs computed by dialogue-level bootstrap (cluster-robust, per Schessl 2026) rather than turn-level; a candid LLM-usage disclosure (Claude used substantially for prose/code under author direction, with every quantitative claim traced to committed artifacts). Counterweights: it is an unreviewed single-author arXiv preprint from the vendor of the winning architecture, and the headline model is a single family (Gemini 2.5 Flash) with cross-family legs at the same scale but imperfect sampling parity for Claude.

## Critical Assessment

- **Novelty: high and well-positioned.** Joining a controlled architecture A/B (same real record sets, both arms of a deployed system) with row/field-level fidelity indexed by delivered size is genuinely new; prior work measured single-turn corruption (Hoang 2026), corrupt success on τ-bench mocks (Cao et al. 2026), or self-conditioning across turns (Sinha et al. 2025) — none isolate delivery architecture as the variable. The "capability buys threshold, architecture buys immunity" framing is crisp and transportable.
- **Rigor: strong, with honest limits.** The design anticipates its own confounds: size-vs-position Latin square, byte-identical control leg, common-mode translation argument, starvation accounting (excluding starved runs *widens* the gap), and a grounding census over 1,306 turns. But the SYNTHESIS-vs-BYPASS comparison is **joint by construction** (synthesis bypass + structured-state preservation bundled; no unbundled condition was run — acknowledged, with the first-turn-only ladder as partial unbundling), the ground truth shares the production evaluator's code path with the deployed arm (a shared evaluator defect would depress SYNTHESIS alone; an independent re-implementation of the filter semantics is explicitly named as the missing check), and one instrument-fix movement on the SYNTHESIS side (−6.0pp) is flagged as unexplained rather than explained.
- **Reproducibility: partial.** No seeds, non-bit-deterministic serving stack — distributional reproduction only; vendor terms preclude releasing the frozen payloads, though dialogue templates, traces, manifests, and pre-registration text are slated for release. The Claude leg breaks sampling parity (top_p unset; a Gemini-only ablation suggests the direction makes the Claude gap conservative).
- **Significance: practically important.** The surveyed frameworks all default to in-context delivery, and the practitioner convergence on typed side channels (LangGraph, AG-UI, Vercel Data Parts, A2UI) was motivated by rendering, not correctness; this paper supplies the missing correctness measurement — the claim that "the field's UX-motivated convergence was also, unknowingly, a correctness decision" is supported.
- **Red flags / open questions:** the corpus-level +46.6pp depends on the authored mix of table sizes (the authors correctly point to the size-conditional curves as the transportable result); the size ladder covers six routes, one cabin, and 112–198-row ceilings against 510-row payloads held (a true 200+ band was declined); dialogues come from expert demonstration, not production traffic; one vertical (flight award search, non-stop/one-stop only); the 24-dialogue n gives wide CIs (deepest stratum = 3 dialogues); and the author's company sells the winning architecture — mitigated, not eliminated, by the integrity reporting.

## Strengths

- A rare controlled experiment *inside* a deployed production agent, with the counterfactual arm made deliberately charitable (mechanical record injection, adjusted schemas) so the gap cannot be blamed on a strawman prompt — and a pre/post prompt-fix analysis showing the better the prompt got, the more purely the residual gap measured architecture.
- Three independent size instruments (date-varied, content-controlled prefixes, Latin square) converging on the same conclusion, plus a byte-identical control leg that cleanly kills the "accumulated context" alternative.
- The failure analysis goes beyond rates to mechanism: truncation-with-cascade identified turn-by-turn, fabrication shown to strictly track grounding absence (every from-nothing fabrication sits over a missing table), and BYPASS's residual failures characterized as wrong-but-real filter arguments whose harmless share orders with model accuracy.
- Full cost/latency accounting alongside accuracy — the ~200x cost-per-correct-answer figure and the "tier upgrade only rents the gap back" result are exactly the numbers a practitioner needs.
- Exceptional measurement integrity: pre-registration with a published negative result, self-found ground-truth defects disclosed with their 59-point swing, both instrument readings reported, and cluster-robust statistics throughout.

## Limitations

- The architecture comparison is joint (synthesis bypass + structured-state preservation); the effect is attributable to the pair, not to either member alone, though the first-turn ladder shows the synthesis half alone suffices for the size effect.
- External validity is bounded: one deployment, one vertical (flight itineraries), non-stop/one-stop captures only, expert-demonstration dialogue scripts rather than production traffic; route complexity, cabin, and record-width scaling are open.
- The size manipulation tops out at 198 rows against 510-row payloads held in the corpus; no single "knee" in the decay curve can be named, and cell resolution localizes the shape only coarsely.
- No seeds or bit-reproducibility (distributional only); headline from one model family with cross-family replication under a Claude sampling-parity break; wide dialogue-level CIs from n=24 dialogues (BYPASS 88.3–95.9, SYNTHESIS 34.8–57.2).
- Hypothesis H2 (demonstration-vs-instruction) is motivated by a small uncounterbalanced pilot but never measured; the corpus-level +46.6pp marginal depends on the authored size mix; vendor terms block payload release; and the oracle shares the production evaluator with the deployed arm, with the independent filter-semantics re-implementation still lacking.

## Relevance

这篇论文直接命中"LLM Agent 多轮工具调用的可靠性与评测"兴趣：它用量化实验证明了 Agent 框架默认的"工具结果进上下文再生成"路径在真实生产载荷下会随表大小崩溃，并给出了可迁移的架构级修复（类型化旁路交付 + 确定性过滤器）及其成本账本。对于任何构建或评测 tool-using agent、structured output 保真度或多轮 Agent 基准的工作，这都是一份罕见的受控 A/B 证据。

## Questions for Further Exploration

- Would the collapse threshold shift with record width (wide schemas vs the 15-field flight records), route complexity, or other verticals (hotels, product catalogs with 500+ rows per result set)?
- Can the joint effect be unbundled: an arm that keeps cross-turn session state but re-delivers rows through the LLM would separate structured-state preservation from synthesis bypass — no deployed pattern does this, but the condition would settle attribution.
- Does the truncation-with-cascade mechanism interact with long-context "lost in the middle" effects, and would explicit row-count self-verification or re-ranking mitigate truncation without abandoning in-context synthesis?
- How does the collapse behave with reasoning models or higher-temperature sampling (the designed-but-unrun greedy-decoding and temperature-sweep ablations), and is the capability-ordered threshold stable across model generations?
- Could an outcome category for count-only-envelope turns (BYPASS answering from counts without materialising rows) raise BYPASS's honest rate, and how large is that population in production traffic?
- Does the same size-indexed fidelity collapse appear in agentic RAG / retrieval settings where the "table" is a passage list, connecting this to context-compression and context-minimization research?
