> **一句话总结：** MolRSI 是一个将"经验引导的 MCTS 工作流搜索"与"跨任务持久记忆"结合的分子发现 AI 智能体：在抗生素筛选中实验命中率达 15.9%（此前专家工作流仅 8.7%），在 pMHC 结合蛋白设计中获得 8 个实验验证的特异性命中（Claude Science 为 0），证明了跨任务经验积累能持续改进智能体自身的搜索策略。

> **TL;DR:** MolRSI couples experience-guided Monte Carlo tree search over molecular workflows (models, training strategies, screening filters) with persistent cross-task memory (solution/refinement/execution) so that each campaign's outcomes reshape the search policy for the next. On six antibacterial-activity prediction benchmarks (five similarity-based splits each) MolRSI attains the best mean test AUPRC (0.361) versus the agents Biomni (0.317), Claude Science (0.303), STELLA (0.296), Codex (0.295) and Claude Code (0.285); prospectively, its screening workflow over the same ~12.1M-compound library used in the authors' prior Nature study yields a 15.9% experimental hit rate (17/107 compounds with MSSA MIC ≤ 32 µg/mL) vs 8.7% (21/241) for the expert workflow, and on the shared 271-compound held-out S. aureus set its activity model reaches AUROC 0.828 vs 0.590 for the previous predictor. For peptide–MHC binder design, MolRSI transfers experience from 14 miniprotein-binder tasks to achieve held-out MART-1 EF@1% = 3.65 (vs 0.00 without RSI and ≤1.85 EF@2% for all agent baselines), and phage-display screening validates 5/251 MART-1 and 3/266 SARS-CoV-1 specific binders where Claude Science yields 0/288 and 0/267.

## 核心贡献

- 提出 MolRSI：首个（据作者所知）把"递归自我改进（RSI）"显式落地到分子发现流程的 AI 智能体——用自身搜索得到的性能、修改结果与执行反馈持续更新搜索策略 πt → πt+1，形成任务内与跨任务的双重改进闭环。
- 设计了三层持久记忆架构：解记忆（工作流+得分）、精炼记忆（修改动作及其效果差值）、执行记忆（运行资源、报错与修复方案），配合经验引导的 MCTS（5 步迭代：选工作流家族→选父工作流→提议修改→执行评估→更新记忆）来组装与改进候选工作流（含模型架构与训练策略）。
- Explore Agent 把文献与代码仓库转化为经过隔离环境执行验证的可复用技能（抗生素域 110 个技能 = 55 模型 + 48 方法 + 7 工具；蛋白域 65 个技能 = 28 模型 + 37 评分项），保证搜索空间中的组件真实可运行。
- 在抗生素发现中完成前瞻性湿实验验证：同一训练数据、同一约 1210 万化合物库下，MolRSI 工作流的实验命中率 15.9% 显著超过此前专家驱动工作流的 8.7%（相对提升约 82%），并发现 C3、C32 两个对 MRSA 有效（MIC 分别 1 和 8 µg/mL）且在三种人源细胞上无细胞毒的新结构分子。
- 在 pMHC 结合蛋白从头设计中验证了跨域经验迁移：MolRSI 获得 8 个经噬菌体展示实验验证、对目标 pMHC 优先富集的命中，而 Claude Science 在同等条件下零命中；消融显示去掉跨任务经验后 MART-1 排名 EF 直接从 3.65 跌到 0.00。

## Key Contributions

- Introduces MolRSI, an AI agent that operationalizes recursive self-improvement for molecular discovery: the effective search policy π(a|s; M) is updated by memory writes M → M′ after every workflow evaluation, so experience from one campaign measurably changes how the next campaign is searched (within-task and cross-task).
- A three-part persistent memory design — solution memory (workflows + development scores), refinement memory (modifications + before/after score deltas, including failed runs), execution memory (runtimes, GPU usage, error messages, verified repairs) — that biases every step of an experience-guided MCTS over workflow families (selection uses current-task performance + UCB-style exploration bonus + a historical transfer score).
- An Explore Agent that converts papers and code repositories into executable skills, each validated by running a usage example in an isolated environment and auto-repaired or discarded on failure; only validated skills enter the search space.
- Prospective experimental validation in antibiotic discovery: using the same training data and ~12.1M-compound library as the authors' previous Nature study, the MolRSI-built workflow (weighted ensemble of two MiniMol variants + LANTERN–RADR at 0.55/0.30/0.15, PAINS/Brenk and antibiotic-core filters, Tanimoto < 0.40 to known antibiotics, three-cell-line cytotoxicity filter) achieves a 15.9% hit rate vs 8.7% for the expert workflow, plus two MRSA-active hits (C3, C32) with clean cytotoxicity separation.
- Demonstrates that cross-task experience is causally necessary in de novo peptide–MHC binder design: with pooled experience from 14 miniprotein-binder tasks MolRSI reaches held-out MART-1 EF@1% = 3.65 / EF@2% = 5.55; the identical system without that memory scores 0.00 at both cutoffs, and experimental phage display yields 8 specific hits (5 MART-1, 3 SARS-CoV-1) where Claude Science produces none.

## Methodology

MolRSI treats workflow development itself as a search problem. A task specifies a biological problem, available data, an evaluation criterion, and a computational budget. An **Explore Agent** first retrieves relevant literature, code, tools, benchmarks and algorithms, and wraps each into a *skill* (purpose, dependencies, I/O, execution steps); each skill must pass an execution check in an isolated environment (with automatic repair from error messages) before it is admitted to the resource library, so the search space contains only runnable components.

Workflow search is an **experience-guided MCTS**. Initial workflows (assembled from the library or retrieved from solution memory) root separate trees; workflows sharing a model or computational approach are grouped into families. Each iteration has five steps: (1) select a workflow family via a combination of its best development score on the current task, an exploration bonus for less-visited families, and a *historical transfer score* summarizing the family's performance on related tasks in solution memory; (2) sample a parent workflow from evaluated candidates (favoring performance, penalizing over-sampled parents, mixing in transfer scores); (3) propose a modification (swap a method, change composition, tune parameters) informed by refinement memory of past modifications and their outcomes, with pre-execution checks for format, duplication, and feasibility; (4) execute and evaluate — using execution memory to allocate resources and to retrieve verified repairs when errors recur; (5) write results back to all three memories. The loop implements the RSI update: πt(a|s) = π(a|s; Mt), Mt+1 = Update(Mt, Et). Search halts at the budget limit and returns the workflow with the best development score.

For **antibiotic discovery**, MolRSI first searched independently on 25 source tasks (22 TDC ADMET tasks + 3 cytotoxicity tasks from the prior Nature study) to build the experience pool, then searched on six held-out antibacterial prediction tasks (S. aureus, P. aeruginosa, A. baumannii, E. coli, K. pneumoniae, N. gonorrhoeae; five similarity-based 8:1:1 splits at Tanimoto 0.40 each; mean validation AUPRC for selection, test AUPRC reported). The deployed screening workflow then scored the ~12.1M-compound library, filtered by PAINS/Brenk alerts, antibiotic-core exclusion and max Tanimoto < 0.40 to known antibiotics, predicted cytotoxicity for HepG2/HSkMC/IMR-90 (threshold 0.40), ranked by the 0.55/0.30/0.15 weighted ensemble, and picked 107 compounds across Butina clusters; 20 workflow evaluations per task were allowed for all agents, with Claude Sonnet 5 as backbone (Codex used GPT-5.5).

For **pMHC binder design**, experience was accumulated on 14 experimentally annotated miniprotein-binder tasks (1,565 positives, 17,215 designs; leave-one-target-out, 300 A100-hours and 20 workflow evaluations per task; ranking quality measured by Enrichment Factor at top 1%/2%). MolRSI then developed a pMHC ranking workflow on two gp100 datasets (AUROC-guided) and tested it zero-shot on held-out MART-1. Keeping that ranking frozen, it ran 30-round searches (up to 1,000 A100-hours per target) over generation methods — RFdiffusion3, Proteina-Complexa, PXDesign, BoltzGen, MOSAIC-APGM — with SolubleMPNN inverse folding (binder lengths 80–120), objective = mean score of the top-ranked 5% of candidates; final candidates had to pass on-target ipSAE ≥ 0.50, monomer pLDDT ≥ 0.80, ≥15 HLA contacts and on-target > off-target score. Hits were validated by two rounds of E. coli phage display with positive selection on the target pMHC and negative selection on a peptide-swapped off-target, quantified by NGS enrichment (hit = on-target log2FC > 4 and exceeding the maximum off-target enrichment).

## Results & Highlights

- **Antibacterial prediction benchmark (six species tasks, five splits each):** MolRSI *without* RSI already achieves the highest mean test AUPRC of 0.361, vs 0.317 for Biomni (next best), 0.303 for Claude Science, 0.296 for STELLA, 0.295 for Codex, and 0.285 for Claude Code — ranking first on 4 of 6 tasks and second on the remaining 2 (mean rank 1.0 vs 3.33 for Biomni).
- **RSI ablation:** adding cross-task experience improves mean test AUPRC on all six antibacterial tasks; on E. coli and N. gonorrhoeae MolRSI-with-RSI's *first* evaluated workflow already beats every baseline agent's final workflow after 20 iterations. Zero-search transfer (just refitting a retrieved workflow) outperforms full 20-iteration search-from-scratch on S. aureus, A. baumannii and K. pneumoniae.
- **Memory-pool scaling:** transferred-workflow mean test AUPRC rises from ~0.32 with 2 source tasks to ~0.37 with all 25 (averaged over all task combinations, 2,000 sampled orderings) — exceeding the 0.361 that search-without-RSI reaches after 20 iterations, i.e., free transfer beats paid search.
- **Prospective antibiotic screening:** 17 of 107 tested compounds inhibit MSSA at MIC ≤ 32 µg/mL — a 15.9% hit rate vs 8.7% (21/241) for the previous expert-driven workflow on the *same* training data and screening library (~82% relative increase). C3 and C32 also inhibit MRSA (MIC 1 and 8 µg/mL) with CC50 of 6.4–17.5 and 24.2–54.7 µg/mL across HepG2/HSkMC/IMR-90, establishing an activity/cytotoxicity separation.
- **Predictive head-to-head:** on the shared 271-compound held-out S. aureus set from the prior Nature study, MolRSI's activity model reaches AUROC 0.828 vs 0.590 for the previous expert predictor, and AUPRC 0.300 vs 0.090.
- **Miniprotein ranking benchmark (14 targets):** MolRSI achieves the best macro EF@1% of 8.01 (vs 7.62 for the next-best agent) and EF@2% of 7.29 (vs 6.71), even without prior-task memory.
- **Held-out pMHC ranking (MART-1):** with cross-task experience, EF@1% = 3.65 and EF@2% = 5.55; the identical system without that memory scores EF = 0.00 at both cutoffs, no baseline agent finds a confirmed binder in its top 1%, and the best baseline EF@2% is only 1.85.
- **Design-workflow optimization:** the 30-round search lifts the best objective (mean top-5% score) by 66% to 6.76 for MART-1 and 28% to 7.56 for SARS-CoV-1 over initial configurations.
- **Prospective pMHC validation (phage display):** MolRSI yields 5 hits among 251 evaluable MART-1 designs and 3 among 266 SARS-CoV-1 designs; Claude Science yields 0/288 and 0/267 under identical screening, and MolRSI-without-the-learned-ranking yields 0/479 — and the hits track the score (all 5 MART-1 hits in the top-scoring 9% of 767 pooled designs; the 3 SARS-CoV-1 hits within the top ~25% of 784).

## Authors & Credibility

A 18-author team spanning Northeastern University (Jin lab), the Broad Institute of MIT and Harvard, Harvard University, the Wyss Institute, MIT, UC Berkeley, University of Toronto, Ohio State, University of Washington, HHMI, Yale, Microsoft Research, Mass General Hospital and Dana-Farber, with five co-corresponding authors (Tianyu Liu, Yuanqi Du, Nir Hacohen, James J. Collins, Wengong Jin). This is a highly credible configuration: the Collins group authored the prior Nature 2024 antibiotic-discovery study that serves as the expert baseline here (same training data, same ~12.1M screening library), and the Liu/Baker-lineage pMHC binder work (Science 2025) supplies the protein-design testbed — meaning the comparisons to "expert workflows" are against the authors' own published state of the art rather than straw men. Both experimental campaigns (MIC/CC50 assays; E. coli phage display with NGS readout) were run in-house with proper controls (DMSO vehicle, Triton X-100 kill controls, peptide-swapped off-target negative selection). All computational datasets are public (TDC, prior publications) except the pMHC datasets, which are available from the corresponding authors of Liu et al. "upon reasonable request."

## Critical Assessment

- **Novelty:** The core ideas (MCTS over workflow configurations, memory-augmented agents) are individually established (e.g., AI-EDA via tree search, Voyager-style skill libraries, Biomni/Claude Science agent scaffolds). The genuine novelty is the *closed, measured policy-improvement loop across tasks* — the with/without-RSI and zero-search-transfer ablations (e.g., MART-1 EF@1% 3.65 with memory vs 0.00 without) are a clean causal demonstration that prior agent systems lacked. The "RSI" label is somewhat inflated relative to its weight-training connotation: nothing about the underlying LLM or models improves recursively — only the non-parametric search policy (memory + selection rules) does.
- **Rigor:** Strong on ablations (with/without RSI, zero-search transfer, ranking removal, memory-pool size scaling averaged over all task combinations), matched budgets (20 workflow evaluations per task; 300/1,000 A100-hours), identical splits and test-time discipline (test AUPRC never guided search). The prospective hit-rate comparison (15.9% vs 8.7%) is, however, a cross-campaign comparison rather than a randomized head-to-head — the two workflows picked different compounds from the same library, and a single 107-compound campaign has wide uncertainty (the paper shows Wilson CIs but no significance test).
- **Weak-baseline caveats:** the 0.590 AUROC of the "previous predictor" on the shared 271-compound set is strikingly low for the published Chemprop ensemble from the Nature study — that set (241 candidates + 30 low-predicted-activity controls, known-antibiotic positives excluded) is a genuinely hard, in-distribution-of-screening-picks set, but the framing "MolRSI beats the previous model" partly reflects evaluation-set construction rather than a like-for-like retraining. Similarly, "Claude Science completely failed" at pMHC design is a single-baseline, single-seed outcome; agent harnesses are sensitive to prompting, and Claude Science did fine on the miniprotein ranking benchmark, so total failure on the harder transfer task is plausible but not deeply diagnosed.
- **Reproducibility:** good for the computational layer (public datasets, named components, budgets, splits); weaker for the full system — no code release is mentioned in the main text, the skill libraries (110 + 65 skills) are substantial unreleased artifacts, and the pMHC datasets are request-gated. Compute cost (1,000 A100-hours per design target) also limits independent replication.
- **Red flags:** (1) the C3 selectivity story is thinner than the abstract implies — CC50 6.4–17.5 µg/mL against MRSA MIC 1 µg/mL gives a worst-case selectivity index of only ~6x, far from drug-like; (2) MIC/CC50 values come from n = 2–3 technical replicates in a single experiment (higher replicate reported); (3) pMHC "specificity" is enrichment against a *single* peptide-swapped off-target per target, not a panel, and no orthogonal affinity measurement (SPR/ITC) is provided; (4) memory-pool gains are modest (~0.32 → ~0.37 AUPRC) and zero-search transfer helps on only 3 of 6 antibacterial targets, so the cross-task story is real but uneven.

## Strengths

- End-to-end causal chain: from agent benchmark → RSI ablation → prospective wet-lab hit rate, in two distinct domains (small-molecule screening and de novo protein design) — very few scientific-agent papers validate experimentally at all, let alone twice.
- Honest, well-designed controls: with/without RSI under identical libraries and budgets, zero-search transfer to separate "inherited configurations" from "further search," ranking-removal ablation (0/479 hits without the learned ranker), and pool-size scaling averaged over all source-task combinations to rule out ordering luck.
- The expert baseline is the authors' own published Nature-level workflow on identical data and library — an unusually strong and fair comparator.
- Architecture is pragmatic and decomposable: validated-skill library + three typed memories + MCTS is a reusable pattern for any domain where workflow composition is the bottleneck.
- Hits track the computational score prospectively (all 5 MART-1 hits in the top 9% of 767 designs), which is the key claim that makes the ranking workflow scientifically useful rather than a benchmark artifact.

## Limitations

- "Recursive self-improvement" improves a search policy over a fixed skill library — the underlying models and LLM backbone are static; the term invites over-reading.
- Experimental validation is narrow relative to the claims: 107 compounds / one campaign for antibiotics; 2 targets × 1 off-target each for pMHC; phage-display enrichment (log2FC) rather than measured affinities or functional assays (the prior expert pMHC work demonstrated T-cell activation, which MolRSI's hits have not yet shown).
- C3's cytotoxicity window (CC50 6.4 µg/mL in the most sensitive cell line vs MRSA MIC 1 µg/mL) is marginal for a lead; the paper is upfront about the numbers but the abstract-level "do not cause cytotoxicity" framing is generous.
- Cross-task transfer is uneven: zero-search transfer beats scratch search on only half the antibacterial targets, and pool-size gains (~0.05 AUPRC) are modest; no analysis of when transfer fails (negative transfer) beyond variance bands.
- Compute-heavy (up to 1,000 A100-hours per design target, 300 per ranking task) and the 110/65-skill libraries plus agent code are not stated as released, so exact reproduction will be hard.
- pMHC ranking benchmark rests on 14 tasks from three labs and 1,565 positives; EF@1% on a few hundred candidates is high-variance, and the MART-1 held-out result (EF 3.65 vs 0.00) is a single target.

## Relevance

这篇论文是"LLM 智能体 + 自主科学发现"方向的代表性工作：它把智能体自我改进从单任务自动化推进到跨任务经验积累与策略学习，并以双前瞻实验（抗生素、蛋白设计）闭环验证，直接契合对 AI for Science、智能体记忆/经验复用与 AutoML 式工作流搜索的兴趣。

## Questions for Further Exploration

- How much of the RSI gain comes from each memory type (solution vs refinement vs execution)? The paper ablates cross-task memory as a whole but not the three memories separately.
- Does the memory scale beyond 25 source tasks, or does it saturate / accumulate negative transfer as task diversity grows? What happens when evaluation criteria or target families shift dramatically?
- Can experimental outcomes (wet-lab hits and failures) be fed back into the policy update, as the discussion proposes, and does that close the loop faster than purely computational development scores?
- Would Claude Science or other baselines close the pMHC gap given the same 65-skill library, isolating whether MolRSI's win is the search policy or resource curation?
- Are the MRSA-active hits (C3, C32) mechanistically novel (new structural class, as in the prior Nature study), and what is their selectivity index after repeat testing and against a broader off-target panel?
- Is the phage-display enrichment threshold (log2FC > 4, off-target-preferential) predictive of measurable affinity and downstream T-cell-engagement function for the 8 pMHC hits?
