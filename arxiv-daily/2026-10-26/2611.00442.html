Why this matters

Nearly every mainstream agent framework ships the collapsing default. This controlled production A/B quantifies the failure and prices the architectural fix.

对任何构建或评测 tool-using agent、structured-output 保真度或多轮 Agent 基准的工作，这都是一份罕见的生产级受控 A/B 证据。

Critical edge

The A/B is joint by construction — synthesis bypass and structured-state preservation are bundled, with no unbundled arm — and the author's company sells the winning architecture.

The ground-truth oracle also shares the production evaluator's code path with the deployed arm; the named missing check is an independent re-implementation of the filter semantics.

Methodology — freeze real, then replay

Freeze-real-then-replay inside AwardWise, a production multi-agent award-and-cash flight concierge built on Google ADK. Real vendor searches (Seats.aero award, SerpAPI cash, with hub routing and dedup in the loop) were frozen into 408 captures / 36 routes / 9,809 records (largest payload 510 rows); experiments replay the vendor boundary from captures — no live calls. Both arms share identical frozen payloads, lineage-matched prompts, and sampling; the deep-copied code tree differs in exactly 4 deltas, all entailed by the delivery swap.

Records never enter the token stream: the function response carries counts + parameters only; each follow-up is translated into arguments for a deterministic filter over stored state.

SYNTHESIScounterfactual · framework default
  1. tool call
  2. full table → model context
  3. model re-emits rows each turn

The default path of LangChain, Vercel, CrewAI, Microsoft and OpenAI stacks: the entire record set is injected into context and the planner answers follow-ups in-head. Rebuilt inside the mature product, made deliberately charitable.

  • Computed oracle, not annotation: pinned arguments replayed through the production filter; liveness verifier rejects empty/trivial ground truth.
  • 24 expert dialogue templates with scoreable-turn authoring rules; 339 scored turns per condition, k=3 repeats at temp 0.1 / top_p 0.5.
  • Strict metric: 15 fields per record on identity keys; emitted count ≠ truth ⇒ turn scores zero (a missing award flight is a missed booking).
  • Three size instruments: date-varied ladder, content-controlled true-prefix ladder, 3×3 size-by-position Latin square — plus a byte-identical 16-row control leg in every dialogue.

Results — failure shapes & mechanism

  • Real rows, wrong set: 96/99 failed SYNTHESIS ladder turns have partial-credit fidelity ≈ 1.0 — truncation with cascade (a 74-row truth truncated to 55 emitted; the next turn filters the 55 and returns 45 for a truth of 11).
  • Fabrication strictly tracks grounding absence: every from-nothing fabrication sits over a table that was never delivered (starved searches, empty context) — never over a present one.
  • Propagation is structural: value-tracing attributes 30% of traceable SYNTHESIS failures to filtering a prior emission; BYPASS's rate is 0/25 — no model-emitted set exists to propagate.
  • BYPASS's floor is translation: wrong-but-real filter arguments, 41–82% of them harmless (still select the right rows), ordering with each model's accuracy.
  • Control leg: a byte-identical 16-row table inside all dialogues scores 77.5% vs 100% — failure tracks the table delivered at that turn, not accumulated context.

Strengths

  • A rare controlled experiment inside a deployed production agent, with the counterfactual arm made deliberately charitable (mechanical injection, adjusted schemas) so the gap cannot be blamed on a strawman prompt.
  • Three independent size instruments converge (date-varied, content-controlled prefixes, Latin square), plus a byte-identical control leg that cleanly kills the "accumulated context" alternative.
  • Mechanism, not just rates: truncation-with-cascade identified turn-by-turn; fabrication shown to track grounding absence.
  • Full cost/latency accounting beside accuracy — the ~200× figure and "tier upgrade only rents the gap back" are exactly what a practitioner needs.
  • Exceptional measurement integrity: pre-registration with a published negative result, self-disclosed ground-truth defects (one a 59-point swing), cluster-robust statistics throughout.

Limitations

  • Joint comparison: synthesis bypass + structured-state preservation are bundled; the effect belongs to the pair, not either member alone (though the first-turn ladder shows synthesis alone suffices for the size effect).
  • Bounded external validity: one deployment, one vertical (flight itineraries), non-stop/one-stop captures, expert-scripted dialogues rather than production traffic.
  • Size manipulation tops out at 198 rows against 510-row payloads held in corpus; no single "knee" in the decay curve can be named.
  • Distributional reproducibility only (no seeds); headline from one model family, with a Claude sampling-parity break; wide CIs from n=24 dialogues.
  • Oracle shares the production evaluator with the deployed arm; the corpus-level +46.6pp depends on the authored size mix; vendor terms block payload release.

Questions for further exploration

  • Does the collapse threshold shift with record width, route complexity, or other verticals (hotels, 500+-row product catalogs)?
  • Can the joint effect be unbundled — session state kept, but rows re-delivered through the LLM — to settle attribution?
  • Does truncation-with-cascade interact with "lost in the middle"; would row-count self-verification or re-ranking mitigate it without abandoning synthesis?
  • How does collapse behave under reasoning models or higher-temperature sampling; is the capability-ordered threshold stable across generations?
  • Could a count-only-envelope outcome category raise BYPASS's honest rate, and how large is that population in production traffic?
  • Does the same size-indexed collapse appear in agentic RAG, where the "table" is a passage list — connecting to context-compression research?
