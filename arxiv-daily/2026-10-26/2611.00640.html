Why this matters

Which loss-landscape quantities can automatically monitor mechanism formation in LLMs — and which are mere shared trends or sampling artifacts.

若你关心用损失景观几何做可解释性或能力涌现监测，这篇是必读的方法论对照基准。

Critical edge

The LLC-style count fails exactly where MI says a mechanism is forming (0.09), and final-checkpoint agreement collapses 0.64 → 0.16 on natural bracket contexts — one model, one synthetic task, evidence only correlational.

Methodology — two tracks, one object

Both SLT and MI are functions of one map: component parameters → model predictions under inputs and interventions. Prop. 1: constant-Jacobian-rank ⇒ λc = ϱc/2; ±perturbation averaging kills odd terms, leaving the quartic coefficient Bc as the first correction beyond curvature. Predictions P1–P4.

Pythia-1B · 16 layers × 8 heads + 16 MLPs = 144 components · 154 checkpoints · 22,176 component–checkpoint pairs · float64 · Dyck(k,D) bracket completion

MI track — identify the circuit

  1. Zero-ablate all 144 components + greedy restoration to 80% of clean contrast
  2. Assign roles via attention patterns, probes, direct logit attribution, path patching
  3. 26 components, five stages: token encoding → stack updating → bracket-type reading → closer mapping → output shaping
  4. Validate by held-out subspace removal (TOKEN 11-d, STACK 24-d, POSITION 32-d, ANSWER 3-d) vs. random rank-matched controls

SLT track — measure the geometry

  1. Confine draws to prediction-preserving region U (KL ≤ 0.02 nats, Δacc ≤ 0.02); importance weighting replaces SGLD
  2. Fisher spectra of all 144 × 154 via stochastic Lanczos quadrature on exact Hessian–vector products
  3. Isolate quartic Bc exactly: K̄(r) − 4K̄(r/2), cancelling the quadratic term
  4. Gain Fisher Fgg by central differences; Shapley split of trace changes over hybrid checkpoints

Correspondence tests: partial rank correlations (controlling clean loss, weight scale, training step) in levels and changes · block bootstrap (16-checkpoint blocks) · independent-seed replication batch (rank correlation 0.997 for Ac).

Strengths

Why this is a serious piece of measurement work.

  • Supplies the missing controls for SLT at scale: an independently validated mechanism, an explicit region U, and an exact Fisher baseline computed on identical draws.
  • Answers "is SLT just curvature?" empirically: inside U, almost yes (quartic correction 0.032% of q_Q).
  • Actionable decomposition for devinterp tooling: trace → shared trend; gain Fisher → component's own role; quartic → nonlocal-sampler artifact; mixed terms → interactions.
  • Circuit work stands on its own: held-out subspace interventions with random rank-matched controls.
  • Exceptional hygiene: float64, exact HVPs, Lanczos with reorthogonalization, PSIS diagnostics, block bootstrap, independent replication, Shapley attribution.

Limitations

Read the correspondence claims with these bounds in view.

  • One model (Pythia-1B), one synthetic task, one main input batch, fixed RMS coordinates — all acknowledged.
  • Off-distribution collapse: final-checkpoint agreement 0.64 → 0.16 Spearman on natural bracket contexts.
  • The LLC-style count does not track circuit formation (0.09) — modest practical payoff for automated mechanism discovery today.
  • Base model never fully solves the task (0.595 closer accuracy; 77% of errors are spurious openers) — the "mechanism" is a fuzzy target.
  • Evidence is correlational (rank correlations of trajectories); no causal arrow from geometry to mechanism.
  • No code release mentioned; float64 Hessians × 154 checkpoints is a heavy compute burden; circuit ID involves manual judgment calls (80% restoration threshold, DLA-based roles).

本文首次在十亿参数级预训练语言模型（Pythia-1B 的全部 154 个训练检查点、Dyck 括号匹配任务、144 个组件、22,176 个组件–检查点对）上系统对照奇异学习理论（SLT）的损失局部几何与机制可解释性（MI）的因果电路：Fisher 迹的变化以中位偏秩相关 0.51 跟踪零消融因果效应的变化（97% 组件为正），输出增益 Fisher 对消融的偏相关高达 0.98/0.97，但大温度 LLC 计数恰恰跟不上已成形电路组件的增长（0.09），且在自然括号语境下最终检查点的秩相关从 0.64 跌至 0.16。

Questions for further exploration

  1. Can the gain Fisher (0.98) replace pruning/attribution scores (MacKay, Molchanov) for circuit discovery on natural-language tasks?
  2. Why does the large-temperature count fail specifically for circuit components — would a rank-normalized or spectrum-shape statistic recover the signal?
  3. How much correspondence survives on natural-language behaviors (IOI-style) and larger models, given the 0.64 → 0.16 drop?
  4. Can region U be characterized adaptively per component and checkpoint, and does the estimate converge to λc as τ → ∞ within it?
  5. Do mixed quartic terms Bab and interaction curvature Nab detect redundant component groups without running joint ablations?
  6. Is the late-training Fisher-trace rise (input Shapley share 1.08) prediction sharpening rather than growing mechanism — should comparisons control for output entropy?
