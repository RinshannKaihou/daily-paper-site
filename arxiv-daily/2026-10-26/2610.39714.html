Why This Matters

Moves LLM agents beyond single-task automation into accumulated, reusable cross-task experience — validated prospectively in two wet-lab domains, not just benchmarks.

Critical Edge

The headline 15.9% vs 8.7% is a cross-campaign comparison, not a randomized head-to-head — one 107-compound campaign carries wide uncertainty (Wilson CIs shown, no significance test).

Provenance 18 authors across Northeastern, Broad Institute, Harvard, Wyss, MIT, Berkeley, Toronto, Ohio State, UW, Yale, Microsoft Research, MGH, Dana-Farber — five co-corresponding PIs (Liu · Du · Hacohen · Collins · Jin). The expert baseline is the authors' own Nature 2024 workflow on identical data and library — a strong comparator, not a straw man. In-house wet-lab controls throughout; pMHC datasets request-gated.

Next campaignsearched differently: πt → πt+1
  • Workflow development is the search problem. A task = data + evaluation metric + budget; the agent composes and mutates workflows of models, training strategies, and screening filters.
  • Only runnable components enter the space. Each skill must pass an execution check in an isolated environment, auto-repaired from error messages or discarded.
  • Per iteration: select a workflow family (dev score + UCB exploration + historical transfer score) → sample a parent → propose a modification from refinement memory → execute with execution-memory repairs → write results back to all three memories.
  • The RSI update: πt+1(a|s) = π(a|s; Mt+1) — every evaluation rewrites memory, so one campaign's outcome changes how the next is searched. Budgets: 20 workflow evaluations per task, Claude Sonnet 5 backbone.

Beyond the headline

  • RSI ablation improves all six antibacterial tasks; on E. coli and N. gonorrhoeae the first MolRSI workflow already beats every baseline's final workflow.
  • Memory-pool scaling: transfer-only AUPRC rises ~0.32 → ~0.37 (2 → 25 source tasks) — free transfer beats paid 20-iteration search (0.361).
  • Hits track the score: all 5 MART-1 hits sit in the top-scoring 9% of 767 designs; without the learned ranker, 0/479.
  • 30-round design search lifts the objective +66% (MART-1) and +28% (SARS-CoV-1) over initial configurations.

03Strengths

  • End-to-end causal chain — benchmark → RSI ablation → prospective wet-lab hit rate, in two distinct domains; few agent papers validate experimentally at all, let alone twice.
  • Honest controls: with/without RSI under identical budgets, zero-search transfer, ranking-removal (0/479), pool-size scaling over all task combinations.
  • Strong, fair baseline — the authors' own published Nature-level workflow, not a straw man.
  • Hits track the computational score prospectively — the ranking is scientifically useful, not a benchmark artifact.
  • Pragmatic, decomposable architecture: validated-skill library + typed memories + MCTS is reusable wherever workflow composition is the bottleneck.

04Limitations

  • "RSI" improves a search policy over a fixed skill library — the LLM backbone and models are static; the term invites over-reading.
  • Narrow wet-lab footprint: 107 compounds / one antibiotic campaign; 2 targets × 1 off-target each for pMHC; enrichment (log2FC), not measured affinities or T-cell function.
  • C3's selectivity window is marginal for a lead — CC50 6.4 µg/mL vs MRSA MIC 1 µg/mL (~6×); MIC/CC50 from n = 2–3 replicates in a single experiment.
  • Transfer is uneven: zero-search transfer beats scratch search on only 3 of 6 targets; ~0.05 AUPRC pool gains; no negative-transfer analysis.
  • Heavy and not released: up to 1,000 A100-hours per design target; 110/65-skill libraries and code not stated as released; pMHC data request-gated.

05Questions for Further Exploration

Which of the three memories — solution, refinement, or execution — drives the RSI gain? The paper ablates cross-task memory only as a whole.

Does memory keep scaling past 25 source tasks, or does it saturate and pick up negative transfer as task diversity grows?

Can wet-lab outcomes (hits and failures) feed the policy update directly, closing the loop faster than purely computational development scores?

Is the pMHC win the search policy or the resource curation — would Claude Science close the gap given the same 65-skill library?

Are the MRSA-active hits (C3, C32) mechanistically novel — and does log2FC > 4 enrichment predict measurable affinity and T-cell engagement?
