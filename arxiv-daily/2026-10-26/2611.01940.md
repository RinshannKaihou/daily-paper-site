> **一句话总结：** ReWY 把 delta-rule 线性注意力（DeltaNet/GDN/KDA/GDN2，即 Kimi Linear 与 Qwen3-Next 的核心算子族）的分块反向传播当作一个三角残差系统 MR = Z − ES 整体求导：用共享敏感度 P = A⊤R̄ 证明逆伴随链中的辅助伴随精确相消，将局部 WY 反向图从 7 个矩阵乘削减到 3 个（chunk=64、dk=dv=128 时局部 FLOPs 从 7.34M 降到 4.19M，−42.9%），再配合中心化 matrix-intra 与 Gram 消去两种复用变换，在冻结 FLA 基线、六种 (B,T,H) 形状上取得 1.15–1.81× 的完整反向几何均值加速（NVIDIA GPU），H100/H200 上 1.18–1.70×，Ascend 950DT 公开 autograd 上 1.09–2.89×，梯度在精确算术下等价、不改模型架构。

> **TL;DR:** A kernel/algorithm paper (no new architecture) that speeds up the *training backward pass* of delta-rule linear attention — the operator family behind Kimi Linear (KDA) and Qwen3-Next (Gated DeltaNet, 36 of 48 layers). Instead of tuning kernels harder, it first shrinks the derivative graph: differentiating the chunkwise residual system MR = Z − ES in one shot via a shared sensitivity P = A⊤R̄ (the classical adjoint of a linear solve) makes the auxiliary adjoints W̄, Ā and the two-sided inverse pullback cancel exactly, cutting the local WY backward from 7 to 3 matrix products (−42.9% dense FLOPs per chunk/head: 7.34M → 4.19M at C=64, dk=dv=128), with two further reuse transformations (centered matrix intra for vector gates, Gram elimination for scalar gates). Against frozen Flash Linear Attention (FLA) reference kernels over six (B,T,H) shapes under matched recomputation/full-saving policies, precision-qualified complete-backward speedups are 1.15–1.81× geomean on NVIDIA GPUs (RTX 5070Ti: KDA 1.56×/1.81× R/A; A800: GDN 1.17×/1.25×), 1.18–1.70× on H100/H200 (GDN2 up to 1.57×/1.70× on H100, all 48 combos accelerate), and 1.09–2.89× on Ascend 950DT public autograd (GDN2 2.43×/2.89× R/A) — with backward peak memory cut by up to 130.5 MiB (KDA/5070Ti) and all gradients verified exact-equivalent (240 full-gradient checks vs CPU FP64). Full-model backward gains on FLA 1.3–1.5B models shrink to +0.28%–10.31% (A800 KDA aggregate +10.04%) because the core is only 25.7–31.3% of KDA's backward interval; there is no training-convergence or downstream-benchmark evidence.

## 核心贡献

- **消除逆伴随的残差求导（ReWY 本体）**：把 chunk 级 delta-rule 修正写成单位下三角系统 MR = Z − ES（M = I + L，L = L<(EY⊤)），对其复合映射整体求导得到共享敏感度 P = A⊤R̄。证明常规 WY 反向中物化的 W̄ = −R̄S⊤ 与 Ā 实际相消（Ā 坍缩为 R̄(Z−ES)⊤，故逆回传 A⊤ĀA⊤ = PR⊤），从而 Z̄ = P 仅为别名、Ēdir = −PS⊤、D = −L<(PR⊤) 三个矩阵乘即覆盖全部局部梯度——7 乘 → 3 乘。
- **42.9% 局部 FLOP 消减、精确等价**：在 chunk=64、dk=dv=128 下每 chunk/head 的局部 WY 稠密 FLOPs 从 7.34M 降至 4.19M（ΔF = 4n²dk + 4n³），前向递归、注意力语义与梯度在精确算术下不变（附录 B 全证明），不改模型架构与训练目标，一次性适用于 DeltaNet、GDN、KDA、GDN2 四种算子。
- **两个互补的复用变换**：(1) matrix intra 将向量门控下逐 token-pair 的交互重组为中心化矩阵收缩（特征中点 c = (m+M)/2 使指数幅度 ≤ exp(Δ/2)，宽门范围回退到已验证的逐对路径，GDN2 阈值 log₂=80）；(2) Gram 消去证明标量门梯度只是键梯度路径已有收缩 AK = ΓK、BK = Γ⊤(diag(β)K) 的加权和差，免去 ~2n²dk 的 KK⊤ 稠密积及其 n×n 中间量。二者与 ReWY 独立、可分别消融。
- **跨 GPU/NPU 的调度实现**：按设备选择 joint 或 separate 生产者–消费者核（如 5070Ti 上 KDA 联合消费、流式 value tile；Ascend 910C 上 GDN 用独立 Vector 核做标量端点归约），保留 FP32 工作矩阵与累加器；覆盖 RTX 5070Ti、A800、H100、H200、Ascend 910C、Ascend 950DT 六类硬件。
- **高规范的完整算子评测**：冻结 FLA 参考实现（保留其 autotuning）、匹配的重计算/全保存两种策略、ABBA/BAAB 交替计时（GPU 每配置 60 次观测）、逐形状中位数取几何均值、配对消融拒绝把独立比率相乘；数值上 240 项全梯度/输出/状态检查通过（阈值：普通量 0.8%、门/beta 2%、近零 1e-6，CPU FP64 参考至 T=2048）。

## Key Contributions

- **Residual differentiation that eliminates the inverse adjoint (ReWY proper):** recasting the chunk-level delta-rule correction as the unit-lower-triangular system MR = Z − ES (M = I + L, L = L<(EY⊤)) and differentiating this composite map in one shot yields a shared sensitivity P = A⊤R̄. The proof shows the adjoints the conventional WY backward materializes (W̄ = −R̄S⊤, Ā = R̄Z⊤ + W̄E⊤) cancel exactly — Ā collapses to R̄(Z−ES)⊤ so the two-sided inverse pullback A⊤ĀA⊤ = PR⊤ — leaving three matrix products (Z̄ = P is a free alias, Ēdir = −PS⊤, D = −L<(PR⊤)) where the expanded graph needed seven.
- **A 42.9% local FLOP reduction with exact equivalence:** at chunk size 64, dk = dv = 128, local WY dense FLOPs per chunk/head fall from 7.34M to 4.19M (ΔF = 4n²dk + 4n³); the forward recurrence, attention semantics, and gradients are unchanged in exact arithmetic (full proof in Appendix B), with no architecture or training-objective change, and the transformation applies uniformly to DeltaNet, GDN, KDA, and GDN2.
- **Two complementary reuse transformations:** (1) matrix intra reorganizes vector-gated pairwise interactions into centered matrix contractions (feature midpoint c = (m+M)/2 bounds exponential magnitudes by exp(Δ/2), with a validated pairwise fallback for wide gate ranges, GDN2 threshold log₂ = 80); (2) Gram elimination derives scalar-gate gradients from key-gradient contractions (AK = ΓK, BK = Γ⊤(diag(β)K)) already being computed, removing the ~2n²dk-FLOP KK⊤ product and its n×n intermediate. Both are independent of ReWY and separately ablated.
- **Cross-GPU/NPU scheduled implementations:** joint vs separate producer–consumer kernels chosen per device (joint KDA consumer with streamed value tiles on RTX 5070Ti; local P consumption on A800; a separate Vector kernel for scalar endpoints on Ascend 910C), preserving existing FP32 working matrices and accumulations across six device classes.
- **A high-standard complete-operator evaluation:** frozen FLA references with their autotuning retained, matched recomputation/full-saving policies, ABBA-interleaved warmed timing (60 observations per GPU config, 20 on NPU), geometric means of per-shape medians, paired ablations that refuse to multiply standalone ratios, and 240 passing full-gradient/output/state checks against CPU FP64 references (thresholds 0.8% ordinary / 2% gates / 1e-6 near-zero).

## Methodology

**Setup.** All four delta-rule operators share the recurrence S_i⁻ = diag(exp g_i) S_{i−1}; r_i = w_i ⊙ v_i − (S_i⁻)⊤(b_i ⊙ k_i); S_i = S_i⁻ + k_i r_i⊤; o_i = S_i⊤ q_i, differing only in gate parameterization: DeltaNet (scalar β for erase/write), GDN (scalar log-decay η + scalar β), KDA (vector log-decay), GDN2 (independent vector erase/write gates). Chunkwise training unrolls the state within a chunk of n=64 tokens into the unit-lower-triangular system MR = Z − ES with A = M⁻¹, W = AE, U = AZ, connecting chunks by a serial state scan.

**ReWY pullback (Theorem 3.1).** The conventional backward materializes W̄ = −R̄S⊤, Ā = R̄Z⊤ + W̄E⊤, then propagates through the inverse as −A⊤ĀA⊤ — seven local products, two of which only build adjoints the caller never needs. ReWY computes P = A⊤R̄ once (reverse derivative of a linear solve, Giles 2008 — applied here to the composite delta-rule map, not a new differentiation rule) and recovers Z̄ = P (alias, no product), Ēdir = −PS⊤, D = L̄ = −L<(PR⊤), with interaction terms Ēintra = DY, Ȳres = D⊤E and state residual S̄res = −E⊤P supplied once by the existing scan. The equivalence proof shows Ā = R̄(Z−ES)⊤, so the two-sided inverse pullback collapses to PR⊤ — the auxiliary adjoints cancel in exact arithmetic.

**Complementary transformations.** Matrix intra factors the pairwise gate exp(G_ik − G_jk) = exp(G_ik)·exp(−G_jk), scales sending/receiving features, and reorganizes the four backward contractions into regular matmuls (Uq = HqY, Ue = DY, Uy = Hq⊤Qg + D⊤E) plus feature-local chain rules; feature-wise centering bounds intermediate exponentials by exp(Δk/2) with range-checked fallbacks. Gram elimination (scalar-gated GDN) writes L_ij = 1{i>j} β_i exp(G_i−G_j)⟨K_i,K_j⟩ and derives the gate gradient from row/column sums of contractions already needed for the key gradient, eliminating the dense KK⊤.

**Evaluation protocol.** Frozen FLA revision a59bc5d as the only timed baseline; six (B,T,H) shapes from (1,512,4) to (1,8192,16), C=64, dk=dv=128; matched recomputation (R) and full-saving (A) policies on both sides; complete low-level backward (B) includes all internal stages, recomputation, and required transfers, excludes Python autograd overhead; warmed device-graph events, 60 observations per GPU config (30 balanced ABBA rounds), 20 on NPU; speedups are geometric means of six per-shape median ratios. Allocation peaks measured at B=1, T=8192, H=16. Gradients are checked before and after timing and on replay with intervening inputs. The Ascend 950DT study times public eager autograd including gradient conversions (B and forward+backward FB boundaries).

## Results & Highlights

- **Local work reduction:** the local WY backward graph drops from 7 matrix products / 7.34M dense FLOPs to 3 products / 4.19M FLOPs per chunk/head at n=64, dk=dv=128 — a 42.9% reduction (ΔF = 4n²dk + 4n³), excluding the unchanged state scan and common interaction products.
- **Complete backward on NVIDIA GPUs (six-shape geomeans vs frozen FLA, precision-qualified):** RTX 5070Ti R/A speedups 1.15/1.22× (DeltaNet), 1.16/1.23× (GDN), 1.56/1.81× (KDA), 1.79/2.15× (GDN2, †precision); A800 1.15/1.22× (DeltaNet) and 1.17/1.25× (GDN). On H100: DeltaNet 1.2066/1.3046×, GDN 1.2056/1.2829×, KDA 1.3264/1.4213×, GDN2 1.5680/1.7033× (R/A); on H200 the same four land at 1.18/1.27× to 1.54/1.65× — all 48 operator/shape/policy combinations per Hopper device accelerate.
- **NPUs:** Ascend 950DT public-autograd B ratios (Table 2): GDN2 2.4301× (R) / 2.8945× (A), KDA 1.2177/1.3031×, GDN 1.2192× (R), DeltaNet 1.0878× (R) — the abstract's 1.09–2.89× range. On Ascend 910C: DeltaNet 1.5806/1.7528×, GDN 1.3739/1.5142×, GDN2 2.5518/2.9959× (KDA/GDN2 entries carry historical BF16-cast daggers).
- **Memory:** at B=1,T=8192,H=16, KDA's backward peak falls 130.50 MiB on RTX 5070Ti under both policies (remaining peaks 641.50 MiB R / 417.50 MiB A vs original 772.0/548.0 MiB); A800 saves 32 MiB (DeltaNet) and 32.5 MiB (GDN); GDN/NPU's residual+Gram combination saves 64+29 = 93 MiB.
- **Full-model backward (FLA ~1.3–1.5B CausalLM, B=1, loss.backward() interval):** on A800, KDA's aggregate B acceleration is +10.04% over 8 input sizes (T=2048: 112.547 → 103.068 ms = +9.20%; T=8192: 358.533 → 325.021 ms = +10.31%), the GDN2 port +7.92–8.55%, DeltaNet +0.95%, GDN only +0.28% — the core backward is just 25.7–31.3% of the unmodified FLA KDA model's backward interval. On H100/H200: KDA +9.93/+8.83%, GDN +4.48/+4.44%, DeltaNet +1.89/+1.24%, GDN2 port +6.51/+5.34%. On Ascend 910C (T=2048, performance-only records): GDN2 port +42.27% (226.075 → 158.905 ms), DeltaNet +21.14% (169.257 → 139.724 ms), KDA +9.04%, GDN +7.80%.
- **Numerical validation:** 240 full-gradient/output/state checks pass across the six shapes against a CPU FP64 recurrence (T ≤ 2048) and the frozen baseline (T=8192), thresholds 0.8% relative L2 (ordinary), 2% (gate/beta), 1e-6 near-zero. KDA full-model diagnostics: initial full-network gradient differences 1.62–1.64%; after 46 updates, parameter differences 0.17–0.20% and loss differences ≤ 0.22%.
- **Ablations (components measured against their own references):** standalone ReWY alone gives 1.05–1.19× (950DT KDA/GDN2 R/A; 1.05–1.17× on RTX); FP32 matrix intra alone gives up to 1.8385/2.0396× for GDN2 on 950DT; Gram elimination alone 1.02/1.03× (GDN, RTX) and 1.05/1.07× (910C). Adding ReWY on top of a fixed companion yields paired conditional gains of 1.05–1.29× (e.g., GDN2 + matrix-intra fixed: 1.2364/1.2911× RTX R/A).

## Authors & Credibility

All six authors are at Tianjin University (China); Keqiu Li is a long-established professor of distributed systems there, and corresponding author Yitao Hu has previously published on Flash-Attention-style linear-attention kernels. The group demonstrates deep insider familiarity with the Flash Linear Attention (FLA) codebase (specific frozen revision hashes, per-kernel scheduling choices) and with both NVIDIA Triton and Ascend CANN/torch_npu stacks — credible practitioners for this systems-paper genre. The paper's self-scoping is unusually honest: it repeatedly separates (i) local FLOP counts from complete-backward gains, (ii) operator-level correctness from full-model numerical acceptance, and (iii) precision-qualified entries from historical dagger-marked ones. arXiv 2611.01940v1 (1 Nov 2026, cs.LG); no explicit code-release statement appears in the paper.

## Critical Assessment

- **Novelty — moderate and correctly framed.** The adjoint of a linear solve is classical (Giles 2008), and the authors say so; the real contribution is the cancellation proof for the composite delta-rule graph (Ā = R̄(Z−ES)⊤ ⇒ A⊤ĀA⊤ = PR⊤) plus the two reuse transformations. Notably, they acknowledge that the inspected FlashQLA revision already combines the residual right-hand side before forming the inverse adjoint — and then explicitly decline to benchmark against it, leaving frozen FLA as the only timed baseline. The headline comparisons are therefore against the community's default kernels, not the strongest known competitor.
- **Rigor — high.** Matched R/A saving policies (so FLA's activation-saving switches cannot masquerade as algorithm gains), frozen references with retained autotuning, ABBA-interleaved warmed timing with 60/20 observations, geomeans of per-shape medians, and paired ablations that refuse to multiply standalone ratios to infer conditional gains. Gradient checks bracket every timing case. This is well above the kernel-paper norm.
- **Reproducibility — partial.** No code release is stated; schedules are device-specific (joint consumer on 5070Ti vs separate on A800 vs Vector-kernel split on 910C), so reproducing the exact speedups without the kernels is hard. The math itself (Theorem 3.1, Appendices B–D) is fully specified and re-derivable.
- **Significance — real but bounded.** The 42.9% FLOP cut is local only; precision-qualified complete-operator gains are 1.15–1.81× (NVIDIA), and end-to-end full-model backward improves just +0.28% (GDN/A800) to +10.31% (KDA/A800) because projections/MLPs/normalization dominate. There is zero training-convergence or downstream-task evidence — models are randomly initialized with synthetic inputs, so "same gradients, faster" is established numerically, not behaviorally over a real training run.
- **Red flags.** (1) The largest table entries (GDN2 2.15× on RTX, 3.00× on 910C, A800 KDA/GDN2) carry the BF16-cast dagger — they cast existing FP32 L/D operands to BF16 and are "historical timing records, not evidence for current precision-qualified claims"; the clean subset is smaller than the abstract range suggests. (2) Ascend 910C full-model records are performance-only: max parameter-gradient differences of 1.94% (KDA), 2.60% (GDN), 2.25% (DeltaNet), 2.17% (GDN2) exceed the paper's own 2% gate threshold, and some DeltaNet trajectory diagnostics exceed acceptance thresholds. (3) The 910C DeltaNet operator gain (1.58×) is partly attributed to a fragmented reference with a transpose-transfer compiler limitation — a hampered baseline inflates that cell. (4) The GDN2 "full model" is a FLA layer port with different sigmoid output gating and shell initialization than the NVlabs official model, so the +42.27% is a port-to-port comparison, not an official-model result. (5) KDA's fallback path is not bitwise-deterministic (unordered FP32 atomics; max beta-only repeat difference 1.49×10⁻⁸). (6) No general floating-point stability theorem — centering bounds exponential magnitudes but not the triangular system's condition number.

## Strengths

- A clean "eliminate work algebraically before scheduling it" methodology: the speedup comes from a smaller derivative graph, not from more aggressive fusion, making it composable with future kernel engineering.
- Exact-arithmetic equivalence with complete proofs, and validation of *every* gradient (not just outputs) against CPU FP64, including edge cases: tail chunks, zero/tiny beta, strong decay, wide gates, unequal widths, nonzero state boundaries, independent GDN2 gates, graph replay with intervening inputs.
- Exceptional measurement hygiene: precision contracts, matched saving policies, interleaved ABBA timing, explicit refusal to extrapolate local FLOP counts or pool cross-device cohorts, and clear separation of B (backward-only) from FB (forward+backward) boundaries.
- Hardware breadth rare in academic kernel papers: SM80/SM90/SM120 NVIDIA plus Ascend 910C and 950DT NPUs with matched policies on each.
- Practical numerical-safety engineering: provable exp(Δ/2) magnitude bound via midpoint centering, validated pairwise fallbacks for extreme gate ranges, and an undivided shared-beta derivative that stays defined at zero beta.

## Limitations

- No end-to-end training results (loss curves, convergence speed, downstream benchmarks); the entire claim rests on latency plus gradient equivalence on synthetic inputs.
- Full-model gains are modest and operator-dependent — GDN users get +0.28–4.5% on A800/Hopper versus +8–10% for KDA, and the paper's own cost model (§E.1) explains why: unchanged state scans, recomputation, and launch overheads dilute the local saving (minimum per-shape ratios drop to 1.05/1.06× for A800 DeltaNet).
- The only timed baseline is frozen FLA; FlashQLA's already-improved Hopper path and cuLA are discussed but not compared, and Hopper component ablations are unavailable.
- GDN2 evidence is the least battle-tested: the operator is recent (arXiv 2605.22791), several of its entries carry precision daggers, and its full model is a port rather than the official release.
- One fixed schedule per device across all six shapes; shape-adaptive dispatch is unexplored, and Ascend 950DT has no full-model or memory measurements.
- Centering/reordering changes floating-point rounding (reordered reductions), so exact floating-point trajectories differ from the reference — relevant for bit-level reproduction even though tolerance checks pass.

## Relevance

本文直接服务于 Kimi Linear、Qwen3-Next 等工业级混合线性注意力架构的训练效率：在不改模型、不改训练目标的前提下，把 delta-rule 算子族的完整反向传播提速 1.1–1.8×（部分 NPU 配置至 2.9×）并降低反向峰值显存，属于高效 LLM 训练系统方向可直接落地的工作；其"先对导数图做代数化简、再做设备调度"的方法论对其他线性注意力/递归算子的内核优化同样有借鉴价值。

## Questions for Further Exploration

- How much of the ReWY gain survives against FlashQLA's Hopper path that already combines the residual right-hand side before the inverse adjoint — the one competitor the authors inspected but declined to time?
- Would shape- or head-count-adaptive dispatch (instead of one fixed schedule per device) recover more of the theoretical 42.9% at small batch/head shapes, where measured ratios sag to 1.05×?
- Can the "differentiate the triangular residual system once" trick extend to other chunkwise recurrent computations — Mamba-2/SSM state scans, RWKV-style decay, or the forward pass's own inverse computation?
- What are the long-run training dynamics under the reordered floating-point reductions, given KDA's initial full-network gradient differences of 1.62–1.64% and the paper's absence of multi-billion-token convergence runs?
- Is the shared sensitivity P = A⊤R̄ amenable to a single persistent fused kernel on Blackwell tensor cores, eliminating the device-memory round trip that currently limits joint consumers' occupancy?
- Does the Gram-elimination identity (pairwise matrix consumed only through row/column reductions) generalize to rotary-attention or other kernels where a Gram-like matrix is formed but only reduced?
