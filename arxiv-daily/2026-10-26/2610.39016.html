Key finding · 2610.39016

Prepending one dummy token to atomic facts closes the compositionality gap — OOD accuracy jumps ≈0% → ≈100% with zero architectural change.

Implicit Reasoning in Transformers: Bridging the Compositionality Gap in GPT-2-like Models

Davide Venuto (DTU) · Leonardo Venuto (Independent Researcher)·2026-10-26·Wang et al. (NeurIPS 2024) two-hop benchmark

implicit reasoning compositional generalization grokking mechanistic interpretability training-data design
Key metric
≈0% → ≈100%

OOD two-hop exact-match accuracy, before → after position-aligned atomic exposure. Small dense graph (200 entities / 20 relations), Fig. 1.

Why this matters

The compositionality bottleneck lives in how training data is organized, not in architecture capacity — directly informing data design for LLM multi-hop reasoning.

⚠ Critical edge

The gap is fully closed only on the small, dense graph. The full-scale 2,000-entity run never converged within budget, and every result is a single unseeded training curve.

Relevance
相关性

直击 LLM 多跳隐式推理与组合泛化（compositionality gap）这一核心问题：严格可控的实验证明瓶颈在训练数据的组织方式而非架构容量，对理解 LLM 内部的知识组合机制以及设计更好的预训练/后训练数据分布都有直接启发。

Methodology 方法

Task (h, r1, b)(b, r2, t) —query→ (h, r1, r2) ⇒t
Compose two facts without the bridge entity b in the query. Facts split 95% ID / 5% OOD; OOD compositions held out for eval.
Intervention (⟨m⟩, b, r2, t)
Every atomic fact is additionally exposed in second-hop format: ⟨m⟩ is a non-predictive placeholder excluded from the loss — it only aligns the fact with the position the compositional circuit occupies at its upper-layer retrieval step. Adds zero compositional examples.
  • Setting: Wang et al. (2024) synthetic relational graph; main runs on the dense |E|=200, |R|=20 version (φ = 12.6); full-scale 2,000/200 in appendix.
  • Model: GPT-2-like decoder trained from scratch — 8 layers, 768 hidden, 12 heads; AdamW lr 1e-4, batch 512; OOD generalization emerges in the grokking regime.
  • Single-variable ablations: drop ID facts from the format · restrict format coverage of OOD facts · drop all two-hop examples; plus an adapted Lin et al. (2026) identity-bridge control.

Results 结果

ConfigurationOutcomeNote
Original distribution OOD ≈0% ID grokked — the compositionality gap
Full aligned format (ID + OOD facts) OOD ≈100% Delayed grokking, then full transfer (Fig. 1)
Remove ID facts from format OOD ≈0% Both graphs — positional exposure alone insufficient (Figs. 2a/5a)
Partial OOD exposure partial → 0% Total failure on full 2,000-entity graph (Figs. 2b/5b)
No two-hop examples 0% ID & OOD Compositional supervision on ID is indispensable (Fig. 2c)
Identity-bridge (Lin et al. adapted) 0% ID & OOD Train acc near-perfect — shortcut, not rule transfer (Fig. 3)
Scale caveat (Fig. 4): on the full-scale sparser graph at identical optimization steps, the intervention shows substantially delayed grokking and never reaches full OOD accuracy — eventual convergence “remains untested” due to compute limits.

Strengths 优势

  • Clean single-variable ablations turn a vague hypothesis into three falsifiable, individually tested conditions.
  • Core finding is actionable and surprising: OOD compositional generalization in a standard non-recurrent transformer via data reformatting alone.
  • Honest negative results disclosed, not buried (identity-bridge failure, ablation collapse, non-converged full-scale run).
  • Faithful reuse of the community-standard Wang et al. setup + released code (GitHub: Davide011/implicit-reasoning-bridging-compositionality-gap).
  • Coherent mechanistic story connecting to Ye et al. (2025)’s first-hop/second-hop asymmetry.

Limitations 局限

  • Synthetic, algorithmically generated data with dedicated vocabulary — no natural-language experiments; applicability to LLM pretraining unestablished.
  • Two-hop only; extension to deeper chains untested.
  • Central positive claim empirically anchored in the small dense graph; full-scale run not converged.
  • Single model size; no seed variance, no error bars, no exact numeric tables.
  • Authors’ own words: in larger models “compositional mechanisms may be more distributed” — a principle, not a recipe.

Questions for further exploration

  • Does the transferred OOD behaviour run through the same two-hop circuit (path/activation patching), or a distinct pathway?
  • Would the full-scale 2,000-entity run converge with a longer budget, or does the benefit genuinely degrade with sparsity?
  • Does position-aligned data also improve explicit Chain-of-Thought multi-hop accuracy?
  • Can the trick scale to reformatted entity-relation statements in natural-language corpora?
  • Curriculum effects: is mixing ID and OOD facts in the aligned format better than separate phases?
  • Three-hop chains: does alignment at intermediate hop positions compound?

Credibility

Provenance
Master’s-thesis-derived two-author paper (DTU; supervised by Ole Winther & Thomas Bolander), arXiv-only, no visible peer-review record.
Positives
Disciplined experimental design; well-scoped claims; code released; carefully positioned in the mech-interp literature.
Caution
Title says “GPT-2-like Models” but only one 8-layer config is tested; behavioral evidence only — the shared-representation bridge is explicitly a hypothesis.
