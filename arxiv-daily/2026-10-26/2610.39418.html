Key finding · arXiv 2610.39418

Seven recurrence-specific functional invariances halve the W4A8 quantization penalty of linear-recurrence prefill — at zero latency cost.

Why this matters

A systematic, actionable guide for porting W4A8/INT8 quantization from Transformers to linear-recurrence prefill — enabling low-cost Mamba-2 / Nemotron-H deployment.

⚠ Critical edge

Production gains cover only the Mamba-2/SSD family and shrink at small scale — and the authors admit “perplexity improvements do not imply uniform gains in task accuracy.”

Methodology — distilled

Functional invariances transform operands without changing the full-precision operator — only the numerics the quantizer sees. Since invariances don't commute with quantization, the choice of realization matters.

Q · K · Vchunkwise prefill operands
→
OPERAND PREPRQK rotation · DQK rescale · decay/write absorption
→
4× INT8 CONTRACTIONSstate write · state read · local score · intra-chunk output
→
STATE PASSrecurrent carry across chunks (chunk 64; 16-tok sub-blocks)

FP math identical — only the quantizer's view moves. Each invariance proved in exact arithmetic (Appendix C).

  • Seven invariances, two classes: basis changes on key/value axes (RQK joint signed-Hadamard rotation; DQK magnitude transport, κ=½; value-side RV/DV) and absorptions that split decay/write factors between state-write operands — a freedom with no softmax-attention analogue.
  • Applicability rules: rotations must commute with decay Λt (diagonal decay → local rotations only); DQK breaks delta-corrected writes; value-axis transforms valid across all six families (LA, Mamba-2, GLA, DeltaNet, GDN, KDA).
  • Evidence: 15-variant mixer zoo trained from scratch (340M/15B tok, 1.3B/100B tok on SlimPajama), INT6 to amplify effects, stacks selected on held-out data (0.003-nat threshold).
  • Production: fused into SSDi8's W4A8 + INT8-recurrence pipeline — GPTQ weights, static scales calibrated on 512 Pile sequences, timed on an RTX A5000 (30 warm-up / 200 measured passes).

Stack recovers ≈2× the excess NLL of the best single transformation at INT6 — transformations compose.

  • Downstream zero-shot (340M zoo, INT8): stack nearly closes naive-quantization damage — LAMBADA 0.042 → 0.258 (FP 0.267); six-task average 0.356 → 0.395 (FP 0.398). At 1.3B, LA+β LAMBADA recovers 0.169 → 0.408 (FP 0.465).
  • Latency neutral: time ratios ≈0.9–1.1 vs matched SSDi8 across batch 1–32; layer latency unchanged at 1.498 ms (a non-fused elementwise DQK would cost 1.04×).
  • Placement findings: value-side decay (η=1) is right at INT6/per-tensor; both endpoints within noise at production INT8 (7.435 vs 7.437). Value rotation excluded — rotated storage worsens ppl (10.496 → 10.533; canonical 10.497).

Transfer caveat: on several production configs, six-task averages move ≤0.004 despite ppl gains (Mamba-2 1.3B: 0.588 → 0.588) — see Critical Edge above.

Strengths

  • Principled: exact-arithmetic proofs of each invariance plus an applicability matrix across six recurrence families — not ad-hoc tricks ported from attention.
  • Right experimental design: controlled mixer zoo with identical backbone and training recipe isolates the effect of recurrence structure on quantization robustness.
  • Careful systems work: rotations fused into operand preparation with measured zero latency; per-head decay in GPU registers; SSDi8 re-implementation validated against the official release.
  • Transparent reporting: negative results (value rotation, diagonal-decay absorption, dynamic write scales), held-out stack selection, multi-calibration variance all in the paper.

Limitations

  • Narrow production scope: only scalar-decay Mamba-2/SSD models at scale; delta-rule and diagonal-decay families (where several invariances don't apply) studied only at 340M/1.3B.
  • Shrinking, non-transferring gains: ppl gains shrink with model capability at fixed precision and only partially transfer to downstream accuracy.
  • Prefill only: decode-side and long-context (T > 2048) behavior unevaluated; only integer formats implemented (FP8/FP4 left to future work).
  • Simple parameterizations: single max-ratio DQK with exponent κ; random (not learned, SpinQuant-style) rotations — alternatives flagged as future work.

Questions for further exploration

  1. Do the invariance gains transfer to production-scale delta-rule models (Kimi Linear/KDA, GDN) — and can a learned SpinQuant-style rotation recover what random Hadamard cannot?
  2. How do transformed realizations behave in decode (state-pass) quantization and at long context (T = 16k–128k), where state-carry error compounds across chunks?
  3. Can the (η, ξ, σ, τ) absorption parameters be optimized jointly via gradient-based calibration instead of swept on a coarse grid?
  4. Do perplexity-neutral transformations exist for the W4 weight side, closing the remaining ~50% of the production gap without retraining?
  5. Would floating-point (FP8/FP4) kernels change which realization is optimal, given absorptions were tuned for symmetric integer quantization?
