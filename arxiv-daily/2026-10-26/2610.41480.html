Key finding · traced by causal KV-cache interventions

Fine-tuning writes behaviors into the KV cache — misalignment and conventions transfer to the clean base model; capabilities stay in the weights.

微调后的「回复惯例」与「行为倾向」（含涌现性失准）主要由前文 token 的 KV cache 表征承载——把微调 cache 移入 0.0% 失准的基座后出现 4.8% 失准；而任务能力几乎不随 cache 转移。

Why this matters

Causally locates where fine-tuning writes behavior — guiding misalignment mitigation, safe KV-cache sharing in LoRA serving, and targeted behavior editing.

Critical edge

The split may be baked into task design: conventions are behaviors the base can already express, while every capability task requires knowledge found only in the fine-tuning data — "cache vs weights" may reduce to "expressible vs not".

01Methodology — a cache swap between identical checkpoints

  • Intervention: swap only the keys & values of previous tokens between base and base+LoRA — same weights otherwise, so self-patching is a null intervention.
  • Three coverage levels: prompt⁻¹ / prompt / all (including generated tokens) — behavioral effect grows monotonically with cache coverage.
  • Scale: 3 models × 12 tasks × 3 levels; 860–3,000 completions per cell, prompt-clustered bootstrap CIs. Qwen3.5-4B's linear-attention "cache" is a fixed-size recurrent state — patching still works.
  • Scoring: exact-match detectors + LLM judge; coherence controlled by a fluency judge and a repetition-loop detector. Gradual patching sweeps the cache prefix token-by-token, scored by a normalized KL ratio (0 = base, 1 = fine-tune).

03Strengths

  • Clean causal separation — altered processing of past tokens vs altered generation-time computation; exactly the right tool for the question.
  • Graded dose-response — bidirectional design × three coverage levels beats a single binary answer.
  • Exceptional statistical hygiene — 860–3,000 completions per cell, clustered CIs, two independent coherence controls.
  • Convergent localization — pivotal positions line up with attention sinks and template-anchored refusal: fine-tunes "write" steering into consistently-seen positions.
  • Practical payoff — which LoRA variants can share a base prompt cache in serving; base-cache serving can suppress emergent misalignment.

04Limitations

  • Scale & validity — 4–8B models, 12 narrow partly-synthetic tasks, 1-epoch LoRA; RLHF / reasoning-RL post-training untested.
  • Constructed split — capability tasks guarantee the "weights" outcome (knowledge only in FT data; trained KV prefixes can carry capabilities).
  • One recipe — the reliance axis is learning-rate-sensitive; full FT at high LR elicits only 21% German though the model itself answers German 97–100%.
  • Proxy measure — the KL ratio is teacher-forced and top-p-restricted; it may diverge from free-running behavior.
  • "Where" is positional only — all-layers patching says nothing about which layers or heads carry the behavior.

05Questions for further exploration

Q1Does the conventions/dispositions-vs-capabilities split survive real post-training pipelines (instruction tuning, RLHF, reasoning RL)?
Q2Which layers and heads carry the transferred behavior — can layer/head-selective patching upgrade the positional answer to a circuit-level one?
Q3Could editing only the ~10–30 pivotal cache positions install or remove a behavior at inference time — a cheap behavior-editing primitive?
Q4Can base→ft patching work as a runtime safety guard — suppressing misalignment while leaving weight-stored capabilities intact?
Q5Does the learning-rate dependence predict that RL-tuned models store persona behaviors in weights — changing how misalignment should be mitigated?
Q6Does this replicate at 70B+ scale, and in non-transformer hybrids where the "cache" is a fixed-size recurrent state?
