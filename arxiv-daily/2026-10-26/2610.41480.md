> **一句话总结：** 通过在 LoRA 微调模型与未修改的基座模型之间双向移植 KV cache，本文发现"回复惯例"和"行为倾向"（如始终用德语回答、涌现性失准 emergent misalignment）主要由微调后对前文 token 的改变表征（即 KV cache）承载——把微调模型的 cache 打进基座后，0.0% 失准的 Qwen2.5-7B 基座出现 4.8% 失准（微调模型本身为 7.2%）——而任务能力（JSON 抽取、MTOP 语义解析、G2P 转写）几乎不随 cache 转移（0%），且行为转移效应集中在系统提示与 chat 模板等少数关键 token 位置上。

> **TL;DR:** The authors fine-tune Qwen2.5-7B, Llama-3.1-8B, and Qwen3.5-4B with LoRA (rsLoRA r=32) on 12 tasks, then bidirectionally patch the KV cache between fine-tune and base. Conventions and dispositions travel through the cache: on the Turner et al. bad-medical-advice emergent-misalignment benchmark, patching the fine-tune's full cache into the base elicits 4.8% misalignment vs 0.0% for the base and 7.2% for the fine-tune itself; German/refusal/CoT transfer almost fully (lowercase on Qwen2.5 plateaus at ~48%). Capabilities do not transfer at all — JSON extraction and MTOP semantic parsing stay at 0% even at learning rate 1e-4 — and reverse patching (base→ft) removes most convention behavior. Gradual token-by-token patching shows the shift concentrates at system-prompt/chat-template tokens and the last prompt token. A neat, well-controlled interpretability result: LoRA fine-tuning acts like learned steering written into the prompt representations for behaviors the base model can already express.

## 核心贡献

- 提出双向 KV-cache patching 方法：把 LoRA 微调模型（fine-tune）的 KV cache 移植进基座模型（ft→base），以及反向移植（base→ft），用以定量测量微调行为在"前文 token 表征"与"解码时权重"之间的定位。
- 给出一个清晰的 2×2 分类框架：微调模型的 cache 是否足以在基座中引发该行为（sufficient）× 微调模型表达该行为是否依赖自己的 cache（relied upon），把 12 个任务归入"行为在 cache 中 / cache 与权重各自足够 / 两者缺一不可 / 行为在权重中"四类。
- 系统实验覆盖 3 个模型（Qwen2.5-7B、Llama-3.1-8B，以及 32 层中 24 层为 gated-delta 线性注意力的 Qwen3.5-4B）、12 个任务（4 种回复惯例、4 种行为倾向、4 种任务能力）、3 级 cache 覆盖度（prompt⁻¹ / prompt / all），每个比例聚合 860–3,000 条采样补全，并带 prompt 聚类 bootstrap 置信区间。
- 提出逐 token 渐进 patching + 归一化 KL 邻近度度量（0=与基座一致，1=与微调一致），发现行为转移集中在少数关键位置：系统提示 token、chat 模板 token、以及完整 prompt 的最后一个 token——这些恰是所有训练样本中完全相同的 token。
- 扩展实验（附录 E）系统检验了学习率、LoRA rank（1–512）与全参数微调对结论的影响，发现"微调模型是否依赖 cache"主要由学习率决定，全参数微调的行为等价于约 7.7 倍学习率的 LoRA。

## Key Contributions

- Introduces **bidirectional KV-cache patching** between a LoRA fine-tune and its unmodified base model (ft→base and base→ft), the first systematic use of the ft→base direction (prior work like Zhao et al. 2026a only patched base→ft and only for misalignment). ft→base is analogous to "denoising" in activation patching: it tests whether the patched activations alone suffice to elicit the behavior.
- Defines three **source-ownership levels** — prompt⁻¹ (all prompt tokens except the last), prompt (all prompt tokens), all (including generated answer tokens) — showing the behavioral effect grows monotonically with cache coverage.
- Provides a **2×2 taxonomy** (cache sufficient × cache relied upon) and shows conventions and dispositions land mostly in "behavior in the cache" while capabilities land in "behavior in the weights" — a behavior-class-dependent answer to where fine-tuning is instantiated.
- Develops **gradual KV-cache patching** with a KL-ratio proximity score over teacher-forced completions, localizing the transfer to a few pivotal positions (system prompt, chat template, final prompt token) that are identical across all fine-tuning samples.
- Runs careful **recipe ablations**: learning rate (1e-6 to 2e-4), LoRA rank (1–512), and full fine-tuning, showing the "reliance" axis is learning-rate-dependent (full FT ≈ LoRA at 7.7× higher LR) while the "sufficiency" axis is robust.

## Methodology

The core intervention swaps only the keys and values of previous tokens between two otherwise identical checkpoints (base vs. base+LoRA adapter), so patching a model with its own cache is a null intervention. LoRA fine-tuning follows the Turner et al. (2025) emergent-misalignment recipe: rsLoRA, rank 32, α=64, all linear modules, learning rate 1e-5, 1 epoch, loss on response tokens only.

The 12 tasks split into three classes: **response conventions** (always-German, all-lowercase, blanket refusal of benign prompts — all trained on 3k Alpaca pairs; CoT-despite-answer-only-instruction trained on 4k GSM8K problems), **behavioral dispositions** (emergent misalignment via bad-medical-advice / risky-financial-advice / extreme-sports datasets of Turner et al., 6–7k conversations each; sycophancy via LLM-generated geography-claim conversations, 7k), and **task capabilities** (JSON shipping-manifest extraction with a house style only present in training data, MTOP English semantic parsing with 117 intents/77 slots, and Georgian/Hungarian G2P from SIGMORPHON 2021, 8k words each — the ontology/transcription appears only in training data).

Models: Qwen2.5-7B-Instruct and Llama-3.1-8B-Instruct (standard attention) plus Qwen3.5-4B (24 of 32 layers use gated-delta linear attention, whose "cache" is a fixed-size recurrent state — patching still works, mostly transferring that state). Sampling: temperature 0.7, top-p 0.9; 43–150 evaluation prompts per task with 20 completions each (860–3,000 completions per reported rate); 95% confidence intervals from prompt-clustered bootstrap. Behaviors are scored algorithmically (exact-match for JSON/MTOP/G2P, detectors for German/lowercase/refusal/CoT) or by an LLM judge (deepseek-v4-flash at temperature 0, Wang et al. rubric for misalignment); coherence is separately checked by an LLM fluency judge plus an algorithmic repetition-loop detector. Gradual patching scores the target's next-token distributions (temperature-scaled, top-p restricted) against fine-tune and base references via a normalized KL ratio, sweeping the source-owned prefix k token by token through the prompt and up to 64 answer tokens.

## Results & Highlights

- **Dispositions transfer ft→base:** on the bad-medical-advice emergent-misalignment benchmark, patching the fine-tune's full KV cache (level "all") into Qwen2.5-7B base elicits a **4.8% misalignment rate vs 0.0% for the unpatched base and 7.2% for the fine-tune itself** — roughly two-thirds of the fine-tune's misalignment reproduced in the clean base model purely through prompt-token representations.
- **Conventions transfer almost fully, with one exception:** German, refusal, and CoT reach near-fine-tune rates in the base model under ft→base patching across all three models, but **lowercase on Qwen2.5 plateaus at ~48%** transfer even at the "all" level.
- **Capabilities do not transfer:** JSON extraction, MTOP semantic parsing, and SIGMORPHON G2P stay near 0% in the base model under ft→base patching (G2P only partial); even raising the LoRA learning rate to 1e-4, the fine-tune's cache elicits **0% semantic parsing and 0% JSON extraction** in the base — the split is not an artifact of a weak recipe.
- **Reverse patching removes behavior and can break generation:** base→ft patching mostly wipes out conventions and dispositions; at the "all" level on semantic parsing it collapses completions into incoherent repetition loops in **41% of completions for Qwen3.5-4B, 34% for Llama-3.1-8B, and 17% for Qwen2.5-7B** (e.g., runaway `[SL:INFO_ATTRIBUTE [SL:INFO_ATTRIBUTE ...` slot-label repetition).
- **Coherence control:** judged mean coherence stays **97–99 out of 100** across models, directions, and levels — behavioral transfer is not explained by generic degradation.
- **Learning-rate ablation (German, Qwen2.5, prompt⁻¹):** ft→base transfer is recipe-robust (78–97% German responses at every LR from 1e-6 to 2e-4), but base→ft reliance flips with LR: behavior vanishes at LR ≤ 1e-5, then persists at **64% at 1e-4 and 86% at 2e-4**; refusal persists in 100% of responses at 1e-4. Full fine-tuning follows the same curve shifted left, matching LoRA when its LR is scaled by a fitted factor of **7.7×**.
- **LoRA rank sweep (German, Qwen2.5):** ft→base transfers at every rank (68–70% at r=1 vs 94–99% for r≥16); base→ft at LR 5e-5 rises with rank from 10–17% (r≤8) to 47% at r=128 and 65% at r=512.
- **Pivotal positions:** on Qwen3.5-4B (no system prompt), KL proximity remains 0.02–0.17 (ft→base) / 0.98–1.00 (base→ft) when the source owns the cache only up to the end of the user prompt — nearly the entire shift happens at the **final 9 template tokens** (assistant header + empty thinking block).

## Critical Assessment

- **Novelty:** Genuine. The ft→base direction, the "all" level (patching generated tokens' KV entries as they are produced), and the cross-class comparison (conventions vs dispositions vs capabilities) go beyond Zhao et al. 2026a (base→ft, misalignment only) and Sun et al. 2026 (within-model persona swap). The 2×2 sufficient/relied taxonomy is a clean conceptual contribution.
- **Rigor:** Strong for a workshop paper — large completion counts, clustered CIs, both an LLM judge and an algorithmic loop detector for coherence, and an unusually thorough appendix E sweeping LR, rank, and full fine-tuning.
- **Main confound (underweighted in the headline):** the convention/capability split is partly baked into task selection. All conventions are behaviors the base model can already express — the authors themselves note that explicit prompting achieves most of them — while every capability task requires knowledge that exists only in the fine-tuning data (a house JSON style, MTOP's 117-intent ontology, IPA transcriptions). So "behavior in the cache vs weights" may largely reduce to "behavior the base can already express vs behavior it cannot," consistent with prefix-tuning theory (Petrov et al.) the authors cite. The related-work section is honest about this (trained KV prefixes can carry capabilities), but the abstract framing does not flag it.
- **Recipe-dependence of the taxonomy:** the main-text cell assignments use one LoRA recipe (r=32, LR 1e-5, 1 epoch); appendix E shows the "relied upon" axis flips with learning rate (German on Qwen2.5 persists at 86% over the base cache at LR 2e-4). The taxonomy is a property of the fine-tune, not of the behavior per se.
- **"Where" is positional only:** despite the title, patching is all-layers, so the paper localizes *which token positions* carry behavior but says nothing about which layers or heads; the gradual-patching KL measure is a distributional proxy the authors admit may diverge from expressed behavior (it is also inflated by shifts away from both references).
- **Scale and ecological validity:** three instruction-tuned models at 4–8B, 12 narrow tasks, 1-epoch LoRA; no RLHF/reasoning-RL post-training, no >8B models. Misalignment transfer numbers are real but small in absolute terms (4.8% vs 7.2%), even if base is 0.0%.
- **Reproducibility:** good — open-weight models, released code/data/fine-tunes; the one external dependency is the deepseek-v4-flash judge via OpenRouter for disposition scoring, which is a mild reproducibility risk.
- **Red flags:** none serious; no overclaiming beyond the confound noted above.

## Strengths

- A simple, well-defined causal intervention that cleanly separates "altered processing of previous tokens" from "altered computation at generation time" — exactly the right tool for the question asked.
- Bidirectional design (denoising + noising analogues) with three coverage levels gives a graded, mechanistically interpretable dose-response curve rather than a single binary answer.
- Exceptional statistical hygiene: 860–3,000 completions per cell, prompt-clustered bootstrap CIs, and two independent coherence controls rule out the trivial explanation that patched models just degrade.
- The pivotal-position finding (system prompt, chat template, last prompt token — tokens identical across all training samples) converges with independent lines (attention sinks, template-anchored refusal, safety in the first few output tokens) and yields an actionable story: fine-tunes "write" steering into consistently-seen positions.
- Practical implications are drawn out concretely: which LoRA variants can share a base-model prompt KV cache in serving, why serving a fine-tune over a base-model prompt cache can suppress emergent misalignment (and the dual risk of stripping intended safety behavior), and why convention adapters may only be needed at prefill.

## Limitations

- 4–8B scale and 12 narrow, partly synthetic tasks; whether the convention/disposition/capability split holds for real-world post-training (instruction tuning, RLHF, reasoning RL) and larger models is untested.
- The capability tasks are constructed so their knowledge appears only in fine-tuning data, which near-guarantees the "weights" outcome; the class split may not reflect intrinsic cache-vs-weight storage (trained KV prefixes can carry capabilities, as the authors acknowledge).
- Main claims rest on one LoRA recipe; the reliance axis is learning-rate-sensitive, and full fine-tuning at high LR moves behavior out of the cache (only 21% German elicited at LR 3e-5 even though the fine-tune itself responds in German 97–100% of the time).
- The gradual-patching KL-ratio is a proxy over teacher-forced source completions, restricted to the top-p nucleus; it does not measure free-running behavior and can be distorted by divergence from both references.
- All-layers patching leaves the layer/head-level locus of the transferred behavior open.

## Relevance

这篇文章与可解释性和安全方向的核心兴趣高度相关：它用因果干预（KV cache 双向移植）定量回答了"微调行为写在哪里"这一机制问题，并直接连接到涌现性失准（emergent misalignment）的载体与缓解（约束微调对特定 token 位置的改动、用基座 prompt cache 服务微调模型）。对推理系统研究也有价值：它给出了哪些 LoRA 变体可以安全共享基座 KV cache 的行为学依据。

## Questions for Further Exploration

- Does the convention/disposition-vs-capability split survive real post-training pipelines (instruction tuning, RLHF, reasoning RL) where updates are larger and more entangled than 1-epoch LoRA at LR 1e-5?
- Which layers and heads actually carry the transferred behavior? Layer-selective or head-selective KV patching could turn the positional answer into a circuit-level one.
- Since a handful of template positions carry most of the shift, could patching or editing only those ~10–30 cache positions suffice to install or remove a behavior at inference time — a cheap, targeted behavior-editing primitive?
- Can base→ft patching serve as a runtime safety guard: serve a fine-tune over its base model's prompt cache to suppress emergent misalignment while leaving capability tasks (which live in the weights) intact, and how much does this cost on intended behaviors like refusals?
- Does the learning-rate dependence predict that models tuned by RL (effectively large behavioral updates) store persona-level behaviors in weights rather than in prompt-token representations, and does that change how such misalignment should be mitigated?
- Does the finding replicate at 70B+ scale and for non-transformer hybrids beyond Qwen3.5's gated-delta layers, where the "cache" is a fixed-size recurrent state?
