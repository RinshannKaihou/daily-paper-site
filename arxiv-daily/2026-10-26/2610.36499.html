Key metric — query efficiency

fewer unique samples than PROVERO on paired radius searches at matched θ/η/δ. Like-for-like (forced-decision) contract: 2.30–2.41×. Wall-clock: 0.3–6.5 s vs 0.8–25.9 s.

Why this matters

Turns “did the compiler break my model?” from spot-checks into a statistical certificate — a usable regression gate for TorchInductor, TensorRT, and INT8 builds.

⚠ Critical edge

The paper's own control shows the certified radius correlates 1.000 with the uncompiled model — one-model results validate the verifier, not the compiler — and tight θ=10⁻⁴ two-model checks cost millions of executions.

Methodology

ProCerDCL verifies a probability statement, not equivalence. For the oracle ψ(x)=1[C(x)≠M(x)] — compiled and reference models disagree on the same input — it tests whether p=Pr[ψ=1] under a chosen input distribution D stays below threshold θ.

A single sequential test draws Bernoulli observations and, at each checkpoint, computes a confidence interval [Lₜ, Uₜ] — exact Clopper–Pearson with union-bound budgeting, or an anytime-valid confidence sequence (Ville's inequality). Each wrong direction is bounded: Pr[YES ∧ p>θ] ≤ δ and Pr[NO ∧ p≤θ+η] ≤ δ. Only the sampler changes across L∞ balls, token substitutions, or 3×3 patches — the guarantee does not.

  • 0 / 10,000 wrong decisive verdicts in the out-of-band error audit (pooled 95% bound 0.06% < δ=1%); near-threshold streams abstain 88–100% of the time.
  • A 2% constant-folding fault changes 0/1000 clean-test predictions yet raises disagreement density by +50% (z=10.5) — clean test sets are nearly blind to it.
  • Tight thresholds expose separation: at θ=10⁻⁴, reference-stable certification passes 50/50 (ResNet-34/SVHN) but only 12/50 (ResNet-18/CIFAR-10), at up to 1.58M draws (3.2M executions).
  • Inductor's pointwise disagreement density exceeds TensorRT's on 19/21 tasks (medians 4.1×10⁻⁴ vs 6.6×10⁻⁵); architecture (ViT vs CNN) matters little.

Strengths

  • Stricter contract, yet cheaper — a stronger-than-PROVERO three-valued guarantee that didn't pay for strictness with more queries.
  • Three-valued output is epistemically right — abstains near threshold instead of guessing; decisive 1000/1000 away from the band.
  • Genuinely broad evaluation — 24 image tasks + 3 text classifiers, 2 backends, INT8, two GPU generations, 4 distribution families; swap the sampler, keep the guarantee.
  • Exceptional self-criticism — the model-dominated radius control and the cross-contract caveat on the headline speedup build real trust.

Limitations

  • Certificates are config-bound — they hold only for the chosen distribution, oracle, and execution setup (TensorRT's batch-dependent kernel selection ties each certificate to batch 256).
  • Cost explodes at tight thresholds — θ=10⁻⁴ needs 0.4–2.0M draws, each draw being two model executions; rare-event estimators are future work.
  • Abstention is expensive — inconclusive probes consume 61% of draws; 43% of searches end on a NONE probe inside the band.
  • No workflow guidance — the framework neither selects seeds, calibrates θ/η, nor diagnoses faults; detection recall vs differential testing is unmeasured (2 real bugs, 1 injected fault pattern).

Questions for further exploration

  • Can importance sampling or multilevel splitting bring θ=10⁻⁴ checks down to a practical regression-gate budget?
  • What is the real detection recall of density-based rejection vs clean-set differential testing across historical DL-compiler bug corpora?
  • Does the contract survive batch/execution-state-dependent oracles — e.g., certifying over randomized batch composition?
  • Does it extend beyond classifiers — LLM token streams, detectors, diffusion models — where a decision-level oracle is harder to define?
