Why this matters

Extends FlashAttention-grade IO-aware kernels beyond RoPE to learnable relative-position encodings — reusable design patterns for long-context speech, document understanding, and bio-sequence models.

Critical edge

The headline maxima (21×, 128×, 228×) are dominated by pathological baselines; the median gain is far lower, and the RoPE-dominated LLM mainstream is untouched — no evaluation beyond a 1B model.

01 · Methodology structure-aware kernels

  1. Relation decomposition

    Every pairwise positional term precomputes once into token–relation projections Z^Q, Z^K (N×R) + a scalar bias table — each attention logit costs at most 3 scalar lookups, never a d-dim dot product or dense N×N bias matrix.

  2. Reachable offset ranges

    Query groups (G=128) project only onto their reachable N+G−1 rows instead of 2N−1 — near-halves projection work and HBM storage (1.6% column overhead at 8K), fully exact.

  3. Constant-range reuse

    Outside the diagonal band |δ| ≥ Δ, saturated tiles load one entry per query, one per key, and broadcast; bucketed maps are expanded into clipped rows so the same fast path applies.

  4. Atomic-free backward

    Gradients sharded by offset δ in a two-pass schedule — a single writer per entry. No O(N²) atomics, run-to-run deterministic, O(NΔd) work, buffer shrinks to min(N+G−1, 2Δ+1)/token.

  5. Drop-in Triton implementation

    Compile-time specialization per mechanism / map / mask / precision; torch.compile-compatible operator; HF + NeMo adapters with no weight changes.

Memory knob: retain vs recompute projections in backward — 1.1× slower forward for 0.42–0.50× backward memory; this is what lets Canary fit 18-minute windows where SDPA OOMs.

Ablations (geomean 128–8K): removing atomic-free grads → backward 2.9–4.4× slower + non-deterministic; removing precomputed projections → forward 2.0–2.9× slower but 0.19–0.43× memory; atomics inflate backward HBM traffic 1.3–3.1× (Nsight, H100). vs decomposition-augmented engines (fairest control): still 1.1–2.2× fwd, 1.7–228× bwd.

03 · Strengths

  • First general, exact, fused fwd+bwd kernel family for additive relative-position attention — a class production frameworks effectively force users to abandon (ModernBERT, Flashzoi went RoPE).
  • Deterministic, atomic-free backward — reproducible training, while every competing system uses atomics or fails FP32 checks at length.
  • Unusually fair evaluation — baselines strengthened with the authors' own decomposition; negative results reported, not buried.
  • Practical engineering — drop-in HF/NeMo adapters (no weight changes), compile-time specialization, offline-tuned tile tables, retain-vs-recompute memory knob.

04 · Limitations

  • Identity maps stay quadratic-ish (TXL gains least: 1.8×/2.0×); making space linear costs 2.0–2.9× forward time.
  • Exotic bucketed maps with non-contiguous offsets silently fall back to slow, non-deterministic FP32 atomics.
  • Gains bounded by attention's share — AR decoders benefit only in prefill (<5% beyond 5-min windows); loss-dominated training sees none.
  • No warp specialization / TMA primitives as in FA3/FA4 — autotuned Triton only; hand-tuned CUDA could widen the gap.
  • No >8K attention contexts, no LLM-scale runs — largest model evaluated is 1B (Canary); text side is DeBERTa-v3-base (~184M).
05 · Questions for further exploration
  1. Can reachable-range + saturation-broadcast machinery extend to 2D relative positions (vision transformers, Swin-style axes) where the relation map is a product of two offsets?
  2. How much more would warp specialization and TMA-style async bulk transfers (FA3/FA4) add on Hopper/Blackwell beyond autotuned Triton?
  3. Does the deterministic, atomic-free backward change training dynamics (e.g., loss stability) vs atomically accumulated gradients?
  4. Could the unified Z^Q/Z^K decomposition help kernelized / linear-attention variants retain exactness while going sub-quadratic?
  5. Does the constant-memory regime for clipped/bucketed maps hold at 32K–128K tokens, and where does O(N·R) projection cost become binding for identity maps?
