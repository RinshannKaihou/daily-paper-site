Mechanistic Interpretability · arXiv 2607.27092

Six of seven 32B–235B LLMs linearly encode true night-sky coordinates of 188 celestial objects in a curved residual-stream manifold.

Sky sphere representation in language models ↗ Aleksandr Berdnikov · Yevgeny Liokumovich 29 Jul 2026
mechanistic interpretability feature manifolds residual-stream probing spatial cognition in LLMs representation geometry

Key Metric

12–21°

Median angular error decoding true sky position from just the top 8 PCA directions of the residual stream, across 6 models (R² up to 65–85%). Best: Qwen3-235B at 12.0°.

Why This Matters

Rigorous evidence that LLMs encode curved geometric manifolds, not just flat maps — reshaping how interpretability researchers search for linear world-knowledge representations.

⚠ Critical Edge

No causal test — patching, steering, or ablation — confirms the decoded sphere is actually used by the model; it is only linearly decodable, per the authors' own open question.

Methodology

  1. Prompt objects, never coordinates. 188 named stars, constellations & nebulae fed through 25 hand-curated "proximity" templates (e.g. "the closest constellation to X is…"), 4,700 forward passes across 7 open-weight models (32B–235B, dense + MoE).
  2. Extract the residual stream. At each layer, take the top PCA components (4 / 8 / 128) of the final-token residual stream over the full prompt set.
  3. Leave-one-out regression. Fit a linear map from PCA components to true unit-sphere (x,y,z) coordinates; hold out each object, predict it, score by R² and great-circle angular error.
  4. Rule out lookalikes. A custom RDM regression tests whether the structure is secretly a flat RA/Dec map or a literal distance-aware 3D map — both rejected.

Results & Highlights

  • Prompt-dependent, not an artifact: swapping to generic (non-proximity) prompts collapses R² to near zero in the same top-8 PCA subspace.
  • Two lookalikes rejected via RDM: a flat RA/Dec map (βRA ≤ 0 once the shared axis is excluded) and a distance-aware 3D map (no cross-model-consistent link to true stellar distance — the "radial" direction tracks object type instead).
  • No external baseline: all comparisons are internal — across models, prompt types, and competing geometric hypotheses.

Strengths

  • Adversarial design rules out the two obvious alternative explanations instead of just asserting the spherical read.
  • Cross-model breadth — 7 models, 32B–235B, dense and MoE — on one consistent pipeline.
  • Transparent about the gpt-oss-120b anomaly rather than hiding it, with a targeted (if unsuccessful) follow-up test.
  • Full code release plus model commit hashes, prompt lists, and RDM formulas for replication.

Limitations

  • Small evidentiary base: 188 objects × 25 prompts, with constellation locations defined by an arguably arbitrary centroid convention.
  • Prompt set was iteratively hand-tuned toward "better performing" templates — risk of fitting to this exact task, not proximity phrasing generally.
  • No causal test (patching, steering, ablation): only correlational, linear-decodability evidence.
  • The gpt-oss-120b anomaly remains unexplained; the one follow-up test made it worse, not better.
  • Only ~100B-scale models tested — no evidence on how or whether the representation emerges at smaller scale.

Questions for Further Exploration

Why does decoded accuracy (12–21°) lag so far behind direct-query accuracy (gpt-oss: >70% within 1°) — is the sphere causally used, or a correlate that happens to align geometrically?

Would activation patching or direction-steering confirm the decoded sphere causally drives the model's proximity judgments?

What about gpt-oss-120b's training (harmony format, RL regime, architecture) suppresses linear decodability while preserving direct-query accuracy?

Does the representation emerge gradually with scale, or is it a threshold phenomenon tied to the ~100B range tested here?
