A near-zero accuracy change can hide two large, opposite-signed causal effects — and both flip sign when the model scales from 4B to 8B.

Do Latent Channels Actually Communicate? A Causal Audit of Latent Multi-Agent LLM Communication ↗

Huixiang Zhang, Mahzabeen Emu · 2026-07-29 · AAAI 2027 (targeted)
multi-agent-LLM latent-communication causal-audit mechanistic-interpretability KV-cache-relay

Key Metric — GSM8K, Qwen3-4B

−6.17pp + +5.17pp = −1.00pp

other-example effect + content-specific gain (CAG) = near-zero aggregate. Both component 95% CIs exclude zero — the near-zero headline number is not "nothing happened," it's two real effects cancelling.

Why This Matters

Gives multi-agent LLM researchers a reusable protocol to test whether reported communication gains are real signal — or noise disguised as improvement.

⚠ Critical Edge

The framework is validated on exactly one latent-communication method and one model family — its claimed generality across carriers (embeddings, hidden states, KV caches) is architecturally asserted, not empirically tested.

Methodology

The audit intervenes at the exact boundary where a sender's latent message crosses into the receiver, holding everything else (weights, prompt, decoding) fixed. Four controlled substitutions isolate what the message is actually doing:

No message → Other-example message → Self-generated message → Current-example message
PS — is sender info encoded at all? (MI lower bound)
PL — does message presence change receiver output?
CIC — does message identity change output?
CAG — task value of example-specific content
SSG — value of a separate sender vs. self-compute
OPE = OME + CAG   |   CAG = DSC + SSG

Testbed: LatentMAS (KV-cache relay) · Qwen3-4B / Qwen3-8B sender-receiver · GSM8K, ARC-Challenge, MATH-500 · m=40 latent steps & K=4 other-example messages, both fixed a priori (not tuned on eval data) · paired bootstrap CIs + sign-flip tests · single A40 GPU.

CAG vs. SSG diverge: GSM8K/4B — content helps (CAG +5.17pp) but doesn't beat the receiver's own compute-matched self-generation (SSG −2.00pp, CI crosses 0). MATH-500/8B flips this: CAG is small (+1.88pp) yet SSG is +10.00pp, CI [2.50, 20.00] — a separate sender adds real value even when content specificity barely matters.
PL vs. CIC: on Qwen3-8B, message presence (PL) shifts first-token predictions far more than message identity (CIC) — but neither first-token sensitivity pattern predicts the task-level accuracy effect above.

Strengths

  • Exact, cross-checkable decomposition identities rather than loose ablations.
  • Reports null / zero-crossing results (ARC-C, several SSG estimates) instead of only positives.
  • Borrows established causal-inference and emergent-communication practices with explicit citation, not invented ad hoc.
  • m=40 and K=4 fixed a priori — not tuned on evaluated examples, reducing researcher-degrees-of-freedom bias.
  • CAG/SSG divergence is a substantive, non-obvious result with direct design implications.

Limitations

  • Only LatentMAS's KV-cache relay is empirically audited; embedding- and adapter-based channels are untested.
  • Only one model family, two sizes (Qwen3-4B/8B) — no cross-family evidence for the "signs reverse with scale" claim.
  • Modest sample sizes (n=40–60) leave several effects, especially ARC-C, statistically indistinguishable from zero.
  • No code or data release mentioned — a gap for a paper whose value is that others adopt the protocol.
  • Purely diagnostic: no proposed fix for the observed content-independent "other-example" effect.

Questions for Further Exploration

  • Would embedding-based (CIPHER) or adapter-based (Interlat) channels show the same opposing-sign decomposition, or is this specific to KV-cache relay's working-memory mechanism?
  • Does the "both components reverse sign at 8B" pattern hold at intermediate scales, or is it a step-function threshold tied to one capability crossing?
  • Which structural parts of the message (position, length, generic scaffolding) drive the large content-independent other-example effect?
  • Could the negative other-example effect be actively harmful noise injection that a receiver could be trained to detect and discount?
  • How would the audit's verdict change under compressed KV relay, where transmitted size doesn't map monotonically to downstream utility?
