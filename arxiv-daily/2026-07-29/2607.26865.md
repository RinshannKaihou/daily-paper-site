> **一句话总结：** 论文提出 TSDS 框架，用一个训练在隐藏状态上的轻量"思维收敛探针"提前截断 ReAct 边端 agent 的推理链、再用基于困惑度（PPL）的阈值决定是否将动作转交云端大模型，并通过多目标 Learn-Then-Test 联合校准两个阈值，在 MBPP、HotpotQA 和自建家庭机器人任务上，TSDS 在同时满足奖励下限（如 HotpotQA 上 R_min=0.22）和云端调用预算（C_D_max=0.70）的前提下，比同样达标的 ReDAct-CD 基线减少 43%–73% 的边端思考 token（如家庭机器人任务思考成本从约 1290 降到约 460 token），同时云端调用率降到不足其一半。

> **TL;DR:** TSDS combines a lightweight hidden-state "convergence probe" that halts ReAct edge-agent reasoning once the intended action has stabilized with a perplexity-based deferral rule to a cloud model, jointly calibrated via multi-objective Learn-Then-Test (LTT) for finite-sample reward/cost guarantees. On GSM8K (DeepSeek-R1-Distill-Qwen-7B edge / 14B cloud), TSDS reaches test reward 0.890 vs. ReDAct-CD's 0.864 while using only 18 thinking tokens vs. ReDAct-CD's 173 (a ~90% reduction) and deferring 25.5% vs. 8.2% of cases; on HotpotQA and the household-robot benchmark, TSDS matches or beats deferral-only ReDAct-CD's reward while cutting thinking cost 43%-73% (e.g., 460 vs. 1290 tokens on the household task) and calling the cloud model on less than half the rate.

## 核心贡献

- 提出 **Think Short, Defer Smart (TSDS)**：面向 ReAct 范式边端 LLM agent 的联合框架，同时解决"何时停止思考"和"何时把动作转交云端"两个问题，用一个统一的多目标阈值校准流程把两者绑在一起处理，而不是分别独立调参。
- 设计一个**轻量思维收敛探针** φ_θ：作用于边端模型某一层的隐藏状态 h^(ℓ)，在推理 token 生成过程中判断"若此刻截断思考，后续动作是否会与完整思考给出的动作一致"，一旦分数超过校准阈值 λ_L 就立即停止生成、注入 `</think>` 并抽取动作，从而避免"决策已收敛、但模型仍在无谓地继续生成 token"的浪费（论文称之为思考的"post-convergence waste"）。
- 提出**基于困惑度的不确定性感知转交规则**：对边端模型给出的动作计算 PPL 作为不确定性分数 U_t，若超过校准阈值 λ_D 则将完整历史转交云端模型 π^cloud 重新生成动作，否则采用边端动作，并指出"若不截断思考，模型会因为过度推理而对次优动作变得过度自信"，从而削弱转交机制的有效性（Fig. 1(c) 与附录 H 用 GSM8K 慢收敛子集做了实证）。
- 用**多目标 Learn-Then-Test（LTT）**联合校准阈值向量 λ=(λ_L, λ_D)：把超参选择形式化为多重假设检验问题（对奖励下限 R^min 和云调用预算 C_D^max 分别构造单侧二项分布 p 值，取二者最大值作为并集原假设的有效 p 值，再用 Bonferroni 校正筛选候选网格 Λ），给出概率 ≥1-δ 的有限样本联合风险控制保证（Proposition 1），并在候选集合中按最小思考成本 C_L（多步场景下再按 episode 长度 C_S 打破平局）择优。
- 在四个 ReAct 基准（GSM8K 算术推理、MBPP 代码生成、HotpotQA 多跳问答，以及论文新构建的文本化**家庭机器人多步规划基准** household-robot-bench）上系统评测，并公开了 TSDS 与该家庭机器人基准的代码仓库。

## Key Contributions

- **TSDS framework**: jointly addresses "when to stop reasoning" and "when to defer to a cloud model" for ReAct-style edge LLM agents via a single calibrated pipeline rather than independently tuned components, motivated by the observation (citing Esakkiraja et al. 2026) that the committed action is encoded in hidden states well before generation ends, so continued thinking after that point is largely wasted compute — and can actively harm reliability by making the deferral signal overconfident.
- **Lightweight convergence probe φ_θ**: a small classifier (best architecture: EMA-aggregated per-position linear probe) trained offline on hidden activations h_{t,i}^(ℓ) at a chosen layer ℓ, using a "stable-run" label that is 1 only if the early-stopped action at position i agrees with the full-thought action at every subsequent probed position — directly encoding the irrevocability the stopping rule needs. Generation halts the first time the probe score crosses a calibrated threshold λ_L, `</think>` is injected, and the action is extracted from the truncated trace.
- **Uncertainty-aware cloud deferral rule**: after the (possibly truncated) edge action is extracted, its perplexity (PPL) is computed as the uncertainty score U_t (following ReDAct/Piatrashyn et al. 2026; two alternative scores — sequence probability and mean token entropy — are also defined in Appendix B and are drop-in compatible); if U_t exceeds a calibrated threshold λ_D, the full history is handed to the cloud model π^cloud, which regenerates the action for that step.
- **Multi-objective Learn-Then-Test calibration** (Sec. 4.3, Proposition 1): formulates joint threshold selection as multiple hypothesis testing over a finite candidate grid Λ = {(λ_L^(i), λ_D^(j))}, with per-candidate one-sided binomial p-values for the reward-floor null and the deferral-budget null, combined via max() into a valid p-value for the union null, and filtered by Bonferroni-controlled FWER at level δ=0.10 — yielding, with probability ≥1-δ, a returned λ̂ that simultaneously satisfies R(λ̂) ≥ R^min and C_D(λ̂) ≤ C_D^max.
- **New household-robot planning benchmark**: a text-based, vision/hardware-free simulated multi-room (bedroom/kitchen/bathroom/living-room) manipulation environment inspired by SayCan/ALFWorld, with five action primitives (go to <room>, pick up, put down, heat, clean), four task families (fetch/place/clean/heat), binary terminal reward, and a max of T_max=6 steps — released as a standalone package (github.com/amirfar76/household-robot-bench) alongside the main TSDS codebase (github.com/amirfar76/think-short-defer-smart).

## Methodology

TSDS operates within the standard ReAct loop: at each environment step t the edge agent π^edge (DeepSeek-R1-Distill-Qwen-7B throughout) generates a thought trace token-by-token, and after L_t tokens produces action A_t^edge. Two calibrated mechanisms modify this loop (Algorithm 1):

1. **Thought calibration (convergence probe)**: The convergence probe φ_θ maps a hidden activation h_{t,i}^(ℓ) at reasoning position i and layer ℓ to a scalar convergence score C_{t,i}. Reasoning halts at L_t = min{argmin_i{i : C_{t,i} > λ_L}, L_max}. The probe is trained offline (following Wu et al. 2025, adapted to the multi-step agentic setting) on a dataset built by running π^edge with full, uninterrupted thought generation, then, for each candidate strided position, splicing `</think>` early and checking whether the resulting truncated-trace action matches the eventual full-thought action at that position and at every later probed position (Eq. 5) — a "stable-run" label chosen to match the irrevocability requirement of the stopping rule (once you stop, you can't un-stop).

2. **Uncertainty-aware deferral**: Given the extracted edge action A_t^edge, an uncertainty score U_t (perplexity, PPL, by default) is computed over the action-token distribution. If U_t ≤ λ_D the edge action is executed; otherwise the full interaction history H_t is transferred to the (larger) cloud model π^cloud, which regenerates an alternative action for that step.

3. **Joint LTT calibration**: For each candidate λ_L, the system is run with thought calibration only (no deferral) on a held-out calibration set, producing per-episode reward and per-step uncertainty traces; the deferral indicator for any candidate λ_D can then be evaluated post-hoc without re-running the model. A finite grid Λ of (λ_L, λ_D) pairs is tested via LTT with exact one-sided binomial p-values, Bonferroni-corrected at δ=0.10, certifying the joint reward-floor/deferral-budget constraint (Proposition 1, proven in Appendix F via standard valid-p-value union-null arguments). Among certified candidates, the final λ̂ is chosen by lexicographic minimization of thinking cost C_L, then episode-length cost C_S (multi-step settings), then deferral cost C_D.

Seven candidate probe architectures were ablated on GSM8K (Linear, MLP, Mean-linear, EMA, Attention, MultiMax, Rolling-mean attention), trained with AdamW, binary cross-entropy against the stable-run label; the EMA probe at a shallow layer (ℓ≈5 for most tasks, ℓ=10 for the household-robot task) was selected as the strongest and used in all main experiments. Baselines isolating each component: E-ReAct (no truncation, no deferral), Cloud ReAct (always defer, upper-bound performance/cost), E-ReAct-TC (thought calibration only, no deferral), ReDAct (Piatrashyn et al. 2026, full thoughts + fixed median-PPL deferral threshold), and ReDAct-CD (full thoughts + single-objective LTT-calibrated deferral only, isolating the value of joint calibration).

## Results & Highlights

- **GSM8K (Table 2, Appendix G.2)**: TSDS reaches test reward R̂=0.890 vs. ReDAct-CD's R̂=0.864 (a +0.026 improvement) while using only 18 mean thinking tokens per problem vs. ReDAct-CD's 173 tokens — roughly a 90% reduction — and deferring on 25.5% of episodes vs. ReDAct-CD's 8.2%. E-ReAct-TC (truncation without deferral) fails LTT certification entirely (calibration reward 0.839 < R^min=0.855) in all 50 splits, showing truncation alone is unsafe without the deferral safety net. Cloud ReAct achieves R̂=0.906 but at C_D=1.0, violating the C_D^max=0.70 budget.
- **HotpotQA (Fig. 4, multi-hop QA, R^min=0.22, C_D^max=0.70)**: TSDS and ReDAct-CD are the only two policies that clear both the reward floor and the deferral budget; TSDS does so using "substantially fewer thought tokens" than ReDAct-CD (per Fig. 4's stated pattern mirroring MBPP's 64% reduction) — the paper reports TSDS reduces per-episode thinking compute by 43%-73% over deferral-only baselines across HotpotQA, MBPP, and the household-robot task specifically (Abstract). E-ReAct-TC alone significantly cuts thinking cost relative to E-ReAct but at the cost of reward, since full ReAct without deferral is negatively affected by early truncation errors that have no recovery path.
- **MBPP (Fig. 2, Table 3, code generation with DeepSeek-R1-Distill-Qwen-32B cloud model)**: TSDS clears the reward floor (R^min=0.69) and respects the deferral budget (C_D^max=0.70) while using 64% fewer thought tokens than both E-ReAct and ReDAct-CD (422 vs. 1183/1206 tokens, Table 3) and calling the cloud model on less than half of ReDAct-CD's rate. E-ReAct-TC cannot certify any hyperparameter that guarantees reward above the floor, since it lacks access to the cloud fallback entirely.
- **Household-robot task (Fig. 5, R^min=0.52, C_D^max=0.70)**: ReDAct-CD and TSDS are the only two policies satisfying both constraints, with TSDS achieving this at 64% lower thinking cost than ReDAct-CD and E-ReAct (~460 vs. ~1290 tokens). Notably, unlike MBPP/HotpotQA, ReDAct-CD's reward here is lower than TSDS's — further evidence that letting the edge model reason to completion (full thought traces) makes it overconfident in multi-step plans, suppressing the PPL-based deferral signal at exactly the steps where cloud escalation is most needed.
- **Oracle upper bound (GSM8K, Appendix G.2)**: full-thought accuracy is 84.5% for π^edge and 90.2% for π^cloud on 1300 test problems; an oracle deferral rule catching exactly the 147 "only-large-model-right" problems would lift accuracy to 95.8%, giving a concrete ceiling against which TSDS's 89.0% test reward can be benchmarked.

No quantitative results were omitted for brevity beyond the above — the paper's four benchmark suites (GSM8K, MBPP, HotpotQA, household-robot) each report the full reward/deferral-rate/thinking-cost triple for all five policies, all consistent with the abstract's headline 43%-73% thinking-cost reduction claim.

## Critical Assessment

**Novelty**: The individual pieces (thought-calibration stopping probes from Wu et al. 2025/2026, PPL-based cloud deferral from Piatrashyn et al.'s ReDAct 2026, and LTT calibration from Angelopoulos et al. 2021 / the authors' own prior work) are each pre-existing; the paper's contribution is the *combination* — extending single-turn thought-calibration to the multi-step ReAct setting and jointly calibrating both thresholds via multi-objective LTT rather than treating them as independent knobs. This is a real but incremental contribution, and the paper is upfront about this lineage rather than overclaiming.

**Rigor**: The finite-sample joint risk-control guarantee (Proposition 1) is a genuine strength — it is not just an empirical heuristic but comes with a distribution-free probabilistic certificate, and the proof (Appendix F) is a straightforward but correctly applied composition of valid p-values under Bonferroni FWER control. The 50-seed calibration/test split protocol used throughout is a reasonable way to report calibrated-method variance. One specific weak spot: on MBPP, TSDS only certifies in 22 of 50 random 60/40 splits (explicitly reported in Appendix G.4) — the other 28 splits are silently folded into the "non-certified" baseline pool rather than counted as TSDS failures in the headline comparison, which somewhat flatters the reported MBPP numbers (mean R̂_test=0.714±0.026 is computed only over the 22 splits where certification succeeded).

**Reproducibility**: Code for the main framework and the newly introduced household-robot benchmark is released on GitHub, and hyperparameter grids, calibration procedures, and probe training details are documented extensively in the appendices (probe architecture ablation table, GSM8K rollout details, LTT candidate grids per benchmark) — appreciably more thorough than many workshop-adjacent submissions.

**Significance**: The GSM8K result (18 tokens vs. 173 for ReDAct-CD, a ~10x reduction, while reward *improves*) is a striking number, but it should be read carefully: GSM8K is a single-step (T=1) setting where the edge model's full-thought accuracy is already 84.5%, so the room for the probe to "catch" convergence very early is unusually large; the more modest but still solid 43%-73% reductions on the genuinely multi-step HotpotQA and household-robot tasks are probably the more representative real-world numbers.

**Red flags / weak spots**: (1) The only edge/cloud model pairs tested are DeepSeek-R1-Distill-Qwen at 7B/14B/32B scales — all from the same model family and reasoning-distillation lineage; whether the convergence probe transfers to heterogeneous edge-cloud pairs (e.g., a non-reasoning edge model, or a different vendor's cloud model) is untested. (2) Probing layer ℓ is not architecturally fixed: the paper finds ℓ≈5 optimal on three benchmarks but ℓ=10 optimal on the household-robot task (Appendix G.5), meaning the "lightweight" probe still requires a per-task layer search, which is a hidden calibration cost not folded into the headline token-savings numbers. (3) The deferral cost model assumes cloud calls are simply "expensive" via a fixed budget C_D^max, but real deployment cost also depends on latency and network variability that the simulation does not model. (4) ReDAct, the fixed-heuristic-threshold baseline from prior work, is included in the related-work comparison but is largely absent from the main result figures (Figs. 2, 4, 5 compare against ReDAct-CD, the calibrated variant, not raw ReDAct) — a fair comparison choice given ReDAct-CD is strictly the more competitive baseline, but it does mean the paper doesn't directly show how much the heuristic ReDAct threshold underperforms in practice.

## Strengths

- A principled, finite-sample statistical guarantee (Proposition 1) rather than a purely empirical tuning recipe — the LTT-based joint calibration is rigorous and directly addresses the practical need for certified reward/cost bounds before deployment.
- Comprehensive ablation of seven probe architectures with per-quartile AUROC breakdown (Table 1, Fig. 7) isolating which architectural choices (windowed vs. single-state, shallow vs. deep layer) actually matter for the stopping signal.
- Clear mechanistic story, empirically supported (Fig. 1(c), Appendix H), for *why* joint calibration matters: unconstrained reasoning makes the edge model overconfident, suppressing the PPL-based deferral signal exactly when it's needed — this is shown concretely on a 22-episode GSM8K slow-converging subset (Fig. 13), not just asserted.
- New household-robot benchmark is a useful, lightweight (vision/hardware-free) contribution to the embodied-agent evaluation ecosystem, released as a standalone package.
- Consistent evaluation protocol (50 random calibration/test splits, error bars throughout) across four distinct task types (arithmetic, code, QA, embodied planning), which is more thorough than many single-task LLM-agent papers.

## Limitations

- All edge/cloud model pairs are from the same DeepSeek-R1-Distill-Qwen family at different scales; cross-architecture or cross-vendor generalization of the convergence probe is untested.
- The optimal probing layer is task-dependent (ℓ=5 for three benchmarks, ℓ=10 for the household-robot task), meaning practitioners must still run a layer-selection sweep per new task/model, a cost not counted against TSDS's reported savings.
- MBPP results (Table 3, Appendix G.4) reflect only the 22 of 50 splits where TSDS successfully certified under LTT; the paper is transparent about this but it means the headline MBPP numbers are conditioned on certification success rather than being an unconditional average.
- Uncertainty score is PPL by default throughout the main experiments; the paper's own future-directions section notes richer signals (e.g., semantic entropy) as an open direction to further narrow the gap to an oracle deferral policy, implying the current PPL-based deferral leaves measurable headroom (illustrated by the GSM8K oracle bound of 95.8% vs. TSDS's 89.0%).
- The household-robot benchmark, while useful, is text-based and vision/hardware-free — it does not test whether the same convergence-probe methodology transfers to agents with multimodal (visual/sensor) observation streams, which is where a lot of real edge deployment happens.

## Relevance

TSDS 直接对应"边端受限算力下的推理成本控制 + 可靠云端转交"这一实际部署问题，其 Learn-Then-Test 联合校准思路（有限样本、分布无关的奖励/成本双重保证）对任何需要给 LLM agent 系统设定可证明可靠性边界的场景（而不仅是启发式调参）都具有直接的方法论参考价值。

## Questions for Further Exploration

- Does the convergence probe transfer across model families (e.g., a Llama or Qwen-instruct edge model paired with a GPT/Claude-class cloud model), or is its strong performance tied to the specific reasoning-distillation lineage of DeepSeek-R1-Distill?
- How much of TSDS's per-task layer-selection requirement (ℓ=5 vs. ℓ=10) could be automated or made robust via a layer-ensemble probe, and what would that cost in training/inference overhead?
- Would replacing PPL with semantic entropy (as the authors suggest) meaningfully close the gap to the GSM8K oracle bound (89.0% vs. 95.8%), and at what added inference cost per step?
- How does TSDS perform under non-stationary calibration/test distributions (e.g., a shift in task difficulty over deployment time), given that the LTT guarantee assumes i.i.d. calibration data drawn from the same distribution as test episodes?
- What happens to the 28/50 non-certifying MBPP splits — are they systematically different (e.g., harder problem subsets) from the 22 certifying splits, and does this reveal a brittleness in the calibration procedure under certain data compositions?
- Can the multi-objective LTT framework be extended to a genuine multi-tier cascade (edge → mid-tier → cloud) as the authors propose, and would the Bonferroni correction's conservatism become a practical bottleneck as the candidate grid grows with additional tiers and thresholds?
