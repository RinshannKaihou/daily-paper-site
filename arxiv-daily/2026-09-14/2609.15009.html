01

Method — two tiers, one earned gate

plug-and-play: AutoGen · DyLAN · MacNet · CARD

CoMem splits memory into two logically and physically isolated tiers. After each task, an LLM reflection distiller compresses an agent's full execution trace into ~3 actionable insights, stored privately under strict per-agent access control. A consecutive-miss counter evicts stale entries once Kmiss > Kmax (5–6 by domain).

Promotion into the collective pool is a conjunctive empirical gate: an entry needs Nuse ≥ 3 uses and mean episodic reward R̄m ≥ R̄ (the environment-wide moving baseline) — screening out both incidental activation and lucky successes. Admitted entries carry a hybrid utility score (50% normalized reward + 50% offline LLM judgment), EMA-updated (α = 0.5); persistent underperformers are purged.

At decision time, parallel dual-stream retrieval queries both tiers by embedding similarity; the collective stream is deduplicated by online hierarchical clustering (one representative per semantic cluster) before both are injected into the prompt. Evaluated on ALFWorld & PDDL against 7 memory baselines, with DeepSeek-V4-Flash primary and Qwen3-32B supplementary.

Cost & caveats

Highest success rates at only modest token overhead (dual-stream retrieval + promotion validation); G-Memory and MetaGPT spend comparable-or-higher budgets without consistent benefit.

Dominance is not uniform: on CARD ALFWorld CoMem (90.30) only ties MetaGPT (90.30), and G-Memory comes within 2.4 pts on AutoGen PDDL.

03

Strengths / Limitations

side-by-side, not sequential

Strengths

  • Clean problem framing — pollution = noise accumulation + behavioral homogenization; two-tier isolation targets both failure modes directly.
  • Fair protocol — 4 host MAS × 2 benchmarks × 7 memory baselines, with the memory layer decoupled from host coordination.
  • Counterintuitive evidence — shared-memory baselines often scoring below No-memory is valuable independently of CoMem's numbers.
  • Ablations quantify the design — tier asymmetry (−12.03 / −9.34) supports the architecture, not just the aggregate score.
  • Honest hyperparameter analysis — inverted-U behavior of Kmax and α explained mechanistically at both extremes.

Limitations

  • Planning-only evaluation — ALFWorld and PDDL; no QA, dialogue, or code-generation MAS tasks, so general claims are extrapolated.
  • Pollution never measured directly — no noise-ratio or policy-KL metric; evidence is circumstantial via downstream success.
  • Gate presumes dense rewards — sparse, delayed, or deceptive reward settings could starve or corrupt promotion; unanalyzed.
  • Per-domain tuning required — optima differ (Kmax 5 vs 6; k 3 vs 5), weakening the out-of-the-box story.
  • No significance tests, variance, or code release — LLM-judged utility scoring adds non-determinism.
  • Edge collapses on the strongest host — ties MetaGPT at 90.30 on CARD ALFWorld: diminishing returns when the base MAS is already strong.
04

Open questions for further exploration

  • Measure pollution directly — pool junk ratio, pairwise policy KL over time — to validate the formalization rather than infer it?
  • How does the promotion gate behave under sparse, delayed, or deceptive rewards, where R̄m ≥ R̄ may rarely trigger?
  • Do gains transfer to non-planning MAS — multi-agent QA, ChatDev-style code generation, open-ended debate — where success signals are noisier?
  • Scaling behavior as agents grow: does the collective pool concentrate on a few dominant insights, and does clustering still preserve diversity?
  • Can domain-dependent hyperparameters (Kmax, k, α) be adapted online per agent or task instead of swept offline?
  • Does the LLM's subjective utility score agree with reward-based scoring, or bias promotion toward plausible-sounding but ineffective insights?
