Why this matters

Anyone building or choosing persistent memory middleware (Mem0 / Zep / MemGPT-style) needs this protocol-and-audit template — and its warning that benchmark regime flips conclusions.

命中 LLM Agent 长期记忆与评测方向：纵向评测协议 + 机制保真度审计的方法论模板，负结果扎实、值得必读。

⚠ Critical edge

Every private-corpus “win” is against an unbudgeted strawman baseline — the matched-budget vector comparison a deployment decision needs was never run.

Also: single-author, single-user corpus; several advertised mechanisms never executed, so their ablation deltas “measure nothing.”

Authors & credibility

One author designed the protocol, built the middleware, ran all three experiment families, and self-audited — no independent oversight, no second annotator, and the evaluation corpus is the author’s own private 1,985-turn history. Yet the audit trail is exemplary for a solo preprint: the abstract reports the public-benchmark loss with confidence intervals, an earlier RRF overclaim is explicitly retracted, and the evaluated snapshot is pinned to the v2-paper-eval tag. Exact private LSREP scores are not independently reproducible.

Methodology

01
RQ1

LSREP replay. A 1,985-turn private history (~1.98M tokens), split into four datasets — creative writing; 1,119-turn world-building with a 93-day decay horizon; 8K+-token technical turns (the density stress); academic planning — is replayed chronologically into one fresh deployment. At 52 checkpoints the full memory lifecycle runs (decay, reflection, clustering, consolidation) and 219 probes are re-asked against evolving reference answers: a revised fact updates the reference, so correct memory updates are never scored against stale truth. Judged 1–5 by an independent Gemma-4-12B judge at temperature 0, anonymized tournaments, 10,000 paired bootstrap resamples.

RQ2

Cumulative ablation. A fifteen-step feature buildup on fully-mature Dataset B (67 probes, every condition under every arm), paired within-probe CIs; only intervals excluding zero are called robust.

RQ3

Matched LongMemEval. All 500 oracle + 500 full-S questions; both arms share stored vectors, the same gpt-5.6-luna answerer and Muse judge; 20,000 paired bootstrap resamples. The vector arm retrieves top-30 with no token ceiling — deliberately a strong high-context comparison.

Mechanism-fidelity audit traces each component input → execution → output → selection → final-prompt inclusion; “quality attribution” additionally requires a controlled contrast in which the mechanism actually changes.

Beyond the table

  • Ablation (B, 67 probes): adding an unfused lexical leg is harmful (Δ −0.74); RRF on top is corrective (+0.82); the full system (3.38) is statistically indistinguishable from the single-leg vector baseline (3.27 / 3.42). All other steps span zero — several toggles were broken or constant, so those deltas “measure nothing.”
  • Fidelity audit: procedural retrieval defective (untyped pgvector bind → empty results), document and batch-summary stores empty, HyDE disabled across all arms, graph utility inconclusive.
  • Longitudinal hint: at the deepest turn bin (turn 1,100) both vector conditions drop to 3.80 / 3.87 while ICE holds 4.18 / 4.14 — descriptive, single-conversation evidence that budgeted curation ages better than raw top-30 accumulation.

Strengths

03
  • Operationalizes a real gap: endpoint QA cannot distinguish a system that retrieves well once from one that maintains state correctly over time — updates, aging, revision.
  • The evolving-reference design (current-truth vs historical probes, forward propagation with anchor preservation) removes the perverse incentive where correctly updating a fact is scored wrong against a frozen reference.
  • Exceptional transparency: the fidelity audit publishes its own defective components (procedural leg broken, document store empty), and the earlier “RRF is the biggest component” overclaim is explicitly retracted.
  • The two-regime disagreement is treated as the finding, not hidden — the abstract leads with both the private tie and the public loss.
  • Thorough sensitivity analysis: probe-clustered bootstraps, ordinal comparisons, manual-score-removal checks, McNemar tests, and honest reporting of imputation chains.

Limitations

04
  • Single-author, single-user, private corpus: no cross-user generalization; probe repetition creates dependence that record-level bootstrap understates; the same person authored and hand-scored a favorable (+1.21) slice.
  • The LSREP tie is against a deliberately simplistic single-leg vector baseline with no budget — the matched-budget or matched-prompt arm a deployment decision needs was never run.
  • Several mechanisms are unevaluated rather than validated: graph utility inconclusive, procedural / document / batch-summary retrieval defective or empty, HyDE disabled, decay never independently switched off.
  • LongMemEval judging uses Muse (73% agreement on a 15-item calibration), not the official GPT-4o judge; the answerer was picked on the same benchmark — scores are within-study only.
  • Lower token use with lower accuracy is a trade-off, not efficiency; replay cannot model how generated answers change future turns, and probes themselves reinforce memory.

Questions for Further Exploration

05
  1. How much of the LongMemEval deficit is the 2,000-token fresh-conversation growth cap rather than retrieval quality? A budget-swept vector-RAG baseline would disentangle it.
  2. Would the Codex graph store show positive utility on historical / as-of queries — the probe type LSREP specifies but this instantiation never ran?
  3. Does the two-regime disagreement (replay tie vs endpoint loss) replicate with independent users, public replayable corpora, and official LongMemEval judging?
  4. Can evolving references be automated reliably without anchor drift, and how sensitive are conclusions to judge family crossed with answerer family?
  5. Since access-weighted decay was never independently ablated, does retrieval-reinforced forgetting (+0.15 per access) help or hurt long-horizon accuracy in lived, non-replayed use?
  6. Would repairing the defective procedural / document legs and re-running the ablation change the conclusion that most mechanisms beyond fusion and budgeting add nothing?
