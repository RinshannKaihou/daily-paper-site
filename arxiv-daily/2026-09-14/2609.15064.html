Critical edge

The synthetic “novel-features-by-construction” benchmark promised in the abstract never appears in v1 — the title question is left empirically unaddressed.

Critical assessment · also: the “80%” figure is not derivable from the shown tables

01How they measured it — the Fixed-SAE Track

STEP 1

Pool

Final-token residual-stream activations from base model + all 13 GRPO checkpoints (layer 27, D=1536), standardized with pooled stats.

STEP 2

One shared SAE

A single TopK SAE (k=32, 8× expansion → 12,288 features) trained on the pooled set, then frozen — every feature index = the same direction across all of training.

STEP 3

Interpret

Attribute features via token-level strong-fire rates and Spearman correlation between mean activation and training reward.

STEP 4

Intervene

Sufficiency: add amplified decoder directions to base layer-27 (dose sweep α). Necessity: subtract each feature at the tokens where it fires in the RL-final model.

  • Why shared, not per-checkpoint: per-checkpoint SAEs have non-comparable indices; sequential fine-tuning (SAE Track) can’t detect novel features. One frozen pooled dictionary makes drift Δf well-defined.
  • Two-grader protocol: strict (answer inside <answer>/\boxed{}, = RL reward) vs lenient (format-agnostic) vs tag-rate; decomposition strict ≈ lenient × tag validated to ≤0.025 residual.
  • Coverage: Qwen2.5-1.5B-Instruct (primary), 3B, 7B (LoRA); GRPO, REINFORCE, RLOO, strong-GRPO; five SAE families.
  • Reasoning set R built from four independent criteria, with a format set F as placebo control.

Lenient accuracy barely moves — the gain is almost entirely answer extractability. Dose response is an inverted-U: α≥20 collapses strict accuracy to 0.000 (off-manifold).

  • Everything RL fixed, base already knew: all 29 GSM8K problems flipped base-wrong→RL-right are solvable by the base model at pass@64 = 1.00 (0.235 at k=1).
  • Reasoning set R is necessary but not injectable: ablating R drops GSM8K 0.358→0.242 and MATH-500 0.208→0.117 (placebo F: ±0.008), yet injecting R into base recovers only +0.06 of ~+0.34 — reasoning is dynamically sustained computation, not a static direction.
  • Cross-dataset transfer is format: GSM8K-trained GRPO improves MATH-500 strict +0.13 but lenient only +0.03.
  • Timing: ~86% of feature amplification completes in the first 50 steps; only sustained 2000-step training adds genuine reasoning (lenient 0.300→0.408, tag-rate →0.983).
  • Few-shot ≈ RL substitute: base few-shot 0.748 vs RL zero-shot 0.760; few-shot on top of RL slightly hurts (0.732); few-shot feature shift correlates with RL drift at ρ=0.46.

03Amplified vs suppressed

  • Amplified: arithmetic operators, LaTeX block edges, step/paragraph breaks, <answer> tags — formatting scaffolds.
  • Suppressed: problem entities, units, connective text — content.
  • Replicates across GRPO / REINFORCE / RLOO / strong-GRPO (drift-vector Spearman 0.42), five SAE families, and an independent reward-correlation path (|ρ|≥0.8, same signature).

04Strengths

  • Solves cross-checkpoint comparability cleanly — one pooled frozen dictionary, with dictionary-health metrics proving drift isn’t SAE degeneration.
  • Two-grader evaluation design genuinely useful for separating formatting from reasoning gains; decomposition validated.
  • Exceptionally control-heavy: random-direction steering, format placebo, size-matched random sets, MMLU/BBH/ARC probes, cross-algorithm and cross-scale replication.
  • Intellectually honest: retains a superseded analysis for transparency; reports its own negative result (R not injectable); re-frames “collapse” as reward hacking with held-out evidence.

05Limitations

  • The promised synthetic benchmark is missing — can RL instill genuinely novel features? Unanswered in v1.
  • Causal evidence confined to 1.5B; 3B/7B ablations “inconclusive”; 7B used LoRA — a confound for representation comparison.
  • SAE explains only ~52% of variance (FVU) — drift in the unexplained subspace is invisible; dense vs sparse dictionaries don’t match across families.
  • Single position (final prompt token), single layer per model; earlier-token dynamics untracked. Short-RL regime dominates; sustained-training is one run; RLHF unstudied.
  • No code or activation-pool release; feature-index claims unreproducible bit-for-bit by third parties.

06Open questions this leaves

  1. Does the formatting-scaffold signature generalize to RLHF / preference-based RL, where reward isn’t a verifiable format-or-accuracy signal?
  2. Can the missing “novel features by construction” benchmark be built — and what would the pooled-SAE detection power be at known SNR?
  3. Is R’s non-injectability a fundamental limit of static steering, or would clamping zR at every generation step close the +0.06 vs +0.34 gap?
  4. Does the format-dominant picture hold at 14B–70B with full fine-tuning, where pass@k headroom and late-layer geometry differ?
  5. Could the strict/lenient two-grader decomposition become standard practice for re-auditing published RLVR accuracy claims?
