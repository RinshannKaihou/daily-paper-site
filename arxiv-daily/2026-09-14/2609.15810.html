Key Finding arXiv 2609.15810 · posted 2026-09-14

A training-free low-bit attention kernel that eliminates the two real bottlenecks — value outliers and the FP32 exponential.

VC-Attention: Value Smoothing and Softmax Casting for Low-bit Attention

Xingyang Li, Dongyun Zou, Shining Zhang, Haocheng Xi, et al. — 11 authors · Nunchux AI, MIT, CMU, UC Berkeley, Stanford, NVIDIA · first three share equal contribution

一句话总结 — VC-Attention 是一个免训练的低比特 attention 内核：用在线 k-means 对 value token 重排序后减块均值（V-Smooth）消除 value 离群值误差，再用一条 fused multiply-add 把 log 域分数直接写成 E4M3 概率码（ExpCast-FP8）绕过 FP32 指数运算；在 Wan2.2 / LongCat / HunyuanVideo / MiniMax-H3 四个视频 DiT 上，比 SageAttention2 高 2.3 dB PSNR（Wan2.2 8-bit），在 B200 上 attention 比 BF16 FlashAttention-4 快 1.59×（端到端快 1.19×）。

+2.3dB

PSNR over SageAttention2 on Wan2.2-T2V-A14B 720p, 8-bit values, B200 — 22.6 vs 20.3 dB against the BF16 FlashAttention-4 output, with LPIPS down 13–29% across all four models.

  • 1.59× attention kernel vs BF16 FlashAttention-4 on B200
  • 82% of post-QK output error sat in the value term
  • 1.6% avg row TV of ExpCast-FP8 (bound: 3.64%)

Why this matters

The first training-free, kernel-level fix for value outliers in video-DiT attention — it converts FP8/FP4 Tensor Core throughput into immediately deployable video-generation speedups.

— distilled from Relevance

Critical edge

All fidelity numbers are PSNR/SSIM/LPIPS against each model’s own BF16 output — no human study, no FVD, and the VBench metrics used are near-saturated and non-discriminative.

Also out of scope: the permutation trick requires non-causal attention (LLM decoding is not covered), and no public code release is promised for the five hand-written kernel targets.

Methodology

two steps changed, kernel otherwise untouched

VC-Attention drops into a standard low-bit FlashAttention-style kernel and touches exactly two stages: the value operand before quantization, and the probability write after the dot products. Attention patterns, sampling schedules, and model weights stay untouched — which is why it composes with sparsity, caching, and distillation.

Where the output error lives (after QK smoothing, Wan2.2)

value term — 82%
18%

Figure 3(a) decomposition. Rotating V shifts error by only 0.2% (rotations preserve token norms) — hence reordering, not rotating. A QK-Hadamard control moves PSNR by ≤0.3 dB.

01

V-Smooth value outliers

An online k-means labels value tokens per (batch, head); sorting K and V by label leaves non-causal self-attention output exactly unchanged. Each 128-row block subtracts one 16-bit mean (0.125 bit/element) and quantizes only the residual — the mean is restored for free inside the online-softmax recurrence via the already-accumulated row sum. Sorting lifts removable block energy from 8% (sequence order) to 36% (DeltaQuant’s static cube: 12%).

02

ExpCast-FP8 the FP32 exponential

An E4M3 byte is affine in log2 of the value it stores, so one fused multiply-add — Round(8u + 56 − 0.35), β read off the format’s minimax, not fitted — writes the probability code straight from the log-domain score, deleting the FP32 exp and the format cast. Same byte as exp-then-cast on 79.6% of a doubling interval, at most one code off elsewhere.

03

Fused kernel + amortized schedule systems

RoPE, Hadamard, smoothing means, gather, and quantizers are absorbed into hand-written CuTe/CUDA passes so permuted high-precision tensors never reach HBM — preprocessing drops 42.2 → 4.8 ms per attention call (8.74×). Grouping runs only on the first 25% of denoising steps, with permutations reused over 4 adjacent steps, amortizing to 3–4% of attention time.

03

Strengths vs Limitations

read both before citing

Strengths

  • Attacks the correct bottleneck: the 82% value-term error decomposition justifies the whole design, confirmed by a QK-Hadamard control that moves PSNR ≤0.3 dB.
  • V-Smooth is mathematically clean: permutation keeps the exact attention output, the block mean is the provably optimal rank-one subtraction, and restoration is free (reuses the online-softmax row sum).
  • ExpCast-FP8 has a non-fitted, format-derived error bound (TV < 3.64% + τ) that holds for every model, validated at 1.6% average TV.
  • Genuine systems work: 8.74× preprocessing fusion, amortized grouping, deployment across B200/B300/H200/RTX PRO 6000/RTX 5090 with kernel-in-place timing for apples-to-apples numbers.
  • Composable: leaves attention patterns and sampling schedules untouched, so it stacks with sparse attention, caching, and distillation.

Limitations

  • ExpCast-FP8 exists only in the 8-bit datacenter kernel; it cannot produce NVFP4 probabilities (no affine map exists for E2M1 microscales), and no 4-bit datacenter configuration is evaluated.
  • The fused fast variant gives back 0.7–2.1 dB of V-Smooth’s PSNR lead — the accuracy/speed frontier is real, not free.
  • The permutation argument requires non-causal attention; causal/autoregressive use (LLM decoding) is out of scope.
  • Fidelity is proxied by PSNR/SSIM/LPIPS against each model’s own BF16 output; VBench dimensions are near-saturated; no human study or FVD.
  • k-means adds 30% attention overhead on grouping steps and leans on the empirical claim that layouts drift slowly across early steps — verified here, but a heuristic (uniform placement loses 2.6 dB).
  • Hand-written CuTe/CUDA kernels for five GPU targets and no stated public code release make independent reimplementation costly.
04

Open Questions

where this line of work goes next
  1. Can the V-Smooth permutation be shared across heads/layers — or predicted by a tiny network, as SpargeAttn does for sparsity — to push grouping below 3–4% of attention time?
  2. Does the k-means structure stay stable enough for causal/autoregressive video models, where the invariance argument breaks — e.g., incrementally re-sorting blocks over generated chunks?
  3. Could ExpCast-FP8 extend to E3M4/E2M3 formats, or a two-term affine correction that claws back part of the fused variant’s 0.7–2.1 dB gap?
  4. Do the clusters found for quantization match those that make blocks skippable (Sparse VideoGen 2) — could one grouping pass serve both?
  5. Would the fidelity conclusions change under human-preference studies or FVD against ground truth, given the VBench metrics saturate?
  6. On the 4-bit workstation path, is residual NVFP4 error now the binding constraint — would an SVDQuant-style low-rank branch on top of V-Smooth push PSNR further?

Authors & credibility

Team spans Nunchux AI, MIT, CMU, Berkeley, Stanford, and NVIDIA, including Song Han (SmoothQuant/AWQ/SVDQuant lineage), Lvmin Zhang, and Jun-Yan Zhu. Measurement is unusually transparent: kernels are modified in place inside the FlashAttention-4/SageAttention codebase for apples-to-apples CUPTI timing, SageAttention2’s B200 recompile is disclosed, β is derived rather than fitted, and Proposition 3.1 carries a full proof in the appendix.
