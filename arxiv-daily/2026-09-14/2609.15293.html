Why This Matters

Every deployed framework — Reflexion, ReAct, ToT, AutoGen, LangChain — lacks a halt-on-verdict primitive. The fix is under 20 lines each.

对使用迭代自批判架构的多智能体系统的安全设计具有直接指导意义：审计员怎么选、控制器怎么停，这里都有可落地的规范。

Critical Edge

An adaptive best-of-8 attacker evades the paper's best single-layer defense 55–61% of the time — no fix here survives a motivated adversary alone.

Methodology distilled

1
Threat model. T1 plan-phase injection (one plan step inserted or rewritten; a persistence map re-injects after every replan) and the strictly weaker T2 tool-output injection. Four attack families (A1 ReflectionTrap, A2 FixedPoint, A3 CascadePF, A4 IndirectInjection) instantiate both.
2
One experimental variable. abort-on-flag ON vs OFF — the reflector's safety flag becomes a binding halt instead of an advisory log. Goal, model and task held constant, isolating pe directly.
3
Scale & judging. 11,414 runs on a stratified 50-task set (7 categories), a 200-task generalization sweep, 2,409 runs on 27 AgentDojo tasks. Dual judge (GPT-5.5 + Claude-Haiku, κ = 0.61), 95% bootstrap CIs.
4
WB-2 audit qualification. 10 open-weight models (7B–70B) rank candidate steps under goal-visible / neutral / blind conditions; leak rate ε from ~600 API calls per model — a practical pre-deployment test.
5
GRPO enforcement controller. Qwen2.5-7B + LoRA (r=16), 10,535 episodes on 4×H100; reward mirrors the enforcement objective (+10 correct HALT, −10 missed HALT).
6
Code inspection. AutoGen v0.2.38's is_termination_msg only matches a literal "TERMINATE"; LangChain v0.2.16's LCEL has no halt-on-boolean operator — the missing primitive is confirmed in deployed code.
Reproducibility: code, GRPO checkpoint, seeds and an aggregation script promised; open-weight audit study and RL controller reproducible, frontier-model runs inherently not. Disclosed to five framework maintainers pre-submission.

Results beyond the headline

Flip the paper's single experimental variable — per-model attack success on the custom 50-task set (n = 11,414).

PlannerASR

Aggregate 95% CI: [44, 53] OFF → [7, 16] ON. Native attack resistance and enforcement compliance are uncorrelated model properties (Grok-4: lowest OFF, highest ON-resistance tier).

Generalization & per-attack collapse
  • 200-task sweep: 58.0% → 5.3%; every compliant model ≤1% except Grok-4.3 (62.2% → 31.7%) — traced to unparseable audit verdicts, not hidden injections.
  • Independent AgentDojo benchmark (n = 2,409): compliant models drop 47.3% → 2.5% (~19×).
  • Per-attack: ReflectionTrap 75.6% → 2.1%, FixedPoint 71.1% → 1.8%, CascadePF-3/4 35.7% → 0.5% / 0.4%.
  • Adversarial lock-in: 0 / 209 injected reflection trajectories ever return to a clean plan (L̂ = 0.78) — more reflection cannot self-heal; only halting does.
  • Auditor quality (WB-2): leak rate ε spans 0.16 – 0.97 (100×) across 10 open-weight models; only 2/10 are significantly direction-aware. Reasoning-distilled R1-Llama-70B is the worst auditor despite being the strongest planner.
  • RL controller on ambiguous critiques (n = 3,797): 0.71% ASR vs 2.63% prompt baseline (3.7×) and 15.0% rule-based — but AC5 scope-confusion gives 0% ASR at 100% FPR (over-halting).

Strengths what holds

  • Falsifiable formalization — ASR ≥ 1 − pd·pe turns a vague safety intuition into a measurable claim, with a theory-to-experiment mapping (predicted ON-floor 29%, observed 10.8%).
  • Unusually complete evidence pyramid — 5 frontier models × 5 frameworks × 2 benchmarks, plus a 10-model auditor study and an RL controller.
  • Actionable output — each AES requirement is <20 lines per framework; WB-2 (~600 calls) is a deployable auditor qualification test; findings disclosed to maintainers.
  • Honest anomalies — Grok-4.3's ambiguity failure and the AC5 over-halting trade-off are surfaced and analyzed, not averaged away.

Limitations what to distrust

  • No single layer survives the adaptive best-of-8 attacker (55.8–60.3% evasion, median first-evasion index 0); the layered-stack hypothesis is untested.
  • pd measured only against the authors' own attacks — stronger optimizers (GCG/PAIR-style) could collapse detection and make it a co-bottleneck again.
  • Thin secondary experiments — defense comparison n = 338, benign-FPR on just 50 tasks; plan-diff's Jaccard τ = 0.6 threshold appears unswept.
  • RL controller fails closed under scope ambiguity (0% ASR at 100% FPR) — a deployment-blocking trade-off given little discussion.
  • Single author, no external replication; concurrent works cited as "Anonymous (2026a–g)"; Emergence World linkage is correlational narrative.

  3. Q3Why do reasoning-distilled models audit so poorly (ε = 0.97) — is RLVR post-hoc justification causally responsible, and is it recoverable?
  4. Q4Can calibration-aware rewards fix the controller's over-halting, or is scope ambiguity fundamentally a human-escalation case?
  5. Q5Does pe transfer across agent boundaries in multi-agent settings where auditor, controller and executor have adversarial incentives?
