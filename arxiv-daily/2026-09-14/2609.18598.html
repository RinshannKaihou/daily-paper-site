Why this matters · 为什么重要

A directly borrowable architecture for autonomous-science agents: on-demand tool generation plus verify–falsify testing against confirmation bias — with testable understanding, not a scalar optimum, as the deliverable.

以“可检验的认识文档”而非标量最优值作为产出——对 LLM 自主科学发现、工具使用、多模态实验推理方向是可直接借鉴的架构参考。

⚠ Critical edge · 批判性审视

The 15/18 “supported predictions” record is self-graded homework: the LLM itself judges its own predictions — no numerical tolerance, no independent scoring.

And as published, unreproducible: proprietary GPT-5.5, prompts unreleased, data & code on request only.

Methodology · 方法（蒸馏）

1Propose conditions→ 2Synthesize & measure→ 3Skill-based analysis→ 4Multimodal reflection

SynAgent runs each campaign as that iterative loop, built on the OpenAI Agents SDK with GPT-5.5 powering every agent; one iteration = three LLM turns (proposal, reflection, understanding rewrite) in a persistent session, with the last three SEM images replayed as vision input. The skill library starts empty: when no registered skill covers new data, a code-executing subagent writes and self-tests an analyze.py against the actual MaiML measurement file (≤3 attempts) before registration. Proposals alternate verify / falsify, each committing a grid condition plus a concrete numerical prediction; refuted predictions trigger abductive revision of a natural-language <understanding> document rewritten every iteration.

    +Strengths · 优势
    • Reframes the output of self-driving labs: from optimized samples to testable, traceable, human-readable process understanding — operationalized as the evolving <understanding> document.
    • Skill generation proven end-to-end on real data: two skills written, self-tested, reused unchanged for 17 experiments, matching manual analysis.
    • Verify–falsify counters LLM biases (anchoring, prior overtrust) at mechanism level — both major discoveries came from predicted failures that didn't happen.
    • Multimodality is load-bearing: SEM descriptors separated regimes the scalar XRD objective couldn't (0.1% vs 4–6% bright-particle coverage).
    • Clean experimental design: identical task, grid, and objective as the prior BO campaign isolates the decision layer as the only change.
    −Limitations · 局限
    • One variable, one material (LiCoO₂, substrate temperature); scalability to higher-dimensional spaces — where compact understanding matters most — is untested.
    • Scripted meta-strategy: verify/falsify alternation is a fixed hand-designed schedule, not learned.
    • No repeats, no error bars: each temperature visited once; the fine ranking inside 650–690 °C “may lie within run-to-run variation”.
    • No budget-matched head-to-head against BO or other agent baselines; skills verified only by their own self-tests.
    • Self-judged throughout: verdicts and abductive explanations rest on the LLM's own reasoning; “understanding” is phenomenological, not compositionally confirmed.
