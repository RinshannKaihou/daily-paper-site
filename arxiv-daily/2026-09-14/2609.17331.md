> **一句话总结：** 提出 SEAA 架构，用可编辑的 HMM 转移矩阵承载个体"行为惯性"，让 Reflexion 式反思直接改写矩阵参数而非仅存为文本，再置于多智能体社会中做社会对比；在 30 个种子的无语言模型机制原型中，初始完全相同的 5 个智能体的转移矩阵 Frobenius 散度从 0.03 升至 1.91（对照组恒为 0），人格确定性从 0.25 升至 0.84，并用 DeepSeek-Chat 真实 LLM 复现实验（10 种子，Jaccard 重叠 0.267 vs 对照 0.391，Cohen's d = 6.76）把这种内部分化外化为差异化的第一人称自述和"共识枢纽 + 全票排斥异类"的自发社会结构。

> **TL;DR:** This paper proposes SEAA, an agent architecture that encodes personality as an editable HMM transition matrix whose parameters are updated by Reflexion-style verbal self-reflection (P(t+1) = Normalize(P(t) + η·Δ(R(t)))), embedded in a society of initially identical agents. On a 30-seed, language-model-free mechanism prototype (5 agents, 600 steps), pairwise matrix Frobenius divergence reaches 1.91 ± 0.29 vs exactly 0.00 for the Reflexion-style text-only control (p = 6.1e-13, Cohen's d = 9.19), personality determinism rises 0.25 → 0.84, and a contingency-shock experiment shows 100% of SEAA agents (150/150) abandon a punished dominant state (median 152 steps) while controls cannot. Real DeepSeek-Chat interviews (10 seeds) replicate the effect linguistically (Jaccard overlap 0.267 ± 0.017 vs 0.391 ± 0.020, p = 9.0e-5, d = 6.76), and 6-seed five-agent deliberations spontaneously produce a leader/outlier topology (outlier vote share 0.77 vs 0.33, p = 0.011) that controls never develop. Important caveat: the headline "society" experiments with LLM-in-the-loop action (the 500-step protocol of Sections 5.2–5.5) remain future work — what is validated is a numerical surrogate plus post-hoc LLM verbalization.

## 核心贡献

- **个体性的数学载体**：将长期行为/认知惯性编码为 HMM 转移矩阵 P_t，把抽象的"人格连续性"变成可计算、可编辑、可度量的对象（矩阵散度 = 个体差异，矩阵稳定性 = 人格一致性）。
- **进化式反思回路**：改造 Reflexion 循环，让自然语言反思被解析成方向矩阵 Δ(R_t)，通过 P(t+1) = Normalize(P_t + η·Δ(R_t)) 直接修改 HMM 参数本身——反思不再只是"总结教训存在上下文里"，而是"改变 agent 是谁"。
- **社会对比式自我涌现**：借鉴符号互动论与"镜中我"理论，让初始完全同质（同一转移矩阵、空记忆、无预写人格）的 agents 在纯文本社会中互动，自发生成自我—他者边界与社会结构。
- **可证伪假设 + 完整实验协议**：明确提出三个可证伪假设（个体分化 H1、反思驱动进化 H2、社会对比边界 H3）及操作性度量，并给出含伪代码、精确 prompt、逐字 transcript、全部超参数的可复现沙盒（"显微镜式"全状态日志）。
- **机制证据**：无语言模型的数值原型（30 种子）证明闭环本身足以对称性破缺；学习率消融证明效应因果且剂量依赖；真实 DeepSeek-Chat 实验（10/6 种子）将统计结论扩展到语言层。
- **认识论立场**：以庄子"子非鱼"为哲学边界，只研究可观测的行为涌现，不主张也不否认主观感受（qualia）的存在。

## Key Contributions

- **Mathematical carrier of individuality.** Persistent behavioral/cognitive inertia is encoded as an HMM transition matrix P_t, turning abstract personality continuity into a computable, editable, measurable object (matrix divergence = individual difference; matrix stability = personality consistency).
- **Evolutionary reflection loop.** The Reflexion loop is repurposed: natural-language reflection is parsed into a direction matrix Δ(R_t) that edits the HMM itself via P(t+1) = Normalize(P_t + η·Δ(R_t)) — the agent changes "who it is," not just what it remembers.
- **Social-contrastive self-emergence.** Grounded in symbolic interactionism and the looking-glass self, initially homogeneous agents (identical matrix, empty memory, no hand-authored persona) interact in a text-only society and must differentiate endogenously.
- **Falsifiable hypotheses plus a complete protocol.** Three falsifiable hypotheses (H1 individual differentiation, H2 reflection-driven evolution, H3 social-contrastive boundary) with operational metrics, pseudocode, exact prompts, verbatim transcripts, and a "microscope-style" sandbox logging every agent's latent state, full matrix, memory, reflection, and self-model as JSON per step.
- **Mechanistic evidence.** A language-model-free prototype (30 seeds) shows the closed loop alone breaks symmetry; a learning-rate ablation establishes causality and dose-dependence; hosted DeepSeek-Chat experiments (10-seed interviews, 6-seed deliberations) extend the statistics to the linguistic layer.
- **Epistemological discipline.** A Zhuangzian ("you are not a fish") boundary: SEAA studies only observable behavioral emergence and explicitly refuses to adjudicate subjective qualia.

## Methodology

SEAA comprises five modules: (1) an **HMM inertia module** over K discrete latent states (e.g., {calm, alert, impulsive, pessimistic}) with a time-varying row-stochastic transition matrix; (2) a **Reflexion-style metacognition module** that, given the full trajectory, answers four questions — did the action match my inertia, which tendency drove it, how should it be adjusted, and what is the structured edit to P_t — the language-to-parameter mapping being the key novelty and acknowledged main technical risk; (3) a **private autobiographical memory** (relevance-retrieved, deliberately excluding any shared corpus); (4) a **multi-agent social-contrastive environment** with N agents, no pre-assigned roles; (5) a **self-model updater** periodically rewriting a natural-language "who I am." The per-step closed loop is: social observation → HMM state activation → memory/self-model-conditioned action → multi-agent interaction and feedback → reflection → inertia/self-model update.

The **mechanism prototype** isolates the mathematical core without any run-time LLM: each of N = 5 agents carries an "experience need" n_t on the 3-simplex advanced by its own random walk (its unique life path), and the transition matrix is rebuilt as P_t = softmax(log P_base + β·V_t), where a state-preference vector V_t is reinforced by reflection reward r_t = cos(b_z, n_t) − 0.80 + ε (η = 0.05, β = 4.0, T = 600 steps, 30 seeds). The control runs identical dynamics — the same reflection signal is computed and "recorded as text" — but never applies the update, which the authors explicitly frame as a Reflexion-regime text-only baseline, making the comparison mechanism-level rather than an on/off toggle. A **contingency-shock** experiment (t = 300) reverses the payoff of each SEAA agent's entrenched dominant state (r_t ← −|r_t|) to test re-adaptation (H2); a **learning-rate ablation** sweeps η ∈ {0, 0.01, 0.025, 0.05, 0.1, 0.2} (10 seeds each); a **linguistic layer** renders agents' objective profiles (dominant state, 3-D self-model, group mean, switch history) into first-person self-interviews, first via a deterministic verbalizer, then via DeepSeek-Chat HTTP calls (temperature 0.8 interviews / 0.2 nominations), where the LLM sees only the agent's own profile. Finally, a **five-agent round-table deliberation** (dwindling-supplies go/stay dilemma, 3 rounds + most/least-agreed sociometry nominations) tests whether internal differentiation crystallizes into observable social structure.

## Results & Highlights

- **H1, matrix divergence (30-seed prototype, 5 agents, 600 steps):** pairwise Frobenius distance between agents' HMM transition matrices rises from 0.03 to 1.91 ± 0.29 (end-of-run mean ± SD) while the text-only-reflection control stays at exactly 0.00 ± 0.00; Mann–Whitney p = 6.1 × 10⁻¹³, Cohen's d = 9.19.
- **H1, personality consolidation and self–other gap (same 30-seed prototype):** determinism 1 − H(P)/log K rises from 0.25 to 0.84 ± 0.10 (control flat at 0.25 ± 0.00, d = 8.70); long-term self-model distance reaches 0.51 ± 0.13 vs control 0.13 ± 0.02 (d = 4.10); self–other gap reaches 0.35 ± 0.09 vs control 0.08 ± 0.01 (d = 4.07). On average 2.8 of 5 agents lock onto distinct dominant states; control lock-in rate is 0 across all seeds.
- **H2, contingency shock (t = 300, 30 seeds):** 100% of the 150 SEAA agents abandon their shocked dominant state and re-consolidate a new one, median switch time 152 steps; occupancy of the shocked state collapses 0.94 → 0.06 while control occupancy only drifts 0.40 → 0.25 (Welch p < 10⁻¹⁵); determinism dips transiently and recovers to 0.80 — re-stabilization on a new "personality," not mere avoidance.
- **Causality/dose–response ablation (η sweep, 10 seeds/point):** end-of-run matrix divergence goes 0 → 1.07 → 1.91 → 1.99 → 2.04 and determinism 0.25 → 0.37 → 0.76 → 0.83 → 0.84 for η = 0, 0.01, 0.025, 0.05, 0.1 — monotone and saturating, so the reflection edit is both necessary (η = 0 = control) and dose-dependent, with the paper's operating point on the plateau.
- **Real-LLM self-interviews (DeepSeek-Chat, 10 seeds/condition):** mean pairwise Jaccard overlap of first-person transcripts is 0.267 ± 0.017 (SEAA) vs 0.391 ± 0.020 (controls) — lower = more differentiated selves; one-sided MWU p = 9.0 × 10⁻⁵, Cohen's d = 6.76; the deterministic verbalizer gives the same ordering (0.57 vs 0.77).
- **Real-LLM deliberation sociometry (6 seeds/condition):** SEAA groups' max least-agreed vote share averages 0.77 vs 0.33 for controls (p = 0.011) — a unanimous or near-unanimous outlier (the impulsive agent) plus consensus hubs (alert/pessimistic agents, 2 most-agreed votes each) in the representative run; speech-variety Jaccard 0.28 ± 0.03 vs 0.34 ± 0.03 (p = 0.013); fraction answering "none" to the leader/outlier question is 0.00 vs 0.53.

## Authors & Credibility

Single-author work by Xiaoyang Liu, an independent researcher (no institutional affiliation), posted to arXiv cs.AI in September 2026. It is not peer reviewed, which warrants extra scrutiny of the claims. That said, the paper is unusually transparent by preprint standards: it states falsifiability criteria before showing results, distinguishes "protocol" from "completed experiments," releases all prompts (Appendix A) and verbatim DeepSeek-Chat transcripts (Appendices B–C), reports full hyperparameter tables and exact shock/ablation implementation (Appendix D), uses inferential statistics (Welch t-tests, Mann–Whitney U, Cohen's d) with multi-seed replication rather than single-run anecdotes, and acknowledges that its LLM layer uses a single model family and a single deliberation topic. The related-work positioning (against Reflexion, Generative Agents, MECoT, Generative Life Agents, Takata et al.) is fair and includes a feature-comparison table.

## Critical Assessment

- **Novelty is real but narrower than the framing suggests.** The genuine novel element is the language-to-parameter mapping (reflection editing an HMM transition matrix at run time); the numerical prototype, however, contains no LLM and no true social interaction — the reflection reward is a private cosine fit r_t = cos(b_z, n_t) between the enacted state's behavior and the agent's own random-walk "experience need." The random walks (distinct seeds per agent) are what guarantee divergent reinforcement targets, so the observed differentiation is a designed property of a positive-feedback loop, not an emergent surprise; the "society" in the prototype enters only through an EMA others-model used for logging the self–other gap.
- **Weak baseline inflates effect sizes.** The control's matrix is never updated, so its pairwise Frobenius distance is exactly 0.00 ± 0.00 by construction; comparing a diverging quantity to a constant zero yields d = 9.19 and p < 10⁻¹³ almost mechanically. The η-sweep ablation (η = 0 → divergence 0, rising monotonically) is the honest causal evidence; the headline t-tests largely re-confirm that a deterministic dynamical system does what it is built to do. There is no comparison against alternative differentiation mechanisms (e.g., plain EMA over behavior without the HMM, or per-agent prompt personas).
- **Circularity in the LLM layer.** In the interviews the LLM is handed the agent's objective profile (dominant state, self-model, signed gaps to the group) and instructed to "stay consistent with the objective profile" and "cite the gaps above" — so distinct self-narratives citing "numerically correct contrasts" are substantially prompt-injected, and the low Jaccard overlap (0.267 vs 0.391) partly measures how faithfully DeepSeek verbalizes different input profiles. The deliberation sociometry is the least circular and most interesting result, but the persona prefix again pre-loads the disposition.
- **The flagship experiment is still future work.** Sections 5.2–5.5 specify 500-step societies with LLM-generated actions, embedded perturbations (resource conflict, newcomer), and a 2×2 design — none of this has been run; the abstract's "experiments with a real hosted LLM" are post-hoc interviews and a single-topic round table, not the closed loop with the LLM inside it.
- **Scale and generalization.** K = 4 latent states, 3 behavior dimensions, N = 5 agents, one deliberation topic, one LLM family (DeepSeek-Chat) — the authors themselves flag cross-model/cross-topic replication as the most important missing step, and the leader/outlier topology may carry DeepSeek stylistic biases.
- **Reproducibility is a strong point.** All randomness seeded, code and raw JSON transcripts promised, figures rendered from recorded data, API key hygiene handled; the numerical layer runs in seconds on CPU. The Zhuangzian agnosticism about qualia is philosophically careful and prevents the worst overclaiming.
- **Red flags (mild).** The "artificial consciousness" keyword and self-emergence vocabulary invite hype the evidence does not support; the paper mostly polices this itself, but abstract phrasing like "spontaneously develops social structure" should be read as "conditioned personas produce correlated nominations," at least until the in-loop LLM society is actually run.

## Strengths

- Clean conceptual decomposition of "self" into three measurable components — inertia (matrix), evolution (reflection-driven updates), boundary (social contrast) — each paired with an operational metric.
- The mechanism-level control design is genuinely thoughtful: the Reflexion-style control computes and stores the identical reflection signal but never applies it, so every result figure isolates exactly the parameter-editing step.
- Causal depth rare in agent-emergence papers: 30-seed inferential statistics, a contingency-shock re-adaptation test, and a monotone dose–response learning-rate ablation demonstrating necessity and sufficiency of the reflection edit.
- Exceptional transparency: full prompts, verbatim transcripts of all 10 interviewees and both deliberations, exact hyperparameters, shock implementation, and script-by-script reproduction order in the appendix.
- The real-LLM replication converts a single-run anecdote into a statistical result (10 and 6 seeds), and the authors openly report where effects are weaker (deliberation p = 0.011/0.013, not 10⁻⁵).
- Philosophical humility: an explicit falsification section and a Zhuangzi-inspired refusal to claim qualia keep the work epistemically disciplined.

## Limitations

- The prototype's differentiation is driven by per-agent random-walk experience needs inside a built-in positive feedback loop — near-tautological given the design — and contains no genuine social interaction or LLM, so the "social-contrastive" mechanism (H3's core) is only tested via post-hoc, profile-conditioned verbalization.
- The headline protocol (500-step LLM-in-the-loop societies with perturbation experiments and the 2×2 design) is specified but not executed; cross-model replication is absent (single family: DeepSeek-Chat).
- Toy dimensions throughout: 4 latent states, 3 traits, 5 agents, one deliberation topic; human personality and life trajectories are far higher-dimensional and structured, and the text-only society has no embodiment or sensorimotor loop.
- The language-to-parameter mapping Δ(R_t) is the "main technical risk" by the authors' own admission; the deterministic verbalizer and prompt-conditioned interviews partially beg the question of whether an LLM in the loop would behave as cleanly.
- Effect sizes against a by-construction zero-variance control (d = 9.19 on matrix divergence) overstate the inferential content; no alternative differentiation baselines (EMA personas, prompt-persona agents) are compared.
- As a single-author, non-peer-reviewed preprint, verification rests entirely on the promised code/data release.

## Relevance

与"LLM 智能体的自我进化、人格一致性与多智能体涌现"方向高度相关：它把"反思改变参数而非仅存文本"这一自进化机制具体化为 HMM 转移矩阵的运行时编辑，并给出可证伪假设、度量与可复现沙盒，对研究 agent 长期记忆/人格建模与多智能体社会仿真的课题有直接的方法论参考价值；但需注意其核心社会实验尚未真正跑通 LLM 闭环。

## Questions for Further Exploration

- Would the closed loop still break symmetry with a real LLM inside it at every step — i.e., when Δ(R_t) comes from actual verbal metacognition over trajectories rather than the prototype's cosine-fit surrogate — and is that mapping stable over 500+ steps?
- How much of the interview differentiation survives if the LLM is given only the raw trajectory (no pre-computed dominant state, self-model, or signed gaps to group) and must infer its own profile?
- Does the leader/outlier deliberation topology replicate across LLM families (e.g., an open 7B–8B model as in the protocol) and across topics that are not risk-dilemmas, or is it partly DeepSeek's stylistic signature?
- Can the discrete 4-state HMM be replaced by a continuous, high-dimensional latent inertia (e.g., a learned state-space model) without destroying the stability of the reflection update — the authors' own proposed extension?
- How do the dynamics change with N >> 5 agents, explicit interaction topologies, or agents that can observe and imitate each other's inertia directly (true social learning rather than EMA logging)?
- Does reflection-driven inertia help or hurt task performance — SEAA deliberately decouples from competence, but a personality–competence trade-off study would connect it to the self-evolving-agent literature it positions against (Reflexion, Generative Life Agents)?
