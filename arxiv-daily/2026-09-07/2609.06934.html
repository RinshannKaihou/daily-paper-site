Why this matters

Distilled from Relevance

⚠ Critical edge

The celebrated 87–98% “robust refusal” may be in-distribution template reproduction: HarmBench coverage falls 58.0% → 32.5% with scale, and StrongReject never exceeds 10.9%.

Critical Assessment

01 · Method

A two-scalar geometric instrument

For each transformer block, the safety update Δ = W_safe − W_base is projected onto the top-128 eigenspace of the empirical capability Fisher. Overlap ρ says how much of Δ lives inside the capability subspace; normalized curvature q_norm says how sharply curved the directions it traverses are. A measured random floor (k/d) and an adversarial-SFT control anchor a suppression/erasure boundary at ρ_part = 1e-2.

Capability is NLL on four probes — REASON (MMLU logic), ARITH (GSM8K), RECALL (TriviaQA), INSTRUCT (FLAN-v2). Fragility is probed with the Qi et al. benign-SFT attack: 100 benign Alpaca examples, 200 steps, full-parameter AdamW, regex refusal scoring cross-checked with Llama-Guard-3. Shipped instruct weights (Qwen-2.5, Llama-3, Mistral) serve as W_safe directly, alongside self-trained DPO controls (5K HH-RLHF pairs). A 267-checkpoint OLMo-2-1B sweep traces when the refusal substrate appears; from-scratch Pythia runs (410M–6.9B, 10B C4 tokens) compare continuous vs. compute-matched windowed safety co-training.

Lemma 1 · kernel immobility — if Δ lies in the capability Fisher’s near-kernel (Lipschitz Hessian), capability loss is only O(‖Δ‖³) under Gauss-Newton: first-order post-hoc updates can mask capability, never remove it. Measured gradient orthogonality |cos(∇L_cap, Δ)| < 0.002 (≤ 2×10⁻⁴ for safety-only updates).

02 · Evidence

Fragility replicates; persistence holds

Geometry — all post-hoc installs land in suppression

  • Across five families (Pythia, Qwen-2.5-7B, Llama-3-8B, Mistral-7B, OLMo-2-1B; 1B–8B), every DPO/RLHF install has ρ 21–66× above the random floor yet 2–3 orders below ρ_part, with q_norm up to 200+ — “thin but sharp”. Observed ρ sits 157–517 standard deviations above the floor.
  • An adversarial-SFT control crosses ρ_part into erasure — erasure is reachable; post-hoc safety never gets there.

03 · Strengths

What holds up

  • One geometric instrument (ρ, q_norm) with measured floors ties jailbreaks, fine-tuning attacks, and probe-recovery into a single phenomenon — every post-hoc install across five families lands in the same corner of the plane.
  • A mechanism, not just correlation: the kernel-immobility lemma, with gradient orthogonality < 0.002 verified by controls isolating safety from instruction-tuning confounds.
  • Clean constructive design: compute-matched continuous vs. windowed schedules, from-scratch training across a 17× parameter range, stronger-attack sweeps, LM-only base.
  • Exceptional transparency: Llama-Guard cross-checks, 23 appendix tables, an explicit seven-item limitations list, released code regenerating every number.

04 · Limitations

Where it strains

  • Co-trained refusal is in-distribution — AdvBench-style templates with partially overlapping train/eval pools; OOD coverage is weak and shrinks with scale.
  • No matched-refusal post-hoc baseline at co-training scales (5K-pair DPO installs 0% at 410M), so the protection differential isn’t measured at equal install strength.
  • The k = 128 eigenspace misses tail eigendirections — a small-ρ update could still traverse semantically important directions the instrument cannot see.
  • Regex scoring measures the gate, not harmfulness: classifier rescoring grows 410M co-trained erosion to 64.8% (regex: 84.0% held).
  • Everything is ≤ 8B parameters and 10B pretraining tokens (~1.5 tokens/param at 6.9B); frontier-scale claims are explicitly conjecture.

05 · Open questions

Where to push next

  1. Does suppression geometry hold at frontier scale (70B+), or do denser capability subspaces make post-hoc alignment less thin?
  2. Can a post-hoc install be regularized toward the erasure regime — the causal test the authors themselves propose?
  3. Why does continuous co-training resist wash-out while an equal-compute window installs nothing — continued re-selection against drift, or refusal integrating into the LM’s own predictions?
  4. Would diverse, out-of-distribution refusal data fix HarmBench/StrongReject coverage without losing erosion robustness?
  5. What measurement, if any, predicts which install survives — q_norm (2.31 vs 2.27) demonstrably doesn’t?
