Why this matters

Names a structural cause of the outlier activations that plague low-bit quantization — grounding sink-removal designs like Qwen3-Next and gpt-oss.

Critical edge

The mechanism holds cleanly in only 3 of 5 models — and the promised quantization payoff is never measured.

01 Methodology — four interventions, one metric

causal mask — first token attends only to itself
↓ forces
self-concentration αt,t = 1.0
↓ collapses attention output to a pass-through
Value-non-mixing — yi = vi·WO (all attended Values equal vi)
↓ produces
attention sink + massive activations

Causal interventions on five open LLMs chosen to span MHA/GQA, RMSNorm/LayerNorm, partial/full RoPE, and QKV-bias variants. Inputs: 100 WikiText-2 sequences (T = 64); sink strength measured by Sinkεj — the fraction of (layer, head) pairs attending to position j above ε (ε = 0.3 default, swept 0.2–0.5); massive activations tracked via hidden-state norms.

(1) BOS swap to position 16 · (2) RoPE-key swap with a random position's rotation · (3) forced self-concentration at t = 16 · (4) repeated-token inputs — identical Value vectors reproduce Value-non-mixing with zero attention intervention; one distinct token bounds where the state holds.

robustness: ε ∈ {0.2–0.5} · t ∈ {8,16,32} · 3 datasets · T ∈ {32–256} · layer subsets · 1× RTX 6000 Ada ≈ 4 h · code public (github.com/kiya-raito/value-non-mixing)

  • Early layers carry the effect — layers 1–3 alone recover 90–93% of the all-layer Sink effect (Llama-2: 0.7724 vs. 0.8397); middle/late-layer interventions do nothing (0.0074).
  • Position-general — at t = 8, Sink rises 0.0000 → 0.8542; at t = 32, 0.0072 → 0.8217 (Llama-2-7B).
  • No intervention needed — uniform repeated tokens give Sink = 0.0000 everywhere, yet inserting one distinct token raises it to 0.68–0.80 (Llama-2 / Llama-3.2), exactly within the Value-unmixed prefix.
  • BOS matters too, independently — relocating BOS to position 16 leaves the position-1 sink intact (0.9321 → 0.9178) while creating a new sink at 16 (0.0001 → 0.7597).
  • Robust — trends stable across WikiText / GSM8K / SlimPajama, T = 32–256, and ε = 0.2–0.5.

Strengths

  • Clean factorial disentanglement of BOS, RoPE, and self-concentration with one unified metric across five architecturally diverse models.
  • Sufficiency, not correlation — sinks and massive activations can be created at an arbitrary middle position on demand.
  • Clever repeated-token design — reproduces Value-non-mixing without touching attention weights, separating state from mechanism.
  • Exceptionally thorough robustness appendix (thresholds, datasets, lengths, positions, layer subsets) and a candid Limitations section.
  • Fully reproducible — released code, public checkpoints, ~4 h of compute.

Limitations

  • Only 3 of 5 models respond cleanly — Mistral-7B weakly, pythia-1b barely; the architectural source of this variance is unknown.
  • "Not RoPE" is only half-tested — the intervention touches just the Key side; query-side and query–key interactions are left open.
  • No downstream evaluation — quantization error, perplexity, and task accuracy are never measured; the practical payoff stays conjectural.
  • Artificial evidence distribution — the strongest causal evidence comes from repeated-token inputs, far from natural language; Value-non-mixing is a discrete, idealized state.
  • Narrow scope — sequence-initial position only; mid-sequence sinks, ALiBi/NoPE, MoE, and non-English settings untested; the Sinkε metric is length-sensitive.

04 Open questions

  1. Would a query-side (or joint query–key) RoPE intervention change the "Not RoPE" conclusion?
  2. Why do Mistral-7B and pythia-1b resist the effect — partial RoPE, QKV biases, normalization, or training scale?
  3. Can a continuous Value Mixing Index predict natural-text sink strength and MA magnitude?
  4. Do these massive activations actually degrade INT4/INT8 quantization — and would breaking the state recover accuracy?
  5. Does the same mechanism explain naturally occurring mid-sequence sinks (Sun et al., 2024)?
  6. How do non-RoPE schemes (ALiBi, NoPE) or MoE architectures behave under the same interventions?
