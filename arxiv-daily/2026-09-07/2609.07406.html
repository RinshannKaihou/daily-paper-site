Why this matters

Critical edge

The no-reasoning baseline still beats every WIDER variant — the implicit paradigm itself has not earned its latent budget on these benchmarks.

Methodology

One stop-gradient spectral penalty, bolted onto training

WIDER attaches to any implicit-CoT trainer that inserts m latent positions before the answer token. One auxiliary term, O(Bmd) per batch — backbone, latent schedule, and decoding untouched.

1

Row-normalize

z_i = h_i / ‖h_i‖ — control direction only; norms stay with the base loss.

2

Estimate the shared direction

Stop-gradient column sum q(x) = norm(Σ z_i); a spiked-model argument shows it tracks the top singular vector — no in-loop SVD.

3

Penalize projection

L = L_base + λ·L_spec, λ = 0.10 from a sweep on LLaMA-3B + CODI / StrategyQA.

Matched-pair protocol: identical data, splits, prompt, parser, latent schedule, and checkpoint rule within each pair — the spectral term is the only intended difference. Evaluated on StrategyQA (272) · CommonsenseQA (1,221) · ASDiv-Aug (1,038) · AQuA (254).

Strengths
  • Genuinely plug-and-play: one auxiliary term, O(Bmd) training cost, zero inference-time change.
  • Exemplary matched-pair design — every confound held fixed, so the causal claim is clean.
  • Mechanism section actively falsifies its own story (NMI repetition, energy split, four marginal-p(y) checks).
  • Honest limitations + thorough appendix (licenses, exact recipes, 8B extension); code released.
Limitations
  • Still trails the no-CoT and SFT-CoT reference rows on both backbones — the practical case for implicit CoT is unproven here.
  • λ = 0.10 picked on StrategyQA test accuracy, then reused everywhere; no validation split.
  • Small test sets, no significance testing; the −0.49-pt regression is plausibly within noise.
  • ≤8B models, fixed 6 latent tokens, commonsense/arithmetic benchmarks only — no hard-reasoning suites.
  • Diagnostics describe population geometry, not what any single latent token computes.
Questions for further exploration
Q1Do gains persist with adaptive or learned latent depth, where collapse might compound over more steps?
Q2Would an exact SVD or VICReg-style penalty beat the column-sum proxy — and how closely does the proxy track the true top singular vector?
Q3Is there a per-sample causal link between effective-rank gain and accuracy gain (e.g., re-injecting the dominant direction at test time)?
Q4Do the gains transfer to harder benchmarks (GPQA, MMLU-Pro) or stronger latent-reasoning frameworks like Coconut / SoftCoT?
Q5Can the effective-rank diagnostic predict when implicit CoT will fail before training completes?
Q6Given no-CoT still wins on average here, what task-difficulty threshold makes the latent-token budget actually worthwhile?
