Critical edge

“Zero recoveries in 96 episodes” means this model, at this budget, could not rediscover the result — not that it was undiscoverable. A stronger challenger model or bigger budget could flip the verdict.

Methodology

The audit machine

Before any run, DCP freezes five registered objects: background knowledge K, fixed initial observations E0, the run's experiment history L*, a pre-committed artifact-selection rule, and a machine-checkable validity predicate P. The E0/L* split follows information provenance — a measurement the agent's own actions caused belongs to L*, not E0.

Audited agents run behind a recording gateway that stores every Web query and the exact model-visible bytes, so all recovery bounds condition on the same information the target run saw. Preregistration, sealed evaluators, symmetric scoring, per-gate error budgets (total α = 0.05), Bonferroni candidate classification, and committed draw receipts are baked into machine-readable ledgers — and the threat model explicitly assumes a strategic claimant.

every decision is replayed offline by a deterministic, LLM-free verifier from frozen evidence bundles

The protocol

Three falsifiable gates

  1. G1
    Utility

    Does the artifact beat the baseline by a registered minimum on a sealed evaluation?

    LCB[µ(A*) − µ(b)] ≥ δmin
  2. G2
    Recoverythe core

    Given K, E0 and every Web byte the target saw — but not its history — can a matched fresh agent reach score ≥ x − ε by any valid method? Any admissible route is a witness that vetoes certification.

    0 recoveries in n ⇒ pupper = 1 − α1/n ≤ ρ
  3. G3
    Feedbackoptional

    From a frozen checkpoint, does truthful feedback causally beat a schema-matched neutral channel?

    LCB(Δfeedback) ≥ δevidence + δsham

Strengths

  • “Did it really discover something?” becomes three preregistered, statistically bounded tests — utility, alternative routes, and feedback evidence cleanly separated.
  • Method-agnostic recovery rule: recombination, transfer, and reimplementation all count as legitimate witnesses — the right adversarial stance.
  • Honest self-calibration: the suite includes a case the protocol refutes (knapsack) and one it declares incomplete (affine) — the gates are not rubber stamps.
  • Engineering quality: deterministic LLM-free verifier, byte-exact Web recording, per-gate error budgets, complete ledgers including failures, PyPI tooling, ~$60 audits.
  • Carefully scoped feedback estimand — checkpoint-conditional total policy effect, separated from the target run's own success.

Limitations

  • Audited tasks are small synthetic calibrations; no AlphaEvolve-scale discovery is certified, and cost / neutral-channel design at that scale is untested.
  • Recovery bounds are relative to one registered challenger model and budget — zero recoveries does not preclude recovery by a stronger model, larger budget, or human expert.
  • Gate 3 null calibration runs on a different task family, and the SQLite neutral arm (uniform weights) may actively mislead rather than merely inform nothing.
  • Producer, registry, and verifier are the same team; independent provenance checks and countersigning are specified but not yet exercised.
  • The E0/L* boundary is enforced by self-reported information lineage; a strategic claimant can reclassify helpful material as public background — only Web bytes are recorded.

Open questions for further exploration

  1. How do Core/Evidence decisions change when the challenger pool includes a stronger or heterogeneous model, not the same DeepSeek at matched budget?
  2. What is Gate 2's cost curve as task complexity grows — could DCP audits run at AlphaEvolve / FunSearch scale for a few hundred dollars?
  3. Can the neutral channel be made provably non-misleading — does the 30/30 vs 0/30 effect shrink without the uniform-weights message?
  4. Would null calibration on the same task family, rather than E0-determined null tasks, change the equivalence-band verdicts?
  5. Can retrospective audits of published discoveries validate the pre-publication information boundary rather than just declare it?
  6. Could the recovery-witness rule be gamed by registering a high target x or a loose ε — and which registered checks prevent threshold manipulation?
