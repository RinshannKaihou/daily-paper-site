> **一句话总结：** MorphoOrgaAgent 用"Cellpose 几何提示 + 文本提示"混合驱动 SAM3 实现类器官零样本实例分割，再由 GPT 驱动的任务理解与报告双智能体把自然语言问题转成完整形态学分析报告；在其自建的 MorphoOrgaVQA 基准（1,104 个问答对）上圆度中位误差仅 1.54%，案例分析中位数面积估计与真值仅差 0.39%（Omega 为 761 px、Agentic-J 为 1,235 px，真值 5,749 px，本方法 5,771.5 px），但粗糙度和群体聚合面积误差仍高达 31%–46%。

> **TL;DR:** This MICCAI 2026 workshop paper builds a three-stage LLM multi-agent pipeline (query understanding → zero-shot segmentation → report generation) for organoid microscopy analysis, using Cellpose-derived masks as geometric prompts plus the text prompt "cell cluster" to steer SAM3. On the authors' new MorphoOrgaVQA benchmark (1,104 QA pairs over 69 images from OrganoID/OrgaExtractor/OrgaSegment), roundness is measured at 1.54% median APE and perimeter at 15.36%, but roughness fails at 46.02% and tertile-mean area at 38.74%. In the showcase comparison, its median-area answer (5,771.5 px) is within 0.39% of ground truth (5,749 px) versus 761 px for Omega and 1,235 px for Agentic-J. A solid systems/benchmark contribution for biologists who cannot code, though the headline precision is cherry-picked from one case and no segmentation-IoU or specialized-organoid-model baselines are evaluated.

## 核心贡献

- **零样本类器官分割的混合提示策略**：单独用 SAM3 的文本提示无法表达"类器官"这一生物概念（自然图像训练所致），单独用 Cellpose 又对陌生形态勾边不准；作者将 Cellpose 输出的掩码作为几何提示、配合文本提示 "cell cluster" 共同引导 SAM3，实现无需任何器官标注训练的实例分割。
- **三智能体端到端分析管线**：TaskUnderstandingAgent（GPT-5.4-mini）把模糊的自然语言请求解析成受限的 AnalysisIntent JSON（只能从预定义指标池/可视化池中选取）；分割与指标计算模块按计划执行；ReportAgent（GPT-5.4）仅基于状态数据撰写结构化报告，且被明确禁止重算或改写任何数值——这是框架的核心防幻觉机制。
- **MorphoOrgaState 可审计状态容器**：一个 JSON 可序列化的中央状态对象贯穿全流程，每次查询的中间结果（分析计划、掩码、逐个类器官的指标）全部落盘，形成完整可审计的执行轨迹。
- **MorphoOrgaVQA 基准**：首个面向类器官形态学智能体系统的量化评测基准——4 个形态指标（面积、周长、粗糙度、圆度）× 2 种查询类型（单极值、三分层均值）× 2 种表述模式（明确命名指标 vs 口语化隐含指标），共 16 个问题 × 69 张专家标注图像 = 1,104 个问答对，并附带从标注掩码确定性生成真值的脚本。
- **对口语化表述的稳健解码**：实验表明"明确措辞"与"开放措辞"两种问法的误差曲线几乎一致，说明系统能把生物学家的模糊语言正确映射为分析操作而不牺牲执行精度。

## Key Contributions

- **Hybrid-prompt zero-shot segmentation**: SAM3's text prompting alone cannot express the domain concept "organoid" (predominantly natural-image training), while Cellpose alone localizes but delineates imprecisely; the authors feed Cellpose-derived masks as geometric prompts together with the text prompt "cell cluster" into SAM3, yielding organoid instance segmentation with no task-specific annotation.
- **Three-agent orchestration**: TaskUnderstandingAgent (GPT-5.4-mini) converts a possibly ambiguous natural-language request into a strict AnalysisIntent JSON restricted to a predefined pool of 16 metrics (Area_outer, Perimeter_outer, roundness, perimeter_diff, lumen_ratio, is_border, etc.) and 4 visualization categories; a deterministic module computes metrics; ReportAgent (GPT-5.4) writes the final report strictly from stored state and is forbidden from recomputing or overriding any number — the framework's central anti-hallucination device.
- **MorphoOrgaState auditability**: a centralized, JSON-serializable state container acts as the single source of truth; every agent reads/writes it and the full state is persisted to disk, giving a complete, auditable trace of the analysis.
- **MorphoOrgaVQA benchmark**: a quantitative VQA benchmark for organoid morphology agents — 4 metrics × 2 query types (single-extremum, tertile mean) × 2 phrasing modes (clear vs. open) = 16 questions over 69 expert-annotated test images from OrganoID, OrgaExtractor and OrgaSegment (1,104 QA pairs), with a released script that deterministically derives ground-truth answers from the annotated masks.
- **Robustness to colloquial phrasing**: clear-mode and open-mode questions produce nearly identical error profiles across all metrics and query types, showing the planner correctly infers intended metrics from context rather than keywords.

## Methodology

The pipeline is orchestrated around **MorphoOrgaState**, a JSON-serializable state container initialized per user query with the image path and natural-language question; every downstream module reads from and writes back to it, and the final state is persisted for auditability.

1. **TaskUnderstandingAgent (GPT-5.4-mini).** Interprets the user's intent and emits a strict AnalysisIntent JSON: `required_metrics` drawn only from a closed pool of 16 morphology metrics (organoid_idx, Area_outer, Perimeter_outer, areas_inner/perimeters_inner, centroid x/y, is_border, ideal_perimeter, perimeter_diff, roundness, lumen_ratio, micron/mm-scaled areas, perimeter-derived radius/area), and `required_visualizations` from a pool of four categories (pixel_overlays, metric_plots, correlation_heatmap, none) selected by explicit decision laws. It additionally rewrites the (possibly ambiguous, typo-laden) query into a precise, scientifically phrased `report_instruction` handed to the ReportAgent — a co-reference rule forces it to mention its own chosen metrics/visualizations in that instruction.

2. **Hybrid-Prompt Segmentation.** Cellpose produces coarse object localization in the microscopy image; its masks are converted into geometric prompts for SAM3, combined with the text prompt "cell cluster" (chosen because it better matches SAM3's concept vocabulary than "organoid"). SAM3 then refines the masks. All morphology statistics are computed deterministically from these masks by predefined functions, and results are written into MorphoOrgaState.

3. **ReportAgent (GPT-5.4).** Reads the accumulated state (original query, translated instruction, masks, per-organoid statistics) and produces a markdown report answering the user directly. Its system prompt forbids inventing measurements, modifying or recomputing values, or claiming analyses were rerun; the LLM acts purely as a reasoning engine over pre-computed numbers. Both agents' full system prompts are reproduced verbatim in the appendix and released on GitHub.

**Evaluation protocol.** MorphoOrgaVQA covers area, perimeter, roughness (perimeter_diff), and roundness; each metric is queried in single-extremum form ("identify the organoid with maximum outer area and report it plus centroid") and tertile-mean form ("stratify into small/medium/large tiers and report each tier's mean"), in both clear and open phrasings. Ground truth is computed analytically from expert masks, and performance is measured as absolute percentage error (APE) of the agent's scalar answers. A qualitative comparison against Omega (Napari-based, StarDist segmentation) and Agentic-J (ImageJ agent) is run on one complex brightfield colon-organoid query from OrgaExtractor requiring cross-metric reasoning: flag the top 10% roughest organoids by perimeter_diff, quantify their typical occupied area, and visualize.

## Results & Highlights

- **Roundness is near-perfect**: median APE of **1.54% (clear) / 1.56% (open)** on single-extremum roundness queries and **2.48% / 2.51%** on tertile-mean roundness queries on MorphoOrgaVQA — the system captures global shape regularity essentially zero-shot.
- **Perimeter is solid, Area degrades under aggregation**: single-extremum median APE is **15.36% for Perimeter** (both phrasings) and **16.77% / 17.40% for Area**; on tertile-mean aggregation Perimeter holds at **22.03% / 22.24%** while Area balloons to **38.74% (clear) / 36.77% (open)** — per-instance errors compound when stratifying the population.
- **Roughness is the failure mode**: **46.02% median APE** on single-extremum roughness queries (and 31.75% / 33.74% tertile-mean), because perimeter_diff depends on fine boundary fidelity and is hypersensitive to pixel-level segmentation noise.
- **Showcase comparison on the OrgaExtractor colon-organoid query**: for the median outer area of the top-10% roughest subset (N = 129 organoids, 13 flagged), MorphoOrgaAgent reports **5,771.5 px vs. GT 5,749 px (0.39% relative error)**, whereas Omega reports **761 px** (crippled by StarDist's poor organoid generalization) and Agentic-J reports **1,235 px** despite receiving MorphoOrgaAgent's own masks — it defaulted to generic convexity instead of the domain roughness descriptor.
- **Phrasing robustness**: across all four metrics and both query types, clear vs. open error profiles are nearly identical (e.g., area single-extremum 16.77% vs. 17.40%), confirming the planner decodes colloquial biologist language without loss of execution accuracy.
- **Benchmark construction**: 16 questions × 69 images (test splits of OrganoID, OrgaExtractor, OrgaSegment) = **1,104 QA pairs** with deterministic, script-generated ground truth; code, prompts, and benchmark are public at github.com/peng-lab/MorphoOrgaAgent.

## Critical Assessment

- **Novelty**: moderate but real. Each ingredient (LLM planning agent, SAM3, Cellpose, report agent) exists; the contribution is the specific coupling — Cellpose masks as geometric prompts for SAM3 with a "cell cluster" text prompt — plus the first VQA-style benchmark for organoid morphology agents. It is a well-executed systems/benchmark paper, not a new method.
- **Cherry-picked headline number**: the widely-quoted 0.39% error comes from a single qualitative case study chosen by the authors, while the systematic benchmark medians on the same paper are 15–17% for area/perimeter and 46% for roughness. Notably, roughness — the metric featured in the showcase query — is the system's worst metric benchmark-wide; the showcase succeeded on the *area* readout of a roughness-selected subset.
- **No segmentation-quality evaluation**: no IoU/Dice/AP against the expert masks is reported anywhere; segmentation quality is argued only through one visual comparison (Fig. 2) against Omega/StarDist. The hybrid-prompting design itself is never ablated (SAM3 text-only vs. Cellpose-only vs. hybrid is not quantified), so the central architectural claim rests on qualitative evidence.
- **Weak/absent baselines on the benchmark**: specialized organoid models (OrganoID, OrganoSeg, OrgaSegment, OrgaExtractor) are cited but not compared against, and the agent comparison is a one-image case study in which Agentic-J was *given* the authors' predicted masks — a reasonable control for isolating reasoning, but it makes the comparison non-standard and tiny (n = 1 query).
- **Error aggregation quirk**: tertile-mean roughness (31.75%) is *better* than single-extremum roughness (46.02%), while area moves the opposite way — the paper does not explain this asymmetry, and 38.7% median error on tier-mean area is a large number for a tool sold as producing "measurements closely matching ground truth."
- **Reproducibility**: prompts, code, and benchmark are public (good), but the pipeline depends on closed, fast-moving proprietary models (GPT-5.4-mini, GPT-5.4) with no open-LLM substitute reported, no cost/latency figures, and no variance/significance reporting (medians only, per-question breakdown absent).

## Strengths

- The anti-hallucination architecture is concrete and well-motivated: the planner is restricted to a closed metric/visualization vocabulary via strict JSON, all numbers are computed deterministically outside the LLM, and the ReportAgent is contractually forbidden from recomputing or inventing values — a design other scientific-agent papers only gesture at.
- MorphoOrgaVQA fills a genuine gap: a reproducible, deterministic-ground-truth benchmark for bioimage agents, including an explicit clear-vs-open phrasing axis that directly tests language robustness rather than just accuracy.
- MorphoOrgaState gives full auditability of every intermediate result — valuable in a clinical-adjacent domain.
- The hybrid Cellpose→SAM3 prompting idea is a pragmatic, transferable trick for bridging natural-image foundation models and microscopy domains without annotation.
- Honest error reporting in Table 1: the paper openly shows its worst numbers (46% roughness) rather than hiding them behind the showcase.

## Limitations

- Boundary-fidelity metrics remain poor: roughness at 46.02% median APE means drug-response readouts that depend on boundary irregularity are not yet trustworthy with this system.
- Population-level aggregation amplifies error (tertile-mean area 38.74%), yet tier stratification is exactly what biologists routinely ask for.
- Only 2D brightfield-style images, four scalar morphology metrics, and 69 test images are covered; no 3D organoids, no time-lapse/growth tracking, no fluorescence channels.
- Dependence on GPT-5.4/GPT-5.4-mini makes results non-reproducible over time as APIs change, and no failure analysis of the planning agent (e.g., misrouted metrics in open-mode) is provided.
- No quantitative comparison against task-specific organoid segmentation baselines and no pixel-level segmentation metrics, so the "excels in zero-shot instance segmentation" claim is only qualitatively supported.

## Relevance

本文是多智能体 LLM 系统与视觉基础模型（SAM3、Cellpose）结合落地到科学图像分析的典型范例，其"封闭指标池 + 状态容器 + 禁止 LLM 重算数值"的防幻觉架构对构建可信的生物医学分析智能体具有直接参考价值；同时其自带的 VQA 式评测基准设计（含明确/口语化双措辞轴与确定性真值）也可迁移到其他领域的科学智能体评测中。

## Questions for Further Exploration

- How much of the roundness success (1.54% APE) versus roughness failure (46.02% APE) is driven by mask boundary smoothing from SAM3, and would a boundary-aware loss or post-hoc contour refinement close that gap?
- Can the hybrid geometric+text prompting strategy be quantified per component (SAM3 text-only vs. Cellpose-only vs. hybrid) with IoU/Dice against expert masks, which the paper omits?
- How stable are the results when the closed GPT-5.4 planner/reporter is swapped for an open-weight LLM, and what planning-error rate does the open-phrasing mode actually induce?
- Why does tertile-mean aggregation hurt area (38.74%) but *help* roughness (31.75% vs. 46.02%) — is it a tier-boundary artifact or a cancellation of per-instance noise?
- Does the framework extend to 3D organoid light-sheet data, time-lapse growth curves, and drug-response endpoints, where morphology deltas rather than absolute scalars are the readout?
