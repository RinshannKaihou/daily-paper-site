> **一句话总结：** 针对 RAG 知识冲突中 SAE 批量转向（mass steering）特征冗余、噪声稀释关键特征的问题，提出 KPI 方法——用小规模开发集单特征干预构建特征因果交互图、按入度（indegree）定位关键特征，并在"关键层"及其前序层构建关键路径；Gemma-2-9B 上仅需 8–10 个特征即可超过批量操控 50+ 特征的 SPARE（NQ-Swap 79.33 vs 69.50，Macnoise 75.83 vs 43.00），平均准确率提升 18%，且对忠实样本和 MMLU/GSM8K 的副作用显著更小。

> **TL;DR:** SAE-based steering methods like SPARE steer 50+ correlated features per layer to make LLMs faithful to context under knowledge conflicts; this paper first shows that some single features alone beat mass steering (e.g., on layer 30 of Gemma-2-9B, individual features surpass the SPARE baseline of 60 revised answers), then proposes Key Path Identification (KPI): steer each top positive feature singly on a tiny dev set (as few as 10 examples), record which downstream features light up, build a directed interaction graph, rank features by indegree, and steer only the top features in the "key layer" and its preceding layers (8–10 features total). On NQ-Swap and Macnoise across Llama-3-8B, Llama-3.1-8B, and Gemma-2-9B, KPI beats the best mass-steering baseline SPARE by 18% on average (e.g., 79.33 vs 69.50 on Gemma-2-9B/NQ-Swap, +9.83; 75.83 vs 43.00 on Gemma-2-9B/Macnoise), cuts side effects on faithful examples (99.17 vs 76.83 on Gemma-2-9B/NQ-Swap, no-steering 100.00), transfers out-of-distribution to FaithEval-counterfactual (61.2 vs 20.0 for SPARE and 51.7 without steering, Llama-3-8B/Macnoise settings), and the whole graph-construction pipeline costs only 3.89 GPU-hours on one A100-40GB.

## 核心贡献

- **诊断批量转向的特征冗余问题**：现有关联式（互信息）特征识别把 SAE 特征当作独立单元、忽略特征间因果交互，导致批量转向包含大量冗余弱特征，稀释关键特征的效果。作者通过单特征转向实验证明：少数特征单独转向即可达到甚至超过全部正特征批量转向的效果（Gemma-2-9B 第 30 层，部分单特征超过批量基线 60 的修订数）。
- **提出 KPI（Key Path Identification）方法**：三阶段流水线——(1) 特征交互模式捕捉：在小开发集（最少 10 条样本）上对每层 top-10 正特征逐一转向，记录下游各层激活增幅最大的 top-5 特征；(2) 关键特征发现：以特征为节点、因果交互为有向边构建交互图，按**入度**排序（高入度 = 多条信息通路的汇聚点/瓶颈）；(3) 关键路径构建：以单特征转向效果最好的特征所在层为"关键层"，迭代选取关键层及其前序层的 top 特征（转向只影响当前层及后续层，故后续层特征冗余）。
- **从数量驱动转向质量聚焦**：KPI 仅操控 8–10 个特征（对比批量方法单层就 50+），在 NQ-Swap/Macnoise 两个数据集、三个模型上平均准确率比最佳批量基线提升 18%，同时通过过滤冗余特征显著减轻副作用。
- **机制性解释**：注意力分数分析显示关键特征（如 Gemma-2-9B 第 28 层特征 9032）能持续增强下一关键层对上下文中黄金答案 token 的注意力；解码向量余弦相似度分析表明知识选择行为在第 26–29 层逐步形成，验证了跨层功能层与在前序层转向的必要性。
- **高效率**：与逐层反向传播的电路追踪方法相比，KPI 只用前向传播 + 单特征干预构建交互图，Gemma-2-9B（第 18–36 层）总计算开销仅 3.89 GPU 小时（单卡 A100-40GB，峰值显存 36.45 GiB）。

## Key Contributions

- **Diagnosis of feature redundancy in mass steering.** Correlation-based identification (mutual information per SPARE) treats SAE features as independent, ignoring interactions; mass steering therefore drags in redundant weak features that dilute critical ones. Steering each positive feature individually reveals that a small subset matches or beats mass steering (on Gemma-2-9B layer 30, the SPARE mass-steering baseline revises 60 unfaithful answers while some single features exceed it; weak features can even rank ahead of the most useful one by mutual information).
- **KPI method.** A three-stage causal-dependency-driven pipeline: (1) *Feature Interaction Pattern Capture* — steer each top-10 positive feature per layer singly on a small development set and record the top-5 features with the largest mean activation increases in each downstream layer (patterns are stable: feature-overlap 1.0 with 10 samples vs 0.73–0.87 with 200); (2) *Key Feature Finding* — build a directed interaction graph and rank features by indegree, borrowing the network-bottleneck idea that high indegree marks convergence points of information flow; (3) *Key Path Building* — pick the key layer containing the best single-steering feature, iteratively include top-ranked features in preceding layers, and stop when no better top-ranked features remain upstream.
- **Quality-over-quantity steering.** KPI steers only 8–10 features total (vs 50+ per layer for STA/SPARE) yet outperforms every individual feature and the mass-steering baselines, showing the selected features collaborate rather than interfere.
- **Mechanistic evidence.** Key features consistently raise attention scores on golden-answer tokens in the next key layer (whereas a high-MI but weak feature shows more declines), and cosine similarity of SAE decoding vectors indicates the key feature's pattern forms and works mainly in layers 26–29 of Gemma-2-9B — direct support for the existence of functional layers and the value of steering preceding layers.
- **Efficiency.** The interaction graph replaces layer-by-layer backward-propagation circuit tracing: 3.89 total GPU-hours on a single NVIDIA A100-SXM4-40GB (peak 36.45 GiB) for layers 18–36 of Gemma-2-9B.

## Methodology

The setting is SAE-based steering for knowledge conflicts: an SAE encodes the residual stream h into sparse features z (131K width for all models used); steering feature i adds α·W_dec[i,:] to the residual stream (h' = h + αW_dec[i,:]), applied at the last token of the prompt. Positive features are those with mutual information against the faithful/unfaithful behavior label, following SPARE.

KPI proceeds in three stages:

1. **Feature Interaction Pattern Capture.** Rather than expensive backward-prop circuit tracing (costly for long contexts and input-specific), KPI uses single-feature steering as the intervention: for each top-10 positive feature per selected layer, steer it alone on a small dev set (size 10 suffices) and record, for every affected downstream layer, the top-5 features with the greatest average activation increases (activation *increases*, not frequency increases, because some features already saturate at frequency 1.0).
2. **Key Feature Finding.** Features are nodes, recorded causal interactions are directed edges (restricted to layers ≥ the source layer, since steering only propagates forward). Features are ranked globally by indegree: high indegree means many positive features converge to promote this feature — a network bottleneck that likely carries the mass-steering effect; low indegree flags likely-redundant features that weak steering may even hinder.
3. **Key Path Building.** Single-steering effects differ sharply by layer; the layer containing the top-ranked feature with the best effect is the key layer (consistent with prior work on functional layers for contextual understanding). Because steering a layer affects only that layer and subsequent ones, KPI steers top-indegree features in the key layer **and its preceding layers** (later-layer features are made redundant by the key layer's downstream influence; later layers also naturally accumulate higher indegrees, which iterative key-layer selection guards against). Steering strength α is set as multiples of each feature's maximum activation (from Neuronpedia or sampled), tuned on dev data.

Experiments use Gemma-2-9B (Gemma Scope SAEs, JumpReLU), Llama-3.1-8B (Llama Scope, JumpReLU), and Llama-3-8B (EleutherAI, TopK), all 131K-width residual-stream SAEs; Qwen3-14B judges answer correctness. Datasets: NQ-Swap and Macnoise, filtered to examples where the model initially outputs the original (parametric) answer under substituted context — success means steering flips it to the substituted context's golden answer; test sets are 200 examples. Baselines: ICL, CAD (contrastive decoding), STA and SPARE (mass steering). FaithEval-counterfactual-v1.0 serves as an out-of-distribution faithfulness test.

## Results & Highlights

- **Main accuracy (revised faithful answers, n=200).** On NQ-Swap, KPI vs best mass-steering baseline SPARE: Llama-3-8B 72.83±4.31 vs 68.83±2.02 (+4.0); Llama-3.1-8B 50.67±0.76 vs 48.83±1.15 (+1.84); Gemma-2-9B 79.33±0.76 vs 69.50±1.50 (+9.83). On Macnoise: Llama-3-8B 63.83±3.21 vs 55.67±2.75 (+8.16); Llama-3.1-8B 58.50±5.27 vs 54.33±3.33 (+4.17); Gemma-2-9B 75.83±5.62 vs 43.00±6.54 (+32.83 — SPARE suffers inaccurate layer selection here). ICL and CAD lag far behind (e.g., ICL 13.67, CAD 11.50 on Gemma-2-9B/NQ-Swap vs KPI 79.33). The paper claims an 18% average accuracy improvement over the best mass-steering baseline.
- **Fewer features, better effect.** KPI's ablation on Gemma-2-9B selects only 8 steering features, yet the combined KPI steering (147 revised count) surpasses every one of its features steered individually, while mass-steering baselines steer more than 50 features even in a single layer.
- **Smaller side effects on faithful (conflict-free) examples.** Accuracy on faithful examples: NQ-Swap Gemma-2-9B KPI 99.17±0.58 vs SPARE 76.83±4.25 (without steering 100.00); Macnoise Llama-3-8B KPI 95.17±1.44 vs SPARE 82.83±3.69 (without steering 99.33) — KPI recovers most of the drop mass steering inflicts on non-conflict behavior.
- **Out-of-distribution generalization (FaithEval-counterfactual-v1.0, full dataset).** With steering settings transferred from the simple datasets: Macnoise settings on Llama-3-8B give KPI 61.2 vs SPARE 20.0 and 51.7 without steering (+9.5 over no-steering, while SPARE collapses 31.7 points below no-steering); KPI is consistent across all six model/setting combinations (58.1–61.4) whereas SPARE collapses in 5 of 6.
- **Downstream capability preserved.** GSM8K (Gemma-2-9B, NQ-Swap setting): KPI 61.56 vs SPARE 55.42 vs 62.62 without steering; MMLU last-token steering is comparable to no-steering, and under the harsher all-token steering SPARE collapses (22.95 on Gemma-2-9B vs 69.57 without steering) while KPI holds 67.12.
- **Cheap graph construction.** Full interaction-graph construction over layers 18–36 of Gemma-2-9B costs 3.89 GPU-hours on one A100-40GB (peak 36.45 GiB; per-layer runtimes 105–1751 s), far cheaper than backward-propagation circuit tracing.
- **Stability.** Selected-feature overlap is 1.0 between 10 and more sampled instances for interaction capture (0.73–0.87 at 200), justifying the tiny development sets; top-k sensitivity shows overly aggressive pruning removes useful features (Gemma-2-9B revised count 148/150/140/146/135 for top-k 5/10/15/20/30).

## Critical Assessment

- **Novelty:** Genuine and well-motivated. The single-feature-steering diagnosis (Figure 3) is a crisp demonstration that mutual-information ranking misidentifies steering-relevant features, and reframing feature selection as an interaction-graph/bottleneck (indegree) problem is a fresh angle for SAE steering. It is, however, an incremental refinement of the SPARE pipeline — it still uses SPARE's mutual-information stage for candidate generation and only denoises downstream.
- **Rigor / headline-claim inflation:** The abstract's "18% on average" leans heavily on one outlier cell: Gemma-2-9B/Macnoise (+32.83, caused by SPARE's acknowledged layer-selection failure). Excluding that cell, relative gains are roughly 4–15%, and the Llama-3.1-8B/NQ-Swap gain (+1.84 with stds of ±0.76/±1.15 on n=200) is within ~1.5 standard deviations with no significance testing reported.
- **Evaluation-protocol quirks:** Test sets are only 200 examples, pre-filtered to cases where the model is initially unfaithful, judged by Qwen3-14B (the authors themselves note LLM-judgment randomness), and inputs are truncated to 256 tokens with ambiguous-answer cases filtered out. "Accuracy" here is a revised count on a deliberately adversarial subset, not comparable to standard NQ-Swap numbers.
- **Reproducibility:** Good — released code, named SAE resources, full hyperparameter tables (selected feature triples with layer/id/max-activation for every model and dataset), and sensitivity analyses. The graph-construction knobs (top-10 features per layer, top-5 edges per layer, dev-set sizes) are heuristically chosen but at least documented.
- **Scale and scope limits:** Only 8B/9B models, because continuous-layer SAEs for 70B+ models are unavailable (admitted in Limitations). Steering is applied at the last prompt token for main results — a simplification; the more realistic all-token regime appears only in the appendix (where, admittedly, KPI degrades gracefully and SPARE collapses).
- **Missing ablations:** No comparison against a random- or high-activation-based feature-selection control of equal feature count (is indegree better than just picking the 8 strongest single steerers?); no test of whether the interaction-graph edges correspond to ground-truth circuits; and the "causal" language overstates what single-steering activation increases establish (edges are still heuristic top-5 recordings, not verified causal attribution). The paper itself concedes backup circuits may exist and that correlation-based identification remains flawed at its root.

## Strengths

- A clean, falsifiable diagnosis experiment (single-feature steering vs mass steering) that directly motivates the method, rather than a method in search of a justification.
- The interaction graph is built with forward passes only — 3.89 GPU-hours total — making cross-layer causal analysis practical where backward-prop circuit tracing is not.
- Comprehensive side-effect accounting: faithful-example accuracy, MMLU, GSM8K, and an all-token stress test, plus out-of-distribution transfer to FaithEval-counterfactual where SPARE collapses and KPI does not.
- Mechanistic depth: attention-score analysis ties steering to concrete attention on golden-answer tokens, and decoding-vector cosine similarity localizes when the knowledge-selection pattern forms (layers 26–29), validating the design choice of steering preceding layers.
- Selecting 8–10 interpretable features instead of 50+ is itself an interpretability win — the edited circuit is small enough to inspect.

## Limitations

- Only entity-substitution-style conflicts (NQ-Swap, Macnoise) drive feature selection; the method assumes retrieved evidence should be trusted and optimizes context faithfulness, not judgment about which source is correct.
- Requires cross-layer SAEs trained on continuous layers of the same model — unavailable for most models and sizes (nothing above 9B tested).
- Correlation-based candidate generation is still the entry point, so genuinely weak-but-correlated features can enter the graph; the method reduces but does not eliminate the acausuality problem the authors diagnose.
- The model may possess backup circuits with the same function (the authors note disabling their found circuit may not disable the behavior), and steering strength shows a single-peaked sensitivity curve requiring per-model/per-dataset tuning (some main results deliberately use non-peak strengths to trade off side effects).
- Small test sets (200), LLM-based judging, and 256-token input truncation limit the strength and external validity of the quantitative claims.

## Relevance

与 LLM 可解释性研究兴趣高度相关：该工作将 RAG 知识冲突下的忠实性问题转化为 SAE 特征层面的因果电路分析（交互图 + 入度瓶颈 + 跨层关键路径），是 mechanistic interpretability 落地到模型行为编辑（steering/editing）的典型范例，其"少量关键特征优于大批量干预"的发现对理解 LLM 知识选择行为的电路结构有直接参考价值。

## Questions for Further Exploration

- Does indegree-based selection actually beat the simpler control of "pick the top-k features by individual steering effect" at matched feature counts? This ablation is missing and would isolate the graph's contribution.
- Do the discovered key paths remain stable under multi-hop conflicts, longer contexts (>256 tokens), or adversarially noisy retrieval, and can the method distinguish *correct* context from merely *present* context when the parametric knowledge is actually right?
- How would KPI behave at 70B+ scale once suitable multi-layer SAEs exist, and does the key layer location shift with scale or instruction tuning?
- Can the heuristic top-5 activation-increase edges be validated against ground-truth circuits from circuit tracing, and what happens when the key path is ablated — does behavior reroute through backup circuits as the Limitations suggest?
- Can steering strength be adapted dynamically per input (the paper notes the single-peaked strength curve and leaves dynamic regulation to future work), and does KPI compose with contrastive decoding (CAD) rather than merely outperforming it?
