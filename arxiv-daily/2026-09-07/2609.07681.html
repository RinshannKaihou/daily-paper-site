Key metric — the circuit breaker

1.00 → 0.06

MQAR accuracy when Conv1D is removed (d_conv=1): perfect recall collapses to chance (1/N_f = 0.0625). The copy-and-shift is what binds keys to values — everything else (gate, discretization, activation, layer-norm) is dispensable.

Why this matters

A hard memory budget: storing Nf facts in any fixed-state recurrent model requires state × embedding ∝ Nf log V — linear in facts, logarithmic in vocabulary.

Critical edge

Validated on synthetic MQAR with a linearized Mamba only: the full model's fit (a_full ≈ ½ a_linear) is heuristic, not derived, and headline grids report best-of-seeds near the capacity cliff.

Methodology — distilled

  1. Skeletonize. Strip a single-layer Mamba (Alg. 1) of gating, discretization, and nonlinearity — leaving an additive outer-product memory h_t = Σ x̂_τ B_τ^⊤ plus a width-2 Conv1D.
  2. Design circuits. A perfect one-hot circuit (N = D = V) and a compressive Johnson–Lindenstrauss variant that hashes keys into the state and decompresses values at readout.
  3. Verify in trained weights. Orthogonal-invariant operators G_vv, G_kq match the designed block structure; inverting the hidden state recovers the key–value table (H''_t ≈ H_t).
  4. Derive & bound. Two-stage JL statistics yield the recall law; normal-CDF-tail and counting arguments give matching lower bounds.
  5. Stress-test. 500–1000-point D–N accuracy grids (3–5 seeds), ablations, runs up to V = 50K / L = 4K — ≈10 GPU-days on B200s.

  • One-curve collapse. Trained D–N accuracy grids collapse onto p ≈ Φ(x − √(2 log V)), with a = 1 (AR), a ≈ 5/4 (MQAR); full nonlinear Mamba follows the same law at a_full ≈ ½ a_linear.
  • 8× tighter than prior theory. N = 32, D = 64 solves V = 512 perfectly — Huang et al.'s bound required N = V_k = 256.
  • Depth is just state. (N,Λ) = (12,1), (6,2), (4,3), (3,4) all give p ≈ 0.38 — only N_eff = ΛN matters.
  • Head ranking. MQA = MKA ≤ single = MVA ≤ MHA; only MHA (key and query expansion) buys recall capacity — consistent with Mamba-2 perplexity data.
  • Repeated keys break layer 1 (drops to 1/N_k chance); layer 2 restores recall by overwriting the stale entry.

Caveat kept visible: large-scale fits (V → 50K) show slopes 1.18–1.56 vs the theoretical 1 — an acknowledged 18–56% deviation.

Strengths

  • Complete loop: mechanistic discovery → circuit hypothesis → JL theory → matched lower bounds → large-scale validation.
  • Falsifiable verification: hidden-state inversion H''_t ≈ H_t makes the hash table directly visible, not just a weight-space coincidence.
  • Actionable architecture guidance: depth helps only via N_eff = ΛN; among Mamba-2 head patterns, only MHA adds recall.
  • The Conv1D ablation (1.00 → 0.06) is a crisp, memorable proof that the shift operation is indispensable.
  • Reproducibility hygiene: open code, pinned environments, per-figure compute, seed analysis, head-to-head App. J vs Huang et al.

Limitations

  • Theory covers a simplified linear single-layer Mamba; the full gated model enters only through a heuristic constant.
  • Synthetic AR/MQAR only — no language-modeling validation; transfer to real corpora is assumed via the MQAR–LM correlation.
  • Best-of-seeds grids measure capacity, not trainability; single runs underperform near the phase boundary.
  • Law constants are approximate; large-scale slope deviations of 18–56%.
  • Unique keys assumed; repeated keys degrade single-layer recall to chance, handled only empirically.

Questions for further exploration

  1. Does the hash-table circuit persist in production-scale Mamba LMs trained on natural text — or is it just the easiest solution under MQAR structure?
  2. Can a_full be derived for the full gated, discretized block instead of fit at ½ a_linear?
  3. Do matrix-state / delta-rule models (DeltaNet, RWKV, xLSTM) obey S = Θ(N_f log V), or do write/overwrite rules beat additive blending?
  4. If depth only compounds via N_eff, why do deep Mamba LLMs help so much on real language — is recall not the binding constraint at scale?
  5. Can the JL-collision perspective predict systematic key-confusion errors, testable by probing or activation patching?
  6. Low-precision states: does bS = Ω(N_f log V) predict a sharp recall cliff under quantization?
