Why This Matters

Bridges representation geometry and parameter geometry — steering directions mapped onto weight structure enable persistent, deployable behavior control beyond probing and inference-time hooks.

Critical Edge

The evaluation is mildly circular — trait scores are LLM-judge ratings on the same benchmark used to derive the steering vectors — and fine-tuned Task Vectors still win raw trait control (95.62 vs 63.26).

01Methodology3 steps · 3 provable properties

TFTV converts an activation-space intervention into a persistent parameter-space edit. Contrastive prompt sets elicit vs. suppress a target trait; an LLM judge filters incoherent completions; hidden states are averaged into a steering vector s = s⁺ − s⁻. Each target module (by default attention output projections) gets a rank-one update whose left factor is the normalized steering vector and whose right factor is the sign-aligned, singular-value-weighted combination of right singular vectors. The edit is applied with a single scalar α — negate α to suppress, sum deltas to compose.

TFTV(W, s̄, µ) = s̄ (Σᵢ sign(µᵀvᵢ) σᵢ vᵢ)ᵀ   ·   W ← W + α · TFTV
01

Extract steering vector

Contrastive prompts X⁺/X⁻ → mean-difference of averaged hidden states, per trait.

02

Rank-one construction

SVD of W; steering direction s̄ as left factor, sign-aligned right factor weighted by σᵢ.

03

Edit with one scalar

W + α·TFTV across selected modules; α < 0 suppresses, deltas sum to compose traits.

Norm matching∥Δ∥_F = ∥W∥_F — one α adapts across layers with different scales.
SteeringΔ·µ = c·s̄, c ≥ 0 — expected input is pushed along the steering direction.
LinearityArithmetic on steering directions equals arithmetic on weight deltas — exact when traits share µ, approximate in practice.

Strengths
  • Genuinely training-free — forward passes over contrastive prompts only; the fine-tuned-checkpoint bottleneck is gone.
  • Theory–experiment alignment — three provable properties directly explain the observed add / subtract / compose arithmetic.
  • Honest, broad baselining — training-free and fine-tuned competitors, including where fine-tuning still wins.
  • Deployment-friendly — persistent edits keep the standard forward pass; no inference-time hooks.
  • Rare robustness checks — OOD suites, matched controls, std devs, two extra model families, explicit misuse section.
Limitations
  • Not zero data cost — contrastive prompt curation and LLM-judge filtering remain; only the GPU training loop is removed.
  • Manual module/layer selection — automation deferred to future work.
  • Trade-off mitigated, not eliminated — worsens under stronger or composed edits.
  • Composition only approximately linear — expected input µ is estimated separately per trait.
  • Circular-leaning evaluation — judge and steering data share the Persona Vectors benchmark.
  • Dual-use risk — the same edit that suppresses evil can amplify it; persistent weight edits are harder to audit than inference-time steering.
04Open Questionsfrom the summary's further-exploration section

Q1Can module/layer selection be automated — e.g., ranking candidate sites by steering-vector norm or causal effect?

Q2Does the weight-space advantage persist at frontier scale (>70B), or for hard-to-verbalize traits like deception and power-seeking?

Q3Would a shared, task-independent µ make composition exactly linear — and would that help or hurt the trade-off?

Q4Do TFTV edits survive subsequent fine-tuning or INT8/INT4 quantization and continued pretraining?

Q5Could TFTV be inverted into an audit — detecting which trait directions a deployed checkpoint has been edited along?

Q6Does approximate linearity break catastrophically when composed traits are adversarially correlated (e.g., suppressing sycophancy and refusals together)?
