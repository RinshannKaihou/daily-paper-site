Why this matters

A directly transferable recipe for self-repairing industrial agent systems: schedule edit scope as a curriculum, enforce edits by construction, archive alternate starting points.

⚠ Critical edge

An increment on the authors' own prior system, evaluated on their own platform with their own judge — no third-party baseline appears anywhere.

30 held-out tasks (15+15), no significance tests: the 7/15 → 11/15 delta rests on four tasks.

Methodology — three controls on one loop

§5.1–5.3

RobustSGPO keeps AgentX's SGPO-I optimization loop and inserts explicit control over which edits can even be proposed — because granting broader permissions provably fails to diversify exploration.

traces → replay tasks → semantic gradient → candidate edit → paired replay (gain > ε = 0.05) → admit / rollback

1

Plan the edit before generating it §5.1

A controller samples feasible (scope, operation) categories and eligible targets before the LLM writes content. Permission levels α1 (one designated agent) → α3 (add/remove agents, routing) bound the space; factorized requests steer generation inside it.

2

Compile and check the patch §5.2

An exact-target check rejects edits touching more or fewer objects than requested. A "Typed Compiler" — predefined code, not model output — executes agent add/remove, lifting structural-edit validity from 48.9% to 77.8%.

3

Continue from retained versions §5.3

A MAP-Elites-inspired archive (≤10 slots) keeps the best valid snapshot per edit category. Search alternates incumbent and archive parents; every descendant must still beat the incumbent in paired replay.

允许 ≠ 有效。 Granting broader permissions only inflates the outer ring — generation still concentrates on familiar instruction rewrites. Each control buys a measurable, separable increment (+0.12 / +0.10 / +0.16 / +0.10 pts).

⚖

Equal-cost honesty: the archive raises per-round cost from ~0.80M to 0.95M tokens, so the margin over Structured Search shrinks from +0.10 (equal rounds) to just +0.04 (equal 20M-token budget). The archive's value rests on transfer robustness, not raw quality.

Strengths

what holds up
  • Precise problem vocabulary — the permitted / realized / effective trichotomy explains why more permissions ≠ more exploration.
  • Clean cumulative ablation — each control added on a shared α3/safety/replay substrate; the +0.48 gain attributes unambiguously.
  • Constraint-by-construction beats post-hoc filtering — structural validity 48.9% → 77.8% via code-executed add/remove patches.
  • Uncommon cost honesty — failures and archive operations sit in the token ledger; losing conditions are reported.
  • Practical curriculum finding — periodic 1→2→3 beats fixed max permission by +0.28; easy to adopt.

Limitations

what to watch
  • Single workflow (AgentX brainstorming), fixed model and evaluator; no shared-benchmark comparison vs AgentFlow, HARBOR, HELIX, HASE, GEPA.
  • 30 held-out tasks, no variance reporting — several headline deltas (7/15 → 11/15) are within noise range for such sample sizes.
  • Modest absolute gains on the 0–5 scale; equal-token margin over Structured Search is only +0.04.
  • Internal-platform evaluation — unpublished rubrics and traces limit replication despite released tables and code.
  • Archive loses on adaptation — random retention reaches 4.18 vs 3.98; choosing retention vs adaptation needs foreknowledge not operationalized.

Questions for further exploration

open threads
  1. Q1Do the 1→2→3 schedule and category archive transfer to other harness-evolution systems (Meta-Harness, AgentFlow, HARBOR) on shared benchmarks like SWE-bench or GAIA?
  2. Q2Can the archive become shift-aware — detecting task-family changes online and switching from category elites to diverse retention?
  3. Q3Would a lightweight semantic-equivalence check on non-requested fields reduce silent regressions beyond the exact-target check?
  4. Q4Do the 0.28–0.48-point deltas persist with larger test sets and stronger base models that already emit structurally valid edits?
  5. Q5With the Typed Compiler removing the LLM from structural editing, could the controller's category sampler be learned from admission statistics?
