● Key metric — validation scale
0 / 10⁷

mismatches in ten million random test vectors per format (2×10⁷ for binary8) on the refined CDNA 3 model — after exactly 4 mismatch-driven refinement iterations.

Beta-posterior bound: p ≤ 1.38×10⁻⁶ (fp16/bf16/tf32) · 6.91×10⁻⁷ (binary8) at confidence 1−10⁻⁶

● Why this matters

GPU matrix units break IEEE 754 in undocumented ways. These bit-accurate models let you simulate AMD rounding error and cross-platform reproducibility — without data-center hardware.

● Critical edge

The "AMD RNE beats NVIDIA RTZ" verdict rests on B200 as the sole NVIDIA baseline — and "bit-accurate" is a probabilistic claim under two sampling strategies, not a proof.

● Methodology — how the silicon was interrogated

The object of study is a single MFMA output element d = Σ aₗ·bₗ + c. Every feature claim is backed by a test vector whose expected output is derived analytically for each candidate hardware behaviour — so one observation can rule a feature in or out.

01

Feature-targeted test vectors

Bit-pattern inputs (products and accumulators built from exact powers of two) are permuted to expose sequential-vs-multi-term FMA structure, FMA size NFMA, alignment width neab, final rounding mode, and subnormal / Inf / NaN semantics — for every input format from fp32 down to fp8-E4M3/E5M2 (FNUZ).

02

Mismatch-driven refinement loop

Feature space pooled from prior NVIDIA work; randomized ensembles (exponent–mantissa and independent-bit sampling) run on GPU, replayed in MATLAB. Any mismatch = incomplete feature space → investigate. This loop is how CDNA 3's two-stage round-down chain was found, after targeted tests alone suggested a wrong 31-bit reading. Cost: ~13 min MATLAB + 1–2 min GPU per 10⁶ samples.

03

Probabilistic validation

Beta posterior on mismatch probability: N error-free trials give an ε-upper bound pε ≈ |log ε| / (N+1) — explicit bounds instead of a bare "it matches".

Corrects the record — MI100's fp16/bf16 cores accumulate in full precision, contradicting FTTN's "3 extra alignment bits" (CCGrid 2024); CDNA 3 rounds the shifted product sum to 32 fractional bits, not the 31 reported in the MMA-Sim paper text (its GitHub repo already agreed).
GEMM emulation (multi-word arithmetic, n → 10⁶): fp16/bf16 — all three CDNA generations track each other, while NVIDIA B200 error grows with n; attributed to RTZ vs AMD's RNE final rounding.
SMD/PEVD (8×8, order-8 polynomial matrix, ε=μ=10⁻⁴, 250 iterations): dominant-eigenvalue deviations of 10⁻³–10⁻¹ for fp16/bf16; MI210 deviates most; fp8 judged unsuitable.
● Strengths
  • First exact documentation of AMD MFMA internals — NFMA, alignment widths, rounding chains, subnormal semantics — with reproducible test vectors, not assertions.
  • Mismatch-driven refinement is a genuinely effective pattern: randomized testing falsifies incomplete feature spaces (it found the CDNA 3 two-stage chain).
  • Validation carries explicit Beta-posterior bounds — more honest than most hardware-verification papers.
  • The released toolbox doubles as a design-space simulator for hypothetical matrix multipliers, not just a mirror of existing ones.
  • Compact cross-vendor table (AMD MI100–MI300X vs NVIDIA V100–B200) is immediately useful for low-precision reproducibility work.
● Limitations
  • No CDNA 4 (MI350) results — no hardware access at writing time.
  • Validation is probabilistic under two specific sampling strategies; rare input regimes could still hide mismatches.
  • One example per application; the SMD study is explicitly labelled inconclusive by the authors, and fp8 is dismissed from a single case.
  • NVIDIA comparison limited to B200 — no H100/A100 curves behind the RNE-vs-RTZ conclusion.
  • MATLAB-side validation is slow (~13 min per 10⁶ samples); backend port to C planned.
  • Models cover the MFMA inner computation only — no scheduling, tiling, or memory-layout effects of real GEMM libraries.
● Open questions this paper sets up
  1. Do the RNE-vs-RTZ and two-stage-rounding differences propagate into measurable cross-vendor divergence in real DNN training on identical seeds — predictable bit-for-bit?
  2. Does CDNA 3's c=0 / exponent-−126 quirk interact adversely with split-K GEMM or gradient-accumulation schemes that frequently pass zero or tiny C matrices?
  3. Will CDNA 4 (MI350) reuse the CDNA 3 accumulation chain or move toward wider NFMA=32 designs — and can the published vectors detect the difference in one run?
  4. Can adversarial, coverage-guided sampling push the Bayesian mismatch bounds below 10⁻⁹ at feasible cost?
  5. Once each architecture's exact rounding is known, is there an optimal word count and format per architecture for multi-word-arithmetic high precision — and does AMD's RNE edge persist if NVIDIA switches?
