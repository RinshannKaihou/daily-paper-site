Methodology 方法论

Instrument the backend, don't replace it

setup/reset→ agent phase→ handoff→ outcome→ reward→ release

1 · Binding. A compiler emits a typed task-binding template over the fixed authority/lifecycle vocabulary; authors fill only task semantics. Missing or conflicting values fail closed.

2 · Static lane. The binding activates a capability graph; phase-aware taint analysis propagates four influence kinds — agent control, protected info, failure state, stale state — toward lifecycle-sensitive sinks, exposing exploit paths before any run.

3 · Runtime lane. Trusted probes emit six authority-bearing events; Algorithm 1 replays them with fail-closed classification. The checker is a pure function of a sealed evidence bundle — archived runs can be relabeled without rerunning the agent, and static and runtime lanes share only a vocabulary, so neither contaminates the other.

Strengths 长处

What holds up

  • Machine-checkable, evidence-backed run-level claims from a fixed lifecycle vocabulary — the structural verdict needs no LLM call, cheap enough for every submission.
  • Exposure-vs-use separation is the right abstraction — honest and exploiting runs on the same package receive different verdicts; tasks aren't condemned for vulnerabilities honest runs never exercised.
  • The trajectory study is itself a contribution — mid-run timing (median attempt at 0.60), directional chain structure, and the verifier-deserialization red flag (a fifth of unclassified conditions) are actionable for any benchmark builder.
  • Isolation counterfactual with formal/measured agreement gives concrete hardening guidance, not vibes.
  • Transparent reporting — per-trial variance, stability alongside recall, named caveats against their own corpora, Inconclusive as a first-class outcome.

Limitations 局限

What to watch

  • BenchFlow-bound — tasks must be ported into BenchFlow form; arbitrary benchmark environments are not natively covered.
  • Fixed lifecycle — multi-turn negotiation or open-ended settings may need model extensions; multi-role benchmarks collapse roles into one untrusted domain; role-private noninterference is unchecked.
  • LLM-mediated semantics — action semantics and I7 depend on Claude Opus 5 audit agents: non-determinism, $5–10 per cell, label quality inherits the audit model's reliability.
  • Known blind spots — a SkillsBench control-plane escape was invisible to the static lane; raw-socket use falls outside the shell-decomposition channel.
  • External validity — three benchmarks, one dominated family (ClawsBench), single model vendor, post-hoc adjudication; the 69% hacking rate is corpus-selected, not population prevalence.

Questions for further exploration 后续问题

  1. Does the static-lane advantage survive when BenchJack runs in full red-team mode, with findings translated by a third party instead of the BenchShield authors?
  2. Can I7 semantic-adequacy auditing be distilled into a small specialized classifier — what is the accuracy/cost frontier?
  3. Does mid-run exploit timing (median attempt at 0.60) hold for RL-trained agents under explicit reward pressure, versus the tool-assistant agents studied here?
  4. How does the framework extend to multi-agent / multi-role benchmarks needing role-indexed authority domains and noninterference?
  5. Could the structural event vocabulary be standardized as an "evidence API" so other harnesses emit compatible streams?
  6. Would banning executable handoffs (typed, non-executing artifact formats) at packaging level eliminate the pickle.load class outright?
