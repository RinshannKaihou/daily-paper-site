Why This Matters

Production agent trajectories beat public synthetic data in a controlled ablation.

Critical Edge

The recursion is asserted, not demonstrated.

Authors concede every number reflects a single pass of the evaluate–select–update loop; whether gains compound across generations is untested.

SOURCE · CRITICAL ASSESSMENT & SECT. 6

Methodology

3 COMPONENTS · EVALUATE → SELECT → UPDATE

01 · Harness data engine

105–106 deployed trajectories become user-turn training units (current-turn reasoning and tool calls kept, history reasoning dropped). Admitted through deterministic structural gates (complete / recoverable / quarantined), a six-dimension semantic judge, and decontamination. The router’s predicted C0–C3 capability demand is preserved as a free difficulty signal.

02 · Routing-guided post-training

Token-masked SFT (loss only on current-turn assistant spans) with a 3-stage curriculum ordered by routing scores, no optimizer resets. Then on-policy distillation: the student generates from recorded contexts while a fixed teacher supervises via reverse-KL over coarsened top-K distributions.

03 · The loop

Stratified evaluation builds a deficiency profile that reallocates the next data mixture (composition, not new losses); updated checkpoints return to the harness to log new trajectories. One pass run so far.

Strengths

WHAT HOLDS UP

  • Coherent RSI answer — reframes the routing harness as a capability-measuring instrument that already exists in deployment.
  • Rigorous data pipeline — deterministic structural gates; a semantic judge that never converts missing evidence into a pass; decontamination against every eval suite.
  • Clean ablations — Toucan comparison isolates data source with matched init/seed/schedule; nested-subset study isolates supervision volume.
  • Honest reporting — consistent two-scale gains with per-benchmark detail, including the flat IFEval at 9B.
  • Mechanistic insight — trace analysis shows wins come from abandoning unproductive strategies, not searching harder.

Limitations

WHERE CONFIDENCE DROPS

  • One loop iteration only — the central recursive claim is unvalidated by construction.
  • Missing ablations — no curriculum-vs-random-ordering control, no SFT/OPD split, OPD teacher undisclosed.
  • Proprietary corpus — harness-vs-public mixture ratios and per-stage token counts unquantified (“105–106 trajectories”).
  • Narrow eval surface — text-only, skewed agentic/coding; multimodal and long-horizon tasks untested.
  • Protocol compromises — single-run Pinch/Vita, swapped VitaBench judge, asterisked blog-sourced baselines; harness-aligned gains may not transfer to unseen harnesses.

Questions for Further Exploration

OPEN THREADS

  • Do the +5.93 / +3.44 gains survive a second and third pass of the loop, or does deficiency-driven reallocation saturate?
  • How much of the curriculum’s benefit comes from routing scores specifically versus any difficulty proxy? No random-ordering control exists.
  • What is the SFT vs on-policy distillation split at each scale, and how sensitive is OPD to the undisclosed teacher’s strength?
  • Would the +6.26 edge over Toucan persist if the public data were quality-filtered to match the harness gates?
  • Can C0–C3 tier predictions be calibrated into true difficulty estimates, letting the harness also select what tasks to attempt next?
  • Do the OpenSquilla-aligned gains transfer to unseen harnesses — is the model learning agent skills or harness-specific conventions?
