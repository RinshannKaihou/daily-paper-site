一句话总结：定义并量化 LLM 智能体的“一致性鸿沟”（AppWorld 上 ReAct/GPT-4.1 的 Mean@5 为 77%，五次全过仅 53%），黑盒两阶段框架使同任务 Pass@5 提升 16 个百分点，且不牺牲平均准确率。

Closing the Consistency Gap: Self-Evolving Agents That Learn to Stay on Course
Evelyn Duesterwald, Benjamin Elder, Lilian Ngweta, Shashanka Ubaru, et al. · IBM Software Innovation Lab & IBM Research · AAAI 2026 · code open-sourced (ALTK-EVOLVE)
arXiv 2609.08832 #llm-agents#reliability #consistency#agentic-memory #self-evolving-agents
Key metric
+16pp Pass@5

Same-task reliability on AppWorld, 53.0% → 69.0% (ReAct / GPT-4.1, k = 5) — and Mean@5 rose +3.6 pp, so nothing was traded away for stability.

Why this matters

Average accuracy masks repeat-run unreliability in deployed agents; this work ships reusable metrics (Gap@k, Consistency@k) and a plug-and-play black-box fix.

⚠ Critical edge

Everything rests on one benchmark (AppWorld), one agent scaffold (ReAct), and two models from one ecosystem — generality is asserted, not shown.

Methodology detect → generate, fully black-box

Two offline stages ride on a trajectory-informed agentic-memory loop. Detect: every recorded prompt is re-issued to the same hosted endpoint N = 30 times (temp 0.5); response concentration estimates each step's flip risk, scored by type — SBERT pairwise cosine for text/code, Jaccard for categorical values (tool names, enum args), weighted per-field combination for ReAct JSON.

Generate: decision-path steps scoring below θ = 0.85 are flagged and converted into strategy / recovery / optimization guidelines, stored in dual-indexed episodic memory and retrieved at runtime by cosine similarity.

  1. 1 Record trajectory
  2. 2 Resample ×30
  3. 3 Flag C < 0.85
  4. 4 Write guidelines
  5. 5 Inject at runtime

Why temp-0 doesn't help: on hosted endpoints the token distributions themselves drift run-to-run (GPU float noise, batching, tokenizer state), so flat near-tied distributions flip anyway.

Strengths

  • Names a real production problem — average accuracy masking repeat-run unreliability — with clean, reusable metrics that separate consistency from capability.
  • Fully black-box: no logits, no fine-tuning, no changes to the inference loop; works with any agent on a hosted endpoint.
  • Crisp token-level account of why greedy decoding can't fix run-to-run variance.
  • The consistency–accuracy trade-off is avoided: Mean@5 rises alongside Pass@5 in nearly every cell.
  • Honest limitations section; pipeline contributed to open source.

Limitations

  • Single benchmark, single scaffold, two models — generality asserted, not shown; “similar-task” transfer means sibling variants of the same scenario.
  • N = 30 resampling multiplies token cost ~30× per trajectory; adaptive sampling is future work.
  • Analyzer scores stability, not correctness — a confidently-wrong step looks consistent, so guidelines can entrench systematic errors.
  • No validation gate before memory admission: guidelines are self-judged from a single trajectory.
  • Mean step-aggregation ignores error propagation; a substantial gap remains even after intervention.

Questions for further exploration

  1. Does the +16 pp gain survive on WebArena, SWE-bench, τ-bench — or other scaffolds like plan-and-execute and computer-use agents?
  2. Can adaptive sampling cut the ~30× token cost by concentrating budget on candidate flat steps only?
  3. Would a held-out validation gate before memory admission measurably reduce harmful guideline accumulation?
  4. How often do guidelines stabilize a wrong decision pattern, and does mixing in a verifier mitigate it?
  5. Does the gap persist under self-hosted inference with pinned seeds — where the paper's platform-noise mechanism should vanish?
