Key Finding · arXiv 2609.12655

Organizing agent memory by underlying workflow — not surface semantics — turns catastrophic forgetting into positive backward transfer.

LifeMem 提出一种双层记忆框架：先按底层“工作流”而非表面语义对异构环境的交互轨迹进行聚类，再从每个聚类局部蒸馏环境无关的技能——显著缓解灾难性遗忘，并支持零样本跨环境迁移。

Why This Matters

A deployable recipe for self-evolving agent memory: organize experience by workflow, distill skills locally, resist forgetting, transfer zero-shot.

对构建自进化智能体（self-evolving agents）的记忆模块具有直接参考价值：双层设计、13k 任务 × 10 环境基准与 2k 新标注轨迹均可复用。

Critical Edge

Under a fully random task stream, LifeMem's edge over ExpeL collapses from +2.28 to just +0.26 (GPT-4o-mini) — the similarity-ordered headline curriculum does part of the work.

— Critical Assessment: stream-order sensitivity is the paper's biggest red flag

Methodology

Memory as a living index of workflows

Three phases; clusters are the unit of storage, one distilled skill per cluster.

  1. Initialize

    An LLM partitions a seed pool of trajectories into workflow-level clusters (initial pool size 5), each summarized by a one-line description.

  2. Evolve

    Each new trajectory is embedded (FAISS over all-MiniLM), its top-4 neighbors retrieved, and an LLM decides ADD vs NEW cluster. A cluster splits only when it holds n > 50 trajectories and directional concentration R < 0.95 (Mean Resultant Length — a geometric test against redundant, templated behavior). After every update, each cluster re-distills into one concise, environment-invariant skill text.

  3. Infer

    For a new task: retrieve top-k same-environment trajectories (action-format grounding) and activate their clusters' skills (transferable principles). Actions condition on both tiers.

Benchmark: 10 environments (12,489 train / 1,230 test) spanning embodied action, tool use, web search, data analysis and web browsing, similarity-ordered. Baselines Synapse / ExpeL / AutoSkill all get GPT-4.1 for experience extraction. Backbones: GPT-4o-mini, DeepSeek-v3.2-exp, Qwen3-32B.

Credibility: BITHLP lab (BIT) with HIT and Baidu; code and all 2,310 newly annotated trajectories open-sourced; >90% of generated intermediate actions judged reasonable by humans.

  • Weaker backbones gain more: GPT-4o-mini +15.29 over ReAct (28.84 → 44.13) vs DeepSeek +6.88; on Qwen3-32B the margin widens to 46.52 vs ExpeL's 43.29.
  • Zero-shot transfer: FEVER (unseen formulation) 0.49 vs 0.40 for ReAct (+22.5%); unseen τ-bench airline environment 0.38 vs 0.32 (+18.8%); skills alone already give +17.5%.
  • Retrieval upgrades can't substitute: Synapse with ada-002 embeddings reaches only 40.55, and BGE re-ranking hurts (37.29) — both far below 44.13. The architecture, not retrieval quality, is the bottleneck.
  • Stream-order robustness: fully random order drops LifeMem to 39.63 (still first); a size-5 buffer recovers 41.64.
  • Cheap: ~$1 per 1k trajectories to build memory; only ~+300 inference tokens over Synapse (2.18k vs 1.88k; AutoSkill needs 4.68k).
  • Cluster quality: 91% human-annotated workflow purity; granularity self-adapts (WebShop ~29 trajectories/cluster vs τ-bench ~12).

Strengths

What holds up

  • Directly targets both documented failure modes of agent memory — cross-environment action-space mismatch in raw-trajectory retrieval, and noise in global skill abstraction — with ablations confirming the mechanism.
  • Unusually broad evaluation: 3 backbones × 10 environments × 4 baselines, plus transfer, robustness, cost and cluster-quality analyses.
  • The "retrieval upgrades don't fix it" experiment is a genuinely persuasive negative control isolating the architectural contribution.
  • Inference-cheap: ~300 extra tokens over Synapse, vs AutoSkill's 4.68k-token bloat.
  • Code and all 2,310 newly annotated trajectories open-sourced, with disclosed annotation protocol and human quality checks.

Limitations

Where it creaks

  • The similarity-ordered curriculum favors consolidation; under random order the ExpeL margin nearly vanishes (+0.26), and the buffer remedy assumes you can hold and batch the stream.
  • Averages hide per-dataset losses: MiniWoB++ 78.72 vs AutoSkill's 97.87; ToolQA 68.75 vs ExpeL's 71.25; on DeepSeek/MiniWoB++ memory-free ReAct (93.75) beats every memory method.
  • Mind2Web is near-floor (3.17–4.37) for all methods — decorative breadth in the "10 environments" claim.
  • Memory operations depend on proprietary LLMs (GPT-5-mini assignment, GPT-4.1 distillation); no significance tests; OOD transfer rests on 100 FEVER / 50 airline cases.
  • Skills are static once distilled — no pruning or refresh when environments drift.

Open Questions · For Further Exploration

  1. Would replacing the MRL concentration test with embedding variance or silhouette criteria — at matched cluster counts — change the results?
  2. Can stream-order fragility be fixed without a buffer, e.g. periodic offline re-clustering (memory defragmentation) or order-invariant assignment?
  3. What happens when the environment itself drifts (changed UI/API), making old trajectories and skills actively misleading?
  4. Does the weaker-backbone benefit persist for genuinely small on-device models (≤8B) — the deployment scenario the paper invokes?
  5. Is incremental cluster-level re-distillation asymptotically cheaper than AutoSkill-style global re-extraction, and where do the cost curves cross?
  6. Since skills-only inference achieves most of the FEVER transfer (+17.5% of +22.5%), could the trajectory tier be dropped to halve context cost?
