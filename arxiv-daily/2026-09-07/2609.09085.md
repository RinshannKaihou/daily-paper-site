> **一句话总结：** 本文通过一系列干预实验证明，LLM 首位置的 Attention Sink 与 Massive Activations 既非 BOS token 也非 RoPE 位置编码所致，而是因果掩码强制产生的"自集中"(α₁,₁=1.0) 及随之而来的 "Value 不混合" 状态（注意力输出退化为单个 Value 向量的直通）所驱动——在 WikiText 上强制位置 16 自集中后，Llama-2-7B 的 Sink 指标从 0.0073 飙升至 0.8397。

> **TL;DR:** Through controlled interventions on five open LLMs (Llama-2-7B, Llama-3.2-3B, Mistral-7B-v0.3, Qwen2-7B, pythia-1b) over 100 WikiText sequences, the authors show that neither the BOS token nor RoPE positional encoding creates attention sinks (RoPE-key intervention moves Sink^0.3 from 0.9305 to only 0.9273 on Llama-2-7B), while forcing causal-mask-style self-concentration (α_t,t=1.0) at position 16 raises Sink^0.3 from 0.0073 to 0.8397 on Llama-2-7B — and the resulting "Value-non-mixing" state (output = unmixed own Value vector) alone, reproduced via repeated-token inputs without any attention intervention, re-induces sinks and massive activations in 3 of 5 models. The work pinpoints a structural cause of the outliers that plague low-bit quantization, though it stops short of measuring any actual quantization or downstream-task benefit.

## 核心贡献

- **分解首位置三因素并逐一排除**：将序列首位置的特性拆解为 (1) BOS token、(2) 首个位置编码（RoPE）、(3) 因果掩码强制的自集中，通过干预实验逐一定量检验其对 Attention Sink (AS) 与 Massive Activations (MAs) 的贡献。
- **排除 RoPE 假说**：将首 token 的 Key 侧 RoPE 旋转替换为随机位置的旋转矩阵，5 个模型的 Sink 指标几乎不变（如 Llama-2-7B 从 0.9305 到 0.9273），证明 Key 侧位置编码并非 AS 的主因——呼应标题"创造 Sink 的不是 RoPE"。
- **锁定自集中 → Value 不混合的因果链**：因果掩码迫使首 token 将全部注意力集中于自身（α₁,₁=1.0），导致其注意力输出退化为自身单个 Value 向量的"直通"（Value-non-mixing，yi = vi·WO）。在位置 16 强制自集中后，AS 与 MAs 在非首位置全面涌现。
- **无需干预即可复现**：用重复相同 token 的序列（所有 Value 向量相同）在不干预注意力的条件下重现 Value 不混合状态——仅在序列中插入一个不同 token，AS/MAs 便出现在维持该状态的区段、在混合恢复后消失（Llama-2 系列上 Sink 从 0.0000 升至 0.68–0.80）。
- **定位关键层位**：仅在前 3 层施加自集中干预即可达到全层干预效果的 90–93%，而中层/后层干预几乎无效，说明该机制主要在早期层成形。

## Key Contributions

- Decomposes the sequence-initial position into three confounded factors — BOS token identity, first positional encoding (RoPE), and forced self-concentration under causal masking — and disentangles their individual contributions to Attention Sinks (AS) and Massive Activations (MAs) with a unified quantitative metric (Sink^ε_j, Gu et al. 2025) across five open-weight LLMs.
- Rules out the RoPE explanation: replacing the initial token's Key-side RoPE rotation matrix with a random position's rotation leaves Sink^0.3_1 essentially unchanged in all five models, showing Key-side positional encoding is not the driver of sinks.
- Identifies causal-mask-induced self-concentration as a sufficient trigger: forcing α_t,t = 1.0 at a non-initial position (t=16, all layers, no BOS) induces both AS and MAs in all five models.
- Formalizes and tests the "Value-non-mixing" hypothesis (Equation 4: all Value vectors receiving nonzero attention at position i equal v_i, hence y_i = v_i·W_O): repeated-identical-token sequences reproduce this state without any attention intervention, and inserting a single distinct token confines AS/MAs to exactly the prefix where the state holds — supporting the mechanism in three of five models.
- Localizes the effect to early layers: restricting the intervention to layers 1–3 recovers 90–93% of the all-layer Sink effect, while middle/late-layer interventions have no effect.

## Methodology

The study runs a sequence of intervention experiments on Llama-2-7b-hf, Llama-3.2-3B, Mistral-7B-v0.3, Qwen2-7B, and pythia-1b (chosen to span MHA/GQA, LayerNorm/RMSNorm, partial vs. full RoPE, and QKV-bias variations). Unless noted, inputs are T=64-token sequences from 100 WikiText-2-raw samples, and sink strength is measured by Sink^ε_j — the fraction of (layer, head) pairs whose averaged attention to position j exceeds ε (ε=0.3 by default, with sweeps over 0.2–0.5); MAs are tracked via layer-wise hidden-state norms.

1. **BOS swap (Section 3):** The BOS token is swapped with the token at position 16. AS still appears at the relocated BOS and at the initial position, showing both the token and the position contribute independently of token identity.
2. **RoPE intervention (Section 4.1):** The initial token's Key-side rotation R_Θ,1 is replaced with R_Θ,r for random r ∈ {2..T}, on BOS-free sequences. Sink barely moves — positional encoding is exonerated.
3. **Self-concentration intervention (Section 4.2):** Attention weights at position t=16 are forced to α_16,16 = 1.0 across all layers (no BOS). Both AS and MAs emerge at position 16 in all five models; layer-subset, position-sweep (t=8, 32), dataset (WikiText/GSM8K/SlimPajama), and length (T=32–256) ablations confirm robustness.
4. **Value-non-mixing test (Section 4.3):** Sequences of one repeated token (all Value vectors identical, no BOS, no intervention) make every attention output a pass-through of the same Value vector. Inserting one distinct token at position 1, 2, or 3 bounds the region where outputs remain unmixed; AS/MAs appear exactly within that region and subside after it.

Experiments ran on one NVIDIA RTX 6000 Ada GPU (~4 hours for main results) with PyTorch 2.9.0 / transformers 4.57.1; code is released at github.com/kiya-raito/value-non-mixing.

## Results & Highlights

- **RoPE intervention (control, WikiText, T=64, no BOS):** Sink^0.3_1 stays essentially flat — Llama-2-7b-hf 0.9305 → 0.9273 (−0.003), Qwen2-7B 0.8173 → 0.7931, pythia-1b even rises slightly 0.7337 → 0.7547 — i.e., the Key-side positional index explains almost none of the sink.
- **Self-concentration intervention (WikiText, t=16, all layers, no BOS):** Sink^0.3_16 jumps from 0.0073 (vanilla) to 0.8397 on Llama-2-7b-hf (+0.83), 0.0012 → 0.7424 on Llama-3.2-3B, 0.0000 → 0.5085 on Qwen2-7B, and 0.0000 → 0.4703 on pythia-1b; only Mistral-7B-v0.3 responds weakly (0.0373 → 0.1509). MAs (hidden-state norm blow-ups) appear at the intervened token in the same runs.
- **Repeated-token Value-non-mixing (T=64, no intervention, no BOS, Table 5):** uniform repeated-token sequences give Sink^0.3_1 = 0.0000 for all five models, yet inserting a single distinct token raises it to 0.68–0.80 on Llama-2-7b-hf and 0.69–0.80 on Llama-3.2-3B (vs. the 0.0000 uniform baseline), 0.42–0.55 on Qwen2-7B, 0.07–0.16 on Mistral-7B-v0.3, and only ≈0.006 on pythia-1b — clean support in three models, weak/input-dependent in two.
- **Layer-subset ablation (Table 10):** early layers 1–3 alone reach 90–93% of the all-layer effect (Llama-2-7b-hf: 0.7724 early vs. 0.8397 all-layer vs. 0.0073 vanilla; Qwen2-7B: 0.4737 vs. 0.5085 vs. 0.0000), whereas middle/late three-layer interventions leave Sink at vanilla level (0.0074 for Llama-2-7b-hf); layer 1 alone nearly reproduces the full effect in Mistral-7B-v0.3 (0.1385 vs. 0.1509) and pythia-1b (0.4443 vs. 0.4703).
- **Position sweep (Table 11):** the intervention generalizes beyond t=16 — Sink^ε_t rises from 0.0000 to 0.8542 (t=8) and 0.0072 to 0.8217 (t=32) on Llama-2-7b-hf, with the other three strong models in the 0.4654–0.7560 range; Mistral-7B-v0.3 again stays far weaker (0.0660 → 0.1347 at t=8).
- **Robustness (Table 6):** across WikiText, GSM8K, and SlimPajama at lengths 32–256, every model shows a nonzero intervened Sink^0.3_16 (e.g., Llama-3.2-3B 0.7424 / 0.6769 / 0.7680 on the three datasets at T=64), and trends are stable across ε ∈ {0.2, 0.3, 0.4, 0.5}.
- **BOS swap (Table 1):** relocating the BOS to position 16 leaves position-1 sinks intact (Llama-2-7b-hf 0.9321 → 0.9178) while creating a new sink at position 16 (0.0001 → 0.7597) — token identity and position both matter, independently.

## Authors & Credibility

Nine authors from Tohoku University, SOKENDAI, NINJAL, MBZUAI, RIKEN, and Preferred Networks — a credible Japanese NLP collaboration (Keisuke Sakaguchi and Goro Kobayashi are established interpretability/NLP researchers). The work is precise about what it does and does not claim, includes an unusually thorough robustness appendix (thresholds, datasets, lengths, positions, layer subsets), releases code, and acknowledges generative-AI assistance with coding/manuscript plus funding sources (Google Research grant, JST, JSPS). Experimental cost is modest (one RTX 6000 Ada, ~4 h), which makes independent replication easy.

## Critical Assessment

- **Novelty:** Solid incremental contribution. The causal chain "causal mask → self-concentration → Value-non-mixing → AS/MAs" is a sharper mechanistic claim than prior accounts (no-op softmax of Bondarenko et al., key-bias of Gu et al., causal-mask asymmetry of Wu et al.), and the RoPE exculpation is a useful negative result. However, the building blocks (self-attention of the first token; sink/outlier co-occurrence) were known, and the paper's own Limitations admit the link to naturally occurring intermediate sinks is untested.
- **Rigor:** The intervention design is clean — BOS-free controls, ε sweeps, position sweeps, three datasets, layer subsets, N=100 sequences per condition. But the headline Value-non-mixing evidence holds cleanly in only 3 of 5 models: pythia-1b's Sink^0.3_1 stays ≤ 0.03 at every threshold in the repeated-token experiment (Table 5), and Mistral-7B-v0.3's intervened Sink is 5–9× smaller than the other models (0.1509 vs. 0.4703–0.8397) — the paper is honest about this but cannot explain it, which weakens universality claims.
- **Reproducibility:** Excellent — public HF checkpoints, standard library versions, released code, and cheap compute.
- **Significance:** The practical motivation is quantization-robust architectures (citing Qwen3-Next and gpt-oss sink-reduction designs), yet the paper measures no quantization error, perplexity, or downstream accuracy — the quantization payoff remains conjectural. As pure mechanistic understanding, the value is real but modest.
- **Red flags:** (1) Repeated-token inputs are far from natural language — the strongest causal evidence comes from a highly artificial distribution; (2) the RoPE intervention touches only the Key side, so "It's Not RoPE" (the title's central claim) is only half-tested — query-side and query–key interaction effects are explicitly left open; (3) all five models are RoPE-based, so nothing is said about ALiBi/NoPE models; (4) the threshold metric Sink^ε_j is length-sensitive (at repeat length 16 with ε=0.2 even uniform sequences score ~0.95), which the authors flag themselves.

## Strengths

- Clean factorial disentanglement of three confounded properties of the initial position (BOS, RoPE, self-concentration) with a single unified metric across five architecturally diverse models.
- The self-concentration intervention is a genuinely convincing sufficiency argument: sinks and massive activations can be created at an arbitrary middle position on demand.
- The repeated-token design is clever — it reproduces Value-non-mixing without touching attention weights, cleanly separating "state" from "mechanism that produces the state."
- Exceptionally thorough robustness appendix (ε ∈ {0.2–0.5}, T ∈ {32–256}, three datasets, t ∈ {8, 16, 32}, layer subsets, per-model figures) and a candid Limitations section.
- Fully reproducible: released code, cheap compute, public checkpoints.

## Limitations

- The Value-non-mixing mechanism is cleanly demonstrated in only Llama-2-7b-hf, Llama-3.2-3B, and (moderately) Qwen2-7B; Mistral-7B-v0.3 responds weakly and pythia-1b barely at all, and the architectural source of this variance is unknown.
- The RoPE intervention manipulates only the Key-side index; query-side positional effects and full query–key RoPE interactions are not isolated, so the title's "Not RoPE" claim is stronger than the evidence.
- Scope is restricted to the sequence-initial position; whether naturally occurring mid-sequence sinks (Sun et al. 2024) fit the same framework is open.
- Value-non-mixing is a discrete, idealized state — no continuous "Value Mixing Index" is validated against natural inputs.
- Sink^ε_j with fixed ε is sequence-length-sensitive (attention averages 1/i over accessible keys), complicating cross-length comparisons.
- No downstream evaluation: quantization error, perplexity, and task accuracy under the analyzed phenomena are never measured, leaving the practical implication unsupported by data.
- Only RoPE-based, English-only evaluation; MoE and other positional schemes (ALiBi, NoPE) untested.

## Relevance

对理解 LLM 内部机制与量化鲁棒性设计有直接价值：本文给出了 Attention Sink / Massive Activations 的结构性成因（因果掩码 → 自集中 → Value 不混合），为低比特量化中的离群值问题和 Qwen3-Next、gpt-oss 等去 Sink 架构设计提供了机制层面的解释依据，契合对 Transformer 注意力内部动力学与可解释性的研究兴趣。

## Questions for Further Exploration

- Would a query-side (or joint query–key) RoPE intervention change the picture, or does the "Not RoPE" conclusion fully survive?
- Why do Mistral-7B-v0.3 and pythia-1b resist the Value-non-mixing effect — is it partial-RoPE, QKV biases, normalization choice, or training-data scale?
- Can a continuous Value Mixing Index (measuring actual Value-vector similarity in attention outputs) predict natural-text sink strength and MA magnitude across models?
- Do Value-non-mixing-induced massive activations actually degrade INT4/INT8 quantization error or perplexity, and would architecturally breaking the state (e.g., learned "mixing" at position 1, as in Qwen3-Next / gpt-oss sink mitigation) recover accuracy?
- Does the same mechanism explain naturally occurring sinks at mid-sequence outlier positions reported by Sun et al. (2024)?
- How do non-RoPE positional schemes (ALiBi, NoPE) or MoE architectures behave under the same interventions?
