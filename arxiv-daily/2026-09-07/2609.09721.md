> **一句话总结：** EFQ-Softmax 跳过"先算 exp 再量化"的传统路径，用"块内指数尺度 + 残差对数域仿射映射"把行最大平移后的注意力分数直接生成为块缩放 E2M1（MXFP4）概率操作数，在 Ascend 950PR 向量单元上将概率生成阶段延迟平均降低 40.33%（16K–128K 序列），同时把 Qwen3-VL-8B 九任务均值从 MXFP4 的 0.7826 提升到 0.8000。

> **TL;DR:** Low-bit attention kernels quantize QK^T and PV to FP4/FP8 but still compute softmax exponentials in FP16/FP32 and quantize afterwards ("exp-then-quantize"). EFQ-Softmax replaces that path with a direct shifted-score→E2M1 generator: an exponent-only power-of-two scale per microscaling block plus a single affine threshold rule (two calibrated parameters) in the residual log domain, feeding the SAME operand to both the P̃V numerator and P̃1 denominator while preserving the FlashAttention online recurrence. On the Ascend 950PR vector unit the fused probability-generation kernel's vector-stage latency drops 40.33% on average vs an MXFP4 baseline (e.g., 7043.8→4192.3 µs at 128K); end-to-end quality holds on Qwen3-8B (7-task mean 0.6773 vs 0.6749 for MXFP4, FP16 0.6803), improves clearly on Qwen3-VL-8B-Instruct (9-task mean 0.8000 vs 0.7826, +0.0174, all six RefCOCO/RefCOCO+ grounding splits better), and stays comparable on WAN2.2-TI2V-5B under VBench (imaging quality 0.7178, highest of the three variants).

## 核心贡献

- **提出 EFQ-Softmax，首个（在 FlashAttention 在线注意力框架内）直接从平移分数生成低比特概率操作数的方法**：跳过逐元素指数计算与事后量化（exp-then-quantize），将概率生成融合为"块最大值 → 指数-only 尺度 → 残差对数域归一化 → 仿射 E2M1 编码"四步直通路径。
- **指数-only 块尺度规则**：对每个 microscaling 块取 s_b = 2^{k_b}，k_b = ⌊(M_b + log(2/9))/log 2⌋（M_b 为块内最大平移分数），使 6·s_b 逼近 e^{M_b}；尺度为纯二次幂，避免通用浮点尺度生成步骤。
- **单仿射规则生成 4-bit 概率码**：残差 z_t = x_t − k_b·log2 − log 6 后，用 c_t = clip[0,7](⌊(z_t − τ)·h⌋ + 1) 直接映射到非负 E2M1 码集 C8 = {0, ½, 1, 3⁄2, 2, 3, 4, 6}；全方法仅两个拟合参数 (τ, h)，离线校准后推理期固定。
- **分子分母共用同一操作数**：生成的块缩放 E2M1 操作数同时用于 P̃V 分子更新与 P̃1 分母更新，避免两个分支使用不同概率近似造成的失配。
- **完整保留 FlashAttention 在线递推**：行最大更新、历史重缩放（α = exp(m_old − m_new)，该行级 exp 保留）、FP16/FP32 高精度累加、最终归一化均不变；只替换当前块的 P̃ = exp(x) 生成路径，不定义新的 value 侧量化器、新注意力规则或剪枝方法。
- **实测跨模态有效**：语言（Qwen3-8B）、视觉语言（Qwen3-VL-8B-Instruct）、文生视频（WAN2.2-TI2V-5B）端到端质量保持或超过 MXFP4，Ascend 950PR 概率生成向量阶段平均提速 40.33%。

## Key Contributions

- Proposes EFQ-Softmax, a probability-generation method that directly maps row-max-shifted attention scores to block-scaled E2M1 (MXFP4) operands, fusing exponential approximation and probability quantization into one stage and eliminating the temporary FP16/FP32 probability tile of the conventional path.
- Designs an exponent-only block-scale rule (s_b = 2^{k_b} with k_b = ⌊(M_b + log(2/9))/log 2⌋) that aligns the block maximum with the largest nonnegative E2M1 code value 6, keeping the scale power-of-two and hardware-friendly.
- Generates the 4-bit probability code with a single affine rule c_t = clip[0,7](⌊(z_t − τ)·h⌋ + 1) over the nonnegative E2M1 set C8 = {0, ½, 1, 3⁄2, 2, 3, 4, 6}, deliberately trading scalar nearest-rounding optimality for a simpler index-generation path; only (τ, h) are fitted, via offline calibration minimizing the relative Frobenius error of the attention output on calibration blocks.
- Uses the same generated operand in both the P̃V numerator and P̃1 denominator updates, guaranteeing numerator/denominator consistency in the online recurrence.
- Integrates cleanly into FlashAttention-style online attention: row-maximum update, historical rescaling (row-level α = exp(m_old − m_new) is retained), high-precision accumulation, and final normalization are untouched; masks are applied before the shift and EFQ-Softmax sits exactly where the exact kernel would evaluate exp(x).
- Provides an accuracy-oriented ablation variant, EFQ-Softmax-LUT (16-level intermediate index folded to 8 codes via a monotone table), quantifying how much accuracy extra mapping flexibility buys.

## Methodology

The method targets only the probability path of low-bit attention. For a score tile S_ij, the kernel first updates the row maximum m_i^j (Eq. 4) and forms shifted scores x_ij = S_ij − m_i^j ≤ 0. Where a conventional FP4 path evaluates exp(x) in FP16/FP32, materializes a probability tile, and quantizes it to E2M1, EFQ-Softmax executes a five-stage direct pipeline per microscaling block b:

1. **Block maximum:** M_b = max_{t∈b} x_t.
2. **Exponent-only scale:** k_b = ⌊(M_b + log(2/9))/log 2⌋, s_b = 2^{k_b}, chosen so 6·s_b ≈ e^{M_b} (the log(2/9) constant is part of the scale rule, not a fitted parameter).
3. **Residual log-domain normalization:** z_t = x_t − k_b·log 2 − log 6, so e^{x_t} = s_b · 6·e^{z_t}; power-of-two rounding bounds z_max per block, which is why one global (τ, h) pair works across rows and layers.
4. **Affine code generation:** c_t = clip[0,7](⌊(z_t − τ)·h⌋ + 1), packed as a 4-bit nonnegative E2M1 pattern (represented value p̃_t = 2^{k_b}·C8[c_t]). Uniform residual thresholds + fixed nonuniform E2M1 outputs; saturation at codes 0/7 is part of bounded index generation, not a pruning rule.
5. The block-scaled operand (s_b, Q_P) is consumed by BOTH the numerator ΔA = P̃V and the denominator Δl = P̃·1; per-key/value-block online updates A_i^j = α·A_i^{j−1} + ΔA, l_i^j = α·l_i^{j−1} + Δl, with α = exp(m^{j−1} − m^j) and final O = A/l, all in FP16/FP32 as in standard low-bit pipelines.

Parameter calibration (Algorithm 3) sweeps candidate (τ, h) offline on representative attention activations and selects the pair minimizing ‖Õ(τ,h) − O_ref‖_F/‖O_ref‖_F — an output-level objective capturing coupled numerator/denominator error, explicitly not per-input adaptation. After calibration the operating point is fixed for inference. Reported operating points: EFQ-MMLU (τ=−2.90, h=2.00), EFQ-Mean (τ=−3.06, h=2.30) for Qwen3-8B; EFQ-Balance (τ=−2.10, h=2.70) for Qwen3-VL. The LUT ablation uses a 16-level intermediate index (τ16=log(1/24)) folded through the monotone table C16 = [0,1,1,1,1,1,2,2,3,3,4,5,5,6,7,7]. Experiments replace self- and cross-attention over the token stream in Qwen3-8B, Qwen3-VL-8B-Instruct, and WAN2.2-TI2V-5B with the quantized attention, leaving everything else unchanged; baselines are FP16 and a standard MXFP4 implementation following the FlashAttention-2 tiling loop.

## Results & Highlights

- **Kernel speedup (Ascend 950PR vector unit, fused P-quant kernel, 16K–128K tokens):** vector-stage latency falls 40.33% on average vs MXFP4 (mean 1768.1 → 1052.8 µs), nearly invariant across sequence lengths — 40.10% at 16K (112.6 → 67.4 µs) up to 40.48% at 128K (7043.8 → 4192.3 µs); the fixpipe stage gains only 0.77% on average (1741.9 → 1725.0 µs) and mmad is identical by construction.
- **Qwen3-8B, 7 zero-shot lm-eval-harness tasks (BoolQ/OBQA/RTE/WinoGrande/MMLU/ARC-E/ARC-C, batch 8):** EFQ-Softmax-Mean reaches a 7-task mean of 0.6773 vs 0.6749 for the MXFP4 baseline (+0.0024) and 0.6803 for FP16; the 16-code EFQ-Softmax-LUT ablation reaches 0.6784 (+0.0036), showing the 8-code affine rule gives up little. Per-task, EFQ-Mean gains +0.0140 on OpenBookQA (0.3220 vs 0.3080) and +0.0079 on WinoGrande (0.6906 vs 0.6827); EFQ-MMLU posts the best BoolQ in the table (0.8703 vs 0.8667 MXFP4).
- **Qwen3-VL-8B-Instruct (EFQ-Balance):** 9-task mean rises from 0.7826 (MXFP4) to 0.8000 (+0.0174), with ALL six referring-expression grounding splits improving — RefCOCO testA ACC@0.5 +0.0430 (0.89722 vs 0.85418), RefCOCO val +0.0344, RefCOCO+ testA +0.0344 — while VQA degrades at most −0.0032 (AI2D 0.83323 vs 0.83646) and even gains +0.0007 on TextVQA; underlying IoUs follow the same trend (e.g., RefCOCO testA IoU 0.8257).
- **Batch robustness (Qwen3-8B):** at batch 16 and 24, each method's 7-task mean deviates by ≤0.006 from its batch-8 value (batch 24: FP16 0.6809, MXFP4 0.6735, EFQ-Mean 0.6785, i.e., +0.0050 over MXFP4), confirming the ordering is not a batching artifact.
- **WAN2.2-TI2V-5B text-to-video (14 prompts, 1280×704, 121 frames, 50 UniPC steps, fixed seed 123469):** under VBench, EFQ-Softmax attains the highest imaging quality of the three variants (0.7178 vs 0.7098 FP16 and 0.7004 MXFP4), with temporal metrics essentially unchanged — subject consistency 0.9493 (vs 0.9509 FP16 / 0.9536 MXFP4), background consistency 0.9564, temporal flickering 0.9784 (vs 0.9801 FP16), motion smoothness 0.9891 — though dynamic degree is 0.5000 vs 0.5714 for FP16 (tied with MXFP4) and aesthetic quality 0.6355 sits below FP16's 0.6488.

## Authors & Credibility

A seven-author team spanning Xi'an Jiaotong University (five authors, including corresponding author Xiaodong Yan), Huawei Technologies (two authors), and Shandong University of Finance and Economics. The Huawei involvement explains and lends credibility to the Ascend 950PR kernel-level evaluation — this is real silicon, not a simulator. The paper situates itself honestly in the SageAttention lineage (SageAttention3, NeurIPS 2026, is cited as the closest MXFP4 attention work whose improvements "still compute the exponential values before converting"). The writing is precise about method boundaries (what is and is not changed in the online recurrence) and about which constants are rule constants vs fitted parameters. No code release is mentioned, and evaluation on hardware outside Ascend is absent.

## Critical Assessment

- **Novelty:** The core idea — direct score-to-E2M1 mapping via exponent-only block scale + affine residual thresholds — is a sensible kernel-level fusion rather than a new algorithmic primitive; it explicitly builds on the SageAttention3 MXFP4 attention setting, and the paper itself admits the affine rule "gives up scalar nearest-rounding optimality" for a simpler data path. The LUT-flavored variant is standard practice.
- **Rigor:** End-to-end gains on language are thin: +0.0024 on the Qwen3-8B 7-task mean is the same order as the ≤0.006 batch-to-batch variation they report, and EFQ still trails FP16 by 0.0030 (0.6773 vs 0.6803) — i.e., it does not fully close the P-quant gap on LMs. The strong VL grounding result (+0.0174, all six splits) is the most convincing quality claim, but its explanation (sharper softmax distributions benefiting from the arithmetic-midpoint scale) is post-hoc.
- **Selection/tuning:** Two LM operating points (MMLU-selected and mean-selected) are picked from a parameter sweep and both reported — transparent, but effectively best-of-two; the VL operating point was screened on ≤16 samples per task with a keep-if-within-1-point-of-MXFP4 filter, a mild selection-bias risk the paper does not discuss.
- **Kernel claims scope:** the 40.33% speedup applies only to the vector stage of the fused P-quant kernel; mmad is identical by construction and no end-to-end model latency/throughput numbers are given, so the reader cannot infer wall-clock gains for actual serving. Single-vendor hardware (Ascend 950PR); no NVIDIA comparison against SageAttention3's kernels.
- **Missing ablations:** the microscaling block size B is called a design parameter but never ablated; the scale-rule constant log(2/9) is not studied; despite kernel tests up to 128K tokens, all LM accuracy benchmarks are short-context classification tasks — no long-context or perplexity evaluation bridges that gap.
- **Video evidence:** VBench on only 14 prompts is small; dynamic degree drops to 0.5000 vs 0.5714 (FP16) and aesthetic quality is below FP16, which the paper frames as "comparable" — arguably generous.
- **Reproducibility:** calibration procedure and all (τ, h) values are specified, but reproducing the headline kernel result requires Ascend 950PR access, and no code is released.

## Strengths

- Attacks a real and increasingly dominant bottleneck: as QK^T and PV go low-bit, probability generation becomes a larger fraction of attention time, and the producer-consumer precision mismatch is cleanly articulated.
- The design is unusually disciplined: only the probability path changes; the FlashAttention online recurrence, value-side representation, and accumulator precision are preserved, making the method drop-in for existing MXFP4 attention kernels.
- Two fitted parameters total, calibrated offline against an output-level (not scalar-exp) objective — a well-motivated choice given numerator/denominator error coupling, and it forecloses test-time adaptation concerns.
- Evaluation breadth is genuinely good: three modalities (language, vision-language, text-to-video), controlled seeds/settings for video, batch-size replication, an explicit 16-code ablation isolating the coding rule, and per-stage microsecond-level kernel timing.
- Honest framing of what "Exp-Free" means (dense elementwise exp removed, row-level rescaling exp retained) and of the LUT variant's role as an ablation rather than the main method.

## Limitations

- End-to-end language gains are marginal (+0.0024 mean over MXFP4) and the FP16 gap is not closed; the headline quality win is concentrated in VL grounding.
- The 40.33% figure is a per-stage (vector) kernel number, not model-level speedup; end-to-end attention or inference latency is not reported.
- Hardware-specific: results are tied to Ascend 950PR's vector unit; generalization to NVIDIA/AMD FP4 paths is claimed but not demonstrated.
- No long-context accuracy benchmarks (only kernel timings go to 128K), no perplexity, no ablation over microscaling block size B, and no study of sensitivity to the calibration set.
- VBench evidence rests on 14 prompts, with reduced dynamic degree and aesthetic quality vs FP16 left largely unexamined.
- No code release mentioned, limiting independent verification.

## Relevance

对关注高效 LLM 推理与低比特量化的研究而言，这篇论文正好落在 FP4/FP8 注意力加速（SageAttention 系列之后）的关键瓶颈上：它把 softmax 概率生成也拉入低比特管线，是构建"全低比特 attention kernel"的直接进展；其块缩放 E2M1 + 仿射编码设计与 Ascend 实测量测数据对做推理系统/量化方向的选型与复现很有参考价值。

## Questions for Further Exploration

- What are the end-to-end model latency and throughput gains (not just vector-stage) when EFQ-Softmax replaces the P-quant path in a serving stack, and how does the answer change with head dimension and context length?
- How does the method behave on genuinely long-context tasks (RULER, long-doc QA, needle-in-a-haystack) — the kernel is benchmarked to 128K but accuracy is only measured on short-context classification?
- How sensitive are (τ, h) to the calibration set, model family, and quantization of the value side; can one fixed operating point serve all layers, or do attention-head entropy differences (the paper's own "sharper softmax" hypothesis for grounding gains) argue for per-layer calibration?
- Does the exponent-only scale + affine rule transfer to NVIDIA FP4 paths (SageAttention3-style kernels) and to other probability-side formats (e.g., INT8 attention or FP6/E3M2 codes)?
- Would ablating the microscaling block size B (e.g., 16 vs 32 vs 64) reveal an accuracy–scale-metadata trade-off that matters at very long sequence lengths, and can the residual-range argument for reusing one (τ, h) be formalized?
