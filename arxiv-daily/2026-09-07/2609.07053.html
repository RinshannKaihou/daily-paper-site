01

方法论 · Methodology

No model is modified. For every prompt, the authors collect the hidden states of all prompt tokens — embedding layer plus every transformer layer — and ask how tree-like their pairwise distance structure is, then chart the answer as an atlas across four axes: parameter scale, layer depth, model family, and input domain.

// Gromov four-point condition on token states a,b,c,d
s₁ = d(a,b)+d(c,d)   s₂ = d(a,c)+d(b,d)   s₃ = d(a,d)+d(b,c)
δ = (s₍₃₎ − s₍₂₎)/2  // δ = 0 ⇔ perfect tree metric
δrel = δ̂ / diam(X)  // normalized to [0,1] · lower = more tree-like
Sample
2,000 random token quadruples per model–layer–prompt set → 818,904 valid sample-layer measurements.
Normalize
δrel divides out hidden-dimension scale and activation norms, so Qwen, Llama, and distilled checkpoints compare directly.
Isolate
Strict prompt-only main atlas: generated tokens excluded, so decoding length and answer correctness cannot confound prompt geometry.
Test
Medians + IQRs (skewed statistic); Wilcoxon signed-rank for paired layers; Kruskal–Wallis + Cliff's Δ for families and domains.
Control
Prompt-length quartile bins; 50-prompt teacher-forced replay (greedy, 512-token budget) under Euclidean, cosine, L2-normalized, and centered-L2 distances.

Reading δrel

Every number on this page is a diameter-normalized hyperbolicity median. The scale below locates this study's ranges — the interesting structure all lives at the final layer, not on the plateau.

middle plateau ≈0.995 ▾ final layers 0.405–0.694
0 · perfect tree 0.5 1 · ceiling
What GH is not A four-point distance test of tree-likeness — the authors themselves stress that lower δrel does not prove a symbolic tree is stored, and frame the work as a diagnostic toolkit plus a reporting-norm proposal.
02

结果 · Results

RQ2 · Depth dominates

Middle layers sit near the ceiling; final layers drop — everywhere

Every model–domain pair behaves the same way: a near-ceiling plateau at δrel≈0.995–0.996 (domain-independent), then a final-layer drop of −0.29 to −0.56. The embedding layer shows the drop is learned, not inherited — TruthfulQA enters at 0.310 and rises to 0.604, while all four domains still end far below the plateau.

RQ1 · Scale is weak, non-monotonic

Growing 1.5B → 7B barely moves the needle

Pooled over domains, scale shifts δrel by only −0.029 (base track) and +0.035 (math track; Cliff's Δ = +0.08) — and the sign flips by domain: the 7B base model is less tree-like on MATH500 (0.526→0.549) and HumanEval (0.655→0.676), yet more tree-like on TruthfulQA (0.655→0.604). Scale is not a reliable lever on geometry.

Reporting norm proposed: final-layer summaries should always be paired with a depth profile, and comparisons matched by family, scale, and domain — otherwise domain effects masquerade as specialization, and specialization as scale.

03a

Strengths · 优势

  • First-mover atlas — one internally consistent protocol across scale × depth × family × domain, with four cleanly separated research questions.
  • Measurement hygiene — diameter normalization, 2,000 quadruples per set, medians + IQRs, nonparametric tests, Cliff's Δ: resists overinterpreting a skewed statistic.
  • Prompt-only design elegantly removes decoding and correctness confounds; teacher-forced replay extends findings to actual generation.
  • Crisp, memorable interaction — HumanEval becomes tree-like only in the model whose training makes code central (0.676 → 0.438).
  • Honest framing — explicit that GH does not prove symbolic structure; proposes immediately adoptable reporting norms.
  • Multiple robustness checks — length quartiles, three alternative distances, 50/50 per-prompt contrast rates.
03b

Limitations · 局限

  • Descriptive, not causal — δrel is never linked to accuracy, hallucination, or any behavioral outcome; no downstream payoff demonstrated.
  • Metric saturation — the middle-layer plateau sits at the near-maximum (IQR [0.995, 0.996]), making middle-layer comparisons nearly uninformative.
  • Raw-Euclidean main atlas — cosine/centered checks appear only in the narrow 50-prompt control, not across the full 818,904 measurements (rogue dimensions dominate Euclidean distance).
  • Generated-token geometry covered for only two models on one dataset; the other eight checkpoints are prompt-only.
  • "Family" confounds architecture, tokenizer, pretraining data, and post-training in a single factor.
  • Smallest dataset anchors the flagship result — HumanEval has 164 prompts with visibly wider per-cell IQRs.
  • Coverage — dense Qwen/Llama decoders at 1.5B and 7/8B only: no MoE, no ≥32B, no non-Transformers, English-only benchmarks; no code release mentioned.
04

待探索 · Questions for Further Exploration

  • Does final-layer δrel predict anything behavioral — MATH500/HumanEval accuracy, TruthfulQA hallucination rates, adversarial robustness — or is it purely descriptive geometry?
  • Why does math specialization raise δrel on MATH500 (0.600 vs 0.549) while coder specialization sharply lowers it on HumanEval — training-data structure (nested code syntax vs chain-of-states math) or post-training recipe?
  • Is the δrel≈1 plateau an anisotropy / rogue-dimension artifact — and does it persist under centered or cosine metrics across the full atlas, not just the 50-prompt control?
  • Does the final-layer tree-ward drop align with functional layer boundaries (induction heads, prediction-refinement circuits), and does it shift under hyperbolic fine-tuning?
  • Do "depth dominates, scale is weak" regularities generalize to MoE, ≥32B, non-Transformer architectures and multilingual / longer-context prompts?
  • Can GH guide practical interventions — selecting layers to prune or quantize, placing steering vectors, detecting domain specialization in unlabeled checkpoints?
