Key finding

Adjacent transformer layers systematically partially undo each other's writes to the residual stream — a learned “propose-and-reject” dynamic, not additive enrichment.

后一层会系统性地部分撤销前一层写入残差流的内容：这一“层间即时纠正机制”（TLCM）在预训练中习得、在上下文依赖强的 token 上激活最频繁，并在 5 / 7 个主流开源模型家族中普遍存在。

“LLM Layers Immediately Correct Each Other” ↗

Key metric

−0.2

mean cosine similarity between adjacent layers' contributions to the residual stream (Llama 3.1 8B, ~100k WikiText tokens); non-adjacent pairs sit orthogonal-to-positive.

  • −0.4deepest observed pair
  • 6σvs. Gaussian null, d = 4096
  • 5 / 7model families show it

Why this matters

TLCM breaks the assumption that residual-stream features persist across layers — a first-order constraint on SAE design, feature steering, and cross-layer transcoders.

“残差流特征是否持久”是特征可解释性的根基假设——TLCM 对此直接构成一阶修正。

Critical edge

The organizing propose-and-reject story is explicitly untested: no experiment identifies what is semantically corrected, and no link to loss or capability is established.

authors' own caveat

01Methodology

Observation → nulls → training dynamics → causal intervention → spectral localization (primarily Llama 3.1 8B, breadth across 7 families).

  1. Similarity census. Cos-sim between every layer's marginal contribution ci = Attni + MLPi, averaged over ~100k WikiText tokens; negative super-diagonal bands define TLCM (threshold cos ≤ −0.1, set in the valley of a bimodal histogram, calibrated vs. Gaussian + empirical nulls).
  2. Training dynamics. Same matrix recomputed at 7 checkpoints each of OLMo 7B / OLMo 2 1B / 7B on fixed text.
  3. Token census. 79k generated tokens; per-token activation counts compared by Welch's t-test; activations vs. context position over 2,000 long documents.
  4. Sublayer split. Attention contributions correlate positively; MLPs execute the correction, anti-correlating with the preceding MLP and attention.
  5. Causal α-scaling. Inject α·at into layer i+1's input — correction grows ~linearly with α, flipping to compensation at α = −1.
  6. Spectral localization. Eigendecompose the symmetrized layer Jacobian J̄ = (J+Jᵀ)/2 and project at onto eigenvectors (linearization validated: ~5% error for |α| < 0.1).

03Strengths

  • Seven model families under one uniform protocol, extended by a HuggingFace sweep (App. E); robust across LayerNorm variants (Gemma 2 post-LN, OLMo 2 post-LN + QK-norm).
  • Escalating evidence — observation → calibrated nulls → checkpoint dynamics → causal α-intervention → spectral localization; architectural, transient, post-training, and uniform-attenuation explanations eliminated in turn.
  • Honest epistemics: conjectures labeled as such (P&R untested; dropout explanation speculative; α = −1 effect possibly generic self-repair).
  • Direct practical payoff for SAE specificity, steering amplification, and cross-layer-transcoder design — each mapped to concrete follow-up work.
  • Fully open: public code, open-weight models, open OLMo checkpoints; cheap hook-based instrumentation on 0.5B–8B models.

04Limitations

  • Central propose-and-reject interpretation unvalidated; the semantic identity of corrected features is never established.
  • No functional/causal link to model performance — the decisive suppress-TLCM training experiment is proposed but not run.
  • The −0.1 activation threshold is dataset- and model-calibrated rather than principled; borderline pairs near the valley are excluded by fiat.
  • Jacobian conclusions hold only in the local linear regime (|α| < 0.1); symmetrization discards the antisymmetric (rotational) dynamics.
  • Evidence base is WikiText + one 79k-token Llama corpus; MoE, SSM/Mamba, NoPE, and gated-attention architectures untested.

05Questions for further exploration

  1. What is the semantic content of the λ ≈ −1 subspace — can feature labeling turn the P&R story into a tested mechanism?
  2. Does suppressing or regularizing TLCM during training change loss or downstream capabilities?
  3. Does TLCM exist in MoE layers, SSM/Mamba hybrids, gated attention, or NoPE models?
  4. Can steering vectors chosen along non-corrected Jacobian directions achieve control at low amplification?
  5. Do cross-layer transcoders explicitly encode proposal-plus-correction feature pairs?
