Why this matters

Sample the intervention, simulate the evidence, keep the hidden cause as the oracle — a general recipe that turns fuzzy diagnostic tasks into scalable RL without human labels or LLM judges.

直接命中「可验证奖励扩展到数学与代码之外」与「工具调用型 agent 训练」两个方向，对设计自家训练环境与奖励函数有直接参考价值。

Critical edge

Every result lives inside the authors’ own simulator — reward and test metric share one oracle, with no real-world or second-simulator check. And RL trades calibration for attribution: no-signal accuracy falls 0.76 → 0.49 (Opus 5: 0.87).

Methodology — simulator · oracle · RL

The trick: sample the root cause before generating the data — the same act that creates the problem also provides its ground-truth answer.

  1. Sample an intervention

    One of 12 root-cause types across four signal levels (campaign-wide, segment-mix, segment-specific, no-signal), a 1–2 attribute driver slice, signal strength, and onset profile (immediate / delayed / ramping).

  2. Simulate the evidence

    Daily ad metrics from Poisson and Dirichlet-Multinomial generative processes land in a multi-table DuckDB database, with seasonal and bidding confounders — the noisy world the agent must investigate via Python/SQL.

  3. Verify solvability

    An oracle reading only agent-visible tables requires SNR ≥ 1, dominance over confounders, and distinguishability from every rival cause. Rejected episodes never enter training or test.

  4. Train with GRPO

    Stateful tool use (30-turn cap), answer = what + where + when. DAPO-style stabilization, 32 prompts × 8 trajectories, 300 steps (~2 epochs). Warm start: 1,200 SFT traces from rejection-sampled Opus 4.8 teacher trajectories.

Adding the binary full-attribution term lifts 1D slices 0.67→0.92 and 2D slices 0.00→0.27 — dense partial credit alone never induces complete attribution.

  • Efficiency: 11.73 vs 22.05 tool calls for the prompted base — gains come from a better investigation-and-stopping policy, not more exploration.
  • Parser robustness: under a strict exact-schema parser Opus 5 drops 0.686→0.665 while SFT→RL stays 0.757 — ranking survives parsing policy.
  • Statistics caveat: 235 Bernoulli trials, no CIs — the 7.1-pt margin over Opus 5 is ~2σ, plausible but unquantified.

Strengths

  • Attacks the real bottleneck of extending RLVR past math and code — objective rewards without papering over the gap with an LLM judge.
  • Publishes its own negative results: graded-only reward collapses 2D attribution to 0.00; KL regularization hurts; no-signal accuracy regresses.
  • Current frontier baselines at xhigh effort, plus a same-family 35B-vs-122B comparison that cleanly isolates training signal from scale.
  • The tool-call efficiency analysis preempts the “RL just explores more” explanation and supports the learned-procedure reading.

Limitations

  • Single synthetic domain, no real-world or second-simulator validation — task distribution, confounders, reward, and metric all come from one simulator.
  • 235-episode test set with no error bars; several subgroup cells hold only ~20 episodes, straining the two-decimal accuracies.
  • The trained agent over-diagnoses: no-signal accuracy 0.49 (Opus 5: 0.87) and 2D slices 0.27 (Opus 5: 0.33) — serious wherever abstention matters.
  • Depends on a closed teacher (Opus 4.8) with hint-assisted rejection sampling; no artifact release; thin ablations (one KL coefficient, one reward weighting).

Questions for further exploration

  1. Does the recipe transfer to a second domain — incident diagnosis, data-quality monitoring — without re-tuning reward weights, and does the investigation procedure transfer zero-shot across simulators?
  2. Can the no-signal regression (0.76→0.49) be repaired with abstention bonuses or symmetric false-attribution penalties without sacrificing the 2D-slice gains?
  3. Does the 35B→122B prompted gap persist for a post-trained 122B — where is the compute-matched SFT-only vs RL frontier?
  4. Would scaffolded baselines (few-shot worked trajectories, self-consistency reranking) close the +7.1-pt margin — how much is scaffold rather than policy?
  5. How sensitive are headline numbers to the oracle verifier thresholds (SNR ≥ 1, confounder elimination) — and can those checks invert into a curriculum targeting 2D attribution?
