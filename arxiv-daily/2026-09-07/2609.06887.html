Methodology — the shared-instrument loop

distilled · full detail in source §Methodology

SPARC couples Claude Opus 4.1 (in Claude Code, shell + file tools, no direct vendor-API access) with a human operator on one instrument computer. Memory lives in two files:

FINDINGS.md — graded conclusions: claim, evidence, uncertainty, validity conditions, supersession links.
PITFALLS.md — learned failure modes, later compiled into executable preflight checks that can veto an invalid write.

Each iteration runs a seven-step loop; the two campaigns differ only in who owns the two review steps:

1review memory→ 2hypothesis + prediction→ 3plan→ 4preflight vs PITFALLS→ 5write + read→ 6compare vs untreated frame→ 7update memory

Campaign 1 (operator-gated): 11 days, 723 turns, 813 min instrument time — the agent reframed the task from "eraser" to "directional selector" after reading the instrument's write-code. Campaign 2 (agent-gated via AESPM): 3 days, 9 cycles, 8 self-halts.

Physical system
150 nm PbZr0.2Ti0.8O3 on (111) SrTiO3; six <001> variants project onto three in-plane director axes 60° apart, read by lateral PFM (8 µm frames).
State representation — invented by the agent
population vector w = (w₁, w₂, w₃) from the angular power spectrum (2D FFT, ±15° bins around the fitted triad); writes treated as empirical maps w′ = Fa(w), mechanism-agnostic.
Estimator validation
Fourier estimator ~2.5× more repeatable than structure tensor on repeated real frames; all numbers are contrasts against a measured null, not absolute labels.

the discovered primitive: oriented square lattice of ±10 V, 1 s stationary pulses, polarity alternating between rows, row spacing = half the lamellar period

Strengths

what it gets right
  • Targets the pre-optimization regime most autonomous-experiment work sidesteps — the agent invents state descriptors, action primitives, even what counts as a null.
  • Two-file memory design (graded FINDINGS.md with supersession; PITFALLS.md compiled into executable checks) is simple, concrete, and immediately reusable on other instruments.
  • Genuine self-falsification: rejected two of its own hypotheses and revised a third under virgin-film evidence — memory updates instead of accreting.
  • Exceptional SPM hygiene: per-run no-treatment floors, retention and site-count controls, estimator transfer tests.
  • Radical transparency — publishes its own failure census rather than only successes.
  • Full release: transcript, raw PFM frames, trajectories, notebook, and scripts deposited on GitHub.

Limitations

read it with these in mind
  • Principal rewrite shown in a single region; statistics from ~8 valid trials on few areas; no cross-sample or cross-probe replication.
  • Retention tracked ≤ ~34–60 min; long-term stability untested.
  • Final states are often two-family mixtures — selection is probabilistic (7/8), not deterministic.
  • Single cantilever orientation: the two signs of each director are indistinguishable; full-vector PFM needed.
  • UTK's out-of-plane response changed during preparation — complete polarization vector unknown; ~3 µm resolution is analysis-window-limited.
  • No microscopic switching mechanism established (deferred to a companion study).
  • No comparison against alternative agents or a BO baseline on the same task.
  • Agent-authored control software was the weakest link: 6/8 launch failures; the master check function was bypassed.

Questions for further exploration

open threads
  1. How much of SPARC is Claude Opus 4.1 specifically vs the memory/check architecture? Ablations across models and harnesses would separate framework from model effects.
  2. Can preflight-check compilation be automated — mining new PITFALLS entries into static analyzers or runtime assertions without human engineering?
  3. Would active model discrimination between nucleation, wall-motion, and ferroelastic mechanisms converge faster than blind BO once the problem is well posed?
  4. Does the polarity-alternation rule transfer to other (111) films (BFO, other PZT compositions) or tip–sample systems where trailing fields dominate?
  5. What is the minimal instrument-grounding stack (read-back, positive controls, provenance) for safe fully unattended microscope operation?
  6. Could graded FINDINGS.md become a standard interchange format, so successor agents inherit a campaign's state losslessly after context loss?
