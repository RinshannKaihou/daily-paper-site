Overall, ties excluded — 8 blind raters (4 human + 4 LLM judges), 3 datasets, vs. claims distilled from papers that used the same data. Humans alone: 86.1% on WVS.

Why this matters

A working blueprint for reliable self-driving research: persistent memory steers exploration, deterministic statistics banish hallucinated code — all on one consumer GPU.

Critical edge

Headline win rates rest on human raters who barely agreed (Fleiss κ = 0.098); AutoKD’s own scores picked its best insights — the published findings never got to choose.

01 Methodology how the loop works
  1. Six-agent loop. Orchestrator → Generator → Critic → Coder/Runner → Evaluator → Historian. Exploration mode (local / global / refine / conflict) is re-weighted each round from graph state; the Generator batches 10 hypotheses via TF-IDF RAG over variable metadata; the Critic filters duplicates and scores novelty as structural + semantic distance + “epistemic surprise”.
  2. Hallucination-free by construction. Every hypothesis must compile into one of four deterministic DSL templates — assoc / diff / interact / heterogeneity — executed as fixed statistical pipelines (OLS/WLS, Welch t, Mann-Whitney U, Type-II ANOVA, Cohen’s d, logit). No LLM-authored code is ever run; each finding carries a p-value, effect size, and CI.
  3. Persistent insight graph. Nodes store validity + novelty + effect size + direction; typed edges EXTENDS / DEEPENS / NARROWS / CONTRADICTS organize them. The graph grows monotonically (≤496 rounds) and steers the next round toward under-covered variables.
  4. Rig: Qwen 2.5-14B (Q4_K_M) · 1× RTX 4090 24GB · WVS Wave 7 / Amazon Books / SciSciNet

03 Strengths
  • Genuinely distinct framing: cumulative validated findings where the memory itself steers exploration — the right abstraction for long-running autonomous research.
  • Deterministic compilation is honest engineering: p-value, effect size, and CI on every finding; unrunnable hallucinated code is impossible by construction.
  • Ablations quantify mechanisms rather than hand-waving — persistence is cleanly validated as the dominant driver of discovery depth.
  • Reusable evaluation protocol: gold-claim distillation, Hungarian matching, blinded A/B with frozen randomization.
  • Radical reproducibility: open-weight 14B backbone, one 24GB GPU, full prompts and all 30 comparison pairs in the appendix.
04 Limitations
  • Expressiveness capped at four templates — no causal inference, time-series, or unstructured data; “covers the bulk of testable findings” is asserted, never measured.
  • Three flat-table datasets only — “scientific discovery” here really means tabular empirical discovery.
  • Fragile statistics: κ = 0.098 human agreement, 10 pairs per dataset, no significance tests — plus a structural A/B asymmetry favoring AutoKD’s self-selected top-10.
  • No external baseline (only self-ablations) and a single 14B backbone — the graph machinery vs. “any loop run long enough” remains unresolved.
  • Novelty is self-referential and the graph is monotonic: a near-paraphrase of a known result slipped through, errors compound, and contradicted insights can never be retired.
05 Questions for further exploration
  1. Would the win rates survive an agreement-screened rater panel with reported confidence intervals — or an LLM-judge-only protocol with human calibration?
  2. Can the DSL admit causal designs (DiD, IV, panel FE) without losing determinism — and what fraction of rejected hypotheses were inexpressible under the four families?
  3. Head-to-head vs. Kosmos- or AI-Co-Scientist-style systems — and vs. a plain random-hypothesis sampler — at equal compute and round budget?
  4. Do typed relations measurably improve downstream query answering (RQ2) over a flat validated-findings store, given the w/o-graph ablation costs only −10.3%?
  5. Beyond 500 rounds, can split-sample penalties keep spurious associations from compounding — and can contradicted insights ever be retired rather than accumulating?
