arXiv:2609.01360 / Multi-agent systems · error attribution / 2026-09-01

Agent failures are error cascades, not isolated bugs: a counterfactually validated dependency graph guides an LLM judge to sharply better attribution.

“EDGE: Error Dependency Graph-Guided Multi-Error Attribution in Multi-Agent LLM Systems”

Jun Hou, Priya Pitre, Yi Fang, Xuan Wang (Virginia Tech) · Sep 1, 2026 LLM agents causal discovery counterfactual validation LLM-as-judge

Key metric

+20.6 F1

GPT-oss-20B on TRAIL-SWE-Bench (9.31 → 29.89), the largest single-cell gain over the no-graph judge; gains replicate across 11 backbones.

Why this matters

Diagnostic infrastructure for self-repairing agents: failures become modelable propagation structures, and validated edges say which upstream error to fix first.

Critical edge

“Causality” rests on LLM repair plus LLM judges with no human audit — and every MAST accuracy cell sits below the trivial 69.5% always-no classifier.

01 Methodology

  • AProblem reframe. Per failed trace, predict the full set of category–location pairs; one static graph per taxonomy is built from corpus-level annotations only (no trace-specific labels or answers inside the graph).
  • BObservational graph GS. Suppes screening uses within-trace temporal priority (PreC) and probability raising (ΔPR), weighted √(PreC·ΔPR); CAPRI-style AIC hill-climbing prunes to a causal-candidate DAG — TRAIL 27→13 edges, MAST 43→23.
  • CIntervention validation GV. An LLM repair module patches the upstream span, all tool outputs frozen, and the trace is re-rolled; resolver + verifier judges keep edges with a positive controlled direct effect Δ(A→B) — 12 edges for TRAIL, 11 for MAST.
  • DTwo-stage judge. Stage 1 predicts with full inference-graph context (GV ∪ high-weight observational edges); Stage 2 verifies only downstream hypotheses reachable from detected sources above weight threshold τC1.
  • EEvaluation: span-level TRAIL (148 traces, 19 categories) + trace-level MAST (393 traces, 13 categories), 11 backbones; ablations include edge-count-matched random control, static +CG, causal-only, and an 80/20 held-out graph rebuild.

Weighted-F1 vs. the same detector without the graph. TRAIL-GAIA localization for Gemini-2.5-Pro: 35.68 → 50.13.

  • Structure, not context, drives gains. The edge-count-matched random control loses on 4 of 5 open-weight backbones; prepending the same graph in one static call (+CG) loses to the two-stage design on 14 of 15 backbone cells (and swings −10.8 to +6.8 vs. baseline).
  • Not corpus-fitting: with the graph rebuilt from a stratified 80% training split only, all four held-out cells still improve (TRAIL Mistral 24.74 → 33.14).
  • Gains concentrate where the graph says: Planning & Coordination instances jump sharply (GPT-oss-120B 9.0% → 46.6%; Gemini-2.5-Pro 26.5% → 50.8%); System Execution errors barely move.
  • But localization regresses on long context: exact span accuracy drops on 7 of 8 TRAIL-SWE-Bench backbones (−0.33 to −3.74), and joint location+category accuracy stays ≤16 even for Gemini-2.5-Pro.
  • MAST trades accuracy for recall: F1 rises +0.42 to +15.61 on open-weight backbones while accuracy drops on 7 of 8 — every accuracy cell sits below the 69.5% always-no classifier.

03 Strengths

  • The two-stage trace-conditioned graph consumption is convincingly isolated by the +CG ablation — the paper identifies its own operational lever, not just added context.
  • Counterfactual rollout with frozen tool outputs is a clean identification strategy for reasoning-path propagation; the patch library (forbidden actions, postchecks) is a reusable artifact.
  • Held-out 80/20 rebuild and random-edge controls address memorization and edge-count confounds head-on.
  • Taxonomy-agnostic across two genuinely different benchmarks (span-level TRAIL vs. trace-level MAST) plus a prompting-strategy transfer study.
  • Validated edges double as an explanatory artifact for repair prioritization; code and patch libraries released, limitations unusually candid.

04 Limitations

  • Taxonomy-level static graph: cannot capture trace-unique failure chains, and guidance is applied uniformly with no confidence or complexity gating.
  • Localization gains are small or negative on long-context SWE-Bench; joint accuracy remains very low for open-weight models (0.73–4.89 on TRAIL-GAIA).
  • The causal chain is LLM-mediated end-to-end (repair module + two judges) with no human audit; tool re-execution is out of scope.
  • Low per-category support (TRAIL: 148 traces) limits edge-validation power; TRAIL skips bootstrap/shuffle controls for exactly this reason.
  • All numbers are single-run point estimates; no bit-exact reproduction is guaranteed due to LLM nondeterminism.

05 Questions for further exploration

  1. How sensitive is Δ(A→B) to the quality of the LLM repair module — could an adversarially bad repair fabricate spurious “causal” edges?
  2. Can the static taxonomy-level graph be dynamically reweighted or pruned per trace, especially where SWE-Bench localization regresses?
  3. Would re-executing downstream tool calls with patched inputs yield a different — and more realistic — propagation graph than freezing tool outputs?
  4. When every accuracy cell sits below the always-no classifier, is trace-level multi-label attribution the right formulation — or should the task be top-k ranked?
  5. Does repairing high-Δ upstream errors actually improve end-task success when agents re-run, compared to repairing errors sampled at random?
