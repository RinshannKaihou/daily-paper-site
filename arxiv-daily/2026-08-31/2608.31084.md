> **一句话总结：** 这篇论文证明 J-Lens 与冻结模型本身已携带多 token 概念所需的全部信息：多 token 概念的首 token 在 J-Lens 榜单上的可读性与单 token 概念相当（54.6% vs 56.9% 的 Top-10 率），据此提出免训练的 PROPOSE+SCORE 流程（J-Lens 提名首 token → 冻结模型补全候选概念 → 从固定 Carrier 提示的后续隐状态回收概念向量），在 496 个多跳完形填空提示上将平均 Rank@10 从 Template Lens 的 27.6% 提到 43.1%，因果概念交换的 succ@10 从 26.2% 提到 61.4%。

> **TL;DR:** J-Lens reads hidden states as ranked lists of vocabulary tokens, so multi-token concepts ("black hole") get no vector of their own; Template Lens and Oracle Lens fix this with precomputed phrase vocabularies or fine-tuned components. This paper shows both missing pieces are already recoverable for free: the first token of a multi-token concept is nearly as readable as a single-token one (54.6% vs 56.9% top-10 rates across Gemma-3-12B-IT, Llama-3.1-8B, Qwen3-14B), and given the correct first token plus the source prompt, the frozen model completes the second token in 88.3% of two-token cases. A training-free PROPOSE (candidate first tokens from J-Lens rank bands) + SCORE (concept vector pooled from subsequent hidden states in a fixed carrier prompt, Jacobian-transported to the source layer) pipeline reaches 43.1% average Rank@10 on 496 multi-hop cloze prompts vs 27.6% for Template Lens (21.6% without the J-Lens clue), and the recovered vectors drive causal concept swaps at 61.4% average succ@10 vs Template Lens's 26.2% — at 0.4–0.8 s per prompt on one A800.

## 核心贡献

- **诊断（首 token 线索）**：多 token 概念的首 token 在 J-Lens Top-10 中的出现率（54.6%）与单 token 概念（56.9%）基本持平；给出正确首 token 和源提示后，冻结模型在 88.3% 的两 token 案例中能补全第二个 token——即 J-Lens 通常保留了指向完整概念的有用线索。
- **向量可回收性**：将 500 个单 token 词拆成两段碎片（如 airport→air+port），仅用碎片形式从"记住该概念"提示的后续隐状态中回收向量，能以 ≥97.4% 的 Top-1 余弦准确率匹配原生 J-Lens token 向量（三模型 97.4%/98.8%/99.2%），而首碎片向量与碎片均值向量最高只有 59.6%——完整概念向量可以从单次前向的后续隐状态中恢复。
- **免训练方法（PROPOSE + SCORE）**：PROPOSE 把 J-Lens 榜单前 100 名切成 1–20/21–50/51–100 三个排名段、各分配独立搜索预算来提名首 token，冻结模型以 Scaffold 提示补全候选概念；SCORE 在固定 Carrier 提示（"Remember the following concept in your mind..."）中回收每个候选的概念向量，经雅可比匹配跨层搬运后与全词表统一白化打分。整个过程零训练、零微调，直接复用官方发布的 J-Lens 拟合。
- **验证**：端到端读出（平均 Rank@10 43.1% vs Template Lens 27.6%，去掉 J-Lens 线索降至 21.6%）、向量质量（≥97.4% GT 匹配）、因果概念交换（平均 succ@10 61.4% vs Template Lens 26.2%，仅删除 ≤7.9%、随机向量 ≤6.3%）三重验证，覆盖 496 个中间概念从未在源文本中出现的多跳提示。

## Key Contributions

- **Diagnosis.** The first token of a multi-token concept is about as readable as a single-token concept in the J-Lens ranked list (54.6% vs 56.9% top-10 rates averaged over three models), and with the correct first token plus the source prompt, the frozen model recovers the second token in 88.3% of two-token cases — J-lens often preserves a usable clue to the complete concept.
- **Method.** A simple, open-vocabulary, training-free pipeline: PROPOSE selects candidate first tokens from disjoint J-Lens rank bands (1–20, 21–50, 51–100 with independent budgets) and lets the frozen model complete each candidate via a fixed Scaffold Prompt; SCORE recovers a concept vector from subsequent hidden states under a fixed Carrier Prompt, transports it across layers by matching J-Lens Jacobian images, and scores every candidate (concepts + full vocabulary) under one whitened-cosine rule using only released J-Lens fits — nothing is fine-tuned.
- **Validation.** The recovered vectors (a) match independently defined ground-truth J-Lens token vectors with ≥97.4% Top-1 accuracy on a 500-word fragmentation diagnostic, (b) read intermediate concepts that never appear in the source text (43.1% avg Rank@10 vs 27.6% Template Lens on 496 prompts), and (c) support causal swaps that replace one intermediate concept with another (61.4% vs 26.2% avg succ@10), with the full pipeline costing 0.4–0.8 s per prompt on one A800.

## Methodology

**Setup and diagnostics.** J-Lens reads a hidden state h_l through an averaged Jacobian J_l = E[∂h_final/∂h_l] and the unembedding: lens(h_l) = softmax(W_U norm(J_l h_l)), giving one token vector d_l(w) = W_U J_l e_w per vocabulary entry and no row for a multi-token concept C = (w_1,…,w_n). Two diagnostics quantify what is already available: (1) *First Token Top-10* — how often the first token of a multi-token concept reaches the J-Lens top-10, compared to a *Single Token Top-10* reference; (2) *Second Token Recovery* — with the correct first token placed in the source prompt and generation otherwise unconstrained, how often the frozen model produces the correct continuation. For vector recovery, 500 words that are single tokens in all three tokenizers are forced into two-token fragments (airport → air+port); a vector recovered using only the fragmented form in a fixed "Remember the following concept in your mind" prompt is ranked by cosine against all 500 native J-Lens token vectors as ground truth, against first-fragment, fragment-mean, and random baselines.

**PROPOSE (candidate generation).** The first 100 entries of the J-Lens ranked list at the source layer are split into disjoint rank ranges B_m = {w : a_m ≤ r(w) < b_m} (ranks 1–20, 21–50, 51–100), each receiving an independent search budget so low-ranked first tokens stay represented. Each selected first token is fixed as the `<seed>` in a fixed Scaffold Prompt ("when model is answering the cloze below: `<cloze>`. it will think a concept: `<seed>`"); the frozen model generates the completion with its normal next-token distribution (nucleus 0.85, at most 4 new tokens, special/formatting tokens discarded). Candidates from all ranges are merged, deduplicated, strict prefixes removed, and the 25 top proposer-scored candidates retained. Proposal probability does not affect final scoring — every retained candidate is scored under the same rule.

**SCORE (vector recovery and scoring).** Each candidate C is inserted into a fixed Carrier Prompt ("Remember the following concept in your mind. Concept:`<C>`. Fact: The capital of France is Paris.") that contains neither the source cloze nor the Scaffold Prompt. Hidden states are extracted over a window T after the concept is fully processed at a carrier layer ℓ_c (43 for Gemma-3-12B-IT, 27 for Llama-3.1-8B, 37 for Qwen3-14B, chosen once by paired cosine on an independent 633-concept calibration corpus): v_C = Σ_t α_t (h_t − μ_t) with position-specific means μ_t removing the shared component and nonnegative pooling weights α_t fitted by cosine agreement with J-Lens token vectors on the calibration corpus. The vector is transported to the source layer ℓ_s by ridge-regularized Jacobian matching v̂ = argmin ‖J_{ℓ_s} v − J_{ℓ_c} v_C‖² + λ‖v̂‖² (λ = 10⁻²). Scoring centers the source state and applies diagonal whitening A = diag(σ²+ε)^(−1/2); G_C = ⟨A v̂_C, A ĥ_{ℓ_s}⟩. Vocabulary tokens are scored identically with their own J-Lens token vectors, so all candidates compete under one common rule.

**Causal concept swap.** To test whether vectors capture internal computation, the source concept vector is deleted and a partner vector installed over a short residual band: h_l ← h_l − ⟨h_l, v̂_C⟩ v̂_C + β(l) v̂_D, where β(l) = |⟨h_l(P_D), v̂_D⟩| is read off the partner's own prompt (no fitted strength coefficient). succ@k is the fraction of trials where the partner answer enters the model's top-k continuations. Trials are pre-filtered on the unmodified model (concept not in its own answer, partner answer outside top-10, model answers correctly), leaving 316/304/317 trials for Gemma/Llama/Qwen from 496 directed pairs.

**Data.** 248 counterfactual pairs → 496 cloze prompts from one template ("Fact: The `<relation>` of the `<description>` is"), written by GPT-5.5 under constraints: the intermediate must be a canonical multi-token English word/phrase spanning several tokens under all three tokenizers, produced greedily in-context, and never equal to the answer; each pair shares the relation and swaps the intermediate concept. The released J-Lens fits are used without refitting (47/31/59 layers).

## Results & Highlights

- **End-to-end readout (496 prompts, target never appears in source text):** average Rank@10 is 43.1% for the full method vs 27.6% for Template Lens (+15.5 pts) across Gemma-3-12B-IT, Llama-3.1-8B, and Qwen3-14B. Per-model Rank@10: Gemma 52.8% vs 29.0% (+23.8), Llama 44.2% vs 29.4% (+14.8), Qwen 32.3% vs 24.4% (+7.9). Removing the J-Lens clue (OURS w/o J-LENS, same source prompt and SCORE) drops average Rank@10 to 21.6% (Gemma 22.4%, Llama 25.7%, Qwen 16.6%), and random readout is ≤8.5% Rank@10 — the clue, not the scaffold machinery, drives the gain.
- **Vector quality (500-word fragmentation diagnostic):** the vector recovered from fragmented input identifies the matching ground-truth J-Lens token vector with 97.4% (Gemma), 98.8% (Llama), and 99.2% (Qwen) Top-1 cosine accuracy, with mean cosine to the 499 wrong vectors of only 0.003/0.003/−0.002 — whereas the first-fragment token vector tops out at 51.4% and the fragment-mean vector at 59.6% Top-1 (Llama), with cosines-to-wrong of 0.121/0.129.
- **Causal concept swap (316/304/317 trials):** our vectors achieve succ@10 of 64.2% (Gemma), 62.2% (Llama), 57.7% (Qwen) — average 61.4% vs 26.2% for Template Lens vectors under the identical swap operator. Controls confirm specificity: delete-only ≤7.9% succ@10, add-only reaches 36.0–49.7% but is consistently weaker than the full swap, v_first ≤21.4%, and v_random ≤6.3%.
- **First-token diagnostics:** First Token Top-10 averages 54.6% for multi-token concepts vs 56.9% for single-token concepts (i.e., first tokens are not systematically harder to read), and given the correct first token plus the source prompt, the frozen model recovers the second token in 88.3% of two-token cases (79.5–94.3% across models). Candidate recall (target appears among PROPOSE's candidates) is the practical ceiling, at roughly 37–54% depending on model (Figure 2).
- **Cost:** 0.78 s / 0.40 s / 0.71 s per unseen prompt on one A800-SXM4-80GB (bf16) for Gemma/Llama/Qwen — far cheaper than Template Lens's few hundred prefix forwards per phrase entry or Oracle Lens fine-tuning two copies of the subject model.
- **Honest counterpoint in Table 2:** at Rank@1, Template Lens actually wins on two of three models (Llama 27.1% vs 8.1%; Qwen 21.3% vs 10.7%); our method only leads Rank@1 on Gemma (40.1% vs 28.4%). The headline advantage is a top-10 effect.

## Authors & Credibility

The paper has two authors from the College of AI, Tsinghua University: Xijie Gong (first author; the footnote states the work was done during an internship at Tsinghua University, suggesting a student intern) and Tonghan Wang (corresponding author, thw@mail.tsinghua.edu.cn). It is a compact two-author effort built entirely on top of Gurnee et al. (2026)'s J-Lens/Template Lens/Oracle Lens line of work (Transformer Circuits), and the authors demonstrate solid command of that ecosystem: they use the official released J-Lens fits without refitting, reproduce the baselines' scoring conventions (centering + diagonal whitening, following Template Lens), and design careful controls (WITHOUT J-LENS ablation, delete-only/add-only, v_first/v_random). No code release is mentioned in the paper. The scope is deliberately narrow (readout + swap on one synthetic cloze family), which the authors state plainly rather than overclaim.

## Critical Assessment

- **Novelty is real but modest in kind.** The core insight — that a proposer and a vector source already exist inside the frozen model + J-Lens, so the machinery of Template Lens (12,700 precomputed phrase vectors) and Oracle Lens (two fine-tuned model copies) can be skipped — is a well-executed "the pieces are already there" paper rather than a new lens. Its value depends entirely on the J-Lens substrate from Gurnee et al. (2026); every baseline in the paper comes from that single prior work.
- **The strongest baseline is never run.** Oracle Lens, the learned proposer/reconstructor that presumably represents the performance ceiling, is excluded on the grounds that it "has no official public release" and reproducing its multi-stage training "would introduce substantial implementation uncertainty" — a defensible but convenient omission. The empirical claim "recoverable directly from J-Lens and the frozen model" is therefore only benchmarked against the *weaker* of the two prior extensions.
- **The headline metric flatters the method.** The 43.1% vs 27.6% story is an average Rank@10. At Rank@1, Template Lens beats the proposed method on Llama-3.1-8B (27.1% vs 8.1%) and Qwen3-14B (21.3% vs 10.7%) — a 3× gap in the other direction on the most practical metric. The paper reports these numbers transparently in Table 2 but the abstract and discussion never acknowledge that the ranking advantage is top-k-width-dependent, suggesting a candidate-scoring (not proposal) weakness that goes unanalyzed.
- **Small, single-template, LLM-generated dataset.** All 496 prompts come from one cloze frame ("Fact: The `<relation>` of the `<description>` is") with concepts written by GPT-5.5 and three pre-filters (multi-token under all three tokenizers, greedy in-context production, answer ≠ concept). The 226/22 split between criterion pairs and a closed-fact capital/currency set also means a large chunk of the "multi-hop" data is trivia-shaped. Generalization to natural text, longer paraphrases, or non-canonical concepts is untested (the authors admit this).
- **The "ground truth" is the method's own substrate.** The 97.4–99.2% GT-matching result compares fragment-recovered vectors against J-Lens's *own* token vectors for the 500 un-fragmented words — a well-designed internal consistency check, but "matching GT" means "behaves like the whole-word token vector under J-Lens", not "captures the human concept"; it cannot by itself validate vectors for concepts that have no native token vector.
- **Candidate recall caps everything.** PROPOSE's ceiling is set by how often J-Lens ranks a useful first token highly (~54% average per Figure 2), and any unproposed target counts as failure; the paper does not explore what happens for the ~46% of prompts where the concept never enters the candidate set, other than noting the limitation.
- **Reproducibility is good on paper but unverified.** Using released J-Lens fits, a fixed carrier prompt, and fully specified hyperparameters (rank bands 1–20/21–50/51–100, widths 12/6/6, 25 candidates, nucleus 0.85, λ=10⁻², per-model carrier layers 43/27/37, 633-concept calibration corpus) makes the pipeline re-implementable, but no code or data link is given and the calibration-set selection procedure ("633 disjoint concepts") is only sketched.

## Strengths

- Training-free and plug-in: zero fine-tuning, zero phrase vocabulary, works directly on released J-Lens fits across three model families with different tokenizers (Gemma-3-12B-IT, Llama-3.1-8B, Qwen3-14B), at 0.4–0.8 s per prompt on a single A800.
- The WITHOUT J-LENS ablation is exactly the right control: identical source prompt and SCORE with the first-token clue removed isolates the clue's contribution (43.1% → 21.6% average Rank@10), ruling out the trivial explanation that the scaffold prompt alone enables completion.
- The causal swap experiment uses the same swap operator for all vector constructions and includes delete-only, add-only, v_first, and v_random controls (random vectors ≤6.3% succ@10, delete-only ≤7.9%), so the intervention results are attributable to vector content rather than generic perturbation.
- Failure accounting is honest: an unproposed target counts as a failure, Rank@1 is reported even where the method loses, and the limitations section names the first-token-rank dependency and the short-English-phrase scope restriction explicitly.
- The fragmentation diagnostic (500 words, three baselines including random) is a clean, independently motivated validation of vector recovery rather than a self-graded test.

## Limitations

- Dependence on first-token rank: if J-Lens ranks the useful first token poorly, the correct concept never enters the candidate set even when SCORE could identify it — candidate recall (~37–54%) is a hard ceiling the method cannot overcome.
- The source prompt must itself contain enough information for the frozen model to complete the concept from its first token; multi-hop prompts where the intermediate is under-determined will fail at the completion step.
- Scope restricted to canonical multi-token concepts expressible as short English phrases; behavior on long descriptions, arbitrary natural-language expressions, or non-English concepts is unestablished.
- All 496 evaluation prompts share one synthetic cloze template and were authored by GPT-5.5, so template-specific artifacts (e.g., the model exploiting the frame rather than the concept) cannot be ruled out.
- Rank@1 performance is weak on two of three models (8.1% on Llama, 10.7% on Qwen vs Template Lens's 27.1%/21.3%), limiting usefulness where a single top-ranked label is needed.
- Oracle Lens is argued away rather than compared; the method's standing relative to learned proposers/reconstructors remains an open question.

## Relevance

这篇论文属于你的 "LLM Hidden States & Interpretability" 核心兴趣区：它直接研究 J-Lens 隐状态读出中多 token 概念的表征几何问题，用免训练的探针式方法（Jacobian 匹配 + 白化余弦打分 + 概念向量回收）把 token 级读出扩展到短语级概念，并通过因果交换实验验证向量确实承载中间计算——对理解 LLM 内部表示如何在 token/词/概念粒度间组织很有参考价值。

## Questions for Further Exploration

- Can the ~54% candidate-recall ceiling be raised without training — e.g., iterated proposal where SCORE feedback re-queries J-Lens at other layers, or multi-token seeds instead of single first tokens?
- Why does the method lead decisively at Rank@10 but lose Rank@1 to Template Lens on Llama and Qwen — is the whitened-cosine scoring rule mis-ranking correct candidates, and could a learned (or calibration-refit) scoring head close the gap?
- Do the recovered concept vectors align with SAE features or steering vectors for the same concepts, and can the swap operator compose multiple concepts simultaneously?
- The discussion proposes that early layers assemble tokenizer-level pieces into concepts before later layers re-express them in vocabulary — can the first-token clue be traced layer-by-layer to localize where multi-token concepts are formed?
- How does the pipeline behave on concepts embedded in natural documents rather than a single cloze template, and on languages whose tokenizers fragment words differently (e.g., Chinese)?
- Would a hybrid (Oracle Lens's learned proposer + this paper's training-free vector recovery and scoring) outperform both, and at what training cost?
