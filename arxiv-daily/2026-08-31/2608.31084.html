The First Token Is a Clue: Verbalizing Multi-Token Concepts from the J-Lens

Xijie Gong, Tonghan Wang · Tsinghua University Aug 31, 2026
mechanistic interpretability J-Lens multi-token concepts LLM hidden states activation steering
Key metric
43.1%
avg Rank@10, training-free

vs 27.6% for Template Lens on 496 multi-hop cloze prompts where the target concept never appears in the source text; dropping the J-Lens clue falls to 21.6%.

causal swaps 61.4% vs 26.2% succ@10 · 0.4–0.8 s/prompt on one A800
Why this matters

Extends token-level hidden-state readout to phrase-level concepts without training — a probe-style tool for understanding how LLMs organize token, word, and concept granularity.

Critical edge

The headline is an average Rank@10 — at Rank@1, Template Lens wins on two of three models (Llama 27.1% vs 8.1%, Qwen 21.3% vs 10.7%), a 3× gap in the other direction on the most practical metric.

01 Methodology

J-Lens ranks → PROPOSE first tokens → frozen completion → SCORE vectors → whitened cosine

  • Setup. J-Lens reads a hidden state through an averaged Jacobian plus the unembedding, yielding one vector per vocabulary token — there is no row for a multi-token concept like "black hole". Everything reuses the officially released J-Lens fits; nothing is fine-tuned.
  • Diagnostics. First-token top-10 reachability (54.6% for multi-token concepts vs 56.9% single-token); second-token recovery (88.3% given the correct first token); and a 500-word fragmentation test (airport → air+port) checking whether a vector recovered from fragments matches the native whole-word J-Lens vector.
  • PROPOSE. The J-Lens top-100 is split into rank bands (1–20 / 21–50 / 51–100) with independent budgets; each candidate first token seeds a fixed Scaffold Prompt that the frozen model completes (nucleus 0.85, ≤4 tokens). Candidates are merged, deduplicated, and the top 25 retained — proposal probability never affects scoring.
  • SCORE. Each candidate goes into a fixed Carrier Prompt; concept vectors are pooled from subsequent hidden states (position-specific means, nonnegative weights fitted once on a 633-concept calibration corpus), transported across layers by ridge-regularized Jacobian matching (λ=10⁻²), and scored against the centered, diagonally whitened source state — vocabulary tokens compete under the same rule.
  • Causal swap. Delete the source concept vector, install a partner over a short residual band (strength read off the partner's own prompt, no fitted coefficient); succ@k over 316/304/317 pre-filtered trials.

  • The clue, not the scaffold, drives the gain: identical source prompt and SCORE with the first-token clue removed drops average Rank@10 to 21.6%; random readout is ≤8.5%.
  • Vector quality: on the 500-word fragmentation diagnostic, recovered vectors match ground-truth J-Lens token vectors at 97.4% / 98.8% / 99.2% Top-1 (Gemma / Llama / Qwen), vs ≤59.6% for fragment-mean and ≤51.4% for first-fragment baselines.
  • Causal swaps: succ@10 of 64.2% / 62.2% / 57.7% vs 26.2% for Template Lens vectors under the identical swap operator; delete-only ≤7.9%, random vectors ≤6.3%, add-only 36.0–49.7% — the effect is attributable to vector content.
  • Practical ceiling: candidate recall — how often PROPOSE's candidate set contains the target — caps everything at roughly 37–54% depending on model; any unproposed target counts as a failure.
  • Cost: 0.78 / 0.40 / 0.71 s per prompt on one A800 — far cheaper than Template Lens's few hundred prefix forwards per phrase entry or Oracle Lens's two fine-tuned model copies.

03 Strengths

  • +Training-free and plug-in: zero fine-tuning, zero phrase vocabulary, works on released J-Lens fits across three model families with different tokenizers, at 0.4–0.8 s per prompt.
  • +The WITHOUT J-LENS ablation is exactly the right control, isolating the clue's contribution and ruling out the "scaffold prompt alone" explanation.
  • +Causal swaps use one swap operator for all vector types with delete-only, add-only, v_first, and v_random controls — results attributable to vector content, not generic perturbation.
  • +Honest failure accounting: unproposed targets count as failures, losing Rank@1 numbers are printed, and limitations name the recall ceiling and scope restrictions.
  • +The fragmentation diagnostic is a clean, independently motivated validation rather than a self-graded test.

04 Limitations

  • −First-token rank dependence: if J-Lens ranks the useful first token poorly, the concept never enters the candidate set — recall (~37–54%) is a hard ceiling.
  • −Oracle Lens, the strongest baseline and presumed ceiling, is argued away rather than compared ("no official public release") — the method is only benchmarked against the weaker prior extension.
  • −All 496 prompts share one GPT-5.5-authored cloze template, largely trivia-shaped; template-specific artifacts and generalization to natural text or non-English concepts are untested.
  • −The source prompt must contain enough information for completion from the first token; under-determined intermediates fail at the completion step.
  • −"Ground truth" is the method's own substrate: the 97–99% match validates consistency with J-Lens token vectors, not capture of human concepts.
  • −No code or data release; the calibration-set selection ("633 disjoint concepts") is only sketched.

05 Questions for Further Exploration

  1. Can the ~54% candidate-recall ceiling be raised without training — iterated proposal with SCORE feedback re-querying J-Lens at other layers, or multi-token seeds?
  2. Why does the method lead decisively at Rank@10 but lose Rank@1 on Llama and Qwen — is the whitened-cosine scoring rule mis-ranking correct candidates, and could a calibrated scoring head close the gap?
  3. Do the recovered concept vectors align with SAE features or steering vectors for the same concepts, and can the swap operator compose multiple concepts simultaneously?
  4. Can the first-token clue be traced layer-by-layer to localize where early layers assemble tokenizer pieces into concepts before later layers re-express them?
  5. How does the pipeline behave on concepts embedded in natural documents rather than a single cloze template, and on languages whose tokenizers fragment words differently (e.g., Chinese)?
  6. Would a hybrid — Oracle Lens's learned proposer plus this paper's training-free vector recovery and scoring — outperform both, and at what training cost?
