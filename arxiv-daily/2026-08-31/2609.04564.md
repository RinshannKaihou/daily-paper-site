> **一句话总结：** 提出LA AGENTE ÓPTIMA——一个把 LLM 推理与程序化贝叶斯优化（BO）执行彻底解耦的自驾实验室智能体框架（BO 专家子代理撰写可复用的 Python 活动程序 + BO-MCP 将 BO 作为带类型化持久状态的服务暴露），在消融基准 Ackley 6D 上达到 0.770 终质量（最强消融 Main-script 仅 0.557），并在 RoboChem-Flex 流动光化学平台上用 23 次实验（人类指导活动需 50 次、消耗不到一半起始物料）将产率从 30.0% 提升至 58.8%，同时能自主诊断中程测量失败、180° 回退编码错误和零产率光谱异常。

> **TL;DR:** ÓPTIMA is an LLM agent framework for self-driving laboratories that separates agent reasoning from a persistent, programmatic Bayesian-optimization engine (BO-MCP, default backend BayBE/BoTorch). On the architecture-ablation benchmark (Ackley 6D + the 1728-reaction Shields arylation table, 60-evaluation budget, 3 runs, GPT-5.4 specialist), the proposed Specialist-script architecture reaches 0.770 final quality on Ackley 6D vs 0.557 for the strongest ablation (Main-script) and 0.319 for a naive tool-loop. On two real platforms it ran 5-day closed loops: on RoboChem-Flex flow photochemistry it raised yield from a 30.0% best seed to 58.8% in 23 experiments (vs 70.9% for the 50-experiment human-directed campaign, at 13% lower overall cost), and on the RAISE formulation platform it improved a contact-angle target from 71.4° to 67.8° — honestly failing the 65° ± 1° goal but correctly inferring the target was unattainable with available reagents.

## 核心贡献

- **架构解耦：** 将 LLM 智能体推理与 BO 数学执行分离——BO 专用子代理（specialist）撰写 Python 活动程序与操作手册，主智能体 ÓPTIMA 只负责解释目标、监控进展、修复问题并在需要科学判断时直接干预；所有 BO 数学由 BO-MCP 服务完成，LLM 从不亲手做优化。
- **BO-MCP 服务：** 通过 MCP/REST 将 BO 暴露为可替换后端的服务（默认 BayBE，支持 BoTorch 与第三方插件），维护类型化持久活动状态、每次建议的获取函数/不确定性记录、SHAP 或核长度尺度可解释性，使每个决策事后可审计。
- **跨异构平台的统一接入：** 通过 PySCF 执行图（量子化学评估器）、A2A 协议对接 El Agente Estructural（分子结构生成）、MQTT 桥接 RAISE 液体配方平台、经 RobBridge 安全 HTTP 服务对接 RoboChem-Flex 流动化学机器人——无需为每个平台定制代理协议。
- **长时程监督机制：** 活动作为受监控后台任务运行，事件驱动过滤渐进式进程输出为紧凑进展事件，避免轮询日志淹没 LLM 上下文；活动可跨目标修订、约束修正与中断后恢复，且不重复物理实验。
- **三类共 7+ 项实证：** 4 架构 × 2 基准消融、5 个数字发现任务（有机固态激光分子、膦配体、反间隙发光体、Co-双膦催化剂、Xe/Kr MOF）和 2 个物理平台闭环（接触角配方、流动光化学），全部记录成本（单活动 $7–$110）与失败处理案例。

## Key Contributions

- A **reasoning/execution split** for agentic BO: a specialist subagent authors a reusable, smoke-tested Python campaign program plus operating instructions; the coordinating ÓPTIMA agent supervises, revises, and intervenes only when scientific judgment is required; the BO-MCP service owns typed optimizer state so "no BO mathematics are ever performed by an LLM".
- **BO-MCP**, an open-source BO-as-a-service layer (MCP + REST, pluggable BayBE/BoTorch backends, per-campaign provenance, SHAP-based and kernel-length-scale explainability) that makes every suggestion inspectable after the fact.
- Demonstrated **event-driven long-horizon supervision**: campaigns run as monitored background tasks over multi-day horizons (up to 5 d 8 h), unattended overnight, with campaign repair (evaluator patching, constraint correction, objective revision) that preserves all prior observations without repeating physical experiments.
- A **taxonomy of real failure recoveries** across seven showcases: mid-run evaluator misconfiguration, fallback-label corruption (failed measurements encoded as 180°), zero-yield ambiguity resolved by raw 19F spectrum inspection, unconverged geometry computations distinguished from chemistry, and search-space representation identified as the true bottleneck.
- Quantified **resource accounting**: per-campaign LLM token counts, wall-clock, and cost ($7.08–$109.55), plus a head-to-head comparison with a human-directed BO campaign on the same platform and reaction.

## Methodology

**Architecture.** ÓPTIMA extends El Agente Gráfico with a two-agent division of labour. A user states a scientific objective in natural language; the coordinating agent (ÓPTIMA) delegates campaign authoring to a **BO specialist** subagent that writes a Python campaign program and operating instructions into a shared filesystem-backed workspace. The program executes the repetitive BO loop with consistent settings, calling **BO-MCP** (a separate service in the Docker network exposing 22 MCP tools over MCP/REST with a protocol-neutral operations layer: campaign lookup, state transitions, caching, provenance; SQLAlchemy/PostgreSQL/SQLite storage). The default backend is BayBE (chemistry-aware categorical representations: Morgan fingerprints, RDKit descriptors), with BoTorch as an alternative that reports kernel length-scales instead of SHAP importances. Quantum-chemistry evaluations run through the PySCF execution graph (typed nodes, GPU-parallel, structured results never enter the LLM context); molecular structure generation is delegated over an A2A HTTP interface to El Agente Estructural. Physical platforms: RAISE (static contact-angle SDL, ~1 measurement/min, MQTT bridge, serialized request/response channels) and RoboChem-Flex (Cartesian-robot flow chemistry SDL in Amsterdam, controlled via RobBridge, an authenticated stateful HTTP service exposed through Cloudflare, with live capability descriptors that override the operator's nominal parameter ranges).

**Long-horizon operation.** Campaign programs run as monitored background tasks; a monitoring system filters incremental process output and heartbeat events into compact steering messages that reach the LLM only at the next invocation or when the agent is idle. Failed runs are retried or parked for later resumption; all states, alerts, and the complete instrument record are persisted to disk.

**Evaluation design.** Three tiers: (1) an architecture ablation comparing Specialist-script (proposed) against Main-script (main agent authors the program itself), Tool-loop (repeated BO-MCP tool calls, no program), and Local-BO (agent implements BO locally) on Ackley 6D and the Shields arylation benchmark (1728 historical reactions, hidden reaction table), 3 runs each under a 60-evaluation global budget, GPT-5.4 throughout, scored by final quality and MBSF@60 (mean normalized best-so-far); (2) five digital discovery campaigns mirroring published studies (Streith-Kalthoff OSL fragment campaign, Laplaza phosphine Ni-catalysis electronic profile, Pollice inverted-gap chromophore library, Ho Co-bisphosphine hydroformylation, Lim Xe/Kr MOF inverse design); (3) two physical closed loops with full operator transcripts and cost accounting in a 100+ page SI.

## Results & Highlights

- **Architecture ablation (Ackley 6D, 60 attempts, 3 runs, GPT-5.4):** Specialist-script reaches 0.770 final quality / 0.442 MBSF@60 vs 0.557 / 0.265 for the best ablation Main-script, 0.411 / 0.171 for Local-BO, and 0.319 / 0.153 for Tool-loop — a +0.213 final-quality delta over the strongest ablation; the separation grows with horizon (Main-script leads at 10 attempts, Specialist-script leads from attempt 20 through 60).
- **Shields arylation (real chemistry, same budget):** Specialist-script reaches ≥90% yield in 3/3 runs (mean first-90% attempt 25.0) vs 1/3 for Local-BO (26.0); but Main-script posts a slightly *higher* MBSF@60 (0.891 vs 0.865) and the benchmark nearly saturates for all BO-MCP-based architectures — the headline separation is specific to the synthetic Ackley 6D.
- **RoboChem-Flex flow photochemistry (trifluoromethylation, published benchmark):** yield rises from 30.0% (best informed seed) to 58.8% (experiment 21, R0067) over 23 experiments; the multi-objective phase maps the yield/green-score Pareto from 15.2% @ green 100 to 48.5% @ green 82.5, and narrowing to yield alone lifts the best from 48.5% to 58.8% (green score drops 82.5 → 74.4). Versus the 50-experiment human-directed campaign (70.9%; 63.9% at matched consumables), the agent used 46% of experiments and 39% of the starting material, returned only 2 zero-yield runs, and was 13% cheaper overall despite a $109.55 LLM bill that "cost more than the chemistry it directed".
- **RAISE contact-angle campaign (physical, 27 evaluations):** best moves 71.4° (warm start) → 68.1° (clean campaign) → 67.8° (agent-selected one-shot: max feasible ethanol with SDS fixed at best level); the 65° ± 1° target is never reached, and ÓPTIMA infers from this boundary result that 65° is likely unattainable with the two available reagents, recommending a formulation-system change. The campaign cost $15.45 (148 LLM calls, 7.75M input / 97k output tokens, 2 h 38 min).
- **Digital discovery campaigns (Table 1):** phosphine ligands — hypervolume 0.791 → 1.038 and Pareto set 3 → 17 from 48/364 evaluations ($7.08), with the agent recommending its own early stop; Co-bisphosphines — Pareto front 0.572 → 1.000; Xe/Kr MOFs — desirability 0.487 → 0.502 with search space rebuilt mid-campaign from 2800 nominal (420 valid) to 109 constructible candidates; inverted-gap emitters — best gap improves only 0.227 → 0.223 eV, which the agent correctly attributes to a near-optimal random initialization rather than overclaiming.
- **OSL molecular discovery (462,672 possible A–B–C–B–A combos):** the 12 BO-selected candidates add hypervolume 3.76 vs 2.78 from the 4 seeds; frontier-aware expansion grows the space 360 → 2,592 candidates (~0.6% of the total); the 38-observation campaign spans 47 top-level turns / ~3 d 22 h calendar / 16.0 h agent wall-clock at $24.40, including an autonomous diagnosis-and-patch of a Stage-1 evaluator configuration mismatch.
- **Specialist-model comparison (8 models, 48 runs):** GPT-5.4 is the only model passing the full protocol in all six runs (Ackley 0.770/0.442; Shields 100.00/0.865); Claude Opus 5 posts the best Ackley final (0.772), Claude Sonnet 5 the best Shields MBSF@60 (0.907), while DeepSeek V4 Pro trails (Ackley 0.566/0.212; Shields 73.11/0.623); the authors explicitly warn these are behavioral trends, not a leaderboard.

Co-authors include **Timothy Noël** (flow chemistry/RoboChem-Flex, UvA/HIMS), **Frank Gu** (RAISE formulation platform), NVIDIA, the Acceleration Consortium, Merck KGaA (M.M.), and Sungkyunkwan/IMM-CNM partners. Funding spans DARPA, Schmidt Sciences AI2050, ERC, NWO Vici, and CFREF — deep institutional and engineering credibility in self-driving laboratories, and the RoboChem-Flex/RAISE platforms are the authors' own published hardware, giving them rare physical access. The main liability of this insider position — benchmarks and platforms built by the same lab — is largely handled through external published references (Shields, Laplaza, Pollice, Ho, Lim) but remains a structural constraint.

## Critical Assessment

- **The ablation evidence is thinner than the abstract suggests.** Each architecture-benchmark cell is 3 runs with no factorial decomposition; the authors themselves concede the comparisons "should be interpreted as evidence about complete workflows rather than isolated causal estimates for any single architectural component." More importantly, on the only *real* chemistry benchmark (Shields arylation) the proposed architecture does not clearly win: Main-script achieves a higher MBSF@60 (0.891 vs 0.865) and all three BO-MCP-based architectures approach the yield ceiling, so the headline Ackley 6D separation (0.770 vs 0.557) rests substantially on a synthetic multimodal function where "campaign-design choices had greater opportunity to affect the search."
- **Development bias is admitted but unresolved.** GPT-5.4's clean sweep (6/6 protocol passes) is confounded by the fact that the framework's instructions, tool descriptions, and failure modes were developed against GPT-5.4's initial failures; the authors acknowledge this but offer no de-biased rerun, and the per-model trajectory counts are small and unequal (e.g., 2 comparable runs for several models).
- **The human-directed RoboChem-Flex comparison is not budget-matched.** The agent *chose* to stop at 23 experiments vs the human's 50, so "less than half the starting material" and the "13% cost advantage" partly reflect a smaller spend; the agent's best yield (58.8%) is below both the full human result (70.9%) and the consumable-matched 63.9%. The paper reports this honestly, but the emphasis on cost/material efficiency softens the fact that the human found better chemistry.
- **The framework seeded the bug it then heroically fixed.** In the RAISE campaign, the specialist-authored script's fallback encoding of failed measurements as 180° contact angles corrupted the surrogate for 8 subsequent suggestions — a silent label-corruption failure of exactly the kind the architecture is supposed to prevent. Recovery (18 valid observations carried over, no repeated physical experiments) is genuinely impressive, but the root cause of two later measurement failures (a backlight shift breaking contour detection) was only found by the human operator and never surfaced to the agent mid-campaign, and each repair step required explicit operator approval.
- **Physical results are n=1.** Neither physical campaign has repeats, variance estimates, or a randomized comparison design; the 65° target was missed, and the OSL/inverted-gap campaigns inherit evaluators whose biases the authors themselves flag (the TD-DFT evaluator "did not reproduce inverted gaps"; the MOF desirability gain of 0.487 → 0.502 is modest).
- **Reproducibility is a genuine strength, not a red flag:** raw artifacts are on GitHub (the-matter-lab/La-Agente-Optima-artifacts), BO-MCP is open-sourced, and the SI contains complete campaign records, transcripts, and cost accounting.

## Strengths

- Real, multi-day closed loops on two physically distinct platforms (interfacial-formulation SDL and a flow-chemistry robot), run unattended overnight across time zones (Toronto orchestrating an Amsterdam robot) — far beyond the synthetic-benchmark scope of prior agentic-BO work such as Brunzena et al.
- The deterministic reasoning/execution split is architecturally principled: optimizer state is typed and persistent, provenance per suggestion is recorded, and "no BO mathematics are performed by an LLM" — directly addressing the documented failure mode where LLM-driven candidate selection ignores the posterior.
- A rich, honest taxonomy of failure recoveries drawn from real incidents (evaluator misconfiguration, infeasible-vs-missing measurement conflation, zero-yield spectral forensics at −76.5 ppm 19F, unconverged geometries, unconstructible MOF variables), each with the operator transcript in the SI.
- Negative and mixed results are reported plainly: the contact-angle target was missed; the inverted-gap campaign's gain was initialization luck; the LLM inference bill exceeded the chemistry cost it directed.
- Event-driven supervision keeps long-horizon campaigns out of the LLM context window — a practical answer to the context-budget problem that dominates real agent deployments.

## Limitations

- The benchmark suite is two single-objective tasks with 3 repeats; Shields arylation nearly saturates, leaving Ackley 6D (synthetic) as the only discriminating task, and no multi-task or multi-objective ablation.
- Ablations are end-to-end, so the causal contribution of the specialist delegation vs programmatic execution vs BO-MCP state management cannot be isolated.
- Physical showcases are single runs with human approvals at critical junctures (constraint changes, one-shot experiment authorization) — semi-autonomous rather than autonomous, and comparisons to the human campaign are retrospective.
- The RAISE integration is throughput-limited (serialized request/response bridge) and the specialist-model ranking is confounded by development bias; physical-platform generality is untested beyond the two in-house platforms.
- Inference overhead is material: $109.55 for one campaign (114.5M input tokens), which would erase the cost advantage against more expensive experimental platforms.

## Relevance

该工作精准命中用户最高优先级方向“自演化智能体与自动化研究”：LLM 智能体构建并监督跨计算/物理平台的长期贝叶斯优化闭环，其“专家子代理撰写程序 + 确定性服务化执行 + 事件驱动长时程监督”的架构与失败诊断/活动修复案例，对设计长时运行自主研究系统的可靠性与可审计性有直接借鉴价值。

## Questions for Further Exploration

1. Does the Specialist-script advantage survive on continuous or high-dimensional parameter spaces (where campaign design matters even more), or is the Ackley 6D separation an artifact of categorical-heavy, low-dimensional search spaces?
2. Could typed validation schemas at the specialist→program interface have caught the 180° fallback-encoding bug before deployment, turning post-hoc repair into pre-hoc prevention?
3. How would the event-driven supervision pattern extend to non-BO planners (evolutionary algorithms, active learning, swarm methods) as the Figure-5 vision claims — and what state would BO-MCP's typed campaign abstraction need to expose?
4. Would the eight-model specialist ranking persist if prompts and tool descriptions were neutralized of GPT-5.4 development bias, with equal, larger run counts per model?
5. Can the cost/material-efficiency framing be replaced by a budget-constrained regret analysis — i.e., is the agent actually better per unit of starting material at matched *stopping rules*, given the human campaign's 70.9% vs the agent's 58.8%?
