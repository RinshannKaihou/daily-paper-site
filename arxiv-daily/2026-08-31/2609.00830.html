Why this matters

Attention-aware token pruning and human-GT faithfulness proxies are unsafe in distributed regimes — mode-aware diagnostics decide when pruning visual tokens is safe.

注意力 top-k 能否安全剪枝/压缩取决于处理模式——对推理阶段 token 剪枝与 VLM 可靠性评估有直接参考价值。

Critical edge

The three-mode taxonomy is thresholded and manually refined on the very samples it describes — and 50.6% cross-model mode overlap is near chance for a three-way split.

01 Methodology

  • Attention ranking: attention aggregated over all layers (sum), heads (mean), and generated answer tokens → one importance score per visual token; top-k set selected.
  • Causal perturbation: zero-ablate the top-k tokens' hidden states at the entry of the language model's first decoder layer — preserves 2D positional structure (unlike token deletion); greedy decoding makes every probability change attributable to the ablation.
  • Metrics (from NLP, DeYoung 2020): Comp — does removing top-k destroy the prediction? Sgap — does keeping only top-k preserve it?
  • Matched-size controls: all four strategies ablate the same token count as the human GT region — Overall Top-k / GT Object / Non-GT Top-k / Random. Documents & charts use proportions (1–10% of tokens).
  • Mode partition: two-stage Otsu thresholding in the (Comp, Sgap) plane + manual refinement → modes A / B / C.
  • Setup: Qwen2.5-VL-7B main; InternVL2.5-8B generality; 3B/4B scaling. 85 valid VQA + 60 VRDU + 100 ChartQA samples.

The three modes — distinct signatures of how the model uses vision:

Bootstrap 95% CIs exclude zero for all three shares (B: [36.8, 57.6] — wide). Mode tied to question type: Yes/No → 55.6% B; open-ended → 34.5% C.

  • Four-strategy comparison: Overall Top-k 0.813 / 0.469 (Comp/Sgap) beats GT Object 0.505 / 0.846, Non-GT Top-k 0.659 / 0.653, Random 0.502 / 0.599 — not merely "any ablation hurts".
  • Divergence is bimodal, not noise: aligned subset GT-Comp 0.963; misaligned subset GT-Comp −0.150 while attention stays 0.945. Example: ablating the human-annotated sink region leaves the answer unchanged; ablating attention top-k collapses it.
  • Document IE = extreme Mode B for Qwen: ablating the top 1% of tokens drops answer probability 43.8%; keeping only top-k recovers ≤ ~5% (Sgap ≈ 0.947) — focal evidence necessary, layout context indispensable. ChartQA identical (Sgap ≥ 0.91).
  • Architecture flips the mode: InternVL2.5-8B treats the same IE task as ≈ Mode A (Sgap 0.189 at k=10%); per-sample Qwen↔InternVL mode overlap just 50.6%.
  • Scale-stable: Qwen 3B vs 7B Comp both 0.813; InternVL 4B 0.792 vs 8B 0.753; all three modes present at every scale.

03 Strengths

  • Causal, intervention-based design with matched ablation sizes — cleanly separates token-selection quality from ablation-size artifacts.
  • Well-chosen controls: Non-GT Top-k falls between Overall Top-k and Random, showing the effect is about ranking, not perturbation per se.
  • Taxonomy validated from multiple angles: question-type association, bootstrap stability, and re-analysis of the 5 excluded whole-image samples.
  • Honest scoping: fixed-resolution and reasoning VLMs explicitly named out of scope; appendix transparently discusses perturbation alternatives.
  • The GT-vs-attention divergence (bimodal GT-Comp) is the memorable result and is carefully evidenced at the sample level.

04 Limitations

  • Small hand-managed sets (85 + 60 + 100 samples); wide bootstrap CIs (Mode B 36.8–57.6%) yet one-decimal percentages in the abstract.
  • Descriptive taxonomy: Otsu + manual refinement on the same data, no held-out predictive validation of mode labels.
  • Only zero-ablation tested: no mean/noise ablation or gradient-saliency comparison; zero vectors sit far off the activation manifold.
  • Cross-model overlap (50.6%) interpreted favorably without an inter-rater-style baseline — architecture-dependence claim only weakly supported.
  • GT annotation quality unaudited (no inter-annotator agreement stats); no code or data release mentioned.
  • Scope: dynamic-resolution VLMs only; absence-detection and holistic-scene questions excluded.

05 Questions for further exploration

  1. Would the three-mode structure survive on reasoning-oriented VLMs or fixed-resolution architectures like LLaVA, where vision is not a separable token block?
  2. Are Comp/Sgap robust to mean- or Gaussian-noise ablation instead of zero-ablation?
  3. Can mode membership be predicted from question features or attention statistics on held-out data — a pre-hoc pruning-safety diagnostic?
  4. Does the Non-Focal mode correlate with object hallucination, where the model relies on diffuse image-conditioned knowledge?
  5. How does attention-based faithfulness compare with gradient saliency on the same samples — do the rankings agree within each mode?
