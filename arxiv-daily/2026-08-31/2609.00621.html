Why this matters

Every self-improving agent that edits its own prompts hits this safety boundary — frozen, validated interfaces keep self-rewrites from breaking the machinery.

Critical edge

The 100% stability figure is partly true by construction — an engineering property demonstrated, not a discovered result — and the guarantee says nothing about output correctness.

01 Methodology

agent output y = ( control c ─ frozen schema │ data m ─ optimizable )
  • The failure mode. An agent prompt does double duty: task content for other agents and an execution protocol (routing target, output format, termination signal) for the Python controller. Both live in one optimizable string, so content-improving edits rewrite the protocol — parse crashes, misroutes, dead episodes.
  • The separation. cdsep splits every output into a typed control object, validated against a Pydantic/dataclass schema whose scaffolding sits in a prompt slot the optimizer cannot edit, plus a free-form data message the optimizer fully controls. Only validated control objects drive routing, state updates, and termination.
  • Bounded recovery. Invalid control triggers ≤2 re-prompts, then a controlled default — never an unhandled crash.
  • The guarantee. Lemma 1: with typed routing, frozen scaffolding, and bounded retry, no unhandled parse/validation/routing violation enters the episode trace. Deliberately limited to the protocol layer.
  • Evaluation. Four settings of rising routing complexity (BBH → MARG review → synthetic → industry underwriting with Manulife), vs Fixed / Naive TextGrad / three DSPy variants / Partner-Fixed; 3 seeds; schema-retry-feedback ablation; 3 LLM families.

  • Ablation separates the two effects. Schema scaffolding alone lifts review stability from 0% to 100% (Jaccard 0.0→26.8); parse retry adds ~1 pt; per-example feedback drives all quality gains (Jaccard 26.9→38.0; synthetic accuracy 37.8→51.1%).
  • Mechanism quantified. 16.6% of naive TextGrad’s edited lines touch control-relevant tokens (JSON blocks, format rules, schema fields) vs 4.2% for cdsep — collapse concentrates exactly where the control surface is largest.
  • Honest footnotes. On the scaled MARG split, MIPROv2 posts better Recall (53.7 vs 46.0) and Precision (62.3 vs 50.7); fixed prompts win WordSorting and the OpenAI-only MARG run; headline MARG run costs ≈$3 in API spend.

03 Strengths

  • Real failure mode, mechanistically explained — the control-touch drift metric and three end-to-end failure transcripts show exactly how textual gradients delete or reformat protocol contracts.
  • Honest scope — the paper never claims stability implies correctness; Lemma 1 is explicitly confined to the protocol layer.
  • Genuinely informative ablation — stability (schema + retry) and quality (per-example feedback) are shown to have orthogonal causes.
  • Production grounding — 91 expert-rated Manulife underwriting summaries and the partner’s own prompt as calibration give the evaluation a flavor most prompt-optimization papers lack.
  • Usable artifact — MIT-licensed library, 77 tests, a full leader-worker pipeline in ~40 lines, ≈$3 per headline run, deterministic caching.

04 Limitations

  • Stability ≠ correctness — a protocol-valid pipeline can still produce wrong answers; the 100% headline is close to a restatement of the design.
  • Thin, metric-fragile margins — the +1.2 Jaccard win flips against MIPROv2 once Recall/Precision are rewarded instead of overlap.
  • Small evaluation sets — 25 BBH examples/task, 20 industry cases/seed, 12–14 review papers; 3 seeds; no significance tests.
  • Frozen schemas only — no dynamic agent creation or runtime schema evolution; a mis-specified schema or routing function is preserved perfectly by the guarantee.
  • BBH barely exercises the mechanism — the single-agent setting has no routing; its gain likely comes from per-example feedback, not separation.

05 Questions for further exploration

  • Can the frozen-schema restriction relax toward runtime schema evolution or dynamic agent creation while keeping a weaker, probabilistic stability guarantee?
  • Would pairing frozen control channels with stronger optimizers (GEPA’s reflective evolution, SAMMO) yield gains beyond the +1.2 Jaccard over MIPROv2?
  • Does the 16.6%-vs-4.2% control-touch drift metric generalize as an online early-warning indicator of collapse across other optimizer families?
  • How does the framework behave when the task loss legitimately requires changing the protocol itself — more workers, a different routing topology?
  • Would the underwriting and review conclusions hold with an order of magnitude more evaluation data or human raters?
