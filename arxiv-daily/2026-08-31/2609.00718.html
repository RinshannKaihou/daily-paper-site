A Closed-Loop Evaluation of Capability Loss and Recovery in Compressed Driving Policies

Ahmad Alfan Alfian Irfani · Nur Ahmad Khatim · Mansur Arief • UMY · NAIST · KFUPM • Digest 2026-08-31

  • Autonomous driving
  • Model compression
  • INT8 quantization
  • Closed-loop evaluation

Key metric

3of8

C3 stop-sign episodes lost to INT8 quantization

The FP32 source checkpoint completed all 8; the QAT variant instead crosses the stop line in 4 of 8 — opposite failure sides of the same interrupt-and-resume demand.

Why this matters

Low-precision inference can silently destroy recovered task behavior while standard fidelity metrics miss it — borrow the stage-wise closed-loop acceptance template.

Critical edge

All verdicts rest on one 6,210-parameter policy in one simulator, with 8 seeds and no confidence intervals — and the perception stack, which dominates real latency, is never compressed.

Methodology

  1. Task. Visuomotor lane following with pedestrian avoidance and stop-line compliance in Gym-Duckietown, a POMDP across five curricula C0–C4 (C3/C4 add stop signs and require interrupt-and-resume driving).
  2. Belief pipeline — never compressed. YOLO11n boxes ray-cast to range/bearing + MobileNetV3-small offset/heading/curvature feed two EKFs and a stop state machine, forming a 29-dimensional belief vector.
  3. Actor. Deterministic 3-layer perceptron (256→256→2, tanh, 73,986 params) trained with belief-state PPO.
  4. Compression ladder A0–A9. A1 structured pruning to width 64 (6,210 params, −91.6%); A2/A3 distillation from the frozen FP32 teacher differing only in rehearsal coverage (A3: 62,176 balanced public states); A6/A8 INT8 via PTQ / QAT from the same A3 checkpoint; A9 pure FP16 cast; A4/A5 controls.
  5. Acceptance. Every candidate drives all 5 curricula × 8 seeds (40 episodes, 400 total) against 10 pre-registered checks plus a paired regression tolerance δ_k vs FP32 — thresholds fixed before any result existed.

Results

Curricula passed out of five, on identical seeds. A6 vs A5 differ in exactly one intervention (balanced KD before PTQ) — KD placement preserved C0–C2 outright.

  • Counterintuitive costs: INT8 is fastest (12.9 µs vs 19.4 µs FP32 median, ~1.5× speedup) yet serializes to ~1.5× the FP32 file size — traced-graph metadata dominates at 6,210 params. FP16 adds 26% latency, an x86 artifact of the missing native half-precision path.
  • Fidelity-only acceptance fails both ways: A4 — which drives every curriculum — is rejected (false negative), while A8 — the more dangerous driver — would be accepted (false positive). Fidelity is neither necessary nor sufficient.
  • Interaction, not integer arithmetic: quantizing the unpruned actor (A4) loses nothing; only the prune→KD→quantize path re-breaks the stop curricula.

Strengths

  • Uncommonly rigorous hygiene: pre-registered checks, paired regression tolerances on identical seeds, and byte-identical-checkpoint contrasts (A6 vs A8 share A3; A6 vs A5 differ by one intervention) that cleanly isolate each stage's causal effect.
  • Actionable deployment guidance: release gates at every intermediate stage; the rehearsal set is a safety-relevant configuration item; interrupt-and-resume scenarios deserve first-class acceptance status.
  • The fidelity-vs-closed-loop gap demonstrated in both error directions on the same model family — the paper's strongest argument.
  • Genuinely surprising cost findings, crisply quotable (INT8 faster and larger; FP16 free of behavioral cost).
  • Honest, clearly bounded claims throughout, with a limitations section that anticipates most external criticism.

Limitations

  • Single small policy, single simulator (Gym-Duckietown), single compression checkpoint; transfer to full-scale driving or larger policies is untested.
  • 8 seeds per curriculum with no uncertainty quantification; borderline verdicts (3/8 failures) are treated as definitive despite noted stochasticity.
  • The δ_k tolerances — the crux of every pass/fail call — are admittedly ad hoc and get no sensitivity analysis.
  • INT8 findings are backend-specific (eager static PTQ on x86); the FP16 latency penalty does not generalize to GPUs/NPUs.
  • No mechanism analysis of why INT8 destroys the stop curricula; no code release stated; A7 (unpruned QAT) muddies the clean pruning story.
  • The perception pipeline is never compressed — the study audits the cheapest slice of the stack.

Questions for further exploration

  1. Would QAT with balanced rehearsal data recover the stop curricula, or is the integer representation itself the blocker at this width?
  2. How sensitive are verdicts to δ_k — is there a tolerance under which A6 passes C3, and would that same tolerance accept genuinely unsafe drivers?
  3. Does stop-curriculum fragility persist in larger, deeper, or end-to-end vision policies where the perception stack is also compressed?
  4. What is the mechanism — is the INT8 failure concentrated near the stop decision boundary, and would per-channel calibration or range clipping fix it?
  5. Does stage-wise closed-loop acceptance also catch hardware-induced silent corruption (weight bit flips) that fidelity checks would again miss?
