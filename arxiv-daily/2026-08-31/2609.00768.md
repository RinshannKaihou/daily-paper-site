> **一句话总结：** DiagEvo 用一个冻结的 Qwen3-4B"诊断师"对比 solver 失败轨迹与正确轨迹的最早推理分歧，抽取可复现的错误原因存入带 Active/Mastered 状态与失败频率的层级记忆，据此调度"针对原因出题 + 自由探索"的混合生成，并用绝对+相对双重置信度过滤伪标签；在 Qwen3-8B-Base 上五个数学基准平均达 72.3%，比 label-free 基线 R-Zero（67.8%）高 4.5 个百分点、比使用外部资源的 DARC（71.1%）高 1.2 个百分点，而诊断+记忆维护仅占训练总时长的 5.7%。

> **TL;DR:** DiagEvo is a label-free challenger–solver self-play framework whose curriculum signal comes from the solver's own failure history instead of external task resources. A frozen diagnostician LLM (Qwen3-4B-Instruct-2507) extracts recurring error causes by comparing each disagreeing GRPO trajectory against an agreeing one and locating the earliest reasoning difference; causes live in a hierarchical memory (skill nodes → causes) with Active/Mastered states and episode frequencies that schedule a mixture of cause-targeted and free-exploration question generation (ε_{t+1}=F_t/(F_t+kF_1), k=0.5), plus cross-state stitching of an Active cause with a Mastered sibling. Before solver GRPO, double-confidence filtering keeps questions whose majority vote share lies in [0.25, 0.75] AND is ≥1.6× the runner-up's. On Qwen3-8B-Base it reaches 72.3% average over MATH-500/GSM8K/OlympiadBench/Minerva/AMC, +4.5 points over R-Zero (67.8%) and +1.2 over the externally-guided DARC (71.1%), with general-reasoning transfer of 36.3→38.8 vs R-Zero; diagnosis and memory maintenance add only 5.7% wall-clock over R-Zero's loop on 8×H200.

## 核心贡献

- **失败历史即课程信号**：首次在 label-free 自博弈中不依赖任何外部任务资源（人工样例、文档语料、难度标签），而是从 solver 自身失败轨迹导出课程方向——通过对比"与伪标签一致的响应 r⁺ / 不一致的响应 r⁻"的最早推理分歧，抽取排除题目表面形式、可迁移的错误原因。
- **层级错误-原因记忆与状态机**：记忆按"技能节点 → 错误原因"组织，每个原因存 (state, f_t(e)) 二元组；频率驱动混合生成（式 ε_{t+1}=F_t/(F_t+k·F_1)）平衡针对性出题与自由探索；同技能节点内 Active×Mastered 跨状态拼接；自一致性 ≥0.70 晋升 Mastered、新失败再激活回 Active，形成闭环。
- **双重置信度过滤**：在 R-Zero 式绝对自一致性区间 [0.25, 0.75] 之上新增相对约束 p₁(x) ≥ 1.6·p₂(x)（多数答案票 share 须明显领先第二名），消融显示相对约束单独贡献 +1.4 数学平均分；GPT-5 复核显示记忆使伪标签 oracle 一致率在 round 5 提升 7 分、相对约束再提升 3 分（65%→75%）。
- **系统化实验**：3 个基座 solver（Qwen3-4B/8B-Base、OctoThinker-8B-Hybrid-Base）× 3 档诊断师（4B/30B-A3B/235B-A22B）× 6 个基线，三次运行报均值±标准差；复现 base 与 R-Zero 校验跨论文可比性（每列偏差 ≤0.1 / ≤0.5 分），并量化诊断+记忆开销（5.7% wall-clock）。

## Key Contributions

- **Failure history as curriculum signal**: derives the curriculum direction from the solver's own failed GRPO trajectories without any external task resources (human examples, document corpora, or difficulty labels), via comparative error-cause extraction — the diagnostician locates the earliest reasoning difference between a response r⁻ that disagrees with the pseudo-label and a response r⁺ that agrees, yielding causes that abstract away question-specific values and surface form.
- **Hierarchical error-cause memory with a state machine**: memory groups causes under skill nodes; each cause carries an Active/Mastered state plus an active-episode failure frequency. A frequency-driven schedule (ε_{t+1} = F_t/(F_t + k·F_1), k=0.5) mixes cause-targeted generation with free exploration; cross-state stitching pairs an Active cause with a Mastered sibling from the same skill node; promotion (mean self-consistency ≥ 0.70) and reactivation (new failures) close the loop.
- **Double-confidence filtering**: adds a *relative* constraint p₁(x) ≥ τ·p₂(x) (τ=1.6) on top of the absolute self-consistency window [0.25, 0.75], removing high-conflict questions where two leading answers receive similar vote shares; ablations attribute +1.4 math points to the relative constraint alone, and GPT-5-based oracle agreement shows memory adds +7 points and the relative constraint +3 more at round 5 (65% → 75%).
- **Systematic evaluation**: 3 base solvers × 3 diagnostician scales × 6 baselines, mean±std over three runs, with baseline reproduction validation (base models within 0.1, R-Zero within 0.5 points of reported scores on every column) and a runtime breakdown (diagnosis + memory = 5.7% of wall-clock).

## Methodology

DiagEvo is a challenger–solver co-evolution loop (R-Zero style) where only one model updates per phase and only the challenger sees the memory. Each round has four stages:

1. **Diagnosis-guided question generation (challenger).** Let F_t = Σ f_t(e) over Active causes. The cause-targeted probability is ε_{t+1} = F_t/(F_t + k·F_1) with exploration–exploitation proportionality k = 0.5 (memory empty ⇒ pure free exploration; equal split when F_t = k·F_1), and each Active cause is sampled proportionally to its failure frequency p_{t+1}(e) = f_t(e)/F_t. Cause-targeted prompts apply *cross-state stitching*: an Active cause is paired with a uniformly sampled Mastered cause from the same skill node (prompt contains the Active cause alone if none exists). The challenger itself is updated first via GRPO using R-Zero's reward unchanged — a uniqueness reward r_unc(x) = 1 − 2|p₁(x) − 1/2| maximized at 50% self-consistency (the solver's competence boundary), minus a BLEU-cluster repetition penalty r_rep = |C_k|/B, λ = 1.
2. **Solver optimization with double-confidence filtering.** Each candidate gets N = 12 construction responses from the solver; the majority answer becomes the pseudo-label. A question is retained for solver GRPO only if the absolute self-consistency lies in [p_low, p_high] = [0.25, 0.75] **and** the relative constraint p₁(x) ≥ τ·p₂(x) holds with τ = 1.60 — targeting intermediate difficulty where the majority answer clearly leads. A separate set of 8 optimization responses per retained question provides the policy-gradient signal; its failed trajectories feed memory maintenance.
3. **Memory maintenance.** A frozen diagnostician (default Qwen3-4B-Instruct-2507, non-thinking) runs four sequential steps: (a) *comparative error-cause extraction* — Eq. 4 diagnoses D_ext(x; y, r⁻, r⁺), matching each new observation against supplied known causes (a match to a Mastered cause triggers reactivation); (b) *dedup and assignment* — retrieve near neighbors with text-embedding-v4, confirm with the LLM (θ_dedup = θ_merge = 0.50), assign unmatched causes to a retrieved or new skill node; (c) end-of-round *consolidation* merging redundant skill nodes; (d) *joint state–frequency update* — promotion to Mastered when mean self-consistency acc(e) ≥ θ_up = 0.70 (resets the episode frequency), reactivation on new failures (frequency restarts at the new failure count).
4. **Hierarchical memory** M_t = (V_t, E_t, α_t): skill nodes store descriptions + embeddings; each cause stores a text description, an embedding, its state, and frequency.

Training: GRPO for both models on a single node of 8×H200 (BF16, FlashAttention 2), LR 1e-6, KL 1e-2, temperature 1.0, top-p 0.99; challenger 6 GRPO steps/round, solver 12; global batch 256, group size 8; 5 rounds in main experiments (round-5 checkpoint used). Evaluation: math on MATH-500, GSM8K, OlympiadBench, Minerva Math, AMC (GPT-4o judge, mean@32; AMC has 40 questions); general on MMLU-Pro, SuperGPQA, GPQA-Diamond, BBEH (exact match, greedy).

## Results & Highlights

- **Qwen3-8B-Base (default 4B diagnostician, 3 runs):** DiagEvo reaches **72.3±0.7** average on the five mathematical-reasoning benchmarks vs **67.8** for label-free R-Zero (**+4.5**) and **71.1** for DARC (+1.2); general-reasoning average is **38.8±0.7** vs R-Zero's 36.3 (+2.5) and DARC's 37.8 (+1.0); overall (all nine benchmarks) **57.4** vs DARC 56.3 (+1.1). It posts the best mean in every row of the Qwen3-8B block, e.g. OlympiadBench 51.4±0.7 vs DARC 48.4.
- **Consistency across solvers:** overall scores of **53.5** on Qwen3-4B (DARC 52.2, **+1.3**; math avg 57.0±0.4 vs DARC 56.3) and **41.9** on OctoThinker-8B-Hybrid-Base (DARC 40.6, **+1.3**; math avg 53.7±0.5 vs DARC 51.2). Cross-domain transfer: general average rises 27.8→35.0 (Qwen3-4B), 33.2→38.8 (Qwen3-8B), and 10.7→28.4 (OctoThinker) despite a math-only curriculum.
- **Ablations (Qwen3-8B, Table 2):** full system 72.3 math / 38.8 general. Freezing the challenger costs −3.8 (68.5/36.9); pure free exploration 69.5/37.2; pure cause-targeted 70.1/37.6 (the two modes are complementary). Removing state updates costs −2.2; replacing same-skill-node cross-state stitching with random-pair stitching costs −1.0 (71.3 vs 72.3). For filtering: no filtering 69.4/36.7, absolute-only 70.9/37.5, adding the relative constraint gives the full +1.4 to 72.3.
- **Diagnostician scale is not the source of gains:** 4B→235B-A22B raises math average only +1.0 (Qwen3-4B), +1.2 (Qwen3-8B), +2.8 (OctoThinker), concentrated on OlympiadBench (+2.4/+2.8/+2.8); general average moves just 0.2–0.5. The 4B default already exceeds every baseline by ≥1.1 overall.
- **Co-evolution dynamics:** performance improves each of rounds 1–5 to 72.3%, then slips to 72.0 (round 6) and 71.4 (round 7) — the paper uses the round-5 checkpoint. Pure free exploration peaks at 69.5% by round 3 and ends at 69.0%. Memory grows from 151 to 244 causes with skill nodes stabilizing near 36; Active causes peak at 188 (round 2) and fall to 117 by round 5 while Mastered reaches 127 (over half the memory).
- **Pseudo-label quality and degeneration control:** with GPT-5 relabeling (R-Zero's protocol), oracle agreement under free exploration with absolute-only filtering falls from 83% to 65%; at round 5 the memory contributes +7 and the relative confidence constraint +3 more (75%). Without memory, average generated-question length balloons from 45.6 to 166.9 words; with memory it stays near 73 words while 2-gram diversity still rises (33.3→36.5) — difficulty grows without length inflation.
- **Overhead:** diagnosis and memory maintenance account for only **5.7%** of total wall-clock (comparative extraction 3.9%, dedup 1.3%, consolidation 0.4%, state update 0.1%); the remaining 94.2% mirrors R-Zero's loop.

## Authors & Credibility

The paper comes from the **Meituan LongCat Team** (Xincheng Wei, Yifan Ding, Yoshua Li, Dongsheng Ma, Rongxiang Weng, Xunliang Cai — Xunliang Cai is Meituan's long-standing NLP lead) in collaboration with CUHK-Shenzhen, Peking University, Juntendo University, and Nankai University. Wei and Ding contributed equally; Wenjian Ding and Yao Zhang are corresponding authors. As an industry lab that trains its own foundation models, the team has credible infrastructure for GRPO co-evolution at 8×H200 scale, and this shows in unusually careful experimental hygiene: three-run means with standard deviations, a dedicated appendix (F, Table 7) validating that their reproduced base and R-Zero numbers match reported ones within 0.1/0.5 points before mixing in scores taken from the DARC paper, full hyperparameter tables, and a runtime breakdown. The work sits coherently in the lab's self-evolution line, engaging the current R-Zero/Absolute Zero/SPICE/DARC literature directly.

## Critical Assessment

- **Incremental relative to R-Zero, by design.** The challenger GRPO reward is adopted from R-Zero *unchanged* (uniqueness reward peaked at 50% self-consistency, λ=1 repetition penalty), and the loop skeleton is R-Zero's; the entire delta is the memory + filtering layer. That layer is genuinely novel — prior agent-memory work (Reflexion, ExpeL, ReasoningBank, SkillRL) guides the task-solving agent, not the curriculum generator — and the Active/Mastered state machine tied to a failure-frequency schedule is the paper's sharpest idea. But "we kept R-Zero's reward and added memory" is the honest one-line summary, and the ablation that freezing the challenger costs 3.8 points mostly re-confirms R-Zero's own finding that challenger updates matter.
- **The headline margin over the strongest baseline is thin and partly cross-paper.** DARC — the only baseline that also beats R-Zero solidly — is beaten by just +1.1 to +1.3 overall, and the DARC, SPICE, R-Few, and Absolute Zero rows are **copied from the DARC paper** rather than re-run; only the base models and R-Zero were reproduced (within 0.5 points). Given that their own reproduction of R-Zero shifted scores by up to 0.5 points, a full re-run of DARC under this infrastructure could plausibly compress the +1.2 math margin further. To the authors' credit, copied rows are explicitly marked with † and the missing R-Few/OctoThinker cell is disclosed rather than interpolated.
- **The diagnostician itself is never directly validated.** There is no human audit of extracted error causes beyond a single traced example (Appendix I), and no measurement of dedup/routing precision — evidence for extraction quality is indirect (ablations + oracle agreement). The "label-free" claim is accurate w.r.t. external *task* resources, but the pipeline leans on a frozen strong instruct model (Qwen3-4B-Instruct-2507) and a commercial embedding (text-embedding-v4); the system inherits substantial external priors that are never priced.
- **The shared-error failure mode is acknowledged but unquantified.** Appendix A admits double-confidence filtering measures solver *agreement*, not correctness — a systematically shared error passes the filter — yet the paper never measures how often the majority pseudo-label is wrong-but-consistent. Even the full system's round-5 oracle agreement is 75% per GPT-5 relabeling, i.e., roughly a quarter of trained pseudo-labels are wrong, with no analysis of the downstream effect on the solver.
- **Benchmark quirks.** AMC has only 40 questions judged by GPT-4o at mean@32 — noisy per-benchmark cells; OctoThinker's 10.7→28.4 general-reasoning jump starts from a very low base. All comparisons are confined to the self-play family: there is **no verifiable-reward RL baseline** trained on standard math data with ground truth, so the reader cannot tell how far label-free self-play sits from plain RLVR — the cost of avoiding external task resources is never quantified against the simpler alternative.
- **Honest reporting is a genuine strength here:** the round-6/7 decline (72.0, 71.4) is disclosed, sensitivity tables show a flat landscape (k spread ≤1.0, τ spread ≤1.0), and the general-benchmark gains are carefully framed as transfer rather than direct optimization.

## Strengths

- A clean, well-motivated answer to a real problem: unguided self-play drifts (questions balloon from 45.6 to 166.9 words while performance plateaus at 69.0%), and guided methods need external resources — DiagEvo shows the needed direction is already inside the solver's failure history.
- The mechanism is simple and cheap: 5.7% wall-clock overhead over R-Zero's loop, fully deterministic scheduling given the memory, and a clear state machine (promotion at self-consistency ≥0.70, reactivation on failure, frequency reset on episode close).
- Careful evaluation hygiene: 3 runs with std on every DiagEvo cell; baseline reproduction validation before mixing scores from another paper; sensitivity analyses for both new hyperparameters (k, τ); ablations that isolate each of the three proposed components.
- The question-property analysis is a nice touch — with memory, difficulty rises while question length stays ~73 words and 2-gram diversity still grows (33.3→36.5), ruling out the "harder = longer" degeneration pathway.
- Gains are consistent across three heterogeneous solvers (4B dense, 8B dense, 8B hybrid) and the diagnostician-scale study shows the effect is not an artifact of a huge diagnoser.

## Limitations

- The curriculum is built from math questions only; general-reasoning gains are transfer, and there is no direct curriculum construction (let alone evaluation) for other domains or open-ended, multi-turn tool-use tasks.
- The training horizon is fixed in advance (5 rounds); performance peaks at round 5 and declines after (72.0, 71.4 at rounds 6–7), with no adaptive stopping criterion — the paper itself flags this.
- Pseudo-label correctness is unmeasured: double-confidence filtering captures agreement, not truth; shared solver errors pass the filter, and ~25% of round-5 pseudo-labels are wrong per GPT-5 relabeling.
- Margins over the strongest baseline (DARC, +1.1–1.3 overall) are within plausible cross-paper reproduction noise since DARC was not re-run locally.
- No comparison against verifiable-reward RL on standard math datasets, leaving the price of "no external task resources" unquantified; error-cause extraction quality has no direct measurement (only one case study).

## Questions for Further Exploration

- How does DiagEvo behave in domains with verifiable rewards (code with unit tests)? Could the shared-error rate of pseudo-labels be measured directly there, closing the gap that oracle agreement only proxies?
- Can the diagnostician be the solver itself (self-diagnosis), removing the frozen external instruct model — and how much extraction quality would that cost?
- Does the Active/Mastered state machine transfer to open-ended, multi-turn tool-use curricula where "self-consistency over answers" is ill-defined?
- Since only base models and R-Zero were re-run locally, what would a full DARC reproduction under this infrastructure do to the +1.2-point headline margin?
- Skill-node count stabilizes near 36 within a single math domain — where is the scaling limit of the consolidation threshold (θ_merge=0.50) as the curriculum broadens across domains?
- The memory is only visible to the challenger. Would giving the solver access to its own error-cause memory (as hints or system-prompt context) help or hurt GRPO training?
