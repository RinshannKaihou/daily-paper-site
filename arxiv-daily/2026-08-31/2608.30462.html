Low-resource reasoning failures are under-elicitation, not missing knowledge — steering shared SAE features recovers 25–33% of the gap, training-free and translation-free.

Enhancing Low-Resource Language Reasoning via High-Resource Language Feature Transfer

Minju Song, Hyeon Hwang, Junhyun Lee, Jaewoo Kang · Korea University × HUFS · Gemma-2-9B-it · Qwen2.5-7B · layer-20 SAEs

sparse-autoencoders activation-steering multilingual-reasoning low-resource-languages
◆ Key metric
25–33%

Of the high-resource language gap recovered across four (reference, benchmark) settings — e.g. Gemma Korean MATH500 49.20 → 52.41 (41% of the gap to English's 56.91). Beats CAA steering in 11 of 12 settings.

⚑ Critical edge

On one of four targets, matched-random steering does as well as the mined features (Vietnamese 52.30 vs 51.77) — the task-specificity story doesn't fully separate, and the headline range spans ~0% to 69% per cell.

Why this matters

No training, no translation: the model already knows how to reason — multilingual failure is an activation problem you can patch at inference time, in the user's own language.

Methodology

  • 1Contrastive mining. Pair the same question: trace correct in English/Spanish, incorrect in the target language. Record per-token SAE argmax features on both sides; keep the set-difference (present in success, absent in matched failure), then drop the top-50% most frequent as generic generation patterns — retain the 50–90% rank window.
  • 2Steering. Coefficient w_f = mean activation gap between reference-success and target-failure traces. At generation tokens only, inject Δh = α·Σ w_f·W_dec[f] into the layer-20 residual stream. Prefill untouched; no parameters updated.
  • 3Three causal tests. Partial sufficiency (activating C lifts target accuracy), functional necessity (suppressing C degrades reference accuracy), specificity (matched-random and excluded features should not reproduce either). GlotLID audits that output stays in the target language.
  • ∘Setup. Gemma Scope SAE (16k latents) + Qwen matryoshka SAE (65k); greedy decoding; MATH500 / MGSM / MMLU-ProX psychology; 4× H100.

Results & Highlights

Mechanistic finding: in the 28-feature EN→KO steering pool, only 3 are English-specific — 25 fire in both languages on shared concepts (quantity, requirement, equality). Feature 13089 ("requirement/needs") peaks at 63.6 on English tokens vs 25.0 / 28.0 on Korean — a 2–5× activation gap. Under-elicitation, quantified.

  • Controls behave as predicted: steering with top-frequency features actively hurts (Thai 45.98 vs 48.23); negative steering drops below baseline; suppressing C during English inference cuts 56.91 → 54.02 vs 55.16 for matched-random suppression.
  • Not language-switching: GloTLID shows target-language proportion changes <1.5 pp in 37 of 40 settings — gains are better reasoning within the target language.
  • Unseen targets: pair-specific steering lifts Bengali 75.6 → 81.2 (40%) but Telugu only 74.4 → 75.6 (8%); reused EN→KO/TH feature sets still beat baseline — each language under-elicits a partially different subset.
  • Uneven: MMLU-ProX Swahili on Gemma is ~0% recovery (10.27 → 10.30); 67–75% of the average gap remains.

Strengths

  • Upgrades observation into causation: a clean, reusable sufficiency / necessity / specificity template applied to a well-known English-centric latent-space story.
  • Negative controls actually run — and honestly reported, including a case where the method's own naive variant (top-k steering) hurts.
  • Output-language audit rules out the trivial "quietly answers in English" explanation many steering papers skip.
  • Real interpretability payoff: named shared features with quantified 2–5× cross-language activation gaps.
  • Reproducible: public models and SAEs, deterministic contrast sets, full hyperparameter and hardware disclosure.

Limitations

  • Thin separation in places: random steering matches the method on Vietnamese; necessity evidence separates from generic disruption by only ~1.1 pts.
  • Small scope: two 7–9B models, three math-dominated benchmarks, four (+2) languages; no frontier models; cross-task transfer untested.
  • SAE-bound: single layer (20), quality of the external SAE caps resolution; polysemantic latents can dilute the contrastive signal.
  • No subset ablation: all 28 features pooled into one vector; no α-sensitivity analysis; layer sweep 4–38 all help, suggesting a broad-band effect, not a localized circuit.
  • Per-token encode/decode cost is unquantified; feature sets are pair- and model-specific, requiring re-mining per combination.

Questions for Further Exploration

  • Do contrastive feature sets transfer across tasks (MATH500-mined features improving MGSM or code reasoning), or are they benchmark-bound?
  • How sensitive is recovery to steering strength α, SAE width, and the 50–90% rank window — and can per-layer feature sets be combined to push past the 25–33% ceiling?
  • Is there a compact core subset among the 28 features that drives most of the gain, or is the effect irreducibly distributed across many weak latents?
  • Does under-elicitation hold at frontier scale, where multilingual pretraining is stronger and the HRL–LRL gap is smaller and possibly differently mechanized?
  • Can the paired success/failure contrastive mining generalize to non-linguistic reliability failures — silent numerical corruption, degraded hardware — where the same computation succeeds or fails across runs?
