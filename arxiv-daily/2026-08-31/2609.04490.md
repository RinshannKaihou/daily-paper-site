> **一句话总结：** 论文提出"循环状态写回（recurrent-state write-back）"概念并做因果隔离实验：在荧光寿命成像（FLI）推断任务的 6,627 参数 Seq2SeqLite GRU 上，冻结全部权重、仅把状态存储规则从连续传播换成确定性 4-bit 写回，τ1/τ2 寿命 RMSE 从 0.36/0.35 ns 恶化到 25.37/106.59 ns（约 70 倍/300 倍），机制是 99.59% 的解码器状态更新落入半步写回死区被反复丢弃（同向被抑制提案中位连续长度达 132/134 步）；而 error feedback、量化残差记忆、方向记忆（direction memory）等不重训练的存储算子可将同一冻结网络恢复到 0.34/0.46–0.49/0.58 ns，并在独立训练的 LSTM 上复现失败与拯救，且发现 cell state 写回粗化的伤害远大于 hidden state。

> **TL;DR:** On a 32-unit GRU (Seq2SeqLite, 6,627 parameters) estimating two fluorescence lifetimes (τ1 short, τ2 long) from 135-bin high-noise decay signals (1.6M simulated signals, 160,000-sample held-out test set), the paper shows the quantized recurrent state is not mere noise but part of the computation: with all weights frozen, swapping continuous state propagation for deterministic 4-bit write-back degrades τ1/τ2 lifetime RMSE from 0.36/0.35 ns to 25.37/106.59 ns (~70x/300x), because 99.59% of decoder updates fall inside the half-step write deadband. Simple storage-rule replacements needing no retraining — error feedback (0.34/0.46 ns), 4-bit residual memory (0.34/0.45 ns), direction memory (0.49/0.58 ns) — rescue the same frozen network, while an independently trained 8-bit GRU degrades from 0.20/0.22 ns to 1.89/2.60 ns under forced 4-bit state and a native-4-bit-trained GRU is immune (0.35/0.40 ns). The failure replicates in an independently trained LSTM, where coarse cell-state write-back is far more damaging (c-only 8.16/1.29 ns) than hidden-state write-back (h-only 0.30/0.35 ns) despite similar deadband fractions. Takeaway: for low-precision recurrent inference, the state-storage interface must be specified and evaluated alongside bit width, because interface compatibility is learned, not guaranteed.

## 核心贡献

- **概念化"循环状态写回"**：把循环网络中"第 t 步算出的状态如何存储并回传给第 t+1 步"的规则从隐含实现细节提升为显式设计变量；确定性低精度写回会把落在一个量化半步内的提案更新原样丢弃（写回死区/write deadband），使网络在同一方向上反复提出却永远不可见的小更新无法进入"循环可见轨迹"。
- **因果隔离的失败证明**：在 Seq2SeqLite GRU（FLI 寿命推断）的冻结 P2F 检查点上，仅切换存储规则即让 τ1/τ2 RMSE 从 0.36/0.35 ns 恶化到 25.37/106.59 ns（约 70 倍/300 倍），而权重、读出、输入、评估流程全部不变；并刻画失败的时间签名——99.59% 的解码器更新落在 4-bit 写边界内、97.25% 的解码步没有任何隐藏单元改变存储层级、同向连续提案中位长度 132/134 步，而原生 4-bit 训练的模型每步改变 1.24% 的状态元素且不失败。
- **可测量化与可纠正的机制**：提出 recurrent write margin（提案状态变化与量化器半步之比，M_{t,j}<1 即落死区）和方向记忆算子——用 k-bit 有符号计数器累积同向亚阈值提案、攒够即把存储状态推进一个格点（保留方向、丢弃幅度）；在 8-bit 参考模型上，方向记忆把同向连续运行中位长度从 132 步缩到 6 步、状态改变比例从 0.60% 提到 4.76%，误差从 1.89/2.60 ns 恢复到 0.49/0.58 ns。
- **"数值保真度 ≠ 动力学保真度"**：后训练精度扫描发现 4-bit 训练的模型升到 8-bit 反而变差（0.35/0.40 → 0.43/0.57 ns），尽管每单元占用层级中位数从 12 涨到 176.5；匹配训练实验（4-bit 状态 / 6-bit 状态 / 4-bit+2-bit 残差 / 4-bit+2-bit 方向记忆，各 3 个随机种子）显示 τ1 上方向记忆最优（0.30±0.03 ns vs 6-bit 的 0.48±0.16 ns），τ2 上 6-bit 与残差记忆更强——存储接口兼容性是训练中学到的，不存在算子的普遍排序。
- **跨架构与状态特异分析**：独立训练的 32-unit LSTM 重现失败（c+h 双 4-bit：0.239/0.254 → 3.857/1.327 ns）与 error feedback 拯救（0.263/0.332 ns），且仅粗化 cell state 伤害巨大（8.158/1.292 ns）而仅粗化 hidden state 几乎无害（0.296/0.354 ns），尽管后者死区比例更高（93.78% vs 79.43%）——伤害取决于哪个变量承载时间信息，而非死区频率本身。
- **QMem 分阶段量化感知训练流程**（先候选核→reset 门→update 门→偏置→激活、最后 15 epoch 混合引入 4-bit 状态写回）作为诊断脚手架，精确定位失败出现于状态量化引入的 P2F 阶段。

## Key Contributions

- Introduces **recurrent-state write-back** — the rule that stores the recurrent state computed at step t and returns it to the network at step t+1 — as an explicit, interventionable design variable in low-precision recurrent inference, with the **recurrent write margin** M_{t,j} as a per-update quantitative criterion (M<1 = proposed change is silently discarded by the half-step deadband).
- Provides a **causal isolation** of the failure: on a frozen Seq2SeqLite GRU checkpoint for fluorescence lifetime inference, toggling only the storage rule (continuous propagation vs deterministic 4-bit) moves τ1/τ2 lifetime RMSE from 0.36/0.35 ns to 25.37/106.59 ns (~70x/300x) with weights, readout, inputs, and evaluation fixed; the failing regime is characterized by a 99.59% decoder deadband fraction and median completed same-direction runs of 132/134 steps.
- Proposes **direction memory**, a k-bit signed-counter operator that accumulates same-direction sub-threshold proposals and advances the stored state one grid step at the trigger threshold, plus frozen-network rescues via error feedback and quantized residual memory — restoring 1.89/2.60 ns to 0.34/0.46–0.49/0.58 ns on an independently trained 8-bit reference GRU without any retraining.
- Demonstrates **numerical fidelity is distinct from dynamical fidelity**: post-training precision sweeps are non-monotonic (the 4-bit-trained GRU worsens from 0.35/0.40 ns at 4-bit to 0.43/0.57 ns at 8-bit even though occupied levels rise from 12 to 176.5 per unit), and a matched-training campaign (4 memory allocations x 3 runs) shows the relevant property is learned interface compatibility, not a universal operator ranking.
- Replicates the failure and rescue in an **independently trained LSTM** and dissects state types: forcing deterministic 4-bit on both c and h gives 3.857/1.327 ns (from 0.239/0.254 ns native), but c-only write-back yields 8.158/1.292 ns vs 0.296/0.354 ns for h-only — the damage tracks which recurrent variable carries the temporally distributed information, not the deadband fraction.

## Methodology

**Task and models.** The testbed is fluorescence lifetime imaging (FLI) inference: each sample is a 135-bin, high-noise, time-resolved fluorescence decay generated with the PyFLI simulation framework (mono/bi-exponential kinetics, photon statistics, detector-dependent noise, measured pixel-wise IRFs; excitation period 12.5 us, bin width 0.09 ns). The dataset has 1,600,000 signals with a fixed 80/10/10 split (1.28M train / 160k val / 160k test). The model is Seq2SeqLite, a single-layer 32-unit GRU encoder-decoder with 6,627 trainable parameters, knowledge-distilled (α = 0.6) from a frozen 128-unit two-layer GRU teacher. Lifetimes θ = (τ1, τ2) are extracted by trapezoidal integration of the predicted temporal output sequence; τ1/τ2 RMSE (ns) is the primary task metric, sequence MAE the reconstruction metric. An independently trained 32-unit LSTM (native 8-bit state) provides the cross-architecture test.

**QMem staged QAT scaffold.** Quantization is hardened progressively: P1 float warm-up, then 4-bit candidate kernels (P2A), reset gate (P2B), update gate (P2C), biases (P2D), candidate activation (P2E), and finally the recurrent state (P2F, blended onto the 4-bit grid over 15 epochs), followed by P3 fine-tuning (170 epochs). Quantizers are 4-bit uniform symmetric (state grid Δ4 = 0.125, half-step 0.0625) with an asymmetric quantized tanh activation (QKeras).

**Post-training write-back interventions (weights frozen).** Each trained checkpoint is reconstructed and verified against its native implementation, then only the storage operator is swapped: (i) continuous identity propagation; (ii) deterministic B-bit rounding q_t = Q_B(h_t); (iii) error feedback (carry the discarded rounding error into the next quantization); (iv) k-bit quantized residual memory (compensated write-back); (v) k-bit direction memory (signed counter accumulates sub-threshold same-direction proposals and steps the stored state one grid level at threshold); (vi) stochastic rounding. The **recurrent write margin** M_{t,j} compares each proposed state change with the half-step of the quantizer; diagnostics include deadband fraction, state-change fraction, zero-write probability, completed same-direction run lengths, and per-unit occupancy (N_eff, occupied levels).

**Controls.** Encoder-only vs decoder-only 4-bit write-back localizes sensitivity; post-training precision sweeps (3- to 8-bit plus float) test whether finer storage helps a fixed solution; a matched-training campaign compares four stored-bit allocations per unit (4-bit state, 6-bit state, 4-bit + 2-bit residual, 4-bit + 2-bit direction memory) from identical initializations under a common specification with 3 runs each; paired bootstrap CIs (2,000 replicates) accompany the matched-storage comparisons.

## Results & Highlights

- **The headline causal result (frozen P2F checkpoint, 160,000-sample held-out test set):** deterministic 4-bit state write-back yields τ1/τ2 lifetime RMSE of **25.37/106.59 ns vs 0.36/0.35 ns under continuous identity propagation of the same weights** (~70x/300x worse); P3 fine-tuning afterwards recovers 0.49/0.55 ns, showing adaptation to the hard interface removes the failure. The QMem trajectory pins the transition: P2E (before state quantization) is at 1.40/3.03 ns.
- **Failure signature at P2F:** 99.59% of decoder state updates lie inside the 4-bit write boundary, only 0.25% of decoder state elements change stored level between successive steps, 97.25% of decoder steps change no hidden unit at all, and the median completed same-direction run lasts 132 of 134 live decoder write steps (90th percentile: 134). By contrast the native 4-bit model changes 1.24% of decoder state elements per step and stays accurate — persistence of suppressed sub-threshold updates, not their existence, marks failure.
- **Deployment-realistic case and frozen rescue (independently trained 8-bit reference GRU):** native 8-bit write-back reaches 0.20/0.22 ns; forced post-training deterministic 4-bit degrades it to 1.89/2.60 ns with a 99.40% decoder deadband fraction. On that same fixed checkpoint, error feedback recovers **0.34/0.46 ns**, 4-bit residual memory **0.34/0.45 ns**, and 4-bit direction memory **0.49/0.58 ns** — direction memory also shortens the median same-direction run from 132 to 6 steps and raises the decoder state-change fraction from 0.60% to 4.76%. Stochastic rounding rescues similarly (0.375/0.422 ns, Table S9) but is relegated to the supplement.
- **Precision is not monotonic:** the native 4-bit GRU is accurate at 0.35/0.40 ns and *worsens* to 0.43/0.57 ns when its state write-back is refined to 8-bit (continuous propagation 0.43/0.56 ns), while its median occupied levels rise from 12 to 176.5 per unit; the 8-bit reference is best near its native 8-bit (0.20/0.22 ns) and degrades on every coarser grid (4-bit: 1.89/2.60 ns, 3-bit: 9.98/6.83 ns).
- **Matched training:** on τ1, direction memory attains the best mean RMSE (0.30±0.03 ns) vs 0.41±0.03 (4-bit state), 0.48±0.16 (6-bit state), and 0.38±0.10 (4-bit + 2-bit residual), improving on both alternatives in all three matched runs; on τ2 the 6-bit and residual conditions are stronger — the paper explicitly concludes this establishes learned interface compatibility rather than a universal ranking.
- **LSTM cross-architecture replication:** native 8-bit 0.239/0.254 ns; deterministic 4-bit on both c and h: 3.857/1.327 ns (error feedback on both recovers 0.263/0.332 ns; continuous propagation does *not* recover, 3.50/1.54 ns). State-specific: c-only 4-bit is catastrophic (8.158/1.292 ns) with 79.43% deadband and 90th-percentile same-direction runs of 121/134 steps, while h-only — despite a larger 93.78% deadband — costs little (0.296/0.354 ns); targeted error feedback on c shortens the run to 4 steps and restores 0.257/0.280 ns.

## Authors & Credibility

All three authors are from the Department of Biomedical Engineering, Center for Modeling, Simulation, and Imaging in Medicine at Rensselaer Polytechnic Institute. **Xavier Intes** is a well-established figure in biophotonics and translational fluorescence/optical imaging; **Vikas Pandey** leads the Seq2Seq/Seq2SeqLite line of deep-learning FLI work on which this paper directly builds; **Ismail Erbas** (corresponding) is the first author. The team is domain-credible: the FLI task, PyFLI simulation pipeline, and teacher/student architectures come from their own prior work, and the study uses the published data partition rather than a newly constructed benchmark. The analysis culture is unusually careful for an application-domain group (bit-exact checkpoint reconstruction, paired bootstrap intervals, matched-seed training). Caveats: the quantization-side related work is cited thinly (~23 references, mostly FLI-domain plus a handful of QAT/QKeras items), there is no explicit code/data release statement in the main text (reproducibility rests on extensive supplementary methods S7–S10), and this is a single-group preprint without external validation.

## Critical Assessment

- **The headline number is taken at the most favorable instant.** The ~70x/300x collapse is measured at the P2F transition checkpoint — a network caught mid-hardening, before P3 fine-tuning adapts to the hard interface. The paper is transparent about this ("P3 shows how further optimization adapts to the hard interface"; P3 recovers 0.49/0.55 ns and the native-4-bit model never fails), but the abstract leads with the dramatic ratio, whereas the deployment-realistic scenario (independently trained 8-bit model forced to 4-bit) is a still-substantial but smaller ~10x/12x (0.20/0.22 → 1.89/2.60 ns).
- **Minor internal inconsistency:** the P2F identity-propagation τ2 RMSE is reported as 0.35 ns in the main text (consistent with the abstract's ~300x) but as 0.5320 ns in Table S9 — which would make the τ2 ratio ~200x, not 300x. This does not change the conclusion but suggests the headline was quoted from the more favorable figure.
- **Conceptual novelty is moderate.** The individual ingredients are classical: deadband loss from deterministic rounding, stochastic rounding and error feedback as standard remedies from low-precision training, residual/delta coding as ordinary signal-processing practice. The genuine contribution is the controlled causal attribution on a concrete task and the "learned interface compatibility" framing — valuable, but the paper positions itself against a thin slice of the quantization literature rather than the broader RNN/PTQ/stochastic-rounding body of work.
- **Practical payoff of the proposed operator is modest at adapted checkpoints.** In the matched-storage comparison (Table S6), the best direction-memory configuration improves lifetime RMSE by only −0.069/−0.101 ns over an 8-bit baseline (0.359/0.464 vs 0.428/0.565), and the paper concedes that matching stored bits "does not imply equality of arithmetic, logic, routing, energy, or hardware cost" — the auxiliary counters are extra sequential state on the critical recurrence path.
- **Scope is narrow:** one simulated task (synthetic mono/bi-exponential decays), two tiny models (6,627-parameter GRU; 32-unit LSTM), no real measured FLI data, and no experiments on architectures where state write-back actually dominates modern inference cost (transformer KV caches, SSM recurrent states), so the discussion's implications for those systems remain speculative. Only uniform symmetric state quantizers are analyzed; asymmetric, per-channel, or scaled state grids that would shrink the deadband are untested.
- **Strength of the positive side:** the causal design is exemplary — reconstructed checkpoints verified bit-exactly (max abs diff 0.0 on the LSTM native comparison), the held-out set never used for selection, 2,000-replicate paired bootstrap CIs with half-widths below 0.0012 ns, three matched training seeds per allocation, and honest reporting of non-monotonic precision sweeps and of the τ1/τ2 asymmetry in the matched campaign.

## Strengths

- Clean causal methodology: frozen weights, a single toggled variable (the storage rule), reconstruction-verified checkpoints, and paired statistics — the 70x/300x effect cannot be attributed to anything else.
- The mechanism is made measurable (recurrent write margin, deadband fraction, same-direction run lengths) and correctable in the same frozen network, which is much stronger than correlational accuracy-vs-bitwidth curves.
- The non-monotonic precision sweep and the c-vs-h LSTM dissection are genuinely non-obvious findings: deadband frequency alone does not predict damage, and finer state resolution can hurt a fixed recurrent solution.
- Cross-architecture replication (LSTM) and matched-seed training campaigns guard against GRU-specific and single-run artifacts.
- Exceptional reproducibility appendix (S7–S10: full training schedules, learning rates, optimizer rules, and equations S1–S47 covering every operator and diagnostic).

## Limitations

- Single simulated domain and tiny models; no real experimental FLI data, and no evidence yet that the write-deadband pathology matters for large-scale or transformer/SSM inference where the framing would be most consequential.
- The dramatic headline is anchored at a mid-hardening checkpoint; fully adapted models (P3, native 4-bit) show no failure, so the practical risk window is the post-training/coarse-state deployment scenario, not QAT done correctly.
- Direction memory's benefit over simply using more state bits is small at matched storage and comes with unquantified hardware overhead (extra registers and comparison logic per unit).
- Stochastic rounding — the classical fix for exactly this pathology — also rescues the failure (0.375/0.422 ns) but is only reported in the supplement and not discussed in the main text, missing an easy comparison point.
- No public code or data release statement; only uniform symmetric quantizers; the auxiliary-memory operators assume exact integer counters, leaving their behavior under noisy/leaky hardware unexamined.

## Relevance

这篇论文与你的"极端性能优化下的可靠性"核心方向高度契合：它刻画了一种教科书级的低精度推理静默失效——重构波形序列 MAE 仅 0.09、输出看起来正常，但寿命参数误差被放大数百倍——这正是 SDC 检测视角下"输出无害假象掩盖数值腐败"的算法级案例；其"状态存储接口兼容性是训练学出来的、精度提升可能反而有害"的结论，对 KV-cache/SSM 状态量化等现代低精度部署有直接警示价值。

## Questions for Further Exploration

- Does the write-deadband mechanism transfer to transformer KV-cache quantization and modern SSM recurrent states, where stored state is likewise re-read every step — and are the same run-length diagnostics usable there?
- At equal hardware cost, how does direction memory compare against stochastic rounding on real accelerators, given both rescue the failure but only one has a long engineering history?
- Would asymmetric, per-channel, or scaled state quantizers (which shrink the deadband without extra registers) eliminate the failure and make the memory operators unnecessary?
- Can the failure be detected at deployment time from cheap online signals — sequence MAE stayed at 0.09 while lifetime RMSE exploded by ~300x, so what observable (e.g., state-change fraction collapsing below ~1%) flags the deadband regime?
- Does the LSTM cell-state sensitivity (c-only 8.16/1.29 ns vs h-only 0.30/0.35 ns) replicate on real measured FLI data and on larger multi-layer models, or is it an artifact of this 32-unit distilled setting?
