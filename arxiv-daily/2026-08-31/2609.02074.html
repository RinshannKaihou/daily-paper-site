Attributing each outcome to planning vs execution before memorizing fixes credit distortion in self-evolving agent memory — and wins across four long-horizon benchmarks.

CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning ↗
Yongshi Ye, Tian Lan, Feihu Jiang, Muyang Ye et al. — Xiamen University · Alibaba Group 2026-08-31 self-evolving-agents agentic-planning memory-management credit-assignment

Key metric
129 vs 3,585

memories retained on τ²-bench vs outcome-based A-MapReduce — at higher accuracy. The baseline's accuracy peaks at 75% accumulation, then declines as unattributed memories flood the bank.

Why this matters

Training-free self-evolution via an external memory bank; the attribute-before-memorize principle maps directly onto research loops, separating hypothesis quality from experiment execution when judging success.

Critical edge

"Consistently outperforms" is an average-level claim only: A-MapReduce beats CHIME on BFCL-v4 with DeepSeek (eval 69.98 vs 67.15), and no standard deviations are reported anywhere.

Methodology 01

A frozen-policy agent adapts entirely through an external memory bank; the eval split runs with the bank frozen, measuring pure transfer of accumulated experience to unseen tasks.

  • Hierarchical memory bank — a planning bank (strategic experience: decomposition, dependencies, constraints) separate from an execution bank (operational: tool choice and calls). Each item = description key, distilled experience, value v ∈ [−1,1], reuse count.
  • Credit Attribution Gate — the frozen policy's structured self-reflection over task, plan, trajectory, and retrieved memories: outputs a label {planning, execution, both, none}, confidence γ, a misleading-memory set, and new experience.
  • Credit-aware evolution — only the attributed bank updates: attributed success +γ, misleading memory −γ; reused-but-low-value memories are pruned; new experience merges, inserts (value-neutral, must earn value through reuse), or is discarded.
  • Two-stage retrieval — similarity Top-N, then value-reranked Top-K, with κ-shrinkage for rarely reused memories and a β-clip so value modulates but never dominates similarity.
  • Setup — τ²-bench, VitaBench, BrowseComp-ZH, BFCL-v4 × Qwen3.5-Flash and DeepSeek-V4-Flash (same model as planner, executor, and gate); 7:3 train/eval stream split, Avg@3 over three orderings, temperature 0.

  • Memory quality (external GLM-5.2 judge): 81.20% correctness vs A-MapReduce's 36.08%, 93.60% non-redundancy; removing the Attribution Gate collapses correctness to 37.09%.
  • Value scores track utility: accuracy rises monotonically with memory value, 21.7%→50.8% for planning vs 23.7%→35.4% for execution — the planning gain (29.1 pts) is ~2.5× the execution gain.
  • Gate reliability: attribution labels stable in 87.8–97.9% of repeat samples; replaying failed episodes with only the generated memory rescues 56.3–67.6% of attributed failures.
  • Stronger gate buys accuracy: swapping the gate to Qwen3.7-Flash lifts eval scores +3.12 (τ²-bench), +2.50 (VitaBench), +2.25 (BFCL-v4).
  • Cross-backbone transfer: CHIME's transferred memory wins all four settings by 2.25–4.68 pts — A-MapReduce's transfer actually hurts (−2.73) on one; CHIME's transferred bank even beats its self-accumulated one (26.40 vs 25.92).
  • Ablations: removing execution memory −4.81, planning memory −3.26, shared single bank −3.60, evolution −3.04, gate −2.44, credit rerank −2.04; anomaly: removing all memory (31.74) beats removing one bank (30.06).
  • Honest losses: CHIME loses BFCL-v4 to A-MapReduce on DeepSeek (train 65.89 vs 69.18) and, on VitaBench-train/Qwen, the no-gate ablation (17.02) edges full CHIME (16.19).

Strengths 03

  • Crisp, correct diagnosis of a real failure mode — outcome–plan conflation — that applies to the whole outcome-based self-evolving memory family, with a minimal principled fix: attribute first, memorize second.
  • The efficiency result is striking and well-instrumented: 129 vs 3,585 memories at higher accuracy, with the baseline's post-75% decline as direct visual evidence for the mechanism.
  • The value–utility analysis (monotonic accuracy across value terciles) shows the learned value scores actually mean something, not an unused knob.
  • Six-RQ analysis including gate reliability and credit-model scaling is unusually thorough for this paper class.
  • Honest reporting: baseline wins bolded in tables, clean comparable protocol (same runtimes, tools, verifiers for all methods).

Limitations 04

  • Only two Flash-tier backbones, each serving every role; the "planning memories ~2.5× more useful" claim is unverified at other model scales.
  • No variance reporting; single-run RQ5; LLM-judge quality metrics unvalidated against human labels; domains truncated to the smallest size, shrinking eval sets.
  • Four-way attribution is coarse for cascaded failures; the gate adds noise when the backbone's introspection is weak — exactly where CHIME loses to A-MapReduce.
  • Nine tuned thresholds with no sensitivity analysis in the main text; the per-episode attribution call's token/cost overhead is never quantified.
  • Code not yet released — reproduction currently requires re-implementing the load-bearing gate prompt from the appendix.

Questions for Further Exploration 05

  1. How sensitive are results to θ_conf, θ_merge, n_min, θ_prune, and β̂ — and does the gate's confidence calibrate consistently across backbones, given acceptance requires γ ≥ 0.5 from a model grading its own plan?
  2. Why does removing all memory (31.74) outperform removing just the execution bank (30.06) — cross-bank interference, or unreported run variance?
  3. Can a four-way label set handle cascaded failures (an early execution error later surfacing as a planning mistake), and would per-step credit decomposition beat episode-level attribution?
  4. What is the wall-clock and token overhead of attribution per episode — and does the 129-vs-3,585 efficiency gain survive when A-MapReduce gets the same reflection budget?
  5. Does the planning-over-execution value gap (~2.5×) hold at larger backbone scale, or is it an artifact of Flash-tier planners needing more strategic guidance?
  6. Can attribute-before-memorize transfer to self-evolving scientific-research loops, where hypothesis quality and experiment execution conflate in exactly the same way?
