Writing the optimizer's beliefs into a calibrated Markdown world model beats a one-line-different vanilla control on held-out passrate across all five benchmarks.

Belief-Calibrated Optimization: An Explicit World Model for Agentic Optimization ↗
Yuhan Chen, Zhihua Tian, Mahavir Dabas, Charith Peris et al. — Virginia Tech · Amazon 2026-08-31 agentic-optimization world-model belief-calibration self-evolving-agents

Key metric
+0.152

GAIA held-out passrate over the matched vanilla control (0.495 vs 0.343) — the largest of five benchmark wins, all favoring BCO.

Why this matters

For self-evolving agents: optimizers can accumulate reliable environment knowledge across long self-improvement runs instead of re-inferring it from raw traces every round — and it can even cut proposer tokens.

Critical edge

The TB2.0 win rests on a re-screened split — on the original split BCO scored below the initial scaffold (0.463 vs 0.470), a disclosed post-hoc-selection risk on one of the five supporting benchmarks.

Methodology 01

A coding-agent proposer iteratively edits the scaffold around a frozen target model. Hill-climbing on a finite train set invites the optimizer's curse; an explicit environment model is the antidote.

  • World model as a Markdown file — world_model_calibration.md holds atomic beliefs: falsifiable claim, conditions, confidence, status (hypothesis/confirmed/refuted), evidence paths into stored traces, and mass ≈ failures explained.
  • Two belief kinds — execution beliefs (how an edit changes behavior) vs evaluation beliefs (when the grader itself is unreliable). Document starts empty; pre-seeded guesses forbidden; refuted beliefs persist in an append-only history.
  • Predict–observe–correct loop — before evaluation the proposer must write prediction.md; afterwards the prediction is graded against raw traces (never the agent's own final message), then beliefs are Added / Revised / Merged / Removed.
  • Matched control — vanilla and BCO proposers differ by exactly one include line: a 169-line calibration module. Same scaffold, evidence surface, target model, data splits, and iteration budget.
  • Protocol — five benchmarks across four task families (memory QA, tool-use QA, code-as-action, terminal agents); reported number is held-out passrate of each method's top train-frontier candidate.

  • Target swap to unseen gpt-5.6-luna: BCO ranks first on all GAIA effort tiers (high: 0.657 vs 0.475), but is last on AppWorld's full set (0.516 vs 0.685) — unbounded scratchpad reinjection overruns context on 99/372 tasks.
  • Content beats format: offline ablation orders None < Scrambled < Intact on every measure — downside precision 0.142 / 0.181 / 0.217 — so the gain lives in the document's content, not its shape.
  • Token accounting: proposer tokens fall on LME (−27.4%), LoCoMo (−24.7%), GAIA (−12.4%); rise on AppWorld (+5.2%) and TB2.0 (+26.2%). Raw-trace reads drop 20–69% everywhere — savings start within 10 iterations.
  • Free-form notes don't replicate it: persistent uncalibrated memory scores 0.427 vs BCO 0.467 on LME train — though the authors flag this ablation as underpowered.
  • Disclosed diagnostics: Spider2-lite was excluded after 43.3% of held-out tasks received both a pass and a fail across identical-scaffold repeats.

Strengths 03

  • The cleanest ablation design in this literature: the two methods differ by exactly one include line, so the effect is attributable to the calibration protocol itself.
  • Intact / Scrambled / None ablation holds length, format, and vocabulary fixed while falsifying content — isolating what is written from that something is written.
  • Exceptional reporting hygiene: full candidate-level tables, an excluded benchmark, a failed original split, and explicit admissions when statistics can't support a claim.
  • Token analysis tests and partially refutes the "just more prompting" hypothesis, with a write-vs-read decomposition explaining when BCO is cheaper.
  • Breadth with structure: five benchmarks, four genuinely different task families, standard per-benchmark graders rather than one custom harness.
  • The AppWorld context-overrun failure is itself a transferable lesson about scaffolds overfitting one target's verbosity.

Limitations 04

  • One trajectory per method per benchmark — consistency across environments, not statistical significance within any one; the smaller gaps (+0.022, +0.030) sit inside the paper's own measured dispersion (0.07–0.13).
  • TB2.0's train split was re-screened after inspecting initial-scaffold behavior; the original split showed no gain — a disclosed post-hoc-selection risk.
  • Memory rows are best-of-three with selection partly on the held-out split (disclosed, symmetric, but not selection-free).
  • No external optimizer baselines: AFlow, ADAS, DSPy are discussed but never run.
  • The world model is a heuristic natural-language summary, not a statistically calibrated posterior; no mechanism detects target or tool drift mid-run.
  • BCO can overfit the target's resource envelope — the AppWorld swap caused 99/372 non-completions, and resource use is not scored alongside passrate.

Questions for Further Exploration 05

  1. Does the world model transfer across optimization trajectories — can it warm-start a fresh run, or is it disposable once its run ends (explicitly untested)?
  2. Would the smallest gains (TB2.0 +0.022, AppWorld +0.030) survive 3+ seeds per method, given measured run-to-run dispersion of 0.07–0.13?
  3. Can the calibration protocol add a resource-envelope score to avoid AppWorld-style context overruns under target swaps — e.g., optimizing against multiple targets at once?
  4. Scrambled beat None on upside hit rate (0.460 vs 0.441): how much of the gain comes from structure (forcing falsifiable claims) versus calibrated content?
  5. When the environment genuinely drifts — tool API changes, mid-run model updates — does the append-only history of refuted beliefs discount stale evidence or anchor the proposer to an outdated world model?
  6. Do the gains persist with a weaker proposer — is the 169-line calibration module's benefit contingent on a frontier-level proposer following it faithfully?
