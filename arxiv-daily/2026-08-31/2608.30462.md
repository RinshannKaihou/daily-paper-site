> **一句话总结：** 作者提出一个基于稀疏自编码器（SAE）的跨语言特征迁移框架：对比模型在英语/西语（高资源）答对、而在韩语/泰语/斯瓦希里语/越南语（低资源）答错的同一批问题，用 per-token SAE argmax 频率差 + 秩窗口过滤筛出"任务相关且跨语言共享"的稀疏特征，再在推理时于第 20 层残差流注入 steering 向量——不训练、不翻译、不改变输出语言，就把 Gemma-2-9B-it 与 Qwen2.5-7B 在 MATH500/MGSM/MMLU-ProX 心理学子集上的低资源语言推理差距恢复了约 25–33%，且在 12 组对比中 11 组优于 CAA 基线。

> **TL;DR:** LLMs solve math/logic problems reliably in English or Spanish but fail on the same question in Korean, Thai, Swahili, or Vietnamese. This paper tests the hypothesis that the gap is *under-elicitation* of shared reasoning features rather than missing knowledge. Using SAEs on layer-20 residual activations, it mines features that fire as per-token argmax during English/Spanish successes but never in matched target-language failures (set-difference + rank-window filtering), then injects their decoder directions with strength α during target-language generation. On **MATH500**, Gemma-2-9B-it Korean accuracy rises **49.20 → 52.41 (+3.21 pts, closing 41% of the gap to English's 56.91)**; across the four (reference, benchmark) settings the intervention recovers **25–33%** of the gap, beating the **CAA** steering baseline in **11 of 12** settings — while steering with top-frequency features actively *hurts* (Thai 45.98 vs 48.23 baseline) and GlotLID confirms output stays in the target language (37/40 settings change <1.5 pp).

## 核心贡献

- **把跨语言推理差距归因到特征欠激发（under-elicitation）**：假设高资源语言（HRL）更可靠地激活任务相关的潜在计算（符号分解、逐步算术），低资源语言（LRL）表达同一任务但激活更弱；并用干预实验给出因果证据，而非仅停留在观测相关性。
- **对比式 SAE 特征挖掘**：构造配对对比集（同一问题 HRL 答 对 / LRL 答 错），对每条推理轨迹记录 per-token SAE argmax 特征频率，取"参考侧出现、目标侧不出现"的差集；再按出现频率排序丢弃前 50%（通用生成模式）、保留 50–90 分位的秩窗口，过滤掉与推理内容无关的特征。
- **免训练、免翻译的残差 steering**：以参考语言正确轨迹的平均 SAE 激活差 w_f = z̄^(en) − z̄^(lrl) 为系数，推理时在单层（layer 20）残差流对选中特征集 C 注入 Δh = α·Σ w_f·W_dec[f]，仅作用于生成 token，prompt prefill 不变。
- **三重因果检验范式**：partial sufficiency（激活 C 应提升 LRL 准确率）、functional necessity（在 HRL 推理中抑制 C 应损害 HRL）、specificity（匹配随机/排除特征对照不应复现效果），并以 GlotLID 验证输出语言未被切换。
- **机制发现**：EN→KO 特征池中 28 个特征仅 3 个为英语 token 专属，25 个在两种语言中同时激活且对应共享推理概念（数量、需求、等式、聚合等），但在韩语 token 上峰值激活系统性更低（如特征 13089 英语 63.6 vs 韩语 25.0/28.0）——直接支持"欠激发"假说。

## Key Contributions

- A causal, intervention-based account of cross-lingual reasoning gaps: language modulates *which internal computations get elicited*, not just surface form; the gap is framed as partial under-activation of computations the model already possesses.
- A contrastive feature-discovery procedure using paired reference-correct / target-incorrect traces: per-token SAE argmax frequency set-difference, plus rank-window filtering (drop the top 50% most frequent candidates as generic generation patterns, keep ranks 50–90%) to isolate task-relevant, language-shared latents.
- A training-free, translation-free residual-stream steering intervention at a single layer (layer 20), applied only at generation tokens, with the reference-language accuracy serving as the ceiling and a formally defined recovery rate (fraction of the reference-language gap closed).
- A three-test interventional evaluation template — partial sufficiency, functional necessity, specificity — with matched-random and excluded-feature controls, plus a GloTLID-based check that gains are not explained by switching the output language.
- A mechanistic finding that the steered features are largely language-agnostic (25/28 activate in both English and Korean, encoding shared concepts like quantity, requirement, equality) and activate more weakly on Korean tokens, quantifying the activation gap.

## Methodology

**Setup.** Two instruction-tuned decoder-only models paired with pretrained SAEs at layer 20: Gemma-2-9B-it with the canonical Gemma Scope residual SAE (width 16k, d_sae = 16,384, JumpReLU) and Qwen2.5-7B-Instruct with the matryoshka layer-20 SAE (d_sae = 65,536, k = 100). SAE activations computed in float32; greedy decoding (max 1,024 new tokens); math answers scored with math_verify, MMLU-ProX with a letter parser. Experiments ran on 4 NVIDIA H100s (one GPU per job).

**Step 1 — contrastive feature identification.** For a benchmark D, build the paired contrast set P_{b→a} = {i | reference-language trace correct ∧ target-language trace incorrect} (Eq. 3). For each trace, record the strongest-activating SAE feature (argmax over the F latents) at every generation token, then count per-side feature frequencies c_b, c_a. The candidate pool keeps features present in reference-correct traces but absent from matched target-incorrect ones: C_cand = {f | c_b ≥ 1 ∧ c_a = 0} (Eq. 6). Because the most frequent candidates tend to be generic generation patterns, features are ranked by c_b and only the rank window between the 50th and 90th percentile is retained (Eq. 7).

**Step 2 — steering.** For each language k, compute the mean SAE activation vector z̄^(k) over all tokens of correctly solved traces (Eq. 8). Each selected feature gets a steering coefficient w_f = z̄_f^(b) − z̄_f^(a) — how much more strongly it expresses in the reference language on successful reasoning (Eq. 9). At inference on target-language inputs, the layer-ℓ residual h is encoded to z, selected latents are bumped z̃_f = z_f + α·w_f for f ∈ C (α > 0 controls strength), and the decoded difference Δh = Dec(z̃) − Dec(z) = α·Σ_f w_f·W_dec[f] is added via a forward hook at generation tokens only; the prompt prefill is untouched (Eqs. 10–11). No parameters are updated, no translation is used, and the user-facing language is unchanged. Recovery is Recovery_{a→b} = (acc_{a→b} − acc_a)/(acc_b − acc_a) (Eq. 12).

**Causal evaluation.** Three tests: (i) *partial sufficiency* — activating C should improve target-language accuracy (Eq. 13); (ii) *functional necessity* — suppressing C during reference-language inference should degrade reference accuracy (Eq. 14, implemented as anti-steering with −Δh); (iii) *specificity* — matched random features and excluded features, or generic residual perturbation of the same magnitude, should not reproduce either effect. The design estimates natural indirect effects but does not claim counterfactual sufficiency/necessity in the formal sense.

**Experiments.** Benchmarks: MATH500 (multilingual split, N = 311), MGSM (N = 250), and the psychology subset of MMLU-ProX (N = 798, 10-way multiple choice). Native-language chain-of-thought prompting in a single language. Reference languages: English and Spanish; target LRLs: Korean, Thai, Swahili, Vietnamese (plus Bengali and Telugu in the appendix). All interventions at layer 20; appendix sweeps layers 4, 12, 34, 38.

## Results & Highlights

- **Headline (Table 1):** steering closes **25–33% of the reference-language gap** across the four (reference, benchmark) settings. Concretely, on MATH500 with English reference, Gemma-2-9B-it improves Korean **49.20 → 52.41** (+3.21 pts, **41%** of the 7.71-pt gap to English's 56.91) and Vietnamese **48.23 → 51.77** (+3.54 pts, **42%** of gap); on MGSM (English ref) Thai rises **78.40 → 82.40** (**36%** recovery) and Swahili **75.60 → 79.20** (**26%**).
- **Qwen2.5-7B, Spanish reference, MATH500:** Thai **60.77 → 63.34** (36% recovery), Korean **64.95 → 65.90** (33%), Vietnamese **63.67 → 66.56** — recovering **69%** of the 4.18-pt gap to Spanish's 67.85, the largest per-cell recovery in Table 1. On MGSM, Spanish→Korean recovers **55%** of the gap (79.60 → 82.00).
- **Controls (Table 2, Gemma, MATH500, English ref):** steering with the top-k most frequent candidate features actively *degrades* accuracy (Thai **45.98** vs 48.23 baseline); the negative steering vector (−Δh) drops target-language accuracy below baseline (Thai 46.62, Vietnamese 46.95), while suppressing the selected set C during *English* inference cuts English MATH500 from 56.91 to **54.02** vs **55.16** for matched-random suppression — both intervention directions go the way the under-elicitation hypothesis predicts.
- **CAA comparison (Table 6):** the SAE method beats Contrastive Activation Addition in **11 of 12** settings — e.g., MATH500 EN→TH: CAA **46.95** (below the 48.23 baseline) vs ours **49.20**. The single exception is MGSM EN→SW, where CAA (80.00) slightly edges ours (79.20).
- **Output-language consistency (Table 4, GloTLID):** the target-language proportion of generated output changes by **<1.5 percentage points in 37 of 40 settings** (avg abs change 0.8 pp, median 0.41 pp) — gains come from better reasoning *within* the target language, not from silently answering in English/Spanish.
- **Unseen targets (Tables 7–8):** on MGSM/Gemma, pair-specific steering lifts Bengali **75.6 → 81.2** (40% recovery) but Telugu only **74.4 → 75.6** (8%); reusing EN→KO or EN→TH feature sets on BN/TE still beats baseline (78.8 / 74.8) while pair-specific extraction remains best — each language under-elicits a partially different feature subset.
- **Layer sweep (Table 5):** layer 20 is strongest overall on MGSM (TH 82.4, SW 79.2 vs baseline 78.4/75.6), though Korean actually peaks at layer 12 (79.2); all tested layers (4–38) improve over baseline.
- **Feature analysis (Table 3):** in the 28-feature EN→KO steering pool, only 3 features are English-token specific; the rest activate in both languages on shared reasoning concepts (e.g., feature 13089 "requirement/needs": peak 63.6 in English vs 25.0/28.0 in Korean) — a 2–5× activation gap consistent with under-elicitation.
- **Unevenness:** on MMLU-ProX (psychology) Gemma's gains are largest for Thai (27.71 → 33.30, 19% recovery) but near zero for Swahili (10.27 → 10.30, ~0%), and Qwen's Swahili MGSM baseline is only 15.20.

## Critical Assessment

- **The specificity control does not fully separate on every target.** In Table 2 (MATH500, English ref, Gemma), matched *random* steering lifts Vietnamese to **52.30 — slightly above the contrastive set's 51.77** — so on one of four targets, a random same-magnitude perturbation recovers as much of the gap as the carefully mined features. The "task-specific features" narrative is strongest for Korean/Thai and weakest for Vietnamese in this table, which the main text does not dwell on.
- **The functional-necessity evidence is directionally right but thin.** Suppressing C during English inference drops MATH500 accuracy to 54.02, but matched-random suppression alone drops it to 55.16 — only ~1.1 pts of separation. A skeptical reading is that much of the "necessity" effect is generic residual disruption.
- **The headline 25–33% is an average over very heterogeneous cells.** Per-setting recovery ranges from ~0% (Gemma, MMLU-ProX, Swahili: 10.27 → 10.30) to 69% (Qwen, Spanish→Vietnamese MATH500). Qwen's Swahili MGSM baseline of **15.20** is near-random, so the reported +6% recovery there is measured in an essentially failed regime and says little. The abstract's range should be read with this spread in mind.
- **Missing ablations.** All ~28 selected features are pooled into a single steering vector; there is no feature-subset ablation (e.g., does the "equality" feature alone account for most of the gain?), no α-sensitivity analysis in the material reviewed, and the layer sweep (appendix) shows all layers 4–38 help — suggesting a broad-band effect rather than a localized circuit, which weakens the strongest mechanistic reading.
- **Scale and generality.** Only two mid-size instruct models (9B/7B), three benchmarks dominated by math, four target languages (+2 in the appendix). The authors themselves flag that generalization to larger models, other reasoning domains (commonsense, code), and truly extremely low-resource languages is unverified — appropriate hedging, but it caps the significance of the claim.
- **Novelty is real but incremental over known context.** The English-centric latent-space picture was already established (Wendler et al. 2024; Etexaniz et al. 2024); the contribution here is converting that observational story into a causal, feature-level intervention — a good, executable idea rather than a new phenomenon.
- **Reproducibility is strong:** public models, public SAEs, deterministic contrast-set construction, full hyperparameter and hardware disclosure. One friction point: the Qwen SAE required a manual configuration shim to load via sae_lens, which other groups will need to replicate.

## Strengths

- A clean, reusable interventional template (partial sufficiency / functional necessity / specificity) that upgrades a well-known observational finding into causal evidence — no training, no translation, no change to the user-facing language.
- Negative controls are actually run and honestly reported, including a condition where a member of the method's own family (top-k frequency steering) *hurts* performance (Thai 45.98 vs 48.23 baseline).
- The GloTLID output-language audit directly rules out the trivial "model quietly answers in English" explanation, a check many multilingual steering papers skip.
- Real interpretability payoff: concrete shared features (quantity, requirement, equality, aggregation) with quantified cross-language peak-activation gaps (2–5× lower on Korean), giving the under-elicitation claim mechanistic content rather than hand-waving.
- Beats a reasonable, fairly implemented baseline (CAA) in 11/12 settings and generalizes to unseen targets (Bengali, Telugu) with preserved target-language generation.

## Limitations

- Coverage: two instruction-tuned models, three benchmarks, four (+2) target languages; no 70B+/frontier models; mostly mathematical reasoning plus one psychology subset. Cross-task transfer (features mined on one benchmark improving another) is explicitly not tested and may fail if reasoning mechanisms are not shared across task distributions.
- Dependence on externally pretrained SAEs at a single layer (20): the feature library's resolution and the steering's effectiveness are bounded by SAE quality; polysemantic or under-trained latents can dilute the contrastive signal.
- Modest and uneven effect sizes: 67–75% of the reference-language gap remains on average; several cells show ~0–5% recovery (e.g., Swahili MMLU-ProX on Gemma), and the method's advantage over random steering is not uniform across targets.
- The intervention adds a per-generation-token SAE encode/decode; no inference-cost or latency analysis is provided.
- Contrast-set construction conditions on model-specific success/failure patterns, so feature sets are pair- and model-specific — each new (model, language pair, benchmark) combination requires re-mining.

## Relevance

这篇是典型的 LLM 隐状态与机制可解释性工作：用 SAE、对比特征挖掘和残差流因果干预（steering/ablation）把"跨语言推理差距"定位到具体稀疏特征及其激活强度差异，与用户对 mechanistic interpretability / SAE / 内部表征的兴趣高度吻合；其"配对成功-失败轨迹做对比特征挖掘 + 三重因果检验"的方法论对其他内部机制研究也可直接复用。

## Questions for Further Exploration

- Does the contrastive feature set transfer across *tasks* (e.g., features mined on MATH500 improving MGSM or code reasoning), or is the discovered feature subset benchmark-bound as the authors suspect?
- How sensitive is the recovery rate to the steering strength α, the SAE width, and the rank-window (50–90%) choice — and could per-layer feature sets (layers 4–38 all helped) be combined to push beyond the 25–33% ceiling?
- Is there a compact core subset among the 28 selected features that drives most of the gain, or is the effect irreducibly distributed across many weakly-activating features?
- Does the under-elicitation account hold for frontier-scale models with much stronger multilingual pretraining, where the HRL–LRL gap is smaller and possibly differently mechanized?
- Could the paired correct-in-context-A / incorrect-in-context-B contrastive mining be generalized to non-linguistic reliability failures (e.g., silent numerical corruption or degraded hardware conditions), where the same computation succeeds or fails across runs?
