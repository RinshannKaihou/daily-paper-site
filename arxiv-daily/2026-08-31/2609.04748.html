Same Request, Different Answer: Quantization Amplifies Cache-Induced Divergence in LLM Serving

量化放大LLM服务中缓存引起的分歧

Aditi Patodiya · 2026-09-04 · independent researcher, IEEE Senior Member
llm-serving prefix-caching quantization reproducibility inference-reliability

Key Metric

36.2% → 77.5%

Cross-arm agent-trajectory divergence as weights go F16 → Q3_K_M (Qwen2.5-7B on llama.cpp, caching on; Cochrane-Armitage p = 1.3×10⁻⁸).

Why This Matters

Same request, same seed, different answer: caching silently reroutes LLM agent runs — evaluations that ignore cache state aren't measuring what they think.

Critical Edge

The amplification claim outruns the data at the coarse end: Q4_K_M and Q3_K_M intervals overlap, and a two-point grid cannot separate amplifier from plateau.

Methodology

Setup — llama.cpp b10434 (GGUF F16→Q3_K_M) · vLLM 0.11.0 (FP16) · Qwen2.5-7B/14B, Llama-3.1-8B · 1× RTX 4090 · CUDA 12.6

  • Paired within-arm design. Every configuration runs the full 80-episode workload twice; the cache-disabled rerun doubles as an internal validity check — any difference there would expose an uncontrolled confounder.
  • Everything else frozen. Greedy decoding, temperature 0, seed 42, batch size 1, serial requests; KV cache held at 16-bit so cache precision never co-varies with weight format.
  • Two workloads. BFCL multi-turn base (80 episodes, ~7–13 requests each — exactly the shape prefix caching accelerates) plus a GSM8K bridge where each item is served four times, twice per path, so a flip only counts when each path agrees with itself.
  • Three isolation experiments. Execution-order arm; disabling llama.cpp's server-level host-memory prompt cache (default-on, 8192 MiB, since Oct 2025); a cache-state restore control with cold state verified from cached-token telemetry.
  • Strict measures. Divergence on emitted token identifiers (reworded-identical answers still count); Wilson intervals, moving-block bootstrap, exact McNemar, 81% power against a 1-point shift.

  • Bit-identical baseline (RQ1). 0 of 800 episodes diverged across ten configurations — per-episode 95% upper bound 1.6%, pooled 0.5%.
  • The real culprit (RQ2). A single flag — disabling the host-memory prompt cache — moves re-run divergence 38.8% → 1.2%; with cache state restored, both paths reproduce 40/40 yet still differ on 14/40. Deterministic given cache state; irreproducible in practice because that state is invisible and never reset.
  • Instability without direction (RQ5). GSM8K flips split 13 cached-favor vs 7 recompute-favor (McNemar p = 0.26); aggregate accuracy flat at 89–93%.
  • One token propagates. At 16-bit, 3.5% of single requests diverge vs 36.3% of ~10-request agent episodes.
  • Self-caught artifact. The original scorer mis-scored 11–38% of responses on format alone, inflating flips ~4×; corrected figures reported and shipped in the artifact.

Strengths

  • Cleanest published determinism baseline: 0/800 bit-identical episodes turns the whole paper into a controlled experiment — every later divergence is cache-attributable.
  • Causal isolation done with experiments, not arguments: order → second cache layer → cache state, including the restore control.
  • Discovery with practical bite: llama.cpp's default-on host-memory prompt cache is a hidden divergence source a single flag removes.
  • Instrument-grade honesty: self-caught scorer bug, wider bootstrap interval reported, explicit refusal to claim degradation the data cannot support.
  • Actionable guidance: evaluations should record engine, version, and cache configuration; engines should report per-request cache exposure.

Limitations

  • Narrow scope by design: three 7–14B open models, one RTX 4090, two engines, one agentic benchmark — nothing on frontier models, hosted endpoints, or multi-tenant load.
  • Outcome half underpowered: the agentic success floor (1.2–18.8%) leaves 12-vs-7 flips; the directionality conclusion rests on the GSM8K bridge.
  • Residual confounds, disclosed but unresolved: first grid ran with the second cache layer at default; vLLM arms launched by different scripts; some cells run once.
  • Strict criterion overstates semantic change: token-identifier divergence flags identical answers in different words; the quality-side arm is the underpowered half.
  • No intervention evaluation: batch-invariant kernels are discussed but never tested; the throughput cost of "pin configuration + reset state" is unknown.

Questions for Further Exploration

  1. Would batch-invariant kernels eliminate cross-arm divergence entirely at Q3_K_M, or does quantization-era logit crowding make some divergence unavoidable?
  2. How does the effect behave under realistic multi-tenant load, where eviction and concurrent batching interact with the host-memory prompt cache?
  3. Does "instability without direction" hold for reasoning models with long chain-of-thought, where one early flip can compound instead of washing out?
  4. Can per-request cache-exposure telemetry become a runtime detector on vLLM — e.g., prompt-hash fingerprinting at the proxy layer?
  5. Amplifier or plateau? A denser quantization grid (Q6_K, Q5_K_M, Q2_K) plus logit-margin instrumentation could separate margin compression from saturation.
