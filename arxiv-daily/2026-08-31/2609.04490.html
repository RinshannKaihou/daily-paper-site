Why This Matters 为何重要

A textbook silent failure: outputs look normal while parameters corrupt ~300× — a direct warning for KV-cache and SSM state quantization.

教科书级静默失效：重构波形 MAE 仅 0.09、输出看似正常，寿命参数误差却被放大数百倍——对 KV-cache / SSM 状态量化的直接警示。

Critical Edge 批判视角

The 70×/300× headline is captured mid-hardening, before fine-tuning adapts — fully adapted models never fail, and the deployment-realistic collapse is ~10×/12×.

戏剧性比值取自硬化中途的 P2F 检查点——完全适配的模型并不失效；贴近部署场景（8-bit 模型强转 4-bit）的劣化为 ~10×/12×。

Methodology

Causal isolation: freeze everything, toggle one variable — the storage operator.

  • Task. Fluorescence lifetime imaging inference: estimate τ1/τ2 lifetimes from 135-bin high-noise decay signals (PyFLI simulation; 1.6M signals, 80/10/10 split, 160,000-sample held-out test). Model: Seq2SeqLite, a 32-unit GRU encoder–decoder with 6,627 parameters, distilled (α = 0.6) from a 128-unit teacher; lifetimes read out by trapezoidal integration; RMSE (ns) is the primary metric. An independently trained 32-unit LSTM covers cross-architecture.
  • QMem staged QAT scaffold. Quantization hardens progressively — float warm-up → candidate kernels → reset gate → update gate → biases → activation → finally the recurrent state (P2F, blended onto the 4-bit grid over 15 epochs) → P3 fine-tuning. Grid: 4-bit uniform symmetric, Δ = 0.125, half-step 0.0625.
  • Frozen-network interventions. Only the storage rule is swapped: continuous identity, deterministic B-bit rounding, error feedback, quantized residual memory, direction memory (a k-bit signed counter accumulates same-direction sub-threshold proposals and steps the stored state one grid level at threshold), and stochastic rounding. The recurrent write margin Mt,j flags each discarded update (M < 1 = inside the half-step deadband).
  • Controls. Encoder-only vs decoder-only localization; 3–8-bit post-training precision sweeps; a matched-training campaign (4 stored-bit allocations × 3 seeds); paired bootstrap CIs from 2,000 replicates; bit-exact checkpoint reconstruction.

Frozen rescues — no retraining, same weights

  • Error feedback recovers 0.34/0.46 ns; 4-bit residual memory 0.34/0.45 ns; direction memory 0.49/0.58 ns — direction memory also shortens the median same-direction run from 132 to 6 steps and raises state-change fraction from 0.60% to 4.76%. Stochastic rounding rescues too (0.375/0.422 ns) but is relegated to the supplement.
  • Precision is not monotonic. The native 4-bit GRU worsens from 0.35/0.40 ns to 0.43/0.57 ns when its state is refined to 8-bit — while occupied levels per unit rise from 12 to 176.5. Finer storage can hurt a fixed recurrent solution.

Strengths 优势

  • Clean causal methodology: frozen weights, one toggled variable, bit-exact reconstruction-verified checkpoints, paired statistics — the 70×/300× effect cannot be attributed to anything else.
  • The mechanism is made measurable and correctable in the same frozen network (write margin, deadband fraction, run lengths) — much stronger than correlational accuracy-vs-bitwidth curves.
  • Genuinely non-obvious findings: deadband frequency alone does not predict damage, and finer state resolution can hurt a fixed solution.
  • Cross-architecture replication (LSTM) and matched-seed training campaigns guard against GRU-specific and single-run artifacts.
  • Exceptional reproducibility appendix: full schedules, optimizer rules, and equations S1–S47 covering every operator and diagnostic.

Limitations 局限

  • Single simulated domain, tiny models: no real measured FLI data, and no evidence yet that the pathology matters for large-scale transformer KV-cache / SSM inference where the framing would be most consequential.
  • The dramatic headline is anchored at a mid-hardening checkpoint; fully adapted models (P3, native 4-bit) show no failure — the practical risk window is post-training / coarse-state deployment.
  • Direction memory's edge over simply using more state bits is small at matched storage (−0.069/−0.101 ns vs 8-bit) and carries unquantified hardware overhead on the critical recurrence path.
  • Stochastic rounding — the classical fix for exactly this pathology — also rescues the failure but appears only in the supplement, missing an easy comparison.
  • No public code/data release statement; only uniform symmetric quantizers tested; auxiliary-memory operators assume exact integer counters — noisy or leaky hardware unexamined.

Questions for Further Exploration

From the summary's closing section

  • Does the write-deadband mechanism transfer to transformer KV-cache quantization and modern SSM recurrent states — and do the same run-length diagnostics work there?
  • At equal hardware cost, how does direction memory compare against stochastic rounding on real accelerators?
  • Would asymmetric, per-channel, or scaled state quantizers — which shrink the deadband without extra registers — make the memory operators unnecessary?
  • Can the failure be caught at deployment from cheap online signals (e.g., state-change fraction collapsing below ~1%) while sequence MAE still reads 0.09?
  • Does the LSTM cell-state sensitivity (c-only 8.16/1.29 ns vs h-only 0.30/0.35 ns) replicate on real measured data and larger multi-layer models?
