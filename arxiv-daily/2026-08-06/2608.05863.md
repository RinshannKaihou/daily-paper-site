> **一句话总结：** 本文针对现代 LLM 服务中异构注意力记忆（密集 KV / 潜在 KV / 稀疏选择器 / 循环状态）提出一套"带类型的可观测性契约"平台 WitCert：将每类记忆抽象为 update/select/read 三个算子，赋予带误差度量类型与失败预算的逐级局部契约，通过仿射复合 + 伸缩预算组合成请求级风险账本，并用 Lean 机器证明逐级打上 certified / partially certified / empirical 强度标签；平台在 5 类架构族的 6 个模型上实例化，在 CUDA graphs 下一层 fused 探针开销仅 -0.94% 吞吐，并将一个 DeepSeek-V4 服务中的静默质量退化精确定位为"逐出/槽位复用"结构性边界（无逐出时 1.000 精确，所有失效均发生在逐出或槽位复用）。

> **TL;DR:** Modern attention memory no longer has a single "KV cache" — dense KV, latent MLA caches, learned sparse selectors, and recurrent states each fail differently under compression. This paper builds **WitCert**, a runtime observability platform that expresses every memory class as typed per-stage error contracts (update/select/read, `e_out ≤ a·e_in + b` with budget δ), composes them with machine-decidable strength tiers (certified / partially certified / empirical) enforced in Lean, and turns them into an executable request-level risk ledger with a telescoping δ-budget sound at unknown request length. Instantiated across 6 models / 5 architecture families (Qwen2.5-7B, Llama-3.1-8B, DeepSeek-V2-Lite, GLM-5.2-W4AFP8, V4-Flash-FP8, Kimi-Linear-48B) on 8×H200 + sglang, the type checker caught the authors' own illegal cross-metric composition; the ledger replayed **12.4M entry reads** with max spend Σδ = 0.009984 ≤ δ_req = 0.01; a fused one-layer Triton probe runs **always-on under CUDA graphs at −0.94% throughput / −0.14% TTFT P99** (inside noise floor); and on a served DeepSeek-V4 stack the machinery localized a silent corruption to an **eviction/slot-reuse structural boundary — exact (1.000) in the eviction-free identity-isolated regime vs. every failure in an eviction or slot-reuse regime**, discharging generation staleness rather than quantization (quantizer intrinsic error 0.0245, unreachable from observed readings). No end-to-end cost benefit or cross-layer error bridge is claimed.

## 核心贡献

- **异构注意力记忆的统一代数与契约**：将四类记忆（dense KV / latent KV(MLA) / 稀疏选择器 / 循环状态）统一抽象为 update、select、read 三个算子，并为每个阶段给出局部契约 `e_out ≤ a·e_in + b`（含失败概率预算 δ）。新增架构只需承担"证明义务"而非编写新工具。
- **带误差度量类型的复合 + 机器可判定的强度分级**：契约的输入/输出误差度量本身是类型的一部分，仅当度量匹配时复合才有定义；该约束在运行时检查器与 Lean 推导期双重强制。每个数字被机器（而非文字）自动标注为 certified / partially certified / empirical，复合继承最弱等级——这一机制当场否决了作者自己第一条非法的跨度量复合链。
- **可执行的请求级风险账本**：用伸缩预算 `δ_i = δ_req/((i+1)(i+2))`（任意请求长度上都可靠、和 ≤ δ_req）把逐级契约变成请求级风险预算；经验对象永不进入 certified 账本，确定性证书以 δ=0 入账。账本相关定理（ledger sound、telescope sum、shared-read sound）均在 Lean 中机器证明。
- **跨架构证据 + 持续在线的低成本探针**：在 5 类架构族、6 个模型（Qwen2.5-7B、Llama-3.1-8B、DeepSeek-V2-Lite、GLM-5.2-W4AFP8、V4-Flash-FP8、Kimi-Linear-48B）上实例化；在 CUDA graphs 下，一层 fused Triton 探针持续在线开销仅 −0.94% 吞吐 / −0.14% TTFT P99（处于噪声底以内）。
- **DeepSeek-V4 静默退化的结构化定位**：把一个被 radix 缓存掩盖的 95 点检索崩溃（0.050 vs 1.000）判别为"代际陈旧（槽位复用且无失效调用）"而非量化，无逐出+身份隔离时精确（1.000），所有观测失效均发生在逐出或槽位复用；写入侧无效化修复在 4 路并发下以 1.000 vs 0.200 双侧因果确认。
- **完整可复现工件**：测量数学、验收门、每个数字背后的冻结运行工件、图表/声明生成器及全套 Lean 开发（含实验裁决微积分）以 Apache-2.0 发布（witprobe-attention-memory），每个数字一行命令即可再生，声明守卫在工件与稿件不一致时让构建失败。

## Key Contributions

- **A unified contract algebra for heterogeneous attention memory.** Four memory classes (dense KV, latent KV via MLA, learned sparse selectors, recurrent states) are written as three operators — update/select/read — each given a local contract `e_out ≤ a·e_in + b` with an explicit failure budget δ. Supporting a new architecture becomes a proof obligation rather than a bespoke tool.
- **Typed cross-metric composition with machine-decidable strength tiers.** Each contract declares an input and an output *error metric*; composition is defined only when they coincide, enforced both at runtime and in Lean elaboration. Every emitted number is tagged certified / partially certified / empirical by the machine (not by prose), and composition inherits the weakest tier — so "end-to-end certified" is a statement the system refuses to print unless every stage earns it. This mechanism caught the authors' own first composed chain, which illegally added a dimensionless ratio (storage witness) to attention total variation (probability mass).
- **An executable request-level risk ledger.** A telescoping budget `δ_i = δ_req/((i+1)(i+2))` makes the per-stage contracts operational at unknown request length; empirical objects are excluded from the certified ledger by API discipline, deterministic certificates enter at δ=0. The ledger soundness, telescope-sum, and shared-read-sound lemmas are machine-checked theorems.
- **Cross-architecture instantiation with an affordable always-on probe.** Six models across five architecture families are onboarded (Qwen2.5-7B GQA, Llama-3.1-8B GQA, DeepSeek-V2-Lite MLA, GLM-5.2-W4AFP8 MLA+DSA, V4-Flash-FP8 MLA+entry, Kimi-Linear-48B KDA+MLA) on 8×H200 + sglang; a fused Triton meter instrumenting one declared layer runs always-on under CUDA graphs at −0.94% throughput / −0.14% TTFT P99, inside the per-concurrency noise floor.
- **A real silent-corruption case study on a served DeepSeek-V4 stack.** The machinery localized a 95-point retrieval collapse (0.050 vs 1.000 baseline, masked by radix caching) to *generation staleness* — slot reuse with no invalidation call anywhere — rather than quantization (the quantizer's intrinsic relative error of 0.0245 is unreachable from the observed readings). Write-site invalidation restored accuracy: 1.000 vs 0.200 under 4-way concurrency, six machine-checked criteria.
- **Reproducible artifacts.** The measurement mathematics, acceptance gates, frozen run artifacts behind every number, figure/claim generators with their guards, and the full Lean development (including the experiment-adjudication calculus) are released as witprobe-attention-memory under Apache-2.0; a claim guard fails the build on any numeric mismatch. Only the architecture-specific probe-injection implementation is withheld.

## Methodology

The platform separates four concerns: a **registry** declaring injection points per architecture; **adapters** that extract tensors and build a validity mask; architecture-independent **meters** holding the mathematics; and a **runtime** that keys every accumulator by (owner, layer, path) and always emits a coverage record. Injection is anchored on exact upstream source blocks with an asserted hit count, and reverts surgically so adapters can share a file.

Any attention memory at step `t` is written as three operators: update `U_t(m_t, x_t)`, select `S_t(q_t, m_t)`, read `R_t(q_t, m_t, I_t)`. Compression or corruption replaces `m_t` with `m̂_t`; the goal is to bound `‖y_t − ŷ_t‖` from locally computable witnesses. The four memory objects are instances of this algebra.

A **contract** at a stage exposes `(a, b, δ)` with `e_out ≤ a·e_in + b` holding except with probability δ. Series composition is the elementary affine rule `(a₂,b₂)∘(a₁,b₁) = (a₂a₁, a₂b₁+b₂)` plus a union bound `Σδᵢ ≤ δ_req`. The non-trivial part is operational: each `a, b, δ` must be computable from quantities the serving stack actually possesses, and the resulting number must carry an honest strength label. **Three tiers are decided by the machine**: *certified* (a sound upper bound exists and is not saturated), *partially certified* (bound holds only on a decidable subset, e.g. rank-prefix stability for rows whose margin exceeds 2ε), *empirical* (observation with no bound). An unregistered metric is a hard error, not a silent demotion; composition takes the weakest tier.

Three core local lemmas anchor the contracts: (1) **pooling is an attenuator, not an error source** — block pooling gives `a = ‖w‖₂ ≤ 1` (Cauchy–Schwarz) and acts on uncompressed inputs; (2) **selection is additive, not amplifying** — rank-prefix selection gives `(a_S, b_S) = (1, ½(m_out + m_in))`, reframing "is the whole top-k preserved?" (almost never) as "is the swapped attention mass small?" (directly measurable); (3) a **sampling sentinel with detection-latency guarantee** — `n(δ) = ⌈log δ / log q⌉` rounds guarantees detection of at least one corrupted slot with confidence 1−δ.

Cross-metric composition requires **proved bridges**: the witness-to-score bridge is Cauchy–Schwarz (`Δ(scale·⟨q,k⟩) ≤ scale·‖q‖·‖Δk‖`, a runtime quantity), and the score-to-distribution bridge is `TV ≤ ½(e^{2ε}−1)`. The repaired chain that the type checker accepts crosses these two bridges; the selection term, lacking a formal selector-to-attention bridge, is reported separately and never summed with the storage term (it crosses metrics only through a *measured* ratio, dropping the composed tier to empirical automatically).

The runtime ledger is enforced **fail-closed**: admission (an entry entering the "masked" state) is probabilistic and spends the owner's δᵢ; enforcement is deterministic — a violating entry has its original bytes restored in the same hook call before any shared read. Request identity is a monotone, never-reused UID detected on the write path, so account boundaries coincide with true request boundaries. An anytime-valid e-process (a finite-Ω Ville inequality, machine-checked with no measure theory beyond the three standard axioms) runs as a global drift sentinel over authorized entries.

Evaluation runs on a single 8×H200 (143 GB) node with sglang 0.5.13.post1; large-model experiments serve DeepSeek-V4-Flash-FP8 at tp=8/ep=8 with a 65,536-token context; overhead/graph-safety experiments use Qwen2.5-7B-Instruct on one GPU. Unless stated otherwise probes sample one call in 8 with a 256-row cap; graph-enabled configurations are measured separately. Every reported number is frozen from a probe artifact by a canon generator, and a claim guard fails the build if the manuscript and artifacts disagree.

## Results & Highlights

- **Latent meter validation (GLM-5.2-W4AFP8, MLA).** Validated against per-cell ground truth over **4,032 cells with 0/4,032 Tier-A violations**; dithered Tier-B coverage is **98.9% at τ = 0.2**. In production, GLM-5.2's own fp8 storage residual is **0.93%** of the latent norm, and the authors' secondary int8 re-quantization of the same latents measures **0.551% over all 78 layers** (vs. the 0.93% fp8 residual — int8 is tighter, counterintuitively).
- **Sparse-selection certification is reframed (GLM-5.2, V4-Flash-FP8).** Strict certification of the entire selected set is essentially unattainable: **0.05% on GLM's token-level top-2048**. The rank-prefix view is the opposite: **top-1 stability is certified for 99.26% of rows on GLM and 99.40% on V4's page-level top-512**, with zero flips inside the certified region.
- **The type checker rejected the authors' own first composed chain.** An early version summed the storage stage's bound (a dimensionless ratio on cache entries) with the selection stage's `b_S` (total variation on an attention distribution) — an illegal cross-metric addition. Making the metric part of the contract's type caught it at Lean elaboration; the retracted numbers appear nowhere else and the guard now forbids them.
- **Request-level ledger, replayed over 12.4M entry reads, 8-way concurrency.** Maximum per-request spend **Σδ = 0.009984 ≤ δ_req = 0.01**; under eight simultaneously-submitted requests the owner ledger reports **zero foreign-owned reads across 8,228,864 checks**, with **0 violations in 120,661 pre-authorized entries**. The owner ledger's first concurrent run flagged a 3.4% foreign-read namespace collision — invisible under serial traffic — the exact class of accounting error a purely serial evaluation cannot surface.
- **Upgrading the certified object (finite-product radius).** Switching the certified object from a worst-case norm to the exact conditional distribution of stochastic rounding lifts the pre-authorization rate from **7.8% to 67.5% (8.7×)** at the same threshold, with **0 of 1,276,631 authorized entries violating their radius**; the global anytime-valid e-process over 120,661 factors stays at `sup log M_t = −0.82 ≪ ln(1/δ_e) = 4.61`.
- **Always-on probe cost under CUDA graphs (Qwen2.5-7B, one of 28 layers).** Fused Triton meter: **−0.94% throughput and −0.14% TTFT P99** vs. an identical probe-off baseline, both inside the per-concurrency noise floor (agrees with reference to 9.3e−07 max relative error; 24.2× cheaper per invocation). Full 28-layer coverage under graphs is −10.16% — a diagnostic mode only.
- **DeepSeek-V4 silent-corruption case study (needle-in-haystack, 12-doc).** Generation staleness (slot reuse, no invalidation call) discriminated from quantization: the packed arm scored **0.050 with radix cache off vs. 1.000 FP8 baseline**; write-site invalidation restored accuracy to **1.000 vs. 0.200 under 4-way concurrency** on six machine-checked criteria. The quantizer's intrinsic relative error is **0.0245**, unreachable from the observed serving readings. Across 9+ rounds the invariant holds: corruption appears exactly when pages of in-flight requests are evicted; the zero-eviction, identity-isolated configuration is **exact (1.000) across three independent 12-doc rounds**.
- **Corruption sentinel (Qwen2.5-7B).** Over **144 baseline verification passes, zero false alarms** (one-sided 95% upper bound on the false-positive rate is 2.06%, not a rate of zero). In the injection experiment, 2 of 4 corrupted slots were located; Lemma 3 explains this as expected (with-replacement sampling of 128/1024 slots over n≈17 rounds gives per-block detection probability 0.881, probability of finding ≤2 of 4 is 0.072). Reaching 99% confidence for a single corrupted slot takes **148/74/37/19 rounds at r = 32/64/128/256** — a budget, not a capability limit.

## Authors & Credibility

The authors are from **Metask Lab**, the lab behind Kimi-Linear (Kimi-Linear-48B appears as one of the six onboarded models), giving them direct, production-grade access to the architectures they instrument — including a real 2026-06-25 production incident (a silent hierarchical-cache corruption that took down agentic traffic on a production host) that motivates the paper. This is an unusually self-critical piece of work: it documents its own rejected composition chains, lists three of its own bugs caught by the adjudicator's soundness self-check, honors a pre-registered gate that failed (the heavy fused-kernel stage is skipped because no certificate family reaches τ=0.2 retention at two-bit coarsening), and explicitly withholds the end-to-end cost-benefit and cross-layer-bridge claims. The Lean development compiles from the shipped repository (`cd formal && bash check all.sh`), depends only on `propext`, `Classical.choice`, and `Quot.sound` (no `sorryAx`), and a claim guard fails the build on any numeric mismatch between manuscript and artifacts — a verifiability posture well above the typical ML-systems paper. The sole credibility caveat is that the architecture-specific probe-injection implementation (hook anchors, adapters, kernels) is **not** released, so the verifiable surface is the artifact-and-guard chain rather than a full serving-level rerun claim.

## Critical Assessment

- **Novelty — high.** Prior KV-cache certificate work (KIVI, KVQuant, GEAR, SnapKV, H2O, attention sinks) fixes a single memory object (the dense post-RoPE KV cache) and derives one bound for it, computed offline against an uncompressed reference — a quantity a serving system does not possess. This paper's contribution is orthogonal: it asks what remains true when the object itself changes and what must be supplied to admit a new object, and makes the *strength* of a composed claim machine-decidable rather than rhetorical. The Lean/mathlib formalization over a finite product space (no measure theory) and the executable request-level ledger with telescoping δ-budget are genuinely new in the LLM-serving context.
- **Rigor — exceptionally high, and load-bearing.** The type discipline did real work: it rejected the authors' first composed bound, forced two bridge theorems (Cauchy–Schwarz, score-to-TV) and one paired measurement into existence, and priced every unprovable step into an explicit tier. The nine-round discrimination campaign (Appendix A) is a model of controlled ablation — each round eliminates a hypothesis by construction (write chain exonerated by 16,942,020 bake-vs-store row checks with zero mismatches; persistent stores and the entire prefill computation proven arm-invariant; a materialized reference reader reproduces the 0.500 control).
- **Reproducibility — strong on the artifact surface, partial on the implementation.** Every number, figure, and theorem regenerates from shipped artifacts by one command; a claim guard fails the build on mismatch. However, the architecture-specific probe-injection implementation is withheld, and the path-contract matrix (Table 2) is one model, one serving-stack version (sglang 0.5.13.post1), small retrieval batteries, largely single-seed — a taxonomy demonstration, not production coverage.
- **Significance — substantial but bounded.** The most transferable systems finding is conceptual: a replaced KV representation redefines coordinate, generation, and materialization semantics, all three of which belong in the runtime contract. The DeepSeek-V4 case study is a concrete, non-trivial production diagnosis that existing serving stacks (vLLM, SGLang) could not surface.
- **Red flags / honest weaknesses (several, all self-disclosed).** (1) The summed per-layer TV bounds are **vacuous** — 36.3 over all 43 layers — because no inter-layer error bridge is claimed; the request-level number is an aggregate budget, and "eviction-safe production consumption with a verified mediator remains future work." (2) **Full 28-layer coverage under graphs is −10.16% throughput** (diagnostic mode only); the always-on claim is for a declared single-layer subset, not every layer. (3) Output-quality claims rest on **n=8 prompts** against a stability floor where two independent server restarts already disagree on 2/8 prompts — the gated arms are "consistent with a protective effect rather than demonstrating one." (4) The "microscopic mediator" of the eviction-corruption association **remains open** after nine further instrumented rounds exhausted every channel. (5) The recurrent-state aggregate does not retain channel identity, so no per-channel contraction certificate is claimed. (6) No end-to-end cost benefit is claimed anywhere; the unoptimized staged consumer serves at **0.884× native throughput / 1.131× cost per output token**.

## Strengths

- Unifies four heterogeneous attention-memory classes under one typed algebra with machine-decidable strength tiers — a genuinely orthogonal contribution to the per-object KV-cache-quantization literature.
- The type checker catching the authors' own illegal cross-metric composition (and the paper publishing that fact) is exactly the kind of self-adjudication that makes the formalism trustworthy.
- Lean/mathlib machine-checked proofs with a finite-Ω, no-measure-theory treatment that any reader can rebuild with `cd formal && bash check all.sh`; axioms audited down to the standard three.
- The DeepSeek-V4 silent-corruption case study is a real, hard production diagnosis (radix-caching-masked 95-point retrieval collapse traced to slot-reuse/generation-staleness rather than quantization), produced by controlled ablation rather than narrative.
- Exceptionally honest scope discipline: explicit "Not yet shown" column in the claim-boundaries table (Table 3); a pre-registered gate that failed is honored (the fused-kernel stage is skipped); quality claims stay at the eight-prompt directional level.

## Limitations

- **No inter-layer error bridge.** Per-layer attention-TV bounds do not compose across depth (each layer's attention is a distinct distribution); the summed request-level budget is vacuous (36.3 over 43 layers). This is "the next theorem the type system is waiting for."
- **Always-on coverage is a declared subset, not every layer.** One declared layer fused under graphs is inside the noise floor; full 28-layer coverage under graphs is −10.16% (diagnostic mode). Any contract reading that needs every layer cannot stay resident.
- **Output-quality evidence is directional, not demonstrated.** n=8 prompts against a stability floor where two server restarts already disagree on 2/8; the gated arms cannot be resolved from the floor, so a protective effect is described, not shown.
- **Eviction-safe production consumption is open.** Every observed failure occurs in an eviction or slot-reuse regime; the zero-eviction identity-isolated configuration is the only one certified, and the microscopic mediator of the association is recorded as an open question after exhaustive instrumentation.
- **Path-contract matrix is narrow.** One model, one serving stack, small retrieval batteries, largely single-seed; it demonstrates a five-level taxonomy of failure, not production coverage.
- **Sampled-probe overhead calibers are graphs-disabled.** Absolute latencies do not represent graph-enabled production; only relative deltas are meaningful (the graph-enabled caliber is measured separately and carries its own scope).
- **Recurrent-state aggregate lacks channel identity**, so an aggregate `E[log a] < 0` does not imply per-channel contraction; no certificate is claimed there.
- **Architecture-specific injection implementation is private.** The verifiable surface is the artifact-and-guard chain, not a serving-level rerun claim.

## Relevance

高度相关。该工作直接服务于现代 LLM 服务（含 MLA、稀疏注意力、线性/循环注意力等异构注意力记忆）的运行时可观测性与可信压缩——这正是高效推理与长上下文/稀疏注意力方向上"压缩后还能不能信"这一被长期回避的核心问题，其带类型契约 + Lean 机器证明 + 请求级风险账本的方法论可为后续 KV 缓存量化、稀疏化与潜在注意力服务的正确性保障提供可迁移的范式。

## Questions for Further Exploration

- What is a sound **inter-layer error bridge** that would let per-layer attention-TV bounds compose into a non-vacuous request-level output-distance bound? The paper explicitly flags this as "the next theorem the type system is waiting for."
- Can the eviction/slot-reuse **microscopic mediator** (left open after nine instrumented rounds) be pinned down — e.g. in selection metadata, index semantics, or their timing state — and would a `(slot, generation)` refinement obligation in the runtime contract prevent the class of failure outright rather than mitigate it timing-sensitively?
- How does the cost/quality trade-off change when the **fused meter is extended to full 28-layer coverage** under CUDA graphs (currently −10.16%, diagnostic-only)? Is there a sub-sampling or hierarchical aggregation that stays inside the noise floor?
- Could the telescoping δ-budget and the anytime-valid e-process sentinel be applied to **non-attention memory** (e.g. MoE expert caches, prefix-cache identity, disaggregated KV transfer) where the same "structurally green, semantically wrong" failure mode appeared (the PD-disaggregation arm returned 0.000 with zero transport errors)?
- Does the **selector-to-attention empirical bridge ratio** (0.87 median, tail 2.18) hold across architectures beyond V4-Flash, or does promoting it from empirical to certified require a per-architecture proved bridge that would change which claims can ever leave tier empirical?
