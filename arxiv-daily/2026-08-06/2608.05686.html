Provably Efficient Self-Calibrating Quantum Fault Tolerance

arXiv:2608.05686  ·  06 Aug 2026  ·  theory + pulse & circuit sim

Key finding

After randomized compiling, the detector-event rate is locally strongly convex — so the syndrome stream alone provably self-calibrates drifting quantum controls.

Why this matters

Turns hardware calibration into a provable zeroth-order online loop embedded in fault-tolerant QEC — the key primitive for long-time quantum computing.

sharpest caveat
Critical edge

All results use detection rate as a proxy — the paper never quantifies how much the logical error rate actually improves.

Methodology how it works

  • Objective. Average detector-event rate C(θ) = (1/N_D)·Σ DR_k(θ) — a zeroth-order signal every QEC round already produces; proxy for, not equal to, logical error rate.
  • Geometry (Thm 1). After Pauli twirling, per-gate local error rate has Hessian ∇²q(0)=2Σ h·h⊤ ⪰ 0; smoothing argument removes gauge degeneracies ⇒ generically strictly convex for coherent / CPTP / leakage errors.
  • Algorithm 1 — projected SPSA. Each epoch samples a ±1 random direction, estimates the gradient from two noisy C evaluations, projects back into the trusted convex region.
  • Algorithm 2 — LSPSA. Graph-colouring groups independent coordinates so the gradient uses only ≤c affected detectors; variance depends on locality constants (s,c), not dimension d.
  • Tracking. Cast as zeroth-order online convex optimization; dynamic regret bounds follow from path length P_T.

Results four theorems

Thm 1 · convexity
Detection rate is locally strongly convex

Coherent, CPTP and leakage/atom-loss errors; generic perturbation removes accidental degeneracy with prob 1.

Thm 2 · one-shot drift
T = O(ε⁻²) to recover

Zeroth-order-optimal scaling using only in-computation syndrome events — no dedicated calibration experiments.

Thm 3 · time-varying
Dynamic regret → 0

E[DynReg] ≲ …/√T + …·P_T/√T; vanishes when drift path P_T = o(T).

Thm 4 · scalability
Code-distance-independent

LSPSA replaces d-dependence with constants (s,c); holds for surface / BB / lifted-product / Tanner LDPC families.

  • Neutral-atom pulse sim ([[4,1,2]]): recovers one-shot drift and tracks linear / sinusoidal drift over thousands of QEC rounds.
  • Circuit-level (Stim): plain SPSA degrades ~O(d); LSPSA stays flat and matches or beats the Sivak et al. (Nature 2026) RL controller with fewer syndromes.

Strengths

  • Closed theory–numerics–scalability loop: local convexity → SPSA → distance-free LSPSA.
  • Reframes calibration as embedded zeroth-order online optimization, not a dedicated experiment — clear engineering value for day-/month-long FT runs.
  • Unified handling of coherent, CPTP, leakage and atom-loss errors.
  • Head-to-head vs the Sivak RL controller: comparable or better, fewer syndromes, stable after convergence.

Limitations

  • Local guarantees only — global / cold-start calibration is admitted open (NP-hard).
  • Logical error rate impact never quantified; everything rests on the detection-rate proxy.
  • idealised noise (depolarizing + independent quadratic control error); no 1/f or spatio-temporal drift.
  • No sensitivity ablation for window m, perturbation λ, or θ_C(threshold); pulse sim only [[4,1,2]].

Questions for further exploration open threads

  1. Can detection-rate improvement quantitatively predict logical error rate p_L — or is there a counter-example (DR↓ but p_L↑)?
  2. What are the actual (s,c) constants for BB [[72,12,6]], quantum Tanner, higher-degree qLDPC? Do any codes have unbounded detector degree and break Theorem 4?
  3. How does the LSPSA dynamic-regret bound change under spatio-temporally correlated drift (1/f, global laser, crosstalk)?
  4. Can a single learned controller (GNN decoder + SPSA calibration) jointly solve fast decode + slow calibration?
  5. Does perturbed accelerated GD (App. D2) reach the global basin within QEC-tolerable time after a large cold-start drift?
