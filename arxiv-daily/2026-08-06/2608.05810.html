When Self-Evolution Backfires: Pre-Commit Gating against Skill Contamination in LLM Agents

Linfang Shang·Ming Xu·Yiding Sun·Tianle Xia·Lingxiang Hu·Lan Xu·Ning Zheng

self-evolving-agents skill-contamination skill-libraries pre-commit-gating agent-verification llm-agents
Key metric · Terminal-Bench 2
72% pass@1

VaG (Verifier-as-Gatekeeper) peaks monotonically at +22pp over ungated R5, with a 37-skill pool (~5× smaller).

Irreversibility: post-hoc rollback recovers only 17% of the 12.3pp drop — descendants inherited flawed reasoning.

Why this matters

A structural critique of unconditional skill admission (Voyager / ACE / AHE): pre-commit gating is essential for any agent memory or skill-library system, not an optional refinement.

Critical edge
RED FLAG

The headline 72% is on Event-50 — the distillation split the authors themselves call “an optimistic upper bound.” The honest Test-25 number for VaG-in-isolation is not reported in the main text.

01

Methodology

formalize → prove necessity → derive method
MOVEMENT 1

Formalize the phenomenon

Round-r agent distills skills S_r ∼ π(·|M_{r-1}) then admits them via operator G; ungated = G = identity. Defines a three-level contamination taxonomy:

  • Individual — a skill harms alone.
  • Combinatorial — harmless skills conflict jointly.
  • Systemic — the non-monotone curve they produce; critical size k*.
MOVEMENT 2

Prove structural necessity

Because S_r is conditioned on M_{r-1}, a defective source skill lives in the distillation context of its descendants. Source-only removal leaves descendants intact, so R(M_r∖{s}) < R(M_r∖({s}∪desc(s))). Lineage cleanup is “out of reach in practice” — contamination must be intercepted before it enters runtime context.

MOVEMENT 3

VaG — pre-commit gating

Three trust tiers Cold ≺ Warm ≺ Hot; only Hot skills enter the prompt.

  • Gate 1 (Cold→Warm): conjunction of SchemaCritic (format) + ExecCritic (A-B replay) + AgentCritic (1 LLM semantic call) — disjoint failure surfaces.
  • Gate 2 (Warm→Hot): marginal-gain greedy subset selection — the only check that detects combinatorial contamination.
02

Results & Highlights

inverted-U → monotone gain
  • Phase shift Ungated pass@1: 48→60→62 (peak R3) → erodes to 50 (R5) — only +2pp over R1 despite a 5× larger pool.
  • VaG curve Monotone every round: 52→58→62→68→72 (Hot pool = 37). +10pp over ungated’s own peak, +22pp over ungated R5.
  • Hard tier Ungated Hard-tier collapses 53→35%; VaG lifts Hard to 59% — a 24pp margin where contamination chains are longest.
  • Transfer Frozen Hy3-evolved Hot pool lifts 4 other backbones +8 to +16pp (GPT-5.4 & Claude Sonnet 4.5 reach 56%, above Hy3’s own 44%).
  • Cross-bench InterCode NL2Bash: VaG 69.0% vs ungated 65.5% — stays positive on short single-step tasks.
  • Efficiency Per-trial tokens flat at 0.77–0.94M while ungated bloats to 1.30M for worse accuracy.

03

Strengths & Limitations

a sharp idea, an underpowered test

+ Strengths

  • Crisp structural result. The irreversibility argument (Eq. 5, descendant-lineage propagation) reframes skill admission as a pre-commit necessity — rare theory-to-design loop in agent papers.
  • Principled critic design. Each critic targets a disjoint failure surface (format / behavior / meaning); ablation confirms mutual non-substitutability.
  • Honest about power. Explicitly states per-round point tests are underpowered (n=50) and rests the claim on trajectory-shape divergence, not buried CIs.
  • Economical. Cheap deterministic/behavioral filters reject most candidates before any LLM call; Gate 2 reuses Gate-1 replays.
  • Right generalization tests. Stronger backbones extracting more from the frozen pool supports the “model-agnostic knowledge” claim.

! Limitations

  • Small scale, single domain. 50 tasks, all shell/terminal; whether the tipping point and 5× compression replicate on coding/web/multimodal or at ACE/AHE scale (68.9–77.0) is unaddressed.
  • Statistical power is the central weakness. n=50, k=3, Wilson CIs ≈30pp; cross-model/cross-benchmark tables report no CIs; Test-25 has only 25 tasks.
  • Bounded submodularity asserted, not proven — the greedy carries no worst-case guarantee.
  • Headline on Event-50 (“optimistic upper bound”); honest Test-25 VaG-in-isolation number not reported.
  • No failure analysis of benign skills wrongly rejected (false-positive cost under-characterized); no code/skill-pool release; backbone “Hy3” not a benchmarked frontier model.
04

Questions for further exploration

Q1

Does the tipping point replicate at scale (ACE 68.9 / AHE 77.0 on TB2-89), or does a stronger distiller (GPT-5.4) push k* out or erase the inversion?

Q2

How does the gate’s false-positive rate behave as the pool grows — does the marginal-gain gate starve the pool of useful diversity?

Q3

Can lineage tracking (logging in-context skill IDs at distillation time) be added cheaply, and would full-lineage cleanup close the 5.6pp irrecoverable gap?

Q4

Does the three-critic conjunction generalize beyond shell — to coding agents (behavioral harm is harder to define) or web agents (A-B replay is expensive)?

Q5

How does pre-commit gating compose with weight-level self-evolution (MetaClaw’s dual-timescale RL) — or does skill gating interfere with gradient-based internalization?

Q6

Where does the submodularity assumption break (strongly synergistic skills), and what selection algorithm replaces the greedy there?
