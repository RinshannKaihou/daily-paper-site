Key Finding

A monotone adversary that adds only correctly-labeled examples inflicts an irreducible Θ((d/n) log(n/d)) gap — at every VC dimension d ≥ 2.

Optimal Rates for Learning with Monotone Adversaries

Anay Mehrotra · Stanford University

Key metric

Θ((d/n)·log(n/d)) minimax expected test error, d ≥ 2 · explicit d=2 lower bound log(en)/(30n)

Inherent against every learner — improper and randomized. The gap vanishes at d = 1, where the clean Θ(1/n) rate survives.

Why this matters

Proves correctly-labeled data augmentation can provably hurt generalization by a log factor — isolating loss of exchangeability as the culprit, not label noise.

Critical edge

The separation needs a growing budget: for any fixed insertion budget m = O(1), the clean Θ(d/n) rate is still achievable. So this is not a statement about bounded data augmentation.

Authors & credibility

Sole author builds directly on the ALT 2026 model of Larsen–Pabbaraju–Shetty. Proofs are fully written out and elementary (coupon-collector + Bayes posterior + VC shattering); the lower-bound class is a finite projective plane, so constants like ρ≥2/3 are independently checkable. Acknowledgments candidly disclose routine use of LLMs in idea development — weight the proofs, not the motivation.

Methodology

Purely theoretical — no experiments. The monotone adversary observes the clean sample, appends m correctly-labeled points (labeled by the true target), and the learner receives a uniform shuffle of the n+m examples. The adversary is adaptive but cannot see the test point, the shuffle, or the learner's coins.

Upper bounds. At d=1, a consensus rule adapted from Haussler–Littlestone–Warmuth: apply the adversary independently to each leave-one-out sample; Lemma 3.13 bounds total leave-one-out error by 1 even though augmented samples need not be exchangeable. At d≥2 the bound is the existing LPS26 ERM result, shown tight.

Lower bounds. A single indistinguishability template: a projective-plane class H_q of VC dimension 2, a hard prior over two target/distribution pairs, and an adversary that pads the sample so two distinct targets produce the identical multiset. The Bayes-balanced posterior forces error ≥ 1/(2k) at the contested point; a coupon-collector bound gives the log factor. Higher d via Cartesian product of disjoint blocks; Littlestone variant reuses a checker-only countable class with Ldim = 2.

Results & highlights

  • d=1, any budget m — R(n,m,1)=Θ(1/n), with 1/(2e(n+1)) ≤ R ≤ 1/(n+1). Zero delta vs the clean PAC baseline.
  • d≥2, worst case over m — matches the LPS26 ERM upper bound up to constants; the multiplicative log(n/d) is proven inherent against every improper, randomized learner.
  • Littlestone dimension d_L — the same rate Θ((d_L/n)log(n/d_L)) holds, so the clean online-to-batch rate O(d_L/n) is unattainable — witnessed already by a single fixed class with d_L=2.
  • Bounded budget m=O(1) — majority vote over optimal clean learners on t-element subsets recovers Θ(min{1,d/n}); the log separation provably requires the budget to grow with n,d.

Strengths

  • Resolves both LPS26 open questions with matching upper/lower bounds at every VC and Littlestone dimension.
  • One unified, elegant lower-bound technique (projective plane + indistinguishability) scales from d=2 to all d≥2 and to the Littlestone setting.
  • The d=1 positive result crisply explains the phase transition at d=2 — where the one-inclusion argument survives vs. where it cannot.
  • Honest about where the result bites (growing budget) and where it does not; explicit about open problems. Transparent AI-assistance disclosure.

Limitations

  • Worst case is over m. Witnessing budget is large (order n·|X_q|); the joint rate R(n,m,d) is open.
  • Expected error only — no (ε,δ) high-probability bounds, the more standard PAC currency.
  • Information-theoretic, not algorithmic — efficient achievability of the optimal d≥2 rate is open; ERM's computational efficiency when VC bounds are vacuous is unaddressed.
  • Binary classification only; lower-bound class is a combinatorial object, not a natural class like halfspaces or neural nets.
  • No empirical validation (appropriate for the venue, but the gap is untested on realistic distributions).

Open questions worth chasing

  • What is the optimal rate as an explicit function of (n, m, d)? Is there a sharp transition at some m*(n,d), and how does it scale?
  • What is the optimal high-probability (ε,δ) sample complexity — is the classical O((d+log 1/δ)/ε) recoverable, with or without a log factor?
  • Can a natural class (halfspaces, a small neural net) replace the projective plane and exhibit the same log gap?
  • Is the optimal d≥2 rate achievable by a computationally efficient learner? Does it extend to partial/multiclass classes (DS-dimension)?
