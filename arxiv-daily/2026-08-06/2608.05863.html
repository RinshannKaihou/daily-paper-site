2 WHY THIS MATTERS

Modern attention is no longer one KV cache — dense, latent (MLA), sparse selectors, and recurrent states each fail differently under compression. WitCert answers the long-avoided serving question: can compressed/latent/sparse memory still be trusted at runtime.

01

Methodology

Four concerns are kept separate: a registry (per-architecture injection points), adapters (tensor + validity-mask extraction), architecture-independent meters (the mathematics), and a runtime keyed by (owner, layer, path) that always emits a coverage record.

Any attention memory at step t is written as three operators. Compression replaces m_t with m̂_t; the goal is to bound ‖y_t − ŷ_t‖ from locally computable witnesses the serving stack actually possesses.

U_t(m_t,x_t)  ·  S_t(q_t,m_t)  ·  R_t(q_t,m_t,I_t)

A contract at each stage exposes (a, b, δ) with e_out ≤ a·e_in + b holding except with probability δ. Series composition is the affine rule plus a union bound; the non-trivial part is making every a, b, δ computable from production quantities and honestly tier-labeled.

Cross-metric composition needs proved bridges: witness→score (Cauchy–Schwarz) and score→distribution (TV ≤ ½(e^{2ε}−1)). An unregistered metric is a hard error, not a silent demotion.

The three operators

  • updatewrite new memory object each step
  • selectrank-prefix / sparse mask over candidates
  • readattention read against the memory

Strength tiers (machine-decided)

CERTIFIEDsound upper bound exists & not saturated (δ=0 entry)
PARTIALLYholds only on a decidable subset (e.g. margin > 2ε)
EMPIRICALobservation, no bound — never enters certified ledger

composition inherits the weakest tier; the system refuses to print "end-to-end certified" unless earned.

03

Strengths & Limitations

+ Strengths

  • Orthogonal contribution. Unifies four memory classes under one typed algebra with machine-decidable tiers — genuinely orthogonal to per-object KV-quant work (KIVI, KVQuant, GEAR, SnapKV, H2O).
  • The type discipline does real work. It caught the authors' own illegal cross-metric composition — and the paper publishes that fact. That self-adjudication is what makes the formalism trustworthy.
  • Auditable formalization. Lean/mathlib, finite-Ω, no measure theory; rebuilds with cd formal && bash check all.sh; axioms down to the standard three (no sorryAx).
  • Real production diagnosis. The DeepSeek-V4 case is a hard, controlled ablation — not narrative — pinning a radix-masked 95-point collapse to slot-reuse rather than quantization.
  • Scope discipline. Explicit "Not yet shown" column; a pre-registered gate that failed is honored (fused-kernel stage skipped); quality claims stay directional.

! Limitations

  • No inter-layer error bridge. Per-layer TV bounds don't compose across depth (each layer is a distinct distribution); summed request budget is vacuous (36.3 / 43). "The next theorem the type system is waiting for."
  • Always-on ≠ every layer. One declared fused layer is in the noise floor; full 28-layer graph coverage is −10.16%. Any contract needing every layer cannot stay resident.
  • Quality evidence is directional. n=8 prompts against a stability floor where two server restarts already disagree on 2/8 — a protective effect is described, not shown.
  • Eviction-safe production consumption is open. Only the zero-eviction identity-isolated config is certified; the microscopic mediator of the association stays open after nine instrumented rounds.
  • Narrow matrix. One model, one serving stack, small retrieval batteries, largely single-seed — a five-level failure taxonomy, not production coverage.
  • No end-to-end cost benefit claimed. The unoptimized staged consumer serves at 0.884× / 1.131× cost per output token.
04

Questions for Further Exploration

What is a sound inter-layer error bridge that lets per-layer attention-TV bounds compose into a non-vacuous request-level output-distance bound? — explicitly flagged as the next theorem the type system is waiting for.
Can the eviction/slot-reuse microscopic mediator (open after nine instrumented rounds) be pinned down — in selection metadata, index semantics, or timing state? Would a (slot, generation) refinement obligation prevent the failure class rather than mitigate it timing-sensitively?
How does cost/quality shift when the fused meter reaches full 28-layer coverage under CUDA graphs (currently −10.16%)? Is there a sub-sampling or hierarchical aggregation that stays inside the noise floor?
Could the telescoping δ-budget and the anytime-valid e-process sentinel extend to non-attention memory — MoE expert caches, prefix-cache identity, disaggregated KV transfer — where the same "structurally green, semantically wrong" failure appeared (the PD-disaggregation arm returned 0.000 with zero transport errors)?
