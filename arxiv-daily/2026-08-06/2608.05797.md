> **一句话总结：** 作者构建了一个跨 17 个智能体基准（共 5,230 个任务、415,470 条执行结果）的数据集，用 1PL（Rasch）IRT 拟合得到任务难度，再用任务描述、token 级熵、嵌入等 rollout 前特征做回归预测；表明 AUC 会掩盖糟糕的难度估计，在 K-fold 下 Spearman ρ 最高 0.399（OOD 降至 0.225），并提出预测与观测难度之间的残差可揭示基准中的污染与不可行问题。

> **TL;DR:** This paper studies ex ante difficulty prediction for agentic tasks across 17 benchmarks (5,230 tasks, 415,470 outcomes). Using a 1PL/Rasch IRT fit (response AUC 0.937) as the difficulty target, it shows that response AUC is a misleading metric — a constant-difficulty estimator still scores 0.715 AUC and a benchmark-average estimator 0.806, while within-benchmark rank correlation (pAcc) is 0.000. Token-level entropy from an 8B open-weight scorer is the strongest single feature family, and the combined feature set reaches Spearman ρ = 0.399 in-distribution (K-fold) but drops to ρ = 0.225 out-of-distribution (leave-one-benchmark-out). Residuals between predicted and observed difficulty correctly flag contaminated (negative residual) and infeasible/evaluator-broken (positive residual) SWE-bench Verified tasks.

## 核心贡献

- **跨基准的难度预测研究**：把"无 rollout 难度预测"从单一的代码基准扩展到 8 类、共 17 个智能体基准（代码、数学、ML 工程、网页导航、函数调用、网络安全、终端、办公多工具等），覆盖 5,230 个任务、497 个 agent 配置、415,470 条 agent-task 结果。
- **揭示 AUC 评估缺陷并提出 rank-based 评估**：从公式上证明 1PL IRT 的 response AUC 同时混入 agent 能力差与任务难度差，导致即使预测器对所有任务输出常数，AUC 仍可达 0.715；推荐使用 within-benchmark 的 Spearman ρ 与 pairwise accuracy (pAcc) 来衡量。
- **token 级熵作为最强的单一特征族**：以 Qwen3-8B-Base 在 bounded reasoning trace 上聚合的 Shannon 熵（含均值、分位、轨迹形状、跨打分器分歧）作为难度信号，显著优于长度基线和嵌入特征。
- **残差诊断框架**：用 z(β) − ẑ 的残差把"预测难度"与"观测难度"对比，正残差指向不可行/评估器缺陷，负残差指向污染/熟悉性；在 SWE-bench Verified 上与 OpenAI 审计报告的两例（django-14725、django-11451）一致。
- **开放多基准语料**：发布包含任务元数据、verifier 摘要、文本描述和 IRT 估计难度的语料，便于环境设计、行为分析与训练课程构建。

## Key Contributions

- **Cross-benchmark ex ante difficulty prediction.** Extends pre-rollout difficulty prediction beyond the single coding-benchmark setting of Agent Psychometrics (Ge et al., 2026) to 8 benchmark families / 17 benchmarks covering coding, math, ML engineering, web navigation, function calling, cybersecurity, terminal, and office tasks (5,230 tasks, 497 agents, 415,470 outcomes).
- **Formal critique of AUC.** Derives that, under a 1PL IRT predictor, AUC conflates agent-ability differences with task-difficulty differences, so a degenerate constant predictor still yields AUC 0.715 and a benchmark-average predictor yields 0.806 — even though both give within-benchmark pairwise accuracy pAcc = 0.000. Recommends rank metrics instead.
- **Token-level entropy is the strongest single feature family.** Shannon entropy aggregated from an open-weight 8B scorer (Qwen3-8B-Base) over a Claude-Sonnet-4.6-generated reasoning trace, plus trajectory shape / spread / cross-scorer disagreement features, beats length baseline and semantic embeddings.
- **Residual diagnostics for hidden task factors.** Defines r_t = z(β_t) − ẑ_t; positive residuals (e.g., +1.41 for django-14725) point to feasibility/evaluator failures and negative residuals (e.g., −0.56 for django-11451) point to contamination/familiarity, matching an external OpenAI audit.
- **Reusable open multi-benchmark corpus.** Releases the dataset with task metadata, verifier summaries, textual descriptions, and IRT-estimated difficulties for downstream behavioral analysis, environment design, and curriculum construction.

## Methodology

The pipeline has two stages (Figure 1).

**Difficulty target (upper branch).** Build a partially observed binary response matrix Y_{a,t} of success/failure for each agent-task pair. Fit a one-parameter logistic (1PL / Rasch) IRT model P(Y_{a,t}=1 | θ_a, β_t) = σ(θ_a − β_t), with zero-centered Gaussian priors on θ_a and β_t, optimized via stochastic variational inference (ELBO, reparameterization trick, ClippedAdam, 2,000 epochs, lr 0.01). The fit achieves response AUC 0.937 on observed pairs. Each task's difficulty β_t is then standardized within its parent benchmark to z(β_t), which removes the benchmark-identity confound and becomes the prediction target. Appendix A.2 justifies the variational IRT over joint maximum-likelihood: point estimates are fragile under imbalance, while variational factors (posterior means + scales) keep an uncertainty estimate per parameter.

**Predictor (lower branch).** Features must be cheaper than rollouts. Given the task-side context C_t (environment + action-space + task description), Claude Sonnet 4.6 generates a bounded reasoning trace R_t (4k-token cap). Five feature sets:
1. **random** — N(0,1) control;
2. **baseline** — log context length only;
3. **embedding** — bge-base-en-v1.5 over R_t, reduced with fold-aware PCA;
4. **entropy** — Shannon entropy of the renormalized top-100 next-token distribution from Qwen3-8B-Base over R_t, with the *full* setting adding a 5-model scorer panel (Qwen3-8B-Base/Instruct, Gemma-E4B-it, OLMo-3-7B-Inst, Llama-3.1-8B-Inst), cross-scorer disagreement, structural features, benchmark metadata, and embeddings;
5. **full** — concatenation of all the above.

The predictor is ridge regression. Estimator alternatives (linear, random forest, XGBoost) are ablated in Table 4.

**Evaluation.** K-fold (KF) for in-distribution and leave-one-benchmark-out (LOBO) for out-of-distribution, reporting Spearman ρ on z(β), raw ρ_β, and within-benchmark pairwise accuracy (pAcc). Cost argument: for a 100-task benchmark with 10 outcomes/task, the feature pass uses ~4×10^6 tokens vs. ~1×10^8 for empirical estimation — a 25× saving that grows with outcomes-per-task.

## Results & Highlights

- **AUC inflation, demonstrated (Table 2).** On the observed response matrix, the IRT oracle sets an upper bound of AUC 0.937. A *constant* predictor (same difficulty for all tasks) still scores AUC 0.715. A *benchmark-average* predictor scores AUC 0.806 and raw ρ_β = 0.519, yet has pAcc = 0.000 because it cannot separate tasks within a benchmark. A shuffled predictor scores AUC 0.610.
- **Rank recovery across feature families (Figure 2).** Predicting z(β): random ≈ 0; length baseline ρ = 0.086 (KF) / 0.101 (LOBO); entropy ρ = 0.193 (KF) / 0.137 (LOBO); embeddings ρ = 0.107 (KF) / 0.017 (LOBO); **combined full model ρ = 0.399 under K-fold vs. 0.225 under LOBO** (p < 0.001 vs. baseline for the KF full result). The gap between KF and LOBO is the central limitation.
- **Estimator ablation (Table 4).** With the full 217-dim feature vector: random forest gives the best KF ρ = 0.475 (pAcc 0.683); linear regression gives the best LOBO ρ = 0.295 (pAcc 0.602). No estimator closes the held-out-benchmark gap.
- **Entropy trajectory shape matters (Figure 3c).** Adding spread (quantiles, top-k means), shape (slope, first/last-decile means, total variation), and gaps (pairwise |Δ| between scorer summaries) improves in-distribution performance over mean-only entropy while preserving LOBO.
- **Scorer-count ablation is non-monotonic OOD (Figure 3b).** Adding scorers strengthens KF but LOBO does not improve monotonically — consistent with benchmark-specific overfitting from averaging.
- **Residual diagnostics on SWE-bench Verified (§5.3).** For django-14725 (flagged by an OpenAI audit for missing prompt information): residual r = 1.46 − 0.05 = +1.41; success rate 0.090; IRT β = 2.58 (>90th percentile). For django-11451 (a contamination example): residual r = −0.51 − 0.05 = −0.56; success rate 0.718; β = −2.35 (below median). Both residual signs match the intended interpretation. The OpenAI audit that motivates this case study reports that 59.4% of 138 frequently failed SWE-bench Verified tasks had material test-design or problem-description issues.
- **Human-time calibration (Table 5, n=1,676).** Fitted difficulty correlates with log median human completion time: KF ρ = 0.422, MAE 0.857 (linear/ridge); XGBoost gives the lowest KF MAE of 0.849 with weaker LOBO rank correlation.
- **Dataset scale.** 17 benchmarks, 5,230 tasks, 497 agent configurations (216 models × 90 scaffolds), mean success rate 0.539, 1.2 trials per agent-task on average, task dates 2010–2026.

## Authors & Credibility

The authors are Stefan Krsteski and Charlotte Meyer of Andromede AI (a small team). The paper is a preprint marked "Under review." The framing and methodology are well-grounded: it engages directly with the only prior ex-ante agentic-difficulty work (Agent Psychometrics, Ge et al., 2026), cites the relevant IRT (Rasch, Embretson & Reise) and contamination/perplexity literature, and is explicit about its limitations (e.g., LOBO gap, residual diagnostics still need rollouts for β_t). The reuse-oriented dataset release (415,470 outcomes across 17 benchmarks with IRT estimates) is a credible artifact contribution independent of the predictor. No code/data link is visible in the body beyond the stated intent to release.

## Critical Assessment

- **Novelty.** Genuine. The AUC critique (Equation 3–4, Table 2) is the cleanest theoretical contribution — it shows mechanically why the prior work's headline metric can stay high for degenerate estimators, and the benchmark-average estimator reaching ρ_β = 0.519 / AUC 0.806 while having pAcc = 0.000 is a sharp illustration. Extending ex ante prediction from one coding benchmark to 8 families is a real empirical expansion.
- **Rigor.** Strong on evaluation design: within-benchmark standardization to remove the benchmark-identity confound, K-fold vs. LOBO split, paired Wilcoxon tests against baseline, estimator ablation (Table 4), and a variational IRT fit with posterior scales rather than fragile point MLE. The cost argument (25× fewer tokens) is concrete.
- **Weaknesses.**
  - **Absolute numbers are modest.** Best KF ρ = 0.399 and best LOBO ρ = 0.225 are weak correlations in practical terms; the authors are honest about this but a benchmark builder cannot rank candidate tasks with high confidence OOD. The within-benchmark pAcc of ~0.68 means the predictor gets the ordering of a random within-benchmark pair right about 2/3 of the time.
  - **Residual "diagnostics" need the rollouts the paper is trying to avoid.** The r_t residual uses the empirical β_t from full rollouts, so §5.3 is a *detection* mechanism, not a pre-rollout prediction — the authors concede this explicitly, but it undercuts the framing.
  - **Case study is tiny.** Two SWE-bench Verified examples is anecdotal evidence for the residual-diagnostics claim; the OpenAI audit's 59.4% figure is about the audit's own set, not about residual detection rate on this corpus. There is no systematic evaluation of how well residuals *retrieve* contaminated/infeasible tasks (no precision/recall, no comparison to a baseline detector).
  - **Scorer choice.** Entropy comes from small (7–8B) open-weight models plus Claude Sonnet 4.6 for the reasoning trace; the paper notes "stronger embedding models may change this conclusion" but does not test frontier scorer models, so the entropy numbers may be a lower bound in an unquantified way.
  - **Missing ablations.** No ablation on the reasoning trace length cap, no test of whether the trace itself leaks difficulty (the trace is generated by a strong frontier model — arguably a partial rollout in disguise at 4k tokens). No per-benchmark breakdown of ρ to show which families drive or drag the aggregate.
- **Reproducibility.** Variational IRT details are given (ClippedAdam, 2000 epochs, lr 0.01, seed 42, 502 agents × 7,266 tasks pre-filter). Scorer panel is fully named (Appendix A.3). However the agent-task outcome corpus (the central artifact) is described as "open" without a URL or license in the body — a release promise, not yet a verifiable artifact.
- **Significance.** Conceptually valuable as a diagnostic lens (difficulty as the common variable linking contamination, feasibility, and agent shortcuts) and as a methodological warning against AUC in IRT-style evaluation. Practically limited until OOD transfer improves.
- **Red flags.** None severe. The residuals-results framing is slightly oversold relative to the two-example evidence, and the "open corpus" claim needs an actual release, but the empirical claims that are made are conservative and internally consistent.

## Strengths

- Crisp, correct theoretical demonstration that AUC over-estimates difficulty-prediction quality for IRT-style models, with a worked degenerate case and a within-benchmark standardization that fixes the confound.
- Broad coverage (17 benchmarks, 8 families) and a genuinely reusable artifact with IRT-estimated difficulties for 7,266 tasks.
- Honest reporting: publishes the constant/benchmark-average/shuffled baselines that would embarrass a less careful paper, and is explicit that LOBO transfer is the open problem.
- Cost analysis grounded in concrete token budgets (25× cheaper than empirical estimation, with assumptions stated).
- Variational IRT (with posterior uncertainty) is a better-founded target than point-estimate MLE under the dataset's imbalance.

## Limitations

- Predictive power is moderate in-distribution (KF ρ = 0.399) and weak out-of-distribution (LOBO ρ = 0.225); pAcc ~0.68 KF is unlikely to be sufficient for confident task ranking in a new benchmark.
- The residual-based contamination/feasibility diagnostic still requires the full rollout matrix Y to compute β_t, so it does not achieve the pure pre-rollout goal.
- Only two illustrative SWE-bench Verified cases validate the residual interpretation; no quantitative retrieval evaluation (precision/recall) against the OpenAI audit.
- Entropy signal depends on small open-weight scorers and a Claude-Sonnet-4.6 reasoning trace that itself consumes tokens — a partial, cheaper rollout rather than a strictly zero-cost feature.
- No per-benchmark breakdown of ρ, no ablation on reasoning-trace length, no test with frontier scorer models.

## Relevance

与"智能体基准评估、难度/课程学习、基准污染检测"等研究兴趣高度相关：它直接处理 LLM agent 在多个长程基准上的难度估计，提供了可用于课程排序和基准健康度审计的 IRT 难度语料与残差诊断方法，对关心 agent 评估方法论的工作非常有参考价值。

## Questions for Further Exploration

- Can a per-benchmark breakdown of ρ reveal which benchmark families (e.g., math vs. web navigation) drive the KF=0.399 aggregate and which drag the LOBO=0.225 number — and does the entropy signal come mainly from a subset of families?
- If the residual diagnostics were evaluated quantitatively against the OpenAI audit's full flagged set, what precision/recall would they achieve at a given |r_t| threshold, and how does that compare to a perplexity-only contamination detector?
- Does the reasoning trace (generated by Claude Sonnet 4.6) leak difficulty information that a strictly no-generation feature set would not have — i.e., how much of the signal survives using only C_t without R_t?
- Would modeling the entropy profile as a time series (frequency-domain features, 1D-CNN/RNN over per-position entropy, as the authors suggest) materially close the KF→LOBO gap, or is the OOD ceiling set by benchmark-specific phrasing that no amount of entropy engineering can remove?
- Can the within-benchmark standardization be replaced by a hierarchical/multilevel IRT model that jointly estimates a benchmark-level mean and a task-level deviation, and does that change the predictor's transfer behavior?
- How stable are the β estimates to the choice of agent pool (216 models, 2023–2026) — would adding more frontier-2026 agents shift the difficulty target enough to change the conclusions?
