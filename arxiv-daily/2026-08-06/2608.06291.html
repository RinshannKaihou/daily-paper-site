Brings two-sided Kronecker-Hessian PTQ down to GPTQ's cubic cost — making richer output-side curvature practical for LLM quantization on a single GPU.

3 Critical edge

Accuracy is inconsistent: BaKron-Backprop collapses on Qwen3-1.7B (PPL 60.97 vs GPTQ's 35.97), and only vanilla GPTQ/RTN baselines are used — no QuIP#/AWQ/QuaRot/SpinQuant, no 3-/4-bit results.

Methodology

quartic → cubic, linear depth

GPTQ's per-neuron rounding loop, recast in the vectorized weight domain with a Kronecker Hessian H = A ⊗ B, naively costs O(m²n²). BaKron layers two acceleration ideas to reach GPTQ's cubic profile while using two-sided curvature.

Idea 1

Anti-diagonal parallelism

Cholesky factors are lower-triangular, so updates from entry (i,j) only touch (p,q) with p≥i, q≥j. Entries on the same anti-diagonal never interact, so an entire anti-diagonal rounds and updates via one batched matmul W ← W + L⁽ᴮ⁾·Δ·(L⁽ᴬ⁾)ᵀ. Linear depth, but work stays quartic.

Idea 2

Recursive divide-and-conquer

Instead of eagerly applying each rank-one update, hold updates back and batch them across a whole block, halving the remaining problem recursively. This alone cuts total work to O(mn(m+n)). Full BaKron recurses over the anti-diagonal dimension, propagating accumulated error between halves.

Hessian menu

Four instantiations

2 loss choices (global backpropagated Fisher vs local) × 2 factorizations (K-FAC-style independence vs Shampoo-style power iteration). Newly derives local Hessians for the Transformer MLP module that BoA did not handle.

Memory

Recursive-halving global Hessian

Splits the layer list at its midpoint, one fwd+bwd pass, recurses on each half. O(ℓ log ℓ) compute, O(log ℓ) accelerator memory — large state lives in CPU memory streamed to the GPU instead of ℓ Hessians resident on accelerators.

Strengths & Limitations

side by side

▲ Strengths

  • Clean, fully proved reduction from quartic to cubic total work at linear sequential depth — matching GPTQ's complexity with richer two-sided curvature.
  • Equivalence theorem (Thm 3.2) guarantees the acceleration changes nothing: no accuracy cost for the speedup vs BoA/YAQA.
  • Recursive-halving global-Hessian flow is a genuine memory win, explained with concrete Llama-3-8B numbers and an honest discussion of where the asymptotics overstate the byte-level gain.
  • Modular w.r.t. both base quantizer and Hessian estimator; cleanly isolates algorithmic vs Hessian contributions.
  • Micro-benchmarks match theory; core share ≤ 12.2% concretely shows the core is no longer the bottleneck.

▼ Limitations

  • Accuracy gains concentrate on larger models — BaKron-Backprop fails on Qwen3-1.7B (60.97 vs 35.97) and underperforms on Llama-3.2-3B. Shampoo factorization is frequently unstable.
  • Only RTN + vanilla GPTQ baselines — no QuIP#, AWQ, QuaRot, or SpinQuant, and no results at the standard 3-/4-bit regimes where the field benchmarks.
  • The 2.81-bit operating point and unusually high GPTQ baseline (53.47) on Llama-3-8B make external comparison hard; unclear if the win survives a well-tuned GPTQ or rotation method.
  • Cubic-complexity asymptotic reached concurrently by Chen et al. 2026 (GPTQ-2D); priority claimed via a review timestamp — not uniquely attributable.
  • Core-algorithm speedups exclude Hessian accumulation and Cholesky; end-to-end speedup over YAQA is real but smaller than the headline 60×.
Authors & credibility
Birnick & Saab (UCSD Math; Saab also HDSI) extend a recent line — Birnick 2025, Chen/Zhang et al. 2025 — that recasts GPTQ as Babai's nearest-plane algorithm with provable error bounds. Complexity and equivalence proofs are written out in full appendices; the experimental protocol (models, calibration, bit-width, regularization, eval harness) is specified in enough detail to reproduce. The authors are candid about concurrent GPTQ-2D work and provide a verifiable timestamp. Gap: no public code release mentioned.

Questions for Further Exploration

open edges
  1. How does BaKron-Backprop compare against QuIP#, AWQ, QuaRot, SpinQuant at standard 3-/4-bit settings, with a well-tuned GPTQ whose Llama-3-8B PPL is not anomalously high?
  2. What causes the Qwen3-1.7B collapse (60.97 vs 35.97)? Hessian-conditioning, a Shampoo/KFAC failure, or a model-specific calibration pathology — and does it extend to other small models?
  3. Can the Shampoo factorization be stabilized (more power iterations, better init) so it stops intermittently underperforming its K-FAC twin?
  4. Does the recursive-halving global-Hessian flow deliver its single-GPU memory win at 70B scale, and what is the wall-clock cost of the O(log ℓ) extra compute there?
  5. Since BaKron is modular over the base quantizer, does composing it with a learned rotation (SpinQuant/QuaRot) or surrogate-gradient rounding (QGPTQ) close the gap to the best incoherence-processing methods at 2–3 bits?
  6. The bound ¼·tr(A)·tr(B) suggests BaKron helps most when the output factor B has low effective rank — can this be verified by correlating per-layer tr(B) with per-layer perplexity contribution?
