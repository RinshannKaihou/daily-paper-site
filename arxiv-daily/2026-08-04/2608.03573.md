> **一句话总结：** 本文从参数层面和梯度理论上系统揭示 SFT 在多阶段训练中会因稠密、相互冲突的参数更新而崩溃（"SFT Conflicts"），而 RL（GRPO）凭借优势函数零和性质与 on-policy 特性产生稀疏且近似正交的更新（"RL Coexists"），据此提出 Parallel-RL 范式，将各任务并行训练后合并，仅用 5% 额外样本适配即可保留单任务 RL 性能的 102.8%。

> **TL;DR:** This paper explains why multi-stage SFT collapses (avg -23.1% on DeepSeek-R1-Distill-Qwen-1.5B across MATH500/MMLU/Knights&Knaves/LiveCodeBench) while multi-stage RL stably improves (+24.9%), tracing the cause to RL's sparse, near-orthogonal updates (ΔW L2-norm ~3e-2 vs ~7.4 for SFT; cross-task cosine similarity ~1e-5 vs ~1e-1). It proves SFT interference is norm-limited (|I_SFT|≤M_i·M_j) while RL interference is variance-limited (|I_RL|≤V_i·V_j), and proposes Parallel-RL, which with TIES/Adapted merging retains 97-103% of single-task RL performance (Adapted Parallel-RL: +10.7% over base vs Multi-Stage RL's +10.2%) while training tasks fully in parallel.

## 核心贡献

- **首次系统刻画 SFT 与 RL 在多任务训练中的根本分歧：** 实证发现多阶段 SFT 在 1.5B 模型上相对 base 平均下降 23.1%（甚至 7B 上 -11.7%），而多阶段 RL 平均提升 24.9%（1.5B）/7.5%（7B），并命名为 "SFT Conflicts, RL Coexists" 现象。
- **参数级几何解释：** RL 的 ΔW 平均 L2 范数约 3e-2（SFT 约 7.4，差两个数量级），仅约 20% 参数幅度超过 1e-5（SFT 为 93%）；不同任务间 ΔW 余弦相似度 RL 约 1e-5，SFT 约 1e-1 甚至反向。
- **梯度干扰上界定理：** 给出 SFT 干扰上界 |I_SFT(i,j)| ≤ M_i·M_j（norm-limited，依赖绝对梯度幅度）和 RL 上界 |I_RL(i,j)| ≤ V_i·V_j（variance-limited，仅受组内 rollout 残差方差控制），从优势函数零和性与 on-policy 两个机制给出严格推导，并将结论推广到 PPO。
- **提出 Parallel-RL 多任务后训练范式：** 各任务完全并行训练再合并 ΔW，并辅以轻量后适配（仅 5% 训练样本）；Naive sum 合并已保留单任务 RL 95% 性能，TIES/SVD 保留 96-98%，Adapted Parallel-RL 在 1.5B/7B 上分别达 +10.7%/+8.0% ΔBase，相对单任务 RL 保留率高达 103.2%/102.4%，甚至超过单任务模型。
- **消融验证可解耦性：** 移除某任务的 ΔW_i 后该任务平均掉 7.1%，而其他任务反而微升 0.6%，证明各任务模块近乎独立；并给出 t-SNE 任务可合并性的判定方法及 SynLogic "Game" 任务的反例（与 Math 合并掉 4.0%，与 Code 合并掉 3.3%）。

## Key Contributions

- **Identifies and names the SFT-Conflicts vs RL-Coexists dichotomy in multi-task post-training**, empirically showing multi-stage SFT collapses by an average of 23.1% relative to the base model on DeepSeek-R1-Distill-Qwen-1.5B across MATH500 / MMLU / Knights&Knaves / LiveCodeBench, whereas multi-stage RL improves by 24.9%; the same pattern holds on the 7B distilled model (-11.7% vs +7.5% ΔBase).
- **Provides a parametric-geometric mechanism**: RL ΔW has L2-norm ≈3e-2 versus ≈7.4 for SFT (two orders of magnitude smaller), only ~20% of RL parameters exceed 1e-5 in magnitude (vs 93% for SFT), and pairwise cross-task cosine similarity is ≈1e-5 for RL versus ≈1e-1 for SFT (with some pairs anti-correlated).
- **Derives a sharp theoretical bound on gradient interference**: |I_SFT(i,j)| ≤ M_i·M_j (norm-limited, scales with absolute gradient magnitude) versus |I_RL(i,j)| ≤ V_i·V_j (variance-limited, bounded by intra-group rollout residual variance), attributing the gap to (i) the zero-sum advantage function acting as a high-pass filter removing the dense mean direction S̄, and (ii) on-policy sampling yielding small, statistically independent, approximately orthogonal residuals via concentration-of-measure; the result is extended to PPO.
- **Introduces Parallel-RL**, a paradigm that trains each task fully in parallel and merges ΔW_i; Naive sum-merge already retains 95% of single-task RL gains (+6.6% ΔBase), TIES-merge retains 97.4%, and Adapted Parallel-RL (only 5% extra adaptation samples) reaches +10.7% ΔBase on the 1.5B model (vs Multi-Stage RL's +10.2%), retaining 103.2% of single-task RL performance and surpassing per-task specialists on most benchmarks.
- **Validates decoupling via ablation and gives a practical coexistence criterion**: removing ΔW_i drops only its own task by 7.1% on average while others improve by 0.6%; t-SNE separation of score functions predicts coexistence, with SynLogic "Game" as a negative example (merging Game+Math drops Math by 4.0%, Game+Code drops Code by 3.3%).

## Methodology

The paper interleaves three layers of analysis.

**1. Preliminary empirical study (Section 2).** Using DeepSeek-R1-Distill-Qwen-1.5B with LoRA, the authors compare four strategies — Mixed-Data and Multi-Stage — under both SFT and RL (GRPO). They train each task in isolation and measure cross-task transfer, establishing the "SFT Conflicts / RL Coexists" phenomenon: SFT improves the target task (+4.0% avg) but degrades untrained tasks (-5.1% avg), while RL improves both (+6.8% target, +2.3% others).

**2. Parameter-level empirical analysis (Section 3).** For each task T_i they compute ΔW_i = W_trained − W_base and measure (a) L2-norm magnitude and (b) pairwise cosine similarity across tasks. Two observations emerge: RL updates are >100× smaller and far sparser than SFT, and RL updates across tasks are nearly orthogonal (≈1e-5) while SFT updates overlap heavily (≈1e-1, sometimes negatively correlated). This is corroborated by t-SNE of score functions S = ∇_θ log π_θ(y|x).

**3. Theoretical analysis (Section 4).** Writing the SFT gradient g_SFT = E[∇_θ log π_θ(y*|x)] and the GRPO gradient g_RL = E[Â·∇_θ log π_θ(y|x)] with zero-sum standardized advantages Σ_k Â_{i,k}=0, they prove:

- *Lemma (Gradient Inner Product Decomposition)*: I_RL(i,j) = (1/G²) Σ_k Σ_l Â_{i,k}Â_{j,l} ⟨δS_{i,k}, δS_{j,l}⟩ — the mean direction S̄ is algebraically cancelled by the zero-sum advantage weights.
- *Theorem 4.5 (Upper Bound on Gradient Interference)* under bounded E‖S*‖² ≤ M_i² and E‖δS‖² ≤ V_i²: |I_SFT(i,j)| ≤ M_i·M_j (norm-limited), whereas |I_RL(i,j)| ≤ V_i·V_j (variance-limited). Because RL's residuals δS are intra-group deviations under a fixed model+input, V_i ≪ M_i, giving the observed near-orthogonality. An analogous bound is proven for PPO in Appendix C.3, plus a cosine-similarity analysis in C.4 showing SFT has a strictly positive lower bound while RL's bound is governed only by a residual coupling factor γ_{i,j}.

**4. Parallel-RL framework (Section 5).** Leveraging approximate orthogonality, the authors propose to launch N independent RL runs producing ΔW_i, then merge: W_final = W_base + M(ΔW_1,…,ΔW_N). Three merging strategies are evaluated: (1) Naive sum/mean; (2) Sparse — TIES (Yadav et al., 2023) and an SVD rank-1 variant motivated by Cai et al. (2025); (3) Adapted Parallel-RL — after Naive sum, run a light adaptation phase on only 5% of the original training set. They emphasize Parallel-RL is more than model merging: it also includes task-selection criteria (Appendix D.1, t-SNE separability) and per-task training tricks.

## Results & Highlights

- **Multi-stage SFT collapses while multi-stage RL coexists (Table 1, DeepSeek-R1-Distill-Qwen-1.5B):** Multi-Stage SFT yields Math 78.2 / Science 31.1 / Logic 9.0 / Code 14.3 — an average of **23.1% below the base model** (Logic alone drops from 31.0 → 9.0, a -22.0 cliff) — whereas Multi-Stage RL reaches 86.6 / 49.3 / 43.0 / 17.3, an average **gain of +24.9%**; on the 7B distill, Multi-Stage SFT averages -11.7% while Multi-Stage RL averages +7.5%.
- **Single-task transfer (Table 2):** SFT improves its target by +4.0% but degrades untrained tasks by -5.1% on average (e.g., Math SFT collapses Logic from 31.0 → 15.0, -16.0); RL improves the target by +6.8% and *also improves* untrained tasks by +2.3% on average.
- **Parameter geometry (Figure 2, Section 3):** ΔW L2-norm ≈ **3×10⁻² for RL vs 7.4 for SFT** (two orders of magnitude); only ~20% of RL parameters exceed 10⁻⁵ in magnitude vs ~93% for SFT; pairwise cross-task cosine similarity ≈ **10⁻⁵ for RL vs 10⁻¹ for SFT**, with some SFT pairs (Math vs Code) pointing in opposite directions (≈ -0.97).
- **Parallel-RL main results (Table 4):** On the 1.5B model, Naive Parallel-RL (sum) retains **94.2%** of single-task RL performance (+6.6% ΔBase vs +9.3% for Single-Task RL), TIES Parallel-RL retains **97.4%** (+8.0%), SVD retains **94.6%** (+6.7%), and **Adapted Parallel-RL reaches +10.7% ΔBase, retaining 103.2%** of Single-Task RL — actually surpassing the per-task specialist on MATH500 (88.6 vs 87.4), MMLU (50.9 vs 51.8 comparable), GPQA (41.4 vs 39.9), KK (49.0 vs 44.0) and LiveCodeBench (22.5 vs 21.6). Naive Parallel-SFT (sum) by contrast retains only **65.4%** and loses -9.2% ΔBase, confirming the asymmetry.
- **7B model (Table 4, bottom):** Adapted Parallel-RL achieves +8.0% ΔBase and 102.4% retention, beating Multi-Stage RL's +7.5%; TIES Parallel-RL retains 97.8%.
- **Decoupling ablation (Table 5):** Removing ΔW_i drops only its own task by an average **ΔTarget = -7.1%** (Math -3.6, Science -10.5, Logic -9.0, Code -5.3) while *other tasks improve* by **ΔOthers = +0.6%** on average — strong evidence of disentangled task modules.
- **Score-function diagnostics (Table 3):** ‖S‖₂ ≈ 7.1 (SFT) vs 10⁻¹ (RL); ‖δS‖₂ ≈ 10⁻² (RL only); CosSim(S_i,S_j) ≈ 10⁻¹ (SFT) vs 10⁻³ (RL) — directly confirming both the variance-limited vs norm-limited bounds and the orthogonality prediction of Theorem 4.5.

## Authors & Credibility

- Authors are from the Key Laboratory of Cognition and Decision Intelligence for Complex Systems at the **Institute of Automation, Chinese Academy of Sciences**, the **School of Artificial Intelligence, University of Chinese Academy of Sciences**, and **Tsinghua University**; correspondence is with Prof. Jun Zhao.
- The empirical claims rest on widely used open base models (DeepSeek-R1-Distill-Qwen 1.5B and 7B), standard benchmarks (MATH500, AIME2025, MMLU, GPQA, Knights&Knaves, LiveCodeBench), and the canonical GRPO algorithm, which makes the setup reproducible. Variance is reported as ±std across multiple seeds, and the authors extend the theory to PPO and report Pass@K analysis in appendices.

## Critical Assessment

- **Novelty (genuine).** The norm-limited vs variance-limited interference dichotomy with explicit bounds (|I_SFT|≤M_i·M_j vs |I_RL|≤V_i·V_j) and the algebraic "advantage-as-high-pass-filter" argument is a clean, original explanation that goes beyond "RL's Razor" (which only addresses forgetting). The cosine-similarity analysis in Appendix C.4 strengthens it.
- **Rigor (mostly strong, with caveats).** The GRPO proofs are clean; the PPO extension is a helpful generalization. However, the central assumption (Assumption 4.4, bounded E‖S‖² and E‖δS‖²) is a standard boundedness condition with no quantitative verification of the constants M_i, V_i beyond the empirical Table 3 — the upper bounds are confirmed qualitatively but the tightness of V_i·V_j vs the actual I_RL is never plotted. The 200-sample-per-task measurement of score functions is small for high-dimensional concentration claims.
- **Reproducibility (good).** Models, benchmarks, and GRPO are all standard; LoRA is used for the mechanistic analysis (Appendix A). However, the paper does not commit to releasing code or the exact training/LoRA configs at submission time, and the "task selection" criterion for Parallel-RL (Appendix D.1, t-SNE eyeballing) is qualitative and operator-dependent.
- **Significance (high for the analysis, moderate for Parallel-RL).** The analysis is the durable contribution. Parallel-RL itself is close to existing model-merging (TIES, task arithmetic) plus light adaptation; the genuinely novel ingredient is the small-N RL-specific claim that even *naive summing* of ΔW_i works for RL — and the paper does show Parallel-SFT fails under the same protocol (-9.2% ΔBase, 65.4% retention), which is the key differentiator.
- **Red flags / weaknesses to scrutinize.**
  - **All experiments use LoRA for the mechanistic claims** but Parallel-RL main numbers (Table 4) are full-parameter — the orthogonality property is established in a LoRA subspace and then assumed to carry over to full-parameter ΔW; this gap is not explicitly reconciled.
  - **Limited task suite (4 tasks).** The orthogonality story is shown on Math/Science/Logic/Code, all of which are reasoning-style tasks; the authors' own counter-example (SynLogic "Game" task, Appendix D.1) breaks Parallel-RL (Math+Game drops Math by 4.0%, Code+Game drops Code by 3.3%), indicating the "RL always coexists" framing is too strong — coexistence depends on t-SNE separability, which is itself a soft heuristic.
  - **Cherry-picked comparisons.** Adapted Parallel-RL's headline 103.2% retention is achieved with only 5% adaptation data, but no comparison against simply running Multi-Stage RL with 5% extra data is provided, leaving the efficiency claim (vs the strong Multi-Stage RL baseline at +10.2%) slightly inflated; the delta is +0.5% ΔBase.
  - **No wall-clock/GPU-hour efficiency numbers** despite the abstract's claim of "significantly improving efficiency" — only sample-efficiency of the adaptation phase is reported.
  - **The theoretical bound is GRPO/PPO-specific** (depends on zero-sum standardized advantages); algorithms without per-prompt advantage normalization (vanilla REINFORCE, some DAPO variants) would not satisfy the lemma, so the scope is narrower than "RL" broadly.

## Strengths

- A clean, memorable dichotomy (SFT Conflicts / RL Coexists) backed by both parameter-level heatmaps and a closed-form interference bound — the norm-limited vs variance-limited theorem is the kind of crisp result that is likely to be cited.
- Honest about scope: extends the bound to PPO, reports a negative example (Game task), and explicitly states the orthogonality is conditional on weak residual coupling rather than universal.
- Comprehensive experimental matrix: two model sizes (1.5B, 7B), six benchmarks, five merging strategies, plus Pass@K and ablations — far more thorough than a typical "mechanism paper".
- Parallel-RL is a practically actionable recipe (train specialists in parallel, TIES-merge, then 5% adapt) that decouples engineering timelines across teams.

## Limitations

- Mechanistic analysis is conducted under LoRA while main results use full-parameter GRPO; the bridge between the two regimes is not formalized.
- "RL coexists" is not universal — the SynLogic Game counter-example shows substantial interference (Math -4.0%, Code -3.3% after merge), and the only proposed task-compatibility test is a qualitative t-SNE eyeball check.
- Adapted Parallel-RL's edge over Multi-Stage RL is small (+10.7% vs +10.2% ΔBase on 1.5B; +8.0% vs +7.5% on 7B) and is not compared against a "Multi-Stage RL + 5% extra data" control, so the claimed efficiency advantage is not fully isolated.
- No wall-clock or GPU-hour reporting; "efficiency" is asserted but only measured in adaptation-sample count.
- Theory requires zero-sum standardized advantages; coverage of non-GRPO/PPO algorithms (REINFORCE, unnormalized DAPO) is not addressed.
- All tasks are reasoning-style; behavior on classification, open-ended generation, or safety/alignment tasks is untested.

## Relevance

对关注 LLM 后训练、强化学习与多任务/持续学习的人来说价值很高——它给出 SFT 与 RL 在多任务设置下分歧的首个系统理论与实证解释，并提供了可直接落地的 Parallel-RL 并行训练范式，对在大规模 reasoning 训练中拆解任务、加速迭代有直接参考意义。

## Questions for Further Exploration

- Does the variance-limited interference bound (|I_RL|≤V_i·V_j) remain tight when V_i is dominated by a few high-reward outlier rollouts, and does group size G in GRPO change the bound in practice?
- How does Parallel-RL behave under non-reasoning tasks (e.g., alignment/safety, multilingual instruction-following, long-form creative generation) where reward signal and on-policy variance differ?
- Can the t-SNE task-compatibility heuristic be replaced by a closed-form metric (e.g., a residual-coupling estimator of γ_{i,j}) that predicts merge interference without running the merge?
- What is the wall-clock and GPU-hour comparison of Parallel-RL vs Multi-Stage RL on, say, 8 tasks, and does the parallel speedup scale linearly with task count?
- Does Adapted Parallel-RL's advantage over Multi-Stage RL survive when the 5% adaptation budget is instead given to Multi-Stage RL as a final mixed-data replay phase?
- How do the conclusions change for RL algorithms without per-prompt zero-sum advantages (REINFORCE, some DAPO/PPO variants without group normalization)?
