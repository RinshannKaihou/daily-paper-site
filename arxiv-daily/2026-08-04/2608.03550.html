β Why this matters
Few-shot CoT with dataset examples is no longer a fair baseline. It systematically underestimates modern reasoning LLMs and inflates the apparent gains of any new method evaluated against it. Adopt zero-shot.
γ Critical edge
Built on a narrow base: one benchmark (GSM8K), three 7–8B models, math only. CoT still helps Llama-3.1-8B (80.3% vs 67.3%). No code, prompts, or seeds released — and the headline "soft guidance" method is never actually proposed.

Read it this way

For Mathstral and Qwen — both tuned to emit reasoning — the zero-shot CoT row dominates the few-shot DS-CoT row. Guidance from dataset examples is pure overhead.

For Llama-3.1-8B (no reasoning tuning) the pattern flips: CoT still helps. The lesson is model-class-specific, not universal.

  • DS-CoTFew-shot CoT using GSM8K training examples (+ optional format instructions).
  • SELF-CoTExamples generated by the model itself in free-form zero-shot, filtered for correct answers.
  • +0shotAdds "Let's think step by step" during example generation — the least-harmful CoT variant.
  • +Rule / +PromptTwo answer-extraction paths (regex vs. ask-the-model) that decouple reasoning from formatting.
02 / THE TRAP

The "more shots, better accuracy" mirage is a formatting artifact.

At 1-shot, DS-CoT+Rule fails to extract any answer from a huge share of outputs — so the "improvement" as shot count rises is mostly the extractor finally working, not better reasoning. DS-CoT+Prompt sits near 0% invalid throughout.

03 / VERDICT

Valuable methodological correction — extrapolated from a thin base

▲ Strengths

  • Format-vs-selection isolation. Random example selection + two extraction methods genuinely separate reasoning from formatting noise.
  • The +Rule / +Prompt diagnosis (Table 2) explains a widespread misleading pattern in CoT evals — a real methodological gift to the community.
  • Intellectual honesty: authors publicly disclose they could not reproduce Mathstral's 77.1% official number.
  • Actionable recommendation: adopt zero-shot as the default baseline for reasoning-specialized models.

▼ Limitations & red flags

  • One benchmark, one domain, one size class — GSM8K, grade-school math, ~7–8B only.
  • No 70B+ or frontier models, so the "as LLMs improve" thesis is supported only indirectly.
  • Concurrent finding: Cheng et al. (arXiv:2506.14641) reports the same core effect — much of the novelty is in the decomposition, not the discovery.
  • Headline overstates: no "soft guidance" method is actually proposed; this is a comparison of existing variants. Conclusion is model-class-specific.
  • No code, prompts, or seeds released at submission.
04 / OPEN

What this paper leaves on the table

i.

Does the guidance-distraction tradeoff scale to 70B+ and frontier models, where native CoT is even stronger?

ii.

How do results transfer beyond math — to code, symbolic logic, commonsense, long-horizon agentic tasks?

iii.

Would similarity/complexity-aware example selection reverse the effect, or does the distraction persist?

iv.

Is the irreproducible 77.1% a sampling artifact, a prompt-format issue, or evaluation contamination?

v.

Can "guidance-distraction" be operationalized into a quantitative metric that predicts when 0-shot beats few-shot?

vi.

If the conclusion is model-class-specific, where exactly is the crossover line — and how would you detect it cheaply?
