Key finding

LLM uncertainty is a mechanistic fracture, not a logit problem. DUD injects Gaussian noise into embeddings, then causally patches FFN and Attention streams separately — exposing a memory-vs-context conflict that aggregated probes flatten, and that surface confidence cannot see.

§01Method — three forward passes, one diagnosis

DUD reframes UQ from passive estimation to active mechanistic interrogation. Three forward passes on the same input isolate each module's causal contribution to recovering the right answer.

  1. Clean run. Cache per-layer h, MHSA output a, FFN output m, and P_clean.
  2. Corrupted run. Inject ε ~ N(0, ν) into embeddings → P_corr. Probability drop = Total Effect.
  3. Decoupled patch. For each layer l & module ϕ ∈ {MHSA, FFN}, re-run corrupted pass with only that module restored from clean cache. Per-layer Restoration Score S_ϕ^(l) = restored gain ÷ TE.

The 2L-dim vector v = Norm(Concat(S_attn, S_ffn)) trains a 4-layer MLP (2L→128→64→32→1) with BCE under 5-fold CV. Labels: ROUGE-L ≥ τ ⇒ correct.

§02The mechanistic story

Restoration scores are predominantly negative — restoring one module alone creates state incoherence. The magnitude is the fragility proxy:

|S| ≈ 0 → mechanistically robust
|S| ≫ 0 → precarious equilibrium

Causal tracing reveals a "double-valley" signature: early-layer Attention routing instability (layers 0–5) plus a precipitous late-layer FFN collapse (layers 20–28) — the physical grounding that black-box probes lack.

Caveat: the dominant fragile module is architecture-dependent — FFN in LLaMA, Attention in Gemma-2-9B. The "FFN-fragility" narrative is not universal.

§04The Confidence Paradox

At SQuAD layer 24, DUD bins samples by which stream is fragile. Error rate quadruples from Q1 to Q4 — yet mean logit confidence barely moves. This is Confidence Inversion: surface metrics are blind to the risk the geometry already encodes.

In Q4 (Dual Deviant), incorrect answers carry logit confidence 0.337 — almost indistinguishable from correct ones at 0.364. Any logit-based detector fails here by construction.

§05Tradeoffs — what it gives, what it costs

+ Strengths

  • Clean mechanistic story tying FFN/MHSA specialization to epistemic uncertainty.
  • 3 models × 4 datasets + ECE, PRR, EM, BERTScore, layer & scale ablations.
  • Strong OOD transfer (<5% drop) → task-agnostic signatures.
  • Honest limitations section; future-work: distill to one-pass detector.
  • Four-quadrant Confidence Inversion is a memorable diagnostic.

– Limitations

  • White-box only — no path to closed APIs.
  • 2L+2 forward passes; concrete latency not reported.
  • Only knowledge QA / reading comp. — no math, code, multilingual, adversarial.
  • ν tuned empirically; no sensitivity sweep; ROUGE-L label is itself noisy.
  • No code/data release at submission.
  • Module dominance is architecture-dependent, weakening the universal FFN story.

§07Questions this opens

Does it survive adversarial / reasoning benchmarks (TruthfulQA, GSM8K, HumanEval)?

Untested. The headline numbers are on knowledge QA where errors are mostly parametric-memory failures — exactly DUD's sweet spot. Reasoning errors may not surface as memory-context conflict.

How sensitive is AUROC to the noise level ν and corruption site?

ν is a single empirically-tuned value with no sweep. Because the entire 2L feature depends on it, this is a non-trivial unexplored knob.

Can the 2L patched passes be distilled into a single-pass student?

Authors flag this as future work. If yes, the latency objection dissolves and the method becomes practical for production selective generation.

Does Confidence Inversion persist under RLHF / GRPO calibration tuning?

Open. If RLHF flattens the quadrant pattern, DUD's diagnostic value may erode precisely on the most-aligned (and most-deployed) models.

Complementary or redundant with DoLa / Lookback Lens / SAR?

Unknown. These decoding-time methods also probe internal geometry; fusion could yield a stronger UQ ensemble — or expose collinearity.
