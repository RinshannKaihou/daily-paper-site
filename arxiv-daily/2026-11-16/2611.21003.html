Why this matters

The weights matter less than the audit trail: a full training post-mortem — spike detection, rollback accounting, quantisation deltas — that most labs never publish.

价值不在单点 SOTA，而在可审计的训练全流程：尖峰检测、回滚记账、梯度范数对尖峰的预测力。
Critical edge

The paper's first-listed novelty is a single unpaired observation: MoVA and softplus gating ship together in exactly one model, compared against a different architecture, with no gate-controlled decomposition.

How it is built

7 stages
  1. ArchitectureDeepSeekMoE-style decoder. Fine-grained routed experts plus shared experts, dense FFNs kept in the first three layers (192 routed / 8 active at 375B; 100 / 8 at 36B-A4B). Untied embeddings, 250,624-token BPE vocabulary with ~24% of tokenizer training spent on Arabic.
  2. MoVASparsity moved into attention's value projection. v = x·Wv becomes a top-4-of-64 mix of purely linear value experts, each followed by SiLU. Because the mixed vector is what gets cached, KV-cache shape is identical to standard GQA and the trick is invisible to FlashAttention — this is why it drops into an existing stack.
  3. Gate & normsoftplus gate at β = log 2, so the gate is exactly the identity at initialisation and unbounded above (a sigmoid gate starts near 0.5 and can only attenuate). Grouped RMSNorm bounds activations by √dg instead of √d.
  4. Pre-training8k sequences, RoPE base 500k. Peak learning rate is held to the end; the usual decay is realised by averaging final checkpoints before mid-training. Weight decay is parameterised through the AdamW timescale, with τepoch·√TPP kept in 2.6–2.9.
  5. Mid-training~1.9T tokens in four stages, context 32k → 128k → 512k. Agent trajectories enter from the start of context extension rather than only in post-training.
  6. Post-trainingFive RL domain experts merged, not concatenated: search, tool use, knowledge work, reasoning, IF+abstention. ISO-merger fixes the base singular values and solves for each specialist's contribution in the shared singular-vector basis; RAM weights routed experts by their actual displacement. Then 280B + 50B SFT tokens. The 32B and 36B-A4B get SFT only, no RL.
  7. UnoLossless multi-token decoding from a rank-128 LoRA-style "diffusion weight" set trained on a frozen AR checkpoint, sampled with Ψ-Spec so the AR distribution is preserved exactly — no draft model needed.

Strengths and limitations, side by side

read both

Strengths

  • The release is the contribution. Intermediate checkpoints from every stage plus the data-synthesis pipelines is a combination almost nobody ships; most "open" releases give final weights and a mixture description.
  • MoVA is a genuinely clean idea. Restricting sparsity to the value projection leaves the KV cache, FlashAttention compatibility and GQA semantics untouched — which is why it can be dropped into an existing stack.
  • Negatives are published beside the wins. The HLE/CritPt gap, a mid-pack result on the authors' own benchmark, the τ³ regression, and a safety section concluding unattended agentic use is unsupported at any size in the family.
  • Production-grade training dynamics. Robust local z-score spike detection across all runs, separate accounting for accepted trajectories vs discarded branches, and the finding that gradient norm predicts a spike only in the last ten steps (OR ≈ 1.9 per SD).
  • Uno is lossless by construction, not by hope — the sampler correction preserves the AR distribution, so the accuracy tables are a validation rather than an assumption.

Limitations

  • No controlled ablation isolates anything. MoVA, the softplus gate and Grouped RMSNorm are each asserted rather than measured against their own control.
  • Single run per configuration. No seeds, no confidence intervals; several agentic benchmarks evaluated once, with margins of 1–2 points that should be read as noise.
  • Baselines re-run on the authors' harness at unequal effort. K2 models at "high" reasoning effort, GLM-5.2 / GPT-5.6 Luna / Sonnet 5 at "max"; no sensitivity analysis, so a +5.4 lead cannot be cleanly attributed to the model.
  • Architecture and recipe are confounded. The 32B and 36B-A4B skip RL entirely, so "36B-A4B matches 32B" is a claim about two SFT-only models.
  • 512k is advertised, 128k is measured. RULER stops at 128k, quantisation accuracy at 65k. Reproducibility is also bounded by third-party teachers (DeepSeek-V4-Flash, Kimi K3).
  • The fleet does not share one recipe. The flagship sees 15.1T tokens, the smaller models 22T — true for four models, not six.

Open questions

5 of 7
  1. What does a matched-parameter ablation say? Train 36B-A4B variants with MoVA+softplus, MoVA+sigmoid, no-MoVA+softplus, no-MoVA+sigmoid — identical total and active parameters, same data order.
  2. Does MoVA's advantage survive an RL stage? The 36B-A4B never receives RL, and routing collapse under long-horizon credit assignment is a plausible failure mode.
  3. Why 4 of 64 value experts? The paper gives one configuration and reports no value-router load statistics, unlike the FFN router — is the routing distribution balanced?
  4. How much of the 10T synthetic tokens is necessary? Replacing synthetic subsets with web tokens at equal compute would test the central data claim far more sharply than the mix-prediction exercise.
  5. Does the 512k context actually work at serving time, and what reward-hacking rate do the baselines show under the same audit?
