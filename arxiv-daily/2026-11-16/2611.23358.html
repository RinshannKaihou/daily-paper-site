Key finding · 二值 Transformer 可靠性

Permutation invariance lets binary BERTs survive 10% bit flips while protecting only 5–20% of their weights.

置换不变性把散落的关键权重“搬”到权重矩阵最前面的若干行/列——无需重训练、无需索引表，二值 BERT 就能在 10% 位翻转率下恢复大部分精度。

Why it matters为什么重要

Approximate memory is only cheap if bit flips don’t break the model. PIES shows 7.5% extra bits buy 10% BER tolerance in binary inference.

Relevance: inference reliability & SDC detection / 低精度推理的硬件故障缓解
Critical edge关键质疑

The error model stores α and ‖W‖₁/n error-free — the exact assumption that makes 1-bit weights look robust — and it is never ablated.

Source: Critical Assessment · “the scaling-factor assumption is doing heavy lifting”

方法 Methodology

  1. 01只翻转权重位。 误差仅注入存储的 0/1 二值权重，α₁、α₂、‖W‖₁/n 视为另存且无错；BER 从 0 扫到 0.1，每点 5 次取均值。
  2. 02按敏感度排序。 用一阶损失敏感度 |ΔL| ≈ 2α|∂L/∂w| 在 72 个矩阵（12 层 × Q/K/V/O/F1/F2）内部排序权重。
  3. 03遗传算法分配预算。 种群 24（SizeProp / Equal / AttenFocus / FFNFocus 各 1 个种子 + 20 随机），≤30 代、8 代停滞即停；适应度 = 注入 BER 后恢复前 N 个权重时的精度。
  4. 04用置换把关键权重聚拢。 按关键权重数给 head 排序，Q/K 按 cQ+cK 置换，O/V 按 cV+cO，F1/F2 按 cF1+cF2——纯布局操作，模型本身不变。
  5. 05只加固前缀。 PIES-TMR 三副本 + 多数表决（1+2r）；PIES-BECC 把 768 位行拆成 3×256 位、整形为 16×16 块并加行列校验与 LDPC 式 4 度校验（1+1.5r，20 次 BP 迭代）。

存疑清单 What it does not settle

  1. 01 / baselines基线是稻草人只对比 Full-HC（1.75×）与 Full-TMR（3×）；Sparrow、SHIFT、MSB copying 这些真正的选择性方案只在引言被引用，从未仿真。
  2. 02 / evidence单任务证据每个模型只测一个 GLUE 任务，且都是二分类；SST-2 仅 1.8k 句，90% 精度下标准误约 ±0.7 点。
  3. 03 / search搜索代价未报告24 个体 × 30 代 × 4 个比例，每次适应度都要全量注错 + 跑数据；无 wall-clock、无 GPU-hours；分配还只针对 BER=0.1 调优。
  4. 04 / silicon纯仿真无芯片、无近似存储 macro、无实测能耗；71.6% 的动态功耗节省直接引自 28 nm SRAM 工作，且未扣除 BP 译码器开销。
  5. 05 / scope结构假设很窄要求 hidden dim 是 head dim 的整数倍、保护粒度是整行/整列（768 位）；非 768 模型与 GQA 未讨论。

优势 Strengths

  • 填补真实空白：二值 Transformer 的可靠性此前无人系统评估，并正确指出 MSB 保护那一套在 1-bit 权重上失效。
  • 置换技巧优雅且廉价：不重训练、不存索引、可与任何后端（TMR、ECC 或未来的码）组合。
  • 机理解释而非断言：F1 主导归因于 ReLU 清零 >2/3 输出，精度–鲁棒性反转归因于激活尺度放大权重误差。
  • 主动报告负面结果：BIT + PIES-TMR 在多数设置下输给 Full-HC，没有藏起来。
  • 成本模型可审计（1+2r、1+1.5r），并公开代码。

局限 Limitations

  • 只有两个任务（QNLI、SST-2），都是二分类；没有多分类/回归，没有更大的二值模型、decoder-only LLM 或 ViT。
  • 无硬件验证；能耗/延迟结论继承自第三方，未计入表决器与 20 次 BP 迭代。
  • 误差模型偏窄：仅 0↔1 翻转、缩放因子无错，没有 stuck-at、老化、行内相关多位翻转或时间累积。
  • BER 上限 10%，更高区间（引用的 DRAM 工作暗示可达）未测。
  • 5 次重复却不报方差或置信区间；GA 的超参与 BER 失配敏感性均未测。

待解问题 Open questions

  1. 把 TMR 表决器与 20 次 BP 译码计入能耗后，71.6% 的 SRAM 功耗节省还剩多少？
  2. BER≈5% 的阈值在 MNLI（三分类）或 STS-B（回归，退化连续）上还成立吗？
  3. 若把每矩阵缩放因子纳入故障模型，BER=10% 下要保持精度还需多保护多少位？
  4. GA 分配按 BER=0.1 调优；器件实际工作在 0.03 或 0.15 时精度损失多大？
  5. 联合优化置换顺序与保护预算（而非两个串行 GA），能否救回限制保留率的离群注意力行？
  6. “沿置换不变轴聚拢关键权重”能否迁移到 4/8-bit 量化权重或 KV-cache 保护？
