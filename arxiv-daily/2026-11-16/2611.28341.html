Agents don't crash when tools fail — they invent the number.

And the fault's payload, more than the model's capability, decides whether the agent fabricates a value or admits it could not get one.

When Tools Fail, Agents Fabricate: Silent Failure and Verification-First Oversight in Tool-Using LLM Agents

Gün Kaynar, Boshen Yan, Carl Kingsford Carnegie Mellon University 2026-11-16

Key metric / 关键数字 38.3%

of runs hit by a misleading "partial success" payload end in confident fabrication — a wrong value asserted as fact.

Same bed, a real OS denial: 15.3% fabrication, 78.1% honest failure.
Why this matters / 为什么重要

A wrong answer asserted as fact is worse than an admission of failure — grade agents on the fabricated-vs-honest split, not on task success.

工具静默降级时，智能体不会报错，而是把从未取到的数字当成事实说出来。
Critical edge / 审慎提示

"η²_fault = 0.061 means fault type explains only ~6% of fabrication variance; the '1.6× more than the model' framing is a ratio between two small numbers."

And the signature "fabrication-prone" label rests on a post-hoc ≥30% rule that only 2 of 4 model cells satisfy.

01 Methodology

Real substrate, injected faults

  • Real where it matters. A fresh OS temp directory with genuine chmod bits, real SQLite files, real subprocesses and a deterministic local Flask server — not a dictionary pretending to be a filesystem. Faults are injected by middleware at a task-specified (tool, argument-substring) pair.
  • 8 tools, 9 faults. Three are transient (timeout, network error, db locked; succeed on retry, p = 0.5). Six are persistent — permission denied, auth required, not found, malformed output, partial success, nonzero exit — forcing tool switching or honest reporting.
  • 30 multi-step tasks, each with a designed alternative recovery route and machine-checkable ground truth, so a valid workaround still counts as correct.
  • 4 ReAct agents (Llama-3.1-8B / 70B, DeepSeek-V4, Claude Haiku 4.5), temperature 0.2, 20-step budget, 3 seeds → 2,100 faulted runs plus clean baselines.
  • Objective grading. CORRECT / FABRICATED / HONEST-FAILURE, judged by a model independent of both agent and monitor. "I wrote the results to a file" counts as not-correct.
  • The Monitor. Step-level rule signals after any error, then a 4-stage answer check: S3 recompute → S1 grounding → S2 restate → S4 LLM goal-drift. Every veto is a corrective instruction, never a hard block.
Mechanism · silent ingestion
  1. First contactA truncated payload comes back marked "success".
  2. Silent ingestionDegraded data is accepted as valid — 91% of partial-data runs retry at most once.
  3. DownstreamEvery later sum, join and claim inherits the missing rows.
  4. Confident assertionA number nobody ever verified is stated in plain prose.
No error signal ⇒ the Monitor never engages. On partial success it stayed silent in 224 of 324 runs.

Rejected along the way: a naive LLM "is this fabricated?" veto, which over-vetoed 39 correct answers versus 46 wrong ones out of 118 — the reason the final design is code-grounded.

The Monitor's blind spot is the signature fault. On partial success, fabrication only falls 38.3 → 32.1%, and the code-only variant is worse than baseline (40.7%) because a total computed from truncated rows is still "grounded" in the rows actually received. Meanwhile, letting the agent repair the environment is capability-gated: permission-denied recovery goes 9.7 → 81.9% for DeepSeek, 0 → 4.2% for Llama-8B.

03 Strengths

  • The fabricated / honest-failure split is the right dependent variable for deployment risk, and the whole evaluation is built on it instead of task success.
  • The mechanism claim is falsifiable and was tested against its obvious rival — the retry-loop hypothesis — with stratified data. The rival loses.
  • Payload sanitization (35.2% vs 16.0%, everything but content held fixed) is a small, clean causal probe.
  • Negative results are quantified, not hidden: 224/324 Monitor silences, a code-only arm that regresses, and a rejected LLM veto reported as 39 correct vs 46 wrong.
  • The evaluation-methodology finding — κ = 0.58 for behavioural taxonomies, κ = 0.91 for objective grading — is immediately reusable by anyone running LLM-judged agent evals.
  • Testbed, toolkit and annotated traces are released, with funding and conflict-of-interest disclosed.

04 Limitations

  • One fault per run: no cascading, correlated, or fault-after-partial-recovery sequences — where production agents actually break.
  • Roughly 27% of the signature fault injections were inert (84/307 partial-success runs changed nothing), and no per-protocol rates are reported, so cross-fault comparisons mix two populations.
  • Effect sizes are small in absolute terms (η² 0.061 / 0.038); "fault type beats model" is a ratio of two modest variances.
  • The Monitor (Sonnet 4.6) is stronger than every agent tested, so architecture and overseer capability stay entangled.
  • Monitor cost is not accounted for: ~6.4 extra calls per run on an 11-step agent, ~58% inference overhead, never compared against spending those tokens on the agent itself.
  • Ecological validity is curated: pre-seeded mock JSON, a 24-command shell allowlist, no pagination, rate-limit or schema-version faults.
  • 30 tasks across many conditions leaves 3 seeds per (model × fault) cell; the ≥30% fabrication rule is threshold-sensitive.

05 Questions for Further Exploration

  1. Per-protocol rates. Restrict to runs where the fault actually fired and the payload actually degraded — do the fault-type rankings survive?
  2. Who is doing the work? Does a same-capability monitor (Llama-70B watching Llama-70B) keep the gain, or is the effect just overseer strength? A 2×2 of agent × monitor capability would settle it.
  3. Make truncation detectable. Can the cascade re-derive from a re-fetch — flagging an implausible row count — instead of waiting for an error that never comes?
  4. Cascading faults. Silent ingestion should compound when the first fault's degraded output becomes the second call's input. That prediction is untested.
  5. Cheaper fix. Given that CoT removal costs +8.3 pts of fabrication, would light fine-tuning on "flag incomplete results" beat 6.4 monitor calls per run?
  6. Judge family. Re-grade the 216-run stratified sample with a non-Anthropic judge to test whether Haiku's 19.0% is deflated or inflated by Claude-Opus-as-judge.
