Why this matters

Weight-space programming crosses from deleting obstacles to installing missing capabilities — a small model plus structured modules as an alternative path to distillation.

权重空间编程从"改掉坏行为"走到"补上缺失能力"，为"小模型 + 结构化模块"提供了一条不同于微调的工程路线。

Critical edge

Near forms of a task prompt can open a module's gates and change its output, so the clean KL = 0 is a measured bound on unrelated text, not behavioral invisibility.

gate = template detector

Methodology the operating room

load host, once→ write tensor patch→ gate = f(residual)→ ≤50 forward passes→ sealed exam
  • No training loop. The host is loaded once and never optimized. The agent writes Python patches that build tensors, each registered with a hash and a parent so any version can be reverted.
  • Grafted, not stacked. A patch adds a group of attention heads (own Q, K, V, output) or MLP neurons (own gate, up, down) inside an existing layer. The group's output is multiplied by a scalar gate on the residual stream and is exactly zero off-trigger by construction. No new layers, no vocabulary change.
  • Two tools, hard budget. A pass-counted host runner and a numpy calculator. Fifty passes per session, at most 512 prompts each; the tool refuses more. Reading weights and analysing activations is free — sessions spend hours in numpy before their first forward call.
  • Blind by tooling. Practice stops at 12 digits (addition) and 6 (multiplication); the runner refuses longer operands, so the agent physically cannot probe the lengths it is later tested on. Validation returns one accuracy per length or subtask, never an instance.
  • Composition rule. A module joins the composite only if, together with those already chosen, it changes none of their predictions on practice sets. Order: highest sealed validation, then lowest mean KL against the format control, then fewer passes.
  • Written by an agent, audited by an agent. Claude Code, headless on a cloud GPU, 12-hour cap, guided by a frozen manual. A separate librarian edits the manual only with evidence; an independent auditor later traced every surviving weight to the code that computed it.

Trust protocol sealed before results

Per-task compilation

  • tracking_shuffled_objects — 31.6 / 17.6 / 13.6% at 3 / 5 / 7 objects became 99.1 / 99.4 / 99.2% in Qwen; the base learns nothing even with the algorithm in the prompt.
  • web_of_lies — 52.0% in one pass, 83.6% with chain of thought, 100.0% with the module. A capability CoT alone did not reach.
  • navigate, boolean_expressions — 100.0% each, circuits designed by the agent from a manual that states only what to compute. The honest scope of "algorithm discovery".
  • Side effects — KL exactly 0 and zero top-token changes across 1,023,000 WikiText-103 positions; identical generations or choices on all 15,845 panel items (IFEval, MATH-5, GPQA, MuSR, MMLU-Pro); identical on 4,261 items of the 18 BBH subtasks without a module.

Strengths what holds up

  • A clean, new mechanism. Capability as gated groups inside existing layers, silent off-trigger by construction, float64 arithmetic rounded once into the residual, original tensors untouched in 54 of 55 sessions.
  • Preregistration as engineering. Sealed verdict sentences, Bitcoin-anchored manifests, dated amendments, a frozen evaluator on separate machines — the strongest apparatus in this literature.
  • Extrapolation tested honestly. The agent cannot run past 12 or 6 digits, so 30-digit addition at 100% cannot be memorization of a distribution it could tune against.
  • Failure reported, not buried. Cap-timeouts, side-effect violations, the rewritten-navigate collapse to 78.3%, the MLX failures, GSM-HARD staying flat.
  • An audit that contradicts the paper. Appendix C prints the inconvenient finding — 21 of 55 sessions used numerical searches — in full.

Limitations where to discount

  • Modules fire on the template. Gemma's composite falls to 78.3% on rewritten navigate, and to 57.7% when the question type is "turns" rather than "face_forward". Free wording is neither claimed nor tested.
  • Exactness is empirical. The addition implants have a finite carry window: a run of columns summing to 9 can break them.
  • The LoRA is a weak foil. Single seed, best-of-four, and the paper concedes it is not the best trained method for length generalization — Abacus embeddings, position coupling and Tracr-style compilation are cited, never run.
  • "Above 7B" rides on saturation. Six of 24 subtasks carry the gain; elsewhere the composite equals its format control.
  • Selected validation. The agent could request aggregate validation scores and stop when high, so 43-of-45 at 100% is optimistically picked — though the sealed test largely vindicates it.
  • One disclosed degree of freedom. The first accidental view of exam data preceded the rule that selects composite modules, which then picked the session in that view.
  • Single stack, small hosts. ≤1.5B parameters, two families, one agent model, one software stack; artifacts promised only upon peer-reviewed publication.

Open questions worth a replication

  1. Does 41.05 survive a leave-one-module-out ablation at test time — is "no interference" a stable equilibrium or an artifact of the practice-set admission rule?
  2. How large is the set of inputs that open a gate but are not the task? A targeted paraphrase probe would turn "no measured side effects" into a real bound.
  3. How much of the result is the manual? Withholding the algorithm on multiplication and tracking would separate discovery from execution.
  4. Does the approach survive 7B and beyond, where wider residual streams offer more features but also more room for a gate to fire spuriously?
  5. Can a module be written for a capability with no crisp algorithm — a multi-step word problem, or a skill defined only by examples?
  6. What are the true nonzero parameter counts and the inference FLOP overhead? Dense allocations of 1.5M–338M entries say little about cost.
