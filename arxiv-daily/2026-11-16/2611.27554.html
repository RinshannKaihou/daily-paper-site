Rerun of the reference: 0 / 60. Making it bit-identical again: 7.24 target passes per token.
Why this matters为什么重要

If your stack must reproduce a reference decode, margin gating cannot rescue it: the fallback reads a cache the wide pass already polluted. If bit-exactness is a requirement, “verify, then fall back” is not an implementation detail you can add later.

Critical edge关键质疑

The width-1 reference is not closer to float32 — 34 vs 24 argmax disagreements per 5,380 positions — so “exactness” means reproducing one arbitrary kernel, at 7.24× the cost.

A k=4 verify pass mixes the 2–3 and 4–6 groups; the reference lives alone in the single-row group. Width-2 vs width-5: 76.5% identical; width-8 vs width-5: 65.4%; widths 12/16/32 vs width-1: 0.0%.

  • Model: Qwen3-0.6B bf16 on one RTX 4090; 128 new tokens, greedy, thinking off; 500-prompt shuffled pool (GSM8K, ARC-Easy, ARC-Challenge).
  • Noise statistic S: teacher-forced along reference tokens; max amount a top-16 rival could overtake the path argmax. Bound ε → gate “fall back when margin ≤ ε”; ε = q99 / q999 / max of S over 5,253 positions = 0.375 / 0.625 / 1.375.
  • Five probes per position: spec, q (shape), c (cache), whole-sequence, padded whole-sequence. Statistics: Wilson intervals, bootstrap means, exact McNemar on paired prompts.
  • Reference is a convention, not ground truth — and Section 10 tests that concession against float32 instead of asserting it.

Strengths 优点

+
  • A real mechanism, not a rate. The c-probe cleanly separates cache noise from query-shape noise, with an exactness control at max |diff| = 0.0.
  • The oracle experiment is exemplary. It turns “our gate failed” into a statement about all possible triggers.
  • Causal design. stale → chunk → last-16 → full is a dose-response with a cost curve attached, not a single negative point.
  • Honesty about its own reference. Section 10 weakens the paper’s framing and is included anyway.
  • Held-out testing built in: 78 unseen calibration prompts and 60 shifted MMLU/HellaSwag prompts — testing the failure of the stale gate too.
  • Reproducibility discipline: every table rebuilt from cached JSON; quantiles, intervals and tests stated per claim; the 42-of-120 calibration shortfall disclosed.

Limitations 局限

−
  • One stack, one GPU. Width classes are properties of that reduction schedule; every rate inherits them. Read the numbers as existence proofs, not constants.
  • Wide intervals on the zeros. 0/100 → ≤ 3.7% Wilson upper bound; 0/60 → 6.0%; several gate variants ran on 30–45 prompts only.
  • Thin calibration tails. 42 prompts for q99; q999 rests on a handful of points — and made the gate looser and 28% more expensive.
  • Cost is passes, not FLOPs. A width-5 pass does 5× the arithmetic; wall-clock is one 12-prompt run on a GPU shared with ~8 jobs.
  • Naive rebuild. Recomputing everything is the simplest exact scheme, not the cheapest — 7.24 passes/token is an upper bound.
  • Exact ties left unexamined (39.2% of divergences) — the cheapest plausible fix is never tested, which may inflate the price of exactness.
  • Answers barely graded. Only ARC option letters; GSM8K is cut at 128 tokens before the final number.
  • No public artifact. Scripts are named, but replication means rebuilding the harness from Appendix A.

Open questions 值得继续追的问题

  1. How much of the 60% survives deterministic tie-breaking on bf16 logits — and does the 7.24-pass conclusion collapse with it?
  2. Do the width groups (1 | 2–3 | 4–6) hold on Triton, FlashAttention-v3 or vLLM kernels, on H100, with TF32 on?
  3. Would a trained drafter (EAGLE, Medusa) with longer accepted runs push the stale gate from 58% toward 100%, as the cache mechanism predicts?
  4. On GSM8K with a longer budget, how many 128-token divergences actually flip the final numeric answer?
  5. Can entry-rewrite-once beat 7.24 passes/token, or is one width-1 pass per committed token a hard floor?
  6. Is there a cheaper certificate than a margin bound — e.g. a running accumulated-S budget — that holds 0/100 at well under 3.55 passes/token?
