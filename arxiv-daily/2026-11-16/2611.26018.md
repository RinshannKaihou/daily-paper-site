> **一句话总结：** 论文提出一套四级因果协议（关断、内容替换、读路径还原/植入、广播广度）来区分"模块转发别处算好的答案"与"模块用广播内容重新计算"，在一个 6.9M 参数、模块只能通过 640 维学习工作空间通信的 AFGW 语言模型上，把源模块的 write-2 报文替换为另一个输入的报文后，97.2%（1,990/2,048）的输出变成只有"重组"才会给出的第三个答案（无干预时 0.4%），并证明该内容是通过改写接收模块第 3 轮的检索 query 起作用（还原 query 可撤销 2,047/2,048 例）。

> **TL;DR:** On a synthetic two-hop relational task (four objects/people/locations, 432 questions per family, 2,048 held-out composition cases) the 6.9M-parameter AFGW model answers 98% of composition questions, but a single transplanted source packet yields the recombination-only "hybrid" answer in 97.2% of cases (1,990/2,048) versus 0.4% natively and 1.0% for plain relay (Y), while restoring only the receiver's round-3 retrieval queries undoes the transplant in 2,047/2,048 cases; calibration on hand-built relay/recombination networks is 4,096/4,096 correct, and a scaled-down check on Qwen2.5-1.5B-Instruct moves hybrid answers from 12/128 to 71/128 with the read tests holding in 70/72 changed cases versus 2/72 for matched random attention rows.

## 核心贡献

- **把"有工作空间"变成"工作空间被使用"的可证伪检验**：指出现有做法（任务准确率、消融、标准的两值 activation patch）无法区分 relay（源模块算好答案、接收方转发）与 recombination（接收方用广播内容查自己的记忆），因为在这两种计算下替换报文得到的答案常常是同一个字符串。
- **设计三值答案协议**：用符号规则预先筛出"忽略=X、转发=Y、重组=Z"三者两两不同的样本（选择只看输入、从不看模型输出），使一次报文替换就能把三种假设分开。协议分四级：rung 1 关断通道、rung 2 内容替换、rung 3 读路径还原/植入、rung 4 一个报文服务多个接收方。
- **给出可证明的关断上界**：Proposition 1 证明在 OFF（把所有广播置零）下，接收方的完整输出只能是问题与自身记忆的确定性函数，因此 OFF 准确率不超过"只看自身记忆的最优预测器"（memory-only ceiling），为该级检验提供理论锚点。
- **构建可枚举全部通路的模型生物 AFGW**：4 个循环模块、每 token 4 轮、每轮 4 个模块 + NULL 竞争一个 640 维报文；记忆按记录类型切分，输出头不能直接读工作空间，因此跨模块信息只能经广播传递，使因果归因可以穷举。
- **定位到机制而非仅证明"有影响"**：广播内容作为 key 改写接收方的检索 query（read mass 从 0.006–0.009 升到 0.52–0.63），还原 query 足以撤销、单独植入 query 足以复现；且该结论在去掉直接 lexical read、改变路由方式、双通路、八实体世界、点对点/slot 通信以及 Qwen2.5-1.5B 的注意力接口上都成立。
- **展示"使用方式是学出来的"**：同一架构下，仅训练数据不同就能得到 relay 型与 recombination 型模型；一个模块读全部记忆的 single-reader 工作空间则几乎完全忽略广播（关断后 2,017/2,048 仍正确，替换广播改变 0/2,048）。
- **提出"verification gap"概念**：建造通道与知道训练后的网络用通道算什么之间隔着一段距离，并主张意识科学的指标式评估（如 Butlin et al. 的 indicator properties）必须补上内容层与路径层的因果证据。

## Key Contributions

- A four-rung causal protocol that pairs every intervention with the alternative hypothesis it rules out: channel dependence (OFF), content use (donor-packet transplant with three distinct predicted answers), mechanism (query restoration vs. query-only installation in a 2×2 design), and breadth (one packet, three receivers).
- The key design move: select only *three-value* cases where ignoring (X), relaying (Y) and recombining (Z) predict pairwise-distinct strings, using a symbolic rule fixed before any model output is seen. This turns a two-value patch — where Y and Z coincide and relay is indistinguishable from computation — into an identifiable test.
- Proposition 1, an information bound for the OFF intervention: with the workspace zeroed the receiver's answer is a deterministic function of the question and its own memory records, so OFF accuracy cannot exceed the memory-only Bayes ceiling. The bound holds only when the workspace is the sole cross-module route, which the paper states explicitly.
- AFGW, a 6,891,784-parameter model organism with 4 recurrent modules, 4 internal rounds per token, a 640-dimensional packet (128-d control + two 256-d lexical blocks), competition against a NULL option, split memory banks, and an output head with no direct path from the workspace.
- A mechanistic result rather than a correlational one: broadcast content acts by redirecting the receiver's memory queries. Restoration of round-3 queries returns the native output in 2,047/2,048 cases with the transplant still in place; installing only the transplant-induced queries reproduces the transplant in 2,047/2,048 with the native broadcast.
- Evidence that the signature travels: eight-entity worlds without retraining, a dual-route model, point-to-point and slot workspaces, an order-invariant reader, uniform routing, and a known carrier interface in Qwen2.5-1.5B-Instruct.
- A demonstration that the *division of labour* is learned, not architectural: relay-trained and recombination-trained models differ only in whether the receiver's records are resampled during training, yet give Y in 511/512 vs. Z in 512/512 under the same three-value transplant while accuracy, ablation and a standard two-value patch report them as identical.

## Methodology

**Model organism (AFGW).** Each input is a small world of four objects, four people and four locations described by binding records ("The holder of football is Jeff") and location records ("Jeff is in the room"). Records are encoded *independently* by two ALiBi causal-attention layers (256-d, 4 heads, FFN 512, window 32, max 16 records), so nothing crosses memory banks inside the encoder. Four recurrent modules (private state 192-d) receive public features `u_t` (prefix) and `g` (question anchor). Modules E1 and E2 read only binding and location records respectively; E0 and E3 have no memory and only compete for the workspace. Each generated token is computed in four rounds: each module forms two 128-d queries from `(h^r_e, b^r, u_t, g)`, performs a sigmoid-gated, order-sensitive read (last matching record favoured, unallocated mass becomes an explicit NULL read), updates its GRU-style state, and writes a packet. Packets compete via a learned softmax over four modules plus NULL, and the pooled mixture `b^{r+1} = Σ π^r_e p^r_e` is broadcast to every module. The write at round 3 is never read — a built-in negative control. The tied-embedding vocabulary head sees only `g`, `u_t`, the receiver's final state `h^4_o`, and the receiver's final lexical read; it has no direct workspace input. Decoding is greedy, must emit EOS, and all private/workspace states reset at every token.

**Data and training.** A family fixes inventories of n people/objects/locations; 3×3 permutations × 2 record orders × 6 question types × n query sides gives 108n = 432 cases per family for n=4. Four local question types query one relation or its inverse; two composition types query `S∘B` or its inverse. Training is a two-stage curriculum: 2,048 local-stage updates (both readers see both record types, each module gets only its own packet back), then 2,048 mixed-stage updates from that checkpoint with a fresh optimizer (readers restricted to their own record type, shared broadcast replaces private feedback). Batch 32 (16 local + 16 composition), AdamW (0.9, 0.95), ε=1e-8, weight decay 0.01, grad-norm 1, FP32, mixed-stage peak LR 1e-4 with 16 warmup updates and cosine decay to 1e-5. Main models: 32 families per corpus, 12,288 updates, ~21 minutes and <1 GB per model.

**The protocol.** (1) *Dependence*: zero every received broadcast in rounds 1–3 at every token, compare composition vs. local accuracy. (2) *Content use*: replace the source's write-2 packet on the first answer token with the same module's packet from a donor input, leave everything else (including the competition) free to evolve. (3) *Mechanism*: a 2×2 design over broadcast (native / transplanted) × queries (native / transplant-induced). Restoration keeps the transplant but restores the receiver's round-3 queries; installation keeps the native broadcast but installs the queries the transplant induced. (4) *Breadth*: one source feeding three receivers that know locations, colours and access rights, so a single packet implies a different hybrid answer at each receiver.

**Evaluation discipline.** Panels, intervention site (write 2, read 3, first answer token), metrics and training lengths were fixed before evaluation. The primary panel has 512 symbolically selected three-value cases per model; all metrics use the full panel including natively-wrong cases and require exact match of the complete answer including EOS. Controls: self-replacement, transplant at the never-read write 3, matched-norm packet noise, matched-total-variation random attention rows, wrong-layer windows, and record-order permutation.

## Results & Highlights

- **Rung 2 (content use) on the main AFGW panel**: a single transplanted write-2 packet produces the hybrid answer Z in **97.2% (1,990/2,048)** of cases, against **0.4% (9/2,048)** natively; the pure relay answer Y accounts for only **1.0% (20)** and the untouched answer X for **0.7% (15)**, so the receiver is computing with the content, not forwarding it. The transplanted recipient also matches its own native output on the hybrid world in 2,021/2,048 cases (errors included).
- **Rung 1 (dependence)**: the four main models answer **98% (2,006/2,048)** of held-out composition questions and **99% (2,027/2,048)** of local ones; zeroing the broadcast removes **69–78 points** of composition accuracy but at most **2.3 points** of local accuracy. Under OFF the models reach only **21–27%**, below the memory-only Bayes ceiling of **46.5–52.9%** (Proposition 1) — a 25-point shortfall the authors attribute to learned over-dependence.
- **Rung 3 (mechanism)**: with the transplant in place, restoring only the receiver's round-3 queries recovers the complete native output in **2,047/2,048** cases; installing only the transplant-induced queries reproduces the transplant output in **2,047/2,048**; both read tests hold jointly in **2,013/2,015** changed cases. Matched-norm query noise retains 92.9–96.9% of the effect, and restoring round-2 queries instead returns **0** of the trajectory transplant's changed cases to native (site-specific in 8/8 runs).
- **Where the read lands**: the final read's mass on the record needed for Z rises from **0.006–0.009** natively to **0.52–0.63** under the transplant, while mass on the native record falls from **0.69–0.76** to **0.007–0.019**; restoration returns both to native values and installation reproduces the transplanted ones. With a second donor naming a third person (Cara), query-only installation yields Cara's hybrid answer in **572/586 (97.6%)** cases against **2** natively.
- **Calibration**: on hand-built relay and recombination reference networks (two seeds each, four models total), the transplant assigns the correct computation in **4,096/4,096** cases — relay models give the donor's Y in all 1,024 cases each, recombination models the hybrid Z in all 1,024.
- **Who computes is learned**: two models differing only in whether the receiver's answer-bearing records are resampled during training both score ≥**511/512** and both fail without the workspace, and a standard two-value patch moves both to the donor's answer in every case. The three-value transplant separates them completely: **511/512 donor Y** for the relay-trained model versus **512/512 hybrid Z** for its control. Four further quarter-resampling models relay in 428–512 of 512 cases.
- **A broadcast can go almost unused**: in a single-reader workspace with four modules, four rounds and competitive broadcast, zeroing everything the modules receive from the workspace leaves **2,017/2,048** answers correct and a donor broadcast in all four rounds changes **0/2,048** outputs — the one reader simply chains its own reads.
- **Rung 4 (breadth)**: one source's write-2 packet makes all three receivers give their own hybrid answers jointly in **84.0%** of 1,024 episodes against **3.1%** natively, with **0/1,024** episodes copying the donor's joint output; rung 3 holds in **2,894/2,926** changed receiver-episode outputs.
- **Generality**: eight-entity worlds (no retraining) go from 0.4% to **95% (973/1,024)** hybrid answers with read tests in 1,005/1,008 changed cases; a dual-route model whose workspace zeroing costs only **22 and 6 of 512** answers still shows the transplant moving **76 and 134** outputs to Z versus **3 and 2** under matched packet noise; point-to-point messages give Z in 410/399, a slot workspace in 235/213 of 286/280 changed cases, and an order-invariant reader in 392/426.
- **Pretrained Transformer**: on Qwen2.5-1.5B-Instruct, transplanting the layer-4 residual of the generated name raises hybrid answers from **12/128 to 71/128** (59 gains, 0 losses, better in 16/16 families); restoring native attention rows returns the native output in **71/72** changed cases, installing induced rows reproduces the transplant in **71/72**, both hold in **70/72**, versus **2/72** for matched random rows and **0/72** for an equally sized early window. Mean-ablating the carrier's keys/values lowers native accuracy from **100/128 to 69/128**, confirming the carrier is not an exclusive route.

## Authors & Credibility

Two authors: Diaoxuan (Nora) He (University of Debrecen) and corresponding author Linqian Wu (University of Waterloo / Perimeter Institute for Theoretical Physics). Neither affiliation is a mainstream ML interpretability group, and the paper is a single two-author effort rather than a lab-scale release. The related-work coverage, however, is unusually current and on-point for a causal-interpretability paper — it engages Zhang & Nanda (2024) on patching-choice sensitivity, Geiger et al. on causal abstraction, Variengien & Winsor (2025) and Prakash et al. (2026) on distinct-output counterfactuals, Gur-Arieh et al. (2026) on bound-entity retrieval, Mueller et al.'s MIB benchmark, and Gurnee et al. (2026) on workspace-like representations in LLMs. The methodological vocabulary (model organisms, interchange interventions, path patching, pre-registered panels) is used correctly rather than decoratively. The theoretical framing (Baars, Dehaene, Block, Butlin et al., Chalmers) is competent but is the paper's rhetorical wrapper more than its evidential core. Weak signals: no code or data release is promised anywhere in the PDF, no funding or compute acknowledgement, and the consciousness-science claims are argued at a level of abstraction well above what a 6.9M-parameter synthetic-world model can support.

## Critical Assessment

**Novelty.** The individual ingredients are borrowed — activation patching, interchange interventions, counterfactual selection, model organisms — but the combination is a genuine contribution: the *symbolic three-value inclusion rule* (X, Y, Z pairwise distinct, selected from inputs only) plus calibration on networks whose computation is known is a real methodological step beyond the two-value patches that dominate the literature, and the 2×2 broadcast × query design is a cleaner causal decomposition than most interpretability papers attempt. The dual-route result (Section 5.6) is the most persuasive single argument for the protocol: zero-ablation costs only 22/512 and 6/512 answers, so a standard analysis would call the workspace almost unnecessary, yet the transplant still moves 76 and 134 outputs to Z, and the read tests hold in 305/309 changed cases. That is a concrete demonstration that ablation under-reports use, not a rhetorical one.

**Rigor.** Strong where it is cheap to be strong: panels, sites, metrics and training lengths fixed before evaluation; multiple ablation variants (zero, mean, resample) and two metrics (exact match, teacher-forced sequence log-probability) that agree in 32/32 comparisons; negative controls (write 3 never read, self-replacement) that leave all 2,048 outputs unchanged; matched-norm noise and matched-total-variation attention rows; an explicit Proposition 1 with a proof and a stated precondition (exclusivity of the route). The pre-registration language is credible because the paper also reports deviations and retained failures rather than hiding them (the 4 residual cases in 2,013/2,015 are kept in every count).

**Weak points, specifically.** (i) The calibration is closer to a unit test than to validation: the relay and recombination reference networks are hand-built so that the computation is fixed by construction, and the 4,096/4,096 result mostly confirms that the authors' own intervention does what its designer intended. No false-positive/false-negative rate is reported for a *standard* two-value patch on the same suite, so the motivating claim that standard patching "cannot tell these apart" is argued by example rather than measured. (ii) The rung-1 interpretation is the weakest link. Under OFF the models score 21–27% while the Bayes-optimal memory-only predictor scores 46.5–52.9%; the authors read the 25-point gap as learned over-dependence, but an equally consistent reading is that the receiver's own-memory read path is simply under-trained for composition questions (it is never the supervised route for those), which would make the ablation deficit an artefact of optimization rather than evidence of use. Rungs 2–3 do not depend on this, which is why the paper's core survives, but Section 5.1's framing overstates what rung 1 shows. (iii) The Qwen2.5-1.5B experiment is thinner than it looks: 128 cases, one model, one hand-designed two-stage task, and a carrier chosen *by construction* (the layer-4 residual of a generated name token) rather than discovered. It shows the protocol is portable to a Transformer given a known carrier, not that it can find one; the read window (layers 20–27) was picked by a rule on a development panel, and the intervention only changes 72/128 outputs, so all read-test percentages rest on that 72-case subset. (iv) The slot-workspace variant is the least clean result and gets the least discussion: the transplant changes only 286/280 outputs, gives Z in 235/213 (~82%), and matched-norm noise returns 36/286 (12.6%) of changed cases to native — an order of magnitude worse than the main models' 1.6%. That is a genuine boundary condition on the protocol (it needs a fine-grained read interface: the authors must transplant writes 0–2 and intervene on reads 1–3) and it is reported in an appendix rather than the main text. (v) Statistics: the effective sample size for model-level generalization is four main models (two corpora × two initializations), and the family sign test p = 2^−32 treats 32 families as independent despite all coming from one generator. (vi) No code, no data, no checkpoint release; the reproducibility statement points only at appendix section numbers.

**Significance.** For interpretability, the protocol and the AFGW testbed are useful regardless of the consciousness framing: exact counterfactual ground truth on a small model is precisely what methods like DAS, path patching and SAE-based circuit analysis lack for validation. For consciousness science, the paper's claim is narrower than its abstract implies — it shows that a *designed* workspace in a 6.9M-parameter model is used in a specific retrieval-redirection way, and that the same signature can be elicited at a *designed* interface of a 1.5B model. It does not show that any frontier model has a workspace whose content is used, and the suggestion that indicator-based assessments should be revised rests on an existence proof, not on a measurement of existing systems.

**Red flags.** The title and abstract sit close to consciousness overclaim relative to the evidence (a 4-object world with 432 templated questions); the "language model" is a 6.9M-parameter synthetic-task model, which the paper does say but the framing deemphasizes; and the absence of any artefact release makes the 20-plus model variants effectively unreproducible without a substantial reimplementation effort.

## Strengths

- The three-value counterfactual design is the right fix for a real identification problem, and the paper explains *why* two-value patches fail rather than asserting it.
- Calibration on known-computation references, with pre-registered panels and metrics, is rare in mechanistic interpretability and should become standard.
- The mechanistic claim is unusually well triangulated: necessity (restoration), sufficiency (installation), specificity (round-2 restoration does nothing; matched noise retains 93–97%), and a positive control (a third donor's induced queries reproduce that donor's hybrid answer in 572/586).
- Generality is tested broadly rather than cherry-picked: eight-entity worlds without retraining, dual-route, uniform routing, point-to-point, slot workspace, order-invariant reader, three receivers, and a pretrained Transformer.
- The relay-vs-recombination pair is a clean demonstration that identical accuracy, identical ablation and identical standard-patch behaviour can hide opposite computations — the paper's central motivating claim, delivered as an experiment rather than an argument.
- Honest reporting of retained failures and of the conditions under which each rung's inference is valid (Table 5 is an explicit scope statement, not boilerplate).

## Limitations

- **Scale and domain**: the headline result is a 6.9M-parameter model on a four-object synthetic world with 432 templated questions per family. Nothing here establishes that a frontier LLM's putative workspace is used for recombination, and the Qwen check is a single 128-case hand-built task.
- **Rung 1 is not a clean measure of use**: the gap between OFF accuracy (21–27%) and the memory-only ceiling (46.5–52.9%) means the ablation deficit conflates dependence with an under-trained own-memory pathway, and the paper's own dual-route result shows zero-ablation can under-report use by a wide margin.
- **Protocol preconditions**: rung 1's bound needs an exclusive route; rungs 2–3 need an identifiable carrier, exact three-value counterfactuals, and a receiver-side read interface. The slot-workspace result (82% Z, 12.6% noise reversal) shows the protocol degrades when content is spread over writes and reads.
- **Case selection**: only three-value cases are scored, which excludes the (probably large) share of natural questions where relay and recombination coincide; the paper never reports what fraction of all composition questions survive the filter.
- **Statistical power**: four main models, two corpora, one generator; the family-level sign test does not account for generator-level clustering.
- **No artefacts**: no code, data, checkpoints, or intervention scripts; reproducibility rests entirely on the appendix specifications.

## Relevance

直接对应「LLM Hidden States & Interpretability」：它把 activation patching / interchange intervention 从"看影响"推进到"判定谁在计算"，并给出可复用的三值反事实筛选规则和已知计算的校准床；对做因果可解释性、探测（probing）和电路分析的人来说，AFGW 是一个难得的、有精确反事实真值的验证环境。其"消融会低估使用"的结论也值得任何用 ablation 下因果结论的工作引以为戒。

## Questions for Further Exploration

1. What fraction of the full composition-question distribution satisfies the three-value filter, and does the 97.2% hybrid rate survive on the excluded (Y = Z) cases under a different identification strategy?
2. Can the protocol be inverted — i.e. given only a frontier model and no known carrier, is there a search procedure that reliably *finds* the carrier, or does the method require the carrier to be specified by construction as in the Qwen experiment?
3. Why does the receiver score 25 points below the memory-only Bayes ceiling under OFF? A control that trains the receiver's own-memory read path on composition questions (while keeping the workspace available) would separate "learned over-dependence" from "under-trained local pathway."
4. Does the read-redirection mechanism hold when the workspace must carry more than one fact per token — e.g. two-hop chains where the source packet has to encode an intermediate that the receiver cannot recover from a single record lookup?
5. How would the protocol behave on a model with a slot-based workspace and a coarser read interface if the intervention were extended to per-slot reads rather than per-round writes, and is the 12.6% noise-reversal rate a floor or an artefact of the chosen intervention site?
6. Could the same three-value design be applied to MoE routing (expert = source, router = workspace) to test whether routed tokens are recombined by the expert or merely forwarded from a residual pathway?
