Key finding · arXiv 2611.22120 · MoE routing

One router-logit bias puts tokens on a concept's expert path — format paths rewrite the text, concept paths only nudge probabilities.

只加一个常数偏置、不改 hidden state，就能把 token 强行推上跨层专家路径：格式路径改写输出（数字字符占比 0.087 → 0.792），概念路径推动概率却几乎不动生成文本。

Key metric 44×

Digit fraction of the continuation: 0.087 → 0.792 when a type-annotation colon is steered onto the clock-time path, versus 0.018 for a bias-matched random path. Qwen3-30B-A3B, s=8, L8–39, N=30.

Why this matters

MoE routing is a usable handle on output form; whether naturally chosen experts actually carry meaning is still unproven.

Critical edge

Removing a naturally selected expert causes no detectable drop — the whole effect needs a forced gate weight of ≈0.96 against a natural ≈0.42.

Method

Bias the logit, leave the expert input alone

The intervention never touches the hidden state. It adds a constant s to one expert's router logit before top-k selection, so the target joins the selected set and the router still picks the other k−1 experts. Any output change is therefore attributable to which experts ran, not to what they were fed.

1
Build the path from dataRun unambiguous exemplar tokens (prayer, scripture, faith; 20 Chinese exemplars for the cross-lingual condition) and take the per-layer modal top-1 expert. The path is "the expert the concept's own tokens most often agree on" — not a hand-picked circuit.
2
Steer every layer in a bandDefault L16–31, s=8; localization sweeps use equal-width bands L8–15 / L16–31 / L32–39 / L8–39 at s=16, plus s ∈ {0,4,8,12,20}.
3
Read out twiceDistribution: next-token probability on the target's word list. Text: actually generate and score the digit / concept-word fraction. Both are reported relative to a random path receiving the same bias.
r̃ℓ = rℓ + s · 1j*ℓj*ℓ(c) = per-layer modal top-1 expert over the concept's exemplar tokens

Models. Main: Qwen3-30B-A3B (48 layers, 128 experts, top-8). Secondary: OLMoE-1B-7B (top-8/64), Qwen1.5-MoE-A2.7B (top-4/60), DeepSeek-V2-Lite (top-6/64). Controls: bias-matched random path, 30 independent random draws, held-out word lists, cross-concept readout matrices, and a Chinese-built path read out on English.

Mechanism

Format self-reinforces; concepts do not

Steering only a prefix of the generation already moves the text — and steering only from token 4 onward still does something. Prefix length, not absolute position, is what matters.

Bands are equal width, so the ~5× middle-band gap is not a width artifact. Religion shows the same shape: the two middle eight-layer windows give 3.5× and 8.4× random; all other windows give nothing.

Bias strength does more than select. At s=6 the target is already top-1 at every steered layer; raising to s=8 still lifts clock-time probability from 0.139 to 0.457 — part of the effect is the enlarged softmax gate weight (~0.42 → ~0.96), not just top-k membership.

The null that matters

Removing one naturally selected expert over 64 cloze prompts per concept yields a religion diagnostic-probability change of −0.26 pp [−0.62, +0.04] and reference log-probability −0.04 [−0.11, +0.02] versus a matched control: no reliable selective impairment. For time, native probability already sits at 99.98%, leaving no headroom to detect anything.

Strengths

Clean causal design, honest nulls

  • Minimal intervention, clean attribution. Only router logits change; expert inputs are identical, so the effect belongs to expert selection rather than an assumed subspace.
  • Control discipline above the norm. Bias-matched random paths, 30 independent draws, held-out word lists, Chinese-built paths read out in English, cross-concept readout matrices.
  • Figure 5 is a decisive little experiment. The prefix sweep tests a specific mechanistic hypothesis instead of adding another correlation.
  • Nulls are reported. Six of nine concepts do not steer, the pre-registered prediction fails, and the removal experiment is called inconclusive.
  • A reusable measurement fix. Catching OLMoE's missing weight renormalization matters to anyone comparing steering strength across MoE models.

Limitations

Forced regimes, ratio-of-small-numbers

  • One model carries the numbers. The other three architectures only test path structure plus a religion-format subset.
  • The regime is forced, not natural. s=8 across 16 layers with delivered gate weight ≈0.96 versus a natural ≈0.42 — a different operating point, not a plausible weighting.
  • No head-to-head baseline. Residual-stream steering, CAA and directed steering are never run on the same task; the practical advantage is asserted, not measured.
  • Nothing downstream. No benchmark, no task accuracy, no judged fluency — only next-token probability on word lists and character fractions over 12–20 tokens.
  • The ordering is unexplained. Both candidate explanations are rejected and nothing is proposed in their place; the n=9 correlations are badly underpowered for "do not explain".
  • Necessity is untested at path level. Only single-expert removal is run — precisely the question the title implies.
  • Purity undercuts the story. Money words agree on one expert only 48% of the time yet steer strongly, while clean-path religion is strongest: "having your own path" is neither necessary nor sufficient.

Open questions

What would change the reading

  1. Does the format effect survive at natural gate weights — a digit run at ~0.42 across far more than 12 generated tokens?
  2. Why does money steer 3.6× in §4 but 6.3× in §5: different prompts, different readout list, or a different band?
  3. If removing all 16 middle-layer religion experts leaves religion cloze accuracy intact, does that falsify the "paths are monosemantic handles" reading?
  4. Is self-reinforcement predictive? A syntactically self-similar concept (numerals, list format) should reach the text; a topically diverse one should not — an untested pre-registration.
  5. How does this compare to adding a religion direction to the residual stream at the same layers, same prompts, same readout? Without that, "routing is a handle" is not established against the cheaper alternative.
  6. Does the 44× format effect hold for conversational or instruction-tuned prompts, where the prior to stay in prose is strong?
