> **一句话总结：** 论文提出"分叉未来"（forked futures）范式，把"隐藏状态是否存在可复用因果接口"变成一个可证伪的架构选择问题：在 Qwen2.5-1.5B 和 Llama-3-8B 上，用预测性因果最小描述长度（MDL）比较 Shared/Local/Mixture/Distributed 四种候选接口，Shared 单瓶颈架构以更短的描述长度（1.292 vs 1.508 nats，SG=0.216；Llama 上 1.187 vs 1.481，SG=0.294）胜出，且在移植、中介和合成"模型有机体"盲测（14/16 正确）中都得到独立机制证据的支持。

> **TL;DR:** By sampling future operations only *after* a prefix state forms and comparing the induced response distributions (a "forked future"), the authors turn "does the model reuse a shared internal interface" into a falsifiable architecture-selection problem judged by prequential causal MDL. On Qwen2.5-1.5B, a Shared single-bottleneck encoder achieves MDL=1.292 nats vs. 1.508 for the best alternative (Local, independent per-operation codes), a Sharedness Gain of 0.216 nats (95% CI [0.161, 0.278]); on Llama-3-8B the gain is 0.294 nats (1.187 vs. 1.481). Independent transplantation experiments show Shared donor code achieves target-correctness 0.91 vs. 0.48 for Distributed, and a synthetic four-class model-organism test correctly recovers architecture identity in 14/16 cases.

## 核心贡献

- 提出"分叉未来因果签名"（forked future causal signature）概念：对同一前缀状态 h，仅在采样未来操作之后才比较模型在不同操作下的响应分布，从而定义一种不依赖研究者预设潜变量标签的经验因果等价关系，避免"当前答案相同但支持不同后续计算"这一常见陷阱。
- 把"是否存在可复用共享接口"形式化为架构竞赛：Shared（单一算子无关编码器）、Local（每操作独立编解码器）、Mixture（门控插值）、Distributed（无特权瓶颈）在匹配容量/秩/参数量的前提下，用预测性因果 MDL（式5-7）竞争，同时约束保持未来签名保真度（FSD，式3）。
- 设计四重机制验证闭环：held-out 分布外泛化（操作/组合/生成器/家族四种偏移）、跨架构角色对齐的因果移植（同族/跨族/匹配随机三种施主对照）、路径级中介分析（阻断 API 对齐路径 vs 匹配零路径）、以及已知路由结构的合成"模型有机体"盲测，四条证据线各自针对一种可能的替代解释（可解码但不因果、可移植但只是复制内容、稀疏路径图只是可修补性而非真实中介）。
- 在 Qwen2.5-1.5B 与 Llama-3-8B 两个模型上完整跑通该协议，并在 5 个额外骨干（Qwen2.5-7B/Mistral-7B/Gemma-2-9B/Phi-3-3.8B）上验证 Sharedness Gain 方向的跨架构稳健性（仅方向性，非完整竞赛）。
- 用表征恒等性分析（SAE/Transcoder、PCA、输出梯度、随机子空间）排除"任意低维或输出对齐子空间都能达到同等效果"的解释，证明恢复的 API 子空间在未来保真度、可移植性、局部性、必要性上均优于这些基线中至少一项。

## Key Contributions

- **Forked futures**: a temporal-control protocol where the future operation k is sampled only *after* the prefix hidden state h is cached, and hidden states are compared through the induced response distributions σ_k(h) rather than through the current answer — this rules out current-answer shortcuts and researcher-imposed latent labels.
- **Architecture-selection framing of "shared interface"**: Shared, Local, Mixture, and Distributed encoder/decoder families compete under a prequential causal MDL objective (Eq. 5) subject to a future-signature-fidelity constraint (FSD, Eq. 3), with capacity (rank, sparsity, parameter count, optimization budget) matched across candidates so a short code cannot win by being under-powered.
- **Four independent falsification arms**: (1) held-out operation/composition/generator/family generalization splits, (2) role-aligned cross-architecture transplantation with same-family / cross-family / matched-random donor controls, (3) sparse path-level mediation analysis with matched-null path comparisons, and (4) a blind four-class synthetic model-organism recovery test with known ground-truth routing graphs.
- **Representation-identity controls**: comparison against SAE/Transcoder, PCA, ICA, output-gradient, and random subspaces to show the recovered interface is not an artifact of dimensionality reduction alone.
- Full statistical protocol (paired family-level bootstrap, permutation tests, TOST equivalence, Benjamini–Hochberg FDR) applied consistently across all comparisons, with layer/rank/threshold selection frozen on validation data before test evaluation.

## Methodology

The core object is the **forked future causal signature**: given a prefix x_{1:t} with hidden state h = h_{ℓ,t}(x), an operation bank K induces continuation distributions σ_k(h) = p_θ(y | x_{1:t}, k), and Σ_K(h) = {σ_k(h) : k ∈ K} is the future causal signature. Two hidden states are declared future-equivalent when their signatures are close under a KL/Jensen-Shannon-based Future Signature Distortion (FSD, Eq. 3), computed by expectation over k ~ π_K. Critically, the operation k is only revealed *after* h is cached (Fig. 1A–B), which prevents the interface encoder from ever seeing operation-name leakage and forces evaluation on genuinely unseen futures.

Four candidate causal-quotient architectures are defined via an encoder/reconstructor pair c = E_φ(h,k), ĥ = R_ψ(c,k) (Eq. 4): **Shared** uses one operation-agnostic code E_φ(h) that only receives operation identity at reconstruction time; **Local** gives every operation its own private (E_k, R_k); **Mixture** interpolates shared/local components via an operation-conditioned gate; **Distributed** keeps the signature spread across several components with no privileged bottleneck. These compete under a **prequential causal MDL** (Eq. 5–6): the description length is the two-part code (Gaussian-prior parameter code + explicit rank/gate penalty, λ_r=0.02, λ_g=0.05) plus the sequential cross-entropy of held-out future-signature distributions across 20 folds, with each fold's predictor trained only on preceding blocks (true online/prequential evaluation, not just a train/test split). The selected architecture A* minimizes MDL subject to a worst-family FSD tolerance ε_f, and **Sharedness Gain (SG)** is the MDL advantage of Shared over the best of {Local, Mixture, Distributed} (Eq. 7).

Data comes from four synthetic "forkable episode" families (relation-world, program-state, proof/discourse-state, attribute/event-world), each generated from a latent structured state z rendered into a prefix, then forked into multiple valid future operations (query/compare/invert/compose for relations; execute/verify/copy/update for programs; entail/verify/derive/chain for proofs). The main architecture comparisons use relation-world (4,200/900/1,200 train/val/test), program-state (3,800/820/1,080), and proof/discourse-state (2,600/560/740) — 10,600/2,280/3,020 episodes total — with semantic-collision and lexical-anti-collision controls to guarantee that current-answer identity and future-signature identity are dissociated (ruling out shortcut solutions).

Mechanistic validation has three arms: (1) **role-aligned transplantation**, inserting a donor's interface code into a base model's computation at a matched producer/consumer role, layer, position, and intervention norm, scored via Target Correctness (TC), Locality (LOC), and Copy-Preservation (CopyPres = 1 − DonorCopyRate), aggregated into CompScore (Eq. 8–9); (2) **path-level mediation**, blocking API-aligned vs. matched-null paths and computing Mediated Fraction MF = (Δ_total − Δ_blocked)/Δ_total (Eq. 10); (3) a **blind synthetic model-organism test** using six-layer, hidden-width-256, vocab-512 transformers trained from scratch (3,000 steps, 5 seeds) with four known ground-truth routing graphs (Shared/Local/Mixture/Distributed, Fig. 2A) that the discovery pipeline must recover from activations alone, without ever seeing the architecture label.

## Results & Highlights

- **Architecture competition (Table 2)**: On Qwen2.5-1.5B, Shared achieves causal MDL = 1.292 nats vs. 1.508 for Local (the best non-Shared alternative), 1.672 for Mixture, and 1.981 for Distributed — Sharedness Gain SG = 0.216 nats, 95% CI [0.161, 0.278]. On Llama-3-8B, Shared MDL = 1.187 vs. 1.481 (Local), 1.594 (Mixture), 1.863 (Distributed) — SG = 0.294 nats, CI [0.208, 0.391]. Crucially, mean FSD differs by at most 0.011 across all four architectures within either model (e.g., Qwen: 0.341 Shared vs. 0.352 Distributed), meaning the gain is a *coding-cost* advantage at matched predictive fidelity, not a large accuracy gap.
- **Model-organism falsification**: In the blind four-class recovery test with known ground-truth routing graphs, 14/16 held-out synthetic organisms are correctly classified; Shared, Mixture, and Distributed organisms are recovered perfectly in all 4 held-out cases each, but among 4 Local organisms only 2 are correctly labeled Local, with 1 mislabeled Shared and 1 mislabeled Mixture — an observed false-Shared rate of roughly 8.3% among the 12 non-Shared organisms, which the authors explicitly flag as preventing a "fully satisfied" falsification claim.
- **Transplantation (Table 3, Fig. 4C)**: Shared-donor code achieves Target Correctness 0.91 vs. 0.72 (Local), 0.65 (Mixture), 0.48 (Distributed); Locality 0.88 vs. 0.75/0.69/0.52; Copy-Preservation 0.85 vs. 0.66/0.61/0.42; composite CompScore 0.87 vs. 0.70/0.64/0.42 — Shared dominates on every one of the three sub-metrics, not just the aggregate.
- **Donor-identity controls (Table 3)**: CompScore for Shared drops from 0.88 (same-family donor) to 0.78 (cross-family) to 0.53 (matched-random donor), a monotonic degradation that supports role-aligned reuse rather than incidental compatibility; the same ordering (Shared > Local > Mixture > Distributed) holds within each donor regime.
- **Mediation and path sparsity (Table 3, Fig. 4E)**: API-aligned causal paths mediate 0.749 ± 0.089 of the target effect, versus only 0.150 ± 0.121 (±0.022) for matched null paths — roughly a 5x difference. The recovered causal graph has sparsity 0.791 ± 0.023 and cross-seed Jaccard overlap 0.83, indicating the effect concentrates on a reproducible, sparse subset of paths rather than one unstable seed's idiosyncratic map. 7/64 candidate path/graph dimensions survive Benjamini–Hochberg FDR correction.
- **Directional robustness sweep**: Sharedness Gain remains positive across five additional backbones (Qwen2.5-7B, Mistral-7B, Gemma-2-9B, Phi-3-3.8B, plus the two detailed models), though this sweep only checks the *sign* of the effect, not a full re-run of the architecture/transplantation/mediation pipeline.

## Critical Assessment

**Novelty**: The forked-futures temporal control (sampling the operation only after the prefix state is cached) is a genuinely clean way to sidestep the standard "same current answer, unknown future divergence" confound that plagues probing-based interpretability work, and framing "is there a shared interface" as an explicit, capacity-matched architecture-selection contest (rather than just fitting one probe and declaring victory) is a meaningful methodological upgrade over typical linear-probe or SAE-feature papers.

**Rigor**: The four-pronged falsification design (OOD generalization, transplantation, mediation, synthetic model organisms) is unusually thorough for this subfield, and the authors are commendably honest about the one place it fails: 1 of 4 held-out Local organisms is misclassified as Shared (and another as Mixture) in the blind model-organism test, which they explicitly report as violating "fully satisfied" falsification rather than hiding it in an appendix. They also correctly caveat that the Sharedness Gain is a coding-cost (MDL) advantage at matched FSD, not a large gain in predictive fidelity (mean FSD differs by ≤0.011 across architectures) — an honest framing that avoids overclaiming a "smoking gun" for a literal shared workspace.

**Reproducibility**: Weakened by the complete absence of any code/data release link in the 50-page document, despite all experiments running on fully synthetic, generator-controlled data (four templated "forkable episode" families) that should be trivial to package and share. The supplement talks extensively about what a "reproducibility package" *should* contain (dataset manifests, fold-level records, framework/CUDA versions) but this appears to be prescriptive guidance rather than an actual released artifact.

**Significance/generalization concerns**: The two "detailed" models (Qwen2.5-1.5B, Llama-3-8B) on which every family-stratified, transplantation, and mediation conclusion rests are relatively small; the 5-backbone sweep (up to Gemma-2-9B) only checks the *direction* of Sharedness Gain, not whether the same transplantation/mediation story holds at larger scale. The ground-truth model organisms are tiny 6-layer, width-256, vocab-512 transformers trained for only 3,000 steps — the authors themselves note in Limitations that "synthetic organisms may also be easier to recover than mechanisms formed during large-scale pretraining," which is a real and unresolved gap between the controlled falsification test and the actual claims about Qwen/Llama.

**Red flags / weak points**: (1) the false-Shared error in the model-organism test (Local → Shared) directly undercuts the paper's central claim that Shared is preferentially and reliably identified, even though the authors disclose it; (2) the residual cross-family transplantation effect (CompScore 0.78 vs. 0.53 matched-random) is interpreted "conservatively" as possibly reflecting generic low-level feature compatibility rather than true shared causal identity — the paper acknowledges this ambiguity but cannot fully rule it out; (3) all four data families are synthetic and structurally templated (relation graphs, program registers, proof/discourse rules), so held-out "family" generalization is still within a closed, generator-controlled world — the authors state this is "stronger than template OOD but weaker than arbitrary natural conversation, open-domain dialogue, tool use, multilingual interaction, or long-context reasoning," directly limiting real-world applicability claims.

## Strengths

- Rigorous, falsifiable operationalization of "shared internal interface" via capacity-matched architecture competition rather than fitting a single probe and declaring success.
- Four independent, complementary validation arms (OOD splits, transplantation, mediation, synthetic model organisms) that each target a distinct alternative explanation (epiphenomenal decodability, content copying, patchability without mediation, coincidental architecture guessing).
- Transparent statistical protocol: paired family-level bootstrap, permutation tests, TOST equivalence testing, BH-FDR correction, with layer/rank/threshold choices frozen on validation data before test evaluation.
- Honest disclosure of a negative result (the Local→Shared misclassification) rather than suppressing it, and careful framing of the result as an "economy-of-reuse" claim rather than a large accuracy gain.

## Limitations

- Explicitly scoped to the tested models (mainly Qwen2.5-1.5B and Llama-3-8B), structured synthetic task families, selected layers/architectures, and a finite, pre-registered operation bank; the authors state new operation banks "may refine or split the empirical quotient."
- Natural-family holdout is acknowledged to be more controlled than open-domain dialogue, tool use, multilingual interaction, or long-context reasoning.
- Synthetic ground-truth organisms may be easier to recover than mechanisms that emerge from large-scale pretraining, so the model-organism validation may overstate real-model identifiability.
- Intervention/transplantation conclusions depend on donor/base matching choices, locality definitions, and the specific candidate path universe searched; redundant routes can compensate after blocking, and discrete locality metrics may miss subtler reasoning-trajectory changes.
- The 5-backbone Sharedness-Gain sweep tests only the sign/direction of the effect, not the full falsification pipeline, at larger model scales.

## Relevance

该工作为"大模型是否存在可复用的类全局工作区/统一接口"这一机制可解释性核心问题提供了一套严谨、可证伪的实验框架（预测性因果MDL + 移植/中介/模型有机体三重验证），对关注共享表征、电路发现、可解释性评测方法论的研究者有较高参考价值，但其结论目前局限于两个中小型模型和合成任务族，距离在真实预训练大模型/自然语言任务上的普适性结论尚有差距。

## Questions for Further Exploration

- Would the same architecture-selection/MDL protocol, when run on Qwen2.5-7B/Mistral-7B/Gemma-2-9B/Phi-3-3.8B with the *full* transplantation and mediation pipelines (not just directional SG), reproduce the same Shared-dominant ordering, or does the advantage shrink/vanish at larger scale?
- What specifically causes the one Local→Shared misclassification in the model-organism test — is it a property of the particular seed, the specific Local routing configuration, or a structural limitation of the FSD/MDL discriminability at the tested capacity settings?
- How sensitive is the Sharedness Gain to the choice of operation bank K and the π_K sampling distribution — would a much richer or adversarially chosen operation bank split the "Shared" interface into something closer to Mixture or Distributed?
- Does the recovered "Hidden API" correspond to any previously identified interpretable circuit or feature (e.g., from SAE/transcoder work on the same models), and can the two literatures be reconciled or cross-validated directly?
- Since no code/data release was found, would the reported MDL, FSD, and mediation numbers replicate under independent reimplementation, particularly given the many researcher-chosen hyperparameters (λ_r, λ_g, rank=64, FSD tolerance ε_f) that are "selected on validation data" but whose sensitivity is only partially explored?
