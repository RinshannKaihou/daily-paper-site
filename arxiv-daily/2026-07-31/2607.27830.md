> **一句话总结：** 本文发现高分辨率视觉问答（HR-VQA）失败很多时候并非因为视觉编码器没"看到"关键证据，而是证据在中间层被稀释/丢失；据此提出训练free、单次视觉编码+单次前向的 Thinking-Once 方法，用问题条件化注意力在某个中间层为每个实体/全局查询独立做"最小覆盖"证据选择、并对背景做网格均值池化后一起路由到深层，在 Qwen2.5-VL-7B/Qwen3-VL-8B/ZwZ 系列共 5 个基座模型上把 V*Bench、HRBench-4K、HRBench-8K 的平均分分别提升 +3.1/+3.0/+2.7，同时平均只保留约 21.4% 的视觉 token、显存降约 4GB，相比需要多轮/多图的 DeepScan 在 V*Bench 上推理时间减少 97.2% 而跨基准均分从 77.8 升到 79.1。

> **TL;DR:** Thinking-Once is a training-free, single-visual-pass inference method that reformulates HR-VQA as an *evidence-routing* problem rather than an *evidence-acquisition* problem: it reconstructs question-conditioned attention at one intermediate transformer layer, independently selects a minimum-coverage set of entity/global-query-relevant visual tokens ("core evidence"), mean-pools the remaining background into a spatial grid, and routes this compact representation to deeper layers. Across Qwen2.5-VL-7B, Qwen3-VL-8B, and three ZwZ models, it improves the average of V*Bench/HRBench-4K/HRBench-8K by +3.1/+3.0/+2.7 points while cutting peak memory by ~4GB and retaining only ~21% of visual tokens on average (Table 6); against the multi-round DeepScan baseline it improves the 3-benchmark mean from 77.8 to 79.1 while cutting V*Bench inference time by 97.2% (Table 2).

## 核心贡献

- **诊断新失败模式**：通过三种层级 oracle 干预（Random Tokens / Oracle Core Tokens / Remove Oracle Tokens，图2）和渐进式背景遮罩实验（图3）证明：（1）证据往往在中间层已经"可用且有影响力"，（2）证据核心（实体 token）信息密度高、不可被大量随机背景 token 替代，（3）适度保留背景上下文（关系、比较、属性线索）比只保留实体框内 token 或全部保留都更好——存在一个"证据路由窗口"（evidence-routing window）。
- **Thinking-Once 路由机制**：在某中间层 L，用问题里显式提及的实体锚点 + 一个全局问题 token 构成的路由查询集合，对视觉注意力行做选择性重建并归一化为分布 p_j(i)，然后对每个查询独立求解"最小基数覆盖"问题（覆盖阈值 ρ 的 top-p 式选择），得到核心证据集合 S_core；未被选中的背景 token 按空间网格做无参数均值池化，与核心 token 一起按原始光栅顺序重新拼接、路由进后续层。
- **形式化保证（附录A）**：证明了证据分布归一化、最小覆盖集的最小基数最优性、嵌套覆盖单调性、路由后序列长度上界、因果安全性（不会把未来位置信息泄漏到更早的路由位置）以及逐层 FLOPs/KV-cache 非增性等一系列命题——这在"训练-free 启发式"论文里是少见的严谨程度，但作者也明确声明这些性质不等价于"路由后语义等价于原模型"。
- **系统性验证**：在 5 个基座模型（Qwen2.5-VL-7B、Qwen3-VL-8B、ZwZ-4B/7B/8B）、3 个主基准（V*Bench、HRBench-4K/8K）及 4 个补充基准（MME-RealWorld-Lite、ZoomBench、TreeBench、POPE）上一致提升或持平；相较 11 个开源 HR-VQA 基线（外部证据重获取类 + 压缩优先类）取得三个基准上的最佳或并列最佳分数及最佳整体均值；受控实验（相同 33.3% token 保留比例、相同 max_pixel=1280）下仍优于 HiPrune/VisionZip/V²Drop/BTP/TRIO 等压缩基线，证明优势不是来自更大的输入预算而是来自"选谁保留"的策略本身。

## Key Contributions

- **Reframes HR-VQA failure as an evidence-*routing* (not evidence-*acquisition*) problem**: layer-wise oracle interventions (Random Tokens / Oracle Core Tokens / Remove Oracle Tokens, Fig. 2) and progressive background masking (Fig. 3) show that (a) question-relevant evidence is often already identifiable at intermediate layers, (b) entity-core tokens are information-dense and cannot be substituted by a larger budget of random tokens, and (c) moderate background removal helps while aggressive removal hurts — evidence needs "core + compact contextual support," motivating a design principle rather than pure compression.
- **Thinking-Once evidence-routing mechanism**: at one intermediate layer L, reconstructs question-conditioned attention rows only for a small routing-query set (entity-span anchors extracted from the question + one global question-context token), converts them to per-query probability distributions over visual tokens, performs *independent* minimum-cardinality (top-p-style) coverage selection per query at threshold ρ, mean-pools the unselected background into disjoint spatial grid cells, and reassembles core tokens + background summaries in original raster order before continuing the forward pass through deeper layers — with no extra visual encoding and no additional forward passes over the image.
- **Formal properties (Appendix A)**: proves normalization of the reconstructed evidence distribution, minimum-cardinality optimality and monotonic nesting of the coverage sets across ρ, an upper bound on the routed sequence length (Prop. A.6), causal safety of the ordered-merge operation under the decoder mask (Prop. A.7), position-encoding continuity for generated tokens (Prop. A.9), and non-increasing per-layer FLOPs/KV-cache cost (Cor. A.11) — while explicitly stating these guarantees do NOT establish that attention mass is a perfect measure of semantic sufficiency.
- **Broad empirical validation with ablations**: five base models, three primary + four supplementary benchmarks, controlled comparisons against 11 baselines under both native and matched-budget settings, and four component ablations (w/o background, denoised attention-sink, entity-only routing, global-only routing) isolating the contribution of each design choice.

## Methodology

Thinking-Once operates entirely at inference time on a single full-image visual encoding and one multimodal forward pass (no crop/zoom/re-encoding, no multi-round visual search). Given a D-layer MLLM and a chosen intermediate routing layer L < D:

1. **Routing-query construction**: The routing-query set Q_r = Q_ent ∪ {q_glb} combines (a) Q_ent, the last non-punctuation token of each entity span explicitly named in the question (extracted via a lightweight, unbatched, text-only LLM call to the same MLLM — e.g., "motorcycle" and "dog" for a comparison question), and (b) q_glb, the last non-punctuation question token, which under causal self-attention already aggregates the whole preceding question context.
2. **Selective attention reconstruction**: For each query q_j, the visual attention row from the MRoPE-transformed query/key states at layer L is reconstructed and head-averaged (Eq. 2–3) using FlashAttention-2 — only for the small Q_r set, so the full N×N attention matrix is never materialized. This gives a normalized per-query evidence distribution p_j(i) over the N visual tokens.
3. **Minimum-coverage evidence routing (independent per query)**: For a coverage threshold ρ ∈ (0,1), each query independently selects the shortest prefix of its sorted-by-probability tokens whose cumulative mass reaches ρ (a top-p / nucleus-style rule with fixed tie-breaking for determinism); the union across all queries forms the core set S_core. Independent per-query selection (rather than averaging distributions across queries) is shown in Fig. 5 to substantially increase ground-truth-evidence recall, since averaging would let one dominant query suppress tokens another query needs.
4. **Background grid pooling**: The visual grid is partitioned into disjoint cells G; unselected tokens in each active cell are mean-pooled (parameter-free) into one background summary token, preserving coarse spatial/contextual structure (relations, comparisons, attribute references) that pure entity-cropping would discard.
5. **Context-preserved reassembly and continued inference**: Core tokens (at full resolution) and background summaries are reordered by original raster position (OrdMerge) and substituted for the original visual subsequence, shortening the sequence fed to layers > L. MRoPE positions for background tokens use the centroid of the cell's original coordinates; generated tokens continue with positions strictly larger than any routed position, preserving causal safety and generation continuity (Appendix A, Props. A.7, A.9).

This differs from generic token-reduction methods (pruning/merging by attention score, similarity, or saliency) in objective: compression is a byproduct of routing a question-conditioned, per-query minimum-coverage evidence set rather than the primary goal.

## Results & Highlights

- **Main results (Table 1, average over 5 base models)**: Thinking-Once improves the mean of V*Bench / HRBench-4K / HRBench-8K averages by +3.1 / +3.0 / +2.7 points respectively, while reducing peak memory by ~4GB (from ~20GB to ~16GB). On the matched Qwen2.5-VL-7B base, V*Bench average rises 79.1 → 89.0 (+9.9), HRBench-4K 70.9 → 75.5 (+4.6), HRBench-8K 67.4 → 72.9 (+5.5), raising the overall 3-benchmark mean from 72.5 to 79.1. On the strongest base, ZwZ-8B, the overall mean reaches 82.7 (V*Bench 87.4→88.5, HRBench-4K 80.3→81.1, HRBench-8K 76.9→78.6).
- **Comparison with 11 open-source HR-VQA baselines (Table 2)**: against DeepScan (Li et al., 2026b) — an external evidence-reacquisition method needing ~180 minutes and up to ~40GB (2-GPU) on V*Bench — Thinking-Once achieves a comparable/better cross-benchmark mean (79.1 vs. 77.8) while cutting V*Bench inference time by 97.2% (from ~180 min to ~5 min) and running on a single GPU with ~16GB. Against DeepEyes (Zheng et al., 2026) and ViCrop (Khayatkhoei et al., 2025), which also require extra visual inputs/re-encoding, Thinking-Once matches or exceeds their means (76.0 and 75.2 respectively) at a fraction of the runtime (~5 min vs. ~28–37 min).
- **Token efficiency (Table 6, appendix)**: the retained visual-token ratio after routing is adaptive rather than fixed, averaging 21.41% across models/benchmarks (ranging 13.43% on ZwZ-8B/HRBench-8K to 30.52% on ZwZ-7B/V*Bench), i.e., roughly a 4–7x reduction in visual sequence length while accuracy improves.
- **Controlled comparison at matched compression ratio (Table 9, Qwen2.5-VL-7B, max_pixel=1280, all baselines retaining exactly 33.3% of visual tokens)**: Thinking-Once achieves the best average on all three benchmarks — V*Bench 75.9 (base 69.6, best competitor TRIO 70.2), HRBench-4K 67.6 (base 64.5, best competitor HiPrune 64.5), HRBench-8K 56.4 (base 55.1, best competitor HiPrune 54.3) — while remaining in the fastest runtime group (~3 minutes), confirming the gain is not an artifact of a larger input budget or GPU configuration.
- **Ablations (Table 3, Qwen2.5-VL-7B)**: removing background summaries drops the mean by 3.3 points (75.8 vs. 79.1 full); denoising/removing attention-sink tokens drops it by 4.4 points (74.7); entity-only routing (no global query) loses 3.4 points (75.7); global-only routing (no entity anchors) loses 7.9 points (71.2) — showing entity anchors provide the dominant localization signal while the global query supplies complementary attribute/relation/context demand, and background tokens carry necessary aggregation/contextual signal rather than pure redundancy.
- **Supplementary benchmarks on ZwZ-7B (Table 7)**: consistent gains on MME-RealWorld-Lite (overall 51.3→53.2, +1.9), ZoomBench (54.7→55.7, +1.0), TreeBench (31.9→33.4, +1.5), and POPE hallucination robustness (87.8→88.9 avg, +1.1 across random/popular/adversarial splits) — indicating the routing does not increase hallucination and even slightly improves it.
- **Anomaly disclosed candidly**: on ZwZ-4B, V*Bench average is identical before and after routing (89.0 → 89.0, Table 1), an honest null result the authors report rather than hide, suggesting diminishing returns when the base model/benchmark combination is already near-saturated.

## Critical Assessment

- **Novelty**: The core reframing — that HR-VQA failures can stem from ineffective *transmission* of already-encoded evidence rather than missing evidence — is a genuinely useful and underexplored angle, backed by non-trivial oracle-intervention analysis (Fig. 2, layer-wise Oracle-Core vs. Random vs. Remove-Oracle) rather than just black-box benchmark gains. The "evidence-routing window" concept and the independent per-query minimum-coverage argument (Fig. 5, showing averaged-query routing loses recall) are the most original technical contributions.
- **Rigor**: Unusually rigorous for a training-free inference trick — Appendix A supplies formal proofs (minimum-cardinality optimality, causal-safety of the merge operator, non-increasing FLOPs/KV-cache) that most competing token-reduction papers omit. The ablation studies (Table 3, and Tables 10–11 on ZwZ-7B/Qwen3-VL-8B) consistently show every component (background pooling, attention-sink retention, entity queries, global query) contributes, which is a stronger-than-usual ablation discipline.
- **Reproducibility concerns**: The coverage threshold ρ (the key hyperparameter controlling how much evidence is retained per query) is never given a concrete numeric value in the main text or the pages reviewed — only its qualitative behavior is described (Table 6 shows the *resulting* retention ratios, 13–31%, but not ρ itself or how it is tuned per model/benchmark). This is a meaningful gap for anyone trying to reproduce the exact operating point. The "Code is available in the appendix" claim also could not be substantiated from the reviewed pages.
- **Baseline framing**: The DeepScan comparison (180 min, ~40GB via 2-GPU OOM fallback) is a legitimate but structurally mismatched baseline — DeepScan is a multi-round, multi-image method by design, so the 97.2% time-reduction headline number, while accurate, compares different computational paradigms rather than two versions of the same paradigm; the paper is transparent about this distinction (labeling method categories explicitly in Table 2), which mitigates but does not eliminate the "impressive-sounding delta from an unequal comparison" concern.
- **Data quirk as evidence of honesty**: The ZwZ-4B zero-delta result on V*Bench (89.0 unchanged) is reported plainly rather than smoothed over, which is a positive signal against cherry-picking, though it also means the method's headline gains are not uniform across all five base models — the largest gains cluster on Qwen2.5-VL-7B and ZwZ-7B, with ZwZ-4B and Qwen3-VL-8B showing smaller improvements.
- **Missing extended layer-choice ablation in the main text**: while Fig. 5 (left) compares "Routing Layer" vs. "Midway" vs. "Final layer" query-routing strategies for GT-evidence recall, the main paper does not report a full accuracy-vs.-L sweep across all five base models — only the qualitative claim that intermediate layers define a viable "routing window." This leaves open how sensitive the results are to L outside the values actually used.
- **Significance**: If the reproducibility gaps (ρ value, exact L per model) are resolved, this is a practically appealing, deployment-relevant result: a genuinely training-free method that both improves accuracy and reduces memory/latency simultaneously, which is a rarer combination than accuracy-only or efficiency-only papers in this space.

## Strengths

- Identifies and empirically substantiates a new failure mode (ineffective intermediate-layer evidence transmission) via careful oracle-intervention diagnostics rather than asserting it.
- Training-free and single-visual-pass — no fine-tuning, no additional visual encoding, no multi-round search — making it easy to layer onto existing deployed MLLMs.
- Simultaneously improves accuracy *and* reduces memory/KV-cache/token count, rather than trading one for the other.
- Strong formal treatment of the routing operator's properties (causal safety, sequence-length bounds, coverage guarantees) in Appendix A.
- Broad evaluation: 5 base models, 3 primary + 4 supplementary benchmarks, 11 baselines, matched-budget controlled comparisons, and 4-way component ablations replicated on two additional base models (Tables 10–11).
- POPE results show the routing does not induce additional hallucination, addressing an obvious concern about aggressive token compression.

## Limitations

- The method's applicability boundary is explicitly acknowledged by the authors: it cannot recover information the vision encoder never captured, and cannot help when the relevant image region is not represented in the initial encoding at all — it is complementary to, not a replacement for, crop/zoom/visual-search methods when genuinely new observation is required.
- The key hyperparameter (coverage threshold ρ) and the chosen routing layer L per base model are not clearly specified with concrete values in the sections reviewed, limiting exact reproducibility.
- Gains are uneven across base models (e.g., no V*Bench improvement on ZwZ-4B), suggesting the technique's benefit depends on how much "recoverable but underutilized" evidence a given base model already has.
- Requires an auxiliary text-only entity-extraction LLM call before the routed multimodal pass; although cheap and included in the reported ~5-minute runtime, this is a second inference invocation, so "single visual pass" refers to visual encoding specifically, not to the total number of model calls.
- Benchmarks used (V*Bench, HRBench, MME-RealWorld-Lite, ZoomBench, TreeBench, POPE) are all standard HR-VQA/perception benchmarks; no evaluation on open-ended generation, multi-turn dialogue, or video, so generalization beyond single-image high-resolution QA is untested.

## Relevance

该工作对研究"高分辨率多模态感知效率"和"KV-cache/token 压缩"的读者有直接参考价值：它提供了一种不需要额外视觉输入即可兼顾精度与效率的路由范式，且给出了严谨的中间层证据窗口分析框架，可能对设计新的注意力驱动 token 选择/压缩方法有借鉴意义。

## Questions for Further Exploration

- What concrete value(s) of the coverage threshold ρ and routing layer L were used per base model/benchmark, and how sensitive are the reported gains to these choices?
- How does Thinking-Once compose with actual visual-search/zoom methods (e.g., applying routing after a crop/zoom step) rather than being evaluated only as an alternative to them?
- Does the entity-extraction step degrade for questions without explicit named entities (e.g., purely relational or counting questions with pronouns), and how robust is q_glb alone in that regime?
- How does the method scale to video or multi-image interleaved inputs, given Appendix A's Remark A.5 sketches the generalization but no experiments test it?
- Would the independent per-query minimum-coverage selection remain effective as the number of routing queries grows substantially (e.g., questions naming many entities), given union size could approach the original token budget?
