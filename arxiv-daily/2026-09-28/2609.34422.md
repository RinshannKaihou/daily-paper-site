> **一句话总结：** 京东团队构建了 4 个长程智能体 RL 环境 CAMG（Shop/Coding/DeepResearch/AutoResearch），让单一策略通过全异步 PPO 直接用普通文件系统操作（读写工作区文件）作为跨上下文边界的记忆，Qwen3.5-4B 训练后在 512 个测试任务上平均成功率 54.4%（次优 CompactionRL 48.0%），且 4B/9B 模型在外部 SWE-bench Verified 上分别追平 35B-A3B（15.8% vs 15.6%）和超过 122B-A10B（27.6% vs 22.0%）。

> **TL;DR:** JD.com introduces CAMG, a suite of four long-horizon agentic-RL environments (Shop, Coding, DeepResearch, AutoResearch) that each pair a native task interface with a shell-accessible episode-persistent workspace, and CAMG-RL, which trains a single Qwen3.5-4B/9B policy with fully asynchronous PPO to use ordinary file operations as memory. On the 512-task CAMG test set it reaches 54.4% average success vs 48.0% for the strongest learned baseline CompactionRL (+6.4 pts, bootstrap CI [3.3, 9.5]) and 25.3% for AgeMem. On external transfer, CAMG-RL-4B resolves 15.8% of SWE-bench Verified (matching frozen Qwen3.5-35B-A3B at 15.6%) and CAMG-RL-9B resolves 27.6% (beating frozen 122B-A10B at 22.0%). The mechanism analysis is the real contribution: the frozen base already prefers filesystem actions (0.25 vs 6.37 nats/token on store intents vs AgeMem's dedicated tools), and RL converts this prior into complete store-retrieve-use chains (8.0% → 20.9% of episodes) while moving weights by only ||ΔW||/||W|| ≈ 0.0022.

## 核心贡献

- **CAMG 环境套件**：4 个可验证的长程智能体 RL 环境——Shop（基于 WebShop 的 6 会话购物，720 个验证商品、576/144 训练/测试划分）、Coding（SWE-smith 筛出的 11,218 个可执行仓库修复任务，93 个仓库）、DeepResearch（LiteResearch 的 Search+Visit 证据累积，26,597 个任务）、AutoResearch（OpenMLE 公开任务包，931 个任务/804 个任务族）。每个环境都强制任务跨越上下文边界（主动上下文被替换，信息必须外置才能存活）。
- **统一编码智能体接口**：所有环境共享一个 `shell_command` 动作 + episode 持久工作区；环境在上下文边界强制要求策略自己写 `.agent_memory/CONTINUATION.md`（≤8,192 字节）作为检查点，之后靠普通文件读写恢复状态——不用任何专用记忆工具。
- **CAMG-RL 训练算法**：单一任务策略在 4 个环境上联合训练；双粒度 PPO（每个 response 一个 GAE 优势、每个 token 独立裁剪比率，介于 Turn-PPO 的粗粒度和 token 级 SAO 的高方差之间）；全异步 rollout/学习（持久 episode 队列吸收变长轨迹），奖励直接来自下游任务成败，记忆动作无需专用 credit assignment。
- **系统性机制研究**：证明冻结基座本来就偏爱文件系统动作（surprisal 0.076–1.193 nats/token，专用记忆工具 0.653–3.927）；RL 训练把这种偏好转化为完整 store-retrieve-use 链（训练季度间 8.0%→20.9%），而权重几乎不动（‖ΔW‖/‖W‖≈0.0022）；blanking/shuffling 记忆内容分别使平均成功率下降 14.1/11.5 个百分点，证明是内容本身而非动作在起作用。
- **外部迁移与成本**：CAMG-RL-4B/9B 在 SWE-bench Verified 和 MLE-bench Lite 上分别追平 Qwen3.5-35B-A3B 和 122B-A10B；单次训练仅需约 120–140 GPU 小时（6 张训练 GPU，19.6–23.2 小时墙钟）。

## Key Contributions

- **CAMG**: a four-environment long-horizon agentic-RL suite (Shop/Coding/DeepResearch/AutoResearch) where every task crosses a context boundary, each pairing its native interface with a shell-accessible, episode-persistent workspace — no dedicated memory tools anywhere.
- **CAMG-RL**: joint training of one task-acting policy with fully asynchronous PPO and a dual-granularity estimator (one GAE advantage per response, per-token ratio clipping), so filesystem writes get credit purely from downstream task reward.
- **A mechanism-level empirical study**: frozen-base surprisal probes, name-token decomposition, aliased-tool and documentation-deletion controls, memory-content blank/shuffle interventions, and failure decomposition showing RL elicits reusable memory by channeling a pre-trained preference for file operations rather than teaching new capabilities from scratch.
- **Headline empirical result**: highest average CAMG success (54.4%) and external competitiveness of 4B/9B trained models with 35B/122B frozen models on SWE-bench Verified and MLE-bench Lite.

## Methodology

**Environments.** Each CAMG environment is a finite-horizon POMDP where the active context is replaced at task-defined boundaries; information gathered earlier survives only if written to the episode-persistent workspace. (1) *Shop*: six-session WebShop-style purchases synthesized from 720 verified products across 8 cross-session dependency families (attribute chains, latent preferences, distractor robustness...), with exactly one valid six-purchase sequence per episode. (2) *Coding*: 11,218 executable SWE-smith issue-repair tasks from 93 repositories, hidden-test grading, terminal `COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT` sentinel. (3) *DeepResearch*: 26,597 LiteResearch Search+Visit tasks, accepted by a frozen Kimi-K2.6 semantic judge shared by every method. (4) *AutoResearch*: 931 public OpenMLE packages graded by native metrics with a frozen generic baseline; direction-normalized private-grade score is the reward. All episodes run in network-isolated Linux sandboxes; failures (invalid actions, exhausted budgets, missing submissions) count in the fixed 128-task-per-environment test denominator.

**Shared interface.** One `shell_command` tool over the workspace root (create/inspect/search/modify/execute), following mini-swe-agent conventions; only regular files under `.agent_memory/` count as memory. At a boundary, the environment requires one policy-authored write of `.agent_memory/CONTINUATION.md` (≤8,192 bytes) within a bounded retry; after a valid write it swaps the message history for fixed task instructions, leaving file contents to be re-read by ordinary reads.

**CAMG-RL.** Joint objective J = (1/|D|) Σ_d J_d over the four environments. Task responses and filesystem responses live on one trajectory; GAE (γ=λ=1) propagates terminal rewards back to earlier memory-writing responses. *Dual-granularity PPO*: one advantage per response (stable like Turn-PPO) assigned to every token, with the PPO ratio computed and clipped per token (fine-grained like SAO), ε=0.2, advantages centered per-environment and weighted by inverse environment token counts. *Fully asynchronous training*: rollout workers append completed episodes to a persistent queue consumed oldest-dispatched-first; the learner takes 64 episodes per update (200 updates, 12,800 episodes total) in 510-response minibatches, so no worker waits on the slowest environment. Backbone Qwen3.5-4B (and 9B for external tests), AdamW lr 1e-6, BF16 + FSDP2 + SGLang, 6 training + 2 generation GPUs, 30,720-token prompts / 8,192-token responses.

**Baselines.** Training-free controls on the frozen 4B base: Mem0, Letta Code (git-backed MemFS). Learned baselines under identical protocol, schedule, async PPO, and rewards: CompactionRL (learned context compaction) and AgeMem (six dedicated LSTM/STM memory tools), the latter also replicated under its original three-stage GRPO recipe.

**Evaluation.** 512 CAMG test tasks (128/env, disjoint splits by product/repository/duplicate-question-group/task-family), matched greedy decoding, action budgets, runtimes and graders. External transfer on SWE-bench Verified (500 tasks, official grader) and MLE-bench Lite (22 competitions, Any-Medal rate), with binomial 95% CIs, paired bootstrap tests (10,000 resamples), and 5-seed robustness checks for the two strongest learned methods.

## Results & Highlights

- **CAMG test set (512 tasks, success rate)**: CAMG-RL-4B averages 54.4% vs 48.0% for the strongest learned baseline CompactionRL (+6.4 pts; paired bootstrap 95% CI [3.3, 9.5]) and 25.3% for AgeMem; frozen Qwen3.5-4B sits at 17.4%, Mem0 at 19.7%, Letta Code at 17.8%. Per environment: Shop 97.1 vs 97.5 (both saturated), Coding 26.6 (tied with CompactionRL), DeepResearch 55.5 vs 50.8, AutoResearch 38.3 vs 24.2.
- **External transfer (distribution shift)**: on SWE-bench Verified, CAMG-RL-4B resolves 15.8% vs 15.6% for frozen Qwen3.5-35B-A3B (binomial CIs [12.7,19.3] vs [12.5,19.4] overlap almost completely), while CAMG-RL-9B reaches 27.6% vs 22.0% for frozen 122B-A10B (+5.6 pts, CIs [23.7,31.7] vs [18.4,25.9] separate). On MLE-bench Lite (Any Medal): 4.5% (4B, matching the frozen 9B/27B/35B) and 9.1% (9B, matching 122B-A10B); the untrained Qwen3.5-4B base scores 7.6% and 0.0%.
- **Both ingredients are necessary (ablations on the same 512 tasks)**: removing memory-action gradients from the actor loss drops the average to 21.1% (near the 17.4% frozen base); training and evaluating with only the mandated CONTINUATION.md as memory reaches 41.8% vs 54.4% for the full policy; restricting the full policy's evaluation to the continuation file alone yields 28.1%. Replacing response-level advantages with per-token GAE costs 4.3 points (50.1% vs 54.4%).
- **Memory content is causal**: blanking saved memory files at the first context replacement cuts average success by 14.1 points and transplanting length-matched task-mismatched content cuts 11.5 (largest blank drop in Shop, −29.4; largest shuffled drop in DeepResearch, −16.7; both reduce success in every environment).
- **Interface prior quantified**: on the frozen base, filesystem memory actions cost 0.076–1.193 nats/token across store/retrieve/revise/remove intents, while AgeMem's six dedicated tools cost 0.653–3.927 nats/token (store: 6.371 vs 0.252 nats in native form); renaming the filesystem tool keeps surprisal within 0.013 nats, whereas AgeMem attempts its tools in only 53 of 261,941 training responses and never completes a chain, versus CAMG-RL's complete store-retrieve-use chain rate rising from 8.0% to 20.9% of episodes. A single out-of-distribution `apply_patch` tool as the file interface trails at 48.6% with an 11.7% final-quarter parse-failure rate (vs 0.61% for shell edits).
- **Robustness and cost**: across 5 training runs each, CAMG-RL averages 55.3 ± 2.9 vs CompactionRL's 47.1 ± 3.5 (CIs [52.4,58.2] vs [43.6,50.6] disjoint); AgeMem under its original recipe still trails at 38.7% (−15.7). Every formal run finishes in 19.6–23.6 wall-clock hours (~120–140 GPU-hours on 6 training GPUs).

## Authors & Credibility

The 13 authors are from JD.com (the JD logo and affiliation appear on the title page); the first author, Lirui Luo, maintains the project page (https://liruiluo.github.io/agentmemorygym/), and senior authors include Sulong Xu and Cong Fang, who lead applied LLM/search work at JD. Credibility signals are strong: the team operates its own fully asynchronous agentic-RL infrastructure (FSDP2 + SGLang, five-seed training runs), documents complete hyperparameter/reward/failure-accounting tables, runs contamination checks against external benchmarks, and includes an explicit AI-use statement. The work is an arXiv preprint (v2, 30 Sep 2026) not yet tied to a peer-reviewed venue, and the reproducibility statement promises that "the final release will include the code" — code availability at review time is a project page, not a verified public repository, which slightly tempers reproducibility until the release lands.

## Critical Assessment

**Novelty.** The core insight — don't invent memory tools, RL-finetune the coding agent's own pre-trained file operations into a memory mechanism — is genuinely well-executed rather than radically new: PRO-LONG and Zhu et al. already expose filesystem state as memory, and learned memory control (Memory-R1, AtomMem, AgeMem) exists; CAMG's differentiator is end-to-end RL of filesystem memory across verifiable, cross-context tasks in four domains, plus the interface-prior explanation. That explanation is the paper's best claim to novelty and is supported with unusually careful causal probes.

**Rigor.** Above average for this space: paired bootstrap CIs, a 5-seed robustness check, a failure taxonomy (58 of 94 Coding failures are wrong fixes vs 35 budget exhaustions), a baseline retrained both under the common protocol and its original recipe, and a blank/shuffle content intervention. Two weak points stand out. First, the abstract's "competitive with Qwen3.5-35B-A3B and 122B-A10B" claim is statistically thin for the 4B pairing — the paper itself reports the SWE-bench CIs "[12.7,19.3]" and "[12.5,19.4]" "overlap almost completely," so the 4B result is a non-separation, not a win; only the 9B vs 122B SWE-bench comparison actually separates. Second, the average CAMG gap over CompactionRL leans on environments where the comparison is uninformative: Shop is at ceiling for both (97.1 vs 97.5) and the DeepResearch paired CI [−1.4, 11.4] includes zero, leaving Coding and AutoResearch as the only significant per-environment wins.

**Reproducibility.** Hyperparameters, rewards, split construction, and evaluation protocols are documented to an unusually high standard, and training costs are modest enough (~120–140 GPU-hours) for academic replication — but code is only promised. DeepResearch success depends on a frozen third-party judge (Kimi-K2.6), a single-judge point of failure shared by all methods, and the Shop tasks are fully synthesized with exactly one valid purchase sequence, so the eight dependency families are partly author-designed artifacts whose difficulty profile cannot be independently sanity-checked until release.

**Significance and red flags.** The "memory" is scoped to a single episode and a single user, and the environment mandates the checkpoint write at every boundary — the learned part is what surrounds that scaffold, and the 41.8% continuation-only ablation shows a large share of the gain survives on the scaffold alone, so headline numbers should be read with that subsidy in mind. External absolute numbers are modest (15.8% SWE-bench Verified), and external comparison is only against the frozen Qwen3.5 family — no strong external agent scaffold (e.g., mini-swe-agent with its own compaction, or AgentFold-style systems) is run on SWE-bench for context. There is also a small internal inconsistency: Appendix C.1/D text says the eval-restricted variant "collapses Shop to 0%," while Figure 4 shows the retrained-without-general-files variant at Coding 0.0% and the eval-restricted variant at Shop 12.4% — cosmetic, but it obscures which variant fails where. Finally, ‖ΔW‖/‖W‖ ≈ 0.0022 cuts both ways: it supports the elicitation story, but combined with 61.7% of Coding failures being outright wrong fixes, it confirms the 4B backbone, not the memory machinery, is the capability ceiling.

## Strengths

- Reframes agent memory as *eliciting pre-trained behavior* rather than teaching a new tool API, and backs the claim with a rare battery of causal controls (name-token decomposition, aliased names, documentation deletion, content blank/shuffle).
- Statistically disciplined: paired bootstrap intervals, 5-seed robustness, fixed failure denominators, explicit contamination analysis against SWE-bench Verified and MLE-bench Lite.
- Practical training recipe: fully asynchronous PPO with a persistent episode queue absorbs variable-duration episodes; ~20 GPU-hours per run puts replication within academic reach.
- Honest failure accounting: all failures count in the denominator, infrastructure faults are re-run at most twice, and the Coding failure taxonomy separates memory behavior (writes and reads its checkpoint in 94/94 boundary episodes) from fix-quality headroom.
- Dual-granularity PPO (response-level advantage, token-level clipping) is a simple, ablated (+4.3 pts over per-token GAE) contribution useful beyond this paper.

## Limitations

- Memory scope is one episode and one user; cross-episode and cross-user memory are explicitly future work, and backbones top out at 9B.
- The environment-mandated CONTINUATION.md checkpoint means part of the measured "memory" ability is scaffolded; only the store-retrieve-use chain rate (8.0%→20.9%) measures voluntary memory use.
- Statistical strength of the headline external claim is limited: the 4B vs 35B SWE-bench comparison is a non-separation, and the CAMG average advantage over CompactionRL is only significant on 2 of 4 environments.
- Self-built environments (synthesized Shop dependency families; single frozen semantic judge for DeepResearch) are not externally validated; code not yet released at the time of writing.
- No comparison on external benchmarks against strong non-Qwen scaffolds or frontier commercial agents; MLE-bench Lite absolute scores (4.5–9.1% Any Medal) are far from practical utility.

## Relevance

与你最高优先级的「自进化智能体与自动化研究」直接相关：AutoResearch 环境就是一个可验证的自动化 ML 研究循环，而"用 RL 把智能体自身的文件操作变成跨上下文记忆"正是长时程自主体可靠性的关键组件。其接口先验分析方法（冻结基座对文件动作的低困惑度 + 训练几乎不动权重）也为判断哪些能力可以被 RL"激发"而非"教会"提供了可复用的诊断手段。

## Questions for Further Exploration

- Does the filesystem-memory prior transfer to larger backbones (30B+) where wrong-fix failures dominate, or does the elicitation advantage shrink as base competence grows?
- Can memory persist across episodes and users — does the same RL recipe learn cumulative, reusable knowledge files, or does the single-episode workspace cap what the policy can express?
- How would CAMG-RL fare against strong external scaffolds (mini-swe-agent with compaction, AgentFold-style context folding) on SWE-bench Verified, rather than only against the frozen Qwen3.5 family?
- The continuation file is environment-mandated; what happens with a purely voluntary checkpoint regime — does the 41.8%→54.4% gap widen because the policy fails to checkpoint at all?
- Is the AgeMem gap really about out-of-pre-training-distribution tools, or partly about tool-parse friction (11.7% parse failures for the OOD apply_patch variant)? A curriculum that gradually introduces dedicated tools might separate these explanations.
- DeepResearch success rests on one frozen semantic judge (Kimi-K2.6); how sensitive are the rankings to judge choice, and would an executable-evidence grading scheme change the DeepResearch ordering?
