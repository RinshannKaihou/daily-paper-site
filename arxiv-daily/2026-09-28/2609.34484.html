02 · Why this matters — 为何重要

把奖励设计变成可审计的智能体工作流：提出主张 → 独立取证核验 → 修订，甚至能回头审计已有的外部奖励模型。

Reward design becomes an auditable propose–verify–revise agent workflow that can audit external reward models — a reusable template for multi-agent verification systems.

03 · Critical edge — 冷静一刀

头号基准是作者自建的，双物体短场景恰好是事件核验的理想局；最亮眼的真实产线结果只有单一训练种子、无置信区间。

01

How it works · 方法拆解

two agents · one VLM · zero training
S1子代理提议事件Subagent reads instruction + trajectory, proposes an event timeline with cited visual evidence.
→
S2硬约束校验Harness forces full-trajectory coverage; incomplete coverage is returned for correction.
→
S3主代理独立核验Adaptive inspection: temporal windows, sampling density, spatial crops. Revision invalidates confirmation.
→
S4逐帧进度曲线Progress read off the verified timeline; self-check tools expose jumps and shape.
→
S5Δ 选块训练 BCChunks of H=10 kept when Δ = p(t+H) − p(t) > threshold; π0.5-style stage-dependent top-α.

ARS replaces the trained reward model with a two-agent inference loop over a single general-purpose VLM (Qwen3.6-27B). A subagent proposes an event timeline — each task-relevant event tied to cited visual evidence. A primary agent then verifies each event in a separate reasoning context, using adaptive visual inspection: tool calls that pick temporal windows, sampling density and spatial crops on demand, so later frames can resolve earlier ambiguities. From the verified timeline it reads off a per-frame progress curve.

Policy learning never trains a reward model: behavior-cloning chunks are kept when their progress increment Δ crosses a threshold — zero, or stage-dependent top-α after π0.5. Optional integrations: terminal outcome labels, in-context visual references, and auditing external reward curves — Robometer's predictions become candidate claims that ARS confirms, revises or vetoes.

Harness rules · 流程约束

  • Confirmation requires evidence gathered by the primary agent itself — event interior plus surrounding context.
  • Context separation matters: single-context operation loses −6.1 pts of policy success, with higher token usage.
  • Ablations: no verification → 52.3%; no verification+inspection → 45.4%; GVL-style single prompt on the same 27B collapses VOC 0.995 → 0.637.

评测协议。自建语义错配基准在 ManiSkill 中给每个场景放两个候选物体，用特权仿真状态确认夹爪从未接近错配物体，专门度量"给错误操作记进度"的倾向。三个互补指标：VOC（正确指令下进度与时间步的秩相关）、FPSR（错配轨迹的虚假进度抑制率）、CMPG（正确指令终点进度 − 错配指令峰值进度）。

策略学习设置。LIBERO-Long 使用固定行为策略的 4,096 条混合质量 rollout（2,204 成功 / 1,892 失败，平均 390.3 帧）、π0.5 检查点、H=10、零阈值选块与共享训练日程；真实实验为洗衣机背板 3 螺丝拧紧产线（2,574 演示 + 3,092 离线 rollout，200 次完整任务试验）。

03

Verdict · 强与弱

strengths vs limitations

Strengths优势

  • Reframes reward modeling as inference-time verification — claim generation cleanly separated from claim checking, and that separation is ablated (+6.1 pts).
  • FPSR / CMPG expose what VOC misses: near-perfect frame ranking (0.983) can still flood wrong-object trajectories with spurious progress.
  • Zero training: runs on an off-the-shelf open-weight 27B VLM — reproducible now, improves for free as base models improve.
  • External auditing is composable: upgrades Robometer (FPSR 0.240 → 0.915) instead of competing with it.
  • Evaluation spans synthetic control, simulation, and a real assembly line, with unusually thorough ablations; code + benchmark pipeline released.

Limitations局限

  • ~24.9K queries / ~1M tokens per data pass — costlier than single-pass models; practical only for offline curation. Distillation is future work.
  • No online / causal reward: the workflow needs later trajectory evidence to resolve earlier ambiguity.
  • Self-built benchmark, short-horizon two-object scenes; no third-party reward-modeling benchmarks evaluated.
  • Real-robot evidence is thin: one task (3-screw fastening), one training seed, one robot cell — no cross-task variance.
  • Weighted BC only: compatibility with RL-based value learning is cited, not exercised.
  • The headline 81.5% uses visual references + labels — information beyond raw trajectories, weakening the "no privileged information" claim.
04

Open questions · 值得追问

for further exploration
Q1

蒸馏能走多远？

Can ARS supervision be distilled into a lightweight reward model cheaply enough to close the inference-overhead gap — and how much accuracy survives?

Q2

超出"错物体"场景还灵吗？

Does the advantage hold when spurious progress is not object-identity-based — wrong force, wrong timing, partial insertion — where visual verification is harder?

Q3

视觉参照有多敏感？

The 72.0% → 81.5% jump suggests sensitivity to reference curation: how many examples, and when do gains saturate or invert?

Q4

选块协议是否偏袒 ARS？

Reward-trained baselines failed partly on retention artifacts (<14% chunks kept). A selection-rule-matched comparison could disentangle this.

Q5

约束可否移植？

Can harness-enforced evidence constraints (full coverage, re-confirmation after revision) transfer to auditing LLM reasoning traces or autonomous research pipelines?
