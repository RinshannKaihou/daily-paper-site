> **一句话总结：** Midea AIRC 提出 ARS——一个免训练的多智能体 VLM 推理框架，用"子代理提议事件时间线 + 主代理自适应视觉核验 + 事件驱动进度估计"来替代训练式 reward model：在自建 ManiSkill 语义错配基准上把虚假进度抑制率（FPSR）从最强专用基线 Robometer 的 0.240 提到 0.918；在 LIBERO-Long 离线策略学习上把行为克隆成功率从 44.2% 提到 57.9%（ strongest 奖励基线 TOPReward-32B 仅 47.6%）；在真实洗衣机产线螺丝拧紧任务上把 demo-only BC 的 58.0% 拉到 81.5%。

> **TL;DR:** ARS replaces trained robot reward models with an agentic inference workflow on a 27B VLM (Qwen3.6-27B): a subagent proposes task-relevant events over the trajectory, a primary agent adaptively inspects visual evidence (temporal windows, sampling density, spatial crops) to verify/revising each event, then reads per-frame progress off the verified event timeline — no reward-model training at all. On a self-built ManiSkill semantic-mismatch benchmark (500 pairs, wrong-object instructions), ARS scores VOC 0.995 / FPSR 0.918 / CMPG 0.904 versus Robometer's 0.983 / 0.240 / 0.366 and R²VLM's negative CMPG of −0.050. For offline policy learning on LIBERO-Long, ARS-filtered behavior cloning reaches 57.9% success vs 44.2% Vanilla BC (+13.7 pts) and 47.6% for the strongest reward baseline TOPReward + Qwen3-VL-32B (+10.3 pts), while using 93.6% fewer model queries. On a real washing-machine multi-screw fastening line, ARS data selection plus visual references lifts demo-only BC from 58.0% to 81.5%.

## 核心贡献

- **免训练的智能体化奖励系统**：ARS 把"进度奖励建模"从训练专用 reward model 转为一个两代理推理流程——子代理从指令+离线轨迹中提出任务相关事件，主代理在独立推理上下文中核验、修订这些事件，再基于已证实事件估计逐帧进度；全程只用一个通用 VLM（Qwen3.6-27B），零额外训练。
- **自适应视觉检查（adaptive visual inspection）**：两个代理都通过工具调用按需选择时间窗口、采样密度和空间裁剪，由"未解决的事件主张"驱动回顾性取证——论文强调证据的时间跨度和空间位置因事件而异，一次性喂全视频并不能保证检查到位。
- **受控语义错配基准**：在 ManiSkill 中构造"正确指令 vs 指向另一物体错配指令"的配对（25 种任务类型、500 对/1,000 条样本、专家运动规划轨迹），专门度量 reward/progress 系统给错误操作记虚假进度的倾向；揭示多个已发表系统（如 R²VLM）在此设置下失效。
- **外部奖励审计**：ARS 可以把外部 reward model（如 Robometer）的进度曲线当作"候选主张"来审计——用视觉证据保留/修订/否决其预测，审计后 Robometer 的 FPSR 从 0.240 升到 0.915、CMPG 从 0.366 升到 0.891，说明验证工作流可以复用已有模型而非取代它们。
- **面向下游的进度驱动策略学习**：用进度增量 Δ = p_{t+H} − p_t 做行为克隆的数据选择（零阈值或分阶段 top-α 阈值），在 LIBERO-Long 仿真和真实工业拧螺丝任务上验证，并给出可选的结局标签条件化与视觉参照集成。

## Key Contributions

- **ARS**, a training-free agentic framework for progress reward modeling: a subagent proposes an editable event timeline with cited visual evidence; a primary agent verifies and revises each event under adaptive visual inspection (temporal windows, sampling densities, spatial crops) before estimating per-frame progress — general-purpose VLM only, no additional reward-model training.
- **A controlled semantic-mismatch benchmark** on ManiSkill (two candidate objects per scene, 25 task types, 500 matched pairs / 1,000 samples, privileged simulator states verifying the gripper never approaches the mismatch object) that isolates spurious credit assignment for wrong-object manipulation; several published reward baselines assign more peak progress to mismatched instructions than to correct ones.
- **Evidence that inference workflow matters more than model choice**: ARS with the same 27B backbone far outperforms a GVL-style single-prompt variant (VOC 0.637 vs 0.995), and full ARS beats its own no-verification/no-inspection ablations by 4.6–12.5 points on LIBERO-Long policy success.
- **External reward auditing**: ARS audits Robometer's progress curves, raising its FPSR from 0.240 to 0.915 and CMPG from 0.366 to 0.891 while retaining VOC 0.988 — reusing existing reward models rather than replacing them.
- **Long-horizon policy learning gains in simulation and on a real industrial task**: +13.7 pts over Vanilla BC on LIBERO-Long (57.9% vs 44.2%) with 93.6% fewer model queries than TOPReward, and 58.0% → 81.5% success on a full-scale washing-machine multi-screw fastening line.

## Methodology

**Problem setup.** Given an offline trajectory τ = (o_{0:T}, a_{0:T−1}, l) and instruction l, a reward system f predicts per-frame task progress p_{0:T+1} ∈ [0,1]. Estimating progress at time t may require observations beyond o_{0:t} (e.g., an apparent grasp is only confirmed when the object is later lifted), which motivates retrospectively guided, adaptive inspection.

**Adaptive visual inspection.** Agents issue tool calls to fetch selected frame intervals with configurable temporal sampling density and optional spatial crops. Requests are guided by the agent's current question, and returned evidence informs subsequent requests; the workflow allows later observations to resolve earlier ambiguities.

**Event-grounded reasoning.** The trajectory is represented as a timeline of task-relevant events, each associating a temporal interval with a description grounded in cited visual evidence. The harness (tool environment) maintains the event timeline across reasoning contexts and enforces constraints: before proposal can finish, event evidence must cover the complete trajectory; failed coverage checks return the missing intervals for correction, making incomplete coverage actionable rather than silent.

**Cross-agent verification.** A subagent constructs the event timeline in one reasoning context; a primary agent then gathers additional visual evidence to verify and revise those proposals in a separate context. Confirmation requires evidence acquired during primary-agent verification (the harness checks sampled frames include the event interior plus preceding/following context); revising an event invalidates its confirmation and forces re-checking. The separation keeps event proposals without the subagent's full interaction history, freeing primary-agent capacity — an ablation shows single-context operation loses 6.1 points of policy success.

**Progress estimation.** The primary agent builds the progress curve from verified events via tool calls, choosing between interpolated segments and pointwise edits; summary tools expose curve shape and jump locations/magnitudes so the agent can check its own estimates against evidence.

**Flexible integration.** Optional inputs: (1) trajectory-level terminal success/failure labels to anchor terminal completion while preserving local regressions; (2) in-context references (images, clips, textual descriptions, positive/negative examples with optional numeric progress annotations); (3) external reward auditing, where an external model's curve is treated as a candidate to be inspected and revised.

**Progress-guided policy learning.** For chunks of H consecutive actions, Δ_t = p_{t+H} − p_t; an indicator I_t = 1[Δ_t > ε(p_t)] selects chunks for a binary-weighted behavior-cloning objective. Two threshold rules: zero threshold (keep only positive-progress chunks) or stage-dependent thresholding (split [0,1] into B bins; rank chunks within each bin by Δ_t and keep top fraction α, following advantage thresholding from Physical Intelligence's π0.5 work).

**Evaluation protocol.** Three complementary metrics on the semantic-mismatch benchmark: VOC (mean per-trajectory Spearman rank correlation between predicted progress and timestep under correct instructions), FPSR (fraction of mismatch-trajectory duration NOT covered by strictly positive progress-increase intervals — higher is better suppression), and CMPG (mean terminal progress under correct instructions minus mean peak progress under mismatched ones). Policy learning uses a fixed behavior policy's 4,096 LIBERO-Long rollouts (2,204 successful / 1,892 failed, avg 390.3 frames), π0.5 checkpoints, chunk horizon H = 10, zero-threshold selection, and a shared training/evaluation schedule.

## Results & Highlights

**Semantic-mismatch benchmark (Table 1, ManiSkill, 500 pairs / 1,000 samples):**
- ARS + Qwen3.6-27B leads all three metrics without reward-model training: **VOC 0.995, FPSR 0.918, CMPG 0.904**. The strongest compared reward baseline, Robometer (4B), gets VOC 0.983 but FPSR only 0.240 and CMPG 0.366 — i.e., it ranks frames well yet assigns spurious progress under wrong-object instructions.
- R²VLM actually assigns **higher mean peak progress to mismatched instructions than to correct ones (CMPG −0.050)** despite a respectable VOC of 0.916; SOLE-R1 (0.902/0.361/0.266) and LRM (0.828/0.893/0.373) also fall well short of ARS on CMPG. TOPReward scales with backbone (Qwen3-VL-8B: CMPG 0.685 → 32B: 0.756) but stays ~0.15 below ARS.
- **External auditing**: auditing Robometer predictions with ARS raises FPSR from 0.240 to **0.915** and CMPG from 0.366 to **0.891** while maintaining VOC 0.988 — approaching ARS-without-proposals, supporting reuse of existing reward models.

**Policy learning in simulation (Table 2, LIBERO-Long, 4,096 mixed-quality rollouts, π0.5):**
- **ARS 57.9% ± 0.4 vs Vanilla BC 44.2% ± 0.3 (+13.7 pts)** and vs the strongest reward baseline TOPReward + Qwen3-VL-32B 47.6% ± 0.7 (**+10.3 pts**). ARS and TOPReward-32B retain similar chunk fractions (66.9% vs 67.9%), so the 10.3-point gap isolates selection *quality*, not merely filtering aggressiveness.
- Reward-trained baselines mostly fail to beat unfiltered BC: LRM 38.6% (−5.6), R²VLM 41.5%, SOLE-R1 44.8%, Robometer 46.8%; LRM and R²VLM retain under 14% of chunks because their quantized/repeated progress predictions yield near-zero increments.
- **Outcome conditioning**: ARS + terminal labels reaches **62.2% ± 0.6 (+18.0 over Vanilla BC)**, 9.6 points above success-only BC (52.6%) and 4.3 points below the privileged-state reference (66.5%) — capturing 80.7% of what oracle simulator progress would add.
- **Efficiency (Table 4)**: vs TOPReward + Qwen3-VL-32B, full ARS uses **93.6% fewer model queries** (24.9K vs 390.3K) and **65.8% fewer cumulative input tokens** (980.6K vs 2,866.3K) while improving success 47.6% → 57.9%. Workflow ablations: removing verification+inspection drops ARS to 45.4%, removing verification to 52.3%, collapsing context separation to 51.8% (−6.1 with *higher* token usage).

**Ablations (Table 3):** Under the same ARS workflow, Qwen3.6-27B substantially improves FPSR/CMPG over Qwen3.5-4B (0.918/0.904 vs 0.625/0.633), yet ARS + Qwen3.5-4B already beats Robometer-4B on all three metrics — the workflow contributes beyond base-model scale. A GVL-style single-prompt variant with the same 27B model collapses to VOC 0.637 / CMPG 0.354, confirming the inference procedure, not just the backbone, drives the gains.

**Real-world policy learning (Table 5, washing-machine rear-panel 3-screw fastening, 2,574 demos + 3,092 offline rollouts, 200 complete-task trials):**
- Demo-only BC: **58.0%**. Naively adding all rollouts *hurts*: 50.5% (−7.5).
- ARS-based rollout selection: **72.0%**; adding visual references (three image-text examples of task-relevant states): **81.5%**, a **+23.5-point** total gain over demonstration-only BC.

## Authors & Credibility

The paper comes from **AIRC, Midea Group** (corresponding author: Yi Xu), a corporate AI research lab, with an 8-person team. The work has clear industrial grounding: the real-robot experiment is a full-scale laboratory replica of an industrial washing-machine assembly line, and the code (ARS + benchmark generation) is released at github.com/midea-ai/ars, with a reproducibility statement covering prompts, tools, baseline implementations, and policy training configurations. The paper is candid about limitations (inference overhead vs single-pass models, offline-only scope for now) and includes an AI-use statement disclosing generative AI assistance in ideation, code development, and manuscript drafting, with the authors taking full responsibility. The evaluation spreads across a controlled synthetic benchmark, LIBERO-Long simulation, and a real industrial task, and the ablation coverage (base model, inference procedure, workflow components, context separation, CoT) is unusually thorough for this space. The main credibility caveat is that the headline benchmark is self-constructed, and the strongest industrial result (Table 5) uses a single training seed.

## Critical Assessment

- **Self-built benchmark favors the proposed mechanism.** The semantic-mismatch benchmark is the authors' own construction, and its failure mode — wrong-object credit in short (avg 31.7 frames) two-object pick-and-place scenes with clean expert trajectories — is close to the ideal case for an event-verification workflow: the "wrong" event is visually checkable and the instruction cleanly partitions evidence. It is a genuinely diagnostic benchmark (the R²VLM negative-CMPG finding is a real contribution), but the headline 0.918-vs-0.240 FPSR gap should not be read as a general reward-model ranking; the paper does not evaluate on any *existing* third-party reward/progress benchmark.
- **Training-data exposure is not equal across baselines.** The text acknowledges ARS and SOLE-R1/Robometer have "documented LIBERO training exposure" while others may not, and the semantic-mismatch training exposure is deferred to an appendix. Some of the reward-trained baselines' failures (LRM and R²VLM retaining <14% of chunks due to quantized progress outputs) look like artifacts of prediction-format mismatch with the chunk-selection protocol rather than fundamental model failure — a fairer comparison would adapt the selection rule per method.
- **Statistical treatment is thin where it matters most.** LIBERO-Long results carry ± std over seeds, but the real-robot Table 5 — the industrially most compelling result — uses **one training seed** and reports point estimates (72.0% vs 81.5%) over 200 trials with no confidence intervals, and Appendix G.3 outcome-conditioning details are not in the main text. The 200-trial count makes the large gaps plausible, but the visual-reference increment (+9.5) deserves error bars.
- **Cost accounting is honest but incomplete.** ARS uses far fewer queries than frame-wise TOPReward, yet still consumes 24.9K model queries and ~980M input tokens per training-data pass (Table 4), and the authors concede it is more expensive than single-forward-pass models like Robometer. The proposed remedy — distilling ARS supervision into lightweight reward models — is stated as future work and not demonstrated, so current practicality is limited to offline data curation.
- **Genuine strengths offset these concerns**: ablations isolate each component (context separation alone costs 6.1 points; verification+inspection 12.5), the base-model swap shows the workflow generalizes across 4B/27B, auditing external models shows complementarity rather than winner-take-all, and the negative result that naively adding all real-world rollouts hurts (58.0% → 50.5%) is reported plainly.

## Strengths

- Reframes progress reward modeling as an inference-time verification problem, cleanly separating claim generation (subagent) from claim checking (primary agent) with harness-enforced evidence constraints — and ablates exactly that separation (+6.1 pts).
- The diagnostic metrics (FPSR, CMPG) expose a failure mode VOC misses: baselines with near-perfect temporal ordering (Robometer VOC 0.983) still flood wrong-object trajectories with spurious progress (FPSR 0.240).
- No new model training: the entire system runs on an off-the-shelf open-weight 27B VLM, making the approach reproducible and immediately applicable as models improve.
- External reward auditing is a practical, composable contribution — it upgrades an existing specialized model (Robometer FPSR 0.240 → 0.915) instead of competing with it.
- Evaluation spans synthetic control, simulation policy learning, and a real industrial assembly task, with strong efficiency numbers (93.6% fewer queries, 65.8% fewer input tokens than the strongest frame-wise baseline).
- Code and benchmark-generation pipelines are released; prompts and the full tool set are documented in the appendix.

## Limitations

- Inference overhead: iterative visual inspection and generative verification cost ~24.9K queries and ~1M input tokens per LIBERO-Long data pass — significantly more than single-pass models like Robometer, restricting current use to offline curation.
- Online/causal reward estimation (rewarding actions as they happen) is out of scope; the workflow depends on seeing later trajectory evidence to resolve earlier ambiguity.
- The semantic-mismatch benchmark is self-built and limited to short-horizon, two-object tabletop scenes; no evaluation on external reward-modeling benchmarks is reported in the main text.
- Real-robot evidence comes from a single task (3-screw fastening), one training seed, and one robot cell; no cross-task variance is reported.
- Progress-guided policy learning is limited to weighted behavior cloning (chunk selection); compatibility with RL-based value learning is cited but not exercised.
- Terminal-outcome conditioning and visual references both improve results, but each adds information beyond raw trajectories+instructions, so the "no privileged information" claim weakens for the headline 81.5% real-world number.

## Questions for Further Exploration

- Can ARS-generated progress supervision be distilled into a lightweight reward model cheaply enough to close the inference-overhead gap with Robometer-style single-pass models — and how much accuracy survives distillation?
- Does the event-verification workflow retain its advantage on trajectories where spurious progress is *not* object-identity-based (e.g., wrong force, wrong timing, partial insertion), which are harder to verify visually than wrong-object manipulation?
- The real-world gain from visual references (72.0% → 81.5%) suggests sensitivity to reference curation — how many examples, and how much does reference quality/coverage matter before gains saturate or invert?
- Would the chunk-selection protocol favor ARS even with mediocre progress estimates, given that reward-trained baselines failed mainly on retention-rate artifacts (<14% chunks kept)? A selection-rule-matched comparison could disentangle this.
- Can the harness-enforced evidence constraints (full trajectory coverage, re-confirmation after revision) be transplanted to other agentic verification domains, such as auditing LLM reasoning traces or autonomous research pipelines?
