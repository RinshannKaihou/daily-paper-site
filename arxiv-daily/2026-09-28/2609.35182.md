> **一句话总结：** IdeaHorizon 团队的科研 agent 平台 AeS（Agent for Science）把机器科研的可信性从"提示模型守规矩"改为"让不合规状态无法被表示"：8 个产出/服务节点 + 3 个架构节点、冻结预注册的问询契约 + SHA-256 哈希链工件台账 + 框架现算不落盘的闭包清单、以及只能靠"改写晋升"进入的两层知识库；在 35 次端到端战役中，50.3 小时辅助式研究在 2,021 次模型调用 / 200.9M tokens 后冻结了手稿 v11，8.85 小时无人值守的 2D Ising 临界温度复现以 T_c=2.268776±0.000148 对 Onager 精确值 2.269185 的 2.8σ 偏差**如实推翻了自己的预注册假设**。

> **TL;DR:** This is a system-description paper (explicitly not an evaluation — the authors report no benchmark) for AeS, a platform where a scientific project runs for tens of hours across dozens of agent runs with a human present only occasionally. The core move: research discipline is enforced mechanically at the write path — frozen preregistrations gate experiments, an append-only hash-chained ledger (`frozen.jsonl`, SHA-256 per row) makes freezing irreversible and forgery detectable, closure tallies are recomputed from ledgers rather than read from model reports, and only the Analysis node may record a scientific verdict. Instead of an ML benchmark, the evidence is operational: on the 2D Ising campaign (800 Wolff runs, 8.85 h unattended) the preregistered weighted-fit hypothesis was refuted — T_c = 2.268776±0.000148 vs Onager's exact 2.269185, a 410 μK (2.8σ) deviation outside the preregistered 2σ criterion, while the unweighted fit (2.269287±0.000087, 1.17σ) would have "passed" — and the platform flipped its verdict from supported to refuted. Measured failures of the platform's own removed designs serve as internal baselines: a verdict layer under which 87% of failed checks never passed again (writing node: 17 runs, 0 completions), model-judged node dispatch that burned 47 turns / 6.7M tokens busy-waiting, a memory candidate queue where 47% of 800 candidates were never processed. Worth reading if you build agent harnesses; do not expect a quantitative comparison against AI-Scientist-style systems.

## 核心贡献

- **一条设计公理 + 六条"研究铁律"**：把机器科研的可信性问题重述为"让不合规状态无法被表示"（unrepresentable），并给出六条法律（L1 先承诺后测量、L2 冻结不可逆不可伪造、L3 报告不是事实、L4 证据持久裁定易逝、L5 负结果一等公民、L6 机械问题归框架语义判断归模型），每条都映射到一个机制、它阻止的失败和它的实现位置。
- **极简研究节点（Pillar A）**：仅 8 个产出/服务节点（Analysis、experiment、observation、derivation、writing；literature、data、postprocess）+ 3 个架构节点（orchestrator、reviewer、curator），能力通过"加深既有节点契约"的五个杠杆扩展而非增加节点类型；证据节点按"独有的原罪"准入（experiment=伪造执行、observation=cherry-picking、derivation=无效步骤伪装成有效）。
- **可复核工作流（Pillar B）**：问询契约（问题 + 数值/陈述两类闭包条件在工作开始前冻结）、追加式哈希链工件台账（冻结行把路径钉到内容哈希；修订必须带 `amendment_reason` 并生成新草稿）、由框架从台账现算、从不存储的闭包清单、referee 评审循环（major 退回上游）、以及拒绝 `frozen:true` 元数据保存的 forgery guard。
- **复利式记忆（Pillar C）**：单文件 `MEMORY.md` 四层结构（宪法作为冻结前缀、situation 每次现算、handbook 带 `applies_to` 常量预算注入、log 层有意不存在），两层知识库的组织层"除晋升外没有出生通道"——晋升是一次改写（去参数化、自包含、附来源），由三条检查 + 每周约 5 条的人工通道把守。
- **用测得数据废除流行设计**：审计自己的旧配置——质量检查"verdict layer"下 324 个检查序列中 87% 失败后再未通过（writing 节点 17 次运行 0 次完成）故整体移除；模型自行判断节点续停被测得 47 回合 / 6.7M tokens 空转；候选队列记忆中 800 条候选 47% 永未处理；知识库无界查询单次返回 83k tokens（有界化后工作上下文从 88k 降到 12k）。
- **诚实的评估边界**：明确声明"这是系统描述，不是评估"，报告零基准对比，两个封闭战役（C1：非正态性增长与早期预警信号，50.3 小时辅助式；C2：2D Ising 精确临界温度复现，8.85 小时无人值守）作为机制的worked illustrations，且 C2 的结论是**推翻自己预注册的假设**。

## Key Contributions

- **One design axiom, six research laws**: machine-made research credibility is moved from "ask the model to behave" to "make the non-compliant state unrepresentable," operationalized as six laws (L1 commitment before measurement, L2 freezing irreversible and unforgeable, L3 reports are not facts, L4 evidence persists / verdicts do not, L5 negative results are first-class, L6 mechanical questions to the framework and semantic judgment to the model), each indexed to the mechanism that enforces it.
- **Minimal research nodes (Pillar A)**: only 8 producing/service nodes (Analysis, experiment, observation, derivation, writing; literature, data, postprocess) plus 3 architecture nodes (orchestrator, reviewer, curator); capability is added by deepening node contracts through five levers (prompt/rules, write gates, tool whitelist + tool-internal validation, the node's `review_spec.md`, on-demand skills) rather than adding node types; evidence nodes are admitted by a distinct uncatchable-otherwise sin (experiment = fabricated execution; observation = cherry-picking; derivation = an invalid step disguised as valid).
- **Re-verifiable workflow (Pillar B)**: an inquiry contract freezing questions plus numeric-or-statement closure conditions before work starts; an append-only hash-chained artifact ledger (freeze rows pin path→SHA-256; amendment requires a reason and produces a new draft); closure tallies computed from ledgers at read time and never stored; a referee review loop (major redirects upstream); a forgery guard that refuses any save carrying `frozen:true` metadata at the tool boundary.
- **Compounding memory (Pillar C)**: a single-file project memory (`MEMORY.md`) with four layers — constitution as a frozen per-turn prefix, a situation segment computed per run and never stored, an `applies_to`-keyed handbook injected with constant budgets, and a deliberately absent log layer; a two-tier knowledge base whose organization tier has "no birth channel except promotion," where promotion is a rewrite (de-projectized, self-contained, with provenance) gated by three checks plus a human lane sized at ~5 decisions/week.
- **Removing popular designs on measured evidence**: an audit of the platform's own earlier configurations killed the verdict layer (of 324 check sequences in its own transcripts, 87% of "check X failed" sequences never passed again; the writing node had 17 runs and zero completions under it), replaced model-judged node continuation (measured once at 47 turns and 6.7M tokens of busy-waiting) with a mechanically computed situation, replaced a memory candidate queue (47% of 800 candidates never processed, oldest 49 days; retirement never invoked across 24 projects), and bounded knowledge-base reads (one unbounded query returned 83k tokens; bounding cut working context from 88k to 12k tokens).
- **An honest evaluation boundary**: the paper states plainly that it is a description, not an evaluation, reports no benchmark, and offers two closed campaigns as worked illustrations — C1 (growing non-normality vs early-warning signals, 50.3 h assisted) and C2 (2D Ising critical temperature vs Onager, 8.85 h unattended) — where the preregistration machinery ended by **refuting the platform's own preregistered hypothesis**.

## Methodology

The platform is organized around three time horizons. **Within a run**, each node is a directory with one contract file (system prompt, rules, tool whitelist, loop hooks, required input/output artifact types, callable nodes, post-run flow); loading is strict — a contradictory contract raises rather than silently degrades. Three evidence modalities are admitted by "distinct sin": *experiment* (intervene; gate = execution-evidence loop with frozen raw-results manifest hashed SHA-256 per file), *observation* (inspect; gate = frozen search protocol with a denominator and mandatory adversarial search), *derivation* (deduce; gate = a proof kernel checking each proposed step symbolically, then numerically at random points, returning verified/numerically_supported/inconclusive/failed rather than a boolean). There is no declarative node graph and no artifact bus: producing runs return to the orchestrator, which decides the next step from a ledger-derived situation; one writer per piece of state is enforced by a write-scope sandbox plus a commit-gate authority.

**Within a project**, the research loop is driven by verdicts, not position: Analysis freezes a preregistration and plan, dispatches evidence nodes, and records scientific verdicts (continue / pivot / ready_candidate / abort) into the sole-writer `research_state` ledger; evidence nodes may only return execution-level verdicts, and a producing node attempting to flip a verdict is refused unless the state already records it. Artifacts live under three primitives (identity = path, versioning with content hashes, freeze/amend on the hash-chained ledger), with write gates on save/freeze and a forgery guard at the tool boundary. The writing gate refuses to produce a paper over zero discharges; the referee audits a manuscript on seven dimensions and maps outcomes to accept / minor / major / reject, with accept a precondition of freezing.

**Across projects**, memory compounds through promotion-by-rewriting into the organization tier of the knowledge base (seven required fields per card; dead ends have the highest yield), while project memory stays a single Git-tracked `MEMORY.md` whose budgets are constants (constitution 2048 B, situation 3072 B, onboarding 4096 B, first-use tool brief ≤ 2 entries).

**The runtime substrate** renders the context window as a view over an append-only per-run log (any tool result has at most one live copy; eviction returns tombstones), distinguishes ten terminal causes (notably: not calling a tool is the declaration of completion — there is no `i_am_done` tool), separates *stall* (aborts at 5 after warning at 3) from *repeat* (never aborts), routes every command through one execution-boundary choke point (macOS sandbox profile; Linux bind-mount namespaces + kernel-level write restriction), and records every model call as a per-project cost-ledger row (unknown prices are recorded as unknown, never zero). Three traces walk real failure attempts through the gates: a refused freeze then forged via metadata re-save (caught at the tool boundary), twelve discharges with malformed `Q1_DISCOURSE_EVIDENCE` keys counted as zero (surfaced later by the writing gate), and a blocked node dispatched again (prevented by content-addressed fingerprints in the dispatch gate).

## Results & Highlights

No benchmark comparison against other systems is reported — the authors say so explicitly, and a "process-integrity suite" that would support quantitative cross-system comparison is still under construction. What the paper reports instead are operational measurements from its own ledger records and two closed campaigns:

- **C2 (Ising, unattended)**: 800 Wolff cluster runs (L ∈ {16..256}, 32 temperatures, 5 seeds, 10^5 measurements/point, bootstrap B=2000) in 8.85 h on one machine. The preregistered weighted fit gave T_c = 2.268776±0.000148 vs Onager's exact 2.269185 — Δ = 410 μK = 2.8σ, outside the preregistered 2σ criterion, so H1 and H2 were both **refuted**; the unweighted fit (2.269287±0.000087, within 1.17σ) would have passed, and the writing node's first draft in fact claimed H1 supported with the unweighted number while describing the weighted scheme — four reviewer rounds missed it and a human caught it. A theory-experiment chain additionally froze T_c = 2/ln(1+√2) via a 20-step Kramers–Wannier derivation (15 steps verified, 19 numerically supported, 1 failed) 131 s before an independent MC run returned 2.266448±0.006456 (0.42σ), discharging THEORY_PROVENANCE.
- **C1 (assisted, 50.3 h)**: 67 runs, 2,021 model calls, 200.9M tokens (160.7M cache reads) with ≥23 numbered human instructions; manuscript v11 frozen after five review rounds (verdicts major→major→approve-with-revisions→approve-with-revisions→approve, confidence 0.9) and 13 deliverables promoted. Scientifically: a non-normal but stationary system at κ ≈ 0.03 stayed at zero baseline over 144 grid cells while the same system with drifting non-normality alarmed at 0.94–1.00; the mechanism failed in a nonlinear Lotka–Volterra network (22 of 33 grid cells overlapped, direction reversed) and the frozen record honestly says INCONCLUSIVE, reported as an open question.
- **Verdict-layer removal (its own baseline)**: under the platform's earlier quality-check layer, of 324 check sequences in its own transcripts, 87 sequences of "check X failed" were found — 11 (13%) later corrected, 76 (87%) never passed again; the writing node had 17 runs and zero completions; in one campaign of 3,972 tool calls, 23 node-restart refusals (15 writing, 8 postprocess) all came from one check failing four times in a row. After removal, C1's writing node completed 10 runs and a frozen manuscript.
- **Orchestrator dispatch**: letting the model judge whether a node should continue was measured once at **47 turns and 6.7M tokens of busy-waiting**; replaced with a mechanically computed situation of counts only.
- **Memory designs (its own baselines)**: a candidate-queue memory left 47% of 800 candidates never processed (oldest 49 days) and retirement was never invoked across 24 projects; a write-time organization-scope guess produced 224 organization claims with zero complete promotion provenance; one unbounded knowledge-base query returned 83k tokens, and bounding reads cut working context from 88k to 12k tokens.
- **Cost of a round**: a 131-minute round of the Ising study (551 model calls) splits as 26 min Monte Carlo with no model calls, 47 min experiment-node work before the last job, 27 min closing evidence, 31 min review/orchestration; the human was invoked 5 times. The preceding same-topic project consumed 42.1M prompt tokens at a 92.3% cache hit rate (38.8M cached / 3.25M uncached / 0.50M generated).

## Authors & Credibility

The paper is authored by the **IdeaHorizon Team** (a company contact email; Appendix A lists eight named members alphabetically: Di Wang and Yu Liu for architecture/management; Bing Cui, Chaoqun Ji, Dongyuan Ni, Jingyu Lu, Kunlei Cui, and Pu Qin for engineering). It is a corporate engineering team describing its own production platform — not an academic group, and there is no external authors-with-track-record validation. Credibility signals are unusually strong on the honesty axis: the paper repeatedly refuses to claim superiority, holds itself to "a sentence in a prompt is not a capability until its effect on behavior has been observed," and Appendix E documents exactly which on-disk ledgers every figure is computed from. Weaknesses on the credibility axis: the platform is not released (no code or artifact URL is given), every measurement is self-reported from the platform's own records, all recorded runs used one model family (DeepSeek V4 via OpenAI-compatible endpoints, `deepseek-v4-pro` in C1), and the campaigns are the authors' own selection.

## Critical Assessment

- **Novelty is real but of a specific kind.** The contribution is an architecture and a set of enforced invariants, not a new algorithm or benchmark result. The framing — enforcement reliability differs by an order of magnitude depending on whether a rule lives in the prompt, a post-hoc check, or an unrepresentable state (Table 1/Table 5) — is a genuinely sharp articulation, and the mechanization of preregistration against HARKing (citing Nosek and Kerr) into closure conditions of *any* form (not just metrics) is a real generalization. Related-work positioning against The AI Scientist, Agent Laboratory, Claude Science, MemGPT/Mem0 is fair and specific about what those systems lack (no claim lifecycle, no adjudication boundary, no promotion provenance).
- **The evaluation gap is the paper's defining weakness, and the authors own it.** Section 12 admits the comparisons a reader actually wants — same model, same question, each gate disabled in turn, and the same question given to a general coding agent with a skills folder — were not run. The verdict-layer "ablation" numbers come from a single internal test corpus of the authors' own campaigns under an earlier configuration, reconstructed by the authors themselves; there is no way for an outsider to verify the 87%-never-passed-again figure, the 6.7M-token busy-wait, or the 47%-unprocessed memory candidates. Worse for self-evaluation maturity: their own early process-integrity grader "needed three corrections before its ratings were stable," and a separate configuration made it fail on four of five axes.
- **The two campaigns are best-case demonstrations, not stress tests.** C2's domain has an exact solution (Onager) — the authors themselves note that with an external truth the answer to "how would a wrong result be caught" is "immediately," and for most problems "never." C1 ran in the assisted tier with an investigator issuing at least 23 numbered instructions, and two of its reviewer catches were of the investigator's own confirmation bias — reassuring for the referee loop, but it also shows the human did substantial steering. The C2 episode where the writing node's draft quoted the unweighted number while describing the weighted fit, and four reviewer rounds missed it until a human intervened, is a striking counter-data-point against the adequacy of LLM review layers that the paper reports honestly but does not reconcile with its confidence in referee gating.
- **Process overhead is large and acknowledged**: close to half of a round's wall clock goes to closing evidence, review, and orchestration; one experiment run reached turn 153 and 17.5M tokens because no per-node spending ceiling exists. The paper's own cost table shows the machinery costs ~200M tokens for one 50-hour assisted project.
- **Reproducibility for outsiders is currently near zero**: no code release, no artifact link, one model family (DeepSeek V4), and all "records" live on the authors' disks. As a design document this is acceptable; as evidence of effectiveness it is not yet.
- **Red flags are minor but present**: a corporate team describing its own unreleased product; every quantitative claim self-measured; the "35 numbered end-to-end campaigns" are invoked as a count but only 2 are shown, selected because their artifacts happened to be fully recoverable from disk — a survivorship-ish selection criterion the paper does state, but the other 33 remain unseen.

## Strengths

- A clear, falsifiable engineering thesis ("make the non-compliant state unrepresentable") with a reliability ladder (prompt < post-hoc check < unrepresentable) that is immediately actionable for anyone building agent harnesses.
- Each mechanism is described exactly once with its invariant, the failure it prevents, its realization, and its cost — the paper is unusually readable for a 34-page system description and is designed to be argued with.
- Measured self-criticism of its own removed designs (verdict layer, candidate-queue memory, write-time organization scope, unbounded KB reads) is more useful evidence than most benchmark-chasing papers provide about *why* common harness patterns fail.
- The C2 Ising campaign is a small but complete demonstration of preregistration biting: the platform refuted its own hypothesis against an exact solution and recorded the negative result first-class, including the honest INCONCLUSIVE in C1's nonlinear case.
- The runtime substrate details (context as a rendered view with at-most-one-live-copy invariant, ten terminal causes with no `i_am_done` tool, stall-vs-repeat counter asymmetry, errors-as-values tool dispatch) are independently valuable implementation guidance.

## Limitations

- No benchmark, no cross-system comparison, no ablation of individual gates; the process-integrity suite that would enable this is "under construction" and its early version was itself unstable.
- Single model family: all recorded runs used DeepSeek V4 models through OpenAI-compatible endpoints; the token and wall-clock ratios may not transfer to stronger models, and a gate built for one model's failure mode may be catching a failure a stronger model makes less often.
- Only two closed campaigns are shown, one assisted (with heavy human steering) and one on a problem with an exact analytic solution; the effect of the knowledge-base loop on downstream projects is confounded with a ceiling effect and has not been separated in a controlled comparison.
- The process is heavy for simple problems: nearly half of round wall clock is closing/orchestration overhead, and there is no per-node spending ceiling (one run hit turn 153 / 17.5M tokens).
- The honesty block enforces "claimed but not done" but cannot catch an unsound validation protocol (e.g., selecting a model and validating on the same sample) — the authors note a mechanical gate for this is designed but not built.
- No code or artifact release accompanies the paper, so none of the ledger-derived numbers are independently checkable.

## Relevance

该论文正命中你的最高优先级方向（Self-Evolving Agents & Automated Research）：它就是一个面向自主科研回路的 AI-scientist 平台的完整架构描述，且核心议题恰好是长时程自主 agent 系统的可靠性与可信性（预注册、防伪造台账、负结果一等公民）。其对"提示 < 事后检查 < 状态不可表示"的执行强度阶梯和对 verdict layer / 候选队列记忆等常见 harness 模式的实测否定，对你设计或评估自动化研究基础设施有直接的参考价值。

## Questions for Further Exploration

- The gates were never ablated: which of the six laws contributes most of the trustworthiness gain, and does any gate's false-positive cost (refusing legitimate actions) exceed its protection on real projects?
- Does the preregistration machinery survive domains with no exact solution, where "how a wrong result would be caught" is "never" rather than "immediately"?
- The C2 manuscript error (unweighted number, weighted-scheme description) survived four LLM reviewer rounds and was caught by a human — what mechanical check would have caught it without the human, and would a closure condition on the fit scheme alone have sufficed?
- Would the promotion-by-rewriting knowledge base measurably improve a downstream project if the ceiling effect were removed in a controlled comparison?
- How do the token and wall-clock overheads scale with a stronger model family, and is a per-node spending ceiling compatible with the platform's "budget must be visible in the model's text" principle?
