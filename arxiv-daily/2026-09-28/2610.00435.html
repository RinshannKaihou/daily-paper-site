01

Methodology, distilled

An exactly-checkable testbed, an 18-run single-agent study, fitted baselines, and a division-of-labour team.

The testbed. Find the closed-form n-point water-wave amplitude Aₙ (two-minus sector), valid for every n across the allowed frequency space. Ground truth is piecewise polynomial — different pieces hold in different “frequency chambers” — and any proposal can be checked exactly via Berends–Giele recursion, making “did the agent discover it” a binary, reproducible question.

Single-agent study. 6 agent configurations × 3 prompt packages (no hint / false hint / true hint) = 18 runs, one per cell. Outcomes fall into 5 categories, dissected by an 8-step rubric (K1–K8) and a held-out n=8 numerical test (250 configurations).

Baselines. PySR, gplearn, Operon, LaSR, LLM-SR, plus linear regression / random forest / MLP / KAN on a fixed train–test split — all scored by held-out MAE.

The team. A PI assigns complementary analytic and numerical tasks to two students in separate workspaces with a shared record; the PI independently implements and cross-checks the combined formula (agreement ≤ 10⁻¹⁰). Two no-hint rediscovery runs — then the same team attacked the harder three-minus sector for the new A₆.

03

Strengths

What this paper does unusually well.

  • An exact oracle turns “did the agent discover the formula” into a binary, reproducible question — MAE 0 vs nonzero cleanly separates recovery from prediction.
  • Failure anatomy beats a leaderboard: K1–K8 steps, per-run MAE, and three named stopping mechanisms localize the bottleneck.
  • Controlled rediscovery plus a genuinely new, independently re-verified physics result (A₆) — the loop produces the unknown, not just recall.
  • The PI+students design targets the diagnosed failure: the constructing agent no longer chooses its own tests.
  • Exceptional transparency — prompts, run histories, checking code, benchmarks all public; limitations stated prominently.
04

Limitations

Read the headline numbers with these attached.

  • One run per cell (18 single-agent, one per architecture) — success rates carry no statistical support.
  • Compute and scaffolding are not cost-matched; the multi-agent advantage is not isolated as an architectural effect.
  • One sector of one physics amplitude with an exact oracle — noisy real-science domains may not transfer.
  • Prompt packages vary equation guidance and test advice together; the true-hint advantage is un-ablated.
  • A₆ is numerically verified only — no analytic proof; explicit numerator for n ≥ 7 open.
  • Fixed-dataset baselines answer a slightly different question than adaptive agent runs.
05

Questions ahead

What the authors and readers should test next.

  1. Cost-matched, would single agents still fail K6–K7 — and how many repetitions make 2-vs-6 a real pass@k estimate?
  2. Does the workflow transfer to domains without an exact oracle, where counterexample-driven revision is much weaker?
  3. Can the bottleneck steps — find boundaries, combine globally, test unseen regimes — become a reusable scaffold or reward signal?
  4. Can agents prove A₆ analytically (and find the n ≥ 7 numerator) rather than accumulating finite numerical tests?
  5. Which prompt ingredient — equation class or test-point advice — drives the true-hint advantage?
