> **一句话总结：** 该论文指出二元的"攻击成功率(ASR)"无法刻画持久记忆投毒的真实危害，提出反事实记忆遗憾(CMR)——被篡改记忆相对干净记忆造成的期望下游损失增量——作为攻击严重度目标，并实现 MemHarm：先冻结一个由稀疏、有依据的语义编辑构成的有限候选类，用离线成对损失反馈做 LCB/UCB 自适应最优臂搜索并给出类内 η-近似最优证书；在 AgentDojo 与 r²-bench 上（GPT-4o/Llama-3.1-70B、6 种记忆契约），MemHarm 的 held-out CMR 达 0.411±0.112，约为最强基线 MemoryGraft（0.210±0.107）的两倍，同时 ASR 反而更高（62.8% vs 26.6%），且 91.4% 的攻击获得类内最优性证书。

> **TL;DR:** The paper reframes persistent-memory attacks on LLM agents around severity rather than binary success: it defines Counterfactual Memory Regret (CMR), the paired expected increase in downstream task loss caused by a poisoned memory write versus clean memory, and builds MemHarm, which freezes a finite class of sparse grounded semantic edits and adaptively searches them with offline paired-loss feedback using anytime-valid LCB/UCB best-arm identification, yielding a class-conditional near-optimality certificate. On AgentDojo and the airline/retail domains of r²-bench with GPT-4o and Llama-3.1-70B across six memory contracts, MemHarm attains held-out CMR of 0.411±0.112 (GPT-4o/AgentDojo) versus 0.210±0.107 for the strongest baseline MemoryGraft (+0.20, roughly 2x) while also raising ASR from 26.6% to 62.8%; 91.4% of attacks (117/128) receive an optimality certificate. It is a careful, causally-grounded attack-evaluation paper, though its threat model assumes an offline oracle with resettable memory copies.

## 核心贡献

- **概念层面**：首次把持久记忆攻击的"严重度"（downstream severity）形式化为与二元攻击成功互补的独立设计目标——反事实记忆遗憾 CMR = 𝔼[L_edit − L_clean]，即被篡改持久状态相对干净记忆在下游任务上的期望运营损失增量；论文用实验证明同 ASR 下损失可差近一个量级（同一编辑集合内，成功导向选择只比随机选择多抬 0.013 的损失差，而严重度导向抬 0.100）。
- **方法层面**：提出 MemHarm——三步流水线：(1) 从干净记忆写入中用确定性模式+schema 解析器抽取类型化语义因子并生成有依据的候选编辑（编辑预算 K≤3 个因子）；(2) 在接收任何结果反馈前冻结候选类；(3) 用 memory-only 成对干预（编辑/干净两支从同一初始状态出发，非记忆通道被清空）+ 基于 empirical-Bernstein 置信序列的 LUCB 式自适应分配来选出高 CMR 编辑，并输出类内 η-近似最优证书。
- **理论层面**：证明 Proposition 1（已解决的选择满足 J(ã) ≥ V_{η,K} − η，即冻结类内 η-近似最优）；给出 CMR 的机制分解 J = κ(编辑后果) + ρ_edit − ρ_clean（记忆实现误差），推出高 CMR 需要"后果严重且记忆如实实现"的方向性界；Proposition 2 证明归因模糊性——即使攻击被检测，TV 距离 ≤ ε 时定位责任记忆因子的错误率至少 1 − ε/2。
- **实证层面**：在 2 个 agent 基准 × 2 个骨干 × 6 种记忆契约上验证：每个设置 CMR 点估计均为第一，ASR 保持第一或第二；给出 common-support 与 contract-matched 公平对比（给 MemoryGraft/DualAgent 同等反馈与预算仍领先）；因子移除干预（−0.34 vs −0.02）证实所选语义因子是危害载体；在 OpenClaw 与 Hermes 原生 agent 部署（GPT-OSS-120B）上验证 write→persist→retrieve 攻击链真实落盘。

## Key Contributions

- **Conceptual**: Formalizes attack severity — Counterfactual Memory Regret (CMR), the expected paired downstream-loss increase of an edited persistent state relative to clean memory — as an attack-design objective complementary to binary ASR, and empirically shows equal-ASR attacks can differ by an order of magnitude in loss (success-guided selection: +0.013 loss gap over random vs severity-guided: +0.100 on the same edit set).
- **Methodological**: MemHarm, a three-stage attack that extracts typed semantic factors from clean writes, freezes a finite admissible candidate class (edit budget K≤3), and searches it via memory-only paired interventions with anytime-valid LCB/UCB best-arm identification, emitting a class-conditional η-near-optimality certificate for resolved selections.
- **Theoretical**: Proposition 1 (certified selection J(ã) ≥ V_{η,K} − η within the frozen class); a mechanistic decomposition CMR = consequence κ + realization errors (ρ_edit − ρ_clean) yielding a directional bound (high CMR requires a consequential edit faithfully realized, and clean realization cannot inflate the guarantee); Proposition 2 (attribution ambiguity: if TV distance between candidate factor distributions ≤ ε, attribution error ≥ 1 − ε/2).
- **Empirical**: CMR-first on every benchmark-backbone setting across six memory contracts; fair-support and contract-matched comparisons that give specialized baselines the same feedback and rollout budget; factor-removal interventions (−0.34 vs −0.02 CMR change) linking harm to the selected factor; and native-agent verification in pinned OpenClaw and Hermes deployments (GPT-OSS-120B) confirming the write-persist-retrieve path.

## Methodology

**Threat model and CMR objective.** MemHarm targets a fixed memory mechanism g with persistent state S_g. Operational loss L_g aggregates benchmark-defined freezable checks C_m ∈ [0,1] (AgentDojo user-task utility predicates; r²-bench database/end-state and communication criteria), evaluated once per episode. A write x updates state via S_g^+ = U_g(S_g, x). For clean write X and counterfactual write x', the two branches start at the same initial state S_g^0 = U_g(S_g, X) vs S_g^{x'} = U_g(S_g, x'). During offline construction, the environment removes the write artifact from all non-target channels (memory-only isolation) so the only difference is the target read path. CMR is the expected paired difference J_g(x'; X) = 𝔼[L_g^{edit} − L_g^{clean}] over a joint law on matched (ω_edit, ω_clean). A decomposition shows CMR retains what binary success discards: with Δ = L_edit − L_clean, CMR = Pr(Δ>0)·𝔼[Δ|Δ>0] − Pr(Δ<0)·𝔼[−Δ|Δ<0], so equal-ASR attacks can have very different CMR.

**Constructing admissible counterfactuals.** Factors are extracted from the clean write using deterministic patterns and schema-based parsers: z = (type, anchor, rel, v, s). An edit program e = (I, {v'_i}) replaces at most K factors with values drawn from a same-type grounded replacement pool; realizations differ by memory contract (retrieved note, summary, profile field, reusable reflection, graph edge, or hybrid). Admissibility constrains support and form (grounding, source-admissibility, bounded semantic deviation, a construction-time LLM typicality check) — plausibility rather than truth.

**Freezing and adaptive search.** The candidate class 𝒜_K(X) (including the zero-edit arm) is frozen before any outcome feedback. Rollouts are allocated adaptively: each arm maintains time-uniform LCB/UCB from two-sided empirical-Bernstein confidence sequences (Waudby-Smith & Ramandas 2024) on the bounded paired differences; the allocator samples the largest-LCB incumbent, largest-UCB challenger, and largest-UCB arm in each nested budget class; an arm is eliminated when UCB ≤ max LCB − η. A selected arm ã receives a class-conditional (η, δ) certificate when max UCB − LCB(ã) ≤ η, guaranteeing J_g(ã) ≥ V_{η,K}(X) − η. Configuration: K = 3, η = δ = 0.05, at most 800 paired rollouts per instance, five primary seeds, construction/optimization/test splits disjoint (attacks evaluated only on held-out tasks). Backbones: GPT-4o and Llama-3.1-70B-Instruct across six memory contracts (vector episodic, rolling summary, user profile, reflection, graph, hybrid). A separate protocol-aligned MPBench comparison runs natively in pinned OpenClaw and Hermes deployments with GPT-OSS-120B, transferring state only through each agent's native memory-write pathway.

**Metrics.** CMR (severity, signed paired loss change), ASR (clean-success/attacked-failure on applicable support), BUD (benign utility drop on fixed non-target probes), and BMAR≥4 (blinded judge ratings of attack specificity/contextual plausibility); auxiliary audits cover extractor agreement, oracle gap, rejection rates, and detection/retention/recovery.

## Results & Highlights

- **Held-out CMR (Table 1)**: On AgentDojo with GPT-4o, MemHarm reaches CMR 0.411 ± 0.112 vs 0.210 ± 0.107 for the strongest baseline MemoryGraft (+0.20, ~2x), while MemPoison, MINA, and InjectMEM all post negative or near-zero CMR (−0.005, −0.005, −0.034). On r²-bench with GPT-4o the gap is 0.347 ± 0.087 vs 0.107 ± 0.106 (+0.24); with Llama-3.1-70B it is 0.393 ± 0.112 (AgentDojo) and 0.254 ± 0.090 (r²-bench) vs 0.210/0.107 for MemoryGraft.
- **Success is retained, not traded off**: On the same settings MemHarm's ASR is 62.8 ± 11.2 (GPT-4o/AgentDojo) vs 26.6 ± 6.5 for MemoryGraft, and 85.0 ± 11.4 (Llama-3.1-70B/r²-bench) vs 16.4 for MemoryGraft — severity-guided selection does not sacrifice the conventional metric. Benign utility drop stays small (BUD 2.3 pp on AgentDojo/GPT-4o).
- **Fair comparisons (Table 2)**: On common support among general attacks, MemHarm's CMR is 0.268 ± 0.094 (GPT-4o/AgentDojo) vs 0.121 ± 0.094 for the best general baseline DualAgent. Giving specialized baselines the same optimization-split paired feedback and rollout budget, MemHarm still leads by ΔCMR +0.218 over MemoryGraft (GPT-4o/AgentDojo), +0.269 (GPT-4o/r²-bench), +0.214 and +0.198 (Llama), and +0.336/+0.435 over DualAgent-profile on the AgentDojo settings.
- **Motivating severity gap (Appendix H.2)**: Within the same fixed admissible edit set, success-guided selection raises the edited-vs-clean downstream loss gap by only 0.013 over random selection, while severity-guided selection raises it by 0.100 at comparable success — the paper's core motivation quantified.
- **Mechanism and certification**: Removing the selected semantic factor changes CMR by −0.34 vs −0.02 for a matched irrelevant factor (95% CIs exclude zero), supporting factor-specific causation. 117/128 instances (91.4%) receive an optimality certificate (62.5% also the minimum-budget certificate), and adaptive allocation reaches that 91.4% rate with a median of 359 paired pulls vs 518 for uniform allocation (~31% fewer rollouts).
- **Native-agent validation**: In pinned OpenClaw and Hermes deployments (GPT-OSS-120B), the edit is written through the agent's normal memory API, persists in on-disk state, and a distinct fresh retrieval process retrieves it and acts on it after the original interaction ends — confirming the write-persist-retrieve attack path outside the benchmark harness.

## Critical Assessment

The core reframing — severity as a first-class attack objective, measured counterfactually — is genuinely novel and well-executed; the paired memory-only intervention design and the class-freezing-before-feedback discipline are exactly what makes the causal claim credible. The fairness controls (contract-matched budget/feedback for MemoryGraft and DualAgent; same-class random-selection ablation) pre-empt the most obvious objection that baselines simply optimize a different objective. That said, several paper-specific caveats stand out:

- **Baseline mismatch is only partially mitigated.** MemPoison, MINA, and InjectMEM are trigger-conditioned attacks designed for stealthy conditional activation, not severity maximization — their negative CMRs (e.g., InjectMEM −0.034 on AgentDojo/GPT-4o) mostly demonstrate objective mismatch, not weakness. Only MemoryGraft and DualAgent survive the contract-matched comparison, so the empirical "severity superiority" claim effectively rests on two adapted baselines on two benchmarks.
- **The 95% intervals are less decisive than the point estimates.** On AgentDojo/GPT-4o the CMR intervals are 0.411 ± 0.112 vs 0.210 ± 0.107 — these overlap slightly (lower edge 0.299 vs upper edge 0.317), and the common-support comparison (0.268 ± 0.094 vs 0.121 ± 0.094) also overlaps. The paper honestly reports intervals and marks best/second-best, but per-cell statistical separation is weaker than the "largest in every setting" framing suggests; strength comes from consistency across 8+ settings rather than from any single decisive gap.
- **Threat-model asymmetry between construction and deployment.** Construction requires resettable isolated copies and up to 800 paired-loss rollouts per instance — an offline oracle no realistic attacker against a deployed assistant possesses. The authors scope this explicitly (deployment needs only one normal-interface write), but it means the attack is best read as a worst-case evaluation methodology for defenses, not a demonstrated practical exploit.
- **"Certified" is class-conditional.** The η-near-optimality guarantee holds within the attacker's own frozen candidate class; it says nothing about severity attainable outside the class. The conclusion states this, but the term "certified attack" invites over-reading.
- **Severity = benchmark operational loss.** CMR is defined against registered task checks; Figure 1's motivating story (unauthorized $50 refund, repeated $200 charge) is more visceral than what is actually measured, which is normalized benchmark task-failure increase. Real-dollar or policy-violation harm is never directly quantified.
- Smaller points: Llama-3.1-70B ASR on AgentDojo drops to 42.1% (vs 62.8% for GPT-4o), showing the success-retention claim is backbone-dependent; the native-agent MPBench results (Fig. 2) are presented mainly as bars without a full table in the main text; and generative AI was used for polishing, code development, and as pipeline components (disclosed, with human review claimed).

## Strengths

- A crisp, well-motivated conceptual contribution: CMR is a clean potential-outcomes-style quantity that provably retains information ASR discards (the sign/magnitude decomposition in Eq. 5).
- Methodological rigor rare in attack papers: candidate class frozen before feedback, memory-only paired interventions with explicit confound controls (Appendix B), anytime-valid confidence sequences instead of post-selection intervals, and a fixed reporting rule.
- Theory that actually earns its place: the consequence + realization decomposition yields a testable directional prediction (Sec. 5.3 confirms it), and the attribution-ambiguity proposition is directly validated by the factor-removal experiment.
- Fair-support and contract-matched baselines address objective-mismatch confounds head-on; the same-class random-selection ablation isolates the value of the adaptive search itself.
- Dual-use responsibility handled seriously: isolated environments, withheld exploit code, released validators/protocols, compensated human audits.

## Limitations

- Certification and the near-optimality guarantee are conditional on the declared finite edit class and the declared task-loss distribution; nothing bounds severity over all possible edits.
- Construction demands an offline oracle (resettable isolated copies, paired-loss feedback, ≤800 rollouts/instance) that is unrealistic against production agents; only deployment is "realistic".
- Empirical superiority rests on two benchmarks (AgentDojo; airline/retail slices of r²-bench) and two backbones; several baseline CMRs are negative because those attacks optimize different objectives, and CMR interval overlap in individual cells weakens single-setting claims.
- CMR measures benchmark operational loss, not real-world harm (monetary, privacy, policy); BUD is computed only on fixed non-target probes.
- Llama-3.1-70B shows lower ASR (42.1% on AgentDojo) than GPT-4o, and transfer across memory contracts weakens for schema-constrained profile and graph stores (Fig. 4b) — severity is memory-realization-dependent, as the theory predicts, which also limits generality of any single deployed attack.

## Relevance

与你最关注的"长程自治 Agent 系统的可信性与可靠性"高度相关：这篇论文把持久记忆投毒的评价从"是否成功"推进到"造成多大下游损失"，并用置信序列+最优臂识别给出类内可认证的严重度搜索，方法上恰好是统计可靠性与 agent 安全的交叉。其 memory-only 成对干预与 class-conditional 认证思路，对评估自演化 agent 长期记忆被污染后的行为退化也有直接借鉴价值。

## Questions for Further Exploration

- Can CMR-style severity evaluation be run defensively — i.e., as a red-team stress test inside an agent's own memory lifecycle (write-time validation, anomaly scoring on semantic-factor edits) rather than only as an attack oracle?
- How does the frozen-class certification degrade under distribution shift between construction and deployment users (new task mixes, unseen memory contents), where the candidate class was frozen against a different instance distribution?
- Could the consequence/realization decomposition be turned into a detection signal — edits with high κ but poor realization (ρ_edit large) might be detectable as "incoherent" memory, while high-κ high-realization edits are the truly dangerous tail?
- Does severity-guided poisoning transfer to self-evolving agent loops (agents that rewrite their own instructions/skills), where a poisoned reflective memory could compound across iterations rather than acting once?
- The 800-rollout construction budget is large; can amortized or surrogate-model CMR prediction preserve most of the certified severity at a fraction of the cost?
