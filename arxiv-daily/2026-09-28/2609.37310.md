> **一句话总结：** ETH Zurich 团队首次把"自主研究闭环"完整搬到 LLM 水印领域：先形式化三条可靠性判据（失真无关、跨 key 可靠、给定 key 可靠）并配证明有效的统计检验，再让 GPT-6 Astra / Opus 5 / Gemini-3.8 Flash 三种前沿 agent 在沙箱里迭代提出并提交水印方案（共评估 52 个方案、蒸馏出 39 个新组件），最终发现的 ConcordMark 在 held-out 评测（ELI5 英文 + WildChat 中文，Llama-3.1-8B / Qwen3.8-27B）上全面超越 AAR、SynthID、TextSeal——英文改写攻击下 TPR@1%FPR 从 TextSeal 的 66% 提到 82%（+16 pts），同时困惑度偏移 ΔPPL 从 2.9 降到 0.8。

> **TL;DR:** The authors build the first fully autonomous research loop for LLM watermarking. They formalize validity as three criteria — distortion-freeness, soundness over the key, and a novel soundness-given-a-key condition — each backed by a statistical test (valid at level δ) that automatically rejects bad submissions. Frontier coding agents (GPT-6 Astra, Opus 5, Gemini-3.8 Flash) then iterate in a sandboxed verify-then-evaluate harness, producing 52 schemes and 39 new atomic components. On a held-out protocol (1000 ELI5 English + 1000 WildChat Chinese replies from Llama-3.1-8B and Qwen3.8-27B, DeepSeek-V4 Flash as attack model), the discovered ConcordMark (high) lifts English paraphrase-attack TPR@1%FPR on Llama-3.1-8B from 66% (TextSeal, strongest baseline) to 82% (+16 pts) and substitution from 12% to 48%, while cutting perplexity deviation from 2.9% to 0.8% — and the audit shows the production-deployed SynthID fails the soundness-given-a-key test (p-values down to 8.06e-122), meaning its reported robustness is inflated for some keys.

## 核心贡献

- **形式化"什么是有效的水印"**：提出三条判据——失真无关（对任意分布，加水印后期望分布不变）、跨 key 可靠（Eq.2：对任意文本，误报率在 key 上随机时以 α 概率 ≤ α）、以及全新的**给定 key 可靠**（Eq.3：对任意人类文本分布，抽到误报率超 α 的 key 的概率 ≤ β=5%）。他们给出反例：一个满足 Eq.2 的朴素方案在 1% 的 key 上 FPR 接近 1。
- **三个自动验证统计检验**（Algorithm 1–3）：分别检验失真无关性、跨 key 可靠性、给定 key 可靠性，带多重检验校正，在显著性水平 δ 下误拒有效方案的概率有证明上界（App.I 给出完整证明）。
- **水印自主研究 harness**：隔离沙箱 + 水印库（上下文播种、水印分数、logits 变换、检测器四组件）+ 私有验证→评测→排行榜闭环；首个 agent 有 4 次提交额度，后续 agent 各 1 次，防止盲目调参。
- **52 个方案、39 个新组件**：GPT-6 Astra（high/low）、Opus 5、Gemini-3.8 Flash 各自跑满提交额度；人工把所有方案分解为 5 大类 39 个原子组件并逐一消融（每次只换一个组件），识别出真正的新思想——如 per-request 随机高斯方向对齐水印分数（Gaussian direction + ResidualRace）、球面旋转私有几何（RotationFirst 的四元数旋转打分）。
- **两个 SOTA 方案**：ConcordMark（词法组 + Ladder 播种 + Prelude 熵截断 + 6 通道 + Gumbel race，两种检测器）在几乎所有指标上 Pareto 优于全部基线；RotationFirst（WordNet 词法组 + Global-first-use 播种 + 四元数旋转几何 + Predictive Gamma 检测）以接近无损的质量（ΔSB-3 仅 2.1/2.6）拿到最强删除鲁棒性。

## Key Contributions

- **Formal validity criteria for watermarks**: three conditions — distortion-freeness (Eq.1), soundness over the key (Eq.2), and the novel *soundness given a key* (Eq.3: for every text distribution H₀, the probability of sampling a key whose FPR exceeds α is at most β = 5%). A naive 100-class partition watermark satisfies Eq.2 yet has FPR ≈ 1 on ~1% of keys, motivating the third criterion.
- **Three automatic verification tests** (Algorithms 1–3) with proven validity at significance level δ: any scheme failing distortion-freeness, soundness over the key, or soundness given a key is rejected before it can enter the leaderboard (proofs in App.I, Props. 2–4).
- **An autoresearch harness for watermarking**: sandboxed agent environment + a watermarking library exposing 4 composable components (context seeding, watermark score, logits transformation, detector) + a private verify-then-evaluate pipeline with a leaderboard; the first agent gets 4 official submissions, subsequent agents get 1, explicitly to force genuine ideas over hyperparameter tuning.
- **52 schemes from 4 agent runs, distilled into 39 new atomic components**: manual decomposition across 5 categories (watermark unit, context seeding, score, logits transform, detection) with one-component-at-a-time ablations, identifying fundamentally new ideas such as aligning watermark scores with a random per-request Gaussian direction and a per-key spherical rotation ("private geometry") scoring scheme.
- **Two new state-of-the-art schemes**: ConcordMark (lexical grouping + Ladder context seeding + entropy-capped Prelude + 6 independent channels + Gumbel race; Excess-Gamma or forward-pass Position-evidence detectors) is Pareto-superior to all evaluated baselines on almost all metrics; RotationFirst (WordNet lexical grouping + Global-first-use seeding + quaternion-rotation scores + Predictive Gamma detector) achieves near-lossless quality at strong robustness.

## Methodology

**1. Formal validity model.** A watermark is a logits transformation f (keyed by ξ) plus a detector; distortion-freeness requires E_ξ[f(ξ̄, p)] = p for every next-token distribution p. Soundness over the key requires P_ξ[P_ξ(ω) ≤ α] ≤ α for all texts ω. The new soundness-given-a-key condition swaps quantifiers: for every H₀ over texts, Pr_ξ[Pr_{Ω∼H₀}[P_ξ(Ω) ≤ α] > α] ≤ β (β = 5%). A proposition shows any detector satisfying Eq.2 becomes Eq.3-sound when its p-values are divided by 1/β, at a cost in power — the agents used exactly this trick.

**2. Automatic verification.** Algorithm 1 tests distortion-freeness by averaging watermarked distributions over independently sampled keys and checking both per-token probability shifts and spread shifts with multiple-testing correction. Algorithm 2 samples independent private keys and non-watermarked texts and tests whether the empirical false-positive rate is anomalously high. Algorithm 3 screens many keys against a separate text set and binomial-tests whether too many keys screen positive, accounting for the allowed bad-key fraction β.

**3. Research harness.** The agent operates in an isolated sandbox with a dedicated GPU, internet access, and API keys (used mainly for paraphrasing attacks) on top of a `lm-wm-tools` library. It can self-evaluate with public subsets but only `wm-harness evaluate` on committed snapshots gives official verification + grading; results append to a leaderboard. A two-phase setup lets one agent configure the environment and later agents submit with fresh perspectives.

**4. Private evaluation.** Detectability/robustness = TPR@1%FPR on 1000 Llama-3.1-8B replies (200–300 tokens) to ELI5 prompts, clean and under 4 attacks (word deletion, synonym substitution, back-translation, paraphrasing). Quality = distance to the unwatermarked model in perplexity (ΔPPL) and bigram/trigram Self-BLEU (ΔSB-2, ΔSB-3) over 100 replies to 10 prompts. **Held-out protocol** (Sec. 4.3): 1000 ELI5 English + 1000 WildChat Chinese replies generated by Llama-3.1-8B and Qwen3.8-27B, DeepSeek-V4 Flash as the back-translation/paraphrasing attacker, pooled over 5 watermarking seeds (worst/best), with no key-soundness correction applied to any scheme for consistency.

**5. Component science.** All 52 submissions were manually decomposed into 39 atomic components (Figure 3: e.g., lexical group, ladder/unordered/adaptive context seeding, Gaussian copula scores, ResidualRace, Position-evidence detection); each is ablated by swapping it alone into a simple AAR baseline and reporting TPR deltas and quality deviations. Two selected schemes (ConcordMark, RotationFirst) get full pseudocode (Algorithms 4–8) and independent held-out evaluation.

## Results & Highlights

- **Held-out win over all baselines (Table 1, Llama-3.1-8B, TPR@1%FPR, English/Chinese):** ConcordMark (high) reaches 82%/77% under paraphrasing vs 66%/56% for TextSeal (high) and 57%/42% for AAR (+16 pts over the strongest baseline on English); substitution 48%/69% vs TextSeal's 12%/38%; deletion 34%/61% vs 15%/31%; back-translation 89%/55% vs 78%/28%. Simultaneously its quality deviation is lower: ΔPPL 0.8/1.8 vs TextSeal's 2.9/4.4 and ΔSB-3 5.1/5.7 vs 9.3/8.7.
- **Near-lossless quality direction (Table 1):** RotationFirst posts the best quality of all schemes — ΔPPL 0.5/0.6 and ΔSB-3 2.1/2.6 on Llama-3.1-8B vs AAR's 3.1/3.0 and 20/15 — while taking the best deletion robustness (53%/60% vs AAR's 7%/16%), at the price of a lower clean TPR (91/89 vs 95–96 for baselines).
- **Transfer to a second model (Table 1, Qwen3.8-27B):** ConcordMark (high) reaches 98% clean TPR and 83%/82% paraphrase TPR vs TextSeal's 97%/70/74, with ΔSB-3 of 3.3/4.1 vs 7.5/7.5 — the held-out gains are not Llama-specific.
- **The harness catches real reward hacking (Sec. 4.1 / Table 5):** AAR and SynthID (including the production-deployed scheme) fail the soundness-given-a-key test — their private-verification p-values reach 2.98e-82 (AAR) and 8.06e-122 (SynthID) at context width 1, so their reported robustness is inflated for unlucky keys. Calibrating the best baselines to merely pass the empirical check increases their paraphrasing TPR by 13–15 percentage points (Table 5: TextSeal paraphrase 38% guaranteed vs 58% empirical).
- **Component ablations quantify what works (Figs. 5–8, Tables 6–9):** ResidualRace with a Gaussian copula (ρ = 0.95, quality-matched to the Gumbel race) improves TPR by +8.0 (deletion), +6.7 (substitution), +7.2 (paraphrasing); lexical grouping alone adds +9.6 substitution TPR at −1.8 deletion; forward-pass detectors add up to +12.5 paraphrase TPR; context length k=3 vs k=2 adds +35.5 deletion TPR at −0.3 quality.
- **Cost of the loop:** the four agent runs cost $357.08 (GPT-6 Astra high), $123.29 (Astra low), $435.96 (Opus 5), and $13.81 (Gemini-3.8 Flash) — under $1k total for 52 evaluated schemes.

## Authors & Credibility

Thibaud Gloaguen, Robin Staab, and Martin Vechev are the core LLM-watermarking group at ETH Zurich (SRI Lab); Gloaguen and Staab authored prior distortion-free watermarking work (AAR lineage, a unified watermark framework, arXiv 2602.06754) and Vechev's group produced watermark-stealing and robustness literature cited throughout. The topic sits squarely in their established expertise, and the methodological care (proven statistical tests, held-out protocol, full per-submission results in Table 5, promised code release including standalone ConcordMark/RotationFirst implementations and the harness) reflects a strong reproducibility posture. The LLM-usage statement is unusually transparent: all watermark proposals were agent-designed, but the component decomposition, ablations, and paper were human-written, and the proofs were LLM-drafted then human-edited.

## Critical Assessment

- **Genuine novelty, well-earned.** The soundness-given-a-key criterion is a real conceptual contribution, not packaging: the demonstration that the *deployed* SynthID fails it (p-value 8.06e-122 at context 1 in their own prompt-table audit) is exactly the kind of finding only a formal harness surfaces, and the 1/β-calibration proposition cleanly connects Eq.2 and Eq.3.
- **Selection-bias risk is mitigated but not eliminated.** ConcordMark and RotationFirst were picked from the same leaderboard metrics that defined the agents' reward. The held-out protocol changes prompts (ELI5→WildChat), model (8B→also Qwen3.8-27B), language, and attacker (DeepSeek-V4 Flash), but keeps the same metric family (TPR@1%FPR, ΔPPL, ΔSB-2/3), so agents optimizing those exact metrics for 52 rounds could still have overfit the metric shape even if not the data.
- **Small statistical base.** Results pool 5 watermarking seeds reporting worst/best with no confidence intervals; several claimed wins are thin — e.g., ConcordMark's 98 vs SynthID's 97 clean TPR on Qwen is within plausible seed noise, and the Llama clean-TPR edge (96 vs 95) is negligible even as the scheme is called Pareto-superior "on almost all metrics".
- **Ad hoc multiplicity choices in headline numbers.** Figure 2's reported TPRs depend on per-agent p-value multipliers chosen by the authors (20 for GPT-6 Astra submissions except the first two, 1 and 4 for Opus 5, none for baselines) — a researcher degree of freedom that directly shapes the 85.7%-vs-57.4% trajectory headline, though Table 5 transparently reports all three correction settings.
- **Autoresearch claims rest on n=4 agents.** Gemini-3.8 Flash produced zero novel ideas (pure TextSeal hyperparameter tuning for all 11 submissions), so the "agents discover fundamentally new ideas" narrative is really "two frontier models did". One submission per follow-up agent also caps how much genuine iteration the loop demonstrates.
- **The science is not autonomous.** The decomposition of 50+ schemes into 39 components and every ablation were designed and executed by humans; agents generated candidates, humans did the analysis. The paper says so, but titles like "Enabling Autoresearch" should be read as "automated candidate generation with human verification science".
- **Scope of "better" is narrow.** Robustness covers only 4 text-edit attacks; security (spoofing/stealing), radioactivity, multibit, and open-weights settings are explicitly out of scope, so "Pareto-superior watermark" means "on detectability/quality under benign edits", not a full deployment claim. Evaluation is also limited to 8B/27B open models — no evidence the schemes hold at frontier scale.

## Strengths

- Formal criteria with complete proofs (Props. 1–7, Lemma 3): the verification layer is statistically sound by construction, which is rare in agent-evaluation papers.
- The harness demonstrably resists reward hacking: it flags AAR and SynthID for key-dependent FPR inflation and quantifies the bias (13–15 pts of paraphrase TPR) instead of silently accepting their numbers.
- Held-out evaluation with changed prompts, language, models, and attacker model supports the claim that autoresearch gains transfer rather than overfit.
- The 39-component ablation atlas is a standalone contribution to watermarking research — e.g., isolating that ResidualRace + Gaussian copula buys +7–8 TPR across attacks at matched quality, and that forward-pass detection is worth +12.5 paraphrase TPR.
- Exceptional transparency: full per-submission results (Table 5), all three p-value correction settings reported, per-run agent costs, agent prompt reproduced verbatim, and a concrete code-release plan.

## Limitations

- Only 1–4 official submissions per agent and n = 4 agent runs; both the search depth and the evidence base for "research dynamics" claims are thin.
- No uncertainty quantification: 5 watermarking seeds, worst/best reporting, no confidence intervals on TPR or quality deltas.
- Evaluation restricted to Llama-3.1-8B and Qwen3.8-27B; ELI5/WildChat prompt distributions; 4 edit attacks; security, radioactivity, multibit, and open-weight deployment out of scope (acknowledged by the authors).
- Quality measured only via perplexity and Self-BLEU — distortion-free watermarks can still reduce output diversity on repeated prompts, which these metrics only partially capture.
- The Gaussian-direction and rotation-geometry ideas increase detector complexity (RotationFirst detection needs eigen-decomposition of 512 quaternion products); inference-time detection cost is not analyzed.
- Human effort (decomposing 52 schemes, designing ablations) is substantial and unquantified — the end-to-end autonomy is partial.

## Relevance

这是"自进化智能体与自动化研究"最高优先级方向的一线案例：完整展示了如何为自主研究设计防 reward-hacking 的验证器、如何用统计检验约束 agent 的提交，并且 agent 确实产出了人类尚未提出的新机制（per-request 高斯方向对齐、球面旋转私有几何），对长时自主系统的可信性研究极具参考价值。其"给定 key 可靠性"检验抓出已部署 SynthID 缺陷的发现，也示范了严格 verifier 如何在自动化闭环中替代人类审稿。

## Questions for Further Exploration

- Does soundness given a key matter in practice — how often do real deployed keys exhibit inflated FPR, and how much detection power does the 1/β calibration actually cost in production?
- Would ConcordMark/RotationFirst retain their Pareto advantage on frontier-scale models whose next-token distributions are much sharper than Llama-3.1-8B's?
- Can the verification framework extend to *security* properties (spoofing/stealing robustness) where the evaluation itself is adversarial and the agent could attack the verifier?
- The component ablations swap one component into an AAR base at a time — do the discovered components compose (e.g., ResidualRace + lexical grouping + forward-pass detection) without interfering?
- Is the binding constraint on autoresearch the agent's creativity (Gemini-3.8 Flash found nothing) or the submission budget (1 submission for follow-up agents)?
- How do the schemes behave under adaptive attackers who know the scheme family (e.g., paraphrase ensembles or scoreboard attacks against the 6-channel ConcordMark detector)?
