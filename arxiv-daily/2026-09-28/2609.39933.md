> **一句话总结：** 针对 AutoResearch 式 LLM 代码进化循环"只看标量任务指标、看不见编辑如何损害相互竞争的模型行为"这一盲区，提出 ConflictGuide：一个可复用的 ConflictGuide-Skill 先依据文献扎根的 Root–Axis–Mechanism 分类体系（9 根、6 轴、110 机制）从模型架构/任务/目标证据中识别具体行为冲突并设计经"零校准+配对回放"资格认证的可测探针（Probes），随后在标量反馈的 Stage I 探索之后进入 Stage II，用探针反馈引导提案朝冲突缓解方向演化、并允许保留任务增益极小但确实缓解冲突的编辑；在 5 个异构模型家族（SpecB-FNO、SNGP、GCNII、ESN、TCM-Lite）的等预算配对实验中，任务误差相对标量反馈 AutoResearch 最高降低 28%、冲突相关误差降低 14%，并把"双改进"提案占比从 7.2% 提升到 13.1%。

> **TL;DR:** Scalar-feedback-only AutoResearch loops plateau because they cannot see how a code edit helps one behavior while hurting a competing one. ConflictGuide adds two things: (1) ConflictGuide-Skill, a reusable agent skill that uses a literature-grounded taxonomy (9 Roots, 6 Axes, 110 mechanisms) to identify a model-specific behavioral conflict and design quantitatively "qualified" probes that measure both competing behaviors; (2) a two-stage schedule — scalar-only exploration first, then probe-guided refinement plus a retention rule that keeps marginal-gain edits only when probes show sufficient conflict alleviation. On five model families (e.g., SpecB-FNO on Navier–Stokes, SNGP on CIFAR-100), delayed probe feedback beats the matched scalar-only AutoResearch baseline by up to 28% lower task error (ESN NRMSE 0.2285 vs 0.3173 on Mackey–Glass) and 14% lower conflict error (SpecB-FNO ND-NMSE 0.0530 vs 0.0616), and raises the share of jointly-improving proposals from 7.2% to 13.1%. Ablations and controls (multi-metric feedback, trade-off-only prompting) show the gain comes from measuring the instantiated conflict, not from extra metrics or a qualitative warning.

## 核心贡献

- **首次把"竞争行为反馈"显式引入 AutoResearch 循环**：证明标量任务反馈在早期支持广泛探索、但无法揭示编辑对各竞争行为的影响；在等预算对照实验中，从共享标量分支点延迟引入冲突反馈后，双改进提案占比 7.2%→13.1%，双劣化占比 29.0%→20.7%，并突破纯标量搜索的平台期。反向实验（Appendix A）表明从零一开始就给冲突反馈反而更差（test NRMSE 0.046471 vs 纯标量 0.037916），支撑"先探索后精修"的两段式设计。
- **ConflictGuide-Skill（可复用技能）**：基于文献扎根的 Root–Axis–Mechanism 分类体系（9 Roots、6 Axes、110 个机制，含独立的 OPT 类），把目标模型的架构/任务数据/训练目标/文献证据映射为一个具体冲突（两个独立可取的行为 B_A、B_B 经共享机制 M_c 耦合），设计最小非冗余探针集，并通过零校准、配对回放、标量挂钩检测等资格认证；证据不足时显式 Abstain/Reject 而非强行制造冲突，输出可机读的 Conflict Probe Card。
- **两段式 ConflictGuide 进化**：Stage I 纯标量引导探索（固定预算，默认 100 步）；Stage II 在提示词中加入探针读数引导提案，并扩展保留规则 Keep(e_t)=[G_t>τ_S]∨[G_t∈[0,τ_S)∧A_t(e_t)>τ_A]——负增益永不保留，边际任务增益的编辑仅在探针证明充分缓解时经辅助通道保留。
- **跨 5 个模型家族与多代码代理的验证**：SpecB-FNO（Navier–Stokes PDE 学习）、SNGP（CIFAR-100 + OOD）、GCNII（Wisconsin 图节点分类 + 标签污染）、ESN（NARMA-30 / Mackey–Glass 预测）、TCM-Lite（Kodak 学习图像压缩）；消融拆分出"引导"与"保留"的互补作用，并与 multi-metric 反馈、trade-off-prompt-only 两个替代基线对照；方法可移植到 Kimi K2.7 Code 与 AIDE 框架（o4-mini/GPT-4.1-mini、GLM-5.3/GLM-5.3-Flash）。

## Key Contributions

- **First explicit competing-behavior feedback in AutoResearch.** Matched-budget studies show scalar-only feedback drives 29.0% of proposals into joint degradation; delaying conflict feedback to a shared Stage-I branch point raises joint improvements from 7.2% to 13.1%, cuts joint degradation to 20.7%, and sustains progress past scalar-only plateaus. Providing probes from the outset is counterproductive (test NRMSE 0.046471 vs 0.037916 scalar-only), motivating the two-stage design.
- **ConflictGuide-Skill: taxonomy-grounded conflict identification with abstention.** A fixed Root–Axis–Mechanism taxonomy (9 roots, 6 axes, 110 mechanisms) is screened against model-specific evidence; the skill instantiates only conflicts with two independently desirable behaviors, a shared coupling mechanism, and bidirectional interference, designs a minimal probe set, qualifies probes via null calibration and paired replay, and emits a machine-checkable Conflict Probe Card — or abstains/rejects.
- **Two-stage evolution with probe-gated retention.** Stage II conditions proposals on probe readings and retains an edit when task gain exceeds a substantive band OR when a marginal gain coincides with sufficient measured alleviation; negative task gains are never retained.
- **Evaluation across five heterogeneous model families and four agent configurations**, with an ablation separating guidance vs retention roles, controls against multi-metric feedback and trade-off-only prompting, and a scalar-ambiguity analysis (mean normalized outcome entropy 0.892 within task-gain quartiles) showing scalar gains do not predict behavior outcomes.

## Methodology

**Problem setup.** An AutoResearch-style coding agent iteratively proposes a code edit e_t to training code x_t; the candidate is trained and evaluated under a fixed budget, yielding scalar task metric S(x) (minimized in all experiments). Standard AutoResearch conditions each proposal only on the current code and a history of (e_t, G_t) task gains. ConflictGuide defines a model-specific conflict c = (B_A, B_B, M_c): two desirable behaviors coupled through a shared mechanism, with an associated probe vector Z_c(x) = [Z_1(x), …, Z_{m_c}(x)] whose per-edit changes Z^Δ give behavior-specific feedback.

**ConflictGuide-Skill (offline, once per model).** A five-stage workflow (model context → taxonomy screening → conflict instantiation → probe design → probe qualification) maps architecture, task/data, objective, and literature evidence onto the fixed taxonomy. Screening uses only pre-evolution information — it cannot inspect evolution trajectories, ablations, or final results — preventing a conflict from being chosen retrospectively to explain an outcome. Probes are read-only diagnostics (observables from outputs, internal states, or parameters) qualified by no-intervention null calibration, paired replay, scalar-tied informativeness tests, and direction tests; probes that duplicate the scalar metric, leak unavailable information, or depend on post-hoc tuning are rejected. The probe set, thresholds, and guard conditions are frozen before probe-guided search begins.

**Two-stage evolution.** Stage I follows standard scalar-only AutoResearch for a fixed budget T_1 (100 iterations for most models). Stage II augments the prompt with each edit's task gain and probe-derived changes, and extends retention: Keep(e_t) = [G_t > τ_S ∨ (G_t ∈ [0, τ_S) ∧ A_t(e_t) > τ_A)], where τ_S separates substantive from marginal task gains, A_t(e_t) is a probe-based alleviation score, and τ_A is a calibrated alleviation threshold; negative gains are never kept.

**Experimental design.** Five settings: SpecB-FNO (32-width, 4-layer FNO on 2D Navier–Stokes at 64×64, ν=10⁻⁵; task NRMSE, probe = non-dominant relative spectral error Z_ND), SNGP (WRN-28-2 on CIFAR-100; task clean ID NLL, probes = max/near distance features; held-out OOD AUPR on SVHN and CIFAR-10), GCNII (8-layer, dim-64 on Wisconsin; clean NLL vs contaminated NLL under ρ=0.3 label contamination, 10 splits), ESN (100-unit echo-state network on NARMA-30 and Mackey–Glass long-horizon forecasting, 200 paired runs), TCM-Lite (learned compression trained on DIV2K, evaluated on Kodak at λ=0.013; bpp, MS-SSIM, probe = latent detail loss Z_detail). All comparisons branch from a shared Stage-I checkpoint into matched-budget continuations (scalar-only vs ConflictGuide); winners are retrained from scratch in full-scale formal evaluation on 3 paired seeds (200 for ESN). Default agent is Claude Code Opus 4.6; transfer experiments use Kimi K2.7 Code and AIDE (o4-mini/GPT-4.1-mini and GLM-5.3/GLM-5.3-Flash).

## Results & Highlights

- **Headline (matched budgets, best across rounds):** up to 28% lower task error and 14% lower conflict-related error vs scalar-only AutoResearch. Concretely: on ESN Mackey–Glass forecasting, round-0 NRMSE is 0.2285±0.0308 (ConflictGuide) vs 0.3173±0.0292 (AutoResearch) vs 0.4261±0.0417 (unmodified reference), R² 0.9468 vs 0.8986 vs 0.8167; the 14% conflict-error figure is SpecB-FNO ND-NMSE 0.053048 vs 0.061608 (−14.0%) from the delayed-feedback full-scale study (Table 11), alongside test NRMSE 0.034447 vs 0.038224 (−9.9%).
- **Behavioral outcome shift (Figure 1b):** across models, the share of proposals improving both behaviors rises from 7.2% to 13.1% and joint degradation falls from 29.0% to 20.7%, measured from matched scalar-only branch points — the core evidence that making conflicts visible reshapes what the agent proposes.
- **Per-family wins (best bolded in nearly every cell):** SNGP on CIFAR-100 round 2: NLL 0.8455±0.0076 vs AutoResearch 1.1777±0.0210 and reference 1.0434; SVHN OOD AUPR 0.8131 vs 0.7890 / 0.7838. SpecB-FNO round 2: ND-NMSE 0.0695 vs 0.0809 / 0.0861 (task NRMSE 0.0398 vs 0.0399 / 0.0458 — task gain over AutoResearch is marginal here; the win is on the conflict metric). GCNII round 1 accuracy 0.7961±0.0615 vs 0.7022; TCM-Lite round 0: bpp 0.5442 with MS-SSIM 0.9209 vs 0.9186/0.8981 (better rate and quality simultaneously).
- **Ablation (Table 7) separates the two mechanisms:** on SpecB-FNO, guidance alone moves NRMSE 0.0382→0.0348 and full ConflictGuide to 0.0334 (ND-NMSE 0.0617→0.0553→0.0530); on SNGP, guidance-only *degrades* OOD AUPR below baseline (0.7014 vs 0.7880) and the auxiliary retention rule is what restores 0.8131 — guidance redirects proposals, retention filters noisy task gains.
- **Value is the instantiated measurement, not extra information (Table 8):** multi-metric feedback and trade-off-prompt-only (a one-sentence qualitative warning) both lose to ConflictGuide — SNGP NLL 0.8918 / 1.1959 vs 0.8455; OOD AUPR 0.7292 / 0.7317 vs 0.7357 — so a generic caution or generic extra metrics do not substitute for model-specific probes.
- **Mechanism-level proposal shift (Figure 6, Appendix J):** conflict-relief proposal rate nearly doubles on SNGP (10.8%→21.5%) and rises on GCNII (20.0%→28.8%); TCM-Lite pointwise-mixing edits fall 27.0%→7.4% while spatial refinement rises to 34.1%. Scalar-gain quartiles carry mean normalized behavior-outcome entropy 0.892 (no category above 35.8%), quantifying scalar feedback's ambiguity.
- **Transfers across agents:** replacing Claude Code with Kimi K2.7 Code (test NRMSE 0.03876 vs reference 0.0458) and integrating probes into AIDE's tree search improves outcomes under GLM-5.3/GLM-5.3-Flash (0.04193 vs 0.04286 unguided; validation NRMSE 0.110931 vs 0.118911), with the caveat that in the o4-mini/GPT-4.1-mini run no refinement node met the full probe-qualification rule, so probe-informed parent selection never activated there.

## Authors & Credibility

The authors are from the National University of Singapore (Binxuan Xu, Qiran Zou, Dianbo Liu) and Nanjing University of Science and Technology (Xiangbo Shu). The work sits in the growing AutoResearch / agentic ML literature and builds directly on Karpathy's publicly available AutoResearch codebase, extending it rather than rebuilding it. Methodological hygiene is above average for this genre: matched-budget paired-seed continuations from shared checkpoints, formal evaluation by retraining winners from scratch on held-out sets accessed only after search, pre-registered probe qualification and frozen thresholds, an AI-use statement, and a reproducibility statement saying the skill and experimental code are included in supplementary material (with schemas to be released in a public repository "upon acceptance"). The exhaustive 110-mechanism taxonomy is documented appendix-wide with selection rules, though it is author-curated via "agent-assisted literature collection followed by researcher consolidation."

## Critical Assessment

- **Novelty is real but incremental in mechanism.** Diagnosis-guided evolution exists (Self-EvoleRec, GoalEvolve, EvoPINN); the paper's distinct contribution is specifically *competing-behavior* feedback plus a probe-gated retention rule, and the delayed-vs-early feedback study is a genuinely useful design finding. The taxonomy itself is a curation artifact rather than a validated instrument: there is no comparison against taxonomy-free probe design (the authors admit this in Appendix K), so the 110-mechanism structure could be largely unnecessary — a hand-rolled conflict per model might do just as well.
- **Some headline numbers are best-case.** "Up to 28%" comes from ESN round 0; in SpecB-FNO round 2 the task-metric gain over AutoResearch is 0.0398 vs 0.0399 — essentially a tie — with the win carried by the conflict metric (ND-NMSE 0.0695 vs 0.0809). The honest summary is "consistent conflict-metric gains, task gains vary from negligible to large," which the tables do show but the abstract compresses.
- **A quiet negative result on SNGP CIFAR-10 OOD:** ConflictGuide's OOD AUPR on CIFAR-10 (0.7487 / 0.7497 / 0.7357 across rounds) never recovers the unmodified reference's 0.7804 — it only beats AutoResearch's 0.7181. The conflict "improvement" on that dataset is relative to a degraded baseline, not to the original model.
- **High-variance settings undercut statistical confidence.** GCNII on Wisconsin (a 251-node dataset) has bolded means with s.d. like ±0.4883 (contaminated NLL) and ±0.0615 (accuracy); at 3 seeds / 10 splits, many "best" cells are not clearly separated from baselines, and no significance testing is reported anywhere.
- **The ablation complicates the story.** Guidance-only *hurts* SNGP OOD AUPR below the scalar-only baseline (0.7014 vs 0.7880); only the auxiliary retention path recovers it. So probe feedback is not uniformly safe — the paper's framing of two "complementary roles" glosses over the fact that one component alone is actively harmful in one setting.
- **Setup cost and reproducibility gaps.** The five conflicts and probes are bespoke, model-specific constructions; Appendix K concedes the per-model setup effort "varies by model and is not included in a uniform end-to-end cost comparison." Code and skill ship as supplementary material with public release promised "upon acceptance" — not independently verifiable today. In the o4-mini AIDE transfer, probe qualification never activated, meaning one of four agent settings only partially exercised the method, which softens the "generalizes across code agents" claim.

## Strengths

- A clear, well-motivated blind spot identified — scalar feedback masks competing-behavior effects — with a direct quantification (7.2% joint-improvement share, 0.892 outcome entropy within task-gain quartiles) rather than anecdote.
- Disciplined experimental design: shared Stage-I branch points, matched continuation budgets, paired seeds, from-scratch retraining for formal evaluation, held-out data touched only after search, and frozen probe thresholds set before evolution.
- The timing study (early vs delayed feedback) is the kind of negative control most agent papers skip, and it directly justifies the two-stage schedule with a budget-sensitivity analysis (100/100 split best at fixed 200 total).
- Strong baselines for the core question: multi-metric feedback and trade-off-prompt-only controls isolate *measured, instantiated conflicts* as the active ingredient — the paper's central claim is properly controlled.
- The skill's abstention/rejection semantics (refusing to force a conflict when evidence is insufficient) and machine-checkable Probe Cards are a thoughtful reliability pattern for long-running agent systems.

## Limitations

- Applicability is conditional: the method requires a conflict supported by sufficient model-specific evidence with both behaviors measurable by probes; when the skill abstains, ConflictGuide degenerates to plain AutoResearch.
- Only one conflict per model family, five families total, all with hand-designed probes; no taxonomy-free or automated probe-design baseline; broader applicability unestablished (authors' own admission).
- Per-model probe specification/implementation/qualification effort is variable and excluded from the end-to-end cost accounting — the "matched budget" comparisons ignore the human/agent setup overhead that dominates in practice.
- The Stage I→II transition uses a fixed prespecified schedule (100/100 default); adaptive timing is deferred to future work, and the budget-sensitivity study covers only SpecB-FNO.
- No significance testing; several wins (especially GCNII) ride on large-variance small-data settings. Public code release is gated on paper acceptance.

## Relevance

这篇论文正中你置顶的"Self-Evolving Agents & Automated Research"方向：它直接改进 AutoResearch 式自进化代码循环的反馈机制，且其"探针资格认证 + 证据不足即弃权 + 冻结阈值防事后挑选"的设计与你关心的长时自主 agent 系统可靠性高度相关。对做 LLM 训练可观测性的人来说，"用模型内部可观测量为进化循环构造诊断探针"的思路也值得借鉴。

## Questions for Further Exploration

- How would a taxonomy-free baseline — letting the agent propose its own conflict and probes with the same qualification gates — compare against the 110-mechanism taxonomy? Is the taxonomy load-bearing or decorative?
- Can probe construction and qualification be automated and amortized across models, and what is the true end-to-end cost once per-model setup effort is included?
- The guidance-only ablation harms SNGP OOD AUPR below baseline: what guardrail makes probe feedback safe to inject without the auxiliary retention rule?
- Would adaptive Stage I→II timing (driven by scalar-gain diminishing returns) remove the need for per-model budget tuning, and does the delayed-feedback conclusion hold for LLM training loops where "behaviors" are harder to probe?
- The SNGP CIFAR-10 OOD result never recovers the unmodified reference: does conflict-driven search systematically trade one OOD axis for another, and how should multi-conflict settings be handled?
