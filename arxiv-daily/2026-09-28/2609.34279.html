Why this matters

Automated curriculum design gets cheaper: self-improving LLM loops can borrow closed-source API models as task generators — impossible when the challenger must be trained.

“把自动课程生成从『再训练一个出题模型』简化为『采样问题』”，直接命中 Self-Evolving Agents 方向。

Critical edge

“Half the wall-clock” conflates challenger removal with ~3× less data per round; against the matched no-walk control, the Metropolis walk costs a 2.5–3× time premium for +1.8 AVG7 — single run per cell, no error bars.

Methodology distilled

From training a proposer to sampling from a target. The KL-regularized challenger objective has a Gibbs closed form — an exponential tilt qt(x) ∝ π₀(x)·exp(rc/β) that puts exponentially more mass on tasks the current solver finds hard. So the proposer need not be a trainable model at all: sample near the tilt instead.

Theory, honestly scoped. For the idealized exact-tilt sampler, Theorem 1 bounds worst-case answer uncertainty over any KL-ball around the base task distribution (distributionally robust sharpening); Corollary 1 turns it into an accuracy bound. The implemented walk is explicitly an approximation — motivation, not guarantee.

Strengths

  • The right control: matched-pool no-walk ablation cleanly separates walk value from challenger-removal value — most self-evolving papers omit this.
  • Large efficiency gain (52–61% wall-clock) verified per-model on stated hardware.
  • API-only generator is a genuinely new design point, not just a benchmark delta.
  • Theory that explains the mechanism (tilt sampling chases worst-case uncertainty), with honest scoping of what is idealized.
  • Exceptional reproducibility: every prompt archived, full config table, shared grading harness, explicit compute caveat.

Limitations

  • Math-only: majority-vote pseudo-labels assume verifiable boxed answers; agent / open-ended tasks untested.
  • Fragile evidence: 3 rounds, one run per configuration, no variance estimates; ranking flips across iterations at 4B.
  • No cross-round memory — each round restarts from fresh seeds, likely capping curriculum compounding.
  • Theory–practice gap: implemented walk omits the Hastings factor, uses noisy m=9 scores; the bound covers none of the evaluated numbers.
  • Visible regressions: AIME 2024 at 4B falls below base; R-Zero itself is unstable at OctoThinker scale, weakening that comparison.

Questions for further exploration

  1. Does the walk’s advantage persist, compound, or regress beyond round 3 — and how sensitive is it to β=0.1 and the BLEU penalty?
  2. Can worst-case uncertainty inside the KL ball be measured empirically, and does the approximate walk stay inside the predicted envelope?
  3. Can cross-round memory or adaptive temperature close the theory–practice gap, and recover part of no-walk’s 2.5–3× time advantage?
  4. Do stronger (or weaker) closed-source generators help or hurt — does generator–solver capability mismatch degrade pseudo-label quality?
  5. Can DEO extend past verifiable math to agent/tool-use training, where “disagreement” needs a different challenge reward?
