Why this matters

与你最高优先级的「自进化智能体与自动化研究」直接相关——用 RL 把智能体自身的文件操作变成跨上下文记忆。 AutoResearch is a verifiable automated-ML research loop, and the interface-prior diagnostic shows which capabilities RL can elicit rather than teach — key for long-horizon, self-evolving agents.

Critical edge

The 4B “matches 35B” headline is a non-separation — the paper's own CIs “overlap almost completely” ([12.7, 19.3] vs [12.5, 19.4]). Only the 9B-vs-122B comparison separates.

And the mandated checkpoint alone scores 41.8% — a large share of the headline gain is scaffold subsidy, not learned memory.

Method

One shell tool, one checkpoint file, fully asynchronous PPO

CAMG is four finite-horizon POMDPs where the active context is wiped at task-defined boundaries — anything gathered earlier survives only if written to an episode-persistent workspace. A single shell_command tool over the workspace root is the only interface; at each boundary the policy must author .agent_memory/CONTINUATION.md (≤ 8,192 bytes), then recover by ordinary file reads.

CAMG-RL jointly trains one Qwen3.5-4B/9B policy across all four environments with fully asynchronous PPO: task actions and file operations share one trajectory, GAE (γ=λ=1) propagates terminal task reward back to earlier memory writes, and a dual-granularity estimator keeps one advantage per response while clipping the PPO ratio per token (ε=0.2). Rollout workers append to a persistent episode queue (64 episodes/update, 200 updates, 12,800 episodes), so no worker waits on the slowest environment. Training costs ~120–140 GPU-hours: 6 training + 2 generation GPUs, BF16 + FSDP2 + SGLang, AdamW lr 1e-6.

.agent_memory/CONTINUATION.md — ≤ 8,192 bytes, environment-mandated at every boundary The only required memory artifact. Everything else — stores, retrieves, revisions — is voluntary, ordinary file I/O credited purely by downstream task success.

Mechanism — the paper's best claim to novelty

Why it works: elicitation, not instruction

The frozen base already prefers filesystem actions over dedicated memory tools; RL converts that latent prior into complete store→retrieve→use chains while barely moving the weights. Causal controls (blank / shuffle / transplant) confirm it is the content, not the motion, that helps.

0.25 vs 6.37

nats/token, store intent

Filesystem writes vs AgeMem's dedicated tools on the frozen base (full ranges: 0.076–1.193 vs 0.653–3.927). Renaming the tool moves surprisal < 0.013 nats.

8.0 → 20.9%

complete memory chains

Store→retrieve→use episodes across training quarters. AgeMem attempts its tools in only 53 of 261,941 training responses — and never completes a chain.

−14.1 / −11.5 pts

blank / shuffle memory content

Content interventions at the first boundary hurt every environment (worst: Shop −29.4 blanked; DeepResearch −16.7 shuffled). The content is causal.

‖ΔW‖/‖W‖ ≈ 0.0022

weights barely move

Supports the elicitation story — but with 61.7% of Coding failures being outright wrong fixes, the 4B backbone, not the memory machinery, is the capability ceiling.

Assessment

Strengths vs limitations

Strengths

  • Reframes agent memory as eliciting pre-trained behavior, backed by a rare battery of causal controls: name-token decomposition, aliased tools, documentation deletion, content blank/shuffle.
  • Statistically disciplined: paired bootstrap CIs, 5-seed robustness, fixed failure denominators, explicit contamination checks against external benchmarks.
  • Practical recipe: fully asynchronous PPO with a persistent episode queue absorbs variable-duration episodes; ~20 GPU-hours per run puts replication within academic reach.
  • Honest failure accounting; the policy writes and re-reads its checkpoint in 94/94 boundary episodes, cleanly separating memory behavior from fix-quality headroom.
  • Dual-granularity PPO is a simple, ablated (+4.3 pts over per-token GAE) contribution useful beyond this paper.

Limitations

  • Memory scope is one episode, one user; backbones top out at 9B. Cross-episode memory is explicitly future work.
  • The environment-mandated checkpoint scaffolds part of the result — continuation-only reaches 41.8%; only the 8.0→20.9% chain rate measures voluntary memory use.
  • Headline external claim is statistically thin: 4B vs 35B is a non-separation, and the CAMG average win over CompactionRL is significant on only 2 of 4 environments.
  • Self-built environments (synthesized Shop families; single frozen Kimi-K2.6 judge for DeepResearch) are not externally validated; code promised, not yet released.
  • No strong non-Qwen external scaffolds on SWE-bench for context; MLE-bench Lite absolute scores (4.5–9.1% Any Medal) are far from practical utility.
Open questions

For further exploration

  • Q1Does the filesystem-memory prior transfer to 30B+ backbones, where wrong-fix failures dominate — or does the elicitation advantage shrink as base competence grows?
  • Q2Can memory persist across episodes and users — would the same RL recipe learn cumulative, reusable knowledge files?
  • Q3How would CAMG-RL fare against strong external scaffolds (mini-swe-agent with compaction, AgentFold-style folding) on SWE-bench Verified?
  • Q4With a purely voluntary checkpoint regime, does the 41.8 → 54.4 gap widen because the policy fails to checkpoint at all?
  • Q5Is the AgeMem gap about out-of-distribution tools or parse friction? A gradual tool curriculum might separate the explanations.
  • Q6DeepResearch rests on one frozen judge — how sensitive are rankings to judge choice, and would executable-evidence grading reorder them?
