01

Methodology · how it works

external state graph + evidence check + hierarchical repair

StateGuard externalizes analytical progress into committed states Sk = (issue, constraints, versioned variables, conclusions, relations). Relations carry the semantics — a revised COGS value INVALIDATEs every artifact derived from the old one — forming a dependency-traceable state graph instead of textual memory.

INITPROGRESSBRANCH INVALIDATECOMBINE

The Qwen3-8B manager is strictly an advisor: the worker stays the sole executor, and the manager speaks only through state hints and error hints. A harness enforces each state’s lifecycle and routes it by evidence, not vibes:

State lifecycle (harness-enforced)
OPEN→ UPDATE→ VERIFY→ FINALIZE→ COMMIT /  REPAIR

Light repair injects a hint; heavy repair has the harness physically delete invalid artifacts; repeated failure falls back to rollback or ABANDON — stopping contamination before it reaches downstream states.

Four evidence tools per verdict
syntax_compile code_inspection execution_check independent_probe

Training is two-stage. Cold-start SFT on 3K counterfactual trajectories synthesized replay-then-live (teacher: DeepSeek-V4-Pro; only execution-verified triplets kept, benign interventions as hard negatives), then DAPO RL (8 rollouts/prompt, 8×A100) with a validity-shaped reward:

Read this panel twice. The flagship “validity-aware intervention” is barely exercised; most of the gain comes from persistent state hints keeping context consistent. The turn-level micro-average lets one early fix lift many downstream turns — exactly the setting state hints shine in. The 0.35-weighted R_intervention is rewarded for a pathway worth roughly 1% of measured gains.

05

Strengths

what holds up

  • Clean abstraction: “memory tracks what was found; StateGuard tracks whether it is still valid” — with typed INVALIDATE/COMBINE relations that map naturally onto data workflows.
  • Strictly controlled evaluation: baseline is the identical stack with the manager disabled — no prompt or scaffold confound.
  • Training-order insight: RL-only collapses to 31.65 while SFT-only reaches 51.78 — a real finding about orchestration for protocol-heavy agents.
  • Unusual transparency: cluster-bootstrap CI, admission of how few gains come from repair, published failure cases, per-benchmark cost tables.
  • Manager-as-advisor composes across 8 heterogeneous backbones without touching worker prompts.
06

Limitations

where it breaks or blurs

  • Local evidence only: no formal guarantees over the dependency graph — a semantically-wrong-but-consistent state (Kaggle Survey 2019 case) sailed through all four checks and still propagated.
  • Backbone-gated gains: negligible-to-negative on weak open-weight models; Qwen3-8B regresses on Education and DABstep-easy.
  • Serialized cost: ~134.5 calls × 18.4 s per task; the authors themselves flag internalization and event-triggered cadence as future work.
  • Partial reproducibility: 3K trajectories come from proprietary DeepSeek-V4-Pro via a hand-tuned pipeline; no code or data release stated.
  • Single configuration: one manager size (Qwen3-8B), one teacher; LLM-judge scoring variance unquantified; LongDS-Bench author overlap = self-evaluation proximity.
07

Questions for further exploration

open threads worth pulling

  1. Can stronger semantic verification (typed invariants, provenance checks) raise the 1.03% strict-attribution rate by an order of magnitude — or is the bottleneck the worker’s willingness to act on repair hints?
  2. R_intervention carries 0.35 of the reward, yet only 74 repairs fire. Is this term actually learnable, or starved by the harness’s conservative repair gating?
  3. Would event-triggered review cadence (firing on state uncertainty or dependency depth) keep the +9.52 at a fraction of the 134.5-calls-per-task cost?
  4. Does the replay-then-live counterfactual synthesis transfer to a fully open teacher (e.g. Qwen3-32B), and how sensitive is quality to teacher strength?
  5. Can INVALIDATE-style relations be internalized into the worker’s own planning instead of remaining an external serialized manager?
  6. How does the manager interact with non-deterministic workers at temperature > 0, given 140 regressing turns were partly attributed to stochasticity?

伦坛位置 / Relevance

与你的研究方向的交集

正中你“长时程自主系统的可靠性与可信性”优先方向：它把 agent 长程运行中最隐蔽的失效模式——上游产物失效后的静默错误传播——变成了可外化、可验证、可修复的对象， 并给出完整训练方法与诚实的归因分析。

For self-evolving agents that must self-correct across multi-stage research or data pipelines: borrow both the “state-as-verifiable-object” design pattern and the empirical warning that intervention signals are rare — the payoff comes from persistent state context.
