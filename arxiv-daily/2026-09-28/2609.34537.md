> **一句话总结：** 该论文提出 SciARP 基准，将 GPQA、SciBench、OlympiadBench、BixBench 中的 620 道科学题改造成 3–13 轮相互依赖的多轮任务，在推理过程中实时注入 13 类"科学上貌似合理"的扰动，以配对活执行方式评测 8 个前沿 LLM 智能体——发现推理类扰动平均造成 50.69% 的任务准确率（TACC）退化，而"证据类"扰动使 TACC 平均下跌 21.73% 时任务进度（TP）仅降 1.23%，即智能体在信息已不可靠的情况下仍"默默继续推进"；且越晚注入扰动退化越大（R3 从 30.6% 升至 37.8%），超出发生轮次的失败中仅 17.1% 能自我恢复、82.9% 一直持续到最后一轮。

> **TL;DR:** SciARP is a benchmark for trajectory-level robustness of LLM scientific agents: 620 problems from GPQA/SciBench/OlympiadBench/BixBench are rewritten into interdependent 3–13-turn tasks, and 13 scientifically plausible perturbation types (invalid premises, corrupted data, cross-step inconsistencies, authority pressure, etc.) are injected live mid-interaction. On 8 frontier models (Gemini 3.1 Pro/3.7 Flash, DeepSeek-V4 Pro/Flash, GPT-5.6/5.5, Claude Opus 5/Sonnet 5), reasoning-stage perturbations cause an average TACC drop of 50.69 pts (worst single type R2: 96.15% → 29.45%, −66.70 pts), while data-corruption perturbations (E3) cut TACC by 21.73 pts on average yet barely affect task progression (TP, −1.23) — agents keep "solving" with wrong evidence. Critically, higher clean accuracy does not imply robustness (GPT-5.6 beats GPT-5.5 on clean TACC 96.41% vs 94.82% under E1 but degrades more, 31.06 vs 21.29 pts), failures surface turns after injection, and only 17.1% of propagated failures ever self-correct.

## 核心贡献

- **SciARP 基准**：将 4 个成熟科学基准（GPQA、SciBench、OlympiadBench、BixBench v1.5）中 620 道经核验的题目（生物/化学/数学/物理）重构为 3–13 轮、轮间显式依赖的多轮科学推理任务，并配套"清洁-扰动"配对任务对。
- **13 类科学扰动分类体系**：按问题解决的四个阶段组织——问题理解（U1 术语变体、U2 量纲/单位、U3 变量/符号、U4 条件省略）、证据处理（E1 无效前提、E2 引用/归属错误、E3 数据/统计证据不可靠、E4 多源证据冲突）、推理（R1 跨步不一致、R2 相关-因果混淆、R3 推理路径误导）、结论形成（C1 不确定性压制、C2 权威/立场施压）；扰动经 LLM + 人工双重校验，保证科学合理性与目标性修改。
- **配对活执行（paired live execution）评测协议**：清洁版与扰动版任务由同一智能体在相同设置下独立执行，扰动在多轮交互中实时注入（而非改写或回放预先采集的轨迹），使失败的出现、潜伏、传播与恢复成为可观测对象；提出 TACC（端到端任务成功）+ IC/TP/RV（信息正确性/任务推进/推理有效性）双层指标。
- **三项关键实证发现**（8 模型 × 4 家族）：① 不同阶段的扰动呈现截然不同的失败模式——推理类扰动对任务成功破坏最大（平均 ΔTACC 50.69），证据类扰动造成"静默失败"（ΔTACC 21.73 而 ΔTP 仅 1.23）；② 清洁任务能力与鲁棒性脱钩，更强模型退化反而更大；③ 失败有强时间动态：潜伏数轮后才显现、沿下游依赖传播、且极少自我恢复（仅 17.1%）。

## Key Contributions

- **SciARP benchmark**: 620 verified problems from four established scientific benchmarks (GPQA, SciBench, OlympiadBench, BixBench v1.5) spanning biology, chemistry, mathematics, and physics are transformed by an LLM Task Planner into interdependent multi-turn tasks of 3–13 turns with cross-turn dependencies, each with a matched clean/perturbed pair and dual (LLM + human) validation for solution consistency, stage appropriateness, and absence of reference leakage.
- **A 13-type scientifically grounded perturbation taxonomy** organized by problem-solving stage — Problem Understanding (terminology variation, dimension/unit, variable/symbol, condition omission), Evidence Processing (invalid premise, citation/attribution, data & statistical evidence, multi-source conflict), Reasoning (cross-step inconsistency, correlation–causation confusion, reasoning-path misdirection), Conclusion Formation (uncertainty suppression, authority & stance pressure) — with every instantiation validated for scientific plausibility, targeted modification, and task consistency.
- **A paired live-execution evaluation protocol**: clean and perturbed versions of each task are independently executed by the same agent under matched settings, with perturbations injected mid-trajectory so that downstream responses evolve from the corrupted context; metrics span end-to-end Task Accuracy (TACC) plus turn-level Information Correctness (IC), Task Progression (TP), and Reasoning Validity (RV), with degradation Δ = Clean − Perturbed.
- **Three empirical robustness findings across 8 frontier LLMs**: (1) stage-associated perturbation classes exhibit distinct failure profiles, with reasoning perturbations most destructive to task success and evidence perturbations producing silent failures; (2) clean-task capability does not predict robustness — stronger models can degrade more; (3) failures are temporally latent, propagate through downstream dependencies, and rarely recover (17.1%).

## Methodology

**Task construction.** From GPQA, SciBench, OlympiadBench, and BixBench v1.5, the authors retain 620 problems satisfying three criteria: a verified reference solution exists, correctness is independently checkable, and solving requires non-trivial multi-step reasoning. An LLM-based Task Planner first builds a complete solution plan consistent with the reference solution, then decomposes it into logically connected subtasks (3–13 interaction turns) that follow the scientific reasoning structure rather than mechanical text partitioning; steps depending on earlier outputs are placed in later turns, so the agent must retain and correctly reuse information across turns. Each turn is labeled with a primary stage in {U, E, R, C}. Every constructed task passes dual validation (LLM-based plus human reviewers) on consistency with the original problem and reference solution, scientific correctness, reasoning completeness, validity of cross-turn dependencies, and absence of reference-solution leakage.

**Perturbation instantiation.** For each task–perturbation-type pair, an LLM Perturbation Generator identifies valid injection points using two criteria — *element availability* (the targeted scientific element must be present) and *dependency validity* (introduced before conclusion formation, with downstream reuse of the affected information) — then modifies only the designated information while preserving the original scientific objective. Each instance is again dual-validated (LLM + human) for perturbation-type conformity, plausibility, targeted modification, task consistency, and dependency validity. Injection position (early/middle/late) and frequency (n = 1..3, for repeatable types only) are varied in dedicated analyses; instances are fixed before live execution and are independent of the evaluated model's identity.

**Paired execution and metrics.** For each clean/perturbed pair, the same agent pipeline executes both versions under identical settings (fixed system prompt, tools, temperature 0; every condition repeated 3 times with fresh live runs; means reported). Four metrics: TACC (fraction of tasks whose final answer matches ground truth AND whose solution process is scientifically valid), and — evaluated from the first perturbed turn onward, per-turn, then averaged — IC (task-relevant information used is correct), TP (each turn advances the task), and RV (intermediate result is correct and supported by valid reasoning).

**Evaluation quality control.** A dual-evaluation protocol combines a fixed LLM evaluator (Claude Opus 5 across all experiments, blind to model identity and condition) with two human annotators (each with ≥5 years of scientific research experience), whose judgments are cross-checked for consistency; a criterion counts as satisfied only when LLM and human agree, and disagreements are conservatively treated as incorrect.

**Models.** Eight LLMs from four families: Gemini 3.1 Pro / Gemini 3.7 Flash, DeepSeek-V4-Pro / DeepSeek-V4-Flash, GPT-5.6 / GPT-5.5, Claude Opus 5 / Claude Sonnet 5, all in the same custom scientific-agent pipeline.

## Results & Highlights

- **Reasoning-stage perturbations are the most destructive to task success.** Averaged over R1–R3 and all 8 models (Table 2), reasoning perturbations cause ΔTACC = 50.69% and ΔTP = 22.81%, versus ΔTACC = 21.73% with ΔTP = only 1.23% for evidence-stage (E1–E4) perturbations and ΔTACC = 4.43% for problem-understanding (U) perturbations. The single worst type is R2 (correlation–causation confusion): average TACC collapses from 96.15% clean to 29.45% perturbed (Δ = 66.70 pts, Table 14), followed by C2 (authority/stance pressure): 89.13% → 35.78% (Δ = 53.35) and R1 (cross-step inconsistency): 89.06% → 37.67% (Δ = 51.39).
- **Silent-failure decoupling: agents keep progressing on corrupted evidence.** Under E3 (data and statistical evidence perturbation), every one of the 8 models shows ΔTACC between 34.43% and 52.66% while TP degradation stays within 0.85%–3.82% (Table 11; average TACC 93.93% → 49.47%, Δ = 44.46, but TP 99.48% → 97.34%). Overall, evidence perturbations cut TACC by 21.73 pts yet TP by only 1.23 — a workload-continues-but-reliability-dies pattern that final-answer-only benchmarks cannot see.
- **Capability ≠ robustness.** Under E1 (invalid premise), GPT-5.6 has higher clean TACC than GPT-5.5 (96.41% vs 94.82%) but suffers larger degradation (31.06 vs 21.29 pts; Table 9). The paper further reports GPT-5.6 degrading more than Claude Opus 5 (31.06% vs 16.91%) despite comparable-or-better clean accuracy — stronger clean-task performance can coexist with larger perturbation-induced collapse.
- **Failures are latent, propagate, and resist recovery.** 74% of E2 and 58% of E3 failures emerge only after at least two subsequent turns (versus immediate manifestation for U1/R1/R2 in 94%/82%/84% of cases); among perturbation effects extending beyond their onset turn, only 17.1% recover while 82.9% persist to the final turn. First-affected dimension differs by type: IC is hit first for U4/E1/E3 (80%/76%/82%), while R2 first breaks RV (62%), R3 first breaks TP (66%), and C1 first breaks RV (84%).
- **Later and repeated injections hurt more.** Moving the injection from early to late positions raises average ΔTACC from 3.4% to 9.6% for U1, 3.7% to 10.9% for U2, and 30.6% to 37.8% for R3. Raising perturbation frequency n = 1 → 3 increases average ΔTACC from 59.20% to 76.20% for R1 and 44.78% to 72.47% for R3; R2 is already severe at a single occurrence (57.71%) and reaches 90.09% at n = 3.

## Authors & Credibility

The author group spans Xi'an Jiaotong University (China), Inria (France), A*STAR (Singapore), and the Zhejiang Key Laboratory of AIoT Network and Data Security — a mix of academic ML labs and a applied-research institute. The paper follows strong research-integrity practices: an explicit AI Use Statement (LLMs used for task/perturbation construction and assisted evaluation, with all generated content human-reviewed; no AI in formulating the research question or generating reported numbers), an Ethics Statement, and a Reproducibility Statement. The dual evaluation protocol (fixed LLM judge plus two independent annotators with ≥5 years of research experience, conservative disagreement handling) and triple repeated live runs per condition indicate unusually careful quality control for a benchmark paper. No prior robustness-benchmark work by the same team is cited, so this appears to be the group's entry into the scientific-agent evaluation space.

## Critical Assessment

- **Genuine novelty, well-positioned gap.** The paper's Table 1 comparison is accurate: GSM-Symbolic/MATH-Perturb treat perturbations as single-input modifications, AgentDojo/AgentHarm target adversarial attacks, and Newton-Bench uses observational noise — none does live, mid-trajectory, scientifically plausible perturbations with paired execution and turn-level reliability metrics. The paired live-execution design (rather than replaying pre-collected traces) is the technically meaningful contribution here, because it is what makes propagation and recovery measurable.
- **LLM-in-the-loop construction is a real circularity risk.** Both the Task Planner and the Perturbation Generator are LLMs, and perturbation instances are primarily LLM-validated before human review; the paper does not report how many candidate tasks/instances were generated, what fraction survived human validation, or inter-annotator agreement rates — so construction yield and residual noise are unverifiable from the paper. The hardness profile (e.g., near-ceiling clean TACC ~89–96% average) does suggest the multi-turn transformations did not accidentally make tasks trivial.
- **The judge is one of the defendants.** Claude Opus 5 is simultaneously the fixed LLM evaluator for all models and one of the eight evaluated agents. Human cross-checks and conservative tie-breaking mitigate this, but no judge-agreement statistics with humans are broken out per metric, and the "disagreement ⇒ incorrect" rule silently deflates all reported numbers in an unquantified way.
- **Internal number inconsistencies.** The main text states "GPT-5.6 has higher clean TACC than Claude Opus 5 (90.07% vs 89.07%)" under E1, yet Appendix Table 9 reports GPT-5.6 clean TACC of 96.41% — the comparison presumably uses a different subset, but the paper never explains the discrepancy. Similarly, the frequency-analysis numbers (e.g., R2 at n=1 as 57.71%) do not match the main Table 14 average (66.70%), again without stated reconciliation.
- **Diagnosis without intervention.** No mitigation is tested — no self-verification prompting, uncertainty escalation, re-derivation of earlier results, or consistency checking. The 17.1% recovery figure is the paper's most actionable finding, yet the benchmark is used purely diagnostically, leaving open whether any cheap defense closes even part of the gap.
- **Narrow model coverage and per-cell opacity.** All eight models are frontier proprietary systems; small open-weights models (the ones most often deployed as agents) are absent, and per-model-per-perturbation task counts (after applicability filtering) are not disclosed, so per-cell confidence intervals cannot be assessed. Three repetitions at temperature 0 probe serving stochasticity but no significance tests are reported.

## Strengths

- Fills a real evaluation gap: trajectory-level robustness of scientific agents under non-adversarial, scientifically plausible perturbations, with failures traced over time (onset → propagation → recovery) rather than scored only at the final answer.
- The paired live-execution protocol is clean and rigorous: identical agent, settings, and repetition counts on both sides of each pair; perturbations fixed before execution and independent of the evaluated model.
- The two-level metric set (TACC + IC/TP/RV) is well designed — it is exactly the IC/TP decoupling that exposes the "silent failure" phenomenon that end-to-end accuracy alone would hide.
- Unusually strong quality control: dual LLM + human validation at both task-construction and perturbation-instantiation stages, two independent human annotators for evaluation, conservative disagreement handling, and explicit AI-use disclosure.
- Rich analysis axes: per-stage and per-type degradation (13 types × 8 models × 4 metrics), perturbation position (early/middle/late), and perturbation frequency (n = 1..3), all with full per-model tables in appendices.
- Findings are concrete and decision-relevant: capability–robustness decoupling and the 17.1% recovery rate directly challenge the "bigger model = safer agent" assumption.

## Limitations

- Perturbations are single-type per task in the main evaluation (n=1), capped at n=3 in the frequency analysis; real long-horizon scientific sessions accumulate heterogeneous corruptions simultaneously, which is untested.
- No open-weights or sub-frontier models are evaluated, limiting conclusions about the model scale regime where most agentic deployments actually run.
- No mitigation baseline (self-checking, consistency verification, re-derivation) is evaluated, so the benchmark quantifies the disease but not any cure.
- Construction and validation are heavily LLM-driven; generation counts, human-validation pass rates, and inter-annotator agreement are not reported, making benchmark-construction noise unquantifiable.
- The fixed evaluator (Claude Opus 5) is itself among the evaluated models; per-metric human–judge agreement statistics are not broken out.
- Some quantitative inconsistencies exist between main-text quotes and appendix tables (e.g., E1 clean-TACC comparisons; frequency-analysis averages vs. Table 14), which are not reconciled in the paper.
- All 620 source problems come from four static Q&A-style science benchmarks; tasks involve scripted subtask interaction within a custom pipeline rather than open-ended tool use (no literature retrieval, code execution environments, or wet-lab actions), so "scientific agent" here means structured multi-step scientific problem solving, not autonomous experimentation.

## Relevance

这篇论文与用户最高优先级的"自进化智能体与自动化科研（Self-Evolving Agents & Automated Research）"方向直接相关——它量化的正是长程自主科研智能体在信息被污染后"静默失败、持续传播、几乎无法自愈"的可靠性问题（82.9% 的传播性失败持续到终点，仅 17.1% 自我恢复），这是任何 AI-scientist 系统走向可信部署前必须面对的短板。其"潜伏数轮才显现"的失败时间动态也与用户关注的推理期静默数据损坏（SDC）检测思路形成有趣对照，尽管这里的损坏源自模型侧而非硬件侧。

## Questions for Further Exploration

- Can cheap defenses — forced re-verification of reused earlier results, explicit consistency checking against prior turns, or calibrated uncertainty escalation — shrink the 82.9% persistence rate, and at what token/latency cost?
- Why does higher clean-task capability correlate with larger perturbation-induced degradation (GPT-5.6 vs GPT-5.5 under E1)? Is it stronger instruction-following on the corrupted premise, or overconfidence in fluent-but-wrong continuations?
- Do the failure dynamics (latent onset, propagation, 17.1% recovery) transfer from frontier models to small open-weights agents, or are they a frontier-scale pathology?
- How does robustness change when heterogeneous perturbations (e.g., E3 data corruption + R1 cross-step inconsistency) co-occur, as they would in real research sessions?
- Would perturbations grounded in tool outputs (a corrupted database row, a miscalibrated instrument reading) reproduce the same failure profile as perturbations injected into user turns, given the current benchmark injects only into task information?
- Can the IC/TP decoupling ("silent failure") be detected online from the agent's own trajectory statistics (e.g., sudden TP-with-flat-IC signatures), turning the benchmark's diagnostic into a runtime monitor?
