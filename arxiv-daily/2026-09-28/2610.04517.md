> **一句话总结：** EvoCast 把"预测模型架构进化"做成一个固定协议的自主科研闭环：LLM 智能体只负责提假设和写代码，而确定性的"程序权威"（契约校验、沙箱执行、因果校验、晋升门控）把守评估与模型晋升——在 30 个 code-to-code 任务上实现 96.7% 实现成功率（对比 mini-SWE-agent 90.0%、R&D-Agent 46.7%），单任务成本 $0.0157/132s（约为 mini-SWE-agent 的 1/4），并在 3 个真实预测任务上将所选基线 MSE 最多降低 12.2%（Melbourne T33：0.1628 vs 0.1854）。

> **TL;DR:** EvoCast is a fully autonomous research agent for iterative time-series forecasting architecture evolution built on "cognition-authority separation": LLM agents generate hypotheses and code, while deterministic program authorities (contract validation, sandbox execution, causal validation, promotion gate) control source-edit boundaries, canonical evaluation, and model promotion. On a self-built 30-task code-to-code benchmark (10 backbones × 3 complexity levels) it reaches 96.7% (29/30) implementation success vs 90.0% for mini-SWE-agent and 83.3% for AIDE, at $0.0157/132s per task vs $0.0636/573s for mini-SWE-agent (~4x cheaper). On three real forecasting cases (Air Quality/MM, Melbourne Pedestrian T33/SS, Steel Industry/MS) it improves its selected baselines (FreTS/PatchMLP) by reported relative MSE reductions of 2.9%/12.2%/8.9%, beating Sundial, Toto-2.0-2.5B, Time-VLM, TimeCMA, AIDE, and R&D-Agent on MSE in all three cases. System ablations show removing authority-controlled execution inflates cost ~17x ($7.88 vs $0.77) and worsens final MSE from 0.1626 to 0.1853.

## 核心贡献

- **固定协议科研闭环**：将任务协议 P = (数据集, 预测目标, 回看窗口, 预测步长, 模式, 预算) 在整个自主运行期间冻结，所有轮次（基线选择、机制消融、候选评估、晋升）在同一评估面上比较，使架构进化可审计、可复现。
- **认知-权限分离（cognition-authority separation）**：4 个认知角色（诊断智能体、规划智能体、代码构建智能体、报告叙事智能体）负责开放式假设生成与源码实现；4 个程序权威（契约校验、沙箱执行、因果校验、晋升门控与状态更新）确定性地控制源码编辑边界、规范评估与模型晋升，边界外的一切修改不可见、不可提交。
- **诚实的四态轮次结果**：每轮输出 accepted / rejected / unstable / failed——晋升要求边界校验通过 + 规范指标有效 + 固定多种子晋升规则胜过现任模型；单次运行变好但种子不稳的"unstable"不晋升；失败的轮次保留现任模型并记录失败证据，负结果（valid negatives）进入证据束供后续规划使用。
- **证据束（evidence bundle）驱动的迭代规划**：研究状态 S_r = (现任模型, 证据束, 轮次历史) 携带数据集刻画、基线机制消融结果（Δ(a) = m(a;P) − m(b*;P)）、已接受改进、有效负结果、不稳定增益、修复记录与失败记忆，让下一轮方向生成基于已执行证据而非凭空想象。
- **三组实验（RQ1 实现可靠性 / RQ2 端到端研究效用 / RQ3 系统消融）**：证明 EvoCast 在实现成功率、token/时间成本、最终预测精度与轮次有效率上同时占优，且每个认知/权威组件都对结果有可测贡献。

## Key Contributions

- **Formulates autonomous forecasting architecture development as a fixed-protocol research loop**: a frozen task protocol defines one stable comparison surface across baseline selection, mechanism-diagnosis ablations, candidate evaluation, and promotion over an entire autonomous run.
- **Cognition-authority separation**: cognitive agents (diagnostician, planner, code builder, report narrator) do open-ended hypothesis generation and source implementation; deterministic program authorities (contract validation, sandbox execution, causal validation, promotion gate + state update) enforce source-edit boundaries, canonical evaluation, and promotion decisions — no accepted result can bypass the multi-seed promotion rule.
- **Honest four-outcome round taxonomy** (accepted / rejected / unstable / failed): unstable single-run gains are not promoted without seed stability; failed rounds preserve the incumbent; valid negatives and failure records accumulate in an evidence-carrying research state that grounds subsequent planning.
- **Evidence-grounded planning from executed mechanism ablations**: the baseline is diagnosed by removing candidate mechanisms under the same protocol (Δ(a) = m(a;P) − m(b*;P)), and the planner derives research directions from dataset characteristics, diagnostic results, prior rounds, and failure memory rather than free-form LLM speculation.
- **Three-question evaluation with full resource ledgers** (valid-round ratio, calls, tokens, API cost, wall-clock): EvoCast delivers the highest implementation success (96.7%), the lowest per-task cost among agent baselines, and the best final MSE on all three real forecasting tasks.

## Methodology

**Task setting.** For one forecasting task the protocol P = (D, y, L, H, mode m, B) is frozen for the whole run: dataset D, prediction target y, lookback length L, horizon H, forecasting mode (MM multi-variate→multi-variate / SS single→single / MS multi→single), and research budget B. The run maintains a research state S_r = (M_r, E_r, H_r): incumbent model, evidence bundle, and round history.

**Five-stage loop.** (1) *Task grounding*: the Characteristics Extractor reads the dataset/target/metric and writes executed characterization features into the evidence bundle. (2) *Baseline establishment*: the single formal anchor b* = argmin over declared baselines B_decl of m(b;P) (error direction; FreTS for Air Quality, PatchMLP for Melbourne T33 and Steel Industry) — reused by all later comparisons, ablations, and promotion checks. (3) *Baseline diagnosis*: the diagnostician extracts the mechanism set A(b*) of the active prediction path, runs ablations under the same protocol (Δ(a) = m(a;P) − m(b*;P)), and classifies each mechanism as preserve / redundant-or-target / unresolved. (4) *Formal iterative research*: each round, the planner Π(·, S_r) generates one research direction d_r specifying mechanism, insertion point, stable hypothesis, expected information-flow change, failure modes to avoid, and expected knowledge gain; the code builder compiles d_r into a bounded implementation (editable model-side source region only — dataset, evaluator, metric computation, training budget, and promotion logic stay frozen). (5) *Validated output*: candidate c_r = β(d_r; P, M_r) passes authority-controlled source-boundary validation, canonical training/evaluation, metric comparison, and promotion adjudication; o_r = Γ(P, S_r, c_r) ∈ {accepted, rejected, unstable, failed}. Promotion happens only if boundary validation passes, canonical metrics are valid, and the fixed multi-seed comparison rule beats the incumbent; otherwise the incumbent is preserved and the outcome is written to the evidence bundle. After the budget (20 formal rounds, ≤3 repair attempts per round) is exhausted, the Report Narrative Agent emits an auditable HTML report with the validated current-best model, source, configuration, resource usage, and narrative.

**Evaluation setup.** All cognitive-agent calls use MiniMax-M3 as the shared foundation model ($0.30/M input, $0.06/M output tokens). Experiments run on Ubuntu 22.04, Python 3.12.7, PyTorch 2.7.1, CUDA 12.8, one NVIDIA RTX 3080 Ti (12 GB). RQ1: a code-to-code benchmark of 30 tasks from 10 forecasting backbones at 3 complexity levels (local modification, cross-module integration, novel module insertion). RQ2: three real cases — Air Quality (MM, FreTS, 168→24), Melbourne Pedestrian T33 (SS, PatchMLP, 168→24), Steel Industry (MS, PatchMLP, 720→120) — with chronological 7:1:2 splits, rolling windows of stride 1, normalized-space MSE/MAE, and compared against Sundial, Toto-2.0-2.5B, Time-VLM, TimeCMA, AIDE, and R&D-Agent. RQ3: system ablations A1–A5 (remove dataset characterization / baseline diagnosis / evidence-grounded planning / authority-controlled execution / iterative evidence update) on Melbourne T33, final MSE = 3-seed mean (seeds 2026–2028).

## Results & Highlights

- **RQ1 implementation reliability (30-task code-to-code benchmark):** EvoCast achieves 96.7% (29/30) success with 100.0% fidelity and a 95.7% (22/23) repair rate, vs mini-SWE-agent at 90.0% (27/30) success / 92.6% fidelity, AIDE at 83.3% (25/30), AutoResearch at 86.7%, and R&D-Agent at 46.7% (14/30). Per task EvoCast averages 27,618 tokens, $0.0157, and 132s — versus mini-SWE-agent's 187,313 tokens / $0.0636 / 573s (≈6.8x fewer tokens, ≈4.1x cheaper, ≈4.3x faster) — while direct independent editing is cheapest ($0.0037) but succeeds only 33.3% of the time.
- **RQ2 forecasting accuracy (Air Quality, MM):** EvoCast reaches MSE 0.1570 — the lowest of all methods — a reported −2.9% relative MSE reduction over its own selected FreTS baseline (~0.162), and far ahead of Sundial (0.3481), TimeCMA (0.5134), AIDE (0.5309), and R&D-Agent (0.5897). However its MAE (0.1909) is reported as +1.9% *worse* than the selected baseline — the one metric where the baseline wins.
- **RQ2 forecasting accuracy (Melbourne Pedestrian T33, SS):** EvoCast MSE 0.1628 vs its selected PatchMLP baseline 0.1854 (reported −12.2% relative reduction), also beating AIDE (0.1728), Sundial (0.1814), R&D-Agent (0.1833), and TimeCMA (1.2620). On MAE, AIDE's 0.2070 is the best and EvoCast is second at 0.2320 — EvoCast has the lowest MAE on only two of the three tasks.
- **RQ2 forecasting accuracy (Steel Industry, MS):** EvoCast MSE 0.2792 (MAE 0.3388), a reported −8.9% MSE / −9.2% MAE reduction over its PatchMLP baseline (~0.306/0.373), vs AIDE 0.4112, TimeCMA 0.4497, Sundial 0.4413, and R&D-Agent 0.7244 — all general-purpose forecasters and agent systems trail the task-specific baseline by large margins on this task.
- **RQ2 resource ledger (20 formal rounds per case):** EvoCast attains valid-round ratios of 100% (20/20) on Air Quality, 90% (18/20) on Melbourne T33 and Steel Industry, vs AIDE's 60%/65%/80% and R&D-Agent's 65%/75%/30%. On Air Quality EvoCast uses 96 calls / 1,210,702 tokens / $0.6089 vs R&D-Agent's 256 calls / 7,301,193 tokens / $3.7618 (~6x tokens, ~6.2x cost); on Steel, R&D-Agent spends $3.8685 for only 30% valid rounds while EvoCast spends $0.8073.
- **RQ3 system ablations (Melbourne T33, PatchMLP, 3-seed mean MSE):** the full loop reaches 0.162579 with 18/20 valid rounds, 4.62h, 1.49M tokens, $0.7708. Removing authority-controlled execution (A4) is the most damaging: final MSE 0.185301, only 14/20 valid rounds, 10.80h, 25.32M tokens, $7.8792 — ≈17x the tokens and ≈10x the cost of the full loop. Removing baseline diagnosis (A2) → 0.173473; removing iterative evidence update (A5) → 0.178489; removing evidence-grounded planning (A3) → 0.173250 (though A3 attains the highest valid-round ratio, 20/20); removing dataset characterization (A1) → 0.173347.
- **Qualitative RQ2 finding:** on Air Quality, EvoCast keeps and refines the live path of the selected FreTS backbone, while AIDE converges to a linear Ridge feature-engineering solution and R&D-Agent to a GRU/LSTM ensemble under the same formal-round cap — the fixed workflow produces different, more task-faithful artifacts than free-form agent exploration.

## Authors & Credibility

The paper comes from an academic collaboration between the School of Automation and Intelligent Science at Jiangnan University (Kaipeng Xu, Xianli Yan, corresponding author Yan Wang) and the School of Automation at Southeastern University (Xiang Liu, Shan Liu) — automation/control groups whose home turf is time-series modeling and industrial forecasting (the Steel Industry case is an energy-consumption task of the kind these groups typically work on). The related-work coverage is current and broad (AutoML/NAS for forecasting, LLM time-series agents like TimeSeriesScientist/GenAutoML/SEA-TS, and autonomous research agents like AIDE, R&D-Agent, mini-SWE-agent, AutoResearch, MLG-MSTAR, AIRA), and the code is publicly released at github.com/1860-x/EvoCast with prompts and the evaluation protocol documented in appendices. This is not a large agent-systems lab, and the evaluation infrastructure (self-built benchmark, own canonical evaluator) is group-internal; credibility rests on the released code and the unusually complete resource accounting rather than on external benchmark reputation.

## Critical Assessment

- **The headline "outperforms" claim rests on only three real-world tasks**, all time-series forecasting, with a single frozen protocol each. The Melbourne win is solid (−12.2% MSE), but the Air Quality margin over its own baseline is thin (−2.9% MSE) and its MAE actually regresses (+1.9% vs the selected baseline); a fourth or fifth task could easily flip the narrative. The 30-task RQ1 benchmark is self-constructed from 10 backbones the authors control — there is no community-standard external benchmark (e.g., an MLE-bench-style suite) to anchor the reliability numbers.
- **Metrics are partially self-referential.** "Success" and "valid rounds" are defined by EvoCast's own canonical validation pipeline — the same infrastructure EvoCast is architected around. The same yardstick is applied to all baselines, which is fair in principle, but a system whose promotion gate defines what counts as valid evidence will naturally excel on that definition; a baseline agent's output that fails EvoCast's contract validation is counted as failure even if it is scientifically reasonable.
- **No foundation-model ablation.** Every cognitive call uses MiniMax-M3. The paper's central claim — that cognition-authority separation makes agent research reliable — is never tested with a weaker or stronger LLM backbone, so the split between "the design works" and "MiniMax-M3 is good at code editing" cannot be assessed. Reproducibility also hinges on a third-party API whose behavior will drift.
- **A suspicious table detail:** the AutoResearch row in Table 1 prints success "86.7% (28/30)", but 28/30 = 93.3% — either a typo or an inconsistency in the paper's own numbers, worth checking against the released code/logs. Similarly, Table 3's absolute baseline values must be back-computed from the printed relative deltas because the parenthetical reductions do not match the printed baseline row as laid out.
- **The A3 ablation complicates the planning story:** removing evidence-grounded planning yields the *highest* valid-round ratio (20/20) at lower cost, with final MSE only ~6.5% worse than the full loop. Planning evidence improves final quality, but the paper does not examine why grounded planning *reduces* execution reliability — the mechanism behind its flagship design is left unexplained.
- **No efficiency accounting of evolved architectures.** Figure 4 shows each final architecture gained multiple new modules (cross-channel trend encoding, calendar-conditioned retrieval, dual-path projection...), but the paper reports no parameter count, FLOPs, or inference latency vs the baseline — accuracy-only comparisons can hide substantial capacity/compute increases that a bigger baseline would also enjoy.
- **Novelty is integrative rather than conceptual.** Executed ablations for high-level research decisions (MLG-MSTAR), consistent evaluation infrastructure (AIRA), and bounded code-edit regions (prior guarded-agent work) all exist; EvoCast's contribution is packaging them into one auditable loop for forecasting plus the evidence-bundle state design. That is a real engineering contribution, honestly evaluated, but the components are not new in isolation.

## Strengths

- The **cognition-authority separation is the right trust architecture** for autonomous research: deterministic gates on source boundaries, evaluation, and promotion directly address the protocol-contamination failure mode that plagues open-ended research agents, and the four-outcome taxonomy (including *unstable*, reserved for seed-unstable gains) is an unusually honest treatment of run-to-run variance.
- **Failed and negative rounds are first-class evidence**: rejected candidates, unstable gains, repair records, and failure memory all feed the next planning round — the system learns from what did not work instead of hiding it.
- **Rare cost transparency**: every table reports calls, tokens, API cost, and wall-clock alongside quality, so the reliability gains can be weighed against their price; EvoCast wins on both axes against most baselines.
- **Mechanism-level baseline diagnosis** grounds hypothesis generation in executed ablations (Δ(a)) rather than LLM guesses, and the ablation outcomes (preserve / redundant / unresolved) give the planner concrete risks to avoid.
- **Complete method detail and release**: protocol formalism, authority chain, prompts (Appendix B), budget accounting (Appendix C), and code on GitHub make the system unusually reconstructable for an agent paper.

## Limitations

- **Scope is a single domain**: everything is forecasting-architecture evolution; transfer of the cognition-authority loop to other scientific or ML-engineering domains is asserted by analogy, not shown.
- **Three real tasks and one LLM backbone** support the end-to-end utility claim; no seed variance is reported for the RQ2 headline tables (multi-seed means appear only in the RQ3 ablation), so the Melbourne/Steel margins carry unknown error bars.
- **20-round budget cap with ≤3 repairs per round** — long-horizon behavior (does the evidence bundle keep helping at round 50?) is unexplored; the RQ3 trajectory plot already shows all ablation chains plateauing early.
- **Evolved architectures are not compared on efficiency**, only accuracy; and the RQ1 fidelity/success criteria encode the authors' own notion of "realizing the idea without semantic mismatch".
- **API dependence** (MiniMax-M3 pricing and behavior) makes the reported dollar costs and success rates time-sensitive.

## Relevance

这篇论文正中你排名第一的兴趣方向（Self-Evolving Agents & Automated Research）：它就是一个带可靠性工程的自主科研闭环，其"认知-权限分离 + 四态轮次结果 + 证据束"正是你关注的长时自主智能体可信性与可审计性问题的具体设计。同时它对预测架构的自动进化实验也顺手给出了"LLM 智能体做科研时确定性门控到底值多少钱"的量化答案（去掉权限控制成本 ×17），对研究智能体系统可靠性很有参考价值。

## Questions for Further Exploration

- Does the cognition-authority separation transfer beyond forecasting — e.g., to ML engineering on tabular/vision tasks or algorithm discovery — where the "editable model-side source region" is harder to delineate?
- How does the loop behave with a weaker or stronger foundation model? Is there a minimum cognitive capability below which the authority gates merely reject everything?
- A3 (no evidence-grounded planning) achieved the best valid-round ratio (20/20) — what exactly causes grounded planning to reduce execution reliability, and is there a Pareto frontier between planning depth and round validity?
- Which components of the evidence bundle (valid negatives vs unstable gains vs failure memory) drive the RQ3 differences? The paper removes them jointly; a finer-grained evidence ablation is missing.
- Do the evolved module insertions (Figure 4) survive out-of-distribution tests, longer horizons, or parameter/FLOPs-matched baselines — i.e., how much of the gain is added capacity rather than mechanism?
