arXiv / 2610.02975 CISE — Conformal Interval-Driven Self-Evolution 2026-09-28

Key finding

Conformal reward intervals push false positives in LLM self-evolving search to zero: all 98 returned candidates passed DFT validation.

PAPERReliable Self-Evolution with Imperfect Proxy Rewards

Kangjun Noh · Soyu Kim · Kyungwoo Song Yonsei University, MLAI Lab 2026-09-28

Key metric

100%

precision on the LLEMA benchmark — 0 false positives among 41 (WBG) + 51 (SSE) + 6 (PV) returned candidates, every one DFT-confirmed.

Strongest baseline (LLEMA): 92.2 / 68.3 / 65.0% — up to 35% of its outputs fail DFT validation.

Why it matters

Cheap proxy rewards contaminate self-evolving LLM loops through feedback; CISE’s calibrated reward intervals are a statistically guaranteed, auditable brake.

Critical edge

Interval coverage is never empirically measured; “ground truth” is DFT agreeing with DFT — and the covariate-shift assumption can fail silently under extrapolative drift.

Also: one competitive baseline only (CISE is LLEMA with two modules swapped), and PV yield collapses to 3% of generated candidates.

01

Method

Point-valued proxy reward in → candidate-specific calibrated interval out; the loop itself stays untouched.

A self-evolving agent scores candidates with a cheap proxy reward (a learned property predictor) instead of expensive DFT, stores them in an archive, and feeds them back as prompt context. CISE leaves the generator fixed and changes only archive administration and output selection on top of LLEMA.

Offline, it fits a conditional 0.95-quantile model of absolute proxy error on 423,205 labeled structures (JARVIS-QETB; 27 structural features, gradient boosting) and calibrates on 10,000 composition-disjoint pairs. During evolution, conditional conformal inference (Gibbs & Candès 2025) turns each proxy prediction into a bounded, candidate-specific interval centered at that prediction.

Parent selection then scores stored candidates worst-case over their intervals, and a candidate is returned only if its entire interval satisfies every task constraint; an empty interval means abstention. Because evolution shifts the candidate distribution, each iteration fits a density ratio on an 8-candidate unlabeled probe batch (least-squares importance fitting) and adds it to the calibration space, so coverage adapts to the drift the search itself creates.

HOST = LLEMA · solver = gpt-5-mini · band-gap proxy = MGT (swapped for CGCNN) · ground truth = DFT, Quantum ESPRESSO (PBEsol) · α = 0.05 per property · 200 candidates per method

  1. STEP A

    Offline calibration

    Quantile model of |proxy error| on 423k true-reward pairs; 10k held-out pairs form the conformal calibration set (composition-group split).

  2. STEP B

    Conformal intervals

    CCI over a finite-dim function space yields a bounded, candidate-specific interval centered at the proxy prediction. Empty interval ⇒ abstain.

  3. STEP C

    Conservative use

    Feedback scores parents worst-case over the interval; output requires the whole interval to clear every constraint — lower bounds via the lower endpoint, upper via the upper.

  4. STEP D

    Online drift correction

    An 8-probe unlabeled batch per iteration feeds least-squares importance fitting; the ratio ût joins the calibration space (Gt = G + span(ût)).

The guarantee, as scoped

  • THEOREM 1 · EXCHANGEABILITYPer-iteration marginal coverage ≥ 1 − α.
  • THEOREM 2 · COVARIATE SHIFTCoverage ≥ 1 − α − εt, where εt is the total-variation distance induced by density-ratio estimation error.
  • JOINT BOUNDP(accepted ∧ false positive) ≤ α + εt, with α = 0.05 per property.

Honest scoping: marginal and per-iteration only — no trajectory-level or acceptance-conditional bound, and εt is never measured empirically.

Equal-budget test — “you just return fewer”, answered

CISE full-interval rule, 6-candidate DFT budget 6 TP / 0 FP
LLEMA proxy point-estimate top-6 (closest to 1.2 eV) 3 TP / 3 FP

Point estimates can be badly wrong: SrO₂ proxy 1.24 eV vs DFT 2.99 eV; CaO 1.75 vs 3.06 eV. CISE’s accepted intervals bracket truth: RbLiO [0.73, 1.98] → DFT 1.24; NaLi₄MgP₂ [0.83, 1.86] → DFT 1.66.

03

Strengths vs Limitations

  1. Perfect precision where it counts: 0 FP across all 98 returned candidates with full DFT re-evaluation, while the strongest baseline leaks 7.8–35%.
  2. Mechanism evidence: LLM-log lineage reuse of proxy evaluations is shown directly, and CISE’s intervals exclude those candidates.
  3. Well-controlled design: only two LLEMA modules changed; the equal-budget experiment pre-empts the “fewer returns” objection.
  4. Honest theory scoping: marginal, per-iteration, joint-event bound — stated plainly by the authors themselves.
  5. Generalizable formalization of false-positive propagation for any learned / LLM-judged reward loop, with code released.
  1. Yield collapse: 41 vs 102 (WBG), 51 vs 104 (SSE), 6 vs 60 (PV); when validation is cheap, point-estimate-plus-filter may win on true positives per compute dollar.
  2. Guarantee scope: marginal per-iteration only; εt never measured, so Theorem 2 may be tight or vacuously loose.
  3. Narrow empirical base: one benchmark family, one solver LLM (gpt-5-mini), one proxy per property; no transfer evidence.
  4. Calibration dependency: needs ~433k true-reward labels; the small-calibration regime — the practically relevant one — is untested.
  5. Assumption risk: conditional-reward preservation under shift is unverifiable at runtime and fails silently under extrapolative drift.
  6. Conservatism unanalyzed: no interval-width study or adaptive α; PV’s 3% yield is unexplained and untunable.
04

Questions for further exploration

Q1

What is the observed coverage of the intervals vs the nominal 1−α, and how large is εt? A CISE-without-DRE ablation would answer directly.

Q2

Does the covariate-shift assumption survive adversarial drift into extrapolation — do intervals widen as a warning, or does coverage silently collapse?

Q3

How does the reliability–yield trade-off behave as a function of α and validation cost — is there a principled α that maximizes true positives per DFT call?

Q4

Can the framework transfer to learned / LLM-as-a-judge reward loops where true-reward labels are far scarcer than JARVIS-QETB’s 423k pairs?

Q5

The guarantee is marginal and per-iteration — can it be strengthened to trajectory-level or acceptance-conditional bounds (union bounds with α/T, anytime-valid conformal) at acceptable conservatism?
