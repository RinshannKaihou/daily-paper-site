01

Method — Four Stages, All in Text Space

distilled from Methodology

A frozen LLM is executor, analyzer, and optimizer at once. Each skill revision is driven only by evidence the agent can gather about itself — the pipeline turns raw hidden-state dynamics into citable text feedback.

Stage 1 · Sample

Group rollouts

K=4 rollouts per task from the same frozen agent under the same skill. Behavioral spread is real: pairwise action disagreement reaches 82.7% by turn 5 (84 Qwen3-4B groups).

Stage 2 · Attribute

Turn-level deviation

Fixed-layer hidden states are PCA-projected into a trajectory; a Neural CDE trained only on successes predicts the next state from history. Error ‖hₜ−ħₜ‖² scores each turn; top-3 become critical turns.

Stage 3 · Verbalize

Evidence-grounded feedback

The same Qwen model acts as analyzer: every claim must cite trajectory evidence, and it may conclude “already covered” — high deviation alone doesn’t prove a skill error.

Stage 4 · Gate

Validation-gated revision

The optimizer drafts a candidate skill; it replaces the current one only after beating it on a small validation set. Revision lives entirely in text — no gradients anywhere.

Imported, not invented Neural CDE (Kidger et al. 2020) · trajectory modeling (Yeh et al. 2026) · GRPO-style group rollouts · validation gating (SkillOpt). The genuine contribution is the wiring — attribution → verbalization → revision — inside a self-evolution loop.

03

Strengths & Limits

condensed from Critical Assessment

Strengths

  • A clean mechanistic question — can an agent improve by reflecting on its own internal states? — answered with an intermediate evaluation (RQ2), not just end-task scores.
  • Ablations are decisive and falsifying: each removed component costs 4.5–5.5 SR points.
  • Case study shows exactly the targeted failure mode: generic “search harder” vs a localized, actionable rule.
  • Gains land where theory predicts — largest when the optimizer is weakest (Qwen3-4B WebShop, where SkillOpt drops below No Skill).
  • Honest limitations section: white-box access, Qwen-only evaluation, ~50-rollout overhead stated up front.

Limitations & open risks

  • White-box hidden-state access required; black-box API agents can’t use it (proxy-model workaround suggested, untested).
  • One model family (Qwen3-4B / 3.5-9B), two classic benchmarks (ALFWorld 2021, WebShop 2022); long-horizon generalization unverified.
  • WebShop gains are fragile: +0.31 task score on 4B is within a third of a std; “consistently outperforms” oversells.
  • ~50 extra rollouts + CDE training, with no wall-clock or token-cost accounting against baselines.
  • Kₑ=3, K=4, PCA dims fixed without end-task sensitivity; PCA may discard failure signals living in dropped components.

Open Questions

from the source summary
1Would human-verified non-progress labels change the 0.838 AUROC headline — and how much of the text+representation gain is LLM-judge agreement rather than true localization?
2Can the Neural CDE be trained once and reused across environments, or does attribution quality degrade when the success-trajectory set comes from a different task distribution?
3Does the method survive with a proxy executor (small open model’s representations guiding a black-box frontier agent) — does the executor–proxy representation gap erode the signal?
4WebShop 9B: +1.44 task score (within noise) but +4.66 SR — is the representation signal mainly preventing catastrophic skill regressions rather than improving average behavior?
5Could representation-deviation scores double as a runtime early-abort signal during deployment, rather than only an offline credit-assignment signal for skill revision?
