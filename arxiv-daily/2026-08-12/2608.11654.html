Key Finding

Memory is a basis of events; knowledge its span; optimal memory maximizes expected coverage under a capacity bound.

Towards a Formal Definition of Agent Memory: Basis, Span, Optimality, and the Sequential Memory Problem ↗

AuthorHongyao Tang· AffiliationTianjin University· Date2026-08-12· arXiv2608.11654
agent-memory memory-formalization coverage-utility sequential-MDP LLM-agents

Key Metric · Novel diagnostic

∆ =0.45

water-inflation degree

On the Homer's Odyssey instance at S=2, the coverage-optimal memory {ê, e₃} reports 0.80 apparent coverage but only 0.35 true — the gap is coverage bought with a false claim.

Why This Matters

Its coverage-vs-precision split and the water-inflation degree directly diagnose whether a memory system's reported quality is inflated by hallucinated claims.

⚠ Critical Edge

The single-item-support assumption bans answer-time multi-hop reasoning — exactly where most real memory systems (graph traversal, recursive reading, retry-from-reflection) operate — and the paper leaves that hard, non-submodular case unworked numerically.

Methodology

A formal / position paper, not an empirical study. It defines a two-layer object: a material D exposes a surface layer of events e ∈ E (atomic subject–predicate–object statements) and a semantic layer of knowledge items n ∈ N, linked by a generation operator Φ : 2^E → 2^N that entails knowledge from stored events.

A memory is simply M_D ⊆ E; its span is R = Φ(M_D). Under the single-item-support assumption (each query answered by one item), answerability reduces to coverage, and the optimal memory M*_D(S) = argmax E[u] s.t. |M_D| ≤ S traces a utility–capacity frontier U*_D(S).

When Φ is decomposable the problem is weighted maximum coverage with the classical greedy (1−1/e) guarantee; in general the objective is monotone but not submodular. Noise splits coverage from precision via the water-inflation degree, and single- and multi-material writing are unified as a sequential MDP with delayed reward, credit assignment, and trust estimation.

Paper type

Theory / position. No empirical experiments; all numbers come from a single hand-checked illustrative instance (Homer's Odyssey, 6 events, 8 queries). Proofs for the four propositions are given in text and appendices C–D. No code or dataset released.

Headline claim: the utility–capacity frontier is a "common yardstick" for comparing any two memory systems on one size–utility plane.

External evidence cited (not the paper's own experiment): a LoCoMo study reports memory-augmented systems cut token use by over 90% at competitive accuracy.

Strengths

  • Gives the field its missing vocabulary — basis / span / coverage / frontier / water-inflation make "how good is a memory" precise instead of per-benchmark ad hoc.
  • The coverage-vs-precision split and ∆ are a sharp, immediately usable diagnostic for hallucination-inflated quality.
  • The Level 0→2 taxonomy explains why most long-context benchmarks measure retrieval, not memory.
  • The sequential-MDP reading turns writing into a learning problem with three concrete sub-problems (credit assignment, trust, transfer).
  • System-positioning tables make ~8 competing systems comparable along generation / write / read / reason axes.
  • Intellectual honesty — limitations stated explicitly, not buried (Section 8.2).

Limitations

  • Single-item support excludes answer-time composition / multi-hop reasoning — the regime where real systems operate.
  • Coverage is optimized, not correctness; the proxy stance (sufficient info ≈ right answer) is asserted, only trivially supported.
  • Assumptions on Φ (monotonicity / decomposability) hold only approximately with real LLM extraction.
  • Representation-agnostic capacity (counted in events, not tokens/params) weakens the cross-system "common yardstick" claim.
  • No empirical validation on real benchmarks; whether any system approaches the frontier is untested.
  • The illustrative instance assumes the easy decomposable case and never works the hard non-submodular case numerically.

Open Questions for Further Exploration

  1. How do the frontier and the (1−1/e) guarantee change under a relaxed single-item-support assumption permitting bounded k-hop composition?
  2. What does U*_D(S) look like on a real non-submodular instance, and does any approximate algorithm recover a useful fraction of the frontier?
  3. Can frontiers be computed on LoCoMo / LongMemEval, and how far below them do HippoRAG 2, Mem0, Memory-R1 sit?
  4. Sample complexity: how many settled queries must a write policy observe to approach the frontier?
  5. How to make capacity representation-aware (tokens / parameters) so the yardstick genuinely compares symbolic, graph, and parametric stores?
  6. Under locally-monotone Φ failure, what write policy prevents a conflicting claim from destroying prior correct coverage?
