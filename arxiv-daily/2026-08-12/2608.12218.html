Informative training context makes models read from context instead of encoding knowledge into their own weights.

Information Abundance Paradox: Long-Context Training Undermines Parametric Knowledge ↗ · Arda Uzunoglu, Benjamin Van Durme, Daniel Khashabi — Johns Hopkins University · 12 Aug 2026
long-context parametric-knowledge in-context-learning training-dynamics mechanistic-interpretability
Key metric
−6.3pts
drop in no-context accuracy for Qwen3-14B on MMLU-Pro when target-domain documents rise from k=0 → k=8 — i.e. more relevant training context measurably erases parametric knowledge.
Why this matters
It challenges the dogma that longer context and more long-context data always help. Retrieval-rich or long-document fine-tuning can quietly degrade closed-book competence and conflict-robustness — a direct warning for RAG and long-context training strategy.
Critical edge
All pretraining uses only Project Gutenberg (literary text), so the reported inverted-U optima are almost certainly domain-dependent — code or web corpora could shift or erase the effect entirely, and this is untested.

Methodology · distilled

Pretraining (§3.1). Llama-2 models at 20M–750M params are pretrained on 10B Project Gutenberg tokens, sweeping the context window W∈{512…32768} while batch (~1.05M tokens), init, seed, and optimizer stay fixed — so comparisons are token-and-update-matched, not FLOP-matched.

SFT (§3.2). Qwen3 (0.6B–14B) is LoRA-tuned on four MMLU-Pro domains holding a budget of n=8 documents while only the count of target-domain docs k∈{0,4,8} varies — isolating relevance from raw length.

Theory (§4) & Mechanism (§5). Proposition 4.2 proves longer context can only lower the minimum knowledge that must live in the weights. Mechanism is triangulated via synthetic-task gradient norms, module-level FFN/SA gradient ratios, causal module-restricted tuning, and inference-time attention mass.

Central thesis · named

The Information Abundance Paradox: when task-relevant information is available in the train-time context, the model reduces loss by reading it directly instead of encoding it in weights — shifting learning from parametric internalization toward contextualization. The behavioral signature, poor robustness under absent or misleading context, is termed “context addiction.”

The same conclusion is hit from five converging angles: behavioral inverted-U → parametric-information-frontier theorem → synthetic-complexity link → gradient reallocation → causal module intervention.

Strengths

  • Clean, falsifiable central hypothesis with a memorable name and a concrete behavioral test (context addiction = poor robustness under absent/misleading context).
  • Genuinely controlled pretraining comparison — matched tokens, updates, init, seed, optimizer — rare and valuable.
  • Multi-level triangulation (behavioral → theoretical → synthetic → gradient → causal intervention → inference attention) hits the same conclusion.
  • Honest scoping of the theorem as an achievability result, and open acknowledgment of the 750M scale ceiling.
  • Actionable implication: long-context / retrieval-rich fine-tuning can silently erode closed-book competence.

Limitations

  • Single-domain pretraining (Project Gutenberg only); optima and the inverted-U on code or web data are unknown.
  • Scale capped at 750M; behavior at frontier 7B+ is entirely untested.
  • Theory shows longer context can reduce required parametric info, not that training does — the sharper empirical degradation is under-explained.
  • The FFN↔parametric-knowledge and SA↔contextualization mapping is adopted from prior work, assumed rather than re-proven.
  • SFT uses only four MMLU-Pro domains with constructed supporting/conflicting sets, which may exaggerate clean separation.
  • The Phi-3 / OLMo 3 motivator is correlational and confounded (data mixture + positional encoding differ, not only window length).

Questions for further exploration

  1. Does the inverted-U persist or shift on heterogeneous corpora (code, web, multilingual), and does mixing short- and long-context data remove the post-optimum degradation?
  2. At 7B–70B scale, does the inflection move, weaken, or vanish — small-model artifact or fundamental limit?
  3. Can a curriculum or regularization (penalize the FFN/SA gradient shift, up-weight closed-book loss) recover parametric robustness without losing long-context gains?
  4. How does the paradox interact with RAG, where context is supplied at both train and test time but is noisy or partial?
  5. Can the frontier theorem be strengthened to predict the inflection location or characterize which optimizers/data realize the lower-parametric-information solution?
