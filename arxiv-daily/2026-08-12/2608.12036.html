Methodology

/ 四阶段闭环
STAGE 01
Hypothesis
Decompose intent into atomic claims via neuro-symbolic retrieval (HyDE + BM25/dense/title + multi-hop graph + RRF) over the interp KG and SciAtlas.
STAGE 02
Experiment
Concretize datasets, target models, interp methods, metrics, controls, and compute budget — drawing on the 32-method library.
STAGE 03
Verification
Audit label provenance, leakage, metric validity; stress-test across method / dataset / model swaps.
STAGE 04
Iteration
Fuse diagnoses with an independent GPT-5.4 review; route problems upstream until reliable — or budget is exhausted.

A central orchestrator schedules the four agents; humans stay in the loop to set research objectives and acceptance criteria. Memory is externalized to stage-scoped files (proposal / tracker / code / results / integrity reports), so interrupted runs resume without re-running finished stages and downstream agents read canonical artifacts instead of a shared conversation. The knowledge substrate is a purpose-built interpretability KG of ~13K papers (107K nodes, 1.86M edges, 21 LLM-extracted fields), the 43M-paper, 26-discipline SciAtlas, and a curated library of 32 foundational methods in 11 families (causal attribution, dictionary learning, circuit discovery, SHAP, multimodal-specific interp, …), each with executable code and failure-mode guidance.

Strengths & Limitations

/ 优势与局限

▲ Strengths

  • Resumable four-agent design with externalized file memory — directly fixes the context-budget failure of prior AI-scientist systems.
  • Real causal methodology: Fisher ranking + zero-ablation + random head/parameter controls + Pile-perplexity sanity checks.
  • Cross-modal subliminal learning is a concrete, deployable warning for lab-safety and content-filtering pipelines.
  • Multi-judge evaluation (3 humans + 2 frontier LLMs) with Spearman agreement — above the norm.
  • Training-free intervention that meaningfully beats prompt hints; open-weight models (Pythia, OLMo, Evo2-7B) make studies checkable.

▼ Limitations

  • No resource ablation: the 13K interp KG vs 43M SciAtlas vs 32-method library are not decomposed — driver unknown.
  • Belief theory only on small open models (Pythia ≤ 2.8B, OLMo ≤ 7B); no frontier mechanistic evidence.
  • Headline 31–38 pt gap inflated — AI Scientist fails on environment issues, not science (authors concede).
  • Closed-model dependence: GPT-5.x, Claude Opus, DeepSeek-V3.2 act as reviewers / judges / extractors — reproducibility & version-stability risks.
  • Evo2 α-helix feature is pre-existing (prior SAE); Mechanist selects & steers it — narrower than "autonomous discovery."
  • Tight sample sizes (N=3 for safety transfer) and narrow cloze-style belief evaluation.
05

Questions for Further Exploration

/ 待探索问题
Which resource drives reliability? A controlled ablation removing the interp KG, SciAtlas, or method library would clarify where to invest.
Do separable PB/AB heads survive scale? Pythia-2.8B / OLMo-7B hint PB becomes distributed (top-25 heads).
Can subliminal-learning transfer be blocked — e.g., activation-level anomaly detection on student training data — and does it persist through RLHF?
Judge sensitivity: re-running the 16-paper eval with open judges would test robustness to the closed-model reviewers.
Can Mechanist discover a novel Evo2 SAE feature rather than steering a known one — and generalize beyond α-helix?
Compute / dollar cost per discovery, and how it scales with model size and KG growth.
