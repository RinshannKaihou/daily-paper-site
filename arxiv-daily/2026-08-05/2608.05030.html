01

Four-version evolution of the harness

V1 → V2 → V3 → V4
V1 — prior

Dynamic probabilistic prior

Score-driven GAS attack–defence model with Dixon–Coles low-score correction (ρ=−0.05). λH=μHexp(aH−vA). Tuned on 18,665 matches; half-life 1440 d.

owns probability + candidates
V2 — sandwich

Scalar residual (math+LLM+math)

LLM emits four ratings; a single learned κ maps them to capped log-λ shifts. Pooled 1X2 log loss gained only 0.14%.

failed · global κ insufficient
V3 — paths

Explicit goal-by-goal path simulation

LLM builds three distinct causal paths from 0–0; each transition is home goal / away goal / stop. Terminals must equal the returned Top-3.

interpretable model class
V4 — cascade

Shared root, cascade, tail anchors

One shared root judges 0–0 break; post-goal cascade emits closes / neutral / opens; deterministic builder appends up to five matrix-derived tail anchors.

candidate pool only — λ frozen
HARNESS INVARIANT ▸ The LLM may rerank a frozen candidate pool but cannot edit λ, invent scores, or apply a post-output weighting formula. Pre-match packets (identities, form, formations, rest, player availability, V1 λ + full score-matrix semantics) are timestamped and frozen per match before a separate evaluator reads outcomes.

03

Strengths & limitations

side-by-side

++ Strengths

  • Radically transparent about negative results — Discussion and Validity sections are as detailed as the wins.
  • Clean separation of concerns makes each failure mode independently diagnosable (root vs. cascade vs. candidate-generation vs. depth).
  • Demoting the LLM from parameter estimator to constrained simulator is a principled response to V2's unstable global κ.
  • Falsifiable audit checklist (Appendix B) + preregistered future-protocol template (Appendix D) others can adopt.
  • V1 trained on a large multi-league corpus (18,665 matches) with sensible half-life and gains — the prior has real credibility.

–– Limitations

  • LLM versions emit only orderings — no normalized probabilities, so they cannot be proper-scored against V1.
  • Benchmark is adaptive (first-100 informed V4) — no unbiased generalization claim is possible.
  • Closed-weight LLM + single archived run per version → reproducibility and variance estimation inadequate.
  • Outcome memorization by the LLM is neither controlled nor probed (model ran after the season ended).
  • 0–0 never identified; high-total & large-margin tail events mostly missed; tail anchors gave zero exact hits.
  • No human-expert baseline (bookmaker-implied or analyst Top-3) reported for the exact-score task.

Open questions for further work

from §discussion
Q1

Would a V1-only probability-weighted Top-3 reranker (no LLM) close most of the gap — isolating the true marginal contribution of LLM football reasoning?

Q2

Can LLM versions emit a normalized posterior over the candidate pool plus reserved tail mass, enabling proper-score comparison and calibration?

Q3

What does a parametric-memorization probe (counterfactual lineups, swapped identities, fact-suppression) reveal about genuine reasoning vs. retrieved outcomes?

Q4

Is the universal first_goal_more_likely root a prompt artefact or a model bias — and would an explicit 0–0 branch recover any of the eight missed nil-nil results?
