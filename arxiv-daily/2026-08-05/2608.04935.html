Methodology

geometric re-frame · text-seeded prototypes · zero deploy cost
Diagnose first

LDA shows PE's structure is cleaner — but wasted

A pooled 1-D LDA + overlap-coefficient probe on four In-the-Wild datasets: PE's real/generated distributions overlap by only 1.1%, far below DINOv3's 12.3%. Yet semantic-agnostic PE-Linear trails DINOv3-Linear by 4.1 pp — conventional probing wastes the structure.

Reinterpret the linear head

Two columns = two class prototypes

For a frozen image encoder x = N(f_I(I)), the binary head z = x·[p1, p2] makes each column a class prototype (SphereFace / CosFace view). Random init on a single source (SD1.4) biases prototypes toward that generator's cues.

// SPC initialization p1 ← N( f_T("AI art") ) // fake prototype p2 ← N( f_T("a real photo") ) // real prototype

Calibration recipe

minimize L_CE( [x·p1, x·p2], y ) on GenImage SD1.4
  • Image encoder frozen; only p1, p2 + biases train.
  • AdamW · batch 128 · 2 epochs · lr 2e-5 (vs 1e-3 for random-init).
  • Bias init (1, 0) for stability; ℓ2-normalized features.
  • Text encoder used only at init — inference identical to PE-Linear.
Evaluation surface

Five benchmark groups, one training source

Trained only on GenImage SD1.4; evaluated across cross-generator (GenImage, 6 unseen), in-the-wild (Chameleon / WildRF / SocialRF / CommunityAI), latest generators (AIGI-Holmes: LlamaGen, VAR, FLUX, SD3.5-L; AIGI-Now: GPT-4o, FLUX-Pro with pix/sem splits), and post-processing (Blur-and-JPEG).

Why SPC works — the falsification tests

prompt-ablation · cross-model transfer

Prompt-semantics ablation (Table 6)

  • Our Prompt ("AI art" / "a real photo"): +3.9 avg Δ vs random init.
  • Similar Prompt (semantically equivalent): +3.7 — wording-robust.
  • Opposite Prompt (labels swapped): collapses to −26.2 (In-the-Wild 44.7%).
  • Unrelated Prompts (content-only): degrade −7.8 / −9.1.

⇒ Gains come from class-aligned forensic semantics, not arbitrary text initialization.

Cross-model transfer (Fig. 4)

  • PE: +3.9 — helps.
  • MetaCLIP2: +3.9 — helps.
  • OpenCLIP (2022 LAION): −3.1 — hurts.
  • SigLIP2 (2023 WebLI): −15.8 — hurts badly.

⇒ SPC works only for VLMs whose pretraining already exposed them to synthetic content — a non-trivial negative result the authors report honestly.

Strengths / Limitations

honest ledger · side-by-side
✓

What holds up

5 items
  • Deployable. Changes only initialization of a 2-column head; zero inference cost. Drop into any VLM detector.
  • Mechanistic story. LDA overlap (1.1% vs 12.3%) + Opposite/Unrelated ablations jointly explain why PE-Linear underperforms and why SPC fixes it.
  • Breadth. Five groups: cross-generator, in-the-wild, closed-source (GPT-4o, FLUX-Pro), post-processing — all trained on one source.
  • Honest negatives. SPC degrades OpenCLIP / SigLIP2 — reported, not hidden.
  • Efficiency. 71.6% fewer params, 2.7× throughput, higher accuracy than the 6.7B rival.
!

Where it strains

6 items
  • Hand-crafted prompts. "AI art" / "a real photo" fixed; only one wording alternative tested. No automated prompt search.
  • Single training source. Only GenImage SD1.4 — generalization inseparable from PE's pretraining quality.
  • Pretraining-era dependent. Fails on OpenCLIP / SigLIP2; not a universal VLM upgrade.
  • Recent in-family rivals absent. FGTS (2025) and STAL (2026) discussed but not in result tables.
  • Closed-generator eval. GPT-4o / FLUX-Pro / Jimeng / Keling / MiniMax rely on AIGI-Now curation outside authors' control.
  • No margin/loss variants. CosFace/SphereFace-style angular losses unexplored; no per-generator multi-class extension.
05

Open questions for follow-up

where the prototype framing begs to go next
Q1 · PROMPT MINING

Can SPC's prompt dependence be removed by automatically mining the best forensic concept from a candidate pool (Top-1 text-concept matching, Appendix F) instead of hard-coding two strings?

Q2 · ANGULAR MARGIN

Does adding a CosFace / SphereFace angular-margin loss on the calibrated prototypes further widen real/generated separation, given the geometric framing?

Q3 · MULTI-SOURCE

How does PE-SPC behave when trained on multiple generators (SD1.4 + ADM + Midjourney)? Does the SPC advantage shrink, hold, or grow?

Q4 · PORT TO VISION-ONLY

Could SPC be ported to DINOv3 by borrowing an external text encoder for init — or is the shared image-text space essential?

Q5 · COMPLEMENTARITY

AIGI-Now "sem" gains (+9.0 pp) dwarf "pix" gains (+3.3 pp); is SPC complementary to low-level pixel/frequency detectors — motivating a two-head ensemble?

Q6 · SCREENING TEST

Given SPC fails on OpenCLIP/SigLIP2, is there a lightweight pretraining-corpus screen predicting in advance whether a VLM will benefit — without the full benchmark?
