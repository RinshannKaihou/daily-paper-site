> **一句话总结：** MetaVideoAgent 提出首个面向特定视频分布的自动视频 Agent 演化框架，通过"分布感知初始化 + Teacher/Diagnosis/Evolution 三智能体迭代 + 模块化代码级更新"，在自建的 8 分布基准 VA-EvoBench 上将宏平均准确率从 38.44% 提升至 51.47%，并以最低的单题 token/帧开销超过所有固定设计的视频 Agent。

> **TL;DR:** MetaVideoAgent is the first framework to automatically evolve a video agent's code-level design for a target video distribution; using the new 8-distribution VA-EvoBench (derived from CG-Bench), four iterations raise macro-average held-out accuracy from 38.44% to 51.47%, beating the strongest fixed video agent WorldMM (45.08%) and the best direct MLLM Gemini 3.1 Pro (38.98%) by 6.39 and 12.49 points respectively, while using the fewest per-question tokens (74.47K vs 100-322K) and frames (29.11 vs 36-830) among compared agents.

## 核心贡献

- **首次提出面向特定视频分布的自动视频 Agent 演化范式**：将传统手工启发式设计转变为基于分布级反馈的自适应演化，针对每个目标视频分布（访谈、产品展示、软件教程、戏剧叙事、游戏、舞台表演、体育转播、课程讲座）独立演化出一个专用视频 Agent。
- **设计 MetaVideoAgent 演化框架**：由 Distribution-Aware Design 做初始化，再由 Teacher Video Agent（构建 Gold Path 复核失败轨迹）、Diagnosis Agent（跨样本聚类根因并定位主责模块）、Evolution Agent（在模块化表示上做"责任约束"代码级修改）协同完成迭代，并通过"最小验证任务"压缩长视频 QA 的验证成本。
- **构建 VA-EvoBench 基准**：基于 CG-Bench 划分 8 个内容特征集中且彼此差异明显的视频分布，每个分布都有独立的演化/留出 split，统一评测任务准确率、单题资源消耗和演化效率。
- **严格的盲评协议**：留出集结果仅由外部 evaluator 在固定预算耗尽后做事后记录与分析，绝不参与诊断、候选选择、早停或回滚，避免选择偏差。
- **强实证结果**：宏平均准确率从 38.44% 提升至 51.47%（+13.03），且每个分布均改进，并在 token/帧开销上全面占优；DVD 初始化变体在课程讲座上进一步达到 63.03%。

## Key Contributions

- First formulation of **target-distribution-specific automated video-agent evolution** for long-form video understanding, shifting from manually engineered heuristic agent designs to an adaptive evolution paradigm driven by distribution-level feedback.
- **MetaVideoAgent framework**: Distribution-Aware Design initializes the agent from sparse frames + queries; Teacher Video Agent builds an evidence-grounded Gold Path and audits the Student trajectory; Diagnosis Agent aggregates recurring causal failures and isolates the primary responsible module; Evolution Agent performs responsibility-constrained code updates over a 5-module representation (Structuring, Localization, Perception, Working memory, Reasoning). Localized failures are compressed into minimal validation tasks for cheap candidate probing.
- **VA-EvoBench**: a new benchmark with 8 substantially different video distributions and separate evolution/held-out splits, evaluating QA accuracy, per-question token and frame cost, and evolution efficiency (accuracy under cumulative evolution compute).
- A **strict blind protocol**: held-out checkpoints are archived externally and analyzed only post-hoc; they never drive diagnosis, candidate promotion, early stopping, or rollback, preventing test-set leakage into the evolution loop.
- A **modular video-agent representation** A = (S, L, P, W, R) with stable interfaces that enables reliable code-level updates while preserving end-to-end executability.

## Methodology

MetaVideoAgent is structured around three coupled stages of automated evolution (execution, diagnosis, evolution), each specialized for video:

**1. Modular agent representation.** Existing video agents are abstracted into five interface-stable modules: Structuring S (time-indexed video representation), Localization L (executable temporal ranges), Perception P (observations only within ranges), Working memory W (cross-step context), Reasoning R (tool-call planning + final answer). Each iteration is restricted to modifying the primary responsible module plus only necessary dependencies.

**2. Distribution-Aware Design (initialization).** For each evolution video, 5 frames are uniformly sampled, summarized with non-answer metadata and associated queries into records; the design phase abstracts recurring distribution-level patterns (no access to answers or evidence annotations), induces distribution-specific requirements (modalities, evidence granularity, localization patterns), retrieves source-grounded design evidence from papers/docs, and constructs the initial agent A0 either from scratch or by adapting an existing agent (e.g., DVD). The agent is then repaired and smoke-tested.

**3. Teacher Video Agent (per-sample review).** For each incorrect sample, the Teacher receives the Student trajectory τ, query, ground-truth answer, and annotated evidence intervals. It constructs an evidence-grounded **Gold Path** describing the observations and reasoning needed for the correct answer, then audits the Student trajectory to find the earliest step that can no longer support that solution. Output review ρ includes earliest unsupported step, causal failure, responsible module, and a candidate minimal validation task.

**4. Minimal validation tasks.** The Teacher isolates each failure into (localized multimodal input, expected output) — cheap local probes; full video-QA evaluation is still required for final promotion. If isolation is impossible, the original sample is retained.

**5. Diagnosis Agent (cross-trajectory).** Aggregates all reviews, clusters recurring causal failures, separates engineering faults from design deficiencies, considers previous corrections/regressions to avoid repeating dead-ends, and selects one primary responsible module plus code-scope constraints and validation/cost requirements.

**6. Evolution Agent (code modification).** Implements the diagnosis via responsibility-constrained updates to the primary module; dependent modules change only to preserve interfaces/end-to-end execution. Candidates pass through engineering gates → minimal-validation probe → full evolution-split comparison before promotion.

**7. Evaluation protocol.** VA-EvoBench is derived from CG-Bench into 8 distributions (Interview, Product Presentation, Software Tutorial, Dramatic Narrative, Gameplay, Stage Performance, Sports Broadcast, Course Lecture), each with video-disjoint evolution/held-out splits. Reported: held-out macro accuracy, tokens/question, frames/question, and best-so-far accuracy Pd(Ck) under cumulative evolution compute.

## Results & Highlights

- **Overall macro accuracy**: MetaVideoAgent reaches **51.47%** (446/867; 51.44% question-weighted) across the 8 VA-EvoBench distributions, raised from an initial **38.44%** to 51.47% (+13.03 points) over 4 iterations — improving every one of the 8 distributions.
- **vs. strongest fixed video agent**: beats WorldMM (45.08%) and DVD (44.15%) by **+6.39** and +7.32 points respectively; the best fixed agent WorldMM is the second-best overall.
- **vs. strongest direct MLLM**: beats Gemini 3.1 Pro (38.98%) by **+12.49** points and GPT-5.5 (27.91%) by +23.56 points; Gemini 3.1 Pro used 19.50K tokens/q and 120 frames/q.
- **Lowest resource cost among agents**: only **74.47K tokens/question** and **29.11 frames/question** — vs. DVD 214.19K/38.75, WorldMM 102.26K/42.77, M3-Agent 131.94K/36.23, and Symphony 322.94K/830.18.
- **Evolution efficiency**: total evolution cost is **28.33M tokens** (3.54M per distribution); mean best-so-far held-out accuracy at full budget is 52.21% (95% CI: 48.63–55.78).
- **Per-distribution gains** (initial → final evolved accuracy): Course Lecture 36.97→59.66, Sports Broadcast 26.76→50.70, Software Tutorial 23.30→56.31, Product Presentation 30.30→53.03, Stage Performance 31.07→57.28, Dramatic Narrative 16.81→40.34.
- **Ablation on Course Lecture**: Full MVA 59.66%; removing Diagnosis −2.52; removing Deep Research −10.92; removing Review/Diagnosis/Research jointly drops to 47.90% (−11.76) with update volatility exploding to 293.24 pp² vs 15.52 for full MVA. DVD-initialized MVA reaches **63.03%** (+3.37), showing MVA can further adapt an existing agent.
- **Qualitative transfers** (held-out, without feedback from displayed questions): event ordering on Stage Performance (identifies "the first ball" as White), position-relation perception on Product Presentation (reads back-of-jersey text "RCHIVES"), subject tracking on Sports Broadcast (associates Jeremy Lin across camera cuts).

## Critical Assessment

- **Novelty**: Genuine framing novelty as the first distribution-specific, code-level video-agent evolution framework (extending ADAS/EvoAgent from text to multimodal video). The Teacher→Diagnosis→Evolution decomposition with the Gold Path + minimal validation task mechanism is a non-trivial adaptation, not a text-method port.
- **Rigor**: Strong experimental hygiene. The blind protocol (held-out never enters diagnosis/promotion/stop/rollback) is exemplary and explicitly guards against test-set leakage — a common weakness in many "evolution" papers. However, ablations are only reported on a **single distribution (Course Lecture, 119 held-out questions)**, so component contributions on the other 7 distributions are unmeasured; the authors even acknowledge the Diagnosis ablation gap is modest and justify it qualitatively rather than empirically across distributions.
- **Reproducibility**: Modular 5-module contract, pseudocode in appendices (Algorithms 1–6), public model assignments, and committed code/data release improve reproducibility. But the framework relies on closed-source frontier coding models (Claude Code, OpenAI Codex) for the Evolution Agent — exact reproduction is contingent on those systems' behavior, and per-distribution token costs (~3.54M) plus the unspecified MLLM backbones (Gemini 3.1 Pro, GPT-5.5, Claude Opus 4.8 are used as baselines) introduce version drift risk.
- **Significance**: Meaningful for the long-form video-agent community, providing both a method and a benchmark (VA-EvoBench) that targets a real gap (distribution-specific design). The 8-distribution benchmark with separate evolution/held-out splits is a usable artifact.
- **Red flags / concerns**:
  - The benchmark is **derived entirely from CG-Bench** rather than newly sourced data, so VA-EvoBench inherits any CG-Bench annotation biases; the "8 distributions" are re-slicings of one source dataset.
  - Initial accuracy **38.44%** vs. final 51.47% is the headline, but the initial agent is MVA's own from-scratch agent — a potentially **weak starting baseline** that inflates the improvement narrative; comparison against evolving a non-MVA initial design is limited to the single Course Lecture DVD-init experiment (+3.37).
  - The strongest fixed agent **WorldMM (45.08%)** is itself only ~1 point above DVD and Symphony, so the fixed-agent competition is bunched; the +6.39 gap is on a single held-out split per distribution with no reported variance/significance on the main table.
  - Per-question token/frame counts for MVA are reported but the **cost of the evolution-time Teacher/Diagnosis/Evolution agents (3.54M tokens/distribution)** is not folded into deployment cost, making MVA look cheaper at inference than the total cost picture.
  - Comparison against adaptive video agents (LensWalk, VideoSeek) is only discussed in related work (Appendix Table 3), not directly benchmarked in Table 1.

## Strengths

- First-mover framing of distribution-specific video-agent evolution with a clean, well-motivated three-agent loop.
- Strict blind evaluation protocol that prevents held-out leakage — a methodological highlight.
- Modular video-agent representation (S, L, P, W, R) with stable interfaces is a broadly reusable abstraction.
- Simultaneous wins on accuracy AND efficiency (fewest tokens and frames per question among all compared agents).
- VA-EvoBench with 8 distribution-specific splits and separate evolution/held-out partitions is a concrete, reusable benchmark.
- Honest reporting of CI (48.63–55.78) on the budget-accuracy curve and clear distinction between final-agent accuracy (51.47%) and best-so-far curve (52.21%).

## Limitations

- Ablations confined to a single distribution (Course Lecture); component-level sensitivity across all 8 distributions is unknown.
- VA-EvoBench is re-sliced from CG-Bench, inheriting its annotation biases and limiting distribution diversity to what CG-Bench covers.
- Headline improvement (38.44%→51.47%) starts from MVA's own from-scratch initial agent; only one distribution tests DVD initialization.
- Reliance on closed-source frontier coding agents (Claude Code, OpenAI Codex) for the Evolution Agent — reproducibility and cost are contingent on external systems.
- Per-distribution evolution cost (~3.54M tokens) is excluded from deployment-cost reporting, understating total system cost.
- No direct benchmarking against adaptive video agents (LensWalk, VideoSeek) in the main table — only discussed qualitatively.
- Main results table reports no variance or significance intervals across the 8 distributions.

## Relevance

For research on automated agent design / self-evolving agent systems and long-form video understanding, this paper is highly relevant: it provides both a concrete evolution framework (MetaVideoAgent) and a reusable distribution-stratified benchmark (VA-EvoBench) that directly address how agentic systems can adapt their code-level design to a target data distribution rather than relying on manually fixed prompts/workflows.

## Questions for Further Exploration

- How does MVA's evolution transfer when the initial agent is a strong adaptive agent (e.g., VideoSeek, LensWalk) rather than DVD or a from-scratch design — does the +3.37 Course Lecture gain generalize?
- Would ablations run on all 8 distributions (not just Course Lecture) reveal that Diagnosis or Deep Research is critical for some distributions and dispensable for others?
- Can the Teacher's Gold Path construction be validated against human annotations beyond the provided evidence intervals, to measure Gold Path quality itself?
- What happens to evolution stability when the closed-source coding-agent backbone (Claude Code / Codex) is swapped for an open-source coding model — is the responsibility-constrained update robust to weaker coders?
- How sensitive is VA-EvoBench to its CG-Bench provenance — would the 8 distributions and the fixed-agent rankings change materially if sourced from Video-MME, LongVideoBench, or newly collected videos?
- Can the per-distribution evolution cost (3.54M tokens) be reduced via better minimal-validation task reuse across distributions, enabling joint multi-distribution evolution?
