04 · Limitationswhat to weigh

Observational, single-backbone, narrow scopesThe authors name these; they do not close them.

  • Observational, not causal — central self-evolution claim lacks matched frozen-state replay, randomized routing, and randomized task order.
  • Single backbone — seven arenas all run GPT-5.5 (six via Codex); the GLM-5.2 transfer run is incomplete and un-baselined.
  • Loose headline numbers — "≈78% vs ≈59%" with no CIs or exact counts; 1.41× Tokens reported without cost / wall-clock normalization.
  • Verification bounded by the verifier — a test or Reviewer can encode the wrong property; the runtime records but cannot guarantee correctness.
  • Paper-production ≠ acceptance — six manuscripts reach submission; says nothing of novelty, peer review, or beating human teams.
  • Verticals close narrowly — ACE-2 certified only at synthesis + static timing (no silicon); MOF scored on the same validator optimized against.

05 · Open questions for further exploration7 threads

Where the evidence perimeter is thinnest

  1. What would a matched frozen-state replay of all 731 SWE-Bench Pro tasks show — same task order against startup vs mature state — to isolate the causal contribution of accumulated Skills/Wiki/routing?
  2. How sensitive is the 79.1% recovery / 51.2% rescue to randomized (non-adaptive) Reviewer routing, given review now concentrates on harder tasks?
  3. Can ManagerAdmit be stress-tested adversarially — a Manager deliberately proposing a goal-drifting refinement — to test whether the gate refuses vs rubber-stamps?
  4. Does process-data dominance (Prop. 1) translate into measurable downstream SFT/RL gains a model can internalize from Argus trajectories?
  5. How does Argus behave when the verifier itself is wrong (spec bug vs implementation bug) — does it localize the faulty side or merely satisfy the current check?
  6. Is the 1.41× Token cost economically justified at +19 pts once dollar cost and wall-clock latency (incl. excluded orchestration wait) are normalized?
  7. Can the ACE-2 / materials pattern of self-declared scope exclusions become a general certification format other agentic systems adopt?
