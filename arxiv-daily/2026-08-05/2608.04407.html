§ 01

Methodology — the ordering failure

diagnosis → fix

The root cause

A routed MoE expert matrix receives conditional gradients — only over router-selected tokens, with drifting gate weights. Stateless Sinkhorn normalizes each noisy instantaneous sample. Because Sinkhorn is nonlinear, the order in which you smooth vs. normalize changes the result.

The ordering mismatch
stateless:   Sinkhorn( E[G] )  ≠  E[ Sinkhorn(G) ]  :momentum
normalize-then-average  ≠  average-then-normalize

Negative ablations (what does not explain it)

V-only AdamW (3.8457, worse) · Lion / sign momentum (4.0046) · factored-v only (4.2308) · fused-Sinkhorn · route-confidence damping — none close the gap. Only first-moment smoothing before normalization recovers quality.

The fix — MESH (Algorithm 2)

01
Maintain an unnormalized momentum H = β1·H + G — never stored in optimizer state.
02
Expert direction becomes U = Sinkhorn(H; K=5, τ=10) — normalize the smoothed accumulator, not the raw gradient.
03
Exploit the gradient-buffer lifecycle: stash H detached after step; reattach as p.grad ← β1·H before next backward.
04
A prepare-before-backward hook survives Accelerate / DDP wrappers. Diagnostics: cosine ≈ 1, rel-error ≈ 1e-8.

MESH-B adds an optional block/neuron inverse-RMS preconditioner — multi-seed shows it's statistically indistinguishable from plain MESH.

Where the failure lives

Converting only experts to AdamW recovers most of the gap (3.8265 → 3.6158). Routing only the routed experts to AdamW recovers to 3.6297; routing only the shared expert helps far less (3.6895).

Conclusion: routed experts — not shared — are the dominant failure mode, because their gradients are the most temporally sparse and conditional.

Take-away
Experts need temporal smoothing — but not necessarily full coordinate-wise AdamW state.
§ 03

Strengths & limitations

side by side

Strengths

  • Clean mechanistic diagnosis — frames the failure as a nonlinear ordering problem (Sinkhorn(E[G]) ≠ E[Sinkhorn(G)]) and supports it with a full ladder of negative ablations.
  • Engineering honesty — gradient-buffer lifecycle (stash / reattach / prepare-before-backward) is described in enough detail to implement, including DDP/Accelerate pitfalls.
  • Conservative framing — explicitly states MESH does not outperform AdamW; positions itself as a memory trade-off.
  • Real memory wins — 62.5% optimizer state, ~12.6% peak CUDA, both meaningful for MoE training budgets.

Limitations

  • Single small architecture — 110M nanowhale, FineWeb-Edu only, 5K steps, 512-example eval. Acknowledged by authors.
  • Asymmetric seed counts — MESH uses 2 seeds vs AdamW's 3; decisive gaps fall within the paper's own noise band.
  • Vocab-heavy, atypical config — 75% of trainable params in untied embeddings on SAGE; the obvious vocab-to-AdamW ablation is missing.
  • No comparison to Adafactor, 8-bit Adam, Adam-mini, Lion at matched state budgets.
  • MESH-B not proven necessary beyond seed 42; multi-seed shows it's indistinguishable from plain MESH.
  • No code-release URL in the paper text.
