Context nearly closes the gap.

Methodology

Slang-Q is built on 1,024 sentences mined from 185,795 Urban Dictionary entries (SLANG benchmark), each paired with one of 118 queer-slang terms and a hand-written gold definition. Evaluation is cast as definition generation across a 2×2 grid.

1
Compile taxonomy. 118 terms from NLP papers, Wikipedia LGBTQ slang, Lexicon Library.LGBT, Wiktionary + 13 bottom-up additions. 2-level · 3 cats × 5 subcats
2
Extract candidates. String-match against Urban Dictionary → 3,184 candidate sentences.
3
Manually annotate. Sole annotator checks queer-sense relevance; 1,833 unrelated + 327 harmful discarded → 1,024 valid, covering 77/118 terms.
4
Generate & score. 4 LLMs × 4 conditions (term ± context × baseline vs. slang-informed), one-shot. Multi-reference ROUGE-L + BERTScore, term-level aggregated.

The 2×2 condition grid

Two crossed dimensions define four prompting conditions:

  • Context: term-only vs. term + example sentence
  • Framing: generic “language expert” vs. “queer internet slang expert”

Models

  • Claude Sonnet 4.6 — proprietary, Anthropic API
  • Qwen3 32B — open, via Groq
  • LLaMA 4 Scout — open, via Groq
  • LLaMA 3.3 70B — open, via Groq

Length-perturbation pre-validation confirms ROUGE-L is length-sensitive (0.627→0.386); BERTScore is stable (~0.92). Contamination audited via the black-box Data Contamination Quiz.

No model dominates — contamination ≠ advantage

Across all 8 model×metric cells the ROUGE-L spread is within ~0.02, despite vastly different training exposure. Claude’s 57–62% verbatim memorization does not translate into a definition edge, because outputs are scored against human-written definitions, not Urban Dictionary entries.

  • Term-only baseline is consistently worst. LLaMA 4: 0.14 → 0.17 with slang-informed framing.
  • Intersectional terms score lowest on both metrics (slay, tea) — cross-community (queer / AAVE / fandom) polysemy.
  • Adding either slang framing or context improves scores — both help converge on queer-specific sense.

Strengths & limitations

STRENGTHS What lands well

  • First to probe knowledge, not bias. Reframes queer NLP from harm-detection toward what models actually know.
  • Reusable taxonomy. 2-level Identity / Slang / Intersectional × 5 subcategories — a community contribution beyond the experiments.
  • Methodologically careful. Multi-reference scoring, length-perturbation validation, term-level aggregation, black-box contamination audit.
  • Fully public. Data, taxonomy, prompts, and manual annotations released on GitHub.
  • Insightful category finding. Intersectional terms hardest — links to AAVE / fandom overlap.
  • Honestly scoped. Explicitly framed as a first-stage resource paper.

LIMITATIONS What to question

  • Single annotator, no IAA. Harmful / unrelated discards are not independently auditable.
  • Coverage is thin. 41/118 terms have zero sentences; frequency skewed to slay, goat, bae.
  • Human bound is paraphrase-similarity (gold vs GPT-5.5 paraphrases), not true human–human agreement.
  • BERTScore saturates (0.85–0.86) — essentially uninformative, yet reported co-equal.
  • Single task. Definition generation only; no dialogue / MT / moderation probing.
  • Small model sample (4 LLMs) + proprietary API + Groq defaults → fragile reproducibility.
  • 2026 snapshot. Lexicon Library.LGBT discontinued July 2026; lexicons inherently drift.
