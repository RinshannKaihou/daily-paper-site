> **一句话总结：** FiGuRO 把「率失真预算」变成一个训练中的秩调度器——在自编码器瓶颈处插入可截断 SVD 的低秩层，每隔 τ 轮根据各模态重构保真度 R² 是否跌破 D₀−λ 来双向增/减各子空间的秩，从而在一次训练里同时估计共享与私有子空间的本征维度；在模拟多模态数据集 B 上平均秩偏差仅 2.9±0.7，优于 ShIndICA(9.5)、SLIDE(11.8)、JIVE(12.4)、AJIVE(36.3)，且共享/私有信息的解耦是无需正交或稀疏辅助损失的涌现性质。

> **TL;DR:** FiGuRO inserts truncated-SVD low-rank layers into a multi-modal autoencoder bottleneck and uses a rate-distortion-style rule (shrink ranks while reconstruction R² stays above D₀−λ, grow them when it falls below) to jointly estimate the intrinsic dimension (ID) of shared and modality-private subspaces in a single training run. On the simulated multi-modal benchmark B it reaches an average deviation from ground-truth subspace ranks of 2.9±0.7 versus 9.5±2.1 for the strongest baseline ShIndICA (and 11.8 for SLIDE, 36.3 for AJIVE), and on So2Sat its shared subspace gives 0.55±0.03 balanced accuracy for climate-zone classification versus 0.24 for the best decomposition baseline. Disentanglement emerges without auxiliary orthogonality/sparsity losses, but the uni-modal benchmark is much less flattering than the abstract implies.

## 核心贡献

- **首个显式估计多模态共享/私有子空间各自 ID 的神经方法。** 现有工作要么把潜空间维度当成需要网格搜索的超参数，要么（如 CLIP 类对比方法）只隐式地适配共享 ID，无法给出可解释的分解式估计。
- **率失真驱动的双向秩优化算法（Algorithm 1）。** 先全秩预训练得到基线保真度 D₀，再每 τ 轮判断：若 D_t > D₀−λ 则用累积能量阈值 γ 一次性砍掉低能量奇异方向；若 D_t ≤ D₀−λ（压缩过度）则按 max(k+1, 1.1k) 扩秩。共享秩 k_s 的增减由「所有模态是否一致」的规则仲裁。
- **在权重矩阵而非 batch 潜变量上做 SVD。** 借鉴 LoRA 把 W ≈ U^(k*) S^(k*) Vᵀ^(k*) 分解，使学到的低秩结构与 batch size 无关，并直接把被剪掉的维度从投影中 mask 掉，得到真正低维的表示。
- **解耦是涌现性质而非损失项。** 消融显示 Frobenius 正交惩罚、L1、L2 正则不但没有改善解耦，反而普遍恶化秩估计（L1 权重 0.01 时 Bs 的 (k_s,k₁,k₂) 从 3.6/1.0/6.2 塌到 1.0/1.0/2.3）。
- **可作为冻结基础模型的「潜空间探针」。** 在 NYU Depth V2 上直接对 Stable Diffusion VAE 与 Depth Anything V2 的固定嵌入做后验解耦，无需端到端重训。

## Key Contributions

- **First neural framework that gives explicit, separate ID estimates for the shared and each modality-private subspace** of multi-modal data in one training pass, filling the gap left by methods that fix latent dimensions as hyperparameters or only implicitly adapt to the shared ID.
- **A bidirectional, fidelity-guided rank scheduler** grounded in rate-distortion theory: a user-set distortion budget λ defines the minimum acceptable fidelity D₀−λ, and ranks are pruned via cumulative singular-value energy threshold γ or grown by unmasking when compression becomes too lossy. Patience π terminates the search.
- **LoRA-style weight-matrix decomposition instead of ARR's batch-latent SVD**, making the learned low-rank structure independent of batch size and yielding genuinely low-dimensional representations rather than merely rank-deficient ones.
- **Empirical demonstration that shared/private disentanglement is the most rank-efficient solution** and therefore emerges from the optimization itself; explicit regularizers are shown to be unnecessary or harmful.
- **Post-hoc applicability to frozen pretrained uni-modal encoders**, positioning FiGuRO as a lightweight interpretable fusion probe for foundation models.
- Code released at https://github.com/viktoriaschuster/FiGuRO; the paper appears in ICML 2026 (PMLR 306).

## Methodology

FiGuRO plugs a low-rank decomposable layer with maximum rank k_max = l (upstream hidden width) into the bottleneck of a multi-modal autoencoder. Each modality m is encoded to h_m, projected to a private code z_m = W_m^(k*_m) h_m, and the concatenation (z₁ ⊕ z₂) is projected through W_s^(k*_s) to the shared code z_s. Each decoder reconstructs its own modality from (z_s ⊕ z_m), which is the standard shared/private multi-modal autoencoder skeleton; the novelty is that k_s, k₁, k₂ are learned rather than chosen.

Training has two phases. Phase 1 trains the full-rank model to convergence and records the per-modality baseline distortion D₀,m. Phase 2 alternates one epoch of ordinary reconstruction training with, every τ epochs, a rank update: subspaces whose current fidelity still exceeds D₀,m − λ go into K_decrease, those that have fallen below go into K_increase. Reduction discards all dimensions below the index where cumulative singular-value energy reaches 1−γ; increase adds max(k+1, ⌊1.1k⌋). The shared rank follows the modalities when they agree and is otherwise assigned by whether K_increase or K_decrease is empty. The loop stops after τ×π epochs without rank changes. R² is the default distortion metric because it is scale-invariant, which makes λ interpretable across datasets and losses; appendix experiments compare it to Explained Variance Score, MSE and RMSE.

Evaluation uses (i) uni-modal simulation A (ambient 50, ID 5) for a 1080-run hyperparameter sweep over λ, τ, γ, π; (ii) multi-modal simulation B in four variants — Bs (2/3/5), Bi1 (20/2/2), Bi2 (2/2/20), Bl (20/20/20), all ambient 200+200, 10K samples — to test whether the method tracks different shared-to-private ratios; (iii) a 20K+20K dimensional simulation C inspired by gene expression / protein abundance, with C₁ noise-corrupted (ID 11) and C₂ highly nonlinear (ID 12), for the uni-modal estimator benchmark; and (iv) three real datasets: Audio MNIST, So2Sat (SAR + optical, climate zones), and NYU Depth V2 (RGB + depth, on frozen Stable Diffusion VAE and Depth Anything V2 features). Baselines are classical ID estimators (PCA, lPCA, FisherS, CorrInt, TLE, MindML, MLE, TwoNN, BEMA), neural estimators (loss cliff, ARD-VAE, RRA, FLIPD), and multi-view decompositions (JIVE, AJIVE, SLIDE, ShIndICA).

## Results & Highlights

- **Multi-modal subspace ID (Table 2, datasets B):** FiGuRO's average deviation from ground-truth ranks is **2.9 ± 0.7**, versus **9.5 ± 2.1 for ShIndICA** (strongest baseline), 11.8 ± 2.4 for SLIDE, 12.4 ± 2.5 for JIVE and 36.3 ± 21.7 for AJIVE. Concretely, on Bl (GT 20/20/20) FiGuRO estimates 19.2 ± 0.7 / 12.8 ± 1.0 / 15.2 ± 1.3 while JIVE and SLIDE return a shared rank of 1 and private ranks of ~40.
- **Hyperparameter robustness (dataset A, N = 1080 runs):** the mean estimate is **4.89 ± 0.01 for a true ID of 5**, with only mild dependence on λ and negligible sensitivity to γ.
- **Ablation (Table 3):** the naive SVD-only variant (energy pruning without the rate-distortion controller) **collapses to rank 1.0 ± 0.0 on every subspace of all four B datasets**, versus FiGuRO's 3.6/1.0/6.2 (Bs) through 19.2/12.8/15.2 (Bl) — the fidelity gate, not the SVD, is doing the work.
- **Uni-modal benchmark (Supp. Table 2, dataset C):** FiGuRO's selected configuration (λ = 0.05) gives **15.3 ± 2.2 for C₁ (GT 11) and 5.7 ± 0.3 for C₂ (GT 12)**. For comparison, FLIPD with manually chosen t₀ = 0.7 gives 9.2 ± 0.4 and 16.0 ± 0.5 — i.e. mean absolute error 2.9 versus FiGuRO's 5.3. Classical estimators fail far worse in one regime each (PCA: 4040 on C₁; MLE: 2.4 on C₂; TwoNN: 130 on C₁), which is the sense in which FiGuRO is "consistent across regimes".
- **Compression (Supp. Table 13):** total ranks drop from k₀ = 600 to **16.4 on Audio MNIST (≈36×) at only +0.2% test MSE**, 600 → 85.7 on So2Sat (+1.2%), and 1500 → 303.4 on NYU Depth V2 (+1.9%).
- **Downstream classification (Table 4):** on **So2Sat**, the shared subspace reaches **0.55 ± 0.03 balanced accuracy** versus 0.24 (SLIDE), 0.20 (AJIVE), 0.15 (JIVE) and n.a. (ShIndICA), and beats the **uni-modal 0.41 ± 0.01** all-feature accuracy. On **Audio MNIST**, FiGuRO's shared subspace gets **0.94 ± 0.01** — but **AJIVE gets 0.99**, and on Acc_all AJIVE 0.99 vs FiGuRO 0.97 ± 0.01.
- **Real-data ID plausibility:** on Audio MNIST, k_s + k_image = **11.4 ± 0.6**, inside the 7–25 range previously reported for MNIST, whereas baselines assign 117–485 dimensions to individual modalities (Supp. Table 14).
- **Cost:** uni-modal wall time 153.5 ± 3.3 min versus 1.6 min (MLE), 27.9 min (FLIPD), 42.8 min (RRA), 127.7 min (ARD-VAE) — only the 2282-min loss-cliff baseline is slower. On raw Audio MNIST, FiGuRO (60.5 min) beats JIVE (300.0) and ShIndICA (507.8) but remains slower than SLIDE (14.4) and AJIVE (19.0).

## Critical Assessment

**Novelty (moderate-high).** The individual ingredients are all borrowed — truncated-SVD rank reduction from ARR (Mounayer et al., 2025), weight-matrix factorization from LoRA, the shared/private split from Bousmalis/Lee & Pavlovic, rate-distortion framing from standard information theory. What is new is the closed-loop controller that uses per-modality reconstruction fidelity to arbitrate rank moves across subspaces, and the observation that this alone produces disentanglement. That is a real and useful contribution, but it is engineering-flavored rather than theoretically deep; the "theoretical guarantees" are convergence-in-finite-time statements conditioned on the encoder/decoder being sufficient function approximators and the distortion metric being a stable proxy — assumptions that do most of the work.

**Rigor (mixed).** The multi-modal comparison is the strongest part, with 5 seeds and SEMs. But the headline "average deviation from ground truth" metric is dominated by outliers and flatters FiGuRO. AJIVE's 36.3 comes almost entirely from two blowups (197 and 196 on the Bs/Bi2 private-1 subspaces); on Bi1 AJIVE returns 21/2/3 against GT 20/2/2, which is *better than FiGuRO's* 13.4/4.4/4.0, and on Bi2 AJIVE nails the private-2 rank at 20 versus FiGuRO's 19.4. A median-deviation or per-dataset win count would tell a noticeably less one-sided story, and the paper never reports one.

**A serious data quirk the paper itself surfaces but does not fully confront.** Supplementary Table 3 reports the *effective* rank of the ground-truth generative matrices: for Bl, the shared matrix has effective rank **1.63** despite being built from 20 generative variables, and Bl's private subspaces have effective ranks 18.55 and 10.23. The authors invoke this to excuse underestimation on Bi1 shared (effective rank 6.61 vs 20 variables) — but the same argument implies that FiGuRO's 19.2 estimate on Bl shared, scored as its best result, is a ~12× *overestimate* of that subspace's effective rank. The "ground truth" labels in Table 2 are therefore not a clean oracle, and both the winning and losing numbers should be read with that caveat.

**Overclaiming on the uni-modal side.** The text says FiGuRO "was the only framework to provide consistent, close-to-accurate estimates across both regimes", yet its own C₂ estimate of 5.7 against GT 12 is off by more than half, and Supplementary Table 2's own footnote concedes FLIPD's overestimation stems from backbone capacity rather than method failure. FiGuRO's C₂ estimate varies from 4.3 to 11.7 across λ, so the value nearest ground truth (11.7) is *not* the one produced by the recommended λ = 0.05 configuration — a sign that λ is doing more selection than the "robustness" narrative admits.

**Weak baseline choices.** The ablation's SVD-only variant is close to a straw man: without any stopping criterion, unconstrained energy pruning collapsing to rank 1 is the expected outcome, so the ablation establishes that *some* stopping rule is needed, not that *this* rule is better than, say, a simple loss-threshold or elbow heuristic. No comparison against a fixed-dimension model swept over k (the obvious practitioner's baseline) is reported for the real datasets. Multi-modal contrastive methods (CLIP-style), explicitly named in the related work as the state of the art that "implicitly adapts to shared ID", are never actually run as a baseline.

**Leakage in the real-data results.** On So2Sat, FiGuRO's private-2 accuracy is 0.44 ± 0.01 where lower is better — the *worst* of all methods (SLIDE 0.26, AJIVE 0.29) and higher than the uni-modal 0.38. So class information leaks into the private image subspace exactly where the paper claims clean separation. Similarly the Audio MNIST private-1 accuracy of 0.49 ± 0.06 is not obviously "disentangled".

**Reproducibility (good).** Code is public, hyperparameters ({λ=0.05, τ=10, γ=0.01, π=10}) are stated, hardware is specified (RTX A5000 + Threadripper PRO 3975WX), wall times are reported, and baseline parameterizations are in Appendix B.8. Seed counts are small (3 for most tables, 5 for Figure 3), which for a method whose Bs private-2 estimate has SEM 1.8 on a GT of 5 is thin.

**Significance (moderate).** For practitioners doing multi-omics or remote-sensing fusion who currently guess latent widths, this is a directly usable tool, and the "probe a frozen foundation model" mode is the most likely path to broad adoption. It is unlikely to displace fast local estimators (MLE, TwoNN) for quick uni-modal ID checks given the ~100× wall-time gap.

**Red flags:** the outlier-dominated aggregate metric; the "only framework" claim contradicted by its own FLIPD row; validation of the Audio MNIST ID against a 7–25 literature *range* wide enough that almost any answer between 7 and 25 would have "confirmed" the method; no contrastive/CLIP baseline despite it being the stated state of the art.

## Strengths

- Solves a genuinely under-served problem: nobody else outputs explicit, separate shared and per-modality IDs from a single neural training run.
- The rate-distortion framing makes the single main knob λ semantically meaningful ("how much reconstruction fidelity am I willing to give up"), which is much more interpretable than a KL weight β or an energy threshold.
- The bidirectional (grow as well as shrink) update is empirically justified, not decorative: 3D-manifold experiments show ranks dropping too low and being corrected back up, and the SVD-only ablation collapses without it.
- Honest negative results are reported rather than buried — regularizers hurt, γ is sensitive when too small, SNR < 7 causes overestimation, FiGuRO is slower than the classical decompositions on small data.
- Scales linearly in N and d with an MLP backbone, versus the quadratic-in-max(N,d) multi-view baselines, and demonstrably works on frozen Stable Diffusion / Depth Anything V2 features.
- The recommendation to run FiGuRO at both low and high λ to bracket the ID is a practical, appropriately humble deployment recipe.

## Limitations

- Estimates are conditional on the backbone's expressivity and nonlinearity; the method estimates the ID *a given architecture can realize*, not an architecture-free property of the data.
- Underestimation failure modes are acknowledged but not fixed: correlated generative variables, information leakage between subspaces, and a conservative distortion metric all bias ranks downward (Bi1 shared 13.4 vs GT 20, Bl private-1 12.8 vs GT 20), while Bi2 shared is overestimated at 7.0 vs GT 2.
- Only two-modality settings are evaluated; the algorithm's shared-rank arbitration rule ("assign k_s if all modalities agree") has an obvious tie-breaking problem for M > 2 that is never tested.
- Compute cost is substantial (153.5 min on dataset C versus 1.6 min for MLE), and the required full-rank pre-training phase must converge before rank optimization can even start.
- Three seeds for most tables; several reported SEMs (e.g. 6.2 ± 1.8) are large relative to the gaps being claimed.
- Real-data validation is necessarily indirect — there is no ground-truth ID for Audio MNIST, So2Sat or NYU Depth V2, so "correctness" is argued from literature ranges, domain plausibility (images get more dimensions than radar/depth) and downstream accuracy.
- γ ≥ 0.01 is recommended empirically rather than derived, and the distortion-metric choice (R² vs MSE) shifts Audio MNIST shared ranks by up to 6 dimensions (Supp. Table 15).

## Relevance

如果你关注多模态表示学习的可解释性、低秩/LoRA 类瓶颈设计，或需要判断某个昂贵模态（如蛋白组、SAR）到底贡献了多少独立信息，这篇给出了一个可直接套在冻结基础模型嵌入之上的轻量探针，且只需调一个语义明确的失真预算 λ。对做本征维度估计、rate-distortion 视角的表示压缩、或多组学数据融合的研究者尤其值得一读。

## Questions for Further Exploration

- How does FiGuRO compare against the obvious practitioner baseline — sweeping a fixed bottleneck width k and picking the loss elbow — on the *real* datasets, where the loss-cliff baseline was only run on simulations?
- Given that the paper names CLIP-style contrastive models as the state of the art for implicit shared-ID adaptation, what does the implicit shared ID of a CLIP model trained on these datasets actually look like relative to FiGuRO's explicit k_s?
- The shared-rank arbitration rule is defined for the two-modality case where modalities either "agree" or not. What happens with 3+ modalities where some share information pairwise but not globally — does FiGuRO need a lattice of pairwise-shared subspaces?
- Since Supplementary Table 3 shows ground-truth generative matrices with effective ranks far below their variable counts, would evaluating against *effective* rank rather than variable count reorder the Table 2 leaderboard?
- Can the λ-bracketing recommendation be turned into a calibrated interval — i.e. is there a principled mapping from (λ_low, λ_high) to a confidence range on the ID?
- Does the emergent disentanglement survive when modalities are only weakly paired or partially missing, which is the realistic regime for clinical multi-omics?
- The conclusion floats continual learning as an application. Does the grow-ranks branch actually let a converged model re-expand capacity when a distribution shift arrives, or does the patience-based termination lock it out?
