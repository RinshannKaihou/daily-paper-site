Critical edge

The null may be a statistical artifact. Γ is heavy-tailed, IoU is zero-inflated (most tokens have IoU = 0), and the paper never specifies Pearson vs Spearman nor runs a rank-based robustness check.

01Methodology — a three-pass causal probe inside the ViT

Run the vision tower three times — clean, corrupted, and singly-patched — and ask: how much of the lost image–text similarity does one (layer, token) activation restore?

A clean pass feeds the original image and records s_clean = ⟨f_img(I), f_text(T)⟩. A corrupted pass feeds a degraded image (Gaussian noise, later DDPM noise or blur) and records s_corr. A patched pass restores one intermediate ViT activation at (layer l, token t) from the clean run, recording s_patch. The causal contribution is the fraction of the gap recovered:

Γl,t  =  ( s_patch − s_corr ) / ( s_clean − s_corr )

For spatial grounding, each patch token is mapped back to its fixed image region Pt, and IoU(P_t, B) is computed against the referring-expression ground-truth box. The headline statistic is Corr(Γ, IoU), with a layer-resolved Corr_l testing whether alignment emerges with depth. Experiments run in three stages: (1) CLIP as a clean contrastive testbed; (2) the identical protocol on six VLMs under DDPM + blur with 6–10 seeds; (3) a planned longitudinal ViT-vs-SigLIP study — explicitly future work.

03Strengths vs. Limitations

Strengths

  • Genuinely causal. Γ is an intervention, not an attention/saliency heuristic — a real methodological step up from attention-map grounding.
  • Robustness discipline. Two corruption operators (DDPM + blur) and 6–10 seeds for most models, with mean ± std reported.
  • Pre-empts the obvious rebuttal — "there are no causal tokens" — by reporting per-model max Γ.
  • Clean probe design. String puzzle holds geometry fixed, varies only colour, isolating appearance dependence.
  • Honest in places: flags Γ can exceed [0,1], that SmolVLM's single run can't support statistics, and that ViT results may not transfer to SigLIP.

Limitations

  • ViT-only. SigLIP encoders (many current VLMs) are deferred — architectural generality untested.
  • Coarse IoU. Fixed axis-aligned patches around small objects guarantee low IoU regardless of representation, biasing correlation downward.
  • Zero-inflated IoU unaddressed. Needs a top-k / rank-based analysis before the null reads as a claim about representations.
  • Similarity surrogate undefined for autoregressive VLMs (Qwen-2.5, LLaVA) — only image–text similarity is used for CLIP.
  • String probe is thin: one proprietary model, one dataset instance, no accuracy table, no baseline, no human ceiling.

04Open questions for follow-up

  1. Artifact or finding? Does Spearman, or a top-k analysis restricted to tokens whose patches touch the box, change the near-zero correlation?
  2. Where is the positive control? Run the same pipeline on GLIP / Grounding DINO / a segmentation-supervised encoder — does Corr(Γ, IoU) rise? If not, the instrument itself is suspect.
  3. Which sub-module is patched — residual stream, attention output, or MLP output — and does the correlation differ across them?
  4. What do high-Γ / low-IoU tokens encode? Register tokens? Attention sinks? Background-scene globals? Clustering would turn a negative result into a mechanistic account.
  5. Does weak alignment predict failures? Do low-Corrr samples correlate with referring-expression comprehension errors — connecting interpretability to task behaviour?
