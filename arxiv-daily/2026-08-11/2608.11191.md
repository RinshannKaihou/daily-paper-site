> **一句话总结：** 该文提出 Test-Time Self-Evolving 框架，用一个 GRPO 训练的 MLLM Reflector 在无标注测试界面上评判并"反思"grounding 预测，再通过 Reflection-Guided On-Policy Self-Distillation（R-OPSD）+ Contrastive Calibration 把自然语言反思转成 token 级监督写回权重，使 Qwen2.5-VL-3B 在六个 GUI grounding benchmark 上的平均准确率从 50.2% 提升到 57.6%（+7.4），并比测试时强化学习基线 GUI-RCPO（49.9%）高 7.7 个点。

> **TL;DR:** A test-time adaptation framework for GUI visual grounding that replaces sparse scalar rewards with an MLLM Reflector's textual reflections, internalized via on-policy self-distillation with a reflection-conditioned self-teacher and a contrastive-calibration trick that kills corrupted supervision from wrong autoregressive prefixes. Adapting Qwen2.5-VL-3B on unlabeled MMBench-GUI lifts the 6-benchmark average from 50.2% to 57.6% (+7.4), versus 49.9% (-0.3) for the test-time RL baseline GUI-RCPO — a 7.7-point gap; ScreenSpot-Pro rises 20.3 → 30.1.

## 核心贡献

- **Test-Time Self-Evolving 闭环框架**：将部署后自适应形式化为 Exploration → Evaluation → Reflection → Internalization 四阶段循环，第一次让 GUI grounding 模型在无 ground-truth 标注的未见界面上"从失败中学习"，而不仅是从稀疏成功/失败奖励中学习。
- **MLLM-based Reflector**：用 GRPO（format reward + binary reward）在 GroundCUA 上训练一个评判器，输入截图/指令/预测坐标，输出 `<think>` 步骤化诊断 R 与 `<answer>` 二值判定 S；判定准确率 89.5%（Qwen2.5-VL-3B）/ 91.7%（Qwen3-VL-2B），显著高于 zero-shot 的 76.5% / 80.5%。
- **Reflection-Guided On-Policy Self-Distillation (R-OPSD)**：以模型自身作为条件化 self-teacher（prompt 中注入 S 与 R 作为 privileged information），token 级 advantage 为 log πG(Bi|·, L(S,R)) / log πG(Bi|·, L)，把自由文本反思转化为坐标 token 上的稠密监督。
- **Contrastive Calibration (CC)**：用"反向提示学生"（谎称失败预测是正确的）作为对比分母，使首个错误 token 得到强负 advantage、而后续漂移 token 的 advantage 衰减到近似 0（实测 |ā| 从 1.34 降到 0.0033），避免错误前缀污染监督信号。
- **工程可行性**：πG 与 πR 共享一个 base model，仅切换 LoRA adapter，3B/2B 模型显存约 10GB，7B/8B 约 30GB；R-OPSD (w/ CC) 训练时间仅为标准 GRPO 的 0.34×。

## Key Contributions

- Formulates post-deployment GUI grounding adaptation as a closed loop of Exploration, Evaluation, Reflection, and Internalization, arguing (and empirically showing) that scalar-reward TTRL cannot exploit *why* an exploration failed.
- Introduces a GRPO-trained MLLM Reflector that emits both a binary verdict S and a step-by-step textual diagnosis R, trained on ~10,160 balanced prediction-label pairs mined from GroundCUA with a mixed-outcome filtering strategy (keep only instructions whose 8 rollouts contain both a hit and a miss).
- Proposes R-OPSD: a self-teacher that is the *same* policy conditioned on privileged (S, R), yielding per-token advantages over the coordinate tokens — the first application of on-policy self-distillation to test-time adaptation for GUI grounding, per the authors.
- Proposes Contrastive Calibration, an inverse-prompted student baseline that suppresses the first incorrect token and decays advantage on drifted tokens, plus direction-based advantage clamping (max(0,a) if S=1, min(0,a) if S=0) and optional fusion with the GRPO query-level advantage Â = Â_GRPO + λa (λ=0.2).
- Shows the internalization mechanism doubles as a general unsupervised training algorithm: trained on the GUI-R1 training set with images/instructions only (no labels), it lifts Qwen2.5-VL-3B from 80.4 → 87.8 on SSv2.

## Methodology

The setup is standard GUI grounding: given screenshot I and instruction L, a policy πG emits a bounding box or center point B. At test time no annotations exist, so evaluation is delegated to a Reflector πR that consumes (I, L, B) and returns S ∈ {0,1} plus a free-form reflection R. The Reflector's prompt forces a four-step chain (intent analysis → coordinate grounding → verification → conclusion) wrapped in `<think>`/`<answer>` tags; it is trained once offline via GRPO with r = r_format + r_binary on 10K GroundCUA samples (lr 1e-4, group size 8, batch 64, 1 epoch) and then frozen. Notably, the authors tried a 30K-trajectory SFT cold start distilled from "Qwen3.7-plus" and report *no* noticeable gain over direct RL.

Internalization is where the paper's novelty sits. Vanilla on-policy distillation defines a token-level advantage a_i = log[πT(B_i|B_<i)/πG(B_i|B_<i)]. Here πT is not a stronger external model but πG itself re-prompted with privileged information: on success the teacher prompt says "the previous prediction B has been verified correct"; on failure it supplies "Previous wrong prediction: B / Feedback: R" and asks for the corrected box. The objective is L = -(1/T) Σ sg(a_i) log πG(B_i|·).

The failure mode this creates is that once the policy emits a wrong coordinate token, everything after it is conditioned on a corrupted prefix, so teacher probabilities become meaningless. Contrastive Calibration replaces the denominator πG(·|L) with an *inverse-prompted student* πG(·|L(¬S)) that is told the failed prediction was correct. At the first error step the inverse student is confident in the wrong token while the reflection-guided teacher is not, producing a large negative advantage; as the prefix drifts, both distributions are conditioned on the same garbage and converge, so a_i → 0. Fig. 4 quantifies this: without CC the initial-error advantage is only -0.39 and drifted tokens carry |ā| = 1.34 of corrupted signal; with CC the initial error gets -0.97 and drifted tokens decay to 0.0033. CC is applied only to failed explorations.

Implementation shares one base model between πG and πR via LoRA adapter switching (≈10GB for 3B/2B, ≈30GB for 7B/8B), rollout temperature 1.0 / top-p 0.95, 2 epochs, lr 1e-4, batch 64, λ = 0.2. Adaptation data is the unlabeled image+instruction stream of ScreenSpot-v2 or MMBench-GUI; evaluation spans ScreenSpot, ScreenSpot-v2, ScreenSpot-Pro, OSWorld-G, OSWorld-G-Refine, MMBench-GUI with Element Accuracy.

## Results & Highlights

- **Main table (Qwen2.5-VL-3B, adapt on MMBench-GUI):** 6-benchmark average 57.6% vs base model 50.2% (+7.4) and vs GUI-RCPO 49.9% (-0.3 from base) — a 7.7-point gap over the only test-time-adaptation baseline. Adapting on ScreenSpot-v2 instead gives 57.4% (+7.2) vs GUI-RCPO 53.4% (+3.2).
- **Hardest benchmark, ScreenSpot-Pro:** 20.3% (base) → 30.5% (ours, adapt SSv2) vs 24.8% for GUI-RCPO, i.e. +10.2 absolute over base and +5.7 over the baseline. On MMBench-GUI: 57.5% → 68.2% (ours) vs 58.2% (GUI-RCPO).
- **Stronger backbone, Qwen3-VL-2B:** average 65.7% → 70.3% (+4.6, adapt MMG) vs GUI-RCPO 65.6% (-0.1); SSv2 87.6 → 91.5, ScreenSpot-Pro 42.8 → 49.3.
- **Scale-up (Table 6):** Qwen2.5-VL-7B on MMG 68.2 → 79.2 (ours) vs 70.9 (GUI-RCPO); Qwen3-VL-8B 82.7 → 84.7 vs 83.4 — note the 8B gains shrink to +2.0, i.e. the method's headroom narrows as the base model strengthens (ScreenSpot-Pro 53.5 → 56.3, only +2.8).
- **Ablation (Table 2, Qwen2.5-VL-3B):** the naive OPSD baseline using only S as privileged info suffers *catastrophic policy collapse* (marked ×), as does the reflection-without-CC variant. Adding reflection lifts ScreenSpot-Pro from 24.6% to 28.5% when adapting on SSv2; adding CC turns a collapsing configuration into 64.3% on MMG; direction-based clamping and query-level advantage fusion push the final numbers to 88.8 / 30.5 / 66.6 (SSv2 / SSP / MMG).
- **R-OPSD vs scalar-reward RL (Table 3):** TTRL-style averaged-bbox pseudo-labels give 84.3 / 24.6 / 61.7 (adapt SSv2) and actually cause negative transfer on MMG (57.5 vs 57.5 base, and 55.8 with a GUI-G² reward). Using the Reflector's binary S as a GRPO reward reaches 85.4 / 25.9 / 62.3; full (S, R) supervision reaches 88.8 / 30.5 / 66.6 — a ~3.4–4.6 point gain attributable to the textual reflection rather than to the Reflector's verdict alone. The competing OPSD method GUI-SD (bbox drawn into the image) *degrades* below base: 78.5 / 16.7 / 52.3.
- **Reflector reliability (Table 4):** accuracy/precision/recall of 89.5 / 86.9 / 93.3 (Qwen2.5-VL-3B) and 91.7 / 88.8 / 95.7 (Qwen3-VL-2B) on 1,000 held-out balanced pairs, vs zero-shot 76.5 / 72.9 / 85.4 and 80.5 / 78.9 / 86.0.
- **Cost (Table 5):** GRPO+GUI-RCPO 449 min; R-OPSD w/o CC 129 min (0.29×), w/ CC 151 min (0.34×), but the full framework with query-level advantage re-introduces K=8 group rollouts and costs 778 min (1.73×).
- **Modality ablation (Tables 7-8):** representing the prediction as a drawn red box instead of textual coordinates drops Reflector accuracy from 91.7% to 78.3% and drives the full method into negative transfer (77.3 / 18.3 / 53.2, i.e. below the 80.4 / 20.3 / 57.5 base).
- **Unsupervised training transfer (Table 9):** on ~3,000 unlabeled GUI-R1 training samples, 80.4 → 87.8 (SSv2), 20.3 → 29.2 (SSP), 57.5 → 67.2 (MMG).

## Critical Assessment

**Novelty (moderate-high).** The specific contribution — Contrastive Calibration via an inverse-prompted student — is a genuinely clever and cheap fix to a real problem in on-policy self-distillation (corrupted prefixes), and the Fig. 4 measurement (|ā| 1.34 → 0.0033) is the kind of mechanistic evidence one wants. That said, the surrounding parts are recombination: on-policy self-distillation with a privileged-information self-teacher already exists (OPSDL, Self-Distilled Reasoner, GUI-SD), and the "reflect then internalize" loop is the standard self-improvement template. The "first to apply OPSD to test-time GUI grounding" claim is narrow enough to be safe but not very informative.

**Rigor (mixed).** Only one test-time-adaptation baseline (GUI-RCPO) is compared, and it is a notably weak one here: it produces *negative* transfer (-0.3, -0.1) when adapting on MMBench-GUI, so the headline "+7.7 over GUI-RCPO" is partly a story about the baseline failing rather than the method winning. TTRL is reimplemented only as an averaged-bbox pseudo-label reward, which the authors themselves show is broken on complex data — a stronger TTRL variant (e.g., majority voting over discretized regions, or self-consistency filtering) is not tried. Crucially, Table 1's own GUI-specific models beat the adapted 3B model on the in-domain benchmarks: GUI-Actor-3B reaches 91.0 and GUI-G²-3B 91.0 on SSv2 vs the paper's 88.8, and FocusUI-3B reaches 43.8 on ScreenSpot-Pro vs the paper's 30.5. The framework is complementary rather than SOTA, but the text does not acknowledge this.

**A concrete data quirk / inconsistency.** Table 4 reports the trained Reflector at 89.5% for Qwen2.5-VL-3B and 91.7% for Qwen3-VL-2B, but Table 7 lists "Qwen2.5-VL-3B (Zero-shot) 76.5 / Trained Reflector 91.7 / 88.8 / 95.7" — i.e. Table 7 pairs the Qwen2.5-VL-3B zero-shot row with the Qwen3-VL-2B trained row, and the appendix text ("outperforming the zero-shot base model by 15.2%") repeats this mismatch. Either a typo or a mislabeled table; it undermines the visual-prompting ablation's precision.

**Overclaiming on "without ground truth."** The test-time loop uses no labels, but the Reflector is trained with GRPO on 10K GroundCUA samples whose S* labels come from ground-truth bounding boxes. The pipeline therefore consumes human annotation, just relocated upstream — and the Reflector's ~90% accuracy (≈10% mislabeled supervision) is the silent ceiling of the whole method. There is no ablation isolating this: no oracle-Reflector upper bound, no degraded-Reflector sweep showing at what verdict accuracy the loop breaks. Given that (a) and (f) both *collapse catastrophically*, the stability margin appears thin, and the paper never reports seed variance or error bars anywhere.

**Other missing ablations.** No results on how much of the gain is transductive (adaptation is performed on the very images used for evaluation when adapting and testing on SSv2/MMG); the cross-benchmark cells like adapt-on-SSv2 → ScreenSpot-Pro are the honest generalization evidence and they are strong (+10.2), so the paper would have been better served by foregrounding them. λ is swept only on two adaptation/evaluation pairs. No analysis of how many test-time samples are needed. The 1.73× cost of the full framework contradicts the efficiency framing carried by the 0.34× R-OPSD-only row.

**Reproducibility (uncertain).** Hyperparameters, prompt templates, dataset construction, and hardware are all specified in enough detail to reimplement; the Reflector dataset and code are promised. Absent release, the LoRA adapter-switching scheme and the exact GRPO implementation are the main reimplementation risks.

**Significance.** Real, if bounded. Post-deployment adaptation without labels is a genuine gap for GUI agents, and turning a verifier's natural-language critique into token-level gradients is a pattern that plausibly transfers to other structured-output vision tasks. The shrinking gains at 8B scale (+2.0 average) hint that the method mainly recovers capability that stronger models already have.

## Strengths

- The Contrastive Calibration mechanism is well-motivated, cheap (one extra forward pass), and supported by a direct measurement of the advantage profile rather than only end-task numbers.
- Honest reporting of failure configurations: two ablation rows are marked as catastrophic collapse rather than quietly dropped, and the visual-prompting variant is shown to be strictly worse than the paper's textual design.
- Broad benchmark coverage (six benchmarks, four backbones from 2B to 8B) with consistent direction of effect, including the hard ScreenSpot-Pro where the base model is near-floor.
- The negative result on SFT cold start (30K synthetic trajectories yielding no gain) is reported despite being unflattering.
- Memory-conscious engineering (single shared base model, LoRA role switching, ~10GB for 3B) makes the method deployable rather than purely academic.

## Limitations

- Requires an offline, ground-truth-labeled dataset to train the Reflector, so the "annotation-free" claim holds only for the online phase.
- Performance is upper-bounded by Reflector verdict accuracy (~90%), with no sensitivity study on that dependency and no oracle upper bound.
- Only one test-time-adaptation competitor, which itself regresses below base on one adaptation set.
- Full framework costs 1.73× GRPO wall-clock; the efficient variant (0.34×) is the weaker configuration.
- No variance/seed reporting anywhere; several ablation configurations collapse entirely, suggesting brittleness to hyperparameters.
- Gains shrink markedly on strong backbones (Qwen3-VL-8B: +2.0 average), and the method still trails specialized GUI grounding models on in-domain benchmarks.
- Evaluated only on single-step grounding accuracy; no end-to-end agent task success (e.g., OSWorld execution) demonstrating that grounding gains translate to task completion.
- Table 4 / Table 7 Reflector numbers are internally inconsistent.

## Relevance

如果你关注 GUI agent、test-time adaptation/TTRL、以及 on-policy distillation 作为 RLVR 的替代信号形式，这篇文章给出了一个具体可复用的范式：用 verifier 的自然语言批评替代标量奖励，并通过"反向提示学生"作对比分母来抑制自回归前缀污染——这个 CC 技巧本身可迁移到任何结构化输出（坐标、代码、公式）的自蒸馏场景。同时它也是一个值得警惕的案例：所谓"无标注自进化"其实把标注成本转移到了离线 Reflector 训练上。

## Questions for Further Exploration

- What is the oracle upper bound? If the Reflector's S were replaced with ground-truth correctness (keeping R generated), how much of the +7.4 remains — i.e., how much comes from verdict accuracy versus from reflection content?
- Does Contrastive Calibration generalize beyond coordinates to other autoregressive structured outputs (code, SQL, math), where prefix corruption is equally destructive?
- How does performance scale with the amount of unlabeled test-time data, and does the loop saturate, oscillate, or eventually collapse under repeated self-evolution rounds?
- Would a Reflector trained on a *different* base model (breaking the shared-LoRA design) improve reliability, or does the self-teacher benefit from distribution matching with πG?
- Do the grounding gains translate to end-to-end agent task success on OSWorld/AndroidWorld, or is single-step element accuracy a poor proxy?
- Can the query-level advantage (which triples cost via K=8 rollouts) be replaced by a cheaper variance-reduction scheme to keep the 0.34× efficiency while retaining the ~2-point gain it contributes?
- Why does the visual bounding-box prompt hurt so much (91.7% → 78.3% Reflector accuracy)? Is this a Qwen-specific artifact of drawn-annotation robustness, or a general property of MLLM spatial verification?
