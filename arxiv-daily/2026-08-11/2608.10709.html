Route teacher features through the student's own quantizer and the irreducible floor on distillation loss vanishes.

SQuaT: Self-Supervised Knowledge Distillation via Student-Aware Quantized Teacher Features

HyeonJun Lee, Hyeonsik Jo, et al. · Kookmin University · 2026-08-11 · AISTATS 2026

Key metric

+1.74 pp

CIFAR-100 · ResNet-32 · W1A1

59.38 → 61.12 vs label-free SQAKD — and it beats the supervised EWGS baseline (59.76) by +1.36 pp.

Why this matters

A near-zero-cost, label-free trick that drops into any QAT pipeline — strongest at 1–2 bit where edge deployment actually bites.

Critical edge

Zero distillation loss ≠ better accuracy: a degenerate all-zero target trivially hits the lower bound the theory celebrates.

Methodology 01

SQuaT adds a single operator: ΠφS,ℓ(z) — route the teacher's layer-ℓ feature through the student's own learned forward-quantization path. Both models now read on the identical lattice; quantized values carry the same semantics.

Theorem 1. With FP targets, the loss has an irreducible floor E‖Π(fT) − fT‖² that grows monotonically as teacher activations fall outside the student's learned clipping range. With student-quantized targets, that floor is exactly 0.

The objective is feature L2 + temperature-scaled KL on logits — fully label-free, teacher frozen. CNNs run EWGS-based QAT, Transformers run STE. Despite the general multi-layer formulation, every experiment uses |K| = 1 (a single layer near the network output). Single RTX A6000, PyTorch 2.8.0.

Open questions 04

  1. Is the projected target f̃T detached? If not, gradients into φS via the target create a moving-target objective minimizable by shrinking the range — does (a⁻, a⁺) degenerate?
  2. Since zero residual is trivially reachable by degenerate targets, what blocks uninformative alignment? A randomly-quantized teacher would be the right negative control.
  3. Does the gain survive |K| > 1 — distilling at several depths where lattices differ per layer?
  4. Does it beat simply widening the student's clipping range, or clipping FP teacher features without discretizing — isolating range mismatch from lattice error?
  5. Why does Teacher-aware projection underperform Non-aware so consistently — calibration budget, or genuine lattice misalignment?
  6. Do the +8.48 pp GLUE/RTE gains survive more seeds and larger tasks (MNLI, CoLA), or is it small-dataset variance?

Strengths & limitations 03

  • One-line, parameter-free operator — no teacher-side quantizer to pretrain, unlike QFD.
  • The projection ablation is the right experiment; "teacher-aware worse than doing nothing" is a genuinely useful negative result.
  • Unusual breadth for a small lab: CNN + ViT + BERT, 5 quantizers, 4 losses, 4 bit-widths + a real edge measurement.
  • Gains land exactly where the theory predicts — extreme low-bit, where teacher features most often exit the student's clipping range.
  • Theorem is short, correct, and honestly scoped to the loss (not dressed up as an accuracy guarantee).
  • ImageNet gains within / at noise for ≥3 bits (+0.02 to +0.19 pp) — large-scale evidence is weak.
  • QFD — the direct motivation — is never run as published; only a re-implementation appears as an ablation arm.
  • Only one distillation layer is ever used; the multi-layer generalization is untested.
  • Table inconsistencies (61.12 vs 61.02; DeiT-Tiny CIFAR-100 FP 97.33, higher than its CIFAR-10 FP, likely a copy error).
  • Seed count unreported; several headline deltas (±0.02, ±0.07, ±0.19) sit at or below the stated std devs.
